@ 10 | Στον γιατρό | En el médico
I Aprende a explicar un problema de salud y a pedir ayuda con frases básicas.
E Decir qué te pasa :: **Πονάω** significa «me duele» o «tengo dolor». Puedes nombrar la parte del cuerpo: **Πονάει το κεφάλι μου** (me duele la cabeza). :: **Έχω πυρετό** significa tengo fiebre. **Χρειάζομαι βοήθεια** es necesito ayuda. Si no entiendes, pregunta **Μπορείτε να το πείτε ξανά;** (¿puede repetirlo?).
W γιατρό = médico (acusativo) | yatró
W γιατρείο = consulta médica | yatrío
W πονάω = me duele, tengo dolor | ponáo
W πονάει = duele | ponái
W κεφάλι = cabeza | kefáli
W μάτι = ojo | máti
W χέρι = mano, brazo | jéri
W πόδι = pie, pierna | pódi
W κοιλιά = barriga | kiliá
W δόντι = diente | dóndi
W πυρετός = fiebre | piretós
W πυρετό = fiebre (acusativo) | piretó
W πόνος = dolor | pónos
W χρειάζομαι = necesito | jriázome
W βοήθεια = ayuda | voíthia
W φάρμακο = medicamento | fármako
W ξανά = otra vez | xaná
W πείτε = diga, digan | píte
W πάρτε = tome, tomen | párte
W πιείτε = beba, beban | píite
W μπορείτε = puede, pueden (cortés) | boríte
V Στον γιατρό
D Στο γιατρείο
Γιατρός: Τι σας πονάει; = ¿Qué le duele?
  > τι = qué | σας = a usted | πονάει = duele
Μαρία: Πονάει το κεφάλι μου. = Me duele la cabeza.
  > κεφάλι μου = mi cabeza
Γιατρός: Έχετε πυρετό; = ¿Tiene fiebre?
  > έχετε = tiene (cortés) | πυρετό = fiebre
Μαρία: Ναι, έχω λίγο πυρετό. = Sí, tengo un poco de fiebre.
  > ναι = sí | λίγο = un poco | έχω = tengo
Γιατρός: Πάρτε αυτό το φάρμακο και πιείτε νερό. = Tome este medicamento y beba agua.
  > πάρτε = tome | φάρμακο = medicamento | πιείτε = beba | νερό = agua
Μαρία: Ευχαριστώ. Μπορείτε να το πείτε ξανά; = Gracias. ¿Puede repetirlo?
  > ευχαριστώ = gracias | μπορείτε = puede | ξανά = otra vez
T Χρειάζομαι βοήθεια
- Πονάει το δόντι μου. = Me duele el diente.
- Πονάει το πόδι μου. = Me duele la pierna.
- Χρειάζομαι νερό. = Necesito agua.
Q ¿Qué significa «Πονάει το κεφάλι μου»?
+ Me duele la cabeza. :: «Κεφάλι» es cabeza.
- Me duele el diente. :: Diente es «δόντι».
- Tengo fiebre. :: Fiebre es «πυρετός».
Q ¿Qué palabra significa «medicamento»?
+ φάρμακο :: «Φάρμακο» significa medicamento.
- γιατρείο :: «Γιατρείο» es consulta médica.
- βοήθεια :: «Βοήθεια» significa ayuda.
R Έχω λίγο πυρετό.
+ Tengo un poco de fiebre. :: «Πυρετό» es la forma de «fiebre» en esta frase.
- Me duele la cabeza. :: Cabeza es «κεφάλι».
- Necesito agua. :: Necesito es «χρειάζομαι».
H Χρειάζομαι ___ .
+ βοήθεια :: «Βοήθεια» significa ayuda.
- πυρετό :: Significa fiebre.
- κεφάλι :: Significa cabeza.
A Πονάει το δόντι μου.
+ Me duele el diente. :: «Δόντι» significa diente.
- Me duele el ojo. :: Ojo es «μάτι».
- Me duele la pierna. :: Pierna es «πόδι».
O χρειάζομαι βοήθεια :: necesito ayuda :: «Χρειάζομαι» significa necesito.

@ 10 | Στο ταξίδι | De viaje
I Practica frases para llegar a un hotel, pedir una habitación y entender datos básicos de una reserva.
E Pedir alojamiento :: **Έχω κράτηση** significa tengo una reserva. **Θα ήθελα ένα δωμάτιο** significa quisiera una habitación. :: **Θα πάω** significa iré/ voy a ir; **θέλω να πάω** significa quiero ir. Para preguntar por una habitación, puedes decir **Έχετε δωμάτιο;** (¿tiene habitación?).
W ταξίδι = viaje | taxídi
W ταξιδεύω = viajo | taxidévo
W κράτηση = reserva | krátisi
W μονόκλινο = individual (habitación) | mónoklino
W δίκλινο = doble (habitación) | díklino
W μία νύχτα = una noche | mía níjta
W νύχτα = noche | níjta
W νύχτες = noches | níjtes
W θα πάω = iré, voy a ir | tha páo
W θέλω να πάω = quiero ir | thélo na páo
W τριάντα = treinta | triánda
V Στο ξενοδοχείο
D Στη ρεσεψιόν
Υπάλληλος: Καλησπέρα. Έχετε κράτηση; = Buenas tardes. ¿Tiene una reserva?
  > καλησπέρα = buenas tardes | έχετε = tiene | κράτηση = reserva
Ταξιδιώτης: Ναι, έχω κράτηση για μία νύχτα. = Sí, tengo una reserva para una noche.
  > ναι = sí | έχω = tengo | μία νύχτα = una noche
Υπάλληλος: Θέλετε μονόκλινο ή δίκλινο δωμάτιο; = ¿Quiere una habitación individual o doble?
  > θέλετε = quiere | μονόκλινο = individual | δίκλινο = doble | δωμάτιο = habitación
Ταξιδιώτης: Ένα μονόκλινο, παρακαλώ. Πόσο κοστίζει; = Una individual, por favor. ¿Cuánto cuesta?
  > ένα μονόκλινο = una individual | πόσο κοστίζει = cuánto cuesta
Υπάλληλος: Τριάντα ευρώ. = Treinta euros.
  > τριάντα = treinta | ευρώ = euros
Ταξιδιώτης: Ευχαριστώ. Θα πάω στο δωμάτιο τώρα. = Gracias. Iré a la habitación ahora.
  > ευχαριστώ = gracias | θα πάω = iré | τώρα = ahora
T Στο ταξίδι
- Θα πάω στην Αθήνα αύριο. = Iré a Atenas mañana.
- Θέλω να πάω στο ξενοδοχείο. = Quiero ir al hotel.
- Έχω κράτηση για δύο νύχτες. = Tengo reserva para dos noches.
Q ¿Qué significa «κράτηση»?
+ reserva :: «Έχω κράτηση» significa tengo una reserva.
- habitación :: Habitación es «δωμάτιο».
- viaje :: Viaje es «ταξίδι».
Q ¿Qué habitación es «μονόκλινο»?
+ individual :: Una habitación para una persona.
- doble :: Doble es «δίκλινο».
- grande :: Grande es «μεγάλο».
R Έχετε κράτηση;
+ ¿Tiene una reserva? :: «Έχετε» es la forma cortés.
- ¿Tiene una habitación? :: Habitación es «δωμάτιο».
- ¿Cuánto cuesta? :: Se pregunta «Πόσο κοστίζει;».
H Θα ___ στην Αθήνα αύριο.
+ πάω :: «Θα πάω» significa iré.
- θέλω :: «Θέλω» significa quiero.
- έχω :: «Έχω» significa tengo.
A Θέλω να πάω στο ξενοδοχείο.
+ Quiero ir al hotel. :: «Θέλω να πάω» significa quiero ir.
- Tengo una reserva en el hotel. :: Reserva es «κράτηση».
- Voy a la ciudad mañana. :: Ciudad es «πόλη».
O θα πάω στο ξενοδοχείο αύριο :: iré al hotel mañana :: «Θα πάω» es futuro sencillo.

@ 10 | Επανάληψη Α1 | Repaso final A1
I ¡Has llegado al final del primer nivel! En esta lección repasarás presentaciones, vida diaria, compras, direcciones y necesidades básicas.
E Antes de terminar :: En A1 puedes intercambiar información personal, entender frases cotidianas sencillas y producir mensajes breves. Puedes pedir que repitan o hablen más despacio: **Μπορείτε να το πείτε ξανά, παρακαλώ;** :: Repasa el género de los nombres y los artículos, las formas básicas del presente, las preguntas sencillas y expresiones útiles para pedir algo.
W λέγομαι = me llamo | légome
W μιλάτε = habla, hablan (cortés) | miláte
W πιο = más | pio
W αργά = despacio, tarde | argá
V Τελική επανάληψη
Q ¿Cómo dices «me llamo Ana»?
+ Με λένε Άννα. :: «Με λένε» es la fórmula de presentación.
- Πού μένω; :: Significa dónde vivo.
- Θέλω νερό. :: Significa quiero agua.
Q ¿Qué significa «Πού μένεις;»?
+ ¿Dónde vives? :: «Μένεις» es la forma tú de «vivo».
- ¿Qué quieres? :: Se pregunta «Τι θέλεις;».
- ¿Cuánto cuesta? :: Se pregunta «Πόσο κοστίζει;».
R Θα ήθελα ένα νερό, παρακαλώ.
+ Quisiera un agua, por favor. :: Una petición educada en un café.
- Quiero un café con leche. :: Café es «καφέ».
- Me gusta el agua. :: «Μου αρέσει» significa me gusta.
H Δεν ___ να πάω σήμερα.
+ μπορώ :: «Δεν μπορώ» significa no puedo.
- θέλω :: «Δεν θέλω» significa no quiero.
- έχω :: «Δεν έχω» significa no tengo.
A Μπορείτε να μιλάτε πιο αργά, παρακαλώ;
+ ¿Puede hablar más despacio, por favor? :: Una petición para facilitar la conversación.
- ¿Puede repetirlo mañana? :: Mañana es «αύριο».
- ¿Cuánto cuesta el billete? :: Billete es «εισιτήριο».
O μένω στην Αθήνα και δουλεύω :: vivo en Atenas y trabajo :: «Και» une las dos acciones.
X Escribe en griego: «gracias» :: ευχαριστώ :: ευχαριστώ
