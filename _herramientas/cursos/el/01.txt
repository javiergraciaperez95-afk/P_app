@ 1 | Το ελληνικό αλφάβητο 1 | El alfabeto griego (1)
I Empezamos con las letras griegas. Algunas se parecen a las latinas, pero pueden sonar distinto. Escucha y repite cada palabra con calma.
E Vocales y primeras letras :: El griego moderno tiene siete vocales: **α, ε, η, ι, ο, υ, ω**. Las letras **η, ι, υ** suenan como «i»; **ο** y **ω** suenan como «o». :: El acento escrito marca la sílaba que recibe más fuerza: **νερό**. La letra **ς** se escribe solo al final de palabra; en los demás lugares se usa **σ**.
B Vocales | Letra | Sonido aproximado
| α | a
| ε | e
| η / ι / υ | i
| ο / ω | o
W α = alfa | alfa
W ε = épsilon | épsilon
W η = eta | ita
W ι = iota | iota
W ο = ómicron | ómicron
W υ = ípsilon | ípsilon
W ω = omega | omega
W μαμά = mamá | mamá
W νερό = agua | neró
W ένα = uno, una | éna
W ναι = sí | ne
W όχι = no | óji
W και = y | ke
W καφέ = café | kafé
W γεια = hola, adiós | ya
W παρακαλώ = por favor | parakaló
W ευχαριστώ = gracias | efjaristó
V Las primeras palabras
D Στο μάθημα
Ελένη: Γεια! = ¡Hola!
  > Γεια = saludo informal
Αλέξης: Γεια! = ¡Hola!
  > Γεια = saludo informal
Ελένη: Νερό, παρακαλώ. = Agua, por favor.
  > Νερό = agua | παρακαλώ = por favor
Αλέξης: Ναι. = Sí.
  > Ναι = respuesta afirmativa
Ελένη: Ευχαριστώ! = ¡Gracias!
  > Ευχαριστώ = doy las gracias
T Λέξεις στον πίνακα
- νερό = agua
- καφέ = café
- μαμά = mamá
Q ¿Qué letra griega suena como «a»?
+ α :: La alfa suena «a».
- ε :: Épsilon suena «e».
- ο :: Ómicron suena «o».
Q ¿Qué vocales suenan como «i»?
+ η, ι y υ :: Las tres se pronuncian «i» en griego moderno.
- α, ε y ο :: Suenan «a», «e» y «o».
- ω e η :: Omega suena «o».
R νερό
+ agua :: «Νερό» significa agua.
- mamá :: «Μαμά» significa mamá.
- café :: «Καφέ» significa café.
H ___ :: ¿Qué significa «sí»?
+ Ναι :: «Ναι» significa sí.
- Όχι :: «Όχι» significa no.
- Ένα :: «Ένα» significa uno.
A Ευχαριστώ!
+ Gracias. :: «Ευχαριστώ» expresa agradecimiento.
- No. :: No es una respuesta negativa.
- Agua. :: Agua es «νερό».
O μαμά και νερό :: mamá y agua :: «Και» significa «y».
X Escribe en griego: «sí» :: ναι :: ναι

@ 1 | Το ελληνικό αλφάβητο 2 | El alfabeto griego (2)
I Seguimos con el alfabeto y aprendemos a leer palabras cortas. Fíjate en los grupos de letras: a veces dos letras juntas representan un solo sonido.
E Consonantes y combinaciones :: **β** suena como la «v» española; **δ** es parecido a la «th» sonora inglesa; **θ** es la «th» sorda. **χ** suena como una jota suave. :: Las combinaciones **αι, ει, οι, υι** suenan «e», «i», «i», «i». Las combinaciones **ου** suenan «u». En griego, **;** sirve como signo de pregunta.
B Combinaciones frecuentes | Letras | Sonido
| αι | e
| ει / οι / υι | i
| ου | u
| μπ | b (al principio)
| ντ | d (al principio)
W β = vita | víta
W γ = gama | gáma
W δ = delta | délta
W θ = zita | zíta
W χ = ji | ji
W ου = combinación «u» | u
W αι = combinación «e» | e
W ει = combinación «i» | i
W είμαι = soy, estoy | íme
W είσαι = eres, estás | íse
W είστε = es, está; sois, estáis | íste
W τι = qué | ti
W πώς = cómo | pós
W καλά = bien | kalá
W πολύ = mucho, muy | polí
V Letras y palabras
D Δύο μαθητές
Μαρία: Γεια! Πώς είσαι; = ¡Hola! ¿Cómo estás?
  > Γεια = hola | Πώς = cómo | είσαι = estás
Νίκος: Καλά, ευχαριστώ. = Bien, gracias.
  > Καλά = bien | ευχαριστώ = gracias
Μαρία: Είσαι καλά; = ¿Estás bien?
  > είσαι = estás | καλά = bien
Νίκος: Ναι, πολύ καλά. = Sí, muy bien.
  > ναι = sí | πολύ = muy
T Μικρές λέξεις
- είμαι καλά. = Estoy bien.
- είσαι καλά; = ¿Estás bien?
- είστε καλά; = ¿Está usted bien?
Q ¿Cómo se pronuncia «ου»?
+ u :: «Ου» representa el sonido «u».
- e :: «Αι» suena «e».
- i :: «Ει» suena «i».
Q ¿Qué significa «είμαι»?
+ soy, estoy :: «Είμαι» es la primera persona de «ser/estar».
- eres, estás :: «Είσαι» significa eres/estás.
- bien :: «Καλά» significa bien.
R Πώς είσαι;
+ ¿Cómo estás? :: «Πώς» es cómo y «είσαι» es estás.
- ¿Dónde estás? :: «Πού» significa dónde.
- ¿Estás bien? :: Esa pregunta sería «Είσαι καλά;».
H Είμαι ___ .
+ καλά :: La expresión «είμαι καλά» significa estoy bien.
- πολύ :: Significa muy; falta «καλά».
- τι :: Significa qué.
A Είστε καλά;
+ ¿Está usted bien? :: «Είστε» sirve para hablar con cortesía a una persona.
- ¿Cómo te llamas? :: Se pregunta «Πώς σε λένε;».
- Soy agua. :: No es el significado.
O είμαι πολύ καλά :: estoy muy bien :: «Πολύ» modifica a «καλά».
X Escribe en griego: «bien» :: καλά :: καλά

@ 1 | Χαιρετισμοί | Saludos y expresiones de cortesía
I Ya puedes descifrar letras y combinaciones. Ahora aprende saludos que usarás al llegar, despedirte y pedir algo con educación.
E Saludar con educación :: **Γεια σου** es informal; **Γεια σας** sirve para saludar a varias personas o dirigirse con cortesía a una persona. **Καλημέρα** se usa por la mañana; **Καλησπέρα** por la tarde y al anochecer. :: Para despedirse se puede decir **Αντίο**. **Παρακαλώ** significa «por favor» y también se usa al responder a «gracias».
W σου = a ti (informal) | su
W σας = a usted; a ustedes | sas
W καλημέρα = buenos días | kaliméra
W καλησπέρα = buenas tardes, buenas noches (al llegar) | kalispéra
W καληνύχτα = buenas noches (al despedirse) | kaliníjta
W αντίο = adiós | adío
W παρακαλώ = por favor; de nada | parakaló
W συγγνώμη = perdón, disculpe | signómi
W με = me, a mí | me
W σε = te, a ti | se
W θέλετε = quiere, desea (cortés) | thélete
W ορίστε = aquí tiene; dígame | oríste
W λένε = llaman | léne
W το = el, lo (neutro) | to
W όνομα = nombre | ónoma
V Χαιρετισμοί και ευγένεια
D Στο καφέ
Άννα: Καλημέρα σας! = ¡Buenos días!
  > Καλημέρα = saludo de mañana | σας = trato cortés
Κώστας: Καλημέρα. Τι θέλετε; = Buenos días. ¿Qué desea?
  > Τι = qué | θέλετε = desea (forma cortés)
Άννα: Νερό, παρακαλώ. = Agua, por favor.
  > Νερό = agua | παρακαλώ = por favor
Κώστας: Ορίστε. = Aquí tiene.
  > Ορίστε = expresión al entregar algo
Άννα: Ευχαριστώ πολύ. = Muchas gracias.
  > Ευχαριστώ = gracias | πολύ = mucho
T Πώς σε λένε;
- Πώς σε λένε; = ¿Cómo te llamas?
- Με λένε Μαρία. = Me llamo María.
- Γεια σας! = ¡Hola! (cortés)
Q ¿Qué saludo se suele usar por la mañana?
+ Καλημέρα :: «Καλημέρα» significa buenos días.
- Καληνύχτα :: Se usa para despedirse por la noche.
- Αντίο :: Significa adiós.
Q ¿Qué forma es cortés para «hola»?
+ Γεια σας :: «Σας» expresa cortesía o plural.
- Γεια σου :: Es informal y singular.
- Καληνύχτα :: Es un saludo de despedida por la noche.
R Ευχαριστώ πολύ.
+ Muchas gracias. :: «Πολύ» intensifica «ευχαριστώ».
- Por favor. :: «Παρακαλώ» significa por favor.
- Buenas noches. :: Se dice «Καληνύχτα» al despedirse.
H Με ___ Μαρία.
+ λένε :: «Με λένε Μαρία» significa me llamo María.
- λέτε :: «Με λέτε» no expresa esta presentación.
- είστε :: Significa sois/está usted.
A Συγγνώμη.
+ Perdón. :: «Συγγνώμη» sirve para disculparse o llamar la atención.
- Gracias. :: Gracias es «ευχαριστώ».
- Adiós. :: Adiós es «αντίο».
O Γεια σας και καλημέρα :: hola y buenos días :: «Και» une dos saludos.
X Escribe en griego: «por favor» :: παρακαλώ :: παρακαλώ
