@ 3 | Αριθμοί και ηλικία | Números y edad
I Aprende los números básicos para decir tu edad, un teléfono o una cantidad pequeña. Escucha bien las sílabas acentuadas.
E Números y edad :: **Πόσων χρονών είσαι;** significa «¿cuántos años tienes?». En griego se responde con **είμαι** + número + **χρονών**: **Είμαι είκοσι χρονών**. :: Para preguntar un teléfono: **Ποιο είναι το τηλέφωνό σου;**. Los números se combinan para formar cantidades mayores, por ejemplo **είκοσι ένα** (21).
W μηδέν = cero | midén
W δύο = dos | dío
W τρία = tres | tría
W τέσσερα = cuatro | tésera
W πέντε = cinco | pénde
W έξι = seis | éxi
W επτά = siete | eptá
W οκτώ = ocho | októ
W εννέα = nueve | enéa
W δέκα = diez | déka
W έντεκα = once | éndeka
W δώδεκα = doce | dódeka
W δεκατρία = trece | dekatría
W είκοσι = veinte | íkosi
W χρονών = años (de edad) | jronón
W πόσων = cuántos, cuántas (genitivo) | pósōn
W τηλέφωνο = teléfono | tiléfono
W τηλέφωνό = teléfono (con acento antes de σου) | tiléfonó
V Αριθμοί 0–20
D Στο διάλειμμα
Κώστας: Πόσων χρονών είσαι, Άννα; = ¿Cuántos años tienes, Anna?
  > Πόσων χρονών = cuántos años | είσαι = eres/tienes
Άννα: Είμαι είκοσι χρονών. Εσύ; = Tengo veinte años. ¿Y tú?
  > Είμαι = soy/estoy | είκοσι = veinte | χρονών = años
Κώστας: Είμαι είκοσι ένα χρονών. = Tengo veintiún años.
  > είκοσι ένα = veinte uno | χρονών = años
Άννα: Ποιο είναι το τηλέφωνό σου; = ¿Cuál es tu teléfono?
  > Ποιο = cuál | τηλέφωνό σου = tu teléfono
Κώστας: Είναι μηδέν, δύο, τρία, τέσσερα. = Es cero, dos, tres, cuatro.
  > μηδέν = cero | δύο, τρία, τέσσερα = dos, tres, cuatro
T Αριθμοί
- 5 = πέντε
- 10 = δέκα
- 12 = δώδεκα
- 20 = είκοσι
Q ¿Cómo se dice «ocho»?
+ οκτώ :: «Οκτώ» es ocho.
- επτά :: «Επτά» es siete.
- εννέα :: «Εννέα» es nueve.
Q ¿Qué significa «Πόσων χρονών είσαι;»?
+ ¿Cuántos años tienes? :: «Χρονών» se usa al hablar de la edad.
- ¿Cuál es tu teléfono? :: Se pregunta «Ποιο είναι το τηλέφωνό σου;».
- ¿Dónde vives? :: Se pregunta «Πού μένεις;».
R Είμαι δέκα χρονών.
+ Tengo diez años. :: En griego se dice literalmente «soy diez años».
- Tengo dos teléfonos. :: «Τηλέφωνο» significa teléfono.
- Soy el número diez. :: No es el sentido de la frase.
H Είμαι ___ χρονών.
+ είκοσι :: «Είκοσι» es veinte.
- τηλέφωνο :: Significa teléfono.
- πέντε; :: El número no corresponde a la edad del diálogo.
A Δώδεκα.
+ Doce. :: «Δώδεκα» es el número doce.
- Diez. :: Diez es «δέκα».
- Veinte. :: Veinte es «είκοσι».
O δύο, τρία, τέσσερα :: dos, tres, cuatro :: Practica la serie numérica.
X Escribe en griego: «cinco» :: πέντε :: πέντε

@ 3 | Η οικογένειά μου | Mi familia
I En esta lección conocerás palabras de familia y aprenderás a decir qué personas tienes en tu familia.
E El verbo έχω :: **Έχω** significa «tengo». Se conjuga **έχω, έχεις, έχει** (yo, tú, él/ella). :: Las palabras de familia suelen ir con un artículo: **ο πατέρας** (el padre), **η μητέρα** (la madre), **το παιδί** (el niño/la niña). Después de una persona, **μου** significa «mi» y va detrás del nombre: **ο αδελφός μου**.
B Έχω | Persona | Forma
| εγώ | έχω
| εσύ | έχεις
| αυτός / αυτή | έχει
W έχω = tengo | éjo
W έχεις = tienes | éjis
W έχει = tiene | éji
W οικογένεια = familia | ikogénia
W πατέρας = padre | patéras
W μητέρα = madre | mitéra
W αδελφός = hermano | adelfós
W αδελφό = hermano (acusativo) | adelfó
W αδελφή = hermana | adelfí
W παιδί = niño, niña; hijo, hija | pedí
W παιδιά = niños, niñas; hijos, hijas | pediá
W έναν = un (masculino, acusativo) | énan
W γιος = hijo | yos
W γιο = hijo (acusativo) | yio
W κόρη = hija | kóri
W λέγεται = se llama | léyete
W τη = la, a ella | ti
W άντρας = hombre; marido | ántras
W γυναίκα = mujer; esposa | yinéka
W γονείς = padres | gonís
W σου = tu, tuyo; te | su
W μία = una | mía
W οικογένειά = familia (forma con acento antes de «σου») | ikogeniá
W μαζί = juntos | mazí
W αλλά = pero | alá
V Η οικογένεια
D Στο σπίτι
Μαρία: Έχεις αδελφό; = ¿Tienes un hermano?
  > Έχεις = tienes | αδελφό = hermano (objeto)
Ελένη: Ναι, έχω έναν αδελφό και μία αδελφή. = Sí, tengo un hermano y una hermana.
  > Ναι = sí | έχω = tengo | αδελφό = hermano | αδελφή = hermana
Μαρία: Πώς λένε την οικογένειά σου; = ¿Cómo se llama tu familia?
  > Πώς λένε = cómo llaman | την οικογένειά σου = tu familia
Ελένη: Ο πατέρας μου λέγεται Νίκος. = Mi padre se llama Nikos.
  > πατέρας μου = mi padre | λέγεται = se llama
Μαρία: Η μητέρα σου; = ¿Y tu madre?
  > μητέρα σου = tu madre
Ελένη: Τη λένε Άννα. = Se llama Anna.
  > Τη λένε = la llaman
T Στην οικογένεια
- Έχω έναν γιο. = Tengo un hijo.
- Έχω μία κόρη. = Tengo una hija.
- Έχω δύο παιδιά. = Tengo dos hijos.
Q ¿Qué significa «Έχω μία αδελφή»?
+ Tengo una hermana. :: «Έχω» es tengo y «αδελφή» es hermana.
- Tengo un hermano. :: Hermano es «αδελφός».
- Soy una hermana. :: «Έχω» no significa soy.
Q ¿Dónde se coloca «μου» para decir «mi padre»?
+ Después del nombre: «ο πατέρας μου». :: El posesivo suele ir después del sustantivo.
- Antes del nombre: «μου ο πατέρας». :: No es el orden normal.
- Al final de la oración siempre. :: Puede ir después del sustantivo que posee.
R Έχω δύο παιδιά.
+ Tengo dos hijos. :: «Δύο» es dos y «παιδιά» es hijos/niños.
- Tengo dos hermanas. :: Hermana es «αδελφή».
- Soy dos niños. :: La frase lleva el verbo «έχω».
H Έχεις ___;
+ αδελφό :: «Αδελφό» es hermano en esta pregunta.
- αδελφή :: Significa hermana.
- πατέρας :: Significa padre.
A Ο πατέρας μου.
+ Mi padre. :: «Μου» después del nombre significa mi.
- Tu madre. :: Tu madre es «η μητέρα σου».
- Mi hija. :: Hija es «κόρη».
O έχω έναν γιο :: tengo un hijo :: «Έχω» significa tengo.
X Escribe en griego: «familia» :: οικογένεια :: οικογένεια

@ 3 | Τι έχεις; | Posesiones y descripción sencilla
I Ahora combina el verbo «tener» con objetos cotidianos y describe a las personas de tu familia con palabras sencillas.
E Artículos y adjetivos :: **Ένας** se usa con un nombre masculino, **μία** con uno femenino y **ένα** con uno neutro. En plural se usan **δύο** y otros números sin cambiar el nombre en una lista básica. :: El adjetivo concuerda con el nombre: **ένας καλός φίλος**, **μία καλή φίλη**, **ένα καλό παιδί**. Aprende cada sustantivo con su artículo para recordar el género.
B Ένας, μία, ένα | Género | Ejemplo
| Masculino | ένας φίλος
| Femenino | μία φίλη
| Neutro | ένα παιδί
W ένας = un, uno (masculino) | énas
W μία = una (femenino) | mía
W καλός = bueno (masculino) | kalós
W καλή = buena (femenino) | kalí
W καλό = bueno (neutro) | kaló
W σπίτι = casa | spíti
W βιβλίο = libro | vivlío
W κλειδί = llave | klidí
W αυτοκίνητο = coche | aftokínito
W μικρός = pequeño (masculino) | mikrós
W μικρό = pequeño (neutro) | mikró
W μικρή = pequeña (femenino) | mikrí
W μεγάλο = grande (neutro) | megálo
W καινούριος = nuevo (masculino) | kenúrios
W καινούρια = nueva (femenino) | kenúria
W καινούριο = nuevo (neutro) | kenúrio
W ποδήλατο = bicicleta | podílato
V Αντικείμενα και περιγραφή
D Ένα νέο σπίτι
Νίκος: Έχεις καινούριο σπίτι; = ¿Tienes una casa nueva?
  > Έχεις = tienes | καινούριο σπίτι = casa nueva
Μαρία: Ναι, έχω ένα μικρό σπίτι. = Sí, tengo una casa pequeña.
  > έχω = tengo | μικρό = pequeño | σπίτι = casa
Νίκος: Έχεις αυτοκίνητο; = ¿Tienes coche?
  > αυτοκίνητο = coche
Μαρία: Όχι, αλλά έχω ένα καινούριο ποδήλατο. = No, pero tengo una bicicleta nueva.
  > Όχι = no | αλλά = pero | καινούριο = nuevo
Νίκος: Έχεις και ένα βιβλίο; = ¿Tienes también un libro?
  > και = también | βιβλίο = libro
Μαρία: Ναι, έχω ένα καλό βιβλίο. = Sí, tengo un buen libro.
  > καλό = bueno (neutro)
T Μικρές περιγραφές
- Έχω ένα μικρό σπίτι. = Tengo una casa pequeña.
- Έχω μία καλή φίλη. = Tengo una buena amiga.
- Έχω ένα καινούριο βιβλίο. = Tengo un libro nuevo.
Q ¿Qué forma de «bueno» acompaña a «ένα παιδί»?
+ καλό :: El adjetivo neutro termina en -ό.
- καλή :: Es la forma femenina.
- καλός :: Es la forma masculina.
Q ¿Qué significa «κλειδί»?
+ llave :: «Κλειδί» significa llave.
- libro :: Libro es «βιβλίο».
- casa :: Casa es «σπίτι».
R Έχω ένα μικρό σπίτι.
+ Tengo una casa pequeña. :: «Μικρό» describe a «σπίτι».
- Tengo una casa grande. :: Grande es «μεγάλο».
- Tengo una llave pequeña. :: Llave es «κλειδί».
H Έχω ένα ___ βιβλίο.
+ καλό :: «Καλό» concuerda con el neutro «βιβλίο».
- καλή :: Forma femenina.
- καλός :: Forma masculina.
A Έχω ένα καινούριο αυτοκίνητο.
+ Tengo un coche nuevo. :: «Αυτοκίνητο» es coche.
- Tengo una casa nueva. :: Casa es «σπίτι».
- Tengo un libro pequeño. :: Libro es «βιβλίο».
O έχω ένα καλό βιβλίο :: tengo un buen libro :: «Καλό» concuerda con «βιβλίο».
X Escribe en griego: «libro» :: βιβλίο :: βιβλίο
