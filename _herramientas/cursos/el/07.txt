@ 7 | Ρούχα και χρώματα | Ropa y colores
I En una tienda, puedes preguntar por una talla y decir qué color prefieres. Aprende primero los nombres de algunas prendas y colores.
E Adjetivos y colores :: En griego, el adjetivo concuerda con el sustantivo en género. Por ejemplo: **ο καφές είναι μαύρος**, **η τσάντα είναι μαύρη**, **το φόρεμα είναι μαύρο**. :: Los colores pueden cambiar de forma según el género. Conviene aprenderlos junto a los sustantivos que describen.
B Χρώματα | Masculino | Femenino | Neutro
| negro | μαύρος | μαύρη | μαύρο
| blanco | άσπρος | άσπρη | άσπρο
| κόκκινος | κόκκινη | κόκκινο
W ρούχο = prenda de ropa | rújo
W ρούχα = ropa, prendas | rúja
W παντελόνι = pantalón | pandelóni
W φούστα = falda | fústa
W φόρεμα = vestido | fórema
W πουκάμισο = camisa | pukámiso
W παπούτσι = zapato | papútsi
W μαύρος = negro (masculino) | mávros
W μαύρη = negra (femenino) | mávri
W μαύρο = negro (neutro) | mávro
W άσπρος = blanco (masculino) | áspros
W άσπρη = blanca (femenino) | áspri
W άσπρο = blanco (neutro) | áspro
W κόκκινο = rojo (neutro) | kó kino
W μπλε = azul | ble
W πράσινο = verde (neutro) | prásino
W ωραίος = bonito (masculino) | oréos
W ωραία = bonita (femenino) | oréa
W ωραίο = bonito (neutro) | oréo
W αρέσει = gusta | arési
V Ρούχα και χρώματα
D Στο κατάστημα
Λένα: Σου αρέσει η μαύρη τσάντα; = ¿Te gusta el bolso negro?
  > σου αρέσει = te gusta | μαύρη = negra | τσάντα = bolso
Κώστας: Ναι, είναι ωραία. = Sí, es bonito.
  > ναι = sí | είναι = es | ωραία = bonita
Λένα: Και το κόκκινο φόρεμα; = ¿Y el vestido rojo?
  > και = y | κόκκινο = rojo | φόρεμα = vestido
Κώστας: Το φόρεμα είναι ωραίο, αλλά θέλω μαύρο παντελόνι. = El vestido es bonito, pero quiero un pantalón negro.
  > ωραίο = bonito | αλλά = pero | θέλω = quiero | παντελόνι = pantalón
Λένα: Ορίστε, μία άσπρη φούστα. = Aquí tiene, una falda blanca.
  > Ορίστε = aquí tiene | άσπρη = blanca | φούστα = falda
T Χρώματα
- Μαύρο παπούτσι. = Zapato negro.
- Κόκκινο φόρεμα. = Vestido rojo.
- Άσπρη τσάντα. = Bolso blanco.
Q ¿Qué forma de «negro» acompaña a «τσάντα»?
+ μαύρη :: «Τσάντα» es femenino.
- μαύρος :: Es masculino.
- μαύρο :: Es neutro.
Q ¿Qué significa «παντελόνι»?
+ pantalón :: «Παντελόνι» es pantalón.
- falda :: Falda es «φούστα».
- camisa :: Camisa es «πουκάμισο».
R Το κόκκινο φόρεμα είναι ωραίο.
+ El vestido rojo es bonito. :: «Φόρεμα» es neutro y «ωραίο» concuerda con él.
- La falda negra es bonita. :: Falda es «φούστα».
- El pantalón blanco es bonito. :: Pantalón es «παντελόνι».
H Η ___ φούστα.
+ άσπρη :: «Φούστα» es femenino.
- άσπρος :: Masculino.
- άσπρο :: Neutro.
A Θέλω μαύρο παντελόνι.
+ Quiero un pantalón negro. :: «Μαύρο» es neutro y concuerda con «παντελόνι».
- Quiero una falda negra. :: Falda es «φούστα».
- Me gusta el vestido rojo. :: «Μου αρέσει» es me gusta.
O η άσπρη φούστα :: la falda blanca :: El adjetivo concuerda con «φούστα».
X Escribe en griego: «vestido» :: φόρεμα :: φόρεμα

@ 7 | Στο κατάστημα | En la tienda
I Practica cómo preguntar el precio, pedir otra talla y decir que una prenda te queda bien o no.
E Demostrativos y precios :: **Αυτό** significa «este/esta/esto» y **εκείνο** significa «ese/esa/aquel». Para preguntar el precio: **Πόσο κάνει;**. Para decir cuánto cuesta: **Κάνει δέκα ευρώ**. :: **Μου κάνει** puede significar «me queda bien» cuando hablamos de una prenda. **Μεγάλο / μικρό** describe una talla o tamaño neutro; **μεγάλη / μικρή** se usa con un nombre femenino.
W αυτό = este, esta, esto | aftó
W εκείνο = ese, esa, aquello | ekíno
W πόσο = cuánto | póso
W κάνει = cuesta, hace | káni
W ευρώ = euro(s) | evró
W ακριβό = caro (neutro) | akrivó
W φτηνό = barato (neutro) | ftinó
W μεγάλη = grande (femenino) | megáli
W μέγεθος = talla, tamaño | mégethos
W δοκιμάζω = me pruebo | dokimázo
W δοκιμάζεις = te pruebas | dokimázis
W μου κάνει = me queda bien | mu káni
W αυτό το = este, esta, esto (con artículo) | aftó to
W έχετε = tiene, tienen (cortés) | éjete
W κάτι = algo | káti
W δοκιμάστε = pruébese, prueben | dokimáste
V Τιμή και μέγεθος
D Στο μαγαζί
Πελάτισσα: Πόσο κάνει αυτό το φόρεμα; = ¿Cuánto cuesta este vestido?
  > Πόσο κάνει = cuánto cuesta | αυτό το φόρεμα = este vestido
Πωλήτρια: Κάνει είκοσι ευρώ. = Cuesta veinte euros.
  > κάνει = cuesta | είκοσι = veinte | ευρώ = euros
Πελάτισσα: Είναι πολύ ακριβό. Έχετε κάτι φτηνό; = Es muy caro. ¿Tiene algo barato?
  > πολύ = muy | ακριβό = caro | φτηνό = barato
Πωλήτρια: Δοκιμάστε αυτό. = Pruébese este.
  > δοκιμάστε = pruébese | αυτό = esto
Πελάτισσα: Το μέγεθος είναι μικρό. = La talla es pequeña.
  > μέγεθος = talla | μικρό = pequeño
T Στην αγορά
- Πόσο κάνει η τσάντα; = ¿Cuánto cuesta el bolso?
- Κάνει δέκα ευρώ. = Cuesta diez euros.
- Αυτό είναι πολύ ακριβό. = Esto es muy caro.
Q ¿Qué significa «Πόσο κάνει;»?
+ ¿Cuánto cuesta? :: Es la pregunta para saber el precio.
- ¿Qué talla tienes? :: Talla es «μέγεθος».
- ¿Dónde está la tienda? :: Tienda es «μαγαζί».
Q ¿Qué palabra significa «barato»?
+ φτηνό :: «Φτηνό» es barato (neutro).
- ακριβό :: «Ακριβό» es caro.
- μεγάλο :: «Μεγάλο» es grande.
R Κάνει είκοσι ευρώ.
+ Cuesta veinte euros. :: «Είκοσι» es veinte.
- Cuesta diez euros. :: Diez es «δέκα».
- Es muy caro. :: Caro es «ακριβό».
H Το μέγεθος είναι ___ .
+ μικρό :: «Μέγεθος» es neutro.
- μικρή :: Femenino.
- μεγάλη :: Femenino.
A Πόσο κάνει η τσάντα;
+ ¿Cuánto cuesta el bolso? :: «Τσάντα» es bolso.
- ¿Cuánto cuesta el vestido? :: Vestido es «φόρεμα».
- ¿Qué color tiene el bolso? :: Color es «χρώμα».
O αυτό το φόρεμα κάνει είκοσι ευρώ :: este vestido cuesta veinte euros :: «Είκοσι ευρώ» es veinte euros.
X Escribe en griego: «euro» :: ευρώ :: ευρώ

@ 7 | Αγορές και ποσότητες | Compras y cantidades
I Aprende a pedir una cantidad y a comparar precios. En las tiendas puedes indicar si quieres uno, dos o medio kilo.
E Cantidades y acusativo :: Para comprar, la forma más sencilla es **Θέλω δύο μήλα** (quiero dos manzanas). Para una cantidad, usa **ένα κιλό** (un kilo) o **μισό κιλό** (medio kilo). :: Después de **θέλω**, el objeto suele ir en acusativo: **θέλω έναν καφέ**, **θέλω μία σαλάτα**, **θέλω ένα μήλο**. Aprende estas expresiones completas.
W αγορά = compra, mercado | agorá
W μήλα = manzanas | míla
W πορτοκάλι = naranja | portokáli
W πορτοκάλια = naranjas | portokália
W μπανάνα = plátano | banána
W μπανάνες = plátanos | banánes
W κιλό = kilo | kiló
W κιλά = kilos | kilá
W μισό = medio | misó
W φρέσκο = fresco (neutro) | fré sko
W φρέσκα = frescos, frescas | fré ska
W ακριβό = caro | akrivó
W φτηνό = barato | ftinó
W φτηνά = baratos, baratas | ftiná
W δίνω = doy | díno
W δίνετε = da, dais (cortés/plural) | dínite
V Στη λαϊκή αγορά
D Στον πάγκο
Πωλητής: Τι θέλετε; = ¿Qué desea?
  > Τι = qué | θέλετε = desea (cortés)
Μαρία: Θέλω δύο κιλά πορτοκάλια. = Quiero dos kilos de naranjas.
  > θέλω = quiero | δύο = dos | κιλά = kilos | πορτοκάλια = naranjas
Πωλητής: Είναι φρέσκα. Θέλετε και μήλα; = Están frescas. ¿Quiere también manzanas?
  > φρέσκα = frescas | και = también | μήλα = manzanas
Μαρία: Ναι, τρία μήλα και δύο μπανάνες. = Sí, tres manzanas y dos plátanos.
  > τρία = tres | μήλα = manzanas | μπανάνες = plátanos
Πωλητής: Ορίστε. Είναι δέκα ευρώ. = Aquí tiene. Son diez euros.
  > ορίστε = aquí tiene | είναι = son | δέκα = diez | ευρώ = euros
T Μικρή αγορά
- Θέλω ένα κιλό μήλα. = Quiero un kilo de manzanas.
- Θέλω μισό κιλό πορτοκάλια. = Quiero medio kilo de naranjas.
- Είναι πολύ φτηνά. = Están muy baratos.
Q ¿Qué significa «μισό κιλό»?
+ medio kilo :: «Μισό» significa medio.
- dos kilos :: Dos es «δύο».
- un euro :: Euro es «ευρώ».
Q ¿Qué fruta es «μπανάνα»?
+ plátano :: «Μπανάνα» significa plátano.
- naranja :: Naranja es «πορτοκάλι».
- manzana :: Manzana es «μήλο».
R Θέλω δύο κιλά πορτοκάλια.
+ Quiero dos kilos de naranjas. :: «Πορτοκάλια» significa naranjas.
- Quiero tres manzanas. :: Manzanas son «μήλα».
- Quiero medio kilo de plátanos. :: Plátanos son «μπανάνες».
H Θέλω ___ μήλα.
+ τρία :: «Τρία μήλα» significa tres manzanas.
- μισό :: «Μισό» acompaña a kilo.
- φρέσκα :: Significa frescos/frescas.
A Είναι φρέσκα.
+ Están frescas. :: «Φρέσκα» describe a «πορτοκάλια».
- Están caras. :: Caras sería «ακριβά».
- Están lejos. :: Lejos es «μακριά».
O θέλω μισό κιλό πορτοκάλια :: quiero medio kilo de naranjas :: «Μισό κιλό» es medio kilo.
X Escribe en griego: «manzanas» :: μήλα :: μήλα
