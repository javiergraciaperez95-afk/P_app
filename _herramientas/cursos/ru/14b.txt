@ 14 | Уборка и кухня | Vocabulario de la casa: убирать, мыть, гладить, стирать
I Hoy aprendes las tareas de la casa: limpiar, lavar los platos, planchar, lavar la ropa. Son palabras de la vida diaria y aparecen en casi todas las conversaciones de casa.
E Tareas de casa :: **Убирать** (limpiar, recoger), **мыть** (lavar): **мыть посуду** (lavar los platos). **Гладить** (planchar): **гладить рубашку** (planchar la camisa). **Стирать** (lavar la ropa): **стирать бельё** (lavar la ropa blanca).
E Electrodomésticos :: **Стиральная машина** (lavadora), **пылесос** (aspiradora), **холодильник** (nevera, ya conocida). Para decir que algo está roto se usa **сломаться** (estropearse) y para arreglarlo **починить** (arreglar).
B Verbo | Significado | Ejemplo
| убирать | limpiar; recoger | убирать квартиру
| мыть | lavar | мыть посуду
| гладить | planchar | гладить рубашку
| стирать | lavar la ropa | стирать бельё
D Un día de limpieza
Анна: Кто сегодня моет посуду? = ¿Quién lava los platos hoy?
Иван: Я мою посуду, а ты убираешь квартиру. = Yo lavo los platos, y tú limpias el piso.
  > мою посуду = lavo los platos | убираешь квартиру = limpias el piso
Анна: Хорошо. Потом я глажу рубашку и стираю бельё. = Vale. Después plancho la camisa y lavo la ropa.
  > глажу рубашку = plancho la camisa | стираю бельё = lavo la ropa
Иван: Стиральная машина сломалась? = ¿Se ha estropeado la lavadora?
  > сломалась = se estropeó (femenino)
Анна: Нет, она работает, но пылесос нужно починить. = No, funciona, pero hay que arreglar el aspirador.
  > починить = arreglar

W стиральная машина = lavadora | sti-RAL'-na-ya ma-SHI-na

V Vocabulario: la casa y la limpieza
Q ¿Cómo dices «lavo los platos»?
+ Я мою посуду. :: Мыть + acusativo: посуду.
- Я мою посуда. :: Falta el acusativo: посуду.
- Я убираю посуду. :: Eso es «recojo la vajilla».
R Я глажу рубашку.
+ Plancho la camisa. :: Гладить + acusativo.
- Lavo la camisa. :: Eso sería «мою рубашку».
- Compro una camisa. :: No es la frase.
H Пылесос нужно ___ . :: arreglar (починить)
+ починить :: Infinitivo perfectivo tras нужно.
- чинит :: Presente: no va tras нужно.
- починил :: Pasado: no va aquí.
A Стиральная машина сломалась. :: ¿Qué le pasó a la lavadora?
+ Se estropeó. :: Сломалась = se estropeó.
- Se compró. :: No es lo que dice.
- Se lavó. :: No es lo que dice.
O Я убираю квартиру :: Limpio el piso :: убираю + квартиру.
Q ¿Qué significa «бельё»?
+ ropa blanca; ropa interior :: Бельё = ropa blanca.
- toalla :: Toalla es «полотенце».
- mantel :: Mantel es «скатерть».

@ 14 | Суббота дома | Escucha y lectura: un sábado en casa
I Escucha el texto y contesta. Presta atención a los verbos de casa.
T Суббота дома
- В субботу мы убираем квартиру. = El sábado limpiamos el piso.
- Я мою посуду, а сестра гладит бельё. = Yo lavo los platos, y mi hermana plancha la ropa.
- Стиральная машина работает целый день. = La lavadora funciona todo el día.
- Потом мы готовим обед и едим на кухне. = Después preparamos la comida y comemos en la cocina.
- Вечером пылесос опять сломался. = Por la tarde el aspirador se estropeó otra vez.
- Папа говорит, что его нужно починить. = Papá dice que hay que arreglarlo.
W целый = entero; todo (un día entero) | TIE-ly
W опять = otra vez | a-PYAT'
w убираем = limpiamos | u-bi-RA-yem
w гладит = plancha (ella) | GLA-dit
w едим = comemos | YE-dim
w сломался = se estropeó (masculino) | sla-MA-lsya
w говорит = dice (él, ella) | ga-va-RIT
V Vocabulario: sábado en casa
A В субботу мы убираем квартиру. :: ¿Qué hacen el sábado?
+ Limpian el piso. :: Убираем квартиру = limpiamos el piso.
- Compran un piso. :: No lo dice el texto.
- Se van de viaje. :: No lo dice el texto.
A Сестра гладит бельё. :: ¿Qué hace la hermana?
+ Plancha la ropa. :: Гладит бельё = plancha la ropa.
- Lava los platos. :: Eso lo hace el narrador.
- Cocina. :: No lo dice el texto.
A Стиральная машина работает целый день. :: ¿Cuánto tiempo trabaja la lavadora?
+ Todo el día. :: Целый день = todo el día.
- Solo una hora. :: No lo dice el texto.
- Nada. :: No lo dice el texto.
A Потом мы едим на кухне. :: ¿Dónde comen?
+ En la cocina. :: На кухне = en la cocina.
- En el salón. :: No lo dice el texto.
- En el parque. :: No lo dice el texto.
A Вечером пылесос опять сломался. :: ¿Qué le pasó al aspirador?
+ Se estropeó otra vez. :: Опять сломался = se estropeó otra vez.
- Lo compraron ayer. :: No lo dice el texto.
- Lo arreglaron. :: El texto dice que hay que arreglarlo.
A Папа говорит, что его нужно починить. :: ¿Qué dice papá?
+ Que hay que arreglarlo. :: Нужно починить = hay que arreglarlo.
- Que no funciona nunca. :: No lo dice el texto.
- Que lo tiene que tirar. :: No lo dice el texto.
Q ¿Qué hacen el sábado?
+ Limpian el piso. :: В субботу мы убираем квартиру.
- Se van de viaje. :: No lo dice el texto.
- Van al cine. :: No lo dice el texto.
H Мы ___ обед на кухне. :: preparamos (готовим)
+ готовим :: Plural: готовим.
- готовить :: Infinitivo: no va aquí.
- готовит :: Singular: no concuerda con «мы».
