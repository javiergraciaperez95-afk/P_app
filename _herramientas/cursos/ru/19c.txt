Q ¿Qué significa «перемена»?
+ recreo :: Перемена = recreo.
- clase :: Clase es «урок».
- examen :: Examen es «экзамен».
R На перемене мы читаем учебник.
+ En el recreo leemos el libro de texto. :: На перемене = en el recreo.
- En clase leemos el libro de texto. :: Eso sería «на уроке».
- En el recreo escribimos un examen. :: Eso no es la frase.
H Сегодня у нас физика и ___ . :: biología (биология)
+ биология :: Asignatura de biología.
- биологии :: Genitivo: no va después de «и».
- география :: Geografía: no es la frase.
A На географии мы смотрим карту. :: ¿Qué miran en geografía?
+ El mapa. :: Карту.
- Un libro. :: No lo dice la frase.
- Una película. :: No lo dice la frase.
O Иностранный язык очень интересный :: La lengua extranjera es muy interesante :: иностранный + язык + очень + интересный.
Q ¿Qué significa «учебник»?
+ libro de texto :: Учебник = libro de texto.
- cuaderno :: Cuaderno es «тетрадь».
- diccionario :: Diccionario es «словарь».
