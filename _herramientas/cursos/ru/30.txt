@ 30 | Жизнь в городе | Vivir en la ciudad: acostumbrarse, cansarse y los pros y contras
I Hoy aprendes a hablar de la vida diaria en una ciudad: lo que te gusta, lo que te cansa y a lo que te acostumbras con el tiempo.
E Acostumbrarse :: **Привыкнуть к** (acostumbrarse a) va con dativo: **привыкнуть к шуму** (acostumbrarse al ruido). En pasado, **привык** (masculino) y **привыкла** (femenino): **Я привык к городу** (me acostumbré a la ciudad). :: En futuro, **привыкну** (me acostumbraré): **Я привыкну** (me acostumbraré).
E Cansarse de algo :: **Надоесть** (cansar, aburrir) lleva la persona en dativo y lo que cansa en el sujeto: **Мне надоел шум** (el ruido me cansó). El verbo concuerda con lo que cansa: **надоел** (masculino), **надоела** (femenino), **надоело** (neutro). :: Para hablar de pros y contras se usa **с одной стороны... с другой стороны...** (por un lado... por otro).
B Expresión | Caso | Significado | Ejemplo
| привыкнуть к + dativo | dativo | acostumbrarse a | Я привыкну к шуму.
| надоесть + dativo | dativo | cansar; aburrir | Мне надоел шум.
| с одной стороны | — | por un lado | С одной стороны, да.
| привык / привыкла | — | me acostumbré (m / f) | Я привык к городу.
D La ciudad
Анна: Тебе нравится жить в городе? = ¿Te gusta vivir en la ciudad?

Иван: С одной стороны, да, но шум мне надоел. = Por un lado, sí, pero el ruido me cansó.
  > шум мне надоел = el ruido me cansó (надоел concuerda con шум, masculino)
Анна: Ты привык к шуму? = ¿Te acostumbraste al ruido?
  > привык к шуму = te acostumbraste al ruido (привыкнуть + dativo)
Иван: Нет, но я привыкну. = No, pero me acostumbraré.
  > я привыкну = me acostumbraré (futuro perfectivo)

Q ¿Cómo dices «acostumbrarse al ruido»?
+ привыкнуть к шуму :: **привыкнуть** + dativo: **к шуму**.
- привыкнуть шум :: Falta la preposición **к** y el dativo.
- привыкнуть в шуме :: **в** indica el lugar: no es «acostumbrarse».

@ 30 | Аргументы | Argumentar: primero, segundo, por eso y en conclusión
I Hoy aprendes a argumentar: ordenar tus ideas con «en primer lugar», «además», «por eso» y «en conclusión». Es la última habilidad del nivel B1.
E Ordenar las ideas :: **Во-первых** (en primer lugar) y **во-вторых** (en segundo lugar) ordenan los argumentos. **Кроме того** (además) añade algo más. **Поэтому** (por eso) indica consecuencia. :: **Например** (por ejemplo) introduce un ejemplo y **факт** (un hecho) sirve de prueba.
E Concluir :: **В результате** (como resultado) muestra el efecto de algo. **В итоге** (al final) y **итак** (así pues, en resumen) cierran el argumento. **Таким образом** (de este modo) y **следовательно** (por consiguiente) son más formales. :: **Вывод** (conclusión) se usa al final: **Мой вывод**: город лучше (mi conclusión: la ciudad es mejor).
B Conector | Función | Ejemplo
| во-первых / во-вторых | primero / segundo | Во-первых, здесь работа.
| кроме того | además | Кроме того, много развлечений.
| поэтому | por eso | Поэтому я здесь живу.
| в итоге | al final | В итоге я остаюсь.
D Ciudad o pueblo

  > есть транспорт = hay transporte
Анна: Кроме того, здесь много развлечений. = Además, aquí hay muchos entretenimientos.
  > много развлечений = muchos entretenimientos (много + genitivo plural)
Иван: Поэтому я и живу здесь. = Por eso vivo aquí.
  > Поэтому я и живу здесь = por eso vivo aquí (поэтому = por eso)
Анна: Итак, у каждого есть свои аргументы. = Así pues, cada uno tiene sus argumentos.
  > у каждого есть свои аргументы = cada uno tiene sus argumentos
Иван: Точно! = ¡Exacto!

Q ¿Cómo se dice «en primer lugar»?
+ во-первых :: **во-первых** = en primer lugar.
- во-вторых :: **во-вторых** = en segundo lugar.

H Cap. 24. Я выучу русский ___ год. :: en un año (за)
+ за :: **за** + acusativo: el plazo para hacer algo.
- через :: **через** = dentro de: no encaja con «en un año».
- до :: **до** = hasta: no encaja.
Q Cap. 24. ¿Cómo dices «llevo dos años estudiando»?
+ Я учусь два года. :: Duración sin preposición: **два года**.
- Я учусь через два года. :: **через** = dentro de.
- Я учусь за два года. :: **за** = en un plazo, para hacer algo.
H Cap. 24. Я давно ___ его. :: conozco (знаю)
+ знаю :: **знаю** = sé, conozco.
- жду :: **жду** = espero.
- ищу :: no es esta palabra en la frase.
Q Cap. 25. ¿Cómo dices «él es más alto que yo»?
+ Он выше меня. :: **выше** + genitivo **меня**.
- Он больше меня. :: **больше** = más grande: no es «más alto».
- Он высокий меня. :: **высокий** no compara.
H Cap. 25. Это самый ___ город. :: bonito (красивый)
+ красивый :: **самый** + adjetivo masculino.
- красивая :: Femenino: no concuerda con **город**.
- красивое :: Neutro: no concuerda con **город**.
Q Cap. 25. ¿Qué significa «самое лучшее»?
+ lo mejor :: **самое лучшее** = lo mejor.
- lo peor :: Lo peor no es **лучшее**.
- lo más barato :: Lo más barato no es **лучшее**.
Q Cap. 26. ¿Cómo dices «domino el inglés»?
+ Я владею английским. :: **владею** + instrumental **английским**.
- Я владею английский. :: Falta el instrumental.
- Я владею английского. :: **английского** es el genitivo.
H Cap. 26. Совещание ___ на четверг. :: fijada (назначено)
+ назначено :: **совещание** es neutro: **назначено**.
- назначен :: Es masculino: no concuerda con **совещание**.
- назначить :: Es el infinitivo.
Q Cap. 26. ¿Qué significa «уволиться»?
+ dejar el trabajo :: **уволиться** = dejar el trabajo.
- pasar a otro trabajo :: Eso es **перейти**.
- ser despedido :: Eso es **уволить** o **увольнение**.
H Cap. 27. Журналисты ___ , что никто не ранен. :: informan (сообщают)
+ сообщают :: **сообщают** = informan.
- сообщил :: Es pasado: «informó».
- сообщить :: Es el infinitivo.
Q Cap. 27. ¿Cómo dices «entrar en la web»?
+ зайти на сайт :: **зайти** + **на** + acusativo.
- зайти в сайт :: Con **сайт** se usa **на**.
- зайти сайт :: Falta la preposición **на**.
Q Cap. 28. ¿Cómo dices «tengo la gripe»?
+ Я болею гриппом. :: **болеть** + instrumental: **гриппом**.
- Я болею грипп. :: Falta el instrumental.
- Я болею гриппу. :: **гриппу** es el dativo.
Q Cap. 29. ¿Cómo dices «me gustó la película»?
+ Мне понравился фильм. :: **понравился** concuerda con **фильм** (masculino).
- Мне нравится фильм. :: Es presente: no dice «me gustó».
- Мне понравилась фильм. :: **понравилась** es femenino.
H Cap. 30. ___ , я здесь живу. :: Por eso (Поэтому)
+ Поэтому :: **поэтому** = por eso.
- Например :: **например** = por ejemplo.
- Кроме того :: **кроме того** = además.
Q Cap. 30. ¿Qué significa «итак»?
+ así pues; en resumen :: **итак** = así pues, en resumen.
- por ejemplo :: Por ejemplo es **например**.
- además :: Además es **кроме того**.
