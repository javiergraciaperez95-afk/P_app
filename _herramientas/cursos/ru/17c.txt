@ 17 | Утро, полдень, вечер | Momentos del día: полдень, рассвет, закат, полночь
I Hoy aprendes palabras para describir el día: amanecer, mediodía, atardecer y medianoche.
E Momentos del día :: **Рассвет** (amanecer), **полдень** (mediodía), **закат** (atardecer), **полночь** (medianoche). Con adjetivos: **утренний** (matutino), **вечерний** (vespertino).

Q ¿Qué significa «закат»?
+ atardecer :: Закат = atardecer.
- amanecer :: Amanecer es «рассвет».
- medianoche :: Medianoche es «полночь».
R Закат очень красивый.
+ El atardecer es muy bonito. :: Закат = atardecer.
- El amanecer es muy bonito. :: Eso sería «рассвет».
- La medianoche es muy bonita. :: Eso sería «полночь».
Q ¿Qué significa «полночь»?
+ medianoche :: Полночь = medianoche.
- amanecer :: Amanecer es «рассвет».
- mediodía :: Mediodía es «полдень».
H В ___ жарко. :: mediodía (полдень)
+ полдень :: Mediodía: в полдень.
- полночь :: Medianoche: no hace calor a medianoche en el texto.
- рассвет :: Amanecer: no encaja.
A На рассвете птицы поют. :: ¿Cuándo cantan los pájaros?
+ Al amanecer. :: На рассвете = al amanecer.
- Al atardecer. :: Eso sería «на закате».
- A medianoche. :: Eso sería «в полночь».
O Утренний кофе очень вкусный :: El café de la mañana está muy rico :: утренний + кофе + очень + вкусный.
