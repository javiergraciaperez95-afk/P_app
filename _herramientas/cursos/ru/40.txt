@ 40 | Роман и стихи | Arte y literatura: novela, poema, obra de teatro, cuadro
I Hoy aprendes a hablar de arte y de literatura: una novela, un poema, una obra de teatro, un cuadro. Es el vocabulario para comentar lo que has leído o visto.
E Obras :: **Роман** (novela), **стихотворение** (poema), **пьеса** (obra de teatro), **картина** (cuadro). Un escritor famoso es **известный писатель** y un **автор** es el autor de una obra.
E Opinar sobre una obra :: **Произведение** (obra). Para decir que te conmovió: **Произведение меня тронуло** (la obra me conmovió). Para justificar: **Мне понравилось, потому что...** (me gustó porque...).
B Palabra | Significado | Ejemplo
| роман | novela | Я читаю роман.
| стихотворение | poema | Стихотворение короткое.
| пьеса | obra de teatro | Пьеса была интересной.
| картина | cuadro | Картина красивая.
D Un libro favorito
Анна: Какой роман тебе понравился? = ¿Qué novela te gustó?
  > понравился = gustó (masculino)
Иван: Один роман о любви. Автор очень известный. = Una novela sobre el amor. El autor es muy famoso.
  > о любви = sobre el amor | известный = famoso
Анна: А пьеса? Ты ходил в театр? = ¿Y la obra de teatro? ¿Fuiste al teatro?
  > ходил = fuiste (ida y vuelta, a pie)
Иван: Да, пьеса была красивая, и картины в театре тоже хорошие. = Sí, la obra era bonita, y los cuadros del teatro también son buenos.
  > картины = cuadros (plural)
W стихотворение = poema | sti-kha-tvo-RIE-nie
W пьеса = obra de teatro | PIE-sa
W автор = autor | AV-tar
W произведение = obra (de arte o literaria) | pra-iz-vie-DIE-nie
W тронуть = conmover | TRO-nut'
W любовь = amor | lyu-BOF'
w тронуло = conmovió (neutro) | TRO-nu-la
w короткое = corto (neutro) | ka-ROT-ka-ye
w любви = amor (genitivo o preposicional) | lyu-BVI
w театре = teatro (preposicional) | tie-AT-re
w понравилось = gustó (neutro) | pa-nra-VI-las'
w хорошие = buenos (plural) | kha-RO-shi-ye
V Vocabulario: obras, autores y opiniones
Q ¿Qué significa «пьеса»?
+ obra de teatro :: Пьеса = obra de teatro.
- película :: Película es «фильм».
- canción :: Canción es «песня».
R Стихотворение короткое.
+ El poema es corto. :: Стихотворение = poema.
- El cuadro es corto. :: Eso sería «картина».
- La novela es corta. :: Eso sería «роман».
H Этот автор очень ___ . :: famoso (известный)
+ известный :: Masculino: автор es masculino.
- известная :: Femenino: no concuerda con «автор».
- известно :: Adverbio: no describe al autor.
A Произведение меня тронуло. :: ¿Qué sintió?
+ La obra le conmovió. :: Тронуло = conmovió.
- La obra le aburrió. :: Eso sería «надоело».
- La obra le ofendió. :: No es lo que dice la frase.
O Мне понравилось произведение :: Me gustó la obra :: мне + понравилось + произведение.
Q ¿Qué significa «любовь»?
+ amor :: Любовь = amor.
- odio :: Odio es «ненависть».
- amistad :: Amistad es «дружба».
X Dile en ruso: «la novela es muy bonita». :: Роман очень красивый. :: concordancia del adjetivo.

@ 40 | Как снег на голову | Expresiones hechas: frases con sentido figurado
I Hoy aprendes tres expresiones típicas del ruso. Una expresión hecha no se traduce palabra por palabra: su sentido es figurado.
E Tres expresiones :: **Как снег на голову** (de repente, como un rayo): **Новость пришла как снег на голову** (la noticia llegó como un rayo). **Водить за нос** (tomar el pelo, engañar): **Не води меня за нос!** (¡no me tomes el pelo!). **Брать быка за рога** (ir al grano): **Давай возьмём быка за рога** (vamos a ir al grano).
E Uso :: Son expresiones coloquiales y pueden sonar fuertes. Úsalas con amigos, no en un examen ni en una carta formal.
B Expresión | Significado | Ejemplo
| как снег на голову | de repente, como un rayo | Новость пришла как снег на голову.
| водить за нос | tomar el pelo; engañar | Не води меня за нос!
| брать быка за рога | ir al grano | Давай возьмём быка за рога.
D Una noticia inesperada
Анна: Новость пришла как снег на голову! = ¡La noticia llegó como un rayo!
  > пришла = llegó (femenino pasado) | как снег на голову = como un rayo
Иван: Не води меня за нос, это правда? = No me tomes el pelo, ¿es verdad?
  > не води меня за нос = no me tomes el pelo
Анна: Правда. Давай возьмём быка за рога и решим. = Es verdad. Vamos a ir al grano y decidir.
  > возьмём быка за рога = vamos a ir al grano
W бык = toro | byk
W рог = cuerno | rok
W пришла = llegó (femenino pasado) | pri-SHLA
w решим = decidiremos | ra-SHIM
w возьмём = tomaremos | vaz-MIOM
w быка = toro (genitivo o acusativo) | by-KA
w рога = cuerno (genitivo) | ra-GA
w голову = cabeza (acusativo) | GO-lu-vu
w води = lleva; toma (imperativo de водить) | va-DI
V Vocabulario: expresiones hechas y ir al grano
Q ¿Qué significa «как снег на голову»?
+ de repente, como un rayo :: Expresión hecha: llega de repente.
- como la nieve :: Es literal, pero no es el sentido.
- con frío :: No tiene que ver.
R Не води меня за нос.
+ No me tomes el pelo. :: Expresión: engañar.
- No me guardes la nariz. :: Traducción literal sin sentido.
- No me lleves al hocico. :: Sin sentido.
H Давай ___ быка за рога. :: tomemos (возьмём)
+ возьмём :: Vamos a ir al grano: возьмём.
- берём :: Presente de «брать»: no es «vamos».
- взяли :: Pasado: no va.
A Новость пришла как снег на голову. :: ¿Cómo llegó?
+ De repente. :: Como un rayo.
- Con calma. :: No es la frase.
- Como siempre. :: No es la frase.
O Не води меня за нос :: No me tomes el pelo :: не води + меня + за нос.
Q ¿Qué significa «бык»?
+ toro :: Бык = toro.
- vaca :: Vaca es «корова».
- cerdo :: Cerdo es «свинья».
X Dile en ruso: «ir al grano». :: Брать быка за рога. :: expresión hecha.

@ 40 | С каждым годом | Balance: cómo has cambiado y lo que aún quieres mejorar
I Hoy haces el balance del nivel: hablas de lo que has aprendido, de lo que te cuesta y de lo que quieres seguir estudiando. Es la última lección del curso de B2.
E Cambiar y mejorar :: **С каждым днём** (día a día) y **с каждым годом** (año tras año): **С каждым днём я говорю лучше** (cada día hablo mejor). **Я стал лучше понимать** (empecé a entender mejor). **Мне ещё трудно** (todavía me cuesta).
E Lo que falta :: **Надо больше практиковаться** (hay que practicar más). **Чем больше практики, тем легче** (cuanta más práctica, más fácil). Ya tienes una base sólida para comunicarte en ruso.
B Frase | Significado | Ejemplo
| с каждым днём | día a día | С каждым днём я говорю лучше.
| стал + comparativo | empecé a (mejor) | Я стал лучше понимать.
| мне ещё трудно | todavía me cuesta | Мне ещё трудно писать.
| надо больше практиковаться | hay que practicar más | Надо больше практиковаться.
D Balance final
Анна: Как ты сейчас говоришь по-русски? = ¿Cómo hablas ruso ahora?
Иван: С каждым днём лучше. Я стал лучше понимать новости. = Cada día mejor. Empecé a entender mejor las noticias.
  > С каждым днём лучше = cada día mejor | лучше понимать = entender mejor
Анна: А писать тебе трудно? = ¿Y escribir te cuesta?
Иван: Да, но чем больше я пишу, тем легче мне. = Sí, pero cuanto más escribo, más fácil me resulta.
  > чем больше я пишу, тем легче мне = cuanto más escribo, más fácil me resulta
Анна: Значит, продолжай! = Entonces, ¡sigue!
  > продолжай = sigue (imperativo de tú)
W каждым = cada (instrumental) | KAZH-dym
W практиковаться = practicar | prak-ti-KO-va-tsa
W практика = práctica | PRAK-ti-ka
W продолжай = sigue (tú) | pra-dal-ZHAI
w днём = día (instrumental de день) | dnyom
V Vocabulario: progreso, práctica y balance
Q ¿Qué significa «практиковаться»?
+ practicar :: Практиковаться = practicar.
- descansar :: Descansar es «отдыхать».
- olvidar :: Olvidar es «забыть».
R С каждым днём я говорю лучше.
+ Cada día hablo mejor. :: С каждым днём = cada día.
- Hablo menos cada día. :: Eso sería «меньше».
- Hablo como antes. :: Eso sería «как раньше».
H Я стал ___ понимать. :: entender mejor (лучше)
+ лучше :: Comparativo: лучше понимать.
- хорошо :: Adverbio: no va con comparativo.
- хуже :: Peor: no es la frase.
A Надо больше практиковаться. :: ¿Qué debe hacer?
+ Practicar más. :: Больше практиковаться = practicar más.
- Descansar más. :: Eso sería «больше отдыхать».
- Hablar menos. :: Eso sería «меньше говорить».
O Чем больше я пишу, тем легче :: Cuanto más escribo, más fácil :: чем больше + я пишу + тем легче.
Q ¿Qué significa «продолжай»?
+ sigue (tú) :: Продолжай = sigue.
- para :: Para es «стой».
- empieza :: Empieza es «начинай».
X Dile en ruso: «cada día mejor». :: С каждым днём лучше. :: с каждым днём.

@ 40 | Examen final de B2 | Examen final de B2
I Este es el examen final de B2. Hay preguntas de los capítulos 31 a 40. Si fallas alguna, mira de qué capítulo es y repásalo.
E Examen final de B2 :: Veinticinco preguntas sobre los capítulos 31 a 40. Si aciertas veintidós o más, tienes un B2 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 31. ¿Cómo dices «el libro está escrito por Tolstói»?
+ Книга написана Толстым. :: Forma corta femenina y agente en instrumental.
- Книга написала Толстой. :: Es la forma activa: «Tolstói escribió el libro».
- Книга написана Толстой. :: Falta el instrumental: Толстым.
H Cap. 31. Текст ___ нашей командой. :: ha sido traducido (переведён)
+ переведён :: Masculino corto: текст es masculino.
- переведена :: Femenina: no concuerda con «текст».
- переводит :: Forma activa: «traduce».
Q Cap. 31. ¿Cómo dices «me invitaron»?
+ Меня пригласили. :: Plural sin sujeto: пригласили.
- Меня пригласил. :: Es masculino singular: «me invitó (él)».
- Я пригласил. :: Eso es «invité».
H Cap. 32. Он сказал, что ___ позже. :: vendrá (придёт)
+ придёт :: Futuro perfectivo de прийти.
- приходит :: Presente: no es el futuro de esta frase.
- пришёл :: Pasado: no encaja.
Q Cap. 32. ¿Cómo dices «preguntó si vendrías»?
+ Он спросил, придёшь ли ты. :: Ли va después del verbo.
- Он спросил, придёшь ты? :: Falta «ли».
- Он спросил, что придёшь. :: No es una pregunta de sí o no.
H Cap. 32. Я не знаю, придёт ___ он. :: si (ли)
+ ли :: Partícula de pregunta indirecta de sí o no.
- что :: Eso es «qué».
- когда :: Eso es «cuándo».
Q Cap. 32. ¿Cómo dices «me aconsejó descansar»?
+ Он советовал мне отдыхать. :: Советовать + dativo + infinitivo.
- Он советует мне отдыхать. :: Presente: no es la forma.
- Он просил, чтобы я отдыхал. :: Eso es «me pidió que descansara».
H Cap. 33. Всё зависит ___ погоды. :: de (от)
+ от :: Зависеть + от + genitivo.
- в :: Va con «участвовать».
- о :: Va con «заботиться».
Q Cap. 33. ¿Cómo dices «participo en el concurso»?
+ Я участвую в конкурсе. :: Участвовать + в + preposicional.
- Я участвую на конкурсе. :: Con «участвовать» va «в».
- Я участвую конкурс. :: Falta la preposición.
H Cap. 34. Чем раньше, ___ легче. :: tanto más (тем)
+ тем :: Segunda parte de чем... тем.
- чем :: Ya está en la primera parte.
- что :: Eso es «que» en subordinadas.
Q Cap. 34. ¿Cómo dices «ni mi hermano ni mi hermana vinieron»?
+ Ни брат, ни сестра не пришли. :: Ни... ни... con verbo en negativo.
- Брат и сестра пришли. :: Eso sería «и... и».
- Брат или сестра пришли. :: Eso sería «либо... либо».
H Cap. 34. Даже ___ будет дождь, я пойду. :: si (если)
+ если :: Даже если = aunque.
- если бы :: Es condicional irreal.
- когда :: Es «cuándo».
Q Cap. 35. ¿Cómo dices «seguro que vendrá»?
+ Наверняка придёт. :: Наверняка + futuro.
- Вряд ли придёт. :: Es duda, no certeza.
- Возможно, придёт. :: Es «quizá».
H Cap. 35. Скорее ___ , он опоздает. :: todo (всего)
+ всего :: Скорее всего = probablemente.
- всё :: No va con «скорее».
- всех :: Plural: no va aquí.
Q Cap. 35. ¿Cómo dices «parece que llueve»?
+ Как будто идёт дождь. :: Как будто + indicativo.
- Словно идёт дождь. :: Es correcto pero más literario; no es la respuesta pedida.
- Якобы идёт дождь. :: Eso es «supuestamente».
H Cap. 36. Не ___ приходить. :: es necesario (обязательно)
+ обязательно :: Не обязательно = no es necesario.
- обязан :: Es «estoy obligado».
- должен :: Es «debo».
Q Cap. 36. ¿Qué significa «разве»?
+ ¿acaso...? :: Разве ты не знаешь? = ¿acaso no lo sabes?
- ya :: Ya es «уже».
- sin embargo :: Sin embargo es «однако».
H Cap. 36. Неужели он ___ ? :: se ha ido (уехал)
+ уехал :: Pasado de уехать.
- приедет :: Es futuro: «llegará».
- едет :: Es presente: «va».
Q Cap. 37. ¿Cómo dices «una hora y media»?
+ полтора часа :: Полтора + genitivo singular.
- полторы часа :: Полторы es femenino.
- полтора часов :: Часов es genitivo plural.
H Cap. 37. Полторы ___ . :: semanas (недели)
+ недели :: Genitivo singular de неделя.
- неделя :: Nominativo: no va después de полторы.
- недель :: Genitivo plural: no va aquí.
Q Cap. 38. ¿Cómo empiezas una carta formal a un hombre?
+ Уважаемый господин... :: Saludo formal.
- Привет! :: Es para amigos.
- Дорогой друг... :: Demasiado informal.
H Cap. 38. С ___ , Анна. :: atentamente (уважением)
+ уважением :: С уважением = atentamente.
- уважаю :: Es el verbo «respeto».
- уважаемый :: Es el adjetivo: no va en la despedida.
Q Cap. 38. ¿Qué significa «жалоба»?
+ queja; reclamación :: Жалоба = queja.
- felicitación :: Felicitación es «поздравление».
- solicitud :: Solicitud es «заявление».
H Cap. 39. Зарплаты ___ . :: bajan (падают)
+ падают :: Plural de падать.
- падает :: Singular: no concuerda con «зарплаты».
- растёт :: Singular de расти: no.
H Cap. 40. Не ___ меня за нос! :: tomes el pelo (води)
+ води :: Imperativo de tú: водить.
- водит :: Es «conduce» (él, ella).
- водите :: Es de usted: no es «tú».
