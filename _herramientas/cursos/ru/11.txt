@ 11 | Откуда ты? | De dónde eres: «из» y el genitivo
I Hoy aprendes a decir de dónde eres. La clave es una palabra pequeña, «из», y un cambio en la terminación del nombre. Es el genitivo, y lo verás muchísimo en el nivel A2.
E Soy de... :: Para decir de dónde eres se usa **из** («de» de origen) con el genitivo: **Я из Мадрида** = soy de Madrid. **Она из Москвы** = ella es de Moscú. :: Ojo: **в** dice dónde estás, no de dónde vienes: **в Москве** = en Moscú.
E Las terminaciones del genitivo :: Masculinos: se añade **-а** (**Мадрид** → **Мадрида**, **Париж** → **Парижа**). Femeninos en **-а**: cambian a **-ы** (**Москва** → **Москвы**). Nombres en **-ия**: cambian a **-ии** (**Россия** → **России**, **Испания** → **Испании**). :: Casi todos los países en **-ия** son femeninos y siguen esta regla: **из Франции**, **из Германии**, **из Италии**.
B Ciudades y países | Nominativo | Genitivo | Ejemplo
| Мадрид | Мадрид | Мадрида | из Мадрида
| Москва | Москва | Москвы | из Москвы
| Россия | Россия | России | из России
| Испания | Испания | Испании | из Испании
D ¿De dónde eres?
Анна: Откуда ты? = ¿De dónde eres?
  > Откуда ты = ¿de dónde eres? (откуда = de dónde)
Андрей: Я из Мадрида. = Soy de Madrid.
  > из Мадрида = de Madrid (из + genitivo de Мадрид)
Анна: А откуда твоя мама? = ¿Y de dónde es tu mamá?
  > твоя мама = tu mamá
Андрей: Она из Москвы. = Ella es de Moscú.
  > из Москвы = de Moscú (Москва → Москвы)
W страна = país | stra-NA | Es la palabra general para cualquier país.
W Франция = Francia | FRAN-tsiya
W Германия = Alemania | guer-MA-niya
W Италия = Italia | i-TA-liya
W Париж = París | pa-REESH
W Барселона = Barcelona | bar-se-LO-na
W немец = alemán (hombre) | NIE-mets | El femenino es «немка».
W немка = alemana (mujer) | NIEM-ka
W француз = francés (hombre) | fran-TSUS
W француженка = francesa (mujer) | fran-TSU-zhen-ka
W итальянец = italiano (hombre) | i-ta-LIA-nyets
W итальянка = italiana (mujer) | i-ta-LIAN-ka
W москвич = moscovita (hombre) | mask-VICH
W москвичка = moscovita (mujer) | mask-VICH-ka
w Мадрида = Madrid (genitivo) | ma-DRI-da
w Москвы = Moscú (genitivo) | mask-VY
w России = Rusia (genitivo) | ra-SI-i
w Испании = España (genitivo) | is-PA-nii
w Франции = Francia (genitivo) | FRAN-tsii
w Германии = Alemania (genitivo) | ger-MA-nii
w Италии = Italia (genitivo) | i-TA-lii
w Италию = Italia (acusativo) | i-TA-liu
w Парижа = París (genitivo) | pa-RI-zha
w Барселоны = Barcelona (genitivo) | bar-se-LO-ny
w Москве = Moscú (en, preposicional) | mask-VIE
V Vocabulario: países y gentilicios
Q ¿Cómo dices «soy de Madrid»?
+ Я из Мадрида. :: **из** + genitivo: **Мадрид** → **Мадрида**.
- Я в Москве. :: **В** dice dónde estás: «en Moscú», no de dónde eres.
- Я Мадрид. :: Falta **из** y la terminación del genitivo.
R Она из Москвы.
+ Ella es de Moscú. :: **Москвы** es el genitivo de **Москва**.
- Ella vive en Moscú. :: Eso sería «живёт в Москве».
- Ella es moscovita. :: Eso sería «москвичка», y aquí no hay ese nombre.
H Я живу в ___ . :: Москва (Moscú, en)
+ Москве :: **в** + preposicional: **Москва** → **Москве**.
- Москва :: Falta la preposición y el cambio de caso.
- Москвы :: Eso significa «de Moscú», con **из**, no «en Moscú».
A Я из Барселоны. :: ¿De dónde es esta persona?
+ De Barcelona. :: **Барселоны** es el genitivo de **Барселона**.
- De Madrid. :: Madrid sería «из Мадрида», no «Барселоны».
- De Francia. :: Francia sería «из Франции».
O Я из Франции :: Soy de Francia :: **Я** (yo) + **из** (de) + **Франции** (genitivo de Франция).
O Они из Германии :: Ellos son de Alemania :: **Они** (ellos) + **из** + **Германии** (genitivo de Германия).
Q ¿Cómo dices «de Rusia»?
+ из России :: **из** + **России**, el genitivo de **Россия**.
- в России :: **В** = «en Rusia», para decir dónde estás.
- России :: Falta la preposición **из**.
H Он из ___ . :: Италия (Italia)
+ Италии :: **Италия** → **Италии** (-ия → -ии).
- Италия :: Falta el genitivo.
- Италию :: Eso es el acusativo: no va detrás de **из**.

@ 11 | У меня нет брата | No tengo hermano: «нет» + genitivo
I Hoy aprendes a decir lo que tienes y lo que no tienes. Con «есть» y «нет» la palabra cambia de forma. Es un cambio muy útil y muy frecuente.
E Tener y no tener :: Para decir **«tengo»** se usa **У меня есть** + nominativo: **У меня есть брат** (tengo hermano). Para decir **«no tengo»** se usa **У меня нет** + genitivo: **У меня нет брата** (no tengo hermano). :: Lo mismo con cualquier cosa que no hay: **У тебя нет времени** (no tienes tiempo).
E El genitivo de «нет» :: Masculino: **брат** → **брата**. Femenino en **-а**: **сестра** → **сестры**, **машина** → **машины**. Neutro en **-я**: **время** → **времени**. Plural: **деньги** → **денег**. :: **Нет** también responde solo: «¿Есть время?» – «Нет.» = «¿Hay tiempo?» – «No.»
B Tener o no tener | Sustantivo | Con «есть» (sí) | Con «нет» (no)
| брат | У меня есть брат | У меня нет брата
| сестра | У меня есть сестра | У меня нет сестры
| машина | У меня есть машина | У меня нет машины
| время | У меня есть время | У меня нет времени
D ¿Tienes hermano?
Мария: У тебя есть брат? = ¿Tienes hermano?
  > У тебя есть брат = tienes hermano (есть + nominativo)
Иван: Нет, у меня нет брата. У меня есть сестра. = No, no tengo hermano. Tengo hermana.
  > у меня нет брата = no tengo hermano (нет + genitivo)
  > у меня есть сестра = tengo hermana (есть + nominativo)
Мария: А у твоей сестры есть машина? = ¿Y tu hermana tiene coche?
  > у твоей сестры = tu hermana (tiene)
  > есть машина = tiene coche
Иван: Нет, у неё нет машины. = No, ella no tiene coche.
  > у неё нет машины = ella no tiene coche
W время = tiempo | VRE-mya | Neutro. En genitivo cambia a «времени».
W деньги = dinero | DIEN-gi | Siempre en plural.
W ничего = nada | ni-chi-VO
W никто = nadie | nik-TO
W нужен = necesario (masculino) | NU-zhen
W нужна = necesaria (femenino) | nuzh-NA
W нужно = hace falta; hay que | NU-zhna
W свой = propio (masculino) | svoi | Indica que algo es tuyo o mío, por ejemplo «mi propia».
W своя = propia (femenino) | sva-YA
W женщина = mujer | ZHEN-shi-na
W мужчина = hombre (adulto) | muzh-CHI-na
W ребёнок = niño | re-BIOK | Plural irregular: «дети».
w брата = hermano (genitivo) | BRA-ta
w сестры = hermana (genitivo) | sis-TRY
w сестре = a/en la hermana (preposicional) | SIES-tre
w времени = tiempo (genitivo) | VRE-me-ni
w денег = dinero (genitivo plural) | DIE-nyek
w деньгами = con dinero (instrumental) | dien-GA-mi
w твоей = tu (femenino, genitivo) | ta-YEI
w у = a; en casa de (posesión) | u
V Vocabulario: tener, no tener y la familia
Q ¿Cómo dices «no tengo hermana»?
+ У меня нет сестры. :: После «нет» сестра → сестры: **-а** → **-ы**.
- У меня нет сестра. :: Falta el genitivo: después de «нет» la palabra cambia.
- У меня нет сестре. :: **Сестре** es otro caso: no es la forma que pide «нет».
H У меня нет ___ . :: dinero (деньги)
+ денег :: **Деньги** es plural: en genitivo queda **денег**.
- деньги :: Es el nominativo. Después de «нет» no se usa.
- деньгами :: Es el instrumental, «con dinero». Aquí no encaja.
R У меня нет времени.
+ No tengo tiempo. :: **Времени** es el genitivo de **время**.
- Tengo tiempo. :: Eso sería «У меня есть время», con «есть».
- No tengo dinero. :: Dinero es «деньги», no «время».
A У него нет брата. :: ¿Qué dice la frase?
+ Él no tiene hermano. :: **У него нет брата**: «él no tiene hermano».
- Él tiene hermano. :: Eso sería «У него есть брат».
- Él es hermano. :: «Он брат» dice que es hermano, sin **нет**.
O У меня нет денег :: No tengo dinero :: После «нет» деньги → **денег** (genitivo plural).
H У неё есть ___ . :: hermana (сестра)
+ сестра :: После «есть» va el nominativo.
- сестры :: El genitivo solo va después de «нет».
- брата :: Genitivo masculino, y aquí no hay «нет».
Q ¿Qué respondes a «У тебя есть время?» si no tienes tiempo?
+ Нет, у меня нет времени. :: «Нет» + genitivo: **времени**.
- Да, у меня нет времени. :: «Да» es sí, y se contradice.
- Нет, у меня есть времени. :: Con «есть» va el nominativo: **время**.
Q ¿Qué significa «ничего»?
+ nada :: **Ничего** = nada.
- nadie :: Nadie es «никто».
- tiempo :: Tiempo es «время».

@ 11 | Два брата, пять братьев | Números y genitivo: dos hermanos, cinco hermanos
I Ahora los números mandan sobre el nombre. Después de dos, tres o cuatro el nombre cambia, y a partir de cinco cambia otra vez. Así se dicen las cantidades en ruso.
E Dos, tres y cuatro :: Después de **два**, **три** y **четыре** el nombre va en genitivo singular: **два брата** (dos hermanos), **три сестры** (tres hermanas), **четыре города** (cuatro ciudades). :: Con **одна** (una, femenino) el nombre va en singular y en nominativo: **одна сестра** (una hermana).
E Cinco y más :: A partir de **пять** el nombre va en genitivo plural: **пять друзей** (cinco amigos), **сто книг** (cien libros), **десять человек** (diez personas). :: Algunos plurales cambian mucho: **друг** → **друзья** → **друзей**, **брат** → **братья** → **братьев**, **ребёнок** → **дети** → **детей**.
B Cantidad | Forma del nombre | Ejemplo
| uno (una) | nominativo singular | один брат, одна сестра
| dos, tres, cuatro | genitivo singular | два брата, три сестры, четыре города
| cinco y más | genitivo plural | пять друзей, десять человек, сто книг
D Hermanos y amigos
Лена: Сколько у тебя братьев? = ¿Cuántos hermanos tienes?
  > братьев = hermanos (genitivo plural)
Олег: У меня два брата и одна сестра. = Tengo dos hermanos y una hermana.
  > два брата = dos hermanos (два + genitivo singular)
  > одна сестра = una hermana (одна + singular)
Лена: А сколько у тебя друзей? = ¿Y cuántos amigos tienes?
  > друзей = amigos (genitivo plural)
Олег: У меня пять друзей. Мы часто вместе. = Tengo cinco amigos. Nos vemos a menudo juntos.
  > пять друзей = cinco amigos (пять + genitivo plural)
  > часто вместе = a menudo juntos
W одна = una (femenino) | ad-NA | Con «одна» el nombre va en singular.
W люди = gente; personas | LIU-di | Plural de «человек».
W мало = poco | MA-la | El contrario es «много».
W друзья = amigos | dru-ZIA | Plural de «друг».
W подруга = amiga (mujer) | pa-DRU-ga

W взрослый = adulto | vz-ROS-ly

V Vocabulario: números y personas
Q ¿Cómo dices «dos hermanos»?
+ два брата :: После «два» va el genitivo singular: **брат** → **брата**.
- два братья :: Es el nominativo plural: después de «два» no va.
- два братьев :: Es el genitivo plural: con «два» no se usa.
Q ¿Cómo dices «cinco amigos»?
+ пять друзей :: Con cinco o más, el genitivo plural: **друг** → **друзей**.
- пять друга :: Es el genitivo singular: con cinco no va.
- пять друзья :: Es el nominativo plural: no se usa después de «пять».
H У меня три ___ . :: hermana (сестра)
+ сестры :: Después de «три», el genitivo singular: **сестра** → **сестры**.
- сестёр :: Es el genitivo plural: con «три» no va.
- сестра :: Es el nominativo singular: con «три» no va.
R У меня одна сестра.
+ Tengo una hermana. :: **Одна** (una) + **сестра** en singular.
- Tengo dos hermanas. :: Dos es **два**, y no lleva **одна**.
- Tengo cinco hermanas. :: Cinco es **пять**, no **одна**.
O Пять друзей :: Cinco amigos :: **Пять** + genitivo plural: **друзей**.
Q ¿Qué significa «мало»?
+ poco :: **Мало** = poco.
- mucho :: Mucho es **много**.
- mañana :: Mañana es **завтра**.
A У меня пять друзей. :: ¿Cuántos amigos tiene?
+ Cinco. :: **Пять** = cinco.
- Dos. :: Dos es **два**, no lo que dice la frase.
- Diez. :: Diez es **десять**, no lo que dice la frase.
H Здесь два ___ . :: ciudad (город)
+ города :: Con **два**, el genitivo singular: **город** → **города**.
- городов :: Es el genitivo plural: con «два» no va.
- город :: Es el nominativo singular: con «два» no va.
