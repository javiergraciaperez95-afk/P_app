@ 19 | На вокзале | Vocabulario del tren: платформа, расписание, вагон
I Hoy aprendes las palabras de la estación: andén, horario, vagón, revisor. Son imprescindibles para viajar en tren.
E La estación :: **Платформа** (andén), **расписание** (horario), **вагон** (vagón), **проводник** (revisor del tren), **билет** (billete, ya conocido). Para preguntar la hora de salida: **Во сколько отправляется поезд?** (¿a qué hora sale el tren?).
E Verbos útiles :: **Отправляться** (salir, partir) y **прибывать** (llegar, un tren). **Опаздывать** (llegar tarde, un tren se retrasa): **Поезд опаздывает** (el tren llega tarde).
B Palabra | Significado | Ejemplo
| платформа | andén | Поезд на платформе.
| расписание | horario | Расписание на стене.
| вагон | vagón | Мой вагон седьмой.
| проводник | revisor | Проводник проверяет билеты.
D En la estación
Анна: Какая платформа у поезда в Москву? = ¿Qué andén es el del tren a Moscú?
Иван: Пятая. По расписанию он отправляется в девять. = El quinto. Según el horario sale a las nueve.
  > по расписанию = según el horario
Анна: А мой вагон где? = ¿Y mi vagón dónde está?
Иван: Седьмой, в конце платформы. = El séptimo, al final del andén.
  > в конце платформы = al final del andén
Анна: Поезд опаздывает? = ¿El tren llega tarde?
Иван: Нет, проводник говорит, что всё по времени. = No, el revisor dice que todo va a tiempo.
  > по времени = a tiempo

W расписание = horario | ras-pi-SA-nie
W вагон = vagón | va-GON
W проводник = revisor | pra-vad-NIK
W отправляется = sale (un tren) | at-prav-LYA-yet-sya
W опаздывает = llega tarde; se retrasa | a-pa-ZDY-va-yet
w пятая = quinta (femenina) | PIA-ta-ya
w седьмой = séptimo (masculino) | sed-MOI
w конце = al final (preposicional, в конце) | kan-TSE
w времени = tiempo (genitivo, en «по времени») | VRE-me-ni
w поезда = tren (genitivo) | PO-yez-da
w платформы = andén (genitivo) | pla-TFOR-my
w по = según (con dativo) | po

V Vocabulario: estación y tren
Q ¿Cómo dices «andén»?
+ платформа :: Платформа = andén.
- вагон :: Vagón es «вагон».
- билет :: Billete es «билет».
R Поезд опаздывает.
+ El tren llega tarde. :: Опаздывает = llega tarde.
- El tren sale. :: Eso sería «отправляется».
- El tren es nuevo. :: No lo dice la frase.
H Мой ___ седьмой. :: vagón (вагон)
+ вагон :: Masculino: вагон.
- платформа :: Es femenino: no concuerda con «седьмой».
- поезд :: Tren: no es el vagón.
Q ¿Qué significa «платформа»?
+ andén :: Платформа = andén.
- vagón :: Vagón es «вагон».
- horario :: Horario es «расписание».
A По расписанию он отправляется в девять. :: ¿A qué hora sale?
+ A las nueve. :: В девять = a las nueve.
- A las siete. :: No lo dice la frase.
- A las diez. :: No lo dice la frase.
O Поезд отправляется по расписанию :: El tren sale según el horario :: поезд + отправляется + по расписанию.

@ 19 | В поезде | Escucha y lectura: un viaje en tren
I Escucha el texto y contesta. Presta atención a los horarios y a la estación.
T В поезде
- Мы едем в Москву на поезде. = Vamos a Moscú en tren.
- Поезд отправляется с платформы номер два. = El tren sale del andén número dos.
- Наш вагон в середине состава. = Nuestro vagón está en medio del tren.
- Проводник проверяет билеты в девять утра. = El revisor comprueba los billetes a las nueve de la mañana.
- Поезд прибывает в Москву вечером. = El tren llega a Moscú por la noche.
w середине = mitad (preposicional) | sie-RE-di-ne
w состава = composición (genitivo) | sa-STA-va
w номер = número (ya conocido) | NO-mer
w прибывает = llega (un tren) | pri-BY-va-yet
w наш = nuestro (masculino) | NASH
w билеты = billetes (plural, en el tren) | bi-LIE-ty
V Vocabulario: viaje en tren
A Мы едем в Москву на поезде. :: ¿Cómo viajan?
+ En tren. :: На поезде = en tren.
- En avión. :: No lo dice el texto.
- En autobús. :: No lo dice el texto.
A Поезд отправляется с платформы номер два. :: ¿De qué andén sale?
+ Del número dos. :: Платформа номер два.
- Del número cinco. :: No lo dice el texto.
- Del número uno. :: No lo dice el texto.
A Наш вагон в середине состава. :: ¿Dónde está el vagón?
+ En medio del tren. :: В середине состава = en medio del tren.
- Al principio del tren. :: No lo dice el texto.
- Al final del tren. :: No lo dice el texto.
A Проводник проверяет билеты в девять утра. :: ¿Qué hace el revisor?
+ Comprueba los billetes. :: Проверяет билеты.
- Vende billetes. :: No lo dice el texto.
- Limpia el vagón. :: No lo dice el texto.
A Поезд прибывает в Москву вечером. :: ¿Cuándo llega?
+ Por la noche. :: Вечером = por la noche.
- Por la mañana. :: No lo dice el texto.
- A mediodía. :: No lo dice el texto.
Q ¿Dónde está nuestro vagón?
+ En medio del tren. :: В середине состава.
- Al principio. :: No lo dice el texto.
- En el andén. :: No lo dice el texto.
H Поезд ___ в Москву вечером. :: llega (прибывает)
+ прибывает :: Llega (un tren).
- прибывают :: Plural: no concuerda con «поезд».
- отправляется :: Sale: no encaja.
