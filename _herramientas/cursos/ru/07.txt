@ 7 | Одежда | La ropa y los demostrativos
E Este, esta, estos :: Delante de un nombre, «este» concuerda con él: **этот** (masculino), **эта** (femenino), **это** (neutro) y **эти** (plural). :: **этот** свитер (este jersey), **эта** куртка (esta cazadora), **это** платье (este vestido), **эти** туфли (estos zapatos). :: No lo confundas con el **это** que ya conoces («esto es…»), que no cambia nunca: **Это куртка** = esto es una cazadora. :: Para «aquel»: **тот** (masculino) y **та** (femenino).
B Los demostrativos | Género | Este | Ejemplo
| masculino | этот | этот свитер
| femenino | эта | эта куртка
| neutro | это | это платье
| plural | эти | эти туфли
E La ropa :: **Одежда** es «la ropa». **Рубашка** (camisa), **футболка** (camiseta), **свитер** (jersey), **куртка** (cazadora), **пальто** (abrigo), **платье** (vestido), **юбка** (falda), **шапка** (gorro). :: Siempre en plural: **брюки** (pantalones), **джинсы** (vaqueros) y **туфли** (zapatos).
E Me gusta, me gustan :: Igual que en español, el verbo cambia si lo que gusta es plural: **Мне нравится эта куртка** (me gusta esta cazadora), **мне нравятся эти туфли** (me gustan estos zapatos). :: Suenan casi igual, pero se escriben distinto. :: **Смотри!** = ¡mira! **Какое красивое платье!** = ¡qué vestido tan bonito!
W этот = este | E-tat
W эта = esta | E-ta
W эти = estos, estas | E-ti
W тот = aquel | tot
W одежда = ropa | a-DIEZH-da
W рубашка = camisa | ru-BASH-ka
W футболка = camiseta | fud-BOL-ka
W свитер = jersey | SVI-ter
W куртка = cazadora, chaqueta | KURT-ka
W пальто = abrigo | pal-TO
W платье = vestido | PLA-tie
W юбка = falda | YUP-ka
W брюки = pantalones | BRIU-ki
W джинсы = vaqueros | DZHYN-sy
W туфли = zapatos | TUF-li
W шапка = gorro | SHAP-ka
W нравятся = gustan | NRA-vi-tsa
W смотри = ¡mira! | smat-RI
W какое = qué, cómo es (neutro) | ka-KO-ye
W красивое = bonito (neutro) | kra-SI-va-ye
W красивые = bonitos, bonitas | kra-SI-vy-ye
W чёрные = negros, negras | CHOR-ny-ye
W синие = azules | SI-ni-ye
V Vocabulario: la ropa
D Mirando escaparates
Ольга: Смотри, Мария! Какое красивое платье! = ¡Mira, María! ¡Qué vestido tan bonito!
  > Смотри = mira | Какое красивое платье = qué vestido tan bonito
Мария: Да, красивое. Но мне нравится эта юбка. = Sí, es bonito. Pero a mí me gusta esta falda.
  > мне нравится = me gusta | эта юбка = esta falda
Ольга: А эта куртка? Тебе нравится? = ¿Y esta cazadora? ¿Te gusta?
  > эта куртка = esta cazadora | Тебе нравится = te gusta
Мария: Нет, не очень. А тебе нравятся эти туфли? = No, no mucho. ¿Y a ti te gustan estos zapatos?
  > не очень = no mucho | тебе нравятся = te gustan (plural) | эти туфли = estos zapatos
Ольга: Чёрные? Да, очень! И эти синие джинсы тоже красивые. = ¿Los negros? ¡Sí, mucho! Y estos vaqueros azules también son bonitos.
  > Чёрные = los negros | эти синие джинсы = estos vaqueros azules | тоже красивые = también bonitos
Мария: А тот свитер? = ¿Y aquel jersey?
  > тот свитер = aquel jersey
Ольга: Красный? Нет, он мне не нравится. = ¿El rojo? No, no me gusta.
  > он мне не нравится = él a mí no me gusta
T ¿Cómo es?
- Этот свитер новый. = Este jersey es nuevo.
- Эта рубашка белая. = Esta camisa es blanca.
- Эти брюки чёрные. = Estos pantalones son negros.
- Эта шапка красная. = Este gorro es rojo.
- Эти туфли очень красивые. = Estos zapatos son muy bonitos.
Q ¿Cómo dices «esta cazadora»?
+ эта куртка :: «Куртка» es femenino.
- этот куртка :: «Этот» es masculino.
- эти куртка :: «Эти» es plural.
Q ¿Cómo dices «estos zapatos»?
+ эти туфли :: Plural: эти.
- этот туфли :: «Этот» es singular.
- эта туфли :: «Эта» es singular.
Q ¿Cómo dices «me gustan estos vaqueros»?
+ Мне нравятся эти джинсы. :: Plural: нравятся.
- Мне нравится эти джинсы. :: Con plural va «нравятся».
- Я нравятся эти джинсы. :: Hace falta «мне».
Q ¿Qué es «платье»?
+ Un vestido. :: Es neutro.
- Un plato. :: No.
- Un abrigo. :: Eso es «пальто».
R Мне нравится эта юбка.
+ Me gusta esta falda. :: Юбка = falda.
- Me gusta este gorro. :: Gorro es «шапка».
- Me gustan estas faldas. :: Es singular.
H ___ свитер новый.
+ Этот :: «Свитер» es masculino.
- Эта :: Es femenino.
- Эти :: Es plural.
H Мне ___ эти туфли.
+ нравятся :: Plural.
- нравится :: Es singular.
- люблю :: Con «люблю» se dice «я».
A Эти брюки чёрные.
+ Estos pantalones son negros. :: Брюки = pantalones.
- Estos zapatos son negros. :: Zapatos es «туфли».
- Estos pantalones son azules. :: Azules es «синие».
O Мне нравится эта красная куртка :: Me gusta esta cazadora roja :: A mí + gusta + esta + roja + cazadora.

@ 7 | Сколько стоит? | Comprar: tallas y pagar
E ¿Se puede? :: **Можно** significa «se puede» y sirve para pedir permiso con mucha educación. Va seguido de un infinitivo. :: **Можно посмотреть?** = ¿puedo ver? **Можно примерить?** = ¿puedo probármelo? :: También vale solo, con lo que quieres: **Можно картой?** = ¿se puede con tarjeta?
E En la tienda :: El dependiente dirá **Вам помочь?** (¿le ayudo?). :: **Какой у вас размер?** = ¿qué talla tiene? **Размер** es «talla». :: **У вас есть размер больше?** = ¿tiene una talla más grande? **Больше** = más grande; **меньше** = más pequeño. :: El probador es **примерочная**. **Вам идёт** = le queda bien.
E Pagar :: **Я возьму** = me lo llevo. :: **Картой** = con tarjeta. **Наличными** = en efectivo. :: Los miles: **тысяча** (1000), **две тысячи**, **три тысячи**, y a partir de cinco, **пять тысяч**. :: Como «куртка» es el objeto de «ver», cambia: **эту куртку**.
W можно = se puede, ¿puedo? | MOZH-na
W посмотреть = ver, mirar | pas-mat-RIET
W примерить = probarse | pri-MIE-rit
W вам помочь = ¿le ayudo? | vam pa-MOCH
W размер = talla | raz-MIER
W больше = más grande; más | BOL-she
W меньше = más pequeño; menos | MIEÑ-she
W примерочная = probador | pri-MIE-rach-na-ya
W вам идёт = le queda bien | vam i-DIOT
W я возьму = me lo llevo | ya vaz-MU
W картой = con tarjeta | KAR-tai
W наличными = en efectivo | na-LICH-ny-mi
W конечно = claro, por supuesto | ka-NIESH-na | Se dice «kaniéshna».
W тысячи = miles (con 2, 3 y 4) | TY-si-chi
W тысяч = miles (con 5 o más) | TY-sich
w эту = esta (objeto) | E-tu
w куртку = cazadora (objeto) | KURT-ku
V Vocabulario: en la tienda
D Una cazadora nueva
Наташа: Здравствуйте! Вам помочь? = ¡Hola! ¿Le ayudo?
  > Вам помочь = ¿ayudarle?
Карлос: Да, пожалуйста. Можно посмотреть эту куртку? = Sí, por favor. ¿Puedo ver esta cazadora?
  > Можно посмотреть = se puede ver | эту куртку = esta cazadora (objeto)
Наташа: Конечно. Какой у вас размер? = Claro. ¿Qué talla tiene?
  > Конечно = claro | Какой у вас размер = qué talla tiene usted
Карлос: Я не знаю. Можно примерить? = No lo sé. ¿Puedo probármela?
  > Я не знаю = no sé | Можно примерить = se puede probar
Наташа: Да, примерочная там, справа. = Sí, el probador está allí, a la derecha.
  > примерочная = el probador | справа = a la derecha
Карлос: Эта куртка маленькая. У вас есть размер больше? = Esta cazadora es pequeña. ¿Tiene una talla más grande?
  > маленькая = pequeña | размер больше = una talla más grande
Наташа: Да, вот. Вам идёт! = Sí, aquí tiene. ¡Le queda bien!
  > Вам идёт = le queda bien
Карлос: Сколько она стоит? = ¿Cuánto cuesta?
  > Сколько она стоит = cuánto cuesta ella
Наташа: Пять тысяч рублей. = Cinco mil rublos.
  > Пять тысяч = cinco mil
Карлос: Хорошо, я возьму. Можно картой? = Vale, me la llevo. ¿Se puede con tarjeta?
  > я возьму = me la llevo | Можно картой = se puede con tarjeta
Наташа: Конечно. = Claro.
  > Конечно = por supuesto
Q ¿Cómo preguntas si puedes probarte algo?
+ Можно примерить? :: Можно + infinitivo.
- Можно картой? :: Eso es «¿se puede con tarjeta?».
- Вам помочь? :: Eso lo dice el dependiente.
Q ¿Qué significa «размер»?
+ talla :: Какой у вас размер?
- precio :: No.
- probador :: Eso es «примерочная».
Q ¿Cómo preguntas si se puede pagar con tarjeta?
+ Можно картой? :: Картой = con tarjeta.
- Можно наличными? :: Eso es «en efectivo».
- Сколько стоит? :: Eso es el precio.
Q ¿Qué significa «Я возьму»?
+ Me lo llevo. :: Para decir que lo compras.
- Me lo pruebo. :: Eso es «примерить».
- No lo quiero. :: No.
R У вас есть размер больше?
+ ¿Tiene una talla más grande? :: Больше = más grande.
- ¿Tiene una talla más pequeña? :: Sería «меньше».
- ¿Qué talla tiene usted? :: Sería «Какой у вас размер?».
H ___ посмотреть эту куртку?
+ Можно :: ¿Se puede ver…?
- Сколько :: Eso es «cuánto».
- Где :: Eso es «dónde».
H Сколько ___ эта куртка?
+ стоит :: Cuesta.
- стоят :: Es plural.
- размер :: Eso es «talla».
A Вам идёт!
+ ¡Le queda bien! :: Lo dice el dependiente.
- ¡Es muy caro! :: Sería «дорого».
- ¡Aquí tiene! :: Sería «вот».
O Можно посмотреть эту куртку :: ¿Puedo ver esta cazadora? :: Se puede + ver + esta + cazadora.

@ 7 | Лучше или хуже? | Comparar
E Los comparativos no cambian :: En ruso «más grande», «más caro» o «mejor» son una sola palabra, y **no cambia** ni con el género ni con el número. :: **больше** (más grande), **меньше** (más pequeño), **лучше** (mejor), **хуже** (peor), **дороже** (más caro), **дешевле** (más barato), **красивее** (más bonito), **быстрее** (más rápido). :: Para la edad: **старше** (mayor) y **младше** (menor).
E Que: чем :: «Que» es **чем**, con una coma delante: **Москва больше, чем Мадрид** = Moscú es más grande que Madrid. :: **Синяя куртка красивее, чем чёрная** = la cazadora azul es más bonita que la negra.
B Comparativos | Adjetivo | Comparativo | Español
| большой | больше | más grande
| маленький | меньше | más pequeño
| хороший | лучше | mejor
| плохой | хуже | peor
| дорогой | дороже | más caro
| дешёвый | дешевле | más barato
| красивый | красивее | más bonito
E El más :: Se pone **самый** delante del adjetivo, y concuerda como él: **самый** большой город (la ciudad más grande), **самая** красивая куртка, **самое** тёплое пальто (el abrigo más abrigado).
W чем = que (al comparar) | chem
W лучше = mejor | LUCH-she
W хуже = peor | JU-zhe
W дороже = más caro | da-RO-zhe
W дешевле = más barato | di-SHEV-lie
W красивее = más bonito | kra-SI-vi-ye
W быстрее = más rápido | byst-RIE-ye
W старше = mayor (de edad) | STAR-she
W младше = menor (de edad) | MLAT-she
W самый = el más | SA-my
W самое = el más (neutro) | SA-ma-ye
W дорогое = caro (neutro) | da-ra-GO-ye
W тёплое = abrigado, cálido (neutro) | TIO-pla-ye
W автобус = autobús | af-TO-bus
V Vocabulario: comparar
D ¿Cuál te gusta más?
Иван: Анна, какая куртка тебе нравится больше: синяя или чёрная? = Anna, ¿qué cazadora te gusta más: la azul o la negra?
  > какая куртка = qué cazadora | тебе нравится больше = te gusta más | синяя или чёрная = la azul o la negra
Анна: Синяя красивее, чем чёрная. = La azul es más bonita que la negra.
  > красивее, чем = más bonita que
Иван: Но она дороже. = Pero es más cara.
  > дороже = más cara
Анна: Сколько они стоят? = ¿Cuánto cuestan?
  > Сколько они стоят = cuánto cuestan ellas
Иван: Синяя стоит шесть тысяч, а чёрная стоит четыре тысячи. = La azul cuesta seis mil y la negra cuesta cuatro mil.
  > шесть тысяч = seis mil | четыре тысячи = cuatro mil
Анна: Да, чёрная дешевле. Но синяя лучше! = Sí, la negra es más barata. ¡Pero la azul es mejor!
  > дешевле = más barata | лучше = mejor
Иван: А это пальто? Оно самое тёплое. = ¿Y este abrigo? Es el más abrigado.
  > Оно = él (neutro) | самое тёплое = el más abrigado
Анна: И самое дорогое! = ¡Y el más caro!
  > самое дорогое = el más caro
T Comparaciones
- Москва больше, чем Мадрид. = Moscú es más grande que Madrid.
  > больше, чем = más grande que
- Мой брат старше, чем я. = Mi hermano es mayor que yo.
  > старше, чем я = mayor que yo
- Моя сестра младше, чем я. = Mi hermana es menor que yo.
  > младше = menor
- Метро быстрее, чем автобус. = El metro es más rápido que el autobús.
  > быстрее = más rápido
- Это самый красивый город. = Esta es la ciudad más bonita.
  > самый красивый = el más bonito
Q ¿Cómo se dice «más caro»?
+ дороже :: Una sola palabra.
- дешевле :: Eso es «más barato».
- дорого больше :: No se forma así.
Q ¿Cómo se dice «mejor»?
+ лучше :: De «хороший».
- хуже :: Eso es «peor».
- больше :: Eso es «más grande».
Q ¿Cómo dices «Moscú es más grande que Madrid»?
+ Москва больше, чем Мадрид. :: Comparativo + чем.
- Москва большой, что Мадрид. :: Hace falta «больше, чем».
- Москва самый Мадрид. :: No.
Q ¿Cómo dices «la ciudad más bonita»?
+ самый красивый город :: Самый + adjetivo.
- красивее город :: Eso es comparativo.
- очень красивый город :: Eso es «una ciudad muy bonita».
R Чёрная куртка дешевле.
+ La cazadora negra es más barata. :: Дешевле = más barato.
- La cazadora negra es más cara. :: Sería «дороже».
- La cazadora negra es mejor. :: Sería «лучше».
H Синяя куртка красивее, ___ чёрная.
+ чем :: Чем = que.
- что :: Eso es «qué».
- как :: Eso es «cómo».
H Это ___ большой город.
+ самый :: «Город» es masculino.
- самое :: Es neutro.
- лучше :: Eso es «mejor».
A Мой брат старше, чем я.
+ Mi hermano es mayor que yo. :: Старше = mayor.
- Mi hermano es menor que yo. :: Sería «младше».
- Mi hermana es mayor que yo. :: Брат = hermano.
O Метро быстрее чем автобус :: El metro es más rápido que el autobús :: Metro + más rápido + que + autobús.
