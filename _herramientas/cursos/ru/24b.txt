I Escucha el texto y contesta. Fíjate en las expresiones de tiempo: desde, hasta, durante, dentro de.
T Расписание
- С утра до вечера я работаю в офисе. = Desde la mañana hasta la noche trabajo en la oficina.
- В течение недели у меня много встреч. = Durante la semana tengo muchas reuniones.
- Через месяц начинаются каникулы. = Dentro de un mes empiezan las vacaciones.
- Курс длится около года. = El curso dura alrededor de un año.
- После обеда я отдыхаю час. = Después de comer descanso una hora.
w встреч = reuniones (genitivo plural) | fstre-CHYOT
w каникулы = vacaciones (plural) | ka-NI-ku-ly
w длится = dura (un curso) | DLI-tsa
w начинаются = empiezan (plural) | na-chi-NA-yu-tsya
w курс = curso (duración) | kurs
w час = hora (una) | chas

R Через месяц начинаются каникулы.
+ Dentro de un mes empiezan las vacaciones. :: Через месяц = dentro de un mes.
- Hace un mes empezaron las vacaciones. :: Eso sería pasado.
- Las vacaciones terminaron un mes antes. :: Eso sería «раньше».
H Курс длится ___ года. :: alrededor de (около)
+ около :: Около + genitivo.
- через :: Es «dentro de».
- после :: Es «después de».
