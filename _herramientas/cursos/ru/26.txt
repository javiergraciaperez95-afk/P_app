@ 26 | Резюме и собеседование | Currículum y entrevista: experiencia, estudios y salario
I Hoy aprendes el lenguaje de la búsqueda de empleo: cómo presentar tu experiencia, qué estudios tienes, cuánto cobras y qué idiomas dominas. Es un tema de B1 real: te hará falta.
E Experiencia y estudios :: Para decir lo que has estudiado se usa **закончить** (terminar) + acusativo: **Я закончил университет** (terminé la universidad). Para decir que dominas un idioma se usa **владеть** + instrumental: **Я владею английским языком** (domino el inglés). :: **Опыт работы** (experiencia laboral) va en genitivo cuando se explica: **опыт работы пять лет** (cinco años de experiencia).
E Salario :: **От** (desde) y **до** (hasta) van con genitivo para dar una horquilla de salario: **зарплата от двух тысяч до трёх тысяч** (salario de dos mil a tres mil). :: Para pedir una vacante se usa **вакансия** y para pedir información se usa **Расскажите** (cuente usted), de forma cortés.
B Tema | Frase | Significado
| estudios | Я закончил университет. | Terminé la universidad.
| idiomas | Я владею английским. | Domino el inglés.
| experiencia | Опыт работы: пять лет. | Experiencia laboral: cinco años.
| salario | Зарплата от двух тысяч. | Salario desde dos mil.
D Entrevista de trabajo
Рекрутер: Расскажите о себе. = Hábleme de usted.
  > Расскажите о себе = hábleme de usted (расскажите = cuente usted)
Кандидат: Я закончил университет и владею английским. = Terminé la universidad y domino el inglés.
  > владею английским = domino el inglés (владеть + instrumental)
Рекрутер: А какой у вас опыт работы? = ¿Qué experiencia laboral tiene?
  > опыт работы = experiencia laboral (опыт + genitivo работы)
Кандидат: Пять лет в банке. = Cinco años en un banco.

V Vocabulario: estudios, idiomas y salario
Q ¿Cómo dices «domino el inglés»?
+ Я владею английским. :: **владеть** + instrumental: **английским**.
- Я владею английский. :: Falta el instrumental: **английским**.
- Я владею английского. :: **английского** es el genitivo: no va con **владею**.
R Я закончил университет.
+ Terminé la universidad. :: **закончил** = terminé (masculino).
- Estudio en la universidad. :: Eso sería **учусь в университете**.
- Trabajo en la universidad. :: Eso sería **работаю в университете**.
H Я владею ___ . :: el inglés (английским)
+ английским :: **владеть** + instrumental.
- английский :: Es el nominativo: falta el instrumental.
- английского :: Es el genitivo: no va con **владею**.
A Опыт работы — пять лет. :: ¿Cuánto tiempo de experiencia tiene?
+ Cinco años. :: **пять лет** = cinco años.
- Diez años. :: Diez es **десять**: no es lo que dice la frase.
- Dos meses. :: No es lo que dice la frase.
O Зарплата от двух тысяч :: Salario desde dos mil :: **от** + genitivo: **двух тысяч** (dos mil).
Q ¿Qué significa «вакансия»?
+ vacante :: **вакансия** = vacante.
- entrevista :: Entrevista es **собеседование**.
- currículum :: Currículum es **резюме**.
H Мы ищем ___ . :: candidato (кандидата)
+ кандидата :: **ищем** + acusativo: **кандидата**.
- кандидат :: Es el nominativo: no va con **ищем**.
- кандидатом :: Es el instrumental: no va con **ищем**.
Q ¿Qué significa «требование»?
+ requisito :: **требование** = requisito.
- formación :: Formación es **образование**.
- salario :: Salario es **зарплата**.

@ 26 | Совещание назначено | En la oficina: reuniones, plazos y acuerdos
I Hoy aprendes a hablar en la oficina: proponer un proyecto, fijar una reunión, decir cuándo es el plazo y mostrar que estás de acuerdo o no.
E Proponer y discutir :: **Давайте обсудим** (discutamos) es la forma cortés de proponer algo a varios: **Давайте обсудим проект** (discutamos el proyecto). **Обсуждать** es discutir de forma habitual o en proceso; **обсудить** es discutir hasta llegar a una solución. :: **Назначить** significa fijar o convocar: **Совещание назначено на четверг** (la reunión está fijada para el jueves).
E De acuerdo y con quién :: **Я согласен** (estoy de acuerdo, hombre) y **Я согласна** (mujer). Con quién estás de acuerdo se dice con **с** + instrumental: **Я согласен с тобой** (estoy de acuerdo contigo). :: El plazo de entrega se dice con **срок**: **Срок отчёта — пятница** (el plazo del informe es el viernes).
B Frase | Significado | Uso
| Давайте обсудим проект. | Discutamos el proyecto. | proponer
| Срок отчёта — пятница. | El plazo del informe es el viernes. | fecha límite
| Я согласен с тобой. | Estoy de acuerdo contigo. | opinión
| Совещание назначено на четверг. | La reunión está fijada para el jueves. | organización
D Reunión de trabajo
Начальник: Давайте обсудим проект. = Discutamos el proyecto.
  > Давайте обсудим = discutamos (davai-te + perfectivo)
Анна: Хорошо. Срок отчёта — в пятницу. = Vale. El plazo del informe es el viernes.
  > Срок отчёта = el plazo del informe (отчёта = informe, genitivo)
Начальник: Я согласен. Совещание назначено на четверг. = Estoy de acuerdo. La reunión está fijada para el jueves.
  > Я согласен = estoy de acuerdo (masculino)
  > назначено на четверг = fijada para el jueves
Анна: Хорошо, я согласна. = Vale, estoy de acuerdo.
  > я согласна = estoy de acuerdo (femenino)

V Vocabulario: proyectos, reuniones y plazos
Q ¿Cómo dices «estoy de acuerdo» (si eres hombre)?
+ Я согласен. :: **согласен** = de acuerdo (masculino).
- Я согласна. :: **согласна** es femenino.
- Я обсуждаю. :: **обсуждаю** = discuto: no es «de acuerdo».
R Давайте обсудим проект.
+ Discutamos el proyecto. :: **давайте обсудим** = discutamos.
- Terminemos el proyecto. :: Eso sería **выполним**, otro verbo.
- Empecemos el proyecto. :: Eso sería **начнём**, otro verbo.
H Совещание ___ на четверг. :: fijada (назначено)
+ назначено :: **назначено** = fijado (neutro, como **совещание**).
- назначен :: Es masculino: no concuerda con **совещание**.
- назначить :: Es el infinitivo: no se usa aquí.
A Срок отчёта — пятница. :: ¿Cuándo es el plazo?
+ El viernes. :: **пятница** = viernes.
- El jueves. :: Jueves es **четверг**.
- Mañana. :: Mañana es **завтра**.
O Я согласен с тобой :: Estoy de acuerdo contigo :: **согласен** (de acuerdo) + **с тобой** (contigo).
Q ¿Qué significa «проект»?
+ proyecto :: **проект** = proyecto.
- informe :: Informe es **отчёт**.
- reunión :: Reunión es **совещание**.
H Мы выполнили ___ . :: la tarea (задачу)
+ задачу :: **выполнить** + acusativo: **задача** → **задачу**.
- задача :: Es el nominativo: falta el acusativo.
- задачи :: Es el genitivo: no va con **выполнили**.
Q ¿Qué significa «обсуждать»?
+ discutir (en proceso, de forma habitual) :: **обсуждать** = discutir.
- decidir :: Decidir es **решить**.
- ignorar :: Ignorar es **игнорировать**.

@ 26 | Уволиться | Dejar el trabajo y el futuro: despido, vacaciones y nuevo empleo
I Hoy aprendes a decir que dejas un trabajo, que tienes vacaciones y que empiezas en otra empresa. Son las frases de los cambios de vida que más se usan.
E Dejar el trabajo :: Para dejar un trabajo voluntariamente se usa **уволиться** (despedirse). Para decir «irse del trabajo» se usa **уйти с работы**: **Я ухожу с работы в пять** (me voy del trabajo a las cinco). **Увольнение** es el despido que hace la empresa. :: **Перейти** (pasar) va con **на**: **перейти на другую работу** (pasar a otro trabajo).
E Me dieron y me ofrecieron :: Con **дать** (dar) la persona que recibe va en dativo: **Мне дали отпуск** (me dieron vacaciones). Con **предложить** (ofrecer) es igual: **Мне предложили новую работу** (me ofrecieron un nuevo trabajo). :: **Собираться** + infinitivo = estar a punto o pensar en hacer algo: **Я собираюсь уволиться** (pienso dejar el trabajo).
B Verbo o frase | Significado | Ejemplo
| уволиться | dejar el trabajo | Я хочу уволиться.
| уйти с работы | irse del trabajo | Я ухожу с работы в пять.
| перейти на другую работу | pasar a otro trabajo | Я хочу перейти на другую работу.
| дать отпуск | conceder vacaciones | Мне дали отпуск.
D Nuevo trabajo
Иван: Мне предложили новую работу. = Me ofrecieron un nuevo trabajo.
  > Мне предложили = me ofrecieron (предложить, en plural con мне)
Анна: Поздравляю! А ты собираешься уволиться? = ¡Felicidades! ¿Y vas a dejar tu trabajo?
  > собираешься уволиться = vas a dejar el trabajo (собираться + infinitivo)
Иван: Да, в конце месяца. Мне дали отпуск, и потом я начну работать в новой компании. = Sí, a finales de mes. Me dieron vacaciones y luego empezaré a trabajar en una empresa nueva.
  > Мне дали отпуск = me dieron vacaciones (дать + dativo)
  > я начну работать = empezaré a trabajar (начать, futuro perfectivo)
Анна: Желаю удачи! = ¡Te deseo suerte!
  > Желаю удачи = te deseo suerte (желать + genitivo)

V Vocabulario: dejar el trabajo y empezar de nuevo
Q ¿Cómo se dice «dejar el trabajo»?
+ уволиться :: **уволиться** = dejar el trabajo.
- увольнение :: **увольнение** es el despido: lo hace la empresa.
- отпуск :: **отпуск** son las vacaciones.
R Мне дали отпуск.
+ Me dieron vacaciones. :: **дали** (dieron) + **мне** (a mí).
- Di vacaciones. :: Eso sería **я дал отпуск**, otro sentido.
- Pedí vacaciones. :: Pedí no es **дали**.
H Мне ___ новую работу. :: ofrecieron (предложили)
+ предложили :: **предложили** = ofrecieron.
- предлагаю :: **предлагаю** = propongo (yo): no es «ofrecieron».
- предложить :: Es el infinitivo: no se conjuga.
A Я начну работать в понедельник. :: ¿Cuándo empezará?
+ El lunes. :: **понедельник** = lunes.
- Ayer. :: Ayer es **вчера**.
- Hoy. :: Hoy es **сегодня**.
O Я собираюсь уволиться :: Pienso dejar el trabajo :: **собираюсь** (pienso) + **уволиться** (dejar el trabajo).
Q ¿Qué significa «отпуск»?
+ vacaciones (laborales) :: **отпуск** = vacaciones laborales.
- despido :: Despido es **увольнение**.
- oferta :: Oferta es **предложение**.
H Я хочу ___ на другую работу. :: pasar (перейти)
+ перейти :: **перейти на** = pasar a otro.
- отпуск :: Es un sustantivo: no es el verbo.
- увольнение :: Es un sustantivo: no es el verbo.
Q ¿Qué significa «удачи»?
+ suerte (¡buena suerte!) :: **удачи** = suerte.
- éxito :: Éxito es **успех**.
- felicidad :: Felicidad es **счастье**.
