@ 23 | Кто-то, что-нибудь | Pronombres indefinidos y negativos: кто-то, что-нибудь, никто, никакой, сам
I Hoy aprendes a decir «alguien», «algo», «nadie», «ninguno» y «uno mismo». En ruso hay varias formas, y cada una tiene un uso distinto.
E Alguien y algo :: **Кто-то** (alguien) y **что-то** (algo) afirman algo no concreto: **Кто-то звонил** (alguien llamó). **Кто-нибудь** y **что-нибудь** se usan en preguntas y peticiones: **Ты что-нибудь хочешь?** (¿quieres algo?).
E Nadie y ninguno :: **Никто** (nadie) y **ничто** (nada) negados con **не** en el verbo: **Никто не пришёл** (nadie vino). **Никакой** (ninguno, ninguna): **Никакой проблемы нет** (no hay ningún problema).
E Uno mismo :: **Себя** (sí mismo) se usa con preposiciones: **думать о себе** (pensar en uno mismo). **Сам** (uno mismo): **Я сам это сделал** (lo hice yo mismo).
B Palabra | Significado | Ejemplo
| кто-то / что-то | alguien / algo | Кто-то звонил.
| кто-нибудь / что-нибудь | alguien / algo (preguntas) | Ты что-нибудь хочешь?
| никто / ничто | nadie / nada | Никто не пришёл.
| себя | sí mismo | Он думает о себе.
D Una llamada perdida
Анна: Кто-то звонил, пока тебя не было. = Alguien llamó mientras no estabas.
  > кто-то звонил = alguien llamó
Иван: Кто? Никто не сказал мне ничего. = ¿Quién? Nadie me dijo nada.
  > никто не сказал = nadie dijo | ничего = nada
Анна: Я сам не знаю, кто это. = Yo mismo no sé quién era.
  > Я сам = yo mismo
Иван: Ладно, я сам перезвоню. = Vale, yo mismo volveré a llamar.
W кто-то = alguien | KTO-ta
W что-то = algo | SHTO-ta
W ничто = nada (pronombre) | nich-TO
W никакой = ninguno; ninguna | ni-ka-KOI
W сам = uno mismo; mismo | sam
w звонил = llamó (masculino) | zva-NIL
w себя = sí mismo (acusativo) | sye-BIA
w кто-нибудь = alguien (en preguntas) | KTO-ni-bud'
w что-нибудь = algo (en preguntas) | SHTO-ni-bud'
w ничего = nada (con «не») | ni-chi-VO
w перезвоню = volveré a llamar | pe-re-zva-NIU
w ладно = vale (en B1) | LAD-na
w себе = sí mismo (dativo o preposicional) | sye-BIE
w пока = mientras | pa-KA
V Vocabulario: alguien, nadie y uno mismo
Q ¿Cómo dices «nadie vino»?
+ Никто не пришёл. :: Никто + не + verbo.
- Кто-то не пришёл. :: Eso sería «alguien no vino».
- Никто пришёл. :: Falta «не».
Q ¿Qué significa «кто-нибудь»?
+ alguien (en preguntas) :: Кто-нибудь se usa en preguntas.
- nadie :: Nadie es «никто».
- alguien (afirmativo) :: Afirmativo es «кто-то».
R Ты что-нибудь хочешь?
+ ¿Quieres algo? :: Что-нибудь = algo, en preguntas.
- Quieres nada. :: Eso sería «ничего».
- Algo quieres. :: No es la pregunta.
H Я думаю о ___ . :: mí mismo (себе)
+ себе :: Думать о себе: себе con preposición.
- себя :: Acusativo: no va con «о» + pensar.
- сам :: Es «yo mismo», no con «о».
A Кто-то звонил. :: ¿Qué pasó?
+ Alguien llamó. :: Кто-то звонил.
- Nadie llamó. :: Eso sería «никто не звонил».
- Llamó un amigo. :: No lo dice la frase.
O Никто не сказал мне ничего :: Nadie me dijo nada :: никто + не + сказал + мне + ничего.

@ 23 | Пока тебя не было | Escucha y lectura: mensajes y llamadas
I Escucha el texto y contesta. Presta atención a los pronombres indefinidos y negativos.
T Пропущенный звонок
- Вчера мне кто-то звонил, но я не слышал. = Ayer alguien me llamó, pero no lo oí.
- Никто не оставил сообщения. = Nadie dejó un mensaje.
- Я сам перезвоню завтра. = Yo mismo volveré a llamar mañana.
- Ты что-нибудь знаешь о нём? = ¿Sabes algo de él?
- Нет, ничего не знаю. = No, no sé nada.
w слышал = oí (masculino) | SLY-shal
w оставил = dejó (masculino) | a-STA-vil
w сообщения = mensaje (genitivo) | sa-ab-SHCHIE-nia
w знаешь = sabes (tú) | ZNA-yesh
w нём = él (preposicional) | nyom
V Vocabulario: llamadas y mensajes
A Вчера мне кто-то звонил. :: ¿Quién llamó?
+ Alguien. :: Кто-то.
- Su madre. :: No lo dice el texto.
- Nadie. :: No lo dice el texto.
A Никто не оставил сообщения. :: ¿Qué pasó con el mensaje?
+ No dejó ningún mensaje. :: Никто не оставил сообщения.
- Dejó un mensaje largo. :: No lo dice el texto.
- Dejó un mensaje de voz. :: No lo dice el texto.
A Я сам перезвоню завтра. :: ¿Quién volverá a llamar?
+ Yo mismo. :: Я сам.
- Otra persona. :: No lo dice el texto.
- Nadie. :: No lo dice el texto.
A Ты что-нибудь знаешь о нём? :: ¿Qué pregunta?
+ Si sabe algo de él. :: Что-нибудь = algo.
- Si conoce a su madre. :: No lo dice el texto.
- Dónde vive. :: No lo dice el texto.
A Нет, ничего не знаю. :: ¿Qué responde?
+ No sabe nada. :: Ничего не знаю = no sé nada.
- Sabe mucho. :: No lo dice el texto.
- Sabe algo. :: Eso sería «что-то».
Q ¿Quién llamó?
+ Alguien. :: Кто-то звонил.
- Nadie. :: Nadie es «никто».
- Un amigo. :: No lo dice el texto.
H Никто не ___ сообщения. :: dejó (оставил)
+ оставил :: Masculino pasado de оставить.
- оставила :: Femenino: no concuerda con «никто».
- оставит :: Futuro: no encaja.
