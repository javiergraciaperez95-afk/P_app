@ 11 | Cuaca dan musim | El clima y las estaciones
I En indonesio se suele omitir «ser» y «estar»: **Cuaca mendung** significa «el tiempo está nublado». **Mengapa** pregunta el motivo y **karena** introduce la razón.
E Hablar del clima :: **Musim hujan** es la estación lluviosa y **musim kemarau**, la seca. Los adjetivos no cambian por género ni número: **cuaca cerah**, **hari cerah**.
E Preguntar el motivo :: **Mengapa?** significa «¿por qué?». Para contestar, **karena** equivale a «porque». Como en español, la razón puede ir al principio o al final de la oración.
W musim = estación (del año) | MU-sim | Se refiere a una estación o temporada, no al «mismo».
W kemarau = estación seca | ke-ma-RAU | Suele nombrar la estación seca de Indonesia.
W hujan = lluvia; llover | HU-jan | Puede nombrar la lluvia o la acción de llover.
W cuaca = tiempo atmosférico | chu-A-cha | Habla del tiempo, no del tiempo que marca el reloj.
W mendung = nublado | men-DUNG | Describe un cielo con nubes que pueden traer lluvia.
W cerah = despejado; luminoso | che-RAH | Se usa para el cielo o el tiempo.
W angin = viento | A-ngin | Aire que se mueve.
W payung = paraguas | PA-yung | Objeto para protegerse de la lluvia o el sol.
W jas hujan = impermeable; chubasquero | jas HU-jan | Prenda para protegerse de la lluvia.
W basah = mojado | BA-sah | Describe algo que tiene agua.
W kering = seco | ke-RING | Describe algo sin agua o humedad.
W banjir = inundación | BAN-jir | Acumulación de agua que cubre una zona.
W mengapa = por qué | meng-A-pa | Pregunta por una causa o motivo.
W karena = porque | ka-RE-na | Introduce la causa o el motivo.
W mungkin = quizá; puede que | MUNG-kin | Indica posibilidad.
W deras = intenso (lluvia) | de-RAS | En «hujan deras» significa lluvia intensa.
W berubah = cambiar; volverse distinto | be-ru-BAH | El prefijo no cambia con la persona.
V El tiempo y las estaciones
D Una mañana nublada
Nina: Bagaimana cuaca hari ini? = ¿Qué tiempo hace hoy?
  > Bagaimana cuaca = qué tiempo hace | hari ini = hoy
Rina: Cuaca hari ini mendung, tetapi belum hujan. = Hoy está nublado, pero todavía no llueve.
  > Cuaca hari ini = el tiempo hoy | mendung = nublado | tetapi belum hujan = pero todavía no llueve
Nina: Mengapa kamu membawa payung? = ¿Por qué llevas un paraguas?
  > Mengapa = por qué | kamu membawa payung = llevas un paraguas
Rina: Karena mungkin akan hujan deras. = Porque quizá llueva intensamente.
  > Karena = porque | mungkin akan hujan deras = quizá llueva intensamente
Nina: Sekarang musim apa? = ¿Qué estación es ahora?
  > Sekarang = ahora | musim apa = qué estación
Rina: Musim kemarau, tetapi cuaca bisa berubah. = La estación seca, pero el tiempo puede cambiar.
  > Musim kemarau = estación seca | tetapi = pero | cuaca bisa berubah = el tiempo puede cambiar
Nina: Apakah jas hujan kamu basah? = ¿Está mojado tu impermeable?
  > Apakah = marcador de pregunta | jas hujan kamu = tu impermeable | basah = mojado
Rina: Tidak. Jas hujan saya kering. = No. Mi impermeable está seco.
  > Tidak = no | jas hujan saya = mi impermeable | kering = seco
Q ¿Qué pregunta «mengapa»?
+ ¿Por qué? :: Pregunta la causa o el motivo.
- ¿Quién? :: «Siapa» pregunta quién.
- ¿Dónde? :: «Di mana» pregunta dónde.
R Cuaca hari ini mendung. :: Elige la traducción correcta.
+ Hoy está nublado. :: «Mendung» describe el cielo nublado.
- Hoy está despejado. :: «Cerah» significa despejado.
- Hoy hay una inundación. :: «Banjir» significa inundación.
H Musim ___ :: Completa «estación seca».
+ kemarau :: «Musim kemarau» es la estación seca.
- deras :: «Deras» describe la intensidad de la lluvia.
- basah :: «Basah» significa mojado.
A Saya membawa payung. :: Escucha y elige el significado.
+ Llevo un paraguas. :: «Payung» significa paraguas.
- Llevo un impermeable. :: «Jas hujan» significa impermeable.
- Estoy en una inundación. :: «Banjir» significa inundación.
O Hujan deras :: Lluvia intensa :: «Deras» describe la intensidad de la lluvia.
Q ¿Qué palabra introduce una razón, como «porque»?
+ karena :: Introduce la causa.
- mengapa :: Pregunta «por qué».
- musim :: Significa estación o temporada.
R Jas hujan saya kering. :: Traduce la frase.
+ Mi impermeable está seco. :: «Kering» significa seco.
- Mi paraguas está mojado. :: «Payung» es paraguas y «basah», mojado.
- Mi impermeable está mojado. :: «Basah» significa mojado.
A Ada banjir setelah hujan deras. :: ¿Qué ocurre después de la lluvia intensa?
+ Hay una inundación. :: «Banjir» es inundación.
- El cielo está despejado. :: «Cerah» significa despejado.
- El viento cambia. :: «Angin» es viento y «berubah», cambiar.

@ 11 | Membandingkan cuaca | Comparar el tiempo
E Comparativo :: Para comparar se usa **lebih + adjetivo + daripada**: **lebih sejuk daripada** significa «más fresco que». **Daripada** marca el segundo elemento de la comparación.
E Superlativo :: **Paling + adjetivo** expresa «el/la más»: **paling nyaman**, «el más agradable». Los adjetivos indonesios no cambian para concordar con el nombre.
B Comparaciones | Indonesio | Español
| lebih sejuk daripada | más fresco que |
| paling nyaman | el/la más agradable |
| lebih tinggi daripada | más alto/a que |
W daripada = que (en una comparación) | da-ri-PA-da | Introduce el segundo elemento: «más fresco que…».
W paling = el/la más | PA-ling | Va delante del adjetivo en un superlativo.
W suhu = temperatura | SU-hu | Grado de calor o frío del aire.
W derajat = grado | de-RA-jat | Unidad para expresar, por ejemplo, la temperatura.
W sejuk = fresco; templado | se-JUK | Describe una temperatura agradablemente fresca.
W lembap = húmedo | lem-BAP | Describe el aire o un lugar con humedad.
W terik = intenso; abrasador | te-RIK | Se usa especialmente para el sol o el calor fuerte.
W teduh = sombreado; a la sombra | te-DUH | Describe un lugar protegido del sol.
W nyaman = cómodo; agradable | nya-MAN | Describe una situación o un lugar agradable.
W meningkat = subir; aumentar | me-ning-KAT | Indica que una cantidad o nivel crece.
W menurun = bajar; disminuir | me-nu-RUN | Indica que una cantidad o nivel desciende.
W daerah = zona; región | da-E-rah | Área o parte de un territorio.
W mengukur = medir | meng-U-kur | Determinar el tamaño, la distancia o la temperatura.
W termometer = termómetro | ter-mo-ME-ter | Instrumento para medir la temperatura.
W rata-rata = promedio; de media | ra-ta RA-ta | Expresa un valor medio.
V Temperaturas y comparaciones
D El tiempo en dos lugares
Nina: Berapa derajat suhu di daerah ini? = ¿A cuántos grados está la temperatura en esta región?
  > Berapa derajat = cuántos grados | suhu di daerah ini = temperatura en esta región
Rina: Rata-rata, dua puluh delapan derajat. = De media, veintiocho grados.
  > Rata-rata = de media | dua puluh delapan derajat = veintiocho grados
Nina: Cuaca di kota lebih terik daripada di daerah ini? = ¿Hace más sol en la ciudad que en esta región?
  > Cuaca di kota = el tiempo en la ciudad | lebih terik daripada di daerah ini = más intenso que en esta región
Rina: Ya. Cuaca di sini lebih sejuk dan lebih nyaman. = Sí. Aquí el tiempo es más fresco y agradable.
  > Ya = sí | Cuaca di sini = el tiempo aquí | lebih sejuk = más fresco | dan lebih nyaman = y más agradable
Nina: Bagaimana orang mengukur suhu? = ¿Cómo mide la gente la temperatura?
  > Bagaimana = cómo | orang mengukur suhu = la gente mide la temperatura
Rina: Mereka mengukur suhu dengan termometer. = Miden la temperatura con un termómetro.
  > Mereka mengukur suhu = miden la temperatura | dengan termometer = con un termómetro
Nina: Suhu hari ini meningkat? = ¿Sube la temperatura hoy?
  > Suhu hari ini = la temperatura hoy | meningkat = sube
Rina: Tidak, suhu menurun. = No, la temperatura baja.
  > Tidak = no | suhu menurun = la temperatura baja
Q ¿Cómo se forma el comparativo «más… que»?
+ lebih + adjetivo + daripada :: «Daripada» introduce aquello con lo que se compara.
- paling + daripada + adjetivo :: «Paling» forma un superlativo y no va así.
- adjetivo + lebih + daripada :: El orden básico empieza por «lebih».
R Cuaca di daerah ini lebih sejuk daripada di kota. :: Traduce la frase.
+ El tiempo en esta región es más fresco que en la ciudad. :: «Lebih sejuk daripada» es «más fresco que».
- El tiempo en esta región es el más fresco de la ciudad. :: El superlativo lleva «paling».
- El tiempo en esta región es menos fresco que en la ciudad. :: La frase no contiene «kurang».
H Suhu di sini ___ daripada suhu di kota. :: Completa «La temperatura aquí es más alta que en la ciudad».
+ lebih tinggi :: «Lebih tinggi» significa más alta.
- lebih panas :: Significa más caliente; no corresponde a la pista.
- paling tinggi :: Significa la más alta y no se compara con «daripada» aquí.
A Suhu menurun. :: Escucha y elige el significado.
+ La temperatura baja. :: «Menurun» significa bajar o disminuir.
- La temperatura sube. :: «Meningkat» significa subir.
- La temperatura es agradable. :: «Nyaman» significa agradable.
O Cuaca di sini paling sejuk :: El tiempo aquí es el más fresco :: «Paling» va delante del adjetivo en el superlativo.
Q ¿Qué significa «rata-rata»?
+ De media; promedio :: Expresa un valor medio.
- En la sombra :: «Teduh» significa sombreado o a la sombra.
- Muy húmedo :: «Lembap» significa húmedo.
R Mereka mengukur suhu dengan termometer. :: Traduce la frase.
+ Miden la temperatura con un termómetro. :: «Mengukur» es medir y «termometer», termómetro.
- Miden la región con un termómetro. :: «Daerah» es una región, no lo que se mide aquí.
- La temperatura baja con el termómetro. :: Esa sería otra frase; no contiene «menurun».
A Daerah ini lebih teduh daripada kota. :: ¿Qué dice la frase?
+ Esta región tiene más sombra que la ciudad. :: «Lebih teduh daripada» compara la sombra.
- Esta región es la más agradable de la ciudad. :: El superlativo requiere «paling».
- La temperatura de la ciudad está bajando. :: «Suhu menurun» expresa que baja la temperatura.

@ 11 | Musim pancaroba | La estación de transición
I En muchas palabras, la repetición con guion puede indicar plural o una cantidad imprecisa: **pohon-pohon**, «árboles». No es obligatorio repetir el nombre para hablar de más de uno.
E La reduplicación :: En indonesio, **daun-daun** puede significar «hojas» o «muchas hojas». El contexto aclara la cantidad; en español normalmente marcamos el plural con **-s** o **-es**.
E La estación de transición :: **Pancaroba** nombra el cambio entre estaciones. En esta época el clima puede variar; aprende las expresiones completas del vocabulario.
W pancaroba = estación de transición | pan-cha-RO-ba | Periodo de cambio entre estaciones.
W peralihan = transición; cambio de una etapa a otra | pe-ra-LI-han | Paso de una situación a otra.
W tidak menentu = variable; imprevisible | ti-DAK me-NEN-tu | Expresión para algo irregular o difícil de prever.
W petir = rayo; relámpago | pe-TIR | Descarga eléctrica que se ve durante una tormenta.
W guntur = trueno | GUN-tur | Sonido de una descarga eléctrica.
W pelangi = arcoíris | pe-LA-ngi | Arco de colores que puede aparecer después de la lluvia.
W pohon = árbol | PO-hon | Planta grande con tronco y ramas.
W pohon-pohon = árboles (varios) | PO-hon PO-hon | Repetir el nombre puede indicar plural o cantidad imprecisa.
W daun = hoja | DA-un | Parte verde de una planta o un árbol.
W daun-daun = hojas (varias) | DA-un DA-un | Repetición con guion para señalar varias hojas.
W jatuh = caer | JA-tuh | Moverse hacia abajo hasta tocar el suelo.
W awan = nube | A-wan | Masa visible de vapor en el cielo.
W awan-awan = nubes (varias) | A-wan A-wan | Repetición con guion para hablar de varias nubes.
W tanah = suelo; tierra | TA-nah | Superficie de la tierra donde crecen las plantas.
W kuat = fuerte | KU-at | Puede describir el viento u otra fuerza.
W bertiup = soplar | ber-TI-up | Se usa, por ejemplo, para el viento.
W bergerak = moverse | ber-ge-RAK | Cambiar de posición.
W muncul = aparecer | MUN-chul | Empezar a verse o hacerse visible.
W masa = periodo; época | MA-sa | Tramo de tiempo.
W adalah = ser; es | a-DA-lah | Se usa para definir o identificar algo; suele omitirse en frases sencillas.
W antara = entre | an-TA-ra | Sitúa algo en medio de dos cosas.
W saat = cuando; momento | SA-at | Puede situar una acción en el momento en que ocurre otra.
V Tiempo cambiante y palabras repetidas
D En época de transición
Nina: Pancaroba itu masa apa? = ¿Qué periodo es la estación de transición?
  > Pancaroba itu = esa estación de transición | masa apa = qué periodo
Rina: Pancaroba adalah masa peralihan antara musim hujan dan musim kemarau. = La estación de transición es el periodo entre la temporada de lluvias y la seca.
  > Pancaroba adalah = la estación de transición es | masa peralihan antara = el periodo de transición entre | musim hujan dan musim kemarau = la temporada de lluvias y la seca
Nina: Cuaca sering tidak menentu saat pancaroba? = ¿El tiempo suele ser variable durante la estación de transición?
  > Cuaca sering tidak menentu = el tiempo suele ser variable | saat pancaroba = durante la transición
Rina: Ya, awan-awan bergerak dan angin bertiup kuat. = Sí, las nubes se mueven y sopla un viento fuerte.
  > awan-awan bergerak = las nubes se mueven | angin bertiup kuat = sopla un viento fuerte
Nina: Mengapa daun-daun jatuh ke tanah? = ¿Por qué caen hojas al suelo?
  > Mengapa = por qué | daun-daun jatuh ke tanah = las hojas caen al suelo
Rina: Karena angin kuat. = Porque el viento es fuerte.
  > Karena = porque | angin kuat = el viento es fuerte
Nina: Apakah pelangi muncul setelah hujan? = ¿Aparece el arcoíris después de la lluvia?
  > Apakah = marcador de pregunta | pelangi muncul = aparece el arcoíris | setelah hujan = después de la lluvia
Rina: Ya, tetapi kadang-kadang ada petir dan guntur. = Sí, pero a veces hay rayos y truenos.
  > Ya = sí | tetapi kadang-kadang = pero a veces | ada petir dan guntur = hay rayos y truenos
Q ¿Qué puede expresar «pohon-pohon»?
+ Árboles o varios árboles :: El nombre repetido puede indicar plural o cantidad imprecisa.
- Un solo árbol :: Para uno solo se dice «pohon».
- Un bosque cerrado :: La palabra significa árboles, pero no especifica un bosque.
R Awan-awan bergerak dan angin bertiup kuat. :: Traduce la frase.
+ Las nubes se mueven y sopla un viento fuerte. :: «Awan-awan» son varias nubes y «bertiup» es soplar.
- La nube aparece y el viento desaparece. :: La frase dice que las nubes se mueven y el viento sopla.
- Las hojas caen al suelo durante la lluvia. :: Esa idea aparece en otra frase.
H Daun-___ jatuh ke tanah. :: Repite la palabra para decir «varias hojas caen al suelo».
+ daun :: «Daun-daun» puede significar varias hojas.
- pohon :: «Pohon» significa árbol.
- awan :: «Awan» significa nube.
A Pancaroba adalah masa peralihan antara musim hujan dan musim kemarau. :: ¿Qué describe la frase?
+ El periodo de transición entre la estación lluviosa y la seca. :: «Pancaroba» es el periodo de transición.
- La estación seca, sin mencionar otra estación. :: La frase incluye también «musim hujan».
- El tiempo despejado durante todo el año. :: La frase no dice que el tiempo esté siempre despejado.
O Daun-daun jatuh ke tanah :: Las hojas caen al suelo :: La repetición puede señalar varias hojas.
Q ¿Qué significa «tidak menentu» al hablar del clima?
+ Variable o imprevisible :: Describe algo irregular o difícil de prever.
- Muy seco :: «Kering» significa seco.
- A la sombra :: «Teduh» significa sombreado.
R Ada petir dan guntur. :: Traduce la frase.
+ Hay rayos y truenos. :: «Petir» es el rayo y «guntur», el trueno.
- Hay nubes y arcoíris. :: «Awan» es nube y «pelangi», arcoíris.
- Hay árboles y hojas. :: «Pohon» es árbol y «daun», hoja.
A Pelangi muncul setelah hujan. :: ¿Qué aparece después de la lluvia?
+ Un arcoíris. :: «Pelangi» significa arcoíris.
- Un trueno. :: «Guntur» significa trueno.
- Un paraguas. :: «Payung» significa paraguas.
