@ 14 | Belanja dengan santun | Comprar con cortesía
I En las tiendas, **silakan + verbo** permite o invita cortésmente: **Silakan pilih** («Por favor, elija»). No equivale a una orden brusca.
E Probar y elegir :: **Kamar pas** es el probador. **Coba baju ini** significa «prueba esta prenda». El indonesio no marca género en los adjetivos: **cocok** puede ser «adecuado» o «quedar bien», según la frase.
E Describir una prenda :: Para dar detalles, puedes nombrar la tela, el estampado, la talla, las mangas y el cuello. Los nombres no cambian por singular o plural.
W batik = batik; tejido estampado indonesio | ba-TIK | Técnica tradicional de teñido por reserva, también usada para nombrar la tela.
W kain = tela; tejido | KA-in | Material con el que se fabrica una prenda.
W corak = estampado; dibujo | CO-rak | Diseño visible en una tela.
W ukuran = talla; medida | u-KU-ran | Dimensión o talla de una prenda.
W lengan = manga; brazo | LE-ngan | En ropa, parte que cubre el brazo.
W kerah = cuello (de una prenda) | ke-RAH | Parte que rodea el cuello en una camisa.
W jahitan = costura | ja-HI-tan | Línea donde se unen dos partes de una tela.
W katun = algodón | ka-TUN | Tejido hecho de algodón.
W sutra = seda | SU-tra | Tejido fino producido con fibras de seda.
W cocok = adecuado; quedar bien | CO-chok | Se usa para la talla, el estilo o una cosa apropiada.
W coba = probar; intenta | CO-ba | Verbo base que sigue a «silakan» en una invitación cortés.
W tersedia = estar disponible | ter-se-DI-a | Indica que un producto se puede obtener.
W pilih = elegir; elija | PI-lih | Forma base del verbo «elegir».
W kamar pas = probador | KA-mar PAS | Espacio de una tienda donde uno se prueba la ropa.
W pilihan = opción; selección | pi-LI-han | Una de varias cosas entre las que se puede elegir.
W bagus = bonito; bueno | BA-gus | Valoración positiva de una cosa o una elección.
W rapi = ordenado; bien acabado | RA-pi | Describe una prenda limpia o una costura bien hecha.
W kuat = resistente; fuerte | KU-at | Describe una costura o material que soporta uso.
V Prendas y tallas
D En la tienda de batik
Nina: Silakan pilih batik, Mbak. = Por favor, elige un batik.
  > Silakan pilih = por favor, elige | batik = batik
Rina: Saya suka corak ini. = Me gusta este estampado.
  > Saya suka = me gusta | corak ini = este estampado
Nina: Kain ini dari katun atau sutra? = ¿Esta tela es de algodón o de seda?
  > Kain ini = esta tela | dari katun atau sutra = de algodón o de seda
Rina: Kain ini dari katun. Ukuran itu tersedia? = Esta tela es de algodón. ¿Está disponible esa talla?
  > Kain ini dari katun = esta tela es de algodón | ukuran itu tersedia = esa talla está disponible
Nina: Ya. Silakan coba baju ini di kamar pas. = Sí. Por favor, pruébate esta prenda en el probador.
  > Ya = sí | Silakan coba baju ini = por favor, pruébate esta prenda | di kamar pas = en el probador
Rina: Apakah ukuran ini cocok? = ¿Me queda bien esta talla?
  > Apakah = partícula de pregunta | ukuran ini cocok = esta talla queda bien
Nina: Ya, pilihan ini bagus. = Sí, esta opción está bien.
  > Ya = sí | pilihan ini bagus = esta opción está bien
T Detalles de la ropa
- Baju batik ini memiliki lengan panjang. = Esta prenda de batik tiene mangas largas.
  > Baju batik ini = esta prenda de batik | memiliki lengan panjang = tiene mangas largas
- Kerah baju ini rapi. = El cuello de esta prenda está bien acabado.
  > Kerah baju ini = el cuello de esta prenda | rapi = está bien acabado
- Jahitan baju ini kuat. = La costura de esta prenda es resistente.
  > Jahitan baju ini = la costura de esta prenda | kuat = es resistente
- Silakan coba ukuran besar. = Por favor, pruébate la talla grande.
  > Silakan coba = por favor, pruébate | ukuran besar = la talla grande
Q ¿Qué significa «kamar pas»?
+ Probador. :: Es el espacio para probarse ropa.
- Cuello de una prenda. :: Eso es «kerah».
- Estampado de una tela. :: Eso es «corak».
R Kain ini dari katun. :: Traduce la frase.
+ Esta tela es de algodón. :: «Kain» es tela y «katun», algodón.
- Esta tela es de seda. :: «Sutra» significa seda.
- Este estampado es de algodón. :: «Corak» es estampado.
H Silakan coba baju ini di kamar ___. :: Completa «Por favor, pruébate esta prenda en el probador».
+ pas :: «Kamar pas» significa probador.
- kerah :: «Kerah» es el cuello de una prenda.
- lengan :: «Lengan» es manga o brazo.
A Jahitan baju ini kuat. :: ¿Cómo es la costura?
+ Es resistente. :: «Kuat» significa resistente o fuerte.
- Está disponible. :: «Tersedia» significa disponible.
- Es de seda. :: «Sutra» significa seda.
O Baju batik ini memiliki lengan panjang :: Esta prenda de batik tiene mangas largas :: «Lengan» es la manga de la prenda.
Q ¿Qué indica «ukuran»?
+ La talla o medida. :: Sirve para hablar del tamaño de una prenda.
- La costura. :: «Jahitan» significa costura.
- La seda. :: «Sutra» significa seda.
R Corak ini cocok. :: Traduce la frase.
+ Este estampado es adecuado. :: «Cocok» expresa que algo resulta apropiado.
- Este estampado está disponible. :: «Tersedia» significa disponible.
- Esta tela es resistente. :: «Kain» es tela y «kuat», resistente.
A Silakan pilih batik, Mbak. :: ¿Qué invita a hacer la dependienta?
+ Elegir un batik. :: «Silakan pilih» es una invitación cortés a elegir.
- Probarse una talla grande. :: La frase no menciona una talla.
- Revisar una costura. :: La frase no menciona una costura.
@ 14 | Produk yang setara | Comparar productos
I Para comparar dos cosas iguales, usa **sama + adjetivo + -nya + dengan** o **se- + adjetivo**: **sama mahalnya dengan** y **semahal**.
E Comparar igualdad :: **Mobil ini sama luasnya dengan mobil itu** y **Mobil ini sebesar mobil itu** expresan que ambos tienen la misma amplitud. En la forma corta, **se-** se une al adjetivo.
E Anuncios de productos :: Un anuncio puede indicar la marca, las características, la capacidad, el espacio de equipaje, los repuestos y el consumo. **Irit** describe un uso bajo de combustible.
W jenama = marca | je-NA-ma | Término formal para la marca de un producto.
W spesifikasi = especificaciones | spe-si-fi-KA-si | Datos que detallan las características de un producto.
W berkapasitas = tener capacidad para | ber-ka-pa-SI-tas | Se usa para indicar cuántas personas u objetos caben.
W kapasitas = capacidad | ka-pa-SI-tas | Cantidad que puede contener un objeto o vehículo.
W bagasi = maletero; espacio para equipaje | ba-GA-si | Compartimento de un vehículo para guardar equipaje.
W luas = amplio; espacioso | LU-as | Describe una superficie o espacio grande.
W luasnya = su amplitud; lo espacioso que es | LU-as-nya | Forma con -nya que aparece en «sama luasnya dengan».
W onderdil = repuesto; pieza de recambio | on-DER-dil | Pieza que se usa para reparar un vehículo.
W bahan bakar = combustible | BA-han BA-kar | Material que hace funcionar un motor, como la gasolina.
W irit = ahorrador; de bajo consumo | I-rit | En un vehículo, describe que consume poco combustible.
W terjangkau = asequible | ter-jang-KAU | Se usa para un precio al alcance del comprador.
W dealer = concesionario; distribuidor | DE-a-ler | Lugar autorizado donde se venden vehículos.
W resmi = oficial; autorizado | RES-mi | Se usa para un distribuidor autorizado o una comunicación oficial.
W garansi = garantía | ga-RAN-si | Compromiso de reparar o sustituir un producto bajo ciertas condiciones.
W semurah = tan barato como | se-MU-rah | Forma se- + murah para comparar dos precios iguales.
W sebesar = tan grande como | se-be-SAR | Forma se- + besar para indicar el mismo tamaño o capacidad.
W setinggi = tan alto como | se-TING-gi | Forma se- + tinggi para comparar alturas.
W mahalnya = lo caro que es; su precio alto | ma-HAL-nya | Forma usada en «sama mahalnya dengan», comparación de igualdad.
V Características y comparaciones
D En el concesionario
Nina: Apa spesifikasi mobil ini? = ¿Qué especificaciones tiene este coche?
  > Apa spesifikasi = qué especificaciones | mobil ini = este coche
Rina: Mobil ini berkapasitas lima penumpang. = Este coche tiene capacidad para cinco pasajeros.
  > Mobil ini berkapasitas = este coche tiene capacidad para | lima penumpang = cinco pasajeros
Nina: Bagasi mobil ini luas? = ¿Es amplio el maletero de este coche?
  > Bagasi mobil ini = el maletero de este coche | luas = amplio
Rina: Ya, mobil ini sama luasnya dengan mobil itu. = Sí, este coche es tan espacioso como aquel.
  > Ya = sí | mobil ini sama luasnya dengan mobil itu = este coche es tan espacioso como aquel
Nina: Harga mobil ini semurah harga mobil itu? = ¿El precio de este coche es tan bajo como el de aquel?
  > Harga mobil ini = el precio de este coche | semurah harga mobil itu = tan bajo como el precio de aquel
Rina: Ya, sama. = Sí, es igual.
  > Ya = sí | sama = igual
T Un anuncio
- Dealer ini resmi. = Este concesionario es oficial.
  > Dealer ini = este concesionario | resmi = es oficial
- Bagasi mobil luas. = El maletero del coche es amplio.
  > Bagasi mobil = el maletero del coche | luas = amplio
- Mobil ini berkapasitas lima penumpang. = Este coche tiene capacidad para cinco pasajeros.
  > Mobil ini berkapasitas = este coche tiene capacidad para | lima penumpang = cinco pasajeros
- Onderdil mobil ini terjangkau. = Los repuestos de este coche son asequibles.
  > Onderdil mobil ini = los repuestos de este coche | terjangkau = son asequibles
- Bahan bakar mobil ini irit. = Este coche consume poco combustible.
  > Bahan bakar mobil ini = el combustible de este coche | irit = es de bajo consumo
Q ¿Qué significa «onderdil»?
+ Repuesto de un vehículo. :: Es una pieza para reparar un vehículo.
- Maletero. :: «Bagasi» es el espacio para el equipaje.
- Garantía. :: «Garansi» significa garantía.
R Mobil ini sama luasnya dengan mobil itu. :: Traduce la comparación.
+ Este coche es tan espacioso como aquel. :: «Sama luasnya dengan» compara dos espacios iguales.
- Este coche es más amplio que aquel. :: La frase indica igualdad, no superioridad.
- El coche está en el concesionario. :: La frase compara dos coches.
H Mobil ini berkapasitas lima ___. :: Completa «Este coche tiene capacidad para cinco pasajeros».
+ penumpang :: «Penumpang» significa pasajero.
- onderdil :: «Onderdil» significa repuesto.
- bagasi :: «Bagasi» es el espacio de equipaje.
A Bahan bakar mobil ini irit. :: ¿Qué característica tiene el combustible?
+ El coche consume poco combustible. :: «Irit» describe un consumo bajo.
- El maletero es amplio. :: «Bagasi» significa maletero.
- Los repuestos son caros. :: «Onderdil» son repuestos y «terjangkau» significa asequible.
O Harga mobil ini semurah harga mobil itu :: El precio de este coche es tan bajo como el de aquel :: «Semurah» compara precios iguales.
Q ¿Qué forma significa «tan alto como»?
+ setinggi :: Se forma con «se-» más «tinggi».
- sebesar :: Significa tan grande como.
- semurah :: Significa tan barato como.
R Onderdil mobil ini terjangkau. :: Traduce la frase.
+ Los repuestos de este coche son asequibles. :: «Terjangkau» describe un precio al alcance del comprador.
- El concesionario es oficial. :: Esa frase sería «Dealer ini resmi».
- Este coche tiene cinco pasajeros. :: Esa frase sería «Mobil ini berkapasitas lima penumpang».
A Harga mobil ini semurah harga mobil itu. :: ¿Qué se compara?
+ Los precios de los dos coches. :: «Semurah» compara que son igual de baratos.
- La capacidad de los coches. :: La frase habla del precio.
- El tamaño de los maleteros. :: La frase no menciona el maletero.

@ 14 | Pesan lewat telepon | Pedir por teléfono
I Para iniciar una llamada, **Halo** equivale a «hola». Para solicitar que alguien haga algo, **tolong + verbo** suaviza la orden. **Bisa pesan...?** es una manera cortés de preguntar si se puede encargar algo.
E Entrega a domicilio :: **Tolong antarkan pesanan ke rumah saya** significa «Por favor, lleva el pedido a mi casa». **Biaya antar** es el coste de entrega.
E Dos usos de ber- :: En **beraroma** y **berbau**, ber- expresa que algo desprende aroma u olor. En **bermobil** y **bermotor**, se refiere a desplazarse usando un vehículo.
W menghubungi = contactar; llamar | meng-hu-BU-ngi | Se usa para ponerse en contacto con alguien por teléfono.
W pesan antar = servicio de entrega a domicilio | pe-SAN AN-tar | Servicio que lleva una compra o comida hasta el cliente.
W paket = paquete | PA-ket | Conjunto o unidad preparada para enviar o vender.
W sebutkan = diga; mencione | se-BUT-kan | Imperativo cortés para pedir que alguien dé un dato.
W pengiriman = envío; entrega | peng-i-RI-man | Proceso de llevar un producto a su destino.
W antarkan = lleve; entregue | an-TAR-kan | Petición para que alguien lleve algo a otra persona o lugar.
W pesanan = pedido; encargo | pe-SA-nan | Producto que una persona ha encargado.
W biaya antar = coste de entrega | bi-A-ya AN-tar | Precio que se paga por llevar un pedido.
W termasuk = estar incluido; incluir | ter-ma-SUK | Indica que algo forma parte de un precio o conjunto.
W parfum = perfume | par-FUM | Producto con aroma agradable.
W beraroma = desprender aroma | ber-a-RO-ma | Forma ber- + aroma; algo despide un aroma.
W wangi = perfumado; fragante | WA-ngi | Describe un olor agradable.
W sampah = basura; residuos | SAM-pah | Cosas que se desechan.
W berbau = desprender olor; oler | ber-BA-u | Forma ber- + bau; algo despide un olor.
W busuk = podrido; maloliente | BU-suk | Describe comida o residuos en mal estado y su olor.
W bermobil = desplazarse en coche | ber-MO-bil | En este uso, ber- indica que se va en coche.
W bermotor = desplazarse en moto | ber-MO-tor | En este uso, ber- indica que se viaja en motocicleta.
W kampus = campus universitario | KAM-pus | Recinto o zona de una universidad.
V Llamadas y entregas
D Un pedido por teléfono
Nina: Halo, selamat siang. Apakah ini layanan pesan antar? = Hola, buenas tardes. ¿Es este el servicio de entrega?
  > Halo, selamat siang = hola, buenas tardes | Apakah ini = es este | layanan pesan antar = servicio de entrega
Rina: Ya. Anda mau pesan apa? = Sí. ¿Qué desea encargar?
  > Ya = sí | Anda mau pesan apa = qué desea encargar
Nina: Bisa pesan satu paket batik? = ¿Puedo encargar un paquete de batik?
  > Bisa pesan = puedo encargar | satu paket batik = un paquete de batik
Rina: Bisa. Tolong sebutkan alamat pengiriman. = Sí. Por favor, diga la dirección de entrega.
  > Bisa = sí, se puede | Tolong sebutkan = por favor, diga | alamat pengiriman = dirección de entrega
Nina: Tolong antarkan pesanan ke rumah saya. = Por favor, lleva el pedido a mi casa.
  > Tolong antarkan = por favor, lleva | pesanan = el pedido | ke rumah saya = a mi casa
Rina: Baik. Biaya antar sudah termasuk. = De acuerdo. El coste de entrega ya está incluido.
  > Baik = de acuerdo | biaya antar = coste de entrega | sudah termasuk = ya está incluido
T Olores y transporte
- Parfum itu beraroma wangi. = Ese perfume desprende un aroma fragante.
  > Parfum itu = ese perfume | beraroma wangi = desprende un aroma fragante
- Sampah itu berbau busuk. = Esa basura desprende mal olor.
  > Sampah itu = esa basura | berbau busuk = desprende mal olor
- Nina bermobil ke kantor. = Nina va a la oficina en coche.
  > Nina bermobil = Nina va en coche | ke kantor = a la oficina
- Rina bermotor ke kampus. = Rina va a la universidad en moto.
  > Rina bermotor = Rina va en moto | ke kampus = a la universidad
Q ¿Qué significa «biaya antar»?
+ Coste de entrega. :: Es el precio por llevar el pedido.
- El propio pedido. :: «Pesanan» es el pedido.
- Un perfume fragante. :: «Parfum beraroma wangi» es perfume fragante.
R Tolong antarkan pesanan ke rumah saya. :: Traduce la petición.
+ Por favor, lleva el pedido a mi casa. :: «Tolong» suaviza la petición.
- El pedido ya está incluido. :: Eso sería «Pesanan sudah termasuk».
- Por favor, diga la dirección de entrega. :: Eso sería «Tolong sebutkan alamat pengiriman».
H Bisa pesan satu ___ batik? :: Completa «¿Puedo encargar un paquete de batik?».
+ paket :: «Paket» significa paquete.
- parfum :: «Parfum» significa perfume.
- sampah :: «Sampah» significa basura.
A Sampah itu berbau busuk. :: ¿Qué olor desprende la basura?
+ Un olor desagradable, como de algo podrido. :: «Busuk» significa podrido o maloliente.
- Un aroma fragante. :: «Wangi» describe un olor agradable.
- No tiene olor. :: «Berbau» indica que desprende olor.
O Bisa pesan satu paket batik :: ¿Puedo encargar un paquete de batik? :: «Bisa pesan» sirve para pedir algo con cortesía.
Q ¿Qué indica «beraroma»?
+ Que algo desprende aroma. :: En este uso, ber- expresa emitir un aroma.
- Que alguien viaja en coche. :: «Bermobil» se refiere a ir en coche.
- Que algo está incluido. :: «Termasuk» significa incluido.
R Rina bermotor ke kampus. :: Traduce la frase.
+ Rina va a la universidad en moto. :: «Bermotor» indica desplazarse en moto.
- Rina envía un pedido a la universidad. :: La frase habla de desplazarse, no de entregar.
- Rina tiene una moto. :: La frase no expresa posesión.
A Halo, selamat siang. Apakah ini layanan pesan antar? :: ¿Qué pregunta la persona?
+ Si está llamando al servicio de entrega. :: «Layanan pesan antar» es un servicio de entrega.
- Si hay un paquete de perfume. :: La frase no menciona un perfume.
- Si el coste de envío está incluido. :: Esa pregunta aparece al final de la llamada.
