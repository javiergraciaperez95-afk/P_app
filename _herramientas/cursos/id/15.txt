@ 15 | Radio dan perasaan | Radio y sentimientos
I **Ber-** puede indicar un estado: **bersedih** («estar triste») y **berbahagia** («estar feliz»). Para intensificar, el manual usa **sekali** («mucho; muy») y **terlalu** («demasiado»), que ya conoces.
E Pedir una canción :: En una llamada a la radio puedes pedir que pongan una canción con **Tolong putarkan lagu itu** («Por favor, ponga esa canción»). **Putarkan** contiene el sufijo -kan, que dirige la acción hacia algo.
E Verbos con ber- :: **Ber-** no tiene un solo significado: en **bersedih** marca un estado, y en **berkelompok**, que algo está organizado en grupos.
W radio = radio | RA-di-o | Medio de comunicación que transmite programas y música.
W penyiar = locutor/a; presentador/a | pe-NYI-ar | Persona que presenta un programa de radio.
W siaran = emisión; transmisión | si-A-ran | Programa o contenido que se transmite.
W kabin siar = cabina de emisión | KA-bin si-AR | Espacio desde donde se transmite un programa de radio.
W program = programa | pro-GRAM | Contenido preparado para emitirse.
W berada = estar situado; encontrarse | ber-A-da | Indica dónde se encuentra una persona o cosa.
W hiburan = entretenimiento | hi-BU-ran | Actividad o contenido que distrae y divierte.
W sedih = triste | SE-dih | Describe un sentimiento.
W bersedih = estar triste | ber-SE-dih | Forma ber- que indica el estado de estar triste.
W bahagia = feliz; felizmente | ba-HA-gi-a | Describe un estado de felicidad.
W berbahagia = estar feliz | ber-ba-HA-gi-a | Forma ber- que indica un estado de felicidad.
W butuh = necesitar | BU-tuh | Verbo cotidiano para expresar una necesidad.
W tugas = tarea; trabajo asignado | TU-gas | Trabajo que una persona debe completar.
W individu = individual | in-di-VI-du | Se refiere a una persona por separado.
W kelompok = grupo | ke-LOM-pok | Conjunto de personas.
W berkelompok = estar en grupos; agruparse | ber-ke-LOM-pok | Forma ber- que indica que varias personas están en grupos.
W putarkan = ponga; reproduzca | pu-TAR-kan | Petición para que alguien reproduzca una canción.
W durasi = duración | du-RA-si | Tiempo que dura un programa o una canción.
W berlangsung = tener lugar; durar | ber-LANG-sung | Indica que un programa o actividad sucede durante un tiempo.
W banyak = mucho; muchos | BA-nyak | Indica una cantidad grande.
W kenapa = por qué | ke-NA-pa | Pregunta la razón de algo.
V Radio y emociones
D Una llamada al programa
Nina: Halo, ini radio kampus? = Hola, ¿es la radio del campus?
  > Halo = hola | ini radio kampus = es la radio del campus
Rina: Ya, saya penyiar di radio. = Sí, soy locutora de radio.
  > Ya = sí | saya penyiar di radio = soy locutora de radio
Nina: Saya sedang bersedih. Saya butuh hiburan. = Estoy triste. Necesito entretenimiento.
  > Saya sedang bersedih = estoy triste | saya butuh hiburan = necesito entretenimiento
Rina: Kenapa? = ¿Por qué?
  > Kenapa = por qué
Nina: Tugas individu banyak sekali. Tugas berkelompok juga terlalu banyak. = Tengo muchísimas tareas individuales. Las tareas en grupo también son demasiadas.
  > Tugas individu = tareas individuales | banyak sekali = muchísimas | tugas berkelompok = tareas en grupo | terlalu banyak = demasiadas
Rina: Jangan bersedih. Tolong putarkan lagu itu. = No estés triste. Por favor, ponga esa canción.
  > Jangan bersedih = no estés triste | Tolong putarkan lagu itu = por favor, ponga esa canción
T Un programa de radio
- Penyiar berada di kabin siar. = El locutor está en la cabina de emisión.
  > Penyiar = el locutor | berada di kabin siar = está en la cabina de emisión
- Program hiburan berlangsung satu jam. = El programa de entretenimiento dura una hora.
  > Program hiburan = el programa de entretenimiento | berlangsung satu jam = dura una hora
- Siaran radio itu untuk hiburan. = Esa emisión de radio es para entretener.
  > Siaran radio itu = esa emisión de radio | untuk hiburan = para entretener
Q ¿Qué significa «penyiar»?
+ Locutor o presentador. :: Es quien presenta el programa.
- Tarea individual. :: «Tugas individu» significa tarea individual.
- Cabina de emisión. :: «Kabin siar» es la cabina.
R Saya butuh hiburan. :: Traduce la frase.
+ Necesito entretenimiento. :: «Butuh» significa necesitar.
- Estoy muy triste. :: Esa frase sería «Saya bersedih sekali».
- Necesito una canción. :: La frase pide entretenimiento en general.
H Tugas ___ juga terlalu banyak. :: Completa «Las tareas en grupo también son demasiadas».
+ berkelompok :: «Tugas berkelompok» son tareas hechas en grupo.
- bersedih :: «Bersedih» significa estar triste.
- berbahagia :: «Berbahagia» significa estar feliz.
A Program hiburan berlangsung satu jam. :: ¿Cuánto dura el programa?
+ Una hora. :: «Satu jam» significa una hora.
- Un día. :: «Jam» significa hora.
- Una canción. :: La frase habla de un programa.
O Jangan bersedih :: No estés triste :: «Jangan» forma una prohibición o consejo negativo.
Q ¿Qué indica «berkelompok»?
+ Que varias personas están en grupos. :: En esta palabra, ber- indica agrupación.
- Que una persona está triste. :: «Bersedih» expresa tristeza.
- Que el programa está en emisión. :: «Siaran» significa emisión.
R Tolong putarkan lagu itu. :: Traduce la petición.
+ Por favor, ponga esa canción. :: «Putarkan» pide que se reproduzca la canción.
- Por favor, detenga el programa. :: La frase pide poner una canción.
- No estés triste por la canción. :: Esa idea se expresaría de otra manera.
A Saya sedang bersedih. Saya butuh hiburan. :: ¿Cómo se siente la persona?
+ Está triste y necesita entretenimiento. :: «Bersedih» expresa tristeza y «butuh», necesidad.
- Está feliz y presenta la radio. :: «Berbahagia» significaría estar feliz.
- Está en la cabina de emisión. :: No se menciona una cabina.
@ 15 | Jenis film | Géneros de películas
I El vocabulario de películas permite describir personajes y escenas. En indonesio, **komedi** suele ser «comedia» y **komedi lucu** puede describirse como una película que hace reír.
E Géneros :: **Film aksi** suele incluir escenas de acción; **film drama** presenta situaciones serias; **film petualangan** trata de búsquedas o viajes; **film horor** busca asustar; **film perang** cuenta historias de guerra.
E Personajes y escenas :: **Tokoh** es un personaje; **pemeran** es quien lo interpreta. **Adegan menegangkan** es una escena que genera tensión.
W aksi = acción; de acción | AK-si | Se refiere al género de acción o a una acción.
W drama = drama | DRA-ma | Género centrado en situaciones serias o emocionales.
W petualangan = aventura | pe-tu-a-LANG-an | Género de historias de viajes, desafíos o búsquedas.
W perang = guerra; de guerra | pe-RANG | Género de historias sobre guerras.
W adegan = escena | a-DE-gan | Parte de una película o representación.
W tokoh = personaje | TO-koh | Persona que aparece en una historia.
W utama = principal; protagonista | u-TA-ma | Describe al personaje más importante.
W pemeran = actor; intérprete | pe-me-RAN | Persona que interpreta un personaje.
W jagoan = héroe; protagonista valiente | ja-GO-an | Personaje que suele enfrentarse al villano.
W musuh = enemigo | MU-suh | Personaje que se opone al héroe.
W penonton = espectador/a | pe-NON-ton | Persona que mira una película o espectáculo.
W menegangkan = emocionante; que genera tensión | me-ne-GANG-kan | Describe algo que produce tensión.
W penuh = lleno de; lleno | PE-nuh | Indica que algo contiene mucho de cierta cosa.
W lucu = gracioso; divertido | LU-chu | Describe algo que hace reír.
W serius = serio | se-RI-us | Describe una historia o situación sin tono cómico.
W takut = tener miedo; asustado | TA-kut | Describe el miedo de una persona.
W membuat = hacer; provocar | mem-BU-at | Verbo para decir que algo causa un efecto.
W tertawa = reírse | ter-TA-wa | Hacer el sonido o gesto de la risa.
W melawan = luchar contra; enfrentarse a | me-LA-wan | Actuar en contra de un rival o enemigo.
V Géneros y personajes
D Una conversación sobre películas
Nina: Kamu suka film apa? = ¿Qué tipo de películas te gustan?
  > Kamu suka = te gusta | film apa = qué película
Rina: Saya suka film komedi. Film komedi ini lucu. = Me gustan las películas de comedia. Esta comedia es divertida.
  > Saya suka film komedi = me gustan las películas de comedia | film komedi ini lucu = esta comedia es divertida
Nina: Bagaimana dengan film aksi? = ¿Y las películas de acción?
  > Bagaimana dengan = qué tal | film aksi = película de acción
Rina: Film aksi penuh adegan menegangkan. = Las películas de acción están llenas de escenas emocionantes.
  > Film aksi = película de acción | penuh adegan menegangkan = llena de escenas emocionantes
Nina: Siapa tokoh utama dalam film itu? = ¿Quién es el personaje principal de esa película?
  > Siapa tokoh utama = quién es el personaje principal | dalam film itu = en esa película
Rina: Tokoh utama melawan musuh. = El personaje principal se enfrenta al enemigo.
  > Tokoh utama = el personaje principal | melawan musuh = se enfrenta al enemigo
T Una guía breve
- Film drama ini serius. = Este drama es serio.
  > Film drama ini = este drama | serius = es serio
- Pemeran menjadi tokoh utama. = El actor interpreta al personaje principal.
  > Pemeran = el actor | menjadi tokoh utama = interpreta al personaje principal
- Film horor membuat penonton takut. = Las películas de terror asustan al público.
  > Film horor = película de terror | membuat penonton takut = asusta al público
- Film komedi membuat penonton tertawa. = Las comedias hacen reír al público.
  > Film komedi = película de comedia | membuat penonton tertawa = hacen reír al público
Q ¿Qué género suele buscar que el público tenga miedo?
+ horor :: Las películas de terror provocan miedo.
- komedi :: Las comedias buscan hacer reír.
- drama :: El drama se centra en situaciones serias.
R Film komedi membuat penonton tertawa. :: Traduce la frase.
+ Las comedias hacen reír al público. :: «Membuat tertawa» significa hacer reír.
- Las películas de terror asustan al público. :: Eso sería «Film horor membuat penonton takut».
- El drama cuenta una historia de guerra. :: La frase habla de una comedia.
H Film aksi penuh adegan ___. :: Completa «Las películas de acción están llenas de escenas emocionantes».
+ menegangkan :: «Adegan menegangkan» es una escena que genera tensión.
- lucu :: «Lucu» significa gracioso.
- serius :: «Serius» significa serio.
A Tokoh utama melawan musuh. :: ¿Qué hace el personaje principal?
+ Se enfrenta al enemigo. :: «Melawan» significa enfrentarse a.
- Hace reír al público. :: «Tertawa» significa reírse.
- Presenta la película. :: Esa acción correspondería al «pemeran» en otro contexto.
O Film drama ini serius :: Este drama es serio :: «Serius» describe el tono de la historia.
Q ¿Qué palabra significa «espectador»?
+ penonton :: Es quien mira la película.
- pemeran :: Es quien interpreta un personaje.
- tokoh :: Es el personaje de la historia.
R Pemeran menjadi tokoh utama. :: Traduce la frase.
+ El actor interpreta al personaje principal. :: «Pemeran» es quien interpreta y «utama», el principal.
- El espectador se enfrenta al enemigo. :: Esa frase no aparece aquí.
- La película de acción tiene escenas tensas. :: La frase habla de un actor.
A Film horor membuat penonton takut. :: ¿Qué efecto causa la película de terror?
+ Asusta al público. :: «Takut» significa tener miedo.
- Hace que el público se ría. :: Esa es la descripción de una comedia.
- Hace que el público viaje. :: La frase no menciona viajar.

@ 15 | Cerita di balik film | La historia detrás de una película
I Para contar información básica de una película, puedes decir quién la estrenó, de dónde viene la historia y quién interpreta al personaje principal.
E Un estreno :: **Produser merilis film ini** significa «El productor estrena esta película». En esta forma, meN- expresa la acción que realiza el sujeto.
E Clasificadores :: **Seorang** acompaña a una persona, **sebuah** a un objeto y **seekor** a un animal. El español suele decir «un/una» en los tres casos, pero el indonesio distingue estas categorías.
W produser = productor/a | pro-DU-ser | Persona o empresa que organiza y financia una película.
W merilis = estrenar; lanzar | me-RI-lis | Forma meN- que expresa la acción de publicar o estrenar.
W judul = título | JU-dul | Nombre de una película, canción o texto.
W singkat = breve; corto | SING-kat | Describe algo de poca duración o pocas palabras.
W berjudul = titularse; llevar por título | ber-JU-dul | Indica el título de una obra.
W novel = novela | no-VEL | Obra de ficción escrita en prosa.
W berasal = proceder; tener origen | ber-a-SAL | Indica de dónde viene algo.
W lanjutan = continuación; secuela | lan-JU-tan | Obra que continúa una historia anterior.
W sebelumnya = anterior; de antes | se-be-LUM-nya | Se refiere a algo que ocurrió o existió antes.
W seorang = un/una (persona) | se-o-RANG | Clasificador que se usa para contar personas.
W sebuah = un/una (objeto) | se-BU-ah | Clasificador frecuente para contar objetos y obras.
W seekor = un/una (animal) | se-E-kor | Clasificador que se usa para contar animales.
W hewan = animal | HE-wan | Ser vivo que no es una planta ni una persona.
W karakter = carácter; personalidad | ka-RAK-ter | Cualidad o forma de ser de un personaje.
W jujur = honesto; sincero | JU-jur | Describe a una persona que dice la verdad.
W bijaksana = sensato; sabio | bi-jak-SA-na | Describe a una persona que toma buenas decisiones.
W memainkan = interpretar; representar | me-ma-IN-kan | Actuar como un personaje en una película o una obra.
W bersikap = comportarse; actuar | ber-SI-kap | Describe la manera en que una persona actúa.
V Películas y personajes
D Una reseña
Nina: Siapa produser film ini? = ¿Quién produce esta película?
  > Siapa produser = quién es el productor | film ini = esta película
Rina: Seorang produser merilis film ini. = Un productor estrena esta película.
  > Seorang produser = un productor | merilis film ini = estrena esta película
Nina: Apa judul film ini? = ¿Cuál es el título de esta película?
  > Apa judul = cuál es el título | film ini = de esta película
Rina: Judul film ini singkat. Film ini berjudul Cerita Baru. = El título es breve. La película se titula «Historia nueva».
  > Judul film ini singkat = el título de esta película es breve | Film ini berjudul Cerita Baru = la película se titula Historia nueva
Nina: Cerita film ini berasal dari sebuah novel? = ¿La historia de esta película procede de una novela?
  > Cerita film ini = la historia de esta película | berasal dari sebuah novel = procede de una novela
Rina: Ya. Film ini lanjutan dari film sebelumnya. = Sí. Esta película es la continuación de la anterior.
  > Ya = sí | Film ini lanjutan = esta película es la continuación | dari film sebelumnya = de la película anterior
Nina: Bagaimana karakter tokoh utama? = ¿Cómo es la personalidad del personaje principal?
  > Bagaimana karakter = cómo es la personalidad | tokoh utama = del personaje principal
Rina: Tokoh utama jujur dan bijaksana. = El personaje principal es honesto y sensato.
  > Tokoh utama = el personaje principal | jujur dan bijaksana = honesto y sensato
T Datos de una película
- Produser merilis sebuah film tahun ini. = El productor estrena una película este año.
  > Produser = el productor | merilis sebuah film = estrena una película | tahun ini = este año
- Seorang pemeran memainkan tokoh utama. = Un actor interpreta al personaje principal.
  > Seorang pemeran = un actor | memainkan tokoh utama = interpreta al personaje principal
- Film itu berasal dari sebuah novel. = Esa película procede de una novela.
  > Film itu = esa película | berasal dari sebuah novel = procede de una novela
- Tokoh utama bersikap jujur. = El personaje principal se comporta con honestidad.
  > Tokoh utama = el personaje principal | bersikap jujur = se comporta con honestidad
Q ¿Qué clasificador se usa normalmente con una persona?
+ seorang :: Se usa al contar personas.
- sebuah :: Se usa con objetos y obras.
- seekor :: Se usa con animales.
R Seorang produser merilis sebuah film. :: Traduce la frase.
+ Un productor estrena una película. :: «Seorang» acompaña a una persona y «sebuah», a una obra.
- Un animal estrena una película. :: «Seekor» se usa con animales.
- Una novela produce una película. :: La frase dice que un productor estrena la película.
H ___ novel itu berasal dari cerita. :: Completa «Esa novela procede de una historia».
+ Sebuah :: «Sebuah» acompaña a un objeto o una obra.
- Seorang :: «Seorang» acompaña a una persona.
- Seekor :: «Seekor» acompaña a un animal.
A Tokoh utama jujur dan bijaksana. :: ¿Cómo es el personaje principal?
+ Honesto y sensato. :: «Jujur» es honesto y «bijaksana», sensato.
- Triste y feliz. :: Esos sentimientos se expresan con «sedih» y «bahagia».
- Un productor y un actor. :: La frase describe el carácter de un personaje.
O Film ini lanjutan dari film sebelumnya :: Esta película es la continuación de la anterior :: «Lanjutan» significa continuación.
Q ¿Qué significa «berjudul»?
+ Titularse; llevar un título. :: Presenta el título de una obra.
- Proceder de una novela. :: Eso es «berasal dari sebuah novel».
- Ser el productor. :: «Produser» significa productor.
R Cerita film ini berasal dari sebuah novel. :: Traduce la frase.
+ La historia de esta película procede de una novela. :: «Berasal dari» expresa el origen.
- El título de esta película es breve. :: Esa frase sería «Judul film ini singkat».
- Un productor estrena esta película. :: Esa frase sería «Produser merilis film ini».
A Seorang pemeran memainkan tokoh utama. :: ¿Qué hace el actor?
+ Interpreta al personaje principal. :: «Memainkan» significa interpretar aquí.
- Estrena la película. :: Eso lo hace el «produser».
- Cuenta la duración de la película. :: No se menciona la duración.
