@ 17 | Undangan dan harapan | Invitaciones y buenos deseos
I **Semoga + frase** expresa un deseo: **Semoga pesta lancar** («Ojalá la fiesta salga bien»). **Pernah** ya apareció en A1 para preguntar por experiencias; aquí se repasa junto a otras frecuencias.
E Invitaciones :: **Undangan ulang tahun** es una invitación de cumpleaños. **Tema pesta** indica el tema de la fiesta.
E Hablar de experiencias :: **Pernah** significa «alguna vez»; **sering**, «a menudo»; **jarang**, «rara vez»; y **tidak pernah**, «nunca». Estas palabras no cambian el verbo.
W undangan = invitación | un-DANG-an | Mensaje que invita a alguien a una actividad.
W ulang tahun = cumpleaños | u-LANG TA-hun | Día en que se cumple un año más de vida.
W pesta = fiesta | PES-ta | Celebración con invitados.
W tema = tema; asunto | TE-ma | Idea que define el contenido de una actividad.
W pahlawan super = superhéroe | pah-LA-wan SU-per | Personaje con poderes o habilidades extraordinarias.
W semoga = ojalá; espero que | se-MO-ga | Introduce un deseo o una esperanza.
W lancar = ir bien; sin problemas | LAN-char | Describe una actividad que se desarrolla sin dificultad.
W ulangan = examen; prueba de clase | u-LANG-an | Evaluación escolar de los conocimientos.
W bahas = hablar de; discutir | BA-has | Tratar un tema en una conversación.
W merayakan = celebrar | me-ra-YA-kan | Realizar una actividad para conmemorar algo.
W hadiah = regalo | ha-DI-ah | Objeto que se da a otra persona como obsequio.
W tamu = invitado/a; visita | TA-mu | Persona que acude a una casa o celebración.
W menyiapkan = preparar | me-nyi-AP-kan | Dejar algo listo para usar o realizar.
W menarik = interesante; atractivo | me-NA-rik | Describe algo que llama la atención.
W lain = otro/a; distinto | LA-in | Distingue una cosa o persona de otra.
V Invitaciones y deseos
D Preparar una fiesta
Nina: Rina menyiapkan undangan pesta ulang tahun. = Rina prepara las invitaciones para la fiesta de cumpleaños.
  > Rina menyiapkan = Rina prepara | undangan pesta ulang tahun = invitaciones para la fiesta de cumpleaños
Rina: Apa tema pesta itu? = ¿Cuál es el tema de esa fiesta?
  > Apa tema = cuál es el tema | pesta itu = de esa fiesta
Nina: Tema pesta pahlawan super. = El tema de la fiesta es de superhéroes.
  > Tema pesta = el tema de la fiesta | pahlawan super = superhéroes
Rina: Kamu pernah merayakan ulang tahun di rumah? = ¿Alguna vez has celebrado tu cumpleaños en casa?
  > Kamu pernah merayakan = alguna vez has celebrado | ulang tahun di rumah = tu cumpleaños en casa
Nina: Ya. Saya juga pernah menyiapkan hadiah. = Sí. También he preparado un regalo alguna vez.
  > Ya = sí | saya juga pernah menyiapkan hadiah = yo también he preparado un regalo alguna vez
Rina: Semoga pesta lancar. = Ojalá la fiesta salga bien.
  > Semoga = ojalá | pesta lancar = la fiesta sale bien
Nina: Terima kasih. Kita bahas undangan setelah ulangan. = Gracias. Hablemos de la invitación después del examen.
  > Terima kasih = gracias | kita bahas undangan = hablemos de la invitación | setelah ulangan = después del examen
T Una invitación
- Tema pesta itu pahlawan super. = El tema de la fiesta son los superhéroes.
  > Tema pesta itu = el tema de la fiesta | pahlawan super = son los superhéroes
- Tamu membawa hadiah. = Los invitados traen regalos.
  > Tamu = los invitados | membawa hadiah = traen regalos
- Semoga pesta lancar. = Ojalá la fiesta salga bien.
  > Semoga = ojalá | pesta lancar = la fiesta salga bien
- Ulangan selesai, lalu pesta mulai. = Termina el examen y luego empieza la fiesta.
  > Ulangan selesai = termina el examen | lalu pesta mulai = luego empieza la fiesta
Q ¿Qué expresa «semoga»?
+ Un deseo o una esperanza. :: Se usa para expresar lo que uno espera que ocurra.
- Una frecuencia alta. :: «Sering» significa a menudo.
- Una invitación informal. :: «Yuk» invita a hacer algo.
R Semoga pesta lancar. :: Traduce el deseo.
+ Ojalá la fiesta salga bien. :: «Lancar» significa que algo va sin problemas.
- La fiesta es un examen. :: «Ulangan» significa examen.
- Prepara la fiesta ahora. :: La frase expresa un deseo, no una orden.
H Tema pesta ___ super. :: Completa «El tema de la fiesta es de superhéroes».
+ pahlawan :: «Pahlawan super» significa superhéroe.
- hadiah :: «Hadiah» significa regalo.
- tamu :: «Tamu» significa invitado.
A Kamu pernah merayakan ulang tahun di rumah? :: ¿Qué pregunta la persona?
+ Si alguna vez celebraste un cumpleaños en casa. :: «Pernah» pregunta por una experiencia.
- Si preparaste un regalo esta mañana. :: La frase pregunta por una experiencia pasada en general.
- Si la fiesta salió bien. :: No se pregunta cómo fue la fiesta.
O Rina menyiapkan undangan pesta ulang tahun :: Rina prepara las invitaciones para la fiesta de cumpleaños :: «Menyiapkan» significa preparar.
Q ¿Qué significa «ulangan»?
+ Examen o prueba de clase. :: Es una evaluación escolar.
- Invitación. :: «Undangan» significa invitación.
- Regalo. :: «Hadiah» significa regalo.
R Tamu membawa hadiah. :: Traduce la frase.
+ Los invitados traen regalos. :: «Tamu» es invitado y «hadiah», regalo.
- Los superhéroes preparan la fiesta. :: La frase habla de invitados y regalos.
- La invitación sale bien. :: «Lancar» significa ir bien.
A Kita bahas undangan setelah ulangan. :: ¿Cuándo hablarán de la invitación?
+ Después del examen. :: «Setelah» significa después.
- Antes de la fiesta. :: La frase menciona el examen como punto de referencia.
- Durante el cumpleaños. :: La frase no lo indica.
@ 17 | Membuat akun | Crear una cuenta
I En una instrucción, **-lah** se añade al verbo: **Bukalah laman** («Abre la página»). La forma suena como una indicación completa; en listas de pasos también son comunes los imperativos directos.
E Registro en línea :: Para crear una cuenta suelen pedir el nombre, el correo electrónico (**posel**), el número de móvil, la fecha de nacimiento, el género y una contraseña.
E Orden de pasos :: **Selanjutnya** significa «a continuación». **Lalu** y **setelah itu** también ayudan a ordenar instrucciones.
W akun = cuenta (digital) | A-kun | Perfil que permite usar un servicio en línea.
W laman = página web | LA-man | Página de un sitio de internet.
W posel = correo electrónico | PO-sel | Abreviatura formal de «pos elektronik», dirección o servicio de correo.
W kata sandi = contraseña | KA-ta SAN-di | Palabra o combinación usada para acceder a una cuenta.
W nomor ponsel = número de móvil | NO-mor PON-sel | Número de teléfono celular.
W tanggal lahir = fecha de nacimiento | TANG-gal LA-hir | Día, mes y año en que nació una persona.
W jenis kelamin = género; sexo | JE-nis ke-LA-min | Dato que se solicita en algunos formularios.
W bukalah = abre; abra | BU-ka-lah | Imperativo de «buka» con la partícula -lah.
W masukkan = introduce; ingresa | ma-SUK-kan | Imperativo para escribir o colocar un dato en un formulario.
W selanjutnya = a continuación; después | se-LAN-jut-nya | Presenta el paso que sigue.
W klik = haz clic; pulsa | KLIK | Verbo usado para seleccionar un botón en una pantalla.
W daftar = registrarse; inscripción | DAF-tar | En un formulario, suele ser el botón para crear la cuenta.
W konfirmasi = confirma; confirmar | kon-fir-MA-si | Verbo para comprobar o validar un dato.
W formulir = formulario | for-mu-LIR | Documento o pantalla donde se completan datos.
W data = datos | DA-ta | Información que se introduce o se almacena.
W televisi = televisión | te-le-VI-si | Medio de comunicación que transmite imagen y sonido.
V Pasos para registrarse
D Registro en una página
Nina: Bagaimana cara membuat akun? = ¿Cómo se crea una cuenta?
  > Bagaimana cara = cómo | membuat akun = crear una cuenta
Rina: Bukalah laman pendaftaran. = Abre la página de registro.
  > Bukalah = abre | laman pendaftaran = página de registro
Nina: Selanjutnya? = ¿A continuación?
  > Selanjutnya = a continuación
Rina: Masukkan nama, posel, nomor ponsel, tanggal lahir, jenis kelamin, dan kata sandi. = Introduce el nombre, el correo, el móvil, la fecha de nacimiento, el género y la contraseña.
  > Masukkan = introduce | nama, posel, nomor ponsel = el nombre, el correo, el número de móvil | tanggal lahir, jenis kelamin, dan kata sandi = la fecha de nacimiento, el género y la contraseña
Nina: Setelah itu? = ¿Después?
  > Setelah itu = después de eso
Rina: Klik daftar dan konfirmasi posel. = Pulsa «Registrarse» y confirma el correo.
  > Klik daftar = pulsa registrarse | dan konfirmasi posel = y confirma el correo
Nina: Baik, saya coba. = De acuerdo, lo intento.
  > Baik = de acuerdo | saya coba = lo intento
T Instrucciones para crear una cuenta
- Bukalah laman pendaftaran. = Abre la página de registro.
  > Bukalah = abre | laman pendaftaran = página de registro
- Masukkan data dalam formulir. = Introduce los datos en el formulario.
  > Masukkan data = introduce los datos | dalam formulir = en el formulario
- Klik daftar, lalu konfirmasi nomor ponsel. = Pulsa «Registrarse» y luego confirma el número de móvil.
  > Klik daftar = pulsa registrarse | lalu konfirmasi nomor ponsel = luego confirma el número de móvil
Q ¿Qué significa «kata sandi»?
+ Contraseña. :: Es la combinación que se usa para acceder a una cuenta.
- Página web. :: «Laman» significa página web.
- Número de móvil. :: «Nomor ponsel» significa número de móvil.
R Bukalah laman pendaftaran. :: Traduce la instrucción.
+ Abre la página de registro. :: «-lah» aparece en esta forma de instrucción.
- Confirma el correo electrónico. :: Eso sería «Konfirmasi posel».
- Introduce la contraseña. :: Eso sería «Masukkan kata sandi».
H Masukkan ___ dalam formulir. :: Completa «Introduce los datos en el formulario».
+ data :: «Data» significa datos.
- laman :: «Laman» significa página web.
- akun :: «Akun» significa cuenta.
A Klik daftar, lalu konfirmasi nomor ponsel. :: ¿Qué se debe hacer después de pulsar «Registrarse»?
+ Confirmar el número de móvil. :: «Lalu» ordena el paso siguiente.
- Abrir la página de registro. :: Eso ocurre al principio.
- Escribir la fecha de nacimiento. :: La frase no menciona la fecha.
O Bukalah laman pendaftaran :: Abre la página de registro :: «Bukalah» es una instrucción con -lah.
Q ¿Qué indica «selanjutnya»?
+ El paso que sigue. :: Sirve para ordenar instrucciones.
- La fecha de nacimiento. :: Eso es «tanggal lahir».
- El género. :: Eso es «jenis kelamin».
R Klik daftar dan konfirmasi posel. :: Traduce la frase.
+ Pulsa «Registrarse» y confirma el correo. :: «Klik» es pulsar y «konfirmasi», confirmar.
- Introduce el correo y crea una contraseña. :: La frase pide confirmar el correo.
- Abre la página web. :: Eso sería «Bukalah laman».
A Masukkan nama, posel, nomor ponsel, tanggal lahir, jenis kelamin, dan kata sandi. :: ¿Qué dato no se menciona?
+ La dirección de casa. :: La instrucción menciona otros datos.
- El número de móvil. :: Aparece «nomor ponsel».
- La contraseña. :: Aparece «kata sandi».
@ 17 | Tips untuk pewara | Consejos para presentar noticias
I El prefijo peN- aparece en nombres de profesión y de carácter: **pewara** es una profesión; **pendiam** y **pemalu** describen rasgos. La forma cambia según la palabra, así que conviene aprender cada ejemplo. En una recomendación para presentar noticias, «no ser demasiado callado» se refiere al trabajo de hablar ante el público, no a un defecto personal.
E Consejos :: **Berita berisi fakta tentang peristiwa** significa «Las noticias contienen hechos sobre acontecimientos». **Berisi** es ber- + isi («contenido»).
E Imperativos :: **-lah** también forma instrucciones: **Bacalah**, **Latihlah**, **Belajarlah**. En una lista de consejos, cada forma puede encabezar un paso.
W pewara = presentador/a; conductor/a de un programa | pe-WA-ra | Término formal para quien presenta un programa.
W berita = noticias; noticia | be-RI-ta | Información sobre hechos o acontecimientos.
W peristiwa = suceso; acontecimiento | pe-RIS-ti-wa | Algo que ocurre.
W fakta = hecho; dato comprobable | FAK-ta | Información que se puede comprobar.
W tips = consejos; recomendaciones | TIPS | Ideas prácticas para realizar algo.
W wawasan = conocimientos; perspectiva | wa-WA-san | Conocimientos amplios sobre un tema.
W latihan = práctica; entrenamiento | la-TI-han | Actividad repetida para mejorar una habilidad.
W rutin = habitual; regular | ru-TIN | Describe algo que se hace con frecuencia y orden.
W percaya diri = tener confianza en uno mismo | per-CHA-ya DI-ri | Expresión para hablar de seguridad personal.
W berkomunikasi = comunicarse | ber-ko-mu-ni-KA-si | Intercambiar información con otras personas.
W pendiam = callado; reservado | pen-DI-am | Describe a una persona que habla poco.
W pemalu = tímido | pe-MA-lu | Describe a quien siente vergüenza al hablar o actuar.
W pemarah = irritable; de mal genio | pe-MA-rah | Describe a quien se enfada con facilidad.
W penyayang = cariñoso; afectuoso | pe-nya-YANG | Describe a quien muestra cariño.
W mandiri = independiente; autónomo | man-DI-ri | Capaz de actuar sin depender de otra persona.
W manja = consentido; dependiente | MAN-ja | Describe a quien espera muchos cuidados o atenciones.
W berisi = contener; incluir | ber-I-si | Forma ber- que indica qué contenido tiene algo.
W menambah = añadir; aumentar | me-NAM-bah | Hacer que una cantidad o un conocimiento crezca.
W latihlah = practica; practique | la-TIH-lah | Instrucción formada con el verbo «latih» y -lah.
W bacalah = lee; lea | BA-cha-lah | Instrucción formada con el verbo «baca» y -lah.
W belajarlah = aprende; aprenda | be-la-JAR-lah | Instrucción formada con «belajar» y -lah.
W pengajar = profesor/a; docente | peng-A-jar | Persona cuyo trabajo es enseñar.
W sebaiknya = es mejor; sería mejor | se-BA-ik-nya | Introduce una recomendación.
V Noticias y consejos
D Cómo ser presentador
Nina: Bagaimana cara menjadi pewara berita? = ¿Cómo se llega a ser presentador de noticias?
  > Bagaimana cara = cómo | menjadi pewara berita = llegar a ser presentador de noticias
Rina: Seorang pewara membaca berita melalui radio atau televisi. = Un presentador lee las noticias por radio o televisión.
  > Seorang pewara = un presentador | membaca berita = lee las noticias | melalui radio atau televisi = por radio o televisión
Nina: Apa tips menjadi pewara yang baik? = ¿Qué consejos sirven para ser un buen presentador?
  > Apa tips = qué consejos | menjadi pewara yang baik = sirven para ser un buen presentador
Rina: Bacalah berita setiap hari. Latihlah berkomunikasi dengan orang lain. = Lee noticias todos los días. Practica cómo comunicarte con otras personas.
  > Bacalah berita = lee noticias | setiap hari = todos los días | Latihlah berkomunikasi = practica cómo comunicarte | dengan orang lain = con otras personas
Nina: Pewara harus percaya diri, ya? = El presentador debe tener confianza, ¿verdad?
  > Pewara harus = el presentador debe | percaya diri = tener confianza | ya = ¿verdad?
Rina: Ya. Belajarlah bersikap mandiri. = Sí. Aprende a actuar de forma independiente.
  > Ya = sí | Belajarlah bersikap mandiri = aprende a actuar de forma independiente
Nina: Apakah pewara boleh pendiam? = ¿Puede ser callado un presentador?
  > Apakah = partícula de pregunta | pewara boleh pendiam = el presentador puede ser callado
Rina: Sebaiknya tidak, dan jangan terlalu pemalu. = Mejor que no, y que no sea demasiado tímido.
  > Sebaiknya tidak = mejor que no | dan jangan terlalu pemalu = y que no sea demasiado tímido
T Consejos prácticos
- Berita berisi fakta tentang peristiwa. = Las noticias contienen hechos sobre acontecimientos.
  > Berita berisi = las noticias contienen | fakta tentang peristiwa = hechos sobre acontecimientos
- Latihan rutin menambah wawasan. = La práctica habitual amplía los conocimientos.
  > Latihan rutin = la práctica habitual | menambah wawasan = amplía los conocimientos
- Latihlah berkomunikasi dengan orang lain. = Practica cómo comunicarte con otras personas.
  > Latihlah berkomunikasi = practica cómo comunicarte | dengan orang lain = con otras personas
- Belajarlah bersikap mandiri. = Aprende a actuar de forma independiente.
  > Belajarlah bersikap = aprende a actuar | mandiri = de forma independiente
Q ¿Qué significa «peristiwa»?
+ Suceso o acontecimiento. :: Es algo que ocurre.
- Conocimientos amplios. :: «Wawasan» significa conocimientos o perspectiva.
- Presentador de noticias. :: «Pewara berita» es presentador de noticias.
R Berita berisi fakta tentang peristiwa. :: Traduce la frase.
+ Las noticias contienen hechos sobre acontecimientos. :: «Berisi» indica contenido.
- El presentador practica todos los días. :: Esa idea aparece en otra frase.
- El acontecimiento da consejos. :: «Tips» significa consejos.
H Latihan rutin menambah ___. :: Completa «La práctica habitual amplía los conocimientos».
+ wawasan :: «Wawasan» son conocimientos o perspectiva.
- pemalu :: «Pemalu» significa tímido.
- pendiam :: «Pendiam» significa callado.
A Pewara harus percaya diri. :: ¿Qué característica debe tener el presentador?
+ Confianza en sí mismo. :: «Percaya diri» expresa seguridad personal.
- Ser de mal genio. :: «Pemarah» significa irritable.
- Ser dependiente. :: «Mandiri» significa independiente.
O Belajarlah bersikap mandiri :: Aprende a actuar de forma independiente :: «-lah» marca una instrucción.
Q ¿Qué palabra describe a una persona que enseña?
+ pengajar :: Es el profesor o docente.
- pewara :: Presenta un programa.
- peristiwa :: Es un suceso.
R Latihlah berkomunikasi dengan orang lain. :: Traduce el consejo.
+ Practica cómo comunicarte con otras personas. :: «Latihlah» es un imperativo con -lah.
- Lee noticias todos los días. :: Esa frase sería «Bacalah berita setiap hari».
- Aprende a actuar de forma independiente. :: Esa frase sería «Belajarlah bersikap mandiri».
A Sebaiknya tidak, dan jangan terlalu pemalu. :: ¿Qué rasgos recomienda evitar la respuesta?
+ Ser callado y demasiado tímido. :: «Pendiam» es callado y «pemalu», tímido.
- Ser cariñoso e independiente. :: Esos rasgos se expresan con «penyayang» y «mandiri».
- Tener mucha práctica. :: «Latihan» significa práctica.
