@ 26 | Surat keluhan | Escribir una carta de reclamación
I A veces un envío llega tarde o en malas condiciones. Aprenderás a explicar el problema con cortesía, aportar razones y pedir una respuesta concreta.
E Formas con se- :: **Sebulan** significa «un mes» y **sebulan lalu**, «hace un mes». **Seharusnya** expresa lo que se espera o lo que convendría hacer. Estas formas se escriben unidas.
E Una reclamación clara :: Expón el problema, explica qué ocurrió y añade pruebas si las tienes. Una petición concreta ayuda al destinatario a entender qué respuesta esperas.
W mengajukan keluhan = presentar una reclamación | meng-a-JU-kan ke-LU-han
W nomor resi = número de seguimiento de un envío | NO-mor RE-si
W seharusnya = debería; tendría que | se-ha-RUS-nya
W sebulan lalu = hace un mes | se-BU-lan LA-lu
W isi paket = contenido del paquete | I-si PA-ket
W rusak = dañado; estropeado | RU-sak
W melampirkan = adjuntar; incluir como anexo | me-lam-PIR-kan
W bukti foto = prueba fotográfica | BUK-ti FO-to
W menanggapi = responder a; dar respuesta a | me-nang-GA-pi
W secepatnya = lo antes posible | se-che-PAT-nya
W setidaknya = al menos | se-ti-dak-NYA
W tercatat = quedar registrado; registrado | ter-CHA-tat
W bukti pengiriman = comprobante de envío | BUK-ti peng-i-RI-man
W penyelesaian = resolución; solución final | pe-nye-le-SA-i-an
V Vocabulario: explicar el problema
D Un paquete con problemas
Sari: Saya ingin mengajukan keluhan tentang pengiriman paket saya. = Quiero presentar una reclamación sobre el envío de mi paquete.
  > mengajukan keluhan = presentar una reclamación | tentang pengiriman paket saya = sobre el envío de mi paquete
Budi: Apa nomor resi paket itu? = ¿Cuál es el número de seguimiento de ese paquete?
  > nomor resi = número de seguimiento | paket itu = ese paquete
Sari: Paket seharusnya tiba sebulan lalu, tetapi belum saya terima. = El paquete debería haber llegado hace un mes, pero todavía no lo he recibido.
  > seharusnya tiba = debería haber llegado | sebulan lalu = hace un mes | belum saya terima = todavía no lo he recibido
Budi: Apakah isi paket itu rusak? = ¿Está dañado el contenido del paquete?
  > isi paket = contenido del paquete | rusak = dañado
Sari: Ya, saya melampirkan bukti foto kerusakan paket. = Sí, adjunto una prueba fotográfica del daño del paquete.
  > melampirkan bukti foto = adjunto una prueba fotográfica | kerusakan paket = daño del paquete
Budi: Petugas seharusnya menanggapi keluhan secepatnya. = El empleado debería responder a la reclamación lo antes posible.
  > Petugas = el empleado | menanggapi keluhan = responder a la reclamación | secepatnya = lo antes posible
Sari: Setidaknya, nomor resi dan bukti pengiriman sudah tercatat. = Al menos, el número de seguimiento y el comprobante de envío ya quedaron registrados.
  > Setidaknya = al menos | nomor resi = número de seguimiento | bukti pengiriman = comprobante de envío | sudah tercatat = ya quedaron registrados
Q ¿Qué dato permite localizar un envío?
+ nomor resi :: Es el número de seguimiento del paquete.
- isi paket :: Es lo que hay dentro del paquete.
- bukti foto :: Es una imagen que sirve como prueba.
R Paket seharusnya tiba sebulan lalu. :: ¿Qué significa?
+ El paquete debería haber llegado hace un mes. :: «Seharusnya» expresa una expectativa.
- El paquete llegará dentro de un mes. :: «Sebulan lalu» se refiere al pasado.
- El paquete fue abierto hace una semana. :: La frase no habla de abrirlo.
H Saya ___ bukti foto kerusakan paket. :: Completa con «adjunto».
+ melampirkan :: Significa adjuntar un documento o una prueba.
- menanggapi :: Significa responder a algo.
- tercatat :: Significa quedar registrado.
A Isi paket itu rusak. :: ¿Cómo llegó el contenido?
+ Dañado. :: «Rusak» significa dañado o estropeado.
- En perfecto estado. :: Eso expresa lo contrario.
- Sin comprobante de envío. :: La oración no habla de un comprobante.
O Petugas seharusnya menanggapi keluhan secepatnya :: El empleado debería responder a la reclamación lo antes posible :: La petición indica qué respuesta se espera y cuándo.
Q ¿Qué significa setidaknya?
+ al menos :: Indica una cantidad o condición mínima.
- hace un mes :: Eso significa «sebulan lalu».
- lo antes posible :: Eso significa «secepatnya».
H Nomor resi itu ___ pada bukti pengiriman. :: Completa con «quedó registrado».
+ tercatat :: Indica que un dato aparece anotado.
- rusak :: Significa «dañado».
- secepatnya :: Significa «lo antes posible».
R Saya melampirkan bukti foto kerusakan paket. :: ¿Qué adjunta la persona?
+ Una prueba fotográfica del daño del paquete. :: «Melampirkan» introduce lo que se adjunta.
- Una solución final del empleado. :: Eso sería «penyelesaian».
- El contenido nuevo de otro paquete. :: No aparece en la frase.

@ 26 | Menulis surat | Estructurar una carta de reclamación
E Partes de una carta :: El **perihal** indica el asunto. Después del saludo, explica la cronología y la razón de la reclamación; al final, formula una petición y despídete con cortesía.
E Peticiones corteses :: **Memohon** es una forma respetuosa de pedir algo. **Tindak lanjut** es la acción que se realiza después de recibir un informe o una queja.
W perihal = asunto de una carta | pe-RI-hal
W salam pembuka = saludo inicial | sa-LAM pem-BU-ka
W dengan hormat = atentamente; fórmula de saludo formal | de-NGAN hor-MAT
W susunan surat = estructura de la carta | su-SU-nan SU-rat
W kronologi = cronología; orden de los hechos | kro-no-LO-gi
W menyampaikan keluhan = comunicar una reclamación | men-yam-PAI-kan ke-LU-han
W uraian masalah = descripción del problema | u-RAI-an ma-SA-lah
W lampiran = anexo; documento adjunto | lam-pi-RAN
W memohon = solicitar respetuosamente | me-MO-hon
W penggantian biaya = reembolso de gastos | peng-gan-TI-an bi-A-ya
W tindak lanjut = seguimiento; acción posterior | tin-DAK LAN-jut
W sopan = cortés; educado | SO-pan
W penutup surat = cierre de la carta | pe-NU-tup SU-rat
W jelas = claro; comprensible | JE-las
W tujuan surat = propósito de la carta | tu-JU-an SU-rat
W masalah = problema; asunto | ma-SA-lah
W terkirim = enviado; que ha sido enviado | ter-KI-rim
W tanggal = fecha; día del mes | TANG-gal
W sebagai = como; en calidad de | se-ba-GAI
V Vocabulario: partes y petición formal
T Ejemplo de carta
- Perihal: keluhan tentang pengiriman paket. = Asunto: reclamación sobre el envío de un paquete.
  > Perihal = asunto | keluhan tentang pengiriman paket = reclamación sobre el envío de un paquete
- Dengan hormat, saya ingin menyampaikan keluhan tentang paket saya. = Estimado/a, quiero comunicar una reclamación sobre mi paquete.
  > Dengan hormat = estimado/a | menyampaikan keluhan = comunicar una reclamación | tentang paket saya = sobre mi paquete
- Paket tercatat terkirim pada tanggal lima, tetapi belum saya terima. = El paquete figura como enviado el día cinco, pero todavía no lo he recibido.
  > tercatat terkirim = figura como enviado | pada tanggal lima = el día cinco | belum saya terima = todavía no lo he recibido
- Ini kronologi dan uraian masalah yang terjadi pada paket saya. = Esta es la cronología y la descripción del problema que tuvo mi paquete.
  > kronologi dan uraian masalah = cronología y descripción del problema | terjadi pada paket saya = tuvo lugar con mi paquete
- Saya memohon penggantian biaya dan tindak lanjut atas keluhan ini. = Solicito respetuosamente el reembolso de los gastos y seguimiento de esta reclamación.
  > memohon penggantian biaya = solicitar respetuosamente el reembolso | tindak lanjut atas keluhan ini = seguimiento de esta reclamación
- Saya melampirkan foto sebagai lampiran. = Adjunto una foto como anexo.
  > melampirkan foto = adjunto una foto | sebagai lampiran = como anexo
- Susunan surat harus sopan dan jelas. = La estructura de la carta debe ser cortés y clara.
  > susunan surat = estructura de la carta | sopan dan jelas = cortés y clara
Q ¿Qué suele aparecer junto al inicio de una carta para indicar el tema?
+ perihal :: El asunto resume el motivo de la carta.
- nomor resi :: Es un código para seguir un envío.
- bukti foto :: Es una imagen adjunta como prueba.
R Saya memohon penggantian biaya dan tindak lanjut. :: ¿Qué solicita la persona?
+ El reembolso de los gastos y el seguimiento. :: «Memohon» formula una petición respetuosa.
- Un número de seguimiento y un paquete nuevo. :: No son las peticiones de la frase.
- Una descripción del problema y un saludo. :: Esas son partes de la carta.
H Susunan surat harus ___ dan jelas. :: Completa con «cortés».
+ sopan :: Es una petición de tono respetuoso.
- rusak :: Significa «dañado».
- terlambat :: Significa «con retraso».
A Dengan hormat, saya ingin menyampaikan keluhan. :: ¿Qué función tiene «Dengan hormat»?
+ Es un saludo formal al iniciar una carta. :: Se usa en comunicaciones escritas respetuosas.
- Es la despedida de una carta. :: La frase aparece al principio.
- Es el asunto del envío. :: El asunto se expresa con «perihal».
O Ini kronologi dan uraian masalah yang terjadi pada paket saya :: Esta es la cronología y la descripción del problema que tuvo mi paquete :: La persona anuncia los hechos y explica lo sucedido.
Q ¿Qué es una lampiran?
+ un anexo :: Es un documento que acompaña a la carta.
- un saludo inicial :: Eso significa «salam pembuka».
- una cronología :: Eso significa «kronologi».
H Saya ___ penggantian biaya atas keluhan ini. :: Completa con «solicito respetuosamente».
+ memohon :: Es un verbo de petición cortés.
- menyampaikan :: Significa «comunicar».
- melampirkan :: Significa «adjuntar».
R Paket tercatat terkirim pada tanggal lima, tetapi belum saya terima. :: ¿Qué problema explica?
+ El registro dice que se envió, pero la persona aún no lo ha recibido. :: La oración contrapone el registro y la recepción.
- El paquete llegó y se dañó hace un mes. :: Eso no se dice aquí.
- La persona olvidó adjuntar el asunto de la carta. :: No es lo que significa la frase.

@ 26 | Tanggapan dan penyelesaian | Respuesta y resolución
E Leer la respuesta :: Una respuesta debe indicar qué se ha comprobado, qué medida se tomará y en qué plazo. **Sehari** significa «un día»; se forma con **se-** y una unidad de tiempo.
E Cerrar con cortesía :: Agradece la respuesta y conserva los datos del caso. Si la solución no llega, puedes pedir una actualización con respeto.
W pengaduan = queja; reclamación formal | peng-a-DU-an
W tanggapan = respuesta; reacción | tang-GA-pan
W pemeriksaan = revisión; comprobación | pe-me-RIK-sa-an
W memastikan = asegurarse de; confirmar | me-mas-TI-kan
W pengiriman ulang = reenvío | peng-i-RI-man U-lang
W dikembalikan = ser devuelto; ser reembolsado | di-kem-ba-LI-kan
W penggantian = reemplazo; sustitución | peng-gan-TI-an
W sehari = un día | se-HA-ri
W menyelesaikan = resolver; completar | me-nye-le-SAI-kan
W diperbarui = ser actualizado | di-per-ba-HA-ru-i
W tindakannya = su medida; su actuación | tin-DAK-an-nya
W perkembangan = avance; evolución | per-kem-BANG-an
W konfirmasi = confirmación | kon-fir-MA-si
W menghubungi = ponerse en contacto con | meng-hu-BU-ngi
W biaya = coste; gasto | bi-A-ya
W dikirim ulang = ser reenviado; volver a enviar | di-KI-rim U-lang
W diselesaikan = ser resuelto; resolverse | di-se-le-SAI-kan
V Vocabulario: respuesta y seguimiento
D La oficina responde
Sari: Saya menerima tanggapan dari kantor pos. = Recibí una respuesta de la oficina de correos.
  > menerima tanggapan = recibir una respuesta | dari kantor pos = de la oficina de correos
Budi: Apa hasil pemeriksaan? = ¿Cuál es el resultado de la revisión?
  > hasil pemeriksaan = resultado de la revisión
Sari: Petugas memastikan paket dikirim ulang. = El empleado confirma que el paquete será reenviado.
  > memastikan = confirma | paket dikirim ulang = el paquete será reenviado
Budi: Bagaimana dengan biaya pengiriman? = ¿Y qué pasa con el coste del envío?
  > biaya pengiriman = coste del envío
Sari: Biaya itu akan dikembalikan dalam sehari. = Ese coste será reembolsado en un día.
  > akan dikembalikan = será reembolsado | dalam sehari = en un día
Budi: Apakah masalah sudah diselesaikan? = ¿Ya se resolvió el problema?
  > masalah = el problema | sudah diselesaikan = ya se resolvió
Sari: Ya, pengaduan ini selesai sebelum batas waktu. = Sí, esta reclamación se resolvió antes del plazo.
  > pengaduan ini = esta reclamación | selesai sebelum batas waktu = se resolvió antes del plazo
Budi: Menyimpan konfirmasi dan menghubungi petugas penting jika belum ada perkembangan baru. = Guardar la confirmación y contactar al empleado es importante si aún no hay novedades.
  > menyimpan konfirmasi = guardar la confirmación | menghubungi petugas = contactar al empleado | penting = importante | belum ada perkembangan baru = aún no hay novedades
Q ¿Qué puede indicar una respuesta de la oficina?
+ El resultado de la revisión y la medida que tomarán. :: La respuesta explica la comprobación y la solución.
- La sinopsis y el final de una película. :: Es vocabulario de cine.
- El contenido nutricional de un alimento. :: Eso aparece en una etiqueta de alimentos.
R Biaya itu akan dikembalikan dalam sehari. :: ¿Qué significa?
+ Ese coste será reembolsado en un día. :: «Sehari» equivale a un día.
- Ese coste debe reclamarse dentro de un mes. :: «Sebulan» significa un mes.
- Ese coste se pagó hace un día. :: La frase habla de una devolución futura.
H Pengaduan ini ___ sebelum batas waktu. :: Completa con «se resolvió».
+ diselesaikan :: Es la forma pasiva de «resolver».
- diperbarui :: Significa «ser actualizado».
- dikembalikan :: Significa «ser devuelto».
A Petugas memastikan paket dikirim ulang. :: ¿Qué confirma el empleado?
+ Que el paquete se reenviará. :: «Dikirim ulang» significa que se envía de nuevo.
- Que el paquete quedó dañado. :: La frase no menciona daños.
- Que el plazo ya terminó. :: No se habla de un plazo en esa oración.
O Menyimpan konfirmasi dan menghubungi petugas :: Guardar la confirmación y contactar al empleado :: Son dos acciones para dar seguimiento a la reclamación.
Q ¿Qué significa penggantian?
+ reemplazo; sustitución :: Se refiere a poner algo en lugar de otra cosa.
- confirmación :: Eso significa «konfirmasi».
- desarrollo; avance :: Eso significa «perkembangan».
H Biaya itu akan ___ dalam sehari. :: Completa con «ser reembolsado».
+ dikembalikan :: El verbo pasivo indica que el dinero vuelve.
- memastikan :: Significa «confirmar».
- menyelesaikan :: Significa «resolver».
R Menyimpan konfirmasi dan menghubungi petugas jika belum ada perkembangan baru. :: ¿Qué aconseja la frase?
+ Guardar la confirmación y contactar al empleado si aún no hay novedades. :: «Jika» introduce una condición.
- Enviar de nuevo el paquete antes de revisar la respuesta. :: La frase no lo recomienda.
- Esperar un mes sin guardar la confirmación. :: Esa idea no aparece.
