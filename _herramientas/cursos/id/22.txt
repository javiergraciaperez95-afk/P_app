@ 22 | Menjaga lingkungan | Cuidar el medioambiente
I En esta parte aprenderás a hablar de problemas ambientales, desastres naturales y propuestas comunitarias. Algunas partículas se escriben unidas a la palabra; otras, separadas.
E Las partículas -lah y -kah :: **-lah** se une a una forma verbal para suavizar una instrucción o dar énfasis: **Jagalah lingkungan!** («¡Cuida el medioambiente!»). **-kah** se une a una palabra y marca o destaca una pregunta: **Benarkah sungai itu tercemar?** («¿Es cierto que el río está contaminado?»).
E Conservación :: **Pelestarian** es la conservación de algo; **melestarikan** es conservarlo. **Mendaur ulang** significa reciclar y **memilah** es separar residuos para tratarlos de forma distinta.
W lingkungan = entorno; medioambiente | ling-KU-ngan
W lingkungan hidup = medioambiente; entorno natural | ling-KU-ngan HI-dup
W pelestarian = conservación; protección duradera | pe-les-TA-ri-an
W melestarikan = conservar; proteger para el futuro | me-les-TA-ri-kan
W limbah = residuo; desecho | LIM-bah
W pencemaran = contaminación; polución | pen-che-MA-ran
W plastik = plástico | PLAS-tik
W sampah plastik = residuos plásticos; basura plástica | SAM-pah PLAS-tik
W mengurangi = reducir; disminuir | meng-u-RANG-i
W memilah = clasificar; separar por tipos | me-mi-LAH
W mendaur ulang = reciclar; volver a procesar | men-da-UR U-lang
W daur ulang = reciclaje | DA-ur U-lang
W membuang = tirar; desechar | mem-BU-ang
W kebersihan = limpieza; higiene | ke-ber-SI-han
W kesadaran = conciencia; conocimiento de un problema | ke-sa-DA-ran
W dampak = impacto; efecto | DAM-pak
W merusak = dañar; estropear | me-RU-sak
W penting = importante | pen-TING
W sungai = río | SU-ngai
W tercemar = contaminado; polucionado | ter-che-MAR
W jagalah = cuida; cuide (instrucción atenuada) | ja-GA-lah
W benarkah = ¿es cierto que…?; ¿de verdad…? | be-NAR-kah
V Vocabulario: medioambiente y conservación
D Una conversación sobre el río
Nina: Benarkah sungai itu tercemar? = ¿Es cierto que ese río está contaminado?
  > Benarkah = ¿es cierto que...? | sungai itu = ese río | tercemar = contaminado
Budi: Ya, limbah plastik merusak lingkungan. = Sí, los residuos plásticos dañan el medioambiente.
  > limbah plastik = residuos plásticos | merusak = dañan | lingkungan = medioambiente
Nina: Kita harus memilah sampah plastik. = Tenemos que separar los residuos plásticos.
  > harus memilah = tenemos que separar | sampah plastik = residuos plásticos
Budi: Daur ulang membantu mengurangi limbah. = El reciclaje ayuda a reducir los residuos.
  > daur ulang = reciclaje | membantu = ayuda | mengurangi limbah = reducir los residuos
Nina: Jagalah kebersihan lingkungan! = ¡Cuida la limpieza del entorno!
  > Jagalah = cuida | kebersihan lingkungan = la limpieza del entorno
Budi: Pelestarian sungai penting. = La conservación del río es importante.
  > Pelestarian sungai = la conservación del río | penting = importante
Nina: Mari melestarikan lingkungan hidup. = Conservemos el medioambiente.
  > Mari = vamos a | melestarikan = conservar | lingkungan hidup = medioambiente
Q ¿Qué partícula se une al verbo para suavizar una instrucción?
+ -lah :: Se escribe junto al verbo: «jagalah».
- -kah :: Marca o destaca preguntas.
- pun :: Se escribe separado y puede significar «también».
R Jagalah kebersihan lingkungan. :: ¿Qué significa?
+ Cuida la limpieza del entorno. :: «Jagalah» es una instrucción atenuada.
- El entorno está contaminado. :: «Tercemar» significa contaminado.
- Separa los residuos plásticos. :: Esa instrucción sería «memilah sampah plastik».
H Benarkah sungai itu ___? :: Completa con «contaminado».
+ tercemar :: «Tercemar» describe un río contaminado.
- merusak :: Significa dañar.
- penting :: Significa importante.
A Limbah plastik merusak lingkungan. :: ¿Qué problema se describe?
+ Los residuos plásticos dañan el medioambiente. :: «Limbah plastik» y «merusak» dan esa información.
- El reciclaje protege el río. :: «Daur ulang» no aparece.
- El río es importante para la ciudad. :: No se menciona una ciudad.
O Kita harus memilah sampah plastik :: Tenemos que separar los residuos plásticos :: «Harus» expresa necesidad; «memilah» es separar por tipos.
Q ¿Qué palabra significa «polucionado»?
+ tercemar :: Se usa para algo afectado por contaminación.
- pelestarian :: Es conservación.
- daur ulang :: Es reciclaje.
H Daur ulang membantu ___ limbah. :: Completa con «reducir».
+ mengurangi :: «Mengurangi limbah» es reducir residuos.
- membuang :: Significa tirar.
- melestarikan :: Significa conservar.
R Kesadaran tentang kebersihan sangat penting. :: ¿Qué significa?
+ La conciencia sobre la limpieza es muy importante. :: «Kesadaran» es conciencia.
- La contaminación del río ya terminó. :: La frase no lo afirma.
- Separar los residuos es un problema. :: La frase lo presenta como algo importante.

@ 22 | Bencana dan dampaknya | Desastres y sus consecuencias
E La partícula -pun :: **Pun** se escribe separada y suele significar «también» o «incluso»: **Warga pun mengungsi** («Los residentes también se refugiaron»). No la confundas con las palabras compuestas escritas juntas, como **meskipun**.
E El clítico -nya :: **-nya** se une a la palabra anterior. Puede señalar posesión o remitir a algo ya mencionado: **penyebabnya** («su causa»), **dampaknya** («su impacto»). La forma depende del contexto.
W gempa = terremoto; sismo | GEM-pa
W gempa bumi = terremoto | GEM-pa BU-mi
W longsor = deslizamiento de tierra; derrumbe | LONG-sor
W gunung berapi = volcán | GU-nung be-ra-A-pi
W letusan = erupción; estallido | le-TU-san
W korban = víctima | KOR-ban
W evakuasi = evacuación | e-va-ku-A-si
W mengungsi = refugiarse; evacuar una zona | meng-UNG-si
W pengungsian = refugio; centro de evacuación | pe-ngung-SI-an
W bantuan = ayuda; asistencia | ban-TU-an
W kerusakan = daño; destrucción | ke-ru-SA-kan
W penyebabnya = su causa; la causa de eso | pe-nye-BAB-nya
W akibatnya = su consecuencia; como consecuencia | a-KI-bat-nya
W terjadi = ocurrir; suceder | ter-JA-di
W peringatan = aviso; advertencia | pe-ri-NGA-tan
W warga = residente; ciudadano/a | WAR-ga
W terdampak = afectado; damnificado | ter-DAM-pak
W kehilangan = perder; quedarse sin | ke-hi-LA-ngan
W menyelamatkan = salvar; poner a salvo | me-nye-la-MAT-kan
W pun = también; incluso | pun
W dampaknya = su impacto; sus efectos | DAM-pak-nya
W bersiap = prepararse; estar listo | ber-SI-ap
V Vocabulario: desastres y ayuda
D Después del terremoto
Nina: Gempa bumi terjadi kemarin malam. = El terremoto ocurrió anoche.
  > Gempa bumi = terremoto | terjadi = ocurrió | kemarin malam = anoche
Budi: Warga pun segera mengungsi. = Los residentes también se refugiaron enseguida.
  > Warga pun = los residentes también | segera = enseguida | mengungsi = se refugiaron
Nina: Apa penyebabnya? = ¿Cuál es su causa?
  > Apa = cuál | penyebabnya = su causa
Budi: Letusan gunung berapi merusak rumah. = La erupción del volcán dañó las casas.
  > Letusan gunung berapi = la erupción del volcán | merusak rumah = dañó las casas
Nina: Banyak warga kehilangan rumah. = Muchos residentes perdieron sus casas.
  > Banyak warga = muchos residentes | kehilangan rumah = perdieron sus casas
Budi: Bantuan tersedia untuk warga terdampak. = Hay ayuda disponible para los residentes afectados.
  > Bantuan tersedia = hay ayuda disponible | warga terdampak = residentes afectados
Nina: Akibatnya, banyak keluarga mengungsi. = Como consecuencia, muchas familias se refugiaron.
  > Akibatnya = como consecuencia | banyak keluarga = muchas familias | mengungsi = se refugiaron
Budi: Petugas evakuasi menyelamatkan korban. = El personal de evacuación puso a salvo a las víctimas.
  > Petugas evakuasi = personal de evacuación | menyelamatkan korban = puso a salvo a las víctimas
Q ¿Qué forma contiene el clítico -nya y significa «su causa»?
+ penyebabnya :: El clítico se une a «penyebab».
- penyebab :: Es «causa», sin el sentido de «su».
- kehilangan :: Significa perder.
R Warga pun segera mengungsi. :: ¿Qué significa?
+ Los residentes también se refugiaron enseguida. :: «Pun» puede equivaler a «también».
- Los residentes causaron un terremoto. :: No aparece esa acción.
- La evacuación ocurrió antes del aviso. :: No se establece ese orden.
H Apa ___ gempa itu? :: Completa con «su impacto».
+ dampaknya :: «-Nya» remite aquí al terremoto mencionado.
- bantuan :: Significa ayuda.
- longsor :: Significa derrumbe.
A Peringatan itu membantu warga bersiap. :: ¿Qué les permitió hacer el aviso?
+ Prepararse. :: «Bersiap» es prepararse.
- Refugiarse en una ciudad. :: «Mengungsi» no aparece.
- Perder sus casas. :: «Kehilangan rumah» no aparece.
O Bantuan tersedia untuk warga terdampak :: Hay ayuda disponible para los residentes afectados :: «Terdampak» describe a quien sufre los efectos de un suceso.
Q ¿Qué palabra significa «centro de evacuación»?
+ pengungsian :: Es un lugar para acoger a quienes dejan una zona peligrosa.
- peringatan :: Es un aviso o advertencia.
- kerusakan :: Es daño o destrucción.
H Petugas evakuasi ___ korban. :: Completa con «puso a salvo».
+ menyelamatkan :: Significa salvar o poner a salvo.
- kehilangan :: Significa perder.
- terjadi :: Significa ocurrir.
R Akibatnya, banyak warga kehilangan rumah. :: ¿Qué ocurrió?
+ Como consecuencia, muchos residentes perdieron sus casas. :: «Akibatnya» introduce una consecuencia.
- Los residentes prepararon un aviso. :: No lo dice la frase.
- Una erupción salvó a las víctimas. :: No lo dice la frase.

@ 22 | Berdiskusi tentang lingkungan | Debatir soluciones ambientales
E Dar una opinión :: **Menurut saya** presenta una opinión («en mi opinión»). Después puedes decir **Saya setuju** (estoy de acuerdo) o **Saya tidak setuju** (no estoy de acuerdo) y añadir una razón.
E Hablar de beneficios :: **Manfaatnya** se forma con **manfaat** + **-nya** y significa «su beneficio». **Pun** sigue separado y puede añadir la idea de «también»: **Relawan pun menanam pohon**.
W menurut = según; en opinión de | me-NU-rut
W pendapat = opinión; parecer | pen-da-PAT
W alasan = razón; motivo | a-LA-san
W usulan = propuesta; sugerencia | u-su-LAN
W solusi = solución | so-LU-si
W tanggung jawab = responsabilidad | tang-gung JA-wab
W bertanggung jawab = ser responsable | ber-tang-gung ja-WAB
W kerja bakti = trabajo comunitario voluntario | KER-ja BAK-ti
W relawan = voluntario/a | re-LA-wan
W berpartisipasi = participar | ber-par-ti-si-PA-si
W menghemat = ahorrar; usar con moderación | meng-HE-mat
W energi = energía | e-NER-gi
W air bersih = agua limpia; agua potable | A-ir ber-SIH
W menanam = plantar; sembrar | me-NA-nam
W penanaman = plantación; acción de plantar | pe-na-NA-man
W reboisasi = reforestación | re-bo-i-SA-si
W manfaat = beneficio; utilidad | man-FA-at
W manfaatnya = su beneficio; su utilidad | man-FA-at-nya
W mendorong = impulsar; fomentar | men-DO-rong
W masyarakat = sociedad; comunidad | ma-sya-RA-kat
W berdiskusi = conversar; debatir | ber-dis-KU-si
W bermanfaat = beneficioso; útil | ber-man-FA-at
V Vocabulario: opinión y acción comunitaria
D Una propuesta para el barrio
Rina: Menurut saya, kerja bakti sangat bermanfaat. = En mi opinión, el trabajo comunitario es muy beneficioso.
  > Menurut saya = en mi opinión | kerja bakti = trabajo comunitario | sangat bermanfaat = muy beneficioso
Budi: Saya setuju karena kebersihan tanggung jawab bersama. = Estoy de acuerdo porque la limpieza es una responsabilidad compartida.
  > setuju karena = de acuerdo porque | kebersihan = limpieza | tanggung jawab bersama = responsabilidad compartida
Rina: Relawan pun menanam pohon. = Los voluntarios también plantan árboles.
  > Relawan pun = los voluntarios también | menanam pohon = plantan árboles
Budi: Penanaman mendorong reboisasi. = La plantación impulsa la reforestación.
  > Penanaman = la plantación | mendorong reboisasi = impulsa la reforestación
Rina: Apa usulan Anda? = ¿Cuál es su propuesta?
  > usulan Anda = su propuesta
Budi: Kita bisa menghemat energi dan air bersih. = Podemos ahorrar energía y agua limpia.
  > menghemat energi = ahorrar energía | air bersih = agua limpia
Rina: Manfaatnya besar bagi masyarakat. = Su beneficio es grande para la comunidad.
  > Manfaatnya = su beneficio | besar bagi masyarakat = grande para la comunidad
Budi: Mari berdiskusi dan mencari solusi. = Hablemos y busquemos una solución.
  > Mari berdiskusi = hablemos | mencari solusi = buscar una solución
Q ¿Qué expresión presenta la opinión de quien habla?
+ Menurut saya :: Significa «en mi opinión».
- Saya setuju :: Significa «estoy de acuerdo».
- Tanggung jawab bersama :: Significa «responsabilidad compartida».
R Saya bertanggung jawab atas kebersihan lingkungan. :: ¿Qué significa?
+ Soy responsable de la limpieza del entorno. :: «Bertanggung jawab» significa ser responsable.
- Soy voluntario para la limpieza. :: «Relawan» significa voluntario/a.
- Propongo reciclar el agua limpia. :: La frase no propone reciclar.
H Relawan pun ___ pohon. :: Completa con «plantan».
+ menanam :: «Menanam pohon» es plantar árboles.
- menghemat :: Significa ahorrar.
- berdiskusi :: Significa debatir.
A Kita bisa menghemat energi. :: ¿Qué podemos hacer?
+ Ahorrar energía. :: «Menghemat energi» significa ahorrar energía.
- Participar en una evacuación. :: «Evakuasi» no aparece.
- Proponer una limpieza. :: «Usulan» no aparece.
O Manfaatnya besar bagi masyarakat :: Su beneficio es grande para la comunidad :: «-Nya» retoma algo mencionado y se escribe unido.
Q ¿Qué expresión significa «trabajo comunitario voluntario»?
+ kerja bakti :: Es una actividad de colaboración comunitaria.
- kerja sama :: Significa colaboración o cooperación en general.
- peringatan :: Significa aviso o advertencia.
H Menurut saya, usulan itu memberi ___. :: Completa con «beneficio».
+ manfaat :: «Manfaat» es beneficio o utilidad.
- alasan :: Significa razón.
- pendapat :: Significa opinión.
X Escribe en indonesio: «opinión». :: pendapat :: Es la palabra para un parecer o una opinión.
