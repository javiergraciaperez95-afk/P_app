@ 21 | Selamat atas prestasi! | Felicitar por un logro
I En este capítulo aprenderás a felicitar, expresar buenos deseos y escribir mensajes personales. El indonesio no cambia el verbo según quién habla ni según cuándo ocurre algo.
E Felicitar por un logro :: **Selamat atas + nombre** sirve para felicitar a alguien por un acontecimiento: **Selamat atas kelulusan** (¡enhorabuena por la graduación!). :: **Memberi selamat kepada seseorang** significa felicitar a una persona. «Selamat» también aparece en saludos; el contexto aclara su función.
E Hablar de resultados :: **Lulus** es aprobar o graduarse, según el contexto. **Berhasil** indica que se ha conseguido algo; **keberhasilan** es el éxito obtenido. Las formas no expresan por sí solas cuándo ocurrió la acción.
W prestasi = logro; mérito | pres-TA-si
W kelulusan = graduación; aprobación de un examen | ke-lu-LU-san
W ijazah = diploma; título académico | i-JA-zah
W juara = campeón/a; ganador/a | ju-A-ra
W memuaskan = satisfactorio; que deja satisfecho | me-mu-AS-kan
W ujian = examen; prueba | U-ji-an
W nilai = nota; calificación; valor | NI-lai
W bangga = orgulloso; orgullosa | BANG-ga
W membanggakan = enorgullecer; ser motivo de orgullo | mem-bang-GA-kan
W usaha = esfuerzo; empeño | u-SA-ha
W sungguh = realmente; de verdad | SUNG-guh
W penghargaan = reconocimiento; distinción | peng-har-GA-an
W mengumumkan = anunciar; hacer público | meng-u-MUM-kan
W hasil = resultado; producto | HA-sil
W berhasil = lograr; tener éxito | ber-ha-SIL
W keberhasilan = éxito; logro alcanzado | ke-ber-ha-SI-lan
W mengikuti = participar en; seguir | meng-i-KU-ti
W ucapan selamat = felicitación; palabras de enhorabuena | u-CA-pan se-LA-mat
W memberi selamat = felicitar | mem-BE-ri se-LA-mat
W terharu = emocionado; conmovido | ter-HA-ru
W menginspirasi = inspirar | meng-in-spi-RA-si
W lulus = aprobar; graduarse | LU-lus
V Vocabulario: logros y felicitaciones
D La graduación de Nina
Nina: Selamat atas kelulusan ini. = ¡Enhorabuena por esta graduación!
  > Selamat atas = felicitación por | kelulusan ini = esta graduación
Budi: Terima kasih. = Gracias.
  > Terima kasih = gracias
Nina: Sekolah mengumumkan hasil ujian kemarin. = La escuela anunció ayer los resultados del examen.
  > Sekolah = escuela | mengumumkan hasil ujian = anunció los resultados del examen | kemarin = ayer
Budi: Nilai saya memuaskan. = Mis notas son satisfactorias.
  > Nilai saya = mis notas | memuaskan = satisfactorias
Nina: Kamu menjadi juara lomba. = Te convertiste en el ganador del concurso.
  > menjadi juara = convertirte en ganador | lomba = concurso
Budi: Saya bangga atas penghargaan itu. = Estoy orgulloso de ese reconocimiento.
  > bangga atas = orgulloso de | penghargaan itu = ese reconocimiento
Nina: Usaha Budi sungguh membanggakan. = El esfuerzo de Budi es realmente admirable.
  > Usaha Budi = el esfuerzo de Budi | sungguh membanggakan = realmente admirable
Budi: Semoga keberhasilan ini menginspirasi orang lain. = Ojalá este éxito inspire a otras personas.
  > keberhasilan ini = este éxito | menginspirasi = inspira | orang lain = otras personas
Q ¿Qué fórmula sirve para felicitar por una graduación?
+ Selamat atas kelulusan! :: Se usa «selamat atas» para felicitar por un acontecimiento.
- Terima kasih atas kelulusan! :: «Terima kasih» da las gracias, no felicita.
- Sampai jumpa setelah kelulusan! :: Es una despedida.
R Nina lulus ujian. :: ¿Qué significa?
+ Nina aprueba el examen. :: «Lulus» es aprobar o graduarse.
- Nina anuncia el examen. :: «Anunciar» es «mengumumkan».
- Nina corrige el examen. :: No significa corregir.
H Budi memiliki ___ baru. :: Completa con el documento que acredita los estudios.
+ ijazah :: «Ijazah» es el diploma o título académico.
- nilai :: «Nilai» es la nota o calificación.
- usaha :: «Usaha» es el esfuerzo.
A Sekolah mengumumkan hasil ujian. :: ¿Qué anunció la escuela?
+ Los resultados del examen. :: «Hasil ujian» son los resultados del examen.
- La fecha de graduación. :: No aparece una fecha.
- El nombre del ganador. :: No se menciona ningún nombre de ganador.
O Nina berhasil mengikuti lomba :: Nina logró participar en el concurso :: «Berhasil» expresa logro; «mengikuti» introduce la actividad.
Q ¿Qué palabra significa «reconocimiento»?
+ penghargaan :: Se concede como distinción por un logro.
- kelulusan :: Es graduación o aprobación.
- ujian :: Es examen.
H Nilai ujian Nina ___. :: Completa con el adjetivo que significa «satisfactorias».
+ memuaskan :: Describe un resultado que deja satisfecho.
- terharu :: Describe a una persona emocionada.
- bangga :: Significa orgulloso/a.
R Usaha Nina sungguh membanggakan. :: ¿Qué expresa?
+ El esfuerzo de Nina es realmente admirable. :: «Membanggakan» significa que algo es motivo de orgullo.
- Nina felicita a alguien por su esfuerzo. :: «Felicitar» es «memberi selamat».
- Nina participa en un concurso de esfuerzo. :: «Lomba» significa concurso.

@ 21 | Semoga tercapai | Expresar esperanzas y metas
E Expresar buenos deseos :: **Semoga** ya aparece en A2; **mudah-mudahan** también significa «ojalá». Ambas expresiones suelen ir al principio de una frase sobre algo que se desea. :: **Berharap** es esperar o desear que algo ocurra; no requiere una forma verbal especial después.
E Hablar de planes y objetivos :: **Tercapai** significa que una meta se alcanza; **terwujud**, que un deseo se hace realidad; **terlaksana**, que un plan se lleva a cabo. No confundas los tres resultados.
W harapan = esperanza; expectativa | ha-RA-pan
W berharap = esperar; desear | ber-HA-rap
W mudah-mudahan = ojalá; esperemos que | mu-dah-mu-DA-han
W doa = oración; deseo expresado por alguien | DO-a
W tercapai = alcanzarse; lograrse (una meta) | ter-CA-pai
W terwujud = hacerse realidad; materializarse | ter-WU-jud
W kesuksesan = éxito | ke-suk-SE-san
W kesempatan = oportunidad; ocasión | ke-sem-PA-tan
W semangat = ánimo; entusiasmo | se-MA-ngat
W mendoakan = rezar por alguien; desearle algo | men-do-A-kan
W kebahagiaan = felicidad | ke-ba-ha-GI-an
W kedamaian = paz; tranquilidad | ke-da-ma-I-an
W keberuntungan = suerte; buena fortuna | ke-ber-un-TUNG-an
W masa depan = futuro | MA-sa de-PAN
W impian = sueño; aspiración | im-PI-an
W perjuangan = lucha; esfuerzo sostenido | per-ju-ANG-an
W terlaksana = llevarse a cabo; realizarse | ter-lak-SA-na
W mendukung = apoyar; respaldar | men-DU-kung
W bersemangat = estar animado; tener entusiasmo | ber-se-MA-ngat
W rintangan = obstáculo; dificultad | rin-TANG-an
W menghadapi = afrontar; enfrentarse a | meng-ha-DA-pi
V Vocabulario: esperanzas y objetivos
D Un deseo para el futuro
Rina: Apa harapan Anda untuk masa depan? = ¿Cuál es su esperanza para el futuro?
  > harapan Anda = su esperanza | masa depan = futuro
Budi: Saya berharap impian itu terwujud. = Espero que ese sueño se haga realidad.
  > berharap = espero | impian itu = ese sueño | terwujud = se haga realidad
Rina: Anda menghadapi banyak rintangan? = ¿Se enfrenta a muchos obstáculos?
  > menghadapi = enfrentarse a | banyak rintangan = muchos obstáculos
Budi: Ya, tetapi saya tetap bersemangat. = Sí, pero sigo teniendo ánimo.
  > tetapi = pero | tetap bersemangat = sigo teniendo ánimo
Rina: Mudah-mudahan perjuangan Anda berhasil. = Ojalá su esfuerzo sostenido tenga éxito.
  > Mudah-mudahan = ojalá | perjuangan Anda = su esfuerzo sostenido | berhasil = tenga éxito
Budi: Saya mendoakan kesuksesan orang lain. = Deseo éxito a otras personas.
  > mendoakan = desear | kesuksesan = éxito | orang lain = otras personas
Rina: Doa Anda memberi saya semangat. = Su deseo me da ánimo.
  > Doa Anda = su deseo | memberi saya = me da | semangat = ánimo
Q ¿Qué palabra es una fórmula para expresar «ojalá»?
+ mudah-mudahan :: Introduce un deseo o una esperanza.
- sebelum :: Significa «antes».
- karena :: Significa «porque».
R Semoga impian itu terwujud. :: ¿Qué significa?
+ Ojalá ese sueño se haga realidad. :: «Terwujud» significa hacerse realidad.
- Ojalá el sueño se convierta en un obstáculo. :: «Rintangan» es obstáculo.
- El sueño da las gracias por el futuro. :: No corresponde a la frase.
H Saya ___ kesuksesan Anda. :: Completa con el verbo «desear para alguien».
+ mendoakan :: Se usa para expresar un deseo por otra persona.
- menghadapi :: Significa afrontar.
- mendukung :: Significa apoyar.
A Harapan itu tercapai. :: ¿Qué pasó con la esperanza?
+ Se cumplió. :: «Tercapai» indica que se alcanzó.
- Se hizo más difícil. :: No lo dice la frase.
- Se convirtió en una felicitación. :: No lo dice la frase.
O Masa depan Anda penuh kebahagiaan :: Su futuro está lleno de felicidad :: «Masa depan» es futuro; «kebahagiaan», felicidad.
Q ¿Qué palabra significa «obstáculo»?
+ rintangan :: Es una dificultad que hay que afrontar.
- kesempatan :: Es una oportunidad.
- impian :: Es un sueño o aspiración.
H Mudah-mudahan rencana itu ___. :: Completa con «se lleva a cabo».
+ terlaksana :: Se refiere a un plan que se realiza.
- terwujud :: Se refiere a un deseo o sueño que se hace realidad.
- kedamaian :: Significa paz.
X Escribe una forma de decir «ojalá» en indonesio. :: mudah-mudahan | semoga :: Ambas expresiones introducen buenos deseos.

@ 21 | Kartu ucapan | Escribir una felicitación personal
E Tarjetas y mensajes :: **Kartu ucapan** es una tarjeta para acompañar una felicitación o un deseo. **Selamat menempuh hidup baru** es una fórmula de buenos deseos para una pareja que se casa. :: El contexto ayuda a distinguir **ucapan** («palabras, mensaje») de **ucapan selamat** («felicitación»).
E Preposiciones en una felicitación :: **Kepada** señala quién recibe algo; **untuk**, para quién o con qué propósito; **atas**, el motivo de la felicitación. Estas preposiciones ya aparecen en el nivel anterior, pero aquí se combinan en mensajes más largos.
W kartu = tarjeta | KAR-tu
W ucapan = palabras; mensaje oral | u-CA-pan
W kartu ucapan = tarjeta de felicitación | KAR-tu u-CA-pan
W pernikahan = boda; matrimonio | per-ni-KA-han
W perayaan = celebración; festejo | pe-ra-YA-an
W kelahiran = nacimiento | ke-la-HI-ran
W peresmian = inauguración oficial | pe-res-MI-an
W perpisahan = despedida; separación | per-pi-SA-han
W menempuh = emprender; recorrer | me-NEM-puh
W hidup = vida; vivir | HI-dup
W turut = también; compartir una situación | TU-rut
W momen = momento | MO-men
W amplop = sobre | AM-plop
W tulus = sincero; de corazón | TU-lus
W salam hangat = un saludo afectuoso | SA-lam HA-ngat
W pengantin = novio/a; pareja recién casada | pe-NGAN-tin
W perhatian = atención; cuidado | per-ha-TI-an
W kenangan = recuerdo; memoria | ke-NANG-an
W mengenang = recordar; rememorar | me-NE-ngang
W bayi = bebé | BA-yi
W menunjukkan = mostrar; indicar | me-nun-JUK-kan
V Vocabulario: felicitaciones y ocasiones especiales
D Una tarjeta de boda
Sari: Aku menerima undangan pernikahan Rina. = Recibí la invitación de boda de Rina.
  > menerima = recibí | undangan pernikahan = invitación de boda | Rina = Rina
Rina: Selamat menempuh hidup baru, Sari! = ¡Te deseo una nueva vida feliz, Sari!
  > Selamat menempuh hidup baru = fórmula de buenos deseos para una pareja que se casa
Sari: Terima kasih. Doa itu sangat berarti bagi saya. = Gracias. Ese deseo significa mucho para mí.
  > Terima kasih = gracias | Doa itu = ese deseo | sangat berarti = significa mucho | bagi saya = para mí
Rina: Semoga pernikahan ini membawa kebahagiaan. = Ojalá este matrimonio traiga felicidad.
  > pernikahan ini = este matrimonio | membawa kebahagiaan = traiga felicidad
Sari: Saya turut bahagia. = Yo también me alegro.
  > turut bahagia = compartir la alegría
Rina: Saya membawa kartu ucapan. = Traigo una tarjeta de felicitación.
  > membawa = traigo | kartu ucapan = tarjeta de felicitación
Sari: Ucapan yang tulus menunjukkan perhatian. = Unas palabras sinceras muestran atención.
  > Ucapan yang tulus = unas palabras sinceras | menunjukkan perhatian = muestran atención
Q ¿Qué felicitación se usa habitualmente con una pareja recién casada?
+ Selamat menempuh hidup baru! :: Es una fórmula de buenos deseos para una nueva etapa en pareja.
- Selamat atas hasil ujian! :: Felicita por un examen.
- Sampai jumpa di masa depan! :: Es una despedida, no una felicitación de boda.
R Aku menyiapkan kartu ucapan. :: ¿Qué significa?
+ Estoy preparando una tarjeta de felicitación. :: «Kartu ucapan» es una tarjeta con un mensaje.
- Estoy abriendo un sobre. :: «Amplop» significa sobre.
- Estoy recordando una celebración. :: «Mengenang» es recordar.
H Saya menulis salam ___ untuk pengantin. :: Completa la expresión que significa «un saludo afectuoso».
+ hangat :: «Salam hangat» es un saludo afectuoso.
- tulus :: Significa sincero; no completa esta expresión.
- baru :: Significa nuevo.
A Keluarga merayakan kelahiran bayi. :: ¿Qué acontecimiento celebra la familia?
+ El nacimiento de un bebé. :: «Kelahiran bayi» significa nacimiento de un bebé.
- La inauguración de una tarjeta. :: No aparece «peresmian».
- La despedida de una pareja. :: No aparece «perpisahan».
O Ucapan yang tulus menunjukkan perhatian :: Unas palabras sinceras muestran atención :: «Tulus» describe la sinceridad; «perhatian» es atención o cuidado.
Q ¿Qué palabra nombra una inauguración oficial?
+ peresmian :: Se usa para la apertura oficial de un lugar o proyecto.
- perpisahan :: Significa despedida o separación.
- perayaan :: Significa celebración.
R Kami mengenang momen itu. :: ¿Qué hacemos?
+ Recordamos ese momento. :: «Mengenang» es recordar y «momen» es momento.
- Celebramos el nacimiento de un bebé. :: Esa idea sería «merayakan kelahiran bayi».
- Felicitamos a la pareja recién casada. :: La frase no expresa felicitación.
X Escribe en indonesio: «un saludo afectuoso». :: salam hangat :: Es una fórmula cálida para cerrar un mensaje personal.
