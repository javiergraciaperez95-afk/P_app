@ 31 | Profesi dan pilihan karier | Profesiones y opciones de carrera
I En una profesión importan la formación, las habilidades y las oportunidades. Aquí aprenderás a hablar de requisitos y de decisiones laborales.
E Hablar de profesiones :: **Bidang** es un campo o sector. **Keahlian** se refiere a conocimientos especializados; **keterampilan**, a destrezas que se desarrollan con la práctica. :: El indonesio no conjuga el verbo por persona: la forma **melamar** sirve con *saya*, *dia* o *mereka*.
E Solicitar un empleo :: **Melamar lowongan kerja** es solicitar una vacante. **Persyaratan** son los requisitos; **pengalaman kerja**, la experiencia laboral. Una **wawancara kerja** es una entrevista de trabajo.
W bidang = campo; sector | BI-dang
W keahlian = especialidad; conocimiento experto | ke-AH-li-an
W keterampilan = destreza; habilidad práctica | ke-te-RAM-pi-lan
W menekuni = dedicarse a; especializarse en | me-ne-KU-ni
W lowongan kerja = vacante laboral | lo-WO-ngan KER-ja
W melamar = solicitar un empleo | me-LA-mar
W persyaratan = requisitos | per-sya-RA-tan
W pengalaman kerja = experiencia laboral | peng-a-LA-man KER-ja
W wawancara kerja = entrevista de trabajo | wa-wan-CHA-ra KER-ja
W jabatan = puesto; cargo | ja-BA-tan
W tenaga ahli = especialista; personal experto | te-NA-ga AH-li
W seleksi = proceso de selección | se-LEK-si
W pelamar = candidato/a a un puesto | pe-LA-mar
W terpilih = ser seleccionado; resultar elegido | ter-PI-lih
W pegawai tetap = empleado/a fijo/a | pe-GA-wai te-TAP
W pekerja lepas = trabajador/a independiente | pe-KER-ja le-PAS
W mengandalkan = depender de; confiar en | meng-an-DAL-kan
W memenuhi = cumplir; satisfacer | me-me-NU-hi
W desain = diseño | de-SAIN
V Vocabulario: empleo y capacidades
D Una solicitud de empleo
Sari: Saya ingin menekuni bidang desain. = Quiero dedicarme al campo del diseño.
  > menekuni bidang desain = dedicarme al campo del diseño
Budi: Ada lowongan kerja untuk tenaga ahli. = Hay una vacante para un especialista.
  > lowongan kerja = vacante laboral | tenaga ahli = especialista
Sari: Saya melamar jabatan itu dengan pengalaman kerja dan keterampilan desain. = Solicito ese puesto con experiencia laboral y habilidades de diseño.
  > melamar jabatan itu = solicitar ese puesto | pengalaman kerja = experiencia laboral | keterampilan desain = habilidades de diseño
Budi: Apa persyaratan seleksi? = ¿Cuáles son los requisitos de selección?
  > persyaratan seleksi = requisitos de selección
Sari: Pelamar harus memenuhi persyaratan. = El candidato debe cumplir los requisitos.
  > pelamar = candidato | memenuhi persyaratan = cumplir los requisitos
Budi: Perusahaan mengandalkan tenaga ahli untuk pekerjaan ini. = La empresa depende de especialistas para este trabajo.
  > perusahaan = empresa | mengandalkan tenaga ahli = depender de especialistas
Sari: Saya berharap terpilih sebagai pegawai tetap. = Espero resultar seleccionada como empleada fija.
  > terpilih sebagai pegawai tetap = resultar seleccionada como empleada fija
Budi: Pekerja lepas juga dapat menekuni bidang ini. = Los trabajadores independientes también pueden dedicarse a este campo.
  > pekerja lepas = trabajadores independientes | menekuni bidang ini = dedicarse a este campo
Q ¿Qué palabra designa una destreza práctica?
+ keterampilan :: Se desarrolla mediante la práctica.
- persyaratan :: Son las condiciones que hay que cumplir.
- jabatan :: Es el puesto o cargo.
R Saya melamar lowongan kerja itu. :: ¿Qué significa?
+ Solicito esa vacante laboral. :: «Melamar» es solicitar un empleo.
- Dirijo esa empresa. :: «Perusahaan» significa empresa, pero la frase habla de solicitar un puesto.
- Me dedico a la selección. :: «Seleksi» es el proceso, no la acción de solicitar.
H Pelamar harus ___ persyaratan. :: Completa con «cumplir».
+ memenuhi :: «Memenuhi persyaratan» es cumplir los requisitos.
- menekuni :: Significa dedicarse a un campo.
- mengandalkan :: Significa depender de alguien o algo.
A Perusahaan mengandalkan tenaga ahli. :: ¿De quién depende la empresa?
+ De especialistas. :: «Tenaga ahli» es personal experto.
- De trabajadores independientes solamente. :: La frase no limita así el personal.
- De los candidatos que ya fueron elegidos. :: «Terpilih» no aparece en la frase.
O Pelamar memenuhi persyaratan seleksi :: El candidato cumple los requisitos de selección :: «Memenuhi» expresa cumplir una condición.
Q ¿Qué expresión significa «entrevista de trabajo»?
+ wawancara kerja :: Es una entrevista relacionada con un empleo.
- pengalaman kerja :: Significa experiencia laboral.
- pekerja lepas :: Significa trabajador independiente.
H Saya ingin ___ bidang desain. :: Completa con «dedicarme a».
+ menekuni :: Se usa para seguir una actividad o especialidad.
- terpilih :: Significa resultar elegido.
- melamar :: Significa solicitar un puesto.
R Saya berharap terpilih sebagai pegawai tetap. :: Traduce la frase.
+ Espero resultar seleccionada como empleada fija. :: «Terpilih» describe el resultado de una selección.
- Espero solicitar una entrevista laboral. :: Esa acción sería «melamar».
- Espero depender de un especialista. :: Eso sería «mengandalkan tenaga ahli».

@ 31 | Tindakan yang tidak disengaja | Acciones involuntarias
E El prefijo ter- :: En ejemplos como **tertinggal** («quedarse olvidado») y **tertelan** («tragarse sin querer»), **ter-** presenta una acción no intencional. No tiene ese sentido en todas las palabras con **ter-**. :: Para un hispanohablante, a menudo se traduce con «se me…»: **Berkasnya tertinggal** = «Se me quedó el expediente».
E El confijo ke-…-an :: En **ketiduran** («quedarse dormido sin querer») y **kejatuhan** («caérsele algo encima a alguien»), **ke-…-an** también expresa un hecho involuntario. El significado se aprende con cada palabra; no se añade libremente a cualquier raíz.
W tertinggal = quedarse olvidado; dejarse algo sin querer | ter-TING-gal
W terbuang sia-sia = desperdiciarse; acabar sin provecho | ter-BU-ang SI-a SI-a
W tertelan = tragarse sin querer | ter-te-LAN
W ketiduran = quedarse dormido sin querer | ke-ti-DU-ran
W kejatuhan = caerle algo encima a alguien | ke-ja-TU-han
W ketahuan = ser descubierto; quedar al descubierto | ke-ta-HU-an
W kelupaan = olvidarse sin querer | ke-lu-PA-an
W terlewat = pasarse por alto; quedar atrás | ter-LE-wat
W tidak sengaja = sin querer; accidentalmente | ti-dak se-NGA-ja
W tanpa sadar = sin darse cuenta | TAN-pa sa-DAR
W berkas lamaran = expediente de solicitud | BER-kas la-MA-ran
W catatan wawancara = apuntes de la entrevista | cha-TA-tan wa-wan-CHA-ra
W daftar keahlian = lista de especialidades | DAf-tar ke-AH-li-an
W permen = caramelo | PER-men
W rusak = estropeado; dañado | RU-sak
W tersimpan = quedar guardado; estar almacenado | ter-SIM-pan
W memeriksa = revisar; comprobar | me-me-RIK-sa
V Vocabulario: imprevistos y descuidos
D Antes de la entrevista
Sari: Kemarin saya ketiduran sebelum menyiapkan berkas lamaran. = Ayer me quedé dormida antes de preparar el expediente de solicitud.
  > ketiduran = me quedé dormida sin querer | berkas lamaran = expediente de solicitud
Budi: Akibatnya, catatan wawancara tertinggal di rumah. = Como consecuencia, los apuntes de la entrevista se quedaron en casa.
  > catatan wawancara = apuntes de la entrevista | tertinggal di rumah = se quedaron en casa
Sari: Saya juga kelupaan membawa daftar keahlian. = También me olvidé de llevar la lista de especialidades.
  > kelupaan membawa = olvidarme de llevar | daftar keahlian = lista de especialidades
Budi: Tetapi pengalaman kerja saya tidak terbuang sia-sia. = Pero mi experiencia laboral no se desperdició.
  > pengalaman kerja = experiencia laboral | tidak terbuang sia-sia = no se desperdició
Sari: Benar, tetapi permen itu tertelan tanpa sadar. = Es cierto, pero me tragué ese caramelo sin darme cuenta.
  > permen itu tertelan = ese caramelo se tragó | tanpa sadar = sin darse cuenta
Budi: Masalah itu tidak ketahuan oleh petugas. = El empleado no descubrió ese problema.
  > masalah itu = ese problema | tidak ketahuan = no se descubrió | oleh petugas = por el empleado
Sari: Di kantor, Budi kejatuhan buku. = En la oficina, a Budi le cayó un libro encima.
  > Di kantor = en la oficina | Budi kejatuhan buku = a Budi le cayó un libro encima
Budi: Catatan wawancara itu tersimpan dan diperiksa kembali. = Esos apuntes de la entrevista están guardados y se revisan de nuevo.
  > Catatan wawancara itu = esos apuntes de la entrevista | tersimpan = están guardados | diperiksa kembali = se revisan de nuevo
Q ¿Qué suele expresar «tertinggal» en el ejemplo de los apuntes?
+ Que se quedaron olvidados sin intención. :: El prefijo presenta un resultado no intencional en este ejemplo.
- Que alguien los publicó deliberadamente. :: La forma no expresa una publicación voluntaria.
- Que se seleccionaron para un puesto. :: Eso no significa «tertinggal».
R Saya ketiduran sebelum menyiapkan berkas lamaran. :: Traduce la frase.
+ Me quedé dormida antes de preparar el expediente de solicitud. :: «Ketiduran» es quedarse dormido sin querer.
- Me preparé para dormir después de la entrevista. :: La frase no dice eso.
- Me olvidé de solicitar la vacante ayer. :: No aparece «melamar».
H Catatan wawancara ___ di rumah. :: Completa con «se quedaron olvidados».
+ tertinggal :: Se usa aquí para algo que no se llevó sin querer.
- terbuang sia-sia :: Significa desperdiciarse.
- tersimpan :: Significa estar guardado.
A Permen itu tertelan tanpa sadar. :: ¿Qué le pasó al caramelo?
+ Se tragó sin que la persona se diera cuenta. :: «Tertelan» describe una acción involuntaria.
- Se quedó guardado en una caja. :: Eso sería «tersimpan».
- Se desperdició durante la entrevista. :: Eso sería «terbuang sia-sia».
O Saya kelupaan membawa daftar keahlian :: Se me olvidó llevar la lista de especialidades :: «Kelupaan» expresa un olvido involuntario.
Q ¿Qué forma significa «caerle algo encima a alguien»?
+ kejatuhan :: El suceso le ocurre a la persona afectada.
- ketahuan :: Significa quedar al descubierto.
- terlewat :: Significa pasarse por alto.
H Masalah itu tidak ___ oleh petugas. :: Completa con «fue descubierta».
+ ketahuan :: «Ketahuan oleh» indica que alguien descubre algo.
- ketiduran :: Significa quedarse dormido.
- tertelan :: Significa tragarse algo sin querer.
R Pengalaman kerja saya tidak terbuang sia-sia. :: ¿Qué significa?
+ Mi experiencia laboral no se desperdició. :: «Terbuang sia-sia» expresa acabar sin provecho.
- Mis apuntes se quedaron en casa. :: Esa idea se expresa con «catatan tertinggal».
- El entrevistador no descubrió el error. :: Eso corresponde a «kesalahan tidak ketahuan».

@ 31 | Menyusun teks eksposisi | Organizar un texto argumentativo
I Una opinión resulta más convincente cuando presenta una idea central y razones apoyadas en información.
E Partes de una exposición :: Una exposición argumentativa puede empezar con una **pernyataan pendapat**, desarrollar **argumen** y cerrar con una **penegasan**. :: Un **bukti pendukung** concreto ayuda a distinguir una razón de una mera afirmación.
E Conectores de argumento :: **Berdasarkan data** significa «según los datos»; **dengan demikian** introduce una conclusión. En indonesio, el verbo no cambia por persona ni por tiempo, así que el orden y estos conectores ayudan a seguir el argumento.
W teks eksposisi = texto expositivo argumentativo | TEKS eks-po-SI-si
W dimulai = empezar; iniciarse | di-MU-lai
W pernyataan pendapat = planteamiento de una opinión | per-nya-TA-an pen-da-PAT
W argumen = argumento | ar-GU-men
W bukti pendukung = prueba que respalda una idea | BUK-ti pen-DU-kung
W survei = encuesta | sur-VEI
W responden = persona encuestada | res-PON-den
W formasi = plaza; puesto disponible | for-MA-si
W peminat = persona interesada; aspirante | pe-mi-NAT
W persaingan = competencia; rivalidad | per-sa-I-ngan
W ketat = intenso; reñido | ke-TAT
W membuktikan = demostrar; probar | mem-BUK-ti-kan
W terbukti = quedar demostrado | ter-BUK-ti
W berdasarkan data = según los datos | ber-da-SAR-kan DA-ta
W dengan demikian = por lo tanto; así pues | de-NGAN de-MI-ki-an
W penegasan = reafirmación; conclusión enfática | pe-ne-GAS-an
W mengemukakan = exponer; plantear una idea | meng-e-mu-KA-kan
W lowongan terbatas = vacantes limitadas | lo-WO-ngan ter-BA-tas
W berkontribusi = contribuir | ber-kon-tri-BU-si
V Vocabulario: opiniones y argumentos
T Una opinión sobre las profesiones
- Teks eksposisi dimulai dengan pernyataan pendapat. = Un texto expositivo empieza con el planteamiento de una opinión.
  > Teks eksposisi = texto expositivo | pernyataan pendapat = planteamiento de una opinión
- Sari mengemukakan argumen tentang pilihan profesi. = Sari expone argumentos sobre opciones profesionales.
  > mengemukakan argumen = expone argumentos | pilihan profesi = opciones profesionales
- Bukti pendukung dapat berasal dari survei. = Las pruebas de apoyo pueden proceder de una encuesta.
  > bukti pendukung = pruebas de apoyo | berasal dari survei = proceder de una encuesta
- Responden memilih pengalaman kerja sebagai alasan. = Las personas encuestadas eligen la experiencia laboral como razón.
  > responden = personas encuestadas | memilih pengalaman kerja = eligen la experiencia laboral | sebagai alasan = como razón
- Berdasarkan data, jumlah peminat lebih banyak daripada formasi. = Según los datos, hay más personas interesadas que plazas.
  > berdasarkan data = según los datos | jumlah peminat = número de personas interesadas | lebih banyak daripada formasi = más que las plazas
- Persaingan untuk lowongan terbatas sangat ketat. = La competencia por las vacantes limitadas es muy reñida.
  > persaingan = competencia | lowongan terbatas = vacantes limitadas | sangat ketat = muy reñida
- Survei itu membuktikan keterampilan sangat penting. = Esa encuesta demuestra que las habilidades son muy importantes.
  > Survei itu = esa encuesta | membuktikan = demuestra | keterampilan sangat penting = las habilidades son muy importantes
- Dengan demikian, kita harus memilih profesi. = Por lo tanto, debemos elegir una profesión.
  > Dengan demikian = por lo tanto | kita harus memilih profesi = debemos elegir una profesión
Q ¿Qué parte de un texto argumentativo presenta la idea principal?
+ pernyataan pendapat :: Expone la postura que después se apoya con argumentos.
- responden :: Es una persona que contesta una encuesta.
- formasi :: Es un puesto disponible.
R Sari mengemukakan argumen tentang pilihan profesi. :: ¿Qué hace Sari?
+ Expone argumentos sobre las opciones profesionales. :: «Mengemukakan» es exponer una idea.
- Contesta una encuesta sobre un empleo. :: Esa acción sería responder como «responden».
- Ocupa todas las plazas disponibles. :: La oración habla de presentar argumentos.
H Bukti pendukung dapat berasal dari ___. :: Completa con «encuesta».
+ survei :: Puede aportar información que respalde una opinión.
- formasi :: Es una plaza disponible.
- jabatan :: Es un cargo o puesto.
A Berdasarkan data, jumlah peminat lebih banyak daripada formasi. :: ¿Qué muestran los datos?
+ Hay más personas interesadas que plazas disponibles. :: «Lebih banyak daripada» compara cantidades.
- Las plazas superan a las personas interesadas. :: La frase expresa lo contrario.
- La encuesta no incluye ninguna profesión. :: La frase no lo dice.
O Persaingan untuk lowongan terbatas sangat ketat :: La competencia por las vacantes limitadas es muy reñida :: «Ketat» describe una competencia intensa.
Q ¿Qué significa «terbukti»?
+ quedar demostrado :: Indica que algo cuenta con pruebas que lo respaldan.
- ser seleccionado para un puesto :: Eso es «terpilih».
- dedicarse a una especialidad :: Eso es «menekuni».
H Survei itu ___ keterampilan sangat penting. :: Completa con «demuestra».
+ membuktikan :: Expresa que un dato prueba una afirmación.
- mengandalkan :: Significa depender de.
- menekuni :: Significa dedicarse a.
R Dengan demikian, kita harus memilih profesi. :: Traduce la frase.
+ Por lo tanto, debemos elegir una profesión. :: «Dengan demikian» introduce la conclusión.
- Según la encuesta, todos los candidatos fueron seleccionados. :: Esa idea no aparece en la frase.
- La entrevista demuestra que no se necesitan habilidades. :: La frase no menciona una entrevista.
