@ 29 | Dongeng favorit | Relatar y comentar cuentos populares
I Vas a leer una leyenda, reconocer una forma de acción recíproca y explicar por qué una historia te gusta o qué mensaje transmite.
E Partes de una leyenda :: Un relato puede presentar a sus personajes, contar los hechos principales y cerrar con una consecuencia o un mensaje moral. **Asal-usul** significa «origen».
E Mensaje y promesa :: **Pesan moral** y **amanat** se refieren a la enseñanza de una historia. **Menepati janji** es cumplir una promesa; **melanggar janji**, romperla.
W dongeng = cuento; cuento fantástico o tradicional | DON-geng
W cerita rakyat = relato popular; folclore | che-RI-ta ra-KYAT
W suatu hari = un día | su-A-tu HA-ri
W legenda = leyenda | le-GEN-da
W pesan moral = mensaje moral | pe-SAN mo-RAL
W amanat = enseñanza; mensaje de una historia | a-MA-nat
W asal-usul = origen; explicación de un origen | a-SAL u-SUL
W nelayan = pescador/a | ne-LA-yan
W ikan ajaib = pez mágico | I-kan a-JA-ib
W menangkap = atrapar; capturar | me-NANG-kap
W mengisahkan = narrar; contar una historia | meng-i-SAH-kan
W berubah menjadi = convertirse en | be-ru-BAH men-JA-di
W membuat janji = hacer una promesa | mem-BU-at JAN-ji
W menjaga rahasia = guardar un secreto | men-JA-ga ra-HA-si
W melanggar janji = romper una promesa | me-lang-GAR JAN-ji
W menepati janji = cumplir una promesa | me-ne-PA-ti JAN-ji
W membentuk danau = formar un lago | mem-BEN-tuk DA-nau
V Vocabulario: una leyenda y su mensaje
T Un cuento sobre una promesa
- Cerita rakyat ini mengisahkan seorang nelayan. = Este relato popular cuenta la historia de un pescador.
  > Cerita rakyat ini = este relato popular | mengisahkan seorang nelayan = cuenta la historia de un pescador
- Suatu hari, nelayan itu menangkap ikan ajaib. = Un día, el pescador atrapó un pez mágico.
  > Suatu hari = un día | menangkap ikan ajaib = atrapó un pez mágico
- Ikan itu berubah menjadi seorang wanita. = El pez se convirtió en una mujer.
  > berubah menjadi = se convirtió en | seorang wanita = una mujer
- Nelayan itu membuat janji untuk menjaga rahasia. = El pescador hizo una promesa de guardar un secreto.
  > membuat janji = hizo una promesa | menjaga rahasia = guardar un secreto
- Kemudian, nelayan itu melanggar janji. = Después, el pescador rompió la promesa.
  > Kemudian = después | nelayan itu = el pescador | melanggar janji = rompió la promesa
- Dalam legenda itu, air meluap dan membentuk danau. = En esa leyenda, el agua se desbordó y formó un lago.
  > air meluap = el agua se desbordó | membentuk danau = formó un lago
- Pesan moral cerita itu: kita harus menepati janji. = El mensaje moral del cuento: debemos cumplir las promesas.
  > Pesan moral cerita itu = el mensaje moral del cuento | menepati janji = cumplir una promesa
Q ¿Qué tipo de historia suele explicar el origen de un lugar?
+ legenda :: Una leyenda puede explicar el origen de un lago o una costumbre.
- ulasan :: Es una reseña o valoración.
- sinopsis :: Es un resumen breve de una película o una historia.
R Nelayan itu menangkap ikan ajaib. :: ¿Qué ocurrió?
+ El pescador atrapó un pez mágico. :: «Menangkap» significa atrapar.
- El pez rompió una promesa. :: La frase dice que el pescador atrapó al pez.
- El lago guardó un secreto. :: La frase no dice eso.
H Nelayan itu membuat janji untuk ___ rahasia. :: Completa con «guardar».
+ menjaga :: Significa cuidar o mantener algo protegido.
- menangkap :: Significa atrapar.
- membentuk :: Significa formar.
A Dalam legenda itu, air meluap dan membentuk danau. :: ¿Qué pasó?
+ El agua se desbordó y formó un lago. :: La oración cuenta dos hechos consecutivos.
- El pescador cumplió la promesa y guardó el pez. :: No es lo que dice la frase.
- Una mujer atrapó el agua del lago. :: La oración no menciona a una mujer.
O Pesan moral cerita itu: kita harus menepati janji :: El mensaje moral del cuento: debemos cumplir las promesas :: La moraleja resume una enseñanza de la historia.
Q ¿Qué significa melanggar janji?
+ romper una promesa :: Es no hacer lo que se prometió.
- cumplir una promesa :: Eso significa «menepati janji».
- guardar un secreto :: Eso significa «menjaga rahasia».
H Cerita rakyat ini ___ seorang nelayan. :: Completa con «cuenta la historia de».
+ mengisahkan :: Introduce lo que narra un relato.
- berubah menjadi :: Significa «convertirse en».
- menangkap :: Significa «atrapar».
R Ikan itu berubah menjadi seorang wanita. :: ¿Qué significa?
+ El pez se convirtió en una mujer. :: «Berubah menjadi» introduce una transformación.
- La mujer atrapó al pescador. :: La frase dice lo contrario.
- El pez cumplió una promesa y formó un lago. :: No es el contenido de la frase.

@ 29 | Berkejar-kejaran dan bersahut-sahutan | Acciones recíprocas con ber-…-an
E La forma ber-...-an :: En algunas palabras, la base se repite y recibe **ber-** al principio y **-an** al final: **kejar → berkejar-kejaran**. A menudo expresa una acción mutua o compartida; el sentido depende de cada palabra.
E Acciones entre varias personas :: **Bersalam-salaman** es saludarse estrechando las manos; **berpeluk-pelukan**, abrazarse; **bersahut-sahutan**, responderse o llamarse unos a otros.
W berkejar-kejaran = perseguirse unos a otros | ber-ke-JAR ke-JA-ran
W bersahut-sahutan = responderse; llamarse unos a otros | ber-sa-HUT sa-HU-tan
W bersalam-salaman = saludarse estrechando las manos | ber-sa-LAM sa-LA-man
W berpeluk-pelukan = abrazarse unos a otros | ber-pe-LUK pe-LU-kan
W saling menyapa = saludarse mutuamente | SA-ling me-nya-PA
W saling menolong = ayudarse mutuamente | SA-ling me-no-LONG
W berkumpul = reunirse; juntarse | ber-KUM-pul
W pencerita = narrador/a; cuentacuentos | pen-che-RI-ta
W halaman rumah = patio de la casa | ha-LA-man RU-mah
W dari kejauhan = desde lejos | da-ri ke-ja-U-han
W terdengar = oírse; ser escuchado | ter-de-NGAR
W tertawa bersama = reírse juntos | ter-TA-wa ber-SA-ma
W pembukaan cerita = inicio del cuento | pem-bu-KA-an che-RI-ta
W kerumunan = multitud; grupo numeroso | ke-ru-MU-nan
W para tamu = los invitados | PA-ra TA-mu
V Vocabulario: encontrarse y actuar juntos
D Antes de que empiece el cuento
Sari: Anak-anak berkumpul di halaman rumah pencerita. = Los niños se reúnen en el patio de la casa del cuentacuentos.
  > Anak-anak berkumpul = los niños se reúnen | di halaman rumah pencerita = en el patio de la casa del cuentacuentos
Budi: Mereka berkejar-kejaran sambil menunggu. = Se persiguen unos a otros mientras esperan.
  > Mereka berkejar-kejaran = se persiguen unos a otros | sambil menunggu = mientras esperan
Sari: Dari kejauhan, suara mereka terdengar bersahut-sahutan. = Desde lejos, se oyen sus voces llamándose unos a otros.
  > Dari kejauhan = desde lejos | suara mereka = sus voces | terdengar bersahut-sahutan = se oyen llamándose unos a otros
Budi: Ketika pencerita tiba, para tamu saling menyapa. = Cuando llega el cuentacuentos, los invitados se saludan.
  > Ketika pencerita tiba = cuando llega el cuentacuentos | para tamu = los invitados | saling menyapa = se saludan mutuamente
Sari: Mereka juga bersalam-salaman sebelum duduk. = También se saludan estrechando las manos antes de sentarse.
  > bersalam-salaman = saludarse estrechando las manos | sebelum duduk = antes de sentarse
Budi: Setelah cerita selesai, mereka berpeluk-pelukan dan tertawa bersama. = Cuando termina el cuento, se abrazan y se ríen juntos.
  > Setelah cerita selesai = cuando termina el cuento | berpeluk-pelukan = se abrazan unos a otros | tertawa bersama = se ríen juntos
Q ¿Qué suele expresar berkejar-kejaran?
+ Perseguirse unos a otros. :: La acción pasa de una persona a otra.
- Guardar un secreto. :: Eso significa «menjaga rahasia».
- Cumplir una promesa. :: Eso significa «menepati janji».
R Mereka berkejar-kejaran sambil menunggu. :: ¿Qué hacen?
+ Se persiguen unos a otros mientras esperan. :: «Berkejar-kejaran» expresa una acción mutua.
- Se abrazan después de terminar un cuento. :: Eso sería «berpeluk-pelukan».
- Se saludan estrechando las manos antes de sentarse. :: Eso sería «bersalam-salaman».
H Dari kejauhan, suara mereka ___ bersahut-sahutan. :: Completa con «se oye».
+ terdengar :: Es la forma pasiva relacionada con oír.
- berkumpul :: Significa «reunirse».
- menyapa :: Significa «saludar».
A Setelah cerita selesai, mereka berpeluk-pelukan dan tertawa bersama. :: ¿Qué hacen al final?
+ Se abrazan y se ríen juntos. :: «Berpeluk-pelukan» expresa abrazos mutuos.
- Se persiguen antes de que llegue el cuentacuentos. :: Eso sucede antes.
- Se llaman unos a otros desde lejos. :: Esa acción aparece en otra línea.
O Para tamu saling menyapa :: Los invitados se saludan mutuamente :: «Saling» indica reciprocidad.
Q ¿Qué significa bersahut-sahutan?
+ responderse o llamarse unos a otros :: Las voces se contestan entre sí.
- reunirse en un patio :: Eso significa «berkumpul di halaman».
- abrazarse unos a otros :: Eso significa «berpeluk-pelukan».
H Ketika pencerita tiba, para tamu ___ menyapa. :: Completa con «se saludan mutuamente».
+ saling :: Señala que la acción es recíproca.
- dari kejauhan :: Significa «desde lejos».
- bersama :: Significa «juntos».
R Mereka juga bersalam-salaman sebelum duduk. :: ¿Qué hacen los invitados?
+ Se saludan estrechando las manos antes de sentarse. :: «Bersalam-salaman» expresa un saludo mutuo.
- Se reúnen en el patio y esperan al narrador. :: Eso aparece al principio.
- Se persiguen unos a otros mientras esperan. :: Eso sería «berkejar-kejaran».

@ 29 | Menafsirkan dongeng | Comentar un cuento y su enseñanza
E Expresar una interpretación :: Para comentar una historia, menciona una parte concreta y explica qué mensaje entiendes. **Masuk akal** significa «tener sentido» o «ser razonable».
E Dar una opinión y una razón :: Puedes decir si estás de acuerdo y justificarlo: **Saya setuju karena ...** («Estoy de acuerdo porque ...»). Distingue tu interpretación de los hechos que cuenta el relato.
W bagian favorit = parte favorita | ba-GI-an fa-vo-RIT
W perilaku tokoh = comportamiento del personaje | pe-ri-LA-ku TO-koh
W rasa penasaran = curiosidad; deseo de saber | RA-sa pe-na-SA-ran
W penasaran = curioso; con curiosidad | pe-na-SA-ran
W keputusan = decisión | ke-pu-TU-san
W masuk akal = tener sentido; ser razonable | ma-SUK A-kal
W setuju dengan = estar de acuerdo con | se-TU-ju de-NGAN
W pesan tersirat = mensaje implícito | pe-SAN ter-si-RAT
W mengingatkan = recordar; hacer que alguien recuerde | meng-i-NGAT-kan
W menafsirkan = interpretar | me-naf-SIR-kan
W pendapat pribadi = opinión personal | pen-DA-pat pri-BA-di
W alasan kuat = razón convincente | a-la-SAN KU-at
W sudut pandang = punto de vista | SU-dut PAN-dang
W tokoh pendukung = personaje secundario | TO-koh pen-DU-kung
W membayangkan = imaginar | mem-ba-YANG-kan
W berbeda = diferente | ber-BE-da
V Vocabulario: opiniones e interpretaciones
D Comentamos una leyenda
Melati: Apa bagian favorit dari legenda itu? = ¿Cuál es la parte favorita de esa leyenda?
  > bagian favorit = parte favorita | dari legenda itu = de esa leyenda
Sari: Perilaku tokoh utama membuat saya penasaran. = El comportamiento del protagonista me da curiosidad.
  > perilaku tokoh utama = comportamiento del protagonista | membuat saya penasaran = me da curiosidad
Melati: Menurut saya, keputusan nelayan itu masuk akal. = En mi opinión, la decisión del pescador tiene sentido.
  > keputusan nelayan itu = la decisión del pescador | masuk akal = tiene sentido
Sari: Saya setuju dengan pendapat itu karena tokoh itu menjaga rahasia. = Estoy de acuerdo con esa opinión porque el personaje guardó el secreto.
  > setuju dengan pendapat itu = de acuerdo con esa opinión | menjaga rahasia = guardó el secreto
Melati: Pesan tersirat dari legenda itu mengingatkan kita supaya menepati janji. = El mensaje implícito de la leyenda nos recuerda que debemos cumplir las promesas.
  > pesan tersirat dari legenda itu = mensaje implícito de la leyenda | mengingatkan kita = nos recuerda | supaya menepati janji = que cumplamos las promesas
Sari: Dari sudut pandang saya, tokoh pendukung juga penting. = Desde mi punto de vista, el personaje secundario también es importante.
  > dari sudut pandang saya = desde mi punto de vista | tokoh pendukung = personaje secundario | juga penting = también es importante
Melati: Saya membayangkan akhir cerita yang berbeda. = Imagino un final diferente para la historia.
  > membayangkan = imaginar | akhir cerita yang berbeda = un final diferente para la historia
Q ¿Qué significa pesan tersirat?
+ mensaje implícito :: Es una idea que la historia sugiere sin decirla directamente.
- inicio del cuento :: Eso significa «pembukaan cerita».
- número de seguimiento :: Eso significa «nomor resi».
R Keputusan nelayan itu masuk akal. :: ¿Qué opina la hablante?
+ Que la decisión del pescador tiene sentido. :: «Masuk akal» significa razonable o comprensible.
- Que el pescador rompió el paquete. :: La frase no trata de un envío.
- Que la decisión es imposible de entender. :: Expresa lo contrario.
H Saya ___ dengan pendapat itu. :: Completa con «estoy de acuerdo».
+ setuju :: Es una forma breve de expresar acuerdo.
- penasaran :: Significa «con curiosidad».
- membayangkan :: Significa «imaginar».
A Pesan tersirat dari legenda itu mengingatkan kita supaya menepati janji. :: ¿Qué enseñanza comunica?
+ Nos recuerda que debemos cumplir las promesas. :: «Mengingatkan» significa hacer recordar.
- Nos pide perseguirnos unos a otros. :: Eso sería «berkejar-kejaran».
- Nos explica cómo formar un lago. :: No es la enseñanza de la oración.
O Saya setuju dengan pendapat itu :: Estoy de acuerdo con esa opinión :: «Setuju dengan» introduce el punto de vista que compartes.
Q ¿Qué significa tokoh pendukung?
+ personaje secundario :: Acompaña al personaje principal en la historia.
- mensaje implícito :: Eso significa «pesan tersirat».
- razón convincente :: Eso significa «alasan kuat».
H Dari ___ saya, tokoh pendukung juga penting. :: Completa con «punto de vista».
+ sudut pandang :: Es la perspectiva desde la que alguien opina.
- bagian favorit :: Significa «parte favorita».
- pesan moral :: Significa «mensaje moral».
R Saya membayangkan akhir cerita yang berbeda. :: ¿Qué hace la persona?
+ Imagina un final distinto para la historia. :: «Membayangkan» significa imaginar.
- Recuerda el mensaje implícito de la leyenda. :: Eso sería «mengingatkan».
- Saluda a todos los invitados con la mano. :: Eso sería «bersalam-salaman».
