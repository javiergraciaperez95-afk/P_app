N Sari, Budi, Rina, Andi, Nina, Madrid, Spanyol, Indonesia, Dewi, Jepang, Tokyo, Jakarta, Melati, Meli

@ 1 | Halo! | Saludar y presentarse
I En indonesio, muchas frases de presente no necesitan un verbo equivalente a «ser» o «estar». En esta lección verás fórmulas completas para saludar y decir quién eres.
E Decir tu nombre :: **Nama saya Sari** significa literalmente «mi nombre, Sari» y se traduce de forma natural como «me llamo Sari» o «soy Sari». No hace falta añadir un verbo «ser». :: **Saya** es «yo» neutro o cortés; **aku**, «yo» de confianza. Para «tú/usted», **kamu** es informal y **Anda** más formal. No son equivalencias exactas: según la situación también se usa el nombre o un tratamiento.
E Preguntar y decir de dónde eres :: **Siapa nama Anda?** pregunta el nombre; **Anda dari mana?**, de dónde es la otra persona. En la respuesta, **Saya dari Spanyol** equivale a «soy de España». Las preguntas no llevan signos de apertura.
W halo = hola | HA-lo
W hai = hola (informal) | hai
W selamat = fórmula de saludo o buenos deseos | se-LA-mat
W pagi = mañana (parte del día) | PA-gi
W siang = mediodía, primera parte de la tarde | SI-ang
W sore = última parte de la tarde | SO-re
W malam = noche | MA-lam
W tidur = dormir | TI-dur
W nama = nombre | NA-ma
W saya = yo (neutro o cortés) | SA-ya
W aku = yo (de confianza) | A-ku
W siapa = quién | si-A-pa
W Anda = usted; tú (trato formal) | AN-da
W kamu = tú (informal) | KA-mu
W dari = de, desde (origen) | DA-ri
W mana = dónde; cuál | MA-na
W senang = contento; encantado | se-NANG
W bertemu = encontrarse, conocer a alguien | ber-te-MU
W dengan = con | de-NGAN
W juga = también | JU-ga
W oh = ah; oh | O
W ya = sí | YA
V Vocabulario: saludos y presentaciones
D En la mañana
Budi: Selamat pagi! = ¡Buenos días!
  > Selamat pagi = saludo de buenos días.
Sari: Halo, Budi. Nama saya Sari. = Hola, Budi. Me llamo Sari.
  > Halo = hola | Nama saya = literalmente «mi nombre» | Sari = nombre propio
Budi: Saya Budi. Senang bertemu dengan Anda. = Soy Budi. Encantado de conocerla.
  > Saya = yo | Senang bertemu = encantado de conocer | dengan Anda = con usted
Sari: Senang bertemu dengan Anda juga. = Encantada de conocerlo también.
  > Senang bertemu = encantada de conocer | dengan Anda = con usted | juga = también
Budi: Anda dari mana? = ¿De dónde es usted?
  > Anda = usted | dari mana = de dónde
Sari: Saya dari Spanyol. = Soy de España.
  > Saya = yo | dari Spanyol = de España
Budi: Oh, Anda dari Madrid? = Ah, ¿usted es de Madrid?
  > Anda = usted | dari Madrid = de Madrid
Sari: Ya. Saya dari Madrid. = Sí. Soy de Madrid.
  > Ya = sí | Saya = yo | dari Madrid = de Madrid
Q ¿Cuál de estas fórmulas sirve para saludar por la mañana?
+ Selamat pagi :: Se usa por la mañana.
- Selamat malam :: Es el saludo de la noche.
- Selamat tidur :: Se dice al irse a dormir.
Q ¿Qué pronombre eliges para hablar de ti con neutralidad o cortesía?
+ Saya :: Es la opción neutral o cortés.
- Aku :: Es más de confianza.
- Kamu :: Significa «tú» informal.
R Nama saya Budi. :: Elige la traducción.
+ Me llamo Budi. :: La frase presenta el nombre.
- ¿Cómo te llamas, Budi? :: Eso sería una pregunta.
- De dónde es Budi. :: No hay pregunta de origen.
H Nama ___ Sari. :: Presenta tu nombre.
+ saya :: «Nama saya» = mi nombre.
- siapa :: «Siapa» pregunta quién.
- kamu :: «Kamu» significa tú.
A Saya dari Spanyol. :: Escucha y elige el significado.
+ Soy de España. :: «Dari» expresa el origen.
- Soy de Indonesia. :: «Spanyol» significa España.
- Vengo de Madrid. :: Madrid no aparece en esta frase.
O Senang bertemu dengan Anda :: Encantado de conocerle :: «Senang bertemu» expresa agrado; «dengan Anda», con usted.
H Anda dari ___? :: Pregunta el origen.
+ mana :: «Dari mana» = de dónde.
- siapa :: «Siapa» pregunta quién.
- nama :: «Nama» significa nombre.
X Escribe en indonesio: «Me llamo Sari». :: Nama saya Sari | Saya Sari :: En presente no hace falta añadir un verbo equivalente a «ser».

@ 1 | Apa kabar? | Preguntar qué tal y responder con cortesía
E Preguntar cómo está alguien :: **Apa kabar?** es la fórmula habitual para preguntar «¿qué tal?» o «¿cómo estás?». Aunque **apa** significa «qué» y **kabar**, «noticias», no se traduce literalmente como «¿qué noticias?» en esta situación.
E Tratamientos cotidianos :: **Bapak** e **Ibu** sirven para dirigirse con respeto a personas adultas; también pueden significar «padre» y «madre». **Mas** y **Mbak** son tratamientos cotidianos para hombres y mujeres, respectivamente, según la relación y la situación. No siempre equivalen a «señor» y «señora» del español.
W apa = qué | A-pa
W kabar = noticias; novedad | KA-bar
W baik = bueno; bien | ba-IK
W terima kasih = gracias | te-RI-ma KA-sih
W sama-sama = de nada; igualmente | SA-ma SA-ma
W maaf = perdón; disculpe | ma-AF
W permisi = con permiso; disculpe | per-MI-si
W tolong = por favor; ayuda, por favor | TO-long
W silakan = adelante; por favor (invitación) | si-LA-kan
W Bapak = señor; padre (según contexto) | BA-pak
W Ibu = señora; madre (según contexto) | I-bu
W Mbak = tratamiento cotidiano para una mujer | em-BAK
W Mas = tratamiento cotidiano para un hombre | MAS
W sehat = sano, con salud | se-HAT
W duduk = sentarse; estar sentado | DU-duk
V Vocabulario: cortesía y bienestar
D Una visita
Ibu Rina: Selamat pagi, Mas Andi. Apa kabar? = Buenos días, Andi. ¿Qué tal?
  > Selamat pagi = buenos días | Mas Andi = tratamiento + nombre | Apa kabar = ¿qué tal?
Mas Andi: Baik, terima kasih. Ibu? = Bien, gracias. ¿Y usted, señora?
  > Baik = bien | terima kasih = gracias | Ibu = tratamiento respetuoso
Ibu Rina: Baik juga. Anda sehat? = Bien también. ¿Está usted bien de salud?
  > Baik juga = bien también | Anda sehat = usted está sano
Mas Andi: Ya, saya sehat. Terima kasih. = Sí, estoy bien. Gracias.
  > Ya = sí | saya sehat = estoy bien de salud | terima kasih = gracias
Ibu Rina: Sama-sama. Silakan duduk. = De nada. Por favor, siéntese.
  > Sama-sama = de nada | Silakan duduk = invitación cortés a sentarse
Mas Andi: Terima kasih, Ibu Rina. = Gracias, señora Rina.
  > Terima kasih = gracias | Ibu Rina = tratamiento + nombre
Q ¿Qué pregunta significa «¿Qué tal?» en una conversación?
+ Apa kabar? :: Es una fórmula de saludo y bienestar.
- Siapa nama Anda? :: Pregunta el nombre.
- Anda dari mana? :: Pregunta el origen.
Q ¿Qué tratamiento respetuoso puede usarse para dirigirse a una mujer adulta?
+ Ibu :: También puede significar «madre».
- Mas :: Es un tratamiento para un hombre.
- Kamu :: Es el pronombre informal «tú».
R Terima kasih, Ibu. :: Elige la traducción.
+ Gracias, señora. :: «Terima kasih» significa gracias.
- De nada, señora. :: Eso se dice «sama-sama».
- ¿Qué tal, señora? :: Eso se dice «apa kabar».
H Apa ___? :: Completa la fórmula para preguntar qué tal.
+ kabar :: «Apa kabar?» es una fórmula completa.
- nama :: «Apa nama?» pregunta qué nombre.
- sehat :: «Sehat» significa sano.
A Silakan duduk. :: Escucha y elige el sentido.
+ Por favor, siéntese. :: Es una invitación cortés.
- Gracias, siéntese. :: «Gracias» es «terima kasih».
- Perdón, señora. :: «Perdón» es «maaf».
O Terima kasih, Mbak. :: Gracias, señora. :: El tratamiento «Mbak» se mantiene según el contexto.
X Escribe en indonesio: «Perdón». :: Maaf :: Fórmula breve de disculpa.
H Selamat pagi, ___ Rina. :: Elige un tratamiento respetuoso para una mujer.
+ Ibu :: «Ibu» se usa para dirigirse con respeto a una mujer adulta.
- Bapak :: Es un tratamiento para un hombre.
- Mas :: Es un tratamiento cotidiano para un hombre.

@ 1 | Sampai besok! | Dar las gracias, pedir que repitan y despedirse
I En indonesio se escribe con alfabeto latino. Para un hispanohablante, las cinco vocales suelen ser reconocibles; más adelante habrá que distinguir las dos pronunciaciones de la letra **e** y algunos sonidos consonánticos.
E Pedir que repitan :: **Tolong ulangi lagi** significa «por favor, repita otra vez». **Bisa mengeja nama Anda?** pregunta si la otra persona puede deletrear su nombre. Para pedir que hablen despacio: **Tolong bicara pelan-pelan**.
E Despedirse :: **Sampai jumpa** significa «hasta luego» o «hasta la vista»; **sampai besok**, «hasta mañana». **Selamat tidur** se dice cuando alguien se va a dormir; no es una despedida general.
W bagaimana = cómo | ba-GAI-ma-na
W ejaan = deletreo; manera de escribir | e-JA-an
W bisa = poder; saber hacer | BI-sa
W mengeja = deletrear | meng-E-ja
W huruf = letra | HU-ruf
W pelan-pelan = despacio | pe-LAN pe-LAN
W bicara = hablar | bi-CA-ra
W ulangi = repetir; repita | u-LA-ngi
W lagi = otra vez; más | LA-gi
W sampai = hasta | sam-PAI
W jumpa = encontrarse; verse | JUM-pa
W besok = mañana (día siguiente) | BE-sok
W selamat tidur = buenas noches (al irse a dormir) | se-LA-mat TI-dur
V Vocabulario: pedir ayuda y despedirse
D Deletrear un nombre
Nina: Maaf, bagaimana ejaan nama Anda? = Disculpe, ¿cómo se escribe su nombre?
  > Maaf = disculpe | bagaimana = cómo | ejaan nama Anda = deletreo de su nombre
Andi: Nama saya Andi. = Me llamo Andi.
  > Nama saya = mi nombre | Andi = nombre propio
Nina: Bisa mengeja nama Anda? = ¿Puede deletrear su nombre?
  > Bisa mengeja = poder deletrear | nama Anda = su nombre
Andi: Bisa. Nama saya Andi. = Sí. Me llamo Andi.
  > Bisa = puedo | Nama saya = mi nombre
Nina: Terima kasih. Tolong ulangi lagi. = Gracias. Repita otra vez, por favor.
  > Terima kasih = gracias | Tolong ulangi lagi = petición cortés de repetición
Andi: Baik. Nama saya Andi. = De acuerdo. Me llamo Andi.
  > Baik = de acuerdo | Nama saya = mi nombre
Nina: Sampai jumpa, Andi. = Hasta luego, Andi.
  > Sampai jumpa = hasta luego | Andi = nombre propio
Andi: Sampai besok! = ¡Hasta mañana!
  > Sampai besok = hasta mañana
Q ¿Qué palabra significa «letra»?
+ huruf :: Se refiere a una letra del alfabeto.
- ejaan :: Significa deletreo o manera de escribir.
- jumpa :: Significa encontrarse o verse.
Q ¿Cuándo dices «selamat tidur»?
+ Al despedirte de alguien que se va a dormir. :: La expresión desea buen descanso.
- Al saludar a alguien por la mañana. :: Para la mañana se dice «selamat pagi».
- Para decir «gracias». :: «Gracias» es «terima kasih».
R Sampai besok! :: Elige la traducción.
+ ¡Hasta mañana! :: «Besok» es el día siguiente.
- ¡Hasta luego! :: «Sampai jumpa» es hasta luego.
- ¡Buenas noches! :: «Selamat tidur» se dice al irse a dormir.
H Bisa ___ nama Anda? :: Completa la pregunta sobre deletrear.
+ mengeja :: «Mengeja» significa deletrear.
- bicara :: «Bicara» significa hablar.
- ulangi :: «Ulangi» significa repetir.
A Tolong bicara pelan-pelan. :: Escucha y elige el significado.
+ Hable despacio, por favor. :: «Pelan-pelan» significa despacio.
- Repita mañana, por favor. :: «Besok» significa mañana.
- Deletree su nombre, por favor. :: Para deletrear se usa «mengeja».
O Bisa mengeja nama Anda? :: ¿Puede deletrear su nombre? :: «Bisa» + verbo pregunta si alguien puede hacerlo.
X Escribe en indonesio: «Hasta mañana». :: Sampai besok :: «Sampai» significa hasta y «besok», mañana.
H Sampai ___! :: Completa la despedida «hasta luego».
+ jumpa :: «Sampai jumpa» significa hasta luego.
- huruf :: «Huruf» significa letra.
- ejaan :: «Ejaan» significa deletreo.
