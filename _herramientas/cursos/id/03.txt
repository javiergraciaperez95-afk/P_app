@ 3 | Ciri-ciri fisik | Rasgos físicos
I Para decir cómo es alguien, el adjetivo va después del nombre. En indonesio suele omitirse el verbo «ser».
E Adjetivos después del nombre :: Puedes decir **Budi tinggi** («Budi es alto»). No hace falta una palabra equivalente a «es».
E Preguntar por rasgos :: **Bagaimana ciri-cirinya?** significa «¿Cómo son sus rasgos?». La pregunta **bagaimana** también puede significar «¿cómo?».
W ciri-ciri = rasgos | CHI-ri CHI-ri | La repetición forma el plural o expresa una categoría de rasgos.
W tinggi = alto, de estatura | TING-gi | Se refiere a la altura de una persona o cosa.
W pendek = bajo, corto | pen-DEK | Para una persona significa «bajo»; para pelo, «corto».
W rambut = pelo, cabello | RAM-but | No cambia por género ni número.
W lurus = liso, recto | LU-rus | Puede describir el pelo o una línea.
W keriting = rizado | ke-ri-TING | Se usa sobre todo para el pelo.
W wajah = cara, rostro | WA-jah | Nombre del rostro.
W bulat = redondo | bu-LAT | Describe la forma.
W panjang = largo | pan-JANG | Puede describir el pelo o un objeto.
W hidung = nariz | hi-DUNG | Nombre del rostro.
W mata = ojo | MA-ta | La palabra no cambia en plural: «dos ojos» es «dua mata».
W pesek = chato, respingado | pe-SEK | Describe una nariz.
W lonjong = ovalado | LON-jong | Describe una forma ovalada.
V Aspecto básico
D Describir a Budi
Nina: Bagaimana ciri-ciri Budi? = ¿Cómo son los rasgos de Budi?
  > Bagaimana = cómo | ciri-ciri Budi = los rasgos de Budi
Budi: Budi tinggi. = Budi es alto.
  > Budi = Budi | tinggi = alto
Nina: Apakah rambut Budi lurus? = ¿El pelo de Budi es liso?
  > Rambut Budi = el pelo de Budi | lurus = liso
Budi: Ya, rambut Budi panjang. = Sí, el pelo de Budi es largo.
  > Ya = sí | rambut Budi = el pelo de Budi | panjang = largo
Nina: Apakah wajah Budi bulat? = ¿La cara de Budi es redonda?
  > wajah Budi = la cara de Budi | bulat = redonda
Budi: Tidak. Wajah Budi lonjong. = No. La cara de Budi es ovalada.
  > Tidak = no | Wajah Budi = la cara de Budi | lonjong = ovalada
Q Bagaimana ciri-ciri Budi? :: Elige la traducción correcta.
+ ¿Cómo son los rasgos de Budi? :: «Bagaimana» pregunta cómo.
- ¿Dónde está la cara de Budi? :: Para preguntar dónde, se usa «di mana».
- ¿Cuándo viene Budi? :: «Kapan» pregunta cuándo.
R Rambut Budi lurus. :: Traduce la frase.
+ El pelo de Budi es liso. :: «Lurus» describe el pelo liso.
- El pelo de Budi es rizado. :: «Keriting» significa rizado.
- La cara de Budi es redonda. :: «Wajah» significa cara.
A Budi tinggi. :: ¿Qué dice la tutora?
+ Budi es alto. :: «Tinggi» significa alto de estatura.
- Budi es bajo. :: «Pendek» significa bajo.
- Budi tiene el pelo largo. :: Esa frase sería «Rambut Budi panjang».
O Wajah Budi bulat :: La cara de Budi es redonda :: El adjetivo «bulat» va después del nombre.
H Rambut Budi ___. :: Completa «El pelo de Budi es largo».
+ panjang :: «Panjang» significa largo.
- pendek :: «Pendek» significa corto o bajo.
- lurus :: «Lurus» significa liso.
Q ¿Qué palabra significa «nariz»? :: Elige la palabra correcta.
+ hidung :: «Hidung» significa nariz.
- rambut :: «Rambut» significa pelo.
- wajah :: «Wajah» significa cara.
R Wajah Budi lonjong. :: Traduce la frase.
+ La cara de Budi es ovalada. :: «Lonjong» significa ovalada.
- La cara de Budi es redonda. :: «Bulat» significa redondo.
- Budi tiene la nariz chata. :: Esa frase sería «Hidung Budi pesek».
A Hidung Budi pesek. :: ¿Qué rasgo se describe?
+ La nariz de Budi es chata. :: «Pesek» describe una nariz chata.
- El pelo de Budi es liso. :: Esa frase sería «Rambut Budi lurus».
- Los ojos de Budi son redondos. :: «Mata» significa ojos.

@ 3 | Ciri-ciri fisik | Rasgos físicos
I El prefijo **ber-** puede expresar una característica física, como «tener» cierta parte o rasgo.
E Palabras con ber- :: **Berambut** significa «tener pelo» y **bermata** significa «tener ojos» con una característica. La base aparece unida al prefijo.
E Color de piel :: **Berkulit putih** significa «de piel clara». El color va después de la palabra con **ber-**.
W berambut = tener el pelo | be-RAM-but | Se usa junto a una descripción del pelo.
W bermata = tener los ojos | ber-MA-ta | Se usa junto a una descripción de los ojos.
W hitam = negro | hi-TAM | Describe pelo, ojos, ropa u objetos.
W cokelat = marrón, castaño | co-ke-LAT | Se refiere al color; también es la palabra para chocolate en otros contextos.
W kulit = piel | ku-LIT | Nombre; no tiene género gramatical.
W berkulit = tener la piel | ber-ku-LIT | La base «kulit» se une a «ber-».
W putih = blanco, claro | pu-TIH | Para el tono de piel se traduce «claro».
W kacamata = gafas | ka-ca-MA-ta | Nombre que suele usarse en plural en español.
W berkacamata = llevar gafas | ber-ka-ca-MA-ta | «Ber-» expresa llevar puesto este accesorio.
W memakai = llevar puesto, usar | me-ma-KAI | Verbo para prendas y accesorios.
W dan = y | dan | Conjunción para unir elementos.
W baju = ropa, prenda | BA-ju | Nombre general de una prenda o ropa.
W biru = azul | BI-ru | Color.
W berwarna = ser de color | ber-WAR-na | Se forma con «warna» y «ber-».
W warna = color | WAR-na | Nombre; en «berwarna» aparece con el prefijo «ber-».
V Rasgos y colores
D Meli describe su aspecto
Nina: Bagaimana ciri-ciri Meli? = ¿Cómo son los rasgos de Meli?
  > Bagaimana = cómo | ciri-ciri Meli = los rasgos de Meli
Meli: Saya berambut hitam. = Tengo el pelo negro.
  > Saya = yo | berambut hitam = tengo el pelo negro
Nina: Apakah Meli bermata cokelat? = ¿Meli tiene los ojos marrones?
  > Apakah = ¿acaso? / marca pregunta | Meli = Meli | bermata cokelat = tiene los ojos marrones
Meli: Ya, dan saya berkulit putih. = Sí, y tengo la piel clara.
  > Ya = sí | dan saya = y yo | berkulit putih = tengo la piel clara
Nina: Meli berkacamata? = ¿Meli lleva gafas?
  > Meli = Meli | berkacamata = lleva gafas
Meli: Ya. Baju Meli berwarna biru. = Sí. La ropa de Meli es azul.
  > Ya = sí | baju Meli = la ropa de Meli | berwarna biru = es de color azul
Q Meli berambut hitam. :: Elige la traducción correcta.
+ Meli tiene el pelo negro. :: «Berambut» introduce el rasgo del pelo.
- Meli tiene los ojos negros. :: Esa frase sería «Meli bermata hitam».
- Meli lleva gafas negras. :: «Kacamata» son gafas.
R Meli bermata cokelat. :: Traduce la frase.
+ Meli tiene los ojos marrones. :: «Bermata» indica una característica de los ojos.
- Meli tiene el pelo castaño. :: Esa frase sería «Meli berambut cokelat».
- Meli tiene la piel clara. :: Esa frase sería «berkulit putih».
A Meli berkulit putih. :: ¿Qué característica menciona?
+ Meli tiene la piel clara. :: «Putih» significa blanco o claro.
- Meli tiene el pelo largo. :: Para largo se dice «panjang».
- Meli tiene los ojos azules. :: Para azul se dice «biru».
O Nina memakai kacamata :: Nina lleva gafas :: «Memakai» se usa para prendas y accesorios.
H Baju Meli berwarna ___. :: Completa «La ropa de Meli es azul».
+ biru :: «Biru» significa azul.
- hitam :: «Hitam» significa negro.
- putih :: «Putih» significa blanco.
Q ¿Qué expresa «berambut hitam»? :: Elige la traducción correcta.
+ Tener el pelo negro :: «Berambut» se refiere al pelo.
- Tener la piel clara :: Para la piel se usa «berkulit».
- Llevar gafas :: Para gafas se dice «berkacamata».
R Meli memakai kacamata. :: Traduce la frase.
+ Meli lleva gafas. :: «Memakai» significa llevar puesto o usar.
- Meli compra gafas. :: «Memakai» significa llevar puesto.
- Meli tiene los ojos negros. :: Esa frase sería «Meli bermata hitam».
A Baju Meli berwarna biru. :: ¿De qué color es la ropa de Meli?
+ Azul. :: «Biru» significa azul.
- Negra. :: «Hitam» significa negro.
- Blanca. :: «Putih» significa blanco.

@ 3 | Ciri-ciri fisik | Rasgos físicos
I Para identificar a una persona entre varias, pregunta **yang mana** («¿cuál?») y usa **yang** antes del rasgo que la distingue.
E Elegir cuál :: **Yang mana?** significa «¿cuál?» o «¿quién de ellos?» según el contexto. **Yang** puede introducir el rasgo que identifica a alguien.
E Ropa y colores :: El nombre de una prenda va antes del color: **kaus merah**, «camiseta roja».
W kaus = camiseta | KA-us | Prenda para la parte superior del cuerpo.
W merah = rojo | ME-rah | Color.
W hijau = verde | hi-JAU | Color.
W celana = pantalón | che-LA-na | No cambia en plural.
W sepatu = zapato | se-PA-tu | La forma no marca género.
W topi = sombrero, gorra | TO-pi | Prenda para la cabeza.
W itu = ese, esa; aquello | I-tu | Señala algo o alguien algo más alejado.
W pilih = ¡escoge! | PI-lih | Imperativo para elegir entre opciones.
W memilih = elegir | me-mi-LIH | Forma verbal con sujeto, formada con el prefijo meN-.
W dua = dos | DU-a | Número.
W gambar = dibujo, imagen | GAM-bar | Nombre de una imagen.
W foto = foto | FO-to | Fotografía.
W lihat = mira | LI-hat | Imperativo para dirigir la atención.
V Identificar a una persona
D ¿Cuál es Budi?
Nina: Pilih dua gambar. = Elige dos dibujos.
  > Pilih = elige | dua gambar = dos dibujos
Sari: Ini gambar Budi. = Este dibujo es de Budi.
  > Ini gambar Budi = este dibujo es de Budi
Nina: Yang mana Budi? = ¿Cuál es Budi?
  > Yang mana = cuál | Budi = Budi
Sari: Budi yang memakai kaus merah. = Budi, el que lleva una camiseta roja.
  > Budi = Budi | yang memakai = que lleva puesto | kaus merah = camiseta roja
Nina: Orang yang memakai topi hijau? = ¿La persona que lleva una gorra verde?
  > Orang = persona | yang memakai = que lleva puesto | topi hijau = gorra verde
Sari: Ya, itu Budi. = Sí, ese es Budi.
  > Ya = sí | itu = ese | Budi = Budi
Nina: Lihat foto ini. Yang memakai celana biru? = Mira esta foto. ¿Quién lleva pantalón azul?
  > Lihat foto ini = mira esta foto | yang memakai = el que lleva puesto | celana biru = pantalón azul
Sari: Ya. Dia memakai sepatu hitam. = Sí. Él lleva zapatos negros.
  > Ya = sí | Dia = él | memakai sepatu hitam = lleva zapatos negros
Q Yang mana Budi? :: Elige la traducción correcta.
+ ¿Cuál es Budi? :: «Yang mana» pregunta cuál.
- ¿Dónde vive Budi? :: Para preguntar dónde vive, se dice «Budi tinggal di mana?».
- ¿Quién es el profesor? :: Para preguntar «quién», se usa «siapa».
R Budi yang memakai kaus merah. :: Traduce la frase.
+ Budi, el que lleva una camiseta roja. :: «Yang» introduce el rasgo que identifica a Budi.
- Budi lleva una camiseta azul. :: «Merah» significa rojo.
- Budi compra una camiseta roja. :: «Memakai» significa llevar puesto.
A Orang yang memakai topi hijau. :: ¿Qué persona describe?
+ La persona que lleva una gorra verde. :: «Orang» es persona; «hijau» es verde.
- La persona que lleva un pantalón azul. :: «Celana» significa pantalón.
- La persona que lleva zapatos negros. :: «Sepatu» significa zapato.
O Kaus merah :: Camiseta roja :: El nombre de la prenda va antes del color.
H Dia memakai ___ hitam. :: Completa «Él lleva zapatos negros».
+ sepatu :: «Sepatu hitam» significa zapatos negros.
- topi :: «Topi» significa gorra o sombrero.
- kaus :: «Kaus» significa camiseta.
Q ¿Qué palabra pregunta «quién»? :: Elige la palabra correcta.
+ siapa :: «Siapa» pregunta por una persona.
- mana :: «Mana» significa cuál o dónde.
- yang :: «Yang» introduce una característica.
R Dia memakai celana biru. :: Traduce la frase.
+ Él lleva un pantalón azul. :: «Celana» es pantalón y «biru» es azul.
- Él lleva una camiseta roja. :: «Kaus merah» es camiseta roja.
- Él tiene los ojos azules. :: Esa descripción usaría «bermata».
A Sari memilih kaus merah. :: ¿Qué hace Sari?
+ Elige una camiseta roja. :: «Memilih» significa elegir o escoger.
- Lleva zapatos negros. :: Esa frase sería «memakai sepatu hitam».
- Lleva una gorra verde. :: Esa frase sería «memakai topi hijau».
