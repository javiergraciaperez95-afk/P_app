@ 8 | Berbicara lewat telepon | Hablar por teléfono
I **Bisa bicara dengan…?** es una forma cortés de preguntar si puedes hablar con alguien. **Ini siapa?** sirve para preguntar quién llama.
E Llamar y contestar :: **Menelepon** significa llamar por teléfono. **Tunggu sebentar** pide a la otra persona que espere un momento.
E Voz y conexión :: **Suara** es la voz o el sonido; **jelas** significa claro. **Nomor telepon** es número de teléfono.
W telepon = teléfono; llamada | te-LE-pon | Puede nombrar el aparato o una llamada.
W menelepon = llamar por teléfono | me-ne-LE-pon | Verbo formado a partir de «telepon».
W ponsel = teléfono móvil | PON-sel | Forma corta de «teléfono celular».
W nomor = número | NO-mor | Se usa, por ejemplo, para un número de teléfono.
W panggil = llamar; hacer venir | PANG-gil | Llamar a una persona para que venga.
W panggilan = llamada | pang-GI-lan | Nombre relacionado con «panggil».
W sebentar = un momento; un rato | se-BEN-tar | Se usa al pedir una espera breve.
W tunggu = espera; esperar | TUNG-gu | Como orden, significa «espera».
W suara = voz; sonido | su-A-ra | Puede ser la voz de una persona o un sonido.
W jelas = claro/a | JE-las | Describe algo que se oye o se entiende con facilidad.
W salah = equivocado/a; incorrecto/a | SA-lah | Se usa para un nombre o número incorrecto.
W benar = correcto/a | be-NAR | Indica que algo está bien o es correcto.
W untuk = para; a | UN-tuk | Indica a quién va dirigido algo.
W menjawab = contestar; responder | men-JA-wab | Verbo para contestar una llamada o pregunta.
V Una llamada
B Palabras del teléfono | Indonesio | Español

| ponsel | teléfono móvil |
| nomor telepon | número de teléfono |

  > Halo = hola | bisa bicara = poder hablar | dengan Rina = con Rina

  > Maaf = lo siento | Rina tidak ada = Rina no está

  > Saya Nina = soy Nina | teman Rina = amiga de Rina

  > Tunggu sebentar = espera un momento | saya panggil Rina = llamo a Rina

  > Halo = hola | ini Rina = soy Rina
Nina: Ini Nina. Ada pesan untuk kamu. = Soy Nina. Hay un mensaje para ti.
  > Ini Nina = soy Nina | ada pesan = hay un mensaje | untuk kamu = para ti
Rina: Ya, suara kamu jelas. = Sí, tu voz se oye clara.
  > Ya = sí | suara kamu = tu voz | jelas = clara
Nina: Terima kasih. Saya menelepon kamu. = Gracias. Te llamo por teléfono.
  > Terima kasih = gracias | saya menelepon kamu = te llamo por teléfono
Q Bisa bicara dengan Rina? :: Elige la traducción correcta.
+ ¿Puedo hablar con Rina? :: Es una forma cortés de pedir hablar con alguien.
- ¿Puedo llamar a Sari? :: «Menelepon» significa llamar por teléfono.
- ¿Puedo esperar a Rina? :: «Tunggu» significa esperar.

+ Espera un momento. :: «Sebentar» es un momento breve.
- Llama a Rina. :: «Panggil Rina» significa llama a Rina.
- Contesta el teléfono. :: «Menjawab telepon» significa contestar el teléfono.

+ Clara. :: «Jelas» significa claro/a.
- Equivocada. :: «Salah» significa equivocado/a.
- Correcta. :: «Benar» significa correcto/a.
O Nomor ponsel Rina :: El número de móvil de Rina :: «Nomor» es número y «ponsel», móvil.
H Nomor telepon ini ___. :: Completa «Este número de teléfono es incorrecto».
+ salah :: «Salah» significa incorrecto.
- benar :: «Benar» significa correcto.
- jelas :: «Jelas» significa claro.

+ Llamada :: «Panggilan» es llamada.
- Número :: «Nomor» es número.
- Voz :: «Suara» es voz.
R Saya menjawab telepon. :: Traduce la frase.
+ Contesto el teléfono. :: «Menjawab» significa contestar.
- Llamo por teléfono. :: «Menelepon» significa llamar.
- Espero un momento. :: «Tunggu sebentar» significa espera un momento.

+ Llama a Rina por teléfono. :: «Menelepon» es llamar por teléfono.
- Espera a Rina. :: «Tunggu» significa esperar.
- Contesta una llamada. :: «Menjawab» significa contestar.

@ 8 | Sudah dan belum | Ya y todavía no
I **Sudah**, **belum**, **sedang** y **akan** van antes del verbo. Indican si algo ya ocurrió, no ha ocurrido, está ocurriendo o ocurrirá.
E Cuatro momentos :: **Sudah**: ya; **belum**: todavía no; **sedang**: ahora mismo; **akan**: más adelante.
E Verbos con meN- :: **Kirim → mengirim** («enviar») y **balas → membalas** («responder») son formas de acción. El marcador de tiempo va antes del verbo.
W sudah = ya; ya está | SU-dah | Indica que algo ya ocurrió o quedó hecho.
W belum = todavía no; aún no | be-LUM | Indica que algo no ha ocurrido hasta ahora.
W akan = irá a; va a | A-kan | Colocado antes del verbo, indica una acción futura.
W sedang = estar haciendo ahora | se-DANG | Va antes de una acción que está ocurriendo.
W kirim = enviar | KI-rim | Base del verbo «mengirim».
W mengirim = enviar; mandar | meng-GI-rim | Verbo de acción formado con meN-.
W terima = recibir; aceptar | te-RI-ma | También aparece en la expresión «terima kasih».
W menerima = recibir | me-ne-RI-ma | Verbo de acción formado con meN-.
W balas = respuesta; responder | BA-las | Base relacionada con «membalas».
W membalas = responder; contestar | mem-BA-las | Contestar un mensaje o una carta.
W surat = carta; escrito | SU-rat | Texto enviado a una persona.
W naskah = guion; manuscrito | NAS-kah | Texto preparado para una obra o actividad.
W pos-el = correo electrónico | POS-el | Forma abreviada de «pos elektronik».
V Mensajes enviados y recibidos
B Marcador | Ejemplo | Español
| sudah | sudah mengirim | ya envió |
| belum | belum menerima | todavía no recibió |
| sedang | sedang membaca | está leyendo |
| akan | akan membalas | responderá |
D Mensajes y tareas
Nina: Kamu sudah mengirim surat? = ¿Ya enviaste la carta?
  > Kamu sudah mengirim = ya enviaste | surat = la carta
Rina: Ya, saya sudah mengirim naskah. = Sí, ya envié el guion.
  > Ya = sí | saya sudah mengirim = ya envié | naskah = el guion
Nina: Kamu sudah menerima surat saya? = ¿Ya recibiste mi carta?
  > Kamu sudah menerima = ya recibiste | surat saya = mi carta
Rina: Belum. Saya belum menerima surat. = Todavía no. Aún no recibí la carta.
  > Belum = todavía no | saya belum menerima = aún no recibí | surat = la carta
Nina: Kamu sedang menulis surat? = ¿Estás escribiendo una carta?
  > Kamu sedang menulis = estás escribiendo | surat = una carta
Rina: Ya, saya sedang menulis. = Sí, estoy escribiendo.
  > Ya = sí | saya sedang menulis = estoy escribiendo
Nina: Kamu akan mengirim pos-el? = ¿Vas a enviar un correo electrónico?
  > Kamu akan mengirim = vas a enviar | pos-el = correo electrónico
Rina: Ya, saya akan membalas pesan. = Sí, responderé el mensaje.
  > Ya = sí | saya akan membalas = responderé | pesan = el mensaje
Q Saya sudah mengirim naskah. :: Elige la traducción correcta.
+ Ya envié el guion. :: «Sudah» indica que la acción se completó.
- Todavía no envié el guion. :: «Belum» significa todavía no.
- Estoy enviando el guion ahora. :: «Sedang» indica una acción en curso.
R Saya belum menerima surat. :: Traduce la frase.
+ Todavía no recibí la carta. :: «Belum» significa todavía no.
- Ya recibí la carta. :: «Sudah» significa ya.
- Voy a enviar la carta. :: «Akan mengirim» significa va a enviar.
A Nina sedang menulis surat. :: ¿Qué está haciendo Nina?
+ Está escribiendo una carta. :: «Sedang» indica que la acción ocurre ahora.
- Ya envió una carta. :: «Sudah mengirim» significa ya envió.
- Va a responder una carta. :: «Akan membalas» significa va a responder.
O Saya akan membalas pesan :: Voy a responder el mensaje :: «Akan» va antes del verbo para hablar del futuro.
H Saya ___ mengirim surat. :: Completa «Todavía no envío la carta».
+ belum :: «Belum» significa todavía no.
- sudah :: «Sudah» significa ya.
- sedang :: «Sedang» indica que ocurre ahora.
Q ¿Qué marcador indica una acción en curso? :: Elige la respuesta correcta.
+ sedang :: «Sedang» indica que algo está ocurriendo ahora.
- akan :: «Akan» indica una acción futura.
- sudah :: «Sudah» indica que ya ocurrió.
R Kamu akan mengirim pos-el. :: Traduce la frase.
+ Vas a enviar un correo electrónico. :: «Akan» expresa futuro.
- Ya enviaste un correo electrónico. :: «Sudah» expresa una acción completada.
- Todavía no recibiste un correo electrónico. :: «Belum menerima» significa todavía no recibió.
A Saya menerima surat. :: ¿Qué hace la persona?
+ Recibe una carta. :: «Menerima» significa recibir.
- Envía una carta. :: «Mengirim» significa enviar.
- Responde una carta. :: «Membalas» significa responder.

@ 8 | Surat pribadi | Cartas personales
I En una carta cercana puedes empezar con **Hai, Sahabatku** («Hola, amigo/a») y despedirte con **Salam sayang** («con cariño»). El saludo cambia según la relación.
E Partes de una carta :: **Pembuka** es la apertura, **isi**, el contenido, y **penutup**, el cierre. **Pengirim** es quien envía; **penerima**, quien recibe.
E Saludos :: **Sahabatku** es una forma cariñosa de dirigirse a un amigo o amiga. **Dengan hormat** es un saludo respetuoso y formal.
W pribadi = personal | pri-BA-di | Describe una carta para una persona cercana.
W sahabat = amigo/a cercano/a | sa-HA-bat | Amistad cercana.
W sahabatku = mi querido/a amigo/a | sa-HA-bat-ku | «-Ku» expresa mi.
W pengirim = remitente | peng-I-rim | Persona que envía una carta o mensaje.
W penerima = destinatario/a | pe-ne-RI-ma | Persona que recibe una carta o mensaje.
W salam = saludo; saludos | sa-LAM | Fórmula de saludo o despedida.
W hormat = respeto | HOR-mat | Aparece en saludos formales.
W sayang = cariño; querido/a | SA-yang | Expresa afecto.
W pembuka = apertura; inicio | pem-BU-ka | Parte inicial de una carta o texto.
W isi = contenido | I-si | Parte principal de un mensaje o escrito.
W penutup = cierre; final | pe-NU-tup | Parte final de una carta o texto.
W bahasa = lengua; idioma | ba-HA-sa | En «bahasa Indonesia» significa idioma indonesio.
W bulan = mes; luna | BU-lan | El contexto indica si se refiere al mes o a la luna.
W liburan = vacaciones; viaje de vacaciones | li-BU-ran | Tiempo de descanso o viaje.
W cerita = historia; relato | che-RI-ta | Relato sobre algo que pasó o se imagina.
W tentang = sobre; acerca de | ten-TANG | Introduce el tema de algo.
V Escribir a un amigo
B Partes de una carta | Indonesio | Función
| Hai, Sahabatku | saludo inicial |
| pembuka | apertura |
| isi | contenido |
| penutup | cierre |

T Carta de Nina
- Hai, Sahabatku. Apa kabar? = Hola, amigo/a. ¿Cómo estás?
  > Hai = hola | Sahabatku = amigo/a mío/a | Apa kabar = ¿cómo estás?
- Saya sedang belajar bahasa Indonesia. = Estoy aprendiendo indonesio.
  > Saya sedang belajar = estoy aprendiendo | bahasa Indonesia = idioma indonesio
- Bulan depan saya akan pergi ke Jakarta. = El mes que viene iré a Yakarta.
  > Bulan depan = el mes que viene | saya akan pergi = iré | ke Jakarta = a Yakarta
- Saya akan menulis cerita tentang liburan saya. = Escribiré un relato sobre mis vacaciones.
  > Saya akan menulis = escribiré | cerita tentang liburan saya = un relato sobre mis vacaciones
- Salam sayang, Nina. = Con cariño, Nina.
  > Salam sayang = con cariño | Nina = Nina
Q Hai, Sahabatku. :: Elige la traducción correcta.
+ Hola, amigo/a. :: «Sahabatku» es una forma cercana de saludar a un amigo.
- Buenos días, señor/a. :: «Selamat pagi» son buenos días.
- Hasta luego, amigo/a. :: «Sampai jumpa» significa hasta luego.
R Pengirim surat itu Nina. :: Traduce la frase.
+ Nina es la remitente de la carta. :: «Pengirim» es quien envía.
- Nina es la destinataria de la carta. :: «Penerima» es quien recibe.
- Nina escribe el cierre de la carta. :: «Penutup» significa cierre.
A Saya sedang belajar bahasa Indonesia. :: ¿Qué está haciendo Nina?
+ Está aprendiendo indonesio. :: «Sedang belajar» indica una actividad en curso.
- Ya envió una carta. :: «Sudah mengirim surat» significa ya envió una carta.
- Va a viajar el mes que viene. :: «Akan pergi bulan depan» significa que irá el próximo mes.
O Salam sayang :: Con cariño :: Despedida afectuosa para alguien cercano.
H Surat ___ untuk Rina. :: Completa «Carta personal para Rina».
+ pribadi :: «Pribadi» significa personal.
- hormat :: «Hormat» significa respeto.
- penutup :: «Penutup» significa cierre.
Q ¿Quién es el «penerima»? :: Elige la respuesta correcta.
+ La persona que recibe la carta. :: «Penerima» es quien recibe.
- La persona que envía la carta. :: «Pengirim» es quien envía.
- La parte final de la carta. :: «Penutup» es el cierre.
R Bulan depan saya akan pergi ke Jakarta. :: Traduce la frase.
+ El mes que viene iré a Yakarta. :: «Bulan depan» significa el mes que viene.
- El mes pasado fui a Yakarta. :: «Bulan lalu» sería el mes pasado.
- Hoy estoy en Yakarta. :: «Hari ini» significa hoy.
A Salam hormat. :: ¿Qué tipo de despedida es?
+ Respetuosa y formal. :: «Hormat» significa respeto.
- Cariñosa e informal. :: «Salam sayang» es afectuosa.
- Una pregunta por el destinatario. :: «Penerima» significa destinatario.
