@ 19 | Di perpustakaan | En la biblioteca
I En una biblioteca, **meminjam** significa llevarse un libro temporalmente; **mengembalikan**, devolverlo. Un aviso puede indicar cuántos libros se prestan y por cuánto tiempo.
E Ser miembro :: **Menjadi anggota perpustakaan** significa hacerse socio de la biblioteca. **Daftar dahulu** es «inscríbete primero».
E Plazos y multas :: **Batas waktu** es el plazo máximo. **Terlambat** significa llegar o devolver algo tarde; **denda** es la multa.
W perpustakaan = biblioteca | per-pus-ta-KA-an | Lugar donde se consultan o prestan libros.
W anggota = miembro; socio/a | ang-GO-ta | Persona inscrita en una organización o biblioteca.
W meminjam = tomar prestado | me-min-JAM | Llevar algo temporalmente y devolverlo después.
W mengembalikan = devolver | meng-em-ba-LI-kan | Entregar de nuevo algo que se había tomado prestado.
W rak = estante | RAK | Repisa donde se ordenan libros u otros objetos.
W prosedur = procedimiento | pro-se-DUR | Serie de pasos para realizar algo.
W maksimal = como máximo | MAK-si-mal | Indica el límite superior de una cantidad.
W batas waktu = plazo; límite de tiempo | BA-tas WAK-tu | Tiempo máximo para completar o devolver algo.
W denda = multa | DEN-da | Dinero que se paga por incumplir una regla.
W terlambat = tarde; con retraso | ter-lam-BAT | Indica que algo ocurre después de la hora o fecha indicada.
W dahulu = primero; antes | da-HU-lu | Sitúa una acción antes que otra.
W buku = libro | BU-ku | Obra escrita que se consulta o se toma prestada.
W tari = baile; danza | TA-ri | Arte de realizar movimientos al ritmo de la música.
W berarti = significar; querer decir | ber-AR-ti | Introduce el sentido de una palabra o frase.
V Pedir libros prestados
D En la biblioteca
Nina: Saya ingin mencari buku tentang tari tradisional. = Quiero buscar un libro sobre danza tradicional.
  > Saya ingin mencari buku = quiero buscar un libro | tentang tari tradisional = sobre danza tradicional
Rina: Buku itu ada di rak sebelah kanan. = Ese libro está en el estante de la derecha.
  > Buku itu ada = ese libro está | di rak sebelah kanan = en el estante de la derecha
Nina: Bagaimana prosedur meminjam buku? = ¿Cuál es el procedimiento para tomar prestado un libro?
  > Bagaimana prosedur = cuál es el procedimiento | meminjam buku = para tomar prestado un libro
Rina: Sudah menjadi anggota perpustakaan? = ¿Ya eres miembro de la biblioteca?
  > Sudah menjadi anggota = ya eres miembro | perpustakaan = de la biblioteca
Nina: Belum. = Todavía no.
  > Belum = todavía no
Rina: Daftar dahulu menjadi anggota. = Inscríbete primero para hacerte miembro.
  > Daftar dahulu = inscríbete primero | menjadi anggota = para hacerte miembro
Nina: Anggota boleh meminjam maksimal tiga buku? = ¿Los miembros pueden tomar prestados como máximo tres libros?
  > Anggota boleh meminjam = los miembros pueden tomar prestados | maksimal tiga buku = como máximo tres libros
Rina: Ya. Batas waktu satu minggu. = Sí. El plazo es de una semana.
  > Ya = sí | batas waktu = el plazo | satu minggu = una semana
T Reglas de préstamo
- Anggota perpustakaan boleh meminjam maksimal tiga buku. = Los miembros de la biblioteca pueden tomar prestados como máximo tres libros.
  > Anggota perpustakaan = los miembros de la biblioteca | boleh meminjam = pueden tomar prestados | maksimal tiga buku = como máximo tres libros
- Batas waktu satu minggu. = El plazo es de una semana.
  > Batas waktu = el plazo | satu minggu = una semana
- Terlambat mengembalikan buku berarti membayar denda. = Devolver el libro tarde significa pagar una multa.
  > Terlambat mengembalikan buku = devolver el libro tarde | berarti membayar denda = significa pagar una multa
- Rak buku ada di sebelah kanan. = El estante de libros está a la derecha.
  > Rak buku = el estante de libros | ada di sebelah kanan = está a la derecha
Q ¿Qué significa «denda»?
+ Multa. :: Es el dinero que se paga por incumplir una regla.
- Estante. :: «Rak» significa estante.
- Socio de una biblioteca. :: «Anggota» significa miembro.
R Saya ingin mencari buku tentang tari tradisional. :: Traduce la frase.
+ Quiero buscar un libro sobre danza tradicional. :: «Mencari» significa buscar.
- Quiero devolver un libro de la biblioteca. :: «Mengembalikan» significa devolver.
- Quiero inscribirme primero. :: Eso sería «Daftar dahulu».
H Daftar ___ menjadi anggota. :: Completa «Inscríbete primero para hacerte miembro».
+ dahulu :: «Dahulu» significa primero o antes.
- maksimal :: «Maksimal» significa como máximo.
- terlambat :: «Terlambat» significa tarde o con retraso.
A Buku itu ada di rak sebelah kanan. :: ¿Dónde está el libro?
+ En el estante de la derecha. :: «Sebelah kanan» significa lado derecho.
- En la biblioteca regional. :: La frase no da ese lugar.
- En la entrada de la escuela. :: No se menciona la escuela.
O Anggota boleh meminjam maksimal tiga buku :: Los miembros pueden tomar prestados como máximo tres libros :: «Maksimal» indica el límite superior.
Q ¿Qué significa «mengembalikan»?
+ Devolver. :: Se entrega de nuevo lo que se tomó prestado.
- Tomar prestado. :: «Meminjam» significa tomar prestado.
- Inscribirse. :: «Daftar dahulu» significa inscríbete primero.
R Batas waktu satu minggu. :: Traduce la regla.
+ El plazo es de una semana. :: «Batas waktu» es el límite de tiempo.
- La multa es de una semana. :: «Denda» significa multa.
- El estante está a la derecha. :: «Rak sebelah kanan» significa estante de la derecha.
A Terlambat mengembalikan buku berarti membayar denda. :: ¿Qué ocurre si se devuelve tarde un libro?
+ Se paga una multa. :: «Terlambat» es tarde y «denda», multa.
- Se puede tomar otro libro gratis. :: La frase no lo indica.
- Hay que inscribirse otra vez. :: La frase habla de devolverlo tarde.
@ 19 | Pakaian adat | Ropa tradicional
I Indonesia reúne muchos grupos étnicos y tradiciones. Cada grupo tiene sus propias prendas tradicionales.
E Materiales :: **Berbahan kulit tanaman** significa «hecho con piel de planta». **Berbahan** describe el material del que está hecho un objeto.
E Partes de la ropa :: **Penutup kepala** es una prenda que cubre la cabeza; **hiasan** es un adorno. El significado de la ropa varía según el grupo y el contexto.
W suku = grupo étnico | SU-ku | Comunidad que comparte origen, cultura o historia.
W adat = costumbre; tradicional | A-dat | Práctica o norma que forma parte de una tradición.
W pakaian = ropa; prenda | pa-KA-i-an | Nombre general para las prendas de vestir.
W rompi = chaleco | ROM-pi | Prenda exterior sin mangas.
W kulit = piel; cuero | KU-lit | Capa exterior de un cuerpo o material de cuero.
W tanaman = planta | ta-NA-man | Ser vivo que crece en la tierra y no se desplaza.
W bahan alami = material natural | BA-han a-LA-mi | Material que procede de la naturaleza.
W penutup kepala = tocado; prenda para cubrir la cabeza | pe-nu-TUP ke-PA-la | Prenda o pieza que cubre la cabeza.
W hiasan = adorno; decoración | hi-A-san | Objeto que embellece una prenda o lugar.
W bulu = pluma; pelo de animal | BU-lu | Pelo fino o plumas que cubren a ciertos animales.
W burung = ave; pájaro | BU-rung | Animal con plumas y alas.
W manik-manik = cuentas; abalorios | ma-NIK ma-NIK | Bolitas pequeñas que se usan como adorno.
W setagen = faja larga | se-TA-gen | Banda larga de tela que se enrolla alrededor de la cintura.
W kalung = collar | ka-LUNG | Adorno que se lleva alrededor del cuello.
W gelang = pulsera; brazalete | ge-LANG | Adorno que se lleva en la muñeca o el brazo.
W akar = raíz | A-kar | Parte de una planta que crece bajo la tierra.
W berbahan = estar hecho de; fabricado con | ber-BA-han | Forma ber- que indica el material de un objeto.
W terdiri atas = estar compuesto de | ter-DI-ri A-tas | Expresión para enumerar las partes de algo.
W bawahan = prenda de la parte inferior | ba-WA-han | Ropa que cubre la parte inferior del cuerpo.
W baca = leer | BA-ca | Forma básica del verbo «leer».
W bahannya = sus materiales | ba-HAN-nya | «Bahan» con «-nya» expresa «sus materiales».
V Ropa y materiales
D En una exposición cultural
Nina: Apa yang kamu baca? = ¿Qué estás leyendo?
  > Apa yang kamu baca = qué estás leyendo
Rina: Saya membaca tentang pakaian adat. = Estoy leyendo sobre la ropa tradicional.
  > Saya membaca = estoy leyendo | tentang pakaian adat = sobre la ropa tradicional
Nina: Bagaimana pakaian itu? = ¿Cómo es esa ropa?
  > Bagaimana = cómo | pakaian itu = esa ropa
Rina: Pakaian itu terdiri atas rompi dan penutup kepala. = La ropa está compuesta por un chaleco y un tocado.
  > Pakaian itu = esa ropa | terdiri atas rompi dan penutup kepala = está compuesta por un chaleco y un tocado
Nina: Bahannya apa? = ¿De qué material está hecha?
  > Bahannya apa = de qué material está hecha
Rina: Rompi itu berbahan kulit tanaman. = Ese chaleco está hecho de piel de planta.
  > Rompi itu = ese chaleco | berbahan kulit tanaman = está hecho de piel de planta
Nina: Apa hiasan pada penutup kepala? = ¿Qué adorno lleva el tocado?
  > Apa hiasan = qué adorno | pada penutup kepala = en el tocado
Rina: Bulu burung dan manik-manik. = Plumas y cuentas.
  > Bulu burung = plumas | dan manik-manik = y cuentas
T Adornos tradicionales
- Pakaian adat itu memakai setagen dan bawahan. = Esa ropa tradicional lleva una faja y una prenda inferior.
  > Pakaian adat itu = esa ropa tradicional | memakai setagen dan bawahan = lleva una faja y una prenda inferior
- Kalung dan gelang berasal dari akar. = El collar y la pulsera están hechos de raíces.
  > Kalung dan gelang = el collar y la pulsera | berasal dari akar = están hechos de raíces
- Bahan alami menjadi hiasan pakaian. = Los materiales naturales se convierten en adornos de la ropa.
  > Bahan alami = material natural | menjadi hiasan pakaian = se convierte en adorno de la ropa
Q ¿Qué significa «rompi»?
+ Chaleco. :: Es una prenda exterior sin mangas.
- Collar. :: «Kalung» significa collar.
- Faja larga. :: «Setagen» es una faja larga.
R Pakaian itu terdiri atas rompi dan penutup kepala. :: Traduce la frase.
+ La ropa está compuesta por un chaleco y un tocado. :: «Terdiri atas» introduce las partes.
- El chaleco está hecho de cuentas. :: La frase enumera dos prendas.
- La ropa lleva un collar y una pulsera. :: Esa frase sería «Pakaian memakai kalung dan gelang».
H Rompi itu berbahan kulit ___. :: Completa «Ese chaleco está hecho de piel de planta».
+ tanaman :: «Kulit tanaman» significa piel de planta.
- burung :: «Bulu burung» significa plumas de ave.
- akar :: «Akar» significa raíz.
A Bulu burung dan manik-manik. :: ¿Qué se usa como adorno?
+ Plumas de ave y cuentas. :: Ambas palabras nombran adornos.
- Una faja y una prenda inferior. :: Eso sería «setagen dan bawahan».
- Un chaleco y una raíz. :: La respuesta habla de plumas y cuentas.
O Pakaian adat itu memakai setagen dan bawahan :: Esa ropa tradicional lleva una faja y una prenda inferior :: «Bawahan» es una prenda para la parte inferior del cuerpo.
Q ¿Qué significa «hiasan»?
+ Adorno. :: Es algo que embellece una prenda o un objeto.
- Material natural. :: «Bahan alami» significa material natural.
- Grupo étnico. :: «Suku» significa grupo étnico.
R Kalung dan gelang berasal dari akar. :: Traduce la frase.
+ El collar y la pulsera están hechos de raíces. :: «Akar» significa raíz.
- La pulsera está hecha de plumas. :: «Bulu» significa pluma o pelo de animal.
- El chaleco está hecho de una planta. :: Esa frase sería «Rompi itu berbahan kulit tanaman».
A Pakaian adat. :: ¿A qué se refiere la expresión?
+ A la ropa tradicional de un grupo étnico. :: «Suku» es grupo étnico y «adat» es tradición.
- A la ropa deportiva escolar. :: La expresión habla de ropa tradicional.
- A una joya hecha de cuentas. :: Esa joya se describe como «manik-manik».
@ 19 | Tarian dan akhiran -an | Danzas y terminación -an
I El sufijo **-an** puede formar nombres de lugares o de instrumentos. No tiene una única traducción fija: el sentido depende de la palabra.
E Lugares e instrumentos :: **Lapangan** y **kubangan** nombran lugares; **timbangan** y **meteran**, instrumentos. En español cambia la palabra completa: campo, charco, báscula y cinta métrica.
E Bailes :: **Gerakan** es un movimiento y **penari**, la persona que baila. Las direcciones llevan **ke**: **ke depan**, hacia delante; **ke kiri**, hacia la izquierda.
W karnaval = carnaval | kar-na-VAL | Desfile o celebración pública.
W gerakan = movimiento; movimiento corporal | ge-RA-kan | Acción de mover el cuerpo o una parte.
W melompat = saltar | me-lom-PAT | Elevarse del suelo con un impulso.
W ke depan = hacia delante | ke de-PAN | Dirección hacia la parte frontal.
W ke belakang = hacia atrás | ke be-la-KANG | Dirección hacia la parte posterior.
W ke kiri = hacia la izquierda | ke KI-ri | Dirección del lado izquierdo.
W ke kanan = hacia la derecha | ke KA-nan | Dirección del lado derecho.
W panggung = escenario | PANG-gung | Plataforma donde actúan artistas.
W penari = bailarín; bailarina | pe-NA-ri | Persona que baila.
W bermakna = tener el significado de | ber-MAK-na | Se usa para explicar qué expresa una palabra.
W kubangan = charco; hoyo embarrado | ku-BANG-an | Hueco del terreno que suele acumular agua o barro.
W timbangan = báscula; balanza | tim-BANG-an | Instrumento para pesar.
W meteran = cinta métrica | me-te-RAN | Instrumento para medir longitudes.
W terbuka = abierto; despejado | ter-BU-ka | Sin cerrar o sin obstáculos.
W lapang = amplio; despejado | LA-pang | Con espacio libre y abierto.
W berisi = contener; estar lleno de | be-RI-si | Indica qué hay dentro de algo.
W air = agua | A-ir | Líquido que se bebe y que puede acumularse en un charco.
V Bailes y significados

  > Kamu pernah melihat = has visto alguna vez | tarian tradisional = una danza tradicional | saat karnaval = durante un carnaval
Rina: Pernah. Ada gerakan melompat ke depan dan ke belakang. = Sí. Hay movimientos de saltar hacia delante y hacia atrás.
  > Pernah = sí, alguna vez | Ada gerakan melompat = hay movimientos de saltar | ke depan dan ke belakang = hacia delante y hacia atrás
Nina: Bagaimana gerakan penari di panggung? = ¿Cómo son los movimientos de los bailarines en el escenario?
  > Bagaimana gerakan penari = cómo son los movimientos de los bailarines | di panggung = en el escenario
Rina: Penari bergerak ke kiri dan ke kanan. = Los bailarines se mueven hacia la izquierda y hacia la derecha.
  > Penari bergerak = los bailarines se mueven | ke kiri dan ke kanan = hacia la izquierda y hacia la derecha
T Lugares e instrumentos
- Lapangan bermakna tempat terbuka. = «Lapangan» significa un lugar abierto.
  > Lapangan bermakna = significa «lapangan» | tempat terbuka = lugar abierto
- Kubangan berisi air. = El charco contiene agua.
  > Kubangan = el charco | berisi air = contiene agua

  > Timbangan = la báscula | adalah alat = es un instrumento | untuk menimbang barang = para pesar artículos
- Meteran adalah alat untuk mengukur panjang. = La cinta métrica es un instrumento para medir la longitud.
  > Meteran = la cinta métrica | adalah alat = es un instrumento | untuk mengukur panjang = para medir la longitud
Q ¿Qué significa «timbangan»?
+ Báscula o balanza. :: Es un instrumento para pesar.
- Cinta métrica. :: «Meteran» sirve para medir longitudes.
- Charco. :: «Kubangan» es un charco u hoyo embarrado.
R Ada gerakan melompat ke depan dan ke belakang. :: Traduce la frase.
+ Hay movimientos de saltar hacia delante y hacia atrás. :: «Ke depan» y «ke belakang» indican dirección.
- Hay bailarines en el escenario. :: Esa idea sería «Penari di panggung».
- El instrumento mide la longitud. :: Esa idea sería «Meteran mengukur panjang».
H ___ bermakna tempat terbuka. :: Completa «El campo significa un lugar abierto».
+ Lapangan :: En este ejemplo, el sufijo de «lapangan» forma el nombre de un lugar.
- Meteran :: Es un instrumento para medir.
- Kubangan :: Es un charco u hoyo embarrado.
A Penari bergerak ke kiri dan ke kanan. :: ¿Hacia dónde se mueven los bailarines?

- Bailarín o bailarina. :: «Penari» nombra a la persona que baila.
- Carnaval. :: «Karnaval» es una celebración pública.
R Kubangan berisi air. :: Traduce la frase.
+ El charco contiene agua. :: «Berisi» significa contener.
- La báscula pesa artículos. :: Eso sería «Timbangan untuk menimbang barang».
- El campo está abierto. :: Esa idea sería «Lapangan terbuka».
A Lapangan bermakna tempat terbuka. :: ¿Qué expresa aquí el sufijo «-an»?
+ Un lugar. :: «Lapangan» nombra un espacio abierto.
- Un instrumento para pesar. :: Ese significado aparece en «timbangan».
- Una persona que baila. :: «Penari» es el nombre de la persona.
