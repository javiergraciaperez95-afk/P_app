@ 32 | Pendapat dengan santun | Opinar con cortesía
I Una carta pública permite explicar una experiencia y responder a otras opiniones con respeto.
E Acordar y discrepar :: **Sependapat** y **sejalan** expresan que compartes una opinión. **Keberatan dengan** introduce una objeción; conviene explicar el motivo sin atacar a quien piensa distinto. :: El indonesio no usa una forma verbal distinta para «yo» y «ella»: el contexto identifica a la persona.
E Cortesía en una carta :: Una crítica puede ser firme y a la vez **santun**. La **kesantunan** depende de la elección de palabras y de cómo se presenta la petición. Evita expresiones que puedan **menyinggung** a la persona destinataria.
W surat pembaca = carta de lectores; carta al director | SU-rat pem-BA-cha
W surat terbuka = carta abierta | SU-rat ter-BU-ka
W sependapat = estar de acuerdo; compartir una opinión | se-pen-da-PAT
W sejalan = coincidir; estar en sintonía | se-JA-lan
W keberatan = objeción; no estar conforme | ke-be-RA-tan
W kritikan = crítica; comentario crítico | kri-TI-kan
W imbauan = llamamiento; petición pública | im-BAU-an
W masukan = aportación; comentario útil | ma-SU-kan
W pihak terkait = parte implicada | PI-hak ter-KAIT
W ditujukan kepada = estar dirigida a | di-tu-JU-kan ke-PA-da
W menyinggung = ofender; molestar | me-nying-GUNG
W kesantunan = cortesía; respeto al hablar | ke-san-TU-nan
W pilihan kata = elección de palabras | pi-LI-han KA-ta
W santun = cortés; respetuoso | san-TUN
W menyampaikan = expresar; comunicar | me-nyam-PAI-kan
W penulis = autor/a; quien escribe | pe-NU-lis
W redaksi = redacción; equipo editorial | re-DAK-si
W tertentu = determinado; concreto | ter-TEN-tu
V Vocabulario: opiniones y cortesía
D Un comentario respetuoso
Sari: Surat pembaca itu ditujukan kepada pihak terkait. = Esa carta de lectores está dirigida a la parte implicada.
  > surat pembaca itu = esa carta de lectores | ditujukan kepada pihak terkait = está dirigida a la parte implicada
Budi: Saya sependapat dengan tujuan penulis. = Estoy de acuerdo con el objetivo del autor.
  > sependapat dengan = estar de acuerdo con | tujuan penulis = objetivo del autor
Sari: Saya juga sejalan dengan imbauan warga. = También coincido con el llamamiento de los vecinos.
  > sejalan dengan = coincidir con | imbauan warga = llamamiento de los vecinos
Budi: Tetapi, saya keberatan dengan pilihan kata tertentu. = Sin embargo, no estoy conforme con ciertas palabras.
  > keberatan dengan = no estar conforme con | pilihan kata tertentu = ciertas palabras
Sari: Kritikan yang santun tidak menyinggung pihak terkait. = Una crítica respetuosa no ofende a la parte implicada.
  > kritikan yang santun = crítica respetuosa | tidak menyinggung pihak terkait = no ofende a la parte implicada
Budi: Masukan itu membantu redaksi membuat surat terbuka lebih jelas. = Esa aportación ayuda a la redacción a hacer más clara la carta abierta.
  > masukan itu = esa aportación | redaksi = redacción | surat terbuka = carta abierta
Sari: Penulis menyampaikan pendapat dengan kesantunan. = El autor expresa su opinión con cortesía.
  > menyampaikan pendapat = expresar una opinión | dengan kesantunan = con cortesía
Q ¿Qué expresión indica que compartes una opinión?
+ sependapat :: Significa estar de acuerdo con una opinión.
- keberatan :: Expresa una objeción.
- menyinggung :: Significa ofender o molestar.
R Saya sejalan dengan imbauan warga. :: ¿Qué significa?
+ Coincido con el llamamiento de los vecinos. :: «Sejalan dengan» indica coincidencia.
- Me opongo a la carta de los vecinos. :: La frase indica acuerdo.
- La redacción ofende a los vecinos. :: Esa acción no aparece en la frase.
H Kritikan yang ___ tidak menyinggung pihak terkait. :: Completa con «respetuosa».
+ santun :: Describe una forma cortés de expresarse.
- tertentu :: Significa determinado o concreto.
- terbuka :: Significa abierto.
A Saya keberatan dengan pilihan kata tertentu. :: ¿Qué expresa quien habla?
+ Una objeción a ciertas palabras. :: «Keberatan dengan» introduce una objeción.
- Una felicitación al equipo editorial. :: La frase expresa desacuerdo.
- Una invitación a escribir una carta abierta. :: La frase no invita a escribir.
O Penulis menyampaikan pendapat dengan santun :: El autor expresa su opinión con cortesía :: «Santun» describe el tono de la comunicación.
Q ¿Qué significa masukan?
+ aportación o comentario útil :: Es una contribución que puede ayudar a mejorar algo.
- una parte implicada :: Eso es «pihak terkait».
- una objeción formal :: Eso puede expresarse con «keberatan».
H Surat pembaca itu ditujukan kepada pihak ___. :: Completa con «implicada».
+ terkait :: «Pihak terkait» es la parte implicada.
- santun :: Significa cortés.
- sejalan :: Significa coincidir.
R Kritikan yang santun tidak menyinggung pihak terkait. :: Traduce la frase.
+ Una crítica respetuosa no ofende a la parte implicada. :: «Menyinggung» es ofender o molestar.
- Una carta abierta siempre ofende a su autor. :: La frase expresa lo contrario.
- La redacción comparte una crítica con sus lectores. :: Esa acción no aparece aquí.

@ 32 | Kata ulang dalam konteks | La reduplicación en contexto
E Acciones repetidas :: **Berkali-kali**, **berteriak-teriak** y **memanggil-manggil** expresan repetición. La base puede repetirse sola o junto con un afijo. :: No traduzcas cada reduplicación automáticamente como plural: su función depende de la forma y del contexto.
E Conjuntos y variedad :: **Dedaunan** y **pepohonan** pueden referirse a muchos elementos del conjunto. **Sayur-mayur** y **lauk-pauk** nombran variedades; el cambio de sonido forma parte de esas expresiones.

T En el barrio
- Warga berkali-kali mengirim surat pembaca. = Los vecinos enviaron cartas de lectores muchas veces.
  > berkali-kali = muchas veces | mengirim surat pembaca = enviar cartas de lectores
- Mereka meminta bantuan berulang-ulang. = Pidieron ayuda una y otra vez.
  > meminta bantuan = pidieron ayuda | berulang-ulang = una y otra vez
- Di taman, dedaunan jatuh dari pepohonan. = En el parque, caen hojas de los árboles.
  > dedaunan = hojas; follaje | pepohonan = árboles en conjunto
- Warga berteriak-teriak memanggil-manggil petugas. = Los vecinos gritan y llaman repetidamente al empleado.
  > berteriak-teriak = gritan repetidamente | memanggil-manggil petugas = llaman repetidamente al empleado
- Warung menyediakan sayur-mayur dan lauk-pauk. = El pequeño local ofrece verduras y platos variados para acompañar.
  > menyediakan = ofrece | sayur-mayur = verduras variadas | lauk-pauk = platos variados para acompañar
- Menu di warung itu bermacam-macam. = El menú de ese local es variado.
  > menu di warung itu = el menú de ese local | bermacam-macam = de muchos tipos
- Kata ulang dapat berarti tindakan berulang atau kelompok. = Una palabra reduplicada puede expresar una acción repetida o un conjunto.
  > kata ulang = palabra reduplicada | tindakan berulang = acción repetida | kelompok = conjunto
Q ¿Qué forma expresa que alguien llama muchas veces?
+ memanggil-manggil :: La reduplicación del verbo expresa llamadas repetidas.
- menyediakan :: Significa ofrecer o preparar.
- dedaunan :: Se refiere a muchas hojas.
R Warga berteriak-teriak memanggil-manggil petugas. :: ¿Qué hacen los vecinos?
+ Gritan y llaman repetidamente al empleado. :: Ambas formas expresan acciones repetidas.
- Ofrecen verduras variadas al empleado. :: Eso sería «menyediakan sayur-mayur».
- Caen del parque junto con los árboles. :: No es lo que dice la frase.
H Di taman, ___ jatuh dari pepohonan. :: Completa con «follaje».
+ dedaunan :: Se refiere al conjunto de hojas.
- lauk-pauk :: Son platos variados para acompañar.
- kata dasar :: Es una palabra base.
A Warung menyediakan sayur-mayur dan lauk-pauk. :: ¿Qué ofrece el local?
+ Verduras variadas y platos para acompañar. :: Las dos expresiones nombran variedades de comida.
- Cartas y comentarios editoriales. :: La frase habla de comida.
- Árboles y hojas para una carta. :: No es lo que dice la oración.
O Dedaunan jatuh dari pepohonan :: Caen hojas de los árboles :: Las formas reduplicadas pueden expresar conjuntos.
Q ¿Qué significa berkali-kali?
+ muchas veces :: Indica repetición de una acción.
- una sola vez :: Expresa lo contrario.
- de muchos tipos :: Eso significa «bermacam-macam».
H Menu di warung itu ___ . :: Completa con «de muchos tipos».
+ bermacam-macam :: Nombra variedad.
- berkali-kali :: Indica repetición de una acción.
- berubah bunyi :: Significa cambiar de sonido.
R Kata ulang dapat berarti tindakan berulang atau kelompok. :: ¿Qué puede expresar una reduplicación?
+ Una acción repetida o un conjunto. :: Su función depende de la forma y el contexto.
- Siempre un plural idéntico al español. :: La reduplicación tiene más de una función.
- Solo una acción involuntaria. :: Esa función aparece en ciertos afijos, no en toda reduplicación.

@ 32 | Menulis surat pembaca | Estructurar una carta pública
I Una carta eficaz presenta quién escribe, explica los hechos en orden y formula una petición clara con un tono respetuoso.
E Partes de la carta :: **Identitas pengirim** identifica a quien escribe; **alamat tujuan** indica a quién se dirige el mensaje. En el cuerpo, presenta la cronología y explica qué solución esperas.
E Claridad y publicación :: Mantén la exposición **ringkas** y **runtut**. Una carta pública puede **diterbitkan** para que otras personas conozcan el asunto; por eso la cortesía y los datos verificables importan.
W judul surat = título de la carta | JU-dul SU-rat
W identitas pengirim = identidad del remitente | i-den-TI-tas peng-i-RIM
W dicantumkan = incluirse; anotarse | di-chan-TUM-kan
W alamat tujuan = dirección del destinatario | A-la-mat tu-JU-an
W mengetahui = saber; conocer | me-nge-TA-hu-i
W paragraf pembuka = párrafo inicial | pa-ra-GRAF pem-BU-ka
W kronologi kejadian = cronología de los hechos | kro-no-LO-gi ke-ja-DI-an
W ditulis = escribirse; redactarse | di-TU-lis
W permohonan yang jelas = petición clara | per-mo-HO-nan yang JE-las
W menindaklanjuti = dar seguimiento; tomar medidas después | me-tin-dak-lan-JU-ti
W surat tanggapan = carta de respuesta | SU-rat tang-GA-pan
W jawaban resmi = respuesta oficial | ja-WA-ban res-MI
W diterbitkan = publicarse; ser publicado | di-ter-BIT-kan
W menyertakan bukti = adjuntar pruebas | me-nyer-TA-kan BUK-ti
W ringkas = conciso; breve | RING-kas
W secara runtut = de forma ordenada | se-CHA-ra RUN-tut
W bahasa baku = lengua estándar; registro normativo | ba-HA-sa BA-ku
W tujuan penulisan = propósito del escrito | tu-JU-an pe-NU-li-san
W masalah berulang = problema recurrente | ma-SA-lah be-ru-LANG
W perbaikan jalan = reparación de la carretera | per-ba-I-kan JA-lan
W pembaca = lector/a | pem-BA-cha
V Vocabulario: estructura y seguimiento
T Una carta pública
- Judul surat sebaiknya ringkas dan jelas. = Conviene que el título de la carta sea breve y claro.
  > judul surat = título de la carta | ringkas dan jelas = breve y claro
- Identitas pengirim dicantumkan pada paragraf pembuka. = La identidad del remitente se incluye en el párrafo inicial.
  > identitas pengirim = identidad del remitente | paragraf pembuka = párrafo inicial
- Alamat tujuan membantu redaksi mengetahui penerima surat. = La dirección del destinatario ayuda a la redacción a saber quién recibe la carta.
  > alamat tujuan = dirección del destinatario | mengetahui penerima surat = saber quién recibe la carta
- Kronologi kejadian harus ditulis secara runtut. = La cronología de los hechos debe redactarse de forma ordenada.
  > kronologi kejadian = cronología de los hechos | secara runtut = de forma ordenada
- Penulis menyertakan bukti dan permohonan yang jelas. = El autor adjunta pruebas y una petición clara.
  > menyertakan bukti = adjuntar pruebas | permohonan yang jelas = petición clara
- Redaksi dapat menindaklanjuti masalah berulang itu. = La redacción puede tomar medidas sobre ese problema recurrente.
  > menindaklanjuti = tomar medidas después | masalah berulang itu = ese problema recurrente
- Jika surat diterbitkan, pembaca lain mengetahui peristiwa itu. = Si se publica la carta, otros lectores conocen ese suceso.
  > surat diterbitkan = se publica la carta | pembaca lain = otros lectores | mengetahui peristiwa itu = conocer ese suceso
- Surat tanggapan memberi jawaban resmi kepada pengirim. = La carta de respuesta da una respuesta oficial al remitente.
  > surat tanggapan = carta de respuesta | jawaban resmi = respuesta oficial | kepada pengirim = al remitente
Q ¿Qué parte indica quién escribe la carta?
+ identitas pengirim :: Identifica a quien envía el mensaje.
- alamat tujuan :: Indica a quién se dirige.
- kronologi kejadian :: Ordena lo que ocurrió.
R Kronologi kejadian harus ditulis secara runtut. :: ¿Cómo deben presentarse los hechos?
+ En un orden coherente. :: «Runtut» indica una secuencia ordenada.
- Con palabras que ofendan al destinatario. :: La carta pública debe mantener la cortesía.
- Sin explicar qué ocurrió. :: La cronología presenta los hechos.
H Penulis ___ bukti dan permohonan yang jelas. :: Completa con «adjunta».
+ menyertakan :: Significa incluir o adjuntar.
- diterbitkan :: Significa ser publicado.
- menyinggung :: Significa ofender.

+ Una respuesta oficial. :: «Jawaban resmi» es una respuesta oficial.
- Una lista de verduras. :: Esa expresión es «sayur-mayur».
- Una dirección de carretera. :: La frase habla de una respuesta.
O Identitas pengirim dicantumkan pada paragraf pembuka :: La identidad del remitente se incluye en el párrafo inicial :: El inicio sitúa al lector y presenta a quien escribe.

+ publicarse; ser publicado :: Describe que un escrito aparece para sus lectores.

- adjuntar pruebas :: Eso es «menyertakan bukti».

+ jawaban :: «Jawaban resmi» significa respuesta oficial.
- judul :: Significa título.
- kronologi :: Significa cronología.
R Jika surat diterbitkan, pembaca lain mengetahui peristiwa itu. :: Traduce la frase.
+ Si se publica la carta, otros lectores conocen ese suceso. :: «Diterbitkan» expresa la publicación.
- Si el remitente cambia de dirección, la respuesta se anula. :: La frase no dice eso.
- Si se repite una llamada, la redacción publica una canción. :: Es una interpretación ajena a la frase.
