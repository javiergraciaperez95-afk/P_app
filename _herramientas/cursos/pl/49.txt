@ 49 | Egzamin końcowy A2 | Examen final A2
I Repasa invitaciones, vivienda, comida, salud, trabajo, viajes, servicios, cultura, relatos, tiempo, tecnología y convivencia.
w Cap = capítulo (marcador del examen) | KAP
Q Cap. 25. ¿Qué significa zaproszenie?
+ Invitación. :: Es una propuesta para hacer algo juntos.
- Respuesta. :: Respuesta es odpowiedź.
- Despedida. :: Do widzenia es una despedida.
R Cap. 26. Szukam mieszkania do wynajęcia. :: Traduce al español.
+ Busco un piso en alquiler. :: do wynajęcia aparece en anuncios de alquiler.
- Alquilo un piso amueblado. :: La frase dice que busca vivienda.
- Pago el alquiler mensual. :: No menciona un pago.
Q Cap. 27. ¿Qué expresa smakuje mi?
+ Me gusta el sabor de algo. :: Literalmente significa «me sabe».
- Me gustaría pedir algo. :: Esa petición se expresa con poproszę.
- Tiene un precio bajo. :: La expresión habla del sabor.
H Cap. 28. ___ odpoczywać i dużo pić. :: Completa «Deberías descansar y beber mucho», dirigido a un hombre.
+ Powinieneś :: Es la forma dirigida a un hombre.
- Powinnaś :: Es la forma dirigida a una mujer.
- Powinnam :: Significa «yo debería», dicho por una mujer.
R Cap. 29. Interesuje mnie praca w hotelu. :: Traduce al español.
+ Me interesa el trabajo en un hotel. :: La frase expresa interés por ese trabajo.
- Trabajo en un hotel desde hace dos años. :: La frase no indica duración.
- Busco un puesto de recepcionista. :: No nombra un puesto concreto.
H Cap. 30. Samolot odlatuje o ___. :: Completa «El avión sale a las ocho».
+ ósmej :: La hora va en genitivo tras o.
- ósma :: Es la forma básica femenina.
- ósmy :: Es la forma masculina ordinal.
Q Cap. 31. ¿Qué significa list polecony?
+ Carta certificada. :: Es un servicio postal.
- Paquete al extranjero. :: Paquete es paczka.
- Sello postal. :: Sello es znaczek.
R Cap. 32. Dzielimy się opłatkiem i składamy sobie życzenia. :: Traduce al español.
+ Compartimos la oblea y nos damos buenos deseos. :: Es una costumbre de la Nochebuena polaca.
- Pintamos huevos decorados y comemos dulces. :: Eso describe una costumbre de Pascua.
- Enviamos una carta certificada a la familia. :: La frase menciona una costumbre familiar.
H Cap. 33. W zeszłym tygodniu ___ się z koleżanką. :: Completa «La semana pasada quedé con una amiga».
+ spotkałam :: Es una acción terminada y la hablante es mujer.
- spotykałam :: Describe una acción habitual o en curso.
- spotkałyście :: Significa «vosotras quedasteis».
Q Cap. 34. ¿Qué significa nie wolno?
+ No se permite; está prohibido. :: Va seguido de un infinitivo.
- Hay que. :: Hay que es trzeba.
- Conviene. :: Conviene es warto.
R Cap. 35. Wreszcie znalazłem portfel. :: Traduce al español.
+ Por fin encontré la cartera. :: znalazłem es la forma masculina de «encontré».
- Por fin encontré las llaves. :: La frase dice portfel, «cartera».
- Estaba buscando la cartera. :: La frase narra que ya la encontró.
R Cap. 36. Z czasem zmieniłam zdanie. :: Traduce al español.
+ Con el tiempo cambié de opinión. :: zmieniłam es la forma femenina del pasado.
- Antes no me gustaba el café. :: Esa frase es Kiedyś nie lubiłem kawy.
- Mi vida es diferente. :: Esa frase es Moje życie wygląda inaczej.
Q Cap. 37. ¿Qué frase dice «Mi habitación es más grande»?
+ Mój pokój jest większy. :: większy es el comparativo de grande.
- Mój pokój jest mniejszy. :: mniejszy significa «más pequeño».
- Mój pokój jest droższy. :: droższy significa «más caro».
R Cap. 38. Napisz do mnie jutro. :: Traduce al español.
+ Escríbeme mañana. :: Napisz es el imperativo de «escribir».
- Llámame mañana. :: Llamar es zadzwoń.
- Léeme el mensaje mañana. :: Leer el mensaje es przeczytaj wiadomość.
R Cap. 39. Przeczytałam całą książkę. :: Traduce al español.
+ Terminé de leer todo el libro. :: El perfectivo presenta la lectura como terminada.
- Leía un libro durante una hora. :: Esa acción en curso es Czytałam książkę przez godzinę.
- Estaba leyendo un mensaje a un compañero. :: La frase habla de un libro completo.
R Cap. 40. Chciałabym zarezerwować pokój. :: Traduce al español.
+ Quisiera reservar una habitación. :: La forma chciałabym la dice una mujer.
- Quisiera reservar una mesa. :: Esa frase es Chciałbym zamówić stolik.
- Preferiría pagar con tarjeta. :: Esa frase es Wolałbym zapłacić kartą.
H Cap. 41. Powiedz ___ o zmianie. :: Completa «Háblale del cambio».
+ mu :: Es el pronombre de objeto indirecto «a él».
- mi :: Significa «a mí».
- im :: Significa «a ellos».
R Cap. 42. Do piątku muszę wysłać raport. :: Traduce al español.
+ Tengo que enviar el informe antes del viernes. :: do piątku marca el plazo.
- Trabajo desde la mañana hasta la noche. :: Esa frase es Pracuję od rana do wieczora.
- La película empieza dentro de una hora. :: Esa frase es Za godzinę zaczyna się film.
R Cap. 43. Dwie kawy proszę. :: Traduce al español.
+ Dos cafés, por favor. :: Dwie concuerda con el sustantivo femenino kawy.
- Dos billetes, por favor. :: Billetes es bilety.
- Dos personas esperan. :: Personas es osoby.
Q Cap. 44. ¿Qué significa To zależy od sytuacji?
+ Depende de la situación. :: Es una manera de matizar una respuesta.
- Estoy de acuerdo contigo. :: Esa frase es Nie zgadzam się z tobą, en negativo.
- Estoy casi segura de eso. :: Esa frase es Jestem tego prawie pewna.
R Cap. 45. Przepraszam za późną odpowiedź. :: Traduce al español.
+ Perdona por responder tarde. :: późną odpowiedź significa «respuesta tardía».
- Gracias por tu mensaje. :: Esa frase es Dziękuję za twoją wiadomość.
- Te escribo para hacerte una pregunta. :: Esa frase es Piszę do ciebie z pytaniem.
R Cap. 46. W urzędzie trzeba pobrać numer. :: Traduce al español.
+ En la oficina hay que sacar un número. :: trzeba expresa necesidad impersonal.
- Se puede pagar con el teléfono. :: Esa opción es Można płacić telefonem.
- No hace falta imprimir el formulario. :: Esa frase es Nie trzeba drukować formularza.
R Cap. 47. Zapisz plik w chmurze. :: Traduce al español.
+ Guarda el archivo en la nube. :: Es una instrucción para guardar un archivo.
- Cambia la contraseña cada mes. :: Esa instrucción es Zmień hasło co miesiąc.
- No hagas clic en un enlace sospechoso. :: Esa instrucción es Nie klikaj w podejrzany link.
R Cap. 48. Wynoszę śmieci co wieczór. :: Traduce al español.
+ Saco la basura cada noche. :: co wieczór expresa frecuencia.
- Limpio la cocina después de cenar. :: Esa frase es Sprzątam kuchnię po kolacji.
- El sábado lavo la ropa de cama. :: Esa frase es W sobotę piorę pościel.
R Cap. 48. Proszę zostawić klucz sąsiadce. :: Traduce al español.
+ Por favor, deje la llave a la vecina. :: proszę + infinitivo formula una petición cortés.
- Por favor, baje la música. :: Esa frase es Proszę ściszyć muzykę.
- Por favor, contacte con la administración. :: Esa frase es Proszę kontaktować się z administracją.
