Q Cap. 50. ¿Qué significa nikt?
+ Nadie. :: nikt expresa ausencia de personas.
- Alguien. :: Alguien es ktoś.
- Cada persona. :: Cada persona es każdy.
R Cap. 50. Nikt nie jest idealny. :: Traduce al español.
+ Nadie es perfecto. :: nikt significa «nadie».
- Alguien es perfecto. :: La oración lo niega.
- Cada persona es impaciente. :: La frase habla de ser perfecto.
H Cap. 51. Szukam kursu, ___ jest dostępny wieczorem. :: Completa «Busco un curso que esté disponible por la tarde».
+ który :: Concuerda con kurs, masculino singular.
- która :: Es la forma femenina.
- które :: No concuerda con kurs.
R Cap. 51. Robię postępy, chociaż polski jest trudny. :: Traduce al español.

Q Cap. 52. ¿Qué expresa «Czy mógłby Pan...»?

- Una pregunta dirigida a una mujer. :: A una mujer se le dice Pani.

Q Cap. 53. ¿Qué indica «kran jest naprawiany»?

- Que el grifo será sustituido mañana. :: Esa acción es zostanie wymienione.

- Hay que cambiar el grifo porque está dañado. :: Esa idea no aparece.
- La avería se comunicó ayer. :: La frase recomienda comprobar el grifo.

H Cap. 55. Należy ___ dużego wysiłku. :: Completa «Hay que evitar un gran esfuerzo».

Q Cap. 56. ¿Qué significa «według redakcji»?

- Según el autor, la noticia ya fue confirmada. :: La oración dice que todavía no se publicó.
- La redacción publicó el artículo hace una semana. :: La frase lo niega.
