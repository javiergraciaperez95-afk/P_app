@ 53 | Naprawy w mieszkaniu | Reparaciones en casa
I Explicamos qué se está reparando y qué ya se ha arreglado.
E Voz pasiva :: En **Kran jest naprawiany**, la acción está en curso; en **Kran został naprawiony**, la reparación ya terminó. :: El participio cambia para concordar con el nombre: **kran naprawiony**, **awaria naprawiona**.
E El agente :: **Przez** introduce a quien realiza la acción: **Winda jest naprawiana przez fachowca** («El ascensor está siendo reparado por un técnico»).
B Reparaciones | Concepto | Polaco | Español

| la avería fue comunicada | awaria została zgłoszona | la avería fue comunicada

V Averías y arreglos
D Una reparación pendiente
Anna: Czy awaria została zgłoszona? = ¿Se comunicó la avería?
> Czy = partícula de pregunta | awaria została zgłoszona = la avería fue comunicada
Tom: Tak. Hydraulik naprawia kran. = Sí. El fontanero está reparando el grifo.
> Tak = sí | hydraulik = fontanero | naprawia = está reparando | kran = grifo
Anna: A gniazdko? = ¿Y el enchufe?
> A = y | gniazdko = enchufe
Tom: Jest uszkodzone, ale jutro zostanie wymienione. = Está dañado, pero mañana será sustituido.
> Jest = está | uszkodzone = dañado | ale = pero | jutro = mañana | zostanie wymienione = será sustituido
Anna: Czy remont jest już zakończony? = ¿La reforma ya está terminada?
> Czy = partícula de pregunta | remont = reforma | jest = está | już = ya | zakończony = terminado
Tom: Nie. Kran jest naprawiany przez fachowca. = No. El grifo está siendo reparado por un técnico.
> Nie = no | kran jest naprawiany = el grifo está siendo reparado | przez fachowca = por un técnico
Q ¿Qué indica «kran jest naprawiany»?
+ Que están reparando el grifo ahora. :: La pasiva con jest naprawiany presenta una acción en curso.
- Que el grifo ya fue reparado. :: La acción terminada sería został naprawiony.
- Que el grifo será cambiado mañana. :: Esa idea aparece con zostanie wymienione.
R Hydraulik naprawia kran. :: Traduce al español.
+ El fontanero está reparando el grifo. :: naprawia presenta la reparación en curso.
- El técnico ya sustituyó el enchufe. :: La frase menciona un grifo.
- El grifo fue comunicado al técnico. :: La oración dice que el fontanero lo está reparando.
H Czy awaria została ___? :: Completa «¿Se comunicó la avería?».
+ zgłoszona :: Es el participio femenino que concuerda con awaria.
- zgłoszony :: Es la forma masculina.
- wymienione :: Es una forma neutra o plural.
A Jest uszkodzone, ale jutro zostanie wymienione. :: ¿Qué pasará mañana?
+ El enchufe será sustituido. :: zostanie wymienione presenta una acción futura pasiva.
- La avería ya fue comunicada. :: Eso ya ocurrió antes.
- El grifo estará reparado hoy. :: La frase habla del enchufe y de mañana.
O Kran jest naprawiany przez fachowca. :: El grifo está siendo reparado por un técnico. :: przez introduce a quien hace la reparación.
X Escribe «avería» en polaco. :: awaria :: Es una interrupción o un fallo técnico.
Q ¿Qué significa uszkodzony?
+ Dañado. :: Describe algo que tiene un desperfecto.
- Terminado. :: Terminado es zakończony.
- Comunicado. :: Comunicado es zgłoszony o zgłoszona.
R Czy remont jest już zakończony? :: Traduce al español.
+ ¿La reforma ya está terminada? :: zakończony significa «terminado».
- ¿Se ha comunicado ya la avería? :: Esa pregunta sería Czy awaria została zgłoszona?
- ¿El grifo está siendo reparado por el técnico? :: Esa pregunta aparece en otra línea.

@ 53 | Rachunki i zużycie | Facturas y consumo
I Comparamos gastos domésticos y explicamos por qué cambian.
E Comparar cantidades :: **Więcej niż** significa «más que» y **mniej niż**, «menos que». :: Para indicar un cambio, usamos **wzrosnąć** («aumentar») o **spaść** («bajar»).
E Consumo :: **Zużycie prądu** es el consumo de electricidad; **rachunek za wodę**, la factura del agua. :: **Przeciekać** significa que un líquido se escapa por una grieta o una unión.

| consumo de agua | zużycie wody | consumo de agua

D Facturas más altas
Anna: Dlaczego rachunek za wodę jest tak wysoki? = ¿Por qué es tan alta la factura del agua?
> Dlaczego = por qué | rachunek za wodę = factura del agua | jest tak wysoki = es tan alta
Tom: Zużycie wzrosło, ponieważ kran przeciekał. = El consumo aumentó porque el grifo tenía una fuga.
> Zużycie wzrosło = el consumo aumentó | ponieważ = porque | kran przeciekał = el grifo tenía una fuga
Anna: Czy można sprawdzić licznik? = ¿Se puede comprobar el contador?
> Czy = partícula de pregunta | można = se puede | sprawdzić = comprobar | licznik = contador
Tom: Tak. Koszty utrzymania są wyższe niż w zeszłym roku. = Sí. Los gastos de mantenimiento son más altos que el año pasado.
> Tak = sí | koszty utrzymania = gastos de mantenimiento | są wyższe niż = son más altos que | w zeszłym roku = el año pasado
Anna: Czy można oszczędzać wodę? = ¿Se puede ahorrar agua?
> Czy = partícula de pregunta | można = se puede | oszczędzać = ahorrar | wodę = agua (acusativo)
Tom: Tak. Warto sprawdzić, czy kran nie przecieka. = Sí. Vale la pena comprobar si el grifo tiene una fuga.
> Tak = sí | warto = vale la pena | sprawdzić = comprobar | czy = si | kran nie przecieka = el grifo no tiene una fuga
Q ¿Qué significa zużycie?
+ Consumo. :: Nombra la cantidad de agua, electricidad u otro recurso utilizado.
- Avería. :: Avería es awaria.
- Factura. :: Factura es rachunek.
R Koszty utrzymania są wyższe niż w zeszłym roku. :: Traduce al español.
+ Los gastos de mantenimiento son más altos que el año pasado. :: wyższe niż expresa «más altos que».
- El consumo de agua bajó este año. :: La frase compara gastos con el año pasado.
- La factura del agua es menos que la electricidad. :: No compara dos facturas.
H Zużycie ___, ponieważ kran przeciekał. :: Completa «El consumo aumentó porque el grifo tenía una fuga».

- oszczędzać :: Significa «ahorrar» y es infinitivo.
A Czy można oszczędzać wodę? :: ¿Qué pregunta Anna?

- Si la factura ya fue pagada. :: No menciona el pago de una factura.

- Cantidad de dinero. :: Cantidad de dinero es kwota.
- Consumo. :: Consumo es zużycie.
R Zużycie wzrosło, ponieważ kran przeciekał. :: Traduce al español.
+ El consumo aumentó porque el grifo tenía una fuga. :: ponieważ introduce la causa.
- El consumo bajó porque ahorramos agua. :: La oración dice que aumentó.
- La factura se pagó después de reparar el grifo. :: Esa información no aparece.

@ 53 | Zasady w budynku | Normas del edificio
I Leemos reglas de convivencia y hacemos peticiones a los vecinos.
E Construcciones impersonales :: **Nie wolno + infinitivo** expresa prohibición; **trzeba + infinitivo**, necesidad. :: **Mówi się**, «se dice», tiene un sujeto general, como el «se» impersonal en español.
E Normas comunes :: **Obowiązuje cisza nocna** significa «hay horario de silencio nocturno». :: En polaco, **cisza nocna** se usa para las horas en que no se debe hacer ruido.
