@ 79 | Ton i intencja | Tono e intención
I Leemos entre líneas y distinguimos una información neutral de una opinión.
E Lenguaje informativo y valorativo :: **Informować** es presentar datos; **oceniać** es expresar una valoración. :: Un texto puede parecer neutral y, aun así, sugerir una postura.
E Interpretar el tono :: **Ironia** consiste en decir algo de forma que el contexto sugiera otro sentido. :: El **podtekst** no se expresa de manera directa, pero el lector puede deducirlo.

D Un comentario sobre un artículo
Anna: Czy przeczytałeś komentarz do artykułu? = ¿Leíste el comentario sobre el artículo?
> Czy przeczytałeś = ¿leíste? | komentarz do artykułu = comentario sobre el artículo

> Redaktor = editor | używa ironii = usa la ironía

> tekst = texto | informuje = informa | także ocenia = también evalúa
Tom: Słownictwo sugeruje krytyczny stosunek autora. = El vocabulario sugiere una actitud crítica del autor.
> Słownictwo = vocabulario | sugeruje = sugiere | krytyczny stosunek autora = actitud crítica del autor
Anna: Warto sprawdzić kontekst i intencję. = Conviene comprobar el contexto y la intención.
> Warto sprawdzić = conviene comprobar | kontekst = contexto | intencję = intención
Tom: Nie każdy odbiorca odczyta podtekst. = No todos los lectores interpretarán el subtexto.
> Nie każdy odbiorca = no todos los lectores | odczyta = interpretará | podtekst = subtexto
Q ¿Qué diferencia hay entre informuje y ocenia?
+ El primero presenta datos y el segundo valora. :: Son funciones distintas del texto.
- Los dos significan «publica». :: Publicar es opublikować.
- El primero pregunta y el segundo responde. :: La diferencia es informar frente a evaluar.
R Redaktor używa ironii. :: Traduce al español.
+ El editor usa la ironía. :: używa ironii significa «usa la ironía».
- El autor evalúa el contexto. :: La frase menciona a un editor.
- El texto presenta una información neutral. :: La frase dice que usa ironía.
H Nie każdy odbiorca ___ podtekst. :: Completa «No todos los lectores interpretarán el subtexto».
+ odczyta :: Es el futuro de «interpretar».
- ocenia :: Significa «evalúa».
- informuje :: Significa «informa».
A Słownictwo sugeruje krytyczny stosunek autora. :: ¿Qué sugiere el vocabulario?
+ Una actitud crítica del autor. :: sugeruje introduce la interpretación.
- Una noticia neutral sin opinión. :: La frase menciona una actitud crítica.
- Que el editor corrigió el comentario. :: No se habla de una corrección.
O Warto sprawdzić kontekst i intencję. :: Conviene comprobar el contexto y la intención. :: warto + infinitivo expresa recomendación.
X Escribe «subtexto» en polaco. :: podtekst :: Es el sentido indirecto que se puede deducir.
Q ¿Qué significa odbiorca?
+ Destinatario o receptor. :: Es quien lee o recibe un mensaje.
- Editor. :: Editor es redaktor.
- Autor. :: Autor es autor.
R Czy tekst tylko informuje, czy także ocenia? :: Traduce al español.
+ ¿El texto solo informa o también evalúa? :: La pregunta contrasta dos funciones.
- ¿El editor usa ironía en el título? :: Esa pregunta no aparece.
- ¿Quién escribió el comentario crítico? :: La frase pregunta por la función del texto.
@ 79 | Dane i sondaże | Datos y encuestas
I Interpretamos porcentajes y practicamos algunas formas de los numerales.
E Numerales con personas :: En plural masculino personal, el nominativo permite **trzej eksperci** («tres expertos»). :: Con cinco o más, se usa el numeral en **-u** más el genitivo plural: **pięciu badaczy przyszło** («vinieron cinco investigadores», verbo neutro singular).
E Numerales en otros casos :: Los numerales también se declinan: **w dwóch grupach** (en dos grupos), **z trzema ekspertami** (con tres expertos). :: No traduzcas siempre «dos, tres, cinco» con una forma polaca fija.
B Cambios de caso | Concepto | Polaco | Español
| tres expertos (sujeto) | trzej eksperci | tres expertos
| cinco investigadores (sujeto) | pięciu badaczy przyszło | vinieron cinco investigadores
| con tres expertos | z trzema ekspertami | con tres expertos

> W dwóch grupach = en dos grupos | odsetek odpowiedzi = proporción de respuestas | był podobny = fue parecida

> Ilu respondentów = cuántos encuestados | poparło plan = apoyaron el plan

> Trzej eksperci = tres expertos (masculino personal) | przedstawili wyniki = presentaron los resultados
Anna: Czy różnica jest znacząca? = ¿La diferencia es significativa?
> różnica = diferencia | jest znacząca = es significativa
Tom: Nie. W porównaniu z zeszłym rokiem wzrost jest niewielki. = No. En comparación con el año pasado, el aumento es leve.
> W porównaniu z = en comparación con | zeszłym rokiem = el año pasado | wzrost jest niewielki = el aumento es leve
Q ¿Qué forma se usa con un grupo de tres expertos como sujeto?
+ Trzej eksperci. :: Es el nominativo masculino personal.
- Trzy eksperci. :: Trzy se usa con grupos no masculinos personales.
- Trzech eksperci. :: Trzech exige el genitivo ekspertów.
R Trzej eksperci przedstawili wyniki. :: Traduce al español.
+ Tres expertos presentaron los resultados. :: Trzej eksperci es masculino personal.
- Cinco investigadores presentaron un informe. :: La frase usa el numeral tres.
- Los encuestados apoyaron un plan. :: Esa información aparece antes.
H ___ respondentów poparło plan? :: Completa «¿Cuántos encuestados apoyaron el plan?».
+ Ilu :: Es la forma masculina personal de «cuántos».
- Ile :: Se usa con sustantivos no masculinos personales.
- Którzy :: Significa «cuáles», no pregunta por cantidad.

+ Una proporción parecida en dos grupos. :: w dwóch grupach sitúa la comparación.
- Un aumento fuerte en todas las regiones. :: La frase dice que fue parecido.
- Una caída en el resultado de la encuesta. :: No se menciona ningún descenso.

Q ¿Qué significa wzrost?
+ Aumento. :: Describe que una cantidad sube.
- Descenso. :: Descenso es spadek.
- Diferencia. :: Diferencia es różnica.

+ En comparación con el año pasado, el aumento es leve. :: niewielki significa «leve».
- En comparación con el año pasado, la caída fue grande. :: wzrost es «aumento».
- La encuesta tiene pocos participantes. :: La oración compara un aumento.
@ 79 | Weryfikacja informacji | Verificar la información
I Distinguimos lo confirmado de lo supuesto y aprendemos a resumir una noticia con cautela.
E Impersonal y pasiva :: **Podano informację** significa «se dio a conocer la información» sin nombrar a quien lo hizo. :: **Informacja została potwierdzona** pone el foco en la información y su resultado.
E No afirmar de más :: **Przypuszczenie** es algo que se supone, no un hecho confirmado. :: **Wprowadzać w błąd** significa confundir a alguien con información falsa o incompleta.
W doniesienie = noticia; informe | do-NYE-she-nye
W opiera się na = se basa en | o-PYE-ra she na
W powołuje się na = cita; se remite a | po-wo-WU-ye she na
W anonimowego świadka = a un testigo anónimo | a-no-NI-mo-ve-GO SHFYAT-ka
W informacja = información | in-for-MA-tsya
W została potwierdzona = fue confirmada | zo-STA-wa pot-fyer-DZO-na
W podano = se dio; se informó | po-DA-no
W przypuszczenie = suposición | pshi-push-CHE-nye
W w artykule = en el artículo | f ar-ti-KU-le
W wprowadza w błąd = induce a error; engaña | f-pro-VA-dza f BWONT
W odbiorców = a los destinatarios (acusativo plural) | od-BYOR-tsuf
W wyolbrzymiać = exagerar | vi-ol-bzhi-MYACH

V Verificación y cautela
D Comprobar una noticia
Anna: Czy to doniesienie opiera się na źródłach? = ¿Este informe se basa en fuentes?
> Czy to doniesienie = ¿este informe? | opiera się na źródłach = se basa en fuentes
Tom: Autor powołuje się na anonimowego świadka. = El autor cita a un testigo anónimo.
> Autor = el autor | powołuje się na = se remite a | anonimowego świadka = a un testigo anónimo
Anna: Czy informacja została potwierdzona? = ¿Se confirmó la información?
> informacja została potwierdzona = la información fue confirmada
Tom: Nie. W artykule podano tylko przypuszczenie. = No. En el artículo solo se informó de una suposición.
> Nie = no | w artykule = en el artículo | podano = se informó | tylko przypuszczenie = solo una suposición
Anna: Czy tekst wprowadza w błąd? = ¿El texto induce a error?
> tekst wprowadza w błąd = el texto induce a error
Tom: Może wyolbrzymiać problem, dlatego trzeba zweryfikować tę informację. = Puede exagerar el problema; por eso hay que verificar esta información.
> Może wyolbrzymiać problem = puede exagerar el problema | dlatego = por eso | trzeba zweryfikować tę informację = hay que verificar esta información
Q ¿Qué significa doniesienie opiera się na źródłach?
+ El informe se basa en fuentes. :: opiera się na significa «se basa en».
- El informe fue confirmado por un testigo. :: Esa información no está en la expresión.
- El texto exagera el problema. :: Esa idea aparece después.
R W artykule podano tylko przypuszczenie. :: Traduce al español.
+ En el artículo solo se informó de una suposición. :: podano es impersonal y no indica quién lo hizo.
- El artículo confirmó todos los datos. :: La frase dice «suposición», no confirmación.
- El testigo anónimo publicó una rectificación. :: No se menciona al testigo en esa frase.
H W artykule ___ tylko przypuszczenie. :: Completa «En el artículo solo se informó de una suposición».
+ podano :: Es una forma impersonal pasada.
- potwierdzona :: Significa «confirmada» y es femenina.
- wyolbrzymiać :: Significa «exagerar».
A Czy tekst wprowadza w błąd? :: ¿Qué quiere saber Anna?
+ Si el texto engaña a los lectores. :: wprowadza w błąd significa «induce a error».
- Si el autor citó a un testigo anónimo. :: Eso se dice antes.
- Si la información fue confirmada. :: Esa pregunta aparece antes.
O Trzeba zweryfikować tę informację. :: Hay que verificar esta información. :: trzeba + infinitivo expresa necesidad.
X Escribe «desinformación» en polaco. :: dezinformacja :: Es información falsa o manipulada.
Q ¿Qué significa sprostowanie?
+ Rectificación o corrección. :: Es una aclaración que corrige información anterior.
- Desinformación. :: Desinformación es dezinformacja.
- Testigo anónimo. :: Eso es anonimowy świadek.
R Czy informacja została potwierdzona? :: Traduce al español.
+ ¿Se confirmó la información? :: została potwierdzona es una pasiva en pasado.
- ¿Se difundió una suposición? :: Difundir es rozpowszechniać.
- ¿El texto engañó a los lectores? :: Esa es otra pregunta.
