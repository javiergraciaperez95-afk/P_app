@ 24 | Egzamin końcowy A1 | Examen final A1
I Evalúa la comunicación cotidiana y la gramática de los capítulos 1 a 23.
w Cap = capítulo (marcador del examen) | KAP
Q Cap. 1. ¿Qué saludo usarías por la mañana?
+ Dzień dobry. :: Es un saludo formal de uso general durante el día.
- Do widzenia. :: Es una despedida.
- Dobranoc. :: Se dice antes de dormir.
R Cap. 2. Ona ma osiem lat. :: Traduce al español.
+ Ella tiene ocho años. :: ma osiem lat expresa la edad.
- Ella tiene siete años. :: Siete es siedem.
- Ella tiene treinta años. :: Treinta es trzydzieści.
H Cap. 3. Mieszkam ___ Warszawie. :: Completa «Vivo en Varsovia».
+ w :: w Warszawie indica el lugar donde vive.
- z :: z indica origen.
- po :: po se usa en expresiones como hablar un idioma.
R Cap. 4. O której wstajesz? :: Traduce al español.
+ ¿A qué hora te levantas? :: O której pregunta a qué hora.
- ¿Qué desayunas? :: Esa pregunta sería Co jesz na śniadanie?
- ¿Adónde vas? :: Dokąd pregunta por el destino.
A Cap. 5. Poproszę herbatę. :: ¿Qué pide la persona que oyes?
+ Un té, por favor. :: herbatę es el objeto pedido.
- Un café, por favor. :: café es kawę.
- Agua, por favor. :: agua es wodę.
H Cap. 6. Wybieram ___ sukienkę. :: Completa «Elijo un vestido negro».
+ czarną :: El adjetivo concuerda con sukienkę, femenino en acusativo.
- czarna :: Es el femenino básico, no la forma de objeto.
- czarny :: Es masculino.
Q Cap. 7. ¿Qué pregunta por el destino?
+ Dokąd? :: Pregunta «¿adónde?».
- Gdzie? :: Pregunta «¿dónde?».
- Skąd? :: Pregunta «¿de dónde?».
R Cap. 8. Jest pochmurno. :: Traduce al español.
+ Está nublado. :: pochmurno describe el cielo nublado.
- Hace sol. :: «Hace sol» es jest słonecznie.
- Nieva. :: «Nieva» es pada śnieg.
A Cap. 9. Boli mnie głowa. :: ¿Qué significa la frase que oyes?
+ Me duele la cabeza. :: głowa significa «cabeza».
- Me duele la garganta. :: «Garganta» es gardło.
- Tengo fiebre. :: «Tengo fiebre» es Mam gorączkę.
H Cap. 10. ___ w domu. :: Completa «Estuve en casa», hablando una mujer.
+ Byłam :: Es la forma femenina de pasado de la primera persona.
- Byłem :: Es la forma masculina de pasado de la primera persona.
- Była :: Es la forma femenina de tercera persona.
R Cap. 11. Mówię powoli. :: Traduce al español.
+ Hablo despacio. :: powoli significa «despacio».
- Hablo claramente. :: claramente es wyraźnie.
- Hablo en voz alta. :: «En voz alta» es głośno.
Q Cap. 12. ¿Qué dígrafo polaco suena parecido a la «ch» española?
+ cz :: Es un dígrafo con ese sonido aproximado.
- sz :: Suena más parecido a «sh».
- rz :: Tiene un sonido parecido a ż.
R Cap. 13. Jak to się literuje? :: Traduce al español.
+ ¿Cómo se deletrea? :: literuje significa «deletrea».
- ¿Cómo se pronuncia? :: Eso pregunta Jak to się wymawia?
- ¿Cuál es tu dirección? :: dirección es adres.
Q Cap. 14. En «To jest miłe dziecko», ¿qué género tiene dziecko?
+ Neutro :: dziecko es un sustantivo de género neutro.
- Masculino :: El masculino sería, por ejemplo, student.
- Femenino :: La forma femenina sería studentka.
H Cap. 15. Biorę tę ___. :: Completa «Cojo esta sopa».
+ zupę :: zupa pasa a zupę como objeto directo.
- zupa :: Es el nominativo, no el acusativo de este ejemplo.
- ryż :: Significa «arroz».
H Cap. 16. Nie mam ___. :: Completa «No tengo tiempo».
+ czasu :: czas pasa a czasu en genitivo tras nie mam.
- czas :: Es la forma básica.
- czasem :: Es instrumental.
Q Cap. 17. ¿Qué caso sigue a z cuando significa «con»?
+ Instrumental :: z koleżanką expresa compañía y lleva instrumental.
- Genitivo :: z también rige genitivo cuando indica origen.
- Acusativo :: No corresponde a este uso de z.
H Cap. 18. Idę do ___. :: Completa «Voy a la farmacia».
+ apteki :: do rige genitivo: apteka pasa a apteki.
- apteka :: Es la forma básica.
- apteką :: Es instrumental.
R Cap. 19. Czy ma pani mniejszy rozmiar? :: Traduce al español.
+ ¿Tiene una talla más pequeña? :: mniejszy rozmiar significa «talla más pequeña».
- ¿Cuánto cuesta este jersey? :: Esa pregunta es Ile kosztuje ten sweter?
- ¿Puedo pagar con tarjeta? :: Esa pregunta es Czy mogę zapłacić kartą?
Q Cap. 20. ¿Qué significa rzadko?
+ Rara vez :: Expresa baja frecuencia.
- Siempre :: siempre es zawsze.
- Nunca :: nunca es nigdy.
H Cap. 21. Jutro będę pracować w ___. :: Completa «Mañana trabajaré en casa».
+ domu :: w domu expresa el lugar y lleva locativo.
- dom :: Es la forma básica, no el locativo.
- domem :: Es instrumental.
Q Cap. 22. En «Bolą mnie plecy», ¿qué forma concuerda con plecy?
+ Bolą :: plecy es plural y exige bolą.
- Boli :: Es singular.
- Boleć :: Es el infinitivo.
R Cap. 23. Proszę mówić wolniej. :: Traduce al español.
+ Por favor, hable más despacio. :: wolniej significa «más despacio».
- Por favor, repítalo. :: «Repítalo» es proszę powtórzyć.
- ¿Cómo se pronuncia? :: Eso es Jak to się wymawia?
H Cap. 23. Potrzebuję klucza do ___. :: Completa «Necesito la llave de la habitación».
+ pokoju :: do rige genitivo: pokój pasa a pokoju.
- pokój :: Es la forma básica.
- pokojem :: Es instrumental.
R Cap. 23. Oddzwonię za godzinę. :: Traduce al español.
+ Te devolveré la llamada dentro de una hora. :: oddzwonię es «devolveré la llamada».
- Te escribiré ahora mismo. :: Eso es Zaraz do ciebie napiszę.
- No te oigo bien. :: Eso es Nie słyszę cię dobrze.
