@ 85 | Wyniki badań | Resultados de pruebas
I Hablamos de resultados sin confundir una medición con un diagnóstico.
E Medición y diagnóstico :: **Wynik nie przesądza o diagnozie** significa que un resultado por sí solo no determina un diagnóstico.
E Interpretar datos :: **Interpretować łącznie z objawami** significa valorar un resultado junto con los síntomas.

> Poziom cholesterolu = el nivel de colesterol | mieści się w normie = está dentro del rango normal

> wynik badania = el resultado de la prueba | wyklucza problem = descarta el problema

> Nie = no | wynik nie przesądza o diagnozie = el resultado no determina un diagnóstico
Pacjent: Czy trzeba interpretować go łącznie z objawami? = ¿Hay que interpretarlo junto con los síntomas?
> trzeba interpretować = hay que interpretar | łącznie z objawami = junto con los síntomas
Q ¿Qué significa «mieści się w normie»?
+ Está dentro del rango normal. :: Describe un resultado que cae dentro de los límites esperados.
- Requiere una consulta especializada. :: Esa expresión es konsultację specjalistyczną.
- Debe repetirse. :: Eso es wynik wymaga powtórzenia.
R Wynik nie przesądza o diagnozie. :: Traduce al español.
+ El resultado no determina un diagnóstico. :: przesądza significa «determina» en este contexto.
- El resultado confirma un diagnóstico. :: La frase afirma lo contrario.
- El nivel de colesterol está dentro del rango normal. :: Esa es otra oración.
H Poziom cholesterolu ___ się w normie. :: Completa «El nivel de colesterol está dentro del rango normal».
+ mieści :: Forma de mieścić się.
- wymaga :: Significa «requiere».
- zalecić :: Es «recomendar» en infinitivo.
A Czy trzeba interpretować go łącznie z objawami? :: ¿Qué pregunta el paciente?
+ Si hay que interpretarlo junto con los síntomas. :: łącznie z objawami significa eso.
- Si necesita una muestra de sangre. :: La pregunta no menciona una muestra.
- Si se recomienda una prueba de control. :: Esa idea no aparece.
O Przed badaniem. :: Antes de la prueba. :: przed rige instrumental en esta expresión.
X Escribe «prueba de laboratorio» en polaco. :: badanie laboratoryjne :: Es una prueba realizada en un laboratorio.
Q ¿Qué significa «próbka krwi»?
+ Muestra de sangre. :: próbka es «muestra» y krwi significa «de sangre».
- Prueba de control. :: Eso es kontrolne badanie.
- Consulta especializada. :: Esa es konsultacja specjalistyczna.
R Wynik badania wymaga powtórzenia. :: Traduce al español.
+ El resultado de la prueba requiere repetición. :: wymaga powtórzenia indica que debe repetirse.
- El resultado está dentro del rango normal. :: Esa es otra expresión.
- El resultado determina un diagnóstico. :: El texto dice que no lo determina.

@ 85 | Zalecenia i dalsze kroki | Recomendaciones y próximos pasos
I Pedimos orientación y expresamos qué hacer si una situación cambia.
E Condición :: **Jeśli objawy się nasilą** significa «si los síntomas se intensifican»; la forma perfectiva se refiere a un cambio que llegue a ocurrir.
E Precaución :: **Nie zmieniać dawkowania bez konsultacji** expresa una recomendación general, no una pauta médica individual.
