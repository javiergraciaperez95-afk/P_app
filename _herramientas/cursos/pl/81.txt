@ 81 | System i algorytm | Sistemas y algoritmos
I Describimos una acción técnica y el estado que deja.
E Acción y estado :: **Serwer został wyłączony** presenta una acción pasada; **serwer jest wyłączony** describe el estado actual.
E Concordancia :: En la pasiva, el participio concuerda con el nombre: **serwer został wyłączony**, **aplikacja została wyłączona**.
B Pasiva | Concepto | Acción | Estado
| apagar el servidor | serwer został wyłączony | serwer jest wyłączony
| diseñar el sistema | system został zaprojektowany | system jest zaprojektowany
W serwer = servidor | SER-ver
W został wyłączony = fue apagado (masculino) | ZO-staw vi-WON-cho-ni
W przez administratora = por el administrador | pshez ad-mi-ni-STRA-to-ra
W teraz = ahora | TE-ras
W jest wyłączony = está apagado (masculino) | yest vi-WON-cho-ni
W Czy = partícula de pregunta | chi
W system = sistema | SIS-tem
W został zaprojektowany = fue diseñado (masculino) | ZO-staw za-pro-yek-TO-va-ni
W do analizy danych = para analizar datos | do a-NA-li-zi DA-nikh
W nowy algorytm = nuevo algoritmo | NO-vi al-go-RITM
W analizuje = analiza | a-na-LI-zu-ye
W je = los; las (pronombre) | ye
W szybciej = más rápido | SHIB-chey
W program = programa | PRO-gram
W działa = funciona | DZYA-wa
W jego = su; de él | YE-go
W wydajność = rendimiento; eficiencia | vi-DAY-noshch
W znacznie = considerablemente | ZNACH-nye
W wzrosła = aumentó (femenino) | VZROS-wa
V Sistemas automatizados
D Una revisión técnica
Anna: Czy serwer został wyłączony przez administratora? = ¿El servidor fue apagado por el administrador?
> Czy serwer = ¿el servidor? | został wyłączony = fue apagado | przez administratora = por el administrador
Tom: Tak. Teraz jest wyłączony. = Sí. Ahora está apagado.
> Tak = sí | Teraz = ahora | jest wyłączony = está apagado
Anna: Czy system został zaprojektowany do analizy danych? = ¿El sistema fue diseñado para analizar datos?
> Czy system = ¿el sistema? | został zaprojektowany = fue diseñado | do analizy danych = para analizar datos
Tom: Tak. Nowy algorytm analizuje je szybciej. = Sí. Un nuevo algoritmo los analiza más rápido.
> Tak = sí | Nowy algorytm = un nuevo algoritmo | analizuje je szybciej = los analiza más rápido
Anna: Czy program działa poprawnie? = ¿El programa funciona correctamente?
> Czy program = ¿el programa? | działa poprawnie = funciona correctamente
Tom: Tak. Jego wydajność znacznie wzrosła. = Sí. Su rendimiento aumentó considerablemente.
> Tak = sí | jego wydajność = su rendimiento | znacznie wzrosła = aumentó considerablemente
Q ¿Qué expresa «serwer został wyłączony»?
+ La acción de apagar el servidor. :: Presenta lo que ocurrió.
- El estado actual del servidor. :: El estado actual aparece con jest wyłączony.
- El rendimiento del programa. :: Eso se expresa con wydajność.
R Teraz serwer jest wyłączony. :: Traduce al español.
+ Ahora el servidor está apagado. :: jest wyłączony describe el estado.
- El administrador apagó el sistema. :: La oración no tiene esa información.
- El algoritmo analiza los datos. :: Esa es otra acción.
H Serwer został ___ przez administratora. :: Completa «El servidor fue apagado por el administrador».
+ wyłączony :: El participio concuerda con serwer.
- jest wyłączony :: Significa «está apagado», no completa la acción pasada.
- działa poprawnie :: Significa «funciona correctamente».
A Jego wydajność znacznie wzrosła. :: ¿Qué aumentó?
+ El rendimiento del programa. :: jego wydajność significa «su rendimiento».
- La velocidad del servidor. :: No aparece una palabra para velocidad.
- La cantidad de datos. :: La oración no indica una cantidad.
O System został zaprojektowany do analizy danych. :: El sistema fue diseñado para analizar datos. :: La forma pasiva presenta una acción completada.
X Escribe «servidor» en polaco. :: serwer :: Es el equipo que proporciona datos o servicios.
Q ¿Qué significa «poprawnie»?
+ Correctamente. :: Indica que algo funciona bien.
- Ahora. :: Ahora es teraz.
- Más rápido. :: Más rápido es szybciej.
R Czy program działa poprawnie? :: Traduce al español.
+ ¿El programa funciona correctamente? :: działa significa «funciona».
- ¿El servidor está apagado? :: Esa pregunta se refiere al servidor.
- ¿El sistema analiza datos? :: La pregunta trata del programa.
@ 81 | Dane pod ochroną | Datos protegidos
I Hablamos del consentimiento y del tratamiento de datos sensibles.
E Datos y consentimiento :: **Za zgodą użytkownika** significa «con el consentimiento del usuario».
E Pasiva impersonal :: **Udostępniono dane** significa «se compartieron datos»; no se indica quién realizó la acción.
W aplikacja = aplicación | a-pli-KA-tsya
W zbiera = recoge | ZBYE-ra
W dane = datos | DA-ne
W biometryczne = biométricos (plural no masculino personal) | byo-me-TRICH-ne
W tylko = solo | TIL-ko
W za zgodą = con el consentimiento | za ZGO-don
W użytkownika = del usuario | u-zhit-KOV-ni-ka
W są przechowywane = son almacenados (plural no masculino personal) | son pshe-kho-VI-va-ne
W w systemie = en el sistema | f sis-TE-mye
W zabezpieczonym hasłem = protegido por contraseña | za-bez-pye-CHO-nim HAS-wem
W udostępniono = se compartieron | u-do-stemp-NYO-no
W partnerom = a los socios | par-TNE-rom
W zostały zanonimizowane = fueron anonimizados | zo-STA-wi za-no-ni-mi-ZO-va-ne

V Consentimiento y privacidad
D Los datos de una aplicación
Anna: Czy aplikacja zbiera dane biometryczne? = ¿La aplicación recoge datos biométricos?
> Czy aplikacja = ¿la aplicación? | zbiera = recoge | dane biometryczne = datos biométricos
Tom: Tak, ale tylko za zgodą użytkownika. = Sí, pero solo con el consentimiento del usuario.
> Tak = sí | ale tylko = pero solo | za zgodą użytkownika = con el consentimiento del usuario
Anna: Gdzie są przechowywane? = ¿Dónde se almacenan?
> Gdzie = dónde | są przechowywane = son almacenados
Tom: W systemie zabezpieczonym hasłem. = En un sistema protegido por contraseña.
> W systemie = en el sistema | zabezpieczonym hasłem = protegido por contraseña
Anna: Czy dane udostępniono partnerom? = ¿Se compartieron los datos con los socios?
> Czy dane udostępniono = ¿se compartieron los datos? | partnerom = a los socios
Tom: Nie. Zostały zanonimizowane. = No. Fueron anonimizados.
> Nie = no | Zostały zanonimizowane = fueron anonimizados
Q ¿Qué significa «za zgodą użytkownika»?
+ Con el consentimiento del usuario. :: Indica que el usuario autorizó la acción.
- En el sistema protegido por contraseña. :: Esa es otra expresión.
- Se compartieron con los socios. :: Esa es una acción distinta.
R Tak, ale tylko za zgodą użytkownika. :: Traduce al español.
+ Sí, pero solo con el consentimiento del usuario. :: za zgodą significa «con el consentimiento».
- No, los datos fueron anonimizados. :: La frase es afirmativa.
- La aplicación recoge datos biométricos. :: Esa oración es una pregunta distinta.
H Dane są ___ w systemie. :: Completa «Los datos son almacenados en el sistema».
+ przechowywane :: Concuerda con dane, plural no masculino personal.
- zbiera :: Significa «recoge» y necesita un sujeto que recoge.
- partnerom :: Significa «a los socios».
A Czy dane udostępniono partnerom? :: ¿Qué pregunta Anna?
+ Si se compartieron los datos con los socios. :: udostępniono es impersonal.
- Si la aplicación recoge datos biométricos. :: Esa pregunta aparece antes.
- Si los datos son confidenciales. :: La pregunta no menciona poufne.
O Zostały zanonimizowane. :: Fueron anonimizados. :: El participio concuerda con dane.
X Escribe «datos» en polaco. :: dane :: Es la forma plural de dato.
Q ¿Qué significa «poufne»?
+ Confidenciales. :: Es plural no masculino personal.
- Biométricos. :: Biométricos es biometryczne.
- Protegido por contraseña. :: Esa expresión es zabezpieczonym hasłem.
R W systemie zabezpieczonym hasłem. :: Traduce al español.
+ En un sistema protegido por contraseña. :: zabezpieczonym concuerda con systemie.
- Con el consentimiento del usuario. :: Esa es za zgodą użytkownika.
- Se compartieron los datos con los socios. :: La frase describe almacenamiento seguro.
@ 81 | Użytkownicy i dane | Usuarios y datos
I Los participios describen a las personas y los datos sin repetir una oración relativa.
E Participios adjetivales :: **Użytkownik korzystający z usługi** significa «el usuario que utiliza el servicio».
E Proceso y resultado :: **Zbierane dane** presenta una recogida en curso; **zebrane dane**, los datos ya recogidos. El participio concuerda con el nombre.
B Participios | Proceso (español) | Forma en polaco | Resultado (español) | Forma en polaco
| datos que se recogen | zbierane dane | datos recogidos | zebrane dane
| usuario que utiliza el servicio | użytkownik korzystający z usługi | archivo creado | plik utworzony
W pliki = archivos | PLI-ki
W utworzone = creados (plural no masculino personal) | ut-fo-ZHO-ne
W przez = por | pshez
W użytkowników = de los usuarios | u-zhit-KOV-ni-kuf
W są przechowywane w chmurze = son almacenados en la nube | son pshe-kho-VI-va-ne f KHU-zhe
W zebrane w badaniu = recogidos en el estudio | ze-BRA-ne f ba-DA-nyu
W zbierane przez aplikację = recogidos por la aplicación (proceso) | zbye-RA-ne pshez a-pli-KA-tsye
W są anonimizowane = son anonimizados | son a-no-ni-mi-ZO-va-ne
W przed analizą = antes del análisis | pshet a-NA-li-zon
W użytkownik korzystający z usługi = usuario que utiliza el servicio | u-zhit-KOV-nik ko-zhis-TA-yon-tsi z u-SWU-gi
W wie = sabe | uye
W o tym = de eso; sobre eso | o tim
W jasno przedstawiona = presentada claramente (femenino) | YAS-no pshet-sta-VYO-na
V Describir personas y resultados
T Información sobre archivos y datos
- Pliki utworzone przez użytkowników są przechowywane w chmurze. = Los archivos creados por los usuarios se almacenan en la nube.
> Pliki utworzone = archivos creados | przez użytkowników = por los usuarios | są przechowywane w chmurze = se almacenan en la nube

> Dane zebrane w badaniu = datos recogidos en el estudio | są poufne = son confidenciales

> Dane zbierane przez aplikację = datos recogidos por la aplicación | są anonimizowane = se anonimizan | przed analizą = antes del análisis

> Użytkownik korzystający z usługi = el usuario que utiliza el servicio | wie o tym = lo sabe

> Informacja = la información | jest jasno przedstawiona = se presenta claramente
Q ¿Qué significa «zebrane w badaniu»?
+ Recogidos en el estudio. :: Describe datos ya recogidos.
- Recogidos por la aplicación (proceso). :: Eso sería zbierane przez aplikację.
- Presentada claramente. :: Esa expresión es jasno przedstawiona.
R Pliki utworzone przez użytkowników są przechowywane w chmurze. :: Traduce al español.
+ Los archivos creados por los usuarios se almacenan en la nube. :: utworzone describe el resultado de crear.
- Los archivos que se están creando se eliminan. :: La frase no menciona eliminarlos.
- Los datos de usuarios se comparten con socios. :: La frase habla de archivos guardados.
H Dane ___ przez aplikację są anonimizowane przed analizą. :: Completa «Los datos que se recogen por la aplicación se anonimizan antes del análisis».
+ zbierane :: Presenta un proceso de recogida.
- zebrane w badaniu :: Significa «recogidos en el estudio».
- jasno przedstawiona :: Concuerda con un nombre femenino singular.
A Użytkownik korzystający z usługi wie o tym. :: ¿Qué expresa la frase?
+ El usuario que utiliza el servicio lo sabe. :: korzystający describe al usuario.
- El servicio recoge datos biométricos. :: La frase habla de lo que sabe el usuario.
- Los archivos fueron creados por los usuarios. :: Esa es otra frase.
O Informacja jest jasno przedstawiona. :: La información se presenta claramente. :: jasno przedstawiona concuerda con informacja.
X Escribe «información» en polaco. :: informacja :: Es un sustantivo femenino.
Q ¿Qué significa «zbierane»?
+ Que se recogen como proceso. :: Se distingue de zebrane, resultado ya recogido.
- Creados. :: Creados es utworzone.
- Almacenados. :: Almacenados es są przechowywane.
R Dane zebrane w badaniu są poufne. :: Traduce al español.
+ Los datos recogidos en el estudio son confidenciales. :: zebrane presenta el resultado de la recogida.
- Los datos que recoge la aplicación son anónimos. :: Esa es otra construcción.
- La información se presenta claramente. :: La frase comienza con dane.
