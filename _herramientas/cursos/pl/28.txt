@ 28 | Co ci dolega? | ¿Qué te pasa?
I Describimos un resfriado y preguntamos por los síntomas.
E Expresar síntomas :: **Co ci dolega?** significa «¿Qué te pasa?» o «¿Qué te molesta?». :: **Dolega** va con la persona en dativo: **ci** («a ti»).
E Dolor y temperatura :: **Ból gardła** significa «dolor de garganta»; **wysoka temperatura**, «fiebre alta». :: El adjetivo concuerda con **temperatura**, que es femenino.
B Síntomas | Concepto | Polaco | Español
| resfriado (nombre) | przeziębienie | resfriado
| resfriado (hombre) | przeziębiony | resfriado
| dolor de garganta | ból gardła | dolor de garganta
W dolega = molesta; pasa | do-LE-ga
W przeziębienie = resfriado | pshi-zhen-BYE-nye
W przeziębiony = resfriado (masculino) | pshi-zhen-BYO-ni
W przeziębiona = resfriada (femenino) | pshi-zhen-BYO-na
W ból = dolor | BUL
W ból gardła = dolor de garganta | BUL GAR-dwa
W gardła = garganta (genitivo) | GAR-dwa
W temperatura = temperatura | tem-pe-ra-TU-ra
W temperaturę = temperatura (objeto directo) | tem-pe-ra-TU-re
W wysoką = alta (objeto femenino) | vi-SO-kon
W odpoczywać = descansar | ot-po-CHI-vach
W odpoczywam = descanso | ot-po-CHI-vam
W odpoczywasz = descansas | ot-po-CHI-vash
V Síntomas comunes
D En casa
Anna: Co ci dolega? = ¿Qué te pasa?
> Co = qué | ci dolega = te pasa
Tom: Jestem przeziębiony. Mam katar i kaszel. = Estoy resfriado. Tengo catarro y tos.
> Jestem przeziębiony = estoy resfriado | Mam katar i kaszel = tengo catarro y tos
Anna: Czy masz temperaturę? = ¿Tienes fiebre?
> Czy masz = ¿tienes? | temperaturę = fiebre (objeto)
Tom: Tak, mam wysoką temperaturę. = Sí, tengo fiebre alta.
> Tak = sí | mam = tengo | wysoką temperaturę = fiebre alta
Anna: Boli cię głowa? = ¿Te duele la cabeza?
> Boli cię = te duele | głowa = cabeza
Tom: Nie, ale mam ból gardła. = No, pero me duele la garganta.
> Nie = no | ale = pero | mam = tengo | ból gardła = dolor de garganta
Q ¿Qué pregunta Co ci dolega?
+ ¿Qué te pasa? :: dolega pregunta por una molestia o problema.
- ¿Qué quieres comer? :: La frase pregunta por un síntoma.
- ¿A qué hora vienes? :: La frase no pregunta por la hora.
R Mam wysoką temperaturę. :: Traduce al español.
+ Tengo fiebre alta. :: wysoką temperaturę significa «temperatura alta».
- Tengo dolor de garganta. :: Eso sería Mam ból gardła.
- Estoy resfriada. :: Eso lo diría una mujer: Jestem przeziębiona.
H Mam ___ temperaturę. :: Completa «Tengo fiebre alta».
+ wysoką :: Es la forma femenina de «alta» como objeto.
- wysoki :: Es la forma masculina.
- wysoka :: Es la forma femenina básica, no la de objeto.
A Jestem przeziębiony. :: ¿Cómo se encuentra quien habla?
+ Está resfriado. :: La forma masculina es przeziębiony.
- Está resfriada. :: Una mujer dice przeziębiona.
- Tiene dolor de cabeza. :: Eso sería Boli mnie głowa.
O Mam ból gardła. :: Tengo dolor de garganta. :: ból gardła significa literalmente «dolor de garganta».
X Escribe «Tengo fiebre alta». :: Mam wysoką temperaturę. :: wysoką concuerda con temperaturę.
Q ¿Qué significa odpoczywam?
+ Descanso. :: Es la forma de «yo» de descansar.
- Descansas. :: Descansas es odpoczywasz.
- Estoy resfriado. :: Estoy resfriado es Jestem przeziębiony.
R Boli cię głowa? :: Traduce al español.
+ ¿Te duele la cabeza? :: głowa significa «cabeza».
- ¿Te duele la garganta? :: Garganta es gardło.
- ¿Tienes fiebre alta? :: Eso es Czy masz wysoką temperaturę?

@ 28 | Co powinienem zrobić? | ¿Qué debería hacer?
I Damos recomendaciones con las formas de «deber» y los verbos en infinitivo.
E Deber :: **Powinienem** significa «debería» dicho por un hombre; **powinnam**, «debería» dicho por una mujer. :: La forma cambia según el género de quien habla.
E Recomendar a otra persona :: **Powinieneś odpoczywać** significa «deberías descansar» dicho a un hombre. :: **Powinnaś** se usa al hablar con una mujer; después de estas formas va el infinitivo.
B Deber | Persona | Masculino | Femenino
| yo | powinienem | powinnam
| tú | powinieneś | powinnaś
| él / ella | powinien | powinna
W powinienem = debería (yo, hombre) | po-VI-nye-nem
W powinnam = debería (yo, mujer) | po-VIN-nam
W powinieneś = deberías (a un hombre) | po-vi-NYE-nyesh
W powinnaś = deberías (a una mujer) | po-VIN-nash
W powinien = debería (él) | po-VI-nyen
W powinna = debería (ella) | po-VIN-na
W zrobić = hacer (acción concreta) | ZRO-bich
W brać = tomar; coger | BRA-ch
W pić = beber | PICH
W biorę = tomo | BYO-re
W bierzesz = tomas | BYE-zhesz
W lekarstwo = medicamento | le-KAR-stvo
W lekarstwa = medicamento (forma de genitivo) | le-KAR-stva
W tabletka = pastilla; comprimido | ta-BLET-ka
W tabletkę = pastilla (objeto directo) | ta-BLET-ke
V Dar consejos
D Una recomendación
Tom: Co powinienem zrobić? = ¿Qué debería hacer?
> Co = qué | powinienem zrobić = debería hacer
Anna: Powinieneś odpoczywać i dużo pić. = Deberías descansar y beber mucho.
> Powinieneś odpoczywać = deberías descansar | i = y | dużo pić = beber mucho
Tom: Czy powinienem brać lekarstwo? = ¿Debería tomar un medicamento?
> Czy = partícula de pregunta | powinienem brać = debería tomar | lekarstwo = medicamento
Anna: Tak, powinieneś brać lekarstwo. = Sí, deberías tomar un medicamento.
> Tak = sí | powinieneś brać = deberías tomar | lekarstwo = medicamento
Tom: A co powinna zrobić Kasia? = ¿Y qué debería hacer Kasia?
> A = y | co = qué | powinna zrobić = debería hacer | Kasia = nombre propio
Anna: Powinna odpoczywać. = Debería descansar.
> Powinna = debería (ella) | odpoczywać = descansar
Q ¿Qué forma usaría una mujer para decir «debería» hablando de sí misma?
+ powinnam :: La terminación corresponde a una mujer que habla de sí misma.
- powinienem :: Es la forma masculina de «yo».
- powinieneś :: Se usa al hablar con un hombre.
R Powinieneś odpoczywać i dużo pić. :: Traduce al español.
+ Deberías descansar y beber mucho. :: powinieneś va seguido de infinitivos.
- Debería descansar y beber mucho. :: La forma para «él» es powinien.
- Debes tomar una pastilla. :: Esa idea no aparece en la frase.
H ___ brać lekarstwo? :: Completa «¿Debería tomar un medicamento?», hablando un hombre.
+ Czy powinienem :: Es la forma masculina de «yo».
- Czy powinnam :: Es la forma femenina de «yo».
- Czy powinieneś :: Se dirige a un hombre.
A Powinna odpoczywać. :: ¿Qué recomienda Anna para Kasia?
+ Que descanse. :: powinna odpoczywać expresa una recomendación.
- Que tome un medicamento. :: No aparece lekarstwo.
- Que vaya al médico. :: Esa acción no aparece.
O Powinnam brać lekarstwo. :: Debería tomar un medicamento (lo dice una mujer). :: powinnam indica que habla una mujer.
X Escribe «Deberías descansar», dirigido a un hombre. :: Powinieneś odpoczywać. :: powinieneś es la forma que se dirige a un hombre.
Q ¿Qué significa lekarstwo?
+ Medicamento. :: Es un producto para tratar una enfermedad.
- Pastilla. :: Pastilla es tabletka.
- Dolor. :: Dolor es ból.
R Czy powinienem brać lekarstwo? :: Traduce al español.
+ ¿Debería tomar un medicamento? :: powinienem lo dice un hombre de sí mismo.
- ¿Deberías tomar un medicamento? :: Esa forma sería Czy powinieneś brać lekarstwo?
- ¿Debería descansar? :: Descansar es odpoczywać.

@ 28 | Weź tabletkę | Toma una pastilla
I Practicamos instrucciones afirmativas y negativas, y comparamos el aspecto verbal.
E Una acción concreta :: **Weź tabletkę** significa «toma una pastilla»: **weź** presenta una acción concreta que se completa. :: **Wziąć** es el infinitivo perfectivo; su forma de orden es **weź**.
E Una prohibición o hábito :: **Nie bierz więcej tabletek** significa «no tomes más pastillas». :: En consejos generales es frecuente usar el imperfectivo **bierz** en la orden negativa; **więcej** significa «más».
B Instrucciones | Concepto | Polaco | Español
| toma una pastilla | Weź tabletkę | Toma una pastilla
| no tomes más pastillas | Nie bierz więcej tabletek | No tomes más pastillas
| bebe agua | Pij wodę | Bebe agua
W wziąć = tomar (acción concreta) | VZIONCH
W weź = toma (orden, acción concreta) | VESH
W bierz = toma; ve tomando (orden) | BYESH
W jedną = una (femenino como objeto) | YED-non
W pij = bebe (orden) | PIY
W więcej = más | VYEN-tsey
W tabletek = pastillas (genitivo plural) | ta-BLE-tek
W kawy = café (genitivo tras nie pij) | KA-vi
W odpocznij = descansa (orden, acción concreta) | ot-PO-chniy
W odpoczywaj = descansa; ve descansando (orden) | ot-po-CHI-vay
W codziennie = cada día | tso-JEN-nye
W uważaj = ten cuidado | u-VA-zhay
W uważaj na siebie = cuídate | u-VA-zhay na SHYE-bye
W farmaceutka = farmacéutica | far-ma-tse-UT-ka
V Instrucciones sencillas
D En la farmacia
Farmaceutka: Weź jedną tabletkę rano. = Toma una pastilla por la mañana.
> Weź = toma (orden concreta) | jedną tabletkę = una pastilla | rano = por la mañana
Anna: A wieczorem? = ¿Y por la noche?
> A = y | wieczorem = por la noche
Farmaceutka: Nie bierz więcej tabletek. = No tomes más pastillas.
> Nie bierz = no tomes | więcej tabletek = más pastillas
Anna: Czy mogę pić kawę? = ¿Puedo beber café?
> Czy mogę = ¿puedo? | pić = beber | kawę = café (objeto)
Farmaceutka: Nie pij kawy. Pij dużo wody. = No bebas café. Bebe mucha agua.
> Nie pij kawy = no bebas café | Pij dużo wody = bebe mucha agua
Anna: Dobrze, dziękuję. = De acuerdo, gracias.
> Dobrze = de acuerdo | dziękuję = gracias
Q ¿Qué significa weź?
+ Toma. :: Es una orden para realizar una acción concreta.
- No tomes. :: La prohibición es nie bierz.
- Bebe. :: Bebe es pij.
R Nie bierz więcej tabletek. :: Traduce al español.
+ No tomes más pastillas. :: bierz es una orden negativa con el imperfectivo.
- Toma una pastilla por la mañana. :: Eso es Weź jedną tabletkę rano.
- Bebe mucha agua. :: Eso es Pij dużo wody.
H Nie pij ___. :: Completa «No bebas café».
+ kawy :: Con la negación, café aparece en genitivo.
- kawę :: Es el objeto de una frase afirmativa.
- kawa :: Es la forma básica.
A Weź jedną tabletkę rano. :: ¿Qué instrucción oyes?
+ Toma una pastilla por la mañana. :: weź es la orden de tomarla.
- No tomes más pastillas. :: Eso es Nie bierz więcej tabletek.
- Bebe mucha agua. :: Eso es Pij dużo wody.
O Pij dużo wody. :: Bebe mucha agua. :: pij es la forma de orden de pić.
X Escribe «No tomes más pastillas». :: Nie bierz więcej tabletek. :: La negación lleva la forma imperfectiva bierz.
Q ¿Qué significa więcej?
+ Más. :: Aquí indica una cantidad mayor de pastillas.
- Cada día. :: Cada día es codziennie.
- Por la mañana. :: Por la mañana es rano.
R Nie pij kawy. :: Traduce al español.
+ No bebas café. :: nie pij es una orden negativa.
- Bebe café. :: La oración es negativa.
- No bebas agua. :: Agua es woda.
