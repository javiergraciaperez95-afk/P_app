@ 31 | Na poczcie | En correos
I Enviamos cartas y paquetes, y pedimos información en una oficina de correos.
E Cartas y paquetes :: **List polecony** es una carta enviada con seguimiento. :: **Paczka** significa «paquete»; con **wysłać**, se usa la forma de objeto **paczkę**.
E La dirección :: **Koperta** significa «sobre» y **na kopercie** significa «en el sobre». :: **Za granicę** se usa para decir «al extranjero».
B En correos | Concepto | Polaco | Español
| carta certificada | list polecony | carta certificada
| paquete | paczka | paquete
| sello | znaczek | sello
W list = carta | LIST
W polecony = certificado (masculino) | po-le-TSO-ni
W list polecony = carta certificada | list po-le-TSO-ni
W wysłać = enviar (acción concreta) | VI-swach
W wysyłka = envío; envío postal | vi-SIW-ka
W napisać = escribir (acción concreta) | na-PI-sach
W koperta = sobre | ko-PER-ta
W kopercie = en el sobre | ko-PER-tsye
W paczka = paquete | PA-chka
W paczkę = paquete (objeto directo) | PA-chke
W za granicę = al extranjero | za gra-NI-tse
W ważyć = pesar | VA-zhich
W waży = pesa | VA-zhi
W znaczek = sello | ZNA-chek
W wysyłanie = envío; acción de enviar | vi-si-WA-nye
W wysyłam = envío | vi-SI-wam
W wysyłasz = envías | vi-SI-vash
V Enviar correo
D Una carta y un paquete
Anna: Chcę wysłać list polecony. = Quiero enviar una carta certificada.
> Chcę = quiero | wysłać = enviar | list polecony = carta certificada
Tom: Proszę napisać adres na kopercie. = Por favor, escriba la dirección en el sobre.
> Proszę = por favor | napisać = escribir | adres = dirección | na kopercie = en el sobre
Anna: Czy mogę wysłać paczkę za granicę? = ¿Puedo enviar un paquete al extranjero?
> Czy mogę = ¿puedo? | wysłać paczkę = enviar un paquete | za granicę = al extranjero
Tom: Tak. Paczka waży dwa kilo. = Sí. El paquete pesa dos kilos.
> Tak = sí | Paczka = paquete | waży = pesa | dwa kilo = dos kilos
Anna: Ile kosztuje wysyłka? = ¿Cuánto cuesta el envío?
> Ile kosztuje = cuánto cuesta | wysyłka = envío
Tom: Wysyłka kosztuje trzydzieści złotych. = El envío cuesta treinta eslotis.
> Wysyłka = envío | kosztuje = cuesta | trzydzieści złotych = treinta eslotis
Q ¿Qué significa list polecony?
+ Carta certificada. :: Se envía con seguimiento.
- Paquete. :: Paquete es paczka.
- Sello. :: Sello es znaczek.
R Chcę wysłać paczkę za granicę. :: Traduce al español.
+ Quiero enviar un paquete al extranjero. :: wysłać es «enviar» y za granicę, «al extranjero».
- Quiero recibir una carta del extranjero. :: La frase dice enviar un paquete.
- Quiero comprar un sello para el paquete. :: Sello es znaczek.
H Proszę napisać adres na ___. :: Completa «Por favor, escriba la dirección en el sobre».
+ kopercie :: na kopercie significa «en el sobre».
- koperta :: Es la forma básica.
- paczkę :: Significa «paquete» como objeto.
A Paczka waży dwa kilo. :: ¿Qué información da la frase?
+ El paquete pesa dos kilos. :: waży significa «pesa».
- El envío cuesta dos eslotis. :: La frase habla del peso.
- La carta pesa dos kilos. :: La frase habla del paquete.
O Chcę wysłać list polecony. :: Quiero enviar una carta certificada. :: list polecony es una carta con seguimiento.
X Escribe «¿Puedo enviar un paquete al extranjero?». :: Czy mogę wysłać paczkę za granicę? :: mogę expresa posibilidad.
Q ¿Qué significa znaczek?
+ Sello. :: Se pega en una carta o paquete.
- Sobre. :: Sobre es koperta.
- Dirección. :: Dirección es adres.
R Wysyłka kosztuje trzydzieści złotych. :: Traduce al español.
+ El envío cuesta treinta eslotis. :: wysyłka significa «envío».
- El paquete pesa treinta kilos. :: Eso sería Paczka waży trzydzieści kilo.
- La carta certificada cuesta tres eslotis. :: La frase habla del envío.

@ 31 | W banku i bankomacie | En el banco y el cajero
I Hacemos operaciones sencillas y preguntamos cómo pagar una cuenta.
E Depositar y retirar :: **Wpłacić** significa «ingresar dinero» y **wypłacić**, «retirarlo». :: Ambos verbos describen una operación concreta que se completa.
E Pagos :: **Zrobić przelew** significa «hacer una transferencia». :: **Opłacić rachunek** significa «pagar una cuenta»; el verbo **opłacić** lleva el nombre en acusativo.
B Operaciones | Concepto | Polaco | Español
| ingresar dinero | wpłacić pieniądze | ingresar dinero
| retirar dinero | wypłacić pieniądze | retirar dinero
| hacer una transferencia | zrobić przelew | hacer una transferencia
W konto = cuenta bancaria | KON-to
W bankomat = cajero automático | ban-KO-mat
W bankomacie = en el cajero automático | ban-ko-MA-che
W pieniądze = dinero | pye-NYON-dze
W wpłacić = ingresar dinero (acción concreta) | WPWA-chich
W wpłacę = ingresaré dinero | WPWA-tse
W wypłacać = retirar dinero (habitualmente) | vi-PWA-tsach
W wypłacam = retiro dinero | vi-PWA-tsam
W wypłacasz = retiras dinero | vi-PWA-tsash
W wypłacić = retirar dinero (acción concreta) | vi-PWA-chich
W wypłacę = retiraré dinero | vi-PWA-tse
W przelew = transferencia bancaria | PSHE-lef
W opłacić = pagar una cuenta (acción concreta) | o-PWA-chich
W opłacę = pagaré una cuenta | o-PWA-tse
W włożyć = meter; introducir | VWO-zhich
W włożyć kartę = introducir la tarjeta | VWO-zhich KAR-te
W bankomatu = cajero (genitivo tras do/z) | ban-KO-ma-tu
V Operaciones bancarias
D En el banco
Anna: Chcę wpłacić pieniądze na konto. = Quiero ingresar dinero en la cuenta.
> Chcę = quiero | wpłacić = ingresar dinero | pieniądze = dinero | na konto = en la cuenta
Tom: Proszę włożyć kartę do bankomatu. = Por favor, introduzca la tarjeta en el cajero.
> Proszę = por favor | włożyć kartę = introducir la tarjeta | do bankomatu = en el cajero
Anna: Czy mogę wypłacić pieniądze z bankomatu? = ¿Puedo retirar dinero del cajero?
> Czy mogę = ¿puedo? | wypłacić pieniądze = retirar dinero | z bankomatu = del cajero
Tom: Tak. Możesz też zrobić przelew. = Sí. También puedes hacer una transferencia.
> Tak = sí | Możesz = puedes | też = también | zrobić przelew = hacer una transferencia
Anna: Chcę opłacić rachunek. = Quiero pagar una cuenta.
> Chcę = quiero | opłacić rachunek = pagar una cuenta
Tom: Możesz opłacić rachunek kartą. = Puedes pagar la cuenta con tarjeta.
> Możesz = puedes | opłacić rachunek = pagar una cuenta | kartą = con tarjeta
Q ¿Qué significa wypłacić pieniądze?
+ Retirar dinero. :: wypłacić expresa sacar dinero de una cuenta.
- Ingresar dinero. :: Ingresar es wpłacić.
- Hacer una transferencia. :: Eso es zrobić przelew.
R Chcę wpłacić pieniądze na konto. :: Traduce al español.
+ Quiero ingresar dinero en la cuenta. :: wpłacić significa «ingresar dinero».
- Quiero retirar dinero del cajero. :: Eso es Czy mogę wypłacić pieniądze z bankomatu?
- Quiero pagar una cuenta con tarjeta. :: Eso es Chcę opłacić rachunek kartą.
H Proszę ___ kartę do bankomatu. :: Completa «Por favor, introduzca la tarjeta en el cajero».
+ włożyć :: Es el infinitivo usado en una instrucción cortés.
- wypłacić :: Significa «retirar dinero».
- opłacić :: Significa «pagar una cuenta».
A Możesz też zrobić przelew. :: ¿Qué otra operación ofrece Tom?
+ Hacer una transferencia. :: zrobić przelew significa «hacer una transferencia».
- Retirar dinero. :: Retirar dinero es wypłacić pieniądze.
- Ingresar dinero en la cuenta. :: Esa operación es wpłacić pieniądze na konto.
O Możesz opłacić rachunek kartą. :: Puedes pagar la cuenta con tarjeta. :: opłacić rachunek significa «pagar una cuenta».
X Escribe «Quiero retirar dinero del cajero». :: Chcę wypłacić pieniądze z bankomatu. :: wypłacić significa «retirar dinero».
Q ¿Qué significa konto?
+ Cuenta bancaria. :: Es donde se guardan los fondos en el banco.
- Cajero automático. :: Cajero es bankomat.
- Transferencia. :: Transferencia es przelew.
R Chcę opłacić rachunek. :: Traduce al español.
+ Quiero pagar una cuenta. :: opłacić rachunek es «pagar una cuenta».
- Quiero enviar una carta certificada. :: Eso es Chcę wysłać list polecony.
- Quiero ingresar dinero en la cuenta. :: Eso es Chcę wpłacić pieniądze na konto.
