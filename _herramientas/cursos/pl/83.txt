@ 83 | Analiza dzieła | Analizar obras

E Punto de vista :: **Z punktu widzenia narratora** significa «desde el punto de vista del narrador».
E Interpretación :: **Skłaniać do refleksji** significa «invitar a reflexionar». La preposición do exige genitivo.

V Narración y estructura
T Lectura de una novela
- Powieść przedstawia wydarzenia z punktu widzenia narratora. = La novela presenta acontecimientos desde el punto de vista del narrador.
> Powieść przedstawia wydarzenia = la novela presenta acontecimientos | z punktu widzenia narratora = desde el punto de vista del narrador
- Postać główna podejmuje trudną decyzję. = El personaje principal toma una decisión difícil.
> Postać główna = el personaje principal | podejmuje trudną decyzję = toma una decisión difícil
- Tempo akcji jest wolne, ale powieść ma zaskakujące zakończenie. = El ritmo de la acción es lento, pero la novela tiene un final sorprendente.
> Tempo akcji = el ritmo de la acción | jest wolne = es lento | ma zaskakujące zakończenie = tiene un final sorprendente
- Symboliczny motyw skłania do refleksji nad odpowiedzialnością. = Un motivo simbólico invita a reflexionar sobre la responsabilidad.
> Symboliczny motyw = un motivo simbólico | skłania do refleksji = invita a reflexionar | nad odpowiedzialnością = sobre la responsabilidad
Q ¿Qué quiere decir «z punktu widzenia narratora»?
+ Desde el punto de vista del narrador. :: Indica quién cuenta o percibe los hechos.
- Desde el final de la novela. :: Final es zakończenie.
- Sobre la responsabilidad del personaje. :: Esa idea se expresa con nad odpowiedzialnością.
R Postać główna podejmuje trudną decyzję. :: Traduce al español.
+ El personaje principal toma una decisión difícil. :: podejmuje decyzję significa «toma una decisión».
- El narrador presenta un final sorprendente. :: Es otra combinación.
- La novela invita a reflexionar sobre la responsabilidad. :: Esa acción corresponde a otra frase.
H Powieść przedstawia wydarzenia z punktu widzenia ___. :: Completa «La novela presenta acontecimientos desde el punto de vista del narrador».
+ narratora :: Es el genitivo de narrator.
- powieść :: Es el sujeto «novela».
- decyzję :: Es «decisión» en acusativo.
A Tempo akcji jest wolne. :: ¿Cómo es el ritmo de la acción?
+ Es lento. :: wolne significa «lento» aquí.
- Es sorprendente. :: Sorprendente es zaskakujące.
- Es simbólico. :: Simbólico es symboliczny.
O Symboliczny motyw skłania do refleksji. :: Un motivo simbólico invita a reflexionar. :: skłania do reflexji introduce el efecto sobre el lector.
X Escribe «novela» en polaco. :: powieść :: Es una narración extensa de ficción.
Q ¿Qué significa «zaskakujące zakończenie»?
+ Final sorprendente. :: zakończenie es «final».
- Ritmo lento. :: Eso es tempo akcji jest wolne.
- Decisión difícil. :: Eso es trudną decyzję.
R Symboliczny motyw skłania do refleksji nad odpowiedzialnością. :: Traduce al español.
+ Un motivo simbólico invita a reflexionar sobre la responsabilidad. :: nad rige el instrumental en esta expresión.
- El narrador toma una decisión difícil. :: Esa es otra frase.
- La novela termina desde otro punto de vista. :: No dice eso.
@ 83 | Ocena i interpretacja | Valoración e interpretación
