I Pon en práctica los recursos del nivel para comprender, argumentar y sintetizar.
Q Cap. 77. ¿Qué construcción polaca significa «tanto X como Y»?
+ Zarówno X, jak i Y. :: Presenta dos elementos en pareja.
- W przeciwnym razie. :: Significa «de lo contrario».
- Z punktu widzenia X. :: Significa «desde el punto de vista de».
R Cap. 77. Z punktu widzenia zespołu ta teza jest przekonująca. :: Traduce al español.
+ Desde el punto de vista del equipo, esta tesis es convincente. :: z punktu widzenia introduce una perspectiva.
- El equipo presentará dos pruebas. :: Esa idea aparece en otra frase.
- La tesis trata sobre el coste total. :: La oración presenta una valoración.
H Cap. 77. Wtedy opóźnienie ___ na budżet. :: Completa «Entonces el retraso influirá en el presupuesto».
+ wpłynie :: Es la forma futura de influir.
- spełni :: Significa «cumplirá».
- wzrośnie :: Significa «aumentará».
Q Cap. 78. ¿Qué significa «międzypokoleniowe wsparcie»?
+ Apoyo entre generaciones. :: Se refiere a la relación entre personas de edades distintas.
- Soledad. :: Soledad es samotność.
- Participación social. :: Participación social es zaangażowanie społeczne.
R Cap. 78. Żyjemy dłużej, dlatego rośnie liczba seniorów. :: Traduce al español.
+ Vivimos más tiempo; por eso aumenta el número de personas mayores. :: dlatego introduce la consecuencia.
- Las personas mayores viven menos, por eso disminuye su número. :: La frase presenta el cambio contrario.
- Los jóvenes viven más tiempo, por eso crece la soledad. :: La oración trata de la población mayor.
Q Cap. 79. ¿Qué significa «przypuszczenie» en una noticia?
+ Una suposición no confirmada. :: No es lo mismo que un hecho verificado.
- Una rectificación publicada. :: Rectificación es sprostowanie.
- Una fuente anónima. :: Testigo anónimo es anonimowy świadek.
R Cap. 79. W artykule podano tylko przypuszczenie. :: Traduce al español.
+ En el artículo solo se informó de una suposición. :: podano es impersonal pasado.
- El artículo confirmó todos los datos. :: La frase dice «suposición».
- El testigo anónimo publicó una rectificación. :: Esa información no aparece en la oración.
Q Cap. 80. ¿Cuál es el genitivo de «imię»?
+ imienia :: Es la forma irregular de genitivo.
- imię :: Es la forma básica.
- imiona :: Es el plural.
H Cap. 80. Brakuje ___ przyjaciela. :: Completa «Falta el nombre de pila del amigo».
+ imienia :: brakuje rige genitivo.
- imię :: Es el nominativo o acusativo singular.
- imiona :: Es plural.
Q Cap. 81. ¿Qué diferencia hay entre «serwer został wyłączony» y «serwer jest wyłączony»?
+ La primera cuenta la acción pasada; la segunda describe el estado actual. :: został wyłączony es acción y jest wyłączony es estado.
- Ambas expresan una acción futura. :: Ninguna forma es futuro.
- La primera describe el diseño del algoritmo. :: La oración habla del servidor.
R Cap. 81. Teraz serwer jest wyłączony. :: Traduce al español.
+ Ahora el servidor está apagado. :: jest wyłączony describe el estado.
- El administrador apagará el servidor. :: No se indica quién ni cuándo lo apagó.
- El sistema fue diseñado para analizar datos. :: Es una idea diferente.
H Cap. 81. Dane ___ przez aplikację są anonimizowane przed analizą. :: Completa «Los datos que recoge la aplicación se anonimizan antes del análisis».
+ zbierane :: Concuerda con dane y presenta un proceso.
- zebrany :: Es masculino singular.
- zebrani :: Es plural masculino personal.
R Cap. 82. Transport publiczny ogranicza ruch samochodowy w centrum miasta. :: Traduce al español.
+ El transporte público limita el tráfico de coches en el centro de la ciudad. :: ogranicza ruch samochodowy expresa el efecto.
- El transporte público aumenta el tráfico en las zonas peatonales. :: La frase dice que lo limita.
- Los residentes financian una red energética estable. :: La oración trata del tráfico urbano.
H Cap. 82. Gdybyśmy ___ w sieć, można by zmniejszyć emisję. :: Completa «Si invirtiéramos en la red, se podría reducir la emisión».
+ zainwestowali :: Forma pasada plural personal con gdybyśmy.
- zapewni :: Significa «garantizará».
- rozwijać :: Es el infinitivo «desarrollar».
Q Cap. 82. ¿Qué relación introduce «Mimo że»?
+ Una concesión: «aunque». :: El hecho no impide la conclusión.
- Una condición hipotética. :: Esa condición se introduce con gdyby.
- Una consecuencia. :: Una consecuencia puede introducirse con dzięki temu.
Q Cap. 83. ¿Qué significa «wydaje się przekonująca»?
+ Parece convincente. :: Es una valoración expresada con cautela.
- Fue respaldada por un ejemplo. :: Eso es otra construcción pasiva.
- Puede interpretarse de otra manera. :: Es una idea distinta.
R Cap. 83. Jednak argument nie został poparty przykładem. :: Traduce al español.
+ Sin embargo, el argumento no fue respaldado por un ejemplo. :: nie został poparty es pasiva masculina.
- Sin embargo, la crítica encontró un ejemplo convincente. :: La frase dice que no fue respaldado.
- El público interpretó el símbolo de otra manera. :: Esa es otra frase.
R Cap. 84. Powstał w XIX wieku i zachował oryginalny wygląd. :: Traduce al español.
+ Se construyó en el siglo XIX y conservó su aspecto original. :: powstał presenta el origen del edificio.
- Se restauró en el siglo XX y cambió de aspecto. :: La oración no habla de una restauración.
- El guía explicó la influencia de varios estilos. :: Esa idea aparece en otra frase.
Q Cap. 84. ¿Qué aporta la expresión «według źródeł»?
+ Atribuye la información a las fuentes. :: Indica de dónde procede la afirmación.
- Expresa una duda del testigo. :: No significa «duda».
- Indica que un monumento es gratuito. :: No habla del acceso a un monumento.
R Cap. 85. Długotrwałe przeciążenie wpływa na samopoczucie. :: Traduce al español.
+ La sobrecarga prolongada influye en el bienestar. :: wpływa na expresa influencia.
- La actividad física regular empeora el sueño. :: La oración habla de la sobrecarga.
- El resultado de la prueba determina el diagnóstico. :: El texto no trata de una prueba.
H Cap. 85. Jeśli objawy się ___, należy zgłosić się do lekarza. :: Completa «Si los síntomas se intensifican, hay que acudir al médico».
+ nasilą :: Es el futuro perfectivo plural.
- nasilają :: Describe un proceso actual o habitual.
- nasilenie :: Es un sustantivo, «intensificación».
Q Cap. 86. ¿Qué función tiene «zwracam się z prośbą o»?
+ Presenta una solicitud formal. :: Es una fórmula cortés para pedir algo.
- Cierra una carta con cortesía. :: La despedida formal es z poważaniem.
- Confirma que el plazo se cumplió. :: No expresa confirmación.
H Cap. 86. Przed wdrożeniem warto uwzględnić zarówno koszty, jak i ___. :: Completa «Antes de la implementación conviene tener en cuenta tanto los costes como los beneficios».
+ korzyści :: Significa «beneficios».
- dowodów :: Significa «pruebas» en genitivo.
- decyzji :: Significa «decisión» en genitivo.
R Cap. 86. Ustalono, że obie instytucje przedstawią dane przed kolejnym spotkaniem. :: Traduce al español.
+ Se acordó que ambas instituciones presentarían los datos antes de la próxima reunión. :: ustalono es una forma impersonal pasada.
- Ambas instituciones rechazaron compartir datos. :: La oración dice que los presentarán.
- Se acordó cancelar la siguiente reunión. :: La reunión se usa como plazo.
Q Cap. 86. ¿Qué significa «w możliwie krótkim terminie»?
+ En el menor plazo posible. :: Es una fórmula frecuente en mensajes formales.
- En relación con el incumplimiento. :: Eso es w związku z niedotrzymaniem.
- A partir de los datos presentados. :: Eso es na podstawie przedstawionych danych.
