@ 6 | Robię zakupy | Voy de compras
I Elegimos ropa, describimos colores y preguntamos precios y tallas.
E La ropa como objeto :: Con **kupuję** («compro») el nombre de la prenda va en acusativo. :: Muchos nombres femeninos cambian **-a** por **-ę**: **kurtka → kurtkę**, **koszula → koszulę**.
E Nombres plurales :: **Spodnie** («pantalones») y **buty** («zapatos») se usan en plural. :: **Noszę spodnie** significa «llevo pantalones».
B Prendas | Concepto | Forma básica | Como objeto | Español
| camisa | koszula | koszulę | camisa
| chaqueta | kurtka | kurtkę | chaqueta
| vestido | sukienka | sukienkę | vestido
| pantalones | spodnie | spodnie | pantalones
W koszula = camisa | ko-SHU-la
W koszulę = camisa (objeto directo) | ko-SHU-le
W sukienka = vestido | su-KYEN-ka
W sukienkę = vestido (objeto directo) | su-KYEN-ke
W kurtka = chaqueta | KURT-ka
W kurtkę = chaqueta (objeto directo) | KURT-ke
W sweter = jersey | SWE-ter
W spodnie = pantalones | SPOD-nye
W buty = zapatos | BU-ti
W czapka = gorro; gorra | CHAP-ka
W czapkę = gorro (objeto directo) | CHAP-ke
W spódnica = falda | spud-NI-tsa
W spódnicę = falda (objeto directo) | spud-NI-tse
W kupuję = compro | ku-PU-ye
W kupujesz = compras | ku-PU-yesh
W noszę = llevo puesto/a | NO-she
W nosisz = llevas puesto/a | NO-shish
W jaki = qué; cuál (masculino) | YA-ki
W rozmiar = talla; tamaño | ROZ-myar
V Ropa y tallas
D De compras
Anna: Co kupujesz? = ¿Qué compras?
> Co = qué | kupujesz = verbo (compras)
Tom: Kupuję kurtkę. = Compro una chaqueta.
> Kupuję = verbo (compro) | kurtkę = chaqueta (objeto)
Anna: Czy nosisz spodnie? = ¿Llevas pantalones?
> Czy = partícula de pregunta | nosisz = verbo (llevas puesto) | spodnie = pantalones
Tom: Tak, noszę spodnie. = Sí, llevo pantalones.
> Tak = afirmación (sí) | noszę = verbo (llevo puesto) | spodnie = pantalones
Anna: Jaki rozmiar nosisz? = ¿Qué talla llevas?
> Jaki = interrogativo (qué) | rozmiar = talla | nosisz = verbo (llevas)
Tom: Mały rozmiar. = Una talla pequeña.
> Mały = adjetivo (pequeño) | rozmiar = talla
Anna: A koszulę? = ¿Y una camisa?
> A = y | koszulę = camisa (objeto)
Tom: Nie, kupuję sweter. = No, compro un jersey.
> Nie = negación (no) | kupuję = verbo (compro) | sweter = jersey
Q ¿Qué significa sukienka?
+ Vestido. :: Es una prenda de vestir.
- Chaqueta. :: Chaqueta es kurtka.
- Falda. :: Falda es spódnica.
R Kupuję kurtkę. :: Traduce al español.
+ Compro una chaqueta. :: kupuję significa «compro».
- Llevo una chaqueta. :: Llevo puesto se dice noszę.
- Compro una camisa. :: Camisa es koszula.
H Kupujesz ___. :: Completa «Compras un vestido».
+ sukienkę :: El objeto femenino termina en -ę.
- sukienka :: Es la forma básica.
- kurtkę :: kurtkę significa «chaqueta», no «vestido».
A Czy nosisz spodnie? :: ¿Qué pregunta la frase que oyes?
+ ¿Llevas pantalones? :: nosisz significa «llevas puesto».
- ¿Compras pantalones? :: «Compras» sería kupujesz.
- ¿Qué talla llevas? :: Esa pregunta es Jaki rozmiar nosisz?
O Kupuję sweter. :: Compro un jersey. :: kupuję es la forma de «yo» de comprar.
X Escribe «Llevo zapatos». :: Noszę buty. :: buty se usa en plural.
Q ¿Qué significa rozmiar?
+ Talla; tamaño. :: Se usa para hablar de la talla de la ropa.
- Color. :: Color se dice kolor.
- Precio. :: Precio se dice cena.
R Mały rozmiar. :: Traduce al español.
+ Una talla pequeña. :: mały significa «pequeño».
- Una talla grande. :: Grande es duży.
- Un jersey pequeño. :: Jersey es sweter.

@ 6 | Jaki kolor? | ¿Qué color?
I Describimos ropa con adjetivos de color y aprendemos a señalar una prenda.
E Concordancia :: El color concuerda con el género de la prenda: **czerwony sweter**, **czerwona koszula**. :: Igual que otros adjetivos, cambia con el nombre.
E La prenda como objeto :: Con una prenda femenina como objeto, el adjetivo también cambia: **ta czerwona kurtka** («esta chaqueta roja») pasa a **tę czerwoną kurtkę** («esta chaqueta roja», como objeto). :: La forma del español no cambia así.
B Color y género | Concepto | Masculino | Femenino | Femenino como objeto
| rojo | czerwony sweter | czerwona koszula | czerwoną kurtkę
| azul | niebieski sweter | niebieska kurtka | niebieską kurtkę
| negro | czarny sweter | czarna koszula | czarną koszulę
| blanco | biały sweter | biała koszula | białą koszulę
W kolor = color | KO-lor
W czerwony = rojo (masculino) | cher-VO-ni
W czerwona = roja (femenino) | cher-VO-na
W czerwoną = roja (objeto femenino) | cher-VO-ną
W niebieski = azul (masculino) | nye-BYES-ki
W niebieska = azul (femenino) | nye-BYES-ka
W niebieską = azul (objeto femenino) | nye-BYES-ką
W czarny = negro (masculino) | CHAR-ni
W czarna = negra (femenino) | CHAR-na
W czarną = negra (objeto femenino) | CHAR-ną
W biały = blanco (masculino) | BYA-wi
W biała = blanca (femenino) | BYA-wa
W białą = blanca (objeto femenino) | BYA-wą
W ten = este (masculino) | TEN
W ta = esta (femenino) | TA
W tę = esta (objeto femenino) | TE
V Colores y concordancia
D Colores en la tienda
Anna: Jaki kolor lubisz? = ¿Qué color te gusta?
> Jaki kolor = qué color | lubisz = verbo (te gusta)
Tom: Lubię czarny kolor. = Me gusta el color negro.
> Lubię = verbo (me gusta) | czarny kolor = color negro
Anna: A koszula? = ¿Y la camisa?
> A = y | koszula = camisa
Tom: Ta koszula jest czerwona. = Esta camisa es roja.
> Ta koszula = esta camisa | jest = verbo (es) | czerwona = adjetivo femenino (roja)
Anna: Lubisz tę niebieską kurtkę? = ¿Te gusta esta chaqueta azul?
> Lubisz = verbo (te gusta) | tę niebieską kurtkę = esta chaqueta azul (objeto)
Tom: Tak, lubię tę kurtkę. = Sí, me gusta esta chaqueta.
> Tak = afirmación (sí) | lubię = verbo (me gusta) | tę kurtkę = esta chaqueta (objeto)
Anna: A ten sweter? = ¿Y este jersey?
> A = y | ten sweter = este jersey
Tom: Ten sweter jest biały. = Este jersey es blanco.
> Ten sweter = este jersey | jest = verbo (es) | biały = adjetivo masculino (blanco)
Q ¿Qué significa czerwona?
+ Roja. :: Es la forma femenina de «rojo».
- Rojo. :: Rojo masculino es czerwony.
- Azul. :: Azul femenino es niebieska.
R Ta koszula jest czerwona. :: Traduce al español.
+ Esta camisa es roja. :: ta es «esta» y czerwona concuerda con koszula.
- Esta camisa es negra. :: Negra es czarna.
- Este jersey es rojo. :: Jersey es sweter.
H Lubię tę ___ kurtkę. :: Completa «Me gusta esta chaqueta azul».
+ niebieską :: El adjetivo concuerda con kurtkę, objeto femenino.
- niebieska :: Es la forma femenina básica.
- niebieski :: Es la forma masculina.
A Ten sweter jest biały. :: ¿Qué significa la frase que oyes?
+ Este jersey es blanco. :: ten y biały concuerdan con sweter.
- Esta camisa es blanca. :: Eso sería Ta koszula jest biała.
- Este jersey es negro. :: Negro es czarny.
O Ta czerwona koszula. :: Esta camisa roja. :: ta y czerwona concuerdan con koszula.
X Escribe «Me gusta esta chaqueta negra». :: Lubię tę czarną kurtkę. :: tę y czarną son formas femeninas de objeto.
Q ¿Qué significa tę?
+ Esta, como objeto femenino. :: Se usa, por ejemplo, en tę kurtkę.
- Este, con un nombre masculino. :: Este masculino es ten.
- Esta, como sujeto femenino. :: Como sujeto se usa ta.
R Lubię czarny kolor. :: Traduce al español.
+ Me gusta el color negro. :: czarny concuerda con kolor, que es masculino.
- Me gusta el color azul. :: Azul es niebieski.
- Me gusta la camisa negra. :: Eso sería Lubię czarną koszulę.

@ 6 | Ile kosztuje? | ¿Cuánto cuesta?
I Preguntamos por el precio, la talla y cómo pagar.
E Preguntar el precio :: **Ile kosztuje ta kurtka?** significa «¿Cuánto cuesta esta chaqueta?». :: Para una respuesta sencilla, se dice **Kurtka kosztuje czterdzieści złotych** («La chaqueta cuesta cuarenta zlotis»).
E Pagar :: **Płacę kartą** significa «Pago con tarjeta» y **płacę gotówką**, «Pago en efectivo». :: Los nombres después de estas formas van en instrumental; aprende las combinaciones completas.
B Pagos | Polaco | Español
| płacę kartą | pago con tarjeta
| płacę gotówką | pago en efectivo
| paragon, proszę | el recibo, por favor
W cena = precio | TSE-na
W drogi = caro (masculino) | DRO-gi
W droga = cara (femenino) | DRO-ga
W karta = tarjeta | KAR-ta
W kartą = con tarjeta; pagando con tarjeta | KAR-tą
W gotówka = efectivo; dinero en efectivo | go-TUF-ka
W gotówką = en efectivo; con dinero en efectivo | go-TUF-ką
W płacę = pago | PWA-tse
W płacisz = pagas | PWA-chish
W paragon = recibo de compra | pa-RA-gon
W tylko = solo; solamente | TI-ko
W razem = en total; juntos | RA-zem
V Precios y pagos
D En la caja
Anna: Czy masz mały rozmiar? = ¿Tienes una talla pequeña?
> Czy = partícula de pregunta | masz = verbo (tienes) | mały rozmiar = talla pequeña
Tom: Mam tylko mały rozmiar. = Solo tengo una talla pequeña.
> Mam = verbo (tengo) | tylko = adverbio (solo) | mały rozmiar = talla pequeña
Anna: Ile kosztuje ta kurtka? = ¿Cuánto cuesta esta chaqueta?
> Ile kosztuje = cuánto cuesta | ta kurtka = esta chaqueta
Tom: Ta kurtka kosztuje czterdzieści złotych. = Esta chaqueta cuesta cuarenta zlotis.
> Ta kurtka = esta chaqueta | kosztuje = verbo (cuesta) | czterdzieści złotych = cuarenta zlotis
Anna: Ta kurtka jest droga. = Esta chaqueta es cara.
> Ta kurtka = esta chaqueta | jest = verbo (es) | droga = adjetivo femenino (cara)
Tom: Płacisz kartą? = ¿Pagas con tarjeta?
> Płacisz = verbo (pagas) | kartą = con tarjeta
Anna: Nie, płacę gotówką. = No, pago en efectivo.
> Nie = negación (no) | płacę = verbo (pago) | gotówką = en efectivo
Tom: Razem czterdzieści złotych. = En total, cuarenta zlotis.
> Razem = en total | czterdzieści złotych = cuarenta zlotis
Anna: Paragon, proszę. = El recibo, por favor.
> Paragon = recibo | proszę = fórmula cortés (por favor)
Q ¿Qué pregunta Ile kosztuje?
+ ¿Cuánto cuesta? :: Se usa para preguntar el precio.
- ¿Qué talla llevas? :: Eso es Jaki rozmiar nosisz?
- ¿Qué color es? :: Color es kolor.
R Ta kurtka kosztuje czterdzieści złotych. :: Traduce al español.
+ Esta chaqueta cuesta cuarenta zlotis. :: czterdzieści significa «cuarenta».
- Esta chaqueta cuesta veinte zlotis. :: Veinte es dwadzieścia.
- Esta chaqueta es cara. :: Eso es Ta kurtka jest droga.
H Płacę ___. :: Completa «Pago en efectivo».
+ gotówką :: Es una expresión fija de pago.
- kartą :: Significa «con tarjeta».
- gotówka :: Es la forma básica del nombre.
A Płacisz kartą? :: ¿Qué pregunta la frase que oyes?
+ ¿Pagas con tarjeta? :: płacisz significa «pagas».
- ¿Pago con tarjeta? :: «Pago» es płacę.
- ¿Cuánto cuesta la tarjeta? :: Esa pregunta sería Ile kosztuje karta?
O Razem czterdzieści złotych. :: En total, cuarenta zlotis. :: razem significa «en total».
X Escribe «Pago con tarjeta». :: Płacę kartą. :: kartą es la forma instrumental de karta.
Q ¿Qué significa paragon?
+ Recibo de compra. :: Lo puedes pedir al pagar.
- Precio. :: Precio es cena.
- Talla. :: Talla es rozmiar.
R Ta kurtka jest droga. :: Traduce al español.
+ Esta chaqueta es cara. :: droga es la forma femenina de caro.
- Esta chaqueta es barata. :: Barata sería tania.
- Esta chaqueta es grande. :: Grande es duża.
