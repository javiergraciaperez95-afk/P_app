@ 35 | Se avessi tempo, potremmo partire | El periodo ipotetico de posibilidad y de irrealidad
I Las frases con «si» pueden hablar de lo posible, de lo imposible en el presente o de lo que no pasó en el pasado. Esta lección junta los tres casos que más se usan en el nivel B2.
E Posibilidad: se + imperfetto de congiuntivo, condizionale presente :: Lo que sería posible si ocurriera algo: **Se avessi tempo, potremmo partire** (si tuviera tiempo, podríamos salir). :: Es el tipo II ya visto en el B1, con el condicional de cualquier verbo.
E Cortesía con condicional :: **Vorremmo** (querríamos), **accetterei** (aceptaría), **mi trasferirei** (me mudaría). :: Es una manera educada de decir lo que harías.
B Condicional | Ejemplo | Español
| potremmo | Potremmo partire. | Podríamos salir.
| vorremmo | Vorremmo andare. | Querríamos ir.
| accetterei | Accetterei volentieri. | Aceptaría con gusto.
| mi trasferirei | Mi trasferirei subito. | Me mudaría enseguida.
W potremmo = podríamos | po-TREM-mo
W vorremmo = querríamos | vo-REM-mo
W accetterei = aceptaría | at-tʃet-TE-rei
W cambierei = cambiaría | kam-bie-REI
W trasferirsi = mudarse | tra-sfe-RIR-si
W mi trasferirei = me mudaría | mi tra-sfe-REI
W estero = extranjero | e-STE-ro
W ci andremmo = iríamos allí | tci an-DREM-mo
W altra = otra | AL-tra
W offerta = oferta | of-FER-ta
V Vocabulario: posibilidad y cortesía
D Se avessi tempo
Anna: Se avessi tempo, potremmo partire. = Si tuviera tiempo, podríamos salir.
  > se avessi tempo = si tuviera tiempo | potremmo partire = podríamos salir
Luca: Io accetterei volentieri. = Yo aceptaría con gusto.
  > accetterei = aceptaría | volentieri = con gusto
Anna: E se fosse lontano? = ¿Y si fuera lejos?
  > se fosse = si fuera | lontano = lejos
Luca: Mi trasferirei subito. = Me mudaría enseguida.
  > mi trasferirei = me mudaría | subito = enseguida
Q ¿Cómo se dice «podríamos salir»?
+ potremmo partire :: Condicional de «potere».
- possiamo partire :: Eso es presente.
- potessimo partire :: Eso es congiuntivo imperfetto.
H Se avessi tempo, ___ partire. :: Podríamos (potremmo)
+ potremmo :: Condicional de «potere» con «noi».
- potremo :: Eso es futuro.
- possiamo :: Eso es presente.
R Accetterei volentieri.
+ Aceptaría con gusto. :: Condicional de «accettare».
- Acepto con gusto. :: Eso es presente.
- Acepté con gusto. :: Eso es pasado.
A Mi trasferirei subito.
+ Me mudaría enseguida. :: Condicional reflexivo.
- Me mudo enseguida. :: Eso es presente.
- Me mudé enseguida. :: Eso es pasado.
O Ci andremmo :: Iríamos allí :: Condicional de «andare» con «ci».
X Escribe en italiano: «querríamos ir» :: Vorremmo andare. :: Condicional de «volere».
Q ¿Qué significa «altra»?
+ otra :: Femenino de «altro».
- otro :: Eso es masculino: «altro».
- ninguna :: Eso sería «nessuna».
Q ¿Cuál es correcta para «si estuviera lejos, iría»?
+ Se fosse lontano, andrei. :: Tipo II: «se» + congiuntivo imperfetto + condicional.
- Se è lontano, andrei. :: Falta el congiuntivo imperfetto.
- Se fosse lontano, vado. :: Falta el condicional.

@ 35 | Se fossi stato più attento | Lo irreal del pasado: si hubiera hecho
I Cuando algo no pasó y te arrepientes o lo comentas, usas el tipo III: «si lo hubiera sabido, habría llamado». Es la forma de hablar de lo que pudo ser y no fue.
E El tipo III :: **Se** + congiuntivo trapassato, y en la otra parte el condizionale passato: **Se avessi saputo, avrei chiamato** (si lo hubiera sabido, habría llamado). :: Se usan **fossi stato** (hubiera sido) o **avessi fatto** (hubiera hecho) en la parte del «se».
E Condicional passato :: **avrei** + participio: **avrei chiamato** (habría llamado), **avrei dovuto** (habría debido), **avrei potuto** (habría podido). :: Con **essere** se concuerda: **sarei andata** (habría ido, ella).
B Si... (trapassato) | ...entonces (condizionale passato) | Español
| Se avessi saputo | avrei chiamato | si lo hubiera sabido, habría llamado
| Se fossi stato attento | non avrei sbagliato | si hubiera estado atento, no me habría equivocado
W attento = atento | at-TEN-to
W attenta = atenta | at-TEN-ta
W avremmo = habríamos | a-VREM-mo
W avreste = habríais | a-VRES-te
W avrebbe potuto = habría podido | a-VREB-be po-TU-to
W sarei stato = habría sido | sa-REI STA-to
W avrei avuto = habría tenido | a-VREI a-VU-to
W avuto = tenido | a-VU-to
W avrebbero = habrían | a-VREB-be-ro
W avresti fatto = habrías hecho | a-VRES-ti FAT-to
W avrei sbagliato = me habría equivocado | a-VREI zba-LIA-to
W se fossi stato = si yo hubiera sido | se FOS-si STA-to
W più attento = más atento | pju at-TEN-to
V Vocabulario: lo que no fue
D Se avessi saputo
Anna: Se avessi saputo, avrei chiamato. = Si lo hubiera sabido, habría llamado.
  > se avessi saputo = si lo hubiera sabido | avrei chiamato = habría llamado
Luca: Se fossi stato più attento, non avrei sbagliato. = Si hubiera estado más atento, no me habría equivocado.
  > se fossi stato = si hubiera estado | più attento = más atento | non avrei sbagliato = no me habría equivocado
Anna: Avreste dovuto venire. = Habríais debido venir.
  > avreste dovuto venire = habríais debido venir
Luca: Avremmo voluto venire. = Habríamos querido venir.
  > avremmo voluto venire = habríamos querido venir
Q ¿Qué significa «sarei stato»?
+ habría sido (yo) :: Condicional passato de «essere».
- soy :: Eso es presente.
- sería :: Eso es condicional presente.
H Se fossi stato più attento, non ___ sbagliato. :: Habría (avrei)
+ avrei :: Condicional passato con «io».
- avevo :: Eso es imperfecto.
- ho :: Eso es presente.
R Avreste dovuto venire.
+ Habríais debido venir. :: Condicional passato con «voi».
- Debéis venir. :: Eso es presente.
- Debisteis venir. :: Eso es pasado.
A Avremmo voluto venire.
+ Habríamos querido venir. :: Condicional passato con «noi».
- Queremos venir. :: Eso es presente.
- Quisimos venir. :: Eso es pasado.
O Avrei avuto :: Habría tenido :: Condicional passato de «avere».
X Escribe en italiano: «habríais podido» :: Avreste potuto. :: Condicional passato con «voi».

+ habría sido (yo) :: Condicional passato de «essere».
- soy :: Eso es presente.
- sería :: Eso es condicional presente.
Q ¿Cuál es correcta para «si lo hubiera sabido, habría llamado»?
+ Se avessi saputo, avrei chiamato. :: Tipo III: trapassato + condizionale passato.
- Se sapevo, avrei chiamato. :: Falta el congiuntivo trapassato.
- Se avessi saputo, chiamo. :: Falta el condizionale passato.

@ 35 | Parla come se sapesse tutto | Periodo mixto y «come se»
I Hay frases que mezclan dos tiempos: lo que no pasó en el pasado y su efecto en el presente. Y «come se» (como si) lleva congiuntivo imperfetto.
E Como si :: **Come se** + congiuntivo imperfetto: **Parla come se sapesse tutto** (habla como si lo supiera todo). :: Describe una comparación que no es real.
E Mixto :: **Se fossi partito ieri, ora sarei lì** (si hubieras salido ayer, ahora estarías allí). :: La condición es del pasado y el resultado es del presente.
B Frase | Función | Español
| come se sapesse | comparación irreal | como si lo supiera
| come se fosse | comparación irreal | como si fuera
| ora sarei lì | efecto presente | ahora estaría allí
W come se = como si | KO-me se
W sapesse = supiera | sa-PES-se
W credesse = creyera | kre-DES-se
W sembrasse = pareciera | sem-BRAS-se
W come se fosse = como si fuera | KO-me se FOS-se
W lì = allí | LI
W sarei lì = estaría allí | sa-REI LI
W tratta = trata | TRAT-ta
W trattare = tratar | trat-TA-re
W ci sarei = estaría allí | tci sa-REI
W stupito = sorprendido | stu-PI-to
W serio = serio | SE-rio
V Vocabulario: como si y mixto
D Parla come se sapesse tutto
Anna: Parla come se sapesse tutto! = ¡Habla como si lo supiera todo!
  > come se sapesse = como si lo supiera | tutto = todo
Luca: Ha ragione, sembra stupito. = Tiene razón, parece sorprendido.
  > sembra stupito = parece sorprendido
Anna: Se fossi partito ieri, ora sarei lì. = Si hubieras salido ayer, ahora estarías allí.
  > se fossi partito = si hubieras salido | ora sarei lì = ahora estarías allí
Luca: È vero, ma non sono partito. = Es verdad, pero no salí.
  > è vero = es verdad | non sono partito = no salí
Q ¿Qué significa «parla come se sapesse tutto»?
+ habla como si lo supiera todo :: «Come se» + congiuntivo imperfetto.
- habla como si lo sabe todo :: Falta el congiuntivo.
- habla y sabe todo :: No es comparación.
H Parla come se ___ tutto. :: Supiera (sapesse)
+ sapesse :: Congiuntivo imperfetto.
- sa :: Eso es presente.
- saprà :: Eso es futuro.
R Se fossi partito ieri, ora sarei lì.
+ Si hubieras salido ayer, ahora estarías allí. :: Periodo mixto: pasado y presente.
- Si sales ayer, ahora estarás allí. :: Eso no es mixto.
- Si hubiera salido ayer, estoy allí. :: No hay condicional.
A Sembra stupito.
+ Parece sorprendido. :: «Sembra» = parece.
- Parece serio. :: «Serio» es serio, no «stupito».
- Siembra sorprendido. :: Eso no es «sembra».
O Ci sarei :: Estaría allí :: Condicional de «essere» con «ci».
X Escribe en italiano: «como si lo creyera» :: Come se credesse. :: «Come se» + congiuntivo imperfetto.
Q ¿Qué significa «trattare»?
+ tratar :: Verbo.
- tratarse :: Eso sería «trattarsi».
- trazar :: Eso sería «tracciare».
Q ¿Cuál es correcta para «como si fuera»?
+ come se fosse :: «Come se» + congiuntivo imperfetto.
- come se è :: Con «come se» va imperfecto de congiuntivo.
- come se sia :: Eso es congiuntivo presente.
