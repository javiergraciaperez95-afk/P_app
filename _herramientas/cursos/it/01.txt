@ 1 | Ciao! | Saludar y decir cómo te llamas
I El italiano se parece mucho al español, y eso ayuda. Pero ojo: se parece tanto que es fácil confiarse. En la pronunciación verás en MAYÚSCULAS la sílaba que lleva el acento.
E Saludar :: **Ciao** es informal y sirve para saludar y para despedirse. :: Con más distancia: **buongiorno** se usa durante el día y **buonasera** desde la tarde o al anochecer; el momento del cambio varía según el lugar y la situación. :: Para despedirte: **arrivederci**. Antes de dormir: **buonanotte**.
E Tú y usted :: **Tu** es «tú». Para tratar de usted se usa **Lei**, la misma forma verbal que con «ella»: **Lei si chiama**. Escribir **Lei** con mayúscula es una convención de cortesía opcional; también se encuentra **lei**. :: Para decir tu nombre: **Mi chiamo Anna** (me llamo Anna) o **Sono Anna** (soy Anna). :: Para preguntarlo: **Come ti chiami?** (tú) o **Come si chiama?** (usted). :: Al conocer a alguien: **Piacere** (encantado).

+ Ciao :: Vale para las dos cosas en registro informal.
- Buongiorno :: Es más formal y solo se utiliza para saludar de día.
- Arrivederci :: Se utiliza únicamente para despedirse.

@ 1 | L'alfabeto | El alfabeto y los sonidos del italiano
E Casi todo se lee como se escribe :: El italiano se pronuncia casi como se escribe, y las vocales suenan como en español. Solo hay que aprender unas pocas combinaciones. :: **c** y **g** delante de **e, i** suenan suaves: **ce** = «che», **ci** = «chi», **ge** = como «ye», **gi** = como «yi». Por eso **ciao** se dice «chao». :: Para que suenen fuertes delante de e, i se añade una **h**: **che** = «ke», **chi** = «ki», **ghe**, **ghi**. Por eso **chiamo** se dice «kiamo».

E Las consonantes dobles :: En italiano las consonantes dobles **se mantienen más tiempo** que las simples y pueden cambiar el significado: **anno** (año) no suena igual que **ano**. :: La **h** no suena. La **v** se pronuncia con los dientes sobre el labio inferior. La **s** entre vocales puede sonar como una s sorda o una s sonora según la palabra, la región y el hablante; no conviene aprender una regla única.

Q ¿Cómo se pronuncia «ciao»?
+ «chao» :: «Ci» suena «chi» y la i casi no se oye ante la vocal.
- «siao» :: La «c» no tiene sonido de «s» en italiano.
- «kiao» :: Sonaría con «k» si tuviera una h intercalada: «chiao».
Q ¿Cómo se pronuncia «chi»?
+ «ki» :: La «h» intercalada hace que la «c» conserve el sonido duro /k/.
- «chi» :: Así suena la combinación directa «ci».
- «shi» :: Ese sonido corresponde a «sci».
Q ¿Cómo suena «gn» en «signora»?
+ Como la «ñ» española. :: «Gn» forma un único fonema palatal nasal /ɲ/.
- «g» y «n» por separado. :: En italiano forman un dígrafo indivisible.
- Como una «n» simple. :: Tiene una articulación palatal completa, idéntica a la «ñ».
R Non capisco.
+ No entiendo. :: Frase fundamental para indicar incomprensión.
- No lo sé. :: «No lo sé» se dice «non lo so».
- No hablo. :: «No hablo» se dice «non parlo».
H Scusi, può ___ ?
+ ripetere :: «Può ripetere?» significa «¿puede repetir?» (modal + infinitivo).
- capisco :: Es primera persona («entiendo»), no un infinitivo dependiente de «può».
- scrive :: Es tercera persona de indicativo («escribe»), no un infinitivo.
H Come si ___ ?
+ scrive :: «Come si scrive?» = «¿cómo se escribe?».
- chiama :: Preguntaría por el nombre: «¿cómo se llama?».
- sta :: No se combina con «si» para preguntar por la ortografía.
R Il Suo nome, per favore? :: ¿Qué solicita esta frase en recepción?
+ ¿Su nombre, por favor? :: «Nome» es el nombre de pila y «il Suo» indica cortesía.
- ¿Su apellido, por favor? :: «Apellido» se dice «cognome».
- ¿Su habitación, por favor? :: No menciona la habitación; pide el nombre.
O Può ripetere per favore :: ¿Puede repetir, por favor? :: Può + infinitivo + per favore.

@ 1 | C o ci? | Leer «c», «ci» y «ch»
I En italiano, la letra «c» cambia de sonido según la vocal que le sigue: dulce ante «e, i» y dura ante «a, o, u» o con «h».
E La «c» dulce y la «c» dura :: Delante de **a, o, u**, la «c» suena fuerte /k/, igual que en español: **casa**, **come**, **ascolta**. :: Delante de **e, i**, la «c» suena dulce /tʃ/, exactamente como la «ch» española: **cena** (se lee «chena»), **cinema** (se lee «chínema»), **dieci** (se lee «diechi»). :: Para mantener el sonido fuerte /k/ ante e, i, se intercala una «h» muda: **chi** (se lee «ki»), **che** (se lee «ke»), **amiche** (se lee «amike»).
E Las combinaciones cia, cio, ciu :: Cuando veas **cia**, **cio** o **ciu**, la «i» no se pronuncia como vocal independiente: sirve únicamente para indicar que la «c» suena dulce como «ch». Por eso **ciao** se lee «chao» y **cioccolato** se lee «chocolato».

- «kena» :: Para sonar fuerte «k» ante «e» necesitaría una «h»: «ch».
Q ¿Por qué «amiche» se escribe con «h»?

Q En la palabra «ciao», ¿qué función cumple la letra «i»?

- Se pronuncia como una vocal tónica separada. :: El acento recae en la «a», no en la «i».
- Indica que la palabra es plural. :: «Ciao» es un saludo invariable.

Q ¿Cómo se pronuncia el grupo «gn» en «bagno» o «signora»?
+ Como la «ñ» española. :: «Gn» forma un único sonido palatal nasal /ɲ/.
- Como una «g» seguida de «n» pronunciadas por separado. :: En italiano forman un dígrafo inseparable que suena «ñ».
- Como una «n» suave sin apoyo palatal. :: No, tiene el sonido pleno de la «ñ».
Q ¿Cómo suena «gli» en palabras como «figlio» o «famiglia»?
+ Como una «ll» palatal tradicional, líquida y suave. :: «Gli» representa el fonema /ʎ/, similar a la «ll» clásica.
- Como una «g» dura seguida de «li» («g-li»). :: Salvo excepciones cultas muy raras, «gli» suena siempre palatal.
- Como una «j» española fuerte. :: El sonido es suave y lateral, sin fricción velar.

@ 1 | Consonantes dobles y acentos | Distinguir dobles y acentos gráficos
I Las consonantes dobles se pronuncian con más duración y pueden cambiar el significado; las palabras agudas llevan acento escrito obligatorio.
E Las consonantes dobles :: En italiano las consonantes dobles (**doppie**) se pronuncian con mayor tensión y duración que las simples: **penna** (bolígrafo) no suena igual que **pena** (pena, lástima); **notte** (noche) no suena igual que **note** (notas). La diferencia es fonológica y distingue significados.
E El acento gráfico final :: En italiano se escribe tilde obligatoria en las palabras agudas polisílabas que terminan en vocal: **città**, **perché**, **caffè**, **lunedì**, **università**. Q ¿Por qué es fundamental pronunciar bien las consonantes dobles en italiano?
+ Porque sostener la consonante más tiempo puede cambiar el significado de la palabra. :: Por ejemplo, «penna» (bolígrafo) y «pena» (pena) son palabras distintas.
- Porque las consonantes dobles siempre indican que la palabra es plural. :: No guardan relación con el plural morfológico.
- Porque una consonante doble siempre lleva tilde escrita. :: Las consonantes dobles no añaden ninguna tilde.
Q ¿En qué casos es obligatorio escribir acento gráfico en italiano?
+ En palabras polisílabas con acento en la última sílaba, como «città», «caffè» o «lunedì». :: Las palabras agudas de más de una sílaba siempre llevan tilde escrita en la vocal final.
- En todas las palabras llanas o esdrújulas. :: En italiano no se marca tilde en palabras llanas o esdrújulas regulares.
- Solo en las oraciones interrogativas. :: El acento gráfico es ortográfico y léxico, no entonativo.

Q ¿Cuál es diferencia entre «è» y «e»?
