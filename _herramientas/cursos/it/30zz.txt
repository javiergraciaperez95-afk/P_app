@ 30 | Ripasso finale | Repaso final de B1
E Repaso final de B1 :: Doce preguntas para comprobar estructuras clave de los capítulos 21–30. Revisa la unidad correspondiente cuando dudes; este ejercicio orienta el repaso, pero no certifica por sí solo el nivel.
Q Cuando sono arrivata, loro ___ già mangiato.
+ avevano :: Trapassato: auxiliar en imperfecto + participio.
- hanno :: Passato prossimo, no expresa la anterioridad que pide la frase.
- erano :: «Mangiare» forma este tiempo con «avere».
Q ¿Cuál es una petición formal y cortés?
+ Mi potrebbe indicare la stazione? :: Condicional de cortesía con «Lei».
- Mi puoi indicare la stazione? :: «Puoi» trata de tú.
- Mi indicavi la stazione. :: Es imperfecto, no una petición cortés.
Q ¿Qué frase expresa certeza?
+ So che è libero. :: «So che» presenta la información como conocida.
- Penso che sia libero. :: Expresa opinión.
- È possibile che sia libero. :: Expresa posibilidad.
Q Completa la condición real: «Se parti adesso, ___ in tempo».
+ arriverai :: Una consecuencia futura puede ir en futuro.
- arrivassi :: Es congiuntivo imperfetto.
- arriverei :: Es condicional.
Q ¿Cuál expresa una hipótesis poco probable?
+ Se avessi tempo, viaggerei. :: «Se» + congiuntivo imperfetto y condicional.
- Se ho tempo, viaggio. :: Es una condición real.
- Se avrò tempo, viaggio. :: No expresa la hipótesis con esta estructura.
R Mi ha chiesto se avevo mangiato. :: ¿Qué significa?
+ Me preguntó si yo había comido. :: «Avevo» concuerda con el «io» sobreentendido.
- Me preguntó si él había comido. :: Para «él» sería «aveva».
- Me dijo que comía. :: Es una pregunta indirecta sobre una acción anterior.
Q Completa: «Chiunque ___ un’idea può partecipare».
+ abbia :: Congiuntivo con «chiunque» en esta lectura.
- ha :: Aquí no se usa el indicativo.
- avere :: Se necesita un verbo conjugado.
Q ¿Qué frase es correcta?
+ La città in cui vivo è più tranquilla di Milano. :: Relativo con preposición y comparativo.
- La città cui vivo è più tranquilla di Milano. :: «Cui» necesita su preposición.
- La città in che vivo è più tranquilla di Milano. :: Tras la preposición se usa «cui».
Q ¿Cómo se escribe «se lo he dicho»?
+ Gliel’ho detto. :: Pronombres combinados y elisión ante «ho».
- Gli lo ho detto. :: La combinación no se separa.
- Glielo ha detto. :: Cambia la persona del auxiliar.
Q ¿Qué significa «Quanti ne vuoi?»?
+ ¿Cuántos quieres? :: «Ne» retoma la cantidad o el nombre mencionado.
- ¿Cuándo vienes? :: Eso sería «Quando vieni?».
- ¿Cuántos quieres de mí? :: «Ne» no significa «de mí».
Q ¿Cuál es correcta para «lo estoy haciendo»?
+ Lo sto facendo. :: El pronombre puede ir antes de «stare».
- Lo sto fare. :: Se necesita el gerundio.
- Sto lo facendo. :: El pronombre no se coloca ahí.
Q ¿Qué conector completa «Piove, ___ restiamo a casa» para indicar consecuencia?
+ quindi :: Equivale a «así que».
- anche se :: Significa «aunque».
- oppure :: Presenta una alternativa.
