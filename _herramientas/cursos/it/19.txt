@ 19 | Le previsioni | El tiempo: previsiones y estado del cielo
I El tiempo es el tema estrella para charlar. Ya sabes «fa caldo» y «piove». Ahora aprenderás a describir el cielo y a leer la previsión.
E El tiempo que hace :: Con **fa** + sustantivo: **fa caldo** (hace calor), **fa freddo** (hace frío), **fa vento** (hace viento). Con **c'è** o **ci sono** para lo que hay: **C'è nebbia** (hay niebla), **Ci sono nuvole** (hay nubes). :: Para el cielo: **Oggi è nuvoloso** (hoy está nublado).
E Las previsiones :: Las **previsioni** dicen qué va a pasar: **pioggia** (lluvia), **neve** (nieve), **temporale** (tormenta). :: Si llueve, lleva un **ombrello** (paraguas). Si hace frío, ponte la **sciarpa** (bufanda), que se ve en la lección 057.
B Tiempo | Italiano | Español
| calor | fa caldo | hace calor
| niebla | c'è nebbia | hay niebla
| nubes | ci sono nuvole | hay nubes
| lluvia | piove | llueve
| nieve | c'è neve | hay nieve
W previsioni = previsiones | pre-vi-ZIO-ni
W nuvoloso = nublado | nu-vo-LO-so
W nuvole = nubes | NU-vo-le
W temporale = tormenta | tem-po-RA-le
W nebbia = niebla | NEB-bia
W umido = húmedo | U-mi-do
W pioggia = lluvia | PIOD-dja
W neve = nieve | NE-ve
W ombrello = paraguas | om-BREL-lo
W ghiaccio = hielo | GIAT-tcho
W gradi = grados | GRA-di
W sembra = parece | SEM-bra
W porto = llevo | POR-to
V Vocabulario: el tiempo
D Che tempo fa?
Sara: Che tempo fa oggi? = ¿Qué tiempo hace hoy?
  > che tempo fa = qué tiempo hace
Luca: C'è nebbia, e fa freddo. = Hay niebla, y hace frío.
  > c'è nebbia = hay niebla | fa freddo = hace frío
Sara: Le previsioni: pioggia e vento. = Las previsiones: lluvia y viento.
  > le previsioni = las previsiones | pioggia = lluvia | vento = viento
Luca: Allora porto un ombrello. = Entonces llevo un paraguas.
  > porto = llevo | un ombrello = un paraguas
Sara: Brava! Qui piove spesso. = ¡Bien hecho! Aquí llueve a menudo.
  > piove = llueve | spesso = a menudo
Q ¿Cómo se dice «hace frío»?
+ Fa freddo. :: «Fa» + sustantivo para el tiempo.
- È freddo. :: Eso es «está frío».
- Ha freddo. :: Con el tiempo no se usa «ha».
Q ¿Qué significa «c'è nebbia»?
+ hay niebla :: «C'è» = hay.
- hay nubes :: Eso es «ci sono nuvole».
- hay sol :: Eso sería «c'è il sole».
H Le previsioni: ___ e vento. :: Lluvia
+ pioggia :: «Pioggia» = lluvia.
- ombrello :: Es un paraguas.
- neve :: Es nieve.
R Ci sono nuvole.
+ Hay nubes. :: «Ci sono» = hay (plural).
- Hay nieve. :: Eso sería «c'è neve».
- Está nublado. :: Eso sería «è nuvoloso».
A Oggi è nuvoloso.
+ Hoy está nublado. :: «Nuvoloso» = nublado.
- Hoy hace sol. :: Eso sería «c'è il sole».
- Hoy hay niebla. :: Eso sería «c'è nebbia».
O Fa caldo :: Hace calor :: «Fa» + sustantivo para el tiempo.
X Escribe en italiano: «hay niebla» :: C'è nebbia. :: «C'è» = hay.
Q ¿Cuál es correcta para «llevo un paraguas»?
+ Porto un ombrello. :: «Portare» = llevar.
- Sono un ombrello. :: «Essere» no es «llevar».
- Ho un ombrello. :: Eso es «tengo un paraguas».

@ 19 | Se piove, resto a casa | Hipótesis reales: «se»
I Para decir «si llueve, me quedo en casa» no hace falta ningún tiempo complicado. En italiano se usa «se» con el presente en las dos partes.
E La condición real :: **Se** (si) + presente, y después el presente de la consecuencia: **Se piove, resto a casa** (si llueve, me quedo en casa). Se usa para lo que es real o probable. :: Si la frase va al revés, la coma se queda igual: **Resto a casa, se piove**.
E Negar la condición :: **Se non piove** (si no llueve). :: Y para conectar: **quindi** (así que), **altrimenti** (si no).
B Condición | Italiano | Español
| si llueve | Se piove, resto a casa. | Si llueve, me quedo en casa.
| si hace frío | Se fa freddo, metto la sciarpa. | Si hace frío, me pongo la bufanda.
| si no llueve | Se non piove, veniamo al mare. | Si no llueve, vamos a la playa.
W se = si (condición) | se
W resto = me quedo | RE-sto
W veniamo = venimos | ve-NIA-mo
W metto = me pongo | MET-to
W possibile = posible | pos-SI-bi-le
W quindi = así que; por eso | KWIN-di
W altrimenti = si no | al-tri-MEN-ti
W pensare = pensar | pen-SA-re
W fuori = fuera | FUO-ri
W bagnato = mojado | ba-NYA-to
W asciutto = seco | a-SHUT-to
W sciarpa = bufanda | SHAR-pa
V Vocabulario: condiciones y planes
D Se piove
Sara: Se piove, resto a casa. = Si llueve, me quedo en casa.
  > se piove = si llueve | resto a casa = me quedo en casa
Luca: Se fa freddo, metto la sciarpa. = Si hace frío, me pongo la bufanda.
  > se fa freddo = si hace frío | metto = me pongo
Sara: Ma se non piove, veniamo al mare! = ¡Pero si no llueve, vamos a la playa!
  > se non piove = si no llueve | veniamo = venimos | al mare = a la playa
Luca: Possibile! Quindi andiamo al mare. = ¡Posible! Así que vamos a la playa.
  > possibile = posible | quindi = así que | andiamo = vamos
Q ¿Qué significa «se piove, resto a casa»?
+ Si llueve, me quedo en casa. :: «Se» = si.
- Si llueve, voy a casa. :: «Resto» = me quedo, no voy.
- Si llueve, vuelvo a casa. :: «Resto» no es «vuelvo».
Q ¿Cuál es correcta para «si hace frío»?
+ Se fa freddo. :: «Se» = si.
- Se fai freddo. :: Con el tiempo se usa «fa».
- Sono freddo. :: Eso es «soy frío».
H ___ piove, resto a casa. :: Si
+ Se :: «Se» = si.
- Sì :: Es «sí».
- Sei :: Es «eres».
R Se non piove, veniamo al mare.
+ Si no llueve, vamos a la playa. :: «Veniamo» = venimos.
- Si llueve, venimos a la playa. :: Falta el «non».
- Si no llueve, nos quedamos. :: Eso sería «restiamo».
A Metto la sciarpa.
+ Me pongo la bufanda. :: «Metto» = me pongo.
- Me quito la bufanda. :: Eso sería «tolgo».
- Compro la bufanda. :: Eso es «compro».
O Quindi andiamo al mare :: Así que vamos a la playa :: «Quindi» = así que.
X Escribe en italiano: «si hace frío» :: Se fa freddo. :: «Se» = si.
Q ¿Cómo se dice «es posible»?
+ È possibile. :: «Possibile» = posible.
- È sicuro. :: «Sicuro» = seguro.
- È bagnato. :: «Bagnato» = mojado.

@ 19 | Secondo me | Dar tu opinión
I Para decir lo que piensas sin sonar tajante, en italiano hay frases muy fáciles. Y para estar de acuerdo o no, también.
E Tu opinión :: **Secondo me** (según yo), **Mi sembra** (me parece), **Per me** (para mí). :: Ejemplo: **Secondo me è giusto** (según yo es justo).
E De acuerdo o no :: **D'accordo** (de acuerdo) y **Non sono d'accordo** (no estoy de acuerdo). :: Para matizar: **Dipende** (depende), **Tuttavia** (sin embargo).
B Qué quieres decir | Italiano | Español
| opinar | Secondo me, è giusto. | Según yo, es justo.
| estar de acuerdo | Sono d'accordo. | Estoy de acuerdo.
| no estar de acuerdo | Non sono d'accordo. | No estoy de acuerdo.
| depender | Dipende! | ¡Depende!
W secondo me = según yo | se-KON-do me
W d'accordo = de acuerdo | dak-KOR-do
W opinione = opinión | o-pi-NIO-ne
W idea = idea | i-DE-a
W giusto = justo; correcto | DJU-sto
W sbagliato = equivocado | zba-LIA-to
W falso = falso | FAL-so
W dipende = depende | di-PEN-de
W certamente = seguramente | tʃer-ta-MEN-te
W tuttavia = sin embargo | tut-ta-VIA
W mi sembra = me parece | mi SEM-bra
W chiaro = claro | KIA-ro
V Vocabulario: opiniones
D Un'opinione
Sara: Secondo me il caffè è buonissimo. = Según yo, el café está riquísimo.
  > secondo me = según yo | buonissimo = riquísimo
Luca: Non sono d'accordo, è troppo cara. = No estoy de acuerdo, es demasiado cara.
  > non sono d'accordo = no estoy de acuerdo | troppo = demasiado
Sara: Tuttavia, mi sembra giusto. = Sin embargo, me parece justo.
  > tuttavia = sin embargo | mi sembra giusto = me parece justo
Luca: Dipende! = ¡Depende!
  > dipende = depende
Q ¿Cómo dices «según yo»?
+ Secondo me. :: Expresión de opinión.
- Dopo di me. :: Eso es «después de mí».
- Per te. :: Eso es «para ti».
H Mi ___ giusto. :: Parece
+ sembra :: «Mi sembra» = me parece.
- sembrano :: Es plural.
- sono :: Eso es «soy».
R Il tempo dipende dal vento.
+ El tiempo depende del viento. :: «Dipende» = depende.
- El tiempo es del viento. :: Eso no es «dipende».
- El tiempo es bueno. :: «Buono» es bueno.
A Questo è falso.
+ Esto es falso. :: «Falso» = falso.
- Esto es verdadero. :: «Vero» es verdadero.
- Esto es seguro. :: «Sicuro» es seguro.
O Secondo me è giusto :: Según yo es justo :: «Secondo me» = según yo.
X Escribe en italiano: «no estoy de acuerdo» :: Non sono d'accordo. :: «D'accordo» = de acuerdo.
Q ¿Cuál es correcta para «es una opinión»?
+ È una opinione. :: «Opinione» = opinión.
- È una domanda. :: «Domanda» = pregunta.
- È una risposta. :: «Risposta» = respuesta.
