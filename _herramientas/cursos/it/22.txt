@ 22 | Vorrei tanto | El condicional presente: formas y deseos
I El condicional sirve para desear, pedir con educación y decir lo que harías. En español es el «haría», «iría», «tendría». Es muy útil en la conversación.
E Cómo se forma :: En la mayoría de verbos, la raíz del condicional acaba en **-er-**: **parlare → parlerei**, **prendere → prenderei**, **dormire → dormirei**. Las terminaciones son **-ei, -esti, -ebbe, -emmo, -este, -ebbero**. :: Algunos verbos son irregulares en la raíz: **avere → avrei**, **essere → sarei**, **andare → andrei**, **fare → farei**.
E Verbos de deseo :: **Vorrei** (quisiera), **potrei** (podría), **dovrei** (debería), **mi piacerebbe** (me gustaría). :: Con **mi piacerebbe** lo que gustaría va después: **Mi piacerebbe un viaggio** (me gustaría un viaje).
B Persona | parlare | viaggiare
| io | parlerei | viaggerei
| tu | parleresti | viaggeresti
| lui / lei | parlerebbe | viaggerebbe
| noi | parleremmo | viaggeremmo
| voi | parlereste | viaggereste
| loro | parlerebbero | viaggerebbero
W parlerei = hablaría | par-le-REI
W avrei = tendría | a-VREI
W sarei = sería | sa-REI
W potrei = podría | po-TREI
W dovrei = debería | do-VREI
W piacerebbe = gustaría | pia-tce-REB-be
W preferirei = preferiría | pre-fe-ri-REI
W andrei = iría | an-DREI
W sarebbe = sería | sa-REB-be
W ci vorrebbe = haría falta | tci vor-REB-be
W viaggerei = viajaría | viad-dje-REI
W compreresti = comprarías | kom-pre-RES-ti
W mangerei = comería | man-dje-REI
W faresti = harías | fa-RES-ti
V Vocabulario: deseos y cortesía
D Cosa faresti domani?
Sara: Che cosa faresti domani? = ¿Qué harías mañana?
  > che cosa = qué | faresti = harías | domani = mañana
Luca: Andrei al mare, ma piove. = Iría a la playa, pero llueve.
  > andrei = iría | ma piove = pero llueve
Sara: Io vorrei dormire. = Yo querría dormir.
  > vorrei = querría | dormire = dormir
Luca: Mi piacerebbe un viaggio. = Me gustaría un viaje.
  > mi piacerebbe = me gustaría | un viaggio = un viaje
Q ¿Cómo se dice «yo hablaría»?
+ parlerei :: Infinitivo sin -e + -ei.
- parlo :: Eso es presente.
- parlavo :: Eso es imperfecto.
Q ¿Qué significa «mi piacerebbe»?
+ me gustaría :: Forma de deseo.
- me gusta :: Eso es «mi piace».
- me gustó :: Eso es «mi è piaciuto».
H ___ volentieri, ma non posso. :: Yo iría (andrei)
+ Andrei :: Condicional de «andare».
- Vado :: Es presente: «voy».
- Andato :: Es participio.
R Avrei tempo domani.
+ Tendría tiempo mañana. :: «Avrei» = tendría.
- Tengo tiempo mañana. :: Eso es «ho tempo».
- Tuve tiempo mañana. :: Eso sería passato prossimo.
A Potrei venire.
+ Podría venir. :: «Potrei» = podría.
- Puedo venir. :: Eso es «posso».
- Pude venir. :: Eso sería passato prossimo.
O Ci vorrebbe un caffè :: Haría falta un café :: «Ci vorrebbe» = haría falta.
X Escribe en italiano: «yo preferiría» :: Preferirei. :: Condicional de «preferire».
Q ¿Cuál es correcta para «nosotros comeríamos»?
+ mangeremmo :: Condicional de «mangiare».
- mangiamo :: Eso es presente.
- mangerò :: Eso es futuro.

@ 22 | Dovresti riposare | Consejos y pedir con cortesía
I Para dar consejos sin ser brusco y para pedir algo a una persona de usted, usa el condicional. Así suena educado y natural.
E Consejos :: **Dovresti** (deberías, a alguien de tú), **dovrebbe** (debería, de usted). Con infinitivo: **Dovresti riposare** (deberías descansar). :: Es más suave que el imperativo: suena a sugerencia.
E Pedir con cortesía :: **Potrebbe aiutarmi?** (¿podría ayudarme?, usted). **Potresti aiutarmi?** (¿podrías ayudarme?, tú). :: Con usted, **Mi potrebbe indicare la stazione?** (¿podría indicarme la estación?).
B Pedir | De tú | De usted
| ayuda | Potresti aiutarmi? | Potrebbe aiutarmi?
| consejo | Dovresti riposare. | Dovrebbe riposare.
| repetir | Potresti ripetere? | Potrebbe ripetere?
W dovresti = deberías | do-VRES-ti
W dovrebbe = debería | do-VREB-be
W potrebbe = podría (usted) | po-TREB-be
W potresti = podrías | po-TRES-ti
W vorrebbe = querría (usted) | vor-REB-be
W ripetere = repetir | ri-PE-te-re
W dire = decir | DI-re
W indicare = indicar | in-di-KA-re
W indicazioni = indicaciones | in-di-ka-TSIO-ni
W chiedere = preguntar; pedir | KIE-de-re
V Vocabulario: cortesía y consejos
D Mi scusi, potrebbe ripetere?
Anna: Mi scusi, potrebbe ripetere? = Perdone, ¿podría repetir?
  > mi scusi = perdone | potrebbe ripetere = podría repetir
Marco: Certo! Dovrebbe chiedere al signore. = ¡Claro! Debería preguntar al señor.
  > dovrebbe chiedere = debería preguntar | al signore = al señor
Anna: Potresti aiutarmi tu? = ¿Podrías ayudarme tú?
  > potresti aiutarmi = podrías ayudarme
Marco: Sì, volentieri. Dovresti riposare, però. = Sí, con gusto. Deberías descansar, pero.
  > dovresti riposare = deberías descansar | però = pero
Q ¿Cómo pides con cortesía a una persona de usted?
+ Potrebbe aiutarmi? :: «Potrebbe» = usted podría.
- Puoi aiutarmi? :: «Puoi» es tú.
- Posso aiutarti? :: «Posso» es «puedo».
H ___ riposare, sei stanco. :: Deberías (tú)
+ Dovresti :: Consejo a alguien de tú.
- Dovrebbe :: Es para usted.
- Dovrei :: Es «yo debería».
R Potresti venire domani?
+ ¿Podrías venir mañana? :: «Potresti» = podrías.
- ¿Puedes venir mañana? :: Es presente: «puoi».
- ¿Pudiste venir mañana? :: Eso sería passato prossimo.
A Dovrebbe chiedere al signore.
+ Debería preguntar al señor. :: «Dovrebbe» = debería (usted).
- Debe preguntar al señor. :: Eso es presente: «deve».
- Debió preguntar al señor. :: Eso es passato prossimo.
O Mi potrebbe indicare la stazione? :: ¿Podría indicarme la estación? :: Cortesía con «potrebbe» + infinitivo.
X Escribe en italiano: «deberías descansar» (tú) :: Dovresti riposare. :: «Dovresti» = deberías.
Q ¿Qué significa «vorrebbe»?
+ querría (usted) :: Forma de cortesía.
- quiere (usted) :: Eso es «vuole».
- quieres (tú) :: Eso es «vuoi».
Q ¿Cómo se dice «¿podrías ayudarme?» (tú)?
+ Potresti aiutarmi? :: Condicional con tú.
- Potrebbe aiutarmi? :: Es de usted.
- Puoi aiutarmi? :: Es presente.

@ 22 | Avrei dovuto venire | Lo que habría hecho: condicional passato
I A veces hablas de algo que no pasó: lo que habrías hecho, o lo que deberías haber hecho. Eso es el condicional pasado.
E Cómo se forma :: Condicional de **avere** o **essere** + participio: **avrei mangiato** (habría comido), **sarei andato** (habría ido). El auxiliar suele seguir el que lleva el verbo principal en los tiempos compuestos: **sarei partito**, **avrei telefonato**. :: Con **dovere, potere, volere** se conserva la variación: **avrei dovuto partire** y **sarei dovuto partire** son posibles; atiende al auxiliar del infinitivo.
E Avrei dovuto, avrei potuto, avrei voluto :: Con verbos modales: **avrei dovuto** (habría debido), **avrei potuto** (habría podido), **avrei voluto** (habría querido). :: Ejemplo: **Avrei dovuto studiare** (debería haber estudiado).
B Forma | Ejemplo | Español
| avrei + participio | Avrei mangiato. | Habría comido.
| sarei + participio | Sarei andato. | Habría ido.
| avrei dovuto | Avrei dovuto venire. | Habría debido venir.
| avrei voluto | Avrei voluto venire. | Habría querido venir.
W cosa = qué; cosa | KO-sa
W studiare = estudiar | stu-DIA-re
W venuto = venido | ve-NU-to
W potuto = podido | po-TU-to
W dovuto = debido | do-VU-to
W voluto = querido | vo-LU-to
W avrei dovuto = habría debido | a-VREI do-VU-to
W avrei potuto = habría podido | a-VREI po-TU-to
W avrei voluto = habría querido | a-VREI vo-LU-to
W invitato = invitado | in-vi-TA-to
W comunque = de todos modos | kom-MUN-kwe
W purtroppo = por desgracia | pur-TROP-po
W ringraziare = agradecer | rin-gra-TSIA-re
W sbagliare = equivocarse | zba-LIA-re
W avresti = habrías (tú) | a-VRES-ti
W ragione = razón | ra-DJO-ne
V Vocabulario: lo que habría pasado
D Ieri ti ho invitato alla festa.
Anna: Ieri ti ho invitato alla festa. = Ayer te invité a la fiesta.
  > ho invitato = invité | alla festa = a la fiesta
Luca: Purtroppo non sono venuto. = Por desgracia no vine.
  > non sono venuto = no vine | purtroppo = por desgracia
Anna: Peccato! Avresti dovuto venire. = ¡Qué pena! Habrías debido venir.
  > avresti dovuto venire = habrías debido venir
Luca: Hai ragione. Avrei voluto venire. = Tienes razón. Habría querido venir.
  > hai ragione = tienes razón | avrei voluto venire = habría querido venir
Q ¿Cómo se dice «habría ido»?
+ sarei andato :: Condicional passato con «essere» (hombre).
- avrei andato :: «Andare» va con «essere».
- andrei :: Es condicional presente: «iría».
H Avrei ___ venire. :: Querido (voluto)
+ voluto :: «Avrei voluto» = habría querido.
- vogliono :: Es presente plural.
- vorrei :: Es presente condicional, no pasado.
R Avrei dovuto studiare.
+ Debería haber estudiado. :: «Avrei dovuto» = habría debido.
- Debo estudiar. :: Eso es presente.
- Debí estudiar. :: Eso es passato prossimo.
A Ti ho invitato alla festa.
+ Te invité a la fiesta. :: «Ho invitato» = invité.
- Te invitaré a la fiesta. :: Eso es futuro.
- Te invito a la fiesta. :: Eso es presente.
O Non sono venuto :: No vine :: «Sono venuto» = vine (hombre).
X Escribe en italiano: «habría podido» :: Avrei potuto. :: «Avrei» + participio de «potere».
Q ¿Qué significa «purtroppo»?
+ por desgracia :: Expresa pena.
- por fin :: Eso es «finalmente».
- de todos modos :: Eso es «comunque».
Q ¿Cuál es correcta para «habrías debido venir» (tú)?
+ Avresti dovuto venire. :: Condicional passato con tú.
- Avresti venire. :: Falta el participio «dovuto».
- Avevi dovuto venire. :: Eso es trapassato.
