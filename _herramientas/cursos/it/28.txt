@ 28 | Sto leggendo un libro | El gerundio: leyendo, comiendo, haciendo
I El gerundio termina en -ando o -endo, y en español es el «-ando/-iendo» de «estoy leyendo». En italiano lo usas para lo que está pasando ahora y para decir cómo se hace algo.
E Cómo se forma :: Para **-are**: **-ando** (parlando, hablando). Para **-ere** e **-ire**: **-endo** (leggendo, leyendo; dormendo, durmiendo). :: Irregulares: **facendo** (haciendo), **dicendo** (diciendo), **bevendo** (bebiendo), **essendo** (siendo), **avendo** (teniendo).
E Estar + gerundio :: **Stare** + gerundio indica una acción en curso: **Sto leggendo un libro** (estoy leyendo un libro). :: **Stai** (estás), **sta** (está), **stiamo** (estamos), **stanno** (están).
B Verbo | Gerundio | Ejemplo
| parlare | parlando | Sto parlando con Anna.
| leggere | leggendo | Sto leggendo un libro.
| dormire | dormendo | Sta dormendo.
| fare | facendo | Stai facendo?
| dire | dicendo | Sto dicendo la verità.
W parlando = hablando | par-LAN-do
W leggendo = leyendo | led-DJEN-do
W dormendo = durmiendo | dor-MEN-do
W facendo = haciendo | fa-TCHEN-do
W dicendo = diciendo | di-TCHEN-do
W bevendo = bebiendo | be-VEN-do
W avendo = teniendo | a-VEN-do
W essendo = siendo | es-SEN-do
W andando = yendo | an-DAN-do
W scrivendo = escribiendo | skri-VEN-do
W mangiando = comiendo | man-DJAN-do
W finendo = terminando | fi-NEN-do
W stai = estás | STAI
W sto = estoy | sto
V Vocabulario: gerundios
D Cosa stai facendo?
Anna: Cosa stai facendo? = ¿Qué estás haciendo?
  > stai facendo = estás haciendo
Luca: Sto leggendo un libro, e tu? = Estoy leyendo un libro, ¿y tú?
  > sto leggendo = estoy leyendo | e tu = ¿y tú?
Anna: Sto scrivendo un messaggio. = Estoy escribiendo un mensaje.
  > sto scrivendo = estoy escribiendo | messaggio = mensaje
Q ¿Cómo se forma el gerundio de «parlare»?
+ parlando :: -are → -ando.
- parlendo :: Eso es -endo, de -ere e -ire.
- parlato :: Eso es el participio.
Q ¿Cuál es el gerundio de «dire»?
+ dicendo :: Irregular: «dicendo».
- direndo :: No existe.
- dicente :: No es gerundio.
H Sto ___ un libro. :: Leyendo
+ leggendo :: -ere → -endo.
- leggo :: Eso es «leo».
- letto :: Eso es participio (cama o «leído»).
R Sto parlando con Anna.
+ Estoy hablando con Anna. :: Estar + gerundio.
- Hablo con Anna. :: Eso es presente simple.
- Hablé con Anna. :: Eso es pasado.
A Stai facendo?
+ ¿Estás haciendo? :: «Facendo» = haciendo.
- ¿Haces? :: Eso es «fai».
- ¿Hiciste? :: Eso es «hai fatto».
O Sto leggendo :: Estoy leyendo :: Estar + gerundio.
X Escribe en italiano: «estoy escribiendo» :: Sto scrivendo. :: «Stare» + gerundio.
Q ¿Qué forma es el gerundio de «essere»?
+ essendo :: Irregular: «essendo».
- sendo :: No existe.
- essente :: No es gerundio.

@ 28 | Camminando, ho visto Anna | El gerundio para estar en curso o describir cómo
I Además de «estar haciendo», el gerundio dice cómo o mientras qué pasa algo: «yendo a casa vi a Anna», «mientras caminaba». Es una forma muy práctica para contar.
E Estar en curso :: **Stiamo parlando** (estamos hablando), **Stanno ridendo** (están riendo), **Sta lavorando** (está trabajando). :: Se usa **stare** en el presente y el gerundio. Con **in corso** (en curso) se dice lo mismo: **Il lavoro è in corso** (el trabajo está en curso).
E Gerundio de modo o tiempo :: **Camminando, ho visto Anna** (yendo a pie, vi a Anna). **Lavorando, ho capito** (trabajando, entendí). :: El gerundio dice cómo o cuándo pasa lo otro, y el sujeto suele ser el mismo.
B Uso | Italiano | Español
| acción en curso | Stiamo parlando. | Estamos hablando.
| cómo se hace | Camminando, ho visto Anna. | Yendo a pie, vi a Anna.
W stare = estar | STA-re
W stiamo = estamos | STIA-mo
W stanno = están | STAN-no
W sta = está | sta
W camminando = caminando | kam-mi-NAN-do
W guidando = conduciendo | gui-DAN-do
W pensando = pensando | pen-SAN-do
W ridendo = riendo | ri-DEN-do
W piangendo = llorando | pian-DJEN-do
W lavorando = trabajando | la-vo-RAN-do
W in corso = en curso | in KOR-so
W stiamo parlando = estamos hablando | STIA-mo par-LAN-do
V Vocabulario: lo que pasa ahora
D Stiamo parlando
Anna: Stiamo parlando di lavoro. = Estamos hablando de trabajo.
  > stiamo parlando = estamos hablando | di lavoro = de trabajo
Luca: Camminando, ho visto Anna. = Yendo a pie, vi a Anna.
  > camminando = yendo a pie | ho visto = vi
Anna: Stanno ridendo! = ¡Están riendo!
  > stanno ridendo = están riendo
Luca: Stanno lavorando? = ¿Están trabajando?
  > stanno lavorando = están trabajando
Q ¿Qué significa «stiamo parlando»?
+ estamos hablando :: «Stare» + gerundio.
- hablamos :: Eso es presente simple.
- hablábamos :: Eso es imperfecto.
H Camminando, ___ Anna. :: Vi (ho visto)
+ ho visto :: Pasado concreto.
- vedo :: Es presente.
- vedrei :: Es condicional.
R Stanno ridendo!
+ ¡Están riendo! :: «Stanno» = están.
- ¡Ríen! :: Eso es «ridono».
- ¡Rieron! :: Eso sería pasado.
A Stanno lavorando?
+ ¿Están trabajando? :: «Lavorando» = trabajando.
- ¿Trabajan? :: Eso es «lavorano».
- ¿Trabajaron? :: Eso es pasado.
O Sta pensando :: Está pensando :: «Sta» + gerundio.
X Escribe en italiano: «estoy conduciendo» :: Sto guidando. :: «Guidando» = conduciendo.
Q ¿Cuál es correcta para «estoy llorando»?
+ Sto piangendo. :: «Piangendo» = llorando.
- Sto piangere. :: Hay que usar el gerundio.
- Piango. :: Eso es presente simple.

@ 28 | Lo sto facendo | Pronombres con el gerundio
I Los pronombres no van separados del gerundio: se pegan a él, o van delante del verbo «stare». Esto te permite decir «lo estoy haciendo» o «se lo estoy diciendo».
E Dos posiciones :: Delante de **stare**: **Lo sto facendo** (lo estoy haciendo). O pegado al gerundio: **Sto facendolo** (estoy haciéndolo). :: Ambas son correctas y se usan igual.
E Gerundio con pronombre :: **facendolo** (haciéndolo), **dicendolo** (diciéndolo), **parlandogli** (hablándole), **scrivendogli** (escribiéndole). :: Con dos pronombres: **Glielo sto dicendo** (se lo estoy diciendo).
B Pronombre | Gerundio con pronombre | Español
| lo | facendolo | haciéndolo
| gli | parlandogli | hablándole
| ne | mangiandone | comiendo de ello
| la | ascoltandola | escuchándola
| lo | chiamandolo | llamándolo
W facendolo = haciéndolo | fa-TCHEN-do-lo
W dicendolo = diciéndolo | di-TCHEN-do-lo
W parlandogli = hablándole | par-LAN-do-lyi
W scrivendogli = escribiéndole | skri-VEN-do-lyi
W mangiandone = comiendo de ello | man-DJAN-do-ne
W chiamandolo = llamándolo | kia-MAN-do-lo
W aspettandolo = esperándolo | as-pet-TAN-do-lo
W ascoltandola = escuchándola | as-kol-TAN-do-la
W cercandolo = buscándolo | tʃer-KAN-do-lo
W lo sto facendo = lo estoy haciendo | lo sto fa-TCHEN-do
W sto dicendolo = estoy diciéndolo | sto di-TCHEN-do-lo
W segreto = secreto | se-GRE-to
V Vocabulario: pronombres y gerundio
D Glielo sto dicendo
Anna: Hai detto a Marco il segreto? = ¿Le dijiste el secreto a Marco?
  > hai detto = dijiste | il segreto = el secreto
Luca: Lo sto dicendo a tutti! = ¡Se lo estoy diciendo a todos!
  > lo sto dicendo = lo estoy diciendo | a tutti = a todos
Anna: Glielo stai dicendo? = ¿Se lo estás diciendo?
  > glielo stai dicendo = se lo estás diciendo
Luca: No, glielo sto dicendo ora. = No, se lo estoy diciendo ahora.
  > glielo sto dicendo = se lo estoy diciendo | ora = ahora
Q ¿Cómo se dice «haciéndolo»?
+ facendolo :: Gerundio con «lo» pegado.
- lo facendo :: El pronombre va pegado al gerundio.
- facendo lo :: Eso no se escribe así.
H Lo ___ ora. :: Estoy haciendo (sto facendo)
+ sto :: «Lo sto facendo» = lo estoy haciendo.
- stai :: Es «estás».
- sta :: Es «está».
R Glielo sto dicendo.
+ Se lo estoy diciendo. :: «Glielo» = se lo.
- Le estoy diciendo. :: Falta el directo.
- Lo estoy diciendo. :: Falta el indirecto.
A Parlandogli, ho capito.
+ Hablándole, entendí. :: «Parlandogli» = hablándole.
- Hablándome, entendí. :: «Mi» sería «me».
- Hablando, entendí. :: Falta el pronombre.
O Lo sto facendo ora :: Lo estoy haciendo ahora :: «Lo» delante de «sto».
X Escribe en italiano: «se lo estoy diciendo» (a él) :: Glielo sto dicendo. :: «Glielo» = se lo.
Q ¿Cuál es correcta para «buscándolo»?
+ cercandolo :: Gerundio con «lo» pegado.
- cercando lo :: Hay que pegarlo.
- cercato lo :: Eso es participio.
