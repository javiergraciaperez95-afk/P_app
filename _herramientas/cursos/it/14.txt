@ 14 | Che bello! | Comparar y exclamar: più, meno, come
I Ahora sabrás decir cuál es más grande, cuál es menos interesante o qué tal de bueno es algo. Y para decirlo con emoción, empezamos con las exclamaciones.
E Exclamaciones con «che» :: Para exclamar se pone **che** delante del adjetivo: **Che bello!** (¡qué bonito!), **Che interessante!** (¡qué interesante!). :: Para decir que hace frío no se exclama: se usa **fa freddo**, como en el capítulo 9.
E Más, menos e igualdad :: **Più** (más) y **meno** (menos) + adjetivo + **di**: **Marco è più alto di Luca**. Para comparar cantidades se usa a menudo **di** con números y **che** al comparar dos cualidades: **È più alto che simpatico** (es más alto que simpático). :: La igualdad puede expresarse con **(così)… come/quanto**: **Anna è alta come Marco**.
B Comparación | Italiano | Español
| más | più … di | Marco è più alto di Luca.
| menos | meno … di | Il film è meno interessante del libro.
| igual | … come | Anna è alta come Marco.
W che = qué (exclamación) | ke | Va delante del adjetivo: «che bello!».
W tanto = mucho; muy | TAN-to
W veloce = rápido | ve-LO-če
W lento = lento | LEN-to
W bravo = bueno (en algo) | BRA-vo
W brava = buena (en algo) | BRA-va
W interessante = interesante | in-te-res-SAN-te
W difficile = difícil | dif-FI-tʃi-le
W facile = fácil | FA-tʃi-le
W forte = fuerte | FOR-te
W debole = débil | DE-bo-le
W intelligente = inteligente | in-tel-li-DJEN-te
V Vocabulario: adjetivos para comparar
D Al museo
Anna: Che bello! = ¡Qué bonito!
  > Che bello = qué bonito
Marco: Sì, è molto interessante. = Sí, es muy interesante.
  > molto = muy | interessante = interesante
Anna: Marco è più alto di Luca? = ¿Marco es más alto que Luca?
  > più alto di Luca = más alto que Luca
Marco: No, è meno alto di Luca. = No, es menos alto que Luca.
  > meno alto di Luca = menos alto que Luca
Anna: Ma è tanto simpatico! = ¡Pero es muy simpático!
  > tanto = muy | simpatico = simpático
Q ¿Cómo se dice «Marco es más alto que Luca»?
+ Marco è più alto di Luca. :: «Più … di» = más … que.
- Marco è più alto come Luca. :: «Come» es para la igualdad.
- Marco è meno alto di Luca. :: «Meno» = menos.
Q ¿Qué significa «Che freddo!»?
+ ¡Qué frío! :: «Che» + adjetivo = exclamación.
- ¡Qué caliente! :: Eso sería «Che caldo!».
- ¡Hace frío! :: Eso sería «fa freddo».
H Il film è ___ interessante del libro. :: Menos
+ meno :: «Meno … di» = menos … que.
- più :: Esto sería «más».
- come :: Para la igualdad, no aquí.
R Anna è alta come Marco.
+ Anna es tan alta como Marco. :: «Come» = como (igualdad).
- Anna es más alta que Marco. :: Eso sería «più … di».
- Anna es menos alta que Marco. :: Eso sería «meno … di».
A Il treno è veloce.
+ El tren es rápido. :: «Veloce» = rápido.
- El tren es lento. :: «Lento» es lento.
- El tren es caro. :: «Caro» es caro.
O Che bello! :: ¡Qué bonito! :: «Che» + adjetivo = exclamación.
X Escribe en italiano: «es muy interesante» :: È molto interessante. :: «Molto» = muy.
Q ¿Cuál es correcta para «Luca es menos simpático que Marco»?
+ Luca è meno simpatico di Marco. :: «Meno … di».
- Luca è più simpatico di Marco. :: Eso sería «más simpático».
- Luca è meno simpatico come Marco. :: «Come» no sirve para comparar de menos.

@ 14 | Il più bello | Superlativos y mejor y peor
I Cuando algo es lo más de todo, usamos el superlativo. Y hay tres palabras que cambian por completo: buono, cattivo y bene.
E Muy y el más :: El superlativo en **-issimo** concuerda con el nombre: **bello → bellissimo**, **grande → grandissimo**, **cara → carissima**. También se puede usar **molto + adjetivo**: **molto bella**. :: Para comparar con un grupo, usa artículo + **più/meno** + adjetivo: **il più caro**, **la meno cara**, **i più cari**.
E Formas irregulares :: Como adjetivos, **buono → migliore** y **cattivo → peggiore**; con verbos, **bene → meglio** y **male → peggio**. :: **Questo ristorante è il migliore**; **Qui si mangia meglio**. Para «el mejor» el uso de **il migliore** es más natural que **il più buono** en muchos contextos.
B Forma | Adjetivo | Superlativo | Significado
| grande | grande | grandissimo | muy grande
| bello | bello | bellissimo | muy bonito
| caro | caro | carissimo | muy caro
| piccolo | piccolo | piccolissimo | muy pequeño
W buono = bueno; rico | BWO-no
W cattivo = malo | kat-TI-vo
W peggiore = peor | ped-DJO-re
W meglio = mejor (verbo: bien) | ME-glio
W peggio = peor (verbo: mal) | ped-DJO
W città = ciudad | tʃit-TA
W bellissimo = precioso; muy bonito | bel-LIS-si-mo
W bellissima = preciosa; muy bonita | bel-LIS-si-ma
W grandissimo = enorme; muy grande | gran-DIS-si-mo
W carissimo = muy caro | ka-RIS-si-mo
W piccolissimo = muy pequeño | pik-ko-LIS-si-mo
W cibo = comida | TCHI-bo
V Vocabulario: superlativos y comparativos especiales
D El ristorante migliore
Anna: Qual è il ristorante migliore di Roma? = ¿Cuál es el mejor restaurante de Roma?
  > il ristorante migliore = el mejor restaurante
Marco: Per me è il più buono! = ¡Para mí es el más rico!
  > per me = para mí | il più buono = el más rico
Anna: Ma il più buono è anche il più caro! = ¡Pero el más rico es también el más caro!
  > il più caro = el más caro | anche = también
Marco: Sì, ma è buonissimo! = ¡Sí, pero está riquísimo!
  > buonissimo = riquísimo (superlativo de «buono»)
Q ¿Cómo se dice «el más caro»?
+ il più caro :: «Più» delante del adjetivo.
- il caro più :: El «più» va antes.
- il migliore caro :: Ese orden no es correcto.
Q ¿Cuál es el superlativo de «grande»?
+ grandissimo :: Se añade -issimo.
- più grande :: Eso es «más grande», no «muy grande».
- grandissima :: Es femenino; aquí no concuerda.
H Questa casa è ___. :: Muy bonita (femenino)
+ bellissima :: Casa es femenino: -a.
- bellissimo :: Ese final es masculino.
- bellissimi :: Ese final es plural.
R Questo ristorante è il migliore.
+ Este restaurante es el mejor. :: «Migliore» = mejor.
- Este restaurante es peor. :: Eso sería «peggiore».
- Este restaurante es muy bueno. :: Eso sería «buonissimo».
A Il cibo è buono.
+ La comida es buena. :: «Buono» = bueno.
- La comida es mala. :: «Cattivo» es malo.
- La comida es cara. :: «Caro» es caro.
O Il più piccolo :: El más pequeño :: «Il più» + adjetivo.
X Escribe en italiano: «es el mejor» (mejor = migliore) :: È il migliore. :: «Il» + «migliore».
Q ¿Cómo se dice «canta mejor»? (cantare, verbo)
+ canta meglio :: «Meglio» es el mejor con verbos.
- canta migliore :: Con verbos no se usa «migliore».
- canta peggio :: Eso es «canta peor».

@ 14 | Qualche volta | Indefinidos: ogni, qualche, alcuni, nessuno, tutto
I Hay palabras que hablan de cantidad sin decir un número: cada, algunos, ninguno, todo. Son muy útiles, y en italiano cambian según el género y el número.
E Indefinidos básicos :: **ogni** (cada, invariable) y **qualche** (algún/alguna) llevan un nombre singular: **ogni giorno**, **qualche libro**. **Alcuni/e** significa «algunos/as»; **qualcosa** = algo y **nessuno/a** = nadie/ninguno/a. :: En **Non c'è niente** (no hay nada), la negación va delante del verbo.
E Todo, mucho y frecuencia :: **Tutto/a/i/e** (todo/a/os/as) y **tanto/a/i/e** (mucho/a/os/as) concuerdan con el nombre: **tanti turisti**. :: Para «todos los días» son correctas **ogni giorno** y **tutti i giorni**; **qualche volta** significa «alguna vez / algunas veces».
B Palabra | Significado | Ejemplo
| ogni | cada | Ogni giorno.
| qualche | algún / alguna + singular | Qualche libro.
| qualche volta | alguna vez | Qualche volta vado al mare.
| alcuni | algunos | Alcuni turisti sono qui.
| niente | nada | Non c'è niente.
| tutti i giorni | todos los días | Lavoro tutti i giorni.
| tanti | muchos | Ci sono tanti turisti.
W ogni = cada | O-ni
W qualche = algún; alguna | kwal-KE | Va seguido de un sustantivo singular.
W alcuni = algunos | al-KU-ni
W alcune = algunas | al-KU-ne
W nessuno = ninguno; nadie | nes-SU-no
W niente = nada | NIEN-te
W qualcosa = algo | kwal-KO-sa
W tanti = muchos | TAN-ti
W tante = muchas | TAN-te
W tutti = todos | TUT-ti
W tutte = todas | TUT-te
W tutta = toda | TUT-ta
W turisti = turistas | tu-RI-sti
W volta = vez | VOL-ta
V Vocabulario: indefinidos y cantidad
D Un fin de semana tranquilo
Anna: Ci sono tanti turisti in città? = ¿Hay muchos turistas en la ciudad?
  > ci sono = hay | tanti turisti = muchos turistas | in città = en la ciudad
Marco: Sì, tutti i giorni. = Sí, todos los días.
  > tutti i giorni = todos los días
Anna: C'è qualcosa di bello? = ¿Hay algo bonito?
  > c'è qualcosa = hay algo | di bello = bonito
Marco: Non c'è niente. = No hay nada.
  > non c'è niente = no hay nada | niente = nada
Q ¿Cómo se dice «cada día»?
+ ogni giorno :: «Ogni» no cambia.
- tutti i giorni :: También significa «todos los días».
- alcuni giorni :: Eso es «algunos días».
- tanti giorni :: Eso es «muchos días».
Q ¿Cuál es correcta para «no hay nada»?
+ Non c'è niente. :: «Niente» = nada.
- Non c'è nessuno. :: «Nessuno» = ninguno, nadie.
- Non c'è qualcosa. :: «Qualcosa» = algo.
H Ci sono ___ turisti. :: Muchos (masculino plural)
+ tanti :: Plural masculino.
- tanto :: Singular.
- tante :: Femenino plural: no concuerda con «turisti».
R Alcuni turisti sono in città.
+ Algunos turistas están en la ciudad. :: «Alcuni» = algunos.
- Todos los turistas están en la ciudad. :: Eso sería «tutti».
- Ningún turista está en la ciudad. :: Eso sería «nessuno».
A Qualche volta vado al mare.
+ Algunas veces voy al mar. :: «Qualche volta» = alguna vez.
- Nunca voy al mar. :: Eso sería «mai».
- Todos los días voy al mar. :: Eso sería «ogni giorno».
O Ogni giorno :: Cada día :: «Ogni» no cambia.
X Escribe en italiano: «cada día» :: Ogni giorno. :: «Ogni» va sin cambios.
Q ¿Cuál es correcta para «algunos»?
+ Alcuni :: Es «algunos» (masculino plural).
- Ogni :: Es «cada».
- Nessuno :: Es «ninguno».
Q Completa la expresión «algún libro».
+ qualche libro :: «Qualche» va con un nombre singular.
- qualche libri :: Después de «qualche» el nombre va en singular.
- alcuni libro :: «Alcuni» va con un nombre plural.
