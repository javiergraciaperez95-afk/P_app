@ 24 | Se studi, impari | El periodo ipotetico de tipo I: lo que es posible
I Las frases con «si» son de tres tipos. Empezamos por la más sencilla: lo que es real o posible, como «si estudias, aprendes». En italiano la parte con «se» va en presente.
E Tipo I: condiciones reales :: Con **se** puede ir presente y la consecuencia en presente, futuro o imperativo: **Se studi, impari**; **Se parti adesso, arriverai in tempo**; **Se hai tempo, chiama Anna**. :: Sirve para situaciones reales, habituales o posibles. En una condición futura, el presente después de *se* es muy común; también se encuentra el futuro.
E Negar la condición :: **Se non chiama** (si no llama). **Se piove, chiudi la finestra** (si llueve, cierra la ventana). :: El tiempo de la consecuencia puede ser un mandato.
B Condición (se + presente) | Consecuencia | Español
| Se studi | impari | si estudias, aprendes
| Se parti adesso | arriverai in tempo | si sales ahora, llegarás a tiempo
| Se hai tempo | chiama Anna | si tienes tiempo, llama a Anna
| Se piove | chiudi la finestra | si llueve, cierra la ventana
W studi = estudias | STU-di
W impari = aprendes | im-PA-ri
W chiama = llama | KIA-ma
W richiamo = vuelvo a llamar | ri-KIA-mo
W chiudi = cierra | KIU-di
W apri = abre | A-pri
W promosso = aprobado | pro-MOS-so
W bocciato = suspendido | bot-TCHA-to
W passare = aprobar (un examen) | pas-SA-re
W passo = apruebo; paso | PAS-so
W riposo = descanso | ri-PO-so
W scrivi = escribes | SKRI-vi
V Vocabulario: estudiar y exámenes
D Se studi, impari
Sara: Se studi, impari. = Si estudias, aprendes.
  > se studi = si estudias | impari = aprendes
Luca: Se passo un esame, sono contento. = Si apruebo un examen, estoy contento.
  > se passo = si apruebo | sono contento = estoy contento
Sara: Se hai tempo, chiama Anna. = Si tienes tiempo, llama a Anna.
  > se hai tempo = si tienes tiempo | chiama = llama
Luca: Se non chiama, richiamo io. = Si no llama, la vuelvo a llamar yo.
  > se non chiama = si no llama | richiamo = vuelvo a llamar
Q ¿Cómo se dice «si estudias, aprendes»?
+ Se studi, impari. :: Tipo I: «se» + presente, presente.
- Se studio, imparo. :: «Studio» y «imparo» son «yo».
- Se studierai, imparerai. :: La condición futura suele ir en presente: «Se studi»; también existe el futuro.
Q ¿Qué significa «apri la finestra»?
+ abre la ventana :: Imperativo de tú: «apri».
- cierra la ventana :: Eso es «chiudi».
- me acuerdo de la ventana :: Eso no tiene que ver.
H Se hai tempo, ___ Anna. :: Llama (tú)
+ chiama :: Imperativo de tú: llama.
- chiami :: Es presente de usted: «llame».
- chiamo :: Es «yo llamo».
R Se piove, chiudi la finestra.
+ Si llueve, cierra la ventana. :: «Chiudi» = cierra (tú).
- Si llueve, cierro la ventana. :: «Chiudo» es «yo cierro».
- Si llovió, cerré la ventana. :: Eso sería pasado.
A Se passo un esame, sono contento.
+ Si apruebo un examen, estoy contento. :: «Passo» = apruebo.
- Si suspendo un examen, estoy contento. :: «Bocciato» es suspendido.
- Si apruebo un examen, estaba contento. :: Eso sería imperfecto.
O Se studi, impari :: Si estudias, aprendes :: Tipo I: «se» + presente.
X Escribe en italiano: «si estudias, lees» (tú) :: Se studi, leggi. :: Tipo I con presente.
Q ¿Qué significa «bocciato»?
+ suspendido :: Lo contrario de «promosso».
- aprobado :: Eso es «promosso».
- llamado :: Eso es «chiamato».

@ 24 | Vorrei che tu venissi | El congiuntivo imperfetto: formas
I Para lo que sería posible si cambiaras algo, necesitas el congiuntivo imperfetto. Es la forma de la irrealidad: «si yo tuviera», «que vinieras». Se forma con la raíz del infinitivo.
E Cómo se forma :: Para **-are**: **-assi, -assi, -asse, -assimo, -aste, -assero**. Para **-ere** e **-ire**: **-essi** y **-issi**. :: Ejemplo: **parlare → parlassi** (hablara), **venire → venissi** (viniera).
E Essere y avere :: **Essere** es irregular: **fossi, fossi, fosse, fossimo, foste, fossero**. **Avere**: **avessi, avessi, avesse…**. :: Ejemplo: **Se avessi tempo** (si tuviera tiempo).
B Persona | parlare | essere | avere
| io | parlassi | fossi | avessi
| tu | parlassi | fossi | avessi
| lui / lei | parlasse | fosse | avesse
| noi | parlassimo | fossimo | avessimo
| voi | parlaste | foste | aveste
| loro | parlassero | fossero | avessero
W fossi = fuera (yo, tú) | FOS-si
W fosse = fuera (él, ella) | FOS-se
W avessi = tuviera (yo, tú) | a-VES-si
W avesse = tuviera (él, ella) | a-VES-se
W potessi = pudiera | po-TES-si
W facessi = hiciera | fa-TCHES-si
W andassi = fuera (ir) | an-DAS-si
W sapessi = supiera | sa-PES-si
W venissi = viniera | ve-NIS-si
W dicessi = dijera | di-TCHES-si
W parlassi = hablara | par-LAS-si
W dormissi = durmiera | dor-MIS-si
W sapevi = sabías | sa-PE-vi
V Vocabulario: congiuntivo imperfetto
D Vorrei che tu venissi
Anna: Vorrei che tu venissi con me. = Quisiera que vinieras conmigo.
  > vorrei che tu venissi = quisiera que vinieras | con me = conmigo
Luca: Magari potessi! = ¡Ojalá pudiera!
  > magari = ojalá | potessi = pudiera
Anna: Non sapevi che era tardi? = ¿No sabías que era tarde?
  > sapevi = sabías | era tardi = era tarde
Luca: Magari fosse vero! = ¡Ojalá fuera verdad!
  > fosse = fuera | vero = verdad
Q ¿Cómo se dice «que vinieras» (tú)?
+ che tu venissi :: Congiuntivo imperfetto de «venire», con tú.
- che tu vieni :: Es presente.
- che tu verrai :: Es futuro.
Q ¿Cuál es el congiuntivo imperfetto de «essere» con «io»?
+ fossi :: Forma irregular.
- ero :: Es imperfecto de indicativo.
- sia :: Es congiuntivo presente.
H Vorrei che tu ___ con me. :: Que vinieras (venire)
+ venissi :: Congiuntivo imperfetto de «venire».
- vieni :: Es presente.
- venire :: Es infinitivo.
R Magari potessi!
+ ¡Ojalá pudiera! :: «Magari» = ojalá.
- ¡Quizá puedo! :: «Magari» aquí no es quizá.
- ¡Ya puedo! :: Eso sería «posso già».
A Magari fosse vero!
+ ¡Ojalá fuera verdad! :: «Fosse» = fuera.
- ¡Ya es verdad! :: Eso sería «è già vero».
- ¡Era verdad! :: Eso sería «era» en indicativo.
O Vorrei che tu venissi :: Quisiera que vinieras :: «Che» + congiuntivo imperfetto.
X Escribe en italiano: «que tuviera tiempo» (yo) :: Che avessi tempo. :: Congiuntivo imperfetto de «avere».
Q ¿Qué significa «sapessi»?
+ supiera :: Congiuntivo imperfetto de «sapere».
- sabía :: Eso sería «sapevo».
- sé :: Eso es presente: «so».

@ 24 | Se avessi soldi, comprerei una casa | El periodo ipotetico de tipo II: lo irreal
I Ahora el «si» habla de algo que no pasa o es poco probable: «si tuviera dinero, compraría una casa». En italiano es el tipo II.
E Tipo II :: **Se** + congiuntivo imperfetto, y en la otra parte el condizionale presente: **Se avessi soldi, comprerei una casa** (si tuviera dinero, compraría una casa). :: Es lo mismo que en español: la parte de «si» va en pasado de subjuntivo y la consecuencia en condicional.
E Fossi in te :: **Se fossi in te** = «si yo fuera tú». Se usa para dar consejos: **Se fossi in te, chiederei una vacanza** (si yo fuera tú, pediría unas vacaciones). :: Es una forma muy natural de aconsejar.
B Si... (congiuntivo imperfetto) | ...entonces (condizionale) | Español
| Se avessi soldi | comprerei una casa | si tuviera dinero, compraría una casa
| Se potessi | andrei al mare | si pudiera, iría a la playa
| Se fossi in te | chiederei | si yo fuera tú, pediría
W comprerei = compraría | kom-pre-REI
W lavorerei = trabajaría | la-vo-REI
W chiederei = pediría | kie-de-REI
W ricco = rico | RIK-ko
W ricca = rica | RIK-ka
W fossi in te = si yo fuera tú | FOS-si in te
W soldi = dinero | SOL-di
W vivrei = viviría | VI-vrei
W vivere = vivir | VI-ve-re
W lotteria = lotería | lot-te-RIA
W dormirei = dormiría | dor-mi-REI
W aiuterei = ayudaría | a-iu-te-REI
V Vocabulario: dinero y consejos
D Se avessi soldi
Sara: Se avessi soldi, comprerei una casa. = Si tuviera dinero, compraría una casa.
  > se avessi soldi = si tuviera dinero | comprerei = compraría
Luca: Io lavorerei meno. = Yo trabajaría menos.
  > lavorerei = trabajaría | meno = menos
Sara: Se fossi in te, chiederei una vacanza. = Si yo fuera tú, pediría unas vacaciones.
  > se fossi in te = si yo fuera tú | chiederei = pediría | una vacanza = unas vacaciones
Luca: Magari! Vivrei al mare. = ¡Ojalá! Viviría en la playa.
  > vivrei = viviría | al mare = en la playa
Q ¿Cómo se dice «si tuviera dinero»?
+ Se avessi soldi. :: Tipo II: «se» + congiuntivo imperfetto.
- Se ho soldi. :: Eso es presente.
- Se avrò soldi. :: Eso es futuro.
Q ¿Qué significa «se fossi in te»?
+ si yo fuera tú :: «Fossi» = fuera (yo).
- si yo soy tú :: Eso sería «se sono in te».
- si yo era tú :: Eso sería imperfecto indicativo.
H Se potessi, ___ al mare. :: Iría (andrei)
+ andrei :: Condicional de «andare».
- vado :: Es presente.
- andato :: Es participio.
R Lavorerei meno.
+ Trabajaría menos. :: «Lavorerei» = trabajaría.
- Trabajo menos. :: Eso es presente.
- Trabajé menos. :: Eso sería passato prossimo.
A Vivrei al mare.
+ Viviría en la playa. :: «Vivrei» = viviría.
- Vivo en la playa. :: Eso es presente.
- Viví en el mar. :: Eso es pasado.
O Comprerei una casa :: Compraría una casa :: Condicional de «comprare».
X Escribe en italiano: «si tuviera tiempo, viajaría» (yo) :: Se avessi tempo, viaggerei. :: Tipo II.
Q ¿Cuál es correcta para «si yo fuera tú, pediría»?
+ Se fossi in te, chiederei. :: Tipo II con «fossi in te».
- Se sono in te, chiederei. :: Falta el congiuntivo imperfetto.
- Se fossi in te, chiedo. :: Hay que usar el condicional.
