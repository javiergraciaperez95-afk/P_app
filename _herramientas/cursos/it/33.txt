@ 33 | Dopo aver capito | El infinitivo pasado: después de haber hecho algo
I Cuando quieres decir «después de haber entendido», o «después de haber vuelto», el italiano usa un infinitivo del pasado. Es la forma elegante de encadenar acciones.
E Cómo se forma :: **aver** o **essere** en infinitivo + participio: **aver capito** (haber entendido), **essere tornato** (haber vuelto). :: Se usa con **dopo**: **Dopo aver capito, ho deciso** (después de haber entendido, decidí).
E Concordancia :: Con **essere**, el participio concuerda con el sujeto: **dopo essere tornata** (después de haber vuelto, ella). Con **avere** no cambia. :: Así se evita repetir el sujeto.
B Forma | Ejemplo | Español
| aver + participio | Dopo aver capito, ho deciso. | Después de haber entendido, decidí.
| essere + participio | Dopo essere tornato, ho chiamato. | Después de haber vuelto, llamé.
| essere + participio (fem.) | Dopo essere tornata, ho cenato. | Después de haber vuelto, cené.
W aver capito = haber entendido | a-VER ka-PI-to
W aver detto = haber dicho | a-VER DET-to
W aver deciso = haber decidido | a-VER de-TCHI-zo
W aver scritto = haber escrito | a-VER SKRIT-to
W aver fatto = haber hecho | a-VER FAT-to
W dopo aver capito = después de haber entendido | DO-po a-VER ka-PI-to
W dopo aver detto = después de haber dicho | DO-po a-VER DET-to
W dopo aver deciso = después de haber decidido | DO-po a-VER de-TCHI-zo
W essere andato = haber ido | ES-se-re an-DA-to
W essere tornato = haber vuelto | ES-se-re tor-NA-to
W essere stato = haber estado | ES-se-re STA-to
W essere venuto = haber venido | ES-se-re ve-NU-to
W dopo essere tornato = después de haber vuelto | DO-po ES-se-re tor-NA-to
W deciso = decidido | de-TCHI-zo
V Vocabulario: infinitivo pasado
D Dopo aver capito
Anna: Dopo aver capito il problema, ho deciso. = Después de haber entendido el problema, decidí.
  > dopo aver capito = después de haber entendido | ho deciso = decidí
Luca: Dopo essere tornato, ho parlato con lui. = Después de haber vuelto, hablé con él.
  > dopo essere tornato = después de haber vuelto | ho parlato = hablé
Anna: Hai detto tutto? = ¿Dijiste todo?
  > hai detto = dijiste | tutto = todo
Luca: Sì, dopo aver detto tutto, sono uscito. = Sí, después de haber dicho todo, salí.
  > dopo aver detto = después de haber dicho | sono uscito = salí
Q ¿Cómo se dice «después de haber entendido»?
+ dopo aver capito :: «Dopo aver» + participio.
- dopo capire :: Eso es infinitivo presente.
- dopo capito :: Falta «aver».
H Dopo ___ tornato, ho chiamato. :: Haber (essere)
+ essere :: Con «tornare» va «essere».
- aver :: «Tornare» no va con «avere».
- avere :: Es el verbo, no el infinitivo.
R Dopo aver deciso, sono partito.
+ Después de haber decidido, me fui. :: «Aver deciso» = haber decidido.
- Después de decidir, me iré. :: Eso es futuro.
- Antes de decidir, me fui. :: Eso es «prima di».
A Dopo essere tornato, ho parlato con lui.
+ Después de haber vuelto, hablé con él. :: «Essere tornato» = haber vuelto.
- Después de volver, hablaré. :: Eso es futuro.
- Antes de volver, hablé. :: Eso es «prima».
O Dopo aver detto tutto :: Después de haber dicho todo :: Infinitivo pasado.
X Escribe en italiano: «después de haber hecho» :: Dopo aver fatto. :: «Aver» + participio.
Q ¿Qué forma es correcta para «haber ido» (ella)?
+ essere andata :: Con «essere», el participio concuerda: -a.
- avere andata :: «Andare» va con «essere».
- essere andato :: Es masculino.
Q ¿Qué significa «deciso»?
+ decidido :: Participio de «decidere».
- detenido :: Eso sería «fermato».
- conocido :: Eso sería «conosciuto».

@ 33 | Avendo finito, sono uscito | El gerundio pasado: habiendo hecho algo
I El gerundio pasado es más formal y se usa en textos escritos. Significa «habiendo hecho» y explica algo que pasó antes, como causa o secuencia.
E Cómo se forma :: **avendo** o **essendo** + participio: **avendo finito** (habiendo terminado), **essendo arrivato** (habiendo llegado). :: La concordancia es igual que en el infinitivo pasado: **essendo arrivata** (habiendo llegado, ella).
E Cuándo se usa :: En frases formales y narraciones: **Avendo speso troppo, sono stanco** (habiendo gastado demasiado, estoy cansado). :: En el habla normal se prefiere el infinitivo pasado: «dopo aver speso…».
W avendo finito = habiendo terminado | a-VEN-do fi-NI-to
W avendo visto = habiendo visto | a-VEN-do VI-sto
W essendo arrivato = habiendo llegado | es-SEN-do ar-ri-VA-to
W avendo capito = habiendo entendido | a-VEN-do ka-PI-to
W essendo tornata = habiendo vuelto (ella) | es-SEN-do tor-NA-ta
W avendo mangiato = habiendo comido | a-VEN-do man-DJA-to
W avendo detto = habiendo dicho | a-VEN-do DET-to
W avendo speso = habiendo gastado | a-VEN-do SPE-so
W speso = gastado | SPE-so
W avendo risolto = habiendo resuelto | a-VEN-do ri-ZOL-to
W risolto = resuelto | ri-ZOL-to
W essendo stato = habiendo sido | es-SEN-do STA-to
V Vocabulario: gerundio pasado
D Avendo finito il lavoro
Anna: Avendo finito il lavoro, sono andata a casa. = Habiendo terminado el trabajo, fui a casa.
  > avendo finito = habiendo terminado | sono andata = fui (ella)
Luca: Avendo visto il film, ti posso dire la verità. = Habiendo visto la película, puedo decirte la verdad.
  > avendo visto = habiendo visto | ti posso dire = puedo decirte
Anna: Essendo arrivato tardi, non ho mangiato. = Habiendo llegado tarde, no comí.
  > essendo arrivato = habiendo llegado | non ho mangiato = no comí
Luca: Avendo speso troppo, sono stanco. = Habiendo gastado demasiado, estoy cansado.
  > avendo speso = habiendo gastado | troppo = demasiado
Q ¿Cómo se dice «habiendo terminado»?
+ avendo finito :: Gerundio pasado con «avere».
- finendo :: Eso es gerundio simple: «terminando».
- avendo finire :: Falta el participio.
H ___ visto il film, ti posso dire. :: Habiendo
+ Avendo :: Gerundio pasado.
- Avere :: Es infinitivo.
- Ho :: Es presente.
R Avendo capito, ho risposto.
+ Habiendo entendido, respondí. :: «Avendo capito» = habiendo entendido.
- Entendiendo, respondo. :: Eso es gerundio simple y presente.
- Habiendo entendido, responderé. :: Eso es futuro.
A Essendo arrivata tardi, non ho mangiato.
+ Habiendo llegado tarde, no comí. :: «Essendo arrivata» = habiendo llegado (ella).
- Llegando tarde, no como. :: Eso es gerundio simple y presente.
- Llegaré tarde, no comeré. :: Eso es futuro.
O Avendo speso troppo :: Habiendo gastado demasiado :: Gerundio pasado.
X Escribe en italiano: «habiendo dicho eso» :: Avendo detto questo. :: «Avendo» + participio.
Q ¿Qué significa «risolto»?
+ resuelto :: Participio de «risolvere».
- disuelto :: Eso sería «sciolto».
- dicho :: Eso sería «detto».
Q ¿Cuál es correcta para «habiendo sido» (él)?
+ essendo stato :: «Essendo» + participio.
- avendo essere :: Falta el participio «stato».
- essendo sono :: Hay que usar el participio.

@ 33 | Senza dire niente | Sin, para y después: infinitivo con senza y per
I Con infinitivos puedes decir «sin hacer», «para ver» o «sin decir nada». Son frases cortas y muy naturales.
E Senza + infinitivo :: **Senza dire niente** (sin decir nada), **senza salutare** (sin saludar). :: Se usa cuando la acción principal no se hace: **È uscito senza dire niente** (salió sin decir nada).
E Per + infinitivo :: **Per capire** (para entender), **per arrivare** (para llegar). :: Indica finalidad: **Per chiedere, bisogna essere gentili** (para pedir, hay que ser amables).
E Scusarsi :: **Scusarsi** (disculparse): **Senza scusarsi** (sin disculparse). :: Es un verbo reflexivo: **mi scuso** (me disculpo).
B Expresión | Significado | Ejemplo
| senza + infinitivo | sin + infinitivo | Senza parlare, è uscito.
| per + infinitivo | para + infinitivo | Per capire, serve tempo.
| per + infinitivo | para pedir | Per chiedere, bisogna essere gentili.
W senza dire = sin decir | SEN-dza DI-re
W senza parlare = sin hablar | SEN-dza par-LA-re
W senza salutare = sin saludar | SEN-dza sa-lu-TA-re
W salutare = saludar | sa-lu-TA-re
W senza pensare = sin pensar | SEN-dza pen-SA-re
W per vedere = para ver | per ve-DE-re
W per capire = para entender | per ka-PI-re
W per arrivare = para llegar | per ar-ri-VA-re
W arrivare = llegar | ar-ri-VA-re
W scusarsi = disculparse | sku-ZAR-si
W senza scusarsi = sin disculparse | SEN-dza sku-ZAR-si
W per chiedere = para pedir | per KIE-de-re
W serve = hace falta | SER-ve
V Vocabulario: sin y para
D Senza dire niente
Anna: È uscito senza dire niente. = Salió sin decir nada.
  > senza dire = sin decir | niente = nada
Luca: Senza salutare nessuno. = Sin saludar a nadie.
  > senza salutare = sin saludar | nessuno = nadie
Anna: Per capire, bisogna leggere. = Para entender, hay que leer.
  > per capire = para entender | bisogna leggere = hay que leer
Luca: Sono venuto per chiedere scusa. = Vine a pedir perdón.
  > per chiedere = para pedir | scusa = perdón
Q ¿Cómo se dice «salió sin decir nada»?
+ È uscito senza dire niente. :: «Senza» + infinitivo.
- È uscito senza ha detto niente. :: Falta el infinitivo «dire».
- È uscito senza dicendo niente. :: Eso no se usa así.
H Per ___ il problema, serve tempo. :: Entender (capire)
+ capire :: «Per» + infinitivo.
- capisco :: Eso es presente.
- capito :: Eso es participio.
R Senza parlare, è uscito.
+ Sin hablar, salió. :: «Senza» + infinitivo.
- Sin hablar, sale. :: Eso es presente.
- Sin hablado, salió. :: Participio incorrecto.
A È partito senza salutare.
+ Salió sin saludar. :: «Senza» + infinitivo.
- Se fue saludando. :: Eso es gerundio.
- Se fue con saludo. :: Falta «senza».
O Per arrivare :: Para llegar :: «Per» + infinitivo.
X Escribe en italiano: «para ver» :: Per vedere. :: «Per» + infinitivo.
Q ¿Qué significa «senza scusarsi»?
+ sin disculparse :: «Scusarsi» = disculparse.
- con excusas :: Eso es «con» y no «senza».
- por excusas :: Eso es «per».
Q ¿Cuál es correcta para «para pedir»?
+ per chiedere :: «Per» + infinitivo.
- per chiesto :: Falta el infinitivo.
- per chiede :: Falta el infinitivo.
