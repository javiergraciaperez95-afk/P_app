@ 40 | Mi permetta, dottore | Registro formal: dare del Lei, presentarse con usted
I En italiano el trato de usted es muy importante, y el de tú es una decisión. Esta lección enseña cómo tratar a alguien con cortesía y cómo pasar de usted a tú.
E Dare del Lei y dare del tu :: **Dare del Lei** (tratar de usted), **dare del tu** (tutear). Al tratar a alguien de usted se usa **Lei** con verbo en tercera persona: **Lei è gentile** (usted es amable). :: Pasar al tú se propone con **Ci diamo del tu?** (¿nos tuteamos?).
E Fórmulas de cortesía :: **Mi permetta** (permítame), **Con permesso** (con permiso), **Prego, si accomodi** (por favor, tome asiento). **Vi dispiace?** (¿le importa?). :: Son fórmulas muy usadas en oficinas y en la vida diaria.
B Situación | Italiano | Español
| presentarse | Mi permetta, dottore. | Permítame, doctor.
| invitar a sentarse | Prego, si accomodi. | Por favor, tome asiento.
| tutear | Ci diamo del tu? | ¿Nos tuteamos?
| pedir permiso | Con permesso. | Con permiso.
W dare del Lei = tratar de usted | DA-re del LEI
W dare del tu = tutear | DA-re del TU
W gentilmente = amablemente | dʒen-til-MEN-te
W mi permetta = permítame | mi per-MET-ta
W vi dispiace = le importa | vi dis-PIA-tce
W accomodarsi = tomar asiento | ak-ko-mo-DAR-si
W si accomodi = tome asiento | si ak-ko-MO-di
W con permesso = con permiso | kon per-MES-so
W dottore = doctor | dot-TO-re
W diamo = damos | DIA-mo
W dà = da | da
W dà del Lei = trata de usted | da del LEI
V Vocabulario: trato formal
D Mi permetta, dottore
Anna: Mi permetta, dottore. = Permítame, doctor.
  > mi permetta = permítame | dottore = doctor
Luca: Prego, si accomodi. = Por favor, tome asiento.
  > prego = por favor | si accomodi = tome asiento
Anna: Ci diamo del tu? = ¿Nos tuteamos?
  > ci diamo del tu = nos tuteamos
Luca: Con permesso, dottore. = Con permiso, doctor.
  > con permesso = con permiso
Q ¿Cómo se dice «¿nos tuteamos?»?
+ Ci diamo del tu? :: «Darsi del tu» = tutearse.
- Ci diamo del Lei? :: Eso es tratarse de usted.
- Ci diamo? :: Falta «del tu».
H Prego, ___ accomodi. :: Tome asiento (si)
+ si :: Forma de usted de «accomodarsi».
- ti :: Es forma de tú.
- vi :: Es forma de vosotros.
R Mi permetta, dottore.
+ Permítame, doctor. :: «Permetta» = permita (usted).
- Permíteme, doctor. :: «Permetta» es usted.
- Permitimos, doctor. :: Eso sería «permettiamo».
A Vi dispiace?
+ ¿Le importa? :: Forma formal de preguntar.
- ¿Te importa? :: Eso sería «ti dispiace».
- ¿Os importa? :: Eso es vosotros, no formal.
O Con permesso :: Con permiso :: Fórmula de cortesía.
X Escribe en italiano: «tratar de usted» (dare del Lei) :: Dare del Lei. :: Verbo + «del Lei».
Q ¿Qué significa «gentilmente»?
+ amablemente :: Adverbio.
- gentil :: Eso es adjetivo.
- gente :: Eso es «persona» o «gente».
Q ¿Cuál es correcta para «él me trata de usted»?
+ Mi dà del Lei. :: «Dà del Lei» = trata de usted.
- Mi dà del tu. :: Eso es tutear.
- Mi dà Lei. :: Falta «del».

@ 40 | Sarò arrivato | El futuro anterior: habré hecho algo
I Cuando hablas de algo que ocurrirá antes de otra cosa del futuro, usas el futuro anterior: «cuando haya llegado», «habré terminado».
E Cómo se forma :: Futuro de **avere** o **essere** + participio: **avrò finito** (habré terminado), **sarò arrivato** (habré llegado). :: Con **essere** el participio concuerda: **sarò arrivata** (habré llegado, ella).
E Cuándo se usa :: Con **quando**, para algo que pasará antes: **Quando avrò finito, ti chiamo** (cuando haya terminado, te llamo). También para una suposición: **Sarà già partito** (ya habrá salido).
B Forma | Ejemplo | Español
| avrò + participio | Avrò detto tutto. | Habré dicho todo.
| sarò + participio | Sarò già partito. | Ya habré salido.
| saranno + participio | Saranno tutti contenti. | Estarán todos contentos.
W sarò = seré; estaré | sa-RO
W avrò = habré | a-VRO
W sarà = será; habrá | sa-RA
W avrai = habrás | a-VRAI
W saranno = serán; habrán | sa-RAN-no
W avremo = habremos | a-VRE-mo
W avrò finito = habré terminado | a-VRO fi-NI-to
W avrò mangiato = habré comido | a-VRO man-DJA-to
W sarà partito = habrá salido | sa-RA par-TI-to
W quando avrò finito = cuando haya terminado | KUAN-do a-VRO fi-NI-to
W avrò detto = habré dicho | a-VRO DET-to
W avremo visto = habremos visto | a-VRE-mo VI-sto
V Vocabulario: futuro anterior
D Quando avrò finito
Anna: Quando avrò finito, ti chiamo. = Cuando haya terminado, te llamo.
  > quando avrò finito = cuando haya terminado | ti chiamo = te llamo
Luca: Sarò già partito, forse. = Quizá ya habré salido.
  > sarò già partito = ya habré salido | forse = quizá
Anna: Allora avrò detto tutto? = ¿Entonces habré dicho todo?
  > avrò detto = habré dicho | allora = entonces
Luca: Sì, e saranno tutti contenti. = Sí, y estarán todos contentos.
  > saranno = estarán | tutti contenti = todos contentos
Q ¿Cómo se dice «habré terminado»?
+ avrò finito :: Futuro anterior con «avere».
- finirò :: Eso es futuro simple.
- ho finito :: Eso es passato prossimo.
H Quando ___ arrivato, ti chiamo. :: Habré (sarò)
+ sarò :: Futuro anterior de «essere».
- sono :: Eso es presente.
- sarei :: Eso es condicional.
R Avrò detto tutto.
+ Habré dicho todo. :: Futuro anterior.
- Diré todo. :: Eso es futuro simple.
- Dije todo. :: Eso es pasado.
A Sarà già partito.
+ Ya habrá salido. :: Futuro anterior de «partire».
- Ya sale. :: Eso es presente.
- Ya salió. :: Eso es pasado.
O Avremo visto :: Habremos visto :: Futuro anterior.
X Escribe en italiano: «habremos comido» :: Avremo mangiato. :: Futuro anterior con «avere».
Q ¿Qué significa «saranno»?
+ serán / habrán :: Tercera persona plural.
- seremos :: Eso es «siamo».
- son :: Eso es «sono».
Q ¿Cuál es correcta para «cuando haya llegado»?
+ Quando sarò arrivato. :: Futuro anterior con «quando».
- Quando arrivo. :: Eso es presente.
- Quando sarei arrivato. :: Eso es condicional passato.

@ 40 | Mi ha assicurato che sarebbe venuto | El discurso indirecto complejo
I Cuando repites lo que dijo alguien, el verbo puede ir en condicional o en pasado. Así cuentas promesas, confesiones y respuestas con todos sus matices.
E Verbos de comunicación :: **Mi ha assicurato che** (me aseguró que), **Mi ha confessato che** (me confesó que), **Ha ammesso che** (admitió que), **Mi ha giurato che** (me juró que). :: Después, el verbo va en condicional o en pasado.
E Preguntas en indirecto :: **Mi ha chiesto se avrei potuto** (me preguntó si habría podido). :: Se mantiene el condicional passato de la frase original.
B Verbo de comunicación | Ejemplo | Español
| assicurare | Mi ha assicurato che sarebbe venuto. | Me aseguró que habría venido.
| confessare | Mi ha confessato che avrebbe potuto venire. | Me confesó que habría podido venir.
| chiedere | Mi ha chiesto se avrei potuto. | Me preguntó si habría podido.
W mi ha assicurato che = me aseguró que | mi a as-si-ku-RA-to ke
W assicurare = asegurar | as-si-ku-RA-re
W mi ha confessato che = me confesó que | mi a kon-fes-SA-to ke
W confessare = confesar | kon-fes-SA-re
W ammettere = admitir | am-MET-te-re
W mi ha ammesso che = me admitió que | mi a am-MES-so ke
W ha giurato = juró | a dʒu-RA-to
W giurare = jurar | dʒu-RA-re
W mi ha chiesto se avrei = me preguntó si habría | mi a KIES-to se a-VREI
W mi ha giurato che = me juró que | mi a dʒu-RA-to ke
W ha ammesso che = admitió que | a am-MES-so ke
V Vocabulario: decir con matices
D Mi ha assicurato che sarebbe venuto
Anna: Mi ha assicurato che sarebbe venuto. = Me aseguró que habría venido.
  > mi ha assicurato che = me aseguró que | sarebbe venuto = habría venido
Luca: Mi ha confessato che avrebbe potuto venire. = Me confesó que habría podido venir.
  > mi ha confessato che = me confesó que | avrebbe potuto venire = habría podido venir
Anna: Mi ha chiesto se avrei potuto. = Me preguntó si habría podido.
  > mi ha chiesto se avrei = me preguntó si habría | potuto = podido
Luca: E tu cosa hai risposto? = ¿Y tú qué respondiste?
  > hai risposto = respondiste | cosa = qué
Q ¿Cómo se dice «me aseguró que vendría»?
+ Mi ha assicurato che sarebbe venuto. :: Discurso indirecto con condicional.
- Mi ha assicurato che verrà. :: Futuro sin cambio.
- Mi assicura che viene. :: Presente.
H Mi ha confessato che ___ potuto venire. :: Habría (avrebbe)
+ avrebbe :: Condicional passato reportado.
- ha :: Pasado.
- avrà :: Futuro anterior.
R Mi ha chiesto se avrei potuto.
+ Me preguntó si habría podido. :: Interrogativa indirecta con condicional passato.
- Me pregunta si puedo. :: Presente.
- Me preguntó si pude. :: Pasado.
A Mi ha giurato che sarebbe venuto.
+ Me juró que habría venido. :: Discurso indirecto.
- Me jura que vendrá. :: Presente y futuro.
- Me juró que vino. :: Pasado.
O Ha ammesso che :: Admitió que :: Verbo de comunicación + che.
X Escribe en italiano: «me aseguró que habría llegado» :: Mi ha assicurato che sarebbe arrivato. :: Con «essere», -o para hombre.
Q ¿Qué significa «confessare»?
+ confesar :: Verbo.
- confesarse :: Eso es «confessarsi».
- confiar :: Eso es «fidarsi».
Q ¿Cuál es correcta para «me confesó que habría podido»?
+ Mi ha confessato che avrebbe potuto. :: Condicional passato reportado.
- Mi ha confessato che potrà. :: Futuro.
- Mi confessa che avrebbe potuto. :: Presente.

@ 40 | Test finale | Examen final de B2
E Examen final de B2 :: Veinticinco preguntas sobre los diez capítulos del nivel. Si aciertas veinte o más, tienes un B2 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 31. ¿Cómo se dice «el cuadro fue pintado por un artista»?
+ Il quadro è stato dipinto da un artista. :: «Essere» + participio + «da».
- Il quadro dipinge un artista. :: Eso es activa.
- Il quadro è dipinto un artista. :: Falta «da».
H Cap. 31. La casa ___ costruita da molto tempo. :: Es (presente pasivo)
+ è :: Presente de «essere».
- ha :: Es «ha costruito» (activa).
- sta :: Es «sta» con gerundio.
A È scritto da Anna. :: Cap. 31. ¿Qué significa?
+ Está escrito por Anna. :: «Scritto» = escrito.
- Anna escribe el libro. :: Eso es activa.
- Anna escribirá el libro. :: Eso es futuro.
Q Cap. 32. ¿Cómo se dice «él nació»?
+ nacque :: Passato remoto de «nascere».
- nasce :: Presente.
- è nato :: Passato prossimo.
H Cap. 32. Il nonno ___ medico. :: Fue (fu)
+ fu :: Passato remoto de «essere».
- era :: Imperfecto.
- sarà :: Futuro.
Q Cap. 33. ¿Cómo se dice «después de haber entendido»?
+ dopo aver capito :: «Dopo aver» + participio.
- dopo capire :: Infinitivo presente.
- dopo capito :: Falta «aver».
R Avendo capito, ho risposto. :: Cap. 33. ¿Qué significa?
+ Habiendo entendido, respondí. :: «Avendo capito» = habiendo entendido.
- Entendiendo, respondo. :: Gerundio simple y presente.
- Habiendo entendido, responderé. :: Eso es futuro.
Q Cap. 34. ¿Cómo se dice «creo que ha entendido»?
+ Credo che abbia capito. :: Congiuntivo passato con «avere».
- Credo che ha capito. :: Con «che» va congiuntivo.
- Credo che avere capito. :: Falta el congiuntivo.
H Cap. 34. Pensavo che ___ detto. :: Hubieras (avessi)
+ avessi :: Congiuntivo imperfetto de «avere» con tú.
- hai :: Indicativo.
- abbia :: Congiuntivo presente.
Q Cap. 35. ¿Cómo se dice «podríamos salir»?
+ potremmo partire :: Condicional de «potere».
- possiamo partire :: Presente.
- potessimo partire :: Congiuntivo imperfetto.
H Cap. 35. Se fossi stato più attento, non ___ sbagliato. :: Habría (avrei)
+ avrei :: Condicional passato.
- avevo :: Imperfecto.
- ho :: Presente.
Q Cap. 36. ¿Qué significa «la cui»?
+ cuya :: Femenino de «il cui».
- cuyo :: Eso es masculino.
- quien :: Eso es «chi».
H Cap. 36. Lo scrittore, ___ libro è famoso, parla. :: Cuyo (masculino)
+ il cui :: Cuyo masculino.
- la cui :: Es femenino.
- i cui :: Es plural.
R La famiglia, la cui casa è grande, arriva. :: Cap. 36. ¿Qué significa?
+ La familia, cuya casa es grande, llega. :: «La cui» = cuya.
- La familia, de la que la casa es grande, llega. :: «Di cui» no es «cuyo».
- La familia, que su casa es grande, llega. :: Eso no es relativo.
Q Cap. 37. ¿Cómo se dice «aunque llueva, salgo»?
+ Anche se piove, esco. :: «Anche se» + indicativo.
- Anche se piove, uscito. :: Falta el verbo conjugado.
- Se piove, esco. :: «Se» es «si».
R Per quanto studi, non passo. :: Cap. 37. ¿Qué significa?
+ Por mucho que estudie, no apruebo. :: «Per quanto» = por mucho que.
- Porque estudio, no apruebo. :: Eso es causal.
- Para que estudie, no apruebo. :: Eso es final.
Q Cap. 38. ¿Cómo se dice «lo consigo»?
+ ce la faccio :: Expresión de conseguir algo.
- ho la faccia :: Eso es «tengo cara».
- faccio la cosa :: Eso es «hago la cosa».
H Cap. 38. ___ di loro è gentile. :: Cada uno (ciascuno)
+ Ciascuno :: «Cada uno».
- Alcuni :: «Algunos».
- Nessuno :: «Ninguno».
Q Cap. 39. ¿Qué significa «macché»?
+ ¡Qué va! :: Desacuerdo rotundo.
- ¡Claro! :: Eso es «certo».
- ¡Perfecto! :: Eso es «perfetto».
H Cap. 39. Vorrei sapere quanto ___ il biglietto. :: Cueste (costi)
+ costi :: Congiuntivo presente de «costare».
- costa :: Indicativo.
- costerà :: Futuro.
Q Cap. 39. ¿Cómo se dice «claro que sí»?
+ Certo che sì. :: Afirmación enfática.
- Macché! :: Eso es «¡qué va!».
- Mah. :: Eso es duda.
Q Cap. 40. ¿Cómo se dice «habré terminado»?
+ avrò finito :: Futuro anterior con «avere».
- finirò :: Futuro simple.
- ho finito :: Passato prossimo.
H Cap. 40. Quando ___ arrivato, ti chiamo. :: Habré (sarò)
+ sarò :: Futuro anterior de «essere».
- sono :: Presente.
- sarei :: Condicional.
R Avrò detto tutto. :: Cap. 40. ¿Qué significa?
+ Habré dicho todo. :: Futuro anterior.
- Diré todo. :: Futuro simple.
- Dije todo. :: Pasado.
Q Cap. 40. ¿Qué significa «dare del Lei»?
+ tratar de usted :: Trato formal.
- tutear :: Eso es «dare del tu».
- dar las gracias :: Eso es «ringraziare».
