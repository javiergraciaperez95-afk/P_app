@ 7 | I vestiti | La ropa y los demostrativos
E Este y aquel :: **Questo** es «este» y concuerda como un adjetivo en -o: **questo** vestito, **questa** giacca, **questi** pantaloni, **queste** scarpe. :: **Quello** es «ese, aquel». Delante de un nombre se comporta como el artículo: **quel** vestito, **quella** giacca, **quei** pantaloni, **quelle** scarpe.
B Los demostrativos | | Singular | Plural
| masculino | questo vestito | questi pantaloni
| femenino | questa giacca | queste scarpe
E Llevar puesto :: «Llevar puesto» es **indossare**: **Indosso una giacca** (llevo una chaqueta). También se dice **portare**. :: Los colores concuerdan con la prenda: **un cappotto nero**, **una giacca nera**, **le scarpe nere**. Recuerda que **blu** no cambia nunca. :: Para elegir: **Mi piace questo** (me gusta este), **Preferisco quello** (prefiero ese).
W vestiti = ropa | ves-TI-ti
W vestito = vestido; traje | ves-TI-to
W camicia = camisa | ca-MI-cha
W maglietta = camiseta | ma-LIE-ta
W pantaloni = pantalones | pan-ta-LO-ni
W jeans = vaqueros | yins
W gonna = falda | GO-na
W giacca = chaqueta | YA-ca
W cappotto = abrigo | ca-PO-to
W scarpe = zapatos | SCAR-pe
W indosso = llevo puesto | in-DO-so
W indossa = lleva puesto | in-DO-sa
W questi = estos | KUES-ti
W quel = ese, aquel | kuel
W quella = esa, aquella | KUE-la
W nuovi = nuevos | NUO-vi
W bianca = blanca | BIAN-ca
W nere = negras | NE-re
W preferisco = prefiero | pre-fe-RIS-co
W negozio = tienda | ne-GO-tsio
W davanti al = delante del | da-VAN-ti al
W con te = contigo | con te
W vedo = veo | VE-do
V Vocabulario: la ropa
D Por teléfono
Chiara: Ciao, Luca. Dove sei? = Hola, Luca. ¿Dónde estás?
  > Dove sei = dónde estás
Luca: Sono davanti al negozio. Indosso una giacca rossa. = Estoy delante de la tienda. Llevo una chaqueta roja.
  > davanti al negozio = delante de la tienda | Indosso = llevo puesto | una giacca rossa = una chaqueta roja
Chiara: Io indosso un cappotto nero e i jeans blu. = Yo llevo un abrigo negro y los vaqueros azules.
  > un cappotto nero = un abrigo negro | i jeans blu = los vaqueros azules («blu» no cambia)
Luca: Stefano è con te? = ¿Stefano está contigo?
  > con te = contigo
Chiara: Sì. Indossa una maglietta verde. = Sí. Lleva una camiseta verde.
  > Indossa = lleva puesto | una maglietta verde = una camiseta verde
Luca: Va bene, adesso vedo Stefano! = ¡Vale, ya veo a Stefano!
  > adesso = ahora | vedo = veo
D En el escaparate
Elena: Mi piace questo vestito blu. = Me gusta este vestido azul.
  > questo vestito = este vestido
Marco: E questi pantaloni? = ¿Y estos pantalones?
  > questi pantaloni = estos pantalones
Elena: No, preferisco queste scarpe. = No, prefiero estos zapatos.
  > preferisco = prefiero | queste scarpe = estos zapatos (femenino en italiano)
Q ¿Cómo dices «esta chaqueta»?
+ questa giacca :: Femenino singular.
- questo giacca :: «Giacca» es femenino.
- queste giacca :: «Queste» es plural.
Q ¿Cómo dices «estos zapatos»?
+ queste scarpe :: «Scarpe» es femenino plural.
- questi scarpe :: «Questi» es masculino.
- questa scarpe :: Es plural.
Q ¿Cuál es correcta?
+ una giacca nera :: El color concuerda en femenino.
- una giacca nero :: Falta la concordancia.
- una nera giacca :: El color va detrás.
R Indosso un cappotto nero.
+ Llevo un abrigo negro. :: Indossare = llevar puesto.
- Compro un abrigo negro. :: Sería «compro».
- Llevo una chaqueta negra. :: Chaqueta es «giacca».
H ___ pantaloni sono nuovi.
+ Questi :: Masculino plural.
- Queste :: Es femenino.
- Questo :: Es singular.
H Mi piace ___ gonna.
+ questa :: «Gonna» es femenino.
- questo :: Es masculino.
- questi :: Es plural.
A Indossa una camicia bianca.
+ Lleva una camisa blanca. :: Camicia = camisa.
- Lleva una camiseta blanca. :: Camiseta es «maglietta».
- Lleva una camisa negra. :: Negra es «nera».
O Preferisco queste scarpe nere :: Prefiero estos zapatos negros :: Preferisco + demostrativo + prenda + color.

@ 7 | Quanto costa? | Comprar: precios y tallas
E Preguntar el precio :: **Quanto costa?** para una cosa y **Quanto costano?** para varias: **Quanto costa questo vestito?**, **Quanto costano queste scarpe?** :: **Troppo** delante de un adjetivo es «demasiado» y no cambia: **troppo caro**, **troppo piccola**. :: **Caro** es «caro»; lo contrario, **economico**.
E En la tienda :: **Posso provare?** = ¿puedo probármelo? :: **La taglia** es la talla de la ropa; para los zapatos se dice **il numero**. :: En **Lo prendo**, **lo** sustituye a **il vestito**; en **La prendo**, **la** sustituye a **la giacca**. El pronombre directo va antes del verbo. En plural: **li prendo**, **le prendo**. :: Para pagar: **con la carta** (con tarjeta) o **in contanti** (en efectivo).
W quanto costa = ¿cuánto cuesta? | KUAN-to COS-ta
W costa = cuesta | COS-ta
W costano = cuestan | COS-ta-no
W caro = caro | CA-ro
W cara = cara | CA-ra
W economico = barato | e-co-NO-mi-co
W taglia = talla | TA-lia
W posso = puedo | PO-so
W provare = probar, probarse | pro-VA-re
W lo prendo = me lo llevo | lo PREN-do
W la prendo = me la llevo | la PREN-do
W li prendo = me los llevo | li PREN-do
W le prendo = me las llevo | le PREN-do
W pagare = pagar | pa-GA-re
W con la carta = con tarjeta | con la CAR-ta
W in contanti = en efectivo | in con-TAN-ti
V Vocabulario: de compras
D En la tienda de ropa
Sara: Scusi, quanto costa questo vestito? = Disculpe, ¿cuánto cuesta este vestido?
  > quanto costa = cuánto cuesta | questo vestito = este vestido
Giulia: Costa 45 euro. = Cuesta 45 euros.
  > Costa = cuesta
Sara: E queste scarpe? = ¿Y estos zapatos?
  > queste scarpe = estos zapatos
Giulia: Costano 80 euro. = Cuestan 80 euros.
  > Costano = cuestan (plural)
Sara: È troppo caro. Ha questo vestito nella taglia 38? = Es demasiado caro. ¿Tiene este vestido en la talla 38?
  > troppo caro = demasiado caro | nella taglia 38 = en la talla 38
Giulia: Sì, ecco. = Sí, aquí tiene.
  > ecco = aquí tiene
Sara: Posso provare? = ¿Puedo probármelo?
  > Posso = puedo | provare = probar
Giulia: Certo. = Por supuesto.
  > Certo = claro
Sara: È bello. Lo prendo. Posso pagare con la carta? = Es bonito. Me lo llevo. ¿Puedo pagar con tarjeta?
  > Lo prendo = me lo llevo («lo» = il vestito) | pagare con la carta = pagar con tarjeta
Q ¿Cómo preguntas el precio de unos zapatos?
+ Quanto costano queste scarpe? :: Plural → costano.
- Quanto costa queste scarpe? :: «Scarpe» es plural.
- Quante costano queste scarpe? :: Para el precio se usa «quanto».
Q Te llevas una chaqueta («una giacca»). ¿Qué dices?
+ La prendo. :: Femenino → la.
- Lo prendo. :: «Lo» es para masculino.
- Prendo lei. :: El pronombre va delante del verbo.
Q ¿Cómo dices «demasiado cara» hablando de una falda?
+ troppo cara :: «Troppo» no cambia; «cara» concuerda.
- troppa cara :: Delante de un adjetivo, «troppo» no cambia.
- molto caro :: Eso es «muy caro», y en masculino.
R È troppo caro.
+ Es demasiado caro. :: Troppo + adjetivo = demasiado.
- Es muy barato. :: Barato es «economico».
- No es caro. :: No.
H Queste scarpe ___ 80 euro.
+ costano :: Plural.
- costa :: Es singular.
- costi :: No.
H Posso pagare ___ contanti?
+ in :: In contanti = en efectivo.
- con :: «Con» va con «la carta».
- a :: No.
A Posso provare questa giacca?
+ ¿Puedo probarme esta chaqueta? :: Provare = probarse.
- ¿Puedo comprar esta chaqueta? :: Sería «comprare».
- ¿Cuánto cuesta esta chaqueta? :: No.
O Quanto costa questa gonna :: ¿Cuánto cuesta esta falda? :: Quanto costa + demostrativo + prenda.

@ 7 | Più caro, meno caro | Comparar cosas
E Más y menos :: **Più** = más. **Meno** = menos. Van delante del adjetivo: **più grande**, **meno caro**. :: El segundo término lleva **di**, que se funde con el artículo: **Il telefono bianco è meno caro del telefono nero** (di + il = del). Con nombres propios, solo «di»: **Marco è più alto di Luca**. :: La igualdad se dice con **come**: **È alto come suo padre** (es tan alto como su padre).
B Comparar | Estructura | Ejemplo | Español
| più … di | più caro di | más caro que
| meno … di | meno caro di | menos caro que
| … come | caro come | tan caro como
E Mejor y el más :: «Más bueno» puede decirse **più buono** o **migliore** (mejor). «El mejor» es **il migliore**. :: Para «el más» basta poner el artículo delante: **il più caro** (el más caro), **la più grande** (la más grande). :: **Quale** = cuál: **Quale preferisci?** (¿cuál prefieres?).
W più = más | piú
W meno = menos | ME-no
W del = del; que el (al comparar) | del
W grande = grande | GRAN-de
W migliore = mejor | mi-LIO-re
W il migliore = el mejor | il mi-LIO-re
W quale = cuál | KUA-le
W preferisci = prefieres | pre-fe-RI-shi
W allora = entonces | a-LO-ra
W per me = para mí | per me
W me = mí | me
W per te = para ti | per te
V Vocabulario: comparar
D ¿Cuál prefieres?
Paolo: Quale telefono preferisci? = ¿Qué móvil prefieres?
  > Quale telefono = cuál móvil | preferisci = prefieres
Anna: Il telefono bianco è meno caro del telefono nero. = El móvil blanco es más barato que el negro.
  > meno caro = menos caro | del telefono nero = que el móvil negro (di + il = del)
Paolo: Ma il nero è più grande e più bello. = Pero el negro es más grande y más bonito.
  > più grande = más grande | più bello = más bonito
Anna: Sì, ma è anche più caro. = Sí, pero también es más caro.
  > anche = también | più caro = más caro
Paolo: Per me, un telefono piccolo è migliore. = Para mí, un móvil pequeño es mejor.
  > Per me = para mí | migliore = mejor
Anna: Allora il bianco è il migliore per te. = Entonces el blanco es el mejor para ti.
  > Allora = entonces | il migliore = el mejor
Q ¿Cómo dices «más alto que Luca»?
+ più alto di Luca :: Più + adjetivo + di.
- più alto che Luca :: Entre dos personas o cosas se usa «di».
- alto più di Luca :: «Più» va delante del adjetivo.
Q ¿Cómo dices «el más caro»?
+ il più caro :: Artículo + più + adjetivo.
- il caro più :: El orden es otro.
- più il caro :: No.
Q ¿Cómo dices «tan alto como su padre»?
+ alto come suo padre :: La igualdad se dice con «come».
- alto di suo padre :: «Di» es para «más» y «menos».
- più alto come suo padre :: No se mezclan.
R Mia sorella è più alta di me.
+ Mi hermana es más alta que yo. :: Più alta di = más alta que.
- Mi hermana es menos alta que yo. :: Sería «meno alta».
- Yo soy más alta que mi hermana. :: Al revés.
H Questa camicia è meno cara ___ quella giacca.
+ di :: Al comparar, «di».
- che :: Entre dos cosas se usa «di».
- come :: Es para la igualdad.
H È ___ migliore negozio di Roma.
+ il :: Il migliore = el mejor.
- un :: Con el superlativo va el artículo definido.
- più :: «Migliore» ya significa «más bueno».
A Questa borsa è più cara di quel vestito.
+ Este bolso es más caro que ese vestido. :: Più cara di = más cara que.
- Este bolso es más barato que ese vestido. :: Sería «meno cara».
- Ese vestido es más caro que este bolso. :: Al revés.
O Questo cappotto è più caro di quella giacca :: Este abrigo es más caro que esa chaqueta :: Più + adjetivo + di.
