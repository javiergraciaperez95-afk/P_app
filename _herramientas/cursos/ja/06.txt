@ 6 | すき です か | La comida y lo que te gusta
E Me gusta: ～が すき です :: «Gustar» no es un verbo en japonés: se dice con **すき** (gustado) + **です**. Lo que te gusta lleva la partícula **が**: **さかな が すき です** (me gusta el pescado). :: **だいすき** = me encanta. **きらい** = no me gusta nada, lo odio. :: Negación: **すき じゃ ありません** (no me gusta). Para suavizarla se añade **あまり**: **あまり すき じゃ ありません** (no me gusta mucho).
B Gustos | Japonés | Español
| だいすき です | me encanta
| すき です | me gusta
| あまり すき じゃ ありません | no me gusta mucho
| きらい です | no me gusta nada
E Contrastar con は :: Cuando comparas dos cosas, **は** sustituye a **が** o a **を** para marcar el contraste: **さかな は すき です。 にく は すき じゃ ありません** (el pescado me gusta; la carne, no). :: **でも** al principio de la frase es «pero». :: Para preguntar los gustos: **なに が すき です か** (¿qué te gusta?).
W すき = gustar (que gusta) | suki
W だいすき = encantar | daisuki
W きらい = no gustar nada, odiar | kirai
W たべもの = comida | tabemono
W のみもの = bebida | nomimono
W やさい = verdura | yasai
W くだもの = fruta | kudamono
W たまご = huevo | tamago
W ぎゅうにゅう = leche | gyūnyū
W ジュース = zumo | jūsu
W でも = pero | demo
W のみません = no beber | nomimasen
V Vocabulario: la comida
D ¿Te gusta el pescado?
まり: アンナ さん は さかな が すき です か。 = ¿Te gusta el pescado, Anna?
  > さかな が = el pescado (lo que gusta, con «が») | すき です か = ¿te gusta?
アンナ: はい、 だいすき です。 すし を よく たべます。 = Sí, me encanta. Como sushi a menudo.
  > だいすき です = me encanta | すし を よく たべます = como sushi a menudo
まり: にく は？ = ¿Y la carne?
  > にく は = ¿y la carne? (contraste)
アンナ: にく は あまり すき じゃ ありません。 = La carne no me gusta mucho.
  > にく は = la carne, en cambio | あまり すき じゃ ありません = no me gusta mucho
まり: そう です か。 のみもの は なに が すき です か。 = Ya veo. ¿Qué bebidas te gustan?
  > のみもの は = en cuanto a bebidas | なに が すき です か = ¿qué te gusta?
アンナ: おちゃ が すき です。 でも、 コーヒー は のみません。 = Me gusta el té. Pero café no bebo.
  > でも = pero | コーヒー は のみません = café, no bebo
Q ¿Cómo dices «me gusta la fruta»?
+ くだもの が すき です。 :: Cosa + が + すき です.
- くだもの を すき です。 :: Con «すき» la partícula es が.
- くだもの が すき ます。 :: «すき» no es un verbo: va con です.
Q ¿Cómo dices «no me gusta»?
+ すき じゃ ありません。 :: Negación con じゃ ありません.
- すき ません。 :: «すき» no es un verbo.
- すき です ない。 :: No existe.
Q ¿Qué significa «だいすき»?
+ Me encanta. :: Más fuerte que すき.
- No me gusta. :: No.
- Me gusta un poco. :: No.
R やさい は あまり すき じゃ ありません。
+ La verdura no me gusta mucho. :: あまり + negativo = no mucho.
- La verdura me gusta mucho. :: Es negativa.
- No como verdura. :: No dice «comer».
H たまご ___ すき です か。
+ が :: Lo que gusta lleva が.
- を :: No.
- に :: No.
H おちゃ が すき です。 ___ 、 コーヒー は のみません。
+ でも :: «Pero».
- それから :: Significa «después».
- じゃあ :: Significa «entonces».
A ぎゅうにゅう が きらい です。 :: Escucha. ¿Qué significa?
+ No me gusta nada la leche. :: きらい = odiar.
- Me encanta la leche. :: Sería だいすき.
- Bebo leche. :: No.
O わたし は くだもの が だいすき です :: Me encanta la fruta :: Tema + は + cosa + が + だいすき + です.

@ 6 | レストラン で | En el restaurante: pedir y pagar
E Pedir :: Para pedir algo: cosa + **を ください** (deme…) o, más educado, **を おねがいします** (…por favor). **メニュー を ください** (deme la carta). :: Al entrar en cualquier tienda o restaurante te dirán **いらっしゃいませ** (bienvenido). No hay que responder. :: Para llamar al camarero: **すみません**.
E Los precios :: La moneda es el yen: **えん**. Los precios son números grandes, así que hacen falta las centenas y los millares. :: **ひゃく** es 100 y **せん** es 1.000. Se multiplican poniendo el número delante: **にひゃく** (200), **ごせん** (5.000). :: Algunos cambian de sonido: 300 es **さんびゃく**, 600 es **ろっぴゃく**, 800 es **はっぴゃく**; 3.000 es **さんぜん** y 8.000 es **はっせん**. :: El japonés cuenta de diez mil en diez mil: 10.000 es **いちまん**.
B Números grandes | Número | Japonés | Se lee
| 100 | ひゃく | hyaku
| 300 | さんびゃく | sanbyaku
| 600 | ろっぴゃく | roppyaku
| 800 | はっぴゃく | happyaku
| 1.000 | せん | sen
| 3.000 | さんぜん | sanzen
| 10.000 | いちまん | ichiman
E Preguntar el precio :: **いくら です か** = ¿cuánto cuesta? :: **ぜんぶ で** = en total. :: Para pedir la cuenta: **おかいけい を おねがいします**.
W いらっしゃいませ = bienvenido (en una tienda) | irasshaimase
W ください = deme, póngame | kudasai
W おねがいします = por favor (al pedir) | onegaishimasu
W いくら = cuánto (precio) | ikura
W えん = yen | en
W ぜんぶ で = en total | zenbu de
W せん = mil | sen
W まん = diez mil | man
W おかいけい = la cuenta | okaikē
W てんいん さん = dependiente, camarero (al dirigirse a él) | ten'in san
V Vocabulario: en el restaurante
D En el restaurante
てんいん: いらっしゃいませ。 = Bienvenida.
  > いらっしゃいませ = saludo de quien atiende
アンナ: すみません、 メニュー を ください。 = Disculpe, deme la carta.
  > すみません = disculpe | メニュー を ください = deme la carta
てんいん: はい、 どうぞ。 = Sí, aquí tiene.
  > どうぞ = tenga, adelante
アンナ: ラーメン と おちゃ を おねがいします。 = Un ramen y un té, por favor.
  > ラーメン と おちゃ = ramen y té | を おねがいします = por favor
アンナ: すみません、 おかいけい を おねがいします。 いくら です か。 = Disculpe, la cuenta, por favor. ¿Cuánto es?
  > おかいけい = la cuenta | いくら です か = ¿cuánto es?
てんいん: ぜんぶ で 950 えん です。 = En total son 950 yenes.
  > ぜんぶ で = en total | 950 えん = 950 yenes (se lee «kyūhyaku gojū en»)
Q ¿Cómo pides agua?
+ みず を ください。 :: Cosa + を ください.
- みず が ください。 :: La partícula es を.
- みず は です。 :: No.
Q ¿Cómo preguntas el precio?
+ いくら です か。 :: ¿Cuánto cuesta?
- なんさい です か。 :: Eso pregunta la edad.
- なんじ です か。 :: Eso pregunta la hora.
Q ¿Cómo se dice «300»?
+ さんびゃく :: Cambia el sonido: «byaku».
- さんひゃく :: Con el 3 se dice «byaku».
- さんぜん :: Eso es 3.000.
Q ¿Qué número es «にせん»?
+ 2.000 :: Dos veces mil.
- 200 :: Sería «にひゃく».
- 20.000 :: Sería «にまん».
R メニュー を おねがいします。
+ La carta, por favor. :: おねがいします = por favor.
- La cuenta, por favor. :: Sería おかいけい.
- Gracias por la carta. :: No.
H コーヒー ___ ください。
+ を :: Cosa + を ください.
- は :: No.
- に :: No.
A ぜんぶ で 1000 えん です。 :: Escucha. ¿Cuánto es?
+ 1.000 yenes en total. :: せん えん.
- 100 yenes en total. :: Sería ひゃく.
- 10.000 yenes en total. :: Sería いちまん.
O ラーメン と おちゃ を おねがいします :: Un ramen y un té, por favor :: Cosa + と + cosa + を + おねがいします.

@ 6 | ひとつ、 ふたつ | Contar cosas
E Los contadores :: En japonés no se dice «dos cafés» sin más: hay palabras especiales para contar, llamadas **contadores**. El más útil, que vale para casi cualquier objeto, es la serie **ひとつ, ふたつ, みっつ…** (del 1 al 10). :: A partir de 11 se usan los números normales.
B Contar cosas | Cantidad | Japonés | Se lee
| 1 | ひとつ | hitotsu
| 2 | ふたつ | futatsu
| 3 | みっつ | mittsu
| 4 | よっつ | yottsu
| 5 | いつつ | itsutsu
| 6 | むっつ | muttsu
| 7 | ななつ | nanatsu
| 8 | やっつ | yattsu
| 9 | ここのつ | kokonotsu
| 10 | とお | tō
E Dónde va la cantidad :: La cantidad va **después** de la cosa y su partícula, justo delante del verbo: **コーヒー を ふたつ ください** (deme dos cafés; literalmente «café, dos, deme»). :: Para preguntar cuántos: **いくつ**. :: Existen contadores específicos, que irás aprendiendo: **まい** para cosas planas (billetes, hojas), **ほん** para cosas alargadas (botellas, bolígrafos) y **はい** para vasos y tazas.
W ひとつ = uno (contando cosas) | hitotsu
W ふたつ = dos (contando cosas) | futatsu
W みっつ = tres (contando cosas) | mittsu
W よっつ = cuatro (contando cosas) | yottsu
W いつつ = cinco (contando cosas) | itsutsu
W いくつ = cuántos | ikutsu
W ごちゅうもん = su pedido | gochūmon
V Vocabulario: contar
D En la cafetería
てんいん: いらっしゃいませ。 ごちゅうもん は？ = Bienvenidos. ¿Qué van a tomar?
  > ごちゅうもん は = ¿su pedido?
けん: コーヒー を ふたつ と ケーキ を ひとつ ください。 = Dos cafés y una tarta.
  > コーヒー を ふたつ = dos cafés (la cantidad va detrás) | ケーキ を ひとつ = una tarta | ください = deme
てんいん: コーヒー を ふたつ、 ケーキ を ひとつ です ね。 = Dos cafés y una tarta, ¿verdad?
  > です ね = ¿verdad? (para confirmar)
まり: すみません、 みず も ください。 = Disculpe, agua también.
  > みず も = agua también
てんいん: はい。 みず は いくつ です か。 = Sí. ¿Cuántas aguas?
  > いくつ です か = ¿cuántas?
まり: ふたつ おねがいします。 = Dos, por favor.
  > ふたつ = dos
Q ¿Cómo se dice «tres» al contar cosas?
+ みっつ :: Con la consonante doble.
- さんつ :: No existe.
- みつ :: Falta la っ pequeña.
Q ¿Cómo pides dos cafés?
+ コーヒー を ふたつ ください。 :: La cantidad va detrás de «を».
- ふたつ コーヒー を ください。 :: La cantidad no va delante.
- コーヒー ふたつ を ください。 :: «を» va pegada a la cosa.
Q ¿Cómo preguntas «¿cuántos?»?
+ いくつ です か。 :: Para cosas.
- いくら です か。 :: Eso es «¿cuánto cuesta?».
- なんにん です か。 :: Eso es para personas.
R ケーキ を ひとつ ください。
+ Deme una tarta. :: ひとつ = una.
- Deme dos tartas. :: Sería ふたつ.
- Me gusta la tarta. :: No.
H みず を ___ ください。 (tres)
+ みっつ :: Tres.
- ふたつ :: Dos.
- よっつ :: Cuatro.
H ビール ___ ふたつ ください。
+ を :: Cosa + を + cantidad.
- の :: No.
- が :: No.
A アイス を よっつ ください。 :: Escucha. ¿Cuántos helados piden?
+ Cuatro. :: よっつ = cuatro.
- Ocho. :: Sería やっつ.
- Tres. :: Sería みっつ.
O コーヒー を ふたつ ください :: Deme dos cafés :: Cosa + を + cantidad + ください.
