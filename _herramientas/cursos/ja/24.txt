@ 24 | むかし と いつも (1) | Solía: たものだ
I Ahora hablamos del pasado: lo que solías hacer, lo que te pasaba a menudo y lo que has aprendido de tu experiencia.
E 〜たものだ: solía :: Para decir que hacías algo de forma habitual en el pasado y ya no: verbo en forma た + **もの だ**: **こども の とき、 よく うみ へ いった もの です** (de niño solía ir mucho al mar). :: Suena a recuerdo, con un poco de nostalgia.
E 〜ことがある: a veces ocurre :: Para decir que algo pasa de vez en cuando: verbo en forma normal + **こと が ある**: **ときどき、 ねぼう する こと が あります** (a veces me quedo dormido). :: No es lo mismo que la experiencia de 041 (たことがある): aquí se habla de algo que pasa.
E La regla de «もの» :: Con **もの** la idea es «lo que siempre se hacía». :: En la conversación de hoy, **もの です** suena elegante; en lo casual se dice **もん**.
B Recuerdos y ocurrencias | Forma | Significa | Ejemplo
| 〜た もの です | solía (recuerdo) | よく いった もの です
| 〜こと が ある | a veces pasa | ねぼう する こと が あります
W もの = (aquí) lo que se hacía; costumbre | mono
W こども = niño, niña | kodomo
W よく = a menudo; mucho | yoku
W うみ = mar | umi
W ねぼう = quedarse dormido | nebō
W した = hice (forma た de する) | shita
W あそんだ = jugué; jugaba (forma た de あそぶ) | asonda
W よんだ = leí (forma た de よむ) | yonda
V Vocabulario: solía
D Recuerdos de la infancia
まり: けんじ さん は こども の とき、 なに を した もの です か。 = Ken, de niño, ¿qué solías hacer?
  > こども の とき = de niño | なに を した もの です か = ¿qué solías hacer?
けんじ: よく うみ で あそんだ もの です。 = Solía jugar mucho en el mar.
  > よく うみ で あそんだ もの です = solía jugar mucho en el mar
まり: そう です か。 わたし は いえ で ほん を よんだ もの です。 = ¿Ah, sí? Yo solía leer libros en casa.
  > ほん を よんだ もの です = solía leer libros
Q ¿Qué significa «こども の とき、 よく うみ へ いった もの です»?
+ De niño solía ir mucho al mar. :: もの です = solía (recuerdo).
- De niño voy al mar hoy. :: Eso sería el presente.
- De niño nunca fui al mar. :: Eso es lo contrario.
Q ¿Qué expresa «〜た もの です»?
+ Una costumbre del pasado que ya no existe. :: Suena a recuerdo.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H こども の とき、 よく うみ へ ___ もの です。 :: De niño solía ir al mar.
+ いった :: Forma た de いく.
- いく :: Eso sería presente, no recuerdo.
- いきません :: Eso es negativo.
H ___ こと が あります。 :: A veces me quedo dormido.
+ ねぼう する :: Algo que pasa de vez en cuando.
- ねぼう した :: Eso sería algo que ya pasó.
- ねぼう しません :: Eso es negativo.
R こども の とき、 よく うみ で あそんだ もの です。 :: Traduce la frase.
+ De niño solía jugar mucho en el mar. :: もの です = solía.
- De niño juego en el mar. :: Eso sería presente.
- De niño no jugaba en el mar. :: Eso es lo contrario.
A そう です か。 わたし は いえ で ほん を よんだ もの です。 :: ¿Qué cuenta?
+ Que solía leer libros en casa. :: もの です = solía.
- Que lee libros en casa hoy. :: Eso sería presente.
- Que no lee libros. :: Eso es lo contrario.
O ときどき、 ねぼう する こと が あります :: A veces me quedo dormido. :: こと が ある = pasa a veces.
Q ¿Cuál es el sentido de «ときどき ... こと が ある»?
+ Algo que pasa de vez en cuando. :: こと が ある = a veces.
- Algo que nunca pasa. :: Eso sería ありません.
- Algo que pasó una vez. :: Eso sería 〜た こと が あります.

@ 24 | むかし と いつも (2) | Cada vez que y cada
I Hoy aprendes a decir que algo pasa siempre que ocurre otra cosa, y a repartir algo a intervalos regulares.
E 〜たびに: cada vez que :: Para decir que algo pasa siempre que ocurre otra cosa: verbo en forma normal + **たび に**: **かぞく に あう たび に、 うれしく なります** (cada vez que veo a mi familia, me pongo contento). :: Se usa con verbos en forma normal, sobre todo para sentimientos.
E 〜ごとに: cada (intervalos) :: Para decir cada cuánto se repite algo: sustantivo de tiempo + **ごと に**: **1 じかん ごと に、 きゅうけい を します** (cada hora, hago un descanso). :: Se puede usar con cualquier sustantivo: **ひとり ごと に** (cada persona).
B Cada vez y cada | Forma | Significa | Ejemplo
| 〜たび に | cada vez que (acción) | あう たび に
| 〜ごと に | cada (intervalo) | 1じかん ごと に
W たび = vez; ocasión | tabi
W ごと = cada (intervalo) | goto
W うれしく = contento; alegremente (de うれしい) | ureshiku
W なります = se vuelve; se pone | narimasu
W きゅうけい = descanso; pausa | kyūkei
W さむく = frío (adverbio, de さむい) | samuku
V Vocabulario: cada vez y cada
T Mi rutina de trabajo
- かぞく に あう たび に、 うれしく なります。 = Cada vez que veo a mi familia, me pongo contento.
  > あう たび に = cada vez que veo | うれしく なります = me pongo contento
- 1 じかん ごと に、 きゅうけい を します。 = Cada hora, hago un descanso.
  > 1 じかん ごと に = cada hora | きゅうけい を します = hago un descanso
- ふゆ に なる たび に、 さむく なります。 = Cada vez que llega el invierno, hace más frío.
  > なる たび に = cada vez que llega | さむく なります = hace más frío
Q ¿Qué significa «かぞく に あう たび に、 うれしく なります»?
+ Cada vez que veo a mi familia, me pongo contento. :: たび に = cada vez que.
- Cuando vi a mi familia, estuve contento. :: Eso es el pasado puntual.
- Nunca me pongo contento con la familia. :: Eso es lo contrario.
Q ¿Qué expresa «〜ごとに»?
+ Cada cuánto se repite algo. :: ごと に = cada.
- Una causa. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H まいにち 1 じかん ___ 、 きゅうけい を します。 :: Cada hora, hago un descanso.
+ ごと に :: Cada intervalo.
- たび に :: Eso sería cada vez que pasa algo.
- ながら :: Eso sería mientras.
H にほん へ いく ___ 、 にほんご が じょうず に なります。 :: Cada vez que voy a Japón, mi japonés mejora.
+ たび に :: Cada vez que pasa.
- ごと に :: Eso sería cada intervalo de tiempo.
- まえに :: Eso sería antes de.
R かぞく に あう たび に、 うれしく なります。 :: Traduce la frase.
+ Cada vez que veo a mi familia, me pongo contento. :: たび に = cada vez que.
- Nunca veo a mi familia. :: Eso es lo contrario.
- Veo a mi familia antes de ponerme contento. :: Eso invierte el sentido.
A 1 じかん ごと に、 きゅうけい を します。 :: ¿Qué cuenta?
+ Que hace un descanso cada hora. :: ごと に = cada.
- Que hace un descanso una vez en la vida. :: Eso es lo contrario.
- Que descansa mientras trabaja. :: Eso sería ながら.
O ふゆ に なる たび に :: Cada vez que llega el invierno. :: たび に = cada vez que.
Q ¿Cuál significa «ごと に»?
+ Cada (intervalo). :: Marca la repetición.
- Cada vez que pasa algo. :: Eso sería たび に.
- Después de. :: Eso sería あと で.

@ 24 | むかし と いつも (3) | Regla y costumbre: ことになっている y ことにしている
I Por último, dos formas que parecen iguales y no lo son: una para las reglas y otra para tus propias costumbres.
E 〜ことになっている: regla o norma :: Para explicar lo que está establecido por una norma o un acuerdo: verbo en forma normal + **こと に なって いる**: **ここ で は しゃしん を とらない こと に なって います** (aquí está establecido que no se hacen fotos). :: Lo decide la norma, no tú.
E 〜ことにしている: costumbre propia :: Para decir lo que tú haces por costumbre o por decisión propia: verbo en forma normal + **こと に して いる**: **まいにち、 あさ はやく おきる こと に して います** (procuro levantarme pronto cada día). :: Lo decides tú.
B Regla o costumbre | Forma | Quién decide | Ejemplo
| 〜ことになっている | una norma | la norma | とらない こと に なって います
| 〜ことにしている | uno mismo | yo | はやく おきる こと に して います
W なって = (forma て de なる) convertido; establecido | natte
W とらない = no tomar, no sacar (forma ない de とる) | toranai
W たばこ = cigarrillo; tabaco | tabako
W すわない = no sentarse (forma ない de すわる) | suwanai
V Vocabulario: regla y costumbre
D En el museo y en casa
けんじ: ここ で は しゃしん を とって も いい です か。 = ¿Aquí se pueden sacar fotos?
  > とって も いい です か = ¿se pueden sacar?
がくいん: いいえ、 とらない こと に なって います。 = No, aquí está establecido que no se saca.
  > とらない こと に なって います = está establecido que no se saca
まり: わたし は まいにち はやく おきる こと に して います。 = Yo procuro levantarme pronto cada día.
  > おきる こと に して います = procuro levantarme
Q ¿Qué significa «ここ で は しゃしん を とらない こと に なって います»?
+ Aquí está establecido que no se sacan fotos. :: になって いる = norma.
- Aquí decido no sacar fotos. :: Eso sería ことにしている.
- Aquí no puedo sacar fotos. :: Eso sería 〜ない と いけません.
Q ¿Qué expresa «〜ことにしている»?
+ Una costumbre que uno mismo se impone. :: に している = decisión propia.
- Una norma general. :: Eso sería ことになっている.
- Una orden. :: Eso sería 〜て ください.
H まいにち はやく おきる ___ 。 :: Procuro levantarme pronto cada día.
+ こと に して います :: Costumbre propia.
- こと に なって います :: Eso sería una norma.
- ことになりました :: Eso sería una decisión que llegó.
H ここ で は たばこ を すわない ___ 。 :: Aquí está establecido que no se fuma.
+ こと に なって います :: Norma.
- こと に して います :: Eso sería una costumbre propia.
- ことにします :: Eso sería decidir ahora.
R まいにち はやく おきる こと に して います。 :: Traduce la frase.
+ Procuro levantarme pronto cada día. :: に している = costumbre propia.
- Me levanté pronto ayer. :: Eso sería pasado.
- Está prohibido levantarse pronto. :: Eso no es la frase.
A ここ で は しゃしん を とらない こと に なって います。 :: ¿Qué informa?
+ Que está establecido que no se hacen fotos. :: になって いる = norma.
- Que se puede hacer fotos. :: Eso es lo contrario.
- Que el guía decidió no sacar fotos. :: Eso sería una decisión puntual.
O まいにち はやく おきる こと に して います :: Procuro levantarme pronto cada día. :: に して いる = costumbre propia.
Q ¿Cuál dice que es una norma?
+ 〜ことになっている :: Lo establece una norma.
- 〜ことにしている :: Es una decisión propia.
- 〜ことにする :: Es una decisión en un momento concreto.
