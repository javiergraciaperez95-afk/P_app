@ 30 | いっぽうで と がち と きっかけ | Por otra parte, tender a... y la ocasión de...
I Hoy aprendes a expresar dos cosas a la vez, a decir que alguien tiende a algo, y a hablar de la ocasión o el momento que provoca una acción.
E 〜一方で: por otra parte (a la vez) :: Verbo en forma normal + **一方で**: **わたし は はたらく。 いっぽうで、 べんきょう も する** (trabajo; por otra parte, también estudio). :: Presenta dos actividades a la vez.
E 〜がち: tender a (algo habitual, a menudo negativo) :: Forma ます sin ます + **がち**: **わたし は わすれがち です** (tiendo a olvidar cosas). :: Describe una tendencia habitual.
E 〜きっかけ: la ocasión que lleva a algo :: Sustantivo + **きっかけ**: **きっかけ は でんわ でした** (la ocasión fue una llamada). :: Señala lo que provocó un cambio.
E 〜ついでに / 〜うちに: aprovechando; mientras todavía :: **かいもの の ついでに、 ...** (aprovechando que voy de compras...) y **ねつ が ある うち に** (mientras aún tengo fiebre).
W いっぽうで = por otra parte; a la vez | ippō de | kanji: 一方で
W わすれがち = propenso a olvidar | wasuregachi | kanji: 忘れがち
W やすみがち = propenso a faltar; a menudo ausente | yasumigachi | kanji: 休みがち
W きっかけ = ocasión; motivo que empieza algo | kikkake | kanji: きっかけ
W ついでに = aprovechando; de paso | tsuide ni | kanji: ついでに
W うちに = mientras (antes de que cambie) | uchi ni | kanji: うちに
V Vocabulario: a la vez, tender a y ocasión
T Tendencias y ocasiones
- わたし は はたらく。 いっぽうで、 べんきょう も する。 = Trabajo; por otra parte, también estudio.
- わたし は わすれがち です。 = Tiendo a olvidar cosas.
- きっかけ は でんわ でした。 = La ocasión fue una llamada.
- ついでに、 かいもの を します。 = Aprovechando, hago las compras.
- ねつ が ある うち に、 ねます。 = Mientras aún tengo fiebre, me acuesto.
- わたし は やすみがち です。 = Tiendo a faltar.
Q ¿Qué expresa «いっぽうで»?
+ Dos cosas que pasan a la vez. :: Por otra parte.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.
Q ¿Qué expresa «〜がち»?
+ Una tendencia habitual. :: Tiende a hacerlo.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería たい.
H わたし は はたらく。 ___ 、 べんきょう も する。 :: Por otra parte...
+ いっぽうで :: Por otra parte.
- ために :: Para.
- まで :: Hasta.
H ねつ が ある ___ 、 ねます。 :: Mientras aún tengo fiebre, me acuesto.
+ うちに :: Mientras todavía.
- まで :: Hasta.
- から :: Porque.
R きっかけ は でんわ でした。 :: Traduce la frase.
+ The reason was a phone call. :: きっかけ = la ocasión.
- The phone call was the end. :: Eso invierte el sentido.
- There was no reason. :: Eso es lo contrario.
A わたし は わすれがち です。 :: ¿Qué expresa?
+ Que tiende a olvidar cosas. :: がち = tendencia.
- Que nunca olvida nada. :: Eso es lo contrario.
- Que olvidó algo ayer. :: Eso sería el pasado.
A ついでに、 かいもの を します。 :: ¿Qué hace?
+ Hace las compras aprovechando. :: ついでに = de paso.
- Hace las compras sin ganas. :: Eso no aparece.
- No hace compras. :: Eso es lo contrario.
HA わたし は ___ です。 :: Tiendo a faltar.
+ やすみがち :: Tendencia a faltar.
- わすれがち :: Tendencia a olvidar.
- ながら :: Mientras.
O きっかけ は でんわ でした :: La ocasión fue una llamada. :: きっかけ = la ocasión.
