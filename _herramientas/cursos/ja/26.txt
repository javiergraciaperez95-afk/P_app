@ 26 | ちがいない (1) | Por eso: わけだ y わけがない
I Hoy aprendes a sacar conclusiones: cuando entiendes por qué pasa algo, cuando algo no puede ser verdad y cuando no es lo que parece. Son frases muy usadas al hablar.
E 〜わけだ: por eso; así que :: Para decir que algo es la conclusión lógica de lo que sabes: frase en forma normal + **わけ だ**: **かぜ を ひいた わけ です ね** (así que cogió un resfriado, ¿verdad?). :: Suena a «ahora lo entiendo».
E 〜わけがない: no puede ser :: Para decir que algo es imposible según lo que sabes: frase en forma normal + **わけ が ない**: **そんな こと が ある わけ が ありません** (no puede ser que pase algo así). :: Es más firme que 〜はずがない.
E 〜わけではない: no significa que :: Para decir que lo que se ve no es lo que parece: frase en forma normal + **わけ では ない**: **いそがしい わけ では ありません** (no es que esté muy ocupado). :: Sirve para corregir una idea equivocada.
B Conclusión, imposibilidad y matiz | Forma | Significa | Ejemplo
| 〜わけだ | por eso; así que | ひいた わけ です
| 〜わけがない | no puede ser | ある わけ が ありません
| 〜わけではない | no significa que | いそがしい わけ では ありません
W なるほど = ya veo; claro | naruhodo
W ひいた = cogió (un resfriado), pasado de ひく | hiita
W そんな = tal, semejante | sonna
W いそがしい = ocupado | isogashii
V Vocabulario: por eso y no puede ser
T Un día de ausencias
- やまだ さん が いません。 なるほど、 かぜ を ひいた わけ です ね。 = Yamada no está. Ya veo, así que cogió un resfriado, ¿verdad?
  > かぜ を ひいた わけ です ね = así que cogió un resfriado
- そんな こと が ある わけ が ありません。 = No puede ser que pase algo así.
  > そんな こと が ある わけ が ありません = no puede ser que pase algo así
- いそがしい わけ では ありません。 = No es que esté muy ocupado.
  > いそがしい わけ では ありません = no es que esté ocupado
Q ¿Qué significa «かぜ を ひいた わけ です ね»?
+ Así que cogió un resfriado, ¿verdad? :: わけ です = conclusión lógica.
- Cogió un resfriado, y no lo sé. :: Eso no es una conclusión.
- No cogió ningún resfriado. :: Eso es lo contrario.
Q ¿Qué expresa «〜わけがない»?
+ Algo que no puede ser. :: Es imposible según lo que se sabe.
- Algo que seguro es. :: Eso sería 〜に違いない.
- Un deseo. :: Eso sería 〜たい.
H やまだ さん が いません。 なるほど、 かぜ を ___ わけ です。 :: Ya veo, así que cogió un resfriado.
+ ひいた :: Pasado de ひく.
- ひきます :: Eso sería presente.
- ひかない :: Eso sería negativo.
H そんな こと が ある ___ 。 :: No puede ser que pase algo así.
+ わけ が ありません :: Imposible.
- わけ です :: Eso sería conclusión.
- ことは ない :: Eso sería no hace falta.
R いそがしい わけ では ありません。 :: Traduce la frase.
+ No es que esté muy ocupado. :: では ない = no significa que.
- Está muy ocupado. :: Eso es lo contrario.
- Está ocupado, por eso no viene. :: Eso añade otra idea.
A やまだ さん が いません。 なるほど、 かぜ を ひいた わけ です ね。 :: ¿Qué entiende?
+ Que ya ve por qué Yamada no está: cogió un resfriado. :: わけ = conclusión.
- Que Yamada está en casa. :: Eso es lo contrario.
- Que Yamada nunca falta. :: No aparece.
O そんな こと が ある わけ が ありません :: No puede ser que pase algo así. :: わけ が ない = imposible.
Q ¿Cuál significa «わけ では ない»?
+ No significa que... :: Corrige una idea equivocada.
- Es que seguro... :: Eso sería 〜に違いない.
- Debería... :: Eso sería 〜はず.

@ 26 | ちがいない (2) | Seguro que y no parece que: ちがいない y そうにない
I Ahora dos expresiones para hablar con seguridad y para decir que algo no tiene pinta de ocurrir. Son muy útiles en el trabajo.
E 〜にちがいない: seguro que :: Para decir que estás casi seguro: frase en forma normal + **に ちがいない**: **あの ひと は にほんご が じょうず に ちがいない** (seguro que ese hombre habla bien japonés). :: En educado: **に ちがいありません**. Es más seguro que 〜かもしれない.
E 〜そうにない: no parece que :: Para decir que, por lo que se ve, algo no va a pasar: verbo en forma -masu sin ます + **そう に ない**: **この しごと は あした まで に おわりそう に ない です** (no parece que este trabajo termine para mañana). :: Con **ない** sí se usa la forma あ: **おわりそう に ない**.
B Seguridad y poca probabilidad | Forma | Significa | Ejemplo
| 〜に ちがいない | seguro que | じょうず に ちがいない
| 〜そう に ない | no parece que | おわりそう に ない
W ちがいない = seguro que (forma normal) | chigai nai
W おわりそう に ない = no parece que vaya a terminar | owarisō ni nai
W しんぱい = preocupación | shinpai
V Vocabulario: seguro y no parece
D Un colega y un trabajo
けんじ: あの ひと は にほんご が じょうず に ちがいない。 = Seguro que ese hombre habla bien japonés.
  > じょうず に ちがいない = seguro que habla bien
まり: そう です ね。 この しごと は あした まで に おわりそう に ない です。 = Sí, es verdad. Este trabajo no parece que vaya a terminar para mañana.
  > おわりそう に ない です = no parece que vaya a terminar
Q ¿Qué significa «あの ひと は にほんご が じょうず に ちがいない»?
+ Seguro que ese hombre habla bien japonés. :: に ちがいない = seguro que.
- Ese hombre no habla japonés. :: Eso es lo contrario.
- Ese hombre quiere hablar japonés. :: Eso sería 〜たい.
Q ¿Qué expresa «〜そう に ない»?
+ Que no parece que vaya a pasar. :: Juzgar por lo que se ve.
- Que parece que va a pasar. :: Eso es lo contrario.
- Que se oyó algo. :: Eso sería 〜そうです de oído.
H あの ひと は にほんご が じょうず に ___ 。 :: Seguro que ese hombre habla bien japonés.
+ ちがいない :: Seguridad.
- ちがいます :: Eso es «es diferente».
- ください :: Eso sería una petición.
H この しごと は あした まで に ___ です。 :: No parece que este trabajo termine para mañana.
+ おわりそう に ない :: No parece que termine.
- おわりそう です :: Eso sería que parece que termina.
- おわります :: Eso sería que termina.
R この しごと は あした まで に おわりそう に ない です。 :: Traduce la frase.
+ No parece que este trabajo termine para mañana. :: そう に ない = no parece.
- Parece que este trabajo termina mañana. :: Eso es lo contrario.
- Este trabajo terminó ayer. :: Eso es el pasado.
A あの ひと は にほんご が じょうず に ちがいない。 :: ¿Qué opina el hablante?
+ Está seguro de que ese hombre habla bien japonés. :: に ちがいない = seguridad.
- Duda de que sepa japonés. :: Eso es lo contrario.
- Sabe que no habla japonés. :: Eso es lo contrario.
O じょうず に ちがいない :: Seguro que es bueno. :: に ちがいない = seguridad.
Q ¿Cuál es más seguro?
+ 〜に ちがいない :: Es casi seguro.
- 〜かも しれない :: Es solo posible.
- 〜そう です :: Es lo que se ve.

@ 26 | ちがいない (3) | No hay forma de: ようがない y ことはない
I Por último, dos expresiones que dicen que algo no tiene solución o que no hace falta. Son útiles para tranquilizar a alguien o para explicar que algo es imposible.
E 〜ようがない: no hay forma de :: Para decir que algo es imposible porque no hay manera de hacerlo: verbo en forma de diccionario + **よう が ない**: **ばしょ が わからない ので、 いきようがない です** (como no sé el lugar, no hay forma de ir). :: Con **いく** queda **いきようがない**.
E 〜ことはない: no hace falta :: Para tranquilizar a alguien: verbo en forma normal + **こと は ない**: **そんな に しんぱい する こと は ない です** (no hace falta que te preocupes tanto). :: Es más suave que 〜なくても いい.
B Imposible o innecesario | Forma | Significa | Ejemplo
| 〜ようがない | no hay forma de | いきようがない
| 〜ことはない | no hace falta | しんぱい する こと は ない
W ばしょ = lugar; sitio | basho
W いきようがない = no hay forma de ir | ikiyō ga nai
V Vocabulario: no hay forma
T Explicar y tranquilizar
- ばしょ が わからない ので、 いきようがない です。 = Como no sé el lugar, no hay forma de ir.
  > いきようがない = no hay forma de ir
- そんな に しんぱい する こと は ない です。 = No hace falta que te preocupes tanto.
  > しんぱい する こと は ない = no hace falta preocuparse
Q ¿Qué significa «ばしょ が わからない ので、 いきようがない です»?
+ Como no sé el lugar, no hay forma de ir. :: ようがない = imposible.
- Como sé el lugar, voy. :: Eso es lo contrario.
- Quiero ir, pero no sé dónde. :: Eso es un deseo.
Q ¿Qué expresa «〜ことは ない»?
+ No hace falta. :: Tranquiliza.
- Es obligatorio. :: Eso sería なければ なりません.
- Es un deseo. :: Eso sería 〜たい.
H ばしょ が わからない ので、 ___ です。 :: Como no sé el lugar, no hay forma de ir.
+ いきようがない :: Imposible.
- いきたい :: Eso sería un deseo.
- いくべき :: Eso sería un deber.
H そんな に しんぱい する ___ は ない です。 :: No hace falta que te preocupes tanto.
+ こと :: Forma de no hace falta.
- ため :: Eso sería finalidad.
- ばかり :: Eso sería «solo».
R そんな に しんぱい する こと は ない です。 :: Traduce la frase.
+ No hace falta que te preocupes tanto. :: ことは ない = no hace falta.
- Te preocupas mucho. :: Eso es lo contrario.
- Debes preocuparte. :: Eso es lo contrario.
A ばしょ が わからない ので、 いきようがない です。 :: ¿Qué pasa?
+ No hay forma de ir porque no sabe el lugar. :: ようがない = imposible.
- Va porque sabe el lugar. :: Eso es lo contrario.
- No quiere ir. :: Eso no es la frase.
O いきようがない です :: No hay forma de ir. :: ようがない = imposible.
Q ¿Cuál es la diferencia de 〜ことは ない con 〜なければ ならない?
+ 〜ことは ない = no hace falta; 〜なければ ならない = hay que. :: Son opuestas.
- Son iguales. :: No es cierto.
- Ambas expresan un deseo. :: No es cierto.
