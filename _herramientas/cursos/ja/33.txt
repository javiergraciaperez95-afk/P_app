@ 33 | ぎゃく と ゆるし (1) | Aunque, pero: ものの y ながらも
I Hoy aprendes a decir «aunque» con un matiz: sabes algo, pero no lo haces, o algo tiene una parte buena y otra mala. Son frases de nivel alto y muy usadas en la escritura.
E 〜ものの: aunque (pero) :: Para decir que, aunque sabes algo, el resultado no es el esperado: frase en forma normal + **もの の**: **わかって いる ものの、 やめられません** (aunque lo sé, no puedo dejarlo). :: Suena a una lucha interior: tú sabes lo correcto, pero no lo consigues.
E 〜ながらも: aunque (a la vez) :: Para decir que algo tiene dos caras a la vez: adjetivo en -i sin い + **ながらも**: **ちいさい ながらも、 おいしい みせ です** (aunque es pequeño, es un buen sitio). :: También sirve con nombres: **こども ながらも** (aunque es niño).
B Dos caras de algo | Forma | Significa | Ejemplo
| 〜ものの | aunque (lo sé, pero) | わかって いる ものの
| 〜ながらも | aunque (dos cualidades) | ちいさい ながらも
W わかって = (forma て de わかる) sabiendo; entendiendo | wakatte
W ものの = aunque; pero (concesivo) | mono no
W やめられません = no puedo dejarlo; no puedo parar | yamerare masen
W ながらも = aunque; a pesar de | nagara mo
W おなじ = igual; el mismo | onaji
V Vocabulario: aunque
T Dos caras
- わかって いる ものの、 やめられません。 = Aunque lo sé, no puedo dejarlo.
  > わかって いる ものの = aunque lo sé | やめられません = no puedo dejarlo
- ちいさい ながらも、 おいしい みせ です。 = Aunque es pequeño, es un buen sitio.
  > ちいさい ながらも = aunque es pequeño
D Un vicio
けんじ: わかって いる ものの、 やめられません。 = Aunque lo sé, no puedo dejarlo.
  > わかって いる ものの = aunque lo sé
まり: わたし も おなじ です。 = Yo también estoy igual.
  > おなじ です = igual
Q ¿Qué significa «わかって いる ものの、 やめられません»?
+ Aunque lo sé, no puedo dejarlo. :: ものの = aunque (con lucha interior).
- Lo sé, así que lo dejo. :: Eso es lo contrario.
- No lo sé, por eso no lo dejo. :: Eso es lo contrario.
Q ¿Qué expresa «〜ながらも»?
+ Dos cualidades a la vez. :: Aunque una sea negativa.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H わかって いる ___ 、 やめられません。 :: Aunque lo sé, no puedo dejarlo.
+ ものの :: Aunque, con lucha interior.
- ために :: Eso sería «para».
- ながら :: Eso sería «mientras».
H ちいさい ___ 、 おいしい みせ です。 :: Aunque es pequeño, es un buen sitio.
+ ながらも :: Aunque, dos cualidades.
- ために :: Eso sería «para».
- から :: Eso sería «porque».
R わかって いる ものの、 やめられません。 :: Traduce la frase.
+ Aunque lo sé, no puedo dejarlo. :: ものの = aunque.
- Lo sé, así que lo dejo. :: Eso es lo contrario.
- No lo sé, por eso no lo dejo. :: Eso es lo contrario.
A ちいさい ながらも、 おいしい みせ です。 :: ¿Qué cuenta?
+ Que el sitio es pequeño, pero bueno. :: ながらも = dos cualidades.
- Que el sitio es grande y malo. :: Eso es lo contrario.
- Que el sitio está cerrado. :: No aparece.
O わかって いる ものの :: Aunque lo sé. :: ものの = aunque.
Q ¿Cuál es el matiz de «ものの»?
+ Lo que se sabe no se consigue. :: Lucha interior.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.

@ 33 | ぎゃく と ゆるし (2) | Por lo que dices: くせに y まだしも
I Ahora dos expresiones para criticar o para elegir la menos mala. La primera reprocha a alguien; la segunda compara una situación con otra peor.
E 〜くせに: aunque (reproche) :: Para criticar a alguien porque hace algo que no le corresponde: frase en forma normal + **くせ に**: **しらない くせ に、 いばって います** (aunque no lo sabe, presume). :: Suena a crítica directa. Úsala con cuidado.
E 〜まだしも: al menos (lo menos malo) :: Para decir que una opción es menos mala que otra peor: frase + **まだ しも**: **あめ なら まだしも、 ゆき だ と たいへん です** (si fuera lluvia, vale; pero si es nieve, es un problema). :: Se usa para decir que algo es aceptable.
B Crítica y menos malo | Forma | Significa | Ejemplo
| 〜くせに | aunque (reproche) | しらない くせに
| 〜まだしも | al menos; lo menos malo | あめ なら まだしも
W くせに = aunque (reproche; crítica) | kuse ni
W しらない = no sabe; desconoce (de しる) | shiranai
W いばって = presumiendo; alardeando (de いばる) | ibatte
W なら = si es; en caso de que sea | nara
W まだしも = al menos; lo menos malo | mada shimo
V Vocabulario: crítica y lo menos malo
D Un colega
まり: あの ひと、 しらない くせに、 いばって いる。 = Ese, aunque no sabe, presume.
  > しらない くせに = aunque no sabe | いばって いる = presume
けんじ: うん。 あめ なら まだしも、 ゆき だ と たいへん です。 = Sí. Si fuera lluvia, vale, pero con nieve es un problema.
  > あめ なら まだしも = si fuera lluvia, vale
T Crítica y elección
- しらない くせに、 いばって います。 = Aunque no lo sabe, presume.
  > しらない くせに = aunque no lo sabe
- あめ なら まだしも、 ゆき だ と たいへん です。 = Si fuera lluvia, vale; pero con nieve es un problema.
  > あめ なら まだしも = si fuera lluvia, vale
Q ¿Qué significa «しらない くせに、 いばって います»?
+ Aunque no lo sabe, presume. :: くせに = aunque (crítica).
- Como lo sabe, presume. :: Eso es lo contrario.
- No sabe nada y no presume. :: Eso es lo contrario.
Q ¿Qué expresa «〜まだしも»?
+ Lo menos malo de dos opciones. :: Al menos.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H しらない ___ 、 いばって います。 :: Aunque no lo sabe, presume.
+ くせに :: Crítica.
- ために :: Eso sería «para».
- ながら :: Eso sería «mientras».
H あめ なら ___ 、 ゆき だ と たいへん です。 :: Si fuera lluvia, vale.
+ まだしも :: Lo menos malo.
- ばかりに :: Eso sería «por culpa de».
- ながらも :: Eso sería «aunque, dos cualidades».
R しらない くせに、 いばって います。 :: Traduce la frase.
+ Aunque no lo sabe, presume. :: くせに = aunque, crítica.
- Como lo sabe, presume. :: Eso es lo contrario.
- No presume, aunque lo sabe. :: Eso es lo contrario.
A あの ひと、 しらない くせに、 いばって いる。 :: ¿Qué opina?
+ Critica que presume sin saber. :: くせに = crítica.
- Admira lo que sabe. :: Eso es lo contrario.
- Dice que no sabe nada. :: Eso no es la frase.
O あめ なら まだしも :: Si fuera lluvia, vale. :: まだしも = lo menos malo.
Q ¿Cuál es el sentido de «くせに»?
+ Criticar algo que no corresponde. :: Reproche.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.

@ 33 | ぎゃく と ゆるし (3) | Solo es: にすぎない
I Por último, una expresión para quitar importancia a algo: decir que es solo eso, nada más. Es muy útil para explicar algo que parece más grande de lo que es.
E 〜にすぎない: solo es; no es más que :: Para decir que algo es poco comparado con lo que parece: frase normal o nombre + **に すぎ ない**: **それ は ただ の うわさ に すぎない** (eso es solo un rumor). :: Quita importancia a lo que se dice.
E Con la forma formal :: Puede escribirse **〜に すぎません**: **うわさ に すぎません** (no es más que un rumor). :: Es más educado.
B Quitar importancia | Forma | Significa | Ejemplo
| 〜に すぎない | no es más que | うわさ に すぎない
| 〜に すぎません | no es más que (formal) | うわさ に すぎません
W ただ = solo; simplemente | tada
W うわさ = rumor | uwasa
W いけん = opinión | iken
W かんがえ = idea; pensamiento | kangae
W すぎません = no es más que (formal) | sugimasen
W すぎない = no es más que; solo | sugi nai
V Vocabulario: no es más que
D Una noticia
まり: その ニュース、 ほんとう です か。 = ¿Es verdad esa noticia?
  > ほんとう です か = ¿es verdad?
けんじ: いいえ。 ただ の うわさ に すぎない です。 = No. No es más que un rumor.
  > ただ の うわさ に すぎない = no es más que un rumor
T Quitar importancia
- それ は ただ の うわさ に すぎない。 = Eso no es más que un rumor.
  > ただ の うわさ に すぎない = no es más que un rumor
- わたし の いけん は ひとつ の かんがえ に すぎません。 = Mi opinión no es más que una idea.
  > ひとつ の かんがえ に すぎません = no es más que una idea
Q ¿Qué significa «それ は ただ の うわさ に すぎない»?
+ Eso no es más que un rumor. :: に すぎない = no es más que.
- Eso es una noticia verdadera. :: Eso es lo contrario.
- Eso es un hecho importante. :: Eso es lo contrario.
Q ¿Qué expresa «〜に すぎない»?
+ Quitar importancia a algo. :: Solo es eso.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H それ は ただ の うわさ に ___ 。 :: Eso no es más que un rumor.
+ すぎない :: No es más que.
- すぎた :: Eso sería el pasado.
- すぎません :: Forma formal correcta, pero no en la frase.
H わたし の いけん は ひとつ の かんがえ に ___ 。 :: Mi opinión no es más que una idea.
+ すぎません :: Forma formal.
- すぎる :: Eso sería «demasiado».
- ながら :: Eso sería «mientras».
R それ は ただ の うわさ に すぎない。 :: Traduce la frase.
+ Eso no es más que un rumor. :: に すぎない = no es más que.
- Eso es un rumor muy importante. :: Eso es lo contrario.
- Eso es verdad. :: Eso es lo contrario.
A その ニュース、 ほんとう です か。 :: ¿Qué pregunta?
+ ¿Es verdad esa noticia? :: Pide confirmación.
- ¿Dónde está la noticia? :: No aparece.
- ¿Cuándo salió la noticia? :: No aparece.
O ただ の うわさ に すぎない :: Solo es un rumor. :: に すぎない = no es más que.
Q ¿Cuál es la forma más educada de «すぎない»?
+ すぎません :: Forma formal.
- すぎない :: Forma plana.
- すぎた :: Pasado.
