@ 11 | て の けい (1) | La forma て (1): cómo se construye
I Hoy empieza el nivel A2, que en Japón se llama JLPT N4. Empezamos por la forma て, la pieza más importante del japonés intermedio: con ella unes acciones, pides cosas y dices lo que pasa ahora.
E Para qué sirve :: La forma て une acciones: **ごはん を たべて、 いきます** (como y voy). También es la base de **〜てください** (por favor, haga…), **〜ています** (está haciendo…) y **〜てもいいです** (se puede…). :: Se forma a partir de la forma del **diccionario** (la que sale en el diccionario, como たべる o かう) y depende del grupo del verbo.
B Los tres grupos | Cambio | Ejemplo | Forma て
| Grupo 1: acaban en う, つ, る | cambian a って | かう (comprar) → かって
| Grupo 1: acaban en む, ぶ, ぬ | cambian a んで | よむ (leer) → よんで
| Grupo 1: acaban en く | cambian a いて | かく (escribir) → かいて
| Grupo 1: acaban en ぐ | cambian a いで | およぐ (nadar) → およいで
| Grupo 1: acaban en す | cambian a して | はなす (hablar) → はなして
| Grupo 2: -eru / -iru | quitan る y añaden て | たべる (comer) → たべて
| Irregulares | hay que memorizarlos | する → して; くる → きて; いく → いって
E Cuidado con los engañosos :: **かえる** (volver) y **はいる** (entrar) acaban en **-eru** y **-iru**, pero son del grupo 1: **かえって**, **はいって**. :: Si no estás seguro, busca el verbo en el diccionario: no lo adivines por la terminación.
W かって = (forma て de かう) comprar; comprando | katte
W よんで = (forma て de よむ) leer; leyendo | yonde
W かいて = (forma て de かく) escribir; escribiendo | kaite
W およいで = (forma て de およぐ) nadar; nadando | oyoide
W はなして = (forma て de はなす) hablar; hablando | hanashite | La す se convierte en して, no en いて.
W たべて = (forma て de たべる) comer; comiendo | tabete
W みて = (forma て de みる) ver; viendo | mite
W きて = (forma て de くる) venir; viniendo | kite | Verbo irregular: くる → きて.
W して = (forma て de する) hacer; haciendo | shite | Verbo irregular.
W おきて = (forma て de おきる) levantarse; levantándose | okite
W かえって = (forma て de かえる) volver a casa; volviendo | kaette | Aunque acaba en -eru, es del grupo 1.
W あらいます = lavar; me lavo | araimasu
W あと = después de; luego | ato
W まず = primero, antes que nada | mazu
V Vocabulario: la forma て
T Mi día
- まず、 あさ おきて、 かお を あらいます。 = Primero, por la mañana me levanto y me lavo la cara.
  > おきて = levantarme | あらいます = me lavo
- ごはん を たべて、 がっこう へ いきます。 = Como y voy a la escuela.
  > たべて = comer (y) | いきます = voy
- ばんごはん の あと で、 テレビ を みて、 ねます。 = Después de cenar, veo la tele y me acuesto.
  > みて = ver (y) | ねます = me acuesto
- しごと を して、 うち へ かえります。 = Trabajo y vuelvo a casa.
  > して = hacer (y) | かえります = vuelvo a casa
Q ¿Cuál es la forma て de «たべる»?
+ たべて :: Es del grupo 2: quitas る y añades て.
- たべって :: La regla «って» es del grupo 1 (かう → かって).
- たべいて :: «いて» es de los verbos en く (かく → かいて).
Q ¿Cuál es la forma て de «かう» (comprar)?
+ かって :: Los verbos en う cambian a って.
- かいて :: Eso es la forma de かく (escribir).
- かうて :: No existe así: los verbos en う cambian a って.
Q ¿Cuál es la forma て de «する»?
+ して :: Es irregular: hay que memorizarla.
- すって :: Esa forma no existe.
- しって :: Es la forma de しる (saber), otro verbo.
R ここ で まって ください。 :: Traduce la frase.
+ Espere aquí, por favor. :: まって ください es «espere, por favor» (de まつ, esperar).
- Venga aquí, por favor. :: Eso sería ここ へ きて ください.
- Compre aquí, por favor. :: Eso sería ここ で かって ください.
H ともだち と ___ 、 いっしょに ごはん を たべました。 :: Forma て de はなす (hablar)
+ はなして :: Forma て de はなす.
- はなって :: Los verbos en す no cambian a って.
- はないて :: Eso es la forma de かく.
H まいにち ほん を ___、 ねます。 :: Forma て de よむ (leer)
+ よんで :: よむ cambia a よんで.
- よって :: Los verbos en る/う/つ cambian a って; よむ acaba en む.
- よいで :: Eso sería de およぐ.
A パン を かって、 うち へ かえります。 :: ¿Qué hace primero?
+ Compra pan. :: かって es primero; luego vuelve a casa.
- Vuelve a casa. :: Eso es かえります, pero va después.
- Come pan. :: Eso sería たべて.
O ここ に なまえ を かいて ください :: Escriba su nombre aquí, por favor. :: La forma て va antes de ください.

@ 11 | て の けい (2) | 〜ている: lo que pasa ahora
I Con la forma て puedes decir lo que alguien está haciendo ahora, y también algunos estados. Es una de las frases que más se oyen en Japón.
E 〜ている: acción en curso :: Para decir que algo **está pasando ahora** se usa la forma て + **います**: **たべて います** (está comiendo). Se escribe junto: **たべています**. :: Con **〜ている** se dice lo que alguien **sigue haciendo**: **まって います** (está esperando).
E 〜ている: estados :: Con algunos verbos **〜ている** no habla de una acción, sino de un **estado**: **すんでいます** (vive en), **けっこんしています** (está casado/a), **しっています** (lo sabe, lo conoce). :: Son frases que te servirán mucho para hablar de tu familia y de tu vida.
B Dos usos | Uso | Ejemplo | Significa
| Acción en curso | いま ともだち が ごはん を たべています | Ahora mi amigo está comiendo.
| Estado | やまだ さん は けっこんしています | Yamada está casado.
W たべています = está comiendo | tabete imasu
W よんでいます = está leyendo | yonde imasu
W まっています = está esperando | matte imasu
W ねています = está durmiendo | nete imasu
W すんでいます = vive (en un lugar) | sunde imasu
W けっこんしています = está casado, casada | kekkon shite imasu
W しっています = lo sabe; lo conoce | shitte imasu | Es un estado: no se dice «sabo».
W ふっています = está lloviendo (de ふる) | futte imasu
W そと = fuera, afuera | soto
W まだ = todavía, aún | mada
V Vocabulario: 〜ている
D ¿Qué hace la gente ahora?
けんじ: やまだ さん、 いま なに を して います か。 = Yamada, ¿qué está haciendo ahora?
  > なに を して います か = ¿qué está haciendo?
やまだ: ともだち を まっています。 = Estoy esperando a un amigo.
  > まっています = estoy esperando
けんじ: みか さん は？ = ¿Y Mika?
  > みか さん = Mika
やまだ: みか さん は へや で ねています。 = Mika está durmiendo en la habitación.
  > ねています = está durmiendo | へや で = en la habitación
けんじ: あめ が ふっています ね。 = Está lloviendo, ¿eh?
  > ふっています = está lloviendo
やまだ: はい。 そと は さむい です。 = Sí. Fuera hace frío.
  > さむい です = hace frío
Q ¿Cómo dices «estoy esperando»?
+ まっています :: まって + います: la acción sigue pasando.
- まって です :: です no se usa así con ている.
- まりました :: Eso no significa «esperar».
H ともだち を ___ 。 :: Estoy esperando a un amigo.
+ まっています :: まって + います.
- まっていません :: Eso es «no estoy esperando».
- まってです :: です no va con ている.
H みか さん は とうきょう に ___ 。 :: Mika vive en Tokio.
+ すんでいます :: Es un estado: vive en.
- すみます :: Es correcto pero no expresa estado; aquí hace falta ている.
- すんでです :: Ya no es ている.
H あめ が ___ 。 :: Está lloviendo.
+ ふっています :: ふる se convierte en ふって + います.
- ふります :: Es el presente simple: llueve.
- ふったいます :: No existe.
R やまだ さん は けっこんしています。 :: Traduce la frase.
+ Yamada está casado. :: Estado: ya lo está.
- Yamada se casa. :: Eso sería けっこんします.
- Yamada no se casó. :: Eso sería けっこんしませんでした.
A いま、 なに を して います か。 :: ¿Qué pregunta?
+ ¿Qué está haciendo ahora? :: いま y います: acción en curso.
- ¿Qué comió ayer? :: Eso sería きのう なに を たべました か.
- ¿Dónde vive? :: Eso sería どこ に すんでいます か.
O そと は さむい です :: Hace frío fuera. :: そと es «fuera».

@ 11 | て の けい (3) | Pedir permiso y prohibir
I Ahora, dos frases muy útiles en Japón: pedir permiso y decir lo que no se puede hacer. Son fáciles y se oyen en todas partes.
E Pedir permiso: 〜てもいいです :: **〜て + も いい です** = se puede / puedo. :: Para preguntar: **しゃしん を とって も いい です か** (¿puedo sacar fotos?). Para responder que sí: **はい、 いい です** (sí, se puede).
E Prohibir: 〜てはいけません :: **〜て + は いけません** = no se debe / no está permitido. :: **さわって は いけません** (no se debe tocar). En el habla informal se dice **〜ては いけない** (lo verás en el capítulo 19).
B Permitido y prohibido | Forma | Japonés | Español
| Permiso | 〜てもいいです | ここ で しゃしん を とっても いい です | Se pueden hacer fotos aquí.
| Pregunta | 〜てもいいですか | ここ で すわって も いい です か | ¿Puedo sentarme aquí?
| Prohibición | 〜てはいけません | ここ で さわって は いけません | Aquí no se debe tocar.
W とって = (forma て de とる) tomar; sacar (fotos) | totte | «Sacar fotos» se dice しゃしん を とる.
W ねて = (forma て de ねる) dormir; durmiendo | nete
W いけません = no se puede; no se debe | ikemasen
W さわって = (forma て de さわる) tocar | sawatte
W すわって = (forma て de すわる) sentarse | suwatte
W つかって = (forma て de つかう) usar | tsukatte
W フラッシュ = flash (de la cámara) | furasshu
W わかりました = entendido, de acuerdo | wakarimashita
W おと = sonido, ruido | oto
W たてて = (forma て de たてる) hacer ruido | tatete
W もの = cosa, objeto | mono
V Vocabulario: permiso y prohibición
D En el museo
けんじ: しゃしん を とって も いい です か。 = ¿Se pueden hacer fotos?
  > とって も いい です か = ¿se puede sacar?
がくいん: はい、 いい です。 でも、 フラッシュ は つかって は いけません。 = Sí, se puede. Pero no se puede usar el flash.
  > いい です = se puede | つかって は いけません = no se debe usar
けんじ: わかりました。 しずか に します。 = Entendido. Guardaré silencio.
  > わかりました = entendido | しずか に します = guardaré silencio
がくいん: ありがとう ございます。 = Gracias.
  > ありがとう ございます = muchas gracias
Q ¿Cómo preguntas «¿puedo sentarme aquí?»?
+ ここ で すわって も いい です か :: すわって も いい です か = ¿puedo sentarme?
- ここ で すわって は いけません :: Eso es prohibir: no se debe sentar.
- ここ で すわります :: Es afirmar que te sientas, no pedir permiso.
Q ¿Qué significa «さわって は いけません»?
+ No se debe tocar. :: は いけません = no está permitido.
- Se puede tocar. :: Eso sería さわって も いい です.
- Toque, por favor. :: Eso sería さわって ください.
H ここ で しゃしん を ___ 。 :: Se pueden sacar fotos aquí.
+ とって も いい です :: とって + も いい です = se puede.
- とって は いけません :: Eso es prohibir.
- とりません :: Es «no tomo», no un permiso.
H ここ で ___ も いい です。 :: Se puede dormir aquí.
+ ねて :: ねて も いい です = se puede dormir.
- ねない :: Es la forma negativa: no dormir.
- ねました :: Es el pasado.
R えいが の なか で はなして は いけません。 :: Traduce la frase.
+ No se debe hablar dentro del cine. :: は いけません = no está permitido.
- Se puede hablar dentro del cine. :: Eso sería はなして も いい です.
- Hable en el cine, por favor. :: Eso sería はなして ください.
A ねて も いい です か。 :: ¿Qué pregunta?
+ ¿Puedo dormir? :: ねて も いい です か = ¿se puede dormir?
- ¿Dónde duermes? :: Eso sería どこ で ねます か.
- No quiero dormir. :: Eso sería ねたく ない.
O しずか に して ください :: Por favor, guarde silencio. :: して ください = haga, por favor.
Q ¿Qué pide «しずか に して ください»?
+ Que haga silencio. :: しずか に して ください: pedir algo con て + ください.
- Que hable más alto. :: Eso no es esta frase.
- Que se vaya. :: No aparece en la frase.
