@ 16 | おもう と きく (1) | Opinar y suponer
I Hoy aprendes a decir lo que piensas sin afirmarlo del todo. En una conversación, esto suena natural y educado.
E 〜と思います: mi opinión :: Para dar tu opinión, pon la frase en forma normal y añade **と おもいます** (creo que…): **にほんご は むずかしい と おもいます** (creo que el japonés es difícil). :: Es la forma habitual de opinar. Para pedir opinión se dice **どう おもいます か** (¿qué opina?).
E 〜でしょう: suposición :: Con **でしょう** (supongo que…) dices algo que probablemente pasa, y pides confirmación. Se pronuncia con tono de pregunta: **きょう は さむい でしょう** (hoy hará frío, ¿verdad?). :: Con **たぶん** (probablemente) suena más seguro: **たぶん あした は あめ でしょう** (probablemente mañana lloverá).
B Opinar y suponer | Forma | Significa | Ejemplo
| 〜と おもいます | mi opinión | にほんご は むずかしい と おもいます
| 〜でしょう | suposición | きょう は さむい でしょう
| たぶん 〜でしょう | probablemente | たぶん あした は あめ でしょう
W おもいます = creo, pienso | omoimasu
W おもう = pensar, creer (forma de diccionario) | omō
W でしょう = supongo; ¿verdad? | deshō | Se pronuncia con tono de pregunta.
W たぶん = probablemente | tabun
V Vocabulario: opinar y suponer
D Una opinión sobre el tiempo
けんじ: きょう は さむい でしょう。 = Hoy hará frío, ¿verdad?
  > さむい でしょう = hará frío, ¿verdad?
やまだ: はい。 あした も さむい と おもいます。 = Sí. Creo que mañana también hará frío.
  > と おもいます = creo que
けんじ: たぶん あめ も ふる でしょう。 = Probablemente también llueva.
  > たぶん = probablemente | でしょう = supongo
Q ¿Qué significa «あした は あめ が ふる と おもいます»?
+ Creo que mañana lloverá. :: と おもいます = mi opinión.
- Mañana llueve, seguro. :: Eso sería una afirmación sin duda.
- Mañana no llueve. :: Eso es lo contrario.
Q ¿Qué expresa «でしょう» en «きょう は さむい でしょう»?
+ Una suposición o pedir confirmación. :: でしょう = supongo, ¿verdad?
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H にほんご は むずかしい ___ 。 :: Creo que el japonés es difícil.
+ と おもいます :: Mi opinión.
- と おもって ください :: Eso sería «piense, por favor».
- と いいます :: Eso sería «digo que».
H きょう は さむい ___ 。 :: Hoy hará frío, ¿verdad?
+ でしょう :: Suposición con confirmación.
- でした :: Eso sería «hizo frío» (pasado).
- ですか :: Eso sería una pregunta sin suponer.
R たぶん あした は あめ でしょう。 :: Traduce la frase.
+ Probablemente mañana lloverá. :: たぶん = probablemente.
- Mañana llovió. :: Eso sería el pasado.
- Mañana seguro que no llueve. :: Eso sería lo contrario.
A にほんご は むずかしい と おもいます。 :: ¿Qué opina?
+ Cree que el japonés es difícil. :: と おもいます = opinión.
- Cree que el japonés es fácil. :: Eso es lo contrario.
- Ha estudiado japonés. :: Eso sería pasado.
O あした は あめ が ふる と おもいます :: Creo que mañana lloverá. :: と おもいます = creo que.
Q ¿Cómo se dice «creo que»?
+ と おもいます :: Forma de opinar.
- と おもって ください :: Eso es una petición.
- と いいました :: Eso es «dijo que».

@ 16 | おもう と きく (2) | Quizá y debería
I Ahora, dos formas para hablar de lo que quizá pasa y de lo que debería ser así. Son muy comunes en la vida diaria.
E 〜かもしれません: quizá :: Verbo en forma normal + **かも しれません** = quizá: **あした は あめ が ふる かも しれません** (quizá llueva mañana). :: Con **かも しれません** no estás seguro: hay posibilidades.
E 〜はず です: debería ser :: Verbo o adjetivo en forma normal + **はず です** = debería ser / se supone que es así: **やまだ さん は もう いえ に いる はず です** (Yamada debería estar ya en casa). :: No es duda: es una deducción lógica, porque tienes una razón para pensarlo.
B Duda y deducción | Forma | Significa | Ejemplo
| 〜かもしれません | puede que; quizá | あめ が ふる かも しれません
| 〜はず です | debería ser; se supone | かぎ は かばん の なか に ある はず です
W かも = quizá; puede que (forma de «かもしれない») | kamo
W しれません = puede (que); tal vez | shiremasen
W はず = debería; se supone que | hazu
W いる = estar (personas, animales, forma de diccionario) | iru
V Vocabulario: quizá y debería
T Las llaves
- やまだ さん は もう いえ に いる はず です。 = Yamada debería estar ya en casa.
  > いる はず です = debería estar
- かぎ は かばん の なか に ある はず です。 = La llave debería estar en el bolso.
  > ある はず です = debería estar
- あした は あめ が ふる かも しれません。 = Quizá mañana llueva.
  > ふる かも しれません = quizá llueva
Q ¿Qué significa «あした は あめ が ふる かも しれません»?
+ Quizá mañana llueva. :: かも しれません = quizá.
- Seguro que mañana llueve. :: Eso sería una afirmación.
- Mañana no llueve. :: Eso es lo contrario.
Q ¿Qué expresa «はず です»?
+ Algo que debería ser así, por una razón. :: はず = deducción.
- Un deseo. :: Eso sería 〜たい.
- Una orden. :: Eso sería 〜て ください.
H あめ が ふる ___ 。 :: Quizá llueva.
+ かも しれません :: Duda: puede que.
- と おもいます :: Eso es «creo que» (mi opinión).
- はず です :: Eso es «debería ser».
H かぎ は かばん の なか に ある ___ 。 :: La llave debería estar en el bolso.
+ はず です :: Deducción lógica.
- かも しれません :: Eso es «quizá».
- ありません :: Eso es «no hay».
R やまだ さん は もう いえ に いる はず です。 :: Traduce la frase.
+ Yamada debería estar ya en casa. :: はず = deducción lógica.
- Yamada seguro que no está en casa. :: Eso es lo contrario.
- Yamada no tiene casa. :: No aparece en la frase.
A あめ が ふる かも しれません。 :: ¿Qué dice?
+ Podría llover. :: Duda.
- Va a llover seguro. :: Eso sería una afirmación.
- No llueve. :: Eso es lo contrario.
O あした は あめ が ふる かも しれません :: Quizá mañana llueva. :: かも しれません = quizá.
Q ¿Cómo se dice «quizá no vaya»?
+ いかない かも しれません :: Forma normal + かも しれません.
- いく はず です :: Eso sería «debería ir».
- いきません :: Eso es «no voy».

@ 16 | おもう と きく (3) | Lo que se ve y lo que se oye
I Por último, dos formas para hablar de lo que se ve y de lo que se dice. Son frases que oirás mucho en Japón.
E 〜そうです: parece (aspecto) :: Con adjetivos en -i, quita la **い** y añade **そう です**: **おいしい** → **おいしそう です** (parece rico). :: Con verbos, usa la forma -masu sin ます + **そう です**: **ふります** → **ふりそう です** (parece que va a llover).
E 〜そうです: dicen que :: Con **〜そう です** también se dice lo que has oído de otra persona. Hay que tener cuidado: la forma **そう です** (así es) es otra cosa.
E 〜らしい: dicen que (por lo visto) :: Con **〜らしい** se dice algo que se ha oído o que parece claro por las pruebas: **あした は やすみ らしい です** (dicen que mañana es fiesta). :: Es más general que 〜そう です.
B Aspecto y oído | Forma | Significa | Ejemplo
| 〜そう です (aspecto) | い → そう です | parece | おいしそう です
| 〜そう です (oído) | forma normal + そう です | dicen que | かえる そう です
| 〜らしい です | forma normal + らしい | por lo visto | やすみ らしい です
W おいしそう = parece rico | oishisō
W ふりそう = parece que va a llover | furisō
W かえる = volver (forma de diccionario) | kaeru
W らしい = dicen que; por lo visto | rashii
V Vocabulario: lo que se ve y se oye
D En la oficina
まり: この ケーキ は おいしそう です ね。 = Esta tarta parece rica, ¿verdad?
  > おいしそう です = parece rica
けんじ: やまだ さん は あした かえる そう です。 = Dicen que Yamada vuelve mañana.
  > かえる そう です = dicen que vuelve
まり: じゃあ、 あした は やすみ らしい です か。 = Entonces, ¿mañana es fiesta, por lo visto?
  > やすみ らしい です か = ¿por lo visto es fiesta?
Q ¿Qué significa «この ケーキ は おいしそう です»?
+ Esta tarta parece rica. :: そう = parece, por el aspecto.
- Esta tarta es rica. :: Eso sería una afirmación.
- Esta tarta es cara. :: No aparece en la frase.
Q ¿Qué expresa «らしい»?
+ Lo que se dice o se ve; por lo visto. :: らしい = por lo visto.
- Lo que quiero hacer. :: Eso sería 〜たい.
- Una orden. :: Eso sería 〜て ください.
H この ケーキ は ___ です。 :: Esta tarta parece rica.
+ おいしそう :: Aspecto.
- おいしかった :: Eso sería «estaba rica».
- おいしい :: Eso sería «es rica» sin dudar.
H あした は やすみ ___ です。 :: Dicen que mañana es fiesta.
+ らしい :: Por lo visto.
- でしょう :: Eso sería «supongo».
- かも :: Eso sería «quizá».
R あめ が ふりそう です。 :: Traduce la frase.
+ Parece que va a llover. :: そう = parece, por el aspecto.
- Dicen que llueve. :: Eso sería oído, otra forma.
- Llovió ayer. :: Eso es el pasado.
A やまだ さん は あした かえる そう です。 :: ¿Qué informa?
+ Dicen que Yamada vuelve mañana. :: Oído.
- Yamada parece cansado. :: No aparece en la frase.
- Yamada no vuelve. :: Eso es lo contrario.
O おいしそう です :: Parece rico. :: そう = parece.
Q ¿Cuál es la forma de «parece que va a llover»?
+ ふりそう です :: Forma -masu sin ます + そう です.
- ふります :: Eso es llover (presente).
- ふったら :: Eso es «si llueve».
