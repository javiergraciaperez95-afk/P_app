@ 33 | からといって と とはかぎらない | Solo porque... / no necesariamente...
I Hoy aprendes a decir que una razón no basta para llegar a una conclusión, y que una regla general no siempre se cumple.
E 〜からといって: solo porque... (no basta) :: Oración + **からといって**: **たかい からといって、 いい もの だ とはかぎらない** (solo porque es caro, no significa que sea bueno). :: Rechaza una conclusión que parece lógica.
E 〜とはかぎらない: no necesariamente; no siempre :: Oración + **とはかぎらない**: **ともだち が くる とはかぎらない** (no siempre viene mi amigo). :: Expresa que una regla no se cumple siempre.

Q ¿Qué significa «たかい からといって、 いい もの だ とはかぎらない»?
+ Solo porque es caro, no significa que sea bueno. :: からといって = solo porque.
- Como es caro, es bueno. :: Eso es lo contrario.
- Es caro, pero no lo compro. :: Eso no es la frase.
Q ¿Qué expresa «とはかぎらない»?
+ Que una regla no siempre se cumple. :: No necesariamente.
- Que siempre es así. :: Eso es lo contrario.
- Que es imposible. :: Eso sería 〜わけがない.

R ともだち が くる とはかぎらない。 :: Traduce la frase.
+ My friend doesn't always come. :: とはかぎらない = not necessarily.
- My friend always comes. :: Eso es lo contrario.

A たかい からといって、 いい もの だ とはかぎらない。 :: ¿Qué cuenta?
+ Que el precio alto no garantiza la calidad. :: Lo caro no siempre es bueno.
- Que lo caro siempre es bueno. :: Eso es lo contrario.
- Que el precio no importa. :: Eso no es la frase.
O ともだち が くる とはかぎらない :: No siempre viene mi amigo. :: とはかぎらない = no necesariamente.
Q ¿Cuál es el sentido de «からといって»?
+ Solo porque... (razón insuficiente). :: Razón no suficiente.
- Porque... (causa directa). :: Eso sería から.
- Aunque... (concesión). :: Eso sería でも.
