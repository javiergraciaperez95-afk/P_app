@ 1 | ひらがな 1 | El hiragana (1): de «a» a «no»
I El japonés se escribe con tres sistemas a la vez. Empezamos por el hiragana, que es la base. En este curso las frases van con espacios entre las palabras para que te sea más fácil; en Japón se escribe todo seguido.
E Tres escrituras :: El japonés mezcla tres sistemas. El **hiragana** (ひらがな) sirve para las terminaciones, las partículas y cualquier palabra. El **katakana** (カタカナ) se usa para palabras extranjeras. Los **kanji** (漢字) son los caracteres de origen chino. :: Con el hiragana ya puedes escribir **cualquier** palabra japonesa, y por eso se aprende primero. Tiene 46 signos básicos.
E Cómo suena :: Cada signo es una **sílaba**, no una letra: か es «ka», no «k». :: Las cinco vocales suenan **como en español**: a, i, u, e, o. Esa es la gran ventaja de los hispanohablantes. :: Las filas siguen siempre el mismo orden: a, i, u, e, o. Solo hay tres sorpresas en esta lección: し se dice **shi** (no «si»), ち se dice **chi** (no «ti») y つ se dice **tsu** (no «tu»). :: En la pronunciación que verás, la **h** se aspira como una jota muy suave, la **sh** es como en inglés y la **z** vibra, como un zumbido.
B Hiragana: las cinco primeras filas | | a | i | u | e | o
| vocales | あ a | い i | う u | え e | お o
| k | か ka | き ki | く ku | け ke | こ ko
| s | さ sa | し shi | す su | せ se | そ so
| t | た ta | ち chi | つ tsu | て te | と to
| n | な na | に ni | ぬ nu | ね ne | の no

Q ¿Cómo se lee «か»?
+ ka :: Fila k, vocal a.
- sa :: Eso es さ.
- ta :: Eso es た.
Q ¿Cómo se lee «し»?
+ shi :: Es una de las tres excepciones.
- si :: En japonés no existe el sonido «si».
- su :: Eso es す.
Q ¿Cómo se lee «つ»?
+ tsu :: Excepción de la fila t.
- tu :: En japonés no existe «tu».
- chi :: Eso es ち.
Q ¿Qué signo es «su»?
+ す :: Fila s, vocal u.
- さ :: Eso es «sa».
- せ :: Eso es «se».
Q ¿Qué signo es «ne»?
+ ね :: Fila n, vocal e.
- ぬ :: Eso es «nu».
- の :: Eso es «no».

+ sushi :: Su-shi.
- sake :: Sake es さけ.

Q ¿Cuál es «tsukue» (escritorio)?
+ つくえ :: Tsu-ku-e.
- ちかい :: Eso es «chikai».
- たかい :: Eso es «takai».
O おいしい すし :: Sushi rico :: El adjetivo va delante del nombre.

@ 1 | ひらがな 2 | El hiragana (2): de «ha» a «n»
E El resto del silabario :: Con estas filas completas los 46 signos básicos. :: La **h** se aspira: は es «ha» como una jota muy suave. Pero ふ es **fu**: se sopla entre los labios, sin morder el labio. :: La **r** japonesa es un solo toque de lengua, como la r de «pero», nunca fuerte como la de «perro». :: Las filas **y** y **w** están incompletas: solo や, ゆ, よ y わ, を. :: ん es una **n** suelta: es el único signo que no lleva vocal.
B Hiragana: las cinco últimas filas | | a | i | u | e | o
| h | は ha | ひ hi | ふ fu | へ he | ほ ho
| m | ま ma | み mi | む mu | め me | も mo
| y | や ya | | ゆ yu | | よ yo
| r | ら ra | り ri | る ru | れ re | ろ ro
| w | わ wa | | | | を o
| n | ん n | | | |
E Tres signos con truco :: を se pronuncia igual que お («o») y solo se usa como partícula. :: は se lee «ha» dentro de una palabra, pero cuando es partícula se lee **wa**. Por eso こんにちは se dice «konnichiwa». :: へ se lee «he», pero cuando es partícula se lee **e**. Las partículas las verás muy pronto.

Q ¿Cómo se lee «ふ»?
+ fu :: Es la excepción de la fila h.
- hu :: Se sopla entre los labios: suena «fu».
- ho :: Eso es ほ.
Q ¿Cómo se lee «ん»?
+ n :: Es una n suelta, sin vocal.
- nu :: Eso es ぬ.
- mu :: Eso es む.
Q ¿Cómo se lee «こんにちは»?
+ konnichiwa :: La は final es partícula y se lee «wa».
- konnichiha :: Aquí は no se lee «ha».
- konichiba :: No.
Q ¿Qué signo es «ri»?
+ り :: Fila r, vocal i.
- れ :: Eso es «re».
- る :: Eso es «ru».
Q ¿Qué signo es «mo»?
+ も :: Fila m, vocal o.
- ま :: Eso es «ma».
- む :: Eso es «mu».
R わたし
+ yo :: Wa-ta-shi.
- tú :: No.
- nombre :: Nombre es なまえ.
R せんせい
+ profesor :: Se-n-se-i.
- estudiante :: No.
- persona :: Persona es ひと.
A すみません :: Escucha. ¿Qué significa?
+ Perdón, disculpe. :: Sirve para disculparse y para llamar la atención.
- Buenos días. :: Eso es おはよう.
- Adiós. :: Eso es さようなら.
A おはよう :: Escucha. ¿Qué significa?
+ Buenos días. :: Se dice por la mañana.
- Hola. :: Eso es こんにちは.
- Sí. :: Eso es はい.
O しろい くるま :: Coche blanco :: Adjetivo + nombre.

@ 1 | ひらがな 3 | El hiragana (3): sonidos sonoros, dobles y largos
E Dos rayitas y un circulito :: Con dos rayitas (゛) arriba a la derecha, la consonante se vuelve **sonora**: か ka → **が ga**, さ sa → **ざ za**, た ta → **だ da**, は ha → **ば ba**. :: Con un circulito (゜), la fila h se convierte en **p**: は ha → **ぱ pa**. :: Excepciones: **じ** se dice «ji» (como la j inglesa de «jeans») y **づ**, casi sin uso, «zu».
B Sonidos sonoros | | a | i | u | e | o
| g | が ga | ぎ gi | ぐ gu | げ ge | ご go
| z | ざ za | じ ji | ず zu | ぜ ze | ぞ zo
| d | だ da | ぢ ji | づ zu | で de | ど do
| b | ば ba | び bi | ぶ bu | べ be | ぼ bo
| p | ぱ pa | ぴ pi | ぷ pu | ぺ pe | ぽ po
E La pequeña つ y las vocales largas :: Una **っ** pequeña no se pronuncia: hace una pausa y **dobla** la consonante siguiente. がっこう se dice «gak-kō». :: Las vocales pueden ser **largas** (duran el doble) y eso cambia el significado. La o larga se suele escribir **おう** y la e larga, **えい**: とうきょう es «tōkyō», せんせい es «sensē». En la pronunciación las verás con una raya: ō, ē, ū.
E Sílabas combinadas :: Un signo de la columna «i» seguido de **ゃ, ゅ, ょ** pequeñas forma una sola sílaba: **きゃ** kya, **きゅ** kyu, **きょ** kyo. :: Las más usadas: **しゃ** sha, **しゅ** shu, **しょ** sho · **ちゃ** cha, **ちゅ** chu, **ちょ** cho · **じゃ** ja, **じゅ** ju, **じょ** jo · **りょ** ryo.

Q ¿Cómo se lee «が»?
+ ga :: か con dos rayitas.
- ka :: Eso es か, sin rayitas.
- za :: Eso es ざ.
Q ¿Cómo se lee «ぱ»?
+ pa :: は con un circulito.
- ba :: Eso es ば, con rayitas.
- ha :: Eso es は.
Q ¿Qué hace la «っ» pequeña en «がっこう»?
+ Dobla la consonante siguiente: «gak-kō». :: Se hace una pequeña pausa.
- Se lee «tsu». :: Solo la つ grande se lee «tsu».
- No hace nada. :: Cambia la pronunciación.
Q ¿Cómo se lee «きょう»?
+ kyō :: きょ es una sola sílaba y la う alarga la o.
- kiyou :: No son sílabas separadas.
- kyu :: No.
Q ¿Cómo se lee «じ»?
+ ji :: Como la j inglesa.
- zi :: En japonés no existe «zi».
- shi :: Eso es し.
