@ 35 | もし と なら (1) | Si es así: なら
I Hoy aprendes a partir de lo que el otro ha dicho o de lo que tú sabes: «si es así, entonces». Es una forma muy natural de contestar en una conversación.
E 〜なら: si es así (partiendo de lo dicho) :: Para responder a algo que ya se sabe o que el otro acaba de decir: frase en forma normal + **なら**: **にほん へ いく なら、 わたし も いきます** (si vas a Japón, yo también iré). :: Es diferente de 〜たら: aquí se parte de una información ya conocida.
E Con nombres y な-adjetivos :: Después de un nombre o un adjetivo en -na se usa **なら**: **ひま なら、 てつだって ください** (si tienes tiempo libre, ayúdame). :: Con **です** queda **です なら**.
B Partiendo de lo dicho | Forma | Significa | Ejemplo
| 〜なら | si es así | いく なら
| 〜な なら | si es (nombre o -na) | ひま な なら
W なら = si es así; partiendo de eso | nara
W ふったら = si llueve (de ふる) | futtara
W おわらない = no termina; no acaba (de おわる) | owaranai
V Vocabulario: si es así
D Un viaje
けんじ: にほん へ いく の？ = ¿Vas a Japón?
  > いく の = ¿vas?
まり: うん。 にほん へ いく なら、 わたし も いきます。 = Sí. Si vas a Japón, yo también iré.
  > いく なら = si vas
T Partiendo de lo que se sabe
- にほん へ いく なら、 わたし も いきます。 = Si vas a Japón, yo también iré.
  > いく なら = si vas
- しごと が おわらない なら、 あした やります。 = Si el trabajo no termina, lo haré mañana.
  > おわらない なら = si no termina
Q ¿Qué significa «にほん へ いく なら、 わたし も いきます»?
+ Si vas a Japón, yo también iré. :: なら = partiendo de lo dicho.
- Aunque vayas a Japón, no iré. :: Eso es lo contrario.
- Iré a Japón, y tú irás también. :: No es la frase.
Q ¿Qué diferencia hay entre «なら» y «たら»?
+ なら parte de algo ya dicho; たら es condición futura. :: Son distintas.
- Son exactamente iguales. :: No es cierto.
- なら expresa causa; たら expresa deseo. :: No es cierto.
H にほん へ いく ___ 、 わたし も いきます。 :: Si vas a Japón, yo también iré.
+ なら :: Partiendo de lo dicho.
- たら :: Eso sería condición futura.
- から :: Eso sería porque.
H しごと が おわらない ___ 、 あした やります。 :: Si no termina, lo haré mañana.
+ なら :: Partiendo de lo dicho.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
R にほん へ いく なら、 わたし も いきます。 :: Traduce la frase.
+ If you're going to Japan, I'll go too. :: なら = si es así.
- If I go to Japan, you'll go too. :: Eso invierte el sujeto.
- Although you go to Japan, I won't. :: Eso es lo contrario.
A うん。 にほん へ いく なら、 わたし も いきます。 :: ¿Qué cuenta?
+ Que ella irá también si él va. :: なら = condición de lo dicho.
- Que ella no irá nunca. :: Eso es lo contrario.
- Que ella irá antes. :: Eso no es la frase.
O いく なら :: Si vas. :: なら = partiendo de lo dicho.
Q ¿Cuál es más natural en una conversación?
+ なら, para partir de lo que dijo el otro. :: Es una respuesta natural.
- たら, para algo que no se sabe. :: No es el uso habitual aquí.
- ために, para la finalidad. :: No es el uso aquí.

@ 35 | もし と なら (2) | Si sigues así: ようでは
I Ahora, cómo advertir a alguien de las consecuencias de su manera de actuar. Es una expresión seria, muy usada en los consejos y en las críticas.
E 〜ようでは: si sigues así :: Para advertir que una forma de hacer las cosas llevará a un mal resultado: verbo o adjetivo en forma normal + **よう で は**: **ねて ばかり いる ようでは、 しけん に おちる** (si te pasas el día durmiendo, suspenderás el examen). :: Es una advertencia firme.
E Crítica de un resultado :: Se usa para mostrar que algo no es suficiente. :: Suele ir con una frase negativa: **〜ようでは ない** o **〜ようでは だめ です**.
B Advertencia | Forma | Significa | Ejemplo
| 〜ようでは | si sigues así | ねて ばかり いる ようでは
| 〜ようでは だめ です | así no es suficiente | がんばらない ようでは だめ です
W ようでは = si sigues así; si es así | yō de wa
W おちる = suspender; caer (de un examen) | ochiru
W ずっと = todo el tiempo; durante mucho | zutto
W だめ = inútil; no sirve; no vale | dame
W いました = estuve; había (pasado de いる) | imashita
W がんばらない = no esforzarse (forma ない de がんばる) | ganbaranai
V Vocabulario: si sigues así
D Un consejo a un amigo
けんじ: きょう は ずっと ねて いました。 = Hoy estuve durmiendo todo el día.
  > ずっと ねて いました = estuve durmiendo todo el día
まり: ねて ばかり いる ようでは、 しけん に おちる よ。 = Si te pasas el día durmiendo, suspenderás el examen.
  > ねて ばかり いる ようでは = si sigues así
T Advertencias
- ねて ばかり いる ようでは、 しけん に おちる。 = Si te pasas el día durmiendo, suspenderás el examen.
  > ねて ばかり いる ようでは = si sigues así
- がんばらない ようでは だめ です。 = Si no te esfuerzas, no es suficiente.
  > がんばらない ようでは だめ です = si no te esfuerzas, no es suficiente
Q ¿Qué significa «ねて ばかり いる ようでは、 しけん に おちる»?
+ Si te pasas el día durmiendo, suspenderás el examen. :: ようでは = advertencia.
- Duermes, así que apruebas el examen. :: Eso es lo contrario.
- Duermes para aprobar el examen. :: Eso invierte la lógica.
Q ¿Qué expresa «〜ようでは»?
+ Una advertencia sobre las consecuencias. :: Advertencia firme.
- Un permiso. :: Eso sería 〜て も いい.
- Un deseo. :: Eso sería 〜たい.
H ねて ばかり いる ___ 、 しけん に おちる。 :: Si sigues así, suspenderás.
+ ようでは :: Advertencia.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H がんばらない ___ だめ です。 :: Si no te esfuerzas, no es suficiente.
+ ようでは :: Advertencia.
- ばかりか :: Eso sería no solo.
- ことは ない :: Eso sería no hace falta.
R ねて ばかり いる ようでは、 しけん に おちる。 :: Traduce la frase.
+ If you keep sleeping all day, you'll fail the exam. :: ようでは = advertencia.
- You sleep, so you pass the exam. :: Eso es lo contrario.
- You sleep to pass the exam. :: Eso invierte la lógica.
A まり: ねて ばかり いる ようでは、 しけん に おちる よ。 :: ¿Qué advierte?
+ Que dormir todo el día hará suspender. :: Consecuencia negativa.
- Que dormir todo el día es bueno. :: Eso es lo contrario.
- Que el examen es fácil. :: No aparece.
O がんばらない ようでは だめ です :: Si no te esfuerzas, no es suficiente. :: ようでは = advertencia.
Q ¿Cuál expresa una advertencia?
+ 〜ようでは :: Advierte del resultado.
- 〜ように :: Expresa finalidad.
- 〜ながら :: Expresa simultaneidad.

@ 35 | もし と なら (3) | Aunque sea: たとえ〜ても y としても
I Por último, la forma de decir «aunque sea lo peor»: incluso si ocurre algo, la decisión no cambia. Es una expresión muy firme y se usa para mostrar determinación.
E たとえ〜ても: aunque (incluso si) :: Para decir que no importa lo que pase, la decisión es la misma: たとえ + frase con 〜ても o 〜としても: **たとえ あめ が ふったとしても、 いきます** (incluso si llueve, iré). :: La palabra たとえ refuerza el sentido.
E 〜としても: incluso si (suposición) :: Para hablar de una suposición fuerte: forma たとして + も: **ふったとしても** (incluso si llueve). :: Es más formal que 〜ても.
B Incluso si | Forma | Significa | Ejemplo
| たとえ〜ても | incluso si | たとえ あめ が ふっても
| 〜としても | incluso si lo supones | ふったとしても
W たとえ = incluso si; aunque | tatoe
W ふったとしても = incluso si llueve (suposición fuerte) | futta toshite mo
W いきます = iré (de いく) | ikimasu
W いかない = no ir | ikanai
V Vocabulario: incluso si
D Una decisión firme
けんじ: あした、 あめ が ふったら、 いかない の？ = Mañana, si llueve, ¿no vas?
  > ふったら = si llueve
まり: いいえ。 たとえ あめ が ふったとしても、 いきます。 = No. Incluso si llueve, iré.
  > たとえ あめ が ふったとしても = incluso si llueve
T Decisiones
- たとえ あめ が ふったとしても、 いきます。 = Incluso si llueve, iré.
  > たとえ あめ が ふったとしても = incluso si llueve
- たとえ ひとり で も、 がんばります。 = Incluso si estoy solo, me esforzaré.
  > たとえ ひとり で も = incluso si estoy solo
Q ¿Qué significa «たとえ あめ が ふったとしても、 いきます»?
+ Incluso si llueve, iré. :: たとえ = incluso si.
- Si llueve, no iré. :: Eso es lo contrario.
- Llueve, así que iré. :: Eso no es la frase.
Q ¿Qué expresa «たとえ»?
+ Que la decisión no cambia. :: Incluso si pasa algo.
- Una causa. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H たとえ あめ が ___、 いきます。 :: Incluso si llueve, iré.
+ ふったとしても :: Suposición fuerte.
- ふったら :: Eso sería si llueve.
- ふって :: Eso no es concesivo.
H たとえ ひとり で ___、 がんばります。 :: Incluso si estoy solo, me esforzaré.
+ も :: Incluso.
- ながら :: Eso sería mientras.
- から :: Eso sería porque.
R たとえ あめ が ふったとしても、 いきます。 :: Traduce la frase.
+ Incluso si llueve, iré. :: たとえ = incluso si.
- Si llueve, no iré. :: Eso es lo contrario.
- Llueve, así que iré. :: Eso no es la frase.
A いいえ。 たとえ あめ が ふったとしても、 いきます。 :: ¿Qué decide?
+ Que irá aunque llueva. :: Decisión firme.
- Que no irá si llueve. :: Eso es lo contrario.
- Que lloverá. :: No aparece.
O たとえ あめ が ふっても :: Aunque llueva. :: たとえ = incluso si.
Q ¿Cuál es más formal?
+ 〜としても :: Es más formal.
- 〜たら :: Es más simple.
- 〜ながら :: Es simultaneidad.
