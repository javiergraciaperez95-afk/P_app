@ 35 | もし と なら (1) | Si es así: なら
I Hoy aprendes a partir de lo que el otro ha dicho o de lo que tú sabes: «si es así, entonces». Es una forma muy natural de contestar en una conversación.
E 〜なら: si es así (partiendo de lo dicho) :: Para responder a algo que ya se sabe o que el otro acaba de decir: frase en forma normal + **なら**: **にほん へ いく なら、 わたし も いきます** (si vas a Japón, yo también iré). :: Es diferente de 〜たら: aquí se parte de una información ya conocida.
E Con nombres y な-adjetivos :: Se añade **なら** directamente al nombre o al adjetivo en -な: **ひま なら** (si tienes tiempo) / **学生 なら** (si eres estudiante). :: No se añade **です** antes de **なら**; en un registro cortés pueden usarse formas como **学生でしたら**.
B Partiendo de lo dicho | Forma | Significa | Ejemplo
| 〜なら | si es así | いく なら
| nombre o adjetivo en -な + なら | si es así | 学生 なら / ひま なら
W なら = si es así; partiendo de eso | nara
W ふったら = si llueve (de ふる) | futtara
W おわらない = no termina; no acaba (de おわる) | owaranai

  > いく の = ¿vas?

  > いく なら = si vas
T Partiendo de lo que se sabe
- にほん へ いく なら、 わたし も いきます。 = Si vas a Japón, yo también iré.
  > いく なら = si vas
- しごと が おわらない なら、 あした やります。 = Si el trabajo no termina, lo haré mañana.
  > おわらない なら = si no termina
Q ¿Qué significa «にほん へ いく なら、 わたし も いきます»?
+ Si vas a Japón, yo también iré. :: なら = partiendo de lo dicho.
- Aunque vayas a Japón, no iré. :: Eso es lo contrario.
- Iré a Japón, y tú irás también. :: No es la frase.
Q ¿Qué diferencia hay entre «なら» y «たら»?
+ なら parte de algo ya dicho; たら es condición futura. :: Son distintas.
- Son exactamente iguales. :: No es cierto.
- なら expresa causa; たら expresa deseo. :: No es cierto.

+ なら :: Partiendo de lo dicho.
- たら :: Eso sería condición futura.
- から :: Eso sería porque.
H しごと が おわらない ___ 、 あした やります。 :: Si no termina, lo haré mañana.
+ なら :: Partiendo de lo dicho.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.

+ Si vas a Japón, yo también iré. :: なら = si es así.

- Que ella irá antes. :: Eso no es la frase.

+ なら, para partir de lo que dijo el otro. :: Es una respuesta natural.
- たら, para algo que no se sabe. :: No es el uso habitual aquí.
- ために, para la finalidad. :: No es el uso aquí.
