@ 38 | こうしき の ことば (1) | Durante: にわたって y において
I Hoy aprendes palabras del lenguaje formal, de los informes y de las noticias. Sirven para decir cuánto dura algo y dónde ocurre, con un tono más serio que en la conversación.
E 〜にわたって: durante; a lo largo de :: Indica que una acción o situación abarca un periodo o una extensión: sustantivo + **にわたって**. No implica necesariamente que ocurra sin interrupción: **さんねん にわたって けんきゅう しました** (investigué a lo largo de tres años).
E 〜において: en (un lugar o ámbito) :: Sitúa formalmente un acto, evento o asunto: sustantivo + **において**. Es más propio de informes y anuncios que de conversación: **かいぎ は 東京 において おこなわれました** (la reunión se celebró en Tokio).
B Formal: tiempo y lugar | Forma | Significa | Ejemplo
| 〜にわたって | durante (todo el periodo) | さんねん にわたって
| 〜において | en (lugar o ámbito formal) | 東京 において
W にわたって = durante (todo un periodo) | ni watatte
W において = en; en el ámbito de | ni oite
W さんねん = tres años | sannen
W けんきゅう = investigación; estudio | kenkyū
w かいぎ = reunión; conferencia | kaigi
W おこなわれました = se celebró; se llevó a cabo | okonawaremashita
W かかりました = llevó (tiempo); costó (de かかる) | kakarimashita
V Vocabulario: durante y en
D Un informe
けんじ: その けんきゅう、 どのくらい かかりました か。 = ¿Cuánto tiempo te llevó esa investigación?
  > どのくらい かかりました か = ¿cuánto tiempo te llevó?
まり: さんねん にわたって しました。 = Lo hice durante tres años.
  > さんねん にわたって しました = lo hice durante tres años
T Lenguaje formal
- さんねん にわたって、 けんきゅう しました。 = Investigué durante tres años.
  > さんねん にわたって = durante tres años
- かいぎ は 東京 において おこなわれました。 = La reunión se celebró en Tokio.
  > 東京 において = en Tokio (registro formal)
Q ¿Qué significa «さんねん にわたって、 けんきゅう しました»?
+ Investigué durante tres años. :: にわたって = durante todo el periodo.
- Investigué tres veces. :: Eso sería repetición.
- Investigué hace tres años. :: Eso sería el pasado puntual.
Q ¿Qué expresa «〜において»?
+ El lugar o el ámbito de algo. :: Es formal.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H さんねん ___ 、 けんきゅう しました。 :: Durante tres años investigué.
+ にわたって :: Todo el periodo.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H かいぎ は 東京 ___ おこなわれました。 :: La reunión se celebró en Tokio.
+ において :: Lugar o ámbito.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
R さんねん にわたって、 けんきゅう しました。 :: Traduce la frase.
+ Investigué durante tres años. :: にわたって = durante todo el periodo.
- Investigué tres veces. :: Eso es repetición.
- Investigué hace tres años. :: Eso es el pasado puntual.
A まり: さんねん にわたって しました。 :: ¿Qué cuenta?
+ Que lo hizo durante tres años. :: Duración.
- Que lo hizo una vez. :: Eso es lo contrario.
- Que no lo hizo. :: Eso es lo contrario.
O 東京 において :: En Tokio (formal). :: において sitúa formalmente un evento.
Q ¿Cuál es más formal?
+ において :: Lenguaje formal.
- で :: Es conversacional.
- に :: Es neutro.

@ 38 | こうしき の ことば (2) | En el momento de: にさいして y にあたって
I Ahora dos palabras para hablar de momentos importantes: la salida de un viaje, un examen, una reunión. Son muy usadas en discursos, en avisos y en el trabajo.
E 〜にさいして: en el momento de :: Para decir que algo se hace en un momento importante: sustantivo + **に 際して**: **しゅっぱつ にさいして、 ごあいさつ を します** (al salir, doy unas palabras de despedida). :: Es muy formal.
E 〜にあたって: al hacer / al empezar :: Se usa al iniciar o prepararse para un acto importante: sustantivo + **にあたって**: **しゅっぱつ にあたって、 かぞく に あいさつ します** (al partir, me despido de mi familia). :: No es simplemente una versión más natural de **に際して**; las dos son formales y el contexto decide.
B Momento importante | Forma | Significa | Ejemplo
| 〜にさいして | en el momento de | しゅっぱつ にさいして
| 〜にあたって | al empezar; para | しけん にあたって
W にさいして = en el momento de (muy formal) | ni saishite
W にあたって = al empezar; al preparar | ni atatte
W ごあいさつ = saludo; palabras de despedida | goaisatsu
V Vocabulario: en el momento de
T Momentos importantes
- しゅっぱつ にさいして、 ごあいさつ を します。 = Al salir, doy unas palabras de despedida.
  > しゅっぱつ にさいして = al salir
- しけん にあたって、 じゅんび を します。 = Para el examen, me preparo.
  > しけん にあたって = para el examen
Q ¿Qué significa «しゅっぱつ にさいして、 ごあいさつ を します»?
+ Al salir, doy unas palabras de despedida. :: にさいして = en el momento de.
- Después de salir, no digo nada. :: Eso es lo contrario.
- Al llegar, saludo. :: Eso es lo contrario.
Q ¿Qué expresa «〜にあたって»?
+ Lo que se hace al empezar o al preparar. :: Momento de inicio.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H しけん ___ 、 じゅんび を します。 :: Para el examen, me preparo.
+ にあたって :: Al empezar.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H しゅっぱつ ___ 、 ごあいさつ を します。 :: Al salir, doy unas palabras.
+ にさいして :: En el momento de.
- まで :: Eso sería hasta.
- ばかり :: Eso sería solo.
R しけん にあたって、 じゅんび を します。 :: Traduce la frase.

- Que no dirá nada. :: Eso es lo contrario.
- Que llegará tarde. :: No aparece.
O しゅっぱつ にさいして :: Al salir. :: にさいして = en el momento de.
Q ¿Cuál es más formal?
+ にさいして :: Muy formal.
- にあたって :: Formal, pero más natural.
- ために :: Finalidad.

@ 38 | こうしき の ことば (3) | Basado en: をもとに y にもとづいて
I Por último, dos formas para decir que algo se hace partiendo de datos o de una base. Son típicas de los informes y de los artículos de opinión.
E 〜をもとに: tomando como base :: Indica el material o los datos que sirven de punto de partida: sustantivo + **をもとに**. **この データ を もとに、けいかく を たてます** (a partir de estos datos, elaboraré un plan).
E 〜にもとづいて: basándose en; de acuerdo con :: Presenta la base o criterio que respalda una acción: sustantivo + **にもとづいて**. **きそく に もとづいて、判断します** (decidiremos de acuerdo con las normas). La diferencia con **をもとに** depende del contexto; no es una oposición absoluta.
B Partir de una base | Forma | Significa | Ejemplo
| 〜を もとに | a partir de (datos) | この データ を もとに
| 〜に もとづいて | basado en (principio) | けいけん に もとづいて
W データ = datos | dēta
W もとに = a partir de; basándose en | moto ni
W たてます = elaboraré; haré (un plan) | tatemasu
w けいけん = experiencia | keiken
W きそく = norma; reglamento | kisoku
W はんだんします = decidiré; juzgaré | handan shimasu
W もとづいて = basándose en; según | motozuite
V Vocabulario: basado en
T Planes y opiniones
- この データ を もとに、 けいかく を たてます。 = Basándome en estos datos, haré un plan.
  > この データ を もとに = basándome en estos datos
- わたし の けいけん に もとづいて、 はなします。 = Hablaré basándome en mi experiencia.
  > わたし の けいけん に もとづいて = basándome en mi experiencia
Q ¿Qué significa «この データ を もとに、 けいかく を たてます»?
+ Basándome en estos datos, haré un plan. :: を もとに = a partir de.
- Sin datos, haré un plan. :: Eso es lo contrario.
- Haré un plan para tener datos. :: Eso invierte la lógica.
Q ¿Qué diferencia hay entre «をもとに» y «にもとづいて»?
+ にもとづいて es más formal y se refiere a principios o experiencia. :: Son muy parecidas.
- Son exactamente iguales. :: No es cierto.
- をもとに es más formal. :: No es cierto.
H この データ を ___ 、 けいかく を たてます。 :: Basándome en estos datos...
+ もとに :: A partir de.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H わたし の けいけん ___ 、 はなします。 :: Basándome en mi experiencia...
+ に もとづいて :: Según una base.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
R この データ を もとに、 けいかく を たてます。 :: Traduce la frase.
+ Basándome en estos datos, haré un plan. :: もとに = a partir de.
- Haré un plan sin datos. :: Eso es lo contrario.
- Haré un plan para conseguir datos. :: Eso invierte la lógica.
A わたし の けいけん に もとづいて、 はなします。 :: ¿Qué hará?
+ Hablará basándose en su experiencia. :: に もとづいて = basado en.
- Hablará sin experiencia. :: Eso es lo contrario.
- No hablará. :: Eso es lo contrario.
O この データ を もとに :: Basándome en estos datos. :: を もとに = a partir de.
Q ¿Cuál es más formal?
+ にもとづいて :: Principio o experiencia.
- をもとに :: Datos o información.
- ために :: Finalidad.
