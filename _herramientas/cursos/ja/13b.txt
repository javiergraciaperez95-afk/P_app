@ 13 | てから と まで に と あいだ に | Después de, a más tardar y mientras
I Hoy aprendes tres formas de ordenar el tiempo: qué pasa después de algo, hasta cuándo se puede hacer y qué pasa mientras dura otra cosa.
E 〜てから: después de (hacer algo) :: Verbo en forma て + **から**: **たべて から、 でかけます** (salgo después de comer). :: Es la secuencia de dos acciones, una tras otra.
E 〜まで に: a más tardar :: Tiempo límite + **まで に**: **げつまつ まで に、 しごと を します** (hago el trabajo antes de fin de mes). :: Marca el último momento posible.
E 〜あいだ に: mientras (dura algo) :: Verbo en forma normal + **あいだ に**: **ねている あいだ に、 あめ が ふります** (mientras duermo, llueve). :: Dos cosas que pasan a la vez.
W あいだ = mientras; durante | aida | kanji: 間
W げつまつ = fin de mes | getsumatsu | kanji: 月末
W ひるごはん = almuerzo | hirugohan | kanji: 昼ご飯
W もどって = volviendo (forma て de もどる) | modotte | kanji: 戻って

W ふとん = futón | futon | kanji: 布団
W めざまし = despertador | mezamashi | kanji: 目覚まし

V Vocabulario: después, a más tardar y mientras
T Un día normal
- ひるごはん を たべて から、 かいしゃ に もどって ください。 = Después de comer, vuelva a la oficina, por favor.
- げつまつ まで に、 しごと を します。 = Trabajo antes de fin de mes.
- わたし が ねている あいだ に、 はは は りょうり を します。 = Mientras duermo, mi madre cocina.
A わたし が ねている あいだ に、 はは は りょうり を します。 :: ¿Qué pasa mientras duerme?
+ Su madre cocina. :: あいだ に = mientras.
- Su madre duerme. :: Eso no es lo que pasa.
- Ella cocina. :: Eso sería otra persona.
A げつまつ まで に、 しごと を します。 :: ¿Cuándo termina el trabajo?
+ Antes de fin de mes. :: まで に = a más tardar.
- Después de fin de mes. :: Eso es lo contrario.
- Cada día. :: Eso no aparece.
HA ひるごはん を たべて ___ 、 かいしゃ に もどって ください。 :: Después de comer.
+ から :: Después de.
- まで :: Eso sería hasta.
- あいだ :: Eso sería mientras.
Q ¿Qué significa «たべて から、 でかけます»?
+ Salgo después de comer. :: てから = después de hacer algo.
- Salgo antes de comer. :: Eso invierte el orden.
- Como mientras salgo. :: Eso sería ながら.
Q ¿Qué expresa «まで に»?
+ Un plazo límite. :: Hay que hacerlo antes de cierta fecha.
- Un deseo. :: Eso sería 〜たい.
- Un permiso. :: Eso sería 〜て も いい.
H ひるごはん を たべて ___ 、 しごと を します。 :: Después de comer, trabajo.
+ から :: Después de.
- まで :: Eso sería hasta.
- あいだ :: Eso sería mientras.
H げつまつ ___ に、 しごと を します。 :: Trabajo antes de fin de mes.
+ まで :: A más tardar.
- から :: Eso sería desde.
- あいだ :: Eso sería mientras.
H ねている ___ に、 あめ が ふります。 :: Mientras duermo, llueve.
+ あいだ :: Mientras.
- まで :: Eso sería hasta.
- から :: Eso sería desde.
R ひるごはん を たべて から、 かいしゃ に いきます。 :: Traduce la frase.
+ After eating, I go to the office. :: てから = después de.
- Before eating, I go to the office. :: Eso invierte el orden.
- I go to the office without eating. :: Eso es lo contrario.
A げつまつ まで に、 しごと を します。 :: ¿Qué cuenta?
+ Que el trabajo se hará antes de fin de mes. :: まで に = a más tardar.
- Que el trabajo ya terminó. :: Eso es el pasado.
- Que no hará el trabajo. :: Eso es lo contrario.
O たべて から、 かいしゃ に いきます :: Después de comer, voy a la oficina. :: てから = después de.
