@ 30 | さいご の テスト | Examen final de B1
E Examen final de B1 :: Veinticinco preguntas sobre los capítulos 21 a 30. Si aciertas veinte o más, tienes un B1 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
A すいみん は ふかい です。 :: ¿Cómo es el sueño?
+ Profundo. :: ふかい = profundo.
- Ligero. :: Eso sería あさい.
- Corto. :: Eso no aparece.
A やむをえず、 ひきうけます。 :: ¿Qué hace?
+ Lo acepta a regañadientes. :: やむをえず = a regañadientes.
- Lo rechaza. :: Eso es lo contrario.
- Lo pospone. :: Eso no aparece.
Q Cap. 21. ¿Qué significa «あめ が ふっている ので、 かさ を もって いきます»?
+ Como llueve, llevo paraguas. :: ので = motivo.
- Llueve, así que no llevo paraguas. :: Eso es lo contrario.
- Llevo paraguas, pero no llueve. :: Eso es lo contrario.
H Cap. 21. ねつ が ある ___ 、 がっこう を やすみました。 :: Motivo con cortesía.
+ ので :: Motivo.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H Cap. 21. あめ の ___ 、 でんしゃ が おくれました。 :: Por culpa de la lluvia.
+ せいで :: Causa negativa.
- おかげで :: Causa positiva.
- ように :: Finalidad.
H Cap. 21. わすれない ___ 、 メモ を します。 :: Para no olvidar.
+ ように :: Objetivo.
- ながら :: Eso sería mientras.
- まえに :: Eso sería antes de.
Q Cap. 22. ¿Qué significa «あめ が ふっても、 さんぽ を します»?
+ Aunque llueva, doy un paseo. :: ても = aunque.
- Como llueve, doy un paseo. :: Eso sería ので.
- Antes de que llueva, doy un paseo. :: Eso sería まえに.
H Cap. 22. ここ で すわっても ___ 。 :: No importa si te sientas aquí.
+ かまいません :: No importa.
- ください :: Eso sería una petición.
- いけません :: Eso sería no se puede.
H Cap. 22. この みせ は やすい ___ 、 おいしい です。 :: Considerando que es barato, está rico.
+ わりに :: Considerando que.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H Cap. 22. でんわ を かけました。 ___ 、 でませんでした。 :: Sin embargo, no contestó.
+ ところが :: Sin embargo.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
Q Cap. 23. ¿Qué significa «てんき よほう に よると、 あした は あめ です»?
+ Según la previsión, mañana lloverá. :: によると = según una fuente.
- Mañana la previsión dice que no llueve. :: Eso es lo contrario.
- Mañana llueve, y la previsión no lo dice. :: No aparece en la frase.
H Cap. 23. やまだ さん は らいげつ にほん へ いく ___ 。 :: Dicen que irá a Japón.
+ という こと だ :: Algo oído.
- と おもいます :: Eso sería tu opinión.
- でしょう :: Eso sería tu suposición.
H Cap. 23. もし にほん へ いく ___ 、 なに を します か。 :: Si fuera a Japón.
+ としたら :: Suposición.
- から :: Eso sería porque.
- ながら :: Eso sería mientras.
H Cap. 23. あした は あめ ___ 。 :: Seguro que mañana lloverá.
+ に ちがいありません :: Seguridad.
- ください :: Eso sería una petición.
- ありませんでした :: Eso es no hubo.
H Cap. 24. かぞく に あう ___ 、 うれしく なります。 :: Cada vez que veo a mi familia.
+ たび に :: Cada vez que pasa.
- ごと に :: Eso sería cada intervalo.
- まえに :: Eso sería antes de.
H Cap. 25. しごと が おおい から、 やすむ ___ は いきません。 :: No puedo permitirme faltar.
+ わけ に :: No puedo permitirme.
- ため に :: Eso sería para.
- ながら :: Eso sería mientras.
H Cap. 25. おかね が ない ので、 あるく ___ ありません。 :: No hay más remedio que caminar.
+ しか :: Solo queda esa opción.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H Cap. 25. なにも ___ 、 でかけました。 :: Salió sin decir nada.
+ いわずに :: Sin decir.
- いって :: Eso sería decir y luego.
- いわなくても :: Eso sería no hace falta decir.
H Cap. 26. あの ひと は にほんご が じょうず に ___ 。 :: Seguro que habla bien japonés.
+ ちがいない :: Seguridad.
- ちがいます :: Eso es «es diferente».
- ください :: Eso sería una petición.
H Cap. 27. ねこ が ___ と して います。 :: El gato está intentando escapar.
+ にげよう :: Forma volitiva de にげる.
- にげて :: Eso es la forma て.
- にげた :: Eso es el pasado.
H Cap. 27. いま、 ちょうど でかける ___ です。 :: Ahora mismo estoy a punto de salir.
+ ところ :: Momento exacto.
- ため :: Eso sería finalidad.
- とき :: Eso sería cuando, sin el momento exacto.
H Cap. 27. ふゆ は さむくて ___ です。 :: El invierno hace un frío insoportable.
+ しょうがない :: Insoportable.
- ください :: Eso sería una petición.
- いけません :: Eso sería no se puede.
H Cap. 28. わざと へんじ を ___ 。 :: No contesté a propósito.
+ しなかった :: Negativo en pasado.
- した :: Eso sería que sí contestó.
- しません :: Eso es presente.
H Cap. 28. ついに ゆめ が ___ 。 :: Al final se cumplió mi sueño.
+ かなった :: Se cumplió.
- かなわない :: Eso es no se cumple.
- かなって ください :: Eso es una petición.
Q Cap. 30. ¿Qué significa «にほんご だけ で なく、 えいご も はなせます»?
+ No solo hablo japonés, también hablo inglés. :: だけで なく = no solo.
- Solo hablo japonés. :: Eso es lo contrario.
- Hablo inglés, pero no japonés. :: Eso es lo contrario.
H Cap. 29. にほん と いえば、 ___ です ね。 :: Hablando de Japón, son los cerezos.
+ さくら :: Lo que se asocia.
- たべます :: No encaja.
- いく :: No encaja.
H Cap. 29. でんしゃ で ___ いい です。 :: Podrías ir en tren.
+ いけば :: Forma ば de いく.
- いけない :: Eso sería no se puede.
- いきたい :: Eso sería quiero ir.
