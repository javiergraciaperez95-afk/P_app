@ 14 | ば と condiciones | Si... (condición general)
I Hoy aprendes la forma ば, que expresa una condición: si se da una cosa, pasa otra.
E 〜ば: si (condición) :: Se cambia la última vocal del verbo: **かえる** → **かえれば**, **たべる** → **たべれば**, **ある** → **あれば**, **する** → **すれば**. Se usa para decir lo que pasa si se cumple algo: **くるま が あれば、 はやく いきます** (si tengo coche, voy rápido). :: Suena más general que 〜たら.
E 〜ば: consejos y verdades generales :: Se usa para dar un consejo o decir una verdad: **まいにち べんきょう すれば、 いい です** (si estudias cada día, está bien). :: Expresa una condición que siempre da el mismo resultado.
W ふれば = si llueve (forma ば de ふる) | fureba | kanji: 降れば
W かえれば = si vuelves (forma ば de かえる) | kaereba | kanji: 帰れば
W あれば = si hay; si tengo (forma ば de ある) | areba | kanji: あれば
W すれば = si lo haces (forma ば de する) | sureba | kanji: すれば
W ねれば = si duermes (forma ば de ねる) | nereba | kanji: 寝れば
W おとな = adulto | otona | kanji: 大人
W ぼく = yo (masculino, informal) | boku | kanji: 僕
W てつどう = ferrocarril | tetsudō | kanji: 鉄道

V Vocabulario: si (condición con ば)
T Condiciones
- あめ が ふれば、 うち へ かえれば いい です。 = Si llueve, está bien volver a casa.
- くるま が あれば、 はやく いきます。 = Si tengo coche, voy rápido.
- まいにち べんきょう すれば、 いい です。 = Si estudias cada día, está bien.
- はやく ねれば、 あさ は げんき です。 = Si duermes pronto, por la mañana estás bien.
A はやく ねれば、 あさ は げんき です。 :: ¿Qué pasa si duerme pronto?
+ Por la mañana está bien. :: ねれば = si duermes.
- Llega tarde. :: Eso no aparece.
- No puede levantarse. :: Eso no aparece.
A くるま が あれば、 はやく いきます。 :: ¿Qué hace si tiene coche?
+ Va rápido. :: あれば = si tengo.
- Va a pie. :: Eso no aparece.
- No va. :: Eso es lo contrario.
HA まいにち べんきょう ___ 、 いい です。 :: Si estudias cada día, está bien.
+ すれば :: Si lo haces.
- した :: Eso sería el pasado.
- します :: Eso sería el presente.
Q ¿Qué significa «あめ が ふれば、 うち へ かえれば いい です»?
+ Si llueve, está bien volver a casa. :: ば = si.
- Como llueve, vuelvo a casa. :: Eso sería ので.
- Aunque llueva, no vuelvo. :: Eso sería 〜ても.
H くるま が ___ 、 はやく いきます。 :: Si tengo coche, voy rápido.
+ あれば :: Si hay.
- あった :: Eso sería el pasado.
- あります :: Eso sería solo hay.
H まいにち べんきょう ___ 、 いい です。 :: Si estudias cada día, está bien.
+ すれば :: Si lo haces.
- した :: Eso sería el pasado.
- します :: Eso sería presente.
H はやく ___ 、 あさ は げんき です。 :: Si duermes pronto, por la mañana estás bien.
+ ねれば :: Si duermes.
- ねた :: Eso sería el pasado.
- ねて :: Eso sería forma て.
R あめ が ふれば、 うち へ かえれば いい です。 :: Traduce la frase.
+ If it rains, it is fine to go home. :: ば = si.
- Since it rains, I go home. :: Eso sería ので.
- Although it rains, I don't go home. :: Eso es lo contrario.
A くるま が あれば、 はやく いきます。 :: ¿Qué cuenta?
+ Que irá rápido si tiene coche. :: Condición.
- Que no tiene coche. :: Eso es lo contrario.
- Que ya fue en coche. :: Eso es el pasado.
O あれば、 いい です :: Si hay, está bien. :: ば = si.
Q ¿Qué forma es «ふれば»?
+ Forma ば de ふる. :: Condición de ふる.
- Forma て de ふる. :: Eso sería 降って.
- Forma pasada de ふる. :: Eso sería 降った.
