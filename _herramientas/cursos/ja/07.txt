@ 7 | おおきい、 ちいさい | Los adjetivos en -i
E Dos familias de adjetivos :: El japonés tiene dos tipos de adjetivos. Los primeros acaban en **い** y se llaman adjetivos en -i: **おおきい** (grande), **たかい** (caro, alto), **あたらしい** (nuevo). :: Van delante del nombre sin nada en medio: **あたらしい くるま** (coche nuevo). :: Al final de la frase se les añade **です** para ser educado: **たかい です** (es caro).
E Negar un adjetivo en -i :: Estos adjetivos se conjugan ellos mismos. Para negar, la **い** final cambia a **く** y se añade **ない**: **たかい** → **たかく ない です** (no es caro). :: Una excepción muy usada: **いい** (bueno) se niega **よく ない** (no es bueno). :: No se dice «たかい じゃ ありません»: eso es solo para nombres y para el otro tipo de adjetivos.
B Adjetivos en -i | Afirmación | Negación | Español
| おおきい です | おおきく ない です | es grande / no es grande
| たかい です | たかく ない です | es caro / no es caro
| やすい です | やすく ない です | es barato / no es barato
| いい です | よく ない です | es bueno / no es bueno
E Matizar :: **とても** = muy: **とても いい です** (es muy bueno). :: **ちょっと** = un poco: **ちょっと たかい です** (es un poco caro). :: **あまり** + negativo = no muy: **あまり たかく ない です** (no es muy caro).
W おおきい = grande | ōkii
W ちいさい = pequeño | chiisai
W やすい = barato | yasui
W あたらしい = nuevo | atarashii
W ふるい = viejo, antiguo | furui
W おもしろい = interesante, divertido | omoshiroi
W むずかしい = difícil | muzukashii
W とても = muy | totemo
W ない = no (negación de adjetivos) | nai
W たかく ない = no es caro | takaku nai
W よく ない = no es bueno | yoku nai
V Vocabulario: adjetivos en -i
D El móvil nuevo
けん: これ は わたし の あたらしい スマホ です。 = Este es mi móvil nuevo.
  > あたらしい スマホ = móvil nuevo (adjetivo delante, sin nada en medio)
まり: いい です ね。 たかい です か。 = Qué bien. ¿Es caro?
  > いい です ね = qué bien | たかい です か = ¿es caro?
けん: いいえ、 たかく ない です。 やすい です。 = No, no es caro. Es barato.
  > たかく ない です = no es caro (い → く + ない) | やすい = barato
まり: でも、 ちょっと ちいさい です ね。 = Pero es un poco pequeño, ¿no?
  > ちょっと ちいさい = un poco pequeño
けん: はい。 でも、 とても いい です。 まり さん の スマホ は？ = Sí. Pero es muy bueno. ¿Y tu móvil, Mari?
  > とても いい = muy bueno
まり: わたし の は ふるい です。 よく ない です。 = El mío es viejo. No es bueno.
  > わたし の は = el mío | ふるい = viejo | よく ない です = no es bueno (negación irregular de «いい»)
Q ¿Cómo dices «coche nuevo»?
+ あたらしい くるま :: Adjetivo + nombre, sin nada en medio.
- あたらしい の くるま :: No lleva の.
- くるま あたらしい :: El adjetivo va delante.
Q ¿Cómo niegas «たかい です»?
+ たかく ない です。 :: い → く + ない.
- たかい じゃ ありません。 :: Eso es solo para nombres y adjetivos en -na.
- たかい ない です。 :: Hay que cambiar la い por く.
Q ¿Cuál es la negación de «いい です»?
+ よく ない です。 :: Es irregular.
- いく ない です。 :: No existe.
- いい じゃ ありません。 :: No.
R この ほん は とても おもしろい です。
+ Este libro es muy interesante. :: とても = muy.
- Este libro es un poco interesante. :: Sería ちょっと.
- Este libro no es interesante. :: No es negativa.
H この くるま は ___ ない です。
+ たかく :: い → く delante de ない.
- たかい :: Hay que cambiar la い por く.
- たかな :: No existe.
H にほんご は ___ むずかしい です。 (un poco)
+ ちょっと :: Un poco.
- とても :: Muy.
- あまり :: Va con negativo.
A この かばん は あまり たかく ない です。 :: Escucha. ¿Qué significa?
+ Este bolso no es muy caro. :: あまり + negativo.
- Este bolso es muy caro. :: Es negativa.
- Este bolso es barato y pequeño. :: No.
O わたし の スマホ は あたらしい です :: Mi móvil es nuevo :: Tema + は + adjetivo + です.

@ 7 | きれい な まち | Los adjetivos en -na
E La segunda familia :: El otro tipo de adjetivos se comporta como un nombre. Se llaman adjetivos en **-na** porque llevan **な** cuando van delante de un nombre: **しずか な まち** (ciudad tranquila), **ゆうめい な こうえん** (parque famoso). :: Al final de la frase no llevan な: **この まち は しずか です** (esta ciudad es tranquila). :: Se niegan igual que los nombres: **しずか じゃ ありません** (no es tranquila).
B Adjetivos en -na | Uso | Japonés | Español
| delante de un nombre | きれい な へや | habitación bonita
| al final | きれい です | es bonita
| negación | きれい じゃ ありません | no es bonita
E Cuidado con dos que engañan :: **きれい** (bonito, limpio) y **きらい** (que no gusta) acaban en い, pero son adjetivos en **-na**: se dice **きれい な**, no «きれい へや». :: Para preguntar cómo es algo: **どんな** + nombre: **どんな まち です か** (¿qué tipo de ciudad es?).
W きれい = bonito; limpio | kirē
W しずか = tranquilo, silencioso | shizuka
W にぎやか = animado, bullicioso | nigiyaka
W べんり = práctico, cómodo | benri
W ゆうめい = famoso | yūmē
W しんせつ = amable | shinsetsu
W な = (une un adjetivo en -na con su nombre) | na
W まち = ciudad, pueblo | machi
W どんな = qué tipo de, cómo es | donna
W とおい = lejos | tōi
V Vocabulario: adjetivos en -na
D ¿Cómo es tu ciudad?
アンナ: けん さん の まち は どんな まち です か。 = ¿Cómo es tu ciudad, Ken?
  > けん さん の まち は = la ciudad de Ken (tema) | どんな まち = qué tipo de ciudad
けん: しずか な まち です。 あまり にぎやか じゃ ありません。 = Es una ciudad tranquila. No es muy animada.
  > しずか な まち = ciudad tranquila («な» delante del nombre) | にぎやか じゃ ありません = no es animada
アンナ: きれい です か。 = ¿Es bonita?
  > きれい です か = ¿es bonita? (sin «な» al final)
けん: はい、 とても きれい です。 ゆうめい な こうえん が あります。 = Sí, es muy bonita. Hay un parque famoso.
  > ゆうめい な こうえん = un parque famoso
アンナ: べんり です か。 = ¿Es práctica?
  > べんり = práctica, bien comunicada
けん: いいえ、 あまり べんり じゃ ありません。 えき が とおい です。 = No, no es muy práctica. La estación está lejos.
  > えき が とおい です = la estación está lejos («とおい» es adjetivo en -i)
Q ¿Cómo dices «habitación bonita»?
+ きれい な へや :: «きれい» es adjetivo en -na.
- きれい へや :: Aunque acabe en い, necesita な.
- きれい の へや :: No lleva の.
Q ¿Cómo niegas «しずか です»?
+ しずか じゃ ありません。 :: Como los nombres.
- しずかく ない です。 :: Eso es para adjetivos en -i.
- しずか な ありません。 :: No.
Q ¿Cuál es correcta al final de la frase?
+ この まち は にぎやか です。 :: Al final no lleva な.
- この まち は にぎやか な です。 :: «な» solo va delante de un nombre.
- この まち は にぎやか い です。 :: No.
R たなか さん は とても しんせつ です。
+ El señor Tanaka es muy amable. :: しんせつ = amable.
- El señor Tanaka es muy famoso. :: Sería ゆうめい.
- El señor Tanaka no es amable. :: No es negativa.
H とうきょう は にぎやか ___ まち です。
+ な :: Adjetivo en -na + な + nombre.
- の :: No.
- い :: No.
H ___ まち です か。 — きれい な まち です。
+ どんな :: ¿Qué tipo de…?
- どこ :: Eso es «dónde».
- だれ :: Eso es «quién».
A この スーパー は べんり じゃ ありません。 :: Escucha. ¿Qué significa?
+ Este supermercado no es práctico. :: べんり じゃ ありません.
- Este supermercado es muy práctico. :: Es negativa.
- Este supermercado no es barato. :: Sería やすく ない.
O わたし の まち は しずか です :: Mi ciudad es tranquila :: Tema + は + adjetivo en -na + です.

@ 7 | かいもの | De compras: ropa, colores y comparar
E Los colores :: Casi todos los colores básicos son adjetivos en -i: **あかい** (rojo), **あおい** (azul), **しろい** (blanco), **くろい** (negro), **きいろい** (amarillo). :: Van delante del nombre: **くろい ジャケット** (chaqueta negra). :: **の** puede sustituir a un nombre ya mencionado, como «el» en español: **あおい の** (el azul), **やすい の** (el barato).
E En la tienda :: **これ を ください** = me llevo este. :: **もっと** = más. **もっと やすい の は あります か** (¿tienen uno más barato?). :: **そして** une dos frases: «y además».
E Comparar con より :: **より** significa «que» en las comparaciones y va detrás de lo que se compara: **A は B より やすい です** (A es más barato que B). :: El adjetivo **no cambia**: no existe una forma especial para «más barato».
W ふく = ropa | fuku
W シャツ = camisa | shatsu
W ズボン = pantalón | zubon
W スカート = falda | sukāto
W くつ = zapatos | kutsu
W ぼうし = sombrero, gorro | bōshi
W ジャケット = chaqueta | jaketto
W あおい = azul | aoi
W くろい = negro | kuroi
W きいろい = amarillo | kiiroi
W もっと = más | motto
W より = que (al comparar) | yori
W そして = y, además | soshite
W あたたかい = cálido, que abriga | atatakai
V Vocabulario: ropa y colores
D En la tienda de ropa
アンナ: すみません、 この くろい ジャケット は いくら です か。 = Disculpe, ¿cuánto cuesta esta chaqueta negra?
  > この くろい ジャケット = esta chaqueta negra | いくら です か = ¿cuánto cuesta?
てんいん: 8000 えん です。 = Son 8.000 yenes.
  > 8000 えん = se lee «hassen en»
アンナ: ちょっと たかい です ね。 もっと やすい の は あります か。 = Es un poco cara. ¿Tienen una más barata?
  > ちょっと たかい = un poco cara | もっと やすい の = una más barata («の» sustituye a «chaqueta»)
てんいん: この あおい ジャケット は 5000 えん です。 = Esta chaqueta azul cuesta 5.000 yenes.
  > この あおい ジャケット = esta chaqueta azul
アンナ: あおい の は くろい の より やすい です ね。 = La azul es más barata que la negra.
  > あおい の は = la azul (tema) | くろい の より = que la negra | やすい です = es barata
てんいん: はい。 そして、 とても あたたかい です。 = Sí. Y además abriga mucho.
  > そして = y además | あたたかい = cálida
アンナ: じゃあ、 これ を ください。 = Entonces me llevo esta.
  > これ を ください = deme esta
Q ¿Cómo dices «zapatos negros»?
+ くろい くつ :: Color + nombre.
- くつ くろい :: El color va delante.
- くろい な くつ :: «くろい» es adjetivo en -i: no lleva な.
Q ¿Cómo dices «A es más barato que B»?
+ A は B より やすい です。 :: より va detrás de B.
- A より B は やすい です。 :: Eso diría que B es más barato.
- A は B やすい より です。 :: El adjetivo va al final.
Q ¿Qué significa «やすい の»?
+ El barato. :: «の» sustituye al nombre.
- Lo barato de. :: No.
- Barato, ¿verdad? :: Eso sería やすい です ね.
R もっと おおきい の は あります か。
+ ¿Tienen uno más grande? :: もっと = más.
- ¿Tienen uno más pequeño? :: Sería ちいさい.
- ¿Es este el más grande? :: No.
H この シャツ は あの シャツ ___ たかい です。
+ より :: «Que» al comparar.
- と :: No.
- を :: No.
H この あかい スカート ___ ください。
+ を :: Cosa + を ください.
- は :: No.
- が :: No.
A この くつ は 6000 えん です。 :: Escucha. ¿Cuánto cuestan los zapatos?
+ 6.000 yenes. :: ろくせん えん.
- 600 yenes. :: Sería ろっぴゃく.
- 60.000 yenes. :: Sería ろくまん.
O あおい の は くろい の より やすい です :: El azul es más barato que el negro :: A + は + B + より + adjetivo + です.
