@ 17 | できる と すき (1) | La forma de poder
I Hoy aprenderás a decir lo que sabes hacer y lo que puedes hacer. En japonés se hace con una forma propia del verbo, muy regular.
E La forma de poder :: Para decir que **puedes** hacer algo, los verbos del grupo 1 cambian la última letra a **e** y añaden **る**: **はなす** → **はなせる** (poder hablar), **かく** → **かける** (poder escribir). :: Los del grupo 2 cambian **る** por **られる**: **たべる** → **たべられる** (poder comer). Con ます: **はなせます**, **たべられます**.
E Los irregulares :: **する** → **できる** (poder hacer). **くる** → **こられる** (poder venir). :: Lo que se puede hacer lleva la partícula **が**: **にほんご が はなせます** (puedo hablar japonés). Recuerda que es **が**, no **を**.
B La forma de poder | Verbo | Poder | Ejemplo
| はなす (hablar) | はなせる | にほんご が はなせます
| かく (escribir) | かける | てがみ を かけます
| およぐ (nadar) | およげる | およげません (no sé nadar)
| たべる (comer) | たべられる | すし を たべられます
| する (hacer) | できる | にほんご が できます
W はなせます = puedo hablar | hanasemasu | Es la forma de poder de はなす.
W かけます = puedo escribir | kakemasu | Es la forma de poder de かく.
W およげません = no puedo nadar | oyogemasen | Es la forma de poder de およぐ.
W たべられます = puedo comer | taberaremasu | Es la forma de poder de たべる.
W こられません = no puedo venir | korarenemasen | Es la forma de poder de くる.
W てがみ = carta (de papel) | tegami
V Vocabulario: poder
T Lo que sé hacer
- わたし は にほんご が はなせます。 = Puedo hablar japonés.
  > にほんご が はなせます = puedo hablar japonés
- わたし は すし を たべられます。 = Puedo comer sushi.
  > すし を たべられます = puedo comer sushi
- わたし は にほんご で てがみ を かけます。 = Puedo escribir cartas en japonés.
  > てがみ を かけます = puedo escribir cartas
- わたし は あした こられません。 = Mañana no puedo venir.
  > こられません = no puedo venir
- わたし は およげません。 = No sé nadar.
  > およげません = no puedo nadar
Q ¿Qué significa «わたし は にほんご が はなせます»?
+ Puedo hablar japonés. :: はなせます = puedo hablar.
- Quiero hablar japonés. :: Eso sería 〜たい.
- Hablé japonés ayer. :: Eso sería el pasado.
Q ¿Cuál es la forma de poder de «たべる»?
+ たべられます :: Del grupo 2: たべる → たべられる.
- たべます :: Eso es «como».
- たべたい :: Eso es «quiero comer».
H わたし は すし を ___ 。 :: Puedo comer sushi.
+ たべられます :: Forma de poder.
- たべます :: Eso sería «como».
- たべたい :: Eso sería «quiero comer».
H わたし は あした ___ 。 :: Mañana no puedo venir.
+ こられません :: Forma de poder en negativo.
- きません :: Eso sería «no vengo».
- きたい :: Eso sería «quiero venir».
R わたし は にほんご で てがみ を かけます。 :: Traduce la frase.
+ Puedo escribir cartas en japonés. :: かけます = puedo escribir.
- Escribo cartas en japonés siempre. :: Eso sería un hábito.
- Quiero escribir cartas en japonés. :: Eso sería 〜たい.
A わたし は およげません。 :: ¿Qué dice?
+ No sé nadar. :: No puede nadar.
- Nado todos los días. :: Eso sería un hábito.
- Quiero nadar. :: Eso sería 〜たい.
O わたし は にほんご が はなせます :: Puedo hablar japonés. :: が marca lo que se puede hacer.
Q ¿Cómo se dice «puedo nadar»?
+ およげます :: Forma de poder de およぐ.
- およぎます :: Eso es «nado».
- およぎたい :: Eso es «quiero nadar».

@ 17 | できる と すき (2) | Poder hacer y gustar hacer
I Ahora, dos frases para hablar de tus habilidades y de lo que te gusta hacer. Serán muy útiles para presentarte.
E 〜ことができます: poder hacer algo :: Otra forma de decir que puedes hacer algo, más formal: verbo en forma de diccionario + **こと が できます**: **にほんご を はなす こと が できます** (puedo hablar japonés). :: **こと** significa «cosa, hecho» y aquí sirve para convertir el verbo en nombre.
E 〜の が すき です: me gusta hacer :: Para decir lo que te gusta hacer, verbo en forma de diccionario + **の が すき です**: **うた を うたう の が すき です** (me gusta cantar). :: Con **の** conviertes el verbo en nombre y le das a **が** la función de sujeto.
E 〜の が じょうず です: ser bueno en :: Para decir que lo haces bien, usa el mismo molde con **じょうず**: **りょうり が じょうず です** (soy bueno cocinando). :: Ojo: **じょうず** es un adjetivo en -na: se dice **じょうず です**, no **じょうずい**.
B Poder, gustar y dar | Forma | Significa | Ejemplo
| 〜こと が できます | poder hacer algo | はなす こと が できます
| 〜の が すき です | gustar hacer algo | うたう の が すき です
| 〜の が じょうず です | ser bueno haciendo algo | りょうり が じょうず です
W はなす = hablar (forma de diccionario) | hanasu
W およぐ = nadar (forma de diccionario) | oyogu
W うたう = cantar (forma de diccionario) | utau
W うた = canción | uta
W うたえます = puedo cantar | utaemasu | Es la forma de poder de うたう.
V Vocabulario: poder y gustar
D ¿Qué te gusta hacer?
やまだ: けんじ さん は なに が すき です か。 = Ken, ¿qué te gusta?
  > なに が すき です か = ¿qué te gusta?
けんじ: わたし は うた を うたう の が すき です。 = Me gusta cantar canciones.
  > うたう の が すき です = me gusta cantar
やまだ: すごい です ね。 にほんご の うた も うたえます か。 = ¡Qué bien! ¿Puedes cantar canciones en japonés también?
  > うたえます か = ¿puedes cantar?
けんじ: はい、 にほんご を はなす こと が できます。 = Sí, puedo hablar japonés.
  > はなす こと が できます = puedo hablar
Q ¿Qué significa «わたし は およぐ の が すき です»?
+ Me gusta nadar. :: の が すき です = me gusta hacer.
- Nado todos los días. :: Eso sería un hábito.
- Nado mejor que tú. :: Eso no aparece en la frase.
Q ¿Qué forma usas para decir «puedo hacer algo» (formal)?
+ 〜こと が できます :: Verbo en diccionario + こと が できます.
- 〜の が じょうず です :: Eso es «soy bueno».
- 〜たい :: Eso es «quiero».
H わたし は にほんご を はなす ___ が できます。 :: Puedo hablar japonés.
+ こと :: Convierte el verbo en nombre.
- の :: Con の se dice «me gusta», no «puedo».
- ところ :: Eso sería «el momento de».
H わたし は うた を うたう の が ___ です。 :: Me gusta cantar.
+ すき :: Gustar hacer algo.
- じょうず :: Eso sería «soy bueno cantando».
- きらい :: Eso sería «no me gusta nada».
R わたし は りょうり が じょうず です。 :: Traduce la frase.
+ Soy bueno cocinando. :: じょうず = hábil, bueno.
- Me gusta cocinar. :: Eso sería すき.
- Cocino mal. :: Eso sería lo contrario.
A わたし は およぐ の が すき です。 :: ¿Qué le gusta?
+ Le gusta nadar. :: すき = gusto.
- Le gusta comer. :: No aparece en la frase.
- Le gusta leer. :: No aparece en la frase.
O はなす こと が できます :: Puedo hablar. :: こと が できます = poder hacer algo.
Q ¿Cómo se dice «me gusta cantar»?
+ うたう の が すき です :: の が すき です.
- うたう こと が すき です :: Eso no se usa así.
- うたえます :: Eso es «puedo cantar».

@ 17 | できる と すき (3) | Cambios y hábitos
I Por último, cómo decir que algo cambia con el tiempo, o que te esfuerzas en cambiar algo. Así describes tu progreso.
E 〜ように なりました: llegar a ser capaz :: Para decir que has llegado a hacer algo, verbo en forma de diccionario o de poder + **ように なりました**: **はなせる ように なりました** (llegué a poder hablar). :: Describe un cambio que ya ha ocurrido.
E 〜ように して います: procurar hacer algo :: Para decir que te esfuerzas por hacer algo como hábito: verbo en forma de diccionario + **ように して います**: **はやく おきる ように して います** (procuro levantarme pronto). :: Describe un esfuerzo que se mantiene en el tiempo.
B Cambio y esfuerzo | Forma | Significa | Ejemplo
| 〜ように なりました | ha llegado a | はなせる ように なりました
| 〜ように して います | procuro, me esfuerzo | はやく おきる ように して います
W ように = para que; de forma que (con なりました) | yō ni
W なりました = llegó a ser; se ha convertido | narimashita
W ようにしています = procuro; me esfuerzo por | yō ni shite imasu
W おきる = levantarse (forma de diccionario) | okiru
W たべる = comer (forma de diccionario) | taberu
W はなせる = poder hablar (forma de poder de はなす) | hanaseru
V Vocabulario: cambios y hábitos
T Mi progreso
- まいにち べんきょう して、 にほんご が はなせる ように なりました。 = Estudiando cada día, llegué a poder hablar japonés.
  > はなせる ように なりました = llegué a poder hablar
- まいにち はやく おきる ように して います。 = Procuro levantarme temprano cada día.
  > おきる ように して います = procuro levantarme
- やさい を たべる ように なりました。 = He llegado a comer verdura.
  > たべる ように なりました = he llegado a comer
Q ¿Qué significa «まいにち べんきょう して、 にほんご が はなせる ように なりました»?
+ Estudiando cada día, llegué a poder hablar japonés. :: ように なりました = un cambio.
- Estudio cada día, pero no hablo japonés. :: Eso es lo contrario.
- Hablo japonés desde niño. :: No aparece en la frase.
Q ¿Qué expresa «ようにしています»?
+ Me esfuerzo por hacer algo, como hábito. :: ように して います = procurar.
- Quiero hacer algo. :: Eso sería 〜たい.
- Algo ya terminó. :: Eso sería el pasado.
H まいにち はやく おきる ___ 。 :: Procuro levantarme temprano cada día.
+ ようにしています :: Esfuerzo como hábito.
- ようになりました :: Eso sería un cambio ya ocurrido.
- ことができます :: Eso sería «puedo».
H やさい を たべる ___ なりました。 :: He llegado a comer verdura.
+ ように :: Cambio que ya ocurrió.
- ことが :: Eso sería poder.
- ために :: Eso sería «para».
R やさい を たべる ように なりました。 :: Traduce la frase.
+ He llegado a comer verdura. :: ように なりました = cambio.
- Comí verdura ayer. :: Eso sería el pasado.
- Quiero comer verdura. :: Eso sería 〜たい.
A まいにち べんきょう して、 にほんご が はなせる ように なりました。 :: ¿Qué cuenta?
+ Que ha llegado a poder hablar japonés. :: Un cambio.
- Que ha dejado el japonés. :: Eso es lo contrario.
- Que no estudia. :: Eso es lo contrario.
O はなせる ように なりました :: Llegué a poder hablar. :: ように なりました = un cambio.
Q ¿Qué expresa «ように なりました»?
+ Un cambio que ya ha pasado. :: Llegar a ser capaz.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
