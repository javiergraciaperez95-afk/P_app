@ 31 | けっか と ついで (1) | Al final de: あげく
I Empezamos el nivel B2, que en Japón se llama JLPT N2. Hoy aprendes a hablar del final de un proceso largo: lo que pasó después de mucho pensar, discutir o dudar.
E 〜あげく: al final de todo :: Para decir que, después de mucho de algo, se llegó a un resultado, normalmente no deseado: verbo en forma た + **あげく**: **なんども はなしあった あげく、 けっきょく わかれました** (después de hablarlo muchas veces, al final nos separamos). :: Con nombres se usa **の あげく**: **議論 の あげく** (tras la discusión).
E El tono de «después de tanto» :: **あげく** casi siempre se refiere a algo cansado o negativo. :: Se usa en noticias y en relatos: suena a que el esfuerzo no dio buen resultado.
B Final de un proceso | Forma | Significa | Ejemplo
| 〜た あげく | después de mucho | はなしあった あげく
| 〜の あげく | tras (un proceso) | けんか の あげく
W あげく = al final de (tras un proceso largo) | ageku
W なんども = muchas veces | nando mo
W はなしあった = (forma た de はなしあう) hablaron entre sí | hanashiatta
W けっきょく = al final; finalmente | kekkyoku
W わかれました = nos separamos; me separé | wakaremashita
W さんざん = mucho, de forma intensa | sanzan
W まよった = dudé (de まよう) | mayotta
W やめた = lo dejé (de やめる) | yameta
W かんがえた = pensé (de かんがえる) | kangaeta
V Vocabulario: al final de
D Una decisión difícil
けんじ: あの しごと、 やめた の？ = ¿Dejaste ese trabajo?
  > やめた の = ¿lo dejaste?
まり: うん。 なんども かんがえた あげく、 やめた の。 = Sí. Después de pensarlo muchas veces, lo dejé.
  > かんがえた あげく = después de pensarlo | やめた の = lo dejé
T Tras mucho pensar
- なんども はなしあった あげく、 けっきょく わかれました。 = Después de hablarlo muchas veces, al final nos separamos.
  > はなしあった あげく = después de hablarlo | けっきょく わかれました = al final nos separamos
- さんざん まよった あげく、 いえ を かいました。 = Después de dudar mucho, al final compré una casa.
  > さんざん まよった あげく = después de dudar mucho | いえ を かいました = compré una casa
Q ¿Qué significa «なんども はなしあった あげく、 けっきょく わかれました»?
+ Después de hablarlo muchas veces, al final nos separamos. :: あげく = al final de un proceso.
- Hablamos una vez y nos separamos enseguida. :: Eso no es un proceso largo.
- Nos separamos antes de hablar. :: Eso invierte el orden.
Q ¿Qué expresa «〜あげく»?
+ El resultado final de un proceso largo. :: Suele ser negativo.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H なんども はなしあった ___ 、 けっきょく わかれました。 :: Al final nos separamos.
+ あげく :: Final de un proceso.
- ばかりに :: Eso sería «por culpa de».
- ながら :: Eso sería «mientras».
H さんざん まよった ___ 、 いえ を かいました。 :: Después de dudar mucho, compré una casa.
+ あげく :: Resultado final.
- ために :: Eso sería «para».
- ように :: Eso sería «para que».
R さんざん まよった あげく、 いえ を かいました。 :: Traduce la frase.
+ After much hesitation, I finally bought a house. :: あげく = al final de.
- I bought a house without hesitating. :: Eso no es un proceso.
- I hesitated, so I didn't buy a house. :: Eso es lo contrario.
A うん。 なんども かんがえた あげく、 やめた の。 :: ¿Qué cuenta?
+ Que lo dejó después de pensarlo mucho. :: あげく = resultado final.
- Que lo dejó sin pensarlo. :: Eso es lo contrario.
- Que no lo dejó. :: Eso es lo contrario.
O けっきょく わかれました :: Al final nos separamos. :: けっきょく = al final.
Q ¿Qué significa «さんざん»?
+ Mucho, de forma intensa. :: Refuerza el proceso.
- Poco. :: Eso es lo contrario.
- Pronto. :: No aparece.

@ 31 | けっか と ついで (2) | Por culpa de y cada vez más: ばかりに y ばかりだ
I Ahora dos formas con la misma palabra que aprendiste en 040, pero con otros sentidos. Una expresa un arrepentimiento y la otra una tendencia.
E 〜ばかりに: por culpa de (arrepentimiento) :: Para decir que una causa, normalmente una pequeña, provocó un resultado negativo: verbo en forma た + **ばかり に**: **かさ を わすれた ばかりに、 ぬれて しまいました** (por haber olvidado el paraguas, me mojé). :: Expresa que lo lamentas.
E 〜ばかりだ: cada vez más :: Para decir que algo sigue en aumento o en descenso: verbo en forma normal + **ばかり だ**: **ねだん は あがる ばかりだ** (los precios no paran de subir). :: No es lo mismo que **〜た ばかり** (acabo de).
B Causa lamentada y tendencia | Forma | Significa | Ejemplo
| 〜た ばかり に | por culpa de | わすれた ばかり に
| 〜ばかりだ | no para de, cada vez más | あがる ばかりだ
W ばかりに = por culpa de (arrepentimiento) | bakari ni
W ばかりだ = cada vez más; no para de | bakari da
W わすれた = olvidé (forma た de わすれる) | wasureta
W ぬれて = mojado; mojándose (de ぬれる) | nurete
W ねだん = precio | nedan
W あがる = subir; aumentar | agaru
V Vocabulario: por culpa de y cada vez más
D La lluvia y el paraguas
やまだ: どうして ぬれて いる の？ = ¿Por qué estás mojado?
  > ぬれて いる = estás mojado
けんじ: かさ を わすれた ばかりに、 ぬれて しまいました。 = Por haber olvidado el paraguas, me mojé.
  > わすれた ばかりに = por haber olvidado
T Precios y descuidos
- かさ を わすれた ばかりに、 ぬれて しまいました。 = Por haber olvidado el paraguas, me mojé.
  > わすれた ばかりに = por haber olvidado
- ねだん は あがる ばかりだ。 = Los precios no paran de subir.
  > あがる ばかりだ = no paran de subir
Q ¿Qué significa «かさ を わすれた ばかりに、 ぬれて しまいました»?
+ Por haber olvidado el paraguas, me mojé. :: ばかりに = causa lamentada.
- Aunque olvidé el paraguas, no me mojé. :: Eso es lo contrario.
- Olvidé el paraguas para mojarme. :: Eso invierte el sentido.
Q ¿Qué expresa «〜ばかりだ»?
+ Una tendencia que sigue en aumento. :: Cada vez más.
- Algo que acaba de pasar. :: Eso sería 〜た ばかり.
- Algo que pasó una sola vez. :: No es cierto.
H かさ を わすれた ___ 、 ぬれて しまいました。 :: Por olvidar el paraguas, me mojé.
+ ばかりに :: Causa lamentada.
- ために :: Eso sería «para».
- ながら :: Eso sería «mientras».
H ねだん は あがる ___ 。 :: Los precios no paran de subir.
+ ばかりだ :: Tendencia.
- ばかりか :: Eso sería «no solo... también».
- ことは ない :: Eso sería «no hace falta».
R ねだん は あがる ばかりだ。 :: Traduce la frase.
+ Los precios no paran de subir. :: ばかりだ = tendencia.
- Los precios han bajado. :: Eso es lo contrario.
- Los precios ya no suben. :: Eso es lo contrario.
A かさ を わすれた ばかりに、 ぬれて しまいました。 :: ¿Qué cuenta?
+ Que se mojó porque olvidó el paraguas. :: ばかりに = causa lamentada.
- Que se mojó a propósito. :: Eso es lo contrario.
- Que no se mojó. :: Eso es lo contrario.
O あがる ばかりだ :: No para de subir. :: ばかりだ = tendencia.
Q ¿Cuál es el sentido de «ばかりに»?
+ Lamentar una causa que lleva a algo malo. :: Expresa arrepentimiento.
- Una finalidad. :: Eso sería ために.
- Una condición. :: Eso sería たら.

@ 31 | けっか と ついで (3) | Como era de esperar: だけあって, だけに y だけのことはある
I Por último, tres expresiones para decir que algo es lógico o merecido: por ser lo que es, algo sale como era de esperar, o el esfuerzo tiene premio.
E 〜だけあって: como era de esperar :: Para decir que el resultado es lógico porque algo tiene esa característica: nombre + **だけ あって** / frase + **だけ あって**: **プロ だけあって、 じょうず です** (como es profesional, es muy bueno). :: Es un elogio.
E 〜だけに: precisamente porque :: Para decir que algo es así precisamente por una característica: **ゆうめい な だけ に、 ひと が おおい です** (precisamente porque es famoso, hay mucha gente). :: Va con な después de adjetivos en -na.
E 〜だけのことはある: no es de extrañar :: Para decir que el esfuerzo tuvo el resultado merecido: frase + **だけ の こと は ある**: **あれ だけ れんしゅう した だけ の こと は ある** (con todo lo que practicó, no es de extrañar que lo haga bien). :: Es un elogio al esfuerzo.
B Lógico o merecido | Forma | Significa | Ejemplo
| 〜だけあって | como era de esperar | プロ だけあって
| 〜だけに | precisamente porque | ゆうめい な だけに
| 〜だけのことはある | no es de extrañar | れんしゅう した だけのことはある
W だけあって = como era de esperar, dado que | dake atte
W だけに = precisamente porque | dake ni
W だけのことはある = no es de extrañar; lo merece | dake no koto wa aru
W プロ = profesional | puro
W れんしゅう = práctica; entrenamiento | renshū
W ピアニスト = pianista | pianisuto
V Vocabulario: lógico y merecido
D Un pianista
けんじ: あの ピアニスト、 すごい です ね。 = Ese pianista es increíble, ¿verdad?
  > ピアニスト = pianista
まり: まいにち れんしゅう した だけのことはある です ね。 = Practica todos los días, no es de extrañar que sea tan bueno, ¿verdad?
  > れんしゅう した だけのことはある = no es de extrañar
T Tres casos
- プロ だけあって、 じょうず です。 = Como es profesional, es muy bueno.
  > プロ だけあって = como es profesional
- ゆうめい な だけに、 ひと が おおい です。 = Precisamente por ser famoso, hay mucha gente.
  > ゆうめい な だけに = precisamente por ser famoso
- あれ だけ れんしゅう した だけのことはある。 = Con todo lo que practicó, no es de extrañar que lo haga bien.
  > れんしゅう した だけのことはある = no es de extrañar
Q ¿Qué significa «プロ だけあって、 じょうず です»?
+ Como es profesional, es muy bueno. :: だけあって = como era de esperar.
- Es profesional, pero no es bueno. :: Eso es lo contrario.
- Es bueno, así que no es profesional. :: Eso invierte la lógica.
Q ¿Qué expresa «〜だけのことはある»?
+ Que el esfuerzo tiene un resultado merecido. :: No es de extrañar.
- Que no es suficiente. :: Eso es lo contrario.
- Que es imposible. :: Eso es lo contrario.
H ゆうめい な ___ 、 ひと が おおい です。 :: Precisamente por ser famoso, hay mucha gente.
+ だけに :: Precisamente porque.
- ために :: Eso sería «para».
- ながら :: Eso sería «mientras».
H あれ だけ れんしゅう した ___ 。 :: No es de extrañar que lo haga bien.
+ だけのことはある :: Lo merece.
- ばかりに :: Eso sería «por culpa de».
- だけでなく :: Eso sería «no solo».
R プロ だけあって、 じょうず です。 :: Traduce la frase.
+ As a professional, he's very good. :: だけあって = como era de esperar.
- Being a professional, he's not good. :: Eso es lo contrario.
- He's good, but not professional. :: Eso invierte la lógica.
A あの ピアニスト、 すごい です ね。 :: ¿Qué opina?
+ Que el pianista es increíble. :: Admiración.
- Que el pianista es malo. :: Eso es lo contrario.
- Que el pianista no toca. :: No aparece.
O ゆうめい な だけに :: Precisamente por ser famoso. :: だけに = precisamente porque.
Q ¿Cuál es el sentido de «だけに»?
+ Precisamente porque... :: Explica por qué algo es así.
- Solo por... :: Eso sería だけ.
- Aunque... :: Eso sería ても.
