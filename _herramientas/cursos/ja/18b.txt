@ 18 | てみる と かどうか と ようと思う | Probar, si o no, e intención de...
I Hoy aprendes tres formas de hablar de intentos y dudas: probar algo, expresar que no sabes si algo ocurre y decir una intención que todavía no se ha cumplido.
E 〜てみる: probar a hacer algo :: Verbo en forma て + **みる**: **この りょうり を たべて みて ください** (pruebe este plato, por favor). :: Sirve para probar algo y ver qué pasa.
E 〜かどうか: si (una duda) :: Oración en forma normal + **かどうか**: **あした いく かどうか わかりません** (no sé si iré mañana). :: Expresa una duda sobre algo que todavía no se sabe.
E 〜ようと思う: tener intención de :: Verbo en forma よう (いく → いこう) + **と おもいます**: **にほん へ いこう と おもいます** (tengo intención de ir a Japón). :: Expresa una intención que aún no se ha cumplido.
W かどうか = si (duda) | ka dō ka | kanji: かどうか
W いこう = ir (forma de intención: vamos / voy a ir) | ikō | kanji: 行こう
W ためし = prueba; intento | tameshi | kanji: 試し
W ためしに = a modo de prueba | tameshi ni | kanji: 試しに
W ぜひ = sin falta; a toda costa | zehi | kanji: 是非
W やっぱり = después de todo; como esperaba | yappari
V Vocabulario: probar, dudar e intención
T Probar y decidir
- この りょうり を たべて みて ください。 = Pruebe este plato, por favor.
- あした いく かどうか わかりません。 = No sé si iré mañana.
- ためしに、 つくって みます。 = A modo de prueba, lo haré.
- わたし は にほん へ いこう と おもいます。 = Tengo intención de ir a Japón.
- やっぱり いく こと に しました。 = Después de todo, decidí ir.
- ぜひ きて ください。 = Venga sin falta, por favor.
Q ¿Qué significa «この りょうり を たべて みて ください»?
+ Pruebe este plato, por favor. :: てみる = probar a hacer algo.
- Coma este plato siempre. :: Eso no es la idea de probar.
- Este plato no se come. :: Eso es lo contrario.
Q ¿Qué expresa «〜かどうか»?
+ Una duda: si algo ocurre o no. :: Expresa incertidumbre.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería たい.
H あした いく ___ わかりません。 :: No sé si iré mañana.
+ かどうか :: Si (duda).
- ために :: Para.
- ながら :: Mientras.
H わたし は にほん へ ___ と おもいます。 :: Tengo intención de ir a Japón.
+ いこう :: Forma de intención de いく.
- いった :: Eso sería fui.
- いって :: Eso sería forma て.
R ぜひ きて ください。 :: Traduce la frase.
+ Venga sin falta, por favor. :: ぜひ = sin falta.
- Venga si puede. :: Eso no es ぜひ.
- No venga, por favor. :: Eso es lo contrario.
A ためしに、 つくって みます。 :: ¿Qué hace?
+ Lo prueba (lo hace a modo de prueba). :: てみます = probar.
- Lo compra. :: Eso no aparece.
- Lo olvida. :: Eso no aparece.
A わたし は にほん へ いこう と おもいます。 :: ¿Qué piensa hacer?
+ Tiene intención de ir a Japón. :: よう と おもいます = intención.
- Ya fue a Japón. :: Eso sería el pasado.
- No irá nunca. :: Eso es lo contrario.
HA あした いく ___ わかりません。 :: Duda sobre si irá mañana.
+ かどうか :: Si.
- まで :: Hasta.
- から :: Porque.
O やっぱり いく こと に しました :: Después de todo, decidí ir. :: やっぱり = como esperaba.
