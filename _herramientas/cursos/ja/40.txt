@ 40 | おわり の はなし (1) | En torno a: をめぐって
I Llegamos al último capítulo del nivel B2. Hoy aprendes a hablar de un tema de debate o de conflicto: «en torno a», «sobre» algo que genera opiniones distintas.
E 〜をめぐって: en torno a (un debate o conflicto) :: Para decir que una discusión o un problema gira alrededor de algo: sustantivo + **を めぐって**: **その もんだい を めぐって、 はげしい ぎろん が あります** (en torno a ese problema hay un debate intenso). :: Se usa mucho en noticias y en análisis.
E Sentido de polémica :: Expresa que hay varias opiniones y no un acuerdo. :: Por eso suele ir con palabras como はげしい (intenso) o ぎろん (debate).
B Tema de debate | Forma | Significa | Ejemplo
| 〜を めぐって | en torno a (debate) | その もんだい を めぐって
W めぐって = en torno a; sobre (un tema de debate) | meguatte
W はげしい = intenso; violento | hageshii
W ぎろん = debate; discusión | giron
W いろいろ = varios; diversos | iroiro
V Vocabulario: en torno a
D Un tema de debate
けんじ: その もんだい、 どう です か。 = ¿Qué tal ese problema?
  > その もんだい = ese problema
まり: その もんだい を めぐって、 はげしい ぎろん が あります。 = En torno a ese problema hay un debate intenso.
  > その もんだい を めぐって = en torno a ese problema
T Debates
- その もんだい を めぐって、 はげしい ぎろん が あります。 = En torno a ese problema hay un debate intenso.
  > その もんだい を めぐって = en torno a ese problema
- おかね を めぐって、 いろいろ な いけん が あります。 = En torno al dinero hay muchas opiniones.
  > おかね を めぐって = en torno al dinero
Q ¿Qué significa «その もんだい を めぐって、 はげしい ぎろん が あります»?
+ En torno a ese problema hay un debate intenso. :: めぐって = en torno a.
- Ese problema ya no tiene debate. :: Eso es lo contrario.
- El debate empezó después del problema. :: Eso invierte el sentido.
Q ¿Qué expresa «〜をめぐって»?
+ Un debate o conflicto alrededor de algo. :: Polémica.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H その もんだい を ___ 、 はげしい ぎろん が あります。 :: En torno a ese problema...
+ めぐって :: Alrededor de un tema.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H おかね を ___ 、 いろいろ な いけん が あります。 :: En torno al dinero...
+ めぐって :: Alrededor de un tema.
- まで :: Eso sería hasta.
- ばかり :: Eso sería solo.
R その もんだい を めぐって、 はげしい ぎろん が あります。 :: Traduce la frase.
+ There is an intense debate about that issue. :: めぐって = en torno a.
- That issue has no debate anymore. :: Eso es lo contrario.
- The debate started after the issue. :: Eso invierte el sentido.
A まり: その もんだい を めぐって、 はげしい ぎろん が あります。 :: ¿Qué cuenta?
+ Que hay mucha polémica en torno al tema. :: Debate.
- Que no hay polémica. :: Eso es lo contrario.
- Que el tema está resuelto. :: Eso es lo contrario.
O めぐって はげしい ぎろん :: Un debate intenso sobre el tema. :: めぐって = en torno a.
Q ¿Qué tipo de tema suele ir con をめぐって?
+ Un tema controvertido. :: Con opiniones distintas.
- Un tema pacífico y sin debate. :: Eso es lo contrario.
- Un tema de cocina. :: No suele ser así.

@ 40 | おわり の はなし (2) | En cuanto a: にかけては y を経て
I Ahora dos expresiones para hablar de la especialidad de alguien y de un proceso que se completa paso a paso. Son muy útiles para presentaciones y currículos.
E 〜にかけては: en cuanto a (lo que se refiere a) :: Para decir en qué área alguien es especialmente bueno: sustantivo + **にかけては**: **にほんご にかけては、 だれ に も まけない** (en cuanto a japonés, no pierdo ante nadie). :: Es un elogio seguro de uno mismo.
E 〜を経て: tras pasar por :: Para decir que algo llega a su final después de pasar por varias etapas: sustantivo + **を へて**: **いくつ か の だんかい を へて、 かんせい しました** (tras varias etapas, se completó). :: Es formal y se usa en la historia y en los procesos.
B Especialidad y proceso | Forma | Significa | Ejemplo
| 〜にかけては | en cuanto a | にほんご にかけては
| 〜を経て | tras pasar por | だんかい を へて
W にかけては = en cuanto a (lo que se refiere a) | ni kakete wa
W まけない = no perder; no ser derrotado | makenai
W だんかい = etapa; fase | dankai
W へて = (forma て de へる) pasando por | hete
W かんせい = finalización; terminación | kansei
V Vocabulario: en cuanto a y tras pasar por
D Una presentación
まり: にほんご にかけては、 だれ に も まけない です。 = En cuanto a japonés, no pierdo ante nadie.
  > にほんご にかけては = en cuanto a japonés
けんじ: いくつ か の だんかい を へて、 かんせい しました。 = Tras varias etapas, se completó.
  > いくつ か の だんかい を へて = tras varias etapas
T Especialidades y procesos
- にほんご にかけては、 だれ に も まけない です。 = En cuanto a japonés, no pierdo ante nadie.
  > にほんご にかけては = en cuanto a japonés
- いくつ か の だんかい を へて、 かんせい しました。 = Tras varias etapas, se completó.
  > いくつ か の だんかい を へて = tras varias etapas
Q ¿Qué significa «にほんご にかけては、 だれ に も まけない です»?
+ En cuanto a japonés, no pierdo ante nadie. :: にかけては = en cuanto a.
- En japonés pierdo ante todos. :: Eso es lo contrario.
- Nadie sabe japonés. :: No aparece.
Q ¿Qué expresa «〜を経て»?
+ Un proceso que pasa por etapas. :: Tras.
- Un deseo. :: Eso sería 〜たい.
- Una orden. :: Eso sería 〜て ください.
H にほんご ___ 、 だれ に も まけない です。 :: En cuanto a japonés, no pierdo ante nadie.
+ にかけては :: En cuanto a.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H いくつ か の だんかい ___ 、 かんせい しました。 :: Tras varias etapas...
+ を へて :: Tras pasar por.
- まで :: Eso sería hasta.
- ばかり :: Eso sería solo.
R にほんご にかけては、 だれ に も まけない です。 :: Traduce la frase.
+ When it comes to Japanese, I don't lose to anyone. :: にかけては = en cuanto a.
- In Japanese, I lose to everyone. :: Eso es lo contrario.
- Nobody knows Japanese. :: No aparece.
A いくつ か の だんかい を へて、 かんせい しました。 :: ¿Qué cuenta?
+ Que se completó tras varias etapas. :: を へて = tras.
- Que se detuvo en la primera etapa. :: Eso es lo contrario.
- Que no se completó. :: Eso es lo contrario.
O だんかい を へて :: Tras pasar por las etapas. :: を へて = tras.
Q ¿Qué expresa «〜にかけては»?
+ Destacar en un área concreta. :: En cuanto a.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.

@ 40 | おわり の はなし (3) | Contra lo esperado: に反して
I Por último, una forma para decir que algo sale al revés de lo que se esperaba. Es la expresión de un final con sorpresa, muy típica de las noticias deportivas y de las historias.
E 〜に反して: contrario a lo esperado :: Para decir que el resultado es lo contrario de lo que se pensaba: sustantivo + **に はんして**: **よそう に はんして、 かちました** (contra todo pronóstico, ganó). :: Va con verbos como はんする (ir en contra).
E Sorpresa del resultado :: Se usa para resaltar un resultado inesperado. :: Suena a noticia o a relato dramático.
B Contra lo esperado | Forma | Significa | Ejemplo
| 〜に反して | contra lo esperado | よそう に はんして
W よそう = previsión; pronóstico; expectativa | yosō
W ほか = otro; aparte; además | hoka
W さんせい = acuerdo; estar de acuerdo | sansei
W はんして = (forma て de はんする) yendo en contra de | hanshite
W かちました = gané; ganó (de かつ) | kachimashita
W しあい = partido; competición | shiai
W けっか = resultado | kekka
V Vocabulario: contra lo esperado
D Un partido
けんじ: しあい の けっか は どう でした か。 = ¿Cómo fue el resultado del partido?
  > しあい の けっか = el resultado del partido
まり: よそう に はんして、 かちました。 = Contra todo pronóstico, ganó.
  > よそう に はんして = contra todo pronóstico
T Resultados
- よそう に はんして、 かちました。 = Contra todo pronóstico, ganó.
  > よそう に はんして = contra todo pronóstico
- ほか の ひと の いけん に はんして、 わたし は さんせい しました。 = Contra la opinión de los demás, yo estuve de acuerdo.
  > ほか の ひと の いけん に はんして = contra la opinión de los demás
Q ¿Qué significa «よそう に はんして、 かちました»?
+ Contra todo pronóstico, ganó. :: に反して = contrario a lo esperado.
- Según el pronóstico, ganó. :: Eso sería lo esperado.
- Perdió, como se esperaba. :: Eso es lo contrario.
Q ¿Qué expresa «〜に反して»?
+ Algo contrario a lo que se esperaba. :: Sorpresa.
- Una causa. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H よそう ___ 、 かちました。 :: Contra todo pronóstico, ganó.
+ に はんして :: Contrario.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H ほか の ひと の いけん ___ 、 わたし は さんせい しました。 :: Contra la opinión de los demás...
+ に はんして :: Contrario.
- まで :: Eso sería hasta.
- ばかり :: Eso sería solo.
R よそう に はんして、 かちました。 :: Traduce la frase.
+ Contrary to all predictions, he won. :: に反して = contrario a lo esperado.
- As predicted, he won. :: Eso es lo esperado.
- He lost, as predicted. :: Eso es lo contrario.
A まり: よそう に はんして、 かちました。 :: ¿Qué informa?
+ Que ganó contra lo esperado. :: Sorpresa.
- Que perdió. :: Eso es lo contrario.
- Que no hubo partido. :: No aparece.
O よそう に はんして :: Contra todo pronóstico. :: に反して = contrario.
Q ¿Qué idea expresa «はんして»?
+ Ir en contra de algo. :: Lo contrario.
- Ir a favor de algo. :: Eso es lo contrario.
- Acabar algo. :: No es el sentido.
