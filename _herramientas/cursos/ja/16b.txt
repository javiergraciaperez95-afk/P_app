@ 16 | ようだ と みたい | Parece que... / como si...
I Hoy aprendes a decir cómo parece algo por lo que ves o notas, sin estar del todo seguro.
E 〜ようだ: parece que (por lo que se ve) :: Verbo o adjetivo en forma normal + の + **よう です**: **あした は あめ の よう です** (parece que mañana lloverá). :: Expresa una impresión a partir de lo que se observa.
E 〜みたい: como si; parece (coloquial) :: Sustantivo + **みたい**: **ともだち は ねこ みたい です** (mi amigo parece un gato). :: Es la forma coloquial de 〜ようだ.
W よう = apariencia; aspecto | yō | kanji: 様
W たいよう = sol | taiyō | kanji: 太陽
W つき = luna | tsuki | kanji: 月
W ほし = estrella | hoshi | kanji: 星
W くも = nube | kumo | kanji: 雲
W にじ = arcoíris | niji | kanji: 虹
W あさやけ = amanecer (cielo) | asayake | kanji: 朝焼け
W ゆうやけ = atardecer (cielo) | yūyake | kanji: 夕焼け
W はれ = buen tiempo; despejado | hare | kanji: 晴れ
W くうき = aire | kūki | kanji: 空気
W せいてん = cielo despejado | seiten | kanji: 晴天
W かみなり = trueno | kaminari | kanji: 雷
V Vocabulario: parece que
T Impresiones
- ともだち は つかれた よう です。 = Parece que mi amigo está cansado.
- そら が あおい よう です。 = Parece que el cielo está azul.
- ともだち は ねこ みたい です。 = Mi amigo parece un gato.
- ひと が おおい みたい です。 = Parece que hay mucha gente.
- あした は あめ の よう です。 = Parece que mañana lloverá.
A ともだち は ねこ みたい です。 :: ¿Qué dice?
+ Mi amigo parece un gato. :: みたい = parece.
- Mi amigo es un gato. :: Eso sería afirmación fuerte.
- Mi amigo tiene un gato. :: Eso no aparece.
A そら が あおい よう です。 :: ¿Qué expresa?
+ Parece que el cielo está azul. :: よう です = parece.
- El cielo es azul. :: Eso sería afirmación.
- El cielo estaba azul. :: Eso sería el pasado.
HA あした は あめ の ___ です。 :: Parece que mañana lloverá.
+ よう :: Parece.
- ほう :: Lado.
- ため :: Para.
Q ¿Qué significa «ともだち は つかれた よう です»?
+ Parece que mi amigo está cansado. :: ようだ = deducción por lo que se ve.
- Mi amigo está cansado sin duda. :: Eso no es una suposición.
- Mi amigo no está cansado. :: Eso es lo contrario.
H あした は あめ の ___ です。 :: Parece que mañana lloverá.
+ よう :: Parece.
- ほう :: Eso sería lado o dirección.
- ため :: Eso sería para.
H ともだち は ___ です。 :: Mi amigo parece un gato.
+ ねこ みたい :: Como un gato.
- ねこ だ :: Eso sería afirmación fuerte: es un gato.
- ねこ の ほう :: Eso sería el lado del gato.
R そら が あおい よう です。 :: Traduce la frase.
+ The sky seems to be blue. :: ようだ = parece que.
- The sky is blue for sure. :: Eso no es una suposición.
- The sky was blue. :: Eso es el pasado.
A あした は あめ の よう です。 :: ¿Qué cuenta?
+ Que parece que lloverá mañana. :: Suposición.
- Que mañana hará sol. :: Eso es lo contrario.
- Que ya llovió. :: Eso es el pasado.
O ひと が おおい みたい です :: Parece que hay mucha gente. :: みたい = parece (coloquial).
Q ¿Cuál es más coloquial?
+ みたい :: Es más informal.
- よう :: Es más formal.
- ため :: Eso es finalidad.
Q ¿Qué expresa «よう» en «あめ の よう»?
+ Una impresión a partir de lo que se ve o se nota. :: Apariencia.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería たい.
