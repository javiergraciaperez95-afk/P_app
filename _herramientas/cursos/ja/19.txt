@ 19 | ともだち の ことば (1) | La forma plana (informal)
I Hasta ahora has hablado con educación (です, ます). Hoy aprendes la forma plana, la que usas con amigos, familia y en el día a día. No la uses con personas que no conoces o que son mayores.
E Del educado al plano :: Los verbos en forma plana son los del diccionario: **いく** (ir), **たべる** (comer). La negación acaba en **ない**: **いかない** (no ir), **たべない** (no comer). El pasado acaba en **た**: **いった** (fui), **たべた** (comí). :: Para «ir» y «comer» en la forma educada, en cambio, tienes **いきます** y **たべます**.
E Los adjetivos y el verbo ser :: **です** se convierte en **だ**: **これ は ほん だ** (esto es un libro). La negación es **じゃない** (no es), y el pasado es **だった**. :: Los adjetivos en -i no cambian mucho: **さむい** (hace frío) → **さむかった** (hacía frío).
B Educado y plano | Educado | Plano | Significa
| いきます | いく | ir
| いきません | いかない | no ir
| いきました | いった | fui
| です | だ | es
| じゃありません | じゃない | no es
| さむかった | さむかった | hacía frío (igual)
W うん = sí (informal) | un | Es el «sí» de amigos; no se usa con gente que no conoces.
W だ = es (forma plana de です) | da
W じゃない = no es (forma plana de じゃありません) | ja nai
W わからない = no entiendo; no sé | wakaranai | Es la forma plana de わかりません.
W さむかった = hacía frío | samukatta | Es el pasado de さむい.
V Vocabulario: hablar en confianza
D Entre amigos
やまだ: あした、 どこ へ いく？ = ¿Mañana adónde vas?
  > あした = mañana | どこ へ いく = ¿adónde vas?
けんじ: うん、 にほん へ いく。 = Sí, voy a Japón.
  > うん = sí | いく = voy
やまだ: ごはん たべた？ = ¿Comiste?
  > たべた = comiste
けんじ: まだ。 ぜんぜん わからない。 = Todavía no. No entiendo nada.
  > わからない = no entiendo
Q ¿Cuál es la forma plana de «いきます»?
+ いく :: Es el diccionario de いきます.
- いきません :: Es la forma educada negativa.
- いきました :: Es la forma educada del pasado.
Q ¿Qué significa «あした、 どこ へ いく？»?
+ ¿Adónde vas mañana? :: どこ へ いく = ¿adónde vas?
- ¿Cuándo vas mañana? :: Eso sería いつ.
- ¿Dónde estuviste mañana? :: Eso sería el pasado.
H これ は ほん ___ 。 :: Esto es un libro.
+ だ :: Forma plana de です.
- です :: Es la forma educada.
- じゃありません :: Es la negación educada.
H ごはん ___ ？ :: ¿Comiste?
+ たべた :: Pasado plano de たべる.
- たべます :: Es presente educado.
- たべません :: Es negación educada.
H ぜんぜん ___ 。 :: No entiendo nada.
+ わからない :: Forma plana de わかりません.
- わかります :: Es «entiendo» (educado).
- わかりました :: Es «entendí» (educado).
R うん、 にほん へ いく。 :: Traduce la frase.
+ Sí, voy a Japón. :: うん = sí (informal).
- Sí, fui a Japón. :: Eso sería いった.
- No, no voy a Japón. :: Eso sería いかない.
A これ は ほん じゃない。 :: ¿Qué dice?
+ Esto no es un libro. :: じゃない = no es (plano).
- Esto es un libro. :: Eso sería だ.
- Esto no es un coche. :: No aparece en la frase.
O きのう は さむかった :: Ayer hacía frío. :: さむかった = hacía frío.

@ 19 | ともだち の ことば (2) | Explicar con んです
I Ahora una frase muy común en japonés: «es que…». Sirve para explicar o para dar una razón sin decirlo de golpe.
E 〜んです: es que… :: Para explicar algo, pon la frase en forma plana y añade **んです**: **あたま が いたい んです** (es que me duele la cabeza). :: Suena mucho más amable que dar la razón directamente.
E 〜んです en preguntas :: Con **の** al final, pides una explicación: **どうした の？** (¿qué pasa?). :: En la conversación casual se oye mucho **の？**, que es la forma plana de **んです か**.
B Explicar | Forma | Significa | Ejemplo
| 〜んです | es que… | あたま が いたい んです
| 〜の？ | ¿qué pasa? | どうした の？
| 〜よ | te informo | はやく かえった ほう が いい よ
W んです = es que… (explicación) | n desu
W どうした = ¿qué pasó?; ¿qué te pasa? | dō shita
V Vocabulario: explicar
D Un amigo no viene
やまだ: どうした の？ = ¿Qué pasa?
  > どうした の = ¿qué pasa?
けんじ: あたま が いたい んです。 = Es que me duele la cabeza.
  > いたい んです = es que me duele
やまだ: はやく かえった ほう が いい よ。 = Es mejor que vuelvas pronto.
  > はやく かえった ほう が いい よ = es mejor que vuelvas pronto
けんじ: ありがとう。 = Gracias.
  > ありがとう = gracias
Q ¿Qué significa «あたま が いたい んです»?
+ Es que me duele la cabeza. :: んです = es que, explicación.
- Me duele la cabeza, ¿verdad? :: Eso sería でしょう.
- Me dolía la cabeza ayer. :: Eso sería el pasado.
Q ¿Qué expresa «〜んです»?
+ Explicar o dar una razón. :: んです = es que.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H あたま が いたい ___ 。 :: Es que me duele la cabeza.
+ んです :: Explicación.
- でした :: Eso sería «era» (pasado).
- でしょう :: Eso sería «supongo».
H はやく かえった ___ よ。 :: Es mejor que vuelvas pronto.
+ ほう が いい :: Consejo.
- ことに しました :: Eso sería una decisión.
- ように なりました :: Eso sería un cambio.
R あたま が いたい んです。 :: Traduce la frase.
+ Es que me duele la cabeza. :: んです = es que.
- Me duele la cabeza, ¿verdad? :: Eso sería でしょう.
- Me dolía la cabeza ayer. :: Eso sería el pasado.
A どうした の？ :: ¿Qué pregunta?
+ ¿Qué te pasa? :: Pide una explicación.
- ¿Qué comes? :: Eso sería なに を たべます か.
- ¿Cuándo vuelves? :: Eso sería いつ かえります か.
O はやく かえった ほう が いい よ :: Es mejor que vuelvas pronto. :: よ = te informo.
Q ¿Cuál es la forma plana de «です»?
+ だ :: です se vuelve だ.
- です :: Es la forma educada.
- でした :: Es el pasado educado.

@ 19 | ともだち の ことば (3) | Decir lo que dijo otra persona
I Por último, cómo contar lo que dijo otra persona sin repetir sus palabras exactas. Se llama «estilo indirecto» y es muy útil.
E 〜と いいました: dijo que… :: Pon la frase en forma plana y añade **と いいました**: **やまだ さん は あした くる と いいました** (Yamada dijo que vendría mañana). :: **と** marca dónde empieza lo que alguien dijo.
E 〜と いっていました: había dicho que… :: Para contar algo que alguien dijo hace un rato, usa **と いっていました**: **けんじ さん は あした やすみ だ と いっていました** (Ken había dicho que mañana es fiesta). :: Cuando lo cuentes a otra persona en plano, las frases del citado van en forma plana.
B Contar lo que dijo | Forma | Significa | Ejemplo
| 〜と いいました | dijo que | くる と いいました
| 〜と いっていました | había dicho que | やすみ だ と いっていました
W くる = venir (forma de diccionario) | kuru
W いいました = dijo | iimashita | Es la forma educada de いう (decir).
W いっていました = había dicho | itte imashita
V Vocabulario: lo que dijo
D Un mensaje de Ken
みか: やまだ さん は あした くる と いいました。 = Yamada dijo que vendría mañana.
  > くる と いいました = dijo que vendría
けんじ: そう です か。 じゃあ、 わたし も いく。 = ¿Ah, sí? Entonces, yo también iré.
  > わたし も いく = yo también iré

Q ¿Qué significa «やまだ さん は あした くる と いいました»?
+ Yamada dijo que vendría mañana. :: と いいました = dijo que.
- Yamada viene mañana. :: Eso sería sin decir que lo dijo.
- Yamada no vendrá mañana. :: Eso es lo contrario.
Q ¿Qué expresa «と いいました»?
+ Lo que dijo alguien, contado por otra persona. :: Estilo indirecto.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H みか さん は ねつ が ある ___ いいました。 :: Mika dijo que tenía fiebre.
+ と :: Marca lo que se dijo.
- が :: Es sujeto, no cita.
- を :: Es objeto, no cita.
H けんじ さん は あした やすみ ___ と いっていました。 :: Ken había dicho que mañana era fiesta.
+ だ :: Forma plana dentro de la cita.
- じゃない :: Eso sería «no es».
- だった :: Eso sería «era» (pasado).
R やまだ さん は にほん へ いった と いいました。 :: Traduce la frase.
+ Yamada dijo que fue a Japón. :: Estilo indirecto en pasado.
- Yamada dijo que irá a Japón. :: Eso es el futuro.
- Yamada dijo que no fue a Japón. :: Eso es lo contrario.
A けんじ さん は あした やすみ だ と いっていました。 :: ¿Qué cuenta?
+ Que Ken había dicho que mañana es fiesta. :: いっていました = había dicho.
- Que Ken trabajará mañana. :: Eso es lo contrario.
- Que Ken está cansado. :: No aparece en la frase.
O やまだ さん は あした くる と いいました :: Yamada dijo que vendría mañana. :: と いいました = dijo que.
Q ¿Cuál es la forma de «dijo» en educado?
+ いいました :: Forma educada del pasado de いう.
- いいます :: Es «dice».
- いって ください :: Es «diga, por favor».
