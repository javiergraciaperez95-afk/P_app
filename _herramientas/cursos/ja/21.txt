@ 21 | げんいん と りゆう (1) | Porque: ので y から
I Empezamos el nivel B1, que en Japón se llama JLPT N3. Hoy aprendes a explicar el motivo de algo con ので y から, las dos formas más usadas para decir «porque».
E 〜ので: motivo con cortesía :: Pon la frase en forma normal y añade **ので**: **あめ が ふっている ので、 かさ を もって いきます** (como llueve, llevo paraguas). :: Suena más suave y educado. Es el motivo habitual para explicar una situación.
E 〜から: motivo directo :: Con **から** das tu motivo de forma más directa y personal: **おいしい から、 たくさん たべました** (como estaba rico, comí mucho). :: Suena más directo: con personas que no conoces, mejor **ので**. Ojo: en el capítulo 1 ya viste **から** como «de» o «desde»; aquí es «porque».
E Con nombres y adjetivos en -na :: Delante de **ので** o **から**, los nombres y los adjetivos en -na llevan **な**: **ひま な ので** (como tengo tiempo libre). :: Con los adjetivos en -i no hace falta nada: **おいしい から**.
B Porque… | Forma | Tono | Ejemplo
| 〜ので | con cortesía; explica una situación | あめ が ふっている ので
| 〜から | directo; tu motivo | おいしい から
| なに + ので | nombre o adjetivo en -na | ひま な ので
W ので = porque (como; motivo objetivo) | node | Va después de la frase que explica el motivo.
W ふっている = está lloviendo (forma normal) | futte iru
W みに = para ver; a ver | mi ni
W たくさん = mucho, muchos | takusan
W どうして = ¿por qué? | dōshite
W やすみました = falté; no fui (de やすむ) | yasumimashita
W やすむ = faltar; descansar; no ir | yasumu
V Vocabulario: porque
D ¿Por qué no viniste?
やまだ: きのう、 どうして やすみました か。 = Ayer, ¿por qué faltaste?
  > どうして = ¿por qué? | やすみました = faltaste
けんじ: ねつ が ある ので、 がっこう を やすみました。 = Como tenía fiebre, falté a clase.
  > ねつ が ある ので = como tenía fiebre
やまだ: そう です か。 もう だいじょうぶ です か。 = ¿Ah, sí? ¿Ya estás bien?
  > もう だいじょうぶ です か = ¿ya estás bien?
けんじ: はい、 もう だいじょうぶ です。 = Sí, ya estoy bien.
  > もう だいじょうぶ です = ya estoy bien
T Un día con lluvia
- あめ が ふっている ので、 かさ を もって いきます。 = Como llueve, llevo paraguas.
  > ふっている ので = como llueve | もって いきます = llevo
- ひま な ので、 えいが を みに いきます。 = Como tengo tiempo libre, voy a ver una película.
  > ひま な ので = como tengo tiempo libre | みに いきます = voy a ver
- おいしい から、 たくさん たべました。 = Como estaba rico, comí mucho.
  > おいしい から = como estaba rico | たくさん たべました = comí mucho
Q ¿Qué significa «あめ が ふっている ので、 かさ を もって いきます»?
+ Como llueve, llevo paraguas. :: ので = motivo de la acción.
- Llueve, así que no llevo paraguas. :: Eso es lo contrario.
- Llevo paraguas, pero no llueve. :: Eso es lo contrario.
Q ¿Qué forma es correcta antes de ので con «ひま»?
+ ひま な ので :: Un nombre o adjetivo en -na lleva な.
- ひま ので :: Falta な.
- ひま い ので :: い no va con ひま.
H ねつ が ある ___ 、 がっこう を やすみました。 :: Como tenía fiebre, faltó a clase.
+ ので :: Motivo con cortesía.
- まで :: Eso sería «hasta».
- ながら :: Eso sería «mientras».
H おいしい ___ 、 たくさん たべました。 :: Como estaba rico, comió mucho.
+ から :: Motivo directo.
- を :: Eso no explica nada.
- まで :: Eso sería «hasta».
R けんじ さん は ねつ が ある ので、 がっこう を やすみました。 :: Traduce la frase.
+ Ken faltó a clase porque tenía fiebre. :: ので = motivo.
- Ken tenía fiebre, pero fue a clase. :: Eso es lo contrario.
- Ken faltó a clase y después tuvo fiebre. :: Eso cambia el orden.
A おいしい から、 たくさん たべました。 :: ¿Qué cuenta?
+ Que comió mucho porque estaba rico. :: から = motivo.
- Que comió poco porque estaba rico. :: Eso es lo contrario.
- Que comió mucho sin motivo. :: Falta el motivo.
O ひま な ので :: Como tengo tiempo libre. :: ので = motivo.
Q ¿Qué significa «みに いきます»?
+ Voy a ver (algo). :: みに = para ver.
- Vuelvo a casa. :: Eso sería かえります.
- Como fuera. :: No aparece.

@ 21 | げんいん と りゆう (2) | Gracias a y por culpa de
I Hoy aprendes a decir si un resultado es bueno o malo y de quién depende. Son dos palabras muy útiles en el trabajo y en las conversaciones.
E 〜おかげで: gracias a (positivo) :: Para algo bueno que pasó gracias a alguien o algo: **みなさん の おかげで、 にほんご が じょうず に なりました** (gracias a todos, mi japonés mejoró). :: Se usa para dar las gracias de forma indirecta.
E 〜せいで: por culpa de (negativo) :: Para algo malo que pasó por culpa de alguien o algo: **あめ の せいで、 でんしゃ が おくれました** (por culpa de la lluvia, el tren se retrasó). :: Con **せいで** se culpa a alguien o algo, y casi siempre suena a queja.
B Bueno o malo | Forma | Tono | Ejemplo
| 〜おかげで | positivo; gracias | みなさん の おかげで
| 〜せいで | negativo; culpa | あめ の せいで
W おかげで = gracias a (con resultado positivo) | okage de | Escrito 御蔭で.
W せいで = por culpa de (con resultado negativo) | sei de | Escrito 所為で.
W みなさん = todos, todas las personas | minasan
W おくれました = llegó tarde; se retrasó | okuremashita
W かぜ = resfriado; catarro | kaze
W パーティー = fiesta | pātī
W かえりました = volví (a casa) | kaerimashita
V Vocabulario: gracias a y por culpa de
T Dos resultados
- みなさん の おかげで、 にほんご が じょうず に なりました。 = Gracias a todos, mi japonés mejoró.
  > みなさん の おかげで = gracias a todos
- あめ の せいで、 でんしゃ が おくれました。 = Por culpa de la lluvia, el tren llegó tarde.
  > あめ の せいで = por culpa de la lluvia
- かぜ の せいで、 しごと を やすみました。 = Por culpa del resfriado, falté al trabajo.
  > かぜ の せいで = por culpa del resfriado
D Después de la fiesta
けんじ: きのう の パーティー、 たのしかった ね。 = La fiesta de ayer fue divertida, ¿verdad?
  > たのしかった = fue divertida
まり: はい。 みなさん の おかげで、 とても たのしかった です。 = Sí. Gracias a todos, fue muy divertida.
  > みなさん の おかげで = gracias a todos
けんじ: でも、 あめ の せいで、 はやく かえりました。 = Pero por la lluvia, volví pronto.
  > あめ の せいで = por la lluvia | はやく かえりました = volví pronto
まり: そう です か。 = ¿Ah, sí?
  > そう です か = ¿ah, sí?
Q ¿Qué significa «みなさん の おかげで»?
+ Gracias a todos. :: おかげで = gracias a (positivo).
- Por culpa de todos. :: Eso sería せいで.
- Todos me pidieron algo. :: No aparece en la frase.
Q ¿Qué expresa «〜せいで»?
+ Una causa negativa. :: せいで = por culpa de.
- Una causa positiva. :: Eso sería おかげで.
- Una finalidad. :: Eso sería ために.
H あめ の ___ 、 でんしゃ が おくれました。 :: Por culpa de la lluvia, el tren llegó tarde.
+ せいで :: Causa negativa.
- おかげで :: Causa positiva: no encaja.
- ように :: Eso es finalidad.
H みなさん の ___ 、 にほんご が じょうず に なりました。 :: Gracias a todos, mi japonés mejoró.
+ おかげで :: Causa positiva.
- せいで :: Causa negativa: no encaja.
- ながら :: Eso sería «mientras».
R かぜ の せいで、 しごと を やすみました。 :: Traduce la frase.
+ Por culpa del resfriado, falté al trabajo. :: せいで = por culpa de.
- Gracias al resfriado, falté al trabajo. :: Eso sería おかげで.
- Falté al trabajo para no resfriarme. :: Eso sería ために.
A でも、 あめ の せいで、 はやく かえりました。 :: ¿Qué cuenta?
+ Que volvió pronto por la lluvia. :: せいで = culpa.
- Que se quedó hasta tarde por la lluvia. :: Eso es lo contrario.
- Que la lluvia llegó pronto. :: No es la frase.
O みなさん の おかげで :: Gracias a todos. :: おかげで = gracias a.
Q ¿Cuál dice «por culpa de»?
+ せいで :: Causa negativa.
- おかげで :: Causa positiva.
- でも :: Eso es «pero».

@ 21 | げんいん と りゆう (3) | Para y para que: ために y ように
I Por último, dos formas de decir «para»: una para la causa de algo malo y otra para el objetivo que no controlas. Las dos son muy comunes en las noticias y en el trabajo.
E 〜ために: a causa de (causa) :: Con **ため に** también se dice la causa de algo, sobre todo algo negativo: **じこ の ため に、 でんしゃ が とまりました** (a causa del accidente, el tren se paró). :: Suena más formal que **せいで**. Lo verás mucho en las noticias.
E 〜ように: para que (objetivo) :: Para decir el objetivo de una acción que depende de algo que no controlas: **わすれない ように、 メモ を します** (tomo nota para no olvidar). :: Se usa con la forma en -ない o con la forma potencial: **わすれない ように**, **おきられる ように**.
B Para y por | Forma | Significa | Ejemplo
| 〜ために | a causa de | じこ の ため に
| 〜ように | para que (objetivo) | わすれない ように
| 〜ように | para que (con ない) | わすれない ように
W じこ = accidente | jiko
W とまりました = se paró; se detuvo | tomarimashita
W とまった = se paró (forma た) | tomatta
W わすれない = no olvidar (forma ない de わすれる) | wasurenai
W メモ = nota escrita | memo
W ように = para que (objetivo) | yō ni | Ya la conoces de 053 con なりました; aquí es «para que».
V Vocabulario: para y para que
D Un tren parado
みか: きのう、 でんしゃ が とまった ね。 = Ayer el tren se paró, ¿verdad?
  > でんしゃ が とまった = el tren se paró
けんじ: うん。 じこ の ため に とまった んです。 = Sí. Se paró a causa de un accidente.
  > じこ の ため に = a causa de un accidente
みか: だいじょうぶ でした か。 = ¿Estuvo bien?
  > だいじょうぶ でした か = ¿estuvo bien?
けんじ: はい。 わすれない ように、 もう メモ を しました。 = Sí. Para no olvidarlo, ya tomé nota.
  > わすれない ように = para no olvidarlo | メモ を しました = tomé nota
T Mis costumbres
- わすれない ように、 メモ を します。 = Tomo nota para no olvidar.
  > わすれない ように = para no olvidar
- あした は はやく おきる ように、 はやく ねます。 = Mañana me acuesto temprano para levantarme pronto.
  > はやく おきる ように = para levantarme pronto
- じこ の ため に、 でんしゃ が とまりました。 = A causa del accidente, el tren se paró.
  > じこ の ため に = a causa del accidente
Q ¿Qué significa «じこ の ため に、 でんしゃ が とまりました»?
+ A causa del accidente, el tren se paró. :: ため に = causa.
- Para el accidente, el tren se paró. :: Eso sería finalidad.
- El tren paró para evitar el accidente. :: Eso sería finalidad.
Q ¿Qué expresa «〜ように» en «わすれない ように»?
+ Un objetivo para que algo no ocurra. :: ように = para que.
- Una obligación. :: Eso sería なければ なりません.
- Un deseo. :: Eso sería 〜たい.
H わすれない ___、 メモ を します。 :: Para no olvidar, tomo nota.
+ ように :: Objetivo.
- ながら :: Eso sería «mientras».
- まえに :: Eso sería «antes de».
H じこ の ___ 、 でんしゃ が とまりました。 :: A causa del accidente, el tren se paró.
+ ため に :: Causa.
- おかげで :: Causa positiva: no encaja.
- ように :: Objetivo: no encaja.
R あした は はやく おきる ように、 はやく ねます。 :: Traduce la frase.
+ Mañana me acuesto temprano para levantarme pronto. :: ように = para que.
- Mañana me levanto temprano para acostarme pronto. :: Eso invierte el orden.
- Mañana no me acuesto temprano. :: Eso es lo contrario.
A わすれない ように、 メモ を します。 :: ¿Qué cuenta?
+ Toma nota para no olvidar. :: ように = para que.
- Escribe una carta a un amigo. :: No aparece en la frase.
- Toma nota para olvidar. :: Eso es lo contrario.
O じこ の ため に :: A causa del accidente. :: ため に = causa.
Q ¿Cuál es el motivo de que el tren se parara?
+ El accidente. :: じこ の ため に.
- La lluvia. :: No aparece en la frase.
- La fiesta. :: No aparece en la frase.
