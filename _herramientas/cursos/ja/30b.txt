@ 30 | にくい と やすい と とおり | Difícil de..., fácil de... y tal como...
I Hoy aprendes a decir si algo es fácil o difícil de hacer, a hablar de algo hecho tal como se dijo y a expresar que algo pasa justo al hacer otra cosa.
E 〜にくい / 〜やすい: difícil / fácil de hacer :: Forma ます sin ます + **にくい** (difícil de) o **やすい** (fácil de): **この かんじ は よみにくい です** (este kanji es difícil de leer). :: Describen la facilidad de una acción.
E 〜とおり: tal como :: Sustantivo + の + **とおり**: **せんせい の いう とおり に します** (lo hago tal como dice el profesor). :: Se usa para seguir una indicación.
E 〜とたん: en cuanto (justo al hacer) :: Forma た + **とたん**: **たべた とたん、 でかけます** (en cuanto como, salgo). :: Dos acciones seguidas muy rápido.

V Vocabulario: difícil, fácil y tal como
T Facilidad y puntualidad
- この かんじ は よみにくい です。 = Este kanji es difícil de leer.
- この ほん は わかりやすい です。 = Este libro es fácil de entender.
- せんせい の いう とおり に します。 = Hago lo que dice el profesor.
- たべた とたん、 でかけます。 = En cuanto como, salgo.
A この かんじ は よみにくい です。 :: ¿Qué kanji?
+ Es difícil de leer. :: にくい = difícil de hacer.
- Es fácil de escribir. :: Eso no aparece.
- Es fácil de leer. :: Eso es lo contrario.
A せんせい の いう とおり に します。 :: ¿Qué hace?
+ Hace lo que dice el profesor. :: とおり = tal como.
- Hace lo que quiere. :: Eso es lo contrario.
- No hace nada. :: Eso es lo contrario.
HA たべた ___ 、 でかけます。 :: En cuanto como, salgo.
+ とたん :: En cuanto.
- まで :: Hasta.
- ながら :: Mientras.
Q ¿Qué significa «この かんじ は よみにくい です»?
+ Este kanji es difícil de leer. :: にくい = difícil de hacer.
- Este kanji es fácil de leer. :: Eso es lo contrario.
- Este kanji no se lee. :: Eso no es la frase.
Q ¿Qué expresa «〜とおり»?
+ Hacer algo tal como se dijo o se indicó. :: Igual que.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería たい.
H この ほん は ___ です。 :: Este libro es fácil de entender.
+ わかりやすい :: Fácil de entender.
- わかりにくい :: Eso sería difícil de entender.
- わかりました :: Eso sería lo entendí.
H せんせい の いう ___ に します。 :: Hago lo que dice el profesor.
+ とおり :: Tal como.
- ため :: Eso sería para.
- まで :: Eso sería hasta.
H たべた ___ 、 でかけます。 :: En cuanto como, salgo.
+ とたん :: En cuanto.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
R この かんじ は よみにくい です。 :: Traduce la frase.
+ This kanji is hard to read. :: にくい = difícil de.
- This kanji is easy to read. :: Eso es lo contrario.
- I can read this kanji. :: Eso no es la frase.
A たべた とたん、 でかけます。 :: ¿Qué cuenta?
+ Que sale justo después de comer. :: とたん = en cuanto.
- Que sale antes de comer. :: Eso invierte el orden.
- Que no sale. :: Eso es lo contrario.
O せんせい の いう とおり に します :: Hago lo que dice el profesor. :: とおり = tal como.
