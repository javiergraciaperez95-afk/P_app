@ 4 | これ は なん です か | Esto, eso y aquello
E Tres distancias :: El japonés distingue tres distancias, igual que el español. **これ** = esto (cerca de mí). **それ** = eso (cerca de ti). **あれ** = aquello (lejos de los dos). :: Estas tres palabras van **solas**. Si van delante de un nombre, cambian a **この**, **その**, **あの**: **この ほん** (este libro), **あの ひと** (aquella persona).
B Esto, eso y aquello | | Solo | Delante de un nombre
| cerca de mí | これ | この ほん
| cerca de ti | それ | その ほん
| lejos de los dos | あれ | あの ほん
E De quién es :: La partícula **の** indica posesión, con el dueño delante: **わたし の ほん** (mi libro), **たなか さん の かばん** (el bolso del señor Tanaka). :: Si ya se sabe de qué se habla, el nombre se puede quitar: **わたし の です** (es mío). :: Para preguntar: **だれ の です か** (¿de quién es?). Y **なん です か** es «¿qué es?».
W これ = esto | kore
W それ = eso | sore
W あれ = aquello | are
W この = este, esta (+ nombre) | kono
W その = ese, esa (+ nombre) | sono
W あの = aquel, aquella (+ nombre) | ano
W だれ = quién | dare
W かばん = bolso, mochila | kaban
W スマホ = móvil | sumaho
W とけい = reloj | tokē
W ペン = bolígrafo | pen
W めがね = gafas | megane
W さいふ = cartera | saifu
W あ = ¡ah! | a
V Vocabulario: cosas
D ¿De quién es?
けん: これ は なん です か。 = ¿Qué es esto?
  > これ は = esto (tema) | なん です か = ¿qué es?
まり: それ は わたし の スマホ です。 = Eso es mi móvil.
  > それ = eso (cerca de quien pregunta) | わたし の スマホ = mi móvil
けん: あれ は まり さん の かばん です か。 = ¿Aquello es tu bolso, Mari?
  > あれ = aquello (lejos de los dos) | まり さん の かばん = el bolso de Mari
まり: いいえ、 あれ は わたし の じゃ ありません。 アンナ さん の かばん です。 = No, aquel no es mío. Es el bolso de Anna.
  > わたし の = el mío (sin repetir el nombre) | じゃ ありません = no es
けん: この かぎ は だれ の です か。 = ¿De quién es esta llave?
  > この かぎ = esta llave («この» va con nombre) | だれ の = de quién
まり: あ、 それ は わたし の かぎ です。 ありがとう。 = Ah, esa es mi llave. Gracias.
  > わたし の かぎ = mi llave
Q Tienes un libro en la mano. ¿Cómo dices «esto»?
+ これ :: Cerca de quien habla.
- それ :: Eso es cerca de quien escucha.
- あれ :: Eso es lejos de los dos.
Q ¿Cuál es correcta para «este libro»?
+ この ほん :: Delante de un nombre se usa この.
- これ ほん :: «これ» va solo, sin nombre.
- これ の ほん :: No lleva の.
Q ¿Cómo dices «mi bolso»?
+ わたし の かばん :: Dueño + の + cosa.
- かばん の わたし :: El orden es al revés.
- わたし は かばん :: Eso sería «yo soy un bolso».
R それ は わたし の です。
+ Eso es mío. :: わたし の = el mío.
- Esto es tuyo. :: No.
- Eso soy yo. :: No.
H ___ かぎ は だれ の です か。
+ この :: Delante de un nombre.
- これ :: Va solo.
- だれ :: No.
H これ は たなか さん ___ めがね です。
+ の :: Posesión.
- は :: Ya hay un tema.
- が :: No.
A この とけい は だれ の です か。 :: Escucha. ¿Qué preguntan?
+ De quién es este reloj. :: だれ の = de quién.
- Qué hora es. :: No.
- Dónde está el reloj. :: No.
O あれ は わたし の かばん です :: Aquello es mi bolso :: あれ + は + dueño + の + cosa + です.

@ 4 | ここ は どこ です か | Lugares: aquí, ahí y qué hay
E Aquí, ahí, allí :: Con los lugares pasa lo mismo que con las cosas: **ここ** (aquí), **そこ** (ahí), **あそこ** (allí). Y para preguntar, **どこ** (dónde): **トイレ は どこ です か** (¿dónde está el baño?).
E Hay: あります y います :: Para decir que algo existe o está en un sitio hay **dos verbos**. **あります** es para cosas y plantas. **います** es para personas y animales. :: El lugar lleva la partícula **に** y lo que hay lleva **が**: **へや に ベッド が あります** (en la habitación hay una cama), **にわ に ねこ が います** (en el jardín hay un gato). :: Negación: **ありません** e **いません**.
B Hay y no hay | | Cosas | Personas y animales
| hay | あります | います
| no hay | ありません | いません
E Dos partículas del final :: **ね** al final busca que el otro esté de acuerdo, como «¿verdad?»: **いい へや です ね** (qué buena habitación, ¿eh?). :: **よ** da una información que el otro no sabe.
W ここ = aquí | koko
W そこ = ahí | soko
W あそこ = allí | asoko
W どこ = dónde | doko
W あります = hay, está (cosas) | arimasu
W ありません = no hay (cosas) | arimasen
W に = en; a (partícula de lugar y de tiempo) | ni
W だいどころ = cocina | daidokoro
W にわ = jardín | niwa
W まど = ventana | mado
W ドア = puerta | doa
W テーブル = mesa | tēburu
W いす = silla | isu
W ベッド = cama | beddo
W ソファ = sofá | sofa
W となり = al lado | tonari
W いい = bueno | ii
W ね = ¿verdad?, ¿eh? (partícula final) | ne
V Vocabulario: la casa
D El piso de Anna
アンナ: ここ は わたし の へや です。 = Esta es mi habitación.
  > ここ は = aquí (tema) | わたし の へや = mi habitación
けん: いい へや です ね。 = Qué buena habitación.
  > いい へや = buena habitación | ね = ¿verdad?
アンナ: へや に ベッド と つくえ が あります。 = En la habitación hay una cama y un escritorio.
  > へや に = en la habitación | ベッド と つくえ が = una cama y un escritorio (lo que hay) | あります = hay (cosas)
けん: テレビ は あります か。 = ¿Hay tele?
  > テレビ は = en cuanto a tele | あります か = ¿hay?
アンナ: いいえ、 テレビ は ありません。 = No, tele no hay.
  > ありません = no hay
けん: トイレ は どこ です か。 = ¿Dónde está el baño?
  > どこ です か = ¿dónde está?
アンナ: あそこ です。 だいどころ の となり です。 = Está allí. Al lado de la cocina.
  > あそこ = allí | だいどころ の となり = al lado de la cocina
けん: にわ に ねこ が います ね。 = Hay un gato en el jardín, ¿eh?
  > にわ に = en el jardín | ねこ が います = hay un gato (ser vivo: います)
アンナ: はい、 わたし の ねこ です。 = Sí, es mi gato.
  > わたし の ねこ = mi gato
Q ¿Qué verbo usas para decir que hay un gato?
+ います :: Personas y animales.
- あります :: Es para cosas.
- です :: «です» es «ser», no «haber».
Q ¿Qué partícula lleva el lugar donde hay algo?
+ に :: へや に = en la habitación.
- が :: Esa marca lo que hay.
- は :: No es la del lugar.
Q ¿Cómo preguntas «¿dónde está el baño?»?
+ トイレ は どこ です か。 :: Cosa + は + どこ です か.
- どこ は トイレ です か。 :: «どこ» no puede ser el tema.
- トイレ は なん です か。 :: Eso es «¿qué es el baño?».
R にわ に いぬ が います。
+ Hay un perro en el jardín. :: います = hay (ser vivo).
- Hay un gato en el jardín. :: Gato es ねこ.
- El jardín es de un perro. :: No.
H へや に いす が ___ 。
+ あります :: «いす» es una cosa.
- います :: Es para seres vivos.
- です :: No.
H だいどころ ___ テーブル が あります。
+ に :: Lugar + に.
- が :: Ya va detrás de «テーブル».
- の :: No.
A テレビ は ありません。 :: Escucha. ¿Qué significa?
+ No hay tele. :: ありません = no hay.
- Hay una tele. :: Es negativa.
- La tele está ahí. :: No.
O へや に ベッド が あります :: En la habitación hay una cama :: Lugar + に + cosa + が + あります.

@ 4 | どこ に あります か | Encima, debajo, dentro
E Las posiciones son nombres :: En japonés «encima», «debajo» o «dentro» son **nombres**, y se unen al objeto con **の**: **テーブル の うえ** (encima de la mesa; literalmente «el encima de la mesa»). :: El orden es el contrario al español: primero el objeto, luego la posición. :: Para decir dónde está algo: **A は B の うえ に あります** (A está encima de B).
B Las posiciones | Japonés | Se lee | Español
| うえ | ue | encima
| した | shita | debajo
| なか | naka | dentro
| まえ | mae | delante
| うしろ | ushiro | detrás
| となり | tonari | al lado
E Preguntar dónde :: **スマホ は どこ に あります か** (¿dónde está el móvil?). Con seres vivos: **ねこ は どこ に います か**. :: Si no lo sabes: **わかりません** (no lo sé, no entiendo).
W した = debajo | shita
W なか = dentro | naka
W まえ = delante | mae
W うしろ = detrás | ushiro
W わかりません = no lo sé; no entiendo | wakarimasen
W よ = (partícula final: te informo) | yo
W はこ = caja | hako
V Vocabulario: posiciones
D Buscando cosas
けん: わたし の スマホ は どこ に あります か。 = ¿Dónde está mi móvil?
  > わたし の スマホ は = mi móvil (tema) | どこ に あります か = ¿dónde está?
まり: わかりません。 かばん の なか です か。 = No lo sé. ¿Está dentro del bolso?
  > わかりません = no lo sé | かばん の なか = dentro del bolso
けん: いいえ、 ありません。 = No, no está.
  > ありません = no está
まり: あ、 テーブル の うえ に あります よ。 = Ah, está encima de la mesa.
  > テーブル の うえ に = encima de la mesa | よ = te lo digo yo
けん: ありがとう。 かぎ は？ = Gracias. ¿Y las llaves?
  > かぎ は = ¿y las llaves? (frase sin terminar)
まり: いす の した に あります。 = Están debajo de la silla.
  > いす の した に = debajo de la silla
けん: ねこ は どこ に います か。 = ¿Dónde está el gato?
  > どこ に います か = ¿dónde está? (ser vivo)
まり: ソファ の うしろ に います。 = Está detrás del sofá.
  > ソファ の うしろ に = detrás del sofá
Q ¿Cómo dices «encima de la mesa»?
+ テーブル の うえ :: Objeto + の + posición.
- うえ の テーブル :: Eso sería «la mesa de arriba».
- テーブル うえ の :: の va en medio.
Q ¿Qué significa «した»?
+ Debajo. :: いす の した = debajo de la silla.
- Encima. :: Eso es うえ.
- Dentro. :: Eso es なか.
Q ¿Cómo preguntas dónde está el gato?
+ ねこ は どこ に います か。 :: Ser vivo → います.
- ねこ は どこ に あります か。 :: «あります» es para cosas.
- ねこ は どこ の です か。 :: No.
R かぎ は かばん の なか に あります。
+ Las llaves están dentro del bolso. :: なか = dentro.
- Las llaves están encima del bolso. :: Sería うえ.
- El bolso está dentro de las llaves. :: Al revés.
H スマホ は つくえ ___ うえ に あります。
+ の :: Objeto + の + posición.
- は :: No.
- に :: «に» va después de la posición.
H いぬ は ドア の まえ に ___ 。
+ います :: Ser vivo.
- あります :: Es para cosas.
- です か :: No.
A ねこ は はこ の なか に います。 :: Escucha. ¿Dónde está el gato?
+ Dentro de la caja. :: はこ の なか.
- Encima de la caja. :: Sería うえ.
- Detrás de la caja. :: Sería うしろ.
O ねこ は ソファ の うしろ に います :: El gato está detrás del sofá :: Tema + は + objeto + の + posición + に + います.
