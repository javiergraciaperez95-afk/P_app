@ 34 | ものだ と ものか (1) | Es normal que: ものだ
I Ahora las expresiones con もの para hablar de verdades generales, de sentimientos y de juicios. En japonés suenan muy naturales en la conversación seria.
E 〜ものだ: verdad general o sentimiento :: Puede expresar una observación general o una emoción: frase en forma normal + **ものだ**: **こども は すぐ おおきく なる もの だ** (los niños crecen rápido; es lo normal). :: Con **Vたものだ** también se recuerdan hábitos del pasado; el contexto distingue estos usos.
E Diferencia con 〜のです :: En **ものだ**, el hablante presenta una generalización, un recuerdo o una emoción; **のです** suele explicar o contextualizar una situación concreta. No son intercambiables en todos los casos.
B Verdad o emoción | Forma | Significa | Ejemplo
| 〜もの だ (verdad) | es normal que | すぐ おおきく なる もの だ
| 〜もの だ (emoción) | ¡qué...! | なつかしい もの だ
W すぐ = enseguida; rápido | sugu
W あって = (forma て de あう) encontrarse; quedar | atte
W おおきく = grande; grandemente (de おおきい) | ōkiku
W ひさしぶり = después de mucho tiempo | hisashiburi
W なつかしい = nostálgico; añorado | natsukashii
V Vocabulario: es normal que
T Crecer y reencontrarse
- こども は すぐ おおきく なる もの だ。 = Los niños crecen rápido; es lo normal.
  > すぐ おおきく なる もの だ = crecen rápido, es lo normal
- ひさしぶり に あって、 なつかしい もの だ。 = Hacía mucho que no nos veíamos; ¡qué nostalgia!
  > なつかしい もの だ = ¡qué nostalgia!
D Un reencuentro
けんじ: ひさしぶり です ね。 = Hacía mucho que no nos veíamos, ¿verdad?
  > ひさしぶり です ね = hacía mucho
まり: はい。 こども は すぐ おおきく なる もの だ。 = Sí. Los niños crecen rápido; es lo normal.
  > すぐ おおきく なる もの だ = crecen rápido
Q ¿Qué significa «こども は すぐ おおきく なる もの だ»?
+ Los niños crecen rápido; es lo normal. :: もの だ = verdad general.
- Los niños crecen lentamente. :: Eso es lo contrario.
- Los niños no crecen. :: Eso es lo contrario.
Q ¿Qué expresa «〜もの だ» con «なつかしい»?
+ Una emoción: ¡qué nostalgia! :: Sentimiento.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H こども は すぐ おおきく なる ___ 。 :: Los niños crecen rápido; es lo normal.
+ もの だ :: Verdad general.
- ため だ :: Eso sería «es por».
- から です :: Eso sería «porque es».
H ひさしぶり に あって、 なつかしい ___ 。 :: ¡Qué nostalgia!
+ もの だ :: Emoción.
- こと です :: Eso no expresa la emoción.
- ばかり だ :: Eso sería «solo».
R こども は すぐ おおきく なる もの だ。 :: Traduce la frase.
+ Los niños crecen rápido; es lo normal. :: もの だ = verdad general.
- Los niños crecen despacio. :: Eso es lo contrario.
- Los niños se quedan pequeños. :: Eso es lo contrario.
A ひさしぶり に あって、 なつかしい もの だ。 :: ¿Qué siente?
+ Nostalgia por el reencuentro. :: Emoción.
- Enfado por el reencuentro. :: Eso es lo contrario.
- Indiferencia. :: Eso es lo contrario.
O すぐ おおきく なる もの だ :: Crecen rápido; es lo normal. :: もの だ = verdad general.
Q ¿Cuál es el sentido de «もの だ» aquí?
+ Un hecho natural. :: Verdad general.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.

@ 34 | ものだ と ものか (2) | No se debe, ¡ni hablar!: ものではない y ものか
I Hoy, dos expresiones para decir que algo no se debe hacer y para negar algo con fuerza. Son muy directas y se usan mucho en las discusiones.
E 〜ものではない: no se debe :: Para decir que algo no está bien por norma social o moral: verbo en forma normal + **もの で は ない**: **ひと の はなし を とちゅう で きる もの で は ない** (no se debe interrumpir a alguien mientras habla). :: Presenta una norma o conducta que se considera inaceptable; según el contexto puede sonar admonitorio o directo.
E 〜ものか: ¡ni hablar! :: Para negar con fuerza algo que te parece absurdo: verbo en forma normal + **もの か**: **だれ が そんな こと を する もの か** (¡nadie haría algo así!). :: Es una respuesta emocional y muy directa.
B Prohibición social y negación enérgica | Forma | Significa | Ejemplo
| 〜もの では ない | no se debe | きる もの では ない
| 〜もの か | ¡ni hablar! | する もの か
W きる = interrumpir; cortar | kiru
W はなし = conversación; historia | hanashi
W とちゅう = en medio; a mitad (de algo) | tochū
W そんな = tal; semejante (ya enseñado) | sonna
V Vocabulario: no se debe y ¡ni hablar!
D Una discusión
まり: あの ひと、 ひと の はなし を きる。 = Ese, interrumpe a la gente cuando habla.
  > ひと の はなし を きる = interrumpe lo que dice la gente
けんじ: ひと の はなし を とちゅう で きる もの では ない。 = No se debe interrumpir a alguien mientras habla.
  > きる もの では ない = no se debe interrumpir
T Opiniones fuertes
- ひと の はなし を とちゅう で きる もの では ない。 = No se debe interrumpir a alguien mientras habla.
  > きる もの では ない = no se debe interrumpir
- だれ が そんな こと を する もの か。 = ¡Nadie haría algo así! ¡Ni hablar!
  > する もの か = ¡ni hablar!
Q ¿Qué significa «ひと の はなし を とちゅう で きる もの では ない»?
+ No se debe interrumpir a alguien mientras habla. :: もの では ない = norma.
- Hay que interrumpir siempre. :: Eso es lo contrario.
- Interrumpir es una prueba. :: No aparece.
Q ¿Qué expresa «〜もの か»?
+ Una negación enérgica. :: ¡Ni hablar!
- Un permiso. :: Eso sería 〜て も いい です.
- Un deseo. :: Eso sería 〜たい.
H ひと の はなし を とちゅう で きる ___ 。 :: No se debe interrumpir a alguien.
+ もの では ない :: Norma moral.
- ため では ない :: Eso sería «no es para».
- ながら では ない :: Eso no encaja.
H だれ が そんな こと を する ___ 。 :: ¡Nadie haría algo así!
+ もの か :: Negación enérgica.
- ため か :: Eso no encaja.
- ながら か :: Eso no encaja.
R だれ が そんな こと を する もの か。 :: Traduce la frase.
+ ¡Nadie haría algo así! :: もの か expresa un rechazo enfático.
- ¿Quién haría algo así? :: Es una pregunta retórica con negación fuerte.
- Somebody did such a thing. :: Eso es lo contrario.
A ひと の はなし を とちゅう で きる もの では ない。 :: ¿Qué opina?
+ Que no se debe interrumpir. :: Norma.
- Que hay que interrumpir. :: Eso es lo contrario.
- Que está bien interrumpir. :: Eso es lo contrario.
O する もの か :: ¡Ni hablar! :: もの か = negación enérgica.
Q ¿Cuál es más firme?
+ 〜もの か :: Negación fuerte.
- 〜もの では ない :: Norma educada.
- 〜ように :: Finalidad.

@ 34 | ものだ と ものか (3) | Hay algo que: ものがある y ものなら

| 〜ものなら | si se pudiera | できる ものなら

W 残る = permanecer; quedar | のこる
W 価値 = valor | かち
