@ 18 | けいかく (1) | Intenciones y planes
I Hoy hablamos del futuro: lo que piensas hacer y lo que ya tienes planeado. En japonés hay dos formas que se parecen, pero no son iguales.
E 〜つもり です: intención :: Para decir lo que piensas hacer, verbo en forma de diccionario + **つもり です**: **あう つもり です** (tengo intención de quedar). :: Es tu intención personal, aunque todavía no esté fijada en el calendario.
E 〜よてい です: plan fijado :: Para un plan ya decidido, con fecha o en la agenda: verbo en forma de diccionario + **よてい です**: **いく よてい です** (tengo planeado ir). :: Suena a algo que ya está apuntado. Se dice **よてい が あります** (tengo un plan).
B Intención y plan | Palabra | Forma | Ejemplo
| つもり です | intención personal | あう つもり です
| よてい です | plan fijado | らいげつ に いく よてい です
W あう = encontrarse, quedar | au
W つもり = intención, pensamiento de hacer algo | tsumori
W らいげつ = el mes que viene | raigetsu
W よてい = plan, programa | yotei
V Vocabulario: intenciones y planes
D ¿Qué vas a hacer el domingo?
やまだ: けんじ さん、 らいしゅう の にちようび に なに を します か。 = Ken, ¿qué haces el domingo que viene?
  > なに を します か = ¿qué haces?
けんじ: ともだち と あう つもり です。 = Tengo intención de quedar con un amigo.
  > あう つもり です = tengo intención de quedar
やまだ: そう です か。 らいげつ の よてい は？ = ¿Ah, sí? ¿Y tu plan para el mes que viene?
  > よてい = plan
けんじ: にほん へ いく よてい です。 = Tengo planeado ir a Japón.
  > いく よてい です = tengo planeado ir
Q ¿Qué significa «あう つもり です»?
+ Tengo intención de quedar. :: つもり = intención personal.
- Ya quedé. :: Eso sería el pasado.
- No quiero quedar. :: Eso sería lo contrario.
Q ¿Qué expresa «よてい です»?
+ Un plan que ya está fijado. :: よてい = plan con fecha.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H らいげつ に にほん へ いく ___ です。 :: Tengo planeado ir a Japón el mes que viene.
+ よてい :: Plan ya fijado.
- たい :: Eso sería «quiero ir».
- ください :: Eso sería una petición.
H わたし は あした ともだち と あう ___ です。 :: Tengo intención de quedar mañana con un amigo.
+ つもり :: Intención personal.
- ように なりました :: Eso es un cambio.
- ことに なりました :: Eso es una decisión ajena.
R あした、 ともだち と あう つもり です。 :: Traduce la frase.
+ Tengo intención de quedar mañana con un amigo. :: つもり = intención.
- Quedé ayer con un amigo. :: Eso sería el pasado.
- Un amigo quedó conmigo. :: Eso sería lo contrario.
A らいげつ に にほん へ いく よてい です。 :: ¿Qué informa?
+ Tiene planeado viajar a Japón el mes que viene. :: よてい = plan fijado.
- Viajó a Japón el mes pasado. :: Eso sería el pasado.
- No irá a Japón. :: Eso es lo contrario.
O わたし は あう つもり です :: Tengo intención de quedar. :: つもり = intención.
Q ¿Cuál se usa para un plan ya apuntado en la agenda?
+ よてい です :: Plan fijado.
- つもり です :: Eso es intención personal.
- ように なりました :: Eso es un cambio.

@ 18 | けいかく (2) | Decidir
I Ahora, cómo decir que has tomado una decisión. Hay dos maneras, según quién decide.
E 〜ことに しました: decidir uno mismo :: Verbo en forma de diccionario + **こと に しました** = decidí: **まいにち うんどう する こと に しました** (decidí hacer ejercicio cada día). :: La decisión la tomas tú.
E 〜ことに なりました: se ha decidido :: Verbo en forma de diccionario + **こと に なりました** = se ha decidido que: **らいねん、 にほん で はたらく こと に なりました** (se ha decidido que trabajaré en Japón el año que viene). :: La decisión viene de la empresa, de otra persona o de las circunstancias, no solo de ti.
B Decidir | Forma | Significa | Quién decide
| 〜こと に しました | decidí | する こと に しました | tú
| 〜こと に なりました | se ha decidido | はたらく こと に なりました | otros, las circunstancias
W うんどう = ejercicio físico, deporte | undō
W する = hacer (forma de diccionario) | suru
W らいねん = el año que viene | rainen
W はたらく = trabajar | hataraku
V Vocabulario: decidir
T Decisiones
- まいにち うんどう する こと に しました。 = Decidí hacer ejercicio cada día.
  > する こと に しました = decidí hacer
- らいねん、 にほん で はたらく こと に なりました。 = Se ha decidido que trabajaré en Japón el año que viene.
  > はたらく こと に なりました = se ha decidido que trabajaré
- けさ、 はやく おきる こと に しました。 = Esta mañana decidí levantarme temprano.
  > おきる こと に しました = decidí levantarme
Q ¿Qué significa «まいにち うんどう する こと に しました»?
+ Decidí hacer ejercicio cada día. :: こと に しました = decisión propia.
- Hago ejercicio cada día. :: Eso es un hábito.
- Quiero hacer ejercicio cada día. :: Eso sería 〜たい.
Q ¿Qué expresa «〜こと に なりました»?
+ Una decisión que viene de otros o de las circunstancias. :: なりました = se ha decidido.
- Un deseo. :: Eso sería 〜たい.
- Un permiso. :: Eso sería 〜ても いい.
H まいにち うんどう する ___ 。 :: Decidí hacer ejercicio cada día.
+ こと に しました :: Decisión propia.
- こと に なりました :: Decisión ajena.
- つもり です :: Intención, no una decisión tomada.
H らいねん、 にほん で はたらく ___ 。 :: Se ha decidido que trabajaré en Japón el año que viene.
+ こと に なりました :: Decisión ajena o de las circunstancias.
- はたらきたい :: Eso sería «quiero trabajar».
- はたらかない :: Eso sería «no trabajar».
R まいにち うんどう する こと に しました。 :: Traduce la frase.
+ Decidí hacer ejercicio cada día. :: に しました = decisión propia.
- Hago ejercicio cada día. :: Eso sería un hábito.
- Quiero hacer ejercicio cada día. :: Eso sería 〜たい.
A らいねん、 にほん で はたらく こと に なりました。 :: ¿Qué cuenta?
+ Que se ha decidido que trabajará en Japón el año que viene. :: なりました = decisión ajena.
- Que quiere trabajar en Japón. :: Eso sería 〜たい.
- Que trabajó en Japón el año pasado. :: Eso sería el pasado.
O まいにち うんどう する こと に しました :: Decidí hacer ejercicio cada día. :: に しました = decisión propia.
Q ¿Cuál de estas frases expresa una decisión de otra persona?
+ こと に なりました :: La decisión no es solo tuya.
- こと に しました :: Es decisión propia.
- つもり です :: Es intención.

@ 18 | けいかく (3) | Para qué se hace algo
I Por último, cómo decir la finalidad: para qué haces algo. Es una palabra muy útil para explicar tus razones.
E 〜ために: para (con un objetivo) :: Verbo en forma de diccionario + **ため に** = para: **にほんご を はなす ため に、 まいにち べんきょう します** (para hablar japonés, estudio cada día). :: Explica la meta de la acción que viene después.
E Cuidado con «ため» y «のに» :: **ため に** explica la finalidad: para lograr algo. :: No la confundas con **〜のに** (aunque), que verás en el capítulo 20.
B Finalidad | Forma | Significa | Ejemplo
| 〜ため に | para (lograr algo) | かいしゃ に いく ため に
| 〜ため に (dinero) | para ganar | おかね を かせぐ ため に
W ため = finalidad; objetivo; por causa de | tame
W かせぐ = ganar (dinero) | kasegu
W なぜ = ¿por qué? | naze
V Vocabulario: para qué
D Para qué estudias
まり: けんじ さん は なぜ まいにち べんきょう します か。 = Ken, ¿por qué estudias cada día?
  > なぜ = por qué
けんじ: にほんご を はなす ため に です。 = Para hablar japonés.
  > にほんご を はなす ため に = para hablar japonés
まり: すごい です ね。 = ¡Qué bien!
  > すごい です ね = ¡qué bien!
Q ¿Qué significa «にほんご を はなす ため に、 まいにち べんきょう します»?
+ Para hablar japonés, estudio cada día. :: ため に = finalidad.
- Hablo japonés cada día. :: Eso sería un hábito.
- Estudio cada día sin hablar japonés. :: Eso es lo contrario.
Q ¿Qué expresa «〜ために»?
+ Para qué se hace algo: la finalidad. :: ため に = para.
- Una condición. :: Eso sería 〜たら.
- Una opinión. :: Eso sería 〜と おもいます.
H かいしゃ に いく ___ 、 はやく おきます。 :: Para ir a la empresa, me levanto temprano.
+ ため に :: Finalidad.
- たら :: Eso sería «si/cuando».
- ながら :: Eso sería «mientras».
H おかね を かせぐ ___ 、 しごと を します。 :: Para ganar dinero, trabajo.
+ ため に :: Finalidad.
- まえに :: Eso sería «antes de».
- ながら :: Eso sería «mientras».
R にほんご を はなす ため に、 まいにち べんきょう します。 :: Traduce la frase.
+ Para hablar japonés, estudio cada día. :: ため に = finalidad.
- Hablo japonés cada día. :: Eso sería un hábito.
- Estudio cada día sin hablar japonés. :: Eso es lo contrario.
A かいしゃ に いく ため に、 はやく おきます。 :: ¿Por qué se levanta temprano?
+ Para ir a la empresa. :: ため に = finalidad.
- Porque tiene sueño. :: No aparece en la frase.
- Para dormir más. :: Eso es lo contrario.
O おかね を かせぐ ため に :: Para ganar dinero. :: ため に = finalidad.
Q ¿Cuál dice «para ir a la empresa»?
+ かいしゃ に いく ため に :: ため に = finalidad.
- かいしゃ に いく まえに :: Eso sería «antes de ir».
- かいしゃ に いったら :: Eso sería «cuando vaya».
