@ 27 | しよう と ところ (1) | Intentar: ようとする
I Hoy hablamos de los intentos: cuando alguien intenta hacer algo, aunque no lo consiga, y cuando alguien decide no intentarlo. Son frases de la vida diaria y de las historias.
E 〜ようとする: intentar :: Para decir que alguien intenta hacer algo: forma volitiva del verbo + **と する**: **ねこ が にげよう と して います** (el gato está intentando escapar). :: La forma volitiva se forma así: **にげる** → **にげよう**, **のむ** → **のもう**.
E 〜ようとしない: no intentar :: Para decir que alguien se niega a intentarlo: forma volitiva + **と しない**: **こども は くすり を のまよう と しません** (el niño no quiere tomar la medicina). :: Suena a rechazo o terquedad.
B Intentar y negarse | Forma | Significa | Ejemplo
| 〜ようとする | intentar | にげよう と して います
| 〜ようとしない | negarse a intentar | のまよう と しません
W にげよう = (forma volitiva de にげる) huyamos; voy a huir | nigeyō
W のまよう = (forma volitiva de のむ) intentemos beber; voy a tomar | nomayō
W にげる = huir; escapar | nigeru
V Vocabulario: intentar
T Un gato y un niño
- ねこ が にげよう と して います。 = El gato está intentando escapar.
  > にげよう と して います = está intentando escapar
- こども は くすり を のまよう と しません。 = El niño no quiere tomar la medicina.
  > のまよう と しません = no quiere tomarla
Q ¿Qué significa «ねこ が にげよう と して います»?
+ El gato está intentando escapar. :: ようとする = intentar.
- El gato escapó. :: Eso sería el pasado.
- El gato no quiere huir. :: Eso sería ようとしない.
Q ¿Qué expresa «〜ようとする»?
+ Intentar o estar a punto de hacer algo. :: Acción que se intenta.
- Una orden. :: Eso sería 〜て ください.
- Un hábito. :: Eso sería 〜ます.
H ねこ が ___ と して います。 :: El gato está intentando escapar.
+ にげよう :: Forma volitiva de にげる.
- にげて :: Eso es la forma て.
- にげた :: Eso es el pasado.
H こども は くすり を ___ と しません。 :: El niño no quiere tomar la medicina.
+ のまよう :: Forma volitiva de のむ.
- のんで :: Eso es la forma て.
- のみます :: Eso es el presente educado.
R こども は くすり を のまよう と しません。 :: Traduce la frase.
+ El niño no quiere tomar la medicina. :: ようとしない = negarse a intentar.
- El niño intenta tomar la medicina. :: Eso es lo contrario.
- El niño toma la medicina todos los días. :: Eso es un hábito.
A ねこ が にげよう と して います。 :: ¿Qué pasa?
+ El gato intenta escapar. :: ようとする = intentar.
- El gato duerme. :: No aparece en la frase.
- El gato no sale. :: Eso es lo contrario.
O にげよう と して います :: Está intentando escapar. :: ようとする = intentar.
Q ¿Cuál es la forma volitiva de «にげる»?
+ にげよう :: Verbo del grupo 2: る → よう.
- にげて :: Es la forma て.
- にげない :: Es la forma negativa.

@ 27 | しよう と ところ (2) | Estar a punto de: ところだ y たところ
I Ahora dos expresiones para hablar de momentos: cuando algo está a punto de ocurrir y cuando algo acaba de ocurrir y el resultado no fue el esperado.
E 〜ところだ: estar a punto de :: Para decir que algo va a empezar justo ahora: verbo en forma de diccionario + **ところ です**: **いま、 ちょうど でかける ところ です** (ahora mismo estoy a punto de salir). :: Va con **ちょうど** (justo) cuando el momento es exacto.
E 〜たところ: al hacerlo, resultó que :: Para contar lo que pasó al hacer algo: verbo en forma た + **ところ**: **でんわ を かけた ところ、 でませんでした** (llamé, y no contestó). :: El resultado va después de la coma y suele ser inesperado.
B Momento y resultado | Forma | Significa | Ejemplo
| 〜ところ です | estoy a punto de | でかける ところ です
| 〜た ところ | al hacerlo, resultó que | かけた ところ
W ちょうど = justo; exactamente | chōdo
W ところ = punto; momento; lugar | tokoro
W かけた = llamé (de かける) | kaketa
W しかたが = (de しかた) remedio, forma de | shikata ga
V Vocabulario: momento y resultado
D Un día de llamadas
やまだ: いま、 ちょうど でかける ところ です。 = Ahora mismo estoy a punto de salir.
  > でかける ところ です = estoy a punto de salir
けんじ: でんわ を かけた ところ、 でませんでした。 = Llamé, y no contestó.
  > かけた ところ = al llamar | でませんでした = no contestó
Q ¿Qué significa «いま、 ちょうど でかける ところ です»?
+ Ahora mismo estoy a punto de salir. :: ところ です = a punto de.
- Ya salí hace rato. :: Eso sería el pasado.
- No voy a salir hoy. :: Eso es lo contrario.
Q ¿Qué expresa «〜た ところ»?
+ Lo que pasó al hacer algo: el resultado. :: Suele ser inesperado.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H いま、 ちょうど でかける ___ です。 :: Ahora mismo estoy a punto de salir.
+ ところ :: Momento exacto.
- ため :: Eso sería finalidad.
- とき :: Eso sería cuando, sin el momento exacto.
H でんわ を ___ 、 でませんでした。 :: Llamé, y no contestó.
+ かけた ところ :: Al hacerlo, resultó.
- かける まえに :: Eso sería antes de llamar.
- かけません :: Eso es «no llamo».
R いま、 ちょうど でかける ところ です。 :: Traduce la frase.
+ Estoy a punto de salir ahora mismo. :: ところ です = a punto de.
- Acabo de salir. :: Eso es el pasado.
- Saldré mañana. :: Eso es futuro.
A でんわ を かけた ところ、 でませんでした。 :: ¿Qué pasó?
+ Llamó, pero no contestaron. :: た ところ = resultado.
- Llamó y contestaron enseguida. :: Eso es lo contrario.
- No llamó. :: Eso es lo contrario.
O ちょうど でかける ところ です :: Estoy a punto de salir. :: ところ です = a punto de.
Q ¿Qué significa «ところ» en «ちょうど でかける ところ»?
+ El momento exacto antes de hacer algo. :: A punto de.
- Un lugar. :: Eso es otro sentido.
- Un plan. :: Eso sería よてい.

@ 27 | しよう と ところ (3) | No poder evitarlo: てしょうがない y てしかたがない
I Por último, dos formas para decir que algo es tan intenso que no puedes evitarlo: frío, hambre, preocupación. Son frases muy habladas.
E 〜てしょうがない: insoportable :: Para decir que sientes algo muy intensamente y no puedes evitarlo: adjetivo en forma て + **しょうがない**: **ふゆ は さむくて しょうがない です** (en invierno hace un frío insoportable). :: Con **しかたが ない** se dice lo mismo: **おなか が すいて しかたが ない** (tengo muchísima hambre).
E Con nombres: con preocupación :: Con un sustantivo se usa **で**: **しんぱい で しょうがない** (estoy muy preocupado). :: Es muy natural en la conversación.
B No poder evitarlo | Forma | Significa | Ejemplo
| 〜て しょうがない | insoportable | さむくて しょうがない
| 〜て しかたが ない | lo mismo | すいて しかたが ない
| 〜で しょうがない | con un nombre | しんぱい で しょうがない
W さむくて = frío (forma て de さむい) | samukute
W しょうがない = no hay remedio; insoportable | shōganai
W すいて = (forma て de すく) tener hambre (estar con hambre) | suite
V Vocabulario: no poder evitarlo
D Hambre y frío
けんじ: ふゆ は さむくて しょうがない です ね。 = El invierno hace un frío insoportable, ¿verdad?
  > さむくて しょうがない = hace un frío insoportable
まり: そう です ね。 わたし は おなか が すいて しかたが ない です。 = Sí. Yo tengo muchísima hambre.
  > おなか が すいて しかたが ない = tengo muchísima hambre
Q ¿Qué significa «ふゆ は さむくて しょうがない です»?
+ El invierno hace un frío insoportable. :: しょうがない = insoportable.
- El invierno no hace frío. :: Eso es lo contrario.
- El invierno es corto. :: No aparece en la frase.
Q ¿Qué expresa «〜て しょうがない»?
+ Un sentimiento tan intenso que no se puede evitar. :: Muy intenso.
- Una orden. :: Eso sería 〜て ください.
- Una obligación. :: Eso sería 〜なければ なりません.
H おなか が すいて ___ 。 :: Tengo muchísima hambre.
+ しかたが ない :: Forma equivalente.
- しません :: Eso es «no lo hago».
- すいた あと で :: Eso es después de tener hambre.
H しけん が ある ので、 しんぱい で ___ です。 :: Como hay examen, estoy muy preocupado.
+ しょうがない :: No se puede evitar.
- ください :: Eso sería una petición.
- いけません :: Eso sería «no se puede».
R ふゆ は さむくて しょうがない です。 :: Traduce la frase.
+ El invierno hace un frío insoportable. :: しょうがない = insoportable.
- En invierno no hace frío. :: Eso es lo contrario.
- El invierno es fresco. :: Eso es lo contrario.
A おなか が すいて しかたが ない。 :: ¿Qué dice?
+ Que tiene muchísima hambre. :: しかたが ない = insoportable.
- Que come mucho. :: No aparece en la frase.
- Que no tiene hambre. :: Eso es lo contrario.
O しんぱい で しょうがない です :: Estoy muy preocupado. :: しょうがない = insoportable.
Q ¿Qué sentido tiene «しょうがない» en «さむくて しょうがない»?
+ Que el frío no se puede soportar. :: Intensidad.
- Que no hay frío. :: Eso es lo contrario.
- Que hay que abrigarse. :: Eso sería una obligación.
