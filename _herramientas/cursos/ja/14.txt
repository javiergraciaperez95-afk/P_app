@ 14 | もし と アドバイス (1) | Si y cuando (condición)
I Hoy aprenderás a decir «si» y «cuando» de otra manera: no para preguntar, sino para imaginar o para hablar de algo que va a pasar.
E 〜たら: cuando (algo que va a pasar) :: Con la forma en **たら** (verbo en pasado + **ら**) hablas de algo que **va a ocurrir**: **ばんごはん を たべたら、 さんぽ を します** (cuando cene, doy un paseo). :: Se usa mucho cuando la acción de después todavía no ha pasado.
E 〜たら: si (una condición) :: Para una condición o una situación futura: **あめ が ふったら、 うち に います** (si llueve, me quedo en casa). También puede plantear una hipótesis: **おかね が あったら、 にほん へ いきたい です** (si tuviera dinero, querría ir a Japón).
E 〜なら: si es el caso de… :: **なら** retoma una situación o tema que ya se ha mencionado: **にほん へ いく なら、 はる が いい です** (si vas a Japón, la primavera es buena época). Se usa para ofrecer información o consejo sobre ese tema.
B Formas del pasado + ら | Verbo | Forma たら | Significa
| たべる (comer) | たべたら | cuando (si) como
| ふる (llover) | ふったら | si llueve
| ある (haber, tener) | あったら | si hubiera / si tuviera
| おわる (terminar) | おわったら | cuando termine
W たべたら = cuando coma; si comes | tabetara | Es la forma たら de たべる.
W ふったら = si llueve; cuando llueva | futtara | Es la forma たら de ふる.
W あったら = si hubiera; si tuviera | attara | Es la forma たら de ある.
W おわったら = cuando termine | owattara | Es la forma たら de おわる.
W おわる = terminar; acabar | owaru
W ふる = llover; caer (lluvia, nieve) | furu
W ある = haber, tener (cosas) | aru
W おかね = dinero | okane
W ひま = tiempo libre | hima
W 目的地 = destino | mokutekichi | Lectura: もくてきち.
W 着いたら = cuando llegue; si llega | tsuitara | Lectura: ついたら.
W 地図 = mapa | chizu | Lectura: ちず.
W 忘れ物 = objeto olvidado | wasuremono | Lectura: わすれもの.
W 駅員 = empleado de estación | ekiin | Lectura: えきいん.
W 電話 = teléfono; llamada | denwa | Lectura: でんわ.
W したら = si lo hace; cuando lo haga | shitara
W 聞いて = (forma て de 聞く) preguntar; escuchar | kiite
V Vocabulario: si y cuando
T Planes para hoy
- ばんごはん を たべたら、 さんぽ を します。 = Cuando cene, doy un paseo.
  > たべたら = cuando cene | さんぽ を します = doy un paseo
- あめ が ふったら、 うち に います。 = Si llueve, me quedo en casa.
  > ふったら = si llueve | うち に います = me quedo en casa
- おかね が あったら、 にほん へ いきます。 = Si tuviera dinero, iría a Japón.
  > あったら = si tuviera | にほん へ いきます = iría a Japón
- しごと が おわったら、 でんわ を ください。 = Cuando termine el trabajo, llámeme, por favor.
  > おわったら = cuando termine | でんわ を ください = llame, por favor
T Recordatorio para el viaje
- 目的地 に 着いたら、地図 を 見ます。 = Cuando llegue al destino, miraré el mapa.
- 駅 で 忘れ物 を したら、駅員 に 聞いて ください。 = Si olvida algo en la estación, llame al empleado.
Q ¿Qué debe hacer al llegar al destino?
+ Mirar el mapa. :: 着いたら、地図 を 見ます.
- Tomar el último tren. :: No aparece 終電.
- Ir a la empresa. :: No aparece 会社.
Q ¿Qué significa «ばんごはん を たべたら、 さんぽ を します»?
+ Cuando cene, daré un paseo. :: たら = cuando (algo que va a pasar).
- Antes de cenar, daré un paseo. :: Eso sería まえに.
- Mientras ceno, paseo. :: Eso sería ながら.
Q ¿Qué forma de «ふる» (llover) usas en «si llueve»?
+ ふったら :: Pasado + ら: si llueve.
- ふります :: Es el presente: llueve.
- ふって :: Es la forma て, no la condicional.
H あめ が ___、 うち に います。 :: Si llueve, me quedo en casa.
+ ふったら :: Condición.
- ふります :: Eso sería «llueve», no una condición.
- ふって :: Forma て: no sirve aquí.
H おかね が ___、 にほん へ いきます。 :: Si tuviera dinero, iría a Japón.
+ あったら :: Imaginando una condición.
- あります :: Eso sería «tengo dinero» de verdad.
- あって :: Forma て: no sirve aquí.
R しごと が おわったら、 でんわ を ください。 :: Traduce la frase.
+ Cuando termine el trabajo, llámeme. :: たら = cuando.
- Antes de terminar el trabajo, llame. :: Eso sería まえに.
- Mientras termino el trabajo, llame. :: Eso sería ながら.
A あめ が ふったら、 うち に います。 :: ¿Qué dice?
+ Si llueve, se queda en casa. :: Condición y consecuencia.
- Si llueve, sale a pasear. :: Eso no está en la frase.
- Aunque llueva, sale. :: Eso sería 〜ても.
O ばんごはん を たべたら :: Cuando cene. :: たら = cuando (algo futuro).
Q ¿Cuál dice «si tuviera dinero»?
+ おかね が あったら :: Forma たら de ある.
- おかね が あります :: Eso es «tengo dinero».
- おかね が ありません :: Eso es «no tengo dinero».
Q En «にほん へ いく なら、 はる が いい です», ¿qué expresa なら?
+ Si se da el caso de ir a Japón. :: なら retoma un tema para dar información o consejo.
- Que ya fue a Japón. :: Eso sería にほん へ いきました.
- Que debe ir a Japón. :: La frase no expresa obligación.

@ 14 | もし と アドバイス (2) | Cuando siempre pasa (と)
I La partícula と también sirve para decir que algo pasa **siempre** que se cumple otra cosa. Es muy útil para indicar caminos y para explicar cómo funcionan las cosas.
E 〜と: resultado natural :: Con un verbo en forma de diccionario + **と**, presentas un resultado que ocurre normalmente o de manera automática: **ボタン を おす と、 ドア が あきます** (al pulsar el botón, la puerta se abre). También se usa para dar indicaciones: **みぎ に まがる と、 えき が あります**. :: En este uso, evita una orden o una petición en la segunda parte.
E Cuidado: no es una petición :: Con **と** no se pide nada: no digas «**〜と ください**». Para pedir se usa **〜て ください**. :: Para decir que algo ocurre cada año: **はる に なる と、 さくら が さきます** (en primavera, los cerezos florecen).
B 〜と: resultado automático | Verbo | Forma と | Ejemplo
| まがる (girar) | まがる と | みぎ に まがる と、 えき が あります
| なる (llegar a ser) | なる と | はる に なる と、 さくら が さきます
| おす (pulsar) | おす と | ボタン を おす と、 ドア が あきます
W まがる = girar, doblar | magaru
W なる = llegar a ser; convertirse | naru
W さくら = cerezo; flor de cerezo | sakura
W さきます = florecer | sakimasu
W ボタン = botón | botan
W おす = pulsar, empujar | osu
W あきます = abrirse | akimasu | Es intransitivo: la puerta se abre sola.
W 交番 = puesto de policía | kouban | Lectura: こうばん.
W 直進 = seguir recto | chokushin | Lectura: ちょくしん.
W 出口 = salida | deguchi | Lectura: でぐち.
W 角 = esquina | kado | Lectura: かど.
W 左折 = giro a la izquierda | sasetsu | Lectura: 左折.
V Vocabulario: lo que siempre pasa
D Cómo llegar
けんじ: すみません、 えき は どこ です か。 = Perdone, ¿dónde está la estación?
  > えき は どこ です か = ¿dónde está la estación?
やまだ: まっすぐ いく と、 みぎ に ぎんこう が あります。 = Si va todo recto, a la derecha hay un banco.
  > まっすぐ いく と = si va todo recto | みぎ に ぎんこう が あります = a la derecha hay un banco
けんじ: ぎんこう の となり です か。 = ¿Está al lado del banco?
  > となり = al lado (A1 - pendiente)
やまだ: はい、 そう です。 = Sí, así es.
  > そう です = así es
T Dos cosas que pasan siempre
- ボタン を おす と、 ドア が あきます。 = Al pulsar el botón, la puerta se abre.
  > ボタン を おす と = al pulsar el botón | ドア が あきます = la puerta se abre
- はる に なる と、 さくら が さきます。 = En primavera, los cerezos florecen.
  > はる に なる と = cuando llega la primavera | さくら が さきます = los cerezos florecen
Q ¿Qué significa «みぎ に まがる と、 えき が あります»?
+ Si gira a la derecha, hay una estación. :: と = si (siempre pasa).
- Gire a la derecha, por favor. :: Eso sería 〜て ください.
- Antes de girar a la derecha, hay una estación. :: Eso sería まえに.
Q ¿Qué expresa «〜と» en «はる に なる と»?
+ Algo que siempre pasa. :: と = resultado automático.
- Un deseo. :: Eso sería 〜たい.
- Una orden. :: Eso sería 〜て ください.
H ボタン を ___、 ドア が あきます。 :: Al pulsar el botón, la puerta se abre.
+ おす と :: と = siempre que.
- おして ください :: Eso sería una petición.
- おした あと で :: Eso sería después de pulsar.
H はる に なる ___、 さくら が さきます。 :: Cuando llega la primavera, florecen los cerezos.
+ と :: Resultado automático.
- まえに :: Eso sería antes de.
- ながら :: Eso sería mientras.
R はる に なる と、 さくら が さきます。 :: Traduce la frase.
+ En primavera, los cerezos florecen. :: と = siempre.
- En primavera, los cerezos florecieron. :: Eso sería さきました.
- En primavera, los cerezos no florecen. :: Eso sería さきません.
A みぎ に まがる と、 えき が あります。 :: ¿Qué información da?
+ Hay una estación si gira a la derecha. :: Condición y resultado.
- Hay un banco a la izquierda. :: No es la frase.
- Hay un parque delante. :: No es la frase.
O まっすぐ いく と :: Si va todo recto. :: と = si (siempre).
Q ¿Qué significa «ボタン を おす と、 ドア が あきます»?
+ Al pulsar el botón, la puerta se abre. :: と = resultado automático.
- Pulse el botón, por favor. :: Eso sería おして ください.
- No pulse el botón. :: Eso sería おさない.

@ 14 | もし と アドバイス (3) | Consejos: es mejor que
I Por último, cómo dar consejos con amabilidad. En japonés se aconseja con «es mejor que…», sin mandar.
E 〜た ほう が いい :: Para aconsejar que se haga algo: verbo en pasado + **ほう が いい です**: **かさ を もった ほう が いい です** (es mejor que lleve paraguas). :: Suena amable porque no das una orden.
E 〜ない ほう が いい :: Para aconsejar no hacer algo: verbo en forma -ない + **ほう が いい です**: **あまい もの を たべない ほう が いい です** (es mejor no comer dulces). :: Con **ほう** se compara «esta opción» con las otras y se dice cuál es la mejor.
E 〜ので: porque; como :: **ので** introduce una causa de manera explicativa y suave: **あめ が ふっている ので、 うち に いた ほう が いい です** (como está lloviendo, es mejor quedarse en casa). Con sustantivos y adjetivos en -na se usa **なので**: **あした は やすみ なので、 ゆっくり できます**.
B Dar un consejo | Forma | Significa | Ejemplo
| 〜た ほう が いい | hacerlo es mejor | かさ を もった ほう が いい です
| 〜ない ほう が いい | no hacerlo es mejor | あまい もの を たべない ほう が いい です
W もった = (forma た de もつ) llevó; habiendo llevado | motta
W ほう = lado; opción; mejor opción | hō
W ねた = (forma た de ねる) durmió; habiendo dormido | neta
W たべない = (forma ない de たべる) no comer | tabenai
W あまい = dulce | amai
V Vocabulario: consejos
T Consejos de un amigo
- つかれた とき は、 はやく ねた ほう が いい です。 = Cuando estés cansado, es mejor que te acuestes temprano.
  > ねた ほう が いい = es mejor que te acuestes | はやく = temprano
- あした は あめ が ふります。 かさ を もった ほう が いい です。 = Mañana llueve. Es mejor que lleves paraguas.
  > もった ほう が いい = es mejor que lleves
- あまい もの を たべない ほう が いい です。 = Es mejor no comer dulces.
  > たべない ほう が いい = es mejor no comer
Q ¿Qué significa «かさ を もった ほう が いい です»?
+ Es mejor que lleve paraguas. :: た ほう が いい = es mejor hacerlo.
- Llevo un paraguas. :: Eso sería もちます.
- Compré un paraguas. :: Eso sería かいました.
Q ¿Qué significa «あまい もの を たべない ほう が いい»?
+ Es mejor no comer dulces. :: ない ほう が いい = es mejor no hacerlo.
- Como dulces siempre. :: Eso sería たべます.
- Quiero comer dulces. :: Eso sería たべたい.
H あまい もの を ___ ほう が いい です。 :: Es mejor no comer dulces.
+ たべない :: ない ほう が いい.
- たべた :: Eso sería que es mejor haberlos comido.
- たべて ください :: Eso sería una petición.
H つかれた とき は、 はやく ___ ほう が いい です。 :: Es mejor que te acuestes.
+ ねた :: た ほう が いい.
- ねて ください :: Eso sería una petición.
- ねる まえ :: Eso no encaja en el consejo.
R かさ を もった ほう が いい です。 :: Traduce la frase.
+ Es mejor que lleve paraguas. :: Consejo amable.
- Quiero llevar paraguas. :: Eso sería たい.
- Compré un paraguas. :: Eso sería かいました.
A あまい もの を たべない ほう が いい です。 :: ¿Qué aconsejan?
+ Que no coma dulces. :: Consejo negativo.
- Que coma dulces. :: Eso es lo contrario.
- Que compre dulces. :: No aparece.
O はやく ねた ほう が いい です :: Es mejor que se acueste temprano. :: Consejo.
Q ¿Cuál es el consejo de «つかれた とき は、 はやく ねた ほう が いい»?
+ Acostarse temprano si está cansado. :: Consejo.
- Trabajar más si está cansado. :: No aparece.
- Salir de noche si está cansado. :: No aparece.
Q En «あめ が ふっている ので、 うち に います», ¿qué expresa ので?
+ La causa: como está lloviendo, se queda en casa. :: ので conecta causa y resultado.
- El propósito: estudia para hablar. :: Eso sería ために.
- Una condición imaginaria. :: Eso sería たら.

W ところ = lugar; punto | tokoro | Lectura: ところ.
W 曲がります = girar; doblar | magarimasu | ます: forma educada de 曲がる.
W 近く = cerca | chikaku | Lectura: ちかく.
W 交差点 = cruce; intersección | kousaten | Lectura: こうさてん.
W 信号 = semáforo; señal | shingou | Lectura: しんごう.
W 橋 = puente | hashi | Lectura: はし.
W 入口 = entrada | iriguchi | Lectura: いりぐち.
W 曲がる = girar; doblar | magaru | Lectura: まがる.
V Lectura: indicaciones para llegar
T Indicaciones en un barrio
- まっすぐ 行く と、交差点 が あります。 = Si sigue recto, encontrará un cruce.
- 信号 の ところ を 右 に 曲がります。 = Gire a la derecha en el semáforo.
- 橋 の 近く に 入口 が あります。 = La entrada está cerca del puente.
Q ¿Dónde debe girar?
+ A la derecha, en el semáforo. :: 信号 の ところ を 右 に 曲がります.
- A la izquierda, en el puente. :: No se indica girar a la izquierda.
- Antes del cruce. :: Primero aparece el cruce.
Q ¿Dónde está la entrada?
+ Cerca del puente. :: 橋 の 近く に 入口 が あります.
- Detrás del semáforo. :: No lo dice el texto.
- Dentro del cruce. :: No lo dice el texto.
