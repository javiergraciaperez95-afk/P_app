@ 15 | しなければ なりません (1) | Tengo que... (obligación)
I Hoy aprendemos a decir que algo es necesario. En japonés es muy común, y se usa tanto en el trabajo como en casa.
E La forma なければ :: Para decir «tengo que», coge el verbo en forma **ない**, quita la **い** y añade **なければ**: **おき** + **なければ** → **おきなければ** (tengo que levantarme). :: Con **する** queda **しなければ**, y con **くる** queda **こなければ**. Para los verbos del grupo 1 la forma ない cambia la última letra a **あ** (のむ → のまない → のまなければ).
E Dos maneras de decirlo :: **〜なければ なりません** y **〜なければ いけません** significan lo mismo: **はやく おきなければ なりません** (tengo que levantarme temprano). :: Son formas educadas. En el habla informal se dice **〜なきゃ**.
B Tener que hacer algo | Verbo | Forma なければ | Ejemplo
| おきる (levantarse) | おきなければ | はやく おきなければ なりません
| する (hacer) | しなければ | しごと を しなければ いけません
| のむ (beber, tomar) | のまなければ | くすり を のまなければ なりません
W おきなければ = tengo que levantarme | okinakereba | Es la forma なければ de おきる.
W しなければ = tengo que hacer | shinakereba | Es la forma なければ de する.
W のまなければ = tengo que tomar (beber) | nomanakereba | Es la forma なければ de のむ.
W なりません = no es posible; no se puede (ser) | narimasen | Va con なければ para decir «hay que».
W おおい = muchos; abundante | ōi
W 提出 = entrega; presentar | teishutsu | Lectura: ていしゅつ.
W 書類 = documento; papeles | shorui | Lectura: しょるい.
W 締切 = fecha límite | shimekiri | Lectura: しめきり.
W 必要 = necesario | hitsuyou | Lectura: ひつよう.
W 規則 = regla | kisoku | Lectura: 規則.
W 遅刻 = llegar tarde | chikoku | Lectura: 遅刻.
W 守る = respetar; cumplir | mamoru | Lectura: 守る.
V Vocabulario: tener que
D Un día de trabajo
まり: あした は しごと が おおい です ね。 = Mañana hay mucho trabajo, ¿verdad?
  > しごと が おおい = hay mucho trabajo
けんじ: はい。 はやく おきなければ なりません。 = Sí. Tengo que levantarme temprano.
  > おきなければ なりません = tengo que levantarme
まり: くすり を のまなければ いけません よ。 = Tiene que tomar la medicina, ¿eh?
  > のまなければ いけません = hay que tomar
けんじ: はい、 わかりました。 = Sí, entendido.
  > わかりました = entendido
Q ¿Qué significa «おきなければ なりません»?
+ Tengo que levantarme. :: なければ なりません = obligación.
- No tengo que levantarme. :: Eso sería なくても いい.
- Quiero levantarme. :: Eso sería 〜たい.
Q ¿Cuál es la forma なければ de «のむ»?
+ のまなければ :: Del grupo 1: の-む → の-ま + なければ.
- のむなければ :: No se usa el diccionario con なければ.
- のみなければ :: No es la forma ない de のむ.
H あした は はやく ___ なりません。 :: Tengo que levantarme temprano mañana.
+ おきなければ :: Forma なければ de おきる.
- おきない でも :: No expresa obligación.
- おきたい :: Eso sería «quiero».
H くすり を ___ いけません。 :: Tengo que tomar la medicina.
+ のまなければ :: Obligación.
- のまないで ください :: Eso sería «no tome».
- のみたい :: Eso sería «quiero beber».
R しごと を しなければ いけません。 :: Traduce la frase.
+ Tengo que trabajar. :: なければ いけません = obligación.
- No tengo que trabajar. :: Eso sería なくても いい.
- Puedo trabajar. :: Eso sería できます.
A わかりました。 :: ¿Qué responde?
+ Entendido. :: Confirma que ha entendido.
- Lo siento mucho. :: Eso sería ざんねん.
- Gracias por la comida. :: Eso sería ごちそうさま.
O はやく おきなければ なりません :: Tengo que levantarme temprano. :: なければ なりません = obligación.

@ 15 | しなければ なりません (2) | No hace falta (なくても いい)
I Lo contrario de la obligación: decir que algo no hace falta. Es una frase muy amable y muy útil.
E Forma なくても いい :: Para decir que **no hace falta**, coge la forma **ない** del verbo, quita la **い** y añade **なくても いい です**: **いか** + **なくても いい** → **いかなくても いい です** (no hace falta ir). :: Con **する** queda **しなくても いい**, y con **たべる** queda **たべなくても いい**.
E Con cuidado :: **なくても いい** no es una prohibición: solo dice que no es necesario. Si quieres prohibir, usa **〜てはいけません** (capítulo 11). :: 
B No hace falta | Verbo | Forma なくても | Ejemplo
| いく (ir) | いかなくても | がっこう へ いかなくても いい です
| もつ (tener, llevar) | もたなくても | おかね は もたなくても いい です
| いそぐ (darse prisa) | いそがなくても | いそがなくても いい です
W いかなくても = no hace falta ir | ikanakutemo | Es la forma なくても de いく.
W もたなくても = no hace falta llevar | motanakutemo | Es la forma なくても de もつ.
W いそがなくても = no hace falta darse prisa | isoganakutemo | Es la forma なくても de いそぐ.
W いそぐ = darse prisa | isogu
W 持参 = traer consigo | jisan | Lectura: じさん.
W 用意 = preparación; preparar | youi | Lectura: ようい.
W 申請 = solicitud; solicitar | shinsei | Lectura: しんせい.
W 会員 = socio; miembro | kaiin | Lectura: かいいん.
W 身分証 = documento de identidad | mibunshou | Lectura: 身分証.
W 会費 = cuota | kaihi | Lectura: 会費.
W 期限 = plazo | kigen | Lectura: 期限.
W 持ち物 = cosas que llevar | mochimono | Lectura: 持ち物.
V Vocabulario: no hace falta
D El fin de semana
けんじ: あした は やすみ です か。 = ¿Mañana es fiesta?
  > やすみ です か = ¿es fiesta?
まり: はい。 がっこう へ いかなくても いい です。 = Sí. No hace falta ir a la escuela.
  > いかなくても いい です = no hace falta ir
けんじ: じゃあ、 いそがなくても いい です ね。 = Entonces, no hace falta que te des prisa, ¿verdad?
  > いそがなくても いい です = no hace falta darse prisa
まり: はい。 ゆっくり いきましょう。 = Sí. Vayamos con calma.
  > ゆっくり いきましょう = vayamos con calma
Q ¿Qué significa «いかなくても いい です»?
+ No hace falta ir. :: なくても いい = no hace falta.
- Hay que ir. :: Eso sería なければ なりません.
- Quiero ir. :: Eso sería 〜たい.
Q ¿Cómo se dice «no hace falta comprar»?
+ かわなくても いい :: Forma なくても de かう.
- かわなければ なりません :: Eso es «hay que comprar».
- かいたい :: Eso es «quiero comprar».
H あした は やすみ です。 がっこう へ ___ いい です。 :: Mañana es fiesta: no hace falta ir a la escuela.
+ いかなくても :: No hace falta.
- いかなければ :: Eso es «hay que ir».
- いきたい :: Eso es «quiero ir».
H おかね は ___ いい です。 :: No hace falta llevar dinero.
+ もたなくても :: Forma なくても de もつ.
- もたなければ :: Eso es «hay que llevar».
- もちたい :: Eso es «quiero llevar».
R じゃあ、 いそがなくても いい です ね。 :: Traduce la frase.
+ Entonces, no hace falta que te des prisa, ¿verdad? :: なくても いい = no hace falta.
- Entonces, hay que darse prisa. :: Eso sería なければ なりません.
- Entonces, quiero darme prisa. :: Eso sería 〜たい.
A やすみ です か。 :: ¿Qué pregunta?
+ ¿Es fiesta? :: やすみ = día libre.
- ¿Tiene que trabajar? :: No aparece en la frase.
- ¿Dónde está la escuela? :: No aparece en la frase.
O ゆっくり いきましょう :: Vayamos con calma. :: いきましょう = vayamos.
Q ¿Qué significa «なくても いい»?
+ No hace falta. :: Expresa que no es necesario.
- Está prohibido. :: Eso sería 〜ては いけません.
- Es obligatorio. :: Eso sería 〜なければ なりません.

@ 15 | しなければ なりません (3) | Pedir que no se haga (ないでください)
I Ahora la forma para pedir a alguien que no haga algo. Es muy útil en museos, tiendas, hospitales y casas.
E 〜ないでください :: Para pedir que **no** se haga algo: coge la forma **ない** del verbo, quita la **い** y añade **で ください**: **あけ** + **ないで ください** → **あけないで ください** (no abra, por favor). :: Es más suave que la prohibición de 〜てはいけません: suena a petición.
E Las formas se repiten :: **とる** → **とらないで** (no tomar, no sacar): **しゃしん を とらないで ください** (no saque fotos, por favor). :: **はしる** → **はしらないで** (no correr). **たべる** → **たべないで** (no comer).
B Pedir que no se haga | Verbo | Forma ないで ください | Ejemplo
| あける (abrir) | あけないで | まど を あけないで ください
| とる (tomar, sacar) | とらないで | しゃしん を とらないで ください
| はしる (correr) | はしらないで | ここ で はしらないで ください
| たべる (comer) | たべないで | ここ で たべないで ください
W あけないで = no abra, por favor | akenaide
W とらないで = no saque, por favor | toranaide | Es la forma ないで de とる.
W はしらないで = no corra, por favor | hashiranaide
W たべないで = no coma, por favor | tabenaide
W はしる = correr | hashiru
W 館内 = dentro del edificio | kannai | Lectura: 館内.
V Vocabulario: no hagas
T En un museo y un parque
- ここ で しゃしん を とらないで ください。 = Aquí no saque fotos, por favor.
  > とらないで ください = no saque, por favor
- まど を あけないで ください。 = No abra la ventana, por favor.
  > あけないで ください = no abra, por favor
- ここ で はしらないで ください。 = Aquí no corra, por favor.
  > はしらないで ください = no corra, por favor
- ここ で たべないで ください。 = Aquí no coma, por favor.
  > たべないで ください = no coma, por favor
Q ¿Qué significa «ここ で たべないで ください»?
+ Aquí no coma, por favor. :: ないで ください = petición negativa.
- Aquí coma, por favor. :: Eso sería 〜て ください.
- Aquí puede comer. :: Eso sería 〜て もいい です.
Q ¿Qué forma es «あけないで»?
+ La forma ない de あける + ないで ください. :: Pedir que no se haga.
- La forma て de あける. :: Eso sería pedir que se haga.
- La forma de diccionario. :: No es una petición.
H まど を ___ 。 :: Por favor, no abra la ventana.
+ あけないで ください :: Petición negativa.
- あけて ください :: Eso sería «abra, por favor».
- あけなければ なりません :: Eso sería «hay que abrir».
H ここ で しゃしん を ___ 。 :: Aquí no saque fotos, por favor.
+ とらないで ください :: Petición negativa.
- とって ください :: Eso sería «saque, por favor».
- とっても いい です :: Eso sería «se puede sacar».
R ここ で はしらないで ください。 :: Traduce la frase.
+ Aquí no corra, por favor. :: ないで ください = petición negativa.
- Aquí corra, por favor. :: Eso sería はしって ください.
- Aquí puede correr. :: Eso sería はしっても いい です.
A ここ で たべないで ください。 :: ¿Qué pide?
+ Que no coma aquí. :: Pide no hacer algo.
- Que coma aquí. :: Eso es lo contrario.
- Que compre comida aquí. :: No aparece en la frase.
O しゃしん を とらないで ください :: Por favor, no saque fotos. :: ないで ください = no hacer, por favor.
Q ¿Cómo dices «por favor, no abra la puerta»?
+ ドア を あけないで ください :: Forma ないで ください.
- ドア を あけて ください :: Eso sería «abra, por favor».
- ドア を あけても いい です :: Eso sería «se puede abrir».

W 受付 = recepción; mostrador de atención | uketsuke | Lectura: うけつけ.
