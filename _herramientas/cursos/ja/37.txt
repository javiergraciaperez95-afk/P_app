@ 37 | ままに と ずじまい (1) | Sin llegar a: ずじまい
I Hoy hablamos de lo que no llegó a pasar: algo que se quiso hacer y se quedó sin hacer, sin que hubiera remedio. Es una forma de expresar pena o resignación.
E 〜ずじまい: sin llegar a hacerlo :: Para decir que, al final, algo no se hizo, y ya no hubo ocasión: forma ない sin い + **ず じまい**: **けっきょく、 その みせ に いかず じまい でした** (al final no llegué a ir a esa tienda). :: El verbo する queda **せず じまい**.
E Sentimiento de pena :: Expresa que no se consiguió lo que se quería. :: Suena a resignación o a lamento.
B No llegar a hacer | Forma | Significa | Ejemplo
| 〜ず じまい | no llegar a hacer | いかず じまい
| せず じまい | no llegar a hacer (する) | せず じまい
W いかず = sin ir (forma ず de いく) | ikazu
W じまい = (sin) llegar a; sin poder | jimai
W よまず = sin leer (forma ず de よむ) | yomazu
V Vocabulario: sin llegar a
D Un viaje que no fue
けんじ: あの みせ、 いった の？ = ¿Fuiste a esa tienda?
  > いった の = ¿fuiste?
まり: いいえ、 けっきょく いかず じまい でした。 = No, al final no llegué a ir.
  > いかず じまい でした = no llegué a ir
T Lo que se quedó sin hacer
- けっきょく、 その みせ に いかず じまい でした。 = Al final no llegué a ir a esa tienda.
  > いかず じまい でした = no llegué a ir
- ほん は さいご まで よまず じまい でした。 = No llegué a leer el libro hasta el final.
  > よまず じまい = no llegué a leerlo
Q ¿Qué significa «けっきょく、 その みせ に いかず じまい でした»?
+ Al final no llegué a ir a esa tienda. :: ずじまい = sin llegar a.
- Fui a esa tienda y me gustó. :: Eso es lo contrario.
- Iré a esa tienda mañana. :: Eso es futuro.
Q ¿Qué expresa «〜ず じまい»?
+ Que algo no se hizo y ya no hubo ocasión. :: Pena o resignación.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H けっきょく、 その みせ に ___ でした。 :: Al final no llegué a ir.
+ いかず じまい :: No llegar a ir.
- いきたい :: Eso sería querer ir.
- いきました :: Eso sería que fui.
H ほん は さいご まで よまず ___ でした。 :: No llegué a leerlo.
+ じまい :: Sin llegar a.
- ながら :: Eso sería mientras.
- ために :: Eso sería para.
R けっきょく、 その みせ に いかず じまい でした。 :: Traduce la frase.
+ In the end, I never got to go to that shop. :: ずじまい = sin llegar a.
- In the end, I went to that shop. :: Eso es lo contrario.
- I will go to that shop tomorrow. :: Eso es futuro.
A うん、 けっきょく いかず じまい でした。 :: ¿Qué cuenta?
+ Que no llegó a ir. :: Pena o resignación.
- Que fue y le gustó. :: Eso es lo contrario.
- Que no sabe. :: No aparece.
O いかず じまい でした :: No llegó a ir. :: ずじまい = sin llegar a.
Q ¿Cuál es la forma de «ずじまい» con する?
+ せず じまい :: Forma ず de する.
- しない じまい :: No es la forma correcta.
- して じまい :: No es la forma correcta.

@ 37 | ままに と ずじまい (2) | Tal como está: まま
I Ahora, cómo decir que algo se queda igual que estaba, sin cambiar. Es muy útil para describir la forma en que alguien hace algo, o un estado que no se corrige.
E 〜まま: tal como está :: Para decir que algo sigue igual, sin cambiar: forma た o forma de estado + **まま**: **くつ を はいた まま、 ねて しまいました** (me dormí con los zapatos puestos). :: Se usa con objetos que llevas o con un estado de una persona.
E 〜ままに: según; siguiendo :: Para decir que se actúa siguiendo algo: verbo en forma normal + **ままに**: **こころ の ままに いきる** (vivir según el corazón). :: Suena más literario.
B Sin cambiar | Forma | Significa | Ejemplo
| 〜た まま | tal como está | はいた まま
| 〜ままに | según; siguiendo | こころ の ままに
W まま = tal cual; sin cambiar | mama
W はいた = (forma た de はく) puse (zapatos, pantalones) | haita
W こころ = corazón; sentimientos | kokoro
W しまった = lo hizo sin querer; se acabó del todo | shimatta
W ままに = según; siguiendo | mama ni
V Vocabulario: tal como está
D Un cansancio
まり: くつ を はいた まま、 ねて しまった の？ = ¿Te dormiste con los zapatos puestos?
  > はいた まま = con los zapatos puestos
けんじ: うん。 くつ を はいた まま、 ねて しまいました。 = Sí. Me dormí con los zapatos puestos.
  > はいた まま = tal como estaban puestos
T Lo que se queda igual
- くつ を はいた まま、 ねて しまいました。 = Me dormí con los zapatos puestos.
  > はいた まま = con los zapatos puestos
- こころ の ままに いきます。 = Vivo siguiendo mi corazón.
  > こころ の ままに = siguiendo mi corazón
Q ¿Qué significa «くつ を はいた まま、 ねて しまいました»?
+ Me dormí con los zapatos puestos. :: まま = tal como está.
- Me dormí y me quité los zapatos. :: Eso es lo contrario.
- Me puse los zapatos después de dormir. :: Eso invierte el orden.
Q ¿Qué expresa «〜まま»?
+ Que algo sigue igual sin cambiar. :: Estado.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H くつ を はいた ___ 、 ねて しまいました。 :: Me dormí con los zapatos puestos.
+ まま :: Tal como está.
- ずじまい :: Eso sería sin llegar a.
- ために :: Eso sería para.
H こころ の ___ いきます。 :: Vivo siguiendo mi corazón.
+ ままに :: Siguiendo.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
R くつ を はいた まま、 ねて しまいました。 :: Traduce la frase.
+ I fell asleep with my shoes on. :: まま = tal como está.
- I fell asleep and took my shoes off. :: Eso es lo contrario.
- I put my shoes on after sleeping. :: Eso invierte el orden.
A うん。 くつ を はいた まま、 ねて しまいました。 :: ¿Qué cuenta?
+ Que se durmió con los zapatos puestos. :: Estado sin cambio.
- Que se quitó los zapatos. :: Eso es lo contrario.
- Que no se durmió. :: Eso es lo contrario.
O くつ を はいた まま :: Con los zapatos puestos. :: まま = tal como está.
Q ¿Cuál es el sentido de «ままに»?
+ Seguir algo sin oponerse. :: Según.
- Causa. :: Eso sería ので.
- Finalidad. :: Eso sería ために.

@ 37 | ままに と ずじまい (3) | Muy: てやまない
I Por último, una forma para expresar un sentimiento tan intenso y constante que no desaparece. Es muy literaria y se usa para hablar de deseos y afectos profundos.
E 〜てやまない: no dejo de (sentimiento profundo) :: Para decir que un sentimiento fuerte y constante no desaparece: verbo en forma て + **やまない**: **ともだち の しあわせ を のぞんで やみません** (no dejo de desear la felicidad de mi amigo). :: Solo se usa con sentimientos como 思う (pensar), 願う (desear) o 信じる (creer).
E Sentimiento de siempre :: Es una forma muy formal y escrita. :: Se usa en cartas y discursos.
B Sentimiento constante | Forma | Significa | Ejemplo
| のぞんで やみません | deseo sin parar | ともだち の しあわせ を のぞんで
| しんじて やみません | creo firmemente | しんじて やみません
W のぞんで = (forma て de のぞむ) deseando | nozonde
W しあわせ = felicidad | shiawase
W すてき = bonito; estupendo | suteki
W あなた = tú; usted | anata
W せいこう = éxito | seikō
W やみません = no dejo de; no puedo dejar de | yamimasen
W しんじて = creyendo (forma て de しんじる) | shinjite
V Vocabulario: sentimiento constante
D Una carta
けんじ: わたし は、 ともだち の しあわせ を のぞんで やみません。 = Yo no dejo de desear la felicidad de mi amigo.
  > のぞんで やみません = no dejo de desear
まり: すてき な ことば です ね。 = Qué bonitas palabras, ¿verdad?
  > すてき な ことば です ね = qué bonitas palabras
T Sentimientos profundos
- ともだち の しあわせ を のぞんで やみません。 = No dejo de desear la felicidad de mi amigo.
  > のぞんで やみません = no dejo de desear
- わたし は あなた の せいこう を しんじて やみません。 = No dejo de creer en tu éxito.
  > しんじて やみません = no dejo de creer
Q ¿Qué significa «ともだち の しあわせ を のぞんで やみません»?
+ No dejo de desear la felicidad de mi amigo. :: てやまない = sentimiento constante.
- Ya no deseo la felicidad de mi amigo. :: Eso es lo contrario.
- Deseo algo para mí. :: No aparece.
Q ¿Qué expresa «〜てやまない»?
+ Un sentimiento fuerte y constante. :: Muy formal.
- Una orden. :: Eso sería 〜て ください.
- Una causa. :: Eso sería ので.
H ともだち の しあわせ を ___ 。 :: No dejo de desear la felicidad de mi amigo.
+ のぞんで やみません :: Sentimiento constante.
- のぞみません :: Eso sería «no deseo».
- のぞんで いません :: Eso sería «no estoy deseando».
H わたし は あなた の せいこう を ___ 。 :: No dejo de creer en tu éxito.
+ しんじて やみません :: Sentimiento constante.
- しんじません :: Eso sería «no creo».
- しんじた あと で :: Eso sería después de creer.
R わたし は、 ともだち の しあわせ を のぞんで やみません。 :: Traduce la frase.
+ I can't stop hoping for my friend's happiness. :: てやまない = no dejo de.
- I hope my friend is not happy. :: Eso es lo contrario.
- I stopped hoping for my friend's happiness. :: Eso es lo contrario.
A すてき な ことば です ね。 :: ¿Qué opina?
+ Que son palabras bonitas. :: Admiración.
- Que son palabras malas. :: Eso es lo contrario.
- Que no entiende. :: No aparece.
O のぞんで やみません :: No dejo de desear. :: てやまない = sentimiento constante.
Q ¿Cuál es el registro de «〜てやまない»?
+ Formal y escrito. :: Cartas y discursos.
- Coloquial. :: Eso es falso.
- Infantil. :: Eso es falso.
