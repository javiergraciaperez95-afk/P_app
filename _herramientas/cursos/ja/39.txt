@ 39 | すぎない と まい (1) | Mientras: つつ y つつある
I Hoy aprendes a decir que dos cosas ocurren a la vez y que algo cambia poco a poco. Son expresiones formales, muy comunes en los textos escritos y en los medios.
E 〜つつ: mientras (a la vez, con tensión) :: Para decir que se hacen dos cosas al mismo tiempo, normalmente con una idea de lucha o contraste: verbo en forma ます sin ます + **つつ**: **なやみつつ、 けっせい しました** (lo decidí aunque lo pensé mucho). :: Suena a dos fuerzas que se enfrentan.
E 〜つつある: en proceso :: Para decir que algo está cambiando poco a poco: verbo en forma ます sin ます + **つつ ある**: **せかい は かわりつつある** (el mundo está cambiando poco a poco). :: Se usa mucho en noticias y en análisis.
B Dos cosas a la vez o cambio | Forma | Significa | Ejemplo
| 〜つつ | mientras (tensión) | なやみつつ
| 〜つつある | en proceso de cambio | かわりつつある
W なやみつつ = mientras dudaba; dudando | nayamitsutsu
W けっせい = decisión; resolución | kessei
W かわりつつある = está cambiando poco a poco | kawaritsutsu aru
V Vocabulario: mientras y en proceso
D Una decisión difícil
けんじ: どう しました か。 = ¿Qué decidiste?
  > どう しました か = ¿qué decidiste?
まり: なやみつつ、 けっせい しました。 = Lo pensé mucho, pero lo decidí.
  > なやみつつ = mientras lo dudaba
T Cambios
- なやみつつ、 けっせい しました。 = Lo dudé mucho, pero decidí.
  > なやみつつ = mientras lo dudaba
- せかい は かわりつつある。 = El mundo está cambiando poco a poco.
  > かわりつつある = está cambiando poco a poco
Q ¿Qué significa «なやみつつ、 けっせい しました»?
+ Lo dudé mucho, pero decidí. :: つつ = dos cosas a la vez, con tensión.
- Lo decidí sin dudar. :: Eso es lo contrario.
- Dudé, así que no decidí. :: Eso es lo contrario.
Q ¿Qué expresa «〜つつある»?
+ Algo que está cambiando poco a poco. :: En proceso.
- Algo que ya terminó. :: Eso sería el pasado.
- Algo que nunca cambia. :: Eso es lo contrario.
H ___ 、 けっせい しました。 :: Lo dudé, pero decidí.
+ なやみつつ :: Dos cosas a la vez.
- ために :: Eso sería para.
- ながら :: Eso sería mientras, sin tensión.
H せかい は ___ 。 :: El mundo está cambiando poco a poco.
+ かわりつつある :: En proceso.
- まで :: Eso sería hasta.
- ばかり :: Eso sería solo.
R なやみつつ、 けっせい しました。 :: Traduce la frase.
+ I doubted it a lot, but I decided. :: つつ = a la vez, con tensión.
- I decided without doubt. :: Eso es lo contrario.
- I doubted, so I didn't decide. :: Eso es lo contrario.
A せかい は かわりつつある。 :: ¿Qué cuenta?
+ Que el mundo cambia poco a poco. :: En proceso.
- Que el mundo se detuvo. :: Eso es lo contrario.
- Que el mundo cambió de golpe. :: Eso es lo contrario.
O かわりつつある :: Está cambiando poco a poco. :: つつある = en proceso.
Q ¿Cuál es la idea de «つつ»?
+ Dos cosas que se dan a la vez, con tensión. :: Mientras.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.

@ 39 | すぎない と まい (2) | No lo haré: まい
I Ahora una forma firme para decir que no vas a hacer algo, y otra para decir que algo no es probable. Es el estilo de los discursos y de las promesas formales.
E 〜まい: no voy a (negativa firme) :: Para decir que has decidido no hacer algo: verbo en forma de diccionario + **まい**: **もう うそ は つくまい** (no volveré a mentir). :: Es una promesa firme.
E 〜まい: no creo que (suposición negativa) :: Para decir que algo probablemente no ocurrirá: verbo + **まい**: **あの ひと は こない まい** (creo que ese no vendrá). :: Es más formal que 〜ない でしょう.
B Negativa firme y suposición | Forma | Significa | Ejemplo
| 〜まい | no voy a | つくまい
| 〜まい | no creo que | こない まい
W うそ = mentira | uso
W まい = (negativa firme o suposición) | mai
W つくまい = no voy a mentir | tsukumai
W こない = no venir (forma ない de くる) | konai
V Vocabulario: no voy a
T Promesas y suposiciones
- もう うそ は つくまい。 = No volveré a mentir.
  > つくまい = no voy a mentir
- あの ひと は こない まい。 = No creo que ese venga.
  > こない まい = no creo que venga
Q ¿Qué significa «もう うそ は つくまい»?
+ No volveré a mentir. :: まい = negativa firme.
- Mentiré otra vez. :: Eso es lo contrario.
- Quiero mentir. :: Eso es un deseo.
Q ¿Qué expresa «〜まい» en «こない まい»?
+ Una suposición negativa: no creo que venga. :: Probabilidad baja.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H もう うそ は ___。 :: No volveré a mentir.
+ つくまい :: Negativa firme.
- つく :: Eso sería «miento».
- ついた :: Eso sería el pasado.
H あの ひと は ___ 。 :: No creo que ese venga.
+ こない まい :: Suposición negativa.
- くる :: Eso sería «viene».
- きた :: Eso sería el pasado.
R もう うそ は つくまい。 :: Traduce la frase.
+ I won't lie again. :: まい = negativa firme.
- I will lie again. :: Eso es lo contrario.
- I lied before. :: Eso es el pasado.
A あの ひと は こない まい。 :: ¿Qué supone?
+ Que probablemente no vendrá. :: Suposición negativa.
- Que seguro vendrá. :: Eso es lo contrario.
- Que ya vino. :: Eso es el pasado.
O もう うそ は つくまい :: No volveré a mentir. :: まい = negativa firme.
Q ¿Cuál es más formal?
+ 〜まい :: Estilo escrito y formal.
- 〜ない でしょう :: Es más común.
- 〜ない :: Es neutro.

@ 39 | すぎない と まい (3) | Además de: かたわら
I Por último, una palabra para decir que una persona hace algo además de su trabajo principal. Es muy útil para hablar de la vida de alguien en biografías y presentaciones.
E 〜かたわら: además de (y a la vez) :: Para decir que alguien se dedica a algo además de su actividad principal: sustantivo + **の かたわら**: **しごと の かたわら、 べんきょう を して います** (además de mi trabajo, estudio). :: Se usa mucho en biografías.
E Con verbos :: También se usa con verbos en forma de diccionario: **はたらく かたわら** (mientras trabaja). :: Es más formal que ながら.
B Además de | Forma | Significa | Ejemplo
| 〜の かたわら | además de (un trabajo) | しごと の かたわら
| 〜かたわら | además de (verbo) | はたらく かたわら
W かたわら = al lado de; además de | katawara
V Vocabulario: además de
D Presentación
けんじ: あなた の しごと は なん です か。 = ¿Cuál es tu trabajo?
  > あなた の しごと = tu trabajo
まり: しごと の かたわら、 べんきょう を して います。 = Además de mi trabajo, estudio.
  > しごと の かたわら = además de mi trabajo
T Vida ocupada
- しごと の かたわら、 べんきょう を して います。 = Además de mi trabajo, estudio.
  > しごと の かたわら = además de mi trabajo
- はたらく かたわら、 にほんご を ならって います。 = Mientras trabajo, aprendo japonés.
  > はたらく かたわら = mientras trabaja
Q ¿Qué significa «しごと の かたわら、 べんきょう を して います»?
+ Además de mi trabajo, estudio. :: かたわら = además de.
- Estudio en lugar de trabajar. :: Eso es lo contrario.
- Trabajo y no estudio. :: Eso es lo contrario.
Q ¿Qué expresa «〜かたわら»?
+ Dos actividades a la vez, una principal y otra añadida. :: Además de.
- Una causa. :: Eso sería ので.
- Una finalidad. :: Eso sería ために.
H しごと ___ 、 べんきょう を して います。 :: Además de mi trabajo, estudio.
+ の かたわら :: Además de.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
H はたらく ___ 、 にほんご を ならって います。 :: Mientras trabaja, aprende japonés.
+ かたわら :: Además de.
- ばかり :: Eso sería solo.
- まで :: Eso sería hasta.
R しごと の かたわら、 べんきょう を して います。 :: Traduce la frase.
+ Además de mi trabajo, estudio. :: かたわら = además de.
- Estudio en lugar de trabajar. :: Eso es lo contrario.
- Trabajo y no estudio. :: Eso es lo contrario.
A しごと の かたわら、 べんきょう を して います。 :: ¿Qué cuenta?
+ Que estudia además de trabajar. :: Dos actividades.
- Que solo trabaja. :: Eso es lo contrario.
- Que no estudia. :: Eso es lo contrario.
O はたらく かたわら :: Mientras trabaja. :: かたわら = además de.
Q ¿Cuál es más formal que «ながら»?
+ かたわら :: Es más formal y escrito.
- ながら :: Es conversacional.
- ために :: Es finalidad.
