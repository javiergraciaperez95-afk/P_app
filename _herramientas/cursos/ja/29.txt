@ 29 | という と いえば (1) | Hablando de: といえば y といえば
I Hoy aprendes a hablar de un tema y a decir lo que se te viene a la cabeza al oírlo. Es muy típico en las conversaciones, y te ayudará a sonar natural.
E 〜といえば: hablando de… :: Para tomar un tema y decir lo que lo caracteriza: **にほん と いえば、 さくら です ね** (hablando de Japón, son los cerezos, ¿verdad?). :: Se pone después de la palabra del tema.
E 〜と いうと: si hablamos de… :: Con el mismo sentido, pero más suave: **けいざい と いうと、 むずかしい です** (si hablamos de economía, es difícil). :: Sirve para introducir una opinión sobre un tema.
B Hablar de un tema | Forma | Significa | Ejemplo
| 〜と いえば | hablando de | にほん と いえば
| 〜と いうと | si hablamos de | けいざい と いうと
W と いえば = hablando de | to ieba
W と いうと = si hablamos de | to iu to
W けいざい = economía | keizai
V Vocabulario: hablando de
T Temas de conversación
- にほん と いえば、 さくら です ね。 = Hablando de Japón, son los cerezos, ¿verdad?
  > にほん と いえば = hablando de Japón
- うみ と いえば、 なつ です ね。 = Hablando de mar, es el verano, ¿verdad?
  > うみ と いえば = hablando de mar
- けいざい と いうと、 むずかしい です。 = Si hablamos de economía, es difícil.
  > けいざい と いうと = si hablamos de economía
Q ¿Qué significa «にほん と いえば、 さくら です ね»?
+ Hablando de Japón, son los cerezos, ¿verdad? :: といえば = hablando de.
- Japón no tiene cerezos. :: Eso es lo contrario.
- Japón es muy caro. :: No aparece en la frase.
Q ¿Qué expresa «〜といえば»?
+ Lo que se asocia con un tema. :: Se dice lo que viene a la mente.
- Una orden. :: Eso sería 〜て ください.
- Una causa. :: Eso sería ので.
H にほん と いえば、 ___ です ね。 :: Hablando de Japón, son los cerezos, ¿verdad?
+ さくら :: Lo que se asocia.
- たべます :: Eso no encaja.
- いく :: Eso no encaja.
H けいざい と いうと、 ___ です。 :: Si hablamos de economía, es difícil.
+ むずかしい :: Opinión sobre el tema.
- おいしい :: Eso no encaja.
- きれい :: Eso no encaja.
R うみ と いえば、 なつ です ね。 :: Traduce la frase.
+ Hablando de mar, es el verano, ¿verdad? :: といえば = hablando de.
- El mar es caro en verano. :: Eso no está en la frase.
- Nadamos en invierno. :: Eso no está en la frase.
A けいざい と いうと、 むずかしい です。 :: ¿Qué opina?
+ Que la economía es difícil. :: いうと = al hablar de.
- Que la economía es fácil. :: Eso es lo contrario.
- Que no le gusta la economía. :: No aparece.
O うみ と いえば :: Hablando de mar. :: といえば = hablando de.
Q ¿Qué sentido tiene «いうと»?
+ Al hablar de un tema, lo que se piensa. :: Introduce una opinión.
- Una petición. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.

@ 29 | という と いえば (2) | Más bien que: というより y lo que se llama: というのは
I Ahora dos formas para corregir o precisar lo que dices: decir cuál es la descripción más exacta y explicar la razón de algo. Son muy útiles para hablar con matices.
E 〜というより: más bien que :: Para dar la descripción más exacta, comparando dos ideas: **この りょうり は りょうり という より、 げいじゅつ です** (esta comida es más bien arte que cocina). :: Se usa cuando la primera idea es casi verdad, pero la segunda es más justa.
E 〜というのは: la razón es que :: Para explicar algo que acabas de decir: **わたし は にほんご を ならって いる。 というのは、 しごと の ため です** (estoy aprendiendo japonés. La razón es que es para mi trabajo). :: Va al principio de la frase que explica.
B Precisar y explicar | Forma | Significa | Ejemplo
| 〜というより | más bien que | りょうり という より
| 〜というのは | la razón es que | というのは、 しごと の ため です
W ならって = (forma て de ならう) aprendiendo | naratte
W げいじゅつ = arte | geijutsu
W というのは = la razón es que; es que | to iu no wa
V Vocabulario: precisar y explicar
D ¿Por qué estudias japonés?
まり: この りょうり は りょうり という より、 げいじゅつ です ね。 = Esta comida es más bien arte que cocina, ¿verdad?
  > りょうり という より = más bien que cocina | げいじゅつ です = es arte
けんじ: わたし は にほんご を ならって いる。 というのは、 しごと の ため です。 = Estoy aprendiendo japonés. La razón es que es para mi trabajo.
  > というのは = la razón es que | しごと の ため です = es para mi trabajo
Q ¿Qué significa «この りょうり は りょうり という より、 げいじゅつ です»?
+ Esta comida es más bien arte que cocina. :: というより = más bien que.
- Esta comida es cocina, no arte. :: Eso es lo contrario.
- Esta comida es barata. :: No aparece.
Q ¿Qué expresa «〜というより»?
+ La descripción más exacta, comparando. :: Más bien.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería 〜たい.
H この りょうり は りょうり という ___ 、 げいじゅつ です。 :: Esta comida es más bien arte que cocina.
+ より :: Comparación.
- ため :: Eso sería finalidad.
- ながら :: Eso sería mientras.
H わたし は にほんご を ___ 。 :: Estoy aprendiendo japonés.
+ ならって いる :: Forma て de ならう + いる.
- ならった :: Eso sería el pasado.
- ならいません :: Eso sería no aprendo.
R この りょうり は りょうり という より、 げいじゅつ です。 :: Traduce la frase.
+ This food is more art than cooking. :: というより = más bien que.
- Esta comida es cocina, no arte. :: Eso es lo contrario.
- Esta comida no tiene arte. :: Eso es lo contrario.
A わたし は にほんご を ならって いる。 というのは、 しごと の ため です。 :: ¿Por qué?
+ Porque es para su trabajo. :: というのは = la razón es que.
- Porque es fácil. :: No aparece.
- Porque no tiene trabajo. :: Eso es lo contrario.
O りょうり という より :: Más bien que cocina. :: というより = más bien que.
Q ¿Qué expresa «というのは»?
+ La razón de lo que se acaba de decir. :: Explica.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.

@ 29 | という と いえば (3) | Consejos suaves: ばいい y たらいい
I Por último, cómo dar un consejo suave: decir qué podrías hacer, sin imponer nada. Es la forma más amable de aconsejar.
E 〜ばいい: podrías (consejo suave) :: Para dar una sugerencia: forma ば (de いく: いけば) + **いい です**: **でんしゃ で いけば いい です** (podrías ir en tren). :: Se usa cuando hay varias formas de hacer algo.
E 〜たらいい: podrías (con cuidado) :: Para dar un consejo sobre cómo hacer algo poco a poco: forma たら + **いい です**: **まいにち すこし ずつ べんきょう したら いい です** (podrías estudiar un poco cada día). :: Con **ずつ** se habla de cantidades poco a poco.
B Consejo suave | Forma | Significa | Ejemplo
| 〜ばいい | podrías | いけば いい です
| 〜たらいい | podrías (poco a poco) | したら いい です
W いけば = (forma ば de いく) si vas; ir | ikeba
W ずつ = cada uno; poco a poco | zutsu
W したら = si lo haces; haciéndolo | shitara
V Vocabulario: consejos suaves
D ¿Cómo voy a la fiesta?
けんじ: あした、 どう いけば いい です か。 = ¿Cómo debería ir mañana?
  > どう いけば いい です か = ¿cómo debería ir?
まり: でんしゃ で いけば いい です よ。 = Podrías ir en tren.
  > でんしゃ で いけば いい です = podrías ir en tren
T Un plan para estudiar
- まいにち すこし ずつ べんきょう したら いい です。 = Podrías estudiar un poco cada día.
  > すこし ずつ べんきょう したら いい です = podrías estudiar poco a poco
- でんしゃ で いけば いい です。 = Podrías ir en tren.
  > でんしゃ で いけば いい です = podrías ir en tren
Q ¿Qué significa «でんしゃ で いけば いい です»?
+ Podrías ir en tren. :: ばいい = consejo suave.
- No debes ir en tren. :: Eso es lo contrario.
- Tienes que ir en tren. :: Eso sería なければ なりません.
Q ¿Qué expresa «〜ばいい»?
+ Un consejo suave. :: Sugerencia, sin imponer.
- Una orden fuerte. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H まいにち すこし ___ べんきょう したら いい です。 :: Podrías estudiar un poco cada día.
+ ずつ :: Cada uno, poco a poco.
- まで :: Eso sería hasta.
- たい :: Eso sería quiero.
H でんしゃ で ___ いい です。 :: Podrías ir en tren.
+ いけば :: Forma ば de いく.
- いけない :: Eso sería no se puede.
- いきたい :: Eso sería quiero ir.
R まいにち すこし ずつ べんきょう したら いい です。 :: Traduce la frase.
+ Podrías estudiar un poco cada día. :: したら いい = consejo suave.
- Debes estudiar mucho cada día. :: Eso sería obligación.
- No hace falta estudiar. :: Eso es lo contrario.
A どう いけば いい です か。 :: ¿Qué pregunta?
+ ¿Cómo debería ir? :: Pide un consejo.
- ¿Cuándo vuelve? :: No aparece.
- ¿Dónde está la estación? :: No aparece.
O すこし ずつ :: Poco a poco. :: ずつ = cada uno, poco a poco.
Q ¿Cuál es la diferencia entre 〜ばいい y 〜なければならない?
+ ばいい = consejo suave; なければ = obligación. :: Son distintas.
- Son iguales. :: No es cierto.
- Ambas son deseos. :: No es cierto.
