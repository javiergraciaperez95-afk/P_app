@ 31 | にしたがって と ともに | A medida que... y junto con...
I Hoy aprendes a decir que algo cambia a la vez que otra cosa, como un proceso en paralelo.
E 〜にしたがって: a medida que :: Verbo en forma normal o sustantivo + **にしたがって**: **ねだん が あがる にしたがって、 ふあん が ふえます** (a medida que suben los precios, aumenta la inquietud). :: Expresa un cambio gradual que sigue a otro.
E 〜とともに: junto con; al mismo tiempo que :: Sustantivo o verbo en forma normal + **ともに**: **けいき と ともに、 ぶっか が あがった** (junto con la coyuntura, los precios subieron). :: Dos cambios que ocurren a la vez.
W けいき = coyuntura económica | keiki | kanji: 景気

V Vocabulario: a medida que y junto con
T Cambios en paralelo
- ねだん が あがる にしたがって、 ふあん が ふえます。 = A medida que suben los precios, aumenta la inquietud.
- けいき と ともに、 ぶっか が あがった。 = Junto con la coyuntura, los precios subieron.
- がくせい が ふえる ともに、 きょうしつ が ふえます。 = A medida que aumentan los alumnos, aumentan las aulas.
Q ¿Qué significa «ねだん が あがる にしたがって、 ふあん が ふえます»?
+ A medida que suben los precios, aumenta la inquietud. :: にしたがって = a medida que.
- Los precios suben y luego bajan. :: Eso no es la frase.
- La inquietud baja cuando suben los precios. :: Eso es lo contrario.
H けいき と ___ 、 ぶっか が あがった。 :: Junto con la coyuntura, los precios subieron.
+ ともに :: Junto con.
- まで :: Eso sería hasta.
- ため :: Eso sería para.
H ねだん が あがる ___ 、 ふあん が ふえます。 :: A medida que suben los precios...
+ にしたがって :: A medida que.
- ために :: Eso sería para.
- ながら :: Eso sería mientras.
R がくせい が ふえる ともに、 きょうしつ が ふえます。 :: Traduce la frase.
+ As students increase, classrooms increase too. :: ともに = junto con.
- Students increase but classrooms decrease. :: Eso es lo contrario.
- Classrooms increase before students. :: Eso invierte el orden.
A けいき と ともに、 ぶっか が あがった。 :: ¿Qué cuenta?
+ Que los precios subieron junto con la economía. :: Cambio en paralelo.
- Que la economía no cambió. :: Eso es lo contrario.
- Que los precios bajaron. :: Eso es lo contrario.
O ねだん が あがる にしたがって :: A medida que suben los precios. :: にしたがって = a medida que.
Q ¿Cuál significa «ともに»?
+ Junto con, al mismo tiempo. :: Dos cosas a la vez.
- Antes de. :: Eso sería まえ.
- Después de. :: Eso sería あと.
Q ¿Qué expresa «〜にしたがって»?
+ Un cambio paralelo a otro. :: Dos cambios juntos.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería たい.
