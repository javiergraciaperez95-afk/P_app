@ 22 | でも と ても (1) | Aunque: ても y 〜てもかまわない
I Hoy empieza el capítulo del contraste: decir «aunque» y dar permiso sin pedir nada. Son frases muy frecuentes en las conversaciones de nivel medio.
E 〜ても: aunque :: Con la forma **て + も** dices que algo pasa **sin que** lo anterior lo impida: **あめ が ふっても、 さんぽ を します** (aunque llueva, doy un paseo). :: Con los adjetivos en -i se quita la **い** y se pone **くても**: **たかい** → **たかくても** (aunque sea caro).
E 〜ても かまいません: no importa si :: Para dar permiso con tranquilidad: **ここ で すわっても かまいません** (no importa si te sientas aquí). :: Para preguntar: **〜ても かまいません か** (¿importa si…?).
B Aunque y permiso | Forma | Significa | Ejemplo
| 〜ても | aunque | あめ が ふっても
| 〜くても | aunque (adjetivo en -i) | たかくても
| 〜ても かまいません | no importa si | ここ で すわっても かまいません
W ふっても = aunque llueva | futte mo | Es la forma て + も de ふる.
W たかくても = aunque sea caro | takakute mo
W すわっても = aunque (me) siente | suwatte mo | Es la forma て + も de すわる.
W かまいません = no importa; no hay problema | kamaimasen
W さむくても = aunque haga frío | samukute mo
W あそびます = jugar; divertirse | asobimasu
V Vocabulario: aunque
T Mi día, pase lo que pase
- あめ が ふっても、 さんぽ を します。 = Aunque llueva, doy un paseo.
  > ふっても = aunque llueva | さんぽ を します = doy un paseo
- たかくても、 かいます。 = Aunque sea caro, lo compro.
  > たかくても = aunque sea caro | かいます = lo compro
- さむくても、 そと で あそびます。 = Aunque haga frío, juego fuera.
  > さむくても = aunque haga frío | そと で あそびます = juego fuera
D ¿Vienes mañana?
けんじ: あした、 あめ が ふっても、 いきます か。 = Mañana, aunque llueva, ¿irás?
  > ふっても = aunque llueva
まり: はい、 あめ が ふっても いきます。 = Sí, aunque llueva, iré.
  > ふっても いきます = iré aunque llueva
けんじ: じゃあ、 ここ で すわっても かまいません か。 = Entonces, ¿no importa si me siento aquí?
  > すわっても かまいません か = ¿no importa si me siento?
まり: はい、 かまいません。 = Sí, no importa.
  > かまいません = no importa
Q ¿Qué significa «あめ が ふっても、 さんぽ を します»?
+ Aunque llueva, doy un paseo. :: ても = aunque.
- Como llueve, doy un paseo. :: Eso sería ので.
- Antes de que llueva, doy un paseo. :: Eso sería まえに.
Q ¿Qué forma es correcta para «aunque sea caro»?
+ たかくても :: Adjetivo en -i: い → くて + も.
- たかいても :: No se usa así.
- たかくも :: Falta la forma て.
H ここ で すわっても ___ 。 :: No importa si te sientas aquí.
+ かまいません :: No importa.
- ください :: Eso sería una petición.
- いけません :: Eso sería «no se puede».
H あした、 あめ が ___ 、 いきます。 :: Mañana, aunque llueva, iré.
+ ふっても :: Aunque llueva.
- ふったら :: Eso sería «si llueve».
- ふって :: No es concesivo.
R たかくても、 かいます。 :: Traduce la frase.
+ Aunque sea caro, lo compro. :: ても = aunque.
- Como es caro, no lo compro. :: Eso es lo contrario.
- Era caro, pero lo compré ayer. :: Eso es el pasado.
A ここ で すわっても かまいません か。 :: ¿Qué pregunta?
+ ¿Puedo sentarme aquí? :: かまいません = permiso.
- ¿Tengo que sentarme aquí? :: Eso sería obligación.
- ¿Dónde me siento? :: No aparece en la frase.
O あめ が ふっても いきます :: Aunque llueva, iré. :: ても = aunque.
Q ¿Qué significa «〜ても かまいません»?
+ No importa si... :: Permiso tranquilo.
- Es obligatorio. :: Eso sería なければ なりません.
- Es imposible. :: Eso sería ようがない.

@ 22 | でも と ても (2) | A pesar de, considerando que
I Ahora, cómo decir «a pesar de» y «considerando que». Son expresiones de lenguaje escrito y noticias, pero también se oyen al hablar.
E 〜にもかかわらず: a pesar de :: Con un nombre o una frase: **あめ にもかかわらず、 おおく の ひと が きました** (a pesar de la lluvia, vino mucha gente). :: Es más formal que **〜のに**. Se usa mucho en noticias.
E 〜わりに: considerando que :: Para decir que algo es mejor o peor de lo que se esperaba: **この みせ は やすい わりに、 おいしい です** (considerando que es barato, está rico). :: Va después de un adjetivo o un verbo en forma normal.
E 〜にしては: para ser (algo) :: Para juzgar algo según quién lo hace o lo que es: **がくせい にしては、 にほんご が じょうず です** (para ser estudiante, su japonés es bueno). :: Va después de un nombre.
B Juzgar lo que pasa | Forma | Significa | Ejemplo
| 〜にもかかわらず | a pesar de | あめ にもかかわらず
| 〜わりに | considerando que | やすい わりに
| 〜にしては | para ser | がくせい にしては
W にもかかわらず = a pesar de | ni mo kakawarazu
W わりに = considerando que; para lo que es | wari ni
W にしては = para ser; considerando que | ni shite wa
W おおく = muchos; a menudo | ōku
W ふっていました = estaba lloviendo | futte imashita
V Vocabulario: a pesar de
D Una mañana de lluvia
やまだ: けさ あめ が ふっていました ね。 = Esta mañana estaba lloviendo, ¿verdad?
  > ふっていました = estaba lloviendo
けんじ: あめ にもかかわらず、 おおく の ひと が きました。 = A pesar de la lluvia, vino mucha gente.
  > あめ にもかかわらず = a pesar de la lluvia | おおく の ひと が きました = vino mucha gente
やまだ: すごい です ね。 = ¡Qué increíble!
  > すごい です ね = ¡qué increíble!
T Opiniones
- この みせ は やすい わりに、 おいしい です。 = Considerando que es barato, esta tienda tiene buena comida.
  > やすい わりに = considerando que es barato
- がくせい にしては、 にほんご が じょうず です。 = Para ser estudiante, su japonés es bueno.
  > がくせい にしては = para ser estudiante
Q ¿Qué significa «あめ にもかかわらず、 おおく の ひと が きました»?
+ A pesar de la lluvia, vino mucha gente. :: にもかかわらず = a pesar de.
- Por culpa de la lluvia, vino poca gente. :: Eso es lo contrario.
- Gracias a la lluvia, vino mucha gente. :: Eso sería おかげで.
Q ¿Qué expresa «〜わりに»?
+ Lo que se espera según la situación. :: わりに = considerando que.
- Una causa. :: Eso sería ので.
- Una condición. :: Eso sería たら.
H この みせ は やすい ___ 、 おいしい です。 :: Considerando que es barato, está rico.
+ わりに :: Considerando que.
- から :: Eso sería «porque es barato», no lo mismo.
- まで :: Eso sería «hasta».
H がくせい ___ 、 にほんご が じょうず です。 :: Para ser estudiante, su japonés es bueno.
+ にしては :: Para ser.
- ながら :: Eso sería «mientras».
- たら :: Eso sería «si».
R やすい わりに、 おいしい です。 :: Traduce la frase.
+ Considerando que es barato, está rico. :: わりに = considerando.
- Como es barato, no está rico. :: Eso es lo contrario.
- Es barato porque está rico. :: Eso invierte la causa.
A あめ にもかかわらず、 おおく の ひと が きました。 :: ¿Qué cuenta?
+ Que vino mucha gente aunque llovía. :: にもかかわらず = a pesar de.
- Que no vino nadie por la lluvia. :: Eso es lo contrario.
- Que vino poca gente por la lluvia. :: Eso es lo contrario.
O けさ あめ が ふっていました :: Esta mañana estaba lloviendo. :: ふっていました = estaba lloviendo.
Q ¿Cuál tiene un sentido parecido a «〜にもかかわらず»?
+ 〜のに :: Ambas expresan «aunque».
- 〜ので :: Expresa causa.
- 〜ために :: Expresa finalidad o causa.

@ 22 | でも と ても (3) | Sin embargo, al contrario
I Por último, dos formas para introducir algo inesperado: una cuando el resultado no es el que esperabas, y otra cuando lo contrario es lo que pasa.
E ところが: sin embargo :: Para contar algo que no salió como esperabas: **でんわ を かけました。 ところが、 でませんでした** (llamé. Sin embargo, no contestó). :: Va al principio de la segunda frase, con coma después.
E 〜どころか: lejos de; todo lo contrario :: Para decir que algo es **todo lo contrario** de lo que se dijo: **やさしい どころか、 とても きびしい です** (lejos de ser amable, es muy estricto). :: Va después de un nombre o de un adjetivo.
B Lo inesperado | Forma | Significa | Ejemplo
| ところが | sin embargo | でませんでした
| 〜どころか | lejos de; al contrario | やさしい どころか
W ところが = sin embargo; pero (inesperado) | tokoro ga
W どころか = lejos de; ni mucho menos | dokoro ka
W かけました = llamé (por teléfono) | kakemashita | Es el pasado de かける (llamar por teléfono).
W でませんでした = no contestó; no salió | demasen deshita
W きびしい = estricto; severo | kibishii
W しけん = examen | shiken
W むずかしかった = fue difícil | muzukashikatta
V Vocabulario: lo inesperado
D ¿Cómo es el profesor?
けんじ: あの せんせい は やさしい です か。 = ¿Ese profesor es amable?
  > やさしい です か = ¿es amable?
まり: やさしい どころか、 とても きびしい です。 = Lejos de ser amable, es muy estricto.
  > やさしい どころか = lejos de ser amable | とても きびしい です = es muy estricto
けんじ: そう です か。 = ¿Ah, sí?
  > そう です か = ¿ah, sí?
T Un examen y una llamada
- でんわ を かけました。 ところが、 でませんでした。 = Llamé. Sin embargo, no contestó.
  > ところが = sin embargo | でませんでした = no contestó
- しけん は やさしい どころか、 とても むずかしかった です。 = El examen, lejos de ser fácil, fue muy difícil.
  > やさしい どころか = lejos de ser fácil | むずかしかった です = fue difícil
Q ¿Qué significa «でんわ を かけました。 ところが、 でませんでした»?
+ Llamé. Sin embargo, no contestó. :: ところが = sin embargo.
- Llamé porque no contestó. :: Eso invierte la causa.
- No llamé, y no contestó. :: Eso es lo contrario.
Q ¿Qué expresa «〜どころか»?
+ Lo contrario de lo que se esperaba. :: どころか = lejos de.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería たい.
H しけん は やさしい ___ 、 とても むずかしかった です。 :: Lejos de ser fácil, fue muy difícil.
+ どころか :: Lo contrario.
- から :: Eso sería «porque».
- ながら :: Eso sería «mientras».
H でんわ を かけました。 ___、 でませんでした。 :: Llamé. Sin embargo, no contestó.
+ ところが :: Sin embargo.
- まで :: Eso sería «hasta».
- ながら :: Eso sería «mientras».
R やさしい どころか、 とても きびしい です。 :: Traduce la frase.
+ Lejos de ser amable, es muy estricto. :: どころか = lejos de.
- Es amable, y no es muy estricto. :: Eso es lo contrario.
- Es amable, así que no es estricto. :: Eso invierte la lógica.
A でんわ を かけました。 ところが、 でませんでした。 :: ¿Qué pasó?
+ Llamó, pero no contestaron. :: ところが = sin embargo.
- Llamó y contestaron enseguida. :: Eso es lo contrario.
- No llamó. :: Eso es lo contrario.
O しけん は やさしい どころか :: Lejos de ser fácil, el examen... :: どころか = lejos de.
Q ¿Cuál significa «sin embargo»?
+ ところが :: Introduce lo inesperado.
- どころか :: Significa «lejos de».
- ために :: Significa «para».
