@ 23 | きく と つたえる (1) | Según, y dicen que
I Hoy aprendes a decir de dónde viene una información: si es un dato oficial, lo que has oído o lo que has leído. Es clave para no sonar como si siempre tuvieras razón.
E 〜によると: según (una fuente) :: Pon la fuente y añade **に よると**: **てんき よほう によると、 あした は あめ です** (según la previsión, mañana lloverá). :: **によれば** es la forma más formal y se usa mucho en las noticias.
E 〜ということだ: dicen que :: Para contar algo que has oído de otra persona: frase en forma normal + **という こと だ**: **やまだ さん は らいげつ にほん へ いく という こと だ** (dicen que Yamada irá a Japón el mes que viene). :: Así no te haces responsable de la información.
E 〜によれば: según las noticias :: **ニュース によれば、 ぶっか が あがった という こと です** (según las noticias, los precios han subido). :: Es lo mismo que **によると**, pero más formal.
B Fuente de la información | Forma | Significa | Ejemplo
| 〜によると | según (una fuente) | てんき よほう によると
| 〜ということだ | dicen que; me han dicho que | いく という こと だ
| 〜によれば | según (muy formal) | ニュース によれば
W よほう = previsión, pronóstico | yohō
W によると = según (fuente); según dicen | ni yoru to
W によれば = según (forma formal) | ni yoreba
W ニュース = noticias; noticia | nyūsu
W ぶっか = precios; coste de la vida | bukka
W あがった = subió; aumentó (de あがる) | agatta
W という = que, llamado (forma de decir) | to iu
V Vocabulario: según y dicen que
T La previsión y las noticias
- てんき よほう によると、 あした は あめ です。 = Según la previsión, mañana lloverá.
  > てんき よほう によると = según la previsión del tiempo
- ニュース によれば、 ぶっか が あがった という こと です。 = Según las noticias, los precios han subido.
  > ニュース によれば = según las noticias | あがった という こと です = han subido, dicen
- やまだ さん は らいげつ にほん へ いく という こと だ。 = Dicen que Yamada irá a Japón el mes que viene.
  > いく という こと だ = dicen que irá
Q ¿Qué significa «てんき よほう によると、 あした は あめ です»?
+ Según la previsión, mañana lloverá. :: によると = según una fuente.
- Mañana la previsión dice que no llueve. :: Eso es lo contrario.
- Mañana llueve, y la previsión no lo dice. :: No aparece en la frase.
Q ¿Qué expresa «〜という こと だ»?
+ Algo que se ha oído de otra persona. :: Se cuenta sin ser responsable.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H てんき よほう ___ 、 あした は あめ です。 :: Según la previsión, mañana lloverá.
+ によると :: Según una fuente.
- に ついて :: Eso sería «sobre».
- に とって :: Eso sería «para».
H やまだ さん は らいげつ にほん へ いく ___ 。 :: Dicen que Yamada irá a Japón el mes que viene.
+ という こと だ :: Algo oído.
- と おもいます :: Eso sería tu opinión.
- でしょう :: Eso sería una suposición tuya.
R ニュース によれば、 ぶっか が あがった という こと です。 :: Traduce la frase.
+ Según las noticias, los precios han subido. :: によれば = según una fuente.
- Según las noticias, los precios han bajado. :: Eso es lo contrario.
- Creo que los precios han subido. :: Eso sería tu opinión.
A やまだ さん は らいげつ にほん へ いく という こと だ。 :: ¿Qué cuenta?
+ Que dicen que Yamada irá a Japón el mes que viene. :: という こと = dicen que.
- Que Yamada va a Japón seguro. :: Eso sería una afirmación propia.
- Que Yamada no va a Japón. :: Eso es lo contrario.
O てんき よほう によると :: Según la previsión del tiempo. :: によると = según una fuente.
Q ¿Qué significa «によると»?
+ Según (una fuente). :: Indica de dónde viene la información.
- Sobre (un tema). :: Eso sería について.
- Para (alguien). :: Eso sería にとって.

@ 23 | きく と つたえる (2) | Sobre, para y frente a
I Ahora tres expresiones que se parecen, pero que no significan lo mismo: «sobre» un tema, «para» alguien y «frente a» algo. Hay que elegir la correcta.
E 〜について: sobre (el tema) :: Para decir de qué trata algo: **にほん の ぶんか に ついて はなします** (hablaré sobre la cultura japonesa). :: Se usa mucho en presentaciones y en el trabajo.
E 〜にとって: para (alguien) :: Para dar una opinión desde el punto de vista de alguien: **わたし に とって、 にほんご は むずかしい です** (para mí, el japonés es difícil). :: Expresa lo que le pasa a una persona, no el tema.
E 〜に対して: frente a; hacia :: Para decir la actitud hacia algo: **この けいかく に たいして、 はんたい です** (estoy en contra de este plan). :: Se usa en debates y en noticias.
B Sobre, para, frente a | Forma | Significa | Ejemplo
| 〜について | sobre (el tema) | ぶんか に ついて
| 〜にとって | para (alguien) | わたし に とって
| 〜に対して | frente a; hacia | けいかく に たいして
W ぶんか = cultura | bunka
W ついて = sobre; acerca de | tsuite
W はなします = hablo; hablaré | hanashimasu
W とって = para (alguien); desde el punto de vista | totte
W けいかく = plan; proyecto | keikaku
W たいして = frente a; hacia (de たいする) | taishite
W はんたい = en contra; oposición | hantai
V Vocabulario: sobre, para y frente a
Q ¿Qué significa «にほん の ぶんか に ついて はなします»?
+ Hablaré sobre la cultura japonesa. :: について = sobre el tema.
- Hablaré con la cultura japonesa. :: Eso no tiene sentido.
- Hablé de la cultura japonesa. :: Eso sería el pasado.
Q ¿Qué expresa «〜にとって»?
+ Desde el punto de vista de alguien. :: にとって = para alguien.
- Una causa. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H わたし に ___、 にほんご は むずかしい です。 :: Para mí, el japonés es difícil.
+ とって :: Desde mi punto de vista.
- ついて :: Eso sería «sobre».
- たいして :: Eso sería «frente a».
H この けいかく に ___、 はんたい です。 :: Estoy en contra de este plan.
+ たいして :: Frente a algo.
- ついて :: Eso sería «sobre».
- とって :: Eso sería «para».
R この けいかく に たいして、 はんたい です。 :: Traduce la frase.
+ Estoy en contra de este plan. :: に対して = frente a.
- Estoy a favor de este plan. :: Eso es lo contrario.
- Este plan es muy caro. :: No aparece en la frase.
A にほん の ぶんか に ついて はなします。 :: ¿De qué tema hablará?
+ De la cultura japonesa. :: について = sobre.
- De la comida japonesa. :: No aparece en la frase.
- De otro tema. :: No aparece en la frase.
O わたし に とって :: Para mí. :: にとって = para alguien.
Q ¿Cuál es el sentido de «について»?
+ Sobre (el tema). :: Indica de qué se habla.
- Desde (un lugar). :: Eso sería から.
- Hasta. :: Eso sería まで.

@ 23 | きく と つたえる (3) | Como profesor; seguro que
I Por último, cómo decir «como» (en qué papel), qué pasa si suponemos algo y cuándo algo es seguro. Son expresiones que usarás en el trabajo y para hablar de tus planes.
E 〜として: como (en el papel de) :: Para decir el papel o la posición de alguien: **せんせい として、 にほんご を おしえて います** (como profesor, enseño japonés). :: Lo que sigue es el papel, no la persona.
E 〜としたら: si fuera; suponiendo que :: Para imaginar algo: **もし にほん へ いく としたら、 なに を します か** (si fueras a Japón, ¿qué harías?). :: Se usa mucho para hacer preguntas hipotéticas.
E 〜に違いありません: seguro que :: Para estar casi seguro de algo: **あした は あめ に ちがいありません** (seguro que mañana lloverá). :: Es más seguro que 〜でしょう.
B Papel, suposición y seguridad | Forma | Significa | Ejemplo
| 〜として | como (el papel de) | せんせい として
| 〜としたら | si fuera; suponiendo | いく としたら
| 〜に違いありません | seguro que | あめ に ちがいありません
W として = como (en el papel de) | toshite
W もし = si; en caso de | moshi
W としたら = si fuera; suponiendo que | toshitara
W ちがいありません = seguro que; sin duda | chigai arimasen
V Vocabulario: como y seguro que
D Un viaje imaginario
やまだ: もし にほん へ いく としたら、 なに を します か。 = Si fueras a Japón, ¿qué harías?
  > もし にほん へ いく としたら = si fueras a Japón
けんじ: わたし は とうきょう で すし を たべたい です。 = Yo querría comer sushi en Tokio.
  > たべたい です = querría comer
Q ¿Qué significa «せんせい として、 にほんご を おしえて います»?
+ Como profesor, enseño japonés. :: として = en el papel de.
- Enseño japonés a un profesor. :: Eso invierte la relación.
- El profesor enseña japonés. :: Eso sería otra persona.
Q ¿Qué expresa «〜としたら»?
+ Una suposición para imaginar. :: としたら = si fuera.
- Una causa. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H もし にほん へ いく ___ 、 なに を します か。 :: Si fuera a Japón, ¿qué haría?
+ としたら :: Suposición.
- から :: Eso sería «porque».
- ながら :: Eso sería «mientras».
H あした は あめ ___ 。 :: Seguro que mañana lloverá.
+ に ちがいありません :: Seguridad.
- ください :: Eso sería una petición.
- ありませんでした :: Eso es «no hubo».
R せんせい として、 にほんご を おしえて います。 :: Traduce la frase.
+ Como profesor, enseño japonés. :: として = en el papel de.
- Quiero ser profesor de japonés. :: Eso sería 〜たい.
- Fui profesor de japonés. :: Eso sería el pasado.
A あした は あめ に ちがいありません。 :: ¿Qué opina?
+ Está seguro de que mañana lloverá. :: に違いありません = seguro.
- Cree que mañana no lloverá. :: Eso es lo contrario.
- Dice que mañana hará calor. :: No aparece en la frase.
O もし にほん へ いく としたら :: Si fuera a Japón. :: としたら = suposición.
Q ¿Cuál significa «ちがいありません»?
+ Seguro, sin duda. :: Expresa certeza.
- Es diferente. :: Eso sería ちがいます.
- No es verdad. :: Eso es lo contrario.
