@ 30 | ふだん の はなし (1) | Porque, con disculpa: ものですから
I Estamos en la última parte del nivel B1. Hoy aprendes a dar un motivo con un poco de disculpa y a pedir confirmación de algo que crees. Son frases muy habladas en la vida diaria.
E 〜ものですから: porque (con disculpa) :: Para explicar el motivo de algo con tono de disculpa: frase en forma normal + **もの です から**: **ねつ が ある もの です から、 やすみます** (como tengo fiebre, falto). :: Es más educado que **〜から**. Se usa mucho al pedir perdón o al justificarse.
E 〜んじゃないか: ¿no es que…? :: Para decir lo que crees con cierta seguridad y pedir que la otra persona lo confirme: frase en forma normal + **じゃない か**: **あした は あめ じゃない か** (¿no va a llover mañana?). :: Es más suave que una afirmación directa.
B Motivo con disculpa y confirmación | Forma | Significa | Ejemplo
| 〜もの です から | como (con disculpa) | ねつ が ある もの です から
| 〜じゃない か | ¿no es que...? | あめ じゃない か
W やすみます = falto; no voy (de やすむ) | yasumimasu
W じゃない = (forma plana de じゃありません) no es | ja nai
V Vocabulario: porque con disculpa
D Pedir perdón
けんじ: すみません。 ねつ が ある もの です から、 きょう は やすみます。 = Perdone. Como tengo fiebre, hoy falto.
  > ねつ が ある もの です から = como tengo fiebre
やまだ: そう です か。 あした は あめ じゃない か。 = ¿Ah, sí? ¿No va a llover mañana?
  > あめ じゃない か = ¿no va a llover?
Q ¿Qué significa «ねつ が ある もの です から、 やすみます»?
+ Como tengo fiebre, falto. :: もの です から = motivo con disculpa.
- Tengo fiebre, así que no falto. :: Eso es lo contrario.
- Falto para tener fiebre. :: Eso invierte la causa.
Q ¿Qué expresa «〜じゃない か»?
+ Una suposición que pide confirmación. :: ¿No es que...?
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H ねつ が ある もの です ___ 、 やすみます。 :: Como tengo fiebre, falto.
+ から :: Motivo.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H あした は あめ ___ 。 :: ¿No va a llover mañana?
+ じゃない か :: Confirmación.
- ください :: Eso sería una petición.
- ありませんでした :: Eso sería el pasado.
R ねつ が ある もの です から、 やすみます。 :: Traduce la frase.
+ Como tengo fiebre, falto. :: もの です から = motivo con disculpa.
- Como no tengo fiebre, falto. :: Eso es lo contrario.
- Falto, pero no tengo fiebre. :: Eso es lo contrario.
A あした は あめ じゃない か。 :: ¿Qué pregunta?
+ ¿No va a llover mañana? :: じゃない か = confirmación.
- ¿Va a llover mañana? :: Eso es una pregunta simple.
- ¿Llovió mañana? :: Eso es el pasado.
O ねつ が ある もの です から :: Como tengo fiebre. :: もの です から = motivo.
Q ¿Qué tono tiene 〜ものですから frente a 〜から?
+ Es más educado y con disculpa. :: Se usa al justificarse.
- Es más directo. :: Eso es 〜から.
- Es una orden. :: No es cierto.

@ 30 | ふだん の はなし (2) | No solo... también: ばかりか y だけでなく
I Ahora dos formas para añadir algo fuerte a lo que dices: no solo una cosa, sino también otra. Muy útiles para describir a alguien o algo.
E 〜ばかりか: no solo... sino también :: Para añadir algo que sorprende, después de lo que ya sabes: nombre o frase + **ばかり か**: **かれ は べんきょう ばかり か、 スポーツ も じょうず です** (él no solo estudia, también es bueno en deportes). :: Suena a sorpresa o a elogio.
E 〜だけでなく: no solo... también :: Para añadir algo a lo que ya se ha dicho, sin la sorpresa: nombre + **だけ で なく**: **にほんご だけ で なく、 えいご も はなせます** (no solo hablo japonés, también hablo inglés). :: Es más neutro que ばかりか.
B Añadir algo | Forma | Significa | Ejemplo
| 〜ばかりか | no solo... sino también (sorpresa) | べんきょう ばかりか
| 〜だけで なく | no solo... también | にほんご だけ で なく
W ばかりか = no solo... sino también | bakari ka
W かれ = él | kare
W なく = no (forma negativa de だ, usada para unir) | naku
W えいご = inglés (idioma) | eigo
V Vocabulario: no solo
T Personas y talentos
- かれ は べんきょう ばかり か、 スポーツ も じょうず です。 = Él no solo estudia, también es bueno en deportes.
  > べんきょう ばかり か = no solo estudia
- にほんご だけ で なく、 えいご も はなせます。 = No solo hablo japonés, también hablo inglés.
  > にほんご だけ で なく = no solo japonés
Q ¿Qué significa «かれ は べんきょう ばかり か、 スポーツ も じょうず です»?
+ Él no solo estudia, también es bueno en deportes. :: ばかりか = no solo... sino también.
- Él solo estudia y no hace deporte. :: Eso es lo contrario.
- Él estudia cada día. :: Eso es un hábito.
Q ¿Qué expresa «〜だけで なく»?
+ Añadir algo a lo dicho. :: No solo... también.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería 〜たい.
H にほんご だけ で ___ 、 えいご も はなせます。 :: No solo japonés, también hablo inglés.
+ なく :: No... (unir).
- ない :: Eso sería no existe.
- ながら :: Eso sería mientras.
H かれ は べんきょう ___ 、 スポーツ も じょうず です。 :: No solo estudia, también es bueno en deportes.
+ ばかりか :: No solo... también.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
R にほんご だけ で なく、 えいご も はなせます。 :: Traduce la frase.
+ No solo hablo japonés, también hablo inglés. :: だけでなく = no solo.
- Solo hablo japonés. :: Eso es lo contrario.
- Hablo inglés, pero no japonés. :: Eso es lo contrario.
A かれ は べんきょう ばかり か、 スポーツ も じょうず です。 :: ¿Qué cuenta?
+ Que él es bueno en estudio y en deportes. :: ばかりか = no solo.
- Que él no estudia. :: Eso es lo contrario.
- Que solo juega. :: Eso es lo contrario.
O にほんご だけ で なく :: No solo japonés. :: だけで なく = no solo.
Q ¿Cuál es más sorprendente?
+ 〜ばかりか :: Añade algo que sorprende.
- 〜だけで なく :: Añade algo neutro.
- 〜ために :: Expresa causa.

@ 30 | ふだん の はなし (3) | Cada uno y depende de: ずつ y によって
I Por último, dos palabras para hablar de reparto y de diferencias. Son muy útiles para explicar tus hábitos y para comparar gustos.
E 〜ずつ: cada uno; poco a poco :: Para repartir algo en partes iguales o hacer algo poco a poco: cantidad + **ずつ**: **まいにち ひとつ ずつ、 ことば を おぼえます** (cada día memorizo una palabra). :: Va después del número.
E 〜によって: depende de :: Para decir que algo cambia según la persona, el lugar o la situación: sustantivo + **に よって**: **ひと に よって、 すき な もの は ちがいます** (depende de la persona: lo que cada uno le gusta es distinto). :: Suena natural al comparar gustos y opiniones.
B Reparto y diferencias | Forma | Significa | Ejemplo
| 〜ずつ | cada uno; poco a poco | ひとつ ずつ
| 〜によって | depende de | ひと に よって
W ことば = palabra; idioma; lenguaje | kotoba
W おぼえます = memorizo; aprendo de memoria | oboemasu
W よって = depende de (forma de によって) | yotte
W ちがいます = es diferente | chigaimasu
V Vocabulario: cada uno y depende de
D Gustos distintos
まり: ひと に よって、 すき な もの は ちがいます ね。 = Depende de la persona: lo que cada uno le gusta es distinto, ¿verdad?
  > ひと に よって = depende de la persona
けんじ: そう です ね。 わたし は まいにち ひとつ ずつ、 ことば を おぼえます。 = Sí. Yo memorizo una palabra cada día.
  > ひとつ ずつ = una a una
Q ¿Qué significa «まいにち ひとつ ずつ、 ことば を おぼえます»?
+ Cada día memorizo una palabra. :: ずつ = cada uno.
- Cada día memorizo muchas palabras. :: Eso sería muchas, no una.
- Cada día olvido una palabra. :: Eso es lo contrario.
Q ¿Qué expresa «〜によって»?
+ Que algo cambia según la situación. :: Depende de.
- Una causa exacta. :: Eso sería ので.
- Una orden. :: Eso sería 〜て ください.
H まいにち ひとつ ___、 ことば を おぼえます。 :: Cada día memorizo una palabra.
+ ずつ :: Cada uno.
- まで :: Eso sería hasta.
- たい :: Eso sería quiero.
H ひと に ___ 、 すき な もの は ちがいます。 :: Depende de la persona.
+ よって :: Depende de.
- ながら :: Eso sería mientras.
- ために :: Eso sería para.
R ひと に よって、 すき な もの は ちがいます。 :: Traduce la frase.
+ Depende de la persona: lo que a cada uno le gusta es distinto. :: によって = depende de.
- Todas las personas tienen los mismos gustos. :: Eso es lo contrario.
- Las personas no tienen gustos. :: Eso es lo contrario.
A まいにち ひとつ ずつ、 ことば を おぼえます。 :: ¿Qué cuenta?
+ Que memoriza una palabra cada día. :: ずつ = cada uno.
- Que memoriza diez palabras al día. :: Eso no es la frase.
- Que olvida las palabras. :: Eso es lo contrario.
O ひと に よって :: Depende de la persona. :: によって = depende de.
Q ¿Qué expresa «ずつ»?
+ Repartir en partes iguales. :: Cada uno.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería 〜たい.

@ 30 | さいご の テスト | Examen final de B1
E Examen final de B1 :: Veinticinco preguntas sobre los capítulos 21 a 30. Si aciertas veinte o más, tienes un B1 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 21. ¿Qué significa «あめ が ふっている ので、 かさ を もって いきます»?
+ Como llueve, llevo paraguas. :: ので = motivo.
- Llueve, así que no llevo paraguas. :: Eso es lo contrario.
- Llevo paraguas, pero no llueve. :: Eso es lo contrario.
H Cap. 21. ねつ が ある ___ 、 がっこう を やすみました。 :: Motivo con cortesía.
+ ので :: Motivo.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H Cap. 21. あめ の ___ 、 でんしゃ が おくれました。 :: Por culpa de la lluvia.
+ せいで :: Causa negativa.
- おかげで :: Causa positiva.
- ように :: Finalidad.
H Cap. 21. わすれない ___ 、 メモ を します。 :: Para no olvidar.
+ ように :: Objetivo.
- ながら :: Eso sería mientras.
- まえに :: Eso sería antes de.

- Como llueve, doy un paseo. :: Eso sería ので.
- Antes de que llueva, doy un paseo. :: Eso sería まえに.

- いけません :: Eso sería no se puede.
H Cap. 22. この みせ は やすい ___ 、 おいしい です。 :: Considerando que es barato, está rico.

- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
H Cap. 22. でんわ を かけました。 ___ 、 でませんでした。 :: Sin embargo, no contestó.

- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
Q Cap. 23. ¿Qué significa «てんき よほう に よると、 あした は あめ です»?
