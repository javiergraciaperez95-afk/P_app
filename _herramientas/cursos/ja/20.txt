@ 20 | くらべる と おわり (1) | Comparar de otra manera
I Hoy aprenderás a comparar de otras formas: decir cuál prefieres, decir que algo no es tan… como otra cosa, y decir cuál es el mejor.
E 〜の ほう が: el ... es más :: Para elegir una de dos cosas, pon la elegida con **の ほう が**: **バス の ほう が やすい です** (el bus es más barato). :: Para comparar con otra cosa usa **より**, como ya sabes: **でんしゃ より バス の ほう が やすい です** (el bus es más barato que el tren).
E 〜ほど 〜ない: no tan ... como :: Para decir que algo **no es tan** como otra cosa: **がっこう ほど とおく ない** (no está tan lejos como la escuela). :: Se usa siempre con la negación.
E いちばん: lo más :: **いちばん** significa «el más» o «lo más». Va delante del adjetivo o del verbo: **すし が いちばん すき です** (me gusta más el sushi). :: No hace falta decir «de todos».
B Comparar | Forma | Significa | Ejemplo
| 〜の ほう が 〜 | el ... es más | バス の ほう が やすい です
| 〜より 〜 | más que | でんしゃ より やすい
| 〜ほど 〜ない | no tan ... como | がっこう ほど とおく ない
| いちばん 〜 | lo más | すし が いちばん すき です
W ほど = tanto como; hasta el punto de | hodo
W いちばん = el más; lo más | ichiban
W とおく = lejos (adverbio) | tōku
V Vocabulario: comparar
D Elegir el transporte
けんじ: がっこう へ いく の は でんしゃ です か、 バス です か。 = ¿Vas a la escuela en tren o en bus?
  > でんしゃ です か、 バス です か = ¿en tren o en bus?
まり: バス の ほう が やすい です よ。 でんしゃ より やすい です。 = El bus es más barato. Es más barato que el tren.
  > バス の ほう が やすい = el bus es más barato | でんしゃ より やすい = más barato que el tren
けんじ: そう です か。 じゃあ、 わたし は バス で いきます。 = ¿Ah, sí? Entonces iré en bus.
  > わたし は バス で いきます = iré en bus
まり: わたし の いえ は がっこう ほど とおく ない です。 = Mi casa no está tan lejos como la escuela.
  > がっこう ほど とおく ない = no está tan lejos como la escuela
Q ¿Qué significa «バス の ほう が やすい です»?
+ El bus es más barato. :: の ほう が = el ... es más.
- El bus es caro. :: Eso es lo contrario.
- El tren es más barato. :: Eso es lo contrario.
Q ¿Qué expresa «〜ほど 〜ない»?
+ No tan... como. :: Se compara y se niega la igualdad.
- Más que. :: Eso sería より.
- Lo más. :: Eso sería いちばん.
H わたし は すし が ___ すき です。 :: Me gusta más el sushi.
+ いちばん :: Lo más.
- ほど :: Eso sería «no tan... como».
- より :: Eso sería «más que».
H わたし の いえ は がっこう ___ とおく ない です。 :: Mi casa no está tan lejos como la escuela.
+ ほど :: No tan... como.
- より :: Eso sería «más que».
- いちばん :: Eso sería «lo más».
R でんしゃ より バス の ほう が やすい です。 :: Traduce la frase.
+ El bus es más barato que el tren. :: の ほう が = el ... es más.
- El tren es más barato que el bus. :: Eso es lo contrario.
- El bus es el más barato de todos. :: Eso sería いちばん.
A がっこう ほど とおく ない です。 :: ¿Qué dice?
+ No está tan lejos como la escuela. :: ほど 〜ない = no tan... como.
- Está más lejos que la escuela. :: Eso es lo contrario.
- Está lejísimo. :: No aparece en la frase.
O すし が いちばん すき です :: Me gusta más el sushi. :: いちばん = lo más.
Q ¿Cuál significa «いちばん やすい»?
+ Lo más barato. :: いちばん = el más.
- Más barato que. :: Eso sería より.
- No tan barato. :: Eso sería ほど 〜ない.

@ 20 | くらべる と おわり (2) | Solo y nada más
I Ahora aprenderás a decir que algo es solo eso, sin nada más. Son palabras muy útiles para hablar de lo que comes o de lo que haces.
E 〜だけ: solo :: Pon **だけ** detrás de la palabra: **パン だけ** (solo pan). Se usa con nombres y con cantidades: **いちまい だけ** (solo uno). :: Después de **だけ** va el verbo afirmativo: **パン だけ たべます** (solo como pan).
E 〜ばかり: solo, siempre lo mismo :: **ばかり** también significa «solo», y con mucho uso, «siempre lo mismo»: **ゲーム ばかり して います** (solo hago videojuegos). :: Ojo: ya conoces **〜た ばかり** (acabo de). Es la misma palabra con otro sentido, según lo que va antes.
B Solo o nada más | Forma | Significa | Ejemplo
| 〜だけ | solo, nada más | パン だけ たべます
| 〜ばかり | solo, siempre lo mismo | ゲーム ばかり して います
| 〜た ばかり | acabo de | かえった ばかり です
W だけ = solo; nada más | dake
V Vocabulario: solo
D Un desayuno
まり: あさ は なに を たべます か。 = ¿Qué comes por la mañana?
  > あさ は なに を たべます か = ¿qué comes por la mañana?
けんじ: パン だけ たべます。 = Solo como pan.
  > パン だけ = solo pan
まり: パン だけ です か。 = ¿Solo pan?
  > パン だけ です か = ¿solo pan?
けんじ: はい。 コーヒー も のみません。 = Sí. Tampoco bebo café.
  > コーヒー も のみません = tampoco bebo café
Q ¿Qué significa «パン だけ たべます»?
+ Solo como pan. :: だけ = solo.
- Como pan y bebo café. :: Eso añade cosas.
- No como pan. :: Eso es lo contrario.
Q ¿Qué sentido tiene «ばかり» en «ゲーム ばかり して います»?
+ Hace solo videojuegos, siempre lo mismo. :: ばかり = solo, siempre.
- Acaba de jugar. :: Eso sería 〜た ばかり.
- Va a jugar. :: Eso sería 〜つもり.
H コーヒー ___ のみます。 :: Solo bebo café.
+ だけ :: Solo.
- も :: Eso sería «también».
- より :: Eso sería «más que».
H ゲーム ___ して います。 :: Solo hago videojuegos, siempre.
+ ばかり :: Solo, siempre lo mismo.
- まで :: Eso sería «hasta».
- も :: Eso sería «también».
R パン だけ たべます。 :: Traduce la frase.
+ Solo como pan. :: だけ = solo.
- Como pan y fruta. :: Eso añade cosas.
- No como pan. :: Eso es lo contrario.
A パン だけ です か。 :: ¿Qué pregunta?
+ ¿Solo pan? :: だけ = solo.
- ¿Pan y café? :: Eso añade cosas.
- ¿Cuánto cuesta el pan? :: No aparece en la frase.
O コーヒー も のみません :: Tampoco bebo café. :: も = también (en negativo: tampoco).
Q ¿Cuál dice «acabo de volver»?
+ かえった ばかり です :: 〜た ばかり = acabo de.
- かえって だけ です :: Eso no tiene sentido aquí.
- かえります ばかり です :: No es correcto.

@ 20 | くらべる と おわり (3) | Aunque... (のに)
I Por último, la palabra que sirve para decir que algo pasa al revés de lo esperado. Es muy útil para quejarte con educación o para mostrar sorpresa.
E 〜のに: aunque, a pesar de :: Pon la frase en forma normal y añade **のに**: **やくそく した のに、 ともだち は きませんでした** (aunque habíamos quedado, mi amigo no vino). :: Lo que va después de **のに** es lo que no se cumple o sorprende.
E 〜のに con ない :: Con la forma **ない** también va igual: **おかね が ない のに、 ふく を かいました** (aunque no tenía dinero, compré ropa). :: Con adjetivos en -i va en forma normal: **たかい のに、 かいました** (aunque era caro, lo compré).
B Lo que no se cumple | Forma | Significa | Ejemplo
| 〜のに | aunque; a pesar de | やくそく した のに
| 〜ない のに | aunque no | おかね が ない のに
| 〜い のに | aunque es ... | たかい のに
W やくそく = promesa; cita (acuerdo) | yakusoku
W のに = aunque; a pesar de | noni
W きませんでした = no vino; no fue | kimasen deshita
W かいました = compré | kaimashita | Es el pasado de かいます (comprar).
V Vocabulario: aunque
D Un plan que falló
みか: やくそく した のに、 けんじ さん は きませんでした。 = Habíamos quedado, y Ken no vino.
  > やくそく した のに = aunque habíamos quedado | きませんでした = no vino
けんじ: すみません。 おかね が ない のに、 ふく を かいました。 = Perdón. Aunque no tenía dinero, compré ropa.
  > おかね が ない のに = aunque no tenía dinero | かいました = compré
Q ¿Qué significa «やくそく した のに、 ともだち は きませんでした»?
+ Aunque habíamos quedado, mi amigo no vino. :: のに = a pesar de.
- Mi amigo vino porque habíamos quedado. :: Eso es «porque».
- Mi amigo no quiso quedar. :: No aparece en la frase.
Q ¿Qué expresa «のに»?
+ Algo que pasa al revés de lo esperado. :: のに = aunque.
- Una orden. :: Eso sería 〜て ください.
- Un permiso. :: Eso sería 〜て も いい です.
H おかね が ない ___ 、 ふく を かいました。 :: Aunque no tenía dinero, compré ropa.
+ のに :: Lo esperado no se cumple.
- ために :: Eso sería «para».
- ながら :: Eso sería «mientras».
H たかい ___ 、 かいました。 :: Aunque era caro, lo compré.
+ のに :: Aunque es caro.
- まえに :: Eso sería «antes de».
- たら :: Eso sería «si».
R やくそく した のに、 ともだち は きませんでした。 :: Traduce la frase.
+ Aunque habíamos quedado, mi amigo no vino. :: のに = a pesar de.
- Antes de quedar, mi amigo vino. :: Eso sería まえに.
- Mientras quedábamos, mi amigo vino. :: Eso sería ながら.
A おかね が ない のに、 ふく を かいました。 :: ¿Qué cuenta?
+ Que compró ropa aunque no tenía dinero. :: のに = aunque.
- Que no compró ropa. :: Eso es lo contrario.
- Que tenía dinero y no compró nada. :: Eso es lo contrario.
O やくそく した のに :: Aunque habíamos quedado. :: のに = aunque.
Q ¿Qué significa «やくそく»?
+ Promesa; cita acordada. :: Algo que se ha acordado.
- Dinero. :: Eso sería おかね.
- Viaje. :: Eso sería りょこう.

@ 20 | さいご の テスト | Examen final de A2
E Examen final de A2 :: Veinticinco preguntas sobre los capítulos 11 a 20. Si aciertas veinte o más, tienes un A2 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 11. ¿Cuál es la forma て de «かく» (escribir)?
+ かいて :: Del grupo 1: く → いて.
- かって :: Es la forma de かう (comprar).
- かくて :: No existe: く cambia a いて.
H Cap. 11. あめ が ___ 。 :: Está lloviendo.
+ ふっています :: ふる → ふって + います.
- ふります :: Es el presente: llueve.
- ふったら :: Es «si llueve».
Q Cap. 11. ¿Cómo pides permiso para sentarte?
+ すわって も いい です か :: 〜て も いい です か = ¿puedo...?
- すわって は いけません :: Eso es prohibir.
- すわって ください :: Eso es pedir que te sientes.
H Cap. 11. ここ で しゃしん を ___ 。 :: No se debe sacar fotos aquí.
+ とって は いけません :: 〜て は いけません = no se debe.
- とって も いい です :: Eso es permiso.
- とります :: Eso es «saco fotos» (hecho).
Q Cap. 12. ¿Qué significa «ともだち が わたし に ほん を くれました»?
+ Mi amigo me dio un libro. :: くれました = otro me da a mí.
- Yo le di un libro a mi amigo. :: Eso sería あげました.
- Recibí un libro de mi amigo. :: Eso sería もらいました.
H Cap. 12. わたし は ともだち に ケーキ を ___ 。 :: Le di una tarta a mi amigo.
+ あげました :: Yo doy a otra persona.
- もらいました :: Yo recibo.
- くれました :: Otro me da a mí.
H Cap. 12. けさ かぎ を ___ 。 :: Esta mañana olvidé la llave, sin querer.
+ わすれて しまいました :: 〜てしまう: sin querer, con pena.
- わすれて おきました :: Eso sería dejarla preparada.
- わすれません :: Eso es «no olvido».
Q Cap. 13. ¿Qué significa «ねる まえに»?
+ Antes de dormir. :: まえに = antes de.
- Después de dormir. :: Eso sería あと で.
- Cuando duermo. :: Eso sería とき.
H Cap. 13. ごはん を ___ 、 さんぽ を します。 :: Después de comer, doy un paseo.
+ たべた あと で :: Después de comer.
- たべる まえに :: Eso sería antes de comer.
- たべません :: Eso es «no como».
Q Cap. 13. ¿Qué significa «にほん から かえった ばかり です»?
+ Acabo de volver de Japón. :: 〜た ばかり = acabo de.
- Voy a volver de Japón. :: Eso sería futuro.
- Vuelvo de Japón cada año. :: Eso sería hábito.
H Cap. 14. あめ が ___ 、 うち に います。 :: Si llueve, me quedo en casa.
+ ふったら :: Condición.
- ふります :: Eso sería «llueve», no una condición.
- ふって :: Forma て: no sirve aquí.
Q Cap. 14. ¿Qué significa «みぎ に まがる と、 えき が あります»?
+ Si gira a la derecha, hay una estación. :: と = si (siempre pasa).
- Gire a la derecha, hay una estación. :: Eso sería una orden.
- Antes de girar a la derecha, hay una estación. :: Eso sería まえに.
H Cap. 14. つかれた とき は、 はやく ___ ほう が いい です。 :: Es mejor que te acuestes temprano.
+ ねた :: Forma た + ほう が いい.
- ねない :: Eso sería «es mejor no dormir».
- ねて ください :: Eso sería una petición.
Q Cap. 15. ¿Qué significa «おきなければ なりません»?
+ Tengo que levantarme. :: なければ なりません = obligación.
- No tengo que levantarme. :: Eso sería なくても いい.
- Quiero levantarme. :: Eso sería 〜たい.
H Cap. 15. がっこう へ ___ いい です。 :: No hace falta ir a la escuela.
+ いかなくても :: No hace falta.
- いかなければ :: Eso sería «hay que ir».
- いきたい :: Eso sería «quiero ir».
H Cap. 16. あした は あめ が ふる ___ 。 :: Quizá mañana llueva.
+ かも しれません :: Duda: puede que.
- はず です :: Eso sería «debería ser».
- と おもいます :: Eso sería «creo que».
Q Cap. 16. ¿Qué expresa «おいしそう です»?
+ Que parece rico, por el aspecto. :: そう = parece.
- Que es rico, sin duda. :: Eso sería おいしい です.
- Que era rico. :: Eso sería el pasado.
H Cap. 17. わたし は にほんご が ___ 。 :: Puedo hablar japonés.
+ はなせます :: Forma de poder de はなす.
- はなします :: Eso sería «hablo».
- はなしたい :: Eso sería «quiero hablar».
H Cap. 18. らいげつ に にほん へ いく ___ です。 :: Tengo planeado ir a Japón el mes que viene.
+ よてい :: Plan ya fijado.
- たい :: Eso sería «quiero ir».
- ください :: Eso sería una petición.
Q Cap. 18. ¿Qué significa «まいにち うんどう する こと に しました»?
+ Decidí hacer ejercicio cada día. :: こと に しました = decisión propia.
- Hago ejercicio cada día. :: Eso sería un hábito.
- Quiero hacer ejercicio cada día. :: Eso sería 〜たい.
H Cap. 18. かいしゃ に いく ___ 、 はやく おきます。 :: Para ir a la empresa, me levanto temprano.
+ ため に :: Finalidad.
- たら :: Eso sería «si/cuando».
- ながら :: Eso sería «mientras».
H Cap. 19. あたま が いたい ___ 。 :: Es que me duele la cabeza.
+ んです :: Explicación.
- でした :: Eso sería «era» (pasado).
- でしょう :: Eso sería «supongo».
Q Cap. 19. ¿Qué significa «やまだ さん は あした くる と いいました»?
+ Yamada dijo que vendría mañana. :: と いいました = dijo que.
- Yamada viene mañana. :: Eso sería sin decir que lo dijo.
- Yamada no vendrá mañana. :: Eso es lo contrario.
H Cap. 20. でんしゃ より バス の ___ が やすい です。 :: El bus es más barato que el tren.
+ ほう :: の ほう が = el ... es más.
- もの :: Eso no encaja.
- ばかり :: Eso sería «solo».
H Cap. 20. やくそく した ___ 、 ともだち は きませんでした。 :: Aunque habíamos quedado, mi amigo no vino.
+ のに :: Aunque: lo esperado no se cumple.
- ために :: Eso sería «para».
- たら :: Eso sería «si».
