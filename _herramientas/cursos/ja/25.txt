@ 25 | べき と わけ (1) | Deber: べきだ
I En este capítulo hablamos de lo que hay que hacer, lo que no se puede evitar y lo que se hace sin hacer otra cosa. Son frases de opinión y de decisión.
E 〜べきだ: deber (opinión) :: Para decir lo que debería hacerse, según tu opinión: verbo en forma de diccionario + **べき です**: **まいにち にほんご を べんきょう する べき です** (deberías estudiar japonés cada día). :: Es un consejo firme: no es una orden de alguien, es lo que tú piensas que es correcto.
E 〜べきではない: no debería :: Para decir lo que no debería hacerse: verbo en forma de diccionario + **べき では ありません**: **ひとり で なやむ べき では ありません** (no deberías preocuparte tú solo). :: Con el verbo **する** queda **する べき**.
B Deber según mi opinión | Forma | Significa | Ejemplo
| 〜べき です | deberías | する べき です
| 〜べき では ありません | no deberías | なやむ べき では ありません
W べき = deber (de opinión) | beki
W もんだい = problema; cuestión | mondai
W なやむ = preocuparse; sufrir por algo | nayamu
W では = (forma de じゃ) no es; en ... (negación formal) | de wa
W むり = esfuerzo excesivo; imposible | muri
V Vocabulario: deber
T Consejos
- まいにち にほんご を べんきょう する べき です。 = Deberías estudiar japonés cada día.
  > する べき です = deberías estudiar
- もんだい が ある とき は、 ひとり で なやむ べき では ありません。 = Cuando tengas un problema, no deberías preocuparte tú solo.
  > なやむ べき では ありません = no deberías preocuparte
D Un examen cercano
けんじ: しけん が ちかい ので、 まいにち べんきょう する べき でしょう か。 = Como el examen está cerca, ¿debería estudiar todos los días?
  > する べき でしょう か = ¿debería estudiar?
やまだ: そう です ね。 でも、 むり を する べき では ありません。 = Sí, es verdad. Pero no deberías forzarte.
  > むり を する べき では ありません = no deberías forzarte
Q ¿Qué significa «まいにち にほんご を べんきょう する べき です»?
+ Deberías estudiar japonés cada día. :: べき です = deber según mi opinión.
- Estudias japonés cada día. :: Eso sería un hábito.
- No hace falta estudiar japonés. :: Eso es lo contrario.
Q ¿Qué forma se usa antes de «べき»?
+ La forma de diccionario. :: Verbo en diccionario + べき.
- La forma た. :: Eso sería el pasado.
- La forma ない. :: Eso sería negativo.
H もんだい が ある とき は、 ひとり で ___ べき では ありません。 :: No deberías preocuparte tú solo.
+ なやむ :: Forma de diccionario.
- なやんだ :: Eso sería el pasado.
- なやまない :: Eso sería negativo.
H まいにち べんきょう ___ です。 :: Deberías estudiar cada día.
+ する べき :: Forma de diccionario de する.
- した べき :: Eso sería el pasado.
- しない べき :: Eso es «no deberías» y falta el sentido.
R まいにち にほんご を べんきょう する べき です。 :: Traduce la frase.
+ Deberías estudiar japonés cada día. :: べき です = deber.
- Estudiar japonés cada día es muy caro. :: No aparece en la frase.
- No deberías estudiar japonés. :: Eso es lo contrario.
A でも、 むり を する べき では ありません。 :: ¿Qué aconseja?
+ No forzarse. :: では ありません = no debería.
- Forzarse más. :: Eso es lo contrario.
- Dormir más. :: No aparece en la frase.
O する べき です :: Deberías hacerlo. :: べき です = deber.
Q ¿Cuál significa «むり を する べき では ありません»?
+ No deberías forzarte. :: では ありません = no deberías.
- Es imposible forzarte. :: Eso sería むりです.
- Debes forzarte. :: Eso es lo contrario.

@ 25 | べき と わけ (2) | No hay más remedio: わけにはいかない y しかない
I Ahora dos frases para decir que algo no se puede hacer o que no hay otra opción. Muy útiles en el trabajo y para explicar tus decisiones.
E 〜わけにはいかない: no puedo permitirme :: Para decir que, por la situación o por el deber, no es posible hacer algo: verbo en forma de diccionario + **わけ に は いかない**: **しごと が おおい から、 やすむ わけ に は いきません** (como hay mucho trabajo, no puedo faltar). :: Es una imposibilidad social o moral, no una falta de capacidad.
E 〜しかない: no hay más remedio :: Para decir que solo hay una opción: verbo en forma de diccionario + **しか ない**: **おかね が ない ので、 あるく しか ありません** (como no tengo dinero, no hay más remedio que caminar). :: Va con **ありません** en forma educada.
B No hay más remedio | Forma | Significa | Ejemplo
| 〜わけにはいかない | no puedo permitirme | やすむ わけ に は いきません
| 〜しか ない | no hay más remedio | あるく しか ありません
W わけ = situación; razón; motivo | wake
W あるく = caminar | aruku
W しか = (con negación) solo; no hay más que | shika
W いきません = no voy; no iré | ikimasen
V Vocabulario: no hay más remedio
D Un viernes muy ocupado
やまだ: きょう は やすみ です か。 = ¿Hoy es día libre para ti?
  > やすみ です か = ¿es día libre?
けんじ: いいえ。 しごと が おおい から、 やすむ わけ に は いきません。 = No. Como hay mucho trabajo, no puedo faltar.
  > やすむ わけ に は いきません = no puedo faltar
やまだ: そう です か。 では、 あるく しか ありません ね。 = ¿Ah, sí? Entonces, no hay más remedio que caminar, ¿verdad?
  > あるく しか ありません = no hay más remedio que caminar
Q ¿Qué significa «しごと が おおい から、 やすむ わけ に は いきません»?
+ Como hay mucho trabajo, no puedo faltar. :: わけ に は いかない = no puedo permitirme.
- Como hay mucho trabajo, falto. :: Eso es lo contrario.
- Como hay poco trabajo, no falto. :: Eso no es la frase.
Q ¿Qué expresa «〜しか ない»?
+ Que no hay más remedio. :: Solo queda una opción.
- Que hay muchas opciones. :: Eso es lo contrario.
- Que es un deseo. :: Eso sería 〜たい.
H しごと が おおい から、 やすむ ___ は いきません。 :: No puedo faltar, por la situación.
+ わけ に :: No puedo permitirme.
- ため に :: Eso sería «para».
- ながら :: Eso sería «mientras».
H おかね が ない ので、 あるく ___ ありません。 :: No hay más remedio que caminar.
+ しか :: Solo queda esa opción.
- まで :: Eso sería «hasta».
- ながら :: Eso sería «mientras».
R しごと が おおい から、 やすむ わけ に は いきません。 :: Traduce la frase.
+ Como hay mucho trabajo, no puedo faltar. :: わけ に は いかない = imposible.
- Como hay poco trabajo, puedo faltar. :: Eso es lo contrario.
- Como hay mucho trabajo, falté. :: Eso es el pasado.
A おかね が ない ので、 あるく しか ありません。 :: ¿Qué cuenta?
+ Que no hay más remedio que caminar porque no tiene dinero. :: しか ありません = no hay más remedio.
- Que puede coger un taxi. :: Eso sería una opción.
- Que tiene mucho dinero. :: Eso es lo contrario.
O あるく しか ありません :: No hay más remedio que caminar. :: しか = solo esa opción.
Q ¿Cuál expresa que algo es imposible socialmente?
+ 〜わけにはいかない :: No se puede permitir.
- 〜しかない :: Es que no hay otra opción.
- 〜たい :: Es un deseo.

@ 25 | べき と わけ (3) | Sin hacer algo: ずに y ずにはいられない
I Por último, dos formas muy formales y escritas: hacer algo sin hacer otra cosa, y no poder evitar algo. Aparecen mucho en novelas y en los medios.
E 〜ずに: sin hacer :: Para decir que algo se hace sin hacer otra cosa: forma ない sin い + **ずに**: **なにも いわずに、 でかけました** (salió sin decir nada). :: Con **する** queda **せずに**.
E 〜ずにはいられない: no puedo evitar :: Para decir que no puedes evitar sentir o hacer algo: forma ない sin い + **ずには いられない**: **かわいい です から、 わらわずには いられません** (es tan mono que no puedo evitar reírme). :: Suena muy natural en la conversación formal.
B Sin hacer y sin evitar | Forma | Significa | Ejemplo
| 〜ずに | sin hacer | いわずに
| 〜ずには いられない | no puedo evitar | わらわずには いられません
W なにも = nada (con negación); ni... ni | nanimo
W いわずに = sin decir (forma ず de いう) | iwazu ni
W でかけました = salí (de casa) | dekakemashita
W かわいい = mono; bonito | kawaii
W わらわずには = sin reír (forma ず + には) | warawazu niwa
W いられません = no puedo estar; no puedo evitar | irare masen
V Vocabulario: sin hacer
D Un gato y una sorpresa
けんじ: どうして なにも いわずに かえった の？ = ¿Por qué te fuiste sin decir nada?
  > なにも いわずに = sin decir nada
まり: あの ねこ は かわいい です ね。 わらわずには いられません。 = Ese gato es precioso, ¿verdad? No puedo evitar reírme.
  > わらわずには いられません = no puedo evitar reírme
Q ¿Qué significa «なにも いわずに、 でかけました»?
+ Salió sin decir nada. :: ずに = sin hacer.
- Salió y dijo algo. :: Eso es lo contrario.
- Salió después de hablar. :: Eso invierte el orden.
Q ¿Qué expresa «〜ずには いられない»?
+ No se puede evitar algo. :: Expresa una reacción fuerte.
- Una orden. :: Eso sería 〜て ください.
- Un deseo. :: Eso sería 〜たい.
H なにも ___ 、 でかけました。 :: Salió sin decir nada.
+ いわずに :: Sin decir.
- いって :: Eso sería decir y luego.
- いわなくても :: Eso sería no hace falta decir.
H かわいい です から、 ___ 。 :: Es tan mono que no puedo evitar reírme.
+ わらわずには いられません :: No puedo evitarlo.
- わらって ください :: Eso sería una petición.
- わらいたい :: Eso sería un deseo.
R なにも いわずに、 でかけました。 :: Traduce la frase.
+ Salió sin decir nada. :: ずに = sin.
- Salió diciendo algo. :: Eso es lo contrario.
- Salió antes de que dijera algo? :: Eso no es la frase.
A あの ねこ は かわいい です ね。 わらわずには いられません。 :: ¿Qué cuenta?
+ Que no puede evitar reírse porque el gato es precioso. :: ずには いられない = no puede evitar.
- Que le da miedo el gato. :: Eso es lo contrario.
- Que el gato no es bonito. :: Eso es lo contrario.
O なにも いわずに :: Sin decir nada. :: ずに = sin.
Q ¿Cuál es el sentido de «いわずに»?
+ Sin decir. :: Forma ず de いう.
- Diciendo. :: Eso sería いって.
- Dijo. :: Eso sería いいました.
