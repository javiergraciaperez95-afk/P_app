@ 38 | をはじめ と に応じて と をもって | Empezando por..., según... y a partir de...
I Hoy aprendes tres expresiones formales: para citar lo primero de una lista, para adaptar algo a una situación y para fijar un momento a partir del cual algo vale.
E 〜をはじめ: empezando por; entre otros :: Sustantivo + **をはじめ**: **せんせい をはじめ、 がくせい が います** (están el profesor y los alumnos, entre otros). :: Introduce el primer ejemplo de una lista.
E 〜に応じて: según; de acuerdo con :: Sustantivo + **に応じて**: **てんき に おうじて、 でかけます** (salgo según el tiempo). :: Algo cambia para adaptarse a la situación.
E 〜をもって: a partir de; con motivo de (formal) :: Sustantivo de tiempo + **をもって**: **きょう をもって、 しごと を おわります** (a partir de hoy, el trabajo termina). :: Suena a aviso o comunicado oficial.
W をはじめ = empezando por; entre otros | o hajime | kanji: をはじめ
W におうじて = según; de acuerdo con | ni ōjite | kanji: に応じて
W をもって = a partir de; con motivo de | o motte | kanji: をもって
W しょうかい = presentación; introducción | shōkai | kanji: 紹介
W こうじ = obra; construcción | kōji | kanji: 工事
W はいけん = ver; examinar (humilde) | haiken | kanji: 拝見
W うかがいます = visitar; preguntar (humilde) | ukagaimasu | kanji: 伺います
W まいります = ir; venir (humilde) | mairimasu | kanji: 参ります
W いたします = hacer (humilde) | itashimasu | kanji: いたします

V Vocabulario: empezando por, según y a partir de
T Comunicados
- せんせい をはじめ、 がくせい が います。 = Entre otros, están el profesor y los alumnos.
- てんき におうじて、 でかけます。 = Salgo según el tiempo.
- きょう をもって、 しごと を おわります。 = A partir de hoy, el trabajo termina.
Q ¿Qué significa «せんせい をはじめ、 がくせい が います»?
+ Entre otros, están el profesor y los alumnos. :: をはじめ = empezando por.
- Solo está el profesor. :: Eso es lo contrario.
- Los alumnos se fueron. :: Eso es el pasado.
Q ¿Qué expresa «をもって»?
+ Que algo se aplica a partir de un momento. :: Fecha de inicio formal.
- Una causa. :: Eso sería ので.
- Un deseo. :: Eso sería たい.
H てんき ___ 、 でかけます。 :: Salgo según el tiempo.
+ におうじて :: Según.
- ために :: Eso sería para.
- まで :: Eso sería hasta.
H きょう ___ 、 しごと を おわります。 :: A partir de hoy, el trabajo termina.
+ をもって :: A partir de.
- まで :: Eso sería hasta.
- ながら :: Eso sería mientras.
R せんせい をはじめ、 がくせい が います。 :: Traduce la frase.
+ Including the teacher and the students, there are people here. :: をはじめ = empezando por.
- The teacher is absent. :: Eso es lo contrario.
- The students left. :: Eso es el pasado.
A てんき におうじて、 でかけます。 :: ¿Qué cuenta?
+ Que sale según el tiempo. :: に応じて = según.
- Que nunca sale. :: Eso es lo contrario.
- Que salió ayer. :: Eso es el pasado.
O きょう をもって、 しごと を おわります :: A partir de hoy, el trabajo termina. :: をもって = a partir de.
Q ¿Cuál es más formal?
+ をもって :: Lenguaje oficial.
- ながら :: Es conversacional.
- から :: Es neutro.
