@ 28 | A casa que comprei | La casa que compré: oraciones de relativo con «que»
I Hoy aprenderás a unir dos frases en una: «la casa que compré», «el libro que lees».
E Que :: El pronombre **que** (que) sirve para unir dos frases y señalar un nombre: **A casa que comprei é grande** (la casa que compré es grande). Es el relativo más usado en portugués, como en español. :: Se usa sin importar si el nombre es masculino, femenino, singular o plural: **o jardim que tens**, **as casas que vês**.
E Que sin preposición :: Si la frase de relativo no necesita preposición, usa **que**: **Esse jardim que vês ao fundo** (ese jardín que ves al fondo).
B Frase | Relativo | Traducción
| A casa que comprei. | que | La casa que compré.
| O jardim que tens. | que | El jardín que tienes.
| Esse jardim que vês ao fundo. | que | Ese jardín que ves al fondo.
W ao fundo = al fondo | ao FON-du | Lo que está en la parte de atrás.
W nasci = nací | na-SI | Viene de «nascer» (nacer).
W nasceu = nació | na-SEU | Viene de «nascer» (nacer).
W vives = vives | VI-vesh | Con «tu», de «viver».
W vivo = vivo | VI-vu | Con «eu», de «viver».
W em que = en el que | eim KE | Para indicar lugar o situación.
W com quem = con quien | kon KEM | Para hablar de una persona con quien pasa algo.
W de quem = de quien | d(e) KEM | Para hablar de una persona de quien se habla.
W aquilo que = lo que | a-KI-lu KE | Para hablar de algo que se dijo o hizo.
W que = que (relativo) | KE | Une dos frases para señalar un nombre.
V Vocabulario: unir frases
D Una casa nueva
Ana: A casa que comprei é muito bonita. = La casa que compré es muy bonita.
  > A casa que comprei = la casa que compré | é muito bonita = es muy bonita
Pedro: O jardim que tens é grande. = El jardín que tienes es grande.
  > O jardim que tens = el jardín que tienes | é grande = es grande
Ana: Esse jardim que vês ao fundo é o meu favorito. = Ese jardín que ves al fondo es mi favorito.
  > que vês ao fundo = que ves al fondo | é o meu favorito = es mi favorito
Q ¿Cómo se dice «la casa que compré»?
+ a casa que comprei :: «Que» une la frase con «casa».
- a casa comprei :: Falta el relativo «que».
- a casa onde comprei :: «Onde» es para lugares.
Q ¿Qué palabra usas para unir frases con un nombre sin preposición?
+ que :: Es el relativo más común.
- onde :: Se usa para lugares.
- quem :: Se usa para personas con preposición.
R A casa que comprei é grande.
+ La casa que compré es grande. :: «Que» une la frase.
- La casa compré es grande. :: Falta el relativo.
- La casa que compro es grande. :: Eso es presente.
H O jardim ___ tens é grande. :: Que
+ que :: Relativo con «jardim».
- onde :: Eso es para lugares.
- quem :: Eso es para personas.
H As casas ___ vês são bonitas. :: Que
+ que :: Relativo con plural.
- qual :: Eso no se usa así aquí.
- o que :: Eso no se usa con un nombre.
A Esse jardim que vês é grande.
+ Ese jardín que ves es grande. :: «Que vês» = que ves.
- Ese jardín que comprei es grande. :: No es la frase.
- Ese jardín donde vives es grande. :: Es otro relativo.
O Esse jardim que vês ao fundo. :: Ese jardín que ves al fondo. :: «Ao fundo» = al fondo.
X Escribe en portugués «el libro que lees» :: o livro que lês :: «Que» une la frase con «livro».

@ 28 | A cidade onde nasci | La ciudad donde nací: relativos con preposición
I Hoy aprenderás a hablar de lugares, personas y cosas con preposición: «donde», «con quien», «de quien».
E Onde :: Para lugares, usa **onde** (donde): **A cidade onde nasci** (la ciudad donde nací). :: Con **em que** también se dice lo mismo para cosas: **o bairro em que vives** (el barrio en que vives).
E Preposiciones con personas :: Con una persona, puedes usar **preposición + quem**: **a pessoa com quem falaste** (la persona con quien hablaste), **a professora de quem gosto** (la profesora a quien quiero). También existe **a pessoa com a qual falei**, de registro más formal. :: La preposición depende del verbo: **gostar de**, **falar com**.
B Relativo | Uso | Ejemplo
| onde | lugar | A cidade onde nasci.
| em que | lugar o cosa | O bairro em que vives.
| com quem | persona con preposición | A pessoa com quem falaste.
| com a qual | persona o cosa, más formal | A pessoa com a qual falei.
| de quem | persona de quien | A professora de quem gosto.
W gosto = me gusta | GOSH-tu | Ya lo conoces; aquí va con «de».
W falaste = hablaste | fa-LASH-t(e) | Con «tu», de «falar».
V Vocabulario: lugares y personas
D Hablando de ciudades
Ana: Esta é a cidade onde nasci. = Esta es la ciudad donde nací.
  > a cidade onde nasci = la ciudad donde nací
Pedro: E a pessoa com quem falaste ontem? = ¿Y la persona con quien hablaste ayer?
  > a pessoa com quem falaste = la persona con quien hablaste
Ana: É a minha professora, de quem gosto muito. = Es mi profesora, de quien me gusta mucho.
  > de quem gosto muito = de quien me gusta mucho
Pedro: O bairro em que vives é muito bonito. = El barrio en que vives es muy bonito.
  > em que vives = en que vives
Q ¿Cómo se dice «la ciudad donde nací»?
+ a cidade onde nasci :: «Onde» para lugares.
- a cidade que nasci :: «Que» sin lugar.
- a cidade com quem nasci :: «Com quem» es para personas.
Q ¿Qué relativo puede usarse para una persona con preposición en una forma frecuente?
+ quem :: Por ejemplo, «a pessoa com quem falaste».
- onde :: Es para lugares.
- cujo :: Es un posesivo relativo, no sirve aquí.
R A pessoa com quem falaste.
+ La persona con quien hablaste. :: «Com quem» = con quien.
- La persona que hablaste. :: Falta la preposición.
- La persona donde hablaste. :: «Onde» es para lugares.
H A cidade ___ nasci. :: Onde
+ onde :: Relativo de lugar.
- quem :: Es para personas.
- com quem :: Es para personas.
H A professora de ___ gosto. :: Quem
+ quem :: «De quem» = de quien.
- onde :: Es para lugares.
- que :: Sin preposición no se usa aquí.
A A cidade onde nasci é bonita.
+ La ciudad donde nací es bonita. :: «Onde» = donde.
- La ciudad que nací es bonita. :: Falta el relativo de lugar.
- La ciudad com quem nasci es bonita. :: Eso es para personas.
O O bairro em que vives. :: El barrio en que vives. :: «Em que» para lugares o cosas.
X Escribe en portugués «la persona con quien hablo» :: a pessoa com quem falo :: «Com quem» = con quien.

@ 28 | Aquilo que disseste | Lo que dijiste: relativos sin antecedente
I Hoy aprenderás a hablar de algo sin decir el nombre: «lo que», «quien» (el que).
E Aquilo que / o que :: Para decir «lo que», usa **aquilo que**: **Aquilo que disseste é verdade** (lo que dijiste es verdad). En el habla diaria se dice también **o que**: **Não sei o que vou fazer** (no sé lo que voy a hacer).
E Quem (el que) :: **Quem sabe, sabe** (quien sabe, sabe). Aquí **quem** significa «el que» o «quien».
B Frase | Traducción
| Aquilo que disseste é verdade. | Lo que dijiste es verdad.
| Não sei o que vou fazer. | No sé lo que voy a hacer.
| Quem sabe, sabe. | Quien sabe, sabe.
| Eu sei o que é melhor. | Yo sé lo que es mejor.
W quem sabe = quien sabe | KEM SA-bi | Expresión popular.
V Vocabulario: lo que
D Una opinión
Ana: Aquilo que disseste é verdade. = Lo que dijiste es verdad.
  > Aquilo que disseste = lo que dijiste | é verdade = es verdad
Pedro: Quem sabe, sabe. = Quien sabe, sabe.
  > Quem sabe, sabe = quien sabe, sabe
Ana: Não sei o que vou fazer amanhã. = No sé lo que voy a hacer mañana.
  > o que vou fazer = lo que voy a hacer
Pedro: Eu sei o que é melhor. = Yo sé lo que es mejor.
  > o que é melhor = lo que es mejor
Q ¿Cómo se dice «lo que dijiste»?
+ aquilo que disseste :: Relativo sin antecedente.
- aquilo disseste :: Falta el relativo «que».
- aquilo onde disseste :: «Onde» es para lugares.
Q ¿Qué significa «quem sabe, sabe»?
+ quien sabe, sabe :: Expresión popular con «quem».
- sabe quién es :: No es la frase.
- quién sabe :: Es una pregunta.
R Aquilo que disseste é verdade.
+ Lo que dijiste es verdad. :: «Aquilo que» = lo que.
- Lo dijiste es verdad. :: Falta el relativo.
- Aquello dijiste es verdad. :: Falta el «que».
H Não sei ___ vou fazer. :: O que
+ o que :: Relativo sin antecedente.
- quem :: Es para personas.
- onde :: Es para lugares.
H ___ sabe, sabe. :: Quem
+ quem :: «Quem sabe, sabe» = quien sabe, sabe.
- que :: No se usa aquí.
- onde :: Es para lugares.
A Eu sei o que é melhor.
+ Yo sé lo que es mejor. :: «O que» = lo que.
- Yo sé donde es mejor. :: «Onde» es para lugares.
- Yo sé quien es mejor. :: «Quem» es para personas.
O Quem sabe, sabe. :: Quien sabe, sabe. :: «Quem» = quien.
X Escribe en portugués «lo que quiero» :: o que quero :: «O que» = lo que.
