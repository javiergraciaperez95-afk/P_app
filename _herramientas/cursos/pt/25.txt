@ 25 | Para que tenhas tempo | Para que tengas tiempo: finalidad con conjuntivo
I Hoy aprenderás a explicar para qué haces algo: «para que» con conjuntivo y «para» con infinitivo.
E Para que + conjuntivo :: Cuando el sujeto cambia, usa **para que** + conjuntivo: **Vou ligar-te cedo, para que tenhas tempo** (te llamaré temprano para que tengas tiempo). :: También existe **a fim de que** (con el fin de que), más formal: **a fim de que possamos decidir** (con el fin de que podamos decidir).
E Para + infinitivo :: Cuando el sujeto es el mismo, usa **para** + infinitivo: **Estudo para passar no exame** (estudio para aprobar el examen). Ojo: no digas **para que passe** si eres tú quien estudia.
B Sujeto | Estructura | Ejemplo
| mismo sujeto | para + infinitivo | Estudo para passar no exame.
| sujeto distinto | para que + conjuntivo | Ligo-te para que tenhas tempo.
| formal | a fim de que + conjuntivo | A fim de que possamos decidir.
W para que = para que | PA-ra KE | Finalidad con sujeto distinto: va con conjuntivo.
W a fim de que = con el fin de que | a FIN de KE | Versión más formal de «para que».
W ligar-te = llamarte | li-GAR-t(e) | Infinitivo con «te» al final.
W possamos = podamos | pu-SA-mush | Conjuntivo de «poder», con «nós».
W estudo = estudio (yo) | esh-TU-du | Viene de «estudar»: «estudo para passar».
W ligo-te = te llamo | LI-gu-t(e) | Con «eu» y «te» al final.
W te = te | t(e) | Pronombre de «tu»: va delante o detrás del verbo.
W passar = pasar (un examen) | pa-SAR | Aprobar o cruzar algo.
W exame = examen | e-ZA-m(e) | Prueba para acreditar lo que sabes.
W noite = noche | NOI-t(e) | Ya lo conoces; aquí «a noite toda» = toda la noche.
V Vocabulario: para qué
D Un examen
Ana: Vou ligar-te cedo, para que tenhas tempo de ler o e-mail. = Te llamaré temprano para que tengas tiempo de leer el correo.
  > para que tenhas tempo = para que tengas tiempo | ler o e-mail = leer el correo
Pedro: Para que é isso? = ¿Para qué es eso?
  > Para que é isso = ¿para qué es eso?
Ana: Para que possamos decidir juntos. = Para que podamos decidir juntos.
  > para que possamos decidir = para que podamos decidir
Pedro: Estudo a noite toda para passar no exame. = Estudio toda la noche para aprobar el examen.
  > para passar no exame = para aprobar el examen | a noite toda = toda la noche
Q ¿Cómo se dice «para que tengas tiempo»?
+ para que tenhas tempo :: Sujeto distinto: conjuntivo.
- para ter tempo :: Eso sería para el mismo sujeto.
- para que tens tempo :: Falta el conjuntivo.
Q ¿Qué forma es correcta con el mismo sujeto (yo estudio para aprobar)?
+ Estudo para passar. :: Mismo sujeto: infinitivo.
- Estudo para que passe. :: Sujeto distinto con conjuntivo.
- Estudo para que passo. :: Falta el conjuntivo.
R Ligo-te para que saibas a hora.
+ Te llamo para que sepas la hora. :: «Saibas» = sepas.
- Te llamo para saber la hora. :: Mismo sujeto sería «para saber».
- Te llamo para que sabes a hora. :: Falta el conjuntivo.
H Estudo para ___ no exame. :: Passar
+ passar :: Mismo sujeto: infinitivo.
- passe :: Sujeto distinto.
- passas :: Presente de «tú».
H Vou ligar-te para que ___ tempo. :: Tenhas
+ tenhas :: Conjuntivo de «ter» con «tu».
- tens :: Presente.
- ter :: Infinitivo.
A Estudo para passar no exame.
+ Estudio para aprobar el examen. :: Mismo sujeto.
- Estudio para que aprobe el examen. :: Sujeto distinto.
- Estudiaré el examen. :: Eso es futuro.
O Vou ligar-te para que possas ir. :: Te llamo para que puedas ir. :: «Possas» = puedas.
X Escribe en portugués «para que puedas ir» :: para que possas ir :: «Possas» = puedas.

@ 25 | Antes que chegues | Antes de que llegues: tiempo y conjuntivo
I Hoy aprenderás a decir «antes de que», «hasta que» y «sin que».
E Antes que, até que, sem que :: **Antes que** (antes de que), **até que** (hasta que), **sem que** (sin que) van con conjuntivo cuando el sujeto cambia: **Antes que saias, fecha a porta** (antes de que salgas, cierra la puerta). **Até que chegues** (hasta que llegues).
E Antes de + infinitivo :: Con el mismo sujeto: **Antes de sair, fecho a porta** (antes de salir, cierro la puerta). Ojo: sin **que**.
B Conjunción | Ejemplo | Traducción
| antes que + conjuntivo | Antes que saias, fecha a porta. | Antes de que salgas, cierra la puerta.
| até que + conjuntivo | Vou esperar até que chegues. | Voy a esperar hasta que llegues.
| sem que + conjuntivo | Sem que te atrases... | Sin que llegues tarde...
W antes que = antes de que | AN-tesh KE | Va con conjuntivo cuando el sujeto cambia.
W até que = hasta que | a-TE KE | Va con conjuntivo cuando el sujeto cambia.
W sem que = sin que | sei KE | Va con conjuntivo cuando el sujeto cambia.
W saias = salgas | SA-yash | Conjuntivo de «sair», con «tu».
W fechar = cerrar | fe-SHAR | Infinitivo de «fecha».
W esperar = esperar | esh-pe-RAR | Infinitivo de «espere».
W atrases = retrases | a-TRA-zesh | Conjuntivo de «atrasar», con «tu».
W atrasar-me = llegar tarde | a-tra-ZAR-m(e) | Retrasarse, llegar después de la hora.
W não me atraso = no llego tarde | NAUN m(e) a-TRA-zu | Expresión coloquial.
W combinado = de acuerdo | kon-bi-NA-du | Ya lo conoces; se usa para cerrar un plan.
V Vocabulario: antes y después
D Llegar a tiempo
Ana: Antes que saias, fecha a porta, por favor. = Antes de que salgas, cierra la puerta, por favor.
  > Antes que saias = antes de que salgas | fecha a porta = cierra la puerta
Pedro: Está bem. Vou esperar até que chegues? = Vale. ¿Voy a esperar hasta que llegues?
  > até que chegues = hasta que llegues | esperar = esperar
Ana: Sim, sem que te atrases! = ¡Sí, sin que llegues tarde!
  > sem que te atrases = sin que llegues tarde
Pedro: Não me atraso. Combinado! = No llego tarde. ¡De acuerdo!
  > Não me atraso = no llego tarde | Combinado = de acuerdo
Q ¿Qué significa «até que chegues»?
+ hasta que llegues :: Conjunción de tiempo con conjuntivo.
- hasta llegar :: Con el mismo sujeto sería infinitivo.
- cuando llegas :: Eso no es «até que».
Q ¿Cómo se dice «antes de salir» (yo)?
+ Antes de sair. :: Mismo sujeto: «antes de» + infinitivo.
- Antes que saia. :: Con «que» el sujeto cambia.
- Antes que saio. :: Eso no es el conjuntivo.
R Antes que saias, fecha a porta.
+ Antes de que salgas, cierra la puerta. :: «Saias» = salgas.
- Antes de salir, cierra la puerta. :: Eso cambia el sujeto.
- Antes que sais, fecha a porta. :: Eso no es «tu».
H Vou esperar até que ___. :: Chegues
+ chegues :: Conjuntivo de «chegar» con «tu».
- chegas :: Presente.
- chegar :: Infinitivo.
H Não me ___. :: Atraso
+ atraso :: «Não me atraso» = no llego tarde.
- atrasas :: Es con «tu».
- atraso-me :: Orden incorrecta.
A Sem que te atrases.
+ Sin que llegues tarde. :: «Atrases» = llegues tarde.
- Sin que sales tarde. :: Eso es «sais».
- Sin llegar tarde. :: Eso es sin infinitivo.
O Antes que saias. :: Antes de que salgas. :: «Antes que» + conjuntivo.
X Escribe en portugués «hasta que llegues» :: até que chegues :: «Até que» + conjuntivo.

@ 25 | Ainda que chova, vou | Aunque llueva, voy: concesión y cuando con conjuntivo
I Hoy aprenderás a decir «aunque» y a hablar de cuándo harás algo en el futuro.
E Ainda que, mesmo que :: **Ainda que** y **mesmo que** (aunque) van con conjuntivo: **Ainda que chova, vou à praia** (aunque llueva, voy a la playa). **Mesmo que digas que não, venho** (aunque digas que no, vengo).
E Quando + presente :: Para decir cuándo pasará algo, en el uso diario se usa el presente: **Quando chegas, avisa-me** (cuando llegues, avísame). En el B2 aprenderás el conjuntivo futuro para esto.
B Expresión | Ejemplo | Traducción
| ainda que + conjuntivo | Ainda que chova, vou. | Aunque llueva, voy.
| mesmo que + conjuntivo | Mesmo que digas que não, venho. | Aunque digas que no, vengo.
| quando + presente | Quando chegas, avisa-me. | Cuando llegues, avísame.
W ainda que = aunque | AIN-da KE | Concesiva con conjuntivo.
W mesmo que = aunque | MEZH-mu KE | Concesiva con conjuntivo; más enfática.
W contigo = contigo | kon-TI-gu | Con «tu»: «venho contigo».
W chegas = llegas | she-GASH | Presente de «chegar», con «tu».
W avisa-me = avísame | a-VI-za-m(e) | Orden a un amigo.
W combinado = de acuerdo | kon-bi-NA-du | Ya lo conoces, de acuerdo.
V Vocabulario: aunque y cuando
D Plan de playa
Ana: Ainda que chova, vou à praia amanhã. = Aunque llueva, mañana voy a la playa.
  > Ainda que chova = aunque llueva | vou à praia amanhã = voy a la playa mañana
Pedro: Mesmo que digas que não, venho contigo. = Aunque digas que no, voy contigo.
  > Mesmo que digas = aunque digas | venho contigo = voy contigo
Ana: Quando chegas, avisa-me. = Cuando llegues, avísame.
  > Quando chegas = cuando llegues | avisa-me = avísame
Pedro: Combinado! = ¡De acuerdo!
  > Combinado = de acuerdo
Q ¿Qué significa «ainda que chova»?
+ aunque llueva :: Concesión con conjuntivo.
- como llueve :: Eso sería «como chove».
- porque llueve :: Eso sería «porque chove».
Q ¿Cómo se dice «aunque digas que no»?
+ mesmo que digas que não :: Concesión con «mesmo que».
- porque dizes que não :: Eso sería causa.
- quando dizes que não :: Eso sería tiempo.
R Mesmo que digas que não, venho.
+ Aunque digas que no, vengo. :: «Digas» = digas.
- Porque dices que no, vengo. :: Eso es causa.
- Cuando dices que no, vengo. :: Eso es tiempo.
H Ainda que ___, vou à praia. :: Chova
+ chova :: Conjuntivo de «chover».
- chove :: Presente.
- choverá :: Futuro.
H Quando ___, avisa-me. :: Chegas
+ chegas :: Presente con «tu», para un momento futuro en el uso diario.
- chegou :: Pasado.
- chegarás :: Futuro simple.
A Ainda que chova, vou.
+ Aunque llueva, voy. :: «Ainda que» + conjuntivo.
- Como llueve, voy. :: Eso es causa.
- Cuando llueva, voy. :: Eso es tiempo.
O Venho contigo. :: Voy contigo. :: «Contigo» = con tigo (contigo).
X Escribe en portugués «aunque llueva» :: ainda que chova :: «Ainda que» + conjuntivo.
