@ 26 | O romance foi escrito por uma autora | La novela fue escrita por una autora: la voz pasiva
I Hoy aprenderás la voz pasiva: cuando lo importante no es quién hace algo, sino lo que le pasa a algo.
E Ser + participio :: La voz pasiva se forma con **ser** + **participio**, y el participio concuerda con el sujeto: **O romance foi escrito** (la novela fue escrita), **Os livros foram escritos** (los libros fueron escritos). :: Quien hace la acción va con **por**: **escrito por uma autora** (escrito por una autora).
E Tiempos :: El tiempo lo marca **ser**: **foi** (fue), **é** (es), **será** (será), **era** (era). Ej: **O livro é lido por muitos** (el libro es leído por muchos).
B Tiempo | Ejemplo | Traducción
| pasado (foi) | O romance foi escrito por uma autora. | La novela fue escrita por una autora.
| presente (é) | O livro é lido por muitos. | El libro es leído por muchos.
| plural (foram) | Os livros foram escritos por autores. | Los libros fueron escritos por autores.
W foi escrito = fue escrito | FOI esh-KRI-tu | Voz pasiva en pasado.
W autora = autora | au-TO-ra | Femenino de «autor».
W romance = novela | ro-MAN-s(e) | Libro de ficción largo.
W publicado = publicado | pu-bli-KA-du | Participio de «publicar».
W traduzido = traducido | tra-du-ZI-du | Participio de «traduzir».
W porteiro = portero | por-TEI-ru | Persona que controla la entrada de un edificio.
W fechado = cerrado | fe-SHA-du | Masculino de «fechada».
W fresco = fresco | FRESH-ku | Pan del día: «pão fresco».
W bastante = bastante | bash-TAN-t(e) | Con verbos: «fala-se bastante».
W fuma = se fuma (impersonal) | FU-ma | Viene de «fumar».
W muitos = muchos | MUI-tush | Plural masculino de «muito».
W escritos = escritos | esh-KRI-tush | Plural masculino de «escrito».
W autores = autores | au-TO-resh | Plural de «autor».
W casas = casas | KA-zash | Plural de «casa».
V Vocabulario: la voz pasiva
D Una novela nueva
Ana: O romance foi escrito por uma autora portuguesa. = La novela fue escrita por una autora portuguesa.
  > foi escrito = fue escrita | por uma autora portuguesa = por una autora portuguesa
Pedro: Foi publicado quando? = ¿Cuándo fue publicada?
  > Foi publicado = fue publicada | quando = cuándo
Ana: Foi publicado no ano passado. = Fue publicada el año pasado.
  > Foi publicado = fue publicada | no ano passado = el año pasado
Pedro: E foi traduzido para espanhol? = ¿Y fue traducida al español?
  > foi traduzido = fue traducida
Ana: Sim, foi traduzido por um amigo meu. = Sí, la tradujo un amigo mío.
  > foi traduzido por um amigo meu = fue traducida por un amigo mío
Q ¿Cómo se dice «la novela fue escrita»?
+ O romance foi escrito. :: Ser en pasado + participio.
- O romance escreveu-se. :: Eso es otra construcción.
- O romance está escrito. :: Eso expresa un estado.
Q ¿Qué forma es correcta para «los libros fueron escritos»?
+ Os livros foram escritos. :: Plural: «foram» y «escritos».
- Os livros foi escrito. :: Falta el plural.
- Os livros foram escrito. :: Falta el plural del participio.
R O livro é lido por muitos.
+ El libro es leído por muchos. :: Voz pasiva en presente.
- Muchos leen el libro. :: Eso es voz activa.
- El libro fue leído por muchos. :: Eso es pasado.
H O romance foi ___ por uma autora. :: Escrito
+ escrito :: Participio que concuerda con «romance».
- escrita :: No concuerda: «romance» es masculino.
- escrever :: Eso es infinitivo.
H Os livros foram ___ por autores. :: Escritos
+ escritos :: Plural masculino del participio.
- escrito :: Falta el plural.
- escritas :: Es femenino.
A O romance foi publicado no ano passado.
+ La novela fue publicada el año pasado. :: Pasiva en pasado.
- La novela publicó el año pasado. :: Eso es activa.
- La novela será publicada. :: Eso es futuro.
O Foi traduzido por um amigo. :: Fue traducida por un amigo. :: «Por» indica quién lo hace.
X Escribe en portugués «la novela fue traducida» :: O romance foi traduzido. :: Ser + participio.

@ 26 | A porta está fechada | La puerta está cerrada: estado y acción
I Hoy aprenderás a distinguir si algo está en un estado o si alguien lo acaba de hacer.
E Estar + participio = estado :: Con **estar** + participio, describes cómo está algo ahora: **A porta está fechada** (la puerta está cerrada). El resultado es lo que importa.
E Ser + participio = acción :: Con **ser** + participio, describes el hecho de la acción: **A porta foi fechada pelo porteiro** (la puerta fue cerrada por el portero). Aquí importa quién lo hizo.
B Forma | Significado | Ejemplo
| estar + participio | estado | A janela está aberta.
| ser + participio | acción | A janela foi aberta.
| ser + participio + por | acción y agente | A porta foi fechada pelo porteiro.
W pelo porteiro = por el portero | pe-lu por-TEI-ru | «Por» + «o» + «porteiro».
W estado = estado | esh-TA-du | Situación en la que está algo.
W desde as dez = desde las diez | DESH-d(e) ash DEZH | Para indicar desde cuándo.
V Vocabulario: estado y acción
D Un portal cerrado
Pedro: A porta está fechada? = ¿La puerta está cerrada?
  > A porta está fechada = la puerta está cerrada
Ana: Foi fechada pelo porteiro às dez. = La cerró el portero a las diez.
  > Foi fechada pelo porteiro = la cerró el portero
Pedro: Então está fechada desde as dez? = ¿Entonces está cerrada desde las diez?
  > está fechada desde as dez = está cerrada desde las diez
Ana: Sim, mas a janela está aberta. = Sí, pero la ventana está abierta.
  > a janela está aberta = la ventana está abierta
Q ¿Cómo se dice «la puerta está cerrada» (estado)?
+ A porta está fechada. :: Estado: estar + participio.
- A porta foi fechada. :: Eso es acción.
- A porta fechou-se. :: Eso es otra construcción.
Q ¿Cuál expresa quién cerró la puerta?
+ A porta foi fechada pelo porteiro. :: Acción con «por» y agente.
- A porta está fechada pelo porteiro. :: Estar no expresa acción.
- A porta fechou. :: No indica el agente.
R A janela foi aberta pelo porteiro.
+ La ventana fue abierta por el portero. :: Acción con agente.
- La ventana está abierta. :: Eso es estado.
- El portero abrió la ventana. :: Eso es activa.
H A porta ___ fechada. :: Está
+ está :: Estado.
- foi :: Acción.
- é :: Ser en presente.
H A porta ___ fechada pelo porteiro. :: Foi
+ foi :: Acción con agente.
- está :: Estado.
- é :: Ser con estado.
A A porta está fechada.
+ La puerta está cerrada. :: Estado.
- La puerta fue cerrada. :: Acción.
- El portero cierra la puerta. :: Activa.
O A janela está aberta. :: La ventana está abierta. :: «Estar» = estado.
X Escribe en portugués «la puerta fue cerrada» :: A porta foi fechada. :: Acción con «ser».

@ 26 | Vende-se pão fresco | Se vende pan fresco: pasiva sintética y sujeto indeterminado
I Hoy aprenderás a decir que algo se hace o se vende sin decir quién lo hace.
E Pasiva sintética con se :: Con un verbo transitivo, **se** puede formar una pasiva: **Vende-se pão fresco** equivale a «el pan fresco se vende»; **Vendem-se casas** equivale a «se venden casas». El nombre que recibe la acción es el sujeto, por eso el verbo concuerda con él.
E Sujeto indeterminado :: En **Precisa-se de empregados** (se necesita personal), el verbo queda en singular: **de empregados** va introducido por preposición y no es el sujeto de una pasiva. También: **Trabalha-se muito aqui** (aquí se trabaja mucho). En negativo, el pronombre va delante: **não se fuma**.
B Frase | Traducción
| Vende-se pão fresco. | Se vende pan fresco.
| Vendem-se casas. | Se venden casas. (sujeto plural)
| Precisa-se de empregados. | Se necesita personal. (sujeto indeterminado)
| Trabalha-se muito aqui. | Aquí se trabaja mucho. (sujeto indeterminado)
| Não se fuma. | No se fuma.
W vende-se = se vende | VEN-di-se | Cartel habitual en tiendas.
W precisa-se = se necesita | pre-SI-za-s(e) | Sujeto indeterminado.
W empregados = empleados | em-pre-GA-dush | Plural de «empregado».
W trabalha-se = se trabaja | tra-BA-lha-s(e) | Sujeto indeterminado.
W jornais = periódicos | zhur-NAISH | Plural de «jornal».
W fala-se = se habla | FA-la-s(e) | Pasiva sintética: «português» es sujeto singular.
W fuma-se = se fuma | FU-ma-se | Con «se» impersonal.
W vendem-se = se venden | VEN-deim-se | Plural, con «se».
V Vocabulario: pasiva sintética y sujeto indeterminado
D En una tienda
Ana: Aqui vende-se pão fresco. = Aquí se vende pan fresco.
  > Vende-se = se vende | pão fresco = pan fresco
Pedro: Vendem-se jornais aqui? = ¿Se venden periódicos aquí?
  > Vendem-se jornais = se venden periódicos
Ana: Sim, vendem-se jornais. Mas não se fuma aqui. = Sí, se venden periódicos. Pero aquí no se fuma.
  > vendem-se jornais = se venden periódicos | não se fuma = no se fuma
Pedro: Ótimo, obrigado. = Genial, gracias.
  > Ótimo = genial
Q En «Vendem-se casas», ¿por qué va el verbo en plural?
+ «Casas» es el sujeto paciente y está en plural. :: Equivale a «casas são vendidas».
- «Se» está en plural. :: «Se» no cambia de forma.
- El agente está en plural. :: No se indica quién las vende.
R Fala-se português aqui.
+ Aquí se habla portugués. :: Pasiva sintética con «português» como sujeto singular.
- Aquí hablo portugués. :: Eso es con yo.
- Aquí habla portugués. :: Eso sería con una persona.
H Aqui ___ pão fresco. :: Vende-se
+ vende-se :: Pasiva con sujeto singular «pão fresco».
- vendo :: Es yo.
- vendem :: Es plural.
H Vendem-se ___ aqui. :: Casas
+ casas :: Plural: el verbo va en plural.
- casa :: Eso es singular.
- casas-se :: No existe.
A Não se fuma aqui.
+ No se fuma aquí. :: «Se» impersonal con «não».
- No fumo aquí. :: Es con yo.
- Fuma aquí. :: Es afirmativo con una persona.
O Vendem-se casas. :: Se venden casas. :: Plural con «se».
X Escribe en portugués «aquí se habla portugués» :: Aqui fala-se português. :: «Português» es el sujeto singular de la pasiva sintética.
