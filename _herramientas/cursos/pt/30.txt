- Perguntou-me se estavas. :: Eso sería «si estabas».

H Cap. 29. ___ , é caro. :: Por um lado
+ Por um lado :: Para comparar dos ideas.

Q Cap. 29. ¿Qué significa «apesar de estar cansado»?
+ a pesar de estar cansado :: «Apesar de» + infinitivo.
- porque estou cansado :: Eso sería causa.
- quando estiver cansado :: Eso sería tiempo.
