@ 33 | Deve estar em casa | Debe de estar en casa: probabilidad y suposición
I Hoy aprenderás a decir qué crees que es probable, sin estar seguro.
E Dever + infinitivo :: Para suponer algo con bastante seguridad, usa **dever** (deber) + infinitivo: **Deve estar em casa** (debe de estar en casa). **Deve ter chegado** (debe de haber llegado). :: Es una suposición razonable, no un hecho confirmado.
E Poder + infinitivo :: Para algo posible pero menos seguro, usa **poder**: **Pode estar no escritório** (puede estar en la oficina). :: **Pode ser** (puede ser) es muy útil para contestar.
E El futuro para suponer :: Ya lo viste en el capítulo 21: **Será que está em casa?** (¿estará en casa?). **Estará cansado** (estará cansado).
B Grado de probabilidad | Expresión | Ejemplo
| muy probable | deve + infinitivo | Deve estar em casa.
| posible | pode + infinitivo | Pode estar no escritório.
| supuesto en el futuro | futuro simple | Estará cansado.
| pregunta de duda | será que... ? | Será que ele já chegou?
W deve estar = debe de estar | DE-v(e) esh-TAR | Suposición con bastante seguridad.
W deve ter chegado = debe de haber llegado | DE-v(e) TER she-GA-du | Suposición sobre algo que ya ocurrió.
W pode estar = puede estar | PO-d(e) esh-TAR | Posibilidad.
W pode ser = puede ser | PO-d(e) SER | Para contestar sin estar seguro.
W será que = ¿será que...? | se-RA KE | Para preguntar con duda.
W ele já chegou = ya ha llegado él | E-l(e) ZHA she-GO | Expresión para decir que alguien ya llegó.
W provavelmente = probablemente | pro-va-vel-MEN-t(e) | Con «é provável».
W certamente = seguramente | sher-ta-MEN-t(e) | Cuando estamos muy seguros.
W improvável = improbable | im-pro-VA-vel | Lo contrario de «provável».
W inteligente = inteligente | in-te-li-ZHEN-t(e) | Igual en masculino y femenino.
V Vocabulario: suponer
D ¿Dónde está Pedro?

  > não está no escritório = no está en la oficina

  > Provavelmente = probablemente | Pode ser = puede ser
Q ¿Cómo se dice «debe de estar en casa»?
+ Deve estar em casa. :: «Dever» + infinitivo: suposición.
- Dever estar em casa. :: El orden es incorrecto.
- Deve estar sempre em casa. :: Eso cambia el sentido.
Q ¿Qué expresión sirve para decir «puede ser»?
+ pode ser :: Expresa posibilidad.
- deve ser :: Eso es más seguro.
- será que :: Eso es una pregunta.
R Deve ter chegado.

H Ela ___ estar no escritório. :: Pode

- deve :: Eso sería más seguro.

@ 33 | Será que é verdade? | ¿Será verdad?: grados de certeza
I Hoy aprenderás a expresar certeza, duda e imposibilidad con las expresiones adecuadas.
E Certeza :: Para estar seguro: **Com certeza** (con seguridad) o **certamente** (seguramente), **sem dúvida** (sin duda). Ejemplo: **Sem dúvida, é verdade** (sin duda, es verdad).
E Duda :: Para dudar: **Será que...?** o **talvez** (quizá). Ejemplo: **Talvez seja verdade** (quizá sea verdad). Cuando **talvez** modifica un verbo, se usa normalmente el conjuntivo; no depende de que la duda sea “grande”. El tiempo verbal aporta matices según el contexto.
E Imposibilidad :: Para decir que algo no puede ser: **É impossível que** + conjuntivo: **É impossível que ele saiba** (es imposible que lo sepa).
B Grado | Expresión | Ejemplo
| seguro | com certeza / sem dúvida | Sem dúvida, é verdade.
| duda | talvez / será que | Talvez seja verdade.
| imposible | é impossível que + conjuntivo | É impossível que ele saiba.
W com certeza = con seguridad | kon ser-TE-za | Para estar seguro de algo.
W sem dúvida = sin duda | seim DU-vi-da | Para estar muy seguro.
W é impossível que = es imposible que | e im-po-SI-vel KE | Con conjuntivo.
W saiba = sepa | SAI-ba | Presente del conjuntivo de «saber», con «ele».
W impossível = imposible | im-po-SI-vel | Lo contrario de «possível».
V Vocabulario: certeza y duda
D ¿Es verdad?
Ana: Sem dúvida, o Miguel é inteligente. = Sin duda, Miguel es inteligente.
  > Sem dúvida = sin duda | é inteligente = es inteligente
Pedro: Talvez seja verdade, mas é impossível que saiba tudo. = Quizá sea verdad, pero es imposible que lo sepa todo.
  > Talvez seja verdade = quizá sea verdad | é impossível que saiba = es imposible que sepa
Ana: Com certeza, ele sabe muito. = Con seguridad, él sabe mucho.
  > Com certeza = con seguridad
Pedro: Será que vai ao jantar? = ¿Será que va a la cena?
  > Será que vai = ¿será que va?
Q ¿Qué expresión significa «sin duda»?
+ sem dúvida :: Expresa certeza.
- talvez :: Expresa duda.
- é impossível que :: Expresa imposibilidad.
Q ¿Cómo se dice «es imposible que lo sepa»?
+ É impossível que saiba. :: Con conjuntivo.
- É impossível saber. :: Eso es infinitivo.
- É impossível que sabe. :: Falta el conjuntivo.
R Sem dúvida, é verdade.
+ Sin duda, es verdad. :: Expresa certeza.
- Quizá es verdad. :: Eso es duda.
- Es imposible que sea verdad. :: Eso es imposibilidad.
H ___ seja verdade. :: Talvez
+ talvez :: Expresa duda.
- com certeza :: Expresa certeza.
- sem dúvida :: Expresa certeza.
H É ___ que ele saiba tudo. :: Impossível
+ impossível :: «É impossível que» + conjuntivo.
- possível :: Eso es «es posible que».
- provável :: Eso es «es probable que».
A Com certeza, ele sabe muito.
+ Con seguridad, él sabe mucho. :: Expresa certeza.
- Quizá él sabe mucho. :: Eso es duda.
- Es imposible que él sepa. :: Eso es imposibilidad.
O Talvez seja verdade. :: Quizá sea verdad. :: Expresa duda.

@ 33 | Pode ter sido ele | Puede haber sido él: suposiciones sobre el pasado
I Hoy aprenderás a suponer qué pasó, cuando no lo sabes con certeza.
E Poder/dever + ter + participio :: Para suponer algo del pasado: **Pode ter sido ele** (puede haber sido él). **Deve ter chegado** (debe de haber llegado). Con **ter** + participio, el pasado de la suposición.
E Sería (condicional) :: Para una suposición en el pasado con dudas, usa el condicional: **Seria o Miguel** (sería Miguel). Es más prudente.

W ficado = quedado | fi-KA-du | Participio de «ficar».

@ 33 | Sei que é possível | Sé que es posible: indicativo o conjuntivo
I No elijas el modo solo por una palabra: fíjate en si afirmas un hecho o presentas una posibilidad, valoración o duda.
E Hecho afirmado :: Con **saber que** y **acreditar que** en una afirmación, normalmente se usa indicativo: **Sei que ele está em casa**; **Acredito que a medida é útil**. La negación o la duda puede cambiar el modo: **Não acredito que seja útil**.
E Posibilidad y valoración :: **É possível que**, **duvido que**, **é importante que** y **talvez** suelen llevar conjuntivo: **É possível que esteja em casa**; **Talvez chegue mais tarde**. **Talvez** no requiere una “duda grande”: presenta el hecho como incierto. El tiempo se elige según el contexto.
B Contexto | Modo habitual | Ejemplo
| afirmo que lo sé | indicativo | Sei que ele está.
| posibilidad | conjuntivo | É possível que esteja.
| opinión afirmativa | indicativo frecuente | Acredito que funciona.
| opinión negada | conjuntivo frecuente | Não acredito que funcione.
| posibilidad con talvez | conjuntivo | Talvez funcione.
W acredito que = creo que | a-kre-DI-tu ke | Afirmación de una opinión.
W funcione = funcione | fun-SI-o-n(e) | Presente de conjuntivo de «funcionar».
W esteja = esté | esh-TE-zha | Presente de conjuntivo de «estar».
V Vocabulario: afirmar y dudar
T Uma medida em avaliação
- A equipa sabe que a mudança é necessária, mas duvida que resolva todos os problemas. = El equipo sabe que el cambio es necesario, pero duda que resuelva todos los problemas.
- É possível que os resultados só apareçam no próximo ano. = Es posible que los resultados solo aparezcan el próximo año.
- Talvez a medida funcione melhor quando houver mais dados. = Quizá la medida funcione mejor cuando haya más datos.
Q ¿Qué sabe el equipo?
+ Que el cambio es necesario. :: Es la información presentada como conocida.
- Que ya se resolvieron todos los problemas. :: El equipo duda que eso ocurra.
- Que los resultados aparecerán este año. :: El texto menciona el próximo año.
Q ¿Qué expresa «Talvez a medida funcione melhor»?
+ Una posibilidad, no una certeza. :: «Talvez» presenta incertidumbre.
- Un resultado confirmado. :: El texto no lo confirma.
- Una orden al equipo. :: No es un mandato.
R Não acredito que resolva todos os problemas.
+ No creo que resuelva todos los problemas. :: La negación favorece aquí el conjuntivo.
- Creo que ya resolvió todos los problemas. :: Cambia la polaridad y el tiempo.
- No sé qué problema resolvió. :: No es el significado de la frase.
H É possível que os resultados só ___ no próximo ano. :: Apareçam
+ apareçam :: «É possível que» suele llevar conjuntivo.
- aparecem :: Indicativo.
- apareceram :: Pretérito perfeito.
O Sei que a mudança é necessária. :: Sé que el cambio es necesario. :: Hecho afirmado: indicativo.
Q ¿Qué información se presenta como posibilidad y no como hecho?
+ Que la medida funcione mejor cuando haya más datos. :: La frase empieza con «Talvez».
- Que el equipo sabe que el cambio es necesario. :: Se presenta como información conocida.
- Que los resultados aparecieron el año pasado. :: El texto dice que podrían aparecer el próximo año.
