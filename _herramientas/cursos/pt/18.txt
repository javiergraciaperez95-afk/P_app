@ 18 | Trabalho para pagar | Trabajo para pagar: «para» y «por»
I Hoy aprenderás a distinguir «para» y «por», dos palabras que en español suenan parecido y en portugués cambian mucho el sentido.
E Para: finalidad y destino :: **para** indica para qué se hace algo: **Trabalho para pagar a casa** (trabajo para pagar la casa). :: También indica el destino: **Vou para Lisboa** (voy a Lisboa).
E Por: causa, medio y cantidad de tiempo :: **por** indica la causa: **por causa da chuva** (por culpa de la lluvia), **por isso** (por eso). :: Indica el medio o el precio: **pelo correio** (por correo), **Trabalho por dinheiro** (trabajo por dinero). :: Indica una duración aproximada: **Vou por uma semana** (voy por una semana).
B Para o por | Frase | Traducción
| para (finalidad) | Trabalho para pagar a casa. | Trabajo para pagar la casa.
| por (causa) | Não vou por causa da chuva. | No voy por culpa de la lluvia.
| por (medio) | Envio pelo correio. | Lo envío por correo.
W tanto = tanto | TAN-tu | Va delante de un verbo: «trabalhas tanto».
W pelo = por el | PE-lu | Es «por» + «o». Por eso va con un artículo.
W pela = por la | PE-la | Es «por» + «a».
W pelo correio = por correo | PE-lu kur-REI-u | Expresión fija para enviar cartas.
W por isso = por eso | pur I-su | Lo usamos para explicar la causa.
W por causa de = por culpa de | pur KAU-za d(e) | Expresión fija para dar la causa.
W por exemplo = por ejemplo | pur ee-ZEM-plu | Para poner un ejemplo.
W correio = correo | ku-RREI-u | Plural: correios.
W por dinheiro = por dinero | pur di-NEI-ru | Trabajar por dinero.
W finalidade = finalidad | fi-na-li-DA-d(e) | Para qué sirve algo.
W causa = causa | KAU-za | Lo que provoca algo.
W pelo menos = al menos | PE-lu ME-nush | Para dar una cantidad mínima.
V Vocabulario: para y por
D ¿Por qué trabajas tanto?
Ana: Porque trabalhas tanto? = ¿Por qué trabajas tanto?
  > Porque = por qué | trabalhas tanto = trabajas tanto
Pedro: Trabalho para pagar a casa. = Trabajo para pagar la casa.
  > Trabalho para pagar = trabajo para pagar | pagar a casa = pagar la casa
Ana: E por isso não vais de férias? = ¿Y por eso no te vas de vacaciones?
  > por isso = por eso | não vais de férias = no te vas de vacaciones
Pedro: Vou, sim! Vou por uma semana em agosto. = ¡Sí, voy! Voy una semana en agosto.
  > Vou por uma semana = voy una semana (de duración) | em agosto = en agosto
Q ¿Qué significa «para» en «trabalho para pagar»?
+ finalidad :: Para qué se hace algo.
- causa :: Eso sería «por».
- tiempo :: Eso sería «por» o «durante».
Q ¿Cómo se dice «por correo»?
+ pelo correio :: «Pelo» = por el; aquí, «por» + «o».
- para o correio :: Eso significa «para la oficina de correos».
- por o correio :: Falta contraer «por» + «o» en «pelo».
R Trabalho para pagar a casa.
+ Trabajo para pagar la casa. :: «Para» expresa la finalidad.
- Trabajo por pagar la casa. :: Con «por» no sería la finalidad.
- Trabajo por la casa. :: Eso sería otra idea.
H Não vou à festa ___ chuva. :: Por culpa de la
+ por causa da :: Expresión de causa.
- para a :: Eso sería finalidad.
- pela :: Se usa de otra manera.
H E ___ não vais de férias? :: Por eso
+ por isso :: «Por isso» = por eso.
- para isso :: Significa «para eso».
- pelo :: Falta el sentido.
A Vou para Lisboa.
+ Voy a Lisboa. :: «Para» también indica destino.
- Vengo de Lisboa. :: Eso sería «venho de».
- Voy por Lisboa. :: Eso sería pasar por la ciudad.
O Trabalho por dinheiro. :: Trabajo por dinero. :: «Por» indica el precio o el motivo.
X Escribe en portugués «por eso» :: por isso :: «Por isso» es la causa.

@ 18 | Estou a trabalhar | Estoy trabajando: estar a + infinitivo
I Hoy aprenderás a decir qué estás haciendo justo ahora.
E Estar a + infinitivo :: Para decir que algo está pasando ahora mismo, usa **estar a** + infinitivo: **Estou a trabalhar** (estoy trabajando). :: Igual que en el capítulo 9: **estou a ler** (estoy leyendo), **está a chover** (está lloviendo).
E Andar a + infinitivo :: **Andar a + infinitivo** puede presentar una actividad que se prolonga o se repite durante un período: **Ando a procurar emprego** (llevo un tiempo buscando trabajo). :: Compáralo con **Estou a procurar emprego**, que enfoca lo que estoy haciendo ahora. El sentido exacto depende del contexto.
E Todavía no :: **Ainda não** (todavía no) indica que algo no ha pasado aún: **Ainda não acabou** (todavía no ha terminado). :: Para decir que algo ya no pasa, se usa **já não** (ya no): **Já não trabalho aqui** (ya no trabajo aquí).
B Frase | Traducción
| Estou a trabalhar. | Estoy trabajando.
| Está a chover. | Está lloviendo.
| Ainda não acabou. | Todavía no ha terminado.
| Já não trabalho aqui. | Ya no trabajo aquí.
W ainda = todavía | a-IN-da | Se usa con «não»: «ainda não».
W relatório = informe | re-la-TO-ri-u | Un texto con datos de un trabajo.
W acabou = terminó / ha terminado | a-ka-BOU | Viene de «acabar».
W responder = responder | res-pon-DER | Verbo para contestar.
W resposta = respuesta | resh-POSH-ta | Plural: respostas.
W neste momento = en este momento | NESH-t(e) mu-MEN-tu | Expresión para «ahora mismo».
W ligar = llamar | li-GAR | Por teléfono: «ligar a alguém».
W projeto = proyecto | pru-ZHE-tu | Un trabajo grande que hay que hacer.
W chamada = llamada | sha-MA-da | Una llamada de teléfono.
W pedido = pedido | pe-DI-du | Lo que pides en un restaurante o en el trabajo.
W pensar = pensar | pen-SAR | Verbo para pensar.
W decidir = decidir | de-si-DIR | Verbo para elegir.
V Vocabulario: estar haciendo algo
D Llamada de trabajo
Pedro: Olá, Ana! Onde estás? = ¡Hola, Ana! ¿Dónde estás?
  > Onde estás = ¿dónde estás?
Ana: Estou a trabalhar no escritório. = Estoy trabajando en la oficina.
  > Estou a trabalhar = estoy trabajando | no escritório = en la oficina
Pedro: E o Miguel? = ¿Y Miguel?
  > o Miguel = Miguel
Ana: Está a ler um relatório. = Está leyendo un informe.
  > Está a ler = está leyendo | um relatório = un informe
Pedro: Ainda não acabou? = ¿Todavía no ha terminado?
  > Ainda não acabou = todavía no ha terminado
Ana: Não, ainda está a trabalhar. = No, todavía está trabajando.
  > ainda está a trabalhar = todavía está trabajando
Q ¿Qué significa «estou a trabalhar»?
+ Estoy trabajando. :: Estar a + infinitivo: lo que pasa ahora.
- Trabajo mucho. :: Eso no es «estar a».
- Trabajé ayer. :: Eso es pasado.
Q ¿Cómo se dice «todavía no»?
+ ainda não :: Lo que aún no ha pasado.
- já não :: Eso es «ya no».
- agora não :: No se dice así.
R Estou a ler um relatório.
+ Estoy leyendo un informe. :: Estar a + ler = estoy leyendo.
- Leo un informe. :: Sin «estar a» es presente simple.
- Leí un informe. :: Eso es pasado.
H Ela ___ a responder ao e-mail. :: Está
+ está :: Con «ela» es «está».
- estou :: Es para «yo».
- estão :: Es para «ellos».
H Ainda não ___ o relatório. :: Terminó
+ acabou :: Pasado de «acabar».
- acaba :: Eso es presente.
- acabar :: Eso es el infinitivo.
A Está a chover.
+ Está lloviendo. :: Estar a + infinitivo.
- Llueve. :: Eso es «chove».
- Lloverá. :: Eso es el futuro.
O Estou a estudar agora. :: Estoy estudiando ahora. :: «Agora» = ahora.
X Escribe en portugués «estoy escribiendo» :: Estou a escrever. :: Estar a + infinitivo.
w ando a = llevo un tiempo ... / ando ...
Q ¿Qué idea expresa «Ando a procurar emprego»?
+ Llevo un tiempo buscando empleo. :: «Andar a» presenta una actividad prolongada o repetida.
- Estoy buscando empleo justo en este instante. :: Ese es el foco habitual de «estar a».
- Busqué empleo una sola vez. :: La frase no expresa una acción puntual acabada.
H Neste momento, ___ a trabalhar. :: Estoy
+ estou :: «Estar a» enfoca lo que ocurre ahora.
- ando :: Puede describir una actividad prolongada o repetida.
- andava :: Es imperfecto, pasado.

@ 18 | Preciso de um emprego | Necesito un empleo: é preciso y el trabajo
I Hoy hablamos de buscar trabajo: anuncios, currículum y entrevista.
E Preciso de + nombre :: **Preciso de** (necesito) va con un nombre: **Preciso de um emprego** (necesito un empleo). :: Es lo mismo que «necesitar» en español.
E Precisar de + infinitivo :: **Precisar de** también puede ir seguido de un infinitivo: **Preciso de descansar** (necesito descansar), **Precisamos de trabalhar** (necesitamos trabajar). :: Conserva **de** delante del infinitivo.
E É preciso + infinitivo :: **É preciso** (hace falta) va con infinitivo: **É preciso falar português** (hace falta hablar portugués). :: También se dice **é necessário** (es necesario).
E Trabajar como :: **Trabalho como professora** (trabajo como profesora). Usa **como** para la profesión.
B Frase | Traducción
| Preciso de um emprego. | Necesito un empleo.
| É preciso falar português. | Hace falta hablar portugués.
| Trabalho como professora. | Trabajo como profesora.
W preciso de = necesito (algo) | pre-SI-zu d(e) | Va con un nombre.
W emprego = empleo | em-PRE-gu | Un trabajo para cobrar un sueldo.
W anúncio = anuncio | a-NUN-si-u | Lo que lees en el periódico para buscar trabajo.
W vaga = vacante | VA-ga | Un puesto de trabajo libre.
W currículo = currículum | ku-RRI-ku-lu | Documento para presentarte a un trabajo.
W experiência = experiencia | esh-pe-ri-EN-si-a | Lo que has hecho antes.
W ensino = enseñanza | en-SI-nu | Trabajar en la educación.
W entrevista = entrevista | en-tre-VISH-ta | Conversación para un trabajo.
W salário = salario | sa-LA-ri-u | Lo que cobras por trabajar.
W contrato = contrato | kon-TRA-tu | Documento que firmas al empezar a trabajar.
W formação = formación | for-ma-SAU | Estudios o cursos para aprender.
W candidatar-me = presentarme (a un puesto) | kan-di-da-TAR-m(e) | Con «me», para ti misma o ti mismo.
W enviar = enviar | en-vi-AR | Mandar un correo o un documento.
V Vocabulario: buscar trabajo
D Buscando trabajo
Pedro: Preciso de um emprego. = Necesito un empleo.
  > Preciso de um emprego = necesito un empleo
Ana: Vi um anúncio: há uma vaga para professor. = Vi un anuncio: hay una vacante para profesor.
  > Vi um anúncio = vi un anuncio | há uma vaga = hay una vacante
Pedro: O currículo já está pronto? = ¿El currículum ya está listo?
  > O currículo já está pronto = el currículum ya está listo
Ana: Está, sim. Tens experiência em ensino? = Sí, está. ¿Tienes experiencia en enseñanza?
  > experiência em ensino = experiencia en enseñanza
Pedro: Tenho, trabalho como professor há dois anos. = Tengo, trabajo como profesor desde hace dos años.
  > trabalho como professor = trabajo como profesor | há dois anos = desde hace dos años
Q ¿Qué significa «preciso de um emprego»?
+ Necesito un empleo. :: «Preciso de» = necesito.
- Busco un anuncio. :: Eso sería «procuro um anúncio».
- Tengo un empleo. :: Eso sería «tenho um emprego».
Q ¿Qué significa «é preciso falar português»?
+ Hace falta hablar portugués. :: «É preciso» + infinitivo.
- Hablo portugués. :: Eso sería «falo português».
- Quiero hablar portugués. :: Eso sería «quero falar».
R Trabalho como professora.
+ Trabajo como profesora. :: «Como» = como, para la profesión.
- Trabajo de profesora. :: Esa forma no se usa en portugués.
- Trabajo para profesora. :: No es lo que dice la frase.
H É ___ falar inglês. :: Preciso
+ preciso :: «É preciso» = hace falta.
- precisa :: Sin «é preciso» no es correcto.
- pode :: Eso sería «puede».
H Vi um ___ de emprego. :: Anúncio
+ anúncio :: Lo que lees para buscar trabajo.
- currículo :: Eso es tu documento.
- entrevista :: Eso es la reunión.
A Preciso de experiência.
+ Necesito experiencia. :: «Experiência» = experiencia.
- Tengo experiencia. :: Eso sería «tenho experiência».
- Busco un anuncio. :: No lo dice la frase.
O Tenho experiência em ensino. :: Tengo experiencia en enseñanza. :: «Em ensino» = en enseñanza.
X Escribe en portugués «necesito un empleo» :: Preciso de um emprego. :: «Preciso de» = necesito.
Q ¿Cómo se dice «necesitamos descansar»?
+ Precisamos de descansar. :: «Precisar» conserva «de» delante del infinitivo.
- Precisamos descansar. :: En este patrón se mantiene «de».
- Precisamos para descansar. :: «Para» no sustituye a la preposición del verbo.
H Preciso ___ dormir. :: De
+ de :: «Precisar de» + infinitivo.
- para :: No es la preposición de «precisar».
- em :: No es la preposición de «precisar».
T Oferta de emprego
- Emprego: empregado de mesa para um restaurante no centro. = Empleo: camarero para un restaurante en el centro.
- Horário: de terça-feira a sábado, das 16:00 às 23:00. = Horario: de martes a sábado, de 16:00 a 23:00.
- Experiência em restaurante. Enviar currículo até 30 de setembro. = Experiencia en restaurante. Enviar el currículum antes del 30 de septiembre.
Q ¿Qué puesto ofrece el anuncio?
+ Empregado de mesa. :: Aparece en la primera línea.
- Professor. :: El anuncio no menciona enseñanza.
- Farmacêutico. :: El anuncio no menciona una farmacia.
Q ¿Cuándo termina el horario de trabajo?
+ às 23h :: El horario termina a las 23h.
- às 16h :: Esa es la hora de inicio.
- às 30h :: El anuncio no indica esa hora.
Q ¿Qué hay que enviar?
+ Um currículo. :: La última línea pide el currículo.
- Uma receita. :: No se solicita una receta.
- Uma conta. :: No se solicita una cuenta.
