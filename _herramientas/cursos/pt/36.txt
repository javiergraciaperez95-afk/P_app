@ 36 | Palavras agudas, graves e esdrúxulas | Palabras agudas, llanas y esdrújulas: el acento
I Hoy aprenderás a saber dónde cae la fuerza en una palabra. Con esto sabrás cuándo lleva tilde.
E Tres grupos :: **Agudas**: la fuerza cae en la última sílaba (café, avó, Lisboa). **Graves o llanas**: en la penúltima (casa, mesa, fácil). **Esdrújulas**: en la antepenúltima (lâmpada, pássaro, árvore). :: Las palabras **agudas** con acento escrito son las que acaban en vocal, **-a, -e, -o** no llevan tilde, pero **-em** y **-ens** sí.
E Reglas básicas :: Las **llanas** llevan tilde si acaban en **-l**, **-r**, **-x**, **-n**, **-ps** y en consonante distinta de **-s**: **fácil**, **açúcar**, **tórax**. Las **esdrújulas** siempre llevan tilde: **árvore**, **lâmpada**.
B Tipo | Ejemplo | Regla
| aguda | café | termina en vocal o en -em, -ens (tilde si es -em: «também», «ninguém»)
| llana | fácil | tilde si termina en consonante distinta de -s
| esdrújula | lâmpada | siempre lleva tilde
W lâmpada = lámpara | LAM-pa-da | Esdrújula: la fuerza en «lâm».
W árvore = árbol | AR-vu-r(e) | Esdrújula: la fuerza en «ár».
W pássaro = pájaro | PA-sa-ru | Esdrújula: la fuerza en «pá».
W pelo = por el / pelo (cabello) | PE-lu | Se escribe igual que «pêlo» en el acuerdo.
W pêlo = pelo (del cuerpo o del animal) | PE-lu | Con circunflejo para diferenciar.
V Vocabulario: acento y sílabas
D Una lección de acentos
Ana: A lâmpada é bonita, mas o pássaro é mais bonito. = La lámpara es bonita, pero el pájaro es más bonito.
  > lâmpada = lámpara | pássaro = pájaro
Pedro: Pois. E o café da avó é fácil de fazer. = Pues. Y el café de la abuela es fácil de hacer.
  > café = café | avó = abuela | fácil = fácil
Ana: Compro açúcar e pêlo? = ¿Compro azúcar y pelo?
  > pêlo = pelo del cuerpo o del animal
Pedro: Não, isso é para o cão. = No, eso es para el perro.
  > cão = perro
Q ¿Qué tipo de palabra es «lâmpada»?
+ esdrújula :: La fuerza cae en la antepenúltima sílaba.
- aguda :: La fuerza cae en la última sílaba.
- llana :: La fuerza cae en la penúltima sílaba.
Q ¿Por qué lleva tilde «fácil»?
+ Porque es llana y termina en -l. :: Las llanas con -l llevan tilde.
- Porque es aguda. :: No es aguda.
- Porque es esdrújula. :: No es esdrújula.
R A árvore é alta.
+ El árbol es alto. :: «Árvore» = árbol.
- La lámpara es alta. :: «Lâmpada» = lámpara.
- El pájaro es alto. :: «Pássaro» = pájaro.
H O café é ___. :: Fácil
+ fácil :: Llana con tilde por acabar en -l.
- facil :: Le falta la tilde.
- fácel :: Eso no existe.
H A ___ é bonita. :: Lâmpada
+ lâmpada :: Esdrújula: lleva tilde.
- lampada :: Le falta la tilde.
- lâmpadas :: Es plural.
A Compro açúcar.
+ Compro azúcar. :: «Açúcar» = azúcar.
- Compro café. :: Eso es «café».
- Compro pão. :: Eso es «pan».
O A avó é alta. :: La abuela es alta. :: «Avó» = abuela.
X Escribe en portugués «el pájaro» :: o pássaro :: Esdrújula con tilde.

@ 36 | Vogais abertas e fechadas | Vocales abiertas y cerradas: avô, avó, pêlo, pelo
I Hoy aprenderás a notar la diferencia entre vocales abiertas y cerradas, que cambia el significado de algunas palabras.
E Abierta o cerrada :: Las vocales **é** y **ó** son abiertas (sonido más abierto: **avó**, **pé**). Las **ê** y **ô** son cerradas (**avô**, **pêlo**). :: Esa diferencia cambia el significado: **avó** (abuela) / **avô** (abuelo); **pêlo** (pelo del cuerpo) / **pelo** (por el).
E Vocal átona :: En Portugal, la vocal sin acento se pronuncia muy reducida: **e** se suena casi como «i» o como nada, **o** casi como «u». Por eso **mesa** suena más como «mesh».
B Palabras | Diferencia | Ejemplo
| avó / avô | abuela / abuelo | A minha avó faz bolos.
| pêlo / pelo | pelo del cuerpo / por el | Tenho um pêlo no casaco.
| pé / pê | pie / letra «pê» | O meu pé dói.
W pêlo = pelo (del cuerpo) | PE-lu | Vocal cerrada: se pronuncia más cerrado.
W bolos = pasteles | BO-lush | Plural de «bolo».
W domingos = domingos | do-MEN-gush | Plural de «domingo».
W casaco = chaqueta | ka-ZA-ku | Prenda de abrigo.
W reduzido = reducido | re-du-ZI-du | Participio de «reduzir».
V Vocabulario: vocales
D En casa de los abuelos
Ana: A minha avó faz bolos todos os domingos. = Mi abuela hace pasteles todos los domingos.
  > avó = abuela | bolos = pasteles
Pedro: E o avô come sempre um bolo. = Y el abuelo siempre come un pastel.
  > avô = abuelo | come sempre um bolo = come siempre un pastel
Ana: Tenho um pêlo no casaco. Não sei de onde veio. = Tengo un pelo en la chaqueta. No sé de dónde vino.
  > pêlo = pelo | casaco = chaqueta
Pedro: Deve ser do cão. = Debe de ser del perro.
  > Deve ser = debe de ser
Q ¿Qué palabra significa «abuelo»?
+ avô :: Vocal cerrada.
- avó :: Eso es «abuela».
- avós :: Eso es «abuelos» en plural.
Q ¿Qué significa «pêlo»?
+ pelo del cuerpo :: Con vocal cerrada.
- por el :: Eso es «pelo» sin circunflejo.
- pelo de la cabeza :: Eso es «cabelo».
R A minha avó faz bolos.
+ Mi abuela hace pasteles. :: «Avó» = abuela.
- Mi abuelo hace pasteles. :: Eso sería «avô».
- Mi abuela hace pan. :: Eso sería «pão».
H Tenho um ___ no casaco. :: Pêlo
+ pêlo :: Con vocal cerrada: pelo del cuerpo.
- pelo :: Eso sería «por el».
- pelos :: Es plural.
H O meu ___ dói. :: Pé
+ pé :: Vocal abierta: pie.
- pê :: Eso es la letra «pê».
- pena :: Eso es «pena».
A O avô come um bolo.
+ El abuelo come un pastel. :: «Avô» = abuelo.
- La abuela come un pastel. :: Eso es «avó».
- El abuelo come pan. :: Eso es «pão».
O A avó faz bolos. :: La abuela hace pasteles. :: «Avó» = abuela.
X Escribe en portugués «el abuelo» :: o avô :: Vocal cerrada.

@ 36 | Acordo ortográfico | El acuerdo ortográfico: palabras que cambian
I Hoy aprenderás la ortografía moderna de Portugal, que cambió con el Acuerdo Ortográfico de 1990, y las letras que no se pronuncian.
E Letras mudas :: Muchas consonantes no se pronuncian: **ação** (acción), **facto** (hecho), **ótimo** (óptimo). En Portugal se mantienen para las palabras **que vienen de la misma familia**: **ação**, **factos**. :: Algunas se escriben pero no suenan, como la **c** de **facto** y la **p** de **ótimo**.
E Otros cambios :: **receção** (recepción, con c), **direção** (dirección). Sin tilde: **idade**. La «ç» se usa antes de -a, -o, -u: **ação**, **açúcar**.
B Palabra | Ortografía | Significado
| facto | sin acento, la «c» es muda | hecho
| ação | con «ç» | acción
| receção | con «ç» | recepción
| atual | sin «c» | actual
W facto = hecho | FA-tu | La «c» no se pronuncia.
W ação = acción | a-SAU | Con «ç», que suena «s».
W atual = actual | a-TU-al | Sin «c», que sí se pronunciaba.
W clara = clara (femenino de «claro») | KLA-ra | Lo que se entiende bien.
W direção = dirección | di-re-SAU | Con «ç».
W ótimo = óptimo | O-ti-mu | La «p» no se pronuncia.
W escreve-se = se escribe | esh-KRE-vi-se | Con «se» impersonal.
W pronuncia-se = se pronuncia | pru-nu-SI-a-se | Con «se» impersonal.
W ç = cedilla (letra) | se-di-LA | Letra con cedilla.
W s = ese (letra) | ES | Letra que suena «s».
V Vocabulario: ortografía del acuerdo
D Un texto con errores
Ana: Este facto é ótimo: a receção tem uma direção clara. = Este hecho es óptimo: la recepción tiene una dirección clara.
  > facto = hecho | ótimo = óptimo | receção = recepción | direção = dirección
Pedro: Sim, a ação é muito atual. = Sí, la acción es muy actual.
  > ação = acción | atual = actual
Ana: E a idade da empresa é grande. = Y la edad de la empresa es grande.
  > idade = edad
Pedro: Escreve-se com ç, porque pronuncia-se como s. = Se escribe con ç, porque se pronuncia con s.
  > Escreve-se com ç = se escribe con ç | pronuncia-se como s = se pronuncia como s
Q ¿Cómo se escribe «acción» en portugués?
+ ação :: Con «ç» antes de «ão».
- acção :: Es la forma del Acuerdo antiguo.
- acao :: Le faltan las tildes.
Q ¿Qué palabra tiene una consonante muda?
+ facto :: La «c» no se pronuncia.
- ação :: La «ç» sí suena.
- atual :: Sin acento, aunque «c» no suena.
R Este facto é ótimo.
+ Este hecho es óptimo. :: «Facto» = hecho; «ótimo» = óptimo.
- Este facto es bueno. :: Eso no es la palabra exacta.
- Este hecho es malo. :: Es lo contrario.
H A receção tem uma ___ clara. :: Direção
+ direção :: Con «ç» y con «ão».
- direcção :: Es la forma del Acuerdo antiguo.
- direcao :: Le faltan las tildes.
A A ação é atual.
+ La acción es actual. :: «Ação» = acción.
- La idea es actual. :: Eso es «ideia».
- La acción es antigua. :: Eso es lo contrario.
O A idade da empresa. :: La edad de la empresa. :: «Idade» = edad.
X Escribe en portugués «el hecho» :: o facto :: Consonante muda.
