@ 4 | O que é isto? | Las cosas: plural y colores
E Esto, eso, aquello :: **Isto** (esto), **isso** (eso) y **aquilo** (aquello) se usan para cosas que no nombras. **O que é isto?** = ¿qué es esto? :: Se contesta con um o uma: **É um livro** (es un libro), **é uma caneta** (es un boli).
E El plural :: Lo normal es añadir **-s**: livro → livros. Las que acaban en **-l** suelen cambiar la l por **-is**: azul → azuis. :: Las que acaban en **-r** o **-z** añaden **-es**: cor → cores, luz → luzes. Las acabadas en **-s** suelen añadir **-es** si son agudas (mês → meses); si no lo son, normalmente no cambian (o lápis → os lápis). :: Las que acaban en **-m** hacen **-ns**: jardim → jardins. En **-ão** hay varios plurales; mira irmão/irmãos y pão/pães en la lección de familia.
E Los colores :: **De que cor é?** = ¿de qué color es? :: Van detrás del nombre y concuerdan: um carro **vermelho**, uma mala **vermelha**. Azul y verde no cambian con el género. :: Dos falsos amigos: «rojo» es **vermelho**, y **roxo** es «morado».

| vermelho | rojo
| azul | azul
| verde | verde
| amarelo | amarillo
| branco | blanco
| preto | negro
| castanho | marrón
| roxo | morado

V Vocabulario: cosas y colores
D ¿Qué es esto?
Laura: João, o que é isto? = João, ¿qué es esto?
  > o que é isto = qué es esto
João: Isso é um telemóvel. É o meu telemóvel novo. = Eso es un móvil. Es mi móvil nuevo.
  > Isso = eso | o meu telemóvel novo = mi móvil nuevo
Laura: E aquilo? O que é? = ¿Y aquello? ¿Qué es?
  > aquilo = aquello
João: Aquilo é uma mala. É a mala da Marta. = Aquello es un bolso. Es el bolso de Marta.
  > uma mala = un bolso | da Marta = de «la» Marta (de + a = da)
Laura: De que cor é o teu carro? = ¿De qué color es tu coche?
  > De que cor é = de qué color es | o teu carro = tu coche
João: É vermelho. E o teu? = Es rojo. ¿Y el tuyo?
  > vermelho = rojo | o teu = el tuyo
Laura: O meu carro é branco. É pequeno, mas é muito bonito. = Mi coche es blanco. Es pequeño, pero es muy bonito.
  > branco = blanco | pequeno = pequeño | mas = pero
João: E os livros azuis? São da Marta? = ¿Y los libros azules? ¿Son de Marta?
  > os livros azuis = los libros azules | São = son
Laura: Não, são os meus livros. = No, son mis libros.
  > os meus livros = mis libros
Q ¿Cómo preguntas «¿qué es esto?»?
+ O que é isto? :: Isto = esto.
- O que é este? :: «Este» necesita un nombre detrás.
- Quem é isto? :: «Quem» es «quién».
Q ¿Cuál es el plural de «azul»?
+ azuis :: La -l cambia a -is.
- azules :: Eso es español.
- azuls :: No.
Q ¿Cómo se dice «rojo»?
+ vermelho :: Es el falso amigo más famoso.
- roxo :: Eso es «morado».
- rojo :: Esa palabra no existe en portugués.
Q ¿Qué color es «roxo»?
+ morado :: No te fíes del parecido.
- rojo :: Rojo es «vermelho».
- rosa :: No.
R Aquilo é uma mala.
+ Aquello es un bolso. :: Aquilo = aquello.
- Esto es un bolso. :: Sería «isto».
- Aquello es una mesa. :: Mesa es «mesa».
H A cadeira é ___ .
+ branca :: «Cadeira» es femenino.
- branco :: Es masculino.
- brancos :: Es plural.
H O que é ___ ?
+ isto :: Para cosas sin nombrar.
- esta :: Necesita un nombre detrás.
- um :: No.
A De que cor é o teu carro?
+ ¿De qué color es tu coche? :: Cor = color.
- ¿De quién es el coche? :: No pregunta eso.
- ¿Cómo es tu casa? :: Carro = coche.
O O meu telemóvel é preto :: Mi móvil es negro :: El + mi + cosa + es + color.

@ 4 | A minha casa | La casa: «há»
E Hay: há :: «Hay» se dice **há**, y como en español no cambia: **Há uma mesa** (hay una mesa), **há três quartos** (hay tres dormitorios). :: Negativo: **não há**. Pregunta: **Há jardim?** :: Se pronuncia igual que la «a» del artículo, pero se escribe con hache y con acento.
E Las partes de la casa :: Cuidado con los parecidos: **o quarto** es «el dormitorio», **a sala** es «el salón» y el baño es **a casa de banho**. :: **A cozinha** (la cocina), **a varanda** (el balcón), **o jardim** (el jardín). Un piso es **um apartamento**.
E Los muebles :: **A cama**, **o sofá**, **o armário**, **a televisão**. La ventana es **a janela** y la puerta, **a porta**. La nevera es **o frigorífico**.
E Mi, tu, sin artículo delante :: Después de una fusión como «no» o «da», el posesivo va sin repetir el artículo: **no meu quarto** (en mi dormitorio), **na minha casa** (en mi casa), **da tua mala** (de tu bolso).

T Mi piso
- O meu apartamento é pequeno, mas é bonito. = Mi piso es pequeño, pero es bonito.
  > O meu apartamento = mi piso | mas = pero
- Tem dois quartos, uma sala, uma cozinha e uma casa de banho. = Tiene dos dormitorios, un salón, una cocina y un baño.
  > dois quartos = dos dormitorios | uma casa de banho = un baño

  > Na sala = en el salón | há = hay

  > No meu quarto = en mi dormitorio

  > um frigorífico novo = una nevera nueva
- Não há jardim, mas há uma varanda. = No hay jardín, pero hay un balcón.
  > Não há = no hay | uma varanda = un balcón
D ¿Cómo es tu casa?
Marta: Como é a tua casa, Rui? = ¿Cómo es tu casa, Rui?
  > Como é = cómo es | a tua casa = tu casa
Rui: É um apartamento grande. Tem três quartos. = Es un piso grande. Tiene tres dormitorios.
  > três quartos = tres dormitorios
Marta: Há jardim? = ¿Hay jardín?
  > Há = hay
Rui: Não, não há. Mas há uma varanda grande. = No, no hay. Pero hay un balcón grande.
  > não há = no hay
Marta: E a cozinha? É grande? = ¿Y la cocina? ¿Es grande?
  > a cozinha = la cocina
Rui: Não, a cozinha é pequena, mas é moderna. = No, la cocina es pequeña, pero es moderna.
  > pequena = pequeña | moderna = moderna
Q ¿Cómo dices «hay una mesa»?
+ Há uma mesa. :: Há = hay.
- É uma mesa. :: Eso es «es una mesa».
- Está uma mesa. :: Para «hay» se usa «há».
Q ¿Qué es «o quarto» en una casa?
+ El dormitorio. :: Y también «la habitación».
- El salón. :: El salón es «a sala».
- El baño. :: El baño es «a casa de banho».
Q ¿Cómo se dice «el baño»?
+ a casa de banho :: Literalmente, «la casa de baño».
- o banho :: Eso es «el baño» de bañarse.
- o quarto :: Eso es el dormitorio.
Q ¿Qué es «a janela»?
+ La ventana. :: La puerta es «a porta».
- La puerta. :: Eso es «a porta».
- El balcón. :: Eso es «a varanda».
R Na sala há um sofá e uma televisão.
+ En el salón hay un sofá y una televisión. :: Sala = salón.
- En la cocina hay un sofá y una televisión. :: Cocina es «cozinha».
- En el salón hay una mesa y una televisión. :: Sofá = sofá.
H Na cozinha ___ um frigorífico.
+ há :: Hay.
- é :: Eso es «es».
- são :: Eso es «son».
H O apartamento tem dois ___ .
+ quartos :: Dos dormitorios, en plural.
- quarto :: Hace falta el plural.
- cozinha :: Es singular.
A Não há jardim, mas há uma varanda.
+ No hay jardín, pero hay un balcón. :: Varanda = balcón.
- Hay jardín y también un balcón. :: Dice «não há».
- No hay balcón, pero hay jardín. :: Es al revés.
O A minha casa tem três quartos :: Mi casa tiene tres dormitorios :: La + mi + casa + tiene + número + dormitorios.

@ 4 | Onde estão as chaves? | Dónde están las cosas
E El verbo «estar» :: Para decir dónde está algo o alguien: **estou, estás, está, estamos, estão**. :: **Onde está o gato?** = ¿dónde está el gato? **Onde estão as chaves?** = ¿dónde están las llaves?
E Ser, estar y ficar :: **Ser** identifica o describe algo: **Sou espanhola** (soy española), **é médico** (es médico). **Estar** expresa un estado o una ubicación actual: **Estou cansado**, **o gato está na sala**. :: Para preguntar dónde queda un lugar, es muy frecuente **ficar**: **Onde fica a estação?**. Hay usos que dependen del contexto; estas son pautas iniciales, no equivalencias absolutas con el español.
B «Estar» | Persona | Verbo
| eu | estou
| tu | estás
| ele / ela / você | está
| nós | estamos
| vocês / eles / elas | estão
E Los sitios «quedan»: ficar :: Para lo que no se mueve (edificios, ciudades, países) lo más natural es **ficar**: **Onde fica o banco?** (¿dónde está el banco?), **Lisboa fica em Portugal**. :: Para personas y cosas que se mueven, **estar**: O gato **está** na sala.
E Encima, debajo, al lado :: Estas expresiones llevan **de**, que se funde con el artículo: de + o = **do**, de + a = **da**. :: **Em cima da** mesa (encima de la mesa), **debaixo do** sofá (debajo del sofá), **ao lado do** banco (al lado del banco), **dentro da** mala (dentro del bolso), **em frente do** sofá (enfrente del sofá), **atrás da** porta (detrás de la puerta). :: **Entre** va sin «de»: entre o banco e a escola.

| debaixo de | debajo de
| ao lado de | al lado de
| dentro de | dentro de
| em frente de | enfrente de, delante de
| atrás de | detrás de
| entre | entre

  > Também não = «también no»: tampoco

Q Preguntas por un edificio. ¿Cuál es la forma más natural?
+ Onde fica o banco? :: Para sitios que no se mueven, «ficar».
- Onde é isto o banco? :: No.
- Onde há o banco? :: «Há» es «hay».
Q ¿Cómo dices «encima de la mesa»?
+ em cima da mesa :: De + a = da.
- em cima de a mesa :: «De» y «a» se funden.
- em cima do mesa :: «Mesa» es femenino.
Q ¿Cómo se dice «están»?
+ estão :: Eles estão.
- está :: Eso es «está».
- estamos :: Eso es «estamos».
R O gato está debaixo da cama.
+ El gato está debajo de la cama. :: Debaixo = debajo.
- El gato está encima de la cama. :: Encima es «em cima».
- El perro está debajo de la cama. :: Gato = gato.
H As chaves ___ dentro da mala.
+ estão :: Las llaves: plural.
- está :: Es singular.
- são :: Para decir dónde, «estar».
H O telemóvel está ao lado ___ computador.
+ do :: «Computador» es masculino: de + o.
- da :: Es femenino.
- de :: Falta el artículo.
A Onde estão os meus óculos?
+ ¿Dónde están mis gafas? :: Óculos = gafas.
- ¿Dónde están mis llaves? :: Llaves es «chaves».
- ¿Dónde está mi móvil? :: Móvil es «telemóvel».
