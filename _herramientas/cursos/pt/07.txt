@ 7 | A roupa | La ropa y los demostrativos
E Este, ese, aquel :: Igual que en español, hay tres distancias, y concuerdan con el nombre. :: Fíjate en la pronunciación: **este** suena «esht» y **esse**, «es».
B Los demostrativos | | Masculino | Femenino | Plural
| cerca de mí | este | esta | estes, estas
| cerca de ti | esse | essa | esses, essas
| lejos | aquele | aquela | aqueles, aquelas
E «De» también se funde con ellos :: de + este = **deste**, de + esta = **desta**, de + esse = **desse**, de + aquele = **daquele**. :: Como «gostar» lleva «de», lo oirás a todas horas: **Gosto deste vestido** (me gusta este vestido), **gosto desta camisa** (me gusta esta camisa).
E La ropa :: **A roupa** es «la ropa». **A camisa**, **o vestido**, **os sapatos**, **o casaco** (chaqueta o abrigo), **a saia** (falda), **o chapéu** (sombrero). :: Los pantalones son **as calças**, siempre en plural. Las zapatillas de deporte son **as sapatilhas**. :: Un falso amigo de regalo: en Portugal **a camisola** es «el jersey». :: Para decir que algo es chulo o mono, los portugueses dicen **giro / gira**. **Olha!** = ¡mira!
W esse = ese | E-s(e)
W essa = esa | E-sa
W essas = esas | E-sash
W estes = estos | ESH-t(e)sh
W estas = estas | ESH-tash
W aquele = aquel | a-KE-l(e)
W aquela = aquella | a-KE-la
W aqueles = aquellos | a-KE-l(e)sh
W deste = de este | DESH-t(e)
W desta = de esta | DESH-ta
W roupa = ropa | RRO-pa
W camisa = camisa | ca-MI-za
W camisola = jersey | ca-mi-ZO-la | Falso amigo: no es «camisón».
W calças = pantalones | CAL-sash
W saia = falda | SAI-a
W vestido = vestido | v(e)sh-TI-du
W casaco = chaqueta, abrigo | ca-ZA-cu
W sapatos = zapatos | sa-PA-tush
W sapatilhas = zapatillas de deporte | sa-pa-TI-llash
W chapéu = sombrero | sha-PEU
W gira = chula, mona | ZHI-ra
W olha = ¡mira! | O-lla
W bonitos = bonitos | bu-NI-tush
W bonitas = bonitas | bu-NI-tash
W pretos = negros | PRE-tush
W brancas = blancas | BRAN-cash
V Vocabulario: la ropa
D Mirando escaparates
Marta: Olha, Inês! Gosto muito deste vestido. = ¡Mira, Inês! Me gusta mucho este vestido.
  > Olha = mira | Gosto muito deste vestido = me gusta mucho este vestido (de + este)
Inês: É bonito. Mas eu prefiro aquela saia azul. = Es bonito. Pero yo prefiero aquella falda azul.
  > prefiro = prefiero | aquela saia azul = aquella falda azul
Marta: E esta camisola? É gira! = ¿Y este jersey? ¡Es muy mono!
  > esta camisola = este jersey (en portugués es femenino) | gira = mona, chula
Inês: Sim, e essas calças também são bonitas. = Sí, y esos pantalones también son bonitos.
  > essas calças = esos pantalones | são bonitas = son bonitos
Marta: E aqueles sapatos pretos? = ¿Y aquellos zapatos negros?
  > aqueles sapatos pretos = aquellos zapatos negros
Inês: Não gosto. Prefiro estas sapatilhas brancas. = No me gustan. Prefiero estas zapatillas blancas.
  > Não gosto = no me gustan | estas sapatilhas brancas = estas zapatillas blancas
Q Tienes un vestido en la mano. ¿Cómo dices «este vestido»?
+ este vestido :: Cerca de ti.
- esse vestido :: Eso es «ese».
- aquele vestido :: Eso es «aquel».
Q ¿Cómo dices «aquella falda»?
+ aquela saia :: «Saia» es femenino.
- aquele saia :: Hace falta el femenino.
- essa saia :: Eso es «esa».
Q «De» + «este» se convierte en…
+ deste :: Gosto deste casaco.
- do este :: No.
- neste :: Eso es em + este.
Q ¿Qué es «uma camisola» en Portugal?
+ Un jersey. :: Es un falso amigo.
- Un camisón. :: Eso es lo que parece, pero no.
- Una camisa. :: Eso es «uma camisa».
R Gosto muito deste casaco.
+ Me gusta mucho esta chaqueta. :: Casaco = chaqueta, abrigo.
- Me gusta mucho este vestido. :: Sería «vestido».
- No me gusta esta chaqueta. :: No es negativa.
H ___ sapatos são bonitos.
+ Estes :: «Sapatos» es masculino plural.
- Este :: Es singular.
- Esta :: Es femenino singular.
H Prefiro ___ saia.
+ aquela :: «Saia» es femenino.
- aquele :: Es masculino.
- aqueles :: Es plural.
A Essas calças são bonitas.
+ Esos pantalones son bonitos. :: Calças = pantalones.
- Esas faldas son bonitas. :: Falda es «saia».
- Estos pantalones son bonitos. :: «Essas» es «esos».
O Eu gosto muito desta camisa :: A mí me gusta mucho esta camisa :: Yo + gusto + mucho + de esta + camisa.

@ 7 | Quanto custa? | Comprar: tallas y pagar
E En la tienda :: El dependiente te dirá **Posso ajudar?** (¿puedo ayudar?). :: Tú pides: **Queria ver aquele casaco** (quería ver aquella chaqueta). :: **Que tamanho?** = ¿qué talla? La talla es **o tamanho**: o tamanho M. :: **Posso experimentar?** = ¿puedo probármelo? Te mandarán a **os provadores** (los probadores).
E Cómo queda y cuánto cuesta :: **Fica-me bem** = me queda bien. **Fica-lhe bem** = le queda bien (a usted). :: **É caro** (es caro), **é barato** (es barato). **Tem um tamanho maior?** = ¿tiene una talla más grande? :: **Levo** = me lo llevo.
E Pagar :: **Posso pagar com cartão?** = ¿puedo pagar con tarjeta? :: **Em dinheiro** = en efectivo. **Dinheiro** es «dinero». :: **Claro** = claro, por supuesto.
W posso ajudar = ¿puedo ayudar? | PO-su a-zhu-DAR
W posso = puedo | PO-su
W ver = ver | ver
W tamanho = talla, tamaño | ta-MA-ñu
W experimentar = probar, probarse | (e)sh-p(e)-ri-men-TAR
W provadores = probadores | pru-va-DO-r(e)sh
W fica-me bem = me queda bien | FI-ca-m(e) bein
W fica-lhe = le queda (a usted) | FI-ca-ll(e)
W caro = caro | CA-ru
W barato = barato | ba-RA-tu
W maior = más grande, mayor | mai-OR
W levo = me lo llevo | LE-vu
W pagar = pagar | pa-GAR
W cartão = tarjeta | car-TAUN
W dinheiro = dinero | di-ÑEI-ru
W em dinheiro = en efectivo | ein di-ÑEI-ru
W claro = claro, por supuesto | CLA-ru
V Vocabulario: en la tienda
D Una chaqueta nueva
Ana: Bom dia. Posso ajudar? = Buenos días. ¿Puedo ayudarle?
  > Posso ajudar = puedo ayudar
Carlos: Bom dia. Queria ver aquele casaco preto. = Buenos días. Quería ver aquella chaqueta negra.
  > Queria ver = quería ver | aquele casaco preto = aquella chaqueta negra
Ana: Claro. Que tamanho? = Claro. ¿Qué talla?
  > Que tamanho = qué talla
Carlos: O tamanho M. Posso experimentar? = La talla M. ¿Puedo probármela?
  > Posso experimentar = puedo probar
Ana: Sim, os provadores são ali. = Sí, los probadores están allí.
  > os provadores = los probadores | são ali = están allí
Carlos: É um pouco pequeno. Tem um tamanho maior? = Es un poco pequeña. ¿Tiene una talla más grande?
  > um pouco pequeno = un poco pequeño | um tamanho maior = una talla mayor
Ana: Sim, aqui tem. Este fica-lhe muito bem! = Sí, aquí tiene. ¡Esta le queda muy bien!
  > fica-lhe muito bem = le queda muy bien
Carlos: Quanto custa? = ¿Cuánto cuesta?
  > Quanto custa = cuánto cuesta
Ana: Custa oitenta euros. = Cuesta ochenta euros.
  > oitenta euros = ochenta euros
Carlos: É caro, mas levo. Posso pagar com cartão? = Es cara, pero me la llevo. ¿Puedo pagar con tarjeta?
  > É caro = es caro | levo = me lo llevo | pagar com cartão = pagar con tarjeta
Ana: Claro! = ¡Claro!
  > Claro = por supuesto
Q ¿Cómo preguntas si puedes probarte algo?
+ Posso experimentar? :: Experimentar = probarse.
- Posso ajudar? :: Eso es «¿puedo ayudar?».
- Posso pagar? :: Eso es «¿puedo pagar?».
Q ¿Qué es «o tamanho»?
+ La talla. :: También «el tamaño».
- El precio. :: No.
- El probador. :: Eso es «o provador».
Q ¿Cómo se dice «en efectivo»?
+ em dinheiro :: Dinheiro = dinero.
- com cartão :: Eso es «con tarjeta».
- em conta :: No.
Q Te dicen «Fica-lhe muito bem». ¿Qué significa?
+ Le queda muy bien. :: Lo dice el dependiente.
- Está muy bien de precio. :: No habla del precio.
- Quédese aquí. :: No.
R É caro, mas levo.
+ Es caro, pero me lo llevo. :: Levo = me lo llevo.
- Es barato y me lo llevo. :: Caro no es «barato».
- Es caro; no me lo llevo. :: No es negativa.
H Posso pagar ___ cartão?
+ com :: Pagar com cartão.
- em :: Eso va con «dinheiro».
- de :: No.
H Tem um tamanho ___ ? (más grande)
+ maior :: Maior = más grande.
- caro :: Eso es «caro».
- barato :: Eso es «barato».
A Quanto custa este vestido?
+ ¿Cuánto cuesta este vestido? :: Quanto custa.
- ¿Cuánto cuestan estos zapatos? :: Vestido = vestido.
- ¿De qué color es este vestido? :: No pregunta eso.
O Posso pagar com cartão :: ¿Puedo pagar con tarjeta? :: Puedo + pagar + con + tarjeta.

@ 7 | Mais ou menos? | Comparar cosas
E Más que, menos que :: **Mais … do que** y **menos … do que**. No olvides el «do»: O azul é **mais** bonito **do que** o preto (el azul es más bonito que el negro). :: Para la igualdad: **tão … como** (tan … como). É **tão** confortável **como** o azul.
E Los irregulares :: Como en español, algunos tienen forma propia: **bom** (bueno) → **melhor** (mejor), **mau** (malo) → **pior** (peor), **grande** → **maior** (mayor, más grande). :: «Más pequeño» se dice en Portugal **mais pequeno**.
B Comparar | Portugués | Español
| mais caro do que | más caro que
| menos caro do que | menos caro que
| tão caro como | tan caro como
| melhor do que | mejor que
| pior do que | peor que
| maior do que | más grande que
E El más :: Con el artículo delante: **o mais** barato, **a mais** barata. :: É **a mais barata da** loja = es la más barata de la tienda. :: Para elegir: **Qual preferes?** (¿cuál prefieres?). **Ou** = o.
W mais = más | maish
W do que = que (al comparar) | du k(e)
W tão = tan | taun
W melhor = mejor | m(e)-LLOR
W pior = peor | pi-OR
W bom = bueno | bon
W mau = malo | mau
W preferes = prefieres | pr(e)-FE-r(e)sh
W ou = o | o
W confortável = cómodo | con-fur-TA-vel
W rápido = rápido | RRA-pi-du
W barata = barata | ba-RA-ta
W feia = fea | FEI-a
W sessenta = sesenta | s(e)-SEN-ta
V Vocabulario: comparar
D ¿Cuál prefieres?
Rui: Sofia, qual preferes? O casaco azul ou o casaco preto? = Sofia, ¿cuál prefieres? ¿La chaqueta azul o la chaqueta negra?
  > qual preferes = cuál prefieres | ou = o
Sofia: O azul é mais bonito do que o preto. = La azul es más bonita que la negra.
  > mais bonito do que = más bonito que
Rui: Mas é mais caro. = Pero es más cara.
  > mais caro = más caro
Sofia: Quanto custam? = ¿Cuánto cuestan?
  > Quanto custam = cuánto cuestan
Rui: O azul custa cem euros e o preto custa sessenta. = La azul cuesta cien euros y la negra cuesta sesenta.
  > cem euros = cien euros | sessenta = sesenta
Sofia: Então o preto é melhor. É tão confortável como o azul e é menos caro. = Entonces la negra es mejor. Es tan cómoda como la azul y es menos cara.
  > melhor = mejor | tão confortável como = tan cómodo como | menos caro = menos caro
Rui: E esta camisola? É a mais barata da loja! = ¿Y este jersey? ¡Es el más barato de la tienda!
  > a mais barata da loja = la más barata de la tienda
Sofia: Sim, mas também é a mais feia! = Sí, ¡pero también es el más feo!
  > a mais feia = la más fea
T Comparaciones
- O meu irmão é mais alto do que eu. = Mi hermano es más alto que yo.
  > mais alto do que eu = más alto que yo
- Lisboa é maior do que o Porto. = Lisboa es más grande que Oporto.
  > maior do que = más grande que
- Para mim, o peixe é melhor do que a carne. = Para mí, el pescado es mejor que la carne.
  > melhor do que = mejor que
- Este carro é tão rápido como aquele. = Este coche es tan rápido como aquel.
  > tão rápido como = tan rápido como
- A minha casa é a mais pequena da rua. = Mi casa es la más pequeña de la calle.
  > a mais pequena da rua = la más pequeña de la calle
Q ¿Cómo dices «más alto que»?
+ mais alto do que :: Mais … do que.
- mais alto como :: «Como» es para la igualdad.
- muito alto de :: No.
Q ¿Cómo se dice «mejor»?
+ melhor :: De «bom».
- mais bom :: Tiene forma propia.
- maior :: Eso es «más grande».
Q ¿Cómo dices «tan caro como»?
+ tão caro como :: Tão … como.
- tão caro do que :: «Do que» va con mais y menos.
- mais caro como :: No.
Q ¿Cómo dices «el más barato»?
+ o mais barato :: Artículo + mais + adjetivo.
- o muito barato :: No.
- mais o barato :: El artículo va delante.
R Lisboa é maior do que o Porto.
+ Lisboa es más grande que Oporto. :: Maior = más grande.
- Lisboa es mejor que Oporto. :: Mejor es «melhor».
- Oporto es más grande que Lisboa. :: Es al revés.
H O azul é mais bonito ___ o preto.
+ do que :: Mais … do que.
- como :: Va con «tão».
- tão :: No.
H Este casaco é ___ confortável como aquele.
+ tão :: Tão … como.
- mais :: Iría con «do que».
- muito :: No.
A Esta camisola é a mais barata da loja.
+ Este jersey es el más barato de la tienda. :: A mais barata.
- Este jersey es el más caro de la tienda. :: Barata = barata.
- Esta camisa es la más barata de la tienda. :: Camisola = jersey.
