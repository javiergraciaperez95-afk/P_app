@ 23 | Anunțuri și reguli | Avisos y reglas
I En avisos y procedimientos, el rumano suele usar **se** para hablar de una acción sin decir quién la realiza.
E Forma impersonal :: **Se completează formularul** significa «se completa el formulario». El objeto de la acción funciona como sujeto y el verbo concuerda con él.
E Concordancia :: Con un nombre plural, el verbo también va en plural: **se trimit documentele** («se envían los documentos»).
W se completează = se completa | se kom-ple-TE-a-ză
W se trimite = se envía | se tri-MI-te
W se verifică = se comprueba; se verifica | se ve-ri-FI-kă
W se trimit = se envían | se TRIMIT
W se vând = se venden | se VÎND
W se oferă = se ofrece | se O-fe-ră
W se acceptă = se acepta | se ak-CEP-tă
W se fumează = se fuma; se permite fumar | se fu-me-A-ză
W nu se fumează = está prohibido fumar | nu se fu-me-A-ză
W se organizează = se organiza | se or-ga-ni-ZE-a-ză
W se deschide = se abre | se des-KI-de
W se închide = se cierra | se în-KI-de
W anunț = aviso | a-NUNȚ
W anunțul = el aviso | a-NUN-țul
W gratuit = gratuito (masculino) | gra-TUIT
W gratuită = gratuita (femenino) | gra-TU-i-tă
W documentele = los documentos | do-ku-MEN-te-le
W prin e-mail = por correo electrónico | prin i-MEIL
W online = en línea | on-LAIN
W bilete = entradas | bi-LE-te
V Vocabulario: avisos y normas
D Leer un aviso
Ana: Formularul se completează online? = ¿El formulario se completa en línea?
  > Formularul = el formulario | se completează = se completa | online = en línea
Ana: Și documentele? = ¿Y los documentos?
  > Și = y | documentele = los documentos
Mihai: Documentele se trimit prin e-mail. = Los documentos se envían por correo electrónico.
  > Documentele = los documentos | se trimit = se envían | prin e-mail = por correo electrónico
Ana: Se fumează aici? = ¿Se fuma aquí?
  > Se fumează = se fuma | aici = aquí
Mihai: Nu. Nu se fumează în clădire. = No. Está prohibido fumar en el edificio.
  > Nu = no | nu se fumează = está prohibido fumar | în clădire = en el edificio
T Reguli într-un spațiu public
- Se acceptă documentele online. = Se aceptan los documentos en línea.
  > Se acceptă = se aceptan | documentele online = los documentos en línea
- Se oferă informații la intrare. = Se ofrece información en la entrada.
  > Se oferă = se ofrece | informații = información | la intrare = en la entrada
- Se oferă un program gratuit. = Se ofrece un programa gratuito.
  > Se oferă = se ofrece | un program gratuit = un programa gratuito
- Se vând bilete online. = Se venden entradas en línea.
  > Se vând = se venden | bilete online = entradas en línea
- Se deschide la ora nouă. = Abre a las nueve.
  > Se deschide = se abre | la ora nouă = a las nueve
- Se închide la ora șase. = Cierra a las seis.
  > Se închide = se cierra | la ora șase = a las seis
Q ¿Qué significa «nu se fumează»?
+ Está prohibido fumar. :: Es una norma general sin mencionar quién la impone.
- Se acepta la entrada. :: El aviso no habla de un pago.
- Se cierra el edificio. :: «Se închide» significa «se cierra».
R Documentele se trimit prin e-mail. :: Elige la traducción.
+ Los documentos se envían por correo electrónico. :: El sujeto plural concuerda con «se trimit».
- El formulario se completa en línea. :: Eso sería «Formularul se completează online».
- Los documentos se comprueban en la entrada. :: La frase dice que se envían.
H Formularul ___ online. :: Completa «El formulario se completa en línea».
+ se completează :: Es la construcción impersonal para una acción general.
- se trimit :: Es plural y significa «se envían».
- se închide :: Significa «se cierra».
A Se acceptă documentele online. :: ¿Qué permite el aviso?
+ Enviar los documentos en línea. :: El aviso indica que se aceptan documentos en línea.
- Fumar en el edificio. :: El aviso de fumar dice «nu se fumează».
- Enviar los documentos por correo. :: Eso se dice «documentele se trimit prin e-mail».
O se oferă informații :: se ofrece información :: «Se oferă» deja sin expresar quién ofrece.
X Escribe en rumano: «Se envían los documentos». :: Se trimit documentele. :: El verbo plural concuerda con «documentele».
Q ¿Qué significa «gratuită»?
+ Gratuita. :: Es la forma femenina de «gratuit».
- Obligatoria. :: Es otra cualidad, no indica que sea gratis.
- Cerrada. :: «Închisă» significa «cerrada».
R Se vând bilete online. :: Elige la traducción.
+ Se venden entradas en línea. :: «Se vând» concuerda con el sujeto plural.
- Se ofrece un programa gratuito. :: Eso se dice «Se oferă un program gratuit».
- Está prohibido fumar en el edificio. :: Eso se dice «Nu se fumează în clădire».

@ 23 | Instrucțiuni digitale | Instrucciones digitales
I Para indicar qué debe hacer una persona en un procedimiento, usa el imperativo de cortesía. En pasos sucesivos, puedes omitir el sujeto.
E Imperativo cortés :: **Introduceți**, **apăsați** y **salvați** son instrucciones para varias personas o para una sola persona tratada de usted.
E Pasos :: **Mai întâi** indica el primer paso; **apoi**, el siguiente. El imperativo rumano no necesita un pronombre sujeto.
W apăsați = pulse; pulsen | a-pă-SAȚ
W selectați = seleccione; seleccionen | se-lek-TAȚ
W introduceți = introduzca; introduzcan | in-tro-du-CEȚ
W salvați = guarde; guarden | sal-VAȚ
W apăs = pulso | a-PĂS
W alegeți = elija; elijan | a-le-JEȚ
W bifați = marque; marquen | bi-FAȚ
W cod = código | KOD
W codul = el código | KO-dul
W parolă = contraseña | pa-RO-lă
W parola = la contraseña | pa-RO-la
W buton = botón | bu-TON
W butonul = el botón | bu-TO-nul
W câmp = campo; casilla | KÎMP
W câmpul = el campo; la casilla | KÎM-pul
W verde = verde (invariable en singular) | VER-de
W corect = correcto (masculino) | ko-REKT
W corectă = correcta (femenino) | ko-REK-tă
W datele = los datos | DA-te-le
W fac = hago | FAK
W opțiunea = la opción | op-TSI-u-ne-a
V Vocabulario: pasos digitales
D Completar un formulario en línea
Ana: Ce fac mai întâi? = ¿Qué hago primero?
  > Ce fac = qué hago | mai întâi = primero
Mihai: Introduceți parola în câmp. = Introduzca la contraseña en el campo.
  > Introduceți = introduzca (cortesía) | parola = la contraseña | în câmp = en el campo
Ana: Apoi apăs butonul verde? = ¿Después pulso el botón verde?
  > Apoi = después | apăs = pulso | butonul verde = el botón verde
Mihai: Da. Selectați codul corect și salvați datele. = Sí. Seleccione el código correcto y guarde los datos.
  > Selectați = seleccione (cortesía) | codul corect = el código correcto | salvați datele = guarde los datos
T Pașii necesari (Los pasos necesarios)
- Alegeți codul. = Elija el código.
  > Alegeți = elija (cortesía) | codul = el código
- Introduceți parola în câmp. = Introduzca la contraseña en el campo.
  > Introduceți = introduzca (cortesía) | parola = la contraseña | în câmp = en el campo
- Bifați opțiunea corectă. = Marque la opción correcta.
  > Bifați = marque (cortesía) | opțiunea corectă = la opción correcta
- Apăsați butonul verde. = Pulse el botón verde.
  > Apăsați = pulse (cortesía) | butonul verde = el botón verde
- Salvați datele. = Guarde los datos.
  > Salvați = guarde (cortesía) | datele = los datos
Q ¿Qué significa «parola»?
+ La contraseña. :: Es la forma definida de «parolă».
- El código. :: «Codul» significa «el código».
- El botón. :: «Butonul» significa «el botón».
R Selectați codul corect și salvați datele. :: Elige la traducción.
+ Seleccione el código correcto y guarde los datos. :: Las dos formas son instrucciones de cortesía.
- Marque la contraseña y pulse el campo verde. :: La frase no dice «bifați» ni «câmpul».
- Guarde la opción y seleccione el botón. :: La frase pide seleccionar un código y guardar los datos.
H ___ parola în câmp. :: Completa «Introduzca la contraseña en el campo».
+ Introduceți :: Es el imperativo de cortesía de «introducir».
- Salvați :: Significa «guarde».
- Bifați :: Significa «marque».
A Apăsați butonul verde. :: ¿Qué debe hacer la persona?
+ Pulsar el botón verde. :: «Apăsați» es «pulse».
- Guardar los datos. :: Eso se dice «Salvați datele».
- Elegir el código. :: Eso se dice «Alegeți codul».
O selectați codul :: seleccione el código :: El imperativo de cortesía termina aquí en «-ați».
X Escribe en rumano: «Marque la opción correcta». :: Bifați opțiunea corectă. :: «Bifați» es el imperativo de cortesía.
Q ¿Qué significa «câmpul» en un formulario?
+ El campo; la casilla. :: Es el espacio donde se introduce un dato.
- La contraseña. :: «Parola» significa «la contraseña».
- El botón. :: «Butonul» significa «el botón».
R Alegeți codul și salvați datele. :: Elige la traducción.
+ Elija el código y guarde los datos. :: Son dos instrucciones formales.
- Introduzca la contraseña y marque la opción. :: Eso se dice «Introduceți parola și bifați opțiunea».
- Pulse el botón verde y después elija el código. :: La frase no menciona el botón ni el orden «después».

@ 23 | Pași și proceduri | Pasos y procedimientos
I En una receta o procedimiento, ordena los pasos con conectores temporales y distingue la instrucción directa de la acción general con **se**.
E Secuencia :: **Înainte să** significa «antes de que»; **după ce**, «después de que»; **până când**, «hasta que».
E Procedimientos :: **Adăugați** («añada») da una instrucción. **Se amestecă** describe un paso de forma general o impersonal.
W ingredientele = los ingredientes | in-gre-di-EN-te-le
W facem = hacemos | FA-chem
W adăugați = añada; añadan | a-dă-u-GAȚ
W se amestecă = se mezcla | se a-mes-TE-kă
W turnați = vierta; viertan | tur-NAȚ
W lăsați = deje; dejen | lă-SAȚ
W se fierbe = se hierve | se FIER-be
W fierbeți = hierva; hiervan | fier-BEȚ
W până când = hasta que | PÎ-nă kînd
W după ce = después de que | DU-pă che
W înainte să = antes de que | în-AIN-te să
W la final = al final | la fi-NAL
W amestec = mezcla | a-mes-TEK
W amestecul = la mezcla | a-mes-TE-kul
W serviți = sirva; sirvan | ser-VIȚ
W caldă = caliente; templada (femenino) | KAL-dă
W fiarbă = hierva | FI-ar-bă
W într-un vas = en un recipiente | în-trun VAS
W fierbe = hierve | FIER-be
V Vocabulario: instrucciones y cocina
D Una receta sencilla
Ana: Ce facem mai întâi? = ¿Qué hacemos primero?
  > Ce facem = qué hacemos | mai întâi = primero
Mihai: Adăugați ingredientele în apă. = Añada los ingredientes al agua.
  > Adăugați = añada (cortesía) | ingredientele = los ingredientes | în apă = al agua
Ana: Apoi, se amestecă? = ¿Después, se mezcla?
  > Apoi = después | se amestecă = se mezcla
Mihai: Da. Fierbeți supa până când este caldă. = Sí. Hierva la sopa hasta que esté caliente.
  > Fierbeți supa = hierva la sopa | până când = hasta que | este caldă = esté caliente
Ana: Și la final? = ¿Y al final?
  > Și = y | la final = al final
Mihai: Lăsați amestecul să fiarbă și serviți supa caldă. = Deje hervir la mezcla y sirva la sopa caliente.
  > Lăsați amestecul să fiarbă = deje hervir la mezcla | și serviți supa caldă = y sirva la sopa caliente
T Pașii rețetei (Los pasos de la receta)
- Mai întâi, adăugați ingredientele. = Primero, añada los ingredientes.
  > Mai întâi = primero | adăugați ingredientele = añada los ingredientes
- Apoi, se amestecă bine. = Después, se mezcla bien.
  > Apoi = después | se amestecă = se mezcla | bine = bien
- Turnați supa într-un vas. = Vierta la sopa en un recipiente.
  > Turnați = vierta (cortesía) | supa = la sopa | într-un vas = en un recipiente
- Înainte să serviți supa, lăsați amestecul să fiarbă. = Antes de servir la sopa, deje hervir la mezcla.
  > Înainte să serviți supa = antes de servir la sopa | lăsați amestecul să fiarbă = deje hervir la mezcla
- După ce fierbe, serviți supa caldă. = Después de que hierva, sirva la sopa caliente.
  > După ce fierbe = después de que hierva | serviți supa caldă = sirva la sopa caliente
Q ¿Qué significa «ingredientele»?
+ Los ingredientes. :: Es el plural con artículo definido.
- La cantidad. :: «Cantitatea» significa «la cantidad».
- La mezcla. :: «Amestec» significa «mezcla».
R Adăugați ingredientele în apă. :: Elige la traducción.
+ Añada los ingredientes al agua. :: «Adăugați» es una instrucción cortés.
- Hierva la sopa hasta que esté caliente. :: Eso se dice «Fierbeți supa până când este caldă».
- Vierta la sopa en un recipiente. :: Eso se dice «Turnați supa într-un vas».
H ___ supa caldă. :: Completa «Sirva la sopa caliente».
+ serviți :: Es el imperativo de cortesía de «servir».
- se amestecă :: Significa «se mezcla».
- fierbeți :: Significa «hierva».
A Apoi, se amestecă bine. :: ¿Qué ocurre después?
+ Se mezcla bien. :: «Se amestecă» describe un paso general.
- Se vierte la sopa en un recipiente. :: Eso se dice «Turnați supa într-un vas».
- Se deja la mezcla hasta que hierva. :: La frase no menciona «lăsați».
O după ce fierbe :: después de que hierva :: «După ce» introduce el paso posterior.
X Escribe en rumano: «Primero, añada los ingredientes». :: Mai întâi, adăugați ingredientele. :: «Adăugați» es una instrucción formal.
Q ¿Qué significa «până când»?
+ Hasta que. :: Marca el límite temporal de un paso.
- Antes de que. :: «Înainte să» significa «antes de que».
- Después de que. :: «După ce» significa «después de que».
R Înainte să serviți supa, lăsați amestecul să fiarbă. :: Elige la traducción.
+ Antes de servir la sopa, deje hervir la mezcla. :: «Înainte să» introduce una acción previa.
- Después de que hierva, sirva la sopa caliente. :: Eso se dice «După ce fierbe, serviți supa caldă».
- Primero, añada la cantidad de ingredientes. :: La oración habla de servir y dejar hervir.
