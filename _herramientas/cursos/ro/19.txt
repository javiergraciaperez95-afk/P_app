@ 19 | Programul și semnele | Horarios y carteles
I En la ciudad conviene leer los horarios y los avisos. En los carteles, **deschis** («abierto») concuerda con un nombre masculino y **deschisă**, con uno femenino.
E Horarios :: **Program** puede ser «horario» o «programa», según el contexto. En un servicio, **programul** suele indicar las horas de atención. **Muzeului** significa «del museo».
E Carteles :: **Intrare** es «entrada» e **ieșire**, «salida». **Acces interzis** significa «acceso prohibido».
W program = horario | pro-GRAM
W programul = el horario | pro-GRA-mul
W care = cuál | KA-re
W muzeului = del museo | mu-ZE-u-lui
W deschis = abierto (masculino) | de-SKIS
W deschisă = abierta (femenino) | de-SKI-să
W închis = cerrado (masculino) | în-KIS
W închisă = cerrada (femenino) | în-KI-să
W intrare = entrada | in-TRA-re
W intrarea = la entrada | in-TRA-re-a
W ieșire = salida | ie-SHI-re
W ieșirea = la salida | ie-SHI-re-a
W acces = acceso | ak-CHES
W accesul = el acceso | ak-CHE-sul
W interzis = prohibido | in-ter-ZIS
W temporar = temporalmente | tem-po-RAR
W reparație = reparación | re-pa-RA-tsi-e
W reparații = reparaciones | re-pa-RA-tsi-i
V Vocabulario: horarios y avisos
D Un horario y un aviso
Ana: Care este programul muzeului? = ¿Cuál es el horario del museo?
  > Care este programul = cuál es el horario | muzeului = del museo
Paul: Programul este de luni până vineri. = El horario es de lunes a viernes.
  > Programul = el horario | este de luni până vineri = es de lunes a viernes
Ana: Farmacia este deschisă duminică? = ¿Está abierta la farmacia el domingo?
  > Farmacia = la farmacia | este deschisă = está abierta | duminică = el domingo
Paul: Nu. Accesul este interzis. Muzeul este închis temporar pentru reparații. = No. El acceso está prohibido. El museo está cerrado temporalmente por reparaciones.
  > Nu = no | Accesul este interzis = el acceso está prohibido | Muzeul este închis temporar = el museo está cerrado temporalmente | pentru reparații = por reparaciones
T Carteles de la ciudad
- Intrarea este aici. = La entrada está aquí.
  > Intrarea = la entrada | este aici = está aquí
- Ieșirea este la dreapta. = La salida está a la derecha.
  > Ieșirea = la salida | este la dreapta = está a la derecha
- Farmacia este deschisă. = La farmacia está abierta.
  > Farmacia = la farmacia | este deschisă = está abierta
- Muzeul este închis temporar pentru reparații. = El museo está cerrado temporalmente por reparaciones.
  > Muzeul este închis temporar = el museo está cerrado temporalmente | pentru reparații = por reparaciones
Q ¿Qué significa «intrare»?
+ Entrada. :: «Intrarea» significa «la entrada».
- Salida. :: «Ieșire» significa «salida».
- Horario. :: «Program» significa «horario».
R Muzeul este închis temporar pentru reparații. :: Elige la traducción.
+ El museo está cerrado temporalmente por reparaciones. :: «Închis temporar» indica que no abre por ahora.
- El museo está abierto el domingo. :: «Închis» significa «cerrado».
- La farmacia está cerrada por reparaciones. :: El sujeto es «muzeul», el museo.
H Farmacia este ___. :: Completa «La farmacia está abierta».
+ deschisă :: Concuerda con «farmacia», que es femenino.
- deschis :: Es la forma masculina.
- închisă :: Significa «cerrada».
A Accesul este interzis. :: ¿Se puede entrar?
+ No; el acceso está prohibido. :: «Interzis» significa «prohibido».
- Sí; la entrada está abierta. :: La frase dice que el acceso está prohibido.
- No; el museo está en reparaciones. :: La frase habla del acceso.
O intrarea este la dreapta :: la entrada está a la derecha :: «Intrarea» es «la entrada».
X Escribe en rumano: «La farmacia está cerrada el domingo». :: Farmacia este închisă duminică. :: «Închisă» es la forma femenina de «închis».
Q ¿Qué significa «temporar» en este aviso?
+ Temporalmente. :: Indica que el cierre no es permanente.
- Abierto. :: «Deschis» significa «abierto».
- Prohibido. :: «Interzis» significa «prohibido».
R Programul este de luni până vineri. :: Elige la traducción.
+ El horario es de lunes a viernes. :: «Programul» significa «el horario».
- El museo está cerrado de lunes a viernes. :: La frase no dice que esté cerrado.
- La farmacia está abierta hasta el viernes. :: La frase habla del horario.

@ 19 | În clădire | Dentro del edificio
I Para orientarte en un edificio, pregunta **Unde este...?** («¿Dónde está...?»). Las instrucciones pueden indicar la planta, el pasillo o las escaleras.
E Lugares :: **Parter** es la planta baja. **Hol** es el vestíbulo y **coridor**, el pasillo.
E Ubicación :: **La capătul coridorului** significa «al final del pasillo». En rumano, la forma **coridorului** expresa «del pasillo».
W parter = planta baja | par-TER
W parterul = la planta baja | par-TE-rul
W hol = vestíbulo; recibidor | hol
W holul = el vestíbulo; el recibidor | HO-lul
W coridor = pasillo | ko-ri-DOR
W coridorul = el pasillo | ko-ri-DO-rul
W coridorului = del pasillo | ko-ri-DO-ru-lui
W capăt = extremo; final | KA-păt
W capătul = el extremo; el final | KA-pă-tul
W secretariat = secretaría | se-kre-ta-ri-AT
W secretariatul = la secretaría | se-kre-ta-ri-A-tul
W sală = sala; habitación amplia | SA-lă
W sala = la sala | SA-la
W așteptare = espera | aș-tep-TA-re
W scări = escaleras | skări
W scările = las escaleras | SKĂ-ri-le
W clădire = edificio | clă-DI-re
W clădirea = el edificio | clă-DI-re-a
V Vocabulario: espacios de un edificio
D Buscar la secretaría
Ana: Unde este secretariatul? = ¿Dónde está la secretaría?
  > Unde este = dónde está | secretariatul = la secretaría
Paul: Este la parter, în hol. = Está en la planta baja, en el vestíbulo.
  > Este la parter = está en la planta baja | în hol = en el vestíbulo
Ana: Unde este sala de așteptare? = ¿Dónde está la sala de espera?
  > Unde este = dónde está | sala de așteptare = la sala de espera
Paul: Este la capătul coridorului, lângă scări. = Está al final del pasillo, junto a las escaleras.
  > Este la capătul coridorului = está al final del pasillo | lângă scări = junto a las escaleras
T Orientarse dentro
- Secretariatul este la parter. = La secretaría está en la planta baja.
  > Secretariatul = la secretaría | este la parter = está en la planta baja
- Holul este lângă intrare. = El vestíbulo está junto a la entrada.
  > Holul = el vestíbulo | este lângă intrare = está junto a la entrada
- Sala de așteptare este în clădire. = La sala de espera está en el edificio.
  > Sala de așteptare = la sala de espera | este în clădire = está en el edificio
- La capătul coridorului sunt scările. = Al final del pasillo están las escaleras.
  > La capătul coridorului = al final del pasillo | sunt scările = están las escaleras
Q ¿Qué significa «parter»?
+ Planta baja. :: En un edificio, está al nivel de la entrada.
- Pasillo. :: «Coridor» significa «pasillo».
- Secretaría. :: «Secretariat» significa «secretaría».
R Sala de așteptare este în clădire. :: Elige la traducción.
+ La sala de espera está en el edificio. :: «Sala de așteptare» significa «sala de espera».
- La secretaría está en la planta baja. :: Eso se dice «Secretariatul este la parter».
- El vestíbulo está junto a la entrada. :: Eso se dice «Holul este lângă intrare».
H Secretariatul este la ___. :: Completa «La secretaría está en la planta baja».
+ parter :: Significa «planta baja».
- hol :: Significa «vestíbulo».
- coridor :: Significa «pasillo».
A Este la capătul coridorului, lângă scări. :: ¿Dónde está?
+ Al final del pasillo, junto a las escaleras. :: «La capătul coridorului» significa «al final del pasillo».
- En la planta baja, en el vestíbulo. :: Eso se dice «Este la parter, în hol».
- Junto a la entrada. :: Eso se dice «lângă intrare».
O holul este lângă intrare :: el vestíbulo está junto a la entrada :: «Holul» es «el vestíbulo».
X Escribe en rumano: «La sala de espera está en el edificio». :: Sala de așteptare este în clădire. :: «În clădire» significa «en el edificio».
Q ¿Qué significa «coridorului»?
+ Del pasillo. :: Es la forma que aparece en «la capătul coridorului».
- Las escaleras. :: «Scările» significa «las escaleras».
- El edificio. :: «Clădirea» significa «el edificio».
R Holul este lângă intrare. :: Elige la traducción.
+ El vestíbulo está junto a la entrada. :: «Lângă» significa «junto a».
- La sala de espera está en el edificio. :: Esa frase empieza por «Sala de așteptare».
- La secretaría está al final del pasillo. :: Esa frase empieza por «Secretariatul».

@ 19 | La ghișeu | En ventanilla
I En una institución se usa el trato cortés. **Așteptați**, **prezentați** y **ridicați** son instrucciones para varias personas o para una sola persona tratada de usted.
E Imperativo cortés :: El imperativo de cortesía suele tener la misma forma que **voi**. **Vă rog** («por favor») suaviza la instrucción.
E Trámites :: **Ghișeu** es una ventanilla de atención; **cerere**, una solicitud; **document**, un documento.
W ghișeu = ventanilla | ghi-SHEU
W ghișeul = la ventanilla | ghi-SHE-ul
W cerere = solicitud | che-RE-re
W cererea = la solicitud | che-RE-re-a
W document = documento | do-ku-MENT
W documentul = el documento | do-ku-MEN-tul
W a aștepta = esperar | a aș-tep-TA
W aștept = espero | aș-TEPT
W așteptați = espere; esperen | aș-tep-TAȚ
W a prezenta = presentar; mostrar | a pre-zen-TA
W prezint = presento; muestro | pre-ZINT
W prezentați = presente; presenten | pre-zen-TAȚ
W a ridica = recoger; retirar | a ri-di-KA
W ridic = recojo; retiro | ri-DIK
W ridicați = recoja; recojan | ri-di-KAȚ
V Vocabulario: solicitudes y documentos
D En la ventanilla
Ana: Unde prezint documentul? = ¿Dónde presento el documento?
  > Unde prezint = dónde presento | documentul = el documento
Funcționară: Prezentați documentul la ghișeu. = Presente el documento en la ventanilla.
  > Prezentați = presente (cortesía) | documentul = el documento | la ghișeu = en la ventanilla
Ana: Aștept aici? = ¿Espero aquí?
  > Aștept = espero | aici = aquí
Funcționară: Așteptați aici, vă rog. = Espere aquí, por favor.
  > Așteptați aici = espere aquí (cortesía) | vă rog = por favor
Ana: Când ridic documentul? = ¿Cuándo recojo el documento?
  > Când = cuándo | ridic = recojo | documentul = el documento
Funcționară: Ridicați documentul mâine. = Recoja el documento mañana.
  > Ridicați = recoja (cortesía) | documentul = el documento | mâine = mañana
T Instrucciones
- Completați cererea, vă rog. = Complete la solicitud, por favor.
  > Completați = complete (cortesía) | cererea = la solicitud | vă rog = por favor
- Prezentați documentul la ghișeu. = Presente el documento en la ventanilla.
  > Prezentați = presente (cortesía) | documentul = el documento | la ghișeu = en la ventanilla
- Așteptați aici, vă rog. = Espere aquí, por favor.
  > Așteptați aici = espere aquí (cortesía) | vă rog = por favor
- Ridicați documentul mâine. = Recoja el documento mañana.
  > Ridicați = recoja (cortesía) | documentul = el documento | mâine = mañana
Q ¿Qué es un «ghișeu»?
+ Una ventanilla de atención. :: Es el lugar donde se entregan o recogen documentos.
- Una solicitud. :: «Cerere» significa «solicitud».
- Un documento. :: «Document» significa «documento».
R Prezentați documentul la ghișeu. :: Elige la traducción.
+ Presente el documento en la ventanilla. :: «Prezentați» es una instrucción cortés.
- Espero el documento en la ventanilla. :: Eso sería «Aștept documentul la ghișeu».
- Recoja la solicitud mañana. :: Eso sería «Ridicați cererea mâine».
H ___ aici, vă rog. :: Completa «Espere aquí, por favor» en trato cortés.
+ Așteptați :: Es la forma de cortesía.
- Aștept :: Significa «yo espero».
- A aștepta :: Es el infinitivo «esperar».
A Completați cererea, vă rog. :: ¿Qué debe hacer la persona?
+ Completar la solicitud. :: «Completați cererea» significa eso.
- Recoger el documento. :: Eso se dice «Ridicați documentul».
- Esperar en la ventanilla. :: Eso se dice «Așteptați la ghișeu».
O prezentați documentul :: presente el documento :: La forma cortés puede dirigirse a una persona o a varias.
X Escribe en rumano: «Espero en la ventanilla». :: Aștept la ghișeu. :: «Aștept» significa «espero».
Q ¿Cuál es la forma cortés de «presentar»?
+ prezentați :: Se usa con varias personas o con una persona de usted.
- prezint :: Significa «yo presento».
- a prezenta :: Es el infinitivo «presentar».
R Ridicați documentul mâine. :: Elige la traducción.
+ Recoja el documento mañana. :: «Ridicați» es una instrucción cortés.
- Presento el documento mañana. :: Eso sería «Prezint documentul mâine».
- Espero el documento aquí. :: Eso sería «Aștept documentul aici».
