@ 4 | Casa mea | Mi casa
I Vamos a nombrar las habitaciones y a distinguir «una casa» de «la casa». En rumano, el artículo definido se pega al final del nombre.
E El artículo definido :: **O casă** significa «una casa»; **casa**, «la casa». En muchos nombres femeninos acabados en **-ă**, el artículo cambia esa vocal por **-a**.
E Otros nombres :: En nombres masculinos o neutros frecuentes, el artículo puede añadirse como **-ul**: **un apartament → apartamentul** («un apartamento → el apartamento»). El artículo rumano forma parte de la palabra; en español va delante.
B Indefinido y definido | «Un/una» | «El/la»
| o casă | casa
| un apartament | apartamentul
| o cameră | camera
W casă = casa (vivienda) | KA-să
W casa = la casa | KA-sa
W apartament = apartamento | a-par-ta-MENT
W apartamentul = el apartamento | a-par-ta-MEN-tul
W cameră = habitación; cuarto | ka-ME-ră
W camera = la habitación | ka-ME-ra
W camere = habitaciones; cuartos | KA-me-re
W dormitor = dormitorio | dor-mi-TOR
W dormitorul = el dormitorio | dor-mi-TO-rul
W baie = baño | BA-ie
W baia = el baño | BA-ia
W bucătărie = cocina | bu-kă-tă-RI-e
W bucătăria = la cocina | bu-kă-tă-RI-a
V Vocabulario: la casa y las habitaciones
D En casa
Maria: Ai o casă? = ¿Tienes una casa?
  > Ai = tienes | o casă = una casa
Elena: Da, am o casă. = Sí, tengo una casa.
  > Da = sí | am o casă = tengo una casa
Maria: Casa are un dormitor, o bucătărie și o baie? = ¿La casa tiene un dormitorio, una cocina y un baño?
  > Casa = la casa | are = tiene | un dormitor = un dormitorio | o bucătărie = una cocina | și = y | o baie = un baño
Elena: Da. Casa are două camere și o baie. = Sí. La casa tiene dos habitaciones y un baño.
  > Casa = la casa | are = tiene | două camere = dos habitaciones | o baie = un baño
Mihai: Eu am un apartament. Apartamentul are două camere. = Tengo un apartamento. El apartamento tiene dos habitaciones.
  > Eu am = yo tengo | un apartament = un apartamento | Apartamentul = el apartamento | are două camere = tiene dos habitaciones
Q ¿Qué significa «casa»?
+ La casa. :: El artículo definido está unido al nombre.
- Una casa. :: «O casă» significa «una casa».
- El apartamento. :: «Apartamentul» significa «el apartamento».
Q ¿Cómo se dice «el dormitorio»?
+ dormitorul :: «Dormitor» más el artículo «-ul» forma «dormitorul».
- dormitor :: Significa «dormitorio» sin el artículo definido.
- camera :: Significa «la habitación».
R Apartamentul are două camere. :: Elige la traducción.
+ El apartamento tiene dos habitaciones. :: «Apartamentul» es definido y «camere» es plural.
- Un apartamento tiene dos habitaciones. :: Para «un apartamento» se dice «un apartament».
- El apartamento tiene un dormitorio. :: «Dormitor» es «dormitorio».
H Casa are o ___. :: Completa «La casa tiene una cocina».
+ bucătărie :: «O bucătărie» significa «una cocina».
- baie :: Significa «baño».
- cameră :: Significa «habitación».
H Am un ___. :: Completa «Tengo un apartamento».
+ apartament :: Después de «un» va «apartament».
- apartamentul :: Es «el apartamento», definido.
- bucătărie :: Es «cocina» y es femenino.
A Casa are două camere. :: ¿Cuántas habitaciones tiene la casa?
+ Dos. :: «Două» significa «dos» con este nombre femenino.
- Una. :: «Una» se dice «o» antes de un nombre.
- Diez. :: «Zece» significa «diez».
O o casă :: una casa :: «O» es el artículo indefinido y «casă», casa.
X Escribe «la habitación» en rumano. :: camera :: En «cameră», el artículo femenino cambia «-ă» por «-a».

@ 4 | Unde este? | ¿Dónde está?
I Preguntamos dónde están los muebles y usamos preposiciones sencillas. En varias expresiones de lugar, el nombre aparece sin artículo definido.
E Lugar :: **Pe masă** significa «sobre la mesa» y **sub pat**, «debajo de la cama». En estas expresiones de lugar se omite el artículo que sí aparece en el sujeto: **masa este în bucătărie** («la mesa está en la cocina»).
E «Unde» :: **Unde este…?** significa «¿Dónde está…?». La respuesta conserva el nombre y añade una ubicación, como **în dormitor** («en el dormitorio») o **lângă dulap** («junto al armario»).

| pe | sobre; encima de
| sub | debajo de
| lângă | junto a; al lado de
| în | en; dentro de
W masă = mesa | MA-să
W masa = la mesa | MA-sa
W scaun = silla | skaun
W scaunul = la silla | ska-unul
W pat = cama | pat
W patul = la cama | pa-tul
W canapea = sofá | ka-na-PE-a
W canapeaua = el sofá | ka-na-PE-aua
W dulap = armario | du-LAP
W dulapul = el armario | du-LA-pul
W lampă = lámpara | LAM-pă
W lampa = la lámpara | LAM-pa
W pe = sobre; encima de | pe
W sub = debajo de | sub
W lângă = junto a; al lado de | LÎN-gă
W unde = dónde | UN-de
W carte = libro | KAR-te
W cartea = el libro | KAR-te-a

V Vocabulario: muebles y ubicación
D ¿Dónde están las cosas?
Elena: Unde este cartea? = ¿Dónde está el libro?
  > Unde este = dónde está | cartea = el libro
Paul: Cartea este pe masă. = El libro está sobre la mesa.
  > Cartea = el libro | este = está | pe masă = sobre la mesa
Elena: Unde este geanta? = ¿Dónde está el bolso?
  > Unde este = dónde está | geanta = el bolso
Paul: Geanta este sub pat. = El bolso está debajo de la cama.
  > Geanta = el bolso | este = está | sub pat = debajo de la cama
Elena: Unde este scaunul? = ¿Dónde está la silla?
  > Unde este = dónde está | scaunul = la silla
Paul: Scaunul este lângă dulap. = La silla está junto al armario.
  > Scaunul = la silla | este = está | lângă dulap = junto al armario
Q ¿Qué significa «sub»?
+ Debajo de. :: Indica que algo está bajo otra cosa.
- Sobre. :: «Pe» significa «sobre».
- Junto a. :: «Lângă» significa «junto a».
Q ¿Qué significa «Unde este cartea?»?
+ ¿Dónde está el libro? :: «Unde» significa «dónde».
- ¿Qué es el libro? :: «Ce» significa «qué».
- ¿Quién tiene el libro? :: «Cine» significa «quién».
R Geanta este sub pat. :: Elige la traducción.
+ El bolso está debajo de la cama. :: «Sub pat» es «debajo de la cama».
- El bolso está sobre la cama. :: «Pe pat» significa «sobre la cama».
- La silla está debajo de la cama. :: «Scaunul» significa «la silla».
H Cartea este ___ masă. :: Completa «El libro está sobre la mesa».
+ pe :: Es la preposición «sobre».
- sub :: Significa «debajo de».
- lângă :: Significa «junto a».
H Scaunul este lângă ___. :: Completa «La silla está junto al armario».
+ dulap :: Es «armario» sin artículo después de la preposición.
- patul :: Significa «la cama».
- canapeaua :: Significa «el sofá».
A Canapeaua este lângă dulap. :: ¿Dónde está el sofá?
+ Junto al armario. :: «Lângă dulap» indica su ubicación.
- Debajo de la cama. :: Eso sería «sub pat».
- Sobre la mesa. :: Eso sería «pe masă».
O Cartea este pe masă :: El libro está sobre la mesa :: Después de «pe», esta expresión usa «masă» sin artículo.
X Escribe en rumano: «La lámpara está sobre la mesa». :: Lampa este pe masă. :: «Pe masă» es «sobre la mesa».

@ 4 | O cameră frumoasă | Una habitación bonita
I Los adjetivos suelen ir después del nombre y concuerdan con él en género y número. Practicamos con tamaños y colores.
E Concordancia :: El adjetivo va normalmente después del nombre: **o cameră mică** («una habitación pequeña»). Cambia para concordar con el nombre: **un dormitor mic**, **o cameră mică**.
E Formas :: Algunos adjetivos tienen formas distintas: **alb, albă, albi, albe** («blanco/a/os/as»). **Mare** significa «grande» para masculino y femenino singular; en plural cambia a **mari**.
B «Blanco» | Género y número | Forma
| Masculino singular | alb
| Femenino singular | albă
| Masculino plural | albi
| Femenino plural | albe
W mare = grande (singular masculino o femenino) | MA-re
W mari = grandes | mar
W mic = pequeño (masculino singular) | mik
W mică = pequeña (femenino singular) | MI-că
W mici = pequeños; pequeñas | mich
W alb = blanco (masculino singular) | alb
W albă = blanca (femenino singular) | AL-bă
W albi = blancos | AL-bi
W albe = blancas | AL-be
W roșu = rojo (masculino singular) | RO-shu
W roșie = roja (femenino singular) | RO-shi-e
W roșii = rojos; rojas | RO-shi
V Vocabulario: tamaños y colores
D La habitación
Ana: Casa ta este mare? = ¿Tu casa es grande?
  > Casa ta = tu casa | este mare = es grande
Elena: Da. Casa mea este mare și albă. = Sí. Mi casa es grande y blanca.
  > Casa mea = mi casa | este mare = es grande | și albă = y blanca
Ana: Dormitorul este mic? = ¿El dormitorio es pequeño?
  > Dormitorul = el dormitorio | este mic = es pequeño
Elena: Nu. Camera este mică și roșie. = No. La habitación es pequeña y roja.
  > Nu = no | Camera = la habitación | este mică = es pequeña | și roșie = y roja
Q ¿Qué adjetivo concuerda con «casa»?
+ albă :: «Casă» es femenino singular.
- alb :: Es masculino singular.
- albi :: Es masculino plural.
Q ¿Qué forma es «grande» con un nombre plural?
+ mari :: «Mare» cambia a «mari» en plural.
- mare :: Es la forma singular.
- mică :: Significa «pequeña».
R Dormitorul este mic. :: Elige la traducción.
+ El dormitorio es pequeño. :: «Mic» concuerda con «dormitorul».
- La habitación es pequeña. :: «Camera este mică» significa eso.
- El dormitorio es rojo. :: «Roșu» significa «rojo».
H Casa este ___ și roșie. :: Completa «La casa es grande y roja».
+ mare :: «Mare» se usa con nombres femeninos singulares.
- mari :: Es la forma plural.
- mic :: Es masculino singular y significa «pequeño».
H Dormitorul este ___. :: Completa «El dormitorio es pequeño».
+ mic :: «Dormitorul» es masculino singular.
- mică :: Es femenino singular.
- mici :: Es plural.
A Camera este mică și roșie. :: ¿Qué significa?
+ La habitación es pequeña y roja. :: Los dos adjetivos concuerdan con «camera».
- La habitación es grande y blanca. :: «Mare și albă» significa eso.
- El dormitorio es pequeño y rojo. :: «Dormitorul» significa «el dormitorio».
O o cameră mică :: una habitación pequeña :: «Mică» concuerda con el nombre femenino singular «cameră».
X Escribe «una casa grande» en rumano. :: o casă mare :: «Mare» conserva la misma forma con «casă».
