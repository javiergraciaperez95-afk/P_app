@ 2 | De unde ești? | ¿De dónde eres?
I Preguntamos por el origen y decimos de qué país somos. En rumano, «a fi» significa «ser» o «estar»; aquí indica origen e identidad.
E Origen :: **De unde ești?** significa «¿De dónde eres?». Se responde **Sunt din Spania** («Soy de España»). «Din» introduce el país de origen.
E Nacionalidad :: Los gentilicios rumanos se escriben con minúscula, como en español, pero el español escribe con mayúscula «español». El gentilicio concuerda con la persona: **spaniol** para un hombre y **spaniolă** para una mujer.
B El presente de «a fi» | Persona | Forma
| eu | sunt
| tu | ești
| el / ea | este
| noi | suntem
| voi | sunteți
| ei / ele | sunt
W de unde = de dónde | de UN-de
W din = de; desde (origen) | din
W ești = eres; estás | ești
W el = él | el
W ea = ella | ea
W noi = nosotros; nosotras | noi
W voi = vosotros; vosotras; ustedes | voi
W ei = ellos | ei
W ele = ellas | ele
W suntem = somos; estamos | sun-TEM
W sunteți = sois; son; están (ustedes) | sun-TEȚ
W româncă = rumana (mujer) | ro-MÂN-că
W spaniol = español (hombre) | spa-NI-ol
W spaniolă = española (mujer) | spa-ni-O-lă
W și = y; también | shi
W dar = pero | dar
V Vocabulario: origen y nacionalidad
D De dónde somos
Elena: Salut, Ana! De unde ești? = ¡Hola, Ana! ¿De dónde eres?
  > Salut = hola informal | De unde ești = ¿de dónde eres?
Ana: Sunt din Spania. Eu sunt spaniolă. = Soy de España. Soy española.
  > Sunt din Spania = soy de España | Eu sunt spaniolă = soy española
Elena: Și tu? = ¿Y tú?
  > Și = y | tu = tú
Ana: Dar tu? = ¿Y tú?
  > Dar = pero | tu = tú
Elena: Sunt din România. Eu sunt româncă. = Soy de Rumanía. Soy rumana.
  > Sunt din România = soy de Rumanía | Eu sunt româncă = soy rumana
Q ¿Qué significa «De unde ești?»?
+ ¿De dónde eres? :: Pregunta por el origen.
- ¿Quién eres? :: «Cine?» significa «quién».
- ¿Dónde estás? :: «Unde ești?» pregunta dónde estás.
Q ¿Cómo se dice «española»?
+ spaniolă :: La forma femenina termina en «ă».
- spaniol :: Es la forma masculina.
- româncă :: Significa «rumana».
R Sunt din Spania. :: Elige la traducción.
+ Soy de España. :: «Din» introduce el origen.
- Estoy en España. :: Para «en» se usa «în».
- Soy española. :: Esa traducción corresponde a «Sunt spaniolă».
H Tu ___ din Italia. :: Completa «Tú eres de Italia».
+ ești :: Es la forma de «a fi» para «tu».
- sunt :: Se usa con «eu» y «ei/ele».
- suntem :: Se usa con «noi».
H Noi ___ din România. :: Completa «Nosotros somos de Rumanía».
+ suntem :: Es la forma de «a fi» para «noi».
- sunteți :: Se usa con «voi».
- este :: Se usa con «el/ea».
A El este din Germania. :: ¿Qué significa?
+ Él es de Alemania. :: «El» es «él» y «din» indica origen.
- Ella es de Alemania. :: Para «ella» se usa «ea».
- Ellos son de Alemania. :: Para «ellos» se usa «ei».
O Noi suntem din Italia :: Somos de Italia :: «Noi» es «nosotros» y «suntem», «somos».
X Escribe en rumano: «¿De dónde eres?» :: De unde ești? :: La pregunta empieza con «de unde».

@ 2 | Ce limbi vorbești? | ¿Qué idiomas hablas?
I Los nombres de los idiomas se escriben con minúscula en rumano. Aprendemos también el presente de «a vorbi», hablar.
E Idiomas :: **Limba română** es «el idioma rumano»; **limba spaniolă**, «el idioma español». «Limba» es la forma definida de «limbă» (lengua, idioma).
E Hablar :: El verbo **a vorbi** cambia según la persona. En rumano se suele omitir el pronombre cuando la forma verbal ya indica quién habla.
B El presente de «a vorbi» | Persona | Forma
| eu | vorbesc
| tu | vorbești
| el / ea | vorbește
| noi | vorbim
| voi | vorbiți
| ei / ele | vorbesc
W limbă = lengua; idioma | LIM-bă
W limba = la lengua; el idioma | LIM-ba
W limbi = lenguas; idiomas | limbi
W ce = qué | che
W vorbesc = hablo; hablan | vor-BESK
W vorbești = hablas | vor-BESHT
W vorbește = habla | vor-BESH-te
W vorbim = hablamos | vor-BIM
W vorbiți = habláis; hablan (ustedes) | vor-BIȚ
W engleză = lengua inglesa; inglés | en-GLE-ză
W franceză = lengua francesa; francés | fran-CE-ză
W germană = lengua alemana; alemán | ger-MA-nă
W puțin = un poco | pu-TSIN
V Vocabulario: idiomas y «hablar»
D Los idiomas de Ana
Mihai: Ce limbi vorbești? = ¿Qué idiomas hablas?
  > Ce limbi = qué idiomas | vorbești = hablas
Ana: Vorbesc limba română și limba spaniolă. = Hablo rumano y español.
  > Vorbesc = hablo | limba română = el idioma rumano | și = y | limba spaniolă = el idioma español
Mihai: Vorbești limba engleză? = ¿Hablas inglés?
  > Vorbești = hablas | limba engleză = el idioma inglés
Ana: Da, vorbesc limba engleză. Vorbesc puțin. = Sí, hablo inglés. Hablo un poco.
  > Da = sí | vorbesc = hablo | limba engleză = el idioma inglés | puțin = un poco
Mihai: Dar limba franceză? = ¿Y el francés?
  > Dar = pero; y | limba franceză = el idioma francés
Ana: Nu vorbesc limba franceză. = No hablo francés.
  > Nu = no | vorbesc = hablo | limba franceză = el idioma francés
Q ¿Cómo se dice «idiomas»?
+ limbi :: Es el plural de «limbă».
- limba :: Es la forma definida singular.
- limbă :: Es singular sin artículo definido.
Q ¿Qué forma de «a vorbi» va con «tu»?
+ vorbești :: Corresponde a «tú hablas».
- vorbim :: Corresponde a «nosotros hablamos».
- vorbiți :: Corresponde a «vosotros habláis» o «ustedes hablan».
R Eu vorbesc limba spaniolă. :: Elige la traducción.
+ Hablo el idioma español. :: «Vorbesc» significa «hablo».
- Hablas el idioma español. :: «Vorbești» significa «hablas».
- Hablo el idioma francés. :: «Franceză» significa «francés».
H Tu ___ limba engleză? :: Completa «¿Hablas inglés?».
+ vorbești :: Es la forma para «tu».
- vorbesc :: Es la forma para «eu» y «ei/ele».
- vorbește :: Es la forma para «el/ea».
H Noi ___ limba română. :: Completa «Hablamos rumano».
+ vorbim :: Es la forma para «noi».
- vorbiți :: Es la forma para «voi».
- vorbește :: Es la forma para «el/ea».
A El vorbește limba germană. :: ¿Qué idioma habla?
+ Alemán. :: «Limba germană» es el idioma alemán.
- Inglés. :: «Limba engleză» es el idioma inglés.
- Francés. :: «Limba franceză» es el idioma francés.
O Eu vorbesc și tu vorbești :: Yo hablo y tú hablas :: Las terminaciones cambian según la persona.
X Escribe en rumano: «Hablo francés». :: Vorbesc limba franceză. :: «Vorbesc» corresponde a «yo hablo».

@ 2 | Ce profesie ai? | ¿Qué profesión tienes?
I Decimos a qué nos dedicamos. Con «a avea» (tener), el rumano forma la pregunta cotidiana «Ce profesie ai?» («¿Qué profesión tienes?»).
E Profesiones :: Después de **sunt** («soy»), la profesión suele ir sin artículo: **Sunt profesor** («Soy profesor»). Las profesiones con forma masculina y femenina concuerdan con la persona.
E Tener :: **A avea** significa «tener». Sus formas son **am, ai, are, avem, aveți, au**. En **am o profesie**, el artículo **o** acompaña a un nombre femenino; **un** acompaña a uno masculino.
B El presente de «a avea» | Persona | Forma
| eu | am
| tu | ai
| el / ea | are
| noi | avem
| voi | aveți
| ei / ele | au
W profesie = profesión | pro-fe-SI-e
W ce profesie = qué profesión | che pro-fe-SI-e
W am = tengo | am
W ai = tienes | ai
W are = tiene | A-re
W avem = tenemos | a-VEM
W aveți = tenéis; tienen (ustedes) | a-VEȚ
W au = tienen | au
W profesor = profesor | pro-fe-SOR
W profesoară = profesora | pro-fe-SOA-ră
W student = estudiante (hombre) | stu-DENT
W studentă = estudiante (mujer) | stu-DEN-tă
W medic = médico; médica | me-DIK | La misma forma sirve para hombres y mujeres.
W o = una (artículo femenino) | o
W un = un (artículo masculino) | un
W loc = lugar | lok
W muncă = trabajo | MUN-că
W loc de muncă = lugar de trabajo; empleo | lok de MUN-că
V Vocabulario: profesiones y trabajo
D Profesión y trabajo
Elena: Ce profesie ai, Paul? = ¿Qué profesión tienes, Paul?
  > Ce profesie = qué profesión | ai = tienes
Paul: Sunt profesor. Am o profesie. = Soy profesor. Tengo una profesión.
  > Sunt profesor = soy profesor | Am o profesie = tengo una profesión
Elena: Eu sunt studentă. Nu am un loc de muncă. = Soy estudiante. No tengo empleo.
  > Eu sunt studentă = soy estudiante | Nu am = no tengo | un loc de muncă = un empleo
Paul: Ai un loc de muncă? = ¿Tienes empleo?
  > Ai = tienes | un loc de muncă = un empleo
Elena: Nu. = No.
  > Nu = no
Q ¿Qué significa «Sunt medic»?
+ Soy médico o médica. :: «Medic» sirve para ambos géneros y va sin artículo aquí.
- Tengo un médico. :: «Am» significa «tengo».
- Soy estudiante. :: «Student» es estudiante.
Q ¿Qué forma de «a avea» corresponde a «tu»?
+ ai :: Significa «tienes».
- am :: Significa «tengo».
- avem :: Significa «tenemos».
R Sunt profesoară. :: Elige la traducción.
+ Soy profesora. :: La profesión aparece en femenino.
- Soy profesor. :: «Profesor» es la forma masculina.
- Tengo una profesora. :: «Sunt» significa «soy».
H El ___ o profesie. :: Completa «Él tiene una profesión».
+ are :: Es la forma para «el».
- am :: Es la forma para «eu».
- ai :: Es la forma para «tu».
H Noi ___ un loc de muncă. :: Completa «Tenemos un empleo».
+ avem :: Es la forma para «noi».
- au :: Es la forma para «ei/ele».
- aveți :: Es la forma para «voi».
A Voi aveți un loc de muncă. :: ¿Qué significa?
+ Ustedes tienen un empleo. :: «Aveți» acompaña a «voi».
- Nosotros tenemos un empleo. :: Esa frase sería «Noi avem».
- Tú tienes un empleo. :: Esa frase sería «Tu ai».
O Am o profesie :: Tengo una profesión :: «Am» es la forma de «a avea» para «eu».
X Escribe en rumano: «Tengo un empleo». :: Am un loc de muncă. :: «Loc de muncă» significa «empleo».
