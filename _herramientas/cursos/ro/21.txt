@ 21 | Păreri și argumente | Opiniones y argumentos
I Para dar una opinión, puedes usar **după părerea mea** («en mi opinión») o **eu cred că** («creo que»). Después añade una razón.
E Opinar :: **Părere** significa «opinión» o «parecer». **Sunt de acord** expresa acuerdo; **nu sunt de acord** expresa desacuerdo.
E Matizar :: **În parte** limita el acuerdo; **totuși** introduce una idea que contrasta con la anterior.
W părere = opinión; parecer | pă-RE-re
W părerea = la opinión; el parecer | pă-RE-re-a
W în opinia mea = en mi opinión | în o-PI-ni-a ME-a
W după părerea mea = según mi opinión | DU-pă pă-RE-re-a ME-a
W cred = creo | KRED
W că = que | KĂ
W consider = considero | kon-si-DER
W argument = argumento | ar-gu-MENT
W argumentul = el argumento | ar-gu-MEN-tul
W sunt de acord = estoy de acuerdo | sunt de a-KORD
W nu sunt de acord = no estoy de acuerdo | nu sunt de a-KORD
W în parte = en parte | în PAR-te
W deoarece = porque; ya que | de-o-a-RE-che
W totuși = aun así; sin embargo | TO-tuș
W lectură = lectura | lek-TU-ră
W lectura = la lectura | lek-TU-ra
W lecturii = de la lectura | lek-TU-ri-i
W util = útil (masculino) | u-TIL
W utilă = útil (femenino) | u-TI-lă
W interesantă = interesante (femenino) | in-te-re-SAN-tă
V Vocabulario: expresar una opinión
D Una opinión sobre la lectura
Ana: După părerea mea, lectura este utilă. = En mi opinión, la lectura es útil.
  > După părerea mea = en mi opinión | lectura = la lectura | este utilă = es útil
Mihai: Sunt de acord, deoarece lectura este interesantă. = Estoy de acuerdo, porque la lectura es interesante.
  > Sunt de acord = estoy de acuerdo | deoarece = porque | lectura este interesantă = la lectura es interesante
Ana: Totuși, eu consider lectura utilă. = Aun así, considero útil la lectura.
  > Totuși = aun así | eu consider = yo considero | lectura utilă = la lectura útil
Mihai: Cred că părerea ta este bună. = Creo que tu opinión es buena.
  > Cred că = creo que | părerea ta = tu opinión | este bună = es buena
T Una opinión breve
- În opinia mea, lectura este utilă. = En mi opinión, la lectura es útil.
  > În opinia mea = en mi opinión | lectura este utilă = la lectura es útil
- Eu cred că lectura este interesantă. = Creo que la lectura es interesante.
  > Eu cred că = yo creo que | lectura este interesantă = la lectura es interesante
- Sunt de acord în parte. = Estoy de acuerdo en parte.
  > Sunt de acord = estoy de acuerdo | în parte = en parte
- Totuși, consider lectura utilă. = Aun así, considero útil la lectura.
  > Totuși = aun así | consider lectura utilă = considero útil la lectura
Q ¿Qué significa «părerea»?
+ La opinión; el parecer. :: Es el nombre con artículo definido.
- La lectura. :: «Lectura» significa «la lectura».
- El argumento. :: «Argumentul» significa «el argumento».
R După părerea mea, lectura este utilă. :: Elige la traducción.
+ En mi opinión, la lectura es útil. :: La expresión introduce una valoración personal.
- En mi opinión, la lectura es interesante. :: «Utilă» significa «útil».
- No estoy de acuerdo con la lectura. :: La frase expresa una opinión, no un desacuerdo.
H Lectura este ___. :: Completa «La lectura es útil».
+ utilă :: Es la forma femenina que concuerda con «lectura».
- util :: Es la forma masculina.
- interesantă :: Significa «interesante», no «útil».
A Sunt de acord în parte. :: ¿Qué expresa la persona?
+ Está de acuerdo, pero solo parcialmente. :: «În parte» significa «en parte».
- No está de acuerdo con nada. :: «Sunt de acord» expresa acuerdo.
- Considera la lectura aburrida. :: La frase no menciona que sea aburrida.
O după părerea mea :: en mi opinión :: La expresión introduce un punto de vista.
X Escribe en rumano: «Creo que la lectura es interesante». :: Cred că lectura este interesantă. :: «Cred că» significa «creo que».
Q ¿Qué expresión significa «aun así»?
+ totuși :: Introduce un contraste o una reserva.
- deoarece :: Significa «porque».
- în parte :: Significa «en parte».
R Nu sunt de acord. :: Elige la traducción.
+ No estoy de acuerdo. :: La expresión niega el acuerdo.
- Estoy de acuerdo. :: Esa expresión es «sunt de acord».
- Estoy de acuerdo en parte. :: Para eso se añade «în parte».

@ 21 | Argumente și consecințe | Argumentos y consecuencias
I Una opinión gana claridad cuando explicas el motivo, das un ejemplo y mencionas el resultado o la consecuencia.
E Conectores :: **De exemplu** introduce un caso concreto; **în plus** añade información y **pe de altă parte** presenta otro aspecto.
E Argumentar :: Un argumento explica por qué una idea parece razonable. **Însă** introduce una objeción o un contraste.
W de exemplu = por ejemplo | de eg-ZEM-plu
W în plus = además | în PLUS
W pe de altă parte = por otra parte | pe de AL-tă PAR-te
W însă = sin embargo; pero | în-SĂ
W motiv = motivo; razón | mo-TIV
W motivul = el motivo; la razón | mo-TI-vul
W avantaj = ventaja | a-van-TAJ
W avantajul = la ventaja | a-van-TA-jul
W dezavantaj = desventaja | de-za-van-TAJ
W dezavantajul = la desventaja | de-za-van-TA-jul
W rezultat = resultado | re-zul-TAT
W rezultatul = el resultado | re-zul-TA-tul
W consecință = consecuencia | kon-se-KIN-tsă
W consecința = la consecuencia | kon-se-KIN-tsa
W există = existe; hay | e-GZIS-tă
W timpul = el tiempo | TIM-pul
W fi = ser; estar | FI
W limitat = limitado (masculino) | li-mi-TAT
W clar = claro (masculino) | KLAR
W clară = clara (femenino) | KLA-ră
V Vocabulario: razones y resultados
D Dos aspectos de una idea
Ana: Care este avantajul lecturii? = ¿Cuál es la ventaja de la lectura?
  > Care este = cuál es | avantajul lecturii = la ventaja de la lectura
Mihai: De exemplu, lectura este utilă. = Por ejemplo, la lectura es útil.
  > De exemplu = por ejemplo | lectura este utilă = la lectura es útil
Ana: Există și un dezavantaj? = ¿Hay también una desventaja?
  > Există = hay | și = también | un dezavantaj = una desventaja
Mihai: Da. Pe de altă parte, timpul poate fi limitat. = Sí. Por otra parte, el tiempo puede ser limitado.
  > Da = sí | Pe de altă parte = por otra parte | timpul poate fi limitat = el tiempo puede ser limitado
T Razones y consecuencias
- De exemplu, un motiv este clar. = Por ejemplo, un motivo está claro.
  > De exemplu = por ejemplo | un motiv = un motivo | este clar = está claro
- În plus, există un avantaj. = Además, hay una ventaja.
  > În plus = además | există = hay | un avantaj = una ventaja
- Pe de altă parte, există un dezavantaj. = Por otra parte, hay una desventaja.
  > Pe de altă parte = por otra parte | există = hay | un dezavantaj = una desventaja
- Însă rezultatul nu este clar. = Sin embargo, el resultado no está claro.
  > Însă = sin embargo | rezultatul = el resultado | nu este clar = no está claro
- Consecința este clară. = La consecuencia está clara.
  > Consecința = la consecuencia | este clară = está clara
Q ¿Qué significa «avantajul»?
+ La ventaja. :: Es «avantaj» con artículo definido.
- El motivo. :: «Motivul» significa «el motivo».
- El resultado. :: «Rezultatul» significa «el resultado».
R Pe de altă parte, există un dezavantaj. :: Elige la traducción.
+ Por otra parte, hay una desventaja. :: «Există» significa «hay».
- Además, hay una ventaja. :: Eso se dice «În plus, există un avantaj».
- Sin embargo, el resultado está claro. :: La frase menciona una desventaja.
H De exemplu, un ___ este clar. :: Completa con «motivo».
+ motiv :: Es la palabra que introduce una razón.
- rezultat :: Significa «resultado».
- avantaj :: Significa «ventaja».
A Consecința este clară. :: ¿Qué está claro?
+ La consecuencia. :: «Consecința» es «la consecuencia».
- El motivo. :: «Motivul» significa «el motivo».
- La ventaja. :: «Avantajul» significa «la ventaja».
O în plus :: además :: El conector añade otro argumento.
X Escribe en rumano: «Por otra parte, hay una ventaja». :: Pe de altă parte, există un avantaj. :: «Există» expresa «hay».
Q ¿Qué conector significa «por ejemplo»?
+ de exemplu :: Introduce un caso concreto.
- în plus :: Significa «además».
- însă :: Significa «sin embargo».
R Însă rezultatul nu este clar. :: Elige la traducción.
+ Sin embargo, el resultado no está claro. :: «Însă» marca contraste.
- Además, la consecuencia está clara. :: Eso incluiría «în plus» y «consecința».
- Por ejemplo, hay un motivo. :: Eso incluiría «de exemplu» y «motiv».

@ 21 | Preferințe și compromisuri | Preferencias y acuerdos
I En una conversación puedes comparar opciones, proponer una solución y aceptar un compromiso que tenga en cuenta más de una preferencia.
E Preferencias :: **Prefer** significa «prefiero» y **preferi**, «prefieres». **Mai degrabă** indica una preferencia relativa: «más bien» o «preferiblemente».
E Negociar :: **Propun** presenta una propuesta. **Deocamdată** limita la decisión al momento actual: «por ahora».
W prefer = prefiero | pre-FER
W preferi = prefieres | pre-FER
W preferință = preferencia | pre-fe-RIN-tsă
W preferința = la preferencia | pre-fe-RIN-tsa
W variantă = opción; alternativa | va-ri-AN-tă
W varianta = la opción; la alternativa | va-ri-AN-ta
W opțiune = opción | op-TSI-u-ne
W soluție = solución | so-LU-tsi-e
W soluția = la solución | so-LU-tsi-a
W compromis = compromiso; acuerdo intermedio | kom-pro-MIS
W propunere = propuesta | pro-PU-ne-re
W propunerea = la propuesta | pro-PU-ne-re-a
W propun = propongo | pro-PUN
W aleg = elijo | a-LEJ
W alegem = elegimos | a-LE-jem
W deocamdată = por ahora | de-o-kam-da-TĂ
W mai degrabă = más bien; preferiblemente | mai de-GRA-bă
W fiindcă = porque; dado que | FI-ind-kă
W comod = cómodo (masculino) | ko-MOD
W comodă = cómoda (femenino) | ko-MO-dă
W simplă = sencilla (femenino) | SIM-plă
V Vocabulario: preferencias y propuestas
D Elegir una opción
Ana: Ce variantă preferi? = ¿Qué opción prefieres?
  > Ce variantă = qué opción | preferi = prefieres
Mihai: Prefer trenul, fiindcă este comod. = Prefiero el tren porque es cómodo.
  > Prefer = prefiero | trenul = el tren | fiindcă = porque | este comod = es cómodo
Ana: Propun o soluție simplă. = Propongo una solución sencilla.
  > Propun = propongo | o soluție simplă = una solución sencilla
Mihai: Deocamdată, alegem această variantă. = Por ahora, elegimos esta opción.
  > Deocamdată = por ahora | alegem = elegimos | această variantă = esta opción
T Una decisión compartida
- Prefer trenul, fiindcă este comod. = Prefiero el tren porque es cómodo.
  > Prefer trenul = prefiero el tren | fiindcă este comod = porque es cómodo
- Propunerea este simplă. = La propuesta es sencilla.
  > Propunerea = la propuesta | este simplă = es sencilla
- Deocamdată, alegem soluția. = Por ahora, elegimos la solución.
  > Deocamdată = por ahora | alegem soluția = elegimos la solución
- Mai degrabă aleg această opțiune. = Más bien elijo esta opción.
  > Mai degrabă = más bien | aleg = elijo | această opțiune = esta opción
- Un compromis poate fi util. = Un compromiso puede ser útil.
  > Un compromis = un compromiso | poate fi util = puede ser útil
Q ¿Qué significa «deocamdată»?
+ Por ahora. :: Limita la decisión al momento presente.
- Más bien. :: «Mai degrabă» significa «más bien».
- Porque. :: «Fiindcă» significa «porque».
R Propun o soluție simplă. :: Elige la traducción.
+ Propongo una solución sencilla. :: «Propun» significa «propongo».
- Elijo una opción cómoda. :: Eso se dice «Aleg o opțiune comodă».
- Prefiero el tren por ahora. :: La oración propone una solución.
H Ce variantă ___? :: Completa «¿Qué opción prefieres?».
+ preferi :: Es la forma de «tú prefieres».
- prefer :: Significa «yo prefiero».
- propun :: Significa «propongo».
A Deocamdată, alegem soluția. :: ¿Qué deciden hacer?
+ Elegir la solución por ahora. :: «Alegem» significa «elegimos».
- Proponer una solución sencilla. :: Eso se dice «Propun o soluție simplă».
- Preferir el tren. :: Eso se dice «Prefer trenul».
O un compromis util :: un compromiso útil :: Un compromiso puede combinar preferencias.
X Escribe en rumano: «Prefiero el tren porque es cómodo». :: Prefer trenul, fiindcă este comod. :: «Fiindcă» introduce la razón.
Q ¿Qué significa «preferința»?
+ La preferencia. :: Es «preferință» con artículo definido.
- La propuesta. :: «Propunerea» significa «la propuesta».
- La solución. :: «Soluția» significa «la solución».
R Mai degrabă aleg această opțiune. :: Elige la traducción.
+ Más bien elijo esta opción. :: «Mai degrabă» expresa preferencia relativa.
- Por ahora elegimos la solución. :: Eso se dice «Deocamdată, alegem soluția».
- Propongo una solución sencilla. :: Eso se dice «Propun o soluție simplă».
