@ 7 | Haine și încălțăminte | Ropa y calzado
I Aprendemos prendas comunes. En rumano, algunas prendas se suelen nombrar en plural, como «pantaloni» (pantalones) y «pantofi» (zapatos).
E Ropa :: Los nombres también forman su plural: **bluză → bluze**, **rochie → rochii**, **fustă → fuste**. El artículo definido vuelve a pegarse al nombre: **tricou → tricoul**, «camiseta → la camiseta».
E Singular y plural :: **Pantof** es «zapato» y **pantofi**, «zapatos». Para hablar de los pantalones, el rumano suele usar directamente el plural **pantaloni**.

W tricou = camiseta | tri-KOU
W tricoul = la camiseta | tri-KOUl
W tricouri = camisetas | tri-KOU-ri
W bluză = blusa | BLU-ză
W bluza = la blusa | BLU-za
W bluze = blusas | BLU-ze
W cămașă = camisa | ka-MA-shă
W rochie = vestido | RO-ki-e
W rochia = el vestido | RO-ki-a
W rochii = vestidos | RO-kii
W fustă = falda | FUS-tă
W fusta = la falda | FUS-ta
W fuste = faldas | FUS-te
W pantalon = pantalón | pan-ta-LON
W pantaloni = pantalones | pan-ta-LO-ni
W pantof = zapato | pan-TOF
W pantofi = zapatos | pan-TO-fi
W pantofii = los zapatos | pan-TO-fii
W pulover = jersey | pu-lo-VER

V Vocabulario: prendas de vestir
D En el armario
Maria: Ai haine? = ¿Tienes ropa?
  > Ai = tienes | haine = ropa
Elena: Da. Am un tricou și o bluză. = Sí. Tengo una camiseta y una blusa.
  > Da = sí | Am = tengo | un tricou = una camiseta | o bluză = una blusa
Maria: Ai și o rochie? = ¿Tienes también un vestido?
  > Ai = tienes | și = también | o rochie = un vestido
Elena: Nu, am o fustă. = No, tengo una falda.
  > Nu = no | am = tengo | o fustă = una falda
Q ¿Qué significa «pantaloni»?
+ Pantalones. :: En rumano esta prenda suele nombrarse en plural.
- Zapatos. :: «Pantofi» significa «zapatos».
- Falda. :: «Fustă» significa «falda».
Q ¿Cuál es el singular de «pantofi»?
+ pantof :: Significa «zapato».
- pantaloni :: Significa «pantalones».
- pulover :: Significa «jersey».
R Am o cămașă și un pulover. :: Elige la traducción.
+ Tengo una camisa y un jersey. :: «Cămașă» es «camisa».
- Tengo una falda y un jersey. :: «Fustă» significa «falda».
- Tienes una camisa y un jersey. :: «Am» significa «tengo».
H Am o ___. :: Completa «Tengo una falda».
+ fustă :: «O fustă» significa «una falda».
- geacă :: Significa «chaqueta».
- rochie :: Significa «vestido».
H Am un ___. :: Completa «Tengo un jersey».
+ pulover :: «Un pulover» significa «un jersey».
- pantaloni :: Significa «pantalones» y es plural.
- geacă :: Es un nombre femenino.
A Am pantofi. :: ¿Qué tengo?
+ Zapatos. :: «Pantofi» significa «zapatos».
- Calcetines. :: «Șosete» significa «calcetines».
- Pantalones. :: «Pantaloni» significa «pantalones».
O o bluză :: una blusa :: «O» acompaña al nombre femenino «bluză».
X Escribe «la chaqueta» en rumano. :: geaca :: «Geacă» más el artículo forma «geaca».

@ 7 | Cât costă? | ¿Cuánto cuesta?
I Preguntamos el precio, la talla y el color. El precio se expresa con «lei» (la moneda rumana) y el verbo «costă».
E Preguntar el precio :: **Cât costă bluza?** significa «¿Cuánto cuesta la blusa?». La respuesta puede ser **Bluza costă douăzeci de lei** («La blusa cuesta veinte lei»).
E Color y concordancia :: Los colores también concuerdan con la prenda: **un tricou albastru**, **o bluză albastră**, **pantofi albaștri**, **rochii albastre**. **Verde** tiene la misma forma en singular y **verzi** en plural.
B «Azul» | Género y número | Forma
| Masculino singular | albastru
| Femenino singular | albastră
| Masculino plural | albaștri
| Femenino plural | albastre
W albastru = azul (masculino singular) | al-BAS-tru
W albastră = azul (femenino singular) | al-BAS-tră
W albaștri = azules (masculino plural) | al-BASH-tri
W albastre = azules (femenino plural) | al-BAS-tre
W verde = verde (singular) | VER-de
W verzi = verdes | verzi
W mărime = talla; tamaño | mă-RI-me
W mărimea = la talla; el tamaño | mă-RI-me-a
W costă = cuesta | KOS-tă
W leu = leu (moneda rumana, singular) | leu
W lei = lei (moneda rumana, plural) | lei
W scump = caro (masculino singular) | skump
W scumpă = cara (femenino singular) | SKUM-pă
W ieftin = barato (masculino singular) | ief-TIN
W ieftină = barata (femenino singular) | ief-TI-nă
W preț = precio | preț
W prețul = el precio | PRE-tsul
W cât = cuánto | kît
V Vocabulario: colores, tallas y precios
D En la tienda
Radu: Vreau o bluză albastră. = Quiero una blusa azul.
  > Vreau = quiero | o bluză albastră = una blusa azul
Elena: Ce mărime? = ¿Qué talla?
  > Ce = qué | mărime = talla
Radu: Mărimea mare, vă rog. = La talla grande, por favor.
  > Mărimea mare = la talla grande | vă rog = por favor
Elena: Bluza costă douăzeci de lei. = La blusa cuesta veinte lei.
  > Bluza = la blusa | costă = cuesta | douăzeci de lei = veinte lei
Radu: Este scumpă? = ¿Es cara?
  > Este = es | scumpă = cara
Elena: Nu, este ieftină. = No, es barata.
  > Nu = no | este = es | ieftină = barata
Q ¿Qué color concuerda con «bluză»?
+ albastră :: «Bluză» es femenino singular.
- albastru :: Es masculino singular.
- albaștri :: Es masculino plural.
Q ¿Qué significa «lei»?
+ lei (moneda rumana, plural). :: Es el plural de «leu».
- precio. :: «Preț» significa «precio».
- talla. :: «Mărime» significa «talla».
R Bluza costă douăzeci de lei. :: Elige la traducción.
+ La blusa cuesta veinte lei. :: «Costă» significa «cuesta».
- La blusa cuesta treinta lei. :: «Treizeci» significa «treinta».
- La chaqueta cuesta veinte lei. :: «Geaca» significa «la chaqueta».
H Rochia este ___. :: Completa «El vestido es caro».
+ scumpă :: «Rochie» es femenino singular.
- scump :: Es masculino singular.
- ieftină :: Significa «barata».
H Pantofii sunt ___. :: Completa «Los zapatos son azules».
+ albaștri :: Concuerda con «pantofii», masculino plural.
- albastră :: Es femenino singular.
- albastre :: Es femenino plural.
A Cât costă geaca? :: ¿Qué pregunta oyes?
+ ¿Cuánto cuesta la chaqueta? :: «Geaca» es «la chaqueta».
- ¿Qué talla es la chaqueta? :: Eso se dice «Ce mărime?».
- ¿De qué color es la chaqueta? :: «Ce culoare?» significa «qué color».
O o bluză albastră :: una blusa azul :: «Albastră» concuerda con el nombre femenino «bluză».
X Escribe en rumano: «El vestido es barato». :: Rochia este ieftină. :: «Ieftină» es la forma femenina de «barato».

@ 7 | Această bluză | Esta blusa
I Los demostrativos indican si algo está cerca o más lejos. En rumano, cambian según el género y el número de la prenda.
E Antes del nombre :: Antes del nombre usamos las formas cortas: **acest tricou** («esta camiseta»), **această bluză**, **acești pantofi**, **aceste rochii**. El nombre va sin el artículo definido. **Tricou** es neutro: el demostrativo tiene forma masculina en singular (**acest tricou**) y femenina en plural (**aceste tricouri**).
E «Este» o «ese» :: **Acest, această, acești, aceste** indican cercanía; **acel, acea, acei, acele**, distancia. Si el demostrativo sustituye al nombre, se usa la forma completa: **acesta** («este»), **aceasta** («esta»), **aceștia** («estos»), **acestea** («estas»).
B Demostrativos | Cerca | Más lejos
| Masculino / neutro singular | acest | acel
| Femenino singular | această | acea
| Masculino plural | acești | acei
| Femenino / neutro plural | aceste | acele
W acest = este; ese (demostrativo masculino/neutro singular) | a-CHÉST
W această = esta (femenino singular) | a-CHAS-tă
W acești = estos (masculino plural) | a-CHESHT
W aceste = estas (femenino plural) | a-CHES-te
W acel = ese; aquel (masculino singular) | a-CHEL
W acea = esa; aquella (femenino singular) | a-CHE-a
W acei = esos; aquellos (masculino plural) | a-CHEI
W acele = esas; aquellas (femenino plural) | a-CHE-le
W acesta = este (pronombre masculino singular) | a-CES-ta
W aceasta = esta (pronombre femenino singular) | a-CEAS-ta
W aceștia = estos (pronombre masculino plural) | a-CHESH-ti-a
W acestea = estas (pronombre femenino plural) | a-CHES-te-a
V Vocabulario: demostrativos
D Esta blusa o esa
Elena: Vrei acest tricou? = ¿Quieres esta camiseta?
  > Vrei = quieres | acest tricou = esta camiseta
Radu: Nu. Vreau această bluză. = No. Quiero esta blusa.
  > Nu = no | Vreau = quiero | această bluză = esta blusa
Elena: Aceasta? = ¿Esta?
  > Aceasta = esta (pronombre femenino)
Radu: Da, această bluză. Și acești pantofi. = Sí, esta blusa. Y estos zapatos.
  > Da = sí | această bluză = esta blusa | Și = y | acești pantofi = estos zapatos
Elena: Acei pantofi? = ¿Esos zapatos?
  > Acei pantofi = esos zapatos
Radu: Da, acei pantofi. = Sí, esos zapatos.
  > Da = sí | acei pantofi = esos zapatos
Q ¿Qué demostrativo acompaña a «bluză»?
+ această :: Es la forma femenina singular de «este/esta».
- acest :: Es masculino singular.
- acești :: Es masculino plural.
Q ¿Cómo se dice «aquella blusa»?
+ acea bluză :: «Acea» señala una prenda más lejana.
- această bluză :: Significa «esta blusa», cercana.
- acești pantofi :: Significa «estos zapatos».
R Vreau această bluză. :: Elige la traducción.
+ Quiero esta blusa. :: «Această» concuerda con «bluză».
- Quiero esa blusa. :: «Acea bluză» significa «esa blusa».
- Quieres esta blusa. :: «Vrei» significa «quieres».
H ___ tricou este albastru. :: Completa «Esta camiseta es azul».
+ Acest :: Es masculino singular y va antes del nombre.
- Această :: Es femenino singular.
- Acești :: Es masculino plural.
H ___ pantofi sunt aici. :: Completa «Estos zapatos están aquí».
+ Acești :: «Pantofi» es masculino plural.
- Aceste :: Es femenino plural.
- Acest :: Es masculino singular.
A Vreau acea geacă. :: ¿Qué quiere?
+ Esa chaqueta. :: «Acea geacă» señala una chaqueta más lejana.
- Esta chaqueta. :: «Această geacă» significa «esta chaqueta».
- Estos zapatos. :: «Acești pantofi» significa «estos zapatos».
O Aceasta este bluza :: Esta es la blusa :: «Aceasta» sustituye a un nombre femenino singular.
X Escribe «esos zapatos» en rumano. :: acei pantofi :: «Acei» es el demostrativo masculino plural de distancia.
