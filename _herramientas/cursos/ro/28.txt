@ 28 | Anunțuri de angajare | Anuncios de empleo
I Un anuncio de empleo suele indicar el puesto, los requisitos y cómo contactar. Lee cada dato por separado antes de decidir si la oferta te interesa.
E Oferta :: **Post vacant** es «puesto vacante». **Cerință** significa «requisito»; **a solicita** puede significar «solicitar» o «requerir», según el contexto.
E Concordancia :: **Disponibil** concuerda con un candidato; **disponibilă**, con una candidata. **Experiență relevantă** significa «experiencia pertinente».
W anunț = anuncio | a-NUNȚ
W anunțul = el anuncio | a-NUN-țul
W post = puesto de trabajo | POST
W vacant = vacante (masculino) | va-CANT
W candidat = candidato | can-di-DAT
W candidatul = el candidato | can-di-DA-tul
W cerință = requisito | che-RIN-tsă
W cerințele = los requisitos | che-RIN-tse-le
W relevantă = pertinente (femenino) | re-le-VAN-tă
W cerințe = requisitos | che-RIN-tse
W solicită = solicita; requiere | so-li-CI-tă
W cunoștințe = conocimientos | cu-noș-TIN-tse
W program = horario; programa | pro-GRAM

W flexibil = flexible (masculino) | flek-si-BIL

W apare = aparece | a-PA-re

V Vocabulario: ofertas y requisitos
D Una oferta de trabajo
Ana: Ce cerințe are anunțul? = ¿Qué requisitos tiene el anuncio?
  > Ce cerințe = qué requisitos | are anunțul = tiene el anuncio
Mihai: Solicită experiență relevantă și cunoștințe de română. = Requiere experiencia pertinente y conocimientos de rumano.
  > Solicită = requiere | experiență relevantă = experiencia pertinente | și cunoștințe de română = y conocimientos de rumano
Ana: Este programul flexibil? = ¿El horario es flexible?
  > Este = es | programul flexibil = el horario flexible
Mihai: Da, iar salariul apare în anunț. = Sí, y el salario aparece en el anuncio.
  > Da = sí | iar salariul = y el salario | apare în anunț = aparece en el anuncio
T Un post vacant
- Anunțul prezintă un post vacant. = El anuncio presenta un puesto vacante.
  > Anunțul = el anuncio | prezintă un post vacant = presenta un puesto vacante
- Candidatul are experiență relevantă. = El candidato tiene experiencia pertinente.
  > Candidatul = el candidato | are experiență relevantă = tiene experiencia pertinente
- Cerințele includ cunoștințe de română. = Los requisitos incluyen conocimientos de rumano.
  > Cerințele = los requisitos | includ cunoștințe de română = incluyen conocimientos de rumano
- Programul este flexibil. = El horario es flexible.
  > Programul = el horario | este flexibil = es flexible
- Interviul este în anunț. = La entrevista aparece en el anuncio.
  > Interviul = la entrevista | este în anunț = aparece en el anuncio
Q ¿Qué significa «cerințele»?
+ Los requisitos. :: Es el plural definido de «cerință».
- Los candidatos. :: «Candidații» significa «los candidatos».
- Los salarios. :: «Salariile» significa «los salarios».
R Anunțul prezintă un post vacant. :: Elige la traducción.
+ El anuncio presenta un puesto vacante. :: «Post vacant» es «puesto vacante».
- El candidato solicita un anuncio flexible. :: El sujeto es el anuncio.
- El horario incluye una entrevista. :: La frase habla de un puesto vacante.
H Candidatul are experiență ___. :: Completa «El candidato tiene experiencia pertinente».
+ relevantă :: Concuerda en femenino con «experiență».
- flexibil :: Es masculino y describe «program».
- vacant :: Describe «post».
A Solicită experiență relevantă și cunoștințe de română. :: ¿Qué requiere el anuncio?
+ Experiencia pertinente y conocimientos de rumano. :: Ambos requisitos aparecen unidos por «și».
- Un horario flexible y una entrevista. :: Esos datos aparecen en otras frases.
- Un candidato y un salario. :: No es lo que se solicita.
O postul este vacant :: el puesto está vacante :: «Postul» es el puesto; «vacant» concuerda en masculino.
X Escribe en rumano: «El anuncio requiere conocimientos de rumano». :: Anunțul solicită cunoștințe de română. :: «Solicită» puede significar «requiere» en este anuncio.
Q ¿Qué significa «salariu»?
+ Salario. :: Es la remuneración del puesto.
- Requisito. :: «Cerință» significa «requisito».
- Entrevista. :: «Interviu» significa «entrevista».
R Programul este flexibil. :: Elige la traducción.
+ El horario es flexible. :: «Programul» significa «el horario» aquí.
- El candidato es flexible. :: «Candidatul» sería el candidato.
- El anuncio incluye un salario. :: La frase describe el horario.

@ 28 | Experiență și competențe | Experiencia y competencias
I Para hablar de tu experiencia, describe tareas concretas y explica qué sabes hacer. Las cualidades suelen concordar con la persona que habla.
E Experiencia :: **Experiență profesională** significa «experiencia profesional». **Am lucrat** («he trabajado») sirve para mencionar un periodo o una experiencia pasada.
E Competencias :: **Competențe** son capacidades demostrables. En rumano, **responsabilă** lleva la forma femenina si habla una mujer; **responsabil**, la masculina.
W profesională = profesional (femenino) | pro-fe-si-o-NA-lă
W competență = competencia | kom-pe-TEN-tsă
W competențele = las competencias | kom-pe-TEN-tse-le
W competențe = competencias | kom-pe-TEN-tse
W comunic = me comunico; comunico | ko-mu-NIK
W eficient = eficazmente; eficiente (masculino) | e-fi-CIENT
W gestionez = gestiono | ges-ti-o-NEZ
W organizez = organizo | or-ga-ni-ZEZ
W proiect = proyecto | pro-IEKT
W proiectele = los proyectos | pro-IEC-te-le
W rezolv = resuelvo | re-ZOLV
W lucrat = trabajado | lu-KRAT

V Vocabulario: tareas y capacidades
D Mis puntos fuertes
Ana: Ce competențe ai? = ¿Qué competencias tienes?
  > Ce competențe = qué competencias | ai = tienes
Mihai: Comunic eficient și organizez proiectele. = Me comunico eficazmente y organizo los proyectos.
  > Comunic eficient = me comunico eficazmente | și organizez proiectele = y organizo los proyectos
Ana: Ai lucrat cu o echipă? = ¿Has trabajado con un equipo?
  > Ai lucrat = has trabajado | cu o echipă = con un equipo
Mihai: Da, organizez proiectele. = Sí, organizo los proyectos.
  > Da = sí | organizez proiectele = organizo los proyectos
T Experiență profesională
- Am lucrat într-o echipă. = He trabajado en un equipo.
  > Am lucrat = he trabajado | într-o echipă = en un equipo
- Organizez proiectele și rezolv problemele. = Organizo los proyectos y resuelvo los problemas.
  > Organizez proiectele = organizo los proyectos | și rezolv problemele = y resuelvo los problemas
- Comunic eficient. = Me comunico eficazmente.
  > Comunic eficient = me comunico eficazmente
- Sunt responsabilă și gestionez activitatea. = Soy responsable y gestiono la actividad.
  > Sunt responsabilă = soy responsable | și gestionez activitatea = y gestiono la actividad
- Competențele mele sunt utile. = Mis competencias son útiles.
  > Competențele mele = mis competencias | sunt utile = son útiles
Q ¿Qué significa «competențele»?
+ Las competencias. :: Es la forma plural definida.
- Las habilidades. :: «Abilitățile» significa «las habilidades».
- Los proyectos. :: «Proiectele» significa «los proyectos».
R Comunic eficient. :: Elige la traducción.
+ Me comunico eficazmente. :: «Comunic eficient» describe cómo me comunico.
- Organizo los proyectos. :: Esa acción se expresa con «Organizez proiectele».
- Gestiono los problemas. :: La frase dice cómo me comunico.
H Organizez ___ și rezolv problemele. :: Completa «Organizo los proyectos y resuelvo los problemas».
+ proiectele :: Es el objeto plural de «organizez».
- competențele :: Significa «las competencias».
- clienții :: Significa «los clientes».
A Am lucrat într-o echipă. :: ¿Dónde he trabajado?
+ En un equipo. :: «Într-o echipă» significa «en un equipo».
- Con cada cliente. :: Eso es «cu fiecare client».
- En un proyecto. :: «Într-un proiect» significa eso.
O sunt responsabilă :: soy responsable :: La terminación femenina concuerda con una hablante mujer.
X Escribe en rumano: «Organizo los proyectos». :: Organizez proiectele. :: «Proiectele» es el plural definido de «proiect».
Q ¿Qué significa «gestionez»?
+ Gestiono. :: Es una tarea o capacidad laboral.
- Organizo. :: «Organizez» significa «organizo».
- Resuelvo. :: «Rezolv» significa «resuelvo».
R Competențele mele sunt utile. :: Elige la traducción.
+ Mis competencias son útiles. :: «Mele» expresa «mis».
- Mis habilidades organizan los proyectos. :: La frase no dice «abilitățile».
- Mi experiencia es eficaz. :: Eso sería «Experiența mea este eficientă».

@ 28 | Mesaje profesionale | Mensajes profesionales

E Estructura :: **În legătură cu** significa «en relación con». **Cu stimă** es una despedida formal: «Atentamente».
