@ 14 | La oficiul poștal | En correos
I En un servicio podemos pedir algo con **Aș dori să...** («Quisiera...»). En rumano, **să** va seguido de una forma verbal conjugada: **Aș dori să trimit** («Quisiera enviar»).
E Cartas y paquetes :: **Scrisoare** ya significa «carta»; aquí la usamos para pedir el servicio. **Colet** es «paquete» y **plic**, «sobre». Para un envío se pregunta por la dirección del destinatario.
E Fórmula cortés :: **Aș dori** suena más cortés que **vreau** («quiero»). **Scrieți** se usa como petición formal a una persona o a varias: «escriba / escriban».
W poștă = correo | POȘ-tă
W oficiu = oficina | o-FI-chu
W oficiul = la oficina | o-FI-chul
W poștal = postal (masculino) | poș-TAL
W poștală = postal (femenino) | poș-TA-lă
W oficiu poștal = oficina de correos | o-FI-chu poș-TAL
W colet = paquete | ko-LET
W coletul = el paquete | ko-LE-tul
W plic = sobre | plic
W plicul = el sobre | PLI-cul
W timbru = sello | TIM-bru
W timbrul = el sello | TIM-brul
W expeditor = remitente | eks-pe-di-TOR
W destinatar = destinatario | des-ti-na-TAR
W destinatarului = del destinatario | des-ti-na-ta-RU-lui
W adresă = dirección | a-DRE-să
W adresa = la dirección | a-DRE-sa
W aș dori = quisiera | aș do-RI
W să trimit = enviar (después de «quisiera») | să tri-MIT
W a scrie = escribir | a SKRI-e
W scrieți = escriba; escriban | skri-ETZ
V Vocabulario: correo y envíos
D En el mostrador
Mara: Bună ziua. Aș dori să trimit un colet. = Buenos días. Quisiera enviar un paquete.
  > Bună ziua = buenos días | Aș dori să trimit = quisiera enviar | un colet = un paquete
Angajat: Aveți adresa destinatarului? = ¿Tiene la dirección del destinatario?
  > Aveți = tiene (cortesía) | adresa destinatarului = la dirección del destinatario
Mara: Da, adresa este aici. = Sí, la dirección está aquí.
  > Da = sí | adresa = la dirección | este aici = está aquí
Angajat: Scrieți adresa pe colet, vă rog. = Escriba la dirección en el paquete, por favor.
  > Scrieți = escriba (cortesía) | adresa = la dirección | pe colet = en el paquete | vă rog = por favor
T Objetos para enviar
- Oficiul poștal este aproape. = La oficina de correos está cerca.
  > Oficiul poștal = la oficina de correos | este aproape = está cerca
- O scrisoare este în plic. = Una carta está en el sobre.
  > O scrisoare = una carta | este în plic = está en el sobre
- Timbrul este pe plic. = El sello está en el sobre.
  > Timbrul = el sello | este pe plic = está en el sobre
Q ¿Quién envía el paquete?
+ Expeditor. :: «Expeditor» significa «remitente».
- Destinatarul. :: «Destinatar» es quien recibe el envío.
- Timbrul. :: «Timbru» significa «sello».
R Aș dori să trimit un colet. :: Elige la traducción.
+ Quisiera enviar un paquete. :: «Aș dori» expresa una petición cortés.
- Quiero recibir un paquete. :: «A primi» significa «recibir».
- Quisiera escribir una dirección. :: «A scrie» significa «escribir».
H Scrieți adresa pe ___. :: Completa «Escriba la dirección en el paquete».
+ colet :: Es «paquete» sin artículo.
- timbrul :: Es «el sello».
- destinatar :: Es «destinatario».
A Adresa destinatarului este aici. :: ¿Qué indica la persona?
+ La dirección del destinatario está aquí. :: «Destinatarului» equivale a «del destinatario».
- El remitente está cerca. :: «Expeditor» es «remitente».
- El sobre está en la oficina. :: «Plicul» es «el sobre».
O un colet :: un paquete :: «Colet» es el objeto que se envía.
X Escribe en rumano: «Quisiera enviar una carta». :: Aș dori să trimit o scrisoare. :: La carta se llama «scrisoare»; «aș dori să» suaviza la petición.
Q ¿Qué significa «timbru»?
+ Sello. :: Se pega en el sobre para enviar una carta.
- Paquete. :: «Colet» significa «paquete».
- Oficina de correos. :: «Oficiu poștal» significa eso.
R Timbrul este pe plic. :: Elige la traducción.
+ El sello está en el sobre. :: «Timbrul» es «el sello» y «plicul», «el sobre».
- La dirección está en el paquete. :: «Adresa» significa «la dirección».
- El destinatario escribe la carta. :: «Destinatar» significa «destinatario».

@ 14 | La casa de schimb | En la casa de cambio
I Para cambiar moneda, pregunta **Care este cursul valutar?**. **Curs** también significa «curso» o «clase», pero **curs valutar** significa «tipo de cambio»: el contexto evita la confusión.
E Hablar de divisas :: **A schimba** es «cambiar». **Schimb** significa «cambio» cuando habla la persona **eu**; **schimbați** puede dirigirse con cortesía a una persona o a varias.
E Preguntar por dinero :: **A primi** significa «recibir»: **primesc** («recibo») y **primiți** («recibe / reciben», de cortesía). En las frases de práctica no fijamos un tipo de cambio real.

W schimbi = cambias | SHKIM-bi
W schimbați = cambia (cortesía); cambian | ski-MBAȚ
W există = hay; existe | eg-ZIS-tă
W a primi = recibir | a pri-MI
W primesc = recibo | pri-MESK
W primiți = recibe (cortesía); reciben | pri-MIȚ
W numerar = efectivo | nu-me-RAR

W bancnote = billetes | bank-NO-te

V Vocabulario: cambio de moneda
D En la casa de cambio
Mara: Bună ziua. Aș dori să schimb euro. = Buenos días. Quisiera cambiar euros.
  > Bună ziua = buenos días | Aș dori să schimb = quisiera cambiar | euro = euros
Angajat: Schimbați și dolari? = ¿Cambia también dólares?
  > Schimbați = cambia (cortesía) | și dolari = también dólares
Mara: Nu, schimb doar euro. = No, solo cambio euros.
  > Nu = no | schimb = cambio (yo) | doar euro = solo euros
Angajat: Cursul valutar este bun azi. = El tipo de cambio es bueno hoy.
  > Cursul valutar = el tipo de cambio | este bun = es bueno | azi = hoy
Mara: Există un comision? = ¿Hay una comisión?
  > Există = hay | un comision = una comisión
Angajat: Da, comisionul este mic. = Sí, la comisión es pequeña.
  > Da = sí | comisionul = la comisión | este mic = es pequeña
T En la ventanilla
- Primesc lei în numerar. = Recibo lei en efectivo.
  > Primesc = recibo | lei = lei | în numerar = en efectivo
- Moneda este euro. = La moneda es el euro.
  > Moneda = la moneda | este euro = es el euro
- Schimbi dolari la casa de schimb. = Cambias dólares en la casa de cambio.
  > Schimbi = cambias | dolari = dólares | la casa de schimb = en la casa de cambio
Q ¿Qué significa «numerar»?
+ Efectivo. :: Indica dinero en metálico.
- Comisión. :: «Comision» significa «comisión».
- Divisa. :: «Valută» significa «divisa».
R Cursul valutar este bun azi. :: Elige la traducción.
+ El tipo de cambio es bueno hoy. :: «Cursul valutar» es «el tipo de cambio».
- El curso de hoy es bueno. :: «Valutar» indica que se trata de moneda.
- El billete es bueno hoy. :: «Bancnotă» significa «billete».
H Aș dori să ___ euro. :: Completa «Quisiera cambiar euros».
+ schimb :: Es la forma de «eu» de «a schimba».
- schimbați :: Es una forma de cortesía o plural.
- primesc :: Significa «recibo».
A Primesc lei în numerar. :: ¿Cómo recibe el dinero?
+ En efectivo. :: «Numerar» significa «efectivo».
- En dólares. :: «Dolari» significa «dólares».
- En billetes de euro. :: La frase dice «lei».
O la casa de schimb :: en la casa de cambio :: «Casă de schimb» es una casa de cambio.
X Escribe en rumano: «Quisiera cambiar dólares». :: Aș dori să schimb dolari. :: Se usa «să» seguido de la forma verbal «schimb».
Q ¿Qué significa «comisionul»?
+ La comisión. :: La terminación «-ul» marca el sustantivo como definido.
- La moneda. :: «Moneda» significa «la moneda».
- Los billetes. :: «Bancnote» significa «billetes».

@ 14 | Un mandat poștal | Un giro postal
I En correos puedes preguntar por un **transfer de bani** («transferencia de dinero»). Para dar instrucciones corteses, se usa la forma verbal en plural: **Completați formularul, vă rog** («Complete el formulario, por favor»).
E Formularios y pagos :: **Semnez** significa «firmo»; **semnați** es una petición formal («firme / firmen»). **Păstrați chitanța** quiere decir «guarde el recibo».
E «Chitanță» y «recibo» :: **Chitanță** es el papel que confirma un pago: en español decimos «recibo» o «resguardo». No es la suma pagada: **sumă** significa «cantidad de dinero».

W mandat poștal = giro postal | man-DAT poș-TAL
W formular = formulario | for-mu-LAR
W formularul = el formulario | for-mu-LA-rul
W a completa = rellenar | a kom-ple-TA
W completați = rellene; rellenen | kom-ple-TAȚ
W semnez = firmo | sem-NEZ
W semnați = firme; firmen | sem-NAȚ
W semnătură = firma | sem-nă-TU-ră
W semnătura = la firma | sem-nă-TU-ra
W chitanță = recibo; resguardo | chi-TAN-tsă
W chitanța = el recibo; el resguardo | chi-TAN-tsa
W sumă = suma; cantidad de dinero | SU-mă
W suma = la suma | SU-ma
W taxă = tasa; tarifa | TAK-să
W taxa = la tasa; la tarifa | TAK-sa
W a păstra = guardar; conservar | a pă-STRA
W plată = pago | PLA-tă
W păstrați = guarde; guarden | pă-STRAȚ

Mara: Semnez aici? = ¿Firmo aquí?
  > Semnez = firmo | aici = aquí
Angajat: Da. Plătiți taxa? = Sí. ¿Paga la tasa?
  > Da = sí | Plătiți = paga (cortesía) | taxa = la tasa
Mara: Plătesc taxa. = Pago la tasa.
  > Plătesc = pago | taxa = la tasa
Angajat: Păstrați chitanța. = Guarde el recibo.
  > Păstrați = guarde (cortesía) | chitanța = el recibo
T Documente de plată

  > Un mandat poștal = un giro postal | este un transfer de bani = es una transferencia de dinero
- Formularul are o sumă și o semnătură. = El formulario tiene una suma y una firma.
  > Formularul = el formulario | are = tiene | o sumă = una suma | și o semnătură = y una firma
- Păstrați chitanța după ce plătiți. = Guarde el recibo después de pagar.
  > Păstrați chitanța = guarde el recibo | după ce plătiți = después de que pague
Q ¿Qué quiere decir «chitanță»?
+ Recibo o resguardo. :: Es el comprobante del pago.
- Carta. :: «Scrisoare» significa «carta».
- Comisión. :: «Comision» significa «comisión».
R Completați formularul, vă rog. :: Elige la traducción.
+ Rellene el formulario, por favor. :: Es una instrucción cortés.
- Firmo el formulario, por favor. :: «Semnez» significa «firmo».
- Guarde el recibo, por favor. :: «Păstrați chitanța» significa eso.
H Semnați ___? :: Completa «¿Firmo aquí?».
+ aici :: Significa «aquí».
- taxă :: Significa «tasa».
- suma :: Significa «la suma».
A Păstrați chitanța. :: ¿Qué pide el empleado?
+ Que guarde el recibo. :: «Păstrați» es una petición formal.
- Que pague la tasa. :: Eso es «Plătiți taxa».
- Que rellene el formulario. :: Eso es «Completați formularul».
O transfer de bani :: transferencia de dinero :: La expresión nombra el envío de dinero.
X Escribe en rumano: «Rellene el formulario, por favor». :: Completați formularul, vă rog. :: La forma en plural también se usa para tratar cortésmente a una persona.
Q ¿Qué palabra significa «firma»?
+ semnătură :: Es el sustantivo; «semnez» es «firmo».
- semnez :: Es un verbo: «firmo».
- formular :: Es «formulario».
