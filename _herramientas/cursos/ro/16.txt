@ 16 | Simptome și dureri | Síntomas y dolores
I En A1 ya viste **mă doare** («me duele») y **mă dor** («me duelen»). Ahora aprendemos más partes del cuerpo y síntomas cotidianos.
E Partes del cuerpo :: **Picior** puede significar «pie» o «pierna», según el contexto; no significa «picor». **Spate** es «espalda» y **măsea**, «muela».
E Decir qué nos pasa :: **Îmi curge nasul** significa «me gotea / me corre la nariz». El pronombre **îmi** va antes del verbo; en español normalmente decimos «me moquea la nariz».
W măsea = muela | mă-SE-a
W măseaua = la muela | mă-SE-a-ua
W dinte = diente | DIN-te
W dintele = el diente | DIN-te-le
W spate = espalda | SPA-te
W spatele = la espalda | SPA-te-le
W picior = pie; pierna | pi-CIOR
W piciorul = el pie; la pierna | pi-CIO-rul
W picioare = pies; piernas | pi-CIOA-re
W picioarele = los pies; las piernas | pi-CIOA-re-le
W nasul = la nariz | NA-sul
W îmi curge = me corre; me gotea (la nariz) | îmi KUR-je
W a strănuta = estornudar | a stră-nu-TA
W strănut = estornudo (yo) | stră-NUT
W mult = mucho | mult
W răceală = resfriado | ră-CHEA-lă
W zile = días | ZI-le
W simptom = síntoma | simp-TOM
W simptome = síntomas | simp-TO-me
W vă dor = le duelen (a usted) | vă dor
V Vocabulario: síntomas y partes del cuerpo
D En la consulta
Doctor: Ce simptome aveți? = ¿Qué síntomas tiene?
  > Ce simptome = qué síntomas | aveți = tiene (cortesía)
Ana: Am o răceală și mă doare măseaua de două zile. = Estoy resfriada y me duele la muela desde hace dos días.
  > Am o răceală = tengo un resfriado | mă doare măseaua = me duele la muela | de două zile = desde hace dos días
Doctor: Vă dor picioarele? = ¿Le duelen las piernas?
  > Vă dor = le duelen (cortesía) | picioarele = las piernas
Ana: Nu. Îmi curge nasul și strănut mult. = No. Me gotea la nariz y estornudo mucho.
  > Nu = no | Îmi curge nasul = me gotea la nariz | și strănut mult = y estornudo mucho
T Más síntomas
- Mă doare spatele. = Me duele la espalda.
  > Mă doare = me duele | spatele = la espalda
- Mă dor picioarele. = Me duelen las piernas.
  > Mă dor = me duelen | picioarele = las piernas
- Mă doare un dinte. = Me duele un diente.
  > Mă doare = me duele | un dinte = un diente
Q ¿Qué significa «măsea»?
+ Muela. :: Es un diente posterior.
- Pierna. :: «Picior» puede significar «pierna» o «pie».
- Nariz. :: «Nasul» significa «la nariz».
R Mă doare măseaua de două zile. :: Elige la traducción.
+ Me duele la muela desde hace dos días. :: «Măseaua» significa «la muela».
- Me duele la espalda desde hace dos días. :: «Spatele» significa «la espalda».
- Me duelen las piernas desde hace dos días. :: «Picioarele» significa «las piernas».
H Mă doare ___. :: Completa «Me duele la espalda».
+ spatele :: Es «la espalda».
- picioarele :: Es plural: «las piernas / los pies».
- simptome :: Significa «síntomas».
A Îmi curge nasul și strănut mult. :: ¿Qué síntomas describe?
+ Le gotea la nariz y estornuda mucho. :: «Îmi curge nasul» es «me gotea la nariz».
- Le duele la muela y la espalda. :: Eso se dice «Mă doare măseaua și spatele».
- Le duelen las piernas. :: Eso se dice «Vă dor picioarele».
O mă dor picioarele :: me duelen las piernas :: «Dor» concuerda con el plural «picioarele».
X Escribe en rumano: «Me duele la espalda». :: Mă doare spatele. :: «Spatele» es el nombre con artículo definido.
Q ¿Qué significa «simptome»?
+ Síntomas. :: Es el plural de «simptom».
- Muela. :: «Măsea» significa «muela».
- Resfriado. :: «Răceală» significa «resfriado».
R Mă dor picioarele. :: Elige la traducción.
+ Me duelen las piernas. :: «Picioarele» significa «las piernas» o «los pies».
- Me duele la pierna. :: «Piciorul» es singular.
- Me duele la muela. :: «Măseaua» significa «la muela».

@ 16 | O programare la medic | Una cita con el médico
I Para pedir una consulta puedes decir **Mă programez pentru o consultație** («Pido cita para una consulta»). En este contexto, **programare** significa «cita», no «programación» informática.
E Preguntar desde cuándo :: **De când vă simțiți rău?** pregunta «¿Desde cuándo se encuentra mal?». Para indicar cuánto dura un síntoma, usamos el presente y **de** más una duración: **Mă doare spatele de trei zile** («Me duele la espalda desde hace tres días»).
E En la consulta :: **Cabinet** es la consulta o el consultorio. **Pacient** significa «paciente»; **pacienta** es la forma femenina.
W programare = cita; hora concertada | pro-gra-MA-re
W programarea = la cita | pro-gra-MA-re-a
W a se programa = pedir cita; concertar una consulta | a se pro-gra-MA
W mă programez = pido cita; me doy cita | mă pro-gra-MEZ
W consultație = consulta | kon-sul-TA-tsi-e
W consultația = la consulta | kon-sul-TA-tsi-a
W cabinet = consultorio | ka-bi-NET
W cabinetul = el consultorio | ka-bi-NE-tul
W pacient = paciente (masculino) | pa-TSI-ent
W pacienta = la paciente | pa-TSI-en-ta
W a se simți = sentirse | a se sim-ȚI
W mă simt = me siento | mă simt
W se simte = se siente | se SIM-te
W vă simțiți = se siente (cortesía); se sienten | vă sim-ȚIȚ
W mai bine = mejor | mai BI-ne
W rău = mal; indispuesto | rău
W de trei zile = desde hace tres días | de TREI ZI-le
W de când = desde cuándo | de kînd
V Vocabulario: citas y consultas
D Pedir cita
Ana: Bună ziua. Mă programez pentru o consultație. = Buenos días. Pido cita para una consulta.
  > Bună ziua = buenos días | Mă programez = pido cita | pentru o consultație = para una consulta
Recepționeră: De când vă simțiți rău? = ¿Desde cuándo se encuentra mal?
  > De când = desde cuándo | vă simțiți rău = se encuentra mal (cortesía)
Ana: Mă simt rău. Mă doare spatele de trei zile. = Me encuentro mal. Me duele la espalda desde hace tres días.
  > Mă simt rău = me encuentro mal | mă doare spatele = me duele la espalda | de trei zile = desde hace tres días
Recepționeră: Consultația este mâine la ora zece. = La consulta es mañana a las diez.
  > Consultația = la consulta | este mâine = es mañana | la ora zece = a las diez
T En el consultorio
- Pacienta este la cabinet. = La paciente está en el consultorio.
  > Pacienta = la paciente | este la cabinet = está en el consultorio
- Mihai este pacient. = Mihai es paciente.
  > Mihai = Mihai | este pacient = es paciente
- Programarea este mâine. = La cita es mañana.
  > Programarea = la cita | este mâine = es mañana
- Pacienta se simte rău. = La paciente se encuentra mal.
  > Pacienta = la paciente | se simte rău = se encuentra mal
- Mihai se simte mai bine. = Mihai se encuentra mejor.
  > Mihai = Mihai | se simte mai bine = se encuentra mejor
Q ¿Qué significa «programare» en este contexto?
+ Cita. :: Es la hora acordada para una consulta.
- Programación informática. :: Esa traducción no corresponde a esta situación.
- Paciente. :: «Pacient» significa «paciente».
R Mă simt rău de trei zile. :: Elige la traducción.
+ Me encuentro mal desde hace tres días. :: El presente expresa que el malestar continúa.
- Me encontré mal durante tres días. :: El verbo no está en pasado.
- Me encuentro mejor desde hace tres días. :: «Rău» significa «mal».
H De când vă simțiți ___? :: Completa «¿Desde cuándo se encuentra mal?».
+ rău :: Significa «mal» o «indispuesto».
- mai bine :: Significa «mejor».
- programare :: Significa «cita».
A Consultația este mâine la ora zece. :: ¿Cuándo es la consulta?
+ Mañana a las diez. :: «Mâine» significa «mañana».
- Hoy a las diez. :: «Mâine» no significa «hoy».
- Mañana a las doce. :: «Zece» significa «diez».
O mă simt mai bine :: me encuentro mejor :: «Mai bine» significa «mejor».
X Escribe en rumano: «La cita es mañana». :: Programarea este mâine. :: «Programarea» significa «la cita».
Q ¿Qué significa «cabinet» en una consulta?
+ Consultorio. :: Es el lugar donde atiende el médico.
- Cita. :: «Programare» significa «cita».
- Farmacia. :: «Farmacie» significa «farmacia».
R Pacienta se simte rău. :: Elige la traducción.
+ La paciente se encuentra mal. :: «Pacienta» es la forma femenina.
- La paciente se encuentra mejor. :: «Mai bine» significa «mejor».
- La consulta es mañana. :: Eso se dice «Consultația este mâine».

@ 16 | La farmacie | En la farmacia
I Para preguntar por una medicina puedes decir **Aveți sirop pentru tuse?**. Para preguntar si algo es posible, usamos **pot să** más un verbo conjugado: **Pot să cumpăr...?** («¿Puedo comprar...?»).
E Medicamentos y alergias :: **Rețetă** puede ser una receta de cocina o una prescripción médica; el contexto indica el sentido. **Sunt alergică** lo dice una mujer; un hombre dice **Sunt alergic**.
E Una pregunta prudente :: Puedes preguntar **Pot să cumpăr sirop fără rețetă?**. La respuesta puede depender del medicamento; aquí practicamos la pregunta, sin recomendar ningún tratamiento.
W farmacistă = farmacéutica | far-ma-TSIS-tă
W farmacista = la farmacéutica | far-ma-TSIS-ta
W rețetă = receta; prescripción | re-TSÉ-tă
W rețeta = la receta; la prescripción | re-TSÉ-ta
W sirop = jarabe | si-ROP
W siropul = el jarabe | si-RO-pul
W pastilă = pastilla | pas-TI-lă
W pastile = pastillas | pas-TI-le
W medicament = medicamento | me-di-ka-MENT
W medicamente = medicamentos | me-di-ka-MEN-te
W fără = sin | FĂ-ră
W alergie = alergia | a-ler-GI-e
W alergic = alérgico (masculino) | a-LER-gik
W alergică = alérgica (femenino) | a-LER-gi-că
W a putea = poder | a pu-TE-a
W pot = puedo | pot
W depinde = depende | de-PIN-de
W unele = algunos; algunas | U-ne-le
V Vocabulario: farmacia y tratamientos
D En la farmacia
Mara: Bună ziua. Pot să cumpăr sirop fără rețetă? = Buenos días. ¿Puedo comprar jarabe sin receta?
  > Bună ziua = buenos días | Pot să cumpăr = puedo comprar | sirop fără rețetă = jarabe sin receta
Farmacistă: Depinde de medicament. = Depende del medicamento.
  > Depinde = depende | de medicament = del medicamento
Mara: Am rețetă pentru pastile. = Tengo una receta para pastillas.
  > Am rețetă = tengo una receta | pentru pastile = para pastillas
Farmacistă: Sunteți alergică la unele medicamente? = ¿Es alérgica a algunos medicamentos?
  > Sunteți alergică = es alérgica (cortesía) | la unele medicamente = a algunos medicamentos
Mara: Da, sunt alergică la unele medicamente. = Sí, soy alérgica a algunos medicamentos.
  > Da = sí | sunt alergică = soy alérgica | la unele medicamente = a algunos medicamentos
T En la farmacia
- Farmacista este la farmacie. = La farmacéutica está en la farmacia.
  > Farmacista = la farmacéutica | este la farmacie = está en la farmacia
- Siropul este pentru tuse. = El jarabe es para la tos.
  > Siropul = el jarabe | este pentru tuse = es para la tos
- Mihai este alergic la medicamente. = Mihai es alérgico a los medicamentos.
  > Mihai = Mihai | este alergic = es alérgico | la medicamente = a los medicamentos
- Pot să cumpăr o pastilă? = ¿Puedo comprar una pastilla?
  > Pot să cumpăr = puedo comprar | o pastilă = una pastilla
Q ¿Qué significa «rețetă» en la farmacia?
+ Receta o prescripción. :: En este contexto es la receta médica.
- Jarabe. :: «Sirop» significa «jarabe».
- Alergia. :: «Alergie» significa «alergia».
R Pot să cumpăr sirop fără rețetă? :: Elige la traducción.
+ ¿Puedo comprar jarabe sin receta? :: «Pot să» pregunta si algo es posible.
- ¿Puedo comprar una pastilla con receta? :: «Fără» significa «sin».
- ¿Tengo una receta para pastillas? :: Eso se dice «Am rețetă pentru pastile».
H Sunt ___ la unele medicamente. :: Completa «Soy alérgica a algunos medicamentos».
+ alergică :: Concuerda con quien habla, Mara.
- alergic :: Es la forma masculina.
- farmacistă :: Significa «farmacéutica».
A Sunteți alergică la unele medicamente? :: ¿Qué pregunta la farmacéutica?
+ Si es alérgica a algunos medicamentos. :: «Sunteți» es el trato cortés.
- Si quiere comprar pastillas. :: Eso se pregunta «Pot să cumpăr pastile?».
- Si tiene fiebre. :: «Febră» significa «fiebre».
O fără rețetă :: sin receta :: «Fără» significa «sin».
X Escribe en rumano: «Soy alérgica a algunos medicamentos». :: Sunt alergică la unele medicamente. :: «Alergică» es el femenino de «alergic».
Q ¿Qué significa «depinde»?
+ Depende. :: Es una respuesta que indica que hay que ver el caso.
- Puedo. :: «Pot» significa «puedo».
- Sin. :: «Fără» significa «sin».
R Siropul este pentru tuse. :: Elige la traducción.
+ El jarabe es para la tos. :: «Siropul» es «el jarabe».
- Las pastillas son para la tos. :: «Pastile» significa «pastillas».
- La receta es para la farmacia. :: «Rețeta» significa «la receta».
