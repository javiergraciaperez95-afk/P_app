@ 32 | Semnalarea unei probleme | Comunicar un problema
I Describe el problema con datos concretos y formula la petición con cortesía. En un servicio, **aș dori** suena más cuidadoso que una exigencia directa.
E Presentar una reclamación :: **A depune o reclamație** significa «presentar una reclamación». **Produs defect** describe un producto que no funciona como debería.
E Concordancia :: **Deteriorat** concuerda con un nombre masculino; **deteriorată**, con uno femenino, como **piesă**.
W aș dori = me gustaría (formal) | aș do-RI
W a depune = presentar; entregar | a de-PU-ne
W depun = presento; entrego | de-PUN
W produs = producto | pro-DUS
W produsul = el producto | pro-DU-sul
W reclamație = reclamación | re-kla-MA-tsi-e
W reclamația = la reclamación | re-kla-MA-tsi-a
W privind = respecto a; sobre | pri-VIND
W defect = defectuoso (masculino) | de-FEKT
W defectul = el defecto | de-FEK-tul
W funcționează = funciona | fun-TSI-o-ne-a-ză
W deteriorat = deteriorado (masculino) | de-te-ri-o-RAT
W deteriorată = deteriorada (femenino) | de-te-ri-o-RA-tă
W piesă = pieza | PI-e-să
W piesa = la pieza | PI-e-sa
W lipsește = falta | lip-SEȘ-te
W cumpărare = compra | kum-pă-RA-re
W cumpărarea = la compra | kum-pă-RA-re-a
V Vocabulario: describir una incidencia
D En el mostrador
Ana: Aș dori să depun o reclamație privind produsul. = Me gustaría presentar una reclamación sobre el producto.
  > Aș dori = me gustaría | să depun o reclamație = presentar una reclamación | privind produsul = sobre el producto
Mihai: Ce nu funcționează? = ¿Qué no funciona?
  > Ce nu funcționează = qué no funciona
Ana: Produsul este defect; lipsește o piesă. = El producto está defectuoso; falta una pieza.
  > Produsul este defect = el producto está defectuoso | lipsește o piesă = falta una pieza
Mihai: Piesa este deteriorată? = ¿La pieza está deteriorada?
  > Piesa este deteriorată = la pieza está deteriorada
T Describir la incidencia
- Produsul nu funcționează corect. = El producto no funciona correctamente.
  > Produsul nu funcționează = el producto no funciona | corect = correctamente
- Aș dori să depun reclamația. = Me gustaría presentar la reclamación.
  > Aș dori = me gustaría | să depun reclamația = presentar la reclamación
- Lipsește o piesă din produs. = Falta una pieza del producto.
  > Lipsește o piesă = falta una pieza | din produs = del producto
- Piesa este deteriorată. = La pieza está deteriorada.
  > Piesa este deteriorată = la pieza está deteriorada
Q ¿Qué comunica «aș dori» en una reclamación?
+ Una petición cortés: «me gustaría». :: El condicional suaviza la solicitud.
- Una orden directa. :: No es un imperativo.
- Una afirmación de que ya se resolvió. :: La frase expresa una petición.
R Produsul nu funcționează corect. :: Elige la traducción fiel.
+ El producto no funciona correctamente. :: Describe el fallo del producto.
- Falta una pieza del producto. :: Esa información aparece en otra frase.
- Me gustaría presentar una reclamación. :: Eso empieza con «Aș dori».
H Aș dori să depun o ___. :: Completa «Me gustaría presentar una reclamación».
+ reclamație :: Es el documento o la comunicación formal sobre el problema.
- piesă :: Significa «pieza».
- cumpărare :: Significa «compra».
A Ce nu funcționează? :: ¿Qué pregunta Mihai?
+ Qué no funciona. :: Pide identificar el fallo.
- Qué pieza falta. :: Esa sería otra pregunta.
- Cuándo se hizo la compra. :: No se pregunta por la fecha.
O lipsește o piesă :: falta una pieza :: «Lipsește» presenta algo que no está.
X Escribe en rumano: «La pieza está deteriorada». :: Piesa este deteriorată. :: El adjetivo femenino concuerda con «piesa».
Q ¿Qué significa «privind» en «reclamație privind produsul»?
+ Sobre; respecto al producto. :: Introduce el asunto de la reclamación.
- Debajo del producto. :: No expresa una posición física.
- Después de la compra. :: No indica tiempo.
R Aș dori să depun reclamația. :: Elige la traducción fiel.
+ Me gustaría presentar la reclamación. :: «Aș dori» suaviza la petición.
- Presenté la reclamación ayer. :: La frase no está en pasado.
- Falta una pieza de la reclamación. :: Cambia el sentido de la frase.

@ 32 | Clarificări și documente | Aclaraciones y documentos
I Cuando falta información, pregunta por el plazo, la garantía y los documentos necesarios. Una pregunta cortés facilita que la otra persona precise los datos.
E Preguntar con cortesía :: **Ați putea verifica…?** equivale a «¿podría comprobar…?». Usa la forma de cortesía, también cuando hablas con una sola persona.
E Documentar la petición :: **Dovada plății** es el justificante de pago; **în scris** indica que quieres recibir la respuesta por escrito.
W ați putea = podría; podrían | a-TSI pu-TE-a
W verificare = comprobación | ve-ri-fi-KA-re
W verifica = comprobar | ve-ri-fi-KA
W garanție = garantía | ga-RAN-tsi-e
W garanția = la garantía | ga-RAN-tsi-a
W termen = plazo | TER-men
W termenul = el plazo | TER-me-nul
W valabilă = válida (femenino) | va-la-BI-lă
W clarificare = aclaración | kla-ri-fi-KA-re
W clarificarea = la aclaración | kla-ri-fi-KA-re-a
W în scris = por escrito | în SKRIS
W confirmarea = la confirmación | kon-fir-MA-re-a
W anexez = adjunto | a-ne-KSEZ
W dovada plății = el justificante de pago | DO-va-da PLĂ-tsi-i
W data primirii = la fecha de recepción | DA-ta pri-MI-ri-i
W bon fiscal = recibo fiscal | bon fis-KAL
W bonul fiscal = el recibo fiscal | BO-nul fis-KAL
V Vocabulario: pedir datos y documentos
D Comprobar la garantía
Ana: Ați putea verifica termenul de garanție? = ¿Podría comprobar el plazo de garantía?
  > Ați putea verifica = podría comprobar | termenul de garanție = el plazo de garantía
Mihai: Garanția este valabilă până vineri. = La garantía es válida hasta el viernes.
  > Garanția este valabilă = la garantía es válida | până vineri = hasta el viernes
Ana: Aș dori o clarificare despre data primirii. = Me gustaría una aclaración sobre la fecha de recepción.
  > Aș dori o clarificare = me gustaría una aclaración | despre data primirii = sobre la fecha de recepción
Mihai: Anexez confirmarea și dovada plății. = Adjunto la confirmación y el justificante de pago.
  > Anexez confirmarea = adjunto la confirmación | dovada plății = el justificante de pago
T Solicitar una precisión
- Ați putea verifica bonul fiscal? = ¿Podría comprobar el recibo fiscal?
  > Ați putea verifica = podría comprobar | bonul fiscal = el recibo fiscal
- Termenul de garanție este valabil până vineri. = El plazo de garantía es válido hasta el viernes.
  > Termenul de garanție = el plazo de garantía | este valabil până vineri = es válido hasta el viernes
- Anexez dovada plății. = Adjunto el justificante de pago.
  > Anexez = adjunto | dovada plății = el justificante de pago
- Aștept confirmarea în scris. = Espero la confirmación por escrito.
  > Aștept confirmarea = espero la confirmación | în scris = por escrito
Q ¿Qué significa «în scris»?
+ Por escrito. :: Indica el formato de la respuesta.
- En garantía. :: «Garanție» significa «garantía».
- En el plazo. :: «Termen» significa «plazo».
R Garanția este valabilă până vineri. :: Elige la traducción fiel.
+ La garantía es válida hasta el viernes. :: «Valabilă» concuerda con el nombre femenino.
- El recibo fiscal llega el viernes. :: La frase no menciona el recibo.
- Espero una respuesta por escrito. :: Esa idea aparece en otra frase.
H Ați putea verifica termenul de ___? :: Completa «¿Podría comprobar el plazo de garantía?».
+ garanție :: Es el nombre del documento o cobertura mencionada.
- clarificare :: Significa «aclaración».
- cumpărare :: Significa «compra».
A Anexez confirmarea și dovada plății. :: ¿Qué adjunta la persona?
+ La confirmación y el justificante de pago. :: Los dos documentos están nombrados.
- La garantía y la reclamación. :: No son los documentos de la frase.
- La fecha de recepción y el recibo fiscal. :: Aparecen en otros ejemplos.
O aștept confirmarea :: espero la confirmación :: «Aștept» significa «espero».
X Escribe en rumano: «Adjunto el justificante de pago». :: Anexez dovada plății. :: La expresión identifica el comprobante del pago.
Q ¿Qué significa «bon fiscal»?
+ Recibo fiscal. :: Es el comprobante emitido por una compra.
- Plazo de garantía. :: Eso es «termen de garanție».
- Fecha de recepción. :: Eso es «data primirii».
R Aștept confirmarea în scris. :: Elige la traducción fiel.
+ Espero la confirmación por escrito. :: «În scris» indica el formato.
- Adjunto el justificante de pago. :: Eso se dice «Anexez dovada plății».
- Me gustaría una aclaración sobre la fecha. :: La frase habla de esperar una confirmación.

@ 32 | Soluții negociate | Negociar soluciones
I Expón qué solución prefieres y escucha las alternativas. Puedes aceptar una reparación, pedir un reemplazo o solicitar el reembolso.
E Soluciones :: **Înlocuire** significa «sustitución»; **reparare**, «reparación»; **rambursare**, «reembolso». Son opciones diferentes.
E Negociar :: **Solicit** formula una petición formal. **Cost suplimentar** indica un cargo adicional; pregunta por él antes de aceptar.
W solicit = solicito | so-li-CIT
W solicitarea = la solicitud | so-li-ci-TA-re-a
W soluții = soluciones | so-LU-tsi-i
W produsului = del producto | pro-DU-su-lui
W putem = podemos | pu-TEM
W oferi = ofrecer | o-FE-ri
W înlocuire = sustitución | în-lo-ku-I-re
W înlocuirea = la sustitución | în-lo-ku-I-re-a
W reparare = reparación | re-pa-RA-re
W repararea = la reparación | re-pa-RA-re-a
W rambursare = reembolso | ram-bur-SA-re
W rambursarea = el reembolso | ram-bur-SA-re-a
W acceptăm = aceptamos | ak-cep-TĂM
W refuz = rechazo; rechazo (yo) | re-FUZ
W refuzul = el rechazo | re-FU-zul
W ofertă = oferta | o-FER-tă
W oferta = la oferta | o-FER-ta
W cost suplimentar = coste adicional | KOST su-pli-men-TAR
W fără cost = sin coste | FĂ-ră KOST
W termen limită = plazo límite | TER-men li-MI-tă
W reparat = reparado (masculino) | re-pa-RAT
W oferită = ofrecida (femenino) | o-fe-RI-tă
W cerem = pedimos | CHE-rem
W înseamnă = significa | în-SEAM-nă
V Vocabulario: proponer un resultado
D Elegir una solución
Ana: Ce soluții aveți pentru produsul defect? = ¿Qué soluciones tienen para el producto defectuoso?
  > Ce soluții aveți = qué soluciones tienen | pentru produsul defect = para el producto defectuoso
Mihai: Putem oferi repararea sau înlocuirea. = Podemos ofrecer la reparación o la sustitución.
  > Putem oferi = podemos ofrecer | repararea sau înlocuirea = la reparación o la sustitución
Ana: Prefer rambursarea, dacă este posibilă. = Prefiero el reembolso, si es posible.
  > Prefer rambursarea = prefiero el reembolso | dacă este posibilă = si es posible
Mihai: Nu există cost suplimentar. = No hay coste adicional.
  > Nu există = no hay | cost suplimentar = coste adicional
T Comparar alternativas
- Solicit înlocuirea produsului defect. = Solicito la sustitución del producto defectuoso.
  > Solicit înlocuirea = solicito la sustitución | produsului defect = del producto defectuoso
- Repararea este oferită fără cost. = La reparación se ofrece sin coste.
  > Repararea = la reparación | este oferită fără cost = se ofrece sin coste
- Acceptăm oferta, dar cerem un termen limită. = Aceptamos la oferta, pero pedimos un plazo límite.
  > Acceptăm oferta = aceptamos la oferta | cerem un termen limită = pedimos un plazo límite
- Refuzul nu înseamnă că nu negociem. = El rechazo no significa que no negociemos.
  > Refuzul = el rechazo | nu înseamnă că nu negociem = no significa que no negociemos
Q ¿Qué significa «rambursare»?
+ Reembolso. :: Es una devolución del dinero pagado.
- Reparación. :: Eso es «reparare».
- Sustitución. :: Eso es «înlocuire».
R Putem oferi repararea sau înlocuirea. :: Elige la traducción fiel.
+ Podemos ofrecer la reparación o la sustitución. :: Presenta dos alternativas.
- Podemos devolver el dinero o cobrar un coste adicional. :: No es la información de la frase.
- Aceptamos la oferta y fijamos un plazo límite. :: Esa idea aparece en otra frase.
H Nu există cost ___. :: Completa «No hay coste adicional».
+ suplimentar :: Significa «adicional» y concuerda con «cost».
- limită :: Significa «límite».
- reparat :: Significa «reparado».
A Prefer rambursarea, dacă este posibilă. :: ¿Qué solución prefiere Ana?
+ El reembolso, si es posible. :: «Rambursarea» significa «el reembolso».
- La reparación sin coste. :: Esa es otra alternativa.
- Rechazar la oferta. :: Ana expresa una preferencia.
O solicit înlocuirea :: solicito la sustitución :: «Solicit» es una petición formal.
X Escribe en rumano: «Aceptamos la oferta, pero pedimos un plazo límite». :: Acceptăm oferta, dar cerem un termen limită. :: La petición concreta deja claro el plazo que se necesita.
Q ¿Qué significa «fără cost»?
+ Sin coste. :: La solución no añade un cargo.
- Con coste adicional. :: Eso sería «cost suplimentar».
- Con un plazo límite. :: Eso sería «termen limită».
R Repararea este oferită fără cost. :: Elige la traducción fiel.
+ La reparación se ofrece sin coste. :: «Fără cost» significa «sin coste».
- El reembolso se rechaza por el plazo límite. :: La frase no lo dice.
- Aceptamos una oferta con coste adicional. :: La frase indica que no hay coste.
