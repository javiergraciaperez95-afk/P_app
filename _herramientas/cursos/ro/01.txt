@ 1 | Salut! | Saludos y primeros contactos
I Empezamos con saludos y nombres. Las mayúsculas de la pronunciación aproximada señalan la sílaba tónica.
E Saludar :: **Bună ziua** es un saludo cortés que sirve durante el día y también equivale a «hola». **Bună** y **salut** son informales. :: En **bună ziua**, «bună» concuerda con «ziua» (día, femenino). La expresión completa se usa como saludo; no se traduce palabra por palabra.
E Presentarse :: **Eu sunt Ana** significa «Soy Ana». El pronombre **eu** puede omitirse: **Sunt Ana** también es correcto. :: **Încântat** lo dice un hombre; **încântată**, una mujer. El adjetivo concuerda con quien habla, como en español.
W bună ziua = buenos días; hola (cortés) | BU-nă ZI-ua | Saludo habitual con una persona desconocida.
W bună = hola (informal) | BU-nă
W salut = hola (informal) | sa-LUT
W la revedere = adiós; hasta luego | la re-ve-DE-re
W eu = yo | eu
W tu = tú | tu
W sunt = soy; estoy | sunt | Forma de «a fi» para yo y ellos/ellas.
W mă numesc = me llamo | mă nu-MESK
W încântat = encantado (habla un hombre) | în-kîn-TAT
W încântată = encantada (habla una mujer) | în-kîn-TA-tă
W mulțumesc = gracias | mul-tsu-MESK
W te rog = por favor (a una persona, informal) | te ROG
W da = sí | da
W nu = no | nu
W bine = bien | BI-ne
W dumneavoastră = usted; ustedes (trato cortés) | dum-ne-a-VOAS-tră | El verbo que acompaña a «dumneavoastră» va en plural.
V Vocabulario: los primeros saludos
D Entre vecinos
Ana: Bună! Eu sunt Ana. = ¡Hola! Soy Ana.
  > Bună = hola informal | Eu sunt = yo soy
Mihai: Salut, Ana! Eu sunt Mihai. = ¡Hola, Ana! Soy Mihai.
  > Salut = hola informal | Eu sunt = yo soy
Ana: Încântată! = ¡Encantada!
  > Încântată = forma femenina
Mihai: Încântat! = ¡Encantado!
  > Încântat = forma masculina
Ana: La revedere, Mihai! = ¡Adiós, Mihai!
  > La revedere = adiós
Mihai: La revedere, Ana! = ¡Adiós, Ana!
  > La revedere = adiós
Q ¿Qué expresión significa «adiós»?
+ La revedere. :: Es la despedida.
- Bună ziua. :: Es un saludo cortés.
- Mulțumesc. :: Significa «gracias».
Q ¿Qué palabra significa «yo»?
+ eu :: Es el pronombre de primera persona.
- tu :: Significa «tú».
- sunt :: Es una forma del verbo «ser/estar».
R Eu sunt Ana. :: ¿Qué significa?
+ Soy Ana. :: «Eu» es «yo» y «sunt» es «soy».
- Me llamo Ana. :: Eso se dice «Mă numesc Ana».
- Adiós, Ana. :: «La revedere» es una despedida.
H Eu ___ Mihai. :: Completa con «soy».
+ sunt :: Es la forma «yo soy».
- salut :: Significa «hola».
- bine :: Significa «bien».
H ___, Ana! :: Despídete de Ana.
+ La revedere :: Es la fórmula para decir adiós.
- Bună :: Es un saludo informal.
- Mulțumesc :: Significa «gracias».
A Mulțumesc. :: ¿Qué significa?
+ Gracias. :: Es la forma habitual de agradecer.
- Por favor. :: «Te rog» significa «por favor».
- Adiós. :: «La revedere» significa «adiós».
O Eu sunt Mihai :: Soy Mihai :: El pronombre «eu» puede omitirse, pero aquí aparece.
X Escribe en rumano: «buenos días» (saludo cortés). :: bună ziua :: Es la expresión cortés para saludar durante el día.

@ 1 | Cum te cheamă? | Preguntar y decir el nombre
I En rumano hay una forma cercana para amigos y otra cortés para hablar con una persona desconocida.
E Preguntar el nombre :: **Cum te cheamă?** se usa con «tú»; **Cum vă numiți?** es una forma cortés, equivalente a «¿Cómo se llama usted?». Con **dumneavoastră**, el verbo va en plural aunque en español se hable de usted.
E Nombre y apellido :: **Mă cheamă Elena** se traduce «Me llamo Elena». Literalmente se parece a «me llaman», pero esa traducción palabra por palabra no suena natural en español. **Prenume** es el nombre de pila; **nume**, el apellido en este contexto.
W cum te cheamă = ¿cómo te llamas? (informal) | cum te KIA-mă
W mă cheamă = me llamo; me llaman | mă KIA-mă | En una presentación se traduce «me llamo».
W cum vă numiți = ¿cómo se llama usted? (cortés) | cum vă nu-MITS
W vă rog = por favor (trato cortés) | vă ROG
W nume = apellido; nombre | NU-me
W prenume = nombre de pila | pre-NU-me
W numele = el apellido; el nombre | NU-me-le
W prenumele = el nombre de pila | pre-NU-me-le
W și = y | shi
W meu = mi (con un nombre masculino) | meu
W este = es | ES-te
W doamnă = señora; tratamiento cortés | DOAM-nă
V Vocabulario: nombres y cortesía
D En recepción
Radu: Bună ziua, doamnă! Cum vă numiți? = Buenos días, señora. ¿Cómo se llama usted?
  > Bună ziua = saludo cortés | doamnă = señora | Cum vă numiți = ¿cómo se llama usted?
Elena: Mă numesc Elena Popescu. = Me llamo Elena Popescu.
  > Mă numesc = me llamo | Elena Popescu = nombre y apellido
Radu: Prenumele și numele, vă rog. = El nombre y el apellido, por favor.
  > Prenumele = el nombre de pila | și = y | numele = el apellido | vă rog = por favor, cortés
Elena: Prenumele meu este Elena. = Mi nombre de pila es Elena.
  > Prenumele meu = mi nombre de pila | este = es
Radu: Numele meu este Popescu. = Mi apellido es Popescu.
  > Numele meu = mi apellido | este = es
Elena: Mulțumesc. La revedere! = Gracias. ¡Adiós!
  > Mulțumesc = gracias | La revedere = adiós
Q ¿Qué pregunta usarías para pedir el nombre con cortesía?
+ Cum vă numiți? :: Es la forma cortés.
- Cum te cheamă? :: Es informal, para alguien a quien tratas de tú.
- Eu sunt Radu. :: Significa «Yo soy Radu».
Q En este diálogo, ¿qué significa «prenume»?
+ Nombre de pila. :: Es el nombre propio de la persona.
- Apellido. :: En este contexto, «nume» es apellido.
- Señora. :: «Doamnă» significa «señora».
R Mă cheamă Elena. :: Elige la traducción natural.
+ Me llamo Elena. :: Es la fórmula rumana para presentarse.
- Te llamas Elena. :: Para «te llamas» se usa «te cheamă».
- Se llama Elena. :: No corresponde a la forma «mă».
H Prenumele ___ este Elena. :: Completa «Mi nombre de pila es Elena».
+ meu :: «Meu» significa «mi» con este nombre.
- și :: Significa «y».
- doamnă :: Significa «señora».
H Prenumele ___ numele, vă rog. :: Completa con «y».
+ și :: Une «nombre de pila» y «apellido».
- eu :: Significa «yo».
- nu :: Significa «no».
A Cum vă numiți? :: ¿Qué pregunta oyes?
+ ¿Cómo se llama usted? :: Es la pregunta cortés por el nombre.
- ¿Cómo te llamas? :: Esa es la forma informal.
- ¿Cómo se llama ella? :: La pregunta rumana se dirige a la persona presente.
O Prenumele meu este Elena :: Mi nombre de pila es Elena :: «Prenumele meu» es «mi nombre de pila».
X Escribe en rumano: «¿Cómo se llama usted?» :: Cum vă numiți? :: «Vă» forma parte de la pregunta cortés.

@ 1 | Litere și sunete | Letras y sonidos rumanos
I El rumano se escribe con alfabeto latino. Sus signos diacríticos son importantes: no son adornos y pueden distinguir palabras.
E Cinco letras especiales :: El alfabeto rumano tiene 31 letras. **Ă, â, î, ș, ț** son letras distintas: **ș** suena parecido a «sh» y **ț**, a «ts». **Ă** tiene una vocal neutra que no existe en español.
E Â e î :: **Â** e **î** representan el mismo sonido, que tampoco existe en español. Como regla básica, **î** aparece al principio o al final de una palabra y **â** dentro: **în**, pero **România**. No confundas **ș** con **s** ni **ț** con **t**.
W alfabet = alfabeto | al-fa-BET
W litere = letras | LI-te-re
W sunet = sonido | SU-net
W română = lengua rumana; rumano (femenino) | ro-MÂ-nă
W ă = letra ă; vocal neutra | ă | No tiene equivalente exacto en español.
W â = letra â; vocal central | î | Suena igual que «î».
W î = letra î; vocal central | î | Suena igual que «â».
W ș = letra ș; sonido parecido a «sh» | sh
W ț = letra ț; sonido parecido a «ts» | ts
W în = en; dentro de | în | Empieza con î.
W România = Rumanía | ro-MÂ-ni-a
W român = rumano (hombre) | ro-MÂN
W școală = escuela | ȘCOA-lă
W țară = país | TSA-ră | La primera consonante suena como «ts».
W șase = seis | ȘA-se
W măr = manzana | măr
W pâine = pan | PÂI-ne
W se scrie = se escribe | se SCRI-e
W cum se scrie = ¿cómo se escribe? | cum se SCRI-e
W cu = con | cu
W începe = empieza | în-CE-pe
V Vocabulario: letras y palabras con diacríticos
D Cómo se escriben
Elena: Cum se scrie „școală”? = ¿Cómo se escribe «școală»?
  > Cum se scrie = ¿cómo se escribe? | școală = escuela
Radu: „școală” se scrie cu ș. = «Școală» se escribe con ș.
  > școală = escuela | se scrie = se escribe | cu ș = con ș
Elena: Cum se scrie „țară”? = ¿Cómo se escribe «țară»?
  > Cum se scrie = ¿cómo se escribe? | țară = país
Radu: „țară” se scrie cu ț. = «Țară» se escribe con ț.
  > țară = país | se scrie = se escribe | cu ț = con ț
Elena: Cum se scrie „România”? = ¿Cómo se escribe «România»?
  > Cum se scrie = ¿cómo se escribe? | România = Rumanía
Radu: România se scrie cu â. = România se escribe con â.
  > România = Rumanía | se scrie = se escribe | cu â = con â
Elena: Cum se scrie „în”? = ¿Cómo se escribe «în»?
  > Cum se scrie = ¿cómo se escribe? | în = en
Radu: Începe cu î. = Empieza por î.
  > Începe = empieza | cu î = con î
Q ¿Qué letra representa el sonido parecido a «sh»?
+ ș :: Tiene una coma debajo.
- ț :: Se parece a «ts».
- ă :: Es una vocal.
Q ¿Qué afirmación sobre â e î es correcta?
+ Representan el mismo sonido. :: Cambia la escritura, no el sonido.
- â suena como «a» e î como «i». :: Ninguna tiene esos sonidos españoles.
- Las dos son consonantes. :: Ambas son vocales.
R țară :: ¿Qué significa?
+ País. :: Es una palabra con la letra ț.
- Escuela. :: «Școală» significa «escuela».
- Pan. :: «Pâine» significa «pan».
H ___ se scrie „în”? :: Pregunta cómo se escribe una palabra.
+ Cum :: Así se forma «Cum se scrie?».
- Unde :: Significa «dónde».
- Cine :: Significa «quién».
H „școală” se scrie cu ___. :: Completa la letra de inicio de «școală».
+ ș :: La palabra empieza por ș.
- ț :: «Ț» aparece en «țară».
- ă :: «Ă» es una vocal.
A pâine :: Elige el significado de la palabra que oyes.
+ Pan. :: «Pâine» significa «pan».
- Manzana. :: «Măr» significa «manzana».
- Seis. :: «Șase» significa «seis».
O șase litere :: seis letras :: «Șase» es «seis» y «litere», «letras».
X Escribe en rumano: «manzana». :: măr :: La palabra lleva la vocal ă.
