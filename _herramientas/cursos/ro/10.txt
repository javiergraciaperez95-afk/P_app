@ 10 | La medic | En la consulta
I Aprendemos a decir qué nos duele y a describir síntomas sencillos.
E Dolor :: Para decir «me duele», usamos **mă doare**. El nombre suele llevar el artículo al final: **Mă doare capul** («Me duele la cabeza»).
E Singular y plural :: El verbo concuerda con la parte del cuerpo: **doare** con una parte singular (**Mă doare gâtul**) y **dor** con varias (**Mă dor ochii**). No decimos literalmente «yo tengo dolor».
W doctor = médico; doctor | dok-TOR
W doctorul = el médico | dok-TO-rul
W cap = cabeza | kap
W capul = la cabeza | KA-pul
W gât = garganta | gît
W gâtul = la garganta | GÎ-tul
W stomac = estómago | sto-MAK
W stomacul = el estómago | sto-MA-kul
W febră = fiebre | FE-bră
W tuse = tos | TU-se
W tușesc = toso | tu-SHESK
W mă = me (pronombre) | mă
W doare = duele | DOA-re
W dor = duelen | dor
W mă doare = me duele | mă DOA-re
W mă dor = me duelen | mă dor
W ochi = ojo | ok
W ochii = los ojos | O-kii
V Vocabulario: síntomas y partes del cuerpo
D En la consulta
Doctor: Bună ziua. Ce vă doare? = Buenos días. ¿Qué le duele?
  > Bună ziua = buenos días | Ce vă doare = qué le duele
Ana: Mă doare capul. = Me duele la cabeza.
  > Mă doare = me duele | capul = la cabeza
Doctor: Aveți febră? = ¿Tiene fiebre?
  > Aveți = tiene (usted) | febră = fiebre
Ana: Da, am febră. Mă doare și stomacul. = Sí, tengo fiebre. También me duele el estómago.
  > Da = sí | am = tengo | febră = fiebre | mă doare = me duele | și = también | stomacul = el estómago
Doctor: Vă doare gâtul? = ¿Le duele la garganta?
  > Vă doare = le duele | gâtul = la garganta
Ana: Nu. Mă dor ochii și tușesc. = No. Me duelen los ojos y toso.
  > Nu = no | mă dor = me duelen | ochii = los ojos | și = y | tușesc = toso
Q ¿Qué significa «mă doare»?
+ Me duele. :: Se usa para hablar de un dolor singular.
- Me duelen. :: Para el plural se usa «mă dor».
- Tengo fiebre. :: «Am febră» significa «tengo fiebre».
Q ¿Qué forma acompaña a «ochii» en «Me duelen los ojos»?
+ mă dor :: «Ochii» es plural, por eso usamos «dor».
- mă doare :: «Doare» se usa con una parte singular.
- am febră :: Significa «tengo fiebre».
R Mă doare capul. :: Elige la traducción.
+ Me duele la cabeza. :: «Capul» significa «la cabeza».
- Me duele la garganta. :: «Gâtul» significa «la garganta».
- Me duele el estómago. :: «Stomacul» significa «el estómago».
H Mă ___ gâtul. :: Completa «Me duele la garganta».
+ doare :: «Gâtul» es singular.
- dor :: «Dor» se usa con varias partes del cuerpo.
- tușesc :: Significa «toso».
H Mă ___ ochii. :: Completa «Me duelen los ojos».
+ dor :: «Ochii» es plural.
- doare :: «Doare» se usa con una parte singular.
- febră :: Significa «fiebre».
A Aveți febră? :: ¿Qué pregunta oyes?
+ ¿Tiene fiebre? :: «Aveți» es la forma cortés de «tener».
- ¿Le duele la cabeza? :: Eso se dice «Vă doare capul?».
- ¿Tiene tos? :: «Tuse» significa «tos».
O mă dor ochii :: me duelen los ojos :: «Dor» concuerda con el plural «ochii».
X Escribe «Toso» en rumano. :: Tușesc. :: «Tușesc» significa «toso».

@ 10 | La cazare | El alojamiento
I En el alojamiento, preguntamos por la reserva, entregamos el pasaporte y recibimos la llave.
E Artículo definido :: El artículo se añade al final del nombre: **hotel → hotelul** («hotel → el hotel»), **pașaport → pașaportul** («pasaporte → el pasaporte»).
E Falso amigo :: **Pensiune** suele ser una casa de huéspedes o un pequeño alojamiento; no significa la prestación económica llamada «pensión».
W hotel = hotel | ho-TEL
W hotelul = el hotel | ho-TE-lul
W pentru = para | PEN-tru
W rezervare = reserva | re-zer-VA-re
W rezervarea = la reserva | re-zer-VA-re-a
W nopți = noches | nopts
W pașaport = pasaporte | pa-sha-PORT
W pașaportul = el pasaporte | pa-sha-POR-tul
W cheie = llave | KEI-e
W cheia = la llave | KEI-a
W recepție = recepción | re-CEP-tsi-e
W recepția = la recepción | re-CEP-tsi-a
W valiză = maleta | va-LI-ză
W valiza = la maleta | va-LI-za
W pensiune = casa de huéspedes | pen-SIU-ne
W pensiunea = la casa de huéspedes | pen-SIU-ne-a
V Vocabulario: alojamiento y viaje
D En el hotel
Ana: Bună seara! Am o rezervare la hotel pentru două nopți. = ¡Buenas noches! Tengo una reserva en el hotel para dos noches.
  > Bună seara = buenas noches | Am = tengo | o rezervare = una reserva | la hotel = en el hotel | pentru două nopți = para dos noches
Maria: Bună seara! Pașaportul, vă rog. = ¡Buenas noches! El pasaporte, por favor.
  > Bună seara = buenas noches | Pașaportul = el pasaporte | vă rog = por favor
Ana: Poftim. = Aquí tiene.
  > Poftim = aquí tiene
Maria: Mulțumesc. Aceasta este cheia. = Gracias. Esta es la llave.
  > Mulțumesc = gracias | Aceasta = esta | este = es | cheia = la llave
Ana: Mulțumesc. Unde este valiza? = Gracias. ¿Dónde está la maleta?
  > Mulțumesc = gracias | Unde este = dónde está | valiza = la maleta
Maria: Valiza este în cameră. = La maleta está en la habitación.
  > Valiza = la maleta | este = está | în cameră = en la habitación
Q ¿Qué significa «rezervare»?
+ Reserva. :: Es la reserva que se hace antes de llegar.
- Maleta. :: «Valiză» significa «maleta».
- Llave. :: «Cheie» significa «llave».
Q ¿Qué suele significar «pensiune» en un viaje?
+ Casa de huéspedes. :: Es un tipo pequeño de alojamiento.
- Pasaporte. :: «Pașaport» significa «pasaporte».
- Noche. :: «Noapte» significa «noche».
R Am o rezervare pentru două nopți. :: Elige la traducción.
+ Tengo una reserva para dos noches. :: «Rezervare» significa «reserva».
- Tengo una maleta para dos noches. :: «Valiză» significa «maleta».
- Tengo una llave para dos noches. :: «Cheie» significa «llave».
H ___, vă rog. :: Completa «El pasaporte, por favor».
+ Pașaportul :: Es «pașaport» con el artículo definido.
- Valiza :: Significa «la maleta».
- Cheia :: Significa «la llave».
H Aceasta este ___. :: Completa «Esta es la llave».
+ cheia :: «Cheia» significa «la llave».
- valiza :: Significa «la maleta».
- recepția :: Significa «la recepción».
A Camera este aici. :: ¿Qué frase oyes?
+ La habitación está aquí. :: «Camera» significa «la habitación».
- La llave está aquí. :: Eso se dice «Cheia este aici».
- La maleta está aquí. :: Eso se dice «Valiza este aici».
O pașaportul :: el pasaporte :: El artículo definido se pega al final de «pașaport».
X Escribe «la maleta» en rumano. :: valiza :: Se forma con «valiză» más el artículo definido.

@ 10 | Ce am făcut? | ¿Qué hice?
I Contamos una experiencia terminada. El pasado compuesto rumano se forma con una forma de **a avea** y un participio.
E Pasado compuesto :: **Am fost** significa «estuve» o «he estado»; **am mers**, «fui» o «he ido». El auxiliar cambia según la persona (**am, ai, a**), pero el participio se mantiene igual.
E Una experiencia :: **Unde ai fost?** significa «¿Dónde estuviste?». Para hablar de una visita, podemos decir **Am fost în Brașov** («Estuve en Brașov»).
W ieri = ayer | IE-ri
W fost = sido; estado (participio) | fost
W mers = ido (participio) | mers
W ajuns = llegado (participio) | a-JUNS
W am fost = estuve; he estado | am fost
W ai fost = estuviste; has estado | ai fost
W a fost = estuvo; ha estado | a fost
W am mers = fui; he ido | am mers
W ai mers = fuiste; has ido | ai mers
W a mers = fue; ha ido | a mers
W am ajuns = llegué; he llegado | am a-JUNS
W ai ajuns = llegaste; has llegado | ai a-JUNS
W a ajuns = llegó; ha llegado | a a-JUNS
W vacanță = vacaciones | va-KAN-tsă
W excursie = excursión | eks-KUR-si-e
W excursia = la excursión | eks-KUR-si-a
V Vocabulario: pasado y experiencias
B Pasado compuesto | Persona | Ejemplo
| Yo | am fost
| Tú | ai fost
| Él / ella | a fost
D Una visita a Brașov
Alina: Unde ai fost în vacanță? = ¿Dónde estuviste de vacaciones?
  > Unde ai fost = dónde estuviste | în vacanță = de vacaciones
Radu: Am fost în Brașov. = Estuve en Brașov.
  > Am fost = estuve | în Brașov = en Brașov
Alina: Ai mers cu trenul? = ¿Fuiste en tren?
  > Ai mers = fuiste | cu trenul = en tren
Radu: Da. Am mers cu trenul și am ajuns la hotel. = Sí. Fui en tren y llegué al hotel.
  > Da = sí | Am mers = fui | cu trenul = en tren | și = y | am ajuns = llegué | la hotel = al hotel
Q ¿Qué significa «am fost»?
+ Estuve; he estado. :: Es el pasado compuesto de «a fi» para «yo».
- Fui; he ido. :: «Am mers» es «fui» o «he ido».
- Llegué; he llegado. :: «Am ajuns» significa «llegué».
Q ¿Qué forma acompaña a «tu» en «estuviste»?
+ ai fost :: «Ai» es el auxiliar para «tú».
- am fost :: «Am» corresponde a «yo».
- a fost :: «A» corresponde a «él/ella».
R Ai mers cu trenul? :: Elige la traducción.
+ ¿Fuiste en tren? :: «Ai mers» significa «fuiste».
- ¿Llegaste en tren? :: «Ai ajuns» significa «llegaste».
- ¿Estuviste en el hotel? :: Eso se dice «Ai fost la hotel?».
H Am ___ în Brașov. :: Completa «Estuve en Brașov».
+ fost :: «Am fost» significa «estuve».
- mers :: «Am mers» significa «fui».
- ajuns :: «Am ajuns» significa «llegué».
H Elena ___ în Brașov. :: Completa «Elena estuvo en Brașov».
+ a fost :: Para «él/ella» usamos «a fost».
- ai fost :: Es la forma para «tú».
- am fost :: Es la forma para «yo».
A Am ajuns la hotel. :: ¿Qué experiencia oyes?
+ Llegué al hotel. :: «Am ajuns» significa «llegué».
- Estuve de vacaciones. :: Eso se dice «Am fost în vacanță».
- Fui en tren. :: Eso se dice «Am mers cu trenul».
O am mers :: fui; he ido :: El auxiliar «am» va antes del participio «mers».
X Escribe «Ayer estuve en Brașov» en rumano. :: Ieri am fost în Brașov. :: «Ieri» significa «ayer» y «am fost», «estuve».

@ 10 | Examen final | Examen final
I Responde sin mirar las lecciones. Son 25 preguntas de todo el nivel.
R Cap. 1. Bună ziua! :: Elige la traducción.
+ ¡Buenos días!; ¡buen día! :: Es un saludo cortés.
- ¡Hasta mañana! :: Eso expresa una despedida con «mâine».
- ¡Buenas noches! :: Eso se dice «Bună seara!».
Q Cap. 1. ¿Qué significa «La revedere!»?
+ ¡Hasta luego!; ¡adiós! :: Es una despedida.
- Buenos días. :: «Bună ziua» es un saludo.
- Gracias. :: «Mulțumesc» significa «gracias».
R Cap. 2. Sunt din Spania. :: Elige la traducción.
+ Soy de España. :: «Sunt din» significa «soy de».
- Hablo español. :: Eso se dice «Vorbesc limba spaniolă».
- Vivo en España. :: «Din» expresa origen.
R Cap. 2. Eu vorbesc limba spaniolă. :: Elige la traducción.
+ Yo hablo español. :: «Vorbesc» significa «hablo».
- Yo soy de España. :: Eso se dice «Sunt din Spania».
- Tú hablas español. :: «Eu» significa «yo».
R Cap. 3. Am două surori. :: Elige la traducción.
+ Tengo dos hermanas. :: «Două» acompaña al femenino «surori».
- Tengo dos hermanos. :: Eso se dice «Am doi frați».
- Tengo dos hijos. :: «Surori» significa «hermanas».
Q Cap. 3. ¿Qué significa «Câți ani ai?»?
+ ¿Cuántos años tienes? :: Es la pregunta de edad.

R Cap. 4. Apartamentul are două camere. :: Elige la traducción.
