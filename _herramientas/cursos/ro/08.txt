@ 8 | În oraș | En la ciudad
I Aprendemos a localizar lugares. **Unde este...?** significa «¿Dónde está...?».
E Lugares :: Muchos nombres de lugar aparecen con artículo definido cuando hablamos de un lugar concreto: **muzeu → muzeul** («museo → el museo»), **gară → gara** («estación de tren → la estación de tren»).
E Cerca o lejos :: **Aproape** significa «cerca» y **departe**, «lejos». En rumano, **lângă** significa «junto a» y va seguido directamente del nombre, sin una palabra equivalente a «de».
W oraș = ciudad | o-RASH
W orașul = la ciudad | o-RASH-ul
W stradă = calle | STRA-dă
W strada = la calle | STRA-da
W parc = parque | park
W parcul = el parque | PAR-kul
W muzeu = museo | mu-ZEU
W muzeul = el museo | mu-ZE-ul
W gară = estación de tren | GA-ră
W gara = la estación de tren | GA-ra
W magazin = tienda | ma-ga-ZIN
W magazinul = la tienda | ma-ga-ZI-nul
W farmacie = farmacia | far-ma-CHI-e
W farmacia = la farmacia | far-MA-chi-a
W centru = centro | CHEN-tru
W centrul = el centro | CHEN-trul
W departe = lejos | de-PAR-te
W aproape = cerca | a-PROA-pe
V Vocabulario: lugares de la ciudad
D En el centro
Elena: Unde este muzeul? = ¿Dónde está el museo?
  > Unde = dónde | este = está | muzeul = el museo
Radu: Muzeul este în centru, lângă parc. = El museo está en el centro, junto al parque.
  > Muzeul = el museo | este = está | în centru = en el centro | lângă parc = junto al parque
Elena: Este departe de gară? = ¿Está lejos de la estación de tren?
  > Este = está | departe = lejos | de gară = de la estación de tren
Radu: Nu, este aproape. = No, está cerca.
  > Nu = no | este = está | aproape = cerca
Elena: Unde este farmacia? = ¿Dónde está la farmacia?
  > Unde = dónde | este = está | farmacia = la farmacia
Radu: Farmacia este lângă magazin. = La farmacia está junto a la tienda.
  > Farmacia = la farmacia | este = está | lângă magazin = junto a la tienda
Q ¿Qué significa «orașul»?
+ La ciudad. :: «Oraș» significa «ciudad» y «orașul», «la ciudad».
- La calle. :: «Strada» significa «la calle».
- El parque. :: «Parcul» significa «el parque».
Q ¿Qué palabra significa «estación de tren»?
+ gară :: «Gară» significa «estación de tren».
- farmacie :: Significa «farmacia».
- magazin :: Significa «tienda».
R Farmacia este lângă magazin. :: Elige la traducción.
+ La farmacia está junto a la tienda. :: «Lângă» expresa proximidad.
- La tienda está junto a la farmacia. :: El orden de los nombres cambia quién está junto a quién.
- La farmacia está lejos de la tienda. :: «Departe» significa «lejos».
H Muzeul este în ___. :: Completa «El museo está en el centro».
+ centru :: «În centru» significa «en el centro».
- orașul :: Significa «la ciudad».
- gară :: Significa «estación de tren».
H Farmacia este lângă ___. :: Completa «La farmacia está junto a la tienda».
+ magazin :: «Lângă magazin» significa «junto a la tienda».
- muzeul :: Significa «el museo».
- parcul :: Significa «el parque».
A Este departe de gară? :: ¿Qué pregunta oyes?
+ ¿Está lejos de la estación de tren? :: «Departe» significa «lejos».
- ¿Dónde está la farmacia? :: Eso se dice «Unde este farmacia?».
- ¿Está cerca del parque? :: «Aproape» significa «cerca».
O lângă parc :: junto al parque :: «Lângă» va seguido directamente del nombre.
X Escribe «el museo» en rumano. :: muzeul :: Se añade el artículo definido al final: «muzeu» → «muzeul».

@ 8 | Pe unde mergem? | ¿Por dónde vamos?
I Para indicar una ruta a una persona desconocida, usamos formas corteses como **Mergeți** («vaya») y **Virați** («gire»).
E Direcciones :: **Drept înainte** significa «todo recto», **la stânga**, «a la izquierda», y **la dreapta**, «a la derecha». La preposición **la** aparece también en «a la izquierda/derecha» en español.
E Instrucciones corteses :: **Mergeți** y **virați** son formas de usted/ustedes para dar una indicación. **Apoi** significa «después» y sirve para enlazar los pasos de una ruta.
W drept = recto; derecho | drept
W înainte = adelante | î-na-IN-te
W drept înainte = todo recto | drept î-na-IN-te
W stânga = izquierda | STÎN-ga
W la stânga = a la izquierda | la STÎN-ga
W dreapta = derecha | dreap-ta
W la dreapta = a la derecha | la dreap-ta
W mergeți = vaya; vayan | MER-jets
W virați = gire; giren | vi-RA-ts
W treceți = cruce; crucen | TRE-chets
W prima = primera | PRI-ma
W intersecție = cruce; intersección | in-ter-SEC-tsi-e
W intersecția = la intersección | in-ter-SEC-tsi-a
W semafor = semáforo | se-ma-FOR
W semaforul = el semáforo | se-ma-FO-rul
W colț = esquina | kolts
W colțul = la esquina | KOL-tsul
W Scuzați-mă = disculpe | sku-ZA-tsi-mă
V Vocabulario: indicaciones
D Cómo llegar al museo
Elena: Scuzați-mă, unde este muzeul? = Disculpe, ¿dónde está el museo?
  > Scuzați-mă = disculpe | unde este muzeul = dónde está el museo
Radu: Mergeți drept înainte. = Vaya todo recto.
  > Mergeți = vaya | drept înainte = todo recto
Elena: Și apoi? = ¿Y después?
  > Și = y | apoi = después
Radu: La prima intersecție, virați la stânga. = En el primer cruce, gire a la izquierda.
  > La prima intersecție = en el primer cruce | virați = gire | la stânga = a la izquierda
Elena: Treceți strada la semafor? = ¿Cruzo la calle en el semáforo?
  > Treceți = cruce | strada = la calle | la semafor = en el semáforo
Radu: Da. Apoi, muzeul este lângă parc. = Sí. Después, el museo está junto al parque.
  > Da = sí | Apoi = después | muzeul = el museo | este = está | lângă parc = junto al parque
Q ¿Cómo se dice «todo recto»?
+ drept înainte :: Es la indicación para seguir en línea recta.
- la stânga :: Significa «a la izquierda».
- la dreapta :: Significa «a la derecha».
Q ¿Qué significa «virați» en una indicación cortés?
+ Gire. :: Es una forma cortés para dar una instrucción.
- Está lejos. :: «Departe» significa «lejos».
- Después. :: «Apoi» significa «después».
R Virați la stânga la prima intersecție. :: Elige la traducción.
+ Gire a la izquierda en el primer cruce. :: «La stânga» es «a la izquierda».
- Gire a la derecha en el primer cruce. :: «La dreapta» significa «a la derecha».
- Siga todo recto hasta el primer cruce. :: «Drept înainte» significa «todo recto».
H Mergeți drept ___. :: Completa «Vaya todo recto».
+ înainte :: «Drept înainte» significa «todo recto».
- stânga :: «Stânga» significa «izquierda».
- apoi :: «Apoi» significa «después».
H La prima ___, virați la dreapta. :: Completa «En el primer cruce, gire a la derecha».
+ intersecție :: «Prima intersecție» significa «el primer cruce».
- semafor :: Significa «semáforo».
- colțul :: Significa «la esquina».
A Mergeți drept înainte, apoi la dreapta. :: ¿Qué indicación oyes?
+ Vaya todo recto y después a la derecha. :: «Apoi» significa «después».
- Gire a la izquierda en el primer cruce. :: Eso se dice «Virați la stânga la prima intersecție».
- Cruce la calle en el semáforo. :: Eso se dice «Treceți strada la semafor».
O la prima intersecție :: en el primer cruce :: «Prima» concuerda con el nombre femenino «intersecție».
X Escribe «Gire a la izquierda en el primer cruce». :: Virați la stânga la prima intersecție. :: «Virați» es una instrucción cortés; «la stânga» significa «a la izquierda».

@ 8 | Cu ce mergem? | ¿En qué vamos?
I Aprendemos los transportes y cómo preguntar por una ruta o por el precio del billete.
E Medios de transporte :: Para decir «en autobús» o «en tren», el rumano usa **cu** («con»): **cu autobuzul**, **cu trenul**. Es una diferencia con el español, que suele usar «en».
E Una palabra parecida :: **Magazin** significa «tienda», no «magacín» ni «revista». Para preguntar por el billete, **Cât costă biletul?** significa «¿Cuánto cuesta el billete?».
W autobuz = autobús | au-to-BUZ
W autobuzul = el autobús | au-to-BU-zul
W tramvai = tranvía | tram-VAI
W tramvaiul = el tranvía | tram-va-I-ul
W troleibuz = trolebús | tro-lei-BUZ
W troleibuzul = el trolebús | tro-lei-BU-zul
W tren = tren | tren
W trenul = el tren | TRE-nul
W taxi = taxi | TAK-si
W taxiul = el taxi | tak-SI-ul
W metrou = metro | me-TROU
W metroul = el metro | me-TRO-ul
W bilet = billete | bi-LET
W biletul = el billete | bi-LE-tul
W puteți = puede; pueden | pu-TE-ts
W lua = tomar; coger | lu-A
W ajung = llego; llego a | a-JUNG
W Cum = cómo (al inicio de una pregunta) | kum
W Merg = voy (al inicio de una frase) | merg
W pe jos = a pie | pe JOS
W cu autobuzul = en autobús | ku au-to-BU-zul
W cu trenul = en tren | ku TRE-nul
W stații = paradas; estaciones | sta-TSI
V Vocabulario: transportes y billetes
D En la parada
Maria: Bună ziua! Cum ajung la gară? = ¡Buenos días! ¿Cómo llego a la estación de tren?
  > Bună ziua = buenos días | Cum ajung = cómo llego | la gară = a la estación de tren
Elena: Puteți lua autobuzul sau tramvaiul. = Puede tomar el autobús o el tranvía.
  > Puteți = puede | lua = tomar | autobuzul = el autobús | sau = o | tramvaiul = el tranvía
Maria: Cât costă biletul? = ¿Cuánto cuesta el billete?
  > Cât = cuánto | costă = cuesta | biletul = el billete
Elena: Biletul costă trei lei. = El billete cuesta tres lei.
  > Biletul = el billete | costă = cuesta | trei lei = tres lei
Maria: Mulțumesc. Merg la gară cu autobuzul. = Gracias. Voy a la estación de tren en autobús.
  > Mulțumesc = gracias | Merg = voy | la gară = a la estación de tren | cu autobuzul = en autobús
Q ¿Qué significa «troleibuzul»?
+ El trolebús. :: Es el nombre del vehículo con artículo definido.
- El tranvía. :: «Tramvaiul» significa «el tranvía».
- El autobús. :: «Autobuzul» significa «el autobús».
Q ¿Qué palabra significa «el billete»?
+ biletul :: «Bilet» es «billete» y «biletul», «el billete».
- trenul :: Significa «el tren».
- metroul :: Significa «el metro».
R Puteți lua autobuzul sau tramvaiul. :: Elige la traducción.
+ Puede tomar el autobús o el tranvía. :: «Puteți lua» significa «puede tomar» en un trato cortés.
- Puede tomar el tren o el taxi. :: «Trenul» es «el tren» y «taxiul», «el taxi».
- Puede tomar el metro o el trolebús. :: «Metroul» es «el metro» y «troleibuzul», «el trolebús».
H Ajung la muzeu cu ___. :: Completa «Llego al museo en autobús».
+ autobuzul :: «Cu autobuzul» significa «en autobús».
- trenul :: «Cu trenul» significa «en tren».
- taxiul :: «Cu taxiul» significa «en taxi».
H Cât costă ___? :: Completa «¿Cuánto cuesta el billete?».
+ biletul :: «Biletul» significa «el billete».
- autobuzul :: Significa «el autobús».
- metroul :: Significa «el metro».
A Cum ajung la gară? :: ¿Qué pregunta oyes?
+ ¿Cómo llego a la estación de tren? :: «Cum ajung» significa «cómo llego».
- ¿Cuánto cuesta el billete? :: Eso se dice «Cât costă biletul?».
- ¿Dónde está el museo? :: Eso se dice «Unde este muzeul?».
O cu trenul :: en tren :: En rumano «cu» significa literalmente «con», pero se usa para expresar el medio de transporte.
X Escribe «el billete» en rumano. :: biletul :: El artículo definido se añade al final: «bilet» → «biletul».
