@ 9 | Timp liber | Tiempo libre
I Hablamos de aficiones y de lo que hacemos cuando tenemos tiempo libre.
E Actividades :: Para decir que nos gusta una actividad, usamos **Îmi place să...** («Me gusta...»): **Îmi place să citesc** («Me gusta leer»). El verbo después de **să** cambia según quién habla.
E Lectura y gustos :: En rumano, **Îmi place filmul** significa «Me gusta la película». El pronombre **îmi** equivale aquí a «me» y el verbo **place** va antes de lo que gusta.
W în timpul liber = en el tiempo libre | în TIM-pul LI-ber
W să = partícula que introduce el subjuntivo | să
W citesc = leo | chi-TESK
W ascult = escucho | as-KULT
W muzică = música | MU-zi-că
W muzica = la música | MU-zi-ca
W film = película | film
W filmul = la película | FIL-mul
W filme = películas | FIL-me
W sport = deporte | sport
W sportul = el deporte | SPOR-tul
W joc = juego; juego (yo) | jok
W fotbal = fútbol | FOT-bal
W dansez = bailo | dan-SEZ
W dans = baile | dans
W desenez = dibujo | de-se-NEZ
W desenezi = dibujas | de-se-NEZI
W desen = dibujo | de-SEN
V Vocabulario: actividades y aficiones
D En el tiempo libre
Maria: Ce faci în timpul liber? = ¿Qué haces en el tiempo libre?
  > Ce faci = qué haces | în timpul liber = en el tiempo libre
Elena: Citesc și ascult muzică. = Leo y escucho música.
  > Citesc = leo | și = y | ascult = escucho | muzică = música
Maria: Îți place filmul? = ¿Te gusta la película?
  > Îți place = te gusta | filmul = la película
Elena: Da. Îmi place să joc fotbal și să dansez. = Sí. Me gusta jugar al fútbol y bailar.
  > Da = sí | Îmi place = me gusta | să joc fotbal = jugar al fútbol | să dansez = bailar
Maria: Desenezi? = ¿Dibujas?
  > Desenezi = dibujas
Elena: Da, desenez în timpul liber. = Sí, dibujo en el tiempo libre.
  > Da = sí | desenez = dibujo | în timpul liber = en el tiempo libre
Q ¿Qué significa «citesc»?
+ Leo. :: Es la forma «yo leo».
- Escucho. :: «Ascult» significa «escucho».
- Dibujo. :: «Desenez» significa «dibujo».
Q ¿Qué significa «în timpul liber»?
+ En el tiempo libre. :: Es una expresión para hablar de las aficiones.
- En el centro. :: «În centru» significa «en el centro».
- Junto al parque. :: «Lângă parc» significa «junto al parque».
R Îmi place să joc fotbal. :: Elige la traducción.
+ Me gusta jugar al fútbol. :: «Îmi place să» expresa que una actividad nos gusta.
- Me gusta escuchar música. :: Eso se dice «Îmi place să ascult muzică».
- Me gusta dibujar. :: «Să desenez» significa «dibujar».
H Ascult ___. :: Completa «Escucho música».
+ muzică :: «Ascult muzică» significa «escucho música».
- sportul :: Significa «el deporte».
- filmul :: Significa «la película».
H Îmi place ___. :: Completa «Me gusta la película».
+ filmul :: «Îmi place filmul» significa «me gusta la película».
- filme :: Significa «películas».
- muzică :: Significa «música».
A Citesc și ascult muzică. :: ¿Qué hace la persona?
+ Lee y escucha música. :: «Citesc» es «leo» y «ascult», «escucho».
- Juega al fútbol y baila. :: Eso se dice «Joc fotbal și dansez».
- Dibuja en el tiempo libre. :: Eso se dice «Desenez în timpul liber».
O dansez :: bailo :: «Dansez» es una forma del presente en primera persona.
X Escribe «Me gusta el deporte» en rumano. :: Îmi place sportul. :: «Îmi place» equivale a «me gusta» y «sportul» significa «el deporte».

@ 9 | Calendarul | El calendario
I Aprendemos las estaciones, los meses y a preguntar por la fecha.
E Las estaciones :: **Primăvară, vară, toamnă** și **iarnă** significan «primavera, verano, otoño» e «invierno». En rumano, el nombre de cada estación suele ir sin artículo en frases como **Este toamnă** («Es otoño»).
E La fecha :: Para preguntar «¿Qué fecha es hoy?» decimos **Ce dată este azi?**. En la respuesta ponemos primero el día y después el mes: **Azi este 15 octombrie** («Hoy es 15 de octubre»).
W primăvară = primavera | pri-mă-VA-ră
W vară = verano | VA-ră
W toamnă = otoño | TOAM-nă
W iarnă = invierno | IAR-nă
W ianuarie = enero | ia-nu-A-ri-e
W februarie = febrero | fe-BRU-a-ri-e
W martie = marzo | MAR-ti-e
W aprilie = abril | a-PRI-li-e
W mai = mayo | mai
W iunie = junio | iu-NI-e
W iulie = julio | iu-LI-e
W august = agosto | au-GUST
W septembrie = septiembre | sep-TEM-bri-e
W octombrie = octubre | ok-TOM-bri-e
W noiembrie = noviembre | no-iem-BRI-e
W decembrie = diciembre | de-CEM-bri-e
W dată = fecha | DA-tă
W azi = hoy | azi
W anotimp = estación del año | a-no-TIMP
W lună = mes | LU-nă
W an = año | an
V Vocabulario: estaciones, meses y fecha
D La fecha de hoy
Mihai: Ce dată este azi? = ¿Qué fecha es hoy?
  > Ce dată = qué fecha | este = es | azi = hoy
Maria: Azi este 15 octombrie. = Hoy es 15 de octubre.
  > Azi = hoy | este = es | octombrie = octubre
Mihai: Ce anotimp este acum? = ¿Qué estación del año es ahora?
  > Ce anotimp = qué estación del año | este = es | acum = ahora
Maria: Este toamnă. = Es otoño.
  > Este = es | toamnă = otoño
Q ¿Qué significa «februarie»?
+ Febrero. :: Es el segundo mes del año.
- Abril. :: «Aprilie» significa «abril».
- Agosto. :: «August» significa «agosto».
Q ¿Qué significa «Ce dată este azi?»?
+ ¿Qué fecha es hoy? :: «Dată» significa «fecha» y «azi», «hoy».
- ¿Qué estación es ahora? :: Eso se dice «Ce anotimp este acum?».
- ¿Qué mes es? :: «Lună» significa «mes».
R Azi este 15 octombrie. :: Elige la traducción.
+ Hoy es 15 de octubre. :: En la fecha rumana, primero se dice el día y luego el mes.
- Hoy es 15 de agosto. :: «August» significa «agosto».
- Hoy es 5 de octubre. :: «15» indica el día quince.
H Este ___. :: Completa «Es otoño».
+ toamnă :: «Este toamnă» significa «es otoño».
- iarnă :: Significa «invierno».
- vară :: Significa «verano».
H Azi este 15 ___. :: Completa «Hoy es 15 de octubre».
+ octombrie :: «Octombrie» significa «octubre».
- noiembrie :: Significa «noviembre».
- septembrie :: Significa «septiembre».
A Ce anotimp este acum? :: ¿Qué pregunta oyes?
+ ¿Qué estación del año es ahora? :: «Anotimp» significa «estación del año».
- ¿Qué fecha es hoy? :: Eso se dice «Ce dată este azi?».
- ¿En qué mes estamos? :: «Lună» significa «mes».
O în ianuarie :: en enero :: Los meses se escriben con minúscula en rumano.
X Escribe «primavera» en rumano. :: primăvară :: El nombre de la estación no lleva artículo en esta frase.

@ 9 | Cum este vremea? | ¿Qué tiempo hace?
I Describimos el tiempo y proponemos un plan sencillo. Para una actividad cercana, el rumano también usa el presente con una palabra como **mâine** («mañana»).
E Expresiones del tiempo :: **Este cald** significa «hace calor» y **este frig**, «hace frío». **Plouă** («llueve») y **ninge** («nieva») son expresiones impersonales: no necesitan un sujeto como «ello».
E Acuerdo :: **Vreme** («tiempo atmosférico») es femenino. Por eso decimos **vreme frumoasă** («buen tiempo»), con el adjetivo femenino **frumoasă**.
W vremea = el tiempo (atmosférico) | VRE-me-a
W cald = calor; cálido | kald
W frig = frío | frig
W soare = sol | SOA-re
W plouă = llueve | PLO-uă
W ninge = nieva | NIN-je
W vânt = viento | vînt
W vântul = el viento | VÎN-tul
W bate = sopla | BA-te
W bate vântul = hace viento | BA-te VÎN-tul
W zăpadă = nieve | ză-PA-dă
W înnorat = nublado | în-no-RAT
W afară = fuera; al aire libre | a-FA-ră
W umbrelă = paraguas | um-BRE-lă
W plajă = playa | PLA-jă
W frumoasă = bonita; agradable (femenino) | fru-MOA-să
W mergem = vamos | MER-jem
V Vocabulario: tiempo atmosférico
D Un plan para mañana
Elena: Cum este vremea azi? = ¿Qué tiempo hace hoy?
  > Cum este = cómo está | vremea = el tiempo | azi = hoy
Radu: Este frig și ninge. = Hace frío y nieva.
  > Este = hace | frig = frío | și = y | ninge = nieva
Elena: Mâine mergem la muzeu? = ¿Vamos al museo mañana?
  > Mâine = mañana | mergem = vamos | la muzeu = al museo
Radu: Da. Mâine mergem la muzeu. = Sí. Mañana vamos al museo.
  > Da = sí | Mâine = mañana | mergem = vamos | la muzeu = al museo
Q ¿Qué significa «plouă»?
+ Llueve. :: Es una expresión impersonal del tiempo.
- Nieva. :: «Ninge» significa «nieva».
- Hace frío. :: «Este frig» significa «hace frío».
Q ¿Qué significa «zăpadă»?
+ Nieve. :: Es la nieve que cae o cubre el suelo.
- Viento. :: «Vânt» significa «viento».
- Sol. :: «Soare» significa «sol».
R Este frig și ninge. :: Elige la traducción.
+ Hace frío y nieva. :: «Frig» es «frío» y «ninge», «nieva».
- Hace calor y llueve. :: «Cald» significa «calor» y «plouă», «llueve».
- Hace viento y hay sol. :: «Bate vântul» significa «hace viento».
H Afară este ___. :: Completa «Fuera está nublado».
+ înnorat :: «Înnorat» significa «nublado».
- cald :: Significa «cálido».
- frumoasă :: Es un adjetivo femenino que significa «agradable».
H Bate ___. :: Completa «Hace viento».
+ vântul :: La expresión «bate vântul» significa «hace viento».
- soare :: Significa «sol».
- zăpadă :: Significa «nieve».
A Cum este vremea azi? :: ¿Qué pregunta oyes?
+ ¿Qué tiempo hace hoy? :: «Vremea» significa «el tiempo atmosférico».
- ¿Qué fecha es hoy? :: Eso se dice «Ce dată este azi?».
- ¿Vamos al museo mañana? :: Eso se dice «Mergem la muzeu mâine?».
O este frig :: hace frío :: En rumano se dice literalmente «está frío».
X Escribe «Mañana vamos al museo» en rumano. :: Mâine mergem la muzeu. :: El presente también puede expresar un plan cercano cuando se indica «mâine».
