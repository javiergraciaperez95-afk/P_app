@ 15 | Cu autobuzul și cu trenul | En autobús y en tren
I Para viajar por la ciudad preguntamos dónde validar el billete y en qué parada bajarnos. **Stație** puede ser «parada» o «estación», según el transporte.
E Billetes y validación :: **A valida** significa «validar». **Validez** es «valido» y **validați** sirve para dar una instrucción cortés a una persona o a varias.
E Un falso amigo útil :: **Bilet** es un billete de transporte. No es un billete de banco: para eso se usa **bancnotă**. Con transporte decimos **cu autobuzul** («en autobús»), expresión vista en A1.

  > Unde validez = dónde valido | biletul = el billete

  > La validator = en el validador | lângă ușă = junto a la puerta

  > Biletul = el billete | este valabil = vale | pentru o călătorie = para un viaje

  > Urc în tramvai = subo al tranvía | și cobor la centru = y me bajo en el centro

  > Abonamentul = el abono | este valabil = vale | pentru metrou și tramvai = para el metro y el tranvía
- Validatorul este lângă ușă. = El validador está junto a la puerta.
  > Validatorul = el validador | este lângă ușă = está junto a la puerta
Q ¿Qué se valida?
+ biletul :: Es el billete de transporte.
- formularul :: Es el formulario de correos.
- timbrul :: Es el sello.
R Validați biletul înainte să urcați. :: Elige la traducción.
+ Valide el billete antes de subir. :: «Validați» es la forma cortés de una instrucción.
- Baje en la parada siguiente. :: Eso se dice «Coborâți la stația următoare».

H Cobor la stația ___. :: Completa «Me bajo en la parada siguiente».
+ următoare :: Concuerda con «stația», femenino singular.
- valabil :: Significa «válido» y es masculino.
- validatorul :: Significa «el validador».
A Urc în tramvai și cobor la centru. :: ¿Qué hace la persona?
+ Sube al tranvía y se baja en el centro. :: «Urc» es «subo» y «cobor», «me bajo».
- Valida el billete antes de subir. :: Eso se dice «Validați biletul înainte să urcați».

X Escribe en rumano: «Subo al tranvía y me bajo en el centro». :: Urc în tramvai și cobor la centru. :: «Urc» y «cobor» son formas de «yo».

- Validador. :: «Validator» significa «validador».

+ El billete vale para un viaje. :: «Călătorie» significa «viaje» o «trayecto».
- El abono está en el validador. :: Esa frase sería «Abonamentul este la validator».
- Me bajo en la parada siguiente. :: Eso se dice «Cobor la stația următoare».

@ 15 | La gară | En la estación de tren
I La página de trenes usa los apartados **plecări/sosiri** («salidas/llegadas») y permite buscar trayectos **de la** estación de salida **până la** la de destino.
E Preguntar por el horario :: **La ce oră pleacă...?** significa «¿A qué hora sale...?». Para decir de dónde a dónde va un trayecto usamos **de la... până la...**.
E Salidas y llegadas :: **Plecarea** es «la salida» y **sosirea**, «la llegada». **Peron** es el andén; **orar** es el horario. **Destinație** es destino.
W a pleca = salir; partir | a ple-KA
W pleacă = sale; parte | ple-AKă
W plecare = salida | ple-KA-re
W plecarea = la salida | ple-KA-re-a
W plecări = salidas | ple-KĂ-ri
W a sosi = llegar | a so-SI
W sosește = llega | so-SEȘ-te
W sosire = llegada | so-SI-re
W sosirea = la llegada | so-SI-re-a
W sosiri = llegadas | so-SI-ri
W peron = andén | pe-RON
W peronul = el andén | pe-RO-nul
W orar = horario | o-RAR
W orarul = el horario | o-RA-rul
W spre = hacia | spre
W până = hasta | PÎ-nă
W destinație = destino | des-ti-NA-tsi-e
W destinația = el destino | des-ti-NA-tsi-a
W rută = ruta | RU-tă
W ruta = la ruta | RU-ta
V Vocabulario: horarios y trayectos
D En la estación
Elena: La ce oră pleacă trenul spre Brașov? = ¿A qué hora sale el tren hacia Brașov?
  > La ce oră pleacă = a qué hora sale | trenul = el tren | spre Brașov = hacia Brașov
Angajat: Pleacă la ora opt. = Sale a las ocho.
  > Pleacă = sale | la ora opt = a las ocho
Elena: De la ce peron pleacă? = ¿De qué andén sale?
  > De la ce peron = de qué andén | pleacă = sale
Angajat: De la peronul trei. = Del andén tres.
  > De la peronul trei = del andén tres
Elena: La ce oră sosește la Brașov? = ¿A qué hora llega a Brașov?
  > La ce oră sosește = a qué hora llega | la Brașov = a Brașov
Angajat: Sosește la ora zece. = Llega a las diez.
  > Sosește = llega | la ora zece = a las diez
T El horario del tren
- Orarul are plecări și sosiri. = El horario tiene salidas y llegadas.
  > Orarul = el horario | are = tiene | plecări și sosiri = salidas y llegadas
- Ruta de la București până la Brașov are două stații. = La ruta de București a Brașov tiene dos paradas.
  > Ruta de la București până la Brașov = la ruta de București a Brașov | are două stații = tiene dos paradas
- Destinația este Brașov. = El destino es Brașov.
  > Destinația = el destino | este Brașov = es Brașov
Q ¿Qué significa «sosire»?
+ Llegada. :: «Sosire» es el nombre de la llegada.
- Salida. :: «Plecarea» es «la salida».
- Andén. :: «Peron» significa «andén».
R Trenul sosește la Iași. :: Elige la traducción.
+ El tren llega a Iași. :: «Sosește» significa «llega».
- El tren sale hacia Iași. :: «Pleacă» significa «sale».
- El tren llega a Brașov. :: La frase dice «Iași».
H Trenul pleacă de la ___. :: Completa «El tren sale de București».
+ București :: Es la estación de salida.
- peronul :: Significa «el andén».
- sosirea :: Significa «la llegada».
A La ce oră sosește trenul? :: ¿Qué pregunta oyes?
+ ¿A qué hora llega el tren? :: «Sosește» significa «llega».
- ¿De qué andén sale el tren? :: Eso se dice «De la ce peron pleacă trenul?».
- ¿A qué destino va el tren? :: «Destinație» significa «destino».
O de la București până la Brașov :: de București a Brașov :: «De la... până la...» expresa los dos extremos de un trayecto.
X Escribe en rumano: «El tren sale a las ocho». :: Trenul pleacă la ora opt. :: «Pleacă» es la forma de «el tren».
Q ¿Qué significa «peron»?
+ Andén. :: Es la zona donde se espera el tren.
- Estación. :: «Gară» significa «estación de tren».
- Destino. :: «Destinație» significa «destino».
R Orarul are plecări și sosiri. :: Elige la traducción.
+ El horario tiene salidas y llegadas. :: «Plecări» son salidas; «sosiri», llegadas.
- La estación tiene tres andenes. :: «Peron» significa «andén».
- El tren llega a las diez. :: Eso se dice «Trenul sosește la ora zece».

@ 15 | Trenul întârzie | El tren se retrasa
I En una conexión, pregunta si el tren llega a tiempo. **Dacă** significa «si» condicional: **Dacă trenul întârzie, pierd conexiunea** («Si el tren se retrasa, pierdo la conexión»).
E Comparar rutas :: Para decir «más rápido que», usamos **mai rapid decât**. El adjetivo concuerda con el sustantivo: **trenul direct** es masculino; **ruta directă**, femenino.
E Tren directo o con cambios :: En los horarios puedes ver rutas **directe** y rutas **cu schimbări** («con transbordos»). **Întârziere** es «retraso» y **conexiune** es la conexión con otro tren.

W întârzierea = el retraso | în-tîr-ZI-e-re-a
W minute = minutos | MI-nu-te

  > Verificați orarul = consulte el horario | vă rog = por favor

Q ¿Qué significa «întârziere»?
+ Retraso. :: Se refiere a que algo llega tarde.
- Conexión. :: «Conexiune» significa «conexión».
- Transbordo. :: «Schimbare» puede significar «transbordo».
R Trenul spre Iași întârzie. :: Elige la traducción.
+ El tren hacia Iași se retrasa. :: «Întârzie» significa «se retrasa».
- El tren hacia Iași es directo. :: «Direct» significa «directo».
- El tren hacia Iași llega a la estación. :: «Sosește» significa «llega».
H Dacă trenul ___, pierd conexiunea. :: Completa «Si el tren se retrasa, pierdo la conexión».
+ întârzie :: Es la forma de «el tren».

- directă :: Es un adjetivo femenino: «directa».
A Ruta directă este mai rapidă decât ruta cu schimbări. :: ¿Qué ruta es más rápida?

- Las dos rutas tienen retraso. :: La frase no habla de retraso.

- sosire :: «Sosire» significa «llegada».

- Sale a las ocho, por favor. :: Eso sería «Pleacă la ora opt».
- El tren llega con retraso. :: Eso sería «Trenul întârzie».
