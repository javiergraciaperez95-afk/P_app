@ 26 | Probleme de mediu | Problemas medioambientales
I Hablar del entorno incluye nombrar los residuos y explicar cómo las acciones cotidianas pueden reducir la contaminación.
E Vocabulario :: **Mediu** es «medioambiente» o «entorno»; **deșeuri** son «residuos». **Poluare** significa «contaminación».
E Acciones :: **Se reciclează** significa «se recicla». El pronombre **se** permite hablar del proceso en general sin indicar quién lo realiza.
W mediu = medioambiente; entorno | ME-di-u
W mediul = el medioambiente; el entorno | ME-di-ul
W poluare = contaminación | po-LU-a-re
W poluarea = la contaminación | po-LU-a-re-a
W deșeu = residuo | de-SHEU
W deșeuri = residuos | de-SHE-uri
W deșeurile = los residuos | de-SHEU-ri-le
W plastic = plástico | PLAS-tik
W sticlă = vidrio; botella | STI-clă
W sticla = el vidrio; la botella | STI-cla
W hârtie = papel | HÎR-ti-e
W hârtia = el papel | HÎR-ti-a
W reciclare = reciclaje | re-chi-KLA-re
W reciclarea = el reciclaje | re-chi-KLA-re-a
W reciclăm = reciclamos | re-chi-KLĂM
W se reciclează = se recicla | se re-chi-KLE-a-ză
W ambalaj = envase | am-ba-LAJ
W ambalajul = el envase | am-ba-LA-jul
W reutilizăm = reutilizamos | re-u-ti-li-ZĂM
W poluează = contamina; contamina (él/ella) | po-lu-E-a-ză
W reducem = reducimos | re-DU-chem
W prin = mediante; por | PRIN
V Vocabulario: residuos y reciclaje
D Cuidar el entorno
Ana: Ce facem cu sticla și hârtia? = ¿Qué hacemos con el vidrio y el papel?
  > Ce facem = qué hacemos | cu sticla și hârtia = con el vidrio y el papel
Mihai: Reciclăm sticla și hârtia. = Reciclamos el vidrio y el papel.
  > Reciclăm = reciclamos | sticla și hârtia = el vidrio y el papel
Ana: Și ambalajul? = ¿Y el envase?
  > Și = y | ambalajul = el envase
Mihai: Reutilizăm ambalajul. = Reutilizamos el envase.
  > Reutilizăm = reutilizamos | ambalajul = el envase
Ana: Deșeurile de plastic poluează mediul? = ¿Los residuos de plástico contaminan el medioambiente?
  > Deșeurile de plastic = los residuos de plástico | poluează mediul = contaminan el medioambiente
Mihai: Da. Reducem poluarea prin reciclare. = Sí. Reducimos la contaminación mediante el reciclaje.
  > Da = sí | Reducem poluarea = reducimos la contaminación | prin reciclare = mediante el reciclaje
T Acțiuni pentru mediu
- Reciclăm hârtia și sticla. = Reciclamos el papel y el vidrio.
  > Reciclăm = reciclamos | hârtia și sticla = el papel y el vidrio
- Sticla se reciclează. = El vidrio se recicla.
  > Sticla = el vidrio | se reciclează = se recicla
- Deșeurile de plastic poluează mediul. = Los residuos de plástico contaminan el medioambiente.
  > Deșeurile de plastic = los residuos de plástico | poluează mediul = contaminan el medioambiente
- Reutilizăm ambalajul. = Reutilizamos el envase.
  > Reutilizăm = reutilizamos | ambalajul = el envase
- Reducem poluarea prin reciclare. = Reducimos la contaminación mediante el reciclaje.
  > Reducem poluarea = reducimos la contaminación | prin reciclare = mediante el reciclaje
Q ¿Qué significa «deșeurile»?
+ Los residuos. :: Es la forma plural con artículo definido.
- El envase. :: «Ambalajul» significa «el envase».
- El medioambiente. :: «Mediul» significa «el medioambiente».
R Deșeurile de plastic poluează mediul. :: Elige la traducción.
+ Los residuos de plástico contaminan el medioambiente. :: «Poluează» expresa una acción que afecta al entorno.
- El plástico se recicla mediante el papel. :: La frase dice que los residuos contaminan el entorno.
- Reutilizamos el envase y el papel. :: Eso se dice «Reutilizăm ambalajul și hârtia».
H Sticla se ___. :: Completa «El vidrio se recicla».
+ reciclează :: Es la forma impersonal que describe el proceso.
- poluează :: Significa «contamina».
- reutilizăm :: Significa «reutilizamos».
A Reducem poluarea prin reciclare. :: ¿Qué hacemos?
+ Reducimos la contaminación mediante el reciclaje. :: «Reducem» significa «reducimos».
- Reutilizamos el plástico mediante el envase. :: La frase habla de reducir la contaminación.
- Contaminamos el papel y el vidrio. :: La frase habla de reducir y reciclar.
O hârtia și sticla :: el papel y el vidrio :: Los nombres aparecen en femenino en rumano.
X Escribe en rumano: «Reutilizamos el envase». :: Reutilizăm ambalajul. :: «Reutilizăm» expresa una acción habitual o actual.
Q ¿Qué significa «poluare»?
+ Contaminación. :: Es el nombre del problema medioambiental.
- Reciclaje. :: «Reciclare» significa «reciclaje».
- Residuo. :: «Deșeu» significa «residuo».
R Sticla se reciclează. :: Elige la traducción.
+ El vidrio se recicla. :: «Se reciclează» expresa el proceso en general.
- El vidrio contamina el medioambiente. :: «Poluează mediul» significa eso.
- Reducimos los residuos de plástico. :: Eso incluye «reducem deșeurile de plastic».

@ 26 | Cauze și consecințe | Causas y consecuencias
I Para explicar un problema ambiental, separa su causa de sus efectos. **Din cauza** introduce una causa; **prin urmare** presenta una consecuencia.
E Causa :: **Din cauza** va seguido de un nombre en genitivo: **din cauza fumului** («por el humo»), **din cauza traficului** («por el tráfico»).
E Resultado :: **Din acest motiv** y **prin urmare** señalan lo que ocurre como resultado. En español, el orden de causa y consecuencia puede expresarse de varias maneras.
W trafic = tráfico | tra-FIK
W traficul = el tráfico | tra-FI-kul
W traficului = del tráfico | tra-FI-ku-lui
W fum = humo | FUM
W fumul = el humo | FU-mul
W fumului = del humo | FU-mu-lui
W aer = aire | a-ER
W aerul = el aire | A-e-rul
W aerului = del aire | a-E-ru-lui
W calitate = calidad | ka-li-TA-te
W calitatea = la calidad | ka-li-TA-te-a
W emisiile = las emisiones | e-MI-si-i-le
W zgomot = ruido | ZGO-mot
W zgomotul = el ruido | ZGO-mo-tul
W din cauza = por culpa de; debido a | din KAU-za
W din acest motiv = por este motivo | din a-CHEST mo-TIV
W prin urmare = por lo tanto; por consiguiente | prin ur-MA-re
W scade = disminuye | SKA-de
W afectează = afecta | a-fek-TE-a-ză
W poluat = contaminado (masculino) | po-lu-AT
W a = de (marca del genitivo) | a
W sănătatea = la salud | să-nă-TA-te-a
V Vocabulario: contaminación y efectos
D El aire de la ciudad
Ana: De ce scade calitatea aerului? = ¿Por qué disminuye la calidad del aire?
  > De ce = por qué | scade calitatea aerului = disminuye la calidad del aire
Mihai: Din cauza traficului și a fumului. = Por el tráfico y el humo.
  > Din cauza traficului = por el tráfico | și a fumului = y por el humo
Ana: Emisiile afectează și sănătatea? = ¿Las emisiones también afectan a la salud?
  > Emisiile = las emisiones | afectează = afectan | și sănătatea = también la salud
Mihai: Da. Din acest motiv, reducem traficul. = Sí. Por este motivo, reducimos el tráfico.
  > Da = sí | Din acest motiv = por este motivo | reducem traficul = reducimos el tráfico
T Cauză și rezultat
- Traficul poluează aerul. = El tráfico contamina el aire.
  > Traficul = el tráfico | poluează aerul = contamina el aire
- Din cauza fumului, aerul este poluat. = Por el humo, el aire está contaminado.
  > Din cauza fumului = por el humo | aerul este poluat = el aire está contaminado
- Emisiile afectează calitatea aerului. = Las emisiones afectan a la calidad del aire.
  > Emisiile = las emisiones | afectează calitatea aerului = afectan a la calidad del aire
- Din acest motiv, calitatea scade. = Por este motivo, la calidad disminuye.
  > Din acest motiv = por este motivo | calitatea scade = la calidad disminuye
- Prin urmare, reducem traficul. = Por lo tanto, reducimos el tráfico.
  > Prin urmare = por lo tanto | reducem traficul = reducimos el tráfico
Q ¿Qué significa «din cauza»?
+ Por culpa de; debido a. :: Introduce el motivo o la causa.
- Por lo tanto. :: «Prin urmare» introduce una consecuencia.
- Por este motivo. :: «Din acest motiv» presenta una consecuencia.
R Din cauza traficului, calitatea aerului scade. :: Elige la traducción.
+ Debido al tráfico, disminuye la calidad del aire. :: «Din cauza» introduce la causa.
- Por lo tanto, mejora la calidad del aire. :: La frase habla de una disminución por el tráfico.
- El aire contamina el tráfico y las emisiones. :: La relación de causa está al revés.
H Din cauza ___, aerul este poluat. :: Completa «Por el humo, el aire está contaminado».
+ fumului :: Es el genitivo que sigue a «din cauza».
- fumul :: Es la forma definida de «humo», no el genitivo.
- aerului :: Significa «del aire».
A Emisiile afectează calitatea aerului. :: ¿Qué afecta a la calidad del aire?
+ Las emisiones. :: «Emisiile» significa «las emisiones».
- El ruido. :: «Zgomotul» significa «el ruido».
- El tráfico. :: «Traficul» significa «el tráfico».
O traficul poluează aerul :: el tráfico contamina el aire :: El sujeto es «traficul» y el objeto es «aerul».
X Escribe en rumano: «Por este motivo, reducimos el tráfico». :: Din acest motiv, reducem traficul. :: «Din acest motiv» expresa la consecuencia.
Q ¿Qué significa «prin urmare»?
+ Por lo tanto; por consiguiente. :: Introduce un resultado o una conclusión.
- Debido al humo. :: «Din cauza fumului» significa eso.
- Por este motivo. :: «Din acest motiv» significa eso.
R Din cauza fumului, aerul este poluat. :: Elige la traducción.
+ Por el humo, el aire está contaminado. :: La causa aparece al principio.
- Por lo tanto, el humo disminuye. :: La frase describe el aire contaminado.
- Las emisiones afectan a la salud. :: Eso se expresa con «Emisiile afectează sănătatea».

@ 26 | Acțiuni responsabile | Acciones responsables
I Una concesión reconoce un obstáculo que no impide la acción principal. **Deși** («aunque») introduce una oración completa con verbo.
E Concesión :: **Deși plouă, mergem pe jos** significa «Aunque llueve, vamos a pie». No añadas **dar** («pero») a la misma estructura con **deși**.
E Consumo :: **Economisesc** significa «ahorro»; **refolosesc**, «reutilizo». Puedes hablar de una acción responsable aunque la situación no sea ideal.
W deși = aunque | DEȘ
W cu toate acestea = aun así; a pesar de ello | ku TOA-te a-CES-te-a
W resurse = recursos | re-SUR-se
W puține = pocos; pocas | PU-tsi-ne
W consumul = el consumo | kon-SU-mul
W economisim = ahorramos | e-ko-no-mi-SIM
W risipa = el desperdicio | ri-SI-pa
W refolosesc = reutilizo | re-fo-lo-SESK
W refolosim = reutilizamos | re-fo-lo-SIM
W cu grijă = con cuidado | ku GRI-jă
W responsabilă = responsable (femenino) | res-pon-sa-BI-lă
W recipientul = el recipiente; el envase | re-ci-pi-EN-tul
W ambalajele = los envases | am-ba-LA-je-le
W energie = energía | e-ner-GI-e
W alegere = elección | a-LE-je-re
V Vocabulario: consumo responsable
D Una decisión cotidiana
Ana: Deși consumul este mare, ce facem? = Aunque el consumo es alto, ¿qué hacemos?
  > Deși consumul este mare = aunque el consumo es alto | ce facem = qué hacemos
Mihai: Economisim apă și reducem risipa. = Ahorramos agua y reducimos el desperdicio.
  > Economisim apă = ahorramos agua | și reducem risipa = y reducimos el desperdicio
Ana: Și ambalajele? = ¿Y los envases?
  > Și = y | ambalajele = los envases
Mihai: Cu toate acestea, refolosim recipientul cu grijă. = Aun así, reutilizamos el recipiente con cuidado.
  > Cu toate acestea = aun así | refolosim recipientul = reutilizamos el recipiente | cu grijă = con cuidado
T Obiceiuri responsabile
- Deși avem puține resurse, economisim apă. = Aunque tenemos pocos recursos, ahorramos agua.
  > Deși = aunque | avem puține resurse = tenemos pocos recursos | economisim apă = ahorramos agua
- Consumul de energie este mare. = El consumo de energía es alto.
  > Consumul = el consumo | de energie = de energía | este mare = es alto
- Cu toate acestea, reducem risipa. = Aun así, reducimos el desperdicio.
  > Cu toate acestea = aun así | reducem risipa = reducimos el desperdicio
- Refolosesc recipientul cu grijă. = Reutilizo el recipiente con cuidado.
  > Refolosesc recipientul = reutilizo el recipiente | cu grijă = con cuidado
- Este o alegere responsabilă. = Es una elección responsable.
  > Este = es | o alegere responsabilă = una elección responsable
Q ¿Qué significa «deși»?
+ Aunque. :: Introduce un obstáculo que no impide la acción principal.
- Por lo tanto. :: «Prin urmare» introduce una consecuencia.
- Debido a. :: «Din cauza» introduce una causa.
R Deși avem puține resurse, economisim apă. :: Elige la traducción.
+ Aunque tenemos pocos recursos, ahorramos agua. :: «Deși» introduce la concesión.
- Como tenemos pocos recursos, no ahorramos agua. :: La frase dice que ahorramos agua pese a la dificultad.
- Tenemos muchos recursos y desperdiciamos agua. :: «Puține» significa «pocos».
H Deși consumul este mare, ___ apă. :: Completa «Aunque el consumo es alto, ahorramos agua».
+ economisim :: Es la forma «ahorramos».
- risipă :: Es el nombre «desperdicio».
- refolosesc :: Significa «reutilizo».
A Cu toate acestea, reducem risipa. :: ¿Qué hacemos aun así?
+ Reducimos el desperdicio. :: «Reducem» significa «reducimos».
- Ahorramos agua. :: Eso se dice «Economisim apă».
- Reutilizamos el recipiente. :: Eso se dice «Refolosim recipientul».
O economisim apă :: ahorramos agua :: La acción expresa un consumo responsable.
X Escribe en rumano: «Aunque el consumo es alto, ahorramos agua». :: Deși consumul este mare, economisim apă. :: «Deși» introduce una concesión.
Q ¿Qué significa «cu grijă»?
+ Con cuidado. :: Indica que se actúa atentamente.
- Aun así. :: «Cu toate acestea» significa «aun así».
- Pocos recursos. :: «Puține resurse» significa eso.
R Refolosesc recipientul cu grijă. :: Elige la traducción.
+ Reutilizo el recipiente con cuidado. :: «Refolosesc» significa «reutilizo».
- Reducimos el desperdicio con cuidado. :: Eso sería «Reducem risipa cu grijă».
- Ahorramos energía porque consumimos poco. :: La frase no menciona la energía.
