@ 33 | Læs og find sammenhængen | Lee y encuentra la relación
I En el examen PD3 hay textos largos. Hoy aprendes a encontrar la idea principal y las palabras que unen las frases.
E Buscar la relación :: Para ubicar una frase que falta, busca palabras que la conectan con lo anterior: **det** (eso), **den** (ese), **derfor** (por eso), **dog** (sin embargo). :: Si la frase empieza con **Det** o **Den**, suele referirse a algo ya mencionado.
E Leer antes de contestar :: Primero lee el texto entero, luego las preguntas. Así sabes qué información buscar y no pierdes tiempo. :: Respuestas cortas: copia la palabra exacta, pero cambiando la forma si hace falta.
W fordel = ventaja | FOR-del | Lo contrario de «ulempe».
W udfordringer = retos; dificultades | ud-FOR-dring-er | Plural de «udfordring».
W cykelstierne = los carriles bici | SÜ-ke-stier-ne | Forma con artículo de «cykelsti».
W kendt = conocido
W klar = claro
V Vocabulario: lectura
T Cykelbyen København
- København er kendt for sine cykler. = Copenhague es conocida por sus bicicletas.
  > kendt for sine cykler = conocida por sus bicicletas
- Mange bruger cyklen hver dag, også om vinteren. = Muchos usan la bici cada día, también en invierno.
  > hver dag = cada día | også om vinteren = también en invierno
- Det har en klar fordel: man er hurtig i byen. = Eso tiene una clara ventaja: se va rápido por la ciudad.
  > Det har en klar fordel = eso tiene una clara ventaja | man er hurtig = uno es rápido
- Dog er der også udfordringer, fordi cykelstierne er små. = Sin embargo, también hay retos, porque los carriles bici son pequeños.
  > Dog er der = sin embargo hay | fordi cykelstierne er små = porque los carriles bici son pequeños
- Derfor arbejder byen på at gøre dem større. = Por eso la ciudad trabaja para hacerlos más grandes.
  > Derfor arbejder byen = por eso la ciudad trabaja | på at gøre dem større = para hacerlos más grandes
Q En el texto, ¿qué palabra significa «sin embargo»?
+ Dog :: Es el conector de contraste del texto.
- Derfor :: Significa «por eso».
- Det :: Es el pronombre «eso».
Q ¿Qué se refiere «Det» en «Det har en klar fordel»?
+ La bicicleta (el uso de la bici) :: Lo que se menciona antes: usar la bici.
- Copenhague :: Es el tema, pero no lo que se refiere.
- Las calles :: No aparece antes.
H ___ har en klar fordel: man er hurtig i byen. :: pista: eso
+ Det :: Pronombre neutro que resume lo anterior.
- Dog :: Significa «sin embargo».
- Derfor :: Significa «por eso».
R Derfor arbejder byen på at gøre dem større.
+ Por eso la ciudad trabaja para hacerlos más grandes. :: «derfor» = por eso.
- La ciudad trabaja sin embargo para hacerlos grandes. :: Eso sería «dog».
- La ciudad ya los hizo grandes. :: No lo dice.
A Dog er der også udfordringer.
+ Sin embargo, también hay retos. :: «dog» = sin embargo.
- Tampoco hay retos. :: Eso sería «heller ikke».
- Por eso hay retos. :: Eso sería «derfor».
O Mange bruger cyklen hver dag :: Muchos usan la bici cada día :: sujeto + verbo + objeto + tiempo.
Q ¿Qué significa «udfordringer»?
+ retos; dificultades :: Algo que hay que superar.
- ventajas :: Eso sería «fordele».
- precios :: Eso sería «priser».
X ¿Cómo dices «por eso» en danés? :: derfor | Derfor :: Conector de consecuencia.

@ 33 | Kære Louise, tak for sidst | Querida Louise, gracias por la última vez
I Lee un correo informal y reconoce el lenguaje habitual para resumir tendencias de un gráfico.
E Reconocer un correo informal :: **Kære** y **Hej** pueden abrir un correo; **Knus** es una despedida cercana. Observa quién escribe y qué pregunta antes de interpretar una frase aislada. :: **Tak for sidst** alude a una ocasión compartida reciente.
E Interpretar tendencias :: **Stiger** (sube), **falder** (baja) y **er stort set uændret** (permanece prácticamente igual) describen cambios distintos. Antes de resumir, identifica qué variable se mide y durante qué periodo. :: **Alt i alt viser tallene, at …** introduce una conclusión general, que debe corresponder a los datos.
B Función | Expresión | Ejemplo
| subir | stiger | Antallet af cyklister stiger.
| bajar | falder | Prisen falder i sommer.
| casi igual | er stort set uændret | Bruget er stort set uændret.
| concluir | alt i alt viser tallene | Alt i alt viser tallene, at cyklen bliver mere populær.

W falder = baja | FAL-der | Forma de «falde».

  > svarer gerne = contesto con gusto | hvis du vil vide det = si quieres saberlo

  > Knus = un abrazo
T Gráfico de ciclistas

  > stiger hvert år = sube cada año
- Prisen på bilerne falder lidt. = El precio de los coches baja un poco.
  > falder lidt = baja un poco
- Brugen af bussen er stort set uændret. = El uso del autobús está prácticamente igual.
  > er stort set uændret = está prácticamente igual

  > Alt i alt viser tallene = en resumen las cifras muestran
Q ¿Qué significa «stiger»?
+ sube :: Lo contrario de «falder».
- baja :: Eso sería «falder».
- queda igual :: Eso sería «er uændret».
H Antallet af cyklister ___ hvert år. :: pista: sube
+ stiger :: Presente de «stige»: sube.
- falder :: Eso es «baja».
- stigede :: Es pasado.
R Brugen af bussen er stort set uændret.

- El uso del autobús cambió mucho. :: No es «uændret».

- En resumen, el coche es más popular. :: No lo dice la frase.
- En resumen, las cifras son malas. :: No lo dice la frase.
O Jeg svarer gerne, hvis du vil vide det :: Te contesto con gusto, si quieres saberlo :: sujeto + verbo + adverbio + subordinada.
Q ¿Qué significa «populær»?
+ popular :: Muy conocido o querido.
- caro :: Eso sería «dyr».
- aburrido :: Eso sería «kedelig».
X ¿Cómo dices «sube» en danés? :: stiger | Stiger :: Verbo para subir.

@ 33 | Repetition af B2 | Repaso acumulativo B2

E Repaso :: Las preguntas «Cap.» retoman contenidos anteriores. Lee cada frase completa y valora si se pregunta por forma, significado o relación entre ideas.
Q Cap. 26. ¿Qué significa «Den roman har jeg læst»?
+ Esa novela la he leído. :: El objeto va delante para destacarlo.
- Yo he leído una novela. :: No destaca «esa novela».
- Esa novela me ha leído. :: «læst» no cambia de sujeto.
H Cap. 26. Det var Lars, ___ ringede. :: pista: quien (sujeto)
+ der :: Con sujeto se usa «der».
- som :: Con objeto se usa «som», aquí el sujeto es Lars.

R Cap. 26. Hverken Anna eller Peter kom til festen.
