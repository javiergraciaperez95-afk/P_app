@ 15 | 가 본 적이 있어요 | Experiencias: ¿has hecho algo alguna vez?
E Haber hecho algo alguna vez :: Para hablar de una experiencia se usa **-(으)ㄴ 적이 있어요** (he… alguna vez). Se pone el verbo en forma de pasado delante de **적이**: 가다 → **간 적이 있어요** (he ido alguna vez), 먹다 → **먹은 적이 있어요** (he comido alguna vez). :: 한국에 **간 적이** 있어요 = he estado en Corea alguna vez.
E Nunca :: Para decir que nunca lo has hecho se cambia **있어요** por **없어요**: 먹은 적이 **없어요** = nunca he comido. Con **한 번도** (ni una vez) se refuerza: 한 번도 간 적이 없어요 = nunca he ido.
B Verbo | Pasado delante de 적이 | Alguna vez | Nunca
| 가다 | 간 적이 | 간 적이 있어요 = he ido | 간 적이 없어요 = nunca he ido
| 먹다 | 먹은 적이 | 먹은 적이 있어요 = he comido | 먹은 적이 없어요 = nunca he comido
| 보다 | 본 적이 | 본 적이 있어요 = lo he visto | 본 적이 없어요 = nunca lo he visto
W 적 = vez, experiencia
W 간 적이 있어요 = he ido alguna vez
W 간 적이 없어요 = nunca he ido
W 먹은 적이 있어요 = he comido alguna vez
W 먹은 적이 없어요 = nunca he comido
W 본 적이 있어요 = lo he visto alguna vez
W 한 번도 = ni una vez, nunca
V Vocabulario: experiencias
D ¿Has probado la comida coreana?
안나: 민수 씨, 한국 음식을 먹은 적이 있어요? = Minsu, ¿alguna vez has comido comida coreana?
  > 한국 음식을 = la comida coreana | 먹은 적이 있어요 = has comido alguna vez
민수: 네, 김치찌개를 먹은 적이 있어요. 아주 맛있어요. = Sí, he comido kimchi jjigae alguna vez. Está riquísimo.
  > 김치찌개를 = el kimchi jjigae | 먹은 적이 있어요 = he comido alguna vez | 아주 맛있어요 = está riquísimo
안나: 그럼 한국에 간 적이 있어요? = Entonces, ¿has estado en Corea alguna vez?
  > 한국에 = en Corea | 간 적이 있어요 = has ido alguna vez
민수: 아니요, 한 번도 간 적이 없어요. = No, nunca he ido.
  > 한 번도 = ni una vez | 간 적이 없어요 = nunca he ido
안나: 그럼 같이 가요! = ¡Entonces, vamos juntos!
  > 같이 가요 = vamos juntos
Q ¿Qué significa «한국에 간 적이 있어요?»?
+ ¿Has estado en Corea alguna vez? :: 간 적이 있어요 = has ido alguna vez.
- ¿Vas a ir a Corea? :: Eso sería 갈 거예요?
- ¿Fuiste a Corea ayer? :: Eso sería 어제 갔어요?
H 한국 음식을 ___? :: ¿has comido alguna vez?
+ 먹은 적이 있어요 :: 먹다 → 먹은 적이 있어요.
- 먹어요 :: Es «comes», presente.
- 먹을 거예요 :: Es «vas a comer», futuro.
R 한 번도 간 적이 없어요.
+ Nunca he ido. :: 한 번도 = ni una vez. 간 적이 없어요 = nunca he ido.
- He ido una vez. :: Eso sería 한 번 간 적이 있어요.
- Voy a ir mañana. :: Eso sería 내일 가요.
A 김치찌개를 먹은 적이 있어요. :: ¿Qué dice la persona?
+ Ha comido kimchi jjigae alguna vez. :: 먹은 적이 있어요 = ha comido alguna vez.
- Come kimchi jjigae todos los días. :: Eso sería 매일 먹어요.
- Va a comer kimchi jjigae. :: Eso sería 먹을 거예요.
O 한국에 간 적이 있어요 :: He estado en Corea alguna vez :: 한국에 = en Corea. 간 적이 있어요 = he ido alguna vez.
Q ¿Cómo dices «nunca he comido»?
+ 먹은 적이 없어요 :: 있어요 cambia a 없어요 para negar.
- 먹은 적이 있어요 :: Es «he comido alguna vez».
- 먹어요 :: Es «como».
H 이 식당에 ___? :: ¿has ido alguna vez?
+ 간 적이 있어요 :: 가다 → 간 적이 있어요.
- 가요 :: Es «voy», presente.
- 갈 거예요 :: Es «voy a ir», futuro.
R 이 영화를 본 적이 있어요?
+ ¿Has visto esta película alguna vez? :: 본 적이 있어요 = lo has visto alguna vez.
- ¿Vas a ver esta película mañana? :: Eso sería 내일 볼 거예요?
- ¿Ves esta película ahora? :: Eso sería 봐요.
@ 15 | 먹어 봤어요 | Probar algo: -아/어 보다
E Probar o intentar :: **-아/어 보다** añade la idea de probar o intentar una acción: 먹다 → **먹어 보다** (probar a comer), 입다 → **입어 보다** (probarse ropa), 하다 → **해 보다** (intentar hacerlo). La forma se combina con el tiempo y el nivel de habla: 먹어 **봤어요** (lo probé) y 한번 먹어 **보세요** (pruébelo una vez).
E Diferencia con 적이 있어요 :: **-(으)ㄴ 적이 있어요** cuenta una experiencia que ya tuviste; **-아/어 보다** cuenta algo que pruebas o intentas. :: 먹은 적이 있어요 = lo he comido alguna vez. 먹어 봤어요 = lo he probado (lo probé).
B Verbo | Raíz | Probar (orden cortés) | Lo probé (pasado)
| 먹다 | 먹 | 먹어 보세요 = pruebe | 먹어 봤어요 = lo probé
| 입다 | 입 | 입어 보세요 = pruébeselo | 입어 봤어요 = me lo probé
| 하다 | 하 | 해 보세요 = inténtelo | 해 봤어요 = lo intenté
| 가다 | 가 | 가 보세요 = vaya a ver | 가 봤어요 = fui a ver
W 먹어 보세요 = pruebe
W 먹어 봤어요 = lo probé
W 먹어 봐요 = lo pruebo, pruebas
W 입었어요 = llevé, me puse (ropa)
W 해 보세요 = inténtelo, pruébelo
W 해 봤어요 = lo intenté, lo hice una vez
W 가 봤어요 = fui a ver, estuve allí
W 한번 = una vez (intentar algo)
W 처음 = primera vez
W 또 = otra vez, más
W 드릴까요 = ¿le sirvo?, ¿quiere que le sirva?
V Vocabulario: probar algo
D Probar el kimchi jjigae
직원: 이 김치찌개 한번 먹어 보세요. = Pruebe este kimchi jjigae, una vez.
  > 이 김치찌개 = este kimchi jjigae | 한번 = una vez | 먹어 보세요 = pruebe
손님: 와, 맛있어요! 저 이거 처음 먹어 봐요. = ¡Qué rico! Es la primera vez que lo pruebo.
  > 맛있어요 = está rico | 이거 = esto | 처음 = la primera vez | 먹어 봐요 = lo pruebo
직원: 그럼 또 드릴까요? = ¿Entonces le sirvo más?
  > 또 = más | 드릴까요 = ¿le sirvo?
손님: 네, 주세요. = Sí, por favor.
  > 주세요 = por favor, deme
Q ¿Qué expresa «한번 먹어 보세요»?
+ Una invitación cortés a probarlo una vez. :: -아/어 보세요 sugiere probar la acción.
- Una orden de comerlo todo. :: No se usa una forma de cantidad ni de terminarlo.
- Una afirmación de que ya lo probó. :: El pasado sería 먹어 봤어요.
H 이 옷을 ___. :: pruébeselo
+ 입어 보세요 :: 입다 → 입어 보세요.
- 입어요 :: Es «lo llevo», sin probar.
- 입었어요 :: Es «me lo puse / lo llevé», pasado.
R 저 이거 처음 먹어 봐요.
+ Es la primera vez que lo pruebo. :: 처음 = la primera vez. 먹어 봐요 = lo pruebo.
- Lo como todos los días. :: Eso sería 매일 먹어요.
- Lo pruebo otra vez. :: Eso sería 또 먹어 봐요.
A 한번 해 보세요. :: ¿Qué dice la persona?
+ Inténtelo una vez. :: 해 보세요 = inténtelo. 한번 = una vez.
- No lo haga nunca. :: Eso sería 하지 마세요.
- Hágalo siempre. :: Eso sería 항상 하세요.
O 이 김치찌개 맛있어요 :: Este kimchi jjigae está rico :: 이 = este. 맛있어요 = está rico.
Q ¿Qué significa «가 봤어요»?
+ Fui a ver. :: 가 봤어요 = fui a ver, estuve allí.
- Iré a ver. :: Eso sería 가 볼 거예요.
- Voy ahora. :: Eso sería 가요.
Q ¿Cómo se dice «inténtelo»?
+ 해 보세요 :: 하다 → 해 보세요.
- 하세요 :: Es «haga, por favor».
- 해 봤어요 :: Es «lo intenté».
H 또 ___? :: ¿le sirvo?
+ 드릴까요 :: 드리다 + ㄹ까요.
- 드세요 :: Es «coma, por favor».
- 드렸어요 :: Es «le serví», pasado.
@ 15 | 놀이공원 | Probar lo que quieres hacer: -아/어 보고 싶어요
E Querer probar :: Para decir que quieres probar algo se usa **-아/어 보고 싶어요** (quiero probar a…). Es la misma forma de **-아/어 보다** más **-고 싶어요** de A1. :: 타다 → **타 보고 싶어요** (quiero probar a subir), 먹다 → **먹어 보고 싶어요** (quiero probarlo).
E Experiencia o intento :: **-(으)ㄴ 적이 있어요** cuenta lo que ya hiciste; **-아/어 보고 싶어요** cuenta lo que quieres hacer. :: 가 본 적이 없어요 = nunca he ido. 한번 가 보고 싶어요 = quiero ir una vez.
B Frase | Qué significa
| 타 보고 싶어요 | quiero probar a subir
| 가 본 적이 없어요 | nunca he ido
| 먹어 보고 싶어요 | quiero probar a comerlo
W 놀이공원 = parque de atracciones
W 롤러코스터 = montaña rusa
W 타 봐요 = probemos a subir, subamos
W 타 보고 싶어요 = quiero probar a subir
W 타 보고 싶었어요 = quería probar a subir
W 싶었어요 = quería
W 무서워요 = da miedo, tengo miedo
W 가 본 적이 없어요 = nunca he ido (a ver)
W 가 본 적이 있어요 = he ido alguna vez (a ver)
W 먹어 보고 싶어요 = quiero probarlo
W 놀이공원에 = al parque de atracciones
V Vocabulario: parque de atracciones
D Una montaña rusa
안나: 이 놀이공원에 가 본 적이 있어요? = ¿Alguna vez has ido a este parque de atracciones?
  > 이 놀이공원에 = a este parque de atracciones | 가 본 적이 있어요 = has ido alguna vez
민수: 아니요, 가 본 적이 없어요. = No, nunca he ido.
  > 가 본 적이 없어요 = nunca he ido
안나: 그럼 롤러코스터를 타 봐요! = ¡Entonces, probemos la montaña rusa!
  > 롤러코스터를 = la montaña rusa | 타 봐요 = probemos a subir
민수: 조금 무서워요. 그래도 한번 타 보고 싶었어요. = Me da un poco de miedo. Pero quería probarla una vez.
  > 조금 무서워요 = me da un poco de miedo | 그래도 = aun así | 타 보고 싶었어요 = quería probar a subir
Q ¿Qué significa «타 보고 싶어요»?
+ Quiero probar a subir. :: 타 보고 싶어요 = quiero probar a subir.
- Subí ayer. :: Eso sería 어제 탔어요.
- Subo todos los días. :: Eso sería 매일 타요.
H 저는 한번 ___. :: quiero probarlo
+ 먹어 보고 싶어요 :: 먹다 → 먹어 보고 싶어요.
- 먹어 봤어요 :: Es «lo probé», pasado.
- 먹고 싶어요 :: Es «quiero comer», sin probar.
R 가 본 적이 없어요.
+ Nunca he ido. :: 가 본 적이 없어요 = nunca he ido.
- He ido a menudo. :: Eso sería 자주 가요.
- Iré mañana. :: Eso sería 내일 갈 거예요.
A 롤러코스터를 타 봐요. :: ¿Qué propone la persona?
+ Probemos a subir a la montaña rusa. :: 타 봐요 = probemos a subir.
- Miremos la montaña rusa. :: Eso sería 롤러코스터를 봐요.
- Compremos la montaña rusa. :: Eso sería 사요.
O 놀이공원에 가 본 적이 없어요 :: Nunca he ido al parque de atracciones :: 놀이공원에 = al parque de atracciones. 가 본 적이 없어요 = nunca he ido.
Q ¿Qué significa «싶었어요»?
+ Quería. :: 싶었어요 es el pasado de 싶어요.
- Quiero. :: Es 싶어요, presente.
- Querré. :: Eso sería 싶을 거예요.
H 롤러코스터가 ___. :: da miedo
+ 무서워요 :: 무섭다 → 무서워요: da miedo.
- 재미있어요 :: Es «es divertido».
- 작아요 :: Es «es pequeño».
Q ¿Cuál es la forma de «quiero probar a comer»?
+ 먹어 보고 싶어요 :: 먹다 → 먹어 보고 싶어요.
- 먹고 싶어요 :: Es «quiero comer», sin probar.
- 먹어 봤어요 :: Es «lo probé», pasado.
