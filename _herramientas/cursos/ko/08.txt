@ 8 | 어떻게 가요? | Preguntar el camino
E Pedir algo con educación: -(으)세요 :: Para pedir o indicar algo con respeto se añade a la raíz **-세요** (tras vocal) o **-으세요** (tras consonante). :: 가다 → **가세요** (vaya). 오다 → **오세요** (venga). 기다리다 → **기다리세요** (espere). 앉다 → **앉으세요** (siéntese). :: Ya conocías varias sin saberlo: 안녕히 가세요, 어서 오세요, 주세요.
B Peticiones | Diccionario | Petición | Español
| 가다 | 가세요 | vaya
| 오다 | 오세요 | venga
| 보다 | 보세요 | mire
| 기다리다 | 기다리세요 | espere
| 앉다 | 앉으세요 | siéntese
| 건너다 | 건너세요 | cruce
E Las indicaciones :: **어떻게** = cómo. **지하철역에 어떻게 가요?** = ¿cómo se va a la estación de metro? :: **똑바로 가세요** = siga recto. :: La dirección lleva **으로** (hacia): **오른쪽으로** 가세요 (vaya a la derecha), **왼쪽으로** 가세요 (vaya a la izquierda). :: **사거리에서** = en el cruce. **길을 건너세요** = cruce la calle.
E Cerca o lejos :: **멀어요** = está lejos. **가까워요** = está cerca. :: **걸어서** = andando. **걸려요** = se tarda. **쯤** pegado a una cantidad significa «más o menos»: 걸어서 오 분**쯤** 걸려요 = andando se tarda unos cinco minutos. :: Si te dan las gracias, puedes contestar **아니에요** («no es nada»).
W 어떻게 = cómo
W 길 = calle, camino
W 똑바로 = recto, todo seguido
W 오른쪽 = derecha
W 왼쪽 = izquierda
W 사거리 = cruce
W 가세요 = vaya
W 오세요 = venga
W 보세요 = mire
W 기다리세요 = espere
W 앉으세요 = siéntese
W 건너세요 = cruce
W 멀어요 = está lejos
W 가까워요 = está cerca
W 걸어서 = andando
W 걸려요 = se tarda
V Vocabulario: el camino
D ¿Cómo se va al metro?
안나: 실례합니다. 지하철역에 어떻게 가요? = Disculpe. ¿Cómo se va a la estación de metro?
  > 지하철역에 = a la estación de metro | 어떻게 가요 = cómo se va
준호: 여기에서 똑바로 가세요. 그리고 사거리에서 오른쪽으로 가세요. = Desde aquí siga recto. Y en el cruce vaya a la derecha.
  > 여기에서 = desde aquí | 똑바로 가세요 = siga recto | 사거리에서 = en el cruce | 오른쪽으로 = hacia la derecha
안나: 사거리에서 오른쪽으로 가요? = ¿En el cruce voy a la derecha?
  > 가요 = voy
준호: 네. 은행 옆에 지하철역이 있어요. = Sí. La estación está al lado del banco.
  > 은행 옆에 = al lado del banco
안나: 여기에서 멀어요? = ¿Está lejos de aquí?
  > 멀어요 = está lejos
준호: 아니요, 가까워요. 걸어서 오 분쯤 걸려요. = No, está cerca. Andando se tarda unos cinco minutos.
  > 가까워요 = está cerca | 걸어서 = andando | 오 분쯤 = unos cinco minutos | 걸려요 = se tarda
안나: 감사합니다. = Gracias.
  > 감사합니다 = gracias
준호: 아니에요. = De nada.
  > 아니에요 = «no es nada»: de nada
T Peticiones amables
- 여기 앉으세요. = Siéntese aquí.
  > 앉으세요 = siéntese
- 여기에서 기다리세요. = Espere aquí.
  > 기다리세요 = espere
- 이 책을 보세요. = Mire este libro.
  > 보세요 = mire
- 길을 건너세요. = Cruce la calle.
  > 길을 = la calle (objeto)
- 내일 우리 집에 오세요. = Venga mañana a mi casa.
  > 우리 집에 오세요 = venga a nuestra casa
Q ¿Cómo preguntas cómo se va al hospital?
+ 병원에 어떻게 가요? :: 어떻게 = cómo.
- 병원에 왜 가요? :: Eso es «¿por qué vas al hospital?».
- 병원이 얼마예요? :: Eso es «¿cuánto cuesta el hospital?».
Q ¿Cómo dices «siéntese»? (앉다)
+ 앉으세요. :: Raíz en consonante: 으세요.
- 앉세요. :: Tras consonante hace falta 으.
- 앉으요. :: No existe.
Q ¿Qué significa «오른쪽»?
+ derecha :: Izquierda es 왼쪽.
- izquierda :: Eso es 왼쪽.
- recto :: Eso es 똑바로.
R 똑바로 가세요.
+ Siga recto. :: 똑바로 = recto.
- Vaya a la derecha. :: Sería 오른쪽으로.
- Espere aquí. :: Sería 기다리세요.
H 사거리에서 왼쪽___ 가세요.
+ 으로 :: Dirección: 으로 (tras consonante).
- 을 :: Esa marca el objeto.
- 보다 :: Eso es «que».
H 걸어서 십 분쯤 ___.
+ 걸려요 :: Se tarda.
- 가까워요 :: Eso es «está cerca».
- 멀어요 :: Eso es «está lejos».
A 여기에서 멀어요?
+ ¿Está lejos de aquí? :: 멀어요 = lejos.
- ¿Está cerca de aquí? :: Sería 가까워요.
- ¿Dónde está? :: Sería 어디에 있어요?
A 여기에서 기다리세요.
+ Espere aquí. :: 기다리세요 = espere.
- Siéntese aquí. :: Sería 앉으세요.
- Venga aquí. :: Sería 오세요.
O 사거리에서 오른쪽으로 가세요 :: En el cruce, vaya a la derecha :: Dónde + hacia dónde + vaya.

@ 8 | 지하철로 가요 | El transporte
E En qué vas: (으)로 :: El medio de transporte lleva **로** (tras vocal o tras ㄹ) o **으로** (tras otra consonante): 버스**로** (en autobús), 지하철**로** (en metro), 택시**로** (en taxi), 기차**로** (en tren), 비행기**로** (en avión). :: Andando es **걸어서**.
E Subir, bajar, cambiar :: **타요** = montar, coger. Lleva 을/를: 버스**를** 타요 (cojo el autobús). :: **내려요** = bajarse: 서울역**에서** 내려요 (me bajo en la estación de Seúl). :: **갈아타요** = hacer trasbordo.
E De… a… y cuánto se tarda :: Entre dos lugares: **에서** (de) … **까지** (a). 집**에서** 회사**까지** = de casa a la empresa. :: **얼마나 걸려요?** = ¿cuánto se tarda? :: La duración: los minutos, como siempre (삼십 분). Las horas de duración son **시간**, con números coreanos: 한 **시간** (una hora), 두 **시간** (dos horas). No lo confundas con 시, que es la hora del reloj. :: **시간** significa también «tiempo»: **시간이 없어요** = no tengo tiempo.
B Transportes | Coreano | Español
| 버스 | autobús
| 지하철 | metro
| 택시 | taxi
| 기차 | tren
| 비행기 | avión
| 자전거 | bicicleta
W 지하철 = metro
W 택시 = taxi
W 기차 = tren
W 비행기 = avión
W 자전거 = bicicleta
W 타요 = montar, coger (un transporte)
W 내려요 = bajarse
W 갈아타요 = hacer trasbordo
W 얼마나 = cuánto (tiempo, cantidad)
W 시간 = hora (de duración); tiempo
W 공항 = aeropuerto
W 호텔 = hotel
W 부산 = Busan (ciudad de Corea)
W 정류장 = parada
W 표 = billete
W 왜요 = ¿por qué?
w 사십 = cuarenta
w 시간이 = tiempo + 이 (sujeto)
w 서울역 = la estación de Seúl
V Vocabulario: el transporte
D ¿Cómo vas al trabajo?
카를로스: 지은 씨는 회사에 어떻게 가요? = Jieun, ¿cómo va a la empresa?
  > 회사에 = a la empresa | 어떻게 가요 = cómo va
지은: 지하철로 가요. = Voy en metro.
  > 지하철로 = en metro
카를로스: 집에서 회사까지 얼마나 걸려요? = ¿Cuánto tarda de casa a la empresa?
  > 집에서 = de casa | 회사까지 = hasta la empresa | 얼마나 걸려요 = cuánto se tarda
지은: 사십 분쯤 걸려요. 카를로스 씨는 학교에 어떻게 가요? = Unos cuarenta minutos. ¿Usted cómo va a la escuela?
  > 사십 분쯤 = unos cuarenta minutos
카를로스: 보통 버스를 타요. 하지만 오늘은 택시로 가요. = Normalmente cojo el autobús. Pero hoy voy en taxi.
  > 버스를 타요 = cojo el autobús | 택시로 = en taxi
지은: 왜요? = ¿Por qué?
  > 왜요 = ¿por qué?
카를로스: 시간이 없어요! = ¡No tengo tiempo!
  > 시간이 없어요 = no hay tiempo
T De viaje
- 서울에서 부산까지 기차로 두 시간 반 걸려요. = De Seúl a Busan se tarda dos horas y media en tren.
  > 서울에서 부산까지 = de Seúl a Busan | 기차로 = en tren | 두 시간 반 = dos horas y media
- 비행기로 한 시간 걸려요. = En avión se tarda una hora.
  > 비행기로 = en avión | 한 시간 = una hora
- 공항에서 호텔까지 버스를 타요. = Del aeropuerto al hotel cojo el autobús.
  > 공항에서 호텔까지 = del aeropuerto al hotel
- 서울역에서 내려요. = Me bajo en la estación de Seúl.
  > 내려요 = me bajo
- 저는 매일 자전거로 학교에 가요. = Yo voy todos los días a la escuela en bicicleta.
  > 자전거로 = en bicicleta
Q ¿Cómo dices «voy en metro»?
+ 지하철로 가요. :: Medio de transporte + 로.
- 지하철에 가요. :: Eso es «voy al metro».
- 지하철을 가요. :: 을 no sirve aquí.
Q ¿Cómo dices «cojo el autobús»?
+ 버스를 타요. :: 타요 = montar.
- 버스를 내려요. :: 내려요 es «bajarse».
- 버스를 걸려요. :: 걸려요 es «se tarda».
Q ¿Cómo se dice «dos horas» (de duración)?
+ 두 시간 :: Duración: 시간.
- 두 시 :: Eso es «las dos» en el reloj.
- 이 분 :: Eso es «dos minutos».
R 얼마나 걸려요?
+ ¿Cuánto se tarda? :: 걸려요 = se tarda.
- ¿Cuánto cuesta? :: Sería 얼마예요?
- ¿Qué hora es? :: Sería 몇 시예요?
H 집___ 회사까지 삼십 분 걸려요.
+ 에서 :: 에서 … 까지 = de … a.
- 를 :: Esa marca el objeto.
- 도 :: Eso es «también».
H 저는 버스___ 타요.
+ 를 :: 타요 lleva 을/를.
- 에서 :: Esa marca dónde se hace algo.
- 보다 :: Eso es «que».
A 서울에서 부산까지 기차로 가요.
+ Voy de Seúl a Busan en tren. :: 기차 = tren.
- Voy de Seúl a Busan en avión. :: Avión es 비행기.
- Voy de Busan a Seúl en tren. :: Es al revés.
A 시간이 없어요.
+ No tengo tiempo. :: 시간 = tiempo.
- No tengo billete. :: Billete es 표.
- No tengo dinero. :: No dice eso.
O 저는 지하철로 회사에 가요 :: Voy a la empresa en metro :: Tema + en qué + adónde + voy.

@ 8 | 할 수 있어요 | Lo que puedes y lo que sabes hacer
E Poder: -(으)ㄹ 수 있어요 :: Para decir que puedes o sabes hacer algo, a la raíz se le añade **-ㄹ 수 있어요** (tras vocal) o **-을 수 있어요** (tras consonante). :: 하다 → **할 수 있어요** (puedo hacerlo). 가다 → **갈 수 있어요** (puedo ir). 읽다 → **읽을 수 있어요** (sé leer). 먹다 → **먹을 수 있어요** (puedo comer). :: Para decir que no: **수 없어요**. 갈 수 없어요 = no puedo ir.
B Poder + verbo | Diccionario | Puedo… | Español
| 하다 | 할 수 있어요 | puedo hacer
| 가다 | 갈 수 있어요 | puedo ir
| 오다 | 올 수 있어요 | puedo venir
| 읽다 | 읽을 수 있어요 | sé leer
| 먹다 | 먹을 수 있어요 | puedo comer
E No poder, en corto: 못 :: Hay una forma más corta: **못** delante del verbo. **못 가요** = no puedo ir. **못 먹어요** = no puedo comer. :: Compara: **안** 가요 = no voy (no quiero o no toca). **못** 가요 = no puedo ir. :: Con 해요: **못해요** = no sé, no se me da.
E Bien, todavía, rápido :: **잘** = bien. **잘해요** = se le da bien. **잘 못해요** = no se me da muy bien. :: **아직** = todavía. **빨리** = rápido. :: Delante de un nombre, «picante» es **매운**: 매운 음식 = comida picante.
W 수 있어요 = poder, saber (detrás del verbo)
W 수 없어요 = no poder (detrás del verbo)
W 못 = no poder (delante del verbo)
W 못해요 = no sé, no se me da
W 잘 = bien
W 잘해요 = se le da bien
W 아직 = todavía
W 빨리 = rápido, deprisa
W 수영 = natación
W 운전 = conducir, la conducción
W 피아노 = piano
W 쳐요 = tocar (piano, guitarra)
W 매운 = picante (delante de nombre)
w 할 = hacer (ante 수 있어요)
w 갈 = ir (ante 수 있어요)
w 올 = venir (ante 수 있어요)
w 읽을 = leer (ante 수 있어요)
w 먹을 = comer (ante 수 있어요)
V Vocabulario: poder y saber
D ¡Qué bien hablas!
유나: 카를로스 씨는 한국어를 잘해요! = ¡Carlos, qué bien se le da el coreano!
  > 한국어를 잘해요 = se le da bien el coreano
카를로스: 아니에요. 아직 잘 못해요. = Qué va. Todavía no se me da bien.
  > 아니에요 = no es así | 아직 = todavía | 잘 못해요 = no se me da bien
유나: 한글을 읽을 수 있어요? = ¿Sabe leer hangul?
  > 한글을 = el hangul (objeto) | 읽을 수 있어요 = sabe leer
카를로스: 네, 읽을 수 있어요. 하지만 빨리 못 읽어요. = Sí, sé leerlo. Pero no puedo leer rápido.
  > 빨리 = rápido | 못 읽어요 = no puedo leer
유나: 매운 음식도 먹을 수 있어요? = ¿También puede comer comida picante?
  > 매운 음식도 = comida picante también | 먹을 수 있어요 = puede comer
카를로스: 아니요, 매운 음식은 못 먹어요. 유나 씨는 스페인어를 할 수 있어요? = No, la comida picante no puedo comerla. ¿Usted sabe español, Yuna?
  > 못 먹어요 = no puedo comer | 스페인어를 할 수 있어요 = sabe (hablar) español
유나: 아니요, 못해요. 하지만 영어는 조금 할 수 있어요. = No, no sé. Pero inglés sé un poco.
  > 못해요 = no sé | 영어는 = el inglés (tema) | 조금 할 수 있어요 = sé un poco
T Lo que sé hacer
- 저는 수영을 할 수 있어요. = Sé nadar.
  > 수영을 할 수 있어요 = puedo hacer natación
- 피아노는 못 쳐요. = El piano no sé tocarlo.
  > 못 쳐요 = no sé tocar
- 운전은 아직 못 해요. = Conducir, todavía no sé.
  > 운전은 = conducir (tema) | 아직 못 해요 = todavía no puedo
- 내일은 학교에 갈 수 없어요. = Mañana no puedo ir a la escuela.
  > 갈 수 없어요 = no puedo ir
Q ¿Cómo dices «puedo hacerlo»?
+ 할 수 있어요. :: Raíz + ㄹ 수 있어요.
- 해요 수 있어요. :: Se usa la raíz, no el presente.
- 하다 수 있어요. :: Hay que quitar 다.
Q ¿Qué diferencia hay entre «안 가요» y «못 가요»?
+ 안 가요 = no voy; 못 가요 = no puedo ir. :: 못 es «no poder».
- Son iguales. :: No.
- 안 가요 = no puedo ir; 못 가요 = no voy. :: Es al revés.
Q ¿Cómo dices «no puedo comer» en corto?
+ 못 먹어요. :: 못 delante del verbo.
- 먹어요 못. :: 못 va delante.
- 먹을 수 있어요. :: Eso es «puedo comer».
R 한글을 읽을 수 있어요?
+ ¿Sabes leer hangul? :: 읽을 수 있어요 = saber leer.
- ¿Quieres leer hangul? :: Sería 읽고 싶어요.
- ¿Lees hangul todos los días? :: No dice 매일.

+ 못 :: 못 먹어요 = no puedo comer.

H 영어를 조금 할 수 ___. (puedo)
+ 있어요 :: 할 수 있어요 = puedo.
- 없어요 :: Eso es «no puedo».
- 못해요 :: No va detrás de 수.
A 저는 운전을 못 해요.
+ No sé conducir. :: 운전 = conducir.
- Sé conducir. :: Dice 못.
- No sé nadar. :: Nadar es 수영.
A 아직 한국어를 잘 못해요.
+ Todavía no se me da bien el coreano. :: 아직 = todavía.
- Ya se me da bien el coreano. :: Dice 못해요.
- Todavía no sé inglés. :: 한국어 = coreano.
O 저는 한글을 읽을 수 있어요 :: Sé leer hangul :: Tema + objeto + leer + poder.
