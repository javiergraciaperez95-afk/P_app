@ 28 | 공부할수록 | Cuanto más…, más…: -(으)ㄹ수록
E Cuanto más :: Para decir que, cuanto más se hace algo, más cambia otra cosa, se usa **-(으)ㄹ수록**: 공부하다 → **공부할수록** (cuanto más estudio), 먹다 → **먹을수록** (cuanto más como), 많다 → **많을수록** (cuantos más). :: 한국어를 **공부할수록** 재미있어요 = cuanto más estudio coreano, más divertido es.
E Con dos partes :: Suele haber dos frases con **-(으)ㄹ수록**: la primera dice la causa y la segunda el resultado. :: 연습**할수록** 실력이 늘어요 = cuanto más practicas, más mejora tu nivel.
B Verbo o adjetivo | Con -(으)ㄹ수록 | Español
| 공부하다 | 공부할수록 | cuanto más estudio
| 먹다 | 먹을수록 | cuanto más como
| 많다 | 많을수록 | cuantos más
| 가다 | 갈수록 | cada vez más (con el tiempo)
W 공부할수록 = cuanto más estudio
W 먹을수록 = cuanto más como
W 많을수록 = cuanto más hay
W 갈수록 = cada vez más, con el tiempo
W 점점 = cada vez más, poco a poco
W 어려워요 = es difícil, se hace difícil
W 할수록 = cuanto más hago
W 수록 = cuanto más
W 지날 = que pasa
W 좋아져요 = mejora, se pone mejor
W 늘어요 = aumenta, mejora
W 조금씩 = poco a poco
W 연습할수록 = cuanto más practico
W 재미있어요 = es divertido
V Vocabulario: cuanto más
D Aprender coreano
안나: 한국어를 공부할수록 어려워요. = Cuanto más estudio coreano, más difícil se hace.
  > 한국어를 공부할수록 = cuanto más estudio coreano | 어려워요 = se hace difícil
민수: 그래도 갈수록 재미있어요. = Aun así, cada vez es más divertido.
  > 그래도 = aun así | 갈수록 = con el tiempo | 재미있어요 = es divertido
안나: 맞아요. 연습할수록 실력이 늘어요. = Es verdad. Cuanto más practicas, más mejora el nivel.
  > 연습할수록 = cuanto más practicas | 실력이 늘어요 = el nivel mejora
민수: 그럼 매일 조금씩 해요. = Entonces, hazlo un poquito cada día.
  > 조금씩 = poco a poco | 해요 = haces
Q ¿Qué significa «공부할수록 재미있어요»?
+ Cuanto más estudio, más divertido es. :: 공부할수록 = cuanto más estudio.
- Estudio y me divierto ahora. :: Eso sería 공부하고 재미있어요.
- Estudié y me divertí. :: Eso sería 공부했어요, 재미있었어요.
H 한국어는 공부 ___ 재미있어요. :: cuanto más
+ 할수록 :: 공부할수록 = cuanto más estudias.
- 해요 :: Es «hago», sin comparación.
- 했어요 :: Es «hice», pasado.
R 갈수록 재미있어요.
+ Cada vez es más divertido. :: 갈수록 = con el tiempo, cada vez más.
- Fue divertido. :: Eso sería 재미있었어요.
- Va a ser divertido. :: Eso sería 재미있을 거예요.
A 연습할수록 실력이 늘어요. :: ¿Qué dice la persona?
+ Cuanto más practicas, más mejora el nivel. :: 연습할수록 = cuanto más practicas.
- Practicas, pero el nivel no mejora. :: Eso sería 연습하지만 늘지 않아요.
- Practicas poco y mejoras. :: Eso sería 조금 연습해서 좋아져요.
O 조금씩 해요 :: Hazlo poco a poco :: 조금씩 = poco a poco. 해요 = haces.
Q ¿Cómo dices «cuanto más como»?
+ 먹을수록 :: 먹다 → 먹을수록.
- 먹어요 :: Es «como».
- 먹었어요 :: Es «comí».
H 시간이 지날 ___ 점점 좋아져요. :: cuanto más
+ 수록 :: 지날수록 = cuanto más pasa el tiempo.
- 때 :: Es «cuando».
- 전에 :: Es «antes».
Q ¿Qué significa «점점»?
+ Cada vez más, poco a poco. :: 점점 = progresivamente.
- Alguna vez. :: Eso sería 가끔.
- Muchas veces. :: Eso sería 자주.
@ 28 | 합격하기 위해서 | Para: -기 위해서
E Finalidad formal :: Para decir el propósito de algo se usa **-기 위해서** (para…): 공부하다 → **공부하기 위해서** (para estudiar), 합격하다 → **합격하기 위해서** (para aprobar), 돈을 벌다 → **돈을 벌기 위해서** (para ganar dinero). :: 시험에 **합격하기 위해서** 공부해요 = estudio para aprobar el examen.
E Diferencia con -(으)러 :: **-(으)러** (A2) es informal y se usa con moverse (ir a hacer). **-기 위해서** es más formal y sirve para cualquier propósito. :: 공부하러 가요 = voy a estudiar. 공부하기 위해서 가요 = voy para estudiar (más formal).
B Verbo | Con -기 위해서 | Español
| 공부하다 | 공부하기 위해서 | para estudiar
| 합격하다 | 합격하기 위해서 | para aprobar
| 돈을 벌다 | 돈을 벌기 위해서 | para ganar dinero
| 건강하다 | 건강하기 위해서 | para estar sano
W 공부하기 위해서 = para estudiar
W 합격하기 위해서 = para aprobar
W 돈을 벌기 위해서 = para ganar dinero
W 건강하기 위해서 = para estar sano
W 노력하고 있어요 = me estoy esforzando
W 노력 = esfuerzo
W 노력해요 = me esfuerzo, hago esfuerzo
W 시험에 = para el examen
W 한국에서 = en Corea
V Vocabulario: para
D Un objetivo
민수: 안나 씨는 왜 한국에 가고 싶어요? = Anna, ¿por qué quieres ir a Corea?
  > 왜 = por qué | 한국에 = a Corea | 가고 싶어요 = quieres ir
안나: 한국에서 공부하기 위해서 가고 싶어요. = Quiero ir a Corea para estudiar.
  > 한국에서 = en Corea | 공부하기 위해서 = para estudiar | 가고 싶어요 = quiero ir
민수: 좋아요. 시험에 합격하기 위해서 노력하고 있어요? = Qué bien. ¿Te estás esforzando para aprobar el examen?
  > 시험에 = para el examen | 합격하기 위해서 = para aprobar | 노력하고 있어요 = te estás esforzando
안나: 네, 매일 공부하고 있어요. = Sí, estudio todos los días.
  > 매일 = todos los días | 공부하고 있어요 = estoy estudiando
Q ¿Qué significa «합격하기 위해서 공부해요»?
+ Estudio para aprobar. :: 합격하기 위해서 = para aprobar.
- Estudio porque aprobé. :: Eso sería 합격해서 공부해요.
- Aprobé y dejé de estudiar. :: Eso sería 합격하고 공부를 그만뒀어요.
H 돈을 ___ 일해요. :: para ganar dinero
+ 벌기 위해서 :: 돈을 벌기 위해서 = para ganar dinero.
- 벌어요 :: Es «gano», sin finalidad.
- 벌었어요 :: Es «gané», pasado.
R 건강하기 위해서 운동해요.
+ Hago deporte para estar sano. :: 건강하기 위해서 = para estar sano.
- Estoy sano porque hago deporte. :: Eso sería 건강해서 운동해요.
- Hice deporte y estoy sano. :: Eso sería 운동했고 건강해요.
A 시험에 합격하기 위해서 노력해요. :: ¿Qué dice la persona?
+ Se esfuerza para aprobar el examen. :: 합격하기 위해서 = para aprobar.
- Se esfuerza porque aprobó. :: Eso sería 합격해서 노력해요.
- Ya aprobó el examen. :: Eso sería 합격했어요.
O 한국에서 공부하기 위해서 가요 :: Voy a Corea para estudiar :: 한국에서 = en Corea. 공부하기 위해서 = para estudiar.
Q ¿Cómo dices «para estudiar»?
+ 공부하기 위해서 :: 공부하다 → 공부하기 위해서.
- 공부해요 :: Es «estudio», sin finalidad.
- 공부했어요 :: Es «estudié», pasado.
H 시험에 ___ 노력하고 있어요. :: para aprobar
+ 합격하기 위해서 :: 합격하다 → 합격하기 위해서.
- 합격해요 :: Es «apruebo», sin finalidad.
- 합격했어요 :: Es «aprobé», pasado.
Q ¿Qué significa «노력»?
+ Esfuerzo. :: 노력 es el esfuerzo que haces.
- Descanso. :: Eso sería 휴식.
- Suerte. :: Eso sería 운.
@ 28 | 조심하도록 | Para que, procurar que: -도록
E Para que otro haga algo :: Para decir que algo se hace con un fin, para que algo pase o para que no pase, se usa **-도록**: 잊지 않다 → **잊지 않도록** (para no olvidar), 일찍 도착하다 → **일찍 도착하도록** (para llegar temprano). :: 잊지 **않도록** 메모했어요 = lo apunté para no olvidar.
E Procurar que :: **-도록 하다** significa procurar o cuidar de que algo ocurra: 늦지 않도록 하세요 = procure no llegar tarde. :: Es una forma más suave de dar instrucciones.
B Verbo | Con -도록 | Español
| 잊다 | 잊지 않도록 | para no olvidar
| 도착하다 | 일찍 도착하도록 | para llegar temprano
| 늦다 | 늦지 않도록 하세요 | procure no llegar tarde
| 조심하다 | 조심하도록 하세요 | procure tener cuidado
W 잊지 않도록 = para no olvidar
W 늦지 않도록 하세요 = procure no llegar tarde
W 일찍 도착하도록 = para llegar temprano
W 조심하도록 하세요 = procure tener cuidado
W 출발해요 = sale, parte
W 조심하세요 = tenga cuidado
W 늦지 않도록 할게요 = procuraré no llegar tarde
V Vocabulario: para que
D El tren de las ocho
직원: 이 기차는 여덟 시에 출발해요. = Este tren sale a las ocho.
  > 이 기차는 = este tren | 여덟 시에 = a las ocho | 출발해요 = sale
손님: 그럼 늦지 않도록 할게요. = Entonces procuraré no llegar tarde.
  > 늦지 않도록 할게요 = procuraré no llegar tarde
직원: 네, 일찍 도착하도록 하세요. = Sí, procure llegar temprano.
  > 일찍 도착하도록 하세요 = procure llegar temprano
손님: 감사합니다. 조심하세요! = Gracias. ¡Tenga cuidado!
  > 조심하세요 = tenga cuidado
Q ¿Qué significa «잊지 않도록 메모했어요»?
+ Apunté para no olvidar. :: 잊지 않도록 = para no olvidar.
- Olvidé apuntarlo. :: Eso sería 메모를 잊었어요.
- Apunté y olvidé. :: Eso sería 메모하고 잊었어요.
H 늦지 ___ 하세요. :: procure no llegar tarde (않도록)
+ 않도록 :: 늦지 않도록 하세요 = procure no llegar tarde.
- 않으면 :: Es «si no».
- 않고 :: Es «sin».
R 늦지 않도록 할게요.
+ Procuraré no llegar tarde. :: 늦지 않도록 할게요 = procuraré no llegar tarde.
- Llegaré tarde. :: Eso sería 늦게 올 거예요.
- Llegué tarde. :: Eso sería 늦었어요.
A 일찍 도착하도록 하세요. :: ¿Qué dice la persona?
+ Procure llegar temprano. :: 도착하도록 하세요 = procure llegar.
- Llegue temprano sin problema. :: Eso sería 일찍 와도 돼요.
- Llegó temprano. :: Eso sería 일찍 왔어요.
O 조심하세요 :: Tenga cuidado :: 조심하세요 = tenga cuidado.
Q ¿Cómo dices «procure no llegar tarde»?
+ 늦지 않도록 하세요 :: 늦다 → 늦지 않도록 하세요.
- 늦지 마세요 :: Es «no llegue tarde», orden directa.
- 늦었어요 :: Es «llegó tarde».
H 기차가 ___. :: sale
+ 출발해요 :: 출발하다 → 출발해요.
- 출발했어요 :: Es «salió», pasado.
- 출발할 거예요 :: Es «saldrá», futuro.
Q ¿Qué significa «조심하세요»?
+ Tenga cuidado. :: 조심하세요 = tenga cuidado.
- Vaya rápido. :: Eso sería 빨리 가세요.
- Espere aquí. :: Eso sería 여기서 기다리세요.
