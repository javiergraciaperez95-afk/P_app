@ 12 | 가야 해요 | Tener que hacer algo
E Tener que :: Para decir que algo es necesario o que tienes que hacerlo se usa **-아/어야 해요** (tengo que…, hay que…). :: 가다 → **가야 해요**, 먹다 → **먹어야 해요**, 쉬다 → **쉬어야 해요**, 하다 → **해야 해요**. :: 약을 **먹어야 해요** = tengo que tomar la medicina.
E Cómo se forma :: Se usa la misma combinación de vocales que en -아/어요: **-아야** tras ㅏ/ㅗ y **-어야** en los demás casos; 하다 se contrae a **해야**. Algunas raíces irregulares cambian, por ejemplo 듣다 → 들어야 해요. La ㄹ final se conserva: 살다 → 살아야 해요, 만들다 → 만들어야 해요.
B Verbo | Raíz | Con -아/어야 해요 | Español
| 가다 | 가 | 가야 해요 | tengo que ir
| 먹다 | 먹 | 먹어야 해요 | tengo que comer
| 쉬다 | 쉬 | 쉬어야 해요 | tengo que descansar
| 하다 | 하 | 해야 해요 | tengo que hacer
W 벌써 = ya
W 가야 해요 = tengo que ir, tengo que irme
W 먹어야 해요 = tengo que comer, tengo que tomar
W 쉬어야 해요 = tengo que descansar
W 해야 해요 = tengo que hacer
W 일어나야 해요 = tengo que levantarme
W 공부해야 해요 = tengo que estudiar
W 시험 = examen
W 힘내세요 = ¡ánimo!
V Vocabulario: tener que hacer algo
D Hora de irse
민수: 벌써 여덟 시예요! = ¡Ya son las ocho!
  > 벌써 = ya | 여덟 시예요 = son las ocho
안나: 아, 저 가야 해요. = Ah, tengo que irme.
  > 가야 해요 = tengo que irme
민수: 왜요? = ¿Por qué?
  > 왜요 = ¿por qué?
안나: 내일 시험이 있어요. 공부해야 해요. = Mañana hay examen. Tengo que estudiar.
  > 시험이 있어요 = hay examen | 공부해야 해요 = tengo que estudiar
민수: 아, 힘내세요! = ¡Ah, ánimo!
  > 힘내세요 = ¡ánimo!
Q ¿Cómo dices «tengo que comer»?
+ 먹어야 해요 :: 먹다 → 먹어야 해요.
- 먹었어요 :: Es pasado: «comí».
- 먹어요 :: Es «como», sin obligación.
H 저는 지금 ___. :: tengo que irme
+ 가야 해요 :: 가다 → 가야 해요.
- 가요 :: Es «voy», sin obligación.
- 갔어요 :: Es pasado: «fui».
R 해야 해요.
+ Tengo que hacerlo. :: 해야 해요 = tengo que hacer.
- Hago eso. :: Eso sería 해요.
- Lo hice. :: Eso sería 했어요.
A 저는 지금 쉬어야 해요. :: ¿Qué dice la persona?
+ Tiene que descansar ahora. :: 쉬어야 해요 = tiene que descansar. 지금 = ahora.
- Ya descansó. :: Eso sería 쉬었어요.
- Descansa todos los días. :: Eso sería 매일 쉬어요.
O 내일 일찍 일어나야 해요 :: Mañana tengo que levantarme temprano :: 내일 = mañana. 일찍 = temprano. 일어나야 해요 = tengo que levantarme.
Q ¿Por qué se va Anna?
+ Porque tiene examen mañana. :: 내일 시험이 있어요: hay examen mañana.
- Porque tiene hambre. :: Eso sería 배고파요.
- Porque llueve. :: Eso sería 비가 와요.
Q ¿Qué significa «힘내세요»?
+ ¡Ánimo! :: Es una frase para dar ánimo.
- ¡Adiós! :: Eso sería 안녕히 가세요.
- ¡Feliz cumpleaños! :: Eso sería 생일 축하해요.
H 약을 ___. :: tengo que tomar
+ 먹어야 해요 :: 먹다 → 먹어야 해요.
- 먹어요 :: Es «como», sin obligación.
- 먹었어요 :: Es pasado: «comí».
@ 12 | 하면 안 돼요 | No se puede: prohibición general
E Prohibir o decir que no se debe :: **-(으)면 안 돼요** significa «no se puede» o «no se debe»: **여기서 음식을 먹으면 안 돼요** = aquí no se puede comer. Se forma como -면 después de vocal o ㄹ, y -으면 después de otra consonante: **가면**, **살면**, **먹으면**. Con ㄹ, se elimina la ㄹ: **만들면 안 돼요**.
E Frente a -지 마세요 :: **-지 마세요** se dirige a alguien como petición u orden cortés: «no lo haga, por favor». **-(으)면 안 돼요** presenta una prohibición, regla o consecuencia: «no se puede/no se debe». Ambas formas pueden aparecer en instrucciones públicas; el contexto determina cuál encaja mejor.
B Verbo | Regla | Prohibición | Español
| 가다 | vocal | 가면 안 돼요 | no se puede ir
| 먹다 | otra consonante | 먹으면 안 돼요 | no se puede comer
| 살다 | ㄹ: se quita ㄹ | 살면 안 돼요 | no se puede vivir
| 만들다 | ㄹ: se quita ㄹ | 만들면 안 돼요 | no se puede fabricar
W 안 돼요 = no se puede, no está permitido
W 먹으면 안 돼요 = no se puede comer
W 찍으면 안 돼요 = no se puede sacar (fotos)
W 가면 안 돼요 = no se puede ir
W 들어가면 안 돼요 = no se puede entrar
W 수영하면 안 돼요 = no se puede nadar
W 피우면 안 돼요 = no se puede fumar
W 손님 = cliente
W 드세요 = coma, por favor
W 어디에서 = dónde, en qué lugar
W 먹을 수 있어요 = se puede comer, puedo comer
W 그래요 = ¿de verdad?, ¿así es?
V Vocabulario: no se puede
D En el restaurante
직원: 손님, 여기서 음식을 먹으면 안 돼요. = Señor, aquí no se puede comer.
  > 여기서 = aquí | 음식을 = comida | 먹으면 안 돼요 = no se puede comer
손님: 아, 그래요? 죄송합니다. = Ah, ¿de verdad? Lo siento.
  > 그래요 = ¿de verdad? | 죄송합니다 = lo siento
손님: 그럼 어디에서 먹을 수 있어요? = Entonces, ¿dónde se puede comer?
  > 어디에서 = dónde | 먹을 수 있어요 = se puede comer
직원: 밖에서 드세요. = Coma fuera, por favor.
  > 밖에서 = fuera | 드세요 = coma
Q ¿Qué significa «여기서 사진 찍으면 안 돼요»?
+ No se puede sacar fotos aquí. :: 찍으면 안 돼요 = no se puede sacar.
- Saque fotos aquí, por favor. :: Eso sería 찍으세요.
- Aquí se pueden sacar fotos. :: Eso sería 찍을 수 있어요.
H 여기서 ___ 안 돼요. :: no se puede fumar
+ 피우면 :: 피우다 → 피우면 안 돼요.
- 피우세요 :: Pide que fume, lo contrario.
- 피워요 :: Es «fumo», no una prohibición.
R 음식을 먹으면 안 돼요.
+ No se puede comer. :: 먹으면 안 돼요 = no se puede comer.
- Coma, por favor. :: Eso sería 드세요.
- Se puede comer. :: Eso sería 먹을 수 있어요.
A 여기서 수영하면 안 돼요. :: ¿Qué te dice el cartel?
+ No se puede nadar aquí. :: 수영하면 안 돼요 = no se puede nadar.
- Puedes nadar aquí. :: Eso sería 수영할 수 있어요.
- Vamos a nadar aquí. :: Eso sería 수영하자.
O 밖에서 드세요 :: Coma fuera, por favor :: 밖에서 = fuera. 드세요 = coma.
Q ¿Cómo se dice «no se puede vivir aquí» (살다)?
+ 여기서 살면 안 돼요 :: La forma condicional de 살다 es 살면: se quita ㄹ.
- 여기서 살으으면 안 돼요 :: Con ㄹ no se añade -으으면.
- 여기서 살면 돼요 :: Eso significa «se puede vivir aquí».
Q ¿Qué dice el cartel «들어가면 안 돼요»?
+ No se puede entrar. :: 들어가면 안 돼요 = no se puede entrar.
- Entre, por favor. :: Eso sería la forma de pedir que entres.
- Salga, por favor. :: No es lo que dice.
H 여기서 사진을 ___ 안 돼요. :: sacar
+ 찍으면 :: 찍다 → 찍으면 안 돼요.
- 찍으세요 :: Es «saque, por favor».
- 찍어요 :: Es «saco», sin prohibición.
@ 12 | 해도 돼요 | Pedir permiso
E Puedes hacerlo :: Para pedir o dar permiso se usa **-아/어도 돼요** (se puede, puedes…). :: 가다 → **가도 돼요**, 앉다 → **앉아도 돼요**, 먹다 → **먹어도 돼요**, 하다 → **해도 돼요**. :: 여기 **앉아도 돼요**? = ¿puedo sentarme aquí?
E No hace falta :: Con **안** delante se dice que no hace falta: **안 해도 돼요** = no hace falta hacerlo. :: Ojo: **앉아도 돼요** da permiso, y **앉으면 안 돼요** lo prohíbe.
B Verbo | Raíz | Permiso | Español
| 앉다 | 앉 | 앉아도 돼요 | se puede sentar
| 먹다 | 먹 | 먹어도 돼요 | se puede comer
| 하다 | 하 | 해도 돼요 | se puede hacer
| 보다 | 보 | 봐도 돼요 | se puede mirar
W 앉아도 돼요 = puedo sentarme, se puede sentar
W 먹어도 돼요 = se puede comer, puedo comer
W 해도 돼요 = se puede hacer, puedo hacer
W 봐도 돼요 = puedo mirar, se puede mirar
W 찍어도 돼요 = se puede sacar (fotos), puedo sacar
W 안 해도 돼요 = no hace falta hacerlo
W 먼저 = primero
W 메뉴를 = la carta (메뉴 es A1: se usa con partícula)
V Vocabulario: pedir permiso
D En el restaurante
손님: 여기 앉아도 돼요? = ¿Puedo sentarme aquí?
  > 여기 = aquí | 앉아도 돼요 = puedo sentarme
직원: 네, 앉으세요. = Sí, siéntese.
  > 앉으세요 = siéntese
손님: 메뉴를 먼저 봐도 돼요? = ¿Puedo mirar primero la carta?
  > 메뉴를 = la carta | 먼저 = primero | 봐도 돼요 = puedo mirar
직원: 네, 천천히 보세요. = Sí, mire con calma.
  > 천천히 = despacio | 보세요 = mire
Q ¿Cómo preguntas «¿Puedo sentarme aquí?»?
+ 여기 앉아도 돼요? :: 앉아도 돼요 = ¿puedo sentarme?
- 여기 앉으면 안 돼요? :: Eso sería «¿no se puede sentar aquí?».
- 여기 앉았어요 :: Es pasado: «me senté».
H 여기서 사진을 ___? :: ¿puedo sacar?
+ 찍어도 돼요 :: 찍다 → 찍어도 돼요, pedir permiso.
- 찍으면 안 돼요 :: Es una prohibición.
- 찍어요 :: Es «saco», no un permiso.
R 안 해도 돼요.
+ No hace falta hacerlo. :: 안 해도 돼요 = no hace falta.
- Tienes que hacerlo. :: Eso sería 해야 해요.
- Lo hice. :: Eso sería 했어요.
A 메뉴를 먼저 봐도 돼요. :: ¿Qué pregunta el cliente?
+ ¿Puedo mirar primero la carta? :: 봐도 돼요 = ¿puedo mirar?
- ¿Dónde está la carta? :: Eso no es una petición de permiso.
- ¿Cuánto cuesta la carta? :: No se pregunta por el precio.
O 먼저 드세요 :: Coma primero, por favor :: 먼저 = primero. 드세요 = coma.
Q ¿Cuál es el permiso de «se puede comer»?
+ 먹어도 돼요 :: 먹다 → 먹어도 돼요.
- 먹으면 안 돼요 :: Es una prohibición.
- 먹어요 :: Es «como».
Q ¿Qué significa «여기 봐도 돼요»?
+ Se puede mirar aquí. :: 봐도 돼요 = se puede mirar.
- No se puede mirar aquí. :: Eso sería 여기 보면 안 돼요.
- Mire aquí. :: Eso sería 여기 보세요.
H 여기 ___? :: ¿puedo sentarme?
+ 앉아도 돼요 :: 앉다 → 앉아도 돼요.
- 앉으세요 :: Es «siéntese».
- 앉지 마세요 :: Es «no se siente».
