@ 33 | 도착하는 대로 | En cuanto, según: -는 대로
E En cuanto pase algo :: Para decir que algo se hace justo después de que pase otra cosa, se usa **-는 대로**: 도착하다 → **도착하는 대로** (en cuanto llegue), 받다 → **받는 대로** (en cuanto reciba). :: 도착하**는 대로** 연락해 주세요 = avíseme en cuanto llegue.
E Según :: Con un nombre, **N대로** significa «según» o «como»: 약속**대로** = según lo acordado. :: 생각나**는 대로** 말해 보세요 = diga lo que se le ocurra.
B Forma | Ejemplo | Español
| 도착하다 | 도착하는 대로 | en cuanto llegue
| 받다 | 받는 대로 | en cuanto reciba
| 생각나다 | 생각나는 대로 | según se me ocurra
| 약속 | 약속대로 | según lo acordado
W 도착하는 대로 = en cuanto llegue
W 받는 대로 = en cuanto reciba
W 생각나는 대로 = según se me ocurra
W 약속대로 = según lo acordado
W 하겠습니다 = lo haré, lo haremos
W 연락해 주세요 = avíseme, contácteme
W 연락 = contacto, aviso
W 열두 시 = las doce
W 말해 보세요 = diga, cuéntelo
V Vocabulario: en cuanto
D Avisar al llegar
민수: 도착하는 대로 연락해 주세요. = Avíseme en cuanto llegue.
  > 도착하는 대로 = en cuanto llegue | 연락해 주세요 = avise, por favor
안나: 네, 약속대로 열두 시에 갈게요. = Sí, iré a las doce según lo acordado.
  > 약속대로 = según lo acordado | 열두 시에 = a las doce | 갈게요 = iré
민수: 좋아요. 그럼 기다릴게요. = Vale. Entonces te esperaré.
  > 기다릴게요 = esperaré
Q ¿Qué significa «도착하는 대로 연락해 주세요»?
+ Avíseme en cuanto llegue. :: 도착하는 대로 = en cuanto llegue.
- Avisé cuando llegué. :: Eso sería 도착했을 때 연락했어요.
- Llegue sin avisar. :: Eso sería 연락 없이 도착하세요.
H ___ 연락해 주세요. :: en cuanto llegue
+ 도착하는 대로 :: 도착하는 대로 = en cuanto llegue.
- 도착하면 :: Es «si llega», sin ser inmediato.
- 도착해서 :: Es «porque llegó».
R 약속대로 열두 시에 갈게요.
+ Iré a las doce según lo acordado. :: 약속대로 = según lo acordado.
- Iré cuando quiera. :: Eso sería 원할 때 갈게요.
- Iré tarde. :: Eso sería 늦게 갈게요.
A 생각나는 대로 말해 보세요. :: ¿Qué pide la persona?
+ Que diga lo que se le ocurra. :: 생각나는 대로 = según se le ocurra.
- Que piense mucho antes. :: Eso sería 많이 생각하세요.
- Que lo escriba. :: Eso sería 쓰세요.
O 도착하는 대로 연락해 주세요 :: Avíseme en cuanto llegue :: 도착하는 대로 = en cuanto llegue. 연락해 주세요 = avise.
Q ¿Cómo dices «en cuanto reciba» (받다)?
+ 받는 대로 :: 받다 → 받는 대로.
- 받아요 :: Es «recibo», sin orden.
- 받았어요 :: Es «recibí», pasado.
H ___ 하겠습니다. :: según lo acordado
+ 약속대로 :: 약속대로 = según lo acordado.
- 때문에 :: Es «a causa de».
- 까지 :: Es «hasta».
Q ¿Qué significa «연락»?
+ Contacto, aviso. :: 연락 es comunicarse.
- Retraso. :: Eso sería 지연.
- Compra. :: Eso sería 구매.
@ 33 | 얼마나 좋은지 | Cuánto, qué tan: -(으)ㄴ지 y 얼마나 ~(으)ㄴ지 모르다
E No sabes cuánto :: Para decir que algo es muy de una manera, se usa **얼마나 ~(으)ㄴ지 모르다** (no sabes lo…): 좋다 → **얼마나 좋은지 몰라요** (no sabes lo bueno que es), 바쁘다 → **얼마나 바쁜지 몰라요** (no sabes lo ocupado que está). :: 이 책이 **얼마나 좋은지** 몰라요 = no sabes lo bueno que es este libro.
E Con verbos :: Con verbos se usa **-는지**: 얼마나 먹**는지** 모르겠어요 = no sé cuánto come. :: Con 모르겠어요 se expresa duda; con 몰라요, más seguridad.
B Forma | Ejemplo | Español
| 좋다 | 얼마나 좋은지 몰라요 | no sabes lo bueno que es
| 바쁘다 | 얼마나 바쁜지 몰라요 | no sabe lo ocupado que está
| 먹다 | 얼마나 먹는지 모르겠어요 | no sé cuánto come
| 비싸다 | 얼마나 비싼지 몰라요 | no sé lo caro que es
W 얼마나 좋은지 몰라요 = no sabes lo bueno que es
W 얼마나 바쁜지 몰라요 = no sabe lo ocupado que está
W 얼마나 먹는지 모르겠어요 = no sé cuánto come
W 얼마나 비싼지 몰라요 = no sé lo caro que es
W 바쁜지 = lo ocupado que
W 읽고 싶어요 = quiero leerlo
W 빌려줄게요 = te lo presto
W 몰라요 = no sé
V Vocabulario: no sé cuánto
D Un libro
안나: 이 책이 얼마나 좋은지 몰라요. = No sabes lo bueno que es este libro.
  > 이 책이 = este libro | 얼마나 좋은지 몰라요 = no sabes lo bueno que es
민수: 그래요? 빨리 읽고 싶어요. = ¿Sí? Quiero leerlo pronto.
  > 빨리 = pronto | 읽고 싶어요 = quiero leerlo
안나: 그럼 빌려줄게요. = Entonces te lo presto.
  > 그럼 = entonces | 빌려줄게요 = te lo presto
Q ¿Qué significa «얼마나 좋은지 몰라요»?
+ No sabes lo bueno que es. :: 얼마나 좋은지 몰라요 = no sabes lo bueno que es.
- Es bueno, pero no mucho. :: Eso sería 좋지만 많이 좋지 않아요.
- Es muy malo. :: Eso sería 아주 나빠요.
H 얼마나 ___ 몰라요. :: no sé lo ocupado que está
+ 바쁜지 :: 얼마나 바쁜지 몰라요 = no sé lo ocupado que está.
- 바쁘면 :: Es «si está ocupado».
- 바빠서 :: Es «porque está ocupado».
R 얼마나 먹는지 모르겠어요.
+ No sé cuánto come. :: 얼마나 먹는지 = cuánto come.
- Come mucho. :: Eso sería 많이 먹어요.
- Comió mucho. :: Eso sería 많이 먹었어요.
A 얼마나 비싼지 몰라요. :: ¿Qué dice la persona?
+ No sabe lo caro que es. :: 얼마나 비싼지 몰라요 = no sabe lo caro que es.
- Es barato. :: Eso sería 싸요.
- Es muy caro. :: Eso sería 아주 비싸요.
O 이 책을 빨리 읽고 싶어요 :: Quiero leer este libro pronto :: 빨리 = pronto. 읽고 싶어요 = quiero leerlo.
Q ¿Cómo dices «no sé cuánto come» (먹다)?
+ 얼마나 먹는지 모르겠어요 :: 먹다 → 얼마나 먹는지 모르겠어요.
- 얼마나 먹었어요 :: Es «comió cuánto».
- 많이 먹어요 :: Es «come mucho».
H 이 책을 ___. :: te lo presto
+ 빌려줄게요 :: 빌리다 → 빌려줄게요.
- 빌려요 :: Es «presto», sin oferta.
- 빌렸어요 :: Es «presté», pasado.
Q ¿Qué significa «몰라요»?
+ No sé. :: 몰라요 es no saber.
- Lo sé. :: Eso sería 알아요.
- Lo sabía. :: Eso sería 알았어요.
@ 33 | 울 정도로 | Hasta el punto de: -(으)ㄹ 정도로
E Tanto que :: Para decir hasta qué punto algo es así, se usa **-(으)ㄹ 정도로** (tanto que…, hasta el punto de…): 울다 → **울 정도로** (hasta el punto de llorar), 놀라다 → **놀랄 정도로** (tanto que asombra), 맛있다 → **맛있을 정도로** (tan rico que). :: 울 정도로 슬펐어요 = fue tan triste que lloré.
E Con «정도» :: **-(으)ㄹ 정도이다** es lo mismo, pero como verbo: 울 정도이다 = es tan que llora. :: Es muy común en el habla y en la escritura.
B Verbo o adjetivo | Con -(으)ㄹ 정도로 | Español
| 울다 | 울 정도로 | hasta el punto de llorar
| 놀라다 | 놀랄 정도로 | tanto que asombra
| 맛있다 | 맛있을 정도로 | tan rico que
| 피곤하다 | 피곤할 정도로 | tan cansado que
W 울 정도로 = hasta el punto de llorar
W 놀랄 정도로 = tanto que asombra
W 맛있을 정도로 = tan rico que
W 피곤할 정도로 = tan cansado que
W 많이 먹을 정도로요 = tanto que se come mucho
W 깜짝 = de repente, sorpresa
W 놀랐어요 = me sorprendí
W 깜짝 놀랄 정도로 = tanto que te sorprendes
W 슬펐어요 = fue triste, estaba triste
V Vocabulario: hasta el punto
D Una comida muy rica
민수: 이 음식 정말 맛있어요. 많이 먹을 정도로요. = Esta comida está muy rica. Tanto que se come mucho.
  > 정말 = de verdad | 많이 먹을 정도로요 = tanto que se come mucho
안나: 그래요? 저도 먹어 보고 싶어요. = ¿Sí? Yo también quiero probarla.
  > 저도 = yo también | 먹어 보고 싶어요 = quiero probarla
민수: 깜짝 놀랄 정도로 맛있어요. = Está tan rico que te sorprenderás.
  > 깜짝 놀랄 정도로 = tanto que te sorprenderás | 맛있어요 = está rico
Q ¿Qué significa «울 정도로 슬펐어요»?
+ Fue tan triste que lloré. :: 울 정도로 = hasta el punto de llorar.
- Lloré un poco. :: Eso sería 조금 울었어요.
- Estaba feliz. :: Eso sería 행복했어요.
H 맛있을 ___ 많이 먹었어요. :: tanto que
+ 정도로 :: 맛있을 정도로 = tan rico que.
- 때문에 :: Es «a causa de».
- 대로 :: Es «según».
R 깜짝 놀랄 정도로 맛있어요.
+ Está tan rico que te sorprenderás. :: 놀랄 정도로 = tanto que asombra.
- Está un poco rico. :: Eso sería 조금 맛있어요.
- Está frío. :: Eso sería 차가워요.
A 피곤할 정도로 일했어요. :: ¿Qué dice la persona?
+ Trabajó tanto que se cansó. :: 피곤할 정도로 = tanto que se cansó.
- Trabajó poco. :: Eso sería 조금 일했어요.
- No trabajó. :: Eso sería 일 안 했어요.
O 울 정도로 슬펐어요 :: Fue tan triste que lloré :: 울 정도로 = hasta el punto de llorar. 슬펐어요 = fue triste.
Q ¿Cómo dices «tan rico que» (맛있다)?
+ 맛있을 정도로 :: 맛있다 → 맛있을 정도로.
- 맛있어요 :: Es «está rico», sin grado.
- 맛있었어요 :: Es «estaba rico», pasado.
H 깜짝 ___ 정도로 맛있어요. :: sorprender
+ 놀랄 :: 놀랄 정도로 = tanto que asombra.
- 놀랐어요 :: Es «me sorprendí», pasado.
- 놀라요 :: Es «me sorprendo», presente.
Q ¿Qué significa «깜짝»?
+ De sorpresa. :: 깜짝 es un gesto repentino de sorpresa.
- De cansancio. :: Eso sería 피곤해서.
- De dolor. :: Eso sería 아파서.
