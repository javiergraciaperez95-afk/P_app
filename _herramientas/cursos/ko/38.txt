@ 38 | 맞는지 모르겠어요 | Si es o no: -는지 y -(으)ㄴ지
E Preguntas indirectas :: Para decir «si…» dentro de una frase, se usa **-는지** con verbos y **-(으)ㄴ지** con adjetivos: 오다 → **오는지** (si viene), 맞다 → **맞는지** (si es correcto), 좋다 → **좋은지** (si es bueno), 학생이다 → **학생인지** (si es estudiante). :: 이 답이 **맞는지** 모르겠어요 = no sé si esta respuesta es correcta.
E Dos opciones :: Para decir «si es o si no es» se repite la forma: 가는지 안 가는지 = si va o no. 큰지 작은지 = si es grande o pequeño. :: Con «알아요?» o «모르겠어요» se pregunta o se dice que no se sabe.
B Palabra | Con -는지 / -(으)ㄴ지 | Español
| 오다 | 오는지 | si viene
| 맞다 | 맞는지 | si es correcto
| 좋다 | 좋은지 | si es bueno
| 학생이다 | 학생인지 | si es estudiante
W 맞는지 모르겠어요 = no sé si es correcto
W 맞는지 알아요 = ¿sabes si es correcto?
W 오는지 모르겠어요 = no sé si viene
W 가는지 안 가는지 = si va o no
W 큰지 작은지 = si es grande o pequeño
W 글쎄요 = pues, no sé
W 답 = respuesta
W 이 답 = esta respuesta
W 물어보는 게 좋겠어요 = sería mejor preguntar
W 선생님한테 = al profesor
V Vocabulario: si es o no
D Una respuesta
안나: 민수 씨, 이 답이 맞는지 알아요? = Minsu, ¿sabes si esta respuesta es correcta?
  > 이 답이 = esta respuesta | 맞는지 = si es correcta | 알아요 = sabes
민수: 글쎄요. 맞는지 모르겠어요. = Pues, no sé si es correcta.
  > 글쎄요 = pues | 맞는지 모르겠어요 = no sé si es correcta
안나: 그럼 선생님한테 물어보는 게 좋겠어요. = Entonces sería mejor preguntar al profesor.
  > 그럼 = entonces | 선생님한테 = al profesor | 물어보는 게 좋겠어요 = sería mejor preguntar
민수: 네, 그게 좋겠어요. = Sí, eso sería mejor.
  > 그게 = eso | 좋겠어요 = sería bueno
Q ¿Qué significa «이 답이 맞는지 모르겠어요»?
+ No sé si esta respuesta es correcta. :: 맞는지 = si es correcta.
- Esta respuesta es correcta. :: Eso sería 이 답은 맞아요.
- Sé que esta respuesta es correcta. :: Eso sería 맞다는 것을 알아요.
H 이 답이 ___ 모르겠어요. :: si es correcta
+ 맞는지 :: 맞는지 = si es correcta.
- 맞아요 :: Es «es correcta», sin duda.
- 맞으면 :: Es «si es correcta».
R 가는지 안 가는지 모르겠어요.
+ No sé si va o no. :: 가는지 안 가는지 = si va o no.
- Va y no va. :: Eso no tiene sentido.
- Quiere ir. :: Eso sería 가고 싶어요.
A 큰지 작은지 모르겠어요. :: ¿Qué dice la persona?
+ No sabe si es grande o pequeño. :: 큰지 작은지 = si es grande o pequeño.
- Sabe que es muy grande. :: Eso sería 아주 커요.
- Es pequeño y bonito. :: Eso sería 작고 예뻐요.
O 맞는지 알아요? :: ¿Sabes si es correcto? :: 맞는지 = si es correcto. 알아요 = sabes.
Q ¿Cómo dices «si es bueno» (좋다)?
+ 좋은지 :: 좋다 → 좋은지.
- 좋아요 :: Es «es bueno», sin pregunta.
- 좋았어요 :: Es «fue bueno», pasado.
H 그 사람이 ___ 모르겠어요. :: si viene
+ 오는지 :: 오는지 = si viene.
- 오면 :: Es «si viene», condición.
- 왔어요 :: Es «vino», pasado.
Q ¿Qué significa «글쎄요»?
+ Pues, no sé. :: 글쎄요 muestra duda.
- ¡Claro! :: Eso sería 물론이죠.
- ¡Perfecto! :: Eso sería 완벽해요.
@ 38 | 갈지 말지 | Dudar si hacer o no: -(으)ㄹ지 말지
E Duda :: Para decir que dudas entre hacer algo o no, se usa **-(으)ㄹ지 말지**: 가다 → **갈지 말지** (si ir o no), 먹다 → **먹을지 말지** (si comer o no). :: 파티에 **갈지 말지** 고민이에요 = dudo si ir a la fiesta o no.
E Sin saber :: **-(으)ㄹ지 모르겠어요** dice que no sabes si va a pasar algo. :: 비가 올지 모르겠어요 = no sé si lloverá.
B Palabra | Con -(으)ㄹ지 말지 | Español
| 가다 | 갈지 말지 | si ir o no
| 먹다 | 먹을지 말지 | si comer o no
| 비가 오다 | 비가 올지 모르겠어요 | no sé si lloverá
| 사다 | 살지 말지 | si comprar o no
W 갈지 말지 = si ir o no
W 먹을지 말지 = si comer o no
W 살지 말지 = si comprar o no
W 고민이에요 = es un dilema, estoy dudando
W 고민 = duda, dilema
W 올지 모르겠어요 = no sé si vendrá, no sé si llegará
W 파티에 = a la fiesta
W 그 사람들 = esas personas
W 기다릴 거예요 = esperarán
W 고민해요 = dudo, pienso dudoso
V Vocabulario: dudar
D Una fiesta
민수: 오늘 파티에 갈지 말지 고민이에요. = Dudo si ir a la fiesta de hoy o no.
  > 오늘 파티에 = a la fiesta de hoy | 갈지 말지 = si ir o no | 고민이에요 = es un dilema
안나: 가세요! 친구들이 기다릴 거예요. = ¡Vaya! Sus amigos lo esperarán.
  > 친구들이 = los amigos | 기다릴 거예요 = esperarán
민수: 그럼 가 볼게요. = Entonces iré a verlo.
  > 그럼 = entonces | 가 볼게요 = iré a ver
Q ¿Qué significa «갈지 말지 고민이에요»?
+ Dudo si ir o no. :: 갈지 말지 = si ir o no.
- Iré seguro. :: Eso sería 꼭 갈 거예요.
- No puedo ir. :: Eso sería 갈 수 없어요.
H 파티에 ___ 고민이에요. :: si ir o no
+ 갈지 말지 :: 갈지 말지 = si ir o no.
- 가요 :: Es «voy», sin dudar.
- 갔어요 :: Es «fui», pasado.
R 비가 올지 모르겠어요.
+ No sé si lloverá. :: 올지 모르겠어요 = no sé si lloverá.
- Llueve seguro. :: Eso sería 비가 확실히 와요.
- Llovió ayer. :: Eso sería 어제 비가 왔어요.
A 먹을지 말지 고민해요. :: ¿Qué dice la persona?
+ Duda si comer o no. :: 먹을지 말지 = si comer o no.
- Come seguro. :: Eso sería 확실히 먹어요.
- Ya comió. :: Eso sería 먹었어요.
O 살지 말지 고민이에요 :: Dudo si comprar o no :: 살지 말지 = si comprar o no. 고민이에요 = es un dilema.
Q ¿Cómo dices «no sé si lloverá»?
+ 비가 올지 모르겠어요 :: 오다 → 올지 모르겠어요.
- 비가 와요 :: Es «llueve».
- 비가 왔어요 :: Es «llovió».
H 그 사람들이 ___. :: si vendrá (올지 모르겠어요)
+ 올지 모르겠어요 :: 올지 모르겠어요 = no sé si vendrá.
- 와요 :: Es «viene», sin duda.
- 왔어요 :: Es «vino», pasado.
Q ¿Qué significa «고민»?
+ Duda, dilema. :: 고민 es algo que te preocupa y no decides.
- Alegría. :: Eso sería 기쁨.
- Premio. :: Eso sería 상.
@ 38 | 사다 주세요 | Traer o comprar para alguien: -아/어다 y 을/를 비롯해서
E Ir a buscar y traer :: Para decir que alguien va a un sitio, compra algo y lo trae, se usa **-아/어다(가)**: 사다 → **사다 주세요** (cómpreme y tráigame), 가져다 → **가져다 주세요** (llévelo y tráigalo). :: 편의점에 가서 물 좀 **사다** 주세요 = vaya a la tienda y cómpreme agua, por favor.
E Incluyendo a :: **N을/를 비롯해서** dice que se incluye un grupo empezando por N: 친구들**을 비롯해서** 다 좋아해요 = a todos les gusta, incluidos mis amigos. :: Es una forma de decir «incluido» en el habla formal o escrita.
B Forma | Ejemplo | Español
| 사다 | 사다 주세요 | cómpreme y tráigame
| 가져다 | 가져다 주세요 | lléveselo y tráigalo
| 친구 | 친구들을 비롯해서 | incluidos mis amigos
| 학생 | 학생들을 비롯해서 | incluidos los estudiantes
W 사다 주세요 = cómpreme y tráigame
W 편의점에 가서 = yendo a la tienda
W 편의점 = tienda de conveniencia
W 다른 것도 = también otra cosa
W 다른 = otro, diferente
W 많은 사람이 = muchas personas
W 많은 = muchos, mucha
W 물 좀 = un poco de agua, agua por favor
W 친구들을 비롯해서 = incluidos mis amigos
W 학생들을 비롯해서 = incluidos los estudiantes
W 다 좋아해요 = a todos les gusta
W 가져다 주세요 = lléveselo, tráigamelo
W 필요해요 = lo necesitan, lo necesito
V Vocabulario: traer
D Comprar agua
민수: 편의점에 가서 물 좀 사다 주세요. = Vaya a la tienda y cómpreme agua, por favor.
  > 편의점에 가서 = yendo a la tienda | 물 좀 = un poco de agua | 사다 주세요 = cómpreme y tráigame
안나: 네, 알겠어요. 다른 것도 필요해요? = Sí, de acuerdo. ¿Necesitas también otra cosa?
  > 다른 것도 = también otra cosa | 필요해요 = lo necesitas
민수: 네, 친구들을 비롯해서 다 좋아해요. = Sí, incluidos mis amigos, a todos les gusta.
  > 친구들을 비롯해서 = incluidos mis amigos | 다 좋아해요 = a todos les gusta
Q ¿Qué significa «사다 주세요»?
+ Cómpreme y tráigame. :: 사다 주세요 = cómpreme y tráigame.
- Compré. :: Eso sería 샀어요.
- Compro yo. :: Eso sería 사요.
H 편의점에 가서 물 좀 ___. :: cómpreme y tráigame
+ 사다 주세요 :: 사다 주세요 = cómpreme y tráigame.
- 사요 :: Es «compro», sin encargo.
- 샀어요 :: Es «compré», pasado.
R 학생들을 비롯해서 많은 사람이 왔어요.
+ Incluidos los estudiantes, vinieron muchas personas. :: 학생들을 비롯해서 = incluidos los estudiantes.
- Solo vinieron los estudiantes. :: Eso sería 학생들만 왔어요.
- Vinieron pocas personas. :: Eso sería 사람이 별로 안 왔어요.
A 친구들을 비롯해서 다 좋아해요. :: ¿Qué dice la persona?
+ Todos, incluidos sus amigos, lo quieren. :: 친구들을 비롯해서 = incluidos sus amigos.
- Solo a sus amigos les gusta. :: Eso sería 친구들만 좋아해요.
- A nadie le gusta. :: Eso sería 아무도 좋아하지 않아요.
O 가서 물을 사다 주세요 :: Vaya y cómprele agua :: 가서 = yendo. 사다 주세요 = cómpreme y tráigame.
Q ¿Cómo dices «cómpreme y tráigame» (사다)?
+ 사다 주세요 :: 사다 주세요.
- 사요 :: Es «compro».
- 샀어요 :: Es «compré».
H 가져다 ___. :: lléveselo y tráigalo
+ 주세요 :: 가져다 주세요 = lléveselo y tráigalo.
- 주었어요 :: Es «di», pasado.
- 줄 거예요 :: Es «daré», futuro.
Q ¿Qué significa «비롯해서»?
+ Incluido, empezando por. :: 비롯해서 introduce el primer elemento de un grupo.
- Excluido. :: Eso sería 제외하고.
- Cerca de. :: Eso sería 근처에.
