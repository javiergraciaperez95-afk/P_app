@ 11 | 찍어 주세요 | Pedir un favor
E Pedir un favor :: Para pedir a alguien que haga algo por ti se usa **-아/어 주세요** (hágame el favor de…). :: Se añade a la raíz del verbo: 찍다 → **찍어 주세요**, 기다리다 → **기다려 주세요**, 말하다 → **말해 주세요**. :: Es lo que dirías en la calle para pedir «sáqueme», «espéreme» o «dígame», pero más educado.
B Cómo se forma | Verbo | Con favor | Español
| 찍다 | 찍어 주세요 | sáqueme (una foto)
| 기다리다 | 기다려 주세요 | espéreme
| 말하다 | 말해 주세요 | dígame, háblame
W 찍어 주세요 = sáqueme (una foto)
W 한 장 더 = una foto más, una hoja más | | 장 es el contador para hojas y fotos
W 천천히 = despacio
W 말해 주세요 = dígame, háblame
W 기다려 주세요 = espéreme
W 기다려요 = espero, esperas
W 잠깐만 기다려 주세요 = espéreme un momento
W 설명해 주세요 = explíqueme
W 단어 = palabra
W 써 주세요 = escríbamelo, apúnemelo
W 도와 주세요 = ayúdeme
W 도와요 = ayudo, ayudas
W 다시 말해 주세요 = repítamelo, dígalo otra vez
V Vocabulario: pedir un favor
D Pedir una foto
안나: 여기요, 사진 좀 찍어 주세요. = Oiga, ¿me saca una foto, por favor?
  > 여기요 = oiga | 사진 좀 = una foto, por favor | 찍어 주세요 = sáqueme
민수: 네, 좋아요. 여기 보세요. = Sí, claro. Mire aquí.
  > 좋아요 = está bien | 여기 보세요 = mire aquí
안나: 고마워요. 한 장 더 찍어 주세요. = Gracias. Una foto más, por favor.
  > 고마워요 = gracias | 한 장 더 = una foto más | 찍어 주세요 = sáqueme
민수: 네, 알겠습니다. = Sí, de acuerdo.
  > 알겠습니다 = de acuerdo
Q ¿Qué significa «천천히 말해 주세요»?
+ Hable despacio, por favor. :: 천천히 = despacio. 말해 주세요 = dígame, háblame.
- Hable más rápido, por favor. :: Eso sería 빨리 말해 주세요.
- Hable usted solo. :: No pide nada de hablar despacio.
- Hable con ella. :: No tiene nada que ver con la frase.
Q ¿Cómo le pides a alguien que te saque una foto?
+ 사진 좀 찍어 주세요 :: 찍어 주세요 es «sáqueme», y 좀 suaviza la petición.
- 사진 좀 찍어요 :: Es «yo saco fotos», no pides nada.
- 사진 좀 찍었어요 :: Es pasado: «saqué una foto».
H 잠깐만 ___ 주세요. :: espéreme (un momento)
+ 기다려 :: 기다리다 → 기다려 주세요 = espéreme un momento.
- 기다려요 :: Es «espero», no un favor.
- 기다리 :: Le falta la terminación.
R 단어를 다시 설명해 주세요.
+ Explíqueme otra vez la palabra, por favor. :: 설명해 주세요 = explíqueme. 다시 = otra vez.
- Esta palabra es difícil. :: No es lo que dice la frase.
- Yo explico la palabra. :: Es al revés: aquí pides que te la expliquen.
A 잠깐만 기다려 주세요. :: ¿Qué te pide la persona?
+ Que espere un momento. :: 기다려 주세요 = espéreme.
- Que vaya a la calle. :: No se dice nada de eso.
- Que hable despacio. :: Eso sería 천천히 말해 주세요.
O 도와 주세요 :: Ayúdeme, por favor :: 도와 = ayudar. 주세요 = por favor, hágame el favor.
Q ¿Qué pides con «도와 주세요»?
+ Que me ayude. :: Es un favor de ayuda.
- Yo ayudo. :: Es 도와요.
- Que me explique. :: Es 설명해 주세요.
H 이름을 ___ 주세요. :: escríbamelo
+ 써 :: 쓰다 → 써 주세요 = escríbamelo.
- 사요 :: Es «compro», no escribe.
- 도와 :: Es «ayude», no escribe.
@ 11 | 하지 마세요 | No hagas eso: prohibir con cortesía
E No hagas eso :: Para decir que no se haga algo se usa **-지 마세요** (no…, por favor). Se añade a la raíz del verbo: 가다 → **가지 마세요**, 앉다 → **앉지 마세요**, 만지다 → **만지지 마세요**. :: 여기서 사진 찍**지 마세요** = no saque fotos aquí.
E Órdenes con cortesía :: Para decir «haga esto» de forma educada se usa **-(으)세요**: 가다 → **가세요**, 앉다 → **앉으세요**, 만지다 → **만지세요**. :: Si el verbo acaba en consonante se añade **으**; si acaba en vocal, solo **세요**. :: Es la misma terminación que en 가세요 y 보세요 que ya conoces.
B Orden o prohibición | Verbo | Orden | Prohibición
| 가다 | 가세요 = vaya | 가지 마세요 = no vaya
| 앉다 | 앉으세요 = siéntese | 앉지 마세요 = no se siente
| 만지다 | 만지세요 = toque | 만지지 마세요 = no toque
| 뛰다 | 뛰지 마세요 = no corra | (ya en prohibición)
W 가지 마세요 = no vaya, no vayas
W 앉지 마세요 = no se siente
W 앉아요 = me siento, te sientas
W 만지지 마세요 = no toque
W 만지세요 = toque (por favor)
W 만지다 = tocar
W 여기서 = aquí, en este lugar
W 찍지 마세요 = no saque
W 찍으세요 = saque
W 찍어요 = saco
W 죄송해요 = lo siento, perdone
W 조용히 하세요 = haga silencio
W 밖에서 = fuera, en el exterior
W 뛰지 마세요 = no corra
W 뛰어요 = corro, corres
W 뛰세요 = corra
W 담배 = cigarrillo
W 피우지 마세요 = no fume
W 피워요 = fumo
V Vocabulario: prohibir y ordenar
D En el museo
직원: 여기서 사진 찍지 마세요. = No saque fotos aquí.
  > 여기서 = aquí | 사진 = foto | 찍지 마세요 = no saque
안나: 아, 죄송해요. 알겠습니다. = Ah, perdone. De acuerdo.
  > 죄송해요 = lo siento | 알겠습니다 = de acuerdo
직원: 여기는 조용히 하세요. 밖에서 찍으세요. = Aquí, haga silencio. Saque fotos fuera.
  > 여기는 = aquí | 조용히 하세요 = haga silencio | 밖에서 = fuera | 찍으세요 = saque
안나: 그럼 밖에서 찍어요? = ¿Entonces saco fotos fuera?
  > 그럼 = entonces | 밖에서 = fuera | 찍어요 = saco
직원: 네, 좋아요. = Sí, bien.
  > 좋아요 = está bien
Q ¿Qué significa «여기서 사진 찍지 마세요»?
+ No saque fotos aquí. :: 찍지 마세요 = no saque (prohibición).
- Saque fotos aquí. :: Eso sería 여기서 사진 찍으세요.
- Aquí saqué fotos. :: Es pasado, no una prohibición.
H 여기서 담배를 ___. :: no fume
+ 피우지 마세요 :: 피우다 → 피우지 마세요 = no fume.
- 피우세요 :: Pide que fume, lo contrario.
- 피워요 :: Es «fumo», no una prohibición.
R 조용히 하세요.
+ Haga silencio, por favor. :: 조용히 하세요 = haga silencio.
- Hable despacio, por favor. :: Eso sería 천천히 말해 주세요.
- Entre, por favor. :: No tiene nada que ver con la frase.
A 여기서는 뛰지 마세요. :: ¿Qué le dice el guía?
+ No corra aquí. :: 뛰지 마세요 = no corra.
- Corra aquí, por favor. :: Eso sería 뛰세요 sin prohibición.
- Corra rápido. :: Eso sería 빨리 뛰세요.
O 밖에서 찍으세요 :: Saque fotos fuera :: 밖에서 = fuera. 찍으세요 = saque.
Q ¿Cómo se dice «siéntese» en coreano?
+ 앉으세요 :: 앉다 acaba en consonante, así que se añade 으세요.
- 앉지 마세요 :: Eso es «no se siente».
- 앉아요 :: Es «me siento», no una orden.
Q ¿Cuál es «no toque»?
+ 만지지 마세요 :: 만지다 → 만지지 마세요.
- 만지세요 :: Es «toque, por favor».
- 만지다 :: Es el verbo sin ninguna forma de orden.
H 여기서 ___ 마세요. :: no corra
+ 뛰지 :: 뛰다 + 지 마세요 = no corra.
- 뛰세요 :: Pide que corra.
- 뛰어요 :: Es «corro», no es una prohibición.
@ 11 | 읽으세요 | Órdenes en clase
E Órdenes en clase :: El profesor usa **-(으)세요** para dar órdenes con educación: 펴다 → **펴세요** (abra), 읽다 → **읽으세요** (lea), 쓰다 → **쓰세요** (escriba), 따라 하다 → **따라 하세요** (repita). :: Con verbos que terminan en consonante se usa **으세요**; con vocal, solo **세요**.
B Forma | Verbo | Orden | Español
| 펴다 | 펴세요 | abra (el libro)
| 읽다 | 읽으세요 | lea
| 쓰다 | 쓰세요 | escriba
| 따라 하다 | 따라 하세요 | repita, siga
W 펴세요 = abra, abran
W 펴요 = abro, abres
W 읽으세요 = lea, lean
W 읽어요 = leo, lees
W 쓰세요 = escriba, escriban
W 따라 하세요 = repita, repitan
W 따라 해요 = repito, repites
W 문장 = frase, oración
W 여기에 = aquí, en este lugar
V Vocabulario: órdenes en clase
D En clase
선생님: 책을 펴세요. = Abran el libro.
  > 책을 = el libro | 펴세요 = abran
학생: 네, 선생님. = Sí, profesor.
  > 선생님 = profesor
선생님: 이 문장을 같이 읽으세요. = Lean esta frase juntos.
  > 이 문장을 = esta frase | 같이 = juntos | 읽으세요 = lean
학생: 천천히 말해 주세요. = Hable despacio, por favor.
  > 천천히 = despacio | 말해 주세요 = dígame, háblame
선생님: 네, 다시 따라 하세요. = Sí, repitan otra vez.
  > 다시 = otra vez | 따라 하세요 = repitan
선생님: 여기에 쓰세요. = Escriban aquí.
  > 여기에 = aquí | 쓰세요 = escriban
Q ¿Qué significa «읽으세요»?
+ Lea, por favor. :: 읽다 acaba en consonante, así que se añade 으세요.
- Léame, por favor. :: Eso sería 읽어 주세요.
- Leo yo. :: Eso sería 읽어요, sin pedir nada.
H 책을 ___. :: abran
+ 펴세요 :: 펴다 → 펴세요 = abran.
- 펴요 :: Es «abro», no una orden.
- 쓰세요 :: Es «escriban», otra orden distinta.
R 여기에 쓰세요.
+ Escriban aquí. :: 쓰세요 = escriban. 여기에 = aquí.
- Escribo aquí. :: Eso sería 써요.
- Repitan aquí. :: Eso sería 따라 하세요.
A 다시 따라 하세요. :: ¿Qué pide el profesor?
+ Que repitan otra vez. :: 따라 하세요 = repitan. 다시 = otra vez.
- Que cierren el libro. :: No se dice nada de eso.
- Que escriban otra vez. :: Eso sería 다시 쓰세요.
O 이 문장을 같이 읽으세요 :: Lean esta frase juntos :: 같이 = juntos. 읽으세요 = lean.
Q ¿Cómo se dice «repita» (de 따라 하다)?
+ 따라 하세요 :: 하다 → 하세요.
- 따라 해요 :: Es «repito», sin orden.
- 따라 했어요 :: Es pasado: «repetí».
H 이 문장을 ___. :: lean
+ 읽으세요 :: 읽다 + 으세요 = lean.
- 읽어요 :: Es «leo».
- 펴세요 :: Es «abran».
