@ 27 | 먹여요 | Hacer que alguien haga algo: la causativa
E Causar una acción :: La causativa presenta a alguien como quien hace que otra persona o cosa realice una acción. Algunas formas frecuentes llevan **-이-, -히-, -리-, -기-, -우-, -구-** o **-추-**: 먹다 → **먹이다** (dar de comer), 입다 → **입히다** (vestir a alguien), 자다 → **재우다** (acostar a alguien), 웃다 → **웃기다** (hacer reír). No hay una regla segura para elegir el sufijo: aprende cada verbo con su forma causativa. :: 아기에게 우유를 **먹여요** = doy leche al bebé.
E Uso y conjugación :: Se conjugan como verbos normales: 먹이다 → **먹여요**, 입히다 → **입혀요**, 재우다 → **재워요**. Algunas formas coinciden con pasivas: el significado y los argumentos de la frase permiten distinguirlas.
B Verbo | Causativa | Forma (presente) | Español
| 먹다 | 먹이다 | 먹여요 | dar de comer
| 입다 | 입히다 | 입혀요 | vestir a alguien
| 자다 | 재우다 | 재워요 | acostar a alguien
| 웃다 | 웃기다 | 웃겨요 | hacer reír
| 앉다 | 앉히다 | 앉혀요 | sentar a alguien
W 먹여요 = doy de comer
W 먹이세요 = dé de comer, dele de comer
W 입혀요 = visto a alguien
W 입혀 줄게요 = te lo pondré, le visto
W 재워요 = acuesto a alguien, hago dormir
W 웃겨요 = hago reír
W 앉혀요 = siento a alguien
W 우유를 먹이세요 = dé leche
W 아기 = bebé
W 울어요 = llora
W 웃으면 좋겠어요 = ojalá sonría
V Vocabulario: causar una acción
D El bebé
안나: 아기가 많이 울어요. = El bebé llora mucho.
  > 아기가 = el bebé | 많이 = mucho | 울어요 = llora
민수: 그럼 우유를 먹이세요. = Entonces, dele leche.
  > 우유를 = la leche | 먹이세요 = dé de comer
안나: 네, 그리고 옷도 입혀 줄게요. = Sí, y también le pondré la ropa.
  > 옷도 = también la ropa | 입혀 줄게요 = le pondré
민수: 아기가 웃으면 좋겠어요. = Ojalá el bebé sonría.
  > 웃으면 좋겠어요 = ojalá sonría
Q ¿Qué significa «아기에게 우유를 먹여요»?
+ Doy leche al bebé. :: 먹여요 = doy de comer.
- El bebé come leche. :: Eso sería 아기가 우유를 먹어요.
- Compro leche para el bebé. :: Eso sería 우유를 사요.
H 아기에게 옷을 ___. :: le visto
+ 입혀 줄게요 :: 입다 → 입혀 줄게요: le pondré la ropa.
- 입어요 :: Es «me pongo», sin causar.
- 입었어요 :: Es «me puse», pasado.
R 아기를 재워요.
+ Acuesto al bebé. :: 재워요 = acuesto (hago dormir).
- El bebé duerme. :: Eso sería 아기가 자요.
- Despierto al bebé. :: Eso sería 아기를 깨워요.
A 웃겨요! :: ¿Qué dice la persona?
+ ¡Me haces reír! :: 웃겨요 = hace reír.
- ¡Estás triste! :: Eso sería 슬퍼요.
- ¡Estás cansado! :: Eso sería 피곤해요.
O 아기를 앉혀요 :: Siento al bebé :: 아기 = bebé. 앉혀요 = siento.
Q ¿Cómo dices «dar de comer» (먹다)?
+ 먹여요 :: 먹다 → 먹이다 → 먹여요.
- 먹어요 :: Es «como», activo.
- 먹었어요 :: Es «comí», pasado.
H 아기를 ___. :: acostar
+ 재워요 :: 자다 → 재우다 → 재워요.
- 자요 :: Es «duerme», activo.
- 잤어요 :: Es «dormí», pasado.
Q ¿Qué significa «웃기다»?
+ Hacer reír. :: 웃기다 es causar risa.
- Reírse. :: Eso sería 웃다.
- Llorar. :: Eso sería 울다.
@ 27 | 가게 해요 | Hacer que alguien haga algo: -게 하다
E Hacer que alguien haga algo :: Para decir que alguien hace que otro haga algo, o que alguien deja que lo haga, se usa **-게 하다**: 가다 → **가게 하다** (hacer que vaya), 먹다 → **먹게 하다** (hacer que coma), 공부하다 → **공부하게 하다** (hacer que estudie). :: 선생님은 우리에게 노래를 **듣게 해요** = el profesor nos hace escuchar canciones.
E Diferencia con la causativa :: **-게 하다** sirve para cualquier verbo, incluso los que no tienen causativa. La causativa (lección anterior) es una forma fija del verbo. :: 공부하게 해요 = hace que estudie. 공부시켜요 = hace estudiar (verbo fijo).
B Verbo | Con -게 하다 | Español
| 가다 | 가게 해요 | hace que vaya
| 먹다 | 먹게 해요 | hace que coma
| 듣다 | 듣게 해요 | hace que escuche
| 공부하다 | 공부하게 해요 | hace que estudie
W 듣게 해요 = hace que escuche
W 공부하게 해요 = hace que estudie
W 하게 해요 = hace que haga
W 가게 했어요 = hizo que fuera
W 많이 배우겠어요 = aprenderá mucho
W 재미있겠어요 = debe ser divertido
W 노래를 듣게 해요 = hace que escuche canciones
V Vocabulario: hacer que alguien haga
D El profesor
안나: 우리 선생님은 우리에게 매일 한국어 노래를 듣게 해요. = Nuestro profesor nos hace escuchar canciones coreanas todos los días.
  > 우리에게 = a nosotros | 매일 = todos los días | 듣게 해요 = hace que escuchemos
민수: 그럼 한국어가 재미있겠어요. = Entonces el coreano debe ser divertido.
  > 재미있겠어요 = debe ser divertido
안나: 네, 그런데 숙제도 많이 하게 해요. = Sí, pero también nos hace hacer muchos deberes.
  > 숙제도 = también los deberes | 많이 하게 해요 = hace que hagamos mucho
민수: 그래도 많이 배우겠어요. = Aun así, seguro que aprenderás mucho.
  > 많이 배우겠어요 = aprenderás mucho
Q ¿Qué significa «듣게 해요»?
+ Hace que escuche. :: 듣게 해요 = hace que escuche.
- Escucho ahora. :: Eso sería 들어요.
- Escuchó ayer. :: Eso sería 들었어요.
H 선생님이 우리에게 숙제를 ___. :: hace hacer
+ 하게 해요 :: 하다 → 하게 해요: hace que hagamos.
- 해요 :: Es «hacemos», sin causar.
- 했어요 :: Es «hicimos», pasado.
R 가게 했어요.
+ Hizo que fuera. :: 가게 했어요 = hizo que fuera.
- Fue por su cuenta. :: Eso sería 혼자 갔어요.
- Quiere ir. :: Eso sería 가고 싶어요.
A 선생님은 우리에게 노래를 듣게 해요. :: ¿Qué hace el profesor?
+ Hace que escuchemos canciones. :: 듣게 해요 = hace que escuchemos.
- Canta con nosotros. :: Eso sería 같이 노래해요.
- Toca el piano. :: Eso sería 피아노를 쳐요.
O 매일 공부하게 해요 :: Hace que estudiemos todos los días :: 매일 = todos los días. 공부하게 해요 = hace que estudiemos.
Q ¿Cómo dices «hace que coma» (먹다)?
+ 먹게 해요 :: 먹다 → 먹게 해요.
- 먹어요 :: Es «como», sin causar.
- 먹었어요 :: Es «comí», pasado.
H 아이에게 ___. :: hace que haga los deberes
+ 숙제를 하게 해요 :: 하게 해요 = hace que haga.
- 숙제를 해요 :: Es «hace los deberes», sin causar.
- 숙제를 했어요 :: Es «hizo los deberes», pasado.
Q ¿Qué significa «많이 배우겠어요»?
+ Aprenderá mucho. :: 배우겠어요 = aprenderá, seguro.
- Enseñará mucho. :: Eso sería 많이 가르쳐요.
- Aprendió mucho. :: Eso sería 많이 배웠어요.
@ 27 | 가게 해 주세요 | Dejar que alguien haga algo: -게 해 주다
E Pedir que te dejen hacerlo :: **-게 해 주다** combina «hacer/dejar que» con **주다** («hacer algo por alguien»). En una petición, suele equivaler a «déjeme…»: 가다 → **가게 해 주세요**, 먹다 → **먹게 해 주세요**, 쓰다 → **쓰게 해 주세요**. El permiso o favor se interpreta por el contexto. :: 제가 먼저 **말하게 해 주세요** = déjeme hablar primero.
E Cuidado con la forma :: Es **-게 하다** más **주다** (dar). Suena más educado cuando pides algo a alguien. :: 한번 **해 보게** 해 주세요 = déjeme probarlo una vez.
B Verbo | Pedir permiso | Dar permiso | Español
| 가다 | 가게 해 주세요 | 가게 해 줄게요 | déjeme ir / te dejo ir
| 먹다 | 먹게 해 주세요 | 먹게 해 줄게요 | déjeme comer / te dejo comer
| 말하다 | 말하게 해 주세요 | 말하게 해 줄게요 | déjeme hablar / te dejo hablar
W 가게 해 주세요 = déjeme ir
W 먹게 해 주세요 = déjeme comer
W 말하게 해 주세요 = déjeme hablar
W 가게 해 줄게요 = te dejo ir
W 제가 먼저 = yo primero
W 쓰게 해 주세요 = déjeme escribir
W 해 보게 해 주세요 = déjeme probarlo
W 말씀하세요 = hable (formal)
W 앉게 해 주세요 = déjeme sentarme
W 물론이죠 = por supuesto
W 편하게 = cómodamente, a gusto
V Vocabulario: permitir
D Pedir permiso
손님: 제가 먼저 말하게 해 주세요. = Déjeme hablar primero.
  > 제가 먼저 = yo primero | 말하게 해 주세요 = déjeme hablar
직원: 네, 말씀하세요. = Sí, hable.
  > 말씀하세요 = hable (formal)
손님: 감사합니다. 저도 여기 앉게 해 주세요. = Gracias. Déjeme sentarme aquí también.
  > 저도 = yo también | 앉게 해 주세요 = déjeme sentarme
직원: 물론이죠. 편하게 쓰세요. = Por supuesto. Escriba con comodidad.
  > 물론이죠 = por supuesto | 편하게 쓰세요 = escriba con comodidad
Q ¿Qué significa «가게 해 주세요»?
+ Déjeme ir. :: 가게 해 주세요 = déjeme ir.
- Vaya, por favor. :: Eso sería 가세요.
- Fui ayer. :: Eso sería 갔어요.
H 제가 먼저 ___. :: déjeme hablar
+ 말하게 해 주세요 :: 말하게 해 주세요 = déjeme hablar.
- 말해요 :: Es «hablo», sin permiso.
- 말했어요 :: Es «hablé», pasado.
R 저도 여기 앉게 해 주세요.
+ Déjeme sentarme aquí también. :: 앉게 해 주세요 = déjeme sentarme.
- Me siento aquí. :: Eso sería 여기 앉아요.
- Siéntese aquí. :: Eso sería 여기 앉으세요.
A 제가 먼저 말하게 해 주세요. :: ¿Qué pide la persona?
+ Pide permiso para hablar primero. :: 말하게 해 주세요 = déjeme hablar.
- Pide que hable otro. :: Eso no lo dice la frase.
- Pide ayuda para hablar. :: Eso sería 도와 주세요.
O 편하게 쓰세요 :: Escriba con comodidad :: 편하게 = cómodamente. 쓰세요 = escriba.
Q ¿Cómo dices «déjame comer»?
+ 먹게 해 주세요 :: 먹다 → 먹게 해 주세요.
- 먹어요 :: Es «como».
- 먹으세요 :: Es «coma, por favor».
H 여기서 ___. :: déjeme sentarme
+ 앉게 해 주세요 :: 앉다 → 앉게 해 주세요.
- 앉아요 :: Es «me siento».
- 앉으세요 :: Es «siéntese».
Q ¿Qué significa «편하게»?
+ Con comodidad. :: 편하게 = a gusto, cómodamente.
- Con prisa. :: Eso sería 급하게.
- Con dolor. :: Eso sería 아프게.
@ 27 | 아이를 돌보는 날 | Lectura: cuidar de un niño
W 돌보다 = cuidar
W 씻게 해요 = hago que se lave
W 먹인 뒤 = después de dar de comer
W 낮잠 = siesta
W 재우다 = acostar, hacer dormir
W 물건 = objeto, cosa
W 닿다 = alcanzar, tocar
W 돌보는 날에는 = los días en que cuido
W 울면 = si llora
W 들려줘요 = le hago oír
W 위험한 = peligroso
W 닿지 않는 곳 = un lugar que no alcanza
W 닿지 = no alcanza

W 두세요 = déjelo
W 올라가지 않게 = para que no suba
W 해 주세요 = asegúrese de
T Instrucciones para cuidar a un niño
- 아이를 돌보는 날에는 먼저 손을 씻게 해요. = Cuando cuido al niño, primero hago que se lave las manos.
- 점심을 먹인 뒤 낮잠을 재워요. = Después de darle de comer, lo acuesto para la siesta.
- 아기가 울면 좋아하는 노래를 들려줘요. = Si el bebé llora, le pongo una canción que le gusta.
- 위험한 물건은 아이의 손이 닿지 않는 곳에 두세요. = Deje los objetos peligrosos donde el niño no pueda alcanzarlos.
- 아이가 혼자 계단에 올라가지 않게 해 주세요. = Asegúrese de que el niño no suba solo las escaleras.
Q ¿Qué hace primero quien cuida al niño?
+ Hace que se lave las manos. :: 먼저 손을 씻게 해요.
- Lo acuesta para la siesta. :: Eso sucede después de comer.
- Le pone una canción. :: Eso lo hace si el bebé llora.
H 점심을 ___ 뒤 낮잠을 재워요. :: después de darle de comer
+ 먹인 :: 먹이다 es la causativa de 먹다.
- 먹는 :: Es el modificador presente.
- 먹을 :: Es el modificador futuro.
Q ¿Qué hace si el bebé llora?
+ Le pone una canción que le gusta. :: 좋아하는 노래를 들려줘요.
- Lo deja subir solo. :: El aviso indica que no suba solo.
- Le da otra siesta. :: No dice eso.
Q ¿Dónde deben dejarse los objetos peligrosos?
+ Donde el niño no pueda alcanzarlos. :: 아이의 손이 닿지 않는 곳.
- En las escaleras. :: El niño no debe subir solo.
- Junto a la cama. :: El texto no lo menciona.
O 손을 씻게 해요 :: Hago que se lave las manos :: 씻게 하다 = hacer que se lave. 손 = manos.
Q En «노래를 들려줘요», ¿qué acción realiza el adulto?
+ Le pone o le hace oír una canción al bebé. :: 들려주다 expresa hacer que alguien oiga algo.
- Le pide al bebé que cante. :: No es una forma causativa de cantar.
- El adulto oye una canción solo. :: La frase incluye el favor para otra persona.
