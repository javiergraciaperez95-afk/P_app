@ 13 | 피곤해서 | Explicar con «porque»: -아/어서
E Porque o y después :: Para unir dos frases con «porque» se usa **-아/어서** en el primer verbo. Lo que sigue es el resultado. :: 피곤하다 → **피곤해서** (porque estoy cansado). 가다 → **가서** (fui y…). :: 피곤**해서** 집에 갔어요 = como estaba cansado, me fui a casa.
E Orden de las ideas :: En coreano la causa va primero y el resultado después, como en español. :: Ya conoces **아파서** (porque estoy enfermo) de A1; ahora se usa con cualquier verbo o adjetivo.
B Palabra | Raíz | Con -아/어서 | Español
| 피곤하다 | 피곤하 | 피곤해서 | porque estoy cansado
| 가다 | 가 | 가서 | fui y…
| 먹다 | 먹 | 먹어서 | porque comí / comiendo
| 바쁘다 | 바쁘 | 바빠서 | porque estoy ocupado
W 피곤해서 = porque estoy cansado
W 가서 = fui y, y luego fui
W 먹어서 = comiendo, porque comí
W 바빠서 = porque estoy ocupado
W 배고파서 = porque tengo hambre
W 늦어서 = porque llega tarde, porque llegó tarde
W 와서 = vine y, viniendo
W 늦었어요 = llegaste tarde, llegué tarde
W 일어났어요 = me levanté, te levantaste
W 다음에는 = la próxima vez
V Vocabulario: explicar con «porque»
D Llegar tarde
민수: 안나 씨, 늦었어요! = ¡Anna, llegaste tarde!
  > 늦었어요 = llegaste tarde
안나: 미안해요. 버스가 늦어서 늦었어요. = Perdón. Como el autobús llegó tarde, llegué tarde.
  > 버스가 = el autobús | 늦어서 = porque llegó tarde | 늦었어요 = llegué tarde
민수: 아, 그래요? 괜찮아요. = Ah, ¿sí? No pasa nada.
  > 그래요 = ¿así es? | 괜찮아요 = no pasa nada
안나: 오늘 아침에 피곤해서 늦게 일어났어요. = Esta mañana, como estaba cansada, me levanté tarde.
  > 아침에 = por la mañana | 피곤해서 = porque estaba cansada | 늦게 일어났어요 = me levanté tarde
민수: 그럼 다음에는 일찍 오세요. = Entonces, la próxima vez venga temprano.
  > 다음에는 = la próxima vez | 일찍 = temprano | 오세요 = venga
Q ¿Qué significa «피곤해서 쉬었어요»?
+ Como estaba cansado, descansé. :: 피곤해서 = porque estaba cansado. 쉬었어요 = descansé.
- Descansé y después estoy cansado. :: Eso cambia el orden de las ideas.
- Estoy cansado, así que no descanso. :: Eso sería 쉬지 않아요.
H 피곤해서 ___. :: me fui a casa
+ 집에 갔어요 :: 가다 en pasado: «fui».
- 집에 가요 :: Es «voy a casa», presente.
- 집에 가세요 :: Es «vaya a casa», pedido.
R 배고파서 먹었어요.
+ Como tenía hambre, comí. :: 배고파서 = porque tenía hambre.
- Comí y después tengo hambre. :: El orden está al revés.
- Tengo hambre y no como. :: Eso sería 배고파요, sin la causa.
A 버스가 늦어서 늦었어요. :: ¿Qué explica la persona?
+ Dice que llegó tarde por el autobús. :: 버스가 늦어서 = porque el autobús llegó tarde.
- Dice que el autobús llegó temprano. :: Eso sería 일찍 왔어요.
- Dice que ya llegó a casa. :: No es lo que dice la frase.
O 피곤해서 쉬었어요 :: Como estaba cansado, descansé :: 피곤해서 = porque estaba cansado. 쉬었어요 = descansé.
Q ¿Cómo dices «porque estoy ocupado»?
+ 바빠서 :: 바쁘다 se convierte en 바빠서.
- 바쁘서 :: Esa forma no existe.
- 바쁘어서 :: Parece lógica, pero la forma correcta es 바빠서.
Q ¿Qué significa «와서 같이 먹었어요»?
+ Vino y comimos juntos. :: 와서 = vine y, luego. 같이 = juntos.
- Vine ayer. :: Eso sería 어제 왔어요.
- Comí solo. :: Eso sería 혼자 먹었어요.
H 바빠서 ___. :: no fui
+ 안 갔어요 :: 안 + 가다 en pasado: no fui.
- 갔어요 :: Es «fui».
- 가요 :: Es «voy».
@ 13 | 날씨가 좋으니까 | Dar razones y proponer: -(으)니까
E Dar una razón :: **-(으)니까** presenta el motivo o fundamento de lo que sigue: **날씨가 좋으니까 공원에 갈까요?** = como hace buen tiempo, ¿vamos al parque? También es natural antes de una petición, orden o sugerencia. No significa que la razón tenga que ser evidente para quien escucha.
E Cómo se forma :: Con una raíz acabada en vocal o **ㄹ**, añade **-니까**: 가다 → **가니까**, 살다 → **사니까**. Con otra consonante, añade **-으니까**: 먹다 → **먹으니까**, 좋다 → **좋으니까**. En **ㄹ**, se conserva la raíz sin ㄹ: 만들다 → **만드니까**.
E Frente a -아/어서 :: Ambas formas pueden expresar causa. **-아/어서** presenta con frecuencia una relación causa-resultado; **-(으)니까** destaca la razón que da el hablante y encaja especialmente bien antes de una sugerencia, una orden o una petición. La diferencia depende del contexto; no se reduce a «hecho evidente» frente a «hecho no evidente».
B Verbo | Regla | Con -(으)니까 | Ejemplo de sentido
| 가다 | vocal | 가니까 | como voy
| 먹다 | otra consonante | 먹으니까 | como como
| 살다 | ㄹ: se quita ㄹ | 사니까 | como vivo
| 만들다 | ㄹ: se quita ㄹ | 만드니까 | como lo hago
| 좋다 | otra consonante | 좋으니까 | como está bien
W 좋으니까 = como hace buen tiempo, porque está bien
W 가니까 = como voy, porque voy
W 사니까 = como vivo
W 만드니까 = como lo hago
W 먹으니까 = como como, porque como
W 비가 오니까 = como llueve, porque llueve
W 가져가세요 = lleve (se lo lleve)
W 두고 가세요 = déjelo aquí / márchese sin llevárselo
W 시간이 없다 = no tener tiempo
W 시간이 없으니까 = como no tengo tiempo
W 택시를 타다 = tomar un taxi
W 택시를 타고 = tomando un taxi y
W 나중에 = más tarde, luego
V Vocabulario: motivos y propuestas
D Un día de sol
민수: 오늘 날씨가 좋으니까 공원에 갈까요? = Como hace buen tiempo hoy, ¿vamos al parque?
  > 날씨가 좋으니까 = como hace buen tiempo | 공원에 갈까요 = ¿vamos al parque?
안나: 좋아요! 점심은 어디에서 먹을까요? = ¡Bien! ¿Dónde comemos?
  > 점심은 = el almuerzo (tema) | 어디에서 = dónde | 먹을까요 = ¿comemos?
민수: 공원 근처 식당에서 먹어요. 밖에서 먹으니까 정말 좋아요. = Comemos en un restaurante cerca del parque. Como comemos fuera, es genial.
  > 근처 = cerca | 밖에서 먹으니까 = como comemos fuera
안나: 오늘은 비가 안 와요. 우산은 두고 가세요. = Hoy no llueve. Deje el paraguas.
  > 오늘은 = hoy | 비가 안 와요 = no llueve | 두고 가세요 = déjelo atrás, no se lo lleve
Q ¿Qué matiz tiene «날씨가 좋으니까 공원에 갈까요?»?
+ «-(으)니까» presenta la razón para proponer ir al parque. :: El buen tiempo justifica la propuesta.
- «-(으)니까» significa «aunque». :: El contraste se expresa con -지만.
- La frase dice que fueron al parque ayer. :: No está en pasado.
H 시간이 없으니까 ___ 가세요. :: vaya en taxi
+ 택시를 타고 :: 택시를 타고 가세요 = vaya en taxi.
- 택시를 타서 :: No expresa aquí la recomendación que sigue.
- 택시를 탔어요 :: Es pasado: «tomé un taxi».
R 공원에 갈까요?
+ ¿Vamos al parque? :: 갈까요 = ¿vamos?
- ¿Fuiste al parque? :: Eso sería 갔어요?
- ¿Vas al parque? :: Eso sería 가요?
A 날씨가 좋으니까 밖에서 먹어요. :: ¿Qué dice la persona?
+ Como hace buen tiempo, comemos fuera. :: 좋으니까 = como hace buen tiempo.
- Como hace frío, comemos dentro. :: Eso no es lo que dice.
- Hace buen tiempo y no comemos. :: Eso no lo dice la frase.
O 날씨가 좋으니까 공원에 갈까요? :: Como hace buen tiempo, ¿vamos al parque? :: 좋으니까 presenta la razón de una propuesta: «como hace buen tiempo».
Q Si la raíz acaba en ㄹ, ¿qué pasa antes de -(으)니까?
+ Se quita ㄹ y se añade -니까: 만들다 → 만드니까. :: Esta regla también da 살다 → 사니까.
- Se conserva ㄹ y se añade -으니까: 만들으니까. :: Con ㄹ no se usa 으니까.
- Se conserva ㄹ y se añade -니까: 만들니까. :: La ㄹ final se elimina antes de 니까.
@ 13 | 맛있지만 | Pero: -지만
E Pero con -지만 :: Para decir «pero» después de algo positivo o negativo se usa **-지만**. :: 가다 → **가지만**, 먹다 → **먹지만**, 좋다 → **좋지만**, 비싸다 → **비싸지만**. :: 음식은 **맛있지만** 비싸요 = la comida está rica, pero es cara.
E Frente a 하지만 :: **하지만** (pero) va al principio de la frase; **-지만** va unido al verbo, dentro de la misma frase. :: Ya conoces **하지만**, y **맵지만** de A1; ahora se usa en cualquier frase.
B Verbo | Raíz | Con -지만 | Español
| 좋다 | 좋 | 좋지만 | está bien, pero…
| 먹다 | 먹 | 먹지만 | como, pero…
| 비싸다 | 비싸 | 비싸지만 | es caro, pero…
| 가다 | 가 | 가지만 | voy, pero…
W 맛있지만 = está rico, pero
W 먹지만 = como, pero
W 좋지만 = está bien, pero
W 비싸지만 = es caro, pero
W 불어요 = sopla, hace (viento)
W 날씨는 = el tiempo (tema)
W 그래도 = aun así, sin embargo
W 가지만 = voy, pero
V Vocabulario: pero
D Comer fuera
안나: 이 식당 음식이 맛있지만 좀 비싸요. = La comida de este restaurante está rica, pero es un poco cara.
  > 맛있지만 = está rica, pero | 좀 비싸요 = es un poco cara
민수: 맞아요. 그래도 저는 자주 와요. = Es verdad. Aun así vengo a menudo.
  > 맞아요 = es verdad | 그래도 = aun así | 자주 와요 = vengo a menudo
안나: 날씨는 좋지만 바람이 많이 불어요. = El tiempo es bueno, pero sopla mucho viento.
  > 날씨는 = el tiempo (tema) | 좋지만 = es bueno, pero | 바람이 많이 불어요 = sopla mucho viento
민수: 그럼 안에서 먹어요. = Entonces comemos dentro.
  > 그럼 = entonces | 안에서 = dentro
Q ¿Qué significa «맛있지만 비싸요»?
+ Está rico, pero es caro. :: 맛있지만 = está rico, pero.
- Está caro, pero es rico. :: El orden de las ideas está cambiado.
- Está rico y es caro. :: Falta el contraste «pero».
H 날씨는 좋지만 ___. :: sopla viento
+ 바람이 불어요 :: 바람이 불어요 = sopla viento.
- 바람이 불었어요 :: Es pasado: «sopló».
- 바람이 좋아요 :: No se entiende, el viento no es bueno ahí.
R 음식은 맛있지만 비싸요.
+ La comida está rica, pero es cara. :: 맛있지만 = está rica, pero.
- La comida es cara, aunque está rica. :: Mucho sentido parecido; no es la traducción literal.
- La comida está rica y es barata. :: Eso no lo dice la frase.
A 가지만 바빠요. :: ¿Qué dice la persona?
+ Voy, pero estoy ocupado. :: 가지만 = voy, pero.
- Voy y estoy contento. :: Falta el contraste.
- No voy porque estoy ocupado. :: Eso sería 바빠서 안 가요.
O 날씨는 좋지만 바람이 불어요 :: El tiempo es bueno, pero hay viento :: 좋지만 = es bueno, pero. 바람이 불어요 = hay viento.
Q ¿Cuál es «es caro, pero»?
+ 비싸지만 :: 비싸다 + 지만.
- 비싸서 :: Es «porque es caro», una causa.
- 비싸니까 :: Es «como es caro», una razón evidente.
H 음식은 ___, 맛있어요. :: es caro, pero está rico
+ 비싸지만 :: 비싸다 + 지만.
- 비싸서 :: Es «porque es caro», no el contraste.
- 비싸요 :: Es «es caro», sin contraste.
