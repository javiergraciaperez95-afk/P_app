@ 19 | 먹으러 가요 | Ir a hacer algo: -(으)러 가다
E Propósito de un desplazamiento :: **-(으)러 가다/오다** indica qué acción motiva el desplazamiento: 먹다 → **먹으러 가요** (voy a comer), 사다 → **사러 가요** (voy a comprar), 보다 → **보러 가요** (voy a ver). Suele usarse con verbos de movimiento; el propósito se expresa con esta forma antes de 가다/오다.
E Forma :: Después de vocal o de **ㄹ** se añade **-러**; después de otra consonante, **-으러**: 사다 → **사러**, 살다 → **살러**, 먹다 → **먹으러**. Se usa normalmente con verbos de movimiento como 가다 y 오다: 책을 사러 가요 (voy a comprar un libro).
B Verbo | Raíz | Para… | Español
| 먹다 | otra consonante | 먹으러 가요 | voy a comer
| 사다 | vocal | 사러 가요 | voy a comprar
| 보다 | vocal | 보러 가요 | voy a ver
| 배우다 | vocal | 배우러 가요 | voy a aprender
| 놀다 | ㄹ | 놀러 가요 | voy a divertirme
| 만들다 | ㄹ | 만들러 가요 | voy a hacer/preparar
W 먹으러 가요 = voy a comer
W 사러 가요 = voy a comprar
W 보러 가요 = voy a ver
W 배우러 가요 = voy a aprender
W 마시러 가요 = voy a beber
W 놀러 가요 = voy a divertirme, voy a pasar el rato
W 만들러 가요 = voy a hacer, voy a preparar
W 일하러 가요 = voy a trabajar
W 가도 돼요 = ¿puedo ir?, se puede ir
W 그럼요 = ¡claro!
W 같이 먹으러 가요 = vamos juntos a comer
V Vocabulario: ir a hacer algo
D El plan del sábado
민수: 주말에 뭐 해요? = ¿Qué haces el fin de semana?
  > 주말에 = el fin de semana | 뭐 해요 = qué haces
안나: 시장에 옷을 사러 가요. = Voy al mercado a comprar ropa.
  > 시장에 = al mercado | 옷을 = ropa | 사러 가요 = voy a comprar
민수: 저도 같이 가도 돼요? = ¿Puedo ir contigo también?
  > 저도 = yo también | 같이 가도 돼요 = ¿puedo ir juntos?
안나: 그럼요! 같이 먹으러 가요. = ¡Claro! Vamos juntos a comer.
  > 그럼요 = ¡claro! | 같이 먹으러 가요 = vamos juntos a comer
Q ¿Qué significa «옷을 사러 가요»?
+ Voy a comprar ropa. :: 사러 가요 = voy a comprar.
- Compré ropa. :: Eso sería 옷을 샀어요.
- Compro ropa todos los días. :: Eso sería 매일 옷을 사요.
H 저는 영화를 ___ 가요. :: para ver
+ 보러 :: 보다 → 보러 가요 = voy a ver.
- 봐요 :: Es «veo», sin ir.
- 봤어요 :: Es «vi», pasado.
R 먹으러 가요.
+ Voy a comer. :: 먹으러 가요 = voy a comer.
- Comí. :: Eso sería 먹었어요.
- Como todos los días. :: Eso sería 매일 먹어요.
A 같이 배우러 가요. :: ¿Qué dice la persona?
+ Vamos juntos a aprender. :: 배우러 가요 = vamos a aprender.
- Vamos juntos a comprar. :: Eso sería 같이 사러 가요.
- Vamos juntos a comer. :: Eso sería 같이 먹으러 가요.
O 마시러 가요 :: Voy a beber :: 마시러 가요 = voy a beber.
Q ¿Cómo dices «voy a comprar»?
+ 사러 가요 :: 사다 → 사러 가요.
- 사요 :: Es «compro», sin ir.
- 샀어요 :: Es «compré», pasado.
Q ¿Qué significa «놀러 가요»?
+ Voy a divertirme. :: 놀러 가요 = voy a pasar el rato.
- Voy a trabajar. :: Eso sería 일하러 가요.
- Voy a estudiar. :: Eso sería 공부하러 가요.
H 시장에 옷을 ___ 가요. :: para comprar
+ 사러 :: 사다 → 사러 가요 = voy a comprar.
- 사요 :: Es «compro», sin ir.
- 샀어요 :: Es «compré», pasado.
@ 19 | 갈게요 | Prometer o decidir: -(으)ㄹ게요
E Comprometerse a hacer algo :: **-(으)ㄹ게요** expresa una decisión, disposición o compromiso del hablante, a menudo como respuesta a la situación del interlocutor: 기다릴게요 = te esperaré; 전화할게요 = te llamaré. Normalmente el sujeto es «yo/nosotros» (frecuentemente omitido), y la forma no se usa para preguntar por la intención del interlocutor.
E Frente a -(으)ㄹ 거예요 :: **-(으)ㄹ 거예요** presenta un plan/intención o una predicción: 내일 갈 거예요 = iré mañana / tengo pensado ir mañana. **-(으)ㄹ게요** muestra el compromiso del hablante hacia otra persona: 기다릴게요 = te esperaré. No se limita solo a decisiones tomadas en el instante.
B Verbo | Raíz | Lo haré yo | Español
| 가다 | 가 | 갈게요 | iré
| 먹다 | 먹 | 먹을게요 | comeré, lo tomaré
| 기다리다 | 기다리 | 기다릴게요 | esperaré
| 전화하다 | 전화하 | 전화할게요 | te llamaré
W 갈게요 = iré, voy
W 먹을게요 = comeré, lo tomaré
W 기다릴게요 = esperaré
W 전화할게요 = te llamaré
W 전화 = teléfono, llamada
W 곧 = enseguida, pronto
W 조금만 = un poquito, solo un poco
W 제가 = yo (formal)
V Vocabulario: decidir y prometer
D Llegar a la estación
안나: 민수 씨, 지금 어디에 있어요? = Minsu, ¿dónde estás ahora?
  > 지금 = ahora | 어디에 있어요 = dónde estás
민수: 지금 역 근처예요. 곧 갈게요. = Estoy cerca de la estación. Llego enseguida.
  > 역 근처예요 = cerca de la estación | 곧 = enseguida | 갈게요 = iré
안나: 네, 기다릴게요. = Vale, te esperaré.
  > 기다릴게요 = esperaré
민수: 고마워요. 조금만 기다려 주세요. = Gracias. Espera un poquito, por favor.
  > 조금만 = un poquito | 기다려 주세요 = espera
Q En «제가 기다릴게요», ¿qué expresa -ㄹ게요?
+ El compromiso/disposición del hablante a esperar. :: La forma presenta lo que el hablante se ofrece a hacer.
- Una pregunta al interlocutor sobre si esperará. :: -ㄹ게요 no se usa para preguntar por la intención del otro.
- Una acción pasada. :: El pasado sería 기다렸어요.
H 지금 ___. :: iré
+ 갈게요 :: 가다 → 갈게요: iré.
- 가요 :: Es «voy», sin decidir ahora.
- 갔어요 :: Es «fui», pasado.
R 기다릴게요.
+ Te esperaré. :: 기다릴게요 = esperaré.
- Espero siempre. :: Eso sería 항상 기다려요.
- Esperé ayer. :: Eso sería 어제 기다렸어요.
A 제가 전화할게요. :: ¿Qué dice la persona?
+ Te llamaré yo. :: 전화할게요 = te llamaré.
- Me llamó ayer. :: Eso sería 어제 전화했어요.
- Le llamo todos los días. :: Eso sería 매일 전화해요.
O 먹을게요 :: Comeré / lo tomaré :: 먹을게요 = comeré / lo tomaré.
Q ¿Cómo dices «iré»?
+ 갈게요 :: 가다 → 갈게요.
- 가세요 :: Es «vaya, por favor».
- 가요 :: Es «voy».
Q ¿Qué significa «조금만 기다려 주세요»?
+ Espere un poquito, por favor. :: 조금만 = un poquito; 기다려 주세요 = espere.
- Espere mucho, por favor. :: Eso sería 오래 기다려 주세요.
- Vamos a esperar juntos. :: Eso sería 같이 기다려요.
H 저는 이거 ___. :: lo tomaré
+ 먹을게요 :: 먹다 → 먹을게요.
- 먹어요 :: Es «como», sin decidir.
- 먹었어요 :: Es «comí», pasado.
@ 19 | 도와줄게요 | Ofrecer ayuda: -아/어 줄게요
E Te lo hago yo :: Para ofrecerte a hacer algo por alguien se usa **-아/어 줄게요** (te lo hago, te ayudo): 도와주다 → **도와줄게요** (te ayudo), 가져다주다 → **가져다줄게요** (te lo llevo). :: 제가 **도와줄게요** = yo te ayudo.
E Forma y destinatario :: Se combina **-아/어 주다** («hacer algo para alguien») con **-(으)ㄹ게요**: 도와주다 → **도와줄게요**. El hablante se ofrece a realizar la acción para otra persona. Contrasta **도와 주세요** (le pido que me ayude) con **도와줄게요** (yo le ayudaré). El destinatario puede indicarse con **한테/에게**: 친구한테 알려 줄게요 (se lo diré a mi amigo).
B Forma | Lo que ofreces | Español
| 도와주다 | 도와줄게요 | te ayudo
| 가져다주다 | 가져다줄게요 | te lo llevo
| 알려 주다 | 알려 줄게요 | te lo digo, te aviso
| 같이 가다 | 같이 갈게요 | iré contigo
W 도와줄게요 = te ayudo
W 가져다줄게요 = te lo llevo, te lo traigo
W 짐 = equipaje, cosas, bultos
W 집까지 = hasta casa
W 정말요 = ¿de verdad?
W 같이 갈게요 = iré contigo
W 알려 줄게요 = te lo digo, te aviso
V Vocabulario: ofrecer ayuda
D Llevar las cosas
안나: 짐이 너무 무거워요. = El equipaje pesa mucho.
  > 짐이 = el equipaje | 너무 무거워요 = pesa mucho
민수: 제가 집까지 가져다줄게요. = Yo te lo llevaré hasta casa.
  > 제가 = yo | 집까지 = hasta casa | 가져다줄게요 = te lo llevaré
안나: 정말요? 고마워요. 우리 집은 역 근처예요. = ¿De verdad? Gracias. Mi casa está cerca de la estación.
  > 정말요 = ¿de verdad? | 우리 집은 = mi casa | 역 근처예요 = cerca de la estación
민수: 그럼 같이 갈게요. = Entonces iré contigo.
  > 그럼 = entonces | 같이 갈게요 = iré contigo
  > 그럼 = entonces | 같이 갈게요 = iré contigo
Q ¿Qué expresa «도와줄게요»?
+ El hablante se ofrece a ayudar a otra persona. :: -아/어 주다 + -(으)ㄹ게요: haré esa acción para ti.
- El hablante pide que le ayuden. :: Eso sería 도와 주세요.
- El hablante describe un hábito de ayuda. :: Eso sería 매일 도와요.
H 짐이 무거워요? 제가 ___. :: te ayudaré
+ 도와줄게요 :: 도와주다 → 도와줄게요.
- 도와요 :: Es «ayudo», sin ofrecer.
- 도와 주세요 :: Es «ayúdeme», al revés.
R 제가 가져다줄게요.
+ Yo te lo llevo. :: 가져다줄게요 = te lo llevo.
- Te lo llevé ayer. :: Eso sería 어제 가져다줬어요.
- Llévalo tú, por favor. :: Eso sería 가져가세요.
A 제가 알려 줄게요. :: ¿Qué dice la persona?
+ Yo te lo digo. :: 알려 줄게요 = te lo digo.
- Ya lo sé todo. :: No dice eso la frase.
- Te pido información. :: Eso sería 알려 주세요.
O 같이 갈게요 :: Iré contigo :: 같이 = juntos. 갈게요 = iré.
Q ¿Cómo dices «te ayudaré»?
+ 도와줄게요 :: 도와주다 → 도와줄게요.
- 도와요 :: Es «ayudo», sin ofrecer.
- 도와 주세요 :: Es «ayúdeme», al revés.
Q ¿Qué significa «알려 줄게요»?
+ Te lo digo. :: 알려 줄게요 = te lo digo.
- Lo sé todo. :: Eso sería 다 알아요.
- Lo olvidé. :: Eso sería 잊었어요.
H 제가 ___. :: lo traeré
+ 가져다줄게요 :: 가져다주다 → 가져다줄게요.
- 가져가요 :: Es «llevamos», otra idea.
- 가져가세요 :: Es «lleve, por favor».
