@ 24 | 문이 열려요 | Cosas que se hacen solas: la pasiva con -이/히/리/기
E Qué es la pasiva :: En coreano, muchos verbos tienen una forma que significa que algo se hace solo o que alguien lo hace a otro: 열다 → **열리다** (abrirse, ser abierto), 닫다 → **닫히다** (cerrarse, ser cerrado), 잡다 → **잡히다** (ser atrapado), 보다 → **보이다** (verse). :: 문이 **열려요** = la puerta se abre.
E Forma :: La pasiva se forma con **-이-, -히-, -리-, -기-** según el verbo. Hay que aprenderla con cada verbo. :: Cuando la forma pasiva acaba en ㅣ se conjuga como un verbo normal: 열리다 → **열려요**, 닫히다 → **닫혀요**.
B Activo | Pasiva | Español
| 열다 | 열리다 | abrirse, ser abierto
| 닫다 | 닫히다 | cerrarse, ser cerrado
| 잡다 | 잡히다 | ser atrapado
| 보다 | 보이다 | verse, ser visible
W 열리다 = abrirse, ser abierto
W 열려요 = se abre
W 닫혀요 = se cierra
W 닫히다 = cerrarse, ser cerrado
W 잡히다 = ser atrapado, ser agarrado
W 보여요 = se ve, parece
W 안 열려요 = no se abre
W 잠겨 있어요 = está cerrado con llave
W 닫혀 있어요 = está cerrada
W 열쇠 = llave (A1, uso de contexto)
V Vocabulario: pasiva
D La puerta no se abre
민수: 문이 왜 안 열려요? = ¿Por qué no se abre la puerta?
  > 왜 = por qué | 문이 = la puerta | 안 열려요 = no se abre
안나: 문이 잠겨 있어요. = La puerta está cerrada con llave.
  > 문이 = la puerta | 잠겨 있어요 = está cerrada con llave
민수: 아, 그럼 여기 열쇠가 있어요? = Ah, ¿entonces hay una llave aquí?
  > 여기 = aquí | 열쇠가 있어요 = hay una llave
안나: 네, 저기 가방 안에 보여요. = Sí, se ve ahí dentro, en la bolsa.
  > 저기 = allí | 가방 안에 = dentro de la bolsa | 보여요 = se ve
Q ¿Qué significa «문이 열려요»?
+ La puerta se abre. :: 열려요 = se abre; es la pasiva de 열다.
- Abro la puerta. :: Eso sería 문을 열어요.
- Abrí la puerta. :: Eso sería 문을 열었어요.
H 창문이 ___ 있어요. :: está cerrada
+ 닫혀 :: 닫혀 있어요 = está cerrada.
- 닫아 :: Es activo: «cierro».
- 열려 :: Es «abierta», lo contrario.
R 문이 잠겨 있어요.
+ La puerta está cerrada con llave. :: 잠겨 있어요 = está cerrada con llave.
- La puerta está abierta. :: Eso sería 열려 있어요.
- Cierro la puerta. :: Eso sería 문을 닫아요.
A 가방 안에 보여요. :: ¿Qué dice la persona?
+ Se ve dentro de la bolsa. :: 보여요 = se ve.
- Se ve fuera de la bolsa. :: Eso sería 가방 밖에 보여요.
- No se ve nada. :: Eso sería 아무것도 안 보여요.
O 문이 안 열려요 :: La puerta no se abre :: 문이 = la puerta. 안 열려요 = no se abre.
Q ¿Cómo dices «se cierra» (닫다)?
+ 닫혀요 :: 닫히다 → 닫혀요.
- 닫아요 :: Es «cierro», activo.
- 닫았어요 :: Es «cerré», pasado activo.
H 문이 안 ___. :: se abre
+ 열려요 :: 열리다 → 열려요.
- 열어요 :: Es «abro», activo.
- 열었어요 :: Es «abrí», pasado activo.
Q ¿Qué significa «잠겨 있어요»?
+ Está cerrado con llave. :: 잠겨 있어요 = está cerrado con llave.
- Está abierto. :: Eso es 열려 있어요.
- Está limpio. :: Eso sería 깨끗해요.
@ 24 | 사진이 잘 찍혔어요 | Pasiva en el pasado: lo que salió, lo que fue atrapado
E Lo que sale bien o mal :: Con **찍히다** se dice que algo sale en una foto: 찍다 → **찍혔어요** (salió). También se usa para decir que alguien fue atrapado o pisado: 잡다 → **잡혔어요** (fue atrapado), 밟다 → **밟혔어요** (fue pisado). :: 사진이 잘 **찍혔어요** = la foto ha salido bien.
E Pasado :: La forma pasada se hace como la del verbo normal, con **-았/었어요**: 찍히다 → 찍혔어요, 잡히다 → 잡혔어요, 밟히다 → 밟혔어요. :: 발을 **밟혔어요** = me pisaron el pie.
B Activo | Pasiva (pasado) | Español
| 찍다 | 찍혔어요 | salió (en la foto)
| 잡다 | 잡혔어요 | fue atrapado
| 밟다 | 밟혔어요 | fue pisado
W 찍혔어요 = salió (en una foto)
W 사진이 잘 찍혔어요 = la foto ha salido bien
W 잡혔어요 = fue atrapado
W 도둑 = ladrón
W 밟혔어요 = fue pisado
W 발을 밟혔어요 = me pisaron el pie
W 얼굴 = cara, rostro
W 어두워 보여요 = parece oscuro, se ve oscura
W 근데 = pero (habla), oye
V Vocabulario: lo que sale o lo que atrapan
D La foto
안나: 이 사진 잘 찍혔어요? = ¿Ha salido bien esta foto?
  > 이 사진 = esta foto | 잘 찍혔어요 = ha salido bien
민수: 네, 아주 잘 찍혔어요. = Sí, ha salido muy bien.
  > 아주 = muy | 잘 찍혔어요 = ha salido bien
안나: 근데 제 얼굴이 어두워 보여요. = Pero mi cara se ve oscura.
  > 근데 = pero | 제 얼굴이 = mi cara | 어두워 보여요 = se ve oscura
민수: 아니요, 아주 예뻐요. = No, estás muy guapa.
  > 아주 = muy | 예뻐요 = eres guapa
Q ¿Qué significa «사진이 잘 찍혔어요»?
+ La foto ha salido bien. :: 찍혔어요 = ha salido (en la foto).
- Saqué bien la foto. :: Eso sería 사진을 잘 찍었어요.
- Quiero sacar fotos. :: Eso sería 사진을 찍고 싶어요.
H 도둑이 ___. :: fue atrapado
+ 잡혔어요 :: 잡다 → 잡혔어요: fue atrapado.
- 잡았어요 :: Es «atrapé», activo.
- 잡아요 :: Es «atrapo», activo.
R 발을 밟혔어요.
+ Me pisaron el pie. :: 밟혔어요 = fui pisado.
- Pisé el pie. :: Eso sería 발을 밟았어요.
- Me corté el pie. :: Eso no lo dice la frase.
A 얼굴이 어두워 보여요. :: ¿Cómo se ve la cara?
+ Se ve oscura. :: 어두워 보여요 = se ve oscura.
- Se ve muy grande. :: Eso sería 커 보여요.
- Se ve muy alegre. :: Eso no lo dice la frase.
O 아주 잘 찍혔어요 :: Ha salido muy bien :: 아주 = muy. 잘 찍혔어요 = ha salido bien.
Q ¿Cómo dices «fue atrapado» (잡다)?
+ 잡혔어요 :: 잡다 → 잡혔어요.
- 잡았어요 :: Es «atrapé».
- 잡아요 :: Es «atrapo».
H 근데 제 ___ 어두워 보여요. :: cara
+ 얼굴이 :: 얼굴이 어두워 보여요 = mi cara se ve oscura.
- 발이 :: Es «mi pie».
- 손이 :: Es «mi mano».
Q ¿Qué significa «근데»?
+ Pero (en el habla diaria). :: 근데 suena natural en conversación.
- Por eso. :: Eso sería 그래서.
- Ya. :: Eso sería 벌써.
@ 24 | 소리가 들려요 | Lo que se oye o se conoce: 들리다 y 알려지다
E Lo que se oye :: Para decir que algo se oye, sin que lo hagas tú, se usa **들리다** (ser oído, se oye): 듣다 → **들려요** (se oye). :: 무슨 소리가 **들려요**? = ¿qué ruido se oye?
E Lo que se conoce :: **알려지다** (hacerse conocido) viene de **알다**: 이름이 **알려졌어요** = su nombre se ha hecho conocido. **쓰이다** (usarse) y **쓰여 있다** (estar escrito) vienen de **쓰다**. :: 간판에 **쓰여 있어요** = está escrito en el letrero.
B Activo | Pasiva | Español
| 듣다 | 들리다 | se oye
| 알다 | 알려지다 | llegar a conocerse
| 쓰다 | 쓰여 있다 | estar escrito
W 들려요 = se oye, se escucha
W 소리가 들려요 = se oye un ruido
W 소리 = ruido, sonido
W 간판 = letrero, cartel
W 쓰여 있는 = que está escrito
W 쓰여 있어요 = está escrito
W 알려졌어요 = se hizo conocido, se supo
W 음악 소리가 들려요 = se oye música
V Vocabulario: lo que se oye y se conoce
D Un ruido en la calle
민수: 무슨 소리가 들려요? = ¿Qué ruido se oye?
  > 무슨 소리가 = qué ruido | 들려요 = se oye
안나: 저 밖에서 음악 소리가 들려요. = Se oye música fuera.
  > 저 밖에서 = fuera | 음악 소리가 들려요 = se oye música
민수: 아, 저기 간판에 쓰여 있는 가게예요. = Ah, es la tienda que está escrita en el letrero de allí.
  > 저기 = allí | 간판에 쓰여 있는 = que está escrito en el letrero | 가게예요 = es la tienda
안나: 그 가게 이름이 알려졌어요? = ¿Se ha hecho conocido el nombre de ese local?
  > 가게 이름이 = el nombre del local | 알려졌어요 = se ha hecho conocido
Q ¿Qué significa «소리가 들려요»?
+ Se oye un ruido. :: 들려요 = se oye.
- Escucho un ruido. :: Eso sería 소리를 들어요.
- Hago ruido. :: Eso sería 소리를 내요.
H 저 밖에서 음악 소리가 ___. :: se oye
+ 들려요 :: 듣다 → 들려요: se oye.
- 들어요 :: Es «escucho», activo.
- 들었어요 :: Es «escuché», pasado activo.
R 그 가게 이름이 알려졌어요.
+ El nombre de ese local se ha hecho conocido. :: 알려졌어요 = se ha hecho conocido.
- Ese local tiene un nombre nuevo. :: Eso sería 새 이름이에요.
- Cambiaron el nombre del local. :: Eso sería 이름을 바꿨어요.
A 간판에 쓰여 있어요. :: ¿Dónde está escrito?
+ Está escrito en el letrero. :: 쓰여 있어요 = está escrito.
- Está escrito en un libro. :: Eso sería 책에 쓰여 있어요.
- Lo escribí en el letrero. :: Eso sería 간판에 썼어요.
O 간판에 쓰여 있는 가게 :: El local que está escrito en el letrero :: 간판 = letrero. 쓰여 있는 = que está escrito. 가게 = tienda.
Q ¿Cómo dices «se oye» (듣다)?
+ 들려요 :: 듣다 → 들려요.
- 들어요 :: Es «escucho».
- 들었어요 :: Es «escuché».
Q ¿Qué significa «알려졌어요»?
+ Se hizo conocido. :: 알려졌어요 = se hizo conocido.
- Lo conoció ayer. :: Eso sería 어제 알았어요.
- Lo conozco bien. :: Eso sería 잘 알아요.
