@ 10 | 어제 뭐 했어요? | El pasado
E Cómo se forma el pasado :: El pasado sale del presente con un truco muy sencillo: quita **요** y añade **ㅆ어요**. :: 가요 → **갔어요** (fui). 먹어요 → **먹었어요** (comí). 봐요 → **봤어요** (vi). 마셔요 → **마셨어요** (bebí). 해요 → **했어요** (hice). :: Como siempre, vale para todas las personas: 갔어요 es «fui», «fuiste», «fue»… :: Sirve tanto para «comí» como para «he comido».

@ 10 | 반갑습니다 | El estilo formal
I Todo lo que has aprendido hasta ahora (-아요 / -어요) es la forma educada de la vida diaria. Hay otra, más formal, que oirás en las noticias, en el trabajo y en los avisos, y que aparece en los textos de los exámenes.
E El estilo formal: -ㅂ니다 / -습니다 :: Se forma con la raíz del verbo (la forma del diccionario sin 다). Si acaba en **vocal**, se le pone **-ㅂ니다**: 가다 → **갑니다**, 하다 → **합니다**. Si acaba en **consonante**, **-습니다**: 먹다 → **먹습니다**, 있다 → **있습니다**. :: «Ser» es **입니다**: 학생**입니다** (soy estudiante). «No ser» es **아닙니다**. :: Se pronuncia con «m»: 합니다 = «ham-ni-da». :: Ya conocías dos: **감사합니다** y **반갑습니다**.

E Preguntar en formal :: La pregunta cambia la terminación: **-ㅂ니까? / -습니까?** :: 학생**입니까?** = ¿es usted estudiante? 질문이 **있습니까?** = ¿hay alguna pregunta?
E Fórmulas formales :: **안녕하십니까?** = hola (muy formal). **처음 뵙겠습니다** = mucho gusto, al conocer a alguien. **죄송합니다** = lo siento, perdone. **알겠습니다** = entendido.

T Una presentación formal
- 안녕하십니까? 처음 뵙겠습니다. = Buenos días. Mucho gusto.
  > 안녕하십니까 = hola, muy formal | 처음 뵙겠습니다 = «le veo por primera vez»
- 저는 김민수입니다. = Soy Kim Minsu.
  > 김민수입니다 = soy Kim Minsu
- 한국 사람입니다. 서울에 삽니다. = Soy coreano. Vivo en Seúl.
  > 사람입니다 = soy (persona de) | 서울에 삽니다 = vivo en Seúl
- 은행에서 일합니다. = Trabajo en un banco.
  > 일합니다 = trabajo
- 주말에는 보통 등산을 합니다. = Los fines de semana normalmente hago senderismo.
  > 등산을 합니다 = hago senderismo
- 한국 음식을 좋아합니다. = Me gusta la comida coreana.
  > 좋아합니다 = me gusta
- 질문이 있습니까? = ¿Hay alguna pregunta?
  > 질문이 = pregunta (sujeto) | 있습니까 = ¿hay?
- 감사합니다. = Gracias.
  > 감사합니다 = gracias

Q ¿Cuál es la forma formal de «가요» (voy)?
+ 갑니다 :: Raíz en vocal + ㅂ니다.
- 가습니다 :: 습니다 va tras consonante.
- 가요니다 :: Se usa la raíz, no el presente.
Q ¿Cuál es la forma formal de «먹어요» (como)?
+ 먹습니다 :: Raíz en consonante + 습니다.
- 먹니다 :: Falta 습.
- 먹어습니다 :: Se usa la raíz: 먹.
Q ¿Cuál es la forma formal de «이에요» (es)?
+ 입니다 :: 학생입니다.
- 이습니다 :: No existe.
- 있습니다 :: Eso es «hay».
Q ¿Dónde oirás sobre todo el estilo formal?
+ En las noticias, en el trabajo y en los avisos. :: Y en los textos de examen.
- Entre amigos íntimos. :: Ahí se usa un estilo más cercano.
- Solo con los niños. :: No.
Q ¿Cómo preguntas «¿es usted estudiante?» en estilo formal?
+ 학생입니까? :: La pregunta acaba en 니까.
- 학생입니다? :: En formal la pregunta cambia de terminación.
- 학생이에요까? :: No existe.
R 처음 뵙겠습니다.
+ Mucho gusto. :: Se dice al conocer a alguien.
- Hasta luego. :: No es una despedida.
- Lo siento. :: Eso es 죄송합니다.
H 저는 스페인 사람___.
+ 입니다 :: Soy.
- 합니다 :: Eso es «hago».
- 있습니다 :: Eso es «hay».
A 저는 은행에서 일합니다.
+ Trabajo en un banco. :: 일합니다 = trabajo.
- Vivo cerca de un banco. :: Sería 삽니다.
- Voy al banco. :: Sería 갑니다.
A 죄송합니다.
+ Lo siento. :: Disculpa formal.
- Gracias. :: Eso es 감사합니다.
- Entendido. :: Eso es 알겠습니다.
O 저는 한국 음식을 좋아합니다 :: Me gusta la comida coreana :: Tema + objeto + me gusta.

@ 10 | 시험 | Examen final de A1
I Este es el examen final del nivel inicial. Hay preguntas de todos los capítulos. Si fallas alguna, mira de qué capítulo es y repásalo.
E Examen final :: Veintisiete preguntas sobre los diez capítulos. Si aciertas veintidós o más, tienes una base bien asentada. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 1. ¿Cómo se lee «한국어»?
+ han-gu-gŏ :: La consonante final salta a la sílaba siguiente.
- han-guk-ŏ :: Falta el enlace.
- han-gung-ŏ :: No.
Q Cap. 1. ¿Cómo suena ㅇ al final de una sílaba?
+ ng :: Como en «tango».
- Es muda. :: Solo al principio.
- n :: Eso es ㄴ.
H Cap. 2. 저___ 학생이에요. :: Partícula de tema
+ 는 :: Tras vocal: 는.
- 은 :: Va tras consonante.
- 을 :: Esa marca el objeto.
Q Cap. 2. ¿Cómo dices «no soy médico»?
+ 의사가 아니에요. :: 이/가 아니에요.
- 의사가 없어요. :: Eso es «no hay médico».
- 의사 아니요. :: 아니요 solo sirve para responder.
H Cap. 2. 이 가방은 ___ 거예요? :: ¿De quién?
+ 누구 :: 누구 거 = de quién.
- 뭐 :: Eso es «qué».
- 어디 :: Eso es «dónde».
Q Cap. 3. ¿Cómo dices «veinte años» de edad?
+ 스무 살 :: Edad: números coreanos + 살.
- 이십 살 :: La edad va con números coreanos.
- 스물 개 :: 개 es para cosas.
H Cap. 3. 사과 세 ___ :: Contador de cosas
+ 개 :: Tres manzanas.
- 명 :: Es para personas.
- 살 :: Es para la edad.
Q Cap. 3. ¿Cómo dices «tengo un hermano menor»?
+ 동생이 있어요. :: 이/가 있어요.
- 동생이에요. :: Eso es «soy el hermano menor».
- 동생이 아니에요. :: Eso es «no es mi hermano menor».
H Cap. 4. 화장실은 일 층___ 있어요. :: Lugar
+ 에 :: Lugar + 에 있어요.
- 을 :: Esa marca el objeto.
- 는 :: Esa marca el tema.
Q Cap. 4. ¿Cómo se dice «encima del escritorio»?
+ 책상 위에 :: La posición va detrás.
- 책상 아래에 :: Eso es «debajo».
- 위 책상에 :: El orden es al revés.
Q Cap. 5. ¿Cuál es el presente de «먹다» (comer)?
+ 먹어요 :: Vocal ㅓ: -어요.
- 먹아요 :: -아요 va con ㅏ y ㅗ.
- 먹해요 :: No es un verbo con 하다.
H Cap. 5. 도서관___ 공부해요. :: Dónde se hace algo
+ 에서 :: Acción: 에서.
- 에 :: Es para estar o ir.
- 를 :: Esa marca el objeto.
Q Cap. 5. ¿Cómo se dice «las dos y media»?
+ 두 시 반 :: Hora coreana + 반.
- 이 시 반 :: La hora va con números coreanos.
- 두 분 반 :: 분 son minutos.
H Cap. 6. 비빔밥을 먹고 ___. :: Querer
+ 싶어요 :: -고 싶어요.
- 주세요 :: Eso es «deme».
- 있어요 :: Eso es «hay».
Q Cap. 6. ¿Cómo pides dos cervezas?
+ 맥주 두 병 주세요. :: Cosa + número + contador.
- 맥주 이 병 주세요. :: Se cuenta con números coreanos.
- 두 맥주 병 주세요. :: La cosa va primero.
Q Cap. 7. ¿Cuánto es «만 원»?
+ 10 000 won :: 만 = diez mil.
- 1 000 won :: Eso es 천 원.
- 100 won :: Eso es 백 원.
H Cap. 7. 이 가방이 그 가방___ 비싸요. :: Comparar
+ 보다 :: Más caro que.
- 만 :: Eso es «solo».
- 도 :: Eso es «también».
Q Cap. 8. ¿Cómo dices «vaya a la derecha»?
+ 오른쪽으로 가세요. :: 오른쪽 = derecha.
- 왼쪽으로 가세요. :: Eso es «a la izquierda».
- 똑바로 가세요. :: Eso es «siga recto».
H Cap. 8. 지하철___ 회사에 가요. :: Medio de transporte
+ 로 :: En metro.
- 를 :: Esa marca el objeto.
- 보다 :: Eso es «que».
Q Cap. 8. ¿Cómo dices «no puedo ir»?
+ 못 가요. :: 못 = no poder.
- 안 가요. :: Eso es «no voy».
- 가고 싶어요. :: Eso es «quiero ir».
Q Cap. 9. ¿Cómo propones «¿vemos una película juntos?»?
+ 같이 영화를 볼까요? :: -ㄹ까요? para proponer.
- 같이 영화를 봤어요? :: Eso es pasado.
- 같이 영화를 볼 수 있어요. :: Eso es «podemos ver».
H Cap. 9. 내일 친구를 만날 ___. :: Futuro
+ 거예요 :: -ㄹ 거예요.
- 싶어요 :: Va con -고.
- 주세요 :: Eso es «deme».
Q Cap. 9. ¿Cómo dices «en invierno hace frío»?
+ 겨울에는 추워요. :: 겨울 = invierno.
- 여름에는 추워요. :: 여름 es verano.
- 겨울에는 더워요. :: 더워요 es «hace calor».
Q Cap. 10. ¿Cuál es el pasado de «가요»?
+ 갔어요 :: Fui.
- 갈 거예요 :: Eso es futuro.
- 가세요 :: Eso es «vaya».
H Cap. 10. 머리가 ___ 학교에 못 갔어요. :: Porque me dolía
+ 아파서 :: -아서 da el motivo.
- 아파요 :: Hace falta la forma en 서.
- 아팠어요 :: Eso cerraría la frase.
A 어제 친구하고 영화를 보고 저녁을 먹었어요.
+ Ayer vi una película con un amigo y cené. :: 보고 = ver y…
- Mañana voy a ver una película con un amigo. :: Es pasado.
- Ayer cené solo y vi una película. :: Dice 친구하고.
O 저는 내일 서울에 갈 거예요 :: Mañana voy a ir a Seúl :: Tema + cuándo + adónde + voy a ir.
