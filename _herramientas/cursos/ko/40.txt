T Una noticia sobre un festival de la ciudad
- 어제 서울에서 큰 음악 축제가 열렸어요. = Ayer se celebró un gran festival de música en Seúl.
  > 어제 = ayer | 서울에서 = en Seúl | 열렸어요 = se celebró
- 날씨가 흐렸는데도 많은 사람이 찾아왔어요. = Aunque el tiempo estaba nublado, vino mucha gente.
  > 흐렸는데도 = aunque estaba nublado | 많은 사람이 = mucha gente | 찾아왔어요 = vino
- 주최 측은 내년에도 같은 축제를 열 것 같다고 말했어요. = La organización dijo que parece que el año que viene también celebrará el mismo festival.
  > 같다고 말했어요 = dijo que parece | 열 것 같다고 = que parece que va a celebrar
- 여러 사람들을 비롯해서 학생들도 많이 참여했어요. = Incluidos muchos ciudadanos, también participaron muchos estudiantes.
  > 학생들도 = también los estudiantes | 많이 참여했어요 = participaron mucho
- 축제를 준비하기 위해서 몇 달 동안 노력했대요. = Dicen que, para preparar el festival, se esforzaron durante varios meses.
  > 준비하기 위해서 = para preparar | 노력했대요 = dicen que se esforzaron
Q ¿Qué significa «날씨가 흐렸는데도 많은 사람이 찾아왔어요»?
+ Aunque el tiempo estaba nublado, vino mucha gente. :: 흐렸는데도 = aunque estaba nublado.
- Como el tiempo estaba nublado, no vino nadie. :: Eso no lo dice la frase.
- Vino mucha gente porque hacía sol. :: Eso cambia el tiempo.
H 축제를 ___ 몇 달 동안 노력했대요. :: para preparar
+ 준비하기 위해서 :: 준비하기 위해서 = para preparar.
- 준비하면 :: Es «si prepara».
- 준비했으면 :: Es «si hubieran preparado».
R 내년에도 같은 축제를 열 것 같아요.
+ Parece que el año que viene también celebrará el mismo festival. :: 열 것 같아요 = parece que va a celebrar.
- Se celebró el año pasado. :: Eso sería 작년에 열렸어요.
- No habrá festival el año que viene. :: Eso sería 내년에는 축제가 없어요.
A 여러 사람들을 비롯해서 학생들도 참여했어요. :: ¿Qué dice la noticia?
+ Incluidos muchos ciudadanos, también participaron estudiantes. :: 을 비롯해서 = incluidos.
- Solo participaron los estudiantes. :: Eso sería 학생들만 참여했어요.
- Nadie quiso participar. :: Eso sería 아무도 참여하지 않았어요.
O 날씨가 흐렸는데도 많이 왔어요 :: Aunque el tiempo estaba nublado, vino mucha gente :: 흐렸는데도 = aunque estaba nublado. 많이 왔어요 = vino mucha gente.
Q ¿Cómo dices «para preparar» (준비하다)?
+ 준비하기 위해서 :: 준비하다 → 준비하기 위해서.
- 준비해요 :: Es «preparo», sin finalidad.
- 준비했어요 :: Es «preparé», pasado.
H 몇 달 동안 ___. :: se esforzaron
+ 노력했대요 :: 노력했대요 = dicen que se esforzaron.
- 노력해요 :: Es «me esfuerzo», sin contar.
- 노력할 거예요 :: Es «se esforzará», futuro.
Q ¿Qué significa «주최 측»?
+ Los organizadores. :: 주최 측 = la parte que organiza.
- Los visitantes. :: Eso sería 방문객.
- Los artistas. :: Eso sería 예술가.

민수: 안나 씨, 어제 왜 연락이 안 됐어요? = Anna, ¿por qué no se te pudo contactar ayer?
  > 왜 = por qué | 연락이 안 됐어요 = no se pudo contactar
안나: 휴대폰이 꺼졌거든요. 그래서 못 봤어요. = Es que se apagó el móvil. Por eso no lo vi.
  > 꺼졌거든요 = es que se apagó | 그래서 = por eso | 못 봤어요 = no lo vi
민수: 그랬군요. 충전하지 않으면 안 돼요! = Ya veo. ¡Hay que cargarlo sí o sí!
  > 충전하지 않으면 안 돼요 = hay que cargarlo sí o sí
안나: 맞아요. 제가 바로 충전할게요. = Es verdad. Lo cargaré enseguida.
  > 바로 = enseguida | 충전할게요 = lo cargaré
민수: 그럼 다음에는 꼭 같이 가요. = Entonces, la próxima vez, vayamos juntos sin falta.
  > 다음에는 = la próxima vez | 꼭 같이 가요 = vayamos juntos sin falta
Q ¿Qué significa «휴대폰이 꺼졌거든요»?
+ Es que se apagó el móvil. :: 꺼졌거든요 = es que se apagó.
- El móvil se apaga siempre. :: Eso sería 휴대폰은 항상 꺼져요.
- Compré un móvil nuevo. :: Eso sería 새 휴대폰을 샀어요.
H 연락이 안 됐어요. 휴대폰이 ___. :: es que se apagó
+ 꺼졌거든요 :: 꺼졌거든요 = es que se apagó.
- 꺼졌어요 :: Es «se apagó», sin razón.
- 꺼지면 :: Es «si se apaga».
R 충전하지 않으면 안 돼요.
+ Hay que cargarlo sí o sí. :: 충전하지 않으면 안 돼요 = hay que cargarlo sí o sí.
- Puedes no cargarlo. :: Eso sería 충전 안 해도 돼요.
- Ya lo cargué. :: Eso sería 충전했어요.
A 제가 바로 충전할게요. :: ¿Qué dice la persona?
+ Lo cargaré enseguida. :: 충전할게요 = lo cargaré.
- Lo cargó ayer. :: Eso sería 어제 충전했어요.
- No lo cargará. :: Eso sería 충전 안 할 거예요.
O 그럼 다음에는 꼭 같이 가요 :: Entonces, la próxima vez, vayamos juntos sin falta :: 다음에는 = la próxima vez. 꼭 = sin falta.
Q ¿Cómo dices «es que no tenía tiempo» (없다)?
+ 없었거든요 :: 없다 → 없었거든요.
- 없었어요 :: Es «no tenía», sin razón.
- 없어요 :: Es «no hay», presente.
