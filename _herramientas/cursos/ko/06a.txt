@ 6 | 책을 읽어요 | El objeto 을/를
E Idea clave :: 을/를 marca el objeto directo. Se usa 을 tras consonante y 를 tras vocal. En conversación puede omitirse si el contexto ya deja claro el objeto. :: 책을 읽어요. = Leo un libro.
w 책 = libro
w 읽다 = leer
w 책을 읽어요 = Leo un libro
V Vocabulario clave
Q ¿Qué función tiene 을 en 책을 읽어요?
+ Marca el objeto que se lee. :: La respuesta coincide con el uso explicado.
- Marca el lugar donde se lee. :: La frase permite identificar la opción correcta.
- No se puede determinar a partir de esta frase. :: La frase permite identificar la opción correcta.
R 책을 읽어요. :: ¿Qué significa la frase?
+ Leo un libro. :: La traducción conserva el sentido de la construcción.
- Yo también leo solo libros. :: Esta traducción cambia el sentido de la frase.
- Compro un libro y un lápiz. La habitación es amplia y luminosa. :: Esta traducción cambia el sentido de la frase.
H 책___ 읽어요. :: Completa con la forma adecuada.
+ 을 :: Es la forma que corresponde al contexto.
- 를 :: Esta forma no encaja con la estructura pedida.
- 는 :: Esta forma no encaja con la estructura pedida.
Q ¿Qué frase expresa «Leo un libro.»?
+ 책을 읽어요. :: La frase coreana expresa la traducción indicada.
- 저도 책만 읽어요. :: Esta frase expresa otra idea.
- 책하고 연필을 사요. 방이 넓고 밝아요. :: Esta frase expresa otra idea.
Q ¿Qué significa «책»?
+ libro :: Esta es la ficha de vocabulario de la palabra.
