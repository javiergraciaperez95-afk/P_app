@ 29 | 왔나 봐요 | Parece que: -나 보다
E Hacer una inferencia :: Cuando deduces algo a partir de indicios o del contexto, se usa **-나 보다** (parece que, debe de…): 가다 → **갔나 봐요** (parece que fue), 비가 오다 → **비가 왔나 봐요** (parece que llovió), 아프다 → **아픈가 봐요** (parece que está enfermo). No hace falta que el indicio sea algo que hayas visto directamente. :: 안나 씨가 아직 안 **왔나 봐요** = parece que Anna todavía no ha llegado.
E Según la forma :: Con verbos se usa **-나 보다**, con adjetivos **-(으)ㄴ가 보다** y con sustantivos **-인가 보다**. :: 피곤**한가 봐요** = parece que está cansado. 학생**인가 봐요** = parece que es estudiante.
B Palabra | Con -나/-(으)ㄴ가 보다 | Español
| 가다 | 갔나 봐요 | parece que fue
| 비가 오다 | 비가 왔나 봐요 | parece que llovió
| 피곤하다 | 피곤한가 봐요 | parece que está cansado
| 학생이다 | 학생인가 봐요 | parece que es estudiante
W 왔나 봐요 = parece que vino, parece que llegó
W 갔나 봐요 = parece que fue
W 피곤한가 봐요 = parece que está cansado
W 학생인가 봐요 = parece que es estudiante
W 아직 안 왔어요 = todavía no ha venido
W 아마 = quizá, probablemente
W 막혔나 봐요 = parece que hay atasco
W 막혔어요 = se atascó, hay atasco
W 그렇군요 = ya veo, ah, así es
W 전화해 볼게요 = voy a llamar a ver
V Vocabulario: suposiciones con lo visto
D Anna no llega
민수: 안나 씨가 아직 안 왔어요. = Anna todavía no ha llegado.
  > 안나 씨가 = Anna | 아직 = todavía | 안 왔어요 = no ha venido
유나: 아마 길이 막혔나 봐요. = Quizá se ha atascado el camino.
  > 아마 = quizá | 길이 막혔나 봐요 = parece que hay atasco
민수: 그렇군요. 전화해 볼게요. = Ya veo. Voy a llamarla.
  > 그렇군요 = ya veo | 전화해 볼게요 = voy a llamar a ver
Q ¿Qué significa «비가 왔나 봐요»?
+ Parece que llovió. :: 왔나 봐요 = parece que llovió.
- Va a llover. :: Eso sería 비가 올 거예요.
- Llueve todos los días. :: Eso sería 매일 비가 와요.
H 안나 씨가 아직 ___. :: parece que no ha llegado
+ 안 왔나 봐요 :: 안 왔나 봐요 = parece que no ha llegado.
- 안 와요 :: Es «no viene», sin suponer.
- 안 올 거예요 :: Es «no vendrá», futuro.
R 피곤한가 봐요.
+ Parece que está cansado. :: 피곤한가 봐요 = parece que está cansado.
- Está cansado de verdad. :: Eso sería 정말 피곤해요.
- Estaba cansado. :: Eso sería 피곤했어요.
A 아마 길이 막혔나 봐요. :: ¿Qué cree la persona?
+ Cree que hay atasco. :: 막혔나 봐요 = parece que hay atasco.
- Cree que el tren llegó. :: Eso no lo dice la frase.
- Cree que llueve. :: Eso no lo dice la frase.
O 학생인가 봐요 :: Parece que es estudiante :: 학생인가 봐요 = parece que es estudiante.
Q ¿Cómo dices «parece que fue» (가다)?
+ 갔나 봐요 :: 가다 → 갔나 봐요.
- 가요 :: Es «voy».
- 가 봐요 :: Es «voy a ver».
H 밖에 비가 ___. :: parece que llovió
+ 왔나 봐요 :: 오다 → 왔나 봐요.
- 와요 :: Es «llueve», presente.
- 올 거예요 :: Es «llovera», futuro.
Q ¿Qué significa «그렇군요»?
+ Ya veo. :: 그렇군요 es la reacción al entender algo.
- Eso es mentira. :: No es lo que significa.
- Está lejos. :: Eso sería 멀어요.
@ 29 | 바쁜 모양이에요 | Parece que, en tono formal: -(으)ㄴ 모양이다
E Inferir a partir de indicios :: **-(으)ㄴ 모양이다** también presenta una inferencia: 바쁘다 → **바쁜 모양이에요**, 가다 → **간 모양이에요** (parece que fue), 오다 → **온 모양이에요** (parece que vino). Con un verbo en presente se usa **-는 모양이다**: 가다 → **가는 모양이에요**. :: 요즘 회사에 일이 많은 **모양이에요** = parece que hay mucho trabajo en la empresa.
E Matiz y registro :: **-나 봐요** y **-(으)ㄴ/는 모양이에요** se solapan como expresiones de inferencia. **-나 봐요** es muy corriente en conversación; **모양이다** puede sonar más descriptivo o propio de textos, pero no es simplemente una versión formal y objetiva en todos los contextos.

| 바쁘다 | 바쁜 모양이에요 | parece ocupado
| 가다 | 간 모양이에요 | parece que fue
| 비가 오다 | 비가 온 모양이에요 | parece que ha llovido
| 학생이다 | 학생인 모양이에요 | parece estudiante
W 바쁜 모양이에요 = parece ocupado
W 간 모양이에요 = parece que fue
W 많은 모양이에요 = parece que hay mucho
W 모양이에요 = parece (formal)
W 비가 온 모양이에요 = parece que ha llovido
W 학생인 모양이에요 = parece estudiante

W 도와줄까요 = ¿te ayudo?, ¿los ayudamos?

D Mucho trabajo

  > 요즘 = últimamente | 회사에서 = en la oficina | 일이 많은 모양이에요 = parece que hay mucho trabajo
안나: 맞아요. 민수 씨도 아침부터 계속 바빴어요. = Es verdad. Minsu también ha estado ocupado desde la mañana.
  > 아침부터 = desde la mañana | 계속 = seguido | 바빴어요 = estaba ocupado
유나: 그럼 우리가 도와줄까요? = ¿Entonces los ayudamos?
  > 우리가 = nosotros | 도와줄까요 = ¿los ayudamos?
Q ¿Qué significa «바쁜 모양이에요»?
+ Parece que está ocupado. :: 바쁜 모양이에요 = parece ocupado.
- Está ocupado de verdad. :: Eso sería 정말 바빠요.
- Estaba ocupado. :: Eso sería 바빴어요.
H 요즘 일이 많은 ___. :: parece (formal)
+ 모양이에요 :: 모양이에요 = parece.
- 것 같아요 :: Es «creo que», más hablado.
- 나 봐요 :: Es «parece», informal.
R 간 모양이에요.
+ Parece que fue. :: 간 모양이에요 = parece que fue.
- Va a ir. :: Eso sería 갈 거예요.
- Fue ayer. :: Eso sería 어제 갔어요.
A 비가 온 모양이에요. :: ¿Qué dice la persona?
+ Parece que ha llovido. :: 온 모양이에요 = parece que ha llovido.
- Va a llover. :: Eso sería 비가 올 거예요.
- Llueve ahora. :: Eso sería 지금 비가 와요.
O 계속 바빴어요 :: Ha estado ocupado sin parar :: 계속 = seguido. 바빴어요 = estaba ocupado.
Q ¿Cómo dices «parece ocupado» (바쁘다)?
+ 바쁜 모양이에요 :: 바쁘다 → 바쁜 모양이에요.
- 바빠요 :: Es «estoy ocupado», sin suponer.
- 바빴어요 :: Es «estuvo ocupado», pasado.

- 계속 바빠요 :: Es presente, sin suponer.

@ 29 | 알잖아요 | Ya sabes: -잖아요
E Información compartida :: **-잖아요** presenta una información como compartida o que se puede reconocer: 가다 → **가잖아요**, 먹다 → **먹잖아요**, 좋다 → **좋잖아요**. Puede recordar un acuerdo, justificar una opinión o corregir algo, según el contexto. :: 오늘 같이 점심 **먹잖아요** = hoy comemos juntos, ya sabes.
E Tono :: Puede sonar cercano, insistente o ligeramente quejoso si se usa para recordar algo. No siempre es una queja: el tono y la relación entre hablantes importan. :: 어제 **말했잖아요** = ya te lo dije ayer.
B Palabra | Con -잖아요 | Español
| 가다 | 가잖아요 | ya sabes que vamos
| 먹다 | 먹잖아요 | ya sabes que comemos
| 좋다 | 좋잖아요 | es bueno, ya lo sabes
| 있다 | 있잖아요 | ¿sabes?, oye
W 가잖아요 = ya sabes que vamos
W 먹잖아요 = ya sabes que comemos
W 좋잖아요 = es bueno, ya lo sabes
W 있잖아요 = oye, sabes
W 말했잖아요 = ya te lo dije
W 어디로 = a dónde
W 음식이 좋잖아요 = la comida es buena, ya lo sabes
V Vocabulario: ya sabes
D El restaurante de hoy
안나: 민수 씨, 오늘 같이 점심 먹잖아요. 어디로 갈까요? = Minsu, ya sabes que hoy comemos juntos. ¿A dónde vamos?
  > 같이 점심 먹잖아요 = ya sabes que comemos juntos | 어디로 = a dónde | 갈까요 = ¿vamos?
민수: 아, 맞아요. 어제 말했잖아요. = Ah, es verdad. Ya te lo dije ayer.
  > 어제 = ayer | 말했잖아요 = ya te lo dije
민수: 그럼 저 식당은 어때요? 음식이 좋잖아요. = ¿Y ese restaurante? La comida es buena, ya lo sabes.
  > 저 식당은 = ese restaurante | 음식이 좋잖아요 = la comida es buena
안나: 좋아요! 거기 가요. = ¡Genial! Vamos allí.
  > 거기 = allí | 가요 = vamos
Q ¿Qué significa «어제 말했잖아요»?
+ Ya te lo dije ayer. :: 말했잖아요 = ya te lo dije.
- Te lo digo ahora. :: Eso sería 지금 말해요.
- No te dije nada ayer. :: Eso sería 어제 아무 말도 안 했어요.
H 오늘 같이 점심 ___. :: ya sabes que comemos (먹잖아요)
+ 먹잖아요 :: 먹다 → 먹잖아요: ya sabes que comemos.
- 먹어요 :: Es «comemos», sin recordar.
- 먹었어요 :: Es «comimos», pasado.
R 음식이 좋잖아요.
+ La comida es buena, ya lo sabes. :: 좋잖아요 = es bueno, ya lo sabes.
- La comida es cara. :: Eso sería 음식이 비싸요.
- La comida era buena. :: Eso sería 좋았어요.
A 어디로 갈까요? :: ¿Qué pregunta la persona?
+ ¿A dónde vamos? :: 어디로 = a dónde. 갈까요 = ¿vamos?
- ¿Dónde estuvimos? :: Eso sería 어디에 있었어요?
- ¿Cuándo vamos? :: Eso sería 언제 갈까요?
O 어제 말했잖아요 :: Ya te lo dije ayer :: 어제 = ayer. 말했잖아요 = ya te lo dije.
Q ¿Cómo dices «ya sabes que vamos» (가다)?
+ 가잖아요 :: 가다 → 가잖아요.
- 가요 :: Es «vamos», sin recordar.
- 갔어요 :: Es «fuimos», pasado.
H 저 식당은 음식이 ___. :: es buena, ya lo sabes
+ 좋잖아요 :: 좋다 → 좋잖아요.
- 좋아요 :: Es «es bueno», sin recordar.
- 좋았어요 :: Es «fue bueno», pasado.
Q ¿Qué significa «있잖아요»?
+ Oye, sabes. :: 있잖아요 es una forma de empezar a contar algo.
- Tengo algo. :: Eso sería 있어요.
- Estaba aquí. :: Eso sería 있었어요.

+ 모양 :: -(으)ㄴ/는 모양이다 expresa inferencia.
