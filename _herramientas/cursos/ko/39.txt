@ 39 | 갔더라면 좋았을 거예요 | Si hubiera: -았/었더라면
E Lo que no pasó :: Para decir «si hubiera hecho algo…», sobre algo que ya no se puede cambiar, se usa **-았/었더라면**: 가다 → **갔더라면** (si hubiera ido), 먹다 → **먹었더라면** (si hubiera comido), 알다 → **알았더라면** (si lo hubiera sabido). :: 어제 왔**더라면** 재미있었을 거예요 = si hubieras venido ayer, habría sido divertido.
E Con el resultado :: Después se suele usar **-았/었을 텐데** o **-았/었을 거예요** para decir qué habría pasado: 미리 알았더라면 갔을 텐데 = si lo hubiera sabido antes, habría ido. :: Es un sentimiento de pena o de «qué pena».

| 가다 | 갔더라면 | si hubiera ido
| 먹다 | 먹었더라면 | si hubiera comido
| 알다 | 알았더라면 | si lo hubiera sabido
| 오다 | 왔더라면 | si hubiera venido

W 왔더라면 = si hubiera venido
W 알았더라면 = si lo hubiera sabido
W 재미있었을 거예요 = habría sido divertido

  > 미리 알았더라면 = si lo hubiera sabido antes | 갔을 텐데 = habría ido

  > 다음에는 = la próxima vez | 꼭 = sin falta | 오세요 = venga

@ 39 | 비가 올 듯해요 | Parece que: -(으)ㄹ 듯하다

@ 39 | 안 왔거든요 | Es que…: -거든(요)
E Explicar la razón :: Para justificar algo que has dicho, como «es que…», se usa **-거든(요)** después de una afirmación: 바빴거든요 = es que estaba ocupado. 피곤하거든요 = es que estoy cansado. :: 어제 안 갔어요. 시간이 없었거든요 = no fui ayer, es que no tenía tiempo.
E En la conversación :: Es muy común en el habla para dar una razón de forma suave. :: 모르거든요 = es que no lo sé.

@ 39 | 그랬어요 | Repaso: -거든요 con explicaciones
E Explicar con dos frases :: Puedes usar **-거든요** dentro de una conversación para explicar algo que dijiste antes: 저는 안 먹었어요. 배가 안 고팠거든요 = no comí, es que no tenía hambre. :: Es común en el habla de cada día.
