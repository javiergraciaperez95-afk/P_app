@ 6 | 뭐 먹고 싶어요? | Lo que te gusta y lo que quieres
E Gustar: 좋아해요 :: **좋아해요** es «gustar», y lo que te gusta lleva la partícula de objeto: 저는 김치**를** 좋아해요 = me gusta el kimchi. :: Lo contrario: **안 좋아해요** (no me gusta) o, más fuerte, **싫어해요** (no lo soporto). :: No lo confundas con **좋아요** («es bueno», «vale»), que va con 이/가: 날씨**가** 좋아요.
E Querer hacer algo: -고 싶어요 :: Se coge la raíz del verbo (la forma del diccionario sin 다) y se añade **-고 싶어요**. :: 먹다 → **먹고 싶어요** (quiero comer). 가다 → **가고 싶어요** (quiero ir). 마시다 → **마시고 싶어요** (quiero beber). :: Para preguntar: **뭐 먹고 싶어요?** = ¿qué quieres comer?
B Querer + verbo | Diccionario | Quiero…
| 먹다 (comer) | 먹고 싶어요
| 가다 (ir) | 가고 싶어요
| 마시다 (beber) | 마시고 싶어요
| 보다 (ver) | 보고 싶어요
| 사다 (comprar) | 사고 싶어요
E En la mesa :: **배고파요** = tengo hambre. :: **맛있어요** = está rico (literalmente, «tiene sabor»). **맛없어요** = no está rico. :: Algunos platos que oirás siempre: **비빔밥** (arroz con verduras), **불고기** (ternera marinada), **김밥** (rollo de arroz y alga), **라면** (fideos instantáneos) y **떡볶이** (pastelitos de arroz picantes).
W 좋아해요 = gustar: me gusta, te gusta
W 싫어해요 = no gustar nada, no soportar
W 싶어요 = querer (detrás de un verbo en -고)
W 먹고 싶어요 = quiero comer
W 가고 싶어요 = quiero ir
W 마시고 싶어요 = quiero beber
W 보고 싶어요 = quiero ver
W 배고파요 = tengo hambre
W 맛있어요 = está rico
W 맛없어요 = no está rico
W 음식 = comida
W 비빔밥 = bibimbap (arroz con verduras)
W 불고기 = bulgogi (ternera marinada)
W 김밥 = kimbap (rollo de arroz y alga)
W 라면 = ramen, fideos instantáneos
W 떡볶이 = tteokbokki (pastelitos de arroz picantes)
W 생선 = pescado
W 과일 = fruta
W 야채 = verdura
V Vocabulario: comida y gustos
D ¿Tienes hambre?
준호: 마리아 씨, 배고파요? = María, ¿tiene hambre?
  > 배고파요 = tener hambre
마리아: 네, 배고파요. = Sí, tengo hambre.
  > 네 = sí
준호: 뭐 먹고 싶어요? = ¿Qué quiere comer?
  > 뭐 = qué | 먹고 싶어요 = quiere comer
마리아: 한국 음식을 먹고 싶어요. = Quiero comer comida coreana.
  > 한국 음식을 = comida coreana (objeto)
준호: 무슨 음식을 좋아해요? = ¿Qué comida le gusta?
  > 무슨 음식 = qué comida | 좋아해요 = le gusta
마리아: 저는 비빔밥을 좋아해요. 준호 씨도 비빔밥을 좋아해요? = A mí me gusta el bibimbap. ¿A usted también le gusta?
  > 비빔밥을 좋아해요 = me gusta el bibimbap
준호: 네, 저도 비빔밥을 정말 좋아해요. 그럼 같이 한국 식당에 가요. = Sí, a mí también me gusta muchísimo. Entonces vamos juntos a un restaurante coreano.
  > 저도 = yo también | 같이 한국 식당에 가요 = vamos juntos a un restaurante coreano (el presente también sirve para proponer)
마리아: 좋아요! = ¡Vale!
  > 좋아요 = bien, vale
T Mis gustos
- 저는 과일을 좋아해요. 매일 사과를 먹어요. = Me gusta la fruta. Como manzanas todos los días.
  > 과일을 좋아해요 = me gusta la fruta
- 생선은 안 좋아해요. = El pescado no me gusta.
  > 생선은 = el pescado (tema) | 안 좋아해요 = no me gusta
- 김치는 정말 맛있어요. = El kimchi está riquísimo.
  > 정말 맛있어요 = está realmente rico
- 오늘은 라면을 먹고 싶어요. = Hoy quiero comer ramen.
  > 라면을 먹고 싶어요 = quiero comer ramen
Q ¿Cómo dices «me gusta el kimchi»?
+ 저는 김치를 좋아해요. :: Lo que gusta lleva 을/를.
- 저는 김치에 좋아해요. :: 에 marca el lugar.
- 저는 김치 좋아해요예요. :: No se añade «es».
Q ¿Cómo dices «quiero ir»?
+ 가고 싶어요. :: Raíz + 고 싶어요.
- 가요 싶어요. :: Se usa la raíz, no el presente.
- 가다 싶어요. :: Hay que quitar 다 y poner 고.
Q ¿Qué significa «맛없어요»?
+ No está rico. :: «No tiene sabor».
- Está rico. :: Eso es 맛있어요.
- No tengo hambre. :: Hambre es 배고파요.
R 뭐 먹고 싶어요?
+ ¿Qué quieres comer? :: 먹고 싶어요 = querer comer.
- ¿Qué te gusta? :: Sería 뭐 좋아해요?
- ¿Qué estás comiendo? :: Sería 뭐 먹어요?
H 저는 커피를 마시고 ___. (quiero)
+ 싶어요 :: -고 싶어요 = querer.
- 좋아해요 :: Eso es «gustar».
- 있어요 :: Eso es «hay».
H 저는 생선을 안 ___. (no me gusta)
+ 좋아해요 :: 안 좋아해요 = no me gusta.
- 맛있어요 :: Eso es «está rico».
- 배고파요 :: Eso es «tengo hambre».
A 이 불고기는 정말 맛있어요.
+ Este bulgogi está realmente rico. :: 맛있어요 = está rico.
- Este bulgogi no está rico. :: Sería 맛없어요.
- Este bibimbap está realmente rico. :: Dice 불고기.
A 저는 야채를 싫어해요.
+ No soporto la verdura. :: 싫어해요 = no gustar nada.
- Me gusta la verdura. :: Sería 좋아해요.
- No soporto la fruta. :: Fruta es 과일.
O 저는 한국 음식을 좋아해요 :: Me gusta la comida coreana :: Tema + qué (objeto) + gustar.

@ 6 | 식당에서 | En el restaurante
E Pedir: 주세요 :: **주세요** significa «deme». Se pone detrás de lo que pides, sin partícula: **물 주세요** (agua, por favor). :: Queda más suave con **좀** («un poco») delante: **물 좀 주세요**. :: Para llamar al camarero se dice **여기요!** («¡aquí!»). No es de mala educación: es lo normal.
E Cuántos: los contadores de la mesa :: Recuerda el orden: cosa + número + contador. :: **잔** es para vasos y tazas: 커피 **두 잔** (dos cafés). **병** es para botellas: 맥주 **한 병** (una cerveza). **그릇** es para cuencos: 냉면 **한 그릇**. :: Si no sabes el contador, usa **개** o el número solo: 비빔밥 **하나** 주세요 (un bibimbap, por favor). :: Para unir dos cosas: **하고**. 비빔밥 하나**하고** 김밥 하나 주세요.
B Contadores | Contador | Para | Ejemplo
| 개 | cosas en general | 사과 세 개
| 잔 | vasos, tazas | 커피 두 잔
| 병 | botellas | 맥주 한 병
| 그릇 | cuencos, platos hondos | 냉면 한 그릇
| 명 | personas | 두 명
E Lo que dice el camarero :: **뭐 드릴까요?** = ¿qué le pongo? :: **여기 있어요** = aquí tiene. :: **잠깐만요** = un momento. :: **맛있게 드세요** = que aproveche (literalmente, «coma rico»).
W 주세요 = deme, póngame
W 좀 = un poco; por favor (suaviza)
W 여기요 = ¡oiga! (para llamar al camarero)
W 메뉴 = carta, menú
W 드릴까요 = ¿le pongo?, ¿le traigo?
W 여기 있어요 = aquí tiene
W 잠깐만요 = un momento
W 맛있게 드세요 = que aproveche
W 잔 = (contador de vasos y tazas)
W 병 = (contador de botellas)
W 그릇 = (contador de cuencos)
W 맥주 = cerveza
W 콜라 = cola (refresco)
W 김치찌개 = guiso de kimchi
W 된장찌개 = guiso de pasta de soja
W 냉면 = fideos fríos
V Vocabulario: en el restaurante
D Para pedir
지은: 여기요! 메뉴 좀 주세요. = ¡Oiga! La carta, por favor.
  > 여기요 = ¡oiga! | 메뉴 좀 주세요 = deme la carta, por favor
유나: 네, 여기 있어요. 뭐 드릴까요? = Sí, aquí tiene. ¿Qué le pongo?
  > 여기 있어요 = aquí tiene | 뭐 드릴까요 = qué le pongo
지은: 비빔밥 하나하고 김치찌개 하나 주세요. = Un bibimbap y un guiso de kimchi, por favor.
  > 비빔밥 하나하고 = un bibimbap y… | 김치찌개 하나 = un guiso de kimchi
유나: 네. 맥주도 드릴까요? = Muy bien. ¿Le traigo también cerveza?
  > 맥주도 = cerveza también
지은: 아니요, 콜라 한 병 주세요. = No, una botella de cola, por favor.
  > 콜라 한 병 = una botella de cola
유나: 네, 잠깐만요. = Sí, un momento.
  > 잠깐만요 = un momento
지은: 그리고 물도 좀 주세요. = Y agua también, por favor.
  > 그리고 = y | 물도 = agua también
유나: 네, 여기 있어요. 맛있게 드세요. = Sí, aquí tiene. Que aproveche.
  > 맛있게 드세요 = que aproveche
Q ¿Cómo pides agua con educación?
+ 물 좀 주세요. :: Cosa + 좀 주세요.
- 물 좀 있어요. :: Eso es «hay un poco de agua».
- 물 좀 먹어요. :: No es una petición.
Q ¿Cómo se dice «dos cafés»?
+ 커피 두 잔 :: 잔 es para tazas y vasos.
- 커피 두 병 :: 병 es para botellas.
- 두 커피 잔 :: La cosa va primero.
Q ¿Cómo llamas al camarero?
+ 여기요! :: Es lo normal en Corea.
- 안녕히 계세요! :: Eso es «adiós».
- 맛있게 드세요! :: Eso es «que aproveche».
Q ¿Qué contador se usa para las botellas?
+ 병 :: 맥주 한 병.
- 잔 :: Es para vasos y tazas.
- 명 :: Es para personas.
R 맛있게 드세요.
+ Que aproveche. :: Lo dice quien sirve la comida.
- Está rico. :: Eso es 맛있어요.
- Un momento. :: Eso es 잠깐만요.
H 냉면 한 ___ 주세요.
+ 그릇 :: Es el contador de cuencos.
- 병 :: Es para botellas.
- 명 :: Es para personas.
H 김밥 하나___ 라면 하나 주세요.
+ 하고 :: 하고 = y.
- 에서 :: Esa marca el lugar.
- 을 :: Esa marca el objeto.
A 맥주 세 병 주세요.
+ Deme tres cervezas. :: 세 병 = tres botellas.
- Deme dos cervezas. :: Dos es 두.
- Deme tres vasos de agua. :: 맥주 = cerveza.
O 비빔밥 두 그릇 주세요 :: Póngame dos bibimbap :: Cosa + número + contador + deme.

@ 6 | 맛이 어때요? | Los sabores y «pero»
E Los sabores :: **맛** = sabor. **맛이 어때요?** = ¿qué tal está?, ¿a qué sabe? :: **매워요** (pica), **달아요** (está dulce), **짜요** (está salado). :: La temperatura: **뜨거워요** (quema, está muy caliente) y **차가워요** (está frío). :: Recuerda que funcionan como verbos: 떡볶이가 **매워요** = el tteokbokki pica.
E Demasiado :: **너무** = demasiado. **너무 매워요** = pica demasiado. :: Para negar, 안 delante: **안 매워요** = no pica. :: **괜찮아요** = está bien, no pasa nada. Sirve para tranquilizar y también para decir «no, gracias».
E Un cambio importante: ㅂ :: Algunos adjetivos terminados en **ㅂ** cambian esa consonante a **우** delante de una terminación que empieza por vocal: **맵다 → 매워요**, **춥다 → 추워요**, **덥다 → 더워요**. Es un patrón irregular; por eso no se dice *맵어요*. Aprende estas formas frecuentes como grupo.
E Pero, en la misma frase: -지만 :: Ya conoces 하지만 para empezar una frase nueva. Para decir «pero» **dentro** de la misma frase se añade **-지만** a la raíz. :: 맵다 (ser picante) → **맵지만** 맛있어요 = pica, pero está rico. :: 비싸다 (ser caro) → **비싸지만** 맛있어요 = es caro, pero está rico.
B Sabores | Diccionario | Presente | Español
| 맵다 | 매워요 | pica
| 달다 | 달아요 | está dulce
| 짜다 | 짜요 | está salado
| 뜨겁다 | 뜨거워요 | quema
| 차갑다 | 차가워요 | está frío
W 맛 = sabor
W 매워요 = pica, es picante
W 달아요 = está dulce
W 짜요 = está salado
W 뜨거워요 = quema, está muy caliente
W 차가워요 = está frío
W 너무 = demasiado
W 괜찮아요 = está bien, no pasa nada
W 맵지만 = pica, pero…
W 비싸지만 = es caro, pero…
W 케이크 = tarta
W 와 = ¡guau!
V Vocabulario: sabores
D ¡Cómo pica!
카를로스: 유나 씨, 이게 뭐예요? = Yuna, ¿qué es esto?
  > 이게 뭐예요 = qué es esto
유나: 떡볶이예요. = Es tteokbokki.
  > 떡볶이예요 = es tteokbokki
카를로스: 맛이 어때요? = ¿Qué tal está?
  > 맛이 = el sabor (sujeto) | 어때요 = qué tal es
유나: 조금 맵지만 정말 맛있어요. = Pica un poco, pero está riquísimo.
  > 조금 맵지만 = pica un poco, pero | 정말 맛있어요 = está realmente rico
카를로스: 와, 너무 매워요! 물 좀 주세요. = ¡Guau, pica demasiado! Deme agua, por favor.
  > 너무 매워요 = pica demasiado | 물 좀 주세요 = agua, por favor
유나: 여기 있어요. 괜찮아요? = Aquí tiene. ¿Está bien?
  > 괜찮아요 = ¿está bien?
카를로스: 네, 괜찮아요. 맵지만 맛있어요. = Sí, estoy bien. Pica, pero está rico.
  > 맵지만 맛있어요 = pica, pero está rico
유나: 이 김밥은 안 매워요. = Este kimbap no pica.
  > 이 김밥은 = este kimbap (tema) | 안 매워요 = no pica
T ¿A qué sabe?
- 이 케이크는 아주 달아요. = Esta tarta está muy dulce.
  > 아주 달아요 = está muy dulce
- 김치찌개는 조금 짜요. 하지만 맛있어요. = El guiso de kimchi está un poco salado. Pero está rico.
  > 조금 짜요 = está un poco salado
- 커피가 너무 뜨거워요. = El café quema demasiado.
  > 너무 뜨거워요 = está demasiado caliente
- 냉면은 차가워요. = Los fideos fríos están fríos.
  > 차가워요 = está frío
Q ¿Cómo dices que algo pica?
+ 매워요. :: De 맵다.
- 달아요. :: Eso es «está dulce».
- 짜요. :: Eso es «está salado».
Q ¿Qué significa «너무»?
+ demasiado :: 너무 매워요 = pica demasiado.
- un poco :: Eso es 조금.
- nada :: No.
Q ¿Cómo dices «es caro, pero está rico» en una sola frase?
+ 비싸지만 맛있어요. :: Raíz + 지만.
- 비싸요지만 맛있어요. :: 지만 va en la raíz, sin 요.
- 비싸하고 맛있어요. :: 하고 une nombres, no frases.
R 맵지만 맛있어요.
+ Pica, pero está rico. :: -지만 = pero.
- Pica y no está rico. :: Dice 맛있어요.
- No pica, pero está rico. :: 맵지만 = pica, pero.
H 이 케이크는 너무 ___. (dulce)
+ 달아요 :: Está dulce.
- 매워요 :: Eso es «pica».
- 짜요 :: Eso es «está salado».
H 맛이 ___? (¿qué tal?)
+ 어때요 :: 맛이 어때요? = ¿qué tal está?
- 뭐예요 :: Eso es «¿qué es?».
- 어디예요 :: Eso es «¿dónde está?».
A 커피가 너무 뜨거워요.
+ El café está demasiado caliente. :: 뜨거워요 = quema.
- El café está demasiado frío. :: Sería 차가워요.
- El café está demasiado dulce. :: Sería 달아요.
A 이 김밥은 안 매워요.
+ Este kimbap no pica. :: 안 = no.
- Este kimbap pica mucho. :: Es negativa.
- Este kimbap no está rico. :: Sería 맛없어요.
O 이 음식은 조금 짜요 :: Esta comida está un poco salada :: Este + cosa (tema) + un poco + salada.
