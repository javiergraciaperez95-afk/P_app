@ 16 | 공부하고 있어요 | Estar haciendo algo ahora: -고 있어요
E Acción en curso :: Para decir que algo se está haciendo ahora se usa **-고 있어요** (estoy…, está…). Se añade a la raíz del verbo: 먹다 → **먹고 있어요** (estoy comiendo), 공부하다 → **공부하고 있어요** (estoy estudiando), 자다 → **자고 있어요** (está durmiendo). :: Suele ir con **지금** (ahora): 지금 **자고 있어요** = ahora está durmiendo.
E Diferencia con el presente :: **-아/어요** (como, estudio) habla de costumbres o de cosas en general. **-고 있어요** habla de algo que pasa en este momento. :: 매일 공부해요 = estudio todos los días. 지금 공부하고 있어요 = ahora estoy estudiando.
B Verbo | Raíz | Ahora mismo (-고 있어요) | Español
| 먹다 | 먹 | 먹고 있어요 | estoy comiendo
| 공부하다 | 공부하 | 공부하고 있어요 | estoy estudiando
| 자다 | 자 | 자고 있어요 | está durmiendo
| 기다리다 | 기다리 | 기다리고 있어요 | estoy esperando
W 여보세요 = diga (al teléfono), ¿sí?
W 먹고 있어요 = estoy comiendo
W 공부하고 있어요 = estoy estudiando
W 자고 있어요 = está durmiendo, estoy durmiendo
W 일하고 있어요 = estoy trabajando
W 쉬고 있어요 = estoy descansando
W 걷고 있어요 = estoy caminando
W 기다리고 있어요 = estoy esperando
W 뭐 하고 있어요 = ¿qué estás haciendo?
W 집에서 = en casa
V Vocabulario: lo que pasa ahora
D Al teléfono
안나: 여보세요? 민수 씨, 지금 뭐 하고 있어요? = ¿Diga? Minsu, ¿qué estás haciendo ahora?
  > 여보세요 = diga | 지금 = ahora | 뭐 하고 있어요 = qué estás haciendo
민수: 집에서 쉬고 있어요. 안나 씨는 어디에 있어요? = Estoy descansando en casa. ¿Y tú dónde estás?
  > 집에서 = en casa | 쉬고 있어요 = estoy descansando | 어디에 있어요 = dónde estás
안나: 저는 지금 공원을 걷고 있어요. = Yo ahora estoy paseando por el parque.
  > 지금 = ahora | 공원을 = el parque | 걷고 있어요 = estoy caminando
민수: 좋아요! 지금 갈 거예요. = ¡Genial! Voy ahora.
  > 지금 = ahora | 갈 거예요 = voy a ir
Q ¿Qué significa «지금 공부하고 있어요»?
+ Estoy estudiando ahora. :: 공부하고 있어요 = estoy estudiando, en este momento.
- Estudio todos los días. :: Eso sería 매일 공부해요.
- Estudiaré mañana. :: Eso sería 내일 공부할 거예요.
H 지금 밥을 ___. :: estoy comiendo
+ 먹고 있어요 :: 먹다 → 먹고 있어요.
- 먹어요 :: Es «como», en general.
- 먹었어요 :: Es «comí», pasado.
R 저는 지금 자고 있어요.
+ Ahora estoy durmiendo. :: 자고 있어요 = estoy durmiendo.
- Ahora duermo todos los días. :: Eso sería 매일 자요.
- Ya dormí. :: Eso sería 잤어요.
A 지금 집에서 쉬고 있어요. :: ¿Qué dice la persona?
+ Está descansando en casa. :: 쉬고 있어요 = está descansando.
- Está trabajando en casa. :: Eso sería 집에서 일하고 있어요.
- Está cocinando en casa. :: Eso sería 집에서 요리하고 있어요.
O 민수 씨는 지금 일하고 있어요 :: Minsu está trabajando ahora :: 지금 = ahora. 일하고 있어요 = está trabajando.
Q ¿Qué significa «걷고 있어요»?
+ Estoy caminando. :: 걷다 → 걷고 있어요.
- Estoy corriendo. :: Eso sería 뛰고 있어요.
- Estoy sentado. :: Eso sería 앉아 있어요.
H 저는 지금 친구를 ___. :: estoy esperando
+ 기다리고 있어요 :: 기다리다 → 기다리고 있어요.
- 기다려요 :: Es «espero», en general.
- 만났어요 :: Es «conocí / quedé con», pasado.
Q ¿Cómo dices «estoy estudiando»?
+ 공부하고 있어요 :: 공부하다 → 공부하고 있어요.
- 공부해요 :: Es «estudio», en general.
- 공부했어요 :: Es «estudié», pasado.
@ 16 | 올 때 | Cuando: -(으)ㄹ 때
E Cuando algo pasa :: Para decir «cuando…» se usa **-(으)ㄹ 때** delante de **때** (momento, cuando): 가다 → **갈 때** (cuando voy), 먹다 → **먹을 때** (cuando como), 하다 → **할 때** (cuando hago). :: 피곤**할 때** 음악을 들어요 = cuando estoy cansado, escucho música.
E Para hablar de la infancia :: **어렸을 때** = cuando era pequeño. Es una expresión muy usada para hablar de la niñez. :: 어렸**을 때** 서울에 살았어요 = cuando era pequeño viví en Seúl.
B Verbo o adjetivo | Raíz | Con -(으)ㄹ 때 | Español
| 가다 | 가 | 갈 때 | cuando voy
| 먹다 | 먹 | 먹을 때 | cuando como
| 하다 | 하 | 할 때 | cuando hago
| 바쁘다 | 바ㅃ | 바쁠 때 | cuando estoy ocupado
W 때 = momento, cuando
W 갈 때 = cuando voy, cuando vaya
W 먹을 때 = cuando como, cuando comas
W 할 때 = cuando hago, cuando haga
W 어렸을 때 = cuando era pequeño
W 피곤할 때 = cuando estoy cansado
W 바쁠 때 = cuando estoy ocupado
W 행복해요 = soy feliz, es feliz
W 살았어요 = viví, vivió
W 만날 때 = cuando quedo con alguien, cuando nos vemos
V Vocabulario: cuando
D ¿Cuándo eres feliz?
안나: 민수 씨는 언제 행복해요? = Minsu, ¿cuándo eres feliz?
  > 언제 = cuándo | 행복해요 = eres feliz
민수: 친구들과 같이 밥을 먹을 때 행복해요. = Soy feliz cuando como con mis amigos.
  > 친구들과 = con mis amigos | 밥을 먹을 때 = cuando como | 행복해요 = soy feliz
안나: 저는 피곤할 때 음악을 들어요. = Yo, cuando estoy cansada, escucho música.
  > 피곤할 때 = cuando estoy cansada | 음악을 들어요 = escucho música
민수: 아, 그래요? 저도 그래요. = Ah, ¿sí? Yo también.
  > 저도 = yo también | 그래요 = así es
Q ¿Qué significa «피곤할 때 음악을 들어요»?
+ Cuando estoy cansado, escucho música. :: 피곤할 때 = cuando estoy cansado.
- Escucho música porque estoy cansado. :: Eso sería 피곤해서 음악을 들어요.
- Escuché música ayer. :: Eso sería 어제 음악을 들었어요.
H 친구를 만날 ___ 행복해요. :: cuando
+ 때 :: 만날 때 = cuando nos vemos / cuando quedo con alguien.
- 일 :: Es «trabajo».
- 집 :: Es «casa».
R 할 때 행복해요.
+ Soy feliz cuando lo hago. :: 할 때 = cuando lo hago.
- Lo hago ahora. :: Eso sería 지금 해요.
- Lo hice ayer. :: Eso sería 어제 했어요.
A 저는 바쁠 때 커피를 마셔요. :: ¿Qué dice la persona?
+ Cuando está ocupada, bebe café. :: 바쁠 때 = cuando está ocupada.
- Bebe café todos los días. :: Eso sería 매일 커피를 마셔요.
- Nunca bebe café. :: Eso sería 커피를 안 마셔요.
O 어렸을 때 서울에 살았어요 :: Cuando era pequeño viví en Seúl :: 어렸을 때 = cuando era pequeño. 살았어요 = viví.
Q ¿Cómo se dice «cuando voy»?
+ 갈 때 :: 가다 → 갈 때.
- 가요 :: Es «voy», sin cuando.
- 가서 :: Es «fui y», otra idea.
Q ¿Qué significa «어렸을 때»?
+ Cuando era pequeño. :: 어렸을 때 = cuando era pequeño.
- Cuando soy mayor. :: Eso sería 나이가 많을 때.
- Cuando tengo prisa. :: Eso sería 급할 때.
H 바쁠 ___ 커피를 마셔요. :: cuando
+ 때 :: 바쁠 때 = cuando estoy ocupado.
- 일 :: Es «trabajo».
- 집 :: Es «casa».
@ 16 | 자기 전에 | Antes y después: -기 전에 / -(으)ㄴ 후에
E Antes de :: Para decir «antes de…» se usa **-기 전에**: 자다 → **자기 전에** (antes de dormir), 먹다 → **먹기 전에** (antes de comer). :: 자기 전에 책을 읽어요 = leo un libro antes de dormir.
E Después de :: Para decir «después de…» se usa **-(으)ㄴ 후에** en pasado: 먹다 → **먹은 후에** (después de comer), 일어나다 → **일어난 후에** (después de levantarse). :: 아침에 일어난 **후에** 운동해요 = hago deporte después de levantarme por la mañana.
B Verbo | Antes de (-기 전에) | Después de (-(으)ㄴ 후에) | Español
| 자다 | 자기 전에 | 잔 후에 | dormir / después de dormir
| 먹다 | 먹기 전에 | 먹은 후에 | comer / después de comer
| 일어나다 | 일어나기 전에 | 일어난 후에 | levantarse / después de levantarme
W 자기 전에 = antes de dormir
W 먹기 전에 = antes de comer
W 먹은 후에 = después de comer
W 잔 후에 = después de dormir
W 일어난 후에 = después de levantarme
W 전에 = antes (de)
W 후에 = después (de)
W 씻어요 = me lavo (las manos, la cara)
W 손 = mano (A1 yes; no repetir)
V Vocabulario: antes y después
D Las rutinas de la noche y de la mañana
안나: 민수 씨는 보통 언제 운동해요? = Minsu, ¿cuándo sueles hacer deporte?
  > 보통 = normalmente | 언제 = cuándo | 운동해요 = haces deporte
민수: 아침에 일어난 후에 운동해요. = Hago deporte después de levantarme por la mañana.
  > 아침에 = por la mañana | 일어난 후에 = después de levantarme | 운동해요 = hago deporte
안나: 저는 자기 전에 책을 읽어요. = Yo leo un libro antes de dormir.
  > 자기 전에 = antes de dormir | 책을 읽어요 = leo un libro
민수: 와, 좋아요. 밥 먹기 전에 손을 씻어요? = Qué bien. ¿Te lavas las manos antes de comer?
  > 밥 먹기 전에 = antes de comer | 손을 씻어요 = te lavas las manos
안나: 네, 저도 먹기 전에 씻어요. = Sí, yo también me lavo antes de comer.
  > 먹기 전에 = antes de comer | 씻어요 = me lavo
Q ¿Qué significa «자기 전에 책을 읽어요»?
+ Leo un libro antes de dormir. :: 자기 전에 = antes de dormir.
- Leo un libro después de dormir. :: Eso sería 잔 후에 책을 읽어요.
- Duermo y después leo un libro. :: Eso cambia el orden de las ideas.
H 밥 ___ 손을 씻어요. :: antes de comer
+ 먹기 전에 :: 먹다 → 먹기 전에.
- 먹은 후에 :: Es «después de comer».
- 먹고 있어요 :: Es «estoy comiendo», ahora.
R 일어난 후에 운동해요.
+ Hago deporte después de levantarme. :: 일어난 후에 = después de levantarme.
- Hago deporte antes de levantarme. :: Eso sería 일어나기 전에 운동해요.
- Hago deporte todos los días. :: Eso sería 매일 운동해요.
A 잔 후에 일어났어요. :: ¿Qué pasó?
+ Se levantó después de dormir. :: 잔 후에 = después de dormir.
- Se levantó antes de dormir. :: Eso sería 자기 전에 일어났어요.
- Va a dormir después. :: Eso sería 잘 거예요.
O 아침에 일어난 후에 운동해요 :: Hago deporte después de levantarme por la mañana :: 일어난 후에 = después de levantarme. 운동해요 = hago deporte.
Q ¿Cómo dices «antes de dormir»?
+ 자기 전에 :: 자다 → 자기 전에.
- 잔 후에 :: Es «después de dormir».
- 자고 있어요 :: Es «está durmiendo».
H 밥을 먹은 ___ 커피를 마셔요. :: después
+ 후에 :: 먹은 후에 = después de comer.
- 전에 :: Es «antes».
- 때 :: Es «cuando».
