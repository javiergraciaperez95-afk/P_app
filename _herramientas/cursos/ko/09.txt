@ 9 | 같이 영화를 볼까요? | Aficiones y quedar con alguien
E Las aficiones :: **취미가 뭐예요?** = ¿cuál es tu afición? Se contesta con un nombre: **제 취미는 등산이에요** (mi afición es el senderismo). :: También puedes decir lo que te gusta: 저는 영화를 좋아해요.
E Cada cuánto :: De más a menos: **매일** (todos los días), **자주** (a menudo), **가끔** (a veces). Van delante del verbo o del objeto: 주말에 **자주** 영화를 봐요. :: **많이** = mucho: 사진을 **많이** 찍어요 (hago muchas fotos).
E Proponer un plan: -(으)ㄹ까요? :: Para proponer algo («¿vamos?», «¿qué tal si…?»), se añade **-ㄹ까요?** tras vocal o **ㄹ**, y **-을까요?** tras otra consonante. Suele ir con **같이** (juntos). :: 가다 → **갈까요?**, 살다 → **살까요?**, 먹다 → **먹을까요?**. :: Para aceptar: **좋아요!** Para decir que no puedes: **미안해요** (lo siento) y el motivo, por ejemplo **바빠요** (estoy ocupado).
B Proponer | Diccionario | ¿Y si…? | Español
| 가다 | 갈까요? | ¿vamos?
| 보다 | 볼까요? | ¿vemos?
| 하다 | 할까요? | ¿lo hacemos?
| 만나다 | 만날까요? | ¿quedamos?
| 먹다 | 먹을까요? | ¿comemos?
W 취미 = afición
W 등산 = senderismo, subir a la montaña
W 축구 = fútbol
W 게임 = videojuegos, juego
W 여행 = viaje
W 찍어요 = hacer (fotos)
W 자주 = a menudo
W 가끔 = a veces
W 많이 = mucho
W 갈까요 = ¿vamos?
W 볼까요 = ¿vemos?
W 할까요 = ¿lo hacemos?
W 만날까요 = ¿quedamos?
W 먹을까요 = ¿comemos?
W 미안해요 = lo siento
W 바빠요 = estoy ocupado
W 영화관 = cine
W 이번 = este (el que viene ahora)
W 다음 = el siguiente, el próximo
W 주 = semana
V Vocabulario: aficiones y planes
D ¿Vemos una película?
민수: 마리아 씨, 취미가 뭐예요? = María, ¿cuál es su afición?
  > 취미가 뭐예요 = cuál es la afición
마리아: 저는 영화를 좋아해요. 주말에 자주 영화를 봐요. = Me gusta el cine. Los fines de semana veo películas a menudo.
  > 영화를 좋아해요 = me gustan las películas | 자주 = a menudo
민수: 저도 영화를 좋아해요. 이번 토요일에 같이 영화를 볼까요? = A mí también me gusta. ¿Vemos una película juntos este sábado?
  > 이번 토요일에 = este sábado | 같이 = juntos | 볼까요 = ¿vemos?
마리아: 미안해요. 토요일은 바빠요. 일요일은 어때요? = Lo siento. El sábado estoy ocupada. ¿Qué tal el domingo?
  > 미안해요 = lo siento | 바빠요 = estoy ocupada | 일요일은 어때요 = qué tal el domingo
민수: 좋아요! 몇 시에 만날까요? = ¡Vale! ¿A qué hora quedamos?
  > 몇 시에 = a qué hora | 만날까요 = ¿quedamos?
마리아: 두 시에 영화관 앞에서 만나요. = Quedamos a las dos delante del cine.
  > 영화관 앞에서 = delante del cine | 만나요 = quedamos
민수: 네, 좋아요. 그리고 저녁도 같이 먹을까요? = Sí, vale. ¿Y cenamos juntos también?
  > 저녁도 = la cena también | 먹을까요 = ¿comemos?
마리아: 네, 좋아요! = ¡Sí, vale!
  > 좋아요 = vale, bien
T Mis aficiones
- 제 취미는 등산이에요. 주말에 자주 산에 가요. = Mi afición es el senderismo. Los fines de semana voy a menudo a la montaña.
  > 제 취미는 = mi afición (tema) | 산에 가요 = voy a la montaña
- 가끔 친구하고 축구를 해요. = A veces juego al fútbol con un amigo.
  > 가끔 = a veces | 축구를 해요 = hago fútbol: juego al fútbol
- 게임은 가끔 해요. = A los videojuegos juego a veces.
  > 게임은 = los videojuegos (tema)
- 여행도 좋아해요. 사진을 많이 찍어요. = También me gusta viajar. Hago muchas fotos.
  > 여행도 = los viajes también | 사진을 많이 찍어요 = hago muchas fotos
Q ¿Cómo preguntas a alguien por su afición?
+ 취미가 뭐예요? :: 취미 = afición.
- 직업이 뭐예요? :: Eso es la profesión.
- 이름이 뭐예요? :: Eso es el nombre.
Q ¿Cómo propones «¿vemos una película?»?
+ 영화를 볼까요? :: Raíz + ㄹ까요?
- 영화를 보고 싶어요. :: Eso es «quiero ver una película».
- 영화를 볼 수 있어요. :: Eso es «puedo ver una película».
Q ¿Qué significa «가끔»?
+ a veces :: Menos que 자주.
- a menudo :: Eso es 자주.
- todos los días :: Eso es 매일.
R 몇 시에 만날까요?
+ ¿A qué hora quedamos? :: 만날까요 = ¿quedamos?
- ¿Dónde quedamos? :: Sería 어디에서.
- ¿A qué hora empieza? :: Sería 시작해요.
H 이번 주말에 같이 등산을 ___?
+ 할까요 :: 할까요? = ¿lo hacemos?
- 하고 :: Eso es «y, con».
- 못해요 :: Eso es «no sé».
H 미안해요. 내일은 ___. (estoy ocupado)
+ 바빠요 :: Estoy ocupado.
- 좋아요 :: Eso es «vale».
- 싸요 :: Eso es «barato».
A 저는 자주 사진을 찍어요.
+ Hago fotos a menudo. :: 자주 = a menudo.
- Hago fotos a veces. :: Sería 가끔.
- Veo fotos a menudo. :: Sería 봐요.
A 영화관 앞에서 만나요.
+ Quedamos delante del cine. :: 앞에서 = delante de.
- Quedamos dentro del cine. :: Sería 안에서.
- Vamos al cine. :: Sería 영화관에 가요.
O 이번 토요일에 같이 영화를 볼까요 :: ¿Vemos una película juntos este sábado? :: Cuándo + juntos + objeto + ¿vemos?

@ 9 | 날씨가 어때요? | El tiempo y las estaciones
E Qué tiempo hace :: **날씨** = el tiempo. **날씨가 어때요?** = ¿qué tiempo hace? :: **더워요** (hace calor), **추워요** (hace frío), **따뜻해요** (hace bueno, templado), **시원해요** (hace fresco). :: **맑아요** (está despejado), **흐려요** (está nublado). :: Para la lluvia y la nieve se usa «venir»: **비가 와요** (llueve; «viene la lluvia») y **눈이 와요** (nieva). El viento «sopla»: **바람이 불어요**.
E Las estaciones :: **봄** (primavera), **여름** (verano), **가을** (otoño), **겨울** (invierno). Estación es **계절**. :: Llevan **에** como cualquier momento: 여름**에** 더워요 (en verano hace calor). Para contrastar se añade 는: 여름**에는** 더워요, 겨울**에는** 추워요. :: **요즘** = últimamente, estos días.
B El tiempo | Coreano | Español
| 더워요 | hace calor
| 추워요 | hace frío
| 따뜻해요 | hace bueno, templado
| 시원해요 | hace fresco
| 맑아요 | está despejado
| 흐려요 | está nublado
| 비가 와요 | llueve
| 눈이 와요 | nieva
W 날씨 = el tiempo (clima)
W 더워요 = hace calor
W 추워요 = hace frío
W 따뜻해요 = hace bueno, está templado
W 시원해요 = hace fresco
W 맑아요 = está despejado
W 흐려요 = está nublado
W 비 = lluvia
W 비가 와요 = llueve
W 눈이 와요 = nieva
W 바람 = viento
W 불어요 = sopla
W 계절 = estación (del año)
W 봄 = primavera
W 여름 = verano
W 가을 = otoño
W 겨울 = invierno
W 요즘 = últimamente, estos días
V Vocabulario: el tiempo
D ¿Qué tiempo hace?
지은: 카를로스 씨, 오늘 날씨가 어때요? = Carlos, ¿qué tiempo hace hoy?
  > 날씨가 어때요 = qué tal el tiempo
카를로스: 비가 와요. 그리고 조금 추워요. = Llueve. Y hace un poco de frío.
  > 비가 와요 = viene la lluvia: llueve | 조금 추워요 = hace un poco de frío
지은: 우산이 있어요? = ¿Tiene paraguas?
  > 우산이 있어요 = hay paraguas
카를로스: 아니요, 없어요. = No, no tengo.
  > 없어요 = no tengo
지은: 여기 제 우산이 있어요. 같이 가요. = Aquí tengo el mío. Vamos juntos.
  > 제 우산이 = mi paraguas (sujeto) | 같이 가요 = vamos juntos
카를로스: 고마워요. 한국은 여름에 날씨가 어때요? = Gracias. ¿Qué tiempo hace en Corea en verano?
  > 한국은 = Corea (tema) | 여름에 = en verano
지은: 아주 더워요. 그리고 비가 많이 와요. 스페인은 어때요? = Hace mucho calor. Y llueve mucho. ¿Y en España?
  > 아주 더워요 = hace mucho calor | 비가 많이 와요 = llueve mucho
카를로스: 스페인도 여름에 아주 더워요. 하지만 비는 안 와요. = En España también hace mucho calor en verano. Pero no llueve.
  > 스페인도 = España también | 비는 안 와요 = llover, no llueve
지은: 카를로스 씨는 어느 계절을 제일 좋아해요? = ¿Qué estación le gusta más?
  > 어느 계절을 = qué estación (objeto) | 제일 좋아해요 = le gusta más
카를로스: 저는 봄을 제일 좋아해요. 날씨가 따뜻해요. 그리고 꽃이 많아요. = La que más me gusta es la primavera. Hace bueno. Y hay muchas flores.
  > 봄을 = la primavera (objeto) | 따뜻해요 = hace bueno | 꽃이 많아요 = hay muchas flores
T Las cuatro estaciones
- 봄에는 날씨가 따뜻해요. = En primavera hace bueno.
  > 봄에는 = en primavera (tema)
- 여름에는 더워요. = En verano hace calor.
  > 더워요 = hace calor
- 가을에는 시원해요. 그리고 날씨가 맑아요. = En otoño hace fresco. Y está despejado.
  > 시원해요 = hace fresco | 맑아요 = está despejado
- 겨울에는 추워요. 눈이 와요. = En invierno hace frío. Nieva.
  > 눈이 와요 = viene la nieve: nieva
- 오늘은 흐려요. 바람도 불어요. = Hoy está nublado. También hace viento.
  > 흐려요 = está nublado | 바람도 불어요 = el viento también sopla
Q ¿Cómo preguntas qué tiempo hace hoy?
+ 오늘 날씨가 어때요? :: 날씨 = el tiempo.
- 오늘 몇 시예요? :: Eso es la hora.
- 오늘 무슨 요일이에요? :: Eso es el día de la semana.
Q ¿Cómo se dice «llueve»?
+ 비가 와요. :: «Viene la lluvia».
- 비가 가요. :: La lluvia «viene», no «va».
- 비를 해요. :: No se dice así.
Q ¿Qué significa «추워요»?
+ Hace frío. :: Lo contrario es 더워요.
- Hace calor. :: Eso es 더워요.
- Hace fresco. :: Eso es 시원해요.
Q ¿Qué estación viene después del verano (여름)?
+ 가을 :: Otoño.
- 겨울 :: Eso es invierno.
- 봄 :: Eso es primavera.
R 겨울에는 눈이 와요.
+ En invierno nieva. :: 눈 = nieve.
- En invierno llueve. :: Lluvia es 비.
- En otoño nieva. :: 겨울 = invierno.
H 여름에는 아주 ___. (hace calor)
+ 더워요 :: Hace calor.
- 추워요 :: Eso es «hace frío».
- 흐려요 :: Eso es «está nublado».
H 저는 봄___ 제일 좋아해요.
+ 을 :: 봄 acaba en consonante: 을.
- 를 :: Va tras vocal.
- 에서 :: Esa marca dónde se hace algo.
A 오늘은 날씨가 맑아요.
+ Hoy está despejado. :: 맑아요 = despejado.
- Hoy está nublado. :: Sería 흐려요.
- Hoy llueve. :: Sería 비가 와요.
A 바람이 많이 불어요.
+ Hace mucho viento. :: 바람 = viento.
- Llueve mucho. :: Sería 비가 많이 와요.
- Hace mucho frío. :: Sería 추워요.
O 한국은 여름에 아주 더워요 :: En Corea hace mucho calor en verano :: Tema + cuándo + muy + hace calor.

@ 9 | 생일이 언제예요? | Las fechas y el futuro
E La fecha :: Las fechas van con los números de origen chino y de lo grande a lo pequeño: año (**년**), mes (**월**), día (**일**). :: Los meses no tienen nombre: son número + 월. 일월 (enero), 이월 (febrero), 삼월 (marzo)… Hay dos que cambian un poco: junio es **유월** (no 육월) y octubre es **시월** (no 십월). :: **오월 십오 일** = el 15 de mayo. :: **오늘은 며칠이에요?** = ¿qué día es hoy? **생일이 언제예요?** = ¿cuándo es tu cumpleaños?
B Los meses | Mes | Coreano | Mes | Coreano
| enero | 일월 | julio | 칠월
| febrero | 이월 | agosto | 팔월
| marzo | 삼월 | septiembre | 구월
| abril | 사월 | octubre | 시월
| mayo | 오월 | noviembre | 십일월
| junio | 유월 | diciembre | 십이월
E El futuro: -(으)ㄹ 거예요 :: Para hablar de planes, se añade **-ㄹ 거예요** tras vocal o **ㄹ**, y **-을 거예요** tras otra consonante. :: 하다 → **할 거예요**, 가다 → **갈 거예요**, 살다 → **살 거예요**, 먹다 → **먹을 거예요**. :: Sirve para todas las personas y también para preguntar: **뭐 할 거예요?** = ¿qué vas a hacer?
E Cumpleaños :: **생일** = cumpleaños. **생일 축하해요!** = ¡feliz cumpleaños! :: Para hablar de varias personas se añade **들**: 친구 → **친구들** (los amigos). Solo se usa cuando hace falta dejarlo claro.

W 월 = mes
W 일 = día; uno; trabajo
W 며칠 = qué día (del mes)
W 언제 = cuándo
W 생일 = cumpleaños
W 생일 축하해요 = feliz cumpleaños
W 파티 = fiesta
W 내년 = el año que viene
W 휴가 = vacaciones
W 할 거예요 = voy a hacer
W 갈 거예요 = voy a ir
W 올 거예요 = voy a venir
W 볼 거예요 = voy a ver
W 먹을 거예요 = voy a comer
W 만날 거예요 = voy a quedar (con alguien)
W 살 거예요 = voy a comprar; voy a vivir
W 친구들 = amigos
w 오월 = mayo
w 유월 = junio
w 칠월 = julio
w 팔월 = agosto
w 시월 = octubre

V Vocabulario: fechas y planes

  > 생일이 = el cumpleaños (sujeto) | 언제예요 = cuándo es
준호: 칠월 이십 일이에요. = Es el 20 de julio.
  > 칠월 = julio | 이십 일 = día veinte

유나: 네, 갈 거예요! 뭐 먹을 거예요? = ¡Sí, voy a ir! ¿Qué van a comer?

준호: 불고기하고 케이크를 먹을 거예요. = Vamos a comer bulgogi y tarta.
  > 불고기하고 케이크를 = bulgogi y tarta (objeto)
유나: 좋아요. 저는 선물을 살 거예요. = Qué bien. Yo voy a comprar un regalo.

  > 팔월에 = en agosto | 휴가가 있어요 = hay vacaciones
- 내년에는 한국에서 살 거예요. = El año que viene voy a vivir en Corea.
  > 내년에는 = el año que viene (tema) | 한국에서 살 거예요 = voy a vivir en Corea

- 생일이 어디예요? :: Eso es «dónde».

+ 유월 :: Es una de las dos excepciones.

- 여섯월 :: Los meses van con números de origen chino.

+ 오월 십오 일 :: Primero el mes, después el día.

+ 일 :: 일 = día.

A 생일 축하해요!

+ La semana que viene voy a quedar con un amigo. :: 다음 주 = la semana que viene.
- Esta semana quedo con un amigo. :: Sería 이번 주.
- La semana que viene voy a ir a casa de un amigo. :: Dice 만날 거예요.
O 저는 내일 선물을 살 거예요 :: Mañana voy a comprar un regalo :: Tema + cuándo + objeto + voy a comprar.
