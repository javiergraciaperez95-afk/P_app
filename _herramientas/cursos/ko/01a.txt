@ 1 | 가, 카, 까 | Consonantes simples, aspiradas y tensas
E Idea clave :: Las series ㄱ/ㅋ/ㄲ se distinguen por la aspiración y la tensión; no son tres versiones de una g española. El ejercicio compara sus letras escritas. :: 카는 ㅋ 소리로 시작해요. = 카 empieza con el sonido ㅋ.
W 카 = sílaba con ㅋ
W 가 = sílaba con ㄱ
W 까 = sílaba con ㄲ
W 소리 = sonido
W 시작하다 = empezar
w 카는 ㅋ 소리로 시작해요 = 카 empieza con el sonido ㅋ
V Vocabulario clave
Q ¿Cuál de 가, 카, 까 contiene la consonante aspirada?
+ 카 :: La respuesta coincide con el uso explicado.
- 가 :: La frase permite identificar la opción correcta.
- No se puede determinar a partir de esta frase. :: La frase permite identificar la opción correcta.
R 카는 ㅋ 소리로 시작해요. :: ¿Qué significa la frase?
+ 카 empieza con el sonido ㅋ. :: La traducción conserva el sentido de la construcción.
- ropa, día y exterior terminan en categorías finales distintas :: Esta traducción cambia el sentido de la frase.
- Leo un libro. :: Esta traducción cambia el sentido de la frase.
H 카는 ___ 소리로 시작해요. :: Completa con la forma adecuada.
+ ㅋ :: Es la forma que corresponde al contexto.
- ㄱ :: Esta forma no encaja con la estructura pedida.
- ㅅ :: Esta forma no encaja con la estructura pedida.
Q ¿Qué frase expresa «카 empieza con el sonido ㅋ.»?
+ 카는 ㅋ 소리로 시작해요. :: La frase coreana expresa la traducción indicada.
- 옷, 낮, 밖 :: Esta frase expresa otra idea.
- 책을 읽어요. :: Esta frase expresa otra idea.

- pepino :: Esa traducción corresponde a otra palabra.
