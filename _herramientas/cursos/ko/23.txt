@ 23 | 시간이 있다면 | Hipótesis: -다면 / -(느)ㄴ다면
E Una hipótesis :: **-(으)면** sirve para condiciones posibles o generales; **-다면** plantea la condición como una suposición o escenario. No implica por sí solo que sea falso o imposible: el contexto decide si se traduce «si…» o «si… fuera». :: 시간이 **있다면** 같이 갈 수 있어요 = si tienes (o tuviera) tiempo, podemos ir juntos.
E Cómo se forma :: Con verbos en presente: 가다 → **간다면**, 먹다 → **먹는다면**. Con adjetivos: 바쁘다 → **바쁘다면**. Con nombres: 학생이다 → **학생이라면**. La forma pasada se construye con **-았/었다면**: 시간이 있었다면… (si hubiera tenido tiempo…).
B Tipo | Forma | Ejemplo
| 가다 | 간다면 | si va / si fuera a ir
| 먹다 | 먹는다면 | si come / si comiera
| 있다 | 있다면 | si tuviera, si hubiera
| 학생이다 | 학생이라면 | si fuera estudiante
W 간다면 = si va, si fuera a ir
W 먹는다면 = si come, si comiera
W 있다면 = si tuviera, si hubiera
W 공부 = estudio
W 부자라면 = si fuera rica, si fuera rico
W 학생이라면 = si fuera estudiante
W 시간이 있다면 = si tuviera tiempo
W 돈이 있다면 = si tuviera dinero
W 해외 = extranjero
W 뭐 하고 싶어요 = qué te gustaría hacer
W 부자 = rico, persona rica
W 세계 = mundo
V Vocabulario: suposiciones
D Si tuviera tiempo y dinero
민수: 시간이 있다면 뭐 하고 싶어요? = Si tuvieras tiempo, ¿qué te gustaría hacer?
  > 시간이 있다면 = si tuvieras tiempo | 뭐 하고 싶어요 = qué te gustaría hacer
안나: 저는 제주도에 가고 싶어요. = Me gustaría ir a Jeju.
  > 제주도에 = a Jeju | 가고 싶어요 = me gustaría ir
민수: 돈이 있다면 해외에도 가고 싶어요. = Si tuviera dinero, también me gustaría ir al extranjero.
  > 돈이 있다면 = si tuviera dinero | 해외에도 = también al extranjero | 가고 싶어요 = me gustaría ir
안나: 그럼 우리 같이 가요! = ¡Entonces, vayamos juntos!
  > 그럼 = entonces | 우리 = nosotros | 같이 가요 = vayamos juntos
Q ¿Qué significa «시간이 있다면»?
+ Si tuviera tiempo. :: 있다면 = si tuviera.
- Tengo tiempo. :: Eso sería 시간이 있어요.
- Tuve tiempo. :: Eso sería 시간이 있었어요.
H 돈이 ___ 여행을 가고 싶어요. :: si tuviera
+ 있다면 :: 있다면 = si tuviera.
- 있어요 :: Es «tengo», sin suponer.
- 있었어요 :: Es «tuve», pasado.
R 학생이라면 공부를 많이 할 거예요.
+ Si fuera estudiante, estudiaría mucho. :: 학생이라면 = si fuera estudiante.
- Soy estudiante y estudio mucho. :: Eso sería 학생이에요.
- Fui estudiante y estudié mucho. :: Eso sería 학생이었어요.
A 제가 부자라면 세계를 여행하고 싶어요. :: ¿Qué dice la persona?
+ Si fuera rica, querría viajar por el mundo. :: 부자라면 = si fuera rica.
- Es rica y viaja mucho. :: Eso sería 부자이고 많이 여행해요.
- Viajó por el mundo. :: Eso sería 세계를 여행했어요.
O 시간이 있다면 같이 가요 :: Si tienes tiempo, vamos juntos :: 있다면 = si tienes. 같이 = juntos.
Q ¿Cómo dices «si fuera» (가다)?
+ 간다면 :: 가다 → 간다면.
- 가면 :: Es «si voy», condición real.
- 갔다면 :: Es «si hubiera ido», otra forma.
H 제가 부자라면 세계를 ___. :: viajaría
+ 여행하고 싶어요 :: Es «me gustaría viajar».
- 여행해요 :: Es «viajo», sin suponer.
- 여행했어요 :: Es «viajé», pasado.
Q ¿Qué significa «학생이라면»?
+ Si fuera estudiante. :: 학생이라면 = si fuera estudiante.
- Es estudiante. :: Eso sería 학생이에요.
- Fue estudiante. :: Eso sería 학생이었어요.
@ 23 | 늦을까 봐 | Por miedo a que pase algo: -(으)ㄹ까 봐
E Miedo o preocupación :: Para explicar algo que haces por miedo a que pase algo malo, o algo que no quieres que pase, se usa **-(으)ㄹ까 봐**: 늦다 → **늦을까 봐** (por miedo a llegar tarde), 가다 → **갈까 봐** (por miedo a que vaya), 잊어버리다 → **잊어버릴까 봐** (por miedo a olvidar). :: 버스를 놓칠**까 봐** 뛰었어요 = corrí por miedo a perder el autobús.
E Preocupación y precaución :: Suele expresar preocupación ante algo que se quiere evitar y a menudo explica una precaución: 비가 올**까 봐** 우산을 챙겼어요 = cogí el paraguas por si llovía / por miedo a que lloviera. Para expresar claramente un deseo, es más directo **-(으)면 좋겠어요**.

| 늦다 | 늦을까 봐 | por miedo a llegar tarde
| 가다 | 갈까 봐 | por miedo a que vaya
| 잊어버리다 | 잊어버릴까 봐 | por miedo a olvidar
| 비가 오다 | 비가 올까 봐 | por miedo a que llueva
W 늦을까 봐 = por miedo a llegar tarde
W 갈까 봐 = por miedo a que vaya
W 잊어버릴까 봐 = por miedo a olvidar
W 올까 봐 = por miedo a que venga
W 비가 올까 봐 = por miedo a que llueva
W 놓칠까 봐 = por miedo a perder (algo)
W 뛰었어요 = corrí
W 가져갔어요 = lo llevé, llevé
W 메모했어요 = apunté, tomé nota
W 메모 = nota, apunte

D Corriendo al autobús
안나: 민수 씨, 왜 그렇게 빨리 뛰어요? = Minsu, ¿por qué corres tan rápido?
  > 왜 = por qué | 그렇게 = tan | 빨리 뛰어요 = corres rápido
민수: 버스를 놓칠까 봐 뛰었어요. = Corrí por miedo a perder el autobús.
  > 버스를 = el autobús | 놓칠까 봐 = por miedo a perder | 뛰었어요 = corrí
안나: 그래서 메모했어요? = ¿Por eso lo apuntaste?
  > 그래서 = por eso | 메모했어요 = lo apuntaste
민수: 네, 약속을 잊어버릴까 봐 메모했어요. = Sí, lo apunté por miedo a olvidar la cita.
  > 약속을 = la cita | 잊어버릴까 봐 = por miedo a olvidar | 메모했어요 = lo apunté
Q ¿Qué significa «늦을까 봐 뛰었어요»?
+ Corrí por miedo a llegar tarde. :: 늦을까 봐 = por miedo a llegar tarde.
- Corrí y llegué tarde. :: Eso cambia la causa.
- Llegué temprano corriendo. :: Eso sería 일찍 왔어요.
H 비가 ___ 우산을 가져갔어요. :: por miedo a que llueva
+ 올까 봐 :: 비가 올까 봐 = por miedo a que llueva.
- 와요 :: Es «llueve», presente.
- 왔어요 :: Es «llovió», pasado.
R 잊어버릴까 봐 메모했어요.
+ Apunté por miedo a olvidar. :: 잊어버릴까 봐 = por miedo a olvidar.
- Olvidé apuntar. :: Eso no es la causa.
- Apunté para recordar siempre. :: Eso sería 기억하려고.
A 버스를 놓칠까 봐 뛰었어요. :: ¿Por qué corrió la persona?
+ Por miedo a perder el autobús. :: 놓칠까 봐 = por miedo a perder.
- Porque llovía. :: Eso sería 비가 와서.
- Porque no tenía prisa. :: Eso sería 급하지 않아서.
O 잊어버릴까 봐 메모했어요 :: Apunté por miedo a olvidar :: 잊어버릴까 봐 = por miedo a olvidar.
Q ¿Cómo dices «por miedo a que vaya»?
+ 갈까 봐 :: 가다 → 갈까 봐.
- 가요 :: Es «voy», presente.
- 가면 :: Es «si voy», condición.
H 약속을 ___ 메모했어요. :: por miedo a olvidar
+ 잊어버릴까 봐 :: 잊어버릴까 봐 = por miedo a olvidar.
- 잊어버려요 :: Es «olvido», presente.
- 잊어버렸어요 :: Es «olvidé», pasado.
Q ¿Qué significa «걱정돼요»?

- Estoy cansado. :: Eso sería 피곤해요.
Q ¿Por qué alguien podría coger un paraguas «비가 올까 봐»?
+ Por precaución ante la posibilidad de lluvia. :: -ㄹ까 봐 expresa preocupación o anticipación.
- Porque ya está lloviendo seguro. :: La forma no afirma que llueva.
- Porque quiere que llueva. :: Para un deseo se usaría otra expresión.
@ 23 | 비가 올지도 몰라요 | Puede que…: -(으)ㄹ지도 모르다
E Una posibilidad :: Para decir que algo puede pasar, sin estar seguro, se usa **-(으)ㄹ지도 모르다**: 가다 → **갈지도 몰라요** (puede que vaya), 먹다 → **먹을지도 몰라요** (puede que coma), 맛있다 → **맛있을지도 몰라요** (puede que esté rico). :: 비가 **올지도 몰라요** = puede que llueva.
E Con 혹시 :: **혹시** (quizá, por si acaso) suele ir delante. Así suena a precaución: 혹시 **모르니까요** = por si acaso. :: Úsalo para avisar de una posibilidad: 혹시 늦을지도 몰라요 = quizá llegue tarde.
B Verbo o adjetivo | Con -(으)ㄹ지도 모르다 | Español
| 가다 | 갈지도 몰라요 | puede que vaya
| 먹다 | 먹을지도 몰라요 | puede que coma
| 비가 오다 | 비가 올지도 몰라요 | puede que llueva
| 맛있다 | 맛있을지도 몰라요 | puede que esté rico
W 갈지도 몰라요 = puede que vaya
W 먹을지도 몰라요 = puede que coma
W 비가 올지도 몰라요 = puede que llueva
W 맛있을지도 몰라요 = puede que esté rico
W 갈지도 = puede que vaya (sin 몰라요)
W 혹시 = quizá, por si acaso
W 몰라요 = no sé, no lo sé
W 혹시 모르니까요 = por si acaso
W 좋은데요 = está bien, pero
V Vocabulario: posibilidad
D El paraguas de por si acaso
안나: 우산 가져갈까요? = ¿Llevamos el paraguas?
  > 우산 = paraguas | 가져갈까요 = ¿llevamos?
민수: 날씨가 좋은데요. 그래도 혹시 비가 올지도 몰라요. = El tiempo está bueno. Aun así, quizá llueva.
  > 날씨가 좋은데요 = el tiempo está bueno | 그래도 = aun así | 혹시 = quizá | 비가 올지도 몰라요 = puede que llueva
안나: 그럼 우산을 가져가요. = Entonces llevamos el paraguas.
  > 그럼 = entonces | 우산을 가져가요 = llevamos el paraguas

  > 혹시 모르니까요 = por si acaso
Q ¿Qué significa «비가 올지도 몰라요»?
+ Puede que llueva. :: 올지도 몰라요 = puede que llueva.
- Va a llover seguro. :: Eso sería 비가 올 거예요.
- Llovió ayer. :: Eso sería 어제 비가 왔어요.
Q ¿Qué opción es una posibilidad, no una certeza?
+ 내일 비가 올지도 몰라요. :: -ㄹ지도 모르다 presenta una posibilidad.
- 내일 비가 와요. :: Es una afirmación directa.
- 어제 비가 왔어요. :: Es una afirmación pasada.
Q ¿Qué significa «혹시 늦을지도 몰라요»?
+ Quizá llegue tarde. :: -ㄹ지도 모르다 expresa posibilidad.
- Llegará tarde seguro. :: El enunciado no lo afirma con certeza.
- Llegó tarde ayer. :: Eso sería 어제 늦었어요.
Q ¿Qué significa «혹시» en el diálogo?

- Ya. :: Eso sería 이미.
