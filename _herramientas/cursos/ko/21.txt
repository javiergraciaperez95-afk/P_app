@ 21 | 피곤하다고 했어요 | Lo que dijo otra persona: -다고 하다
E Contar lo que alguien dijo :: Para contar lo que dijo otra persona, sin repetir sus palabras exactas, se usa **-다고 하다**. La forma cambia según la palabra: adjetivo (피곤하다 → **피곤하다고**), verbo sin consonante final (가다 → **간다고**), verbo con consonante final (먹다 → **먹는다고**) y sustantivo (학생이다 → **학생이라고**). :: 민수 씨가 **피곤하다고** 했어요 = Minsu dijo que está cansado.
E Pasado :: El pasado indirecto se forma con **-았다고 / -었다고**: 갔다고 (que fue), 잤다고 (que durmió), 했다고 (que hizo). :: Lo que dijo se pone en pasado con **했어요** (dijo).
B Lo que se dijo | Estilo indirecto | Español
| 피곤해요 | 피곤하다고 | que está cansado
| 가요 | 간다고 | que va
| 먹어요 | 먹는다고 | que come
| 학생이에요 | 학생이라고 | que es estudiante
| 갔어요 | 갔다고 | que fue
W 피곤하다고 = que está cansado
W 간다고 = que va
W 먹는다고 = que come
W 학생이라고 = que es estudiante
W 갔다고 = que fue
W 잤다고 = que se acostó, que durmió
W 했다고 = que hizo
W 못 온다고 = que no puede venir
W 우리끼리 = nosotros solos
W 말했어요 = dijo, habló
V Vocabulario: estilo indirecto
D Minsu no puede venir
안나: 민수 씨가 내일 못 온다고 했어요. = Minsu dijo que mañana no puede venir.
  > 민수 씨가 = Minsu | 내일 = mañana | 못 온다고 = que no puede venir | 했어요 = dijo
유나: 그래요? 왜요? = ¿Ah, sí? ¿Por qué?
  > 그래요 = ¿así es? | 왜요 = ¿por qué?
안나: 피곤하다고 했어요. 어제 늦게 잤다고 했어요. = Dijo que está cansado. Dijo que anoche se acostó tarde.
  > 피곤하다고 = que está cansado | 잤다고 = que se acostó | 했어요 = dijo
유나: 그럼 우리끼리 가요. = Entonces vamos nosotros solos.
  > 그럼 = entonces | 우리끼리 = nosotros solos | 가요 = vamos
Q ¿Qué significa «민수 씨가 피곤하다고 했어요»?
+ Minsu dijo que está cansado. :: 피곤하다고 했어요 = dijo que está cansado.
- Minsu está cansado de verdad. :: Eso no cuenta lo que se dijo.
- Minsu dijo que comió. :: Eso sería 먹었다고 했어요.
H 안나 씨가 내일 ___ 했어요. :: dijo que va
+ 간다고 :: 가다 → 간다고: que va.
- 가요 :: Es «va» directo, no indirecto.
- 갔어요 :: Es «fue», pasado.
R 학생이라고 했어요.
+ Dijo que es estudiante. :: 학생이라고 = que es estudiante.
- Dijo que va a estudiar. :: Eso sería 공부한다고.
- Es estudiante. :: Eso sería 학생이에요.
A 그는 피곤하다고 했어요. :: ¿Qué dijo la persona?
+ Dijo que está cansado. :: 피곤하다고 = que está cansado.
- Dijo que está contento. :: Eso no lo dice la frase.
- Dijo que no está cansado. :: Eso sería 피곤하지 않다고.
O 민수 씨가 피곤하다고 했어요 :: Minsu dijo que está cansado :: 피곤하다고 = que está cansado. 했어요 = dijo.
Q ¿Cómo se dice «que come» (먹다)?
+ 먹는다고 :: 먹다 → 먹는다고.
- 먹어요 :: Es «come», directo.
- 먹었어요 :: Es «comió».
H 그럼 ___ 가요. :: nosotros solos
+ 우리끼리 :: Es «nosotros solos».
- 혼자 :: Es «solo».
- 같이 :: Es «juntos».
Q ¿Cuál es «que hizo» (하다)?
+ 했다고 :: 하다 → 했다고: que hizo.
- 한다고 :: Es «que hace».
- 했어요 :: Es «hizo», sin estilo indirecto.
@ 21 | 가냐고 물었어요 | Preguntas y órdenes indirectas: -냐고, -(으)라고, -자고
E Preguntas :: Para contar una pregunta se usa **-냐고 물었어요** (preguntó si…): 가다 → **가냐고** (preguntó si va), 있다 → **있냐고** (preguntó si hay o si tiene), 먹다 → **먹냐고** (preguntó si come). :: 어디 **가냐고** 물었어요 = preguntó a dónde iba.
E Órdenes y propuestas :: **-(으)라고 했어요** cuenta una orden (dijo que hiciera algo). **-자고 했어요** cuenta una propuesta (propuso que hiciéramos algo). :: 기다리**라고** 했어요 = dijo que esperara. 같이 가**자고** 했어요 = propuso que fuéramos juntos.
B Tipo | Original | Estilo indirecto
| Pregunta | 어디 가요? | 어디 가냐고 물었어요
| Orden | 기다리세요 | 기다리라고 했어요
| Propuesta | 같이 가요 | 같이 가자고 했어요
W 가냐고 물었어요 = preguntó si va
W 있냐고 물었어요 = preguntó si hay, si tiene
W 기다리라고 했어요 = dijo que esperara
W 먹으라고 했어요 = dijo que comiera
W 가자고 했어요 = propuso que fuéramos
W 같이 가자고 했어요 = propuso que fuéramos juntos
W 점심 먹자고 했어요 = propuse que comiéramos
W 저한테 = a mí, a mi persona
W 물었어요 = preguntó
W 뭐라고 했어요 = qué dijo, qué le dije
W 기다리라고 = que esperara (orden indirecta)
W 가자고 = que vayamos (propuesta indirecta)
V Vocabulario: preguntas y propuestas indirectas
D Una propuesta de comer
유나: 안나 씨, 민수 씨가 뭐라고 했어요? = Anna, ¿qué te dijo Minsu?
  > 뭐라고 했어요 = qué dijo
안나: 민수 씨가 저한테 오늘 시간 있냐고 물었어요. = Minsu me preguntó si hoy tenía tiempo.
  > 저한테 = a mí | 오늘 = hoy | 시간 있냐고 물었어요 = preguntó si tenía tiempo
유나: 그래서 뭐라고 했어요? = ¿Y qué le dijiste?
  > 그래서 = entonces, por eso | 뭐라고 했어요 = qué dijiste
안나: 같이 점심 먹자고 했어요. = Le propuse que comiéramos juntos.
  > 점심 먹자고 했어요 = propuse que comiéramos
유나: 좋아요! 그럼 저도 갈게요. = ¡Genial! Entonces yo también iré.
  > 저도 = yo también | 갈게요 = iré
Q ¿Qué significa «민수 씨가 오늘 시간 있냐고 물었어요»?
+ Minsu preguntó si hoy tenía tiempo. :: 있냐고 물었어요 = preguntó si tenía.
- Minsu dijo que hoy tiene tiempo. :: Eso sería 있다고 했어요.
- Minsu tiene tiempo hoy. :: Eso no es una pregunta.
H 역에서 ___ 했어요. :: le pidió que esperara
+ 기다리라고 :: 기다리라고 했어요: dijo que esperara.
- 기다리자고 :: Es propuesta, no orden.
- 기다리냐고 :: Es pregunta, no orden.
R 같이 가자고 했어요.
+ Propuso que fuéramos juntos. :: 가자고 했어요 = propuso que fuéramos.
- Va a venir con nosotros. :: Eso no lo dice la frase.
- Fuimos juntos. :: Eso sería 같이 갔어요.
A 점심 먹자고 했어요. :: ¿Qué propuso la persona?
+ Propuso comer juntos. :: 먹자고 = que comamos.
- Propuso cenar. :: Eso sería 저녁 먹자고.
- Propuso ir al cine. :: Eso sería 영화 보자고.
O 어디 가냐고 물었어요 :: Preguntó a dónde iba :: 어디 = dónde. 물었어요 = preguntó.
Q ¿Cómo se pregunta «¿estás libre?» en estilo indirecto (있다)?
+ 있냐고 :: 있다 → 있냐고: preguntó si tenía.
- 있다고 :: Es afirmar, no preguntar.
- 있으라고 :: Es orden.
Q ¿Qué dijo la persona en «기다리라고 했어요»?
+ Dijo que esperara. :: 기다리라고 = que esperara.
- Preguntó si esperaba. :: Eso sería 기다리냐고.
- Propuso esperar. :: Eso sería 기다리자고.
H 민수 씨가 같이 ___ 했어요. :: propuso que fuéramos
+ 가자고 :: 같이 가자고 했어요 = propuso que fuéramos.
- 가라고 :: Es orden.
- 가냐고 :: Es pregunta.
@ 21 | 간대요 | Lo que te han contado: -대요
E Lo que dicen :: Cuando repites algo que oíste de otra persona se usa **-대요** (dicen que…, me han dicho que…): 가다 → **간대요** (dicen que va), 먹다 → **먹는대요** (dicen que come), 피곤하다 → **피곤하대요** (dicen que está cansado), 학생이다 → **학생이래요** (dicen que es estudiante). :: 민수 씨가 내일 **못 온대요** = dicen que Minsu no puede venir mañana.
E Diferencia con -다고 하다 :: **-다고 하다** cuenta lo que alguien dijo, con sus palabras. **-대요** es lo que se oye, en el habla diaria. :: 날씨가 **좋대요** = dicen que hace buen tiempo.
B Forma | Con -대요 | Español
| 가다 | 간대요 | dicen que va
| 먹다 | 먹는대요 | dicen que come
| 피곤하다 | 피곤하대요 | dicen que está cansado
| 학생이다 | 학생이래요 | dicen que es estudiante
W 대요 = dicen que, me han dicho que
W 간대요 = dicen que va
W 먹는대요 = dicen que come
W 피곤하대요 = dicen que está cansado
W 학생이래요 = dicen que es estudiante
W 온대요 = dicen que viene, dicen que llega
W 날씨가 좋대요 = dicen que hace buen tiempo
W 내일 비가 온대요 = dicen que mañana llueve
W 뉴스 = noticias
W 들었어요 = escuché, oí
W 가져갈까요 = ¿llevamos?
V Vocabulario: lo que se oye
D Las noticias
유나: 뉴스에서 내일 비가 온대요. = Dicen en las noticias que mañana llueve.
  > 뉴스에서 = en las noticias | 내일 비가 온대요 = dicen que mañana llueve
민수: 그래요? 저도 들었어요. 우산을 가져갈까요? = ¿Ah, sí? Yo también lo oí. ¿Llevamos paraguas?
  > 저도 = yo también | 들었어요 = lo oí | 가져갈까요 = ¿llevamos?
유나: 네, 그게 좋겠어요. = Sí, creo que es lo mejor.
  > 그게 = eso | 좋겠어요 = creo que es bueno
Q ¿Qué significa «학생이래요»?
+ Dicen que es estudiante. :: 학생이래요 = dicen que es estudiante.
- Es estudiante. :: Eso sería 학생이에요.
- Dijo que es estudiante. :: Eso sería 학생이라고 했어요.
H 민수 씨가 내일 못 ___. :: dicen que no puede venir (온대요)
+ 온대요 :: 오다 → 온대요: dicen que viene.
- 와요 :: Es «viene», directo.
- 왔어요 :: Es «vino», pasado.
R 내일 비가 온대요.
+ Dicen que mañana llueve. :: 온대요 = dicen que llega / llueve.
- Mañana llovió. :: Eso sería 어제 비가 왔어요.
- Mañana llueve. :: Eso sería 내일 비가 와요.
A 날씨가 좋대요. :: ¿Qué te han dicho?
+ Dicen que hace buen tiempo. :: 좋대요 = dicen que es bueno.
- Dicen que hace frío. :: Eso sería 추대요.
- Hace buen tiempo ahora. :: Eso sería 지금 날씨가 좋아요.
O 피곤하대요 :: Dicen que está cansado :: 피곤하대요 = dicen que está cansado.
Q ¿Cómo se dice «dicen que va»?
+ 간대요 :: 가다 → 간대요.
- 가요 :: Es «va», directo.
- 갔대요 :: Es «dicen que fue», pasado.
Q ¿Qué significa «뉴스»?
+ Noticias. :: 뉴스 es noticias.
- Ventas. :: Eso sería 판매.
- Ejercicio. :: Eso sería 운동.
H 그럼 우리 ___ 가요? :: nosotros solos
+ 우리끼리 :: Es «nosotros solos».
- 혼자 :: Es «solo».
- 같이 :: Es «juntos».
