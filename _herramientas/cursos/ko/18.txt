@ 18 | 비가 오면 | Si pasa algo: -(으)면
E Condición :: Para decir «si…» o «cuando…» con algo que puede pasar se usa **-(으)면**: 가다 → **가면** (si voy), 먹다 → **먹으면** (si como), 있다 → **있으면** (si hay / si tienes), 좋다 → **좋으면** (si es bueno). :: 비가 **오면** 집에서 봐요 = si llueve, lo vemos en casa.
E Forma :: Se usa igual con verbos y adjetivos. Si la raíz acaba en vocal se añade **-면**; si acaba en consonante, **-으면**. :: 시간이 **있으면** 같이 가요 = si tienes tiempo, vamos juntos.
B Verbo o adjetivo | Raíz | Con -(으)면 | Español
| 가다 | 가 | 가면 | si voy
| 먹다 | 먹 | 먹으면 | si como
| 있다 | 있 | 있으면 | si hay, si tienes
| 좋다 | 좋 | 좋으면 | si es bueno
W 가면 = si voy, si vas
W 먹으면 = si como, si comes
W 있으면 = si hay, si tienes
W 좋으면 = si es bueno
W 시간이 있으면 = si tienes tiempo
W 날씨가 좋으면 = si hace buen tiempo
W 비가 오면 = si llueve
W 돈이 있으면 = si tienes dinero
V Vocabulario: si pasa algo
D El plan del fin de semana
민수: 주말에 시간이 있으면 같이 영화 볼까요? = Si tienes tiempo el fin de semana, ¿vemos una película juntos?
  > 시간이 있으면 = si tienes tiempo | 같이 = juntos | 볼까요 = ¿vemos?
안나: 좋아요! 날씨가 좋으면 공원에 가요. = ¡Genial! Si hace buen tiempo, vamos al parque.
  > 날씨가 좋으면 = si hace buen tiempo | 공원에 가요 = vamos al parque
민수: 비가 오면 집에서 봐요. = Si llueve, la vemos en casa.
  > 비가 오면 = si llueve | 집에서 = en casa | 봐요 = la vemos
안나: 그래요, 그럼 주말에 봐요. = Vale, entonces nos vemos el fin de semana.
  > 그래요 = vale | 그럼 = entonces | 주말에 봐요 = nos vemos el fin de semana
Q ¿Qué significa «비가 오면 집에서 봐요»?
+ Si llueve, la vemos en casa. :: 비가 오면 = si llueve.
- Llueve y la vemos en casa. :: Falta la condición «si».
- Llovió ayer y la vimos. :: Eso sería 어제 비가 왔어요.
H 시간이 ___ 같이 가요. :: si tienes
+ 있으면 :: 있다 → 있으면: si tienes.
- 있어요 :: Es «tienes», sin condición.
- 있었어요 :: Es «tuviste», pasado.
R 날씨가 좋으면 공원에 가요.
+ Si hace buen tiempo, vamos al parque. :: 좋으면 = si es bueno.
- Como el tiempo es bueno, fuimos al parque. :: Eso sería pasado con motivo.
- Hace buen tiempo y fuimos al parque. :: Eso sería pasado.
A 돈이 있으면 같이 먹어요. :: ¿Qué dice la persona?
+ Si tiene dinero, comen juntos. :: 있으면 = si tiene.
- Comen juntos todos los días. :: Eso sería 매일 같이 먹어요.
- Compraron comida ayer. :: Eso sería 어제 샀어요.
O 비가 오면 집에서 봐요 :: Si llueve, la vemos en casa :: 비가 오면 = si llueve. 집에서 = en casa. 봐요 = la vemos.
Q ¿Cómo dices «si vas»?
+ 가면 :: 가다 → 가면.
- 가요 :: Es «vas», sin condición.
- 갔어요 :: Es «fuiste», pasado.
Q ¿Qué significa «먹으면»?
+ Si como. :: 먹으면 = si como / si comes.
- Como. :: Eso sería 먹어요.
- Comí. :: Eso sería 먹었어요.
H 날씨가 ___ 공원에 가요. :: si hace buen tiempo
+ 좋으면 :: 좋다 → 좋으면: si es bueno.
- 좋아요 :: Es «es bueno», sin condición.
- 좋았어요 :: Es «fue bueno», pasado.
@ 18 | 좋겠어요 | Ojalá: -(으)면 좋겠어요
E Deseo :: Para decir lo que deseas se usa **-(으)면 좋겠어요** (ojalá…, me gustaría que…): 가다 → **가면 좋겠어요** (ojalá vayamos), 안 오다 → **안 오면 좋겠어요** (ojalá no venga), 합격하다 → **합격하면 좋겠어요** (ojalá apruebe). :: 비가 **안 오면 좋겠어요** = ojalá no llueva.
E Diferencia con -(으)면 :: **-(으)면** habla de una condición; **-(으)면 좋겠어요** habla de un deseo. Ambas usan la misma forma. :: 날씨가 좋으면 가요 = si hace buen tiempo, vamos. 날씨가 좋으면 좋겠어요 = ojalá haga buen tiempo.
B Verbo o adjetivo | Raíz | Ojalá… | Español
| 가다 | 가 | 가면 좋겠어요 | ojalá vayamos
| 오다 | 오 | 안 오면 좋겠어요 | ojalá no venga / no llueva
| 합격하다 | 합격하 | 합격하면 좋겠어요 | ojalá apruebe
| 좋다 | 좋 | 좋으면 좋겠어요 | ojalá sea bueno
W 좋겠어요 = ojalá, me gustaría
W 좋으면 좋겠어요 = ojalá sea bueno
W 안 오면 좋겠어요 = ojalá no venga, ojalá no llueva
W 비가 안 오면 좋겠어요 = ojalá no llueva
W 한국에 가면 좋겠어요 = ojalá vaya a Corea
W 합격하면 좋겠어요 = ojalá apruebe
W 저도요 = yo también
V Vocabulario: deseos
D Ojalá haga buen tiempo
안나: 내일 날씨가 좋으면 좋겠어요. = Ojalá mañana haga buen tiempo.
  > 내일 날씨가 = el tiempo de mañana | 좋으면 좋겠어요 = ojalá sea bueno
민수: 저도요. 같이 공원에 가면 정말 좋겠어요. = Yo también. Ojalá vayamos juntos al parque.
  > 저도요 = yo también | 같이 공원에 가면 = si vamos juntos al parque | 정말 좋겠어요 = ojalá
안나: 좋아요. 그럼 내일 아침에 만나요. = Vale. Entonces nos vemos mañana por la mañana.
  > 그럼 = entonces | 내일 아침에 = mañana por la mañana | 만나요 = nos vemos
Q ¿Qué significa «비가 안 오면 좋겠어요»?
+ Ojalá no llueva. :: 안 오면 = si no llueve; 좋겠어요 = ojalá.
- Llueve mucho. :: Eso sería 비가 많이 와요.
- Hoy no llueve. :: Eso sería 오늘 비가 안 와요.
H 내일 날씨가 ___ 좋겠어요. :: si es (buen tiempo)
+ 좋으면 :: 좋으면 좋겠어요 = ojalá sea bueno.
- 좋아요 :: Es «es bueno», sin deseo.
- 좋았어요 :: Es «fue bueno», pasado.
R 시험에 합격하면 좋겠어요.
+ Ojalá apruebe el examen. :: 합격하면 좋겠어요 = ojalá apruebe.
- Aprobé el examen. :: Eso sería 합격했어요.
- Estudio para el examen. :: Eso sería 시험 공부해요.
A 한국에 가면 좋겠어요. :: ¿Qué dice la persona?
+ Le gustaría ir a Corea. :: 가면 좋겠어요 = me gustaría ir.
- Ya fue a Corea. :: Eso sería 한국에 갔어요.
- Irá a Corea mañana. :: Eso sería 내일 갈 거예요.
O 같이 공원에 가면 좋겠어요 :: Ojalá vayamos juntos al parque :: 같이 = juntos. 가면 좋겠어요 = ojalá vayamos.
Q ¿Cómo dices «ojalá vaya»?
+ 가면 좋겠어요 :: 가다 → 가면 좋겠어요.
- 가요 :: Es «voy», sin deseo.
- 가고 있어요 :: Es «estoy yendo», ahora.
Q ¿Qué significa «좋겠어요»?
+ Ojalá / me gustaría. :: 좋겠어요 expresa un deseo.
- Es bueno. :: Eso sería 좋아요.
- Fue bueno. :: Eso sería 좋았어요.
H 비가 ___ 좋겠어요. :: no llueva
+ 안 오면 :: 안 오면 좋겠어요 = ojalá no llueva.
- 와요 :: Es «llueve», sin deseo.
- 왔어요 :: Es «llovió», pasado.
@ 18 | 돈이 있으면 | Basta con: -(으)면 돼요
E Lo necesario :: Para decir que basta con hacer algo se usa **-(으)면 돼요**: 쓰다 → **쓰면 돼요** (basta con escribir), 내다 → **내면 돼요** (basta con pagar), 가다 → **가면 돼요** (basta con ir). :: 여기에 이름을 **쓰면 돼요** = basta con escribir el nombre aquí.
E Cuando hablas de un trámite :: Es muy útil para explicar cómo hacer algo: primero tienes que hacer una cosa y luego todo está bien. :: 카드를 넣**으면 돼요** = basta con meter la tarjeta.
B Verbo | Raíz | Basta con… | Español
| 쓰다 | 쓰 | 쓰면 돼요 | basta con escribir
| 내다 | 내 | 내면 돼요 | basta con pagar
| 넣다 | 넣 | 넣으면 돼요 | basta con meter
| 기다리다 | 기다리 | 기다리면 돼요 | basta con esperar
W 쓰면 돼요 = basta con escribir
W 내면 돼요 = basta con pagar
W 넣으면 돼요 = basta con meter
W 기다리면 돼요 = basta con esperar
W 돈 = dinero
W 가면 돼요 = basta con ir, sólo tienes que ir
W 계산 = pago, cuenta
W 계산하면 돼요 = basta con pagar
W 계산은 = el pago (tema)
W 넣으세요 = meta, por favor
V Vocabulario: basta con
D Pagar en la tienda
손님: 계산은 어떻게 해요? = ¿Cómo se paga?
  > 계산은 = el pago (tema) | 어떻게 해요 = cómo se hace
직원: 여기서 카드로 계산하면 돼요. = Basta con pagar aquí con tarjeta.
  > 여기서 = aquí | 카드로 계산하면 돼요 = basta con pagar con tarjeta
손님: 카드를 어디에 넣으면 돼요? = ¿Dónde hay que meter la tarjeta?
  > 어디에 = dónde | 넣으면 돼요 = hay que meter
직원: 여기에 넣으면 돼요. 감사합니다. = Basta con meterla aquí. Gracias.
  > 여기에 넣으면 돼요 = basta con meterla aquí
Q ¿Qué significa «카드로 계산하면 돼요?»?
+ ¿Basta con pagar con tarjeta? :: 계산하면 돼요 = basta con pagar.
- ¿Quieres pagar con tarjeta? :: Eso sería 계산하고 싶어요?
- ¿Pagaste con tarjeta? :: Eso sería pasado.
H 여기에 이름을 ___. :: basta con escribir
+ 쓰면 돼요 :: 쓰다 → 쓰면 돼요.
- 쓰세요 :: Es «escriba, por favor», una orden.
- 쓰는 것 :: Es «el hecho de escribir».
R 돈을 내면 돼요.
+ Basta con pagar. :: 내면 돼요 = basta con pagar.
- Pagué ayer. :: Eso sería 어제 냈어요.
- Pagaré mañana. :: Eso sería 내일 낼 거예요.
A 카드를 여기에 넣으면 돼요. :: ¿Qué te dicen?
+ Basta con meter la tarjeta aquí. :: 넣으면 돼요 = basta con meter.
- Hay que sacar la tarjeta aquí. :: Eso sería 꺼내세요.
- Puedes llevarte la tarjeta a casa. :: Eso sería 집에 가져가면 돼요.
O 여기서 기다리면 돼요 :: Basta con esperar aquí :: 여기서 = aquí. 기다리면 돼요 = basta con esperar.
Q ¿Cómo dices «basta con ir»?
+ 가면 돼요 :: 가다 → 가면 돼요.
- 가요 :: Es «voy», sin basta.
- 가세요 :: Es «vaya, por favor», una orden.
Q ¿Qué significa «계산은 어떻게 해요?»?
+ ¿Cómo se paga? :: 계산은 = el pago; 어떻게 해요 = cómo se hace.
- ¿Cuánto cuesta? :: Eso sería 얼마예요?
- ¿Dónde se come? :: Eso sería 어디에서 먹어요?
H 여기에 카드를 ___. :: meter
+ 넣으면 돼요 :: 넣다 → 넣으면 돼요.
- 넣어요 :: Es «meto», sin basta.
- 넣으세요 :: Es «meta, por favor», una orden.
