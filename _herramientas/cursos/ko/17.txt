@ 17 | 비가 올 것 같아요 | Creo que va a…: -(으)ㄹ 것 같아요
E Suponer algo futuro :: Para decir «creo que va a…» o «parece que va a…» se usa **-(으)ㄹ 것 같아요**: 오다 → **올 것 같아요** (creo que va a llover), 먹다 → **먹을 것 같아요** (creo que lo voy a comer), 재미있다 → **재미있을 것 같아요** (creo que será divertido). :: 비가 **올 것 같아요** = creo que va a llover.
E Es una opinión :: Con **-(으)ㄹ 것 같아요** hablas de algo que no sabes seguro: es tu impresión. :: Para algo seguro se usa **-(으)ㄹ 거예요**, que ya conoces de A1: 내일 비가 올 거예요 = mañana lloverá.
B Verbo o adjetivo | Raíz | Creo que… | Español
| 오다 | 오 | 올 것 같아요 | creo que va a venir / llover
| 먹다 | 먹 | 먹을 것 같아요 | creo que lo voy a comer
| 재미있다 | 재미있 | 재미있을 것 같아요 | creo que será divertido
| 맛있다 | 맛있 | 맛있을 것 같아요 | creo que estará rico
W 것 같아요 = creo que, parece que
W 하늘 = cielo
W 어두워요 = está oscuro
W 가져가요 = llevamos, llevas
W 올 것 같아요 = creo que va a venir, creo que va a llover
W 비가 올 것 같아요 = creo que va a llover
W 맛있을 것 같아요 = creo que estará rico, parece rico
W 재미있을 것 같아요 = creo que será divertido
W 먹을 것 같아요 = creo que lo voy a comer
V Vocabulario: suposiciones
D El tiempo de la tarde
안나: 하늘이 어두워요. 비가 올 것 같아요. = El cielo está oscuro. Creo que va a llover.
  > 하늘이 = el cielo | 어두워요 = está oscuro | 비가 올 것 같아요 = creo que va a llover
민수: 그래요? 그럼 우산을 가져가요. = ¿Ah, sí? Entonces llevamos paraguas.
  > 그래요 = ¿así es? | 우산을 = el paraguas | 가져가요 = llevamos
안나: 네. 저녁에 비가 많이 올 것 같아요. = Sí. Creo que esta tarde va a llover mucho.
  > 저녁에 = por la tarde | 많이 = mucho | 올 것 같아요 = creo que va a
민수: 그럼 빨리 가요! = ¡Entonces, vámonos rápido!
  > 빨리 가요 = vámonos rápido
Q ¿Qué significa «비가 올 것 같아요»?
+ Creo que va a llover. :: 올 것 같아요 = creo que va a llover.
- Llovió ayer. :: Eso sería 어제 비가 왔어요.
- Llueve todos los días. :: Eso sería 매일 비가 와요.
H 비가 ___ 것 같아요. :: va a (venir)
+ 올 :: 오다 → 올 것 같아요.
- 와요 :: No se usa con 것 같아요; es presente.
- 왔어요 :: Es pasado; no encaja con 것 같아요.
R 맛있을 것 같아요.
+ Creo que estará rico. :: 맛있을 것 같아요 = creo que estará rico.
- Estoy comiéndolo. :: Eso sería 먹고 있어요.
- Ya lo comí. :: Eso sería 먹었어요.
A 저녁에 비가 올 것 같아요. :: ¿Qué dice la persona?
+ Cree que por la tarde va a llover. :: 올 것 같아요 = cree que va a llover.
- Dice que llovió por la tarde. :: Eso sería 저녁에 비가 왔어요.
- Dice que nunca llueve. :: Eso sería 비가 안 와요.
O 재미있을 것 같아요 :: Creo que será divertido :: 재미있을 것 같아요 = creo que será divertido.
Q ¿Cómo dices «creo que lo voy a comer»?
+ 먹을 것 같아요 :: 먹다 → 먹을 것 같아요.
- 먹었어요 :: Es «comí».
- 먹고 있어요 :: Es «estoy comiendo».
Q ¿Qué significa «어두워요»?
+ Está oscuro. :: 어두워요 = está oscuro.
- Está claro. :: Es lo contrario.
- Hace frío. :: Eso sería 추워요.
H 하늘이 어두워요. 비가 ___ 것 같아요. :: va a llover
+ 올 :: 오다 → 올 것 같아요.
- 왔어요 :: Es pasado, no encaja.
- 와요 :: No encaja con 것 같아요.
@ 17 | 피곤한 것 같아요 | Parece que… (lo que se ve): -는/-(으)ㄴ 것 같아요
E Lo que parece :: Para decir lo que parece en este momento se usa **-(으)ㄴ 것 같아요** con adjetivos y **-는 것 같아요** con verbos: 피곤하다 → **피곤한 것 같아요** (parece cansado), 비싸다 → **비싼 것 같아요** (parece caro), 자다 → **자는 것 같아요** (parece que duerme). :: 민수 씨 **피곤한 것 같아요** = creo que Minsu está cansado.
E Suposición con lo que ves :: Se usa cuando miras algo y lo interpretas. Si es algo que todavía no ha pasado, usa **-(으)ㄹ 것 같아요** (lección anterior). :: 바빠 보여요 es parecido, pero aquí ves algo que ya está pasando.
B Verbo o adjetivo | Raíz | Parece que… | Español
| 피곤하다 | 피곤하 | 피곤한 것 같아요 | parece cansado
| 비싸다 | 비싸 | 비싼 것 같아요 | parece caro
| 바쁘다 | 바ㅃ | 바쁜 것 같아요 | parece ocupado
| 자다 | 자 | 자는 것 같아요 | parece que duerme
| 먹다 | 먹 | 먹는 것 같아요 | parece que come
W 피곤한 것 같아요 = parece cansado
W 비싼 것 같아요 = parece caro
W 바쁜 것 같아요 = parece ocupado
W 자는 것 같아요 = parece que duerme
W 먹는 것 같아요 = parece que come
W 아픈 것 같아요 = parece enfermo
W 것 = cosa, lo que, el hecho de
W 잤어요 = me acosté, dormí
W 그럴 것 같아요 = creo que sí
V Vocabulario: lo que parece
D Parece cansado
안나: 민수 씨, 오늘 피곤한 것 같아요. = Minsu, creo que hoy estás cansado.
  > 피곤한 것 같아요 = parece cansado
민수: 네, 어제 늦게 잤어요. = Sí, anoche me acosté tarde.
  > 늦게 잤어요 = me acosté tarde
안나: 그럼 오늘은 일찍 자요. = Entonces hoy duerme temprano.
  > 일찍 = temprano | 자요 = duerme
민수: 네, 그럴 것 같아요. = Sí, creo que sí.
  > 그럴 것 같아요 = creo que sí
Q ¿Qué significa «피곤한 것 같아요»?
+ Parece cansado. :: 피곤한 것 같아요 = parece cansado.
- Está cansado de verdad. :: Eso sería 정말 피곤해요.
- Estaba cansado ayer. :: Eso sería 어제 피곤했어요.
H 민수 씨는 자는 ___ 같아요. :: parece que duerme
+ 것 :: 자는 것 같아요 = parece que duerme.
- 집 :: Es «casa».
- 사람 :: Es «persona».
R 오늘 바쁜 것 같아요.
+ Parece que hoy está ocupado. :: 바쁜 것 같아요 = parece ocupado.
- Hoy es barato. :: Eso sería 오늘 싸요.
- Hoy estuvo ocupado. :: Eso sería 오늘 바빴어요.
A 그 가방이 비싼 것 같아요. :: ¿Qué opina la persona?
+ Parece que esa bolsa es cara. :: 비싼 것 같아요 = parece caro.
- Parece que esa bolsa es nueva. :: Eso sería 새 가방 같아요.
- Esa bolsa es muy barata. :: Eso sería 싸요.
O 아픈 것 같아요 :: Parece que está enfermo :: 아픈 것 같아요 = parece enfermo.
Q ¿Cómo dices «parece que duerme»?
+ 자는 것 같아요 :: 자다 → 자는 것 같아요.
- 자고 있어요 :: Es «está durmiendo», en realidad.
- 잤어요 :: Es «me acosté / dormí».
H 그 사람은 ___ 것 같아요. :: parece cansado
+ 피곤한 :: 피곤하다 → 피곤한 것 같아요.
- 피곤해요 :: Es «está cansado», sin suponer.
- 피곤했어요 :: Es «estaba cansado», pasado.
Q ¿Qué significa «그럴 것 같아요»?
+ Creo que sí. :: 그럴 것 같아요 = creo que sí.
- ¡Qué bien! :: Eso sería 좋아요!
- Creo que no. :: No es lo que dice.
@ 17 | 수영하는 것 | Me gusta… (hablar de gustos con -는 것)
E Hacer algo como cosa :: Para decir «el hecho de hacer algo» se usa **-는 것**: 수영하다 → **수영하는 것** (nadar), 여행하다 → **여행하는 것** (viajar), 요리하다 → **요리하는 것** (cocinar). :: 수영하**는 것**을 좋아해요 = me gusta nadar.
E Con gustos y sentimientos :: Para decir lo que te gusta o no te gusta se usa **-는 것을 좋아해요** o **-는 것을 싫어해요**. Con **싫어요** también se dice que no te gusta algo. :: 수영하는 것은 **싫어요** = nadar no me gusta.
B Verbo | Raíz | Hacer algo (-는 것) | Español
| 수영하다 | 수영하 | 수영하는 것 | nadar
| 여행하다 | 여행하 | 여행하는 것 | viajar
| 요리하다 | 요리하 | 요리하는 것 | cocinar
| 산책하다 | 산책하 | 산책하는 것 | pasear
W 것을 좋아해요 = me gusta (algo que se hace)
W 수영하는 것 = nadar, el hecho de nadar
W 여행하는 것 = viajar, el hecho de viajar
W 요리하는 것 = cocinar, el hecho de cocinar
W 산책하는 것 = pasear, el hecho de pasear
W 요리하는 = que se cocina, cocinar
W 여행하는 = que se viaja, viajar
W 수영하는 = que se nada, nadar
W 싫어요 = no me gusta
W 뭘 = qué (뭐 + 을/를)
W 특히 = sobre todo, especialmente
W 만들어요 = hago, preparo
W 산책해요 = paseamos, paseas
V Vocabulario: lo que nos gusta
D Gustos
안나: 민수 씨는 뭘 좋아해요? = Minsu, ¿qué te gusta?
  > 뭘 = qué | 좋아해요 = te gusta
민수: 저는 요리하는 것을 좋아해요. 특히 김밥을 만들어요. = Me gusta cocinar. Sobre todo hago kimbap.
  > 요리하는 것을 = cocinar | 특히 = sobre todo | 만들어요 = hago
안나: 저는 여행하는 것을 좋아해요. 하지만 수영하는 것은 싫어요. = A mí me gusta viajar. Pero nadar no me gusta.
  > 여행하는 것을 = viajar | 하지만 = pero | 수영하는 것은 = nadar | 싫어요 = no me gusta
민수: 그럼 우리 같이 산책해요! = ¡Entonces, paseemos juntos!
  > 우리 = nosotros | 같이 = juntos | 산책해요 = paseamos
Q ¿Qué significa «수영하는 것을 좋아해요»?
+ Me gusta nadar. :: 수영하는 것 = el hecho de nadar.
- Nado todos los días. :: Eso sería 매일 수영해요.
- Nadé ayer. :: Eso sería 어제 수영했어요.
H 저는 요리하는 ___ 좋아해요. :: cosa
+ 것을 :: 요리하는 것을 좋아해요 = me gusta cocinar.
- 사람을 :: Es «a la persona».
- 집을 :: Es «la casa».
R 여행하는 것을 좋아해요.
+ Me gusta viajar. :: 여행하는 것 = el hecho de viajar.
- Viajé ayer. :: Eso sería 어제 여행했어요.
- Viajo todos los días. :: Eso sería 매일 여행해요.
A 수영하는 것은 싫어요. :: ¿Qué dice la persona?
+ No le gusta nadar. :: 싫어요 = no me gusta / no le gusta.
- Le gusta nadar. :: Eso sería 좋아요.
- Nada todos los días. :: Eso sería 매일 수영해요.
O 요리하는 것을 좋아해요 :: Me gusta cocinar :: 요리하는 것 = cocinar. 좋아해요 = me gusta.
Q ¿Cómo dices «me gusta pasear»?
+ 산책하는 것을 좋아해요 :: 산책하다 → 산책하는 것을 좋아해요.
- 산책해요 :: Es «paseo», sin gustar.
- 산책했어요 :: Es «paseé», pasado.
Q ¿Qué significa «뭘 좋아해요?»?
+ ¿Qué te gusta? :: 뭘 = qué, y 좋아해요 = te gusta.
- ¿Qué comiste? :: Eso sería 뭘 먹었어요?
- ¿Qué haces? :: Eso sería 뭐 해요?
H 특히 김밥을 ___. :: hago
+ 만들어요 :: 만들다 → 만들어요: hago, preparo.
- 먹어요 :: Es «como».
- 사요 :: Es «compro».
