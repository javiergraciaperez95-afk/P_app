@ 30 | 잃어버렸어요 | Acabar haciendo algo: -고 말다 y -아/어 버리다
E Un desenlace alcanzado :: **-고 말다** presenta un resultado al que finalmente se llegó; a menudo expresa pesar o que ocurrió pese a lo esperado, pero el matiz depende del contexto: 잊다 → **잊고 말았어요** (acabé olvidándolo). :: 기차를 놓치고 말았어요 = al final perdí el tren.

| 잃다 | 잃고 말았어요 | 잃어버렸어요 | lo perdí

- 의사예요 :: Es «soy médico».
- 의사였어요 :: Es «fui médico».
Q Cap. 25. ¿Qué significa «일하게 됐어요»?
+ Por las circunstancias, acabé trabajando. :: -게 됐어요 presenta un resultado o cambio de situación.
- Trabajo todos los días. :: Eso sería 매일 일해요.
- Trabajé ayer. :: Eso sería 어제 일했어요.
Q Cap. 26. ¿Qué significa «약을 먹지 않으면 안 돼요»?
+ Hay que tomar la medicina sí o sí. :: 먹지 않으면 안 돼요 = hay que tomarla sí o sí.
- Puedes dejar la medicina. :: Eso sería 약을 안 먹어도 돼요.
- Tomé la medicina ayer. :: Eso sería 어제 약을 먹었어요.
H Cap. 26. 버스가 없어서 ___. :: no queda más remedio que ir andando
+ 걸어갈 수밖에 없어요 :: 걸어가다 → 걸어갈 수밖에 없어요.
- 걸어가요 :: Es «voy andando», sin remedio.
- 걸어가면 돼요 :: Es «basta con ir andando».
Q Cap. 26. ¿Qué significa «다시 올 필요가 없어요»?
+ No hace falta volver. :: 필요가 없어요 = no hace falta.
- Hay que volver. :: Eso sería 다시 와야 해요.
- Volverá mañana. :: Eso sería 내일 올 거예요.
H Cap. 27. 아기에게 옷을 ___. :: le visto
+ 입혀 줄게요 :: 입다 → 입혀 줄게요.
- 입어요 :: Es «me pongo», sin causar.
- 입었어요 :: Es «me puse», pasado.
Q Cap. 27. ¿Qué significa «우유를 먹이세요»?
+ Dé leche (a alguien). :: 먹이세요 = dé de comer.
- Beba leche. :: Eso sería 우유를 드세요.
- Compre leche. :: Eso sería 우유를 사세요.
Q Cap. 28. ¿Qué significa «공부할수록 재미있어요»?
+ Cuanto más estudio, más divertido es. :: 공부할수록 = cuanto más estudio.
- Estudio y me divierto ahora. :: Eso sería 공부하고 재미있어요.
- Estudié y me divertí. :: Eso sería 공부했고 재미있었어요.
H Cap. 28. 시험에 ___ 노력해요. :: para aprobar
+ 합격하기 위해서 :: 합격하다 → 합격하기 위해서.
- 합격해요 :: Es «apruebo», sin finalidad.
- 합격했어요 :: Es «aprobé», pasado.
Q Cap. 29. ¿Qué significa «피곤한가 봐요»?
+ Parece que está cansado. :: 피곤한가 봐요 = parece que está cansado.
- Está cansado de verdad. :: Eso sería 정말 피곤해요.
- Estaba cansado. :: Eso sería 피곤했어요.
Q Cap. 30. ¿Qué significa «비가 왔는데도 나갔어요»?
+ Salió aunque llovió. :: 왔는데도 = aunque llovió.
- Salió porque llovió. :: Eso sería 비가 와서 나갔어요.
- No salió porque llovió. :: Eso sería 비가 와서 안 나갔어요.
H Cap. 30. 지갑을 ___. :: la perdí
+ 잃어버렸어요 :: 잃어버리다 → 잃어버렸어요.
- 잃었어요 :: También puede significar «perdí»; el contexto distingue el matiz.
- 잃을 거예요 :: Es «perderé», futuro.
