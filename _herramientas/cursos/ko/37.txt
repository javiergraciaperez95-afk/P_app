@ 37 | 가든지 말든지 | Lo que sea, o si: -든(지)
E Dos opciones, da igual :: Para decir que da igual una cosa u otra, o que algo es así sea como sea, se usa **-든(지)**: 가다 → **가든지 오든지** (que vaya o que venga), 먹다 → **먹든지 말든지** (que coma o no). :: 가**든지** 말**든지** 상관없어요 = da igual si vamos o no.
E Con palabras interrogativas :: Con **무엇, 언제, 누구, 어디** se usa **-(이)든지**, que significa «lo que sea», «cuando sea», «quien sea»: 무엇**이든지** = lo que sea, 언제**든지** = cuando sea. :: 언제**든지** 말해 주세요 = dígame cuando sea.
B Palabra | Con -든(지) | Español
| 가다 / 오다 | 가든지 오든지 | que vaya o que venga
| 먹다 | 먹든지 말든지 | que coma o no
| 무엇 | 무엇이든지 | lo que sea
| 언제 | 언제든지 | cuando sea
W 가든지 말든지 = vaya o no, da igual
W 가든지 오든지 상관없어요 = da igual si va o viene
W 가든지 오든지 = que vaya o que venga
W 먹든지 말든지 = que coma o no
W 무엇이든지 = lo que sea
W 언제든지 = cuando sea
W 마음대로 = como quiera, a su gusto
W 상관없어요 = no importa, da igual
W 정할게요 = decidiré
W 점심 = almuerzo
V Vocabulario: lo que sea
D Qué comemos
안나: 점심은 뭘 먹을까요? = ¿Qué comemos?
  > 점심은 = el almuerzo | 뭘 = qué | 먹을까요 = ¿comemos?
민수: 무엇이든지 좋아요. = Lo que sea me parece bien.
  > 무엇이든지 = lo que sea | 좋아요 = está bien
안나: 그럼 가든지 말든지 상관없어요? = Entonces, ¿da igual si vamos o no?
  > 가든지 말든지 = si vamos o no | 상관없어요 = no importa
민수: 네, 언제든지 괜찮아요. = Sí, cuando sea está bien.
  > 언제든지 = cuando sea | 괜찮아요 = está bien
Q ¿Qué significa «무엇이든지 좋아요»?
+ Lo que sea me parece bien. :: 무엇이든지 = lo que sea.
- Me gusta algo concreto. :: Eso sería 특별히 좋아하는 것이 있어요.
- No me gusta nada. :: Eso sería 아무것도 안 좋아요.
H ___ 오든지 상관없어요. :: vaya o que venga
+ 가든지 :: 가든지 = que vaya.
- 면 :: Es «si».
- 니까 :: Es «porque».
R 언제든지 말해 주세요.
+ Dígame cuando sea. :: 언제든지 = cuando sea.
- Dígame ahora mismo. :: Eso sería 지금 말해 주세요.
- Dígame si no puede. :: Eso sería 못 하면 말해 주세요.
A 가든지 말든지 상관없어요. :: ¿Qué dice la persona?
+ Da igual que vayamos o no. :: 가든지 말든지 = que vayamos o no.
- Hay que ir sí o sí. :: Eso sería 가야 해요.
- Vamos a ir. :: Eso sería 갈 거예요.
O 무엇이든지 괜찮아요 :: Lo que sea está bien :: 무엇이든지 = lo que sea. 괜찮아요 = está bien.
Q ¿Cómo dices «cuando sea» (언제)?
+ 언제든지 :: 언제 → 언제든지.
- 언제 :: Es «cuándo», pregunta.
- 언제나 :: Es «siempre».
Q ¿Qué significa «마음대로»?
+ Como uno quiera. :: 마음대로 = a su gusto.
- Como el jefe quiera. :: Eso sería 사장님 마음대로.
- De forma tranquila. :: Eso sería 조용히.
@ 37 | 바로 그 사람이야말로 | Precisamente: N(이)야말로 y 여간 ~지 않다
E Lo que resalta :: Para destacar algo y decir «precisamente…» o «justo…», se usa **N(이)야말로**: 지금**이야말로** 기회예요 = ahora precisamente es la oportunidad. 너**야말로** 내 친구야 = tú precisamente eres mi amigo.
E Intensificar con una negación :: **여간 A-(으)ㄴ 것이 아니다 / V-는 것이 아니다** y **여간 A/V-지 않다** expresan que algo no es de poca intensidad: **여간 힘들지 않아요** = es muy duro; **여간 힘든 일이 아니에요** = es un trabajo tremendamente duro. :: Es una expresión enfática, frecuente en registros cuidados; no se debe interpretar como una negación literal de «difícil».
B Expresión | Forma | Español
| N(이)야말로 | 지금이야말로 | ahora precisamente
| N(이)야말로 | 너야말로 | tú precisamente
| 여간 ~지 않다 | 여간 힘들지 않아요 | es muy duro
| 여간 ~(으)ㄴ/는 것이 아니다 | 여간 힘든 일이 아니에요 | no es poca cosa
W 지금이야말로 = ahora precisamente
W 너야말로 = tú precisamente
W 기회 = oportunidad
W 여간 힘들지 않아요 = es muy duro
W 여간 힘든 일이 아니에요 = no es poca cosa, es muy duro
W 열심히 해요 = lo hacemos con esfuerzo
W 힘든 = duro, difícil
V Vocabulario: precisamente
D Un trabajo duro
민수: 이 일은 여간 힘든 일이 아니에요. = Este trabajo no es nada fácil.
  > 이 일은 = este trabajo | 여간 힘든 일이 아니에요 = no es poca cosa
안나: 맞아요. 그래도 지금이야말로 기회예요. = Es verdad. Aun así, ahora precisamente es la oportunidad.
  > 그래도 = aun así | 지금이야말로 = ahora precisamente | 기회예요 = es la oportunidad
민수: 그래요. 같이 열심히 해요. = Sí. Hagámoslo juntos con esfuerzo.
  > 같이 = juntos | 열심히 해요 = lo hacemos con esfuerzo
Q ¿Qué significa «지금이야말로 기회예요»?
+ Ahora precisamente es la oportunidad. :: 지금이야말로 = ahora precisamente.
- Ahora no es la oportunidad. :: Eso no lo dice la frase.
- La oportunidad fue ayer. :: Eso sería 기회는 어제였어요.
H ___ 기회예요. :: precisamente ahora
+ 지금이야말로 :: 지금이야말로 = ahora precisamente.
- 지금은 :: Es «ahora», sin énfasis.
- 지금까지 :: Es «hasta ahora».
R 여간 힘들지 않아요.
+ Es muy duro. :: 여간 힘들지 않아요 = es muy duro.
- No es duro en absoluto. :: Eso sería 전혀 힘들지 않아요.
- Es un poco duro. :: Eso sería 조금 힘들어요.
A 여간 힘든 일이 아니에요. :: ¿Qué dice la persona?
+ El trabajo es muy duro. :: 여간 힘든 일이 아니에요 = no es poca cosa.
- El trabajo es fácil. :: Eso sería 쉬운 일이에요.
- El trabajo ya acabó. :: Eso sería 일이 끝났어요.
O 너야말로 제 친구예요 :: Tú precisamente eres mi amigo :: 너야말로 = tú precisamente. 제 친구예요 = es mi amigo.
Q ¿Cómo dices «tú precisamente»?
+ 너야말로 :: 너 + 야말로.
- 너 :: Es «tú», sin énfasis.
- 너한테 :: Es «a ti».
Q ¿Qué significa «기회»?
+ Oportunidad. :: 기회 = la ocasión que se presenta.
- Peligro. :: Eso sería 위험.
- Problema. :: Eso sería 문제.
@ 37 | 힘들더라도 | Aunque: -더라도 y -(으)ㄴ 채(로)
E Aunque sea así :: Para decir «aunque sea…» o «aunque pase…», se usa **-더라도**: 힘들**더라도** 끝까지 할 거예요 = aunque sea duro, lo haré hasta el final. 비가 오**더라도** 가요 = aunque llueva, vamos.
E Dejando algo así :: **-(으)ㄴ 채(로)** dice que algo se queda en ese estado: 문을 연 **채로** 나갔어요 = salió dejando la puerta abierta. 옷을 입은 **채로** 잤어요 = dormí con la ropa puesta.
B Palabra | Forma | Español
| 힘들다 | 힘들더라도 | aunque sea duro
| 비가 오다 | 비가 오더라도 | aunque llueva
| 열다 | 연 채로 | dejando abierto
| 입다 | 입은 채로 | con la ropa puesta
W 힘들더라도 = aunque sea duro
W 비가 오더라도 = aunque llueva
W 연 채로 = dejando abierto
W 입은 채로 = con la ropa puesta
W 나가지 마세요 = no salga
W 문을 연 채로 = dejando la puerta abierta
W 알겠어요 = de acuerdo, entendido
V Vocabulario: aunque
D Un viaje con lluvia
안나: 내일 비가 오더라도 여행을 갈 거예요? = Aunque llueva mañana, ¿vas a ir de viaje?
  > 내일 = mañana | 비가 오더라도 = aunque llueva | 여행을 갈 거예요 = vas a ir de viaje
민수: 네, 비가 오더라도 가요. = Sí, aunque llueva, iremos.
  > 비가 오더라도 = aunque llueva | 가요 = iremos
안나: 문을 연 채로 나가지 마세요. = No salga dejando la puerta abierta.
  > 문을 연 채로 = dejando la puerta abierta | 나가지 마세요 = no salga
민수: 알겠어요. = De acuerdo.
  > 알겠어요 = de acuerdo
Q ¿Qué significa «힘들더라도 끝까지 할 거예요»?
+ Aunque sea duro, lo haré hasta el final. :: 힘들더라도 = aunque sea duro.
- Es duro, así que lo haré. :: Eso sería 힘들어서 할 거예요.
- Es duro y no lo haré. :: Eso sería 힘들어서 안 할 거예요.
H ___ 끝까지 할 거예요. :: aunque sea duro
+ 힘들더라도 :: 힘들더라도 = aunque sea duro.
- 힘들어서 :: Es «porque es duro».
- 힘들면 :: Es «si es duro».
R 문을 연 채로 나갔어요.
+ Salió dejando la puerta abierta. :: 연 채로 = dejando abierto.
- Abrió la puerta y salió. :: Eso sería 문을 열고 나갔어요.
- Cerró la puerta y salió. :: Eso sería 문을 닫고 나갔어요.
A 옷을 입은 채로 잤어요. :: ¿Qué hizo la persona?
+ Durmió con la ropa puesta. :: 입은 채로 = con la ropa puesta.
- Durmió sin ropa. :: Eso sería 옷을 벗고 잤어요.
- No durmió. :: Eso sería 안 잤어요.
O 비가 오더라도 가요 :: Aunque llueva, vamos :: 비가 오더라도 = aunque llueva. 가요 = vamos.
Q ¿Cómo dices «aunque sea duro» (힘들다)?
+ 힘들더라도 :: 힘들다 → 힘들더라도.
- 힘들어요 :: Es «es duro», sin aunque.
- 힘들었어요 :: Es «fue duro», pasado.
Q ¿Qué significa «알겠어요»?
+ De acuerdo, entendido. :: 알겠어요 confirma que entendió.
- No entiendo. :: Eso sería 모르겠어요.
- Lo sabía. :: Eso sería 알았어요.
