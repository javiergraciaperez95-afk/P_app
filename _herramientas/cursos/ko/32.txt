@ 32 | 이사한다면서요 | Lo que me dijeron: -다면서(요)
E Confirmar lo que oíste :: Para confirmar algo que has oído, como «¿no dijiste que…?», se usa **-다면서(요)**: 가다 → **간다면서요** (¿no dijiste que vas?), 이사하다 → **이사한다면서요** (¿no dijiste que te mudas?), 좋다 → **좋다면서요** (¿no era bueno?), 학생이다 → **학생이라면서요** (¿no eras estudiante?). :: 민수 씨, 이사**한다면서요**? = Minsu, ¿no dijiste que te mudas?
E Pasado :: Para algo que ya pasó se usa **-았/었다면서요**: 갔다면서요 (¿no dijiste que fuiste?). :: Es una manera de comprobar algo que te contaron.
B Palabra | Con -다면서(요) | Español
| 가다 | 간다면서요 | ¿no dijiste que vas?
| 이사하다 | 이사한다면서요 | ¿no dijiste que te mudas?
| 좋다 | 좋다면서요 | ¿no era bueno?
| 학생이다 | 학생이라면서요 | ¿no eras estudiante?
W 간다면서요 = ¿no dijiste que vas?
W 이사한다면서요 = ¿no dijiste que te mudas?
W 좋다면서요 = ¿no era bueno?
W 학생이라면서요 = ¿no eras estudiante?
W 갔다면서요 = ¿no dijiste que fuiste?
W 이사해요 = me mudo
W 다음 달 = el mes que viene
W 달 = mes
W 넓다면서요 = ¿no era grande?
W 좁아요 = es pequeño, es estrecho
V Vocabulario: lo que me dijeron
D La mudanza
안나: 민수 씨, 이사한다면서요? = Minsu, ¿no dijiste que te mudas?
  > 이사한다면서요 = ¿no dijiste que te mudas?
민수: 네, 다음 달에 이사해요. = Sí, me mudo el mes que viene.
  > 다음 달에 = el mes que viene | 이사해요 = me mudo
안나: 그럼 집이 넓다면서요? = Entonces la casa era grande, ¿no?
  > 집이 = la casa | 넓다면서요 = ¿no dijiste que era grande?
민수: 아니요, 조금 좁아요. = No, es un poco pequeña.
  > 조금 = un poco | 좁아요 = es pequeña
Q ¿Qué significa «이사한다면서요?»?
+ ¿No dijiste que te mudas? :: 이사한다면서요 = ¿no dijiste que te mudas?
- ¿Te mudaste ya? :: Eso sería 이사했어요?
- ¿Dónde te mudas? :: Eso sería 어디로 이사해요?
H 그럼 ___? :: ¿no eras estudiante?
+ 학생이라면서요 :: 학생이라면서요 = ¿no eras estudiante?
- 학생이에요 :: Es «eres estudiante», sin confirmar.
- 학생이지만 :: Es «eres estudiante, pero».
R 집이 넓다면서요?
+ ¿No dijiste que la casa era grande? :: 넓다면서요 = ¿no dijiste que era grande?
- La casa es muy grande. :: Eso sería 집이 아주 넓어요.
- La casa es muy pequeña. :: Eso sería 집이 아주 작아요.
A 다음 달에 이사해요. :: ¿Cuándo se muda la persona?
+ El mes que viene. :: 다음 달에 = el mes que viene.
- Ayer. :: Eso sería 어제.
- Hoy. :: Eso sería 오늘.
O 다음 달에 이사해요 :: Me mudo el mes que viene :: 다음 달에 = el mes que viene. 이사해요 = me mudo.
Q ¿Cómo dices «¿no dijiste que vas?» (가다)?
+ 간다면서요 :: 가다 → 간다면서요.
- 가요 :: Es «voy», sin confirmar.
- 갔어요 :: Es «fui», pasado.
H 조금 ___. :: es pequeña
+ 좁아요 :: 좁다 → 좁아요: es estrecho/pequeño.
- 넓어요 :: Es «es grande».
- 넓었어요 :: Es «era grande», pasado.
Q ¿Qué significa «들었어요»?
+ Escuché, oí. :: 들었어요 es el pasado de 듣다.
- Escucho. :: Eso sería 들어요.
- Escucharé. :: Eso sería 들을 거예요.
@ 32 | 하다 보면 | Si sigues haciéndolo: -다 보면
E Con el tiempo :: Para decir que, si sigues haciendo algo, acabarás consiguiendo algo, se usa **-다 보면**: 공부하다 → **공부하다 보면** (si estudias, con el tiempo), 가다 → **가다 보면** (si sigues andando, verás), 연습하다 → **연습하다 보면** (si practicas). :: 매일 공부**하다 보면** 늘어요 = si estudias todos los días, mejoras.
E Diferencia con -다 보니(까) :: **-다 보면** habla de algo que pasará si sigues; **-다 보니(까)** habla de algo que ya pasó sin que lo notaras (B2 posterior). :: 천천히 **하다 보면** 익숙해져요 = si lo haces despacio, te acostumbras.
B Verbo | Con -다 보면 | Español
| 공부하다 | 공부하다 보면 | si estudias, con el tiempo
| 가다 | 가다 보면 | si sigues andando, verás
| 연습하다 | 연습하다 보면 | si practicas
| 하다 | 하다 보면 | si lo haces, con el tiempo
W 공부하다 보면 = si estudias, con el tiempo
W 가다 보면 = si sigues andando, verás
W 연습하다 보면 = si practicas, con el tiempo
W 하다 보면 = si lo sigues haciendo
W 익숙해져요 = te acostumbras, te haces a ello
W 나와요 = sale, aparece
W 잘 안 들려요 = no se oye bien, no se entiende bien
W 천천히 하다 보면 = si lo haces despacio
W 한국어 = coreano
V Vocabulario: con el tiempo
D Que se hace entendible
안나: 한국어가 너무 어려워요. = El coreano es muy difícil.
  > 한국어가 = el coreano | 너무 = demasiado | 어려워요 = es difícil
민수: 괜찮아요. 매일 공부하다 보면 익숙해져요. = No pasa nada. Si estudias todos los días, te acostumbras.
  > 매일 = todos los días | 공부하다 보면 = si estudias | 익숙해져요 = te acostumbras
안나: 그래요? 지금은 잘 안 들려요. = ¿Sí? Ahora no se oye bien.
  > 지금은 = ahora | 잘 안 들려요 = no se oye bien
민수: 천천히 하다 보면 들려요. = Si lo haces despacio, se oirá.
  > 천천히 하다 보면 = si lo haces despacio | 들려요 = se oye
Q ¿Qué significa «공부하다 보면 늘어요»?
+ Si estudias, con el tiempo mejoras. :: 하다 보면 = si sigues haciéndolo.
- Estudiaste y mejoraste. :: Eso sería 공부했고 늘었어요.
- Estudias y no mejoras. :: Eso sería 공부하지만 안 늘어요.
H 매일 ___ 익숙해져요. :: si practicas
+ 연습하다 보면 :: 연습하다 보면 = si practicas.
- 연습하면 :: Es «si practicas», sin seguir.
- 연습하니까 :: Es «porque practicas».
R 가다 보면 나와요.
+ Si sigues andando, verás la salida. :: 가다 보면 = si sigues andando.
- Fui y salí. :: Eso sería 가서 나왔어요.
- Ando y no sale. :: Eso no lo dice la frase.
A 천천히 하다 보면 익숙해져요. :: ¿Qué dice la persona?
+ Si lo haces despacio, te acostumbras. :: 하다 보면 = si lo sigues haciendo.
- Si lo haces rápido, te acostumbras. :: Eso sería 빨리 하다 보면.
- Lo hiciste y te acostumbraste. :: Eso sería 했고 익숙해졌어요.
O 매일 공부하다 보면 늘어요 :: Si estudias todos los días, mejoras :: 매일 = todos los días. 늘어요 = mejoras.
Q ¿Cómo dices «si practicas» (연습하다)?
+ 연습하다 보면 :: 연습하다 → 연습하다 보면.
- 연습하고 있어요 :: Es «estoy practicando».
- 연습했어요 :: Es «practiqué».
H 천천히 ___ 들려요. :: si lo haces
+ 하다 보면 :: 천천히 하다 보면 = si lo haces despacio.
- 하다 보니까 :: Es «al resultar».
- 하면 :: Es «si», sin seguir.
Q ¿Qué significa «익숙해져요»?
+ Te acostumbras. :: 익숙해져요 = te acostumbras.
- Te cansas. :: Eso sería 피곤해져요.
- Te sientes triste. :: Eso sería 슬퍼져요.
@ 32 | 늦은 것이에요 | Lo que pasa es que: -는 것이다
E Explicar la causa :: Para explicar lo que pasa o la razón de algo se usa **-는 것이다** (lo que pasa es que…): 가다 → **가는 것이다**, 늦다 → **늦은 것이다** (lo que pasa es que llegó tarde), 좋다 → **좋은 것이다**. :: 제가 늦은 것은 버스 때문이에요 = lo que pasa es que llegué tarde por el autobús.
E Con 문제는 o 이유는 :: Se usa mucho con **문제는** (el problema es que) o **이유는** (la razón es que). :: 문제는 비가 온 것이에요 = el problema es que llovió.
B Palabra | Con -는 것이다 | Español
| 늦다 | 늦은 것이에요 | lo que pasa es que llegó tarde
| 비가 오다 | 비가 온 것이에요 | lo que pasó es que llovió
| 좋다 | 좋은 것이에요 | lo bueno es que
| 먹다 | 먹는 것이에요 | lo que pasa es que come
W 문제는 = el problema es que
W 이유는 = la razón es que
W 늦은 것이에요 = lo que pasa es que llegó tarde
W 비가 온 것이에요 = lo que pasó es que llovió
W 좋은 것은 = lo bueno es que
W 나오세요 = salga, por favor
W 버스 때문이에요 = es por el autobús
W 그래요? = ¿así es?
W 그럴게요 = lo haré
W 늦은 = que llegó tarde
W 있다는 = que hay
V Vocabulario: lo que pasa es que
D Llegar tarde
민수: 오늘 왜 늦었어요? = ¿Por qué llegaste tarde hoy?
  > 오늘 = hoy | 왜 = por qué | 늦었어요 = llegaste tarde
안나: 문제는 버스가 늦은 것이에요. = El problema es que el autobús llegó tarde.
  > 문제는 = el problema es | 버스가 늦은 것이에요 = que el autobús llegó tarde
민수: 그래요? 다음에는 일찍 나오세요. = ¿Así es? La próxima vez, salga temprano.
  > 그래요 = ¿así es? | 일찍 나오세요 = salga temprano
안나: 네, 그럴게요. = Sí, lo haré.
  > 그럴게요 = lo haré
Q ¿Qué significa «문제는 버스가 늦은 것이에요»?
+ El problema es que el autobús llegó tarde. :: 늦은 것이에요 = que llegó tarde.
- El autobús llega tarde siempre. :: Eso sería 버스는 항상 늦어요.
- El autobús llegó temprano. :: Eso sería 버스가 일찍 왔어요.
H 제가 늦은 ___ 버스 때문이에요. :: lo que pasa es que
+ 것은 :: 늦은 것은 = lo que pasa es llegar tarde.
- 곳은 :: Es «el lugar».
- 일은 :: Es «el trabajo».
R 이유는 비가 온 것이에요.
+ La razón es que llovió. :: 이유는 = la razón. 온 것이에요 = es que llovió.
- La razón es el dinero. :: Eso sería 이유는 돈이에요.
- Lloverá mañana. :: Eso sería 내일 비가 올 거예요.
A 문제는 버스가 늦은 것이에요. :: ¿Qué explica la persona?
+ El problema es el autobús. :: 늦은 것이에요 = que llegó tarde.
- El problema es el tiempo. :: Eso sería 문제는 날씨예요.
- No hay problema. :: Eso sería 문제가 없어요.
O 좋은 것은 시간이 있다는 것이에요 :: Lo bueno es que hay tiempo :: 좋은 것은 = lo bueno es. 시간이 있다는 것이에요 = que hay tiempo.
Q ¿Cómo dices «lo que pasa es que llegó tarde» (늦다)?
+ 늦은 것이에요 :: 늦다 → 늦은 것이에요.
- 늦어요 :: Es «llega tarde», presente.
- 늦었어요 :: Es «llegó tarde», sin explicar.
H 이유는 날씨가 ___. :: la razón es que es bueno
+ 좋은 것이에요 :: 좋다 → 좋은 것이에요.
- 좋아요 :: Es «es bueno».
- 좋았어요 :: Es «era bueno».
Q ¿Qué significa «이유는»?
+ La razón es. :: 이유는 introduce una explicación.
- La solución es. :: Eso sería 해결 방법은.
- El resultado es. :: Eso sería 결과는.
