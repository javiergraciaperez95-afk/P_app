@ 14 | 큰 집 | Describir con adjetivos delante del nombre
E Adjetivo delante del nombre :: Para describir un nombre con un adjetivo se usa **-(으)ㄴ** entre el adjetivo y el nombre: 크다 → **큰 집** (casa grande), 작다 → **작은 방** (habitación pequeña), 좋다 → **좋은 사람** (buena persona). :: Si la raíz acaba en vocal se añade **ㄴ**; si acaba en consonante, **은**.
E Cuidado con la ㅡ y la ㄹ :: Con verbos o adjetivos que acaban en ㅡ se quita la ㅡ: 예쁘다 → **예쁜 옷**, 크다 → **큰 집**. Con los que acaban en ㄹ se quita la ㄹ: 길다 → **긴 머리** (pelo largo). :: Ya conoces el uso sin nombre (집이 커요). Aquí va siempre pegado al nombre.
B Adjetivo | Raíz | Delante del nombre | Español
| 크다 | 크 | 큰 집 | casa grande
| 작다 | 작 | 작은 방 | habitación pequeña
| 좋다 | 좋 | 좋은 사람 | buena persona
| 예쁘다 | 예쁘 | 예쁜 옷 | ropa bonita
| 길다 | 길 | 긴 머리 | pelo largo
W 큰 = grande
W 작은 = pequeño, pequeña
W 좋은 = bueno, buena
W 예쁜 = bonito, bonita
W 비싼 = caro, cara
W 새 = nuevo, nueva
W 친절한 = amable
W 사람들 = personas, gente
W 긴 = largo, larga
W 짧은 = corto, corta
W 재미있는 = divertido, divertida
V Vocabulario: describir con adjetivos
D Dónde vive Minsu
안나: 민수 씨, 큰 집에 살아요? = Minsu, ¿vives en una casa grande?
  > 큰 집에 = en una casa grande | 살아요 = vives
민수: 아니요, 작은 집에 살아요. = No, vivo en una casa pequeña.
  > 작은 집에 = en una casa pequeña | 살아요 = vivo
안나: 그래요? 좋은 동네예요? = ¿Ah, sí? ¿Es un buen barrio?
  > 좋은 동네예요 = es un buen barrio
민수: 네, 친절한 사람들이 많아요. = Sí, hay muchas personas amables.
  > 친절한 사람들이 = personas amables | 많아요 = hay muchas
Q ¿Cómo se dice «casa grande»?
+ 큰 집 :: 크다 → 큰 집 (se quita la ㅡ).
- 크는 집 :: Ese verbo no se usa con adjetivos.
- 크은 집 :: Esa forma no existe.
R 예쁜 옷이에요.
+ Es una ropa bonita. :: 예쁜 = bonito, bonita.
- Es una ropa cara. :: Eso sería 비싼 옷.
- Es una ropa nueva. :: Eso sería 새 옷.
H 좋은 ___. :: persona
+ 사람 :: 좋은 사람 = buena persona.
- 사람이 :: Lleva sujeto; no encaja.
- 좋아요 :: Es «está bien», no un nombre.
A 작은 집에 살아요. :: ¿Dónde vive la persona?
+ En una casa pequeña. :: 작은 집 = casa pequeña.
- En una casa grande. :: Eso sería 큰 집.
- En un barrio bonito. :: No dice eso la frase.
O 친절한 사람이에요 :: Es una persona amable :: 친절한 = amable. 사람이에요 = es una persona.
Q ¿Qué significa «긴 머리»?
+ Pelo largo. :: 긴 = largo. 머리 = pelo, cabeza.
- Pelo corto. :: Eso sería 짧은 머리.
- Cabeza grande. :: Eso sería 큰 머리.
H 짧은 ___. :: pelo
+ 머리 :: 짧은 머리 = pelo corto.
- 머리가 :: Lleva sujeto; no encaja.
- 짧아요 :: Es «es corto», sin nombre.
Q ¿Qué significa «재미있는 영화»?
+ Película divertida. :: 재미있는 = divertido, delante del nombre.
- Película nueva. :: Eso sería 새 영화.
- Película cara. :: Eso sería 비싼 영화.
@ 14 | 먹는 음식 | La comida que se come: verbo delante del nombre
E Verbo delante del nombre :: Para describir un nombre con lo que se hace de forma habitual se usa **-는** entre el verbo y el nombre: 먹다 → **먹는 음식** (la comida que se come), 보다 → **보는 영화** (la película que se ve), 하다 → **하는 일** (el trabajo que se hace). :: 좋아하는 음식 = la comida que te gusta.
E Forma :: Se quita 다 y se añade **-는**. Si la raíz acaba en ㄹ, se quita la ㄹ: 살다 → **사는 집** (la casa en que se vive), 만들다 → **만드는 요리** (el plato que se cocina). :: Con adjetivos esta forma no sirve; para eso están las lecciones anteriores.
B Verbo | Raíz | Delante del nombre | Español
| 먹다 | 먹 | 먹는 음식 | la comida que se come
| 보다 | 보 | 보는 영화 | la película que se ve
| 하다 | 하 | 하는 일 | el trabajo que se hace
| 살다 | 살 | 사는 집 | la casa en que se vive
W 먹는 음식 = la comida que se come
W 좋아하는 음식 = la comida que te gusta, la comida favorita
W 보는 영화 = la película que se ve
W 하는 일 = el trabajo, lo que se hace
W 사는 집 = la casa en que se vive
W 가는 식당 = el restaurante al que se va
W 만드는 요리 = el plato que se cocina
W 제가 = yo (como sujeto, en tono formal)
W 좋아하는 = que te gusta, que me gusta, favorito
W 먹는 = que se come
W 가는 = que va, al que se va
W 하는 = que se hace
V Vocabulario: lo que se hace
D La comida favorita
안나: 민수 씨가 좋아하는 음식이 뭐예요? = ¿Cuál es la comida que más te gusta?
  > 좋아하는 음식 = la comida que te gusta | 뭐예요 = ¿cuál es?
민수: 제가 좋아하는 음식은 김치찌개예요. = La comida que más me gusta es el kimchi jjigae.
  > 제가 = yo | 좋아하는 음식은 = la comida que me gusta | 김치찌개예요 = es kimchi jjigae
안나: 아, 저도 좋아해요. 자주 먹어요? = Ah, a mí también me gusta. ¿La como a menudo?
  > 좋아해요 = me gusta | 자주 = a menudo | 먹어요 = como
민수: 네. 지금 가는 식당에서도 먹어요. = Sí. También la como en el restaurante al que vamos ahora.
  > 가는 식당에서도 = también en el restaurante al que vamos | 먹어요 = la como
안나: 좋아요! 빨리 가요. = ¡Genial! Vamos rápido.
  > 빨리 가요 = vamos rápido
Q ¿Qué significa «보는 영화»?
+ La película que se ve. :: 보는 = que se ve (presente, delante del nombre).
- La película que vi. :: Eso sería 본 영화.
- La película que vamos a ver. :: Eso sería 볼 영화.
R 먹는 음식이 뭐예요?
+ ¿Cuál es la comida que se come? :: 먹는 음식 = la comida que se come.
- ¿Qué comiste? :: Eso sería 뭘 먹었어요?
- ¿Qué vas a comer? :: Eso sería 뭘 먹을 거예요?
H 사는 ___. :: casa
+ 집 :: 사는 집 = la casa en que se vive.
- 집에 :: Es «en casa», no un nombre.
- 살아요 :: Es «vives», sin nombre.
A 제가 좋아하는 음식은 김치찌개예요. :: ¿Qué dice la persona?
+ La comida que más me gusta es el kimchi jjigae. :: 좋아하는 음식 = la comida favorita.
- Me gusta cocinar el kimchi jjigae. :: Eso sería 요리를 좋아해요.
- Me gusta comprar kimchi. :: No dice eso la frase.
O 하는 일이 재미있어요 :: El trabajo que hago es divertido :: 하는 일 = el trabajo que hago. 재미있어요 = es divertido.
Q ¿Cómo se dice «la casa en que se vive»?
+ 사는 집 :: 살다 pierde la ㄹ: 사는 집.
- 살는 집 :: Esa forma no existe.
- 사는 집에 :: Lleva partícula de lugar; no es el nombre solo.
H 제가 만드는 ___. :: plato
+ 요리 :: 만드는 요리 = el plato que cocino.
- 요리를 :: Lleva partícula; no encaja aquí.
- 요리해요 :: Es «cocino», sin nombre.
R 지금 가는 식당이 좋아요.
+ El restaurante al que vamos ahora es bueno. :: 가는 식당 = el restaurante al que vamos.
- El restaurante donde comimos es bueno. :: Eso sería 먹은 식당.
- El restaurante es grande. :: Eso sería 큰 식당.
Q ¿Cuál es la forma de «que se hace» de 하다?
+ 하는 :: 하다 → 하는.
- 한 :: Es el pasado: «hecho».
- 해요 :: Es «hago».
@ 14 | 어제 본 영화 | La película que vi: pasado delante del nombre
E Pasado delante del nombre :: Para describir un nombre con algo que ya pasó se usa **-(으)ㄴ** antes del nombre: 보다 → **본 영화** (la película que vi), 먹다 → **먹은 음식** (la comida que comí), 만나다 → **만난 친구** (el amigo que conocí). :: 어제 **본** 영화 = la película que vi ayer.
E Forma :: Con verbos que acaban en vocal se añade **ㄴ**; con consonante, **은**. 가다 → **간** (el sitio al que fui), 먹다 → **먹은**, 사다 → **산** (lo que compré). :: No se usa 봤어요 ni 먹었어요 delante del nombre: se usa 본 y 먹은.
B Verbo | Raíz | Delante del nombre | Español
| 보다 | 보 | 본 영화 | la película que vi
| 먹다 | 먹 | 먹은 음식 | la comida que comí
| 가다 | 가 | 간 곳 | el sitio al que fui
| 만나다 | 만나 | 만난 친구 | el amigo que conocí
W 본 영화 = la película que vi
W 먹은 음식 = la comida que comí
W 간 곳 = el sitio al que fui
W 곳 = lugar, sitio
W 만난 친구 = el amigo que conocí
W 산 옷 = la ropa que compré
W 영화였어요 = era una película
W 본 = que vi, que se vio
W 간 = al que fui, al que fue
V Vocabulario: el pasado delante del nombre
D La película de ayer
안나: 어제 본 영화가 정말 재미있었어요. = La película que vi ayer fue muy divertida.
  > 어제 본 영화가 = la película que vi ayer | 재미있었어요 = fue divertida
민수: 무슨 영화였어요? = ¿Qué película era?
  > 무슨 영화였어요 = ¿qué película era?
안나: 한국 영화예요. 지난주에 간 식당도 좋았어요. = Es una película coreana. El restaurante al que fui la semana pasada también estuvo bien.
  > 지난주에 간 식당도 = también el restaurante al que fui la semana pasada | 좋았어요 = estuvo bien
민수: 그럼 다음에 같이 가요. = Entonces, vamos juntos la próxima vez.
  > 다음에 = la próxima vez | 같이 가요 = vamos juntos
Q ¿Qué significa «어제 본 영화»?
+ La película que vi ayer. :: 본 = que vi (pasado delante del nombre).
- La película que veo ayer. :: Eso no tiene pasado.
- La película que veré mañana. :: Eso sería 내일 볼 영화.
R 지난주에 간 식당
+ El restaurante al que fui la semana pasada. :: 간 = al que fui.
- El restaurante al que voy la semana que viene. :: Eso sería 가는 식당 o 갈 식당.
- El restaurante que es grande. :: Eso sería 큰 식당.
H 제가 ___ 영화예요. :: vi
+ 본 :: 보다 → 본 영화 = la película que vi.
- 보는 :: Es «que veo», presente.
- 볼 :: Es «que veré», futuro.
A 어제 본 영화가 재미있어요. :: ¿Qué dice la persona?
+ La película que vio ayer es divertida. :: 본 = que vio.
- La película que verá mañana es divertida. :: Eso sería 볼 영화.
- La película es nueva. :: Eso sería 새 영화.
O 지난주에 간 식당 :: El restaurante al que fui la semana pasada :: 지난주에 = la semana pasada. 간 = al que fui. 식당 = restaurante.
Q ¿Cómo se dice «la comida que comí» (먹다)?
+ 먹은 음식 :: 먹다 → 먹은 음식.
- 먹는 음식 :: Es «la comida que se come».
- 먹을 음식 :: Es «la comida que comeré».
Q ¿Cuál es el pasado delante del nombre de 가다?
+ 간 :: 가다 → 간 (ㅏ + ㄴ).
- 가는 :: Es presente.
- 갈 :: Es futuro.
H 산 ___ 이에요. :: ropa
+ 옷 :: 산 옷 = la ropa que compré.
- 옷이 :: Lleva sujeto; no encaja.
- 샀어요 :: Es «compré», sin nombre.
