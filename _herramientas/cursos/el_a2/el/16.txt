N Ελένη, Άννα, Κώστας, Σοφία, Νίκος, Μαρία
@ 15 | Στο κατάστημα ρούχων | En la tienda de ropa
I Pregunta por una talla o un color, pruébate una prenda y di si te queda bien.
E Tallas y probadores :: **Τι νούμερο φοράτε;** pregunta qué talla usa una persona. **Μπορώ να το δοκιμάσω;** significa «¿puedo probármelo?». :: **Σας κάνει** quiere decir «le queda bien». **Μου είναι μικρό** significa «me queda pequeño». Las terminaciones del adjetivo cambian según el sustantivo: **το παντελόνι είναι μακρύ**, **η φούστα είναι μακριά**.
W κατάστημα = tienda | katástima
W ρούχα = ropa | rúja
W νούμερο = talla, número | número
W δοκιμάζω = pruebo | dokimázo
W δοκιμάσω = probar (después de να) | dokimáso
W μακρύ = largo (neutro) | makrí
W μακριά = larga (femenino) | makriá
W σας κάνει = le queda bien | sas káni
W μου είναι μικρό = me queda pequeño | mu íne mikró
w Βεβαίως = por supuesto | vevéos
w φοράτε = usa (cortés/plural) | foráte
V Ρούχα και μεγέθη
D Στο δοκιμαστήριο
Άννα: Μπορώ να δοκιμάσω αυτό το παντελόνι; = ¿Puedo probarme este pantalón?
  > μπορώ να δοκιμάσω = puedo probar | παντελόνι = pantalón
Υπάλληλος: Βεβαίως. Τι νούμερο φοράτε; = Por supuesto. ¿Qué talla usa?
  > βεβαίως = por supuesto | τι νούμερο = qué talla | φοράτε = usa
Άννα: Το τριάντα οκτώ. Είναι λίγο μακρύ. = La treinta y ocho. Es un poco largo.
  > τριάντα οκτώ = treinta y ocho | μακρύ = largo
Q ¿Qué quiere probarse Anna?
+ Un pantalón. :: Dice «αυτό το παντελόνι».
- Una falda. :: Falda es «φούστα».
- Una chaqueta. :: Chaqueta es «σακάκι».
Q ¿Qué talla lleva Anna?
+ La 38. :: Responde «το τριάντα οκτώ».
- La 40. :: No es la talla que indica.
- La 28. :: El número es 38.
R Το παντελόνι είναι λίγο μακρύ.
+ El pantalón es un poco largo. :: «Μακρύ» concuerda con «παντελόνι».
- La falda es demasiado corta. :: Falda es «φούστα».
- El pantalón es pequeño. :: Pequeño es «μικρό».
H Μπορώ να ___ αυτή τη φούστα;
+ δοκιμάσω :: Después de «να» usamos «δοκιμάσω».
- δοκιμάζω :: Es la forma habitual «pruebo».
- νούμερο :: Significa talla.
A Τι νούμερο φοράτε;
+ ¿Qué talla usa? :: Es una pregunta cortés.
- ¿Qué color le gusta? :: Color es «χρώμα».
- ¿Dónde está la tienda? :: Tienda es «κατάστημα».
O μπορώ να δοκιμάσω αυτό το παντελόνι :: puedo probarme este pantalón :: «Δοκιμάζω» es probar.
X Escribe en griego: «ropa» :: ρούχα :: ρούχα

@ 15 | Ποιο είναι καλύτερο; | ¿Cuál es mejor?
I Compara dos productos y pregunta por la calidad, el precio o el material.
E Comparar productos :: **Ποιο είναι καλύτερο;** pregunta cuál es mejor. **Πιο φτηνό από** significa más barato que; **καλύτερο από** significa mejor que. :: Puedes preguntar **Από τι είναι φτιαγμένο;** (¿de qué está hecho?). **Βαμβάκι** es algodón y **μαλλί** es lana. Con precios, usa **κοστίζει…** o **έχει… ευρώ**.
W καλύτερος = mejor (masculino) | kalíteros
W καλύτερη = mejor (femenino) | kalíteri
W καλύτερο = mejor (neutro) | kalítero
W φτηνότερο = más barato (neutro) | ftinótero
W ποιότητα = calidad | piótita
W βαμβάκι = algodón | vamváki
W μαλλί = lana | malí
W φτιαγμένο = hecho (neutro) | ftiayméno
W υλικό = material | ilikó
W περισσότερο = más | perissótero
W ποια = cuál (femenino) | pia
W μπλούζα = blusa | blúza
W καλής = buena (genitivo femenino) | kalís
W ποιότητας = calidad (genitivo) | piótitas
W σαράντα = cuarenta | saránta
W άλλη = otra (femenino) | áli
W φτηνότερη = más barata (femenino) | ftinóteri
W συνθετικό = sintético (neutro) | sindhetikó
V Συγκρίνουμε
D Δύο μπλούζες
Νίκος: Ποια μπλούζα είναι καλύτερη; = ¿Qué blusa es mejor?
  > ποια = cuál | μπλούζα = blusa | καλύτερη = mejor
Πωλήτρια: Αυτή είναι από βαμβάκι και είναι καλής ποιότητας. = Esta es de algodón y es de buena calidad.
  > βαμβάκι = algodón | καλής ποιότητας = de buena calidad
Νίκος: Και πόσο κοστίζει; = ¿Y cuánto cuesta?
  > πόσο κοστίζει = cuánto cuesta
Πωλήτρια: Σαράντα ευρώ. Η άλλη είναι φτηνότερη, αλλά είναι από συνθετικό υλικό. = Cuarenta euros. La otra es más barata, pero es de material sintético.
  > σαράντα ευρώ = cuarenta euros | φτηνότερη = más barata | συνθετικό υλικό = material sintético
Q ¿De qué material es la primera blusa?
+ De algodón. :: El diálogo dice «από βαμβάκι».
- De lana. :: Lana es «μαλλί».
- De material sintético. :: Eso se dice de la otra.
Q ¿Por qué cuesta menos la otra blusa?
+ Es de material sintético. :: Esa diferencia aparece en la explicación.
- Es de lana. :: No se menciona lana.
- Es de peor talla. :: No se habla de la talla.
R Η άλλη μπλούζα είναι φτηνότερη.
+ La otra blusa es más barata. :: «Φτηνότερη» es comparativo femenino.
- La otra blusa es de mejor calidad. :: Eso no se dice.
- La otra blusa es de algodón. :: Algodón es «βαμβάκι».
H Αυτό το υλικό είναι ___ από μαλλί.
+ καλύτερο :: Se pregunta qué material es mejor.
- καλύτερη :: Es la forma femenina.
- καλύτερος :: Es la forma masculina.
A Αυτή είναι καλής ποιότητας.
+ Esta es de buena calidad. :: «Ποιότητα» significa calidad.
- Esta es más barata. :: Más barata es «φτηνότερη».
- Esta está hecha de lana. :: Lana es «μαλλί».
O είναι από συνθετικό υλικό :: es de material sintético :: «Υλικό» significa material.
X Escribe en griego: «algodón» :: βαμβάκι :: βαμβάκι

@ 15 | Θέλω να το αλλάξω | Quiero cambiarlo
I Explica un problema sencillo con una compra y pide cambiar o devolver el producto.
E Cambios y devoluciones :: **Θέλω να το αλλάξω** significa «quiero cambiarlo». **Έχει πρόβλημα** quiere decir que tiene un problema. :: Para preguntar si puedes devolver algo: **Μπορώ να το επιστρέψω;**. **Έχω την απόδειξη** significa «tengo el recibo»; **μου δίνετε** es una petición cortés: «¿me da…?».
W αλλάζω = cambio | allázo
W αλλάξω = cambiar (después de να) | alláxo
W επιστρέφω = devuelvo | epistréfo
W απόδειξη = recibo | apódixi
W πρόβλημα = problema | próvlima
W σκισμένο = roto (neutro) | skizméno
W άλλο = otro (neutro) | álo
W δίνετε = da (usted), dais | dínete
W συνέβη = ocurrió, pasó | sinévi
W χτες = ayer | jtes
V Στο ταμείο
D Μια αλλαγή
Σοφία: Συγγνώμη, το πουκάμισο έχει ένα πρόβλημα. = Disculpe, la camisa tiene un problema.
  > πουκάμισο = camisa | έχει ένα πρόβλημα = tiene un problema
Υπάλληλος: Τι συνέβη; = ¿Qué ha pasado?
  > τι συνέβη = qué ha pasado
Σοφία: Είναι σκισμένο από χτες. Θέλω να το αλλάξω. = Está roto desde ayer. Quiero cambiarlo.
  > σκισμένο = roto | από χτες = desde ayer | να το αλλάξω = cambiarlo
Υπάλληλος: Έχετε την απόδειξη; = ¿Tiene el recibo?
  > έχετε = tiene (cortés) | απόδειξη = recibo
Σοφία: Ναι. Μου δίνετε ένα άλλο, παρακαλώ; = Sí. ¿Me da otro, por favor?
  > μου δίνετε = me da | ένα άλλο = otro
Q ¿Qué problema tiene la camisa?
+ Está rota. :: «Σκισμένο» significa roto.
- Es demasiado pequeña. :: No se indica la talla.
- Tiene una mancha. :: No se menciona una mancha.
Q ¿Qué documento tiene Sofía?
+ El recibo. :: Responde que sí a la pregunta sobre la «απόδειξη».
- Una garantía. :: No se menciona una garantía.
- Una tarjeta. :: La conversación no menciona tarjeta.
R Θέλω να το αλλάξω.
+ Quiero cambiarlo. :: «Να το αλλάξω» significa cambiarlo.
- Quiero comprarlo. :: Comprar es «αγοράζω».
- Quiero devolver el dinero. :: Devolver dinero se expresa de otro modo.
H Έχετε την ___;
+ απόδειξη :: La dependienta pregunta por el recibo.
- πρόβλημα :: Significa problema.
- πουκάμισο :: Significa camisa.
A Μου δίνετε ένα άλλο, παρακαλώ;
+ ¿Me da otro, por favor? :: Es una petición cortés.
- ¿Me devuelve el recibo? :: No pregunta eso.
- ¿Cuánto cuesta esta camisa? :: No aparece un precio.
O θέλω να το αλλάξω :: quiero cambiarlo :: «Αλλάξω» es cambiar.
X Escribe en griego: «recibo» :: απόδειξη :: απόδειξη
