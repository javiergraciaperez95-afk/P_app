N Ελένη, Άννα, Κώστας, Σοφία, Νίκος, Μαρία
@ 13 | Η μέρα μου | Mi día
I Cuenta una rutina sencilla desde que empieza hasta que termina y usa conectores para ordenar las acciones.
E Ordenar actividades :: **Πρώτα**, **μετά**, **ύστερα** y **τέλος** significan primero, después, luego y al final. :: Para hablar de una rutina, el presente puede acompañarse de expresiones de frecuencia: **κάθε μέρα** (cada día), **συνήθως** (normalmente) y **σπάνια** (rara vez). **Ξυπνάω** es despertarse y **κοιμάμαι** es dormir.
W νωρίς = temprano | norís
W ετοιμάζομαι = me preparo | etimázome
W πρωινό = desayuno | proinó
W συνήθως = normalmente | siníthos
W πρώτα = primero | próta
W ύστερα = luego | ístera
W τέλος = al final | télos
W επιστρέφω = vuelvo | epistréfo
w ξυπνάς = te despiertas | xipnás
V Καθημερινές συνήθειες
D Πριν από τη δουλειά
Ελένη: Τι ώρα ξυπνάς συνήθως; = ¿A qué hora te despiertas normalmente?
  > τι ώρα = a qué hora | ξυπνάς = te despiertas | συνήθως = normalmente
Νίκος: Ξυπνάω νωρίς, στις επτά. = Me despierto temprano, a las siete.
  > νωρίς = temprano | στις επτά = a las siete
Ελένη: Και μετά; = ¿Y después?
  > μετά = después
Νίκος: Ετοιμάζομαι, τρώω πρωινό και επιστρέφω σπίτι το απόγευμα. = Me preparo, desayuno y vuelvo a casa por la tarde.
  > ετοιμάζομαι = me preparo | πρωινό = desayuno | το απόγευμα = por la tarde
Q ¿A qué hora se despierta Nikos?
+ A las siete, temprano. :: «Στις επτά» y «νωρίς».
- A las nueve, tarde. :: No es lo que dice.
- A las ocho, normalmente. :: La hora es siete.
Q ¿Qué hace después de prepararse?
+ Desayuna y vuelve a casa por la tarde. :: Así lo explica Nikos.
- Se acuesta y luego trabaja. :: No es la rutina descrita.
- Sale a correr por la mañana. :: No se menciona.
R Ετοιμάζομαι και τρώω πρωινό.
+ Me preparo y desayuno. :: «Τρώω πρωινό» significa desayuno.
- Me despierto y me visto. :: Despertarse es «ξυπνάω».
- Vuelvo a casa por la tarde. :: Esa frase incluye «επιστρέφω».
H Ξυπνάω ___, στις επτά.
+ νωρίς :: «Νωρίς» significa temprano.
- αργά :: Significa tarde.
- αύριο :: Significa mañana.
A Τι ώρα ξυπνάς συνήθως;
+ ¿A qué hora te despiertas normalmente? :: «Συνήθως» significa normalmente.
- ¿Cuándo vuelves a casa? :: Volver es «επιστρέφω».
- ¿Qué desayunas? :: Desayunar es «τρώω πρωινό».
O επιστρέφω σπίτι το απόγευμα :: vuelvo a casa por la tarde :: «Το απόγευμα» es por la tarde.
X Escribe en griego: «temprano» :: νωρίς :: νωρίς

@ 13 | Δουλειές του σπιτιού | Tareas de casa
I Habla de las tareas domésticas y de cómo se reparten entre las personas que viven juntas.
E Tener que hacer algo :: **Πρέπει να** + verbo expresa obligación: **Πρέπει να καθαρίσω** (tengo que limpiar). Después de **να**, el verbo suele aparecer en una forma distinta del presente habitual. :: **Μπορώ να** significa «puedo». Usa **εγώ** o **εσύ** para aclarar quién hace la tarea; a menudo se entiende por la terminación del verbo.
W δουλειές = tareas | dulies
W καθαρίζω = limpio | katharízo
W πλένω = lavo | pléno
W πιάτα = platos | piáta
W μαγειρεύω = cocino | mayirévo
W πρέπει = debo, hay que | prépi
W να = que, marcador verbal | na
W βοηθάω = ayudo | voitháo
w καθαρίσουμε = limpiemos | katharísume
w πλύνω = lavar (después de να) | plíno
w τα = los, las (artículo neutro plural) | ta
w μαγειρέψω = cocinaré; cocine | mayirépso
w βοηθήσω = ayudaré; ayude | voithíso
V Στο σπίτι
D Μοιράζουμε τις δουλειές
Κώστας: Πρέπει να καθαρίσουμε σήμερα. = Tenemos que limpiar hoy.
  > πρέπει να = tenemos que | καθαρίσουμε = limpiemos | σήμερα = hoy
Σοφία: Μπορώ να πλύνω τα πιάτα. = Puedo lavar los platos.
  > μπορώ να = puedo | πλύνω = lavar | πιάτα = platos
Κώστας: Ωραία. Εγώ θα μαγειρέψω και θα βοηθήσω. = Muy bien. Yo cocinaré y ayudaré.
  > θα μαγειρέψω = cocinaré | θα βοηθήσω = ayudaré
Q ¿Qué tarea elige Sofía?
+ Lavar los platos. :: Dice «Μπορώ να πλύνω τα πιάτα».
- Cocinar. :: Esa tarea la elige Kostas.
- Limpiar el baño. :: No se menciona el baño.
Q ¿Qué expresa «πρέπει να»?
+ Una obligación o algo necesario. :: Equivale a tener que.
- Una posibilidad futura. :: Para eso aparece «θα».
- Una acción habitual. :: No es el significado de esta expresión.
R Μπορώ να βοηθήσω σήμερα.
+ Puedo ayudar hoy. :: «Μπορώ να» significa puedo.
- Tengo que limpiar hoy. :: Eso sería «πρέπει να καθαρίσω».
- Cocino todos los días. :: Esa es una rutina.
H Πρέπει να ___ τα πιάτα.
+ πλύνω :: Después de «να» aparece esta forma verbal.
- πιάτα :: Significa platos.
- σήμερα :: Significa hoy.
A Πρέπει να καθαρίσουμε σήμερα.
+ Tenemos que limpiar hoy. :: «Πρέπει να» indica obligación.
- Podemos cocinar mañana. :: Cocinar es «μαγειρεύω».
- Ayudamos con los platos. :: Ayudar es «βοηθάω».
O μπορώ να πλύνω τα πιάτα :: puedo lavar los platos :: «Μπορώ να» expresa capacidad.
X Escribe en griego: «puedo» :: μπορώ :: μπορώ

@ 13 | Μπορείς να με βοηθήσεις; | ¿Puedes ayudarme?
I Pide ayuda para tareas de casa y responde con cortesía cuando no puedes hacer algo.
E Poder, pedir y responder :: **Μπορείς να…;** pregunta «¿puedes…?». Para una petición cortés, usa **Μπορείτε να…;**. :: Para aceptar: **Βέβαια** (claro) o **Φυσικά** (por supuesto). Para explicar que no puedes, añade **δεν**: **Δεν μπορώ τώρα** (ahora no puedo). **Λίγο αργότερα** significa un poco más tarde.
W μπορείτε = puede (usted); podéis | boríte
W βέβαια = claro, por supuesto | vévea
W φυσικά = naturalmente, por supuesto | fisiká
W αργότερα = más tarde | argótera
W σκουπίζω = barro, paso la escoba | skupízo
W σφουγγαρίζω = friego el suelo | sfungarízo
w σκουπίσεις = barras | skupísis
w πάτωμα = suelo | pátoma
w σφουγγαρίσεις = friegues el suelo | sfungarísis
w βοηθήσετε = ayude (cortés) | voithísete
V Ζητάμε βοήθεια
D Μια μικρή χάρη
Μαρία: Μπορείς να σκουπίσεις το πάτωμα; = ¿Puedes barrer el suelo?
  > μπορείς να = puedes | σκουπίσεις = barrer | πάτωμα = suelo
Άννα: Βέβαια. Και μπορείς να σφουγγαρίσεις μετά; = Claro. ¿Y puedes fregar después?
  > βέβαια = claro | σφουγγαρίσεις = fregar | μετά = después
Μαρία: Δεν μπορώ τώρα, αλλά μπορώ λίγο αργότερα. = Ahora no puedo, pero puedo un poco más tarde.
  > δεν μπορώ = no puedo | τώρα = ahora | αργότερα = más tarde
Q ¿Qué pide María al principio?
+ Que barran el suelo. :: Pregunta «Μπορείς να σκουπίσεις το πάτωμα;».
- Que frieguen los platos. :: No se menciona fregar platos.
- Que cocinen juntos. :: Cocinar no aparece.
Q ¿Cuándo puede ayudar María?
+ Un poco más tarde. :: Dice «λίγο αργότερα».
- Ahora mismo. :: Dice que ahora no puede.
- Mañana por la mañana. :: No da esa hora.
R Δεν μπορώ τώρα.
+ Ahora no puedo. :: «Δεν» niega «μπορώ».
- No quiero hacerlo mañana. :: No se menciona querer ni mañana.
- Puedo hacerlo ahora. :: Es lo contrario.
H Μπορείς να ___ το πάτωμα;
+ σκουπίσεις :: La petición es barrer el suelo.
- σκουπίζω :: Es «yo barro» en presente habitual.
- μαζί :: Significa juntos.
A Μπορείτε να βοηθήσετε;
+ ¿Puede ayudar? (cortés) :: «Μπορείτε» puede dirigirse formalmente a una persona.
- ¿Tienes que ayudar? :: Tener que es «πρέπει».
- ¿Ayudas todos los días? :: La frase pregunta si puede ayudar.
O μπορώ λίγο αργότερα :: puedo un poco más tarde :: «Αργότερα» significa más tarde.
X Escribe en griego: «claro, por supuesto» :: βέβαια :: βέβαια
