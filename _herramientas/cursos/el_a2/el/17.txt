@ 16 | Τα χόμπι μου | Mis aficiones
I Describe cómo pasas tu tiempo libre, dónde vas y con quién haces una actividad.
E Tiempo libre :: **Στον ελεύθερο χρόνο μου** significa «en mi tiempo libre». **Ασχολούμαι με…** es «me dedico a…» o «practico…». :: Para indicar compañía, usa **με τους φίλους μου** (con mis amigos). **Μου αρέσει να…** significa «me gusta…» + verbo; **δύο φορές την εβδομάδα** indica frecuencia.
W χόμπι = afición | jóbi
W ασχολούμαι = me ocupo, me dedico | asjolúme
W φωτογραφία = fotografía | fotografía
W φωτογραφίζω = hago fotos | fotografízo
W πεζοπορία = senderismo | pezoporía
W ομάδα = equipo, grupo | omáda
W προπόνηση = entrenamiento | propónisi
W δύο φορές την εβδομάδα = dos veces por semana | dío forés tin evdomáda
w ελεύθερο = libre (neutro) | eléfthero
w χρόνο = tiempo (acusativo) | jróno
w φίλους = amigos (acusativo plural) | fílus
V Ελεύθερος χρόνος
D Μετά τη δουλειά
Κώστας: Τι κάνεις στον ελεύθερο χρόνο σου; = ¿Qué haces en tu tiempo libre?
  > τι κάνεις = qué haces | ελεύθερο χρόνο σου = tu tiempo libre
Νίκος: Ασχολούμαι με τη φωτογραφία και πηγαίνω για πεζοπορία. = Me dedico a la fotografía y voy de senderismo.
  > ασχολούμαι με = me dedico a | φωτογραφία = fotografía | πεζοπορία = senderismo
Κώστας: Πόσο συχνά πηγαίνεις; = ¿Con qué frecuencia vas?
  > πόσο συχνά = con qué frecuencia
Νίκος: Δύο φορές την εβδομάδα, με φίλους. = Dos veces por semana, con amigos.
  > δύο φορές την εβδομάδα = dos veces por semana | με φίλους = con amigos
Q ¿Qué aficiones tiene Nikos?
+ La fotografía y el senderismo. :: Menciona ambas actividades.
- El cine y la música. :: No aparecen en esta conversación.
- La natación y el fútbol. :: No se mencionan.
Q ¿Con qué frecuencia va de senderismo?
+ Dos veces por semana. :: Esa es su respuesta.
- Todos los días. :: No dice eso.
- Una vez al mes. :: No indica esa frecuencia.
R Ασχολούμαι με τη φωτογραφία.
+ Me dedico a la fotografía. :: «Ασχολούμαι με» introduce una actividad.
- Hago senderismo con amigos. :: Senderismo es «πεζοπορία».
- Voy dos veces por semana. :: Esa es otra frase.
H Πηγαίνω για ___ με φίλους.
+ πεζοπορία :: «Πηγαίνω για πεζοπορία» es voy de senderismo.
- φωτογραφία :: Significa fotografía.
- ομάδα :: Significa equipo.
A Τι κάνεις στον ελεύθερο χρόνο σου;
+ ¿Qué haces en tu tiempo libre? :: «Ελεύθερος χρόνος» es tiempo libre.
- ¿Qué haces en el trabajo? :: Trabajo es «δουλειά».
- ¿Cuánto tiempo tienes hoy? :: No pregunta cuánto tiempo.
O δύο φορές την εβδομάδα :: dos veces por semana :: «Εβδομάδα» significa semana.

@ 16 | Θέλεις να έρθεις; | ¿Quieres venir?
I Invita a una persona a hacer algo, acepta o rechaza con naturalidad y propone otra fecha.
E Invitaciones :: **Θέλεις να έρθεις;** es «¿quieres venir?». **Μετά χαράς** significa «encantado/a». :: Para rechazar con amabilidad, puedes decir **Λυπάμαι, δεν μπορώ**, y explicar brevemente por qué. **Μπορούμε να πάμε άλλη μέρα** ofrece una alternativa: podemos ir otro día.
W έρθεις = venir (después de να) | érthis
W μετά χαράς = encantado, con gusto | metá jarás
W λυπάμαι = lo siento | lipáme
W δυστυχώς = por desgracia | distijós
W άλλη μέρα = otro día | áli méra
W κανονίζουμε = quedamos, organizamos | kanonízume
W παρέα = compañía, grupo de amigos | paréa
W πρόσκληση = invitación | prósklisi
w μας = nos, nosotros | mas
w αρχίζει = empieza | arjizi
w μπορούμε = podemos | borúme
V Κανονίζουμε μια έξοδο
D Πρόσκληση για σινεμά
Μαρία: Θέλεις να έρθεις μαζί μας στο σινεμά; = ¿Quieres venir al cine con nosotros?
  > θέλεις να έρθεις = quieres venir | μαζί μας = con nosotros | σινεμά = cine
Ελένη: Μετά χαράς! Τι ώρα αρχίζει η ταινία; = ¡Encantada! ¿A qué hora empieza la película?
  > μετά χαράς = encantada | ταινία = película | αρχίζει = empieza
Μαρία: Στις οκτώ. = A las ocho.
  > στις οκτώ = a las ocho
Q ¿Adónde invita María a Eleni?
+ Al cine, con su grupo. :: Dice «μαζί μας στο σινεμά».
- A una cena en casa. :: No se menciona una cena.
- A un concierto. :: No se menciona un concierto.
Q ¿A qué hora empieza la película?
+ A las ocho. :: María dice «στις οκτώ».
- A las siete. :: No es la hora del diálogo.
- A las nueve. :: No es la hora del diálogo.
R Δυστυχώς, δεν μπορώ σήμερα.
+ Por desgracia, hoy no puedo. :: «Δυστυχώς» significa por desgracia.
- Encantado, voy hoy. :: Eso sería «μετά χαράς».
- Podemos ir otro día. :: Esa es otra frase.
H Μπορούμε να πάμε ___ μέρα.
+ άλλη :: «Άλλη μέρα» es otro día.
- μετά :: Significa después.
- παρέα :: Significa grupo de amigos.
A Θέλεις να έρθεις μαζί μας;
+ ¿Quieres venir con nosotros? :: Es una invitación.
- ¿Quieres empezar la película? :: Empezar es «αρχίζω».
- ¿Quieres organizar una fiesta? :: Fiesta es «πάρτι».
O μπορούμε να πάμε άλλη μέρα :: podemos ir otro día :: «Άλλη μέρα» es otro día.

@ 16 | Τι παίζει απόψε; | ¿Qué ponen esta noche?
I Lee una cartelera sencilla y pregunta por el tipo de espectáculo, el horario y las entradas.
E Programación :: **Τι παίζει απόψε;** pregunta qué hay o qué ponen esta noche. **Αρχίζει στις…** indica la hora de inicio y **τελειώνει στις…** la hora de fin. :: **Έχει ακόμη εισιτήρια;** pregunta si quedan entradas. **Μπροστινή σειρά** es fila de delante; **θέση δίπλα** es asiento al lado.
W απόψε = esta noche | apópse
W παίζει = ponen, se representa | pézi
W συναυλία = concierto | sinavlía
W παράσταση = función, espectáculo | parástasi
W εισιτήριο = entrada | isitírio
W διαθέσιμος = disponible (masculino) | diathésimos
W διαθέσιμη = disponible (femenino) | diathésimi
W τελειώνει = termina | telióni
W σειρά = fila | sirá
W θέση = asiento, plaza | thési
W θέατρο = teatro | théatro
W κωμωδία = comedia | komodía
W θέσεις = asientos, plazas | thésis
W διαθέσιμες = disponibles (femenino plural) | diathésimes
w μια = una (artículo femenino) | mia
w τις = las (artículo femenino plural) | tis
V Μια βραδινή έξοδος
D Στο ταμείο
Νίκος: Τι παίζει απόψε στο θέατρο; = ¿Qué ponen esta noche en el teatro?
  > τι παίζει = qué ponen | απόψε = esta noche | θέατρο = teatro
Υπάλληλος: Έχει μια κωμωδία στις επτά και μια παράσταση στις εννέα. = Hay una comedia a las siete y una función a las nueve.
  > κωμωδία = comedia | στις επτά = a las siete | στις εννέα = a las nueve
Νίκος: Έχετε δύο θέσεις δίπλα για τις εννέα; = ¿Tiene dos asientos juntos para las nueve?
  > δύο θέσεις δίπλα = dos asientos juntos | για τις εννέα = para las nueve
Υπάλληλος: Ναι, είναι διαθέσιμες. = Sí, están disponibles.
  > διαθέσιμες = disponibles (femenino plural)
Q ¿A qué hora es la función que elige Nikos?
+ A las nueve. :: Pide dos asientos para esa hora.
- A las siete. :: Esa es la hora de la comedia.
- A las ocho. :: No aparece esa hora.
Q ¿Qué pregunta Nikos al pedir entradas?
+ Si hay dos asientos juntos. :: «Δύο θέσεις δίπλα».
- Si la función termina a las nueve. :: No pregunta la hora final.
- Si la comedia está disponible. :: Elige la otra función.
R Είναι διαθέσιμες δύο θέσεις.
+ Hay dos asientos disponibles. :: «Διαθέσιμες» concuerda con «θέσεις».
- La función termina en dos horas. :: «Τελειώνει» es termina.
- Quedan dos entradas para el cine. :: La escena es en el teatro.
H Τι παίζει ___ στο θέατρο;
+ απόψε :: «Απόψε» significa esta noche.
- αύριο :: Significa mañana.
- χτες :: Significa ayer.
A Η παράσταση αρχίζει στις εννέα.
+ La función empieza a las nueve. :: «Αρχίζει» significa empieza.
- La función acaba a las nueve. :: Acabar es «τελειώνει».
- La función está disponible. :: Disponible es «διαθέσιμη».
O δύο θέσεις δίπλα :: dos asientos juntos :: «Δίπλα» significa al lado.
