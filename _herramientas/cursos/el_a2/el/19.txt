N Ελένη, Άννα, Κώστας, Σοφία, Νίκος, Μαρία
@ 18 | Κλείνω εισιτήριο | Compro un billete
I Pide información para un trayecto, compara ida y vuelta y pregunta cuánto dura.
E Información del viaje :: **Με επιστροφή** significa ida y vuelta. **Πόση ώρα κάνει;** pregunta cuánto tarda. :: **Απευθείας** quiere decir directo, sin cambiar de transporte. **Αλλαγή** puede significar cambio o transbordo; **θέση στο παράθυρο** es asiento junto a la ventana.
W επιστροφή = vuelta, regreso | epistrofí
W με επιστροφή = ida y vuelta | me epistrofí
W απευθείας = directamente | apefthías
W διάρκεια = duración | diárkia
W αλλαγή = cambio, transbordo | allayí
W θέση στο παράθυρο = asiento junto a la ventana | thési sto paráthi ro
W μονό = sencillo (solo ida, neutro) | monó
W ώρες = horas | óres
w πόση = cuánto, cuánta (femenino) | pósi
V Στο εκδοτήριο
D Ένα εισιτήριο για Πάτρα
Κώστας: Θα ήθελα ένα εισιτήριο για την Πάτρα με επιστροφή. = Quisiera un billete a Patras, ida y vuelta.
  > θα ήθελα = quisiera | με επιστροφή = ida y vuelta
Υπάλληλος: Υπάρχει απευθείας τρένο στις δέκα. = Hay un tren directo a las diez.
  > υπάρχει = hay | απευθείας = directo
Κώστας: Πόση ώρα κάνει; = ¿Cuánto tarda?
  > πόση ώρα = cuánto tiempo | κάνει = tarda
Υπάλληλος: Τρεις ώρες. = Tres horas.
  > τρεις ώρες = tres horas
Q ¿Qué tipo de billete pide Kostas?
+ Ida y vuelta a Patras. :: Dice «με επιστροφή».
- Solo ida a Atenas. :: Pide Patras y vuelta.
- Ida y vuelta a Salónica. :: El destino es Patras.
Q ¿Cuánto dura el trayecto?
+ Tres horas. :: Esa es la respuesta del empleado.
- Dos horas. :: No es la duración indicada.
- Una hora. :: No es la duración indicada.
R Θα ήθελα ένα εισιτήριο με επιστροφή.
+ Quisiera un billete de ida y vuelta. :: «Με επιστροφή» es ida y vuelta.
- Quiero cambiar de tren. :: Cambio es «αλλαγή».
- Quisiera un asiento junto a la ventana. :: Eso es «θέση στο παράθυρο».
H Υπάρχει ___ τρένο στις δέκα.
+ απευθείας :: El tren no tiene transbordo.
- επιστροφή :: Significa vuelta.
- παράθυρο :: Significa ventana.
A Πόση ώρα κάνει;
+ ¿Cuánto tarda? :: Es una pregunta por la duración.
- ¿A qué hora sale? :: Salir es «φεύγει».
- ¿Cuánto cuesta el billete? :: Costar es «κοστίζει».
O τρεις ώρες :: tres horas :: «Τρεις» significa tres.
X Escribe en griego: «vuelta» :: επιστροφή :: επιστροφή

@ 18 | Έχω κράτηση | Tengo una reserva
I Confirma una reserva y da los datos básicos al llegar a un hotel.
E Reserva de alojamiento :: **Έχω κράτηση στο όνομα…** significa «tengo una reserva a nombre de…». **Δίκλινο δωμάτιο** es una habitación doble. :: **Για δύο νύχτες** indica la duración. Para pedir que confirmen los datos: **Μπορείτε να ελέγξετε την κράτηση;**. **Το πρωινό περιλαμβάνεται;** pregunta si el desayuno está incluido.
W δίκλινο = doble | díklino
W επιβεβαιώνω = confirmo | epiveveóno
W περιλαμβάνεται = está incluido | perilamvánete
W επιβεβαίωση = confirmación | epivevéosi
w πόσες = cuántas | póses
w μέχρι = hasta | méjri
V Στη ρεσεψιόν
D Άφιξη στο ξενοδοχείο
Μαρία: Έχω κράτηση στο όνομα Μαρία Παπαδοπούλου. = Tengo una reserva a nombre de María Papadopoulou.
  > έχω κράτηση = tengo reserva | στο όνομα = a nombre de
Υπάλληλος: Για πόσες νύχτες; = ¿Para cuántas noches?
  > για πόσες νύχτες = para cuántas noches
Μαρία: Για δύο νύχτες. Το πρωινό περιλαμβάνεται; = Para dos noches. ¿Está incluido el desayuno?
  > δύο νύχτες = dos noches | πρωινό = desayuno | περιλαμβάνεται = está incluido
Υπάλληλος: Ναι, από τις επτά μέχρι τις δέκα. = Sí, desde las siete hasta las diez.
  > από τις επτά = desde las siete | μέχρι τις δέκα = hasta las diez
Q ¿A nombre de quién está la reserva?
+ María Papadopoulou. :: Así lo dice María.
- Anna Papadopoulou. :: No es el nombre de la reserva.
- Nikos Papadopoulos. :: No es el nombre indicado.
Q ¿A qué hora se sirve el desayuno?
+ De siete a diez. :: El empleado indica el horario.
- De seis a nueve. :: No es el horario indicado.
- De ocho a once. :: No es el horario indicado.
R Το πρωινό περιλαμβάνεται;
+ ¿Está incluido el desayuno? :: «Περιλαμβάνεται» significa está incluido.
- ¿A qué hora es el desayuno? :: Pregunta si está incluido.
- ¿Cuántas noches incluye? :: No pregunta por las noches.
H Έχω ___ στο όνομα Μαρία.
+ κράτηση :: «Έχω κράτηση» significa tengo una reserva.
- αναχώρηση :: Significa salida.
- επιβεβαίωση :: Significa confirmación.
A Για δύο νύχτες.
+ Para dos noches. :: «Νύχτες» significa noches.
- Para dos habitaciones. :: Habitaciones es «δωμάτια».
- Desde las dos. :: Desde es «από».
O από τις επτά μέχρι τις δέκα :: desde las siete hasta las diez :: «Μέχρι» significa hasta.
X Escribe en griego: «reserva» :: κράτηση :: κράτηση

@ 18 | Το τρένο έχει καθυστέρηση | El tren tiene retraso
I Comprende un anuncio de retraso y pide información clara sobre una salida o un equipaje.
E Retrasos y problemas :: **Έχει καθυστέρηση** significa «tiene retraso». **Πόση ώρα;** pregunta cuánto tiempo. :: **Αποσκευή** es equipaje y **χάθηκε** significa se perdió. Si no entiendes, puedes pedir que repitan: **Μπορείτε να το επαναλάβετε, παρακαλώ;**.
W καθυστέρηση = retraso | kathistérisi
W καθυστερεί = se retrasa | kathisterí
W ανακοινώνω = anuncio (yo) | anakoinóno
W επαναλαμβάνω = repito | epanalamváno
W επαναλάβετε = repita (cortés) | epanalávete
W αποσκευή = equipaje, maleta | aposkeví
W χάθηκε = se perdió | játhike
W γραφείο = oficina | grafío
W πληροφορίες = información | pliroforíes
W περίπου = aproximadamente | perípu
W λεπτών = minutos (genitivo plural) | leptón
W λεπτά = minutos | leptá
w φύγει = salga (después de θα) | fíyi
V Στον σταθμό
D Μια αλλαγή στο πρόγραμμα
Ανακοίνωση: Το τρένο για την Πάτρα έχει καθυστέρηση περίπου είκοσι λεπτών. = Anuncio: el tren a Patras tiene un retraso de unos veinte minutos.
  > έχει καθυστέρηση = tiene retraso | περίπου είκοσι λεπτών = unos veinte minutos
Νίκος: Μπορείτε να το επαναλάβετε, παρακαλώ; = ¿Puede repetirlo, por favor?
  > μπορείτε να = puede usted | το επαναλάβετε = repetirlo | παρακαλώ = por favor
Υπάλληλος: Το τρένο θα φύγει σε είκοσι λεπτά. = El tren saldrá dentro de veinte minutos.
  > θα φύγει = saldrá | σε είκοσι λεπτά = dentro de veinte minutos
Q ¿Cuánto se retrasa el tren?
+ Unos veinte minutos. :: Lo anuncia la megafonía.
- Unos diez minutos. :: No es el tiempo indicado.
- Una hora. :: El retraso es menor.
Q ¿Qué pide Nikos?
+ Que repitan la información. :: Dice «Μπορείτε να το επαναλάβετε;».
- Que le vendan otro billete. :: No pide un billete.
- Que busquen su maleta. :: No habla de equipaje.
R Το τρένο θα φύγει σε είκοσι λεπτά.
+ El tren saldrá dentro de veinte minutos. :: «Θα φύγει» es saldrá.
- El tren llegó hace veinte minutos. :: Llegó es «έφτασε».
- El tren tiene veinte asientos. :: Asientos es «θέσεις».
H Το τρένο έχει ___ περίπου είκοσι λεπτών.
+ καθυστέρηση :: La frase habla de un retraso.
- αποσκευή :: Significa equipaje.
- πληροφορίες :: Significa información.
A Μπορείτε να το επαναλάβετε;
+ ¿Puede repetirlo? :: «Επαναλάβετε» es repita.
- ¿Puede devolverlo? :: Devolver es «επιστρέψω».
- ¿Puede buscarlo? :: Buscar es «ψάχνω».
O έχει καθυστέρηση περίπου είκοσι λεπτών :: tiene un retraso de unos veinte minutos :: «Περίπου» significa aproximadamente.
X Escribe en griego: «retraso» :: καθυστέρηση :: καθυστέρηση
