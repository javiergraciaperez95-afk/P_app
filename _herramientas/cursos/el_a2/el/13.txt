N Ελένη, Άννα, Κώστας, Σοφία, Νίκος, Μαρία
@ 12 | Ψάχνω διαμέρισμα | Busco piso
I En un anuncio de vivienda suelen aparecer el barrio, el número de habitaciones, la planta y el precio.
E Describir una vivienda :: **Ψάχνω διαμέρισμα** significa «busco piso». Para preguntar por una vivienda: **Πόσα δωμάτια έχει;** (¿cuántas habitaciones tiene?). :: **Βρίσκεται** significa «está situado». **Στον δεύτερο όροφο** es «en la segunda planta». Los ordinales concuerdan en género: **δεύτερος όροφος**, **δεύτερη στάση**.
W διαμέρισμα = piso, apartamento | diarísma
W αγγελία = anuncio | angelía
W ψάχνω = busco | psájno
W όροφος = planta, piso de un edificio | órofos
W όροφο = piso, planta (acusativo) | órofo
W δεύτερο = segundo (masculino acusativo / neutro) | déftero
W βρίσκεται = está situado | vrískete
W φωτεινό = luminoso | fotinó
W ασανσέρ = ascensor | asansér
W ενοίκιο = alquiler | eníkio
W κοινόχρηστα = gastos comunitarios | kinójrista
W εξακόσια = seiscientos | exakósia
V Αναζήτηση σπιτιού
D Μια αγγελία
Σοφία: Ψάχνω ένα διαμέρισμα κοντά στο κέντρο. = Busco un piso cerca del centro.
  > ψάχνω = busco | κοντά στο κέντρο = cerca del centro
Νίκος: Αυτό βρίσκεται στον δεύτερο όροφο και έχει δύο δωμάτια. = Este está en la segunda planta y tiene dos habitaciones.
  > βρίσκεται = está situado | δεύτερο όροφο = segunda planta | δύο δωμάτια = dos habitaciones
Σοφία: Έχει ασανσέρ; = ¿Tiene ascensor?
  > ασανσέρ = ascensor
Νίκος: Ναι. Το ενοίκιο είναι εξακόσια ευρώ, χωρίς κοινόχρηστα. = Sí. El alquiler son seiscientos euros, sin gastos comunitarios.
  > ενοίκιο = alquiler | χωρίς = sin | κοινόχρηστα = gastos comunitarios
Q ¿Cuántas habitaciones tiene el piso?
+ Dos. :: El diálogo dice «δύο δωμάτια».
- Una. :: No es lo que dice Nikos.
- Tres. :: El diálogo menciona dos.
Q ¿Qué gastos no están incluidos?
+ Los gastos comunitarios. :: Se indica «χωρίς κοινόχρηστα».
- El agua y la luz. :: No se mencionan.
- El ascensor. :: El ascensor está disponible.
R Το διαμέρισμα βρίσκεται στον δεύτερο όροφο.
+ El piso está en la segunda planta. :: «Βρίσκεται» indica ubicación.
- El piso tiene dos habitaciones. :: Esa información aparece en otra frase.
- El alquiler incluye los gastos. :: Dice «χωρίς κοινόχρηστα».
H Το ενοίκιο είναι ___ ευρώ.
+ εξακόσια :: El número coincide con el anuncio.
- διαμέρισμα :: Significa piso.
- φωτεινό :: Significa luminoso.
A Έχει ασανσέρ;
+ ¿Tiene ascensor? :: Es una pregunta sobre el edificio.
- ¿Cuánto cuesta el ascensor? :: No se pregunta el precio.
- ¿En qué planta está? :: Eso sería «σε ποιον όροφο;».
O ψάχνω ένα διαμέρισμα :: busco un piso :: «Ψάχνω» significa busco.
X Escribe en griego: «alquiler» :: ενοίκιο :: ενοίκιο

@ 12 | Πώς είναι το σπίτι; | Cómo es la casa
I Pregunta por las habitaciones, el mobiliario y el entorno antes de elegir una vivienda.
E Habitaciones y ubicación :: Para decir qué tiene una vivienda, usa **έχει** + sustantivo: **έχει μπαλκόνι** (tiene balcón). **Δίπλα σε** significa «al lado de» y **μακριά από** significa «lejos de». :: **Μεγάλο**, **μικρό**, **παλιό** y **καινούριο** describen cosas neutras; con un sustantivo femenino, suelen cambiar a **μεγάλη**, **μικρή**, **παλιά**, **καινούρια**.
W μπαλκόνι = balcón | balkóni
W ευρύχωρο = espacioso (neutro) | evríjoro
W παλιό = viejo (neutro) | palió
W παλιά = vieja (femenino) | paliá
W θορυβώδης = ruidoso (masculino/femenino) | thorivódis
V Μέσα στο σπίτι
D Στο νέο σπίτι
Ελένη: Το σπίτι είναι παλιό, αλλά πολύ ευρύχωρο. = La casa es vieja, pero muy espaciosa.
  > παλιό = viejo | ευρύχωρο = espacioso
Κώστας: Έχει μεγάλο μπαλκόνι; = ¿Tiene un balcón grande?
  > μεγάλο μπαλκόνι = balcón grande
Ελένη: Ναι, και η κουζίνα είναι καινούρια. = Sí, y la cocina es nueva.
  > κουζίνα = cocina | καινούρια = nueva
Κώστας: Το υπνοδωμάτιο είναι δίπλα στο μπάνιο; = ¿El dormitorio está al lado del baño?
  > υπνοδωμάτιο = dormitorio | δίπλα = al lado
Q ¿Cómo es la casa?
+ Antigua, pero muy espaciosa. :: «Παλιό» y «ευρύχωρο» describen la casa.
- Nueva y pequeña. :: No es lo que dice Eleni.
- Ruidosa y lejos del centro. :: No se menciona eso.
Q ¿Qué habitación es nueva?
+ La cocina. :: Eleni dice que «η κουζίνα είναι καινούρια».
- El dormitorio. :: No se describe su estado.
- El baño. :: Solo se pregunta dónde está.
R Το υπνοδωμάτιο είναι δίπλα στο μπάνιο.
+ El dormitorio está al lado del baño. :: «Δίπλα» significa al lado.
- El baño está dentro del dormitorio. :: La frase indica que están uno al lado del otro.
- La cocina está lejos del baño. :: No aparece «μακριά».
H Η κουζίνα είναι ___ .
+ καινούρια :: Concuerda con el sustantivo femenino «κουζίνα».
- καινούριο :: Es la forma neutra.
- καινούριος :: Es la forma masculina.
A Έχει μεγάλο μπαλκόνι;
+ ¿Tiene un balcón grande? :: «Μεγάλο» describe a «μπαλκόνι».
- ¿Tiene una cocina nueva? :: Cocina es «κουζίνα».
- ¿Tiene un dormitorio pequeño? :: Pequeño es «μικρό».
O το σπίτι είναι ευρύχωρο :: la casa es espaciosa :: «Ευρύχωρο» es espacioso.
X Escribe en griego: «cocina» :: κουζίνα :: κουζίνα

@ 12 | Η γειτονιά μου | Mi barrio
I Habla del barrio donde vives y explica qué servicios tienes cerca.
E Servicios del barrio :: **Στη γειτονιά μου** es «en mi barrio». Puedes decir **υπάρχει** + singular (hay) o **υπάρχουν** + plural. :: **Απέναντι από** significa «enfrente de», **ανάμεσα σε** significa «entre» y **σε πέντε λεπτά** expresa un tiempo aproximado para llegar.
W υπάρχει = hay (singular) | ipárji
W υπάρχουν = hay (plural) | ipárjun
W ανάμεσα = entre | anámesa
W φούρνο = panadería (acusativo) | fúrno
W σε πέντε λεπτά = en cinco minutos | se pénde leptá
V Στη γειτονιά
D Μια βόλτα
Μαρία: Η γειτονιά σου είναι ωραία; = ¿Tu barrio es bonito?
  > γειτονιά σου = tu barrio | ωραία = bonito
Άννα: Ναι, είναι ήσυχη και έχει ένα πάρκο. = Sí, es tranquilo y tiene un parque.
  > ήσυχη = tranquila | πάρκο = parque
Μαρία: Υπάρχει φαρμακείο κοντά; = ¿Hay una farmacia cerca?
  > υπάρχει = hay | φαρμακείο = farmacia | κοντά = cerca
Άννα: Ναι, απέναντι από τον φούρνο. = Sí, enfrente de la panadería.
  > απέναντι από = enfrente de | φούρνο = panadería
Q ¿Cómo es el barrio de Anna?
+ Es tranquilo y tiene un parque. :: Ella lo describe así.
- Es ruidoso y no tiene servicios. :: La descripción no dice eso.
- Es pequeño y está lejos. :: No se mencionan esas características.
Q ¿Dónde está la farmacia?
+ Enfrente de la panadería. :: «Απέναντι από τον φούρνο».
- Dentro del parque. :: El parque aparece en otra frase.
- Entre la casa y la parada. :: No se menciona una parada.
R Υπάρχει φαρμακείο κοντά;
+ ¿Hay una farmacia cerca? :: «Υπάρχει» pregunta si hay algo.
- ¿Dónde está la panadería? :: Panadería es «φούρνος».
- ¿El parque está abierto? :: No se pregunta por el horario.
H Στη γειτονιά μου ___ ένα πάρκο.
+ υπάρχει :: Con un sustantivo singular usamos «υπάρχει».
- υπάρχουν :: Se usa con plural.
- απέναντι :: Significa enfrente.
A Η γειτονιά είναι ήσυχη.
+ El barrio es tranquilo. :: «Ήσυχη» significa tranquila.
- El barrio está lejos. :: Lejos es «μακριά».
- Hay una farmacia. :: Esa frase es «υπάρχει φαρμακείο».
O απέναντι από τον φούρνο :: enfrente de la panadería :: «Απέναντι από» expresa ubicación.
X Escribe en griego: «barrio» :: γειτονιά :: γειτονιά
