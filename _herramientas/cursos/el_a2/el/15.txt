@ 14 | Τι τρως συνήθως; | ¿Qué comes normalmente?
I Habla de tus hábitos de alimentación y expresa qué alimentos te gustan o prefieres.
E Hábitos y preferencias :: **Τρώω συνήθως…** significa «normalmente como…». Para indicar preferencia, di **προτιμώ** (prefiero). :: **Υγιεινό** significa saludable y **ανθυγιεινό** poco saludable. **Περισσότερα λαχανικά** son más verduras; **λιγότερη ζάχαρη**, menos azúcar. La forma del adjetivo concuerda con el sustantivo.
W προτιμώ = prefiero | protimó
W υγιεινός = saludable (masculino) | iyinós
W υγιεινή = saludable (femenino) | iyiní
W υγιεινό = saludable (neutro) | iyinó
W λαχανικά = verduras | lajaniká
W λιγότερη = menos (femenino) | ligóteri
W περισσότερο = más (neutro) | perissótero
W συχνά = a menudo | sijná
V Διατροφικές συνήθειες
D Στο μεσημεριανό
Άννα: Τι τρως συνήθως το μεσημέρι; = ¿Qué comes normalmente al mediodía?
  > τι τρως = qué comes | το μεσημέρι = al mediodía
Κώστας: Τρώω συχνά ψάρι και προτιμώ τα λαχανικά. = A menudo como pescado y prefiero las verduras.
  > συχνά = a menudo | ψάρι = pescado | προτιμώ = prefiero
Άννα: Είναι υγιεινό. Εγώ θέλω λιγότερη ζάχαρη στον καφέ. = Es saludable. Yo quiero menos azúcar en el café.
  > υγιεινό = saludable | λιγότερη ζάχαρη = menos azúcar
Q ¿Qué prefiere Kostas?
+ Las verduras. :: Dice que prefiere «τα λαχανικά».
- El pescado frito. :: No habla de cómo está cocinado.
- El café con azúcar. :: No es lo que prefiere.
Q ¿Qué quiere Anna poner menos en el café?
+ Azúcar. :: «Ζάχαρη» significa azúcar.
- Leche. :: Leche es «γάλα».
- Canela. :: No aparece en el diálogo.
R Τρώω συχνά ψάρι.
+ A menudo como pescado. :: «Συχνά» significa a menudo.
- Prefiero comer verduras. :: Prefiero es «προτιμώ».
- Nunca como pescado. :: «Συχνά» no significa nunca.
H Θέλω ___ ζάχαρη στον καφέ.
+ λιγότερη :: La palabra concuerda con «ζάχαρη».
- λιγότερο :: Es neutro o masculino.
- περισσότερο :: Significa más.
A Τρώω συχνά λαχανικά.
+ A menudo como verduras. :: «Λαχανικά» son verduras.
- Prefiero pescado. :: Pescado es «ψάρι».
- Quiero menos azúcar. :: Azúcar es «ζάχαρη».
O προτιμώ τα λαχανικά :: prefiero las verduras :: «Προτιμώ» significa prefiero.

@ 14 | Μια απλή συνταγή | Una receta sencilla
I Comprende una receta corta y sigue instrucciones básicas en la cocina.
E Instrucciones :: Para dar instrucciones se usa el imperativo: **Κόψε** (corta), **βάλε** (pon), **ανακάτεψε** (mezcla). :: **Πρώτα** introduce el primer paso y **στο τέλος** el último. **Σε κομμάτια** significa en trozos. **Μέχρι να…** quiere decir hasta que…; aquí basta con aprender la expresión como una unidad.
W συνταγή = receta | sindayí
W κόψε = corta | kópse
W βάλε = pon | vále
W ανακάτεψε = mezcla | anakátepse
W αγγούρι = pepino | angúri
W κρεμμύδι = cebolla | kremídi
W κομμάτια = trozos | komátia
W λάδι = aceite | ládi
W μπολ = bol, cuenco | bol
W στύψε = exprime | stípse
W πρόσθεσε = añade | prósthese
V Στην κουζίνα
T Χωριάτικη σαλάτα
- Πρώτα, κόψε την ντομάτα και το αγγούρι. = Primero, corta el tomate y el pepino.
- Βάλε τα κομμάτια σε ένα μπολ. = Pon los trozos en un cuenco.
- Πρόσθεσε κρεμμύδι, λάδι και λίγο αλάτι. = Añade cebolla, aceite y un poco de sal.
- Στο τέλος, ανακάτεψε καλά. = Al final, mezcla bien.
Q ¿Qué hay que hacer primero?
+ Cortar el tomate y el pepino. :: Es el primer paso.
- Añadir aceite y sal. :: Eso aparece después.
- Mezclar todo. :: Es el último paso.
Q ¿Dónde se ponen los trozos?
+ En un cuenco. :: «Σε ένα μπολ».
- En la sartén. :: No se menciona una sartén.
- En el horno. :: No se menciona un horno.
R Βάλε τα κομμάτια σε ένα μπολ.
+ Pon los trozos en un cuenco. :: «Βάλε» es una instrucción.
- Corta el tomate. :: Cortar es «κόψε».
- Añade el aceite al final. :: El texto no dice eso.
H Πρώτα, ___ την ντομάτα.
+ κόψε :: La receta empieza cortando el tomate.
- ανακάτεψε :: Mezclar es el último paso.
- αλάτι :: Significa sal.
A Στο τέλος, ανακάτεψε καλά.
+ Al final, mezcla bien. :: «Στο τέλος» significa al final.
- Primero, corta el pepino. :: Primero es «πρώτα».
- Añade un poco de sal. :: Sal es «αλάτι».
O πρόσθεσε κρεμμύδι και λάδι :: añade cebolla y aceite :: «Πρόσθεσε» es añade.
X Escribe en griego: «receta» :: συνταγή :: συνταγή

@ 14 | Στο εστιατόριο | En el restaurante
I Pide una explicación sobre los platos, elige lo que quieres y pide la cuenta con cortesía.
E Pedir y pagar :: **Θα ήθελα…** es una forma cortés de pedir: «quisiera…». **Τι περιέχει;** pregunta qué contiene un plato. :: Para pedir la cuenta: **Τον λογαριασμό, παρακαλώ**. **Χωρίς…** significa sin; **με…** indica qué lleva. **Περιέχει ξηρούς καρπούς** significa contiene frutos secos.
W περιέχει = contiene | perijéi
W ξηροί καρποί = frutos secos | xirí karpí
W ξηρούς = secos (masculino plural, acusativo) | xirús
W καρπούς = frutos (acusativo plural) | karpús
W φέτα = queso feta | féta
W ψητό = asado | psitó
V Στην ταβέρνα
D Παραγγελία
Σοφία: Τι περιέχει αυτή η σαλάτα; = ¿Qué contiene esta ensalada?
  > τι περιέχει = qué contiene | αυτή η σαλάτα = esta ensalada
Σερβιτόρος: Ντομάτα, αγγούρι, φέτα και ελιές. = Tomate, pepino, feta y aceitunas.
  > φέτα = feta | ελιές = aceitunas
Σοφία: Θα ήθελα τη σαλάτα χωρίς ξηρούς καρπούς, παρακαλώ. = Quisiera la ensalada sin frutos secos, por favor.
  > θα ήθελα = quisiera | χωρίς ξηρούς καρπούς = sin frutos secos
Σοφία: Τον λογαριασμό, παρακαλώ. = La cuenta, por favor.
  > τον λογαριασμό = la cuenta | παρακαλώ = por favor

R Θα ήθελα τη σαλάτα χωρίς τυρί.
+ Quisiera la ensalada sin queso. :: «Χωρίς» significa sin.
- Quiero una ensalada con queso. :: La frase es cortés y dice sin queso.

+ λογαριασμό :: Así se pide la cuenta.

- Quiero una ensalada sin queso. :: No se menciona ensalada.
