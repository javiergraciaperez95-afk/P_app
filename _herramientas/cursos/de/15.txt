@ 15 | Gleichheit mit so wie | Comparar igualdad
I Para comparar dos elementos que poseen el mismo grado de una cualidad usamos la correlación **so + Adjektiv + wie** (tan ... como). Si queremos expresar que no alcanzan el mismo nivel, anteponemos la negación: **nicht so + Adjektiv + wie** (no tan ... como). En esta construcción el adjetivo se mantiene en su **forma base positiva**, sin terminación «-er».
E Estructura de igualdad frente a desigualdad :: 1. Igualdad: **so + Grundform + wie**: *Der Bremer Marktplatz ist so schön wie ein Gemälde* (La plaza de Bremen es tan bonita como un cuadro); *Er ist so alt wie ich* (Es tan mayor como yo). :: 2. Negación de igualdad: **nicht so + Grundform + wie**: *Die Busfahrt ist nicht so spannend wie der Spaziergang* (El viaje en bus no es tan apasionante como el paseo a pie). :: Recuerda: en igualdad se usa siempre **wie**; **als** queda reservado para la desigualdad comparativa con «-er».
B Comparación de igualdad y diferencia | Grado | Estructura correlativa | Ejemplo
| Igualdad afirmativa | so + adjetivo + wie | Er ist so groß wie sein Vater.
| Igualdad negativa | nicht so + adjetivo + wie | Das Hotel ist nicht so teuer wie gedacht.
| Superioridad (contraste) | adjetivo-er + als | Das Auto ist schneller als das Rad.

Q ¿Qué nexo correlativo se utiliza en alemán para expresar una comparación de igualdad («tan … como»)?
+ so + adjetivo base + wie :: La pauta canónica de equivalencia es «so + adjetivo en grado positivo + wie».
- so + adjetivo con -er + als :: El sufijo «-er» y «als» expresan superioridad y desigualdad, no igualdad.
- mehr + adjetivo + wie :: No se emplea «mehr» para formar la igualdad adjetival.
Q ¿Qué forma adjetival debe colocarse entre «so … wie»?
+ El adjetivo en su forma base positiva sin terminación -er (como so alt wie). :: En la comparación de igualdad no se añade la desinencia comparativa «-er».
- El adjetivo en grado superlativo con terminación -ste. :: El superlativo no se combina con «so … wie».
- Únicamente participios de verbos irregulares. :: Se utilizan adjetivos calificativos ordinarios.
H Der Bremer Marktplatz ist so schön ___ ein Gemälde. :: como (comparación de igualdad)
+ wie :: La igualdad con «so» se completa con la partícula «wie».
- als :: «Als» se reserva para comparativos de desigualdad («schöner als»).
- dass :: «Dass» es una conjunción completiva.
H Die Busfahrt ist nicht so spannend ___ der Rundgang zu Fuß. :: como (igualdad negativa)
+ wie :: Con «nicht so» se mantiene la partícula «wie» para contrastar la equivalencia.
- als :: «Als» no se combina con «nicht so».
- denn :: «Denn» es una conjunción coordinante causal.
R Die Tickets für das Museum sind nicht so teuer wie die Opernkarten. :: ¿Qué concluye esta comparación económica?
+ Que las entradas del museo son más económicas que las localidades de ópera. :: «Nicht so teuer wie» significa que el museo cuesta menos dinero que la ópera.
- Que ambas entradas tienen exactamente el mismo precio en taquilla. :: No es correcto, pues la frase niega la igualdad.
- Que las entradas de ópera son gratuitas para los estudiantes. :: No habla de gratuidad.
H Unser Zimmer ist genauso groß ___ eure Wohnung. :: como (igualdad con genauso)
+ wie :: Tras «genauso» se utiliza siempre «wie»: «genauso groß wie».
- als :: Es incorrecto con «genauso».
- wenn :: Es una conjunción condicional/temporal.
O Der Marktplatz ist so schön wie ein Bild :: La plaza del mercado es tan bonita como un cuadro :: Sujeto + verbo + correlación so + adjetivo base + wie + término de comparación.

@ 15 | Vergleich mit genauso | Comparar con genauso
I Para reforzar con énfasis la total equivalencia entre dos personas, espacios o costes, el alemán recurre al adverbio **genauso … wie** (exactamente igual de … que). Para formular la inferioridad en una cualidad, se emplea la construcción **weniger … als** (menos … que).
E Genauso frente a weniger :: 1. **Genauso + Adjektiv + wie**: *Das Zimmer ist genauso gemütlich wie das Luxushotel* (La habitación es exactamente igual de acogedora que el hotel de lujo); *Die Miete ist genauso hoch wie in Berlin* (El alquiler es igual de caro que en Berlín). :: 2. **weniger + Adjektiv + als**: *Die Unterkunft ist weniger teuer als gedacht* (El alojamiento es menos caro de lo pensado); *Dieser Koffer wiegt weniger als zehn Kilo* (Esta maleta pesa menos de diez kilos).
