@ 30 | In zwei Jahren werde ich fertig sein | Dentro de dos años estaré listo
I Llegamos al último capítulo de B1. Hoy practicamos el Futur I con **werden** y las suposiciones sobre el presente y el futuro.
E Futuro I :: Se forma con **werden** conjugado y el infinitivo al final: **In zwei Jahren werde ich mein Studium abschließen** (dentro de dos años terminaré mis estudios). Se usa para planes, promesas y predicciones. En el día a día se usa más el presente con una palabra de tiempo: **Nächstes Jahr fahre ich nach Italien** (el año que viene voy a Italia).
E Suposición con wohl :: Para decir algo probable, se usa **werden** + **wohl** + infinitivo: **Er wird wohl krank sein** (probablemente estará enfermo). Con la idea de «probablemente» se usa **wohl** o **vermutlich**. :: Ojo con el falso amigo: **wohl** no significa «bien»; significa «probablemente».
B Forma | Ejemplo | Significa
| werde + infinitivo | Ich werde Ärztin sein. | Seré médica.
| wird wohl + infinitivo | Er wird wohl kommen. | Probablemente vendrá.
| Präsens + palabra de tiempo | Morgen fahre ich. | Mañana voy.

W abschließen = terminar, acabar (estudios) | AP-shli-sen
W Hoffnung = esperanza (die) | HOF-nung
W Vermutung = suposición (die) | fer-MU-tung
W vermutlich = probablemente | fer-MUT-lij
W wahrscheinlich = probablemente, seguramente | VAR-shain-lij
W Vorsatz = propósito (der) | FOR-zats
W Traum = sueño (der) | traum
W erreichen = alcanzar, conseguir | er-RAI-jen
W fertig = terminado, listo | FER-tig
W fertig sein = haber terminado | FER-tig zain
W nächstes = próximo, siguiente (neutro, delante de un nombre) | NÄX-tes
W sicher = seguro, con seguridad | ZI-cher
W wahr = verdadero, real | vahr

  > werde ich = terminaré | abschließen = terminar | in zwei Jahren = dentro de dos años
Lena: Und dann? = ¿Y después?

  > Ich werde = trabajaré | wahrscheinlich = probablemente | arbeiten = trabajar

  > wird = se | sicher = seguro | wahr = realidad
Q ¿Qué verbo forma el futuro en alemán?
+ werden :: Futuro I: werden + infinitivo.
- haben :: Forma el Perfekt.
- sein :: Forma la pasiva o el estado.
Q ¿Cómo se dice «probablemente estará enfermo»?
+ Er wird wohl krank sein. :: werden + wohl + infinitivo.
- Er ist wohl krank. :: Sin «werden» es afirmación presente, no suposición.
- Er war wohl krank. :: Es pasado.
R In zwei Jahren werde ich mein Studium abschließen.
+ Dentro de dos años terminaré mis estudios. :: werde + infinitivo al final.
- Dentro de dos años terminé mis estudios. :: Es pasado.
- Dentro de dos años termino mis estudios. :: Se entiende como presente, sin el matiz de futuro.
H Er ___ wohl kommen. :: vendrá
+ wird :: Con «er» va «wird».
- werde :: Es con «ich».
- werden :: Es con «wir» o «sie».
H Ich ___ Ärztin sein. :: seré
+ werde :: Con «ich» va «werde».
- wird :: Es con «er» o «sie».
- werdet :: Es con «ihr».
A Er wird wohl kommen.

- Seguro que vino. :: Es pasado.
- Quizá no vendrá. :: Eso sería «vielleicht nicht».
O Ich werde wahrscheinlich in Berlin arbeiten :: Probablemente trabajaré en Berlín :: werden + adverbio + infinitivo al final.
Q ¿Qué expresión significa «probablemente»?
+ wahrscheinlich :: wahrscheinlich = probablemente.
- wohl nicht :: Significa «probablemente no».
- nie :: Significa «nunca».
X Escribe en alemán: «dentro de dos años habré terminado» :: In zwei Jahren werde ich fertig sein | In zwei Jahren werde ich fertig sein :: werde + infinitivo sein al final.
