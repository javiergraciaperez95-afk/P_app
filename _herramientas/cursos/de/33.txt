I Ahora los verbos modales en otra función: no como obligación o capacidad, sino para suponer algo. Es una de las diferencias más importantes del B2.
E Modales de suposición :: Los modales pueden expresar una valoración de quien habla: **Er muss krank sein** (debe de estar enfermo; deducción fuerte), **Er dürfte zu Hause sein** (probablemente esté en casa), **Er kann müde sein** (puede que esté cansado). Q ¿Cuál de las siguientes afirmaciones presenta un hecho empírico comprobado y no una deducción?
+ Der Hauptschalter fiel genau um zehn Uhr aus. :: El indicativo de hechos constata un dato temporal y técnico registrado.
- Ein Materialfehler könnte den Kurzschluss verursacht haben. :: «könnte ... haben» formula una mera hipótesis no verificada.
- Die Hitze dürfte für den Zwischenfall verantwortlich sein. :: «dürfte» expresa una probabilidad estimada por el técnico.
H Nach Prüfung der Daten ___ ein Bedienungsfehler praktisch ausgeschlossen sein. :: probablemente esté / debe de estar
+ dürfte :: «dürfte ... sein» formula la estimación experta fundada de probabilidad.
- darf :: En presente indicativo expresaría permiso o autorización, no deducción pericial.
- will :: Expresaría una pretensión subjetiva de la persona («dice que»).
R Nach den Messergebnissen dürfte diese Annahme eher unwahrscheinlich sein. :: ¿Qué opina el perito?
+ Que las mediciones técnicas hacen que esa hipótesis resulte muy poco creíble. :: «unwahrscheinlich» indica falta de verosimilitud de la suposición planteada.
- Que las pruebas de laboratorio confirman la hipótesis de forma concluyente. :: Afirma lo opuesto: las mediciones descartan casi por completo esa idea.
- Que las mediciones no han aportado ningún dato interpretable por los técnicos. :: Los datos son suficientes para juzgar la hipótesis como inverosímil.
Q ¿Qué estructura gramatical se utiliza para formular una conclusión retrospectiva casi certera?
+ «müssen» en presente + Partizip II + infinitivo perfecto («haben / sein»). :: Por ejemplo: «Die Überlastung muss die Ursache gewesen sein».
- «musste» en Präteritum + infinitivo simple de presente. :: Expresa obligación pasada, no conclusión lógica retrospectiva.
- «werden» en indicativo + infinitivo pasivo. :: Corresponde a la voz pasiva de presente.
H Es ist eine bewiesene Tatsache, dass der Druck vor dem Unfall stark ___ . :: subió / había subido (hecho fáctico)
+ anstieg :: Para hechos objetivos demostrados se utiliza el indicativo del verbo en pasado.
- ansteigen müsste :: El modo condicional plantearía una hipótesis irreal contraria al hecho probado.
- ansteigen solle :: «solle» expresaría que se trata de un rumor ajeno no constatado.
R Ein technischer Materialfehler an den Leitungen könnte vorgelegen haben. :: ¿Qué grado de certeza expresa el técnico?
+ Plantea una posibilidad abierta que no puede descartarse por completo. :: «könnte vorgelegen haben» introduce una hipótesis plausible sujeta a examen.
- Confirma que los materiales defectuosos provocaron el apagón con seguridad. :: No es una confirmación tajante, sino una posibilidad entre otras.
- Demuestra que el fabricante de los cables actuó de manera negligente. :: No realiza acusaciones de culpabilidad, solo plantea un escenario técnico.
O das ist eine gesicherte Tatsache nach den Messungen :: ese es un hecho contrastado según las mediciones :: afirmación fáctica frente a inferencia.
