- Acusativo. :: La forma de 1.ª persona en acusativo sería «mich».
- Nominativo. :: El pronombre nominativo de 1.ª persona es «ich».

- Dieses :: Se emplea para sustantivos neutros.

- tragt :: Corresponde a la segunda persona plural (ihr).

@ 7 | Was kostet das? | Comprar: precios y tallas

@ 7 | Größer, billiger, besser | Comparar cosas
E El comparativo :: Lo habitual es añadir **-er** al adjetivo: billig → **billiger** (más barato), schön → **schöner** (más bonito). Muchos adjetivos cortos añaden diéresis: groß → **größer**, alt → **älter**, jung → **jünger**. **Teuer** pierde una e: **teurer**. :: Para decir «más» con cantidades se usa **mehr** (**mehr Kaffee**, más café), no con todos los adjetivos. Algunas palabras tienen formas especiales: **gut → besser** (bueno → mejor), **viel → mehr** (mucho → más), **gern → lieber** (con gusto → preferir). :: «Que» se dice **als**: **Das weiße Handy ist billiger als das schwarze.** Para igualdad: **so … wie** (**tan… como**).
B Comparativos | Adjetivo | Comparativo | Español
| billig | billiger | más barato
| schön | schöner | más bonito
| klein | kleiner | más pequeño
| groß | größer | más grande
| teuer | teurer | más caro
| gut | besser | mejor
E Mejor y el mejor :: **Gut** es irregular: **besser** (mejor) y **am besten** (lo mejor, el mejor). :: Con los demás, el superlativo se forma con **am** + **-sten**: **am billigsten** (el más barato), **am schönsten** (el más bonito). :: **Welcher, welche, welches** = cuál.

+ größer :: Los adjetivos monosilábicos con vocal -o- suelen adquirir diéresis: «größer».

@ 7 | dieser, diese, dieses | Demostrativos

@ 7 | Komparativ mit als | Comparativo con als
I Aprende a comparar dos elementos en alemán expresando diferencias de cualidad o precio mediante la estructura comparativa con la conjunción als.
E El comparativo de desigualdad con «als» :: Para comparar dos personas, prendas u objetos donde uno supera al otro: :: 1. **Adjetivo en comparativo (-er):** :: **schnell → schneller** (más rápido). :: **billig → billiger** (más barato). :: **warm → wärmer** (más cálido). :: **bequem → bequemer** (más cómodo). :: 2. **Conjunción comparativa «als»:** :: Equivale al «que» comparativo del español: :: **Das schwarze Handy ist schneller als das weiße Modell.** (El móvil negro es más rápido que el modelo blanco). :: **Dieses T-Shirt ist billiger als der Mantel.** (Esta camiseta es más barata que el abrigo). :: 3. **Contraste con la igualdad:** :: Cuando dos cosas son iguales se usa **so ... wie** (tan ... como): :: **Dieses Hemd ist so bequem wie mein Pullover.** (Esta camisa es tan cómoda como mi jersey). :: No confundas: para diferencias se usa siempre **als**; para igualdad se usa **wie**.
B Comparación: superioridad frente a igualdad | Tipo | Estructura | Ejemplo en alemán | Español
| Desigualdad (más... que) | Adjetivo-er + als | Das Handy ist schneller als mein altes. | El móvil es más rápido que el mío anterior.
| Menor precio (más barato que) | billiger + als | Das T-Shirt ist billiger als der Mantel. | La camiseta es más barata que el abrigo.
| Mayor calidez (más abrigado) | wärmer + als | Der Mantel ist wärmer als die Jacke. | El abrigo es más abrigado que la chaqueta.
| Igualdad (tan... como) | so + adjetivo + wie | Er ist so groß wie sein Bruder. | Es tan alto como su hermano.
w schneller = con más velocidad, más rápido | SHNE-la
w schnell = veloz, rápido | shnel
w bequem = confortable, cómodo | be-KVEM
w bequemer = más confortable | be-KVE-ma
w wärmer = más cálido, más abrigado | VER-ma
w stimmt = es cierto, concuerda | shtimt
w Modell = modelo (das) | mo-DEL
V Vocabulario: comparar con als
D ¿Cuál es mejor?
Tim: Welches Handy gefällt dir besser, Felix? = ¿Qué móvil te gusta más, Felix?
  > Welches Handy = qué móvil | gefällt dir besser = te gusta más
Felix: Das schwarze Handy ist schneller als das weiße Handy. = El móvil negro es más rápido que el móvil blanco.
  > schneller als = más rápido que
Tim: Aber das weiße Handy ist oft billiger als das schwarze Modell! = ¡Pero el móvil blanco es a menudo más barato que el modelo negro!
  > oft billiger als = a menudo más barato que
Felix: Das stimmt, aber dieser Mantel ist wärmer als diese Jacke. = Es verdad, pero este abrigo es más cálido que esta chaqueta.
  > Das stimmt = es verdad | wärmer als = más cálido que
Tim: Ja, und dieses Hemd ist so bequem wie mein Pullover. = Sí, y esta camisa es tan cómoda como mi jersey.
  > so bequem wie = tan cómoda como
T Vergleiche im Alltag
- Das schwarze Handy ist schneller als das weiße Handy. = El móvil negro es más rápido que el móvil blanco.
  > schneller als = más rápido que
- Dieses T-Shirt ist billiger als der Mantel. = Esta camiseta es más barata que el abrigo.
  > billiger als der Mantel = más barata que el abrigo
- Mein Bruder ist so groß wie mein Vater. = Mi hermano es tan alto como mi padre.
  > so groß wie = tan alto como
Q ¿Qué conjunción se emplea en alemán para la comparación de superioridad («más rápido que...»)?
+ als :: Tras una forma comparativa en «-er» se usa obligatoriamente «als».
- wie :: «Wie» se reserva para comparaciones de igualdad («so schnell wie»).
- dass :: «Dass» es una conjunción subordinante que significa «que» completivo.
Q ¿Cómo se expresa «El móvil negro es más rápido que el modelo blanco» en alemán?
+ Das schwarze Handy ist schneller als das weiße Modell. :: Se forma el comparativo regular «schneller» seguido de «als».
- Das schwarze Handy ist mehr schnell als das weiße Modell. :: En alemán no se utiliza «mehr» para formar el comparativo de adjetivos.
- Das schwarze Handy ist schneller wie das weiße Modell. :: Con comparativos de desigualdad no debe utilizarse «wie».
Q ¿Qué estructura expresa igualdad entre dos elementos en alemán?
+ so ... wie :: La correlación para «tan ... como» es «so + adjetivo base + wie».
- so ... als :: «Als» no se combina con «so» para indicar igualdad.
- mehr ... wie :: Estructura inexistente en la norma gramatical alemana.
H Dieses T-Shirt ist billiger ___ der Mantel.
+ als :: La conjunción que sigue a «billiger» es «als».
- wie :: Solo se usa con comparaciones de igualdad.
- von :: «Von» indica procedencia o autoría.
H Das schwarze Handy ist ___ als das weiße Modell. (más rápido)
+ schneller :: Comparativo regular del adjetivo «schnell»: sufijo «-er».
- schnell :: Es el adjetivo positivo sin graduar.
- am schnellsten :: Es la forma de grado superlativo.
R Dieser Mantel ist wärmer als diese Jacke. :: ¿Qué significa esta frase?
+ Este abrigo es más cálido que esta chaqueta. :: «Wärmer als» expresa mayor calidez comparativa.
- Esta chaqueta es más cálida que este abrigo. :: El sujeto de la oración es «Dieser Mantel».
- Este abrigo es tan cálido como esta chaqueta. :: La igualdad se expresaría con «so warm wie».
O Dieses Handy ist schneller als das weiße Modell :: Este móvil es más rápido que el modelo blanco :: Sujeto + verbo + comparativo + als + término.

@ 7 | Adjektive nach sein | Adjetivo predicativo
I Descubre la sencillez de los adjetivos predicativos en alemán: cuando van después de verbos como sein no llevan ninguna terminación y son invariables.
E Adjetivos después de «sein» (función predicativa) :: En alemán existe una regla que simplifica enormemente la gramática: :: 1. **Adjetivo predicativo (invariable):** :: Cuando el adjetivo aparece detrás de un verbo como **sein** (ser/estar) para describir al sujeto, **nunca añade desinencias**, sin importar el género ni el número: :: **Der Mantel ist warm.** (El abrigo es cálido). :: **Die Jacke ist warm.** (La chaqueta es cálida). :: **Das Kleid ist warm.** (El vestido es cálido). :: **Die Schuhe sind bequem.** (Los zapatos son cómodos). :: 2. **Contraste con la posición atributiva:** :: Solo cuando el adjetivo se coloca *delante* del sustantivo recibe terminaciones (*ein warmer Mantel*, *eine warme Jacke*). :: Detrás de **ist** o **sind**, la forma permanece siempre pura y básica: **schön, neu, alt, kurz, teuer, billig, bequem**.
B Adjetivo predicativo: siempre invariable | Sujeto | Verbo | Adjetivo | Traducción
| Der Mantel (masculino) | ist | warm | El abrigo es cálido.
| Die Hose (femenino) | ist | neu | El pantalón es nuevo.
| Das Kleid (neutro) | ist | schön | El vestido es bonito.
| Die Schuhe (plural) | sind | bequem | Los zapatos son cómodos.
w kurz = de poca longitud, corto | kurts
w praktisch = de uso práctico | PRAK-tish
w wirklich = verdaderamente | VIRK-lij
w findest = consideras, encuentras | FIN-dest
w zu = con exceso, demasiado | tsu
w hier = aquí mismo, por aquí | hia
V Vocabulario: adjetivos predicativos
D Probándose ropa
Maria: Wie findest du diese Jeans, Anna? = ¿Qué te parecen estos vaqueros, Anna?
  > Wie findest du = qué consideras | diese Jeans = estos vaqueros
Anna: Die Jeans ist wirklich modern und bequem. = Los vaqueros son verdaderamente modernos y cómodos.
  > wirklich modern = verdaderamente modernos | bequem = cómodos
Maria: Und dieser Rock? Ist er zu kurz? = ¿Y esta falda? ¿Es demasiado corta?
  > dieser Rock = esta falda | zu kurz = demasiado corta
Anna: Nein, der Rock ist nicht zu kurz, er ist sehr schön und elegant. = No, la falda no es demasiado corta, es muy bonita y elegante.
  > nicht zu kurz = no demasiado corta | sehr schön und elegant = muy bonita y elegante
Maria: Aber die Jacke hier ist zu groß für mich. = Pero la chaqueta de aquí es demasiado grande para mí.
  > zu groß = demasiado grande | für mich = para mí
T Kleidung und Adjektive
- Das Kleid ist schön und die Schuhe sind bequem. = El vestido es bonito y los zapatos son cómodos.
  > Das Kleid ist schön = el vestido es bonito | die Schuhe sind bequem = los zapatos son cómodos
- Dieser Pullover ist warm, aber er ist nicht teuer. = Este jersey es abrigado, pero no es caro.
  > Dieser Pullover ist warm = este jersey es abrigado | nicht teuer = no es caro
- Meine Jacke ist alt, aber die Hose ist neu. = Mi chaqueta es vieja, pero el pantalón es nuevo.
  > Meine Jacke ist alt = mi chaqueta es vieja | die Hose ist neu = el pantalón es nuevo
Q Cuando un adjetivo va detrás del verbo «sein» (función predicativa), ¿qué terminación recibe?
+ Ninguna terminación; el adjetivo queda en su forma base e invariable. :: Tras el verbo «sein», los adjetivos no se declinan: «Die Schuhe sind bequem».
- La terminación «-e» si el sujeto es femenino o plural. :: Solo reciben desinencia si van directamente delante del sustantivo.
- Siempre la terminación «-er». :: «-er» es la marca del comparativo, no de la función predicativa.
Q ¿Cuál es la forma correcta para decir «Los zapatos son cómodos»?
+ Die Schuhe sind bequem. :: Al ir tras «sind», el adjetivo predicativo no añade ninguna desinencia.
- Die Schuhe sind bequeme. :: «Bequeme» llevaría terminación atributiva indebida tras «sein».
- Die Schuhe sind bequemen. :: Forma incorrecta para la función predicativa.
Q En la frase «Dieser Rock ist sehr schön», ¿por qué «schön» no lleva terminación?
+ Porque funciona como adjetivo predicativo detrás del verbo «ist». :: Los adjetivos que siguen a «sein» no se declinan jamás.
- Porque «Rock» es masculino y los masculinos nunca declinan adjetivos. :: Delante de sustantivo sí se declinan («ein schöner Rock»).
- Porque «sehr» elimina las terminaciones adjetivales. :: El adverbio de grado no altera la regla sintáctica.
H Das Kleid ist schön und die Schuhe sind ___ . (cómodos)
+ bequem :: Tras «sind», el adjetivo predicativo no recibe terminación: «bequem».
- bequeme :: Es un error añadir desinencia atributiva en posición predicativa.
- bequemer :: Expresaría comparativo («más cómodo»), no la cualidad simple.
H Diese Jacke ist zu ___ für mich. (grande)
+ groß :: Forma invariable del adjetivo predicativo tras «ist».
- große :: No lleva desinencia atributiva en esta posición.
- großen :: No se declina tras el verbo «sein».
R Meine Jacke ist alt, aber die Hose ist neu. :: ¿Qué significa esta frase?
+ Mi chaqueta es vieja, pero el pantalón es nuevo. :: Ambos adjetivos («alt» y «neu») van en posición predicativa sin desinencias.
- Mi chaqueta es nueva, pero el pantalón es viejo. :: El orden de los adjetivos está invertido en esta opción.
- Mi abrigo es caro, pero los zapatos son baratos. :: Los sustantivos son «Jacke» y «Hose».
O Das Kleid ist schön und modern :: El vestido es bonito y moderno :: Sujeto neutro + verbo + predicativo + und + predicativo.
