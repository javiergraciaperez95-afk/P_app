@ 36 | Eine Studie zum Verkehr | Leer un resumen de investigación
I Distingue tema, resultado, explicación propuesta y límite de los datos.
E Lectura práctica :: En un resumen de investigación, separa lo que midió el estudio de las causas que proponen sus autores; **jedoch** introduce una limitación.
W Studie = estudio
W vergleicht = compara (de «vergleichen»)
W Nutzung = uso, utilización
W öffentlicher = público (genitivo masculino)
W Städten = ciudades (dativo plural)
W deutlichen = notable (forma declinada)
W Anstieg = aumento
W Fahrgastzahlen = cifras de pasajeros
W Forschende = investigadores
W Verbindung = conexión
W Gründe = motivos, razones
W betont = subraya (de «betonen»)
W jedoch = sin embargo
W Daten = datos
W Zeitraum = periodo de tiempo
W abbilden = reflejar, representar
V Vocabulario de investigación
T Verkehr und Nachfrage
- Eine Studie vergleicht die Nutzung öffentlicher Verkehrsmittel in drei Städten. = Un estudio compara el uso del transporte público en tres ciudades.
- Die Umfrage zeigt einen deutlichen Anstieg der Fahrgastzahlen. = La encuesta muestra un aumento notable del número de pasajeros.
- Forschende nennen den Preis und die bessere Verbindung als Gründe. = Los investigadores señalan el precio y una mejor conexión como motivos.
- Der Bericht betont jedoch, dass die Daten nur einen Zeitraum abbilden. = Sin embargo, el informe subraya que los datos solo reflejan un periodo.
Q ¿Qué compara el estudio?
+ El uso del transporte público en tres ciudades :: Es el tema de la primera frase.
- El precio de los coches en una ciudad :: No aparece.
- El número de trenes de mercancías :: No se menciona.
Q ¿Qué cambio muestra la encuesta?
+ Un aumento notable de pasajeros :: La segunda frase lo especifica.
- Una caída de los precios :: No aparece.
- Una reducción de las conexiones :: No se afirma.
Q ¿Qué motivos citan los investigadores?
+ El precio y una mejor conexión :: La tercera frase enumera ambos.
- El clima y el tamaño de las ciudades :: No aparecen.
- La duración de los viajes únicamente :: No se menciona.
Q ¿Qué limitación señala el informe?
+ Los datos reflejan solo un periodo :: La última frase presenta ese límite.
- El estudio no compara ciudades :: La primera frase sí lo hace.
- La encuesta no incluye pasajeros :: El texto habla de sus cifras.
Q ¿Qué función cumple «jedoch»?
+ Introduce un contraste o una limitación :: Presenta una reserva sobre los datos.
- Añade un motivo más :: No añade una causa.
- Indica una conclusión segura :: No es su función aquí.
Q ¿Qué diferencia hay entre el resultado y la explicación?
+ La encuesta muestra un aumento; los investigadores proponen motivos :: El texto separa dato y explicación.
- Los investigadores realizaron la encuesta en un solo periodo :: No se afirma quién la realizó.
- El precio es el único resultado medido :: Es uno de los motivos propuestos.
