@ 39 | Das muss bezahlt werden | Eso hay que pagarlo
I Hoy juntamos dos cosas: la pasiva y los verbos modales. Es muy útil para hablar de obligaciones en compras, contratos y normas.
E Pasiva con modal :: Se forma con el modal conjugado + **werden** + participio al final: **Das muss bezahlt werden** (eso hay que pagarlo). El modal va en segunda posición, y al final van los dos verbos: el participio y **werden**. :: Con otros modales: **Die Ware kann umgetauscht werden** (la mercancía puede cambiarse), **Der Vertrag soll unterschrieben werden** (el contrato debe firmarse).
E Pasiva en Perfekt :: El Perfekt pasivo se forma con **ist … worden** (sein + worden + participio): **Die Ware ist gestern geliefert worden** (la mercancía se entregó ayer). El participio «worden» sustituye al participio de «werden». Ojo con el falso amigo: **worden** no significa «hecho», sino el participio de «werden» en la pasiva.
B Forma | Ejemplo | Significado
| modal + werden + participio | Das muss bezahlt werden. | Eso hay que pagarlo.
| ist … worden + participio | Die Ware ist geliefert worden. | La mercancía se ha entregado.
| wurde + participio (pasado) | Die Ware wurde geliefert. | La mercancía se entregó.
W Ware = mercancía (die) existente (082)
W umtauschen = cambiar (un producto) | UM-tau-shen
W umgetauscht = cambiado (participio de «umtauschen») | UM-ge-tauscht
W geliefert = entregado (participio de «liefern») | ge-LI-fert
W worden = (participio de «werden» en pasiva) | VOR-den
W Rabatt = descuento (der) | ra-BAT
W Zahlung = pago (die) | TSA-lung
W Kreditkarte = tarjeta de crédito (die) | kre-DIT-kar-te
W Bargeld = dinero en efectivo (das) | BAR-gelt
W Käufer = comprador (der) | KOI-fer
W Auktion = subasta (die) | auk-TSION
W Produkt = producto (das) | pro-DUKT
W Marke = marca (die) | MAR-ke
W Kundenservice = servicio de atención al cliente (der) | KUN-den-zer-vis
W Quittung = recibo (die) | KVIT-tung
W eingerechnet = incluido en el cálculo (participio de «einrechnen») | AIN-ge-rekh-net
W bestätigt = confirmado (participio de «bestätigen») | be-SHTE-tigt
W Betrag = importe, cantidad (der) | be-TRAK
V Vocabulario: compras
D En la tienda
Lena: Das Produkt muss heute bezahlt werden. = Este producto hay que pagarlo hoy.
  > muss = hay que | bezahlt werden = pagarlo
Tim: Die Ware kann noch umgetauscht werden, wenn der Kassenbon da ist. = La mercancía todavía se puede cambiar si está el ticket.
  > kann = se puede | umgetauscht werden = cambiar
Lena: Der Rabatt ist schon eingerechnet, oder? = El descuento ya está incluido, ¿verdad?
  > Der Rabatt ist = el descuento está
Tim: Ja, die Zahlung ist gestern bestätigt worden. = Sí, el pago se confirmó ayer.
  > ist = ha sido | bestätigt worden = confirmado
Q ¿Cómo se dice «eso hay que pagarlo»?
+ Das muss bezahlt werden. :: Modal + participio + werden al final.
- Das muss bezahlen werden. :: El participio es «bezahlt».
- Das muss bezahlt worden. :: El modal va con werden.
Q ¿Qué forma es el Perfekt pasivo de «liefern» (entregar)?
+ ist geliefert worden :: sein + participio + worden.
- ist geliefert werden :: Falta «worden».
- hat geliefert worden :: Con pasiva se usa sein.
R Die Ware kann umgetauscht werden.
+ La mercancía se puede cambiar. :: kann + participio + werden: posibilidad.
- La mercancía puede cambiar. :: Eso sería activa.
- La mercancía cambió. :: Es pasado.
H Der Vertrag soll ___ werden. :: unterschrieben
+ unterschrieben :: Participio al final.
- unterschreiben :: Es el infinitivo.
- unterschreibt :: Es presente activo.
A Die Ware ist gestern geliefert worden.
+ La mercancía se entregó ayer. :: ist geliefert worden = se ha entregado.
- La mercancía se entrega mañana. :: Es futuro.
- La mercancía fue vendida ayer. :: No es «geliefert».
O Das muss bezahlt werden :: Eso hay que pagarlo :: modal + participio + werden.
Q ¿Qué significa «der Rabatt»?
+ el descuento :: Rabatt = descuento.
- el recibo :: Eso sería «Quittung».
- la marca :: Eso sería «Marke».
X Escribe en alemán: «la mercancía puede cambiarse» :: Die Ware kann umgetauscht werden | Die Ware kann umgetauscht werden :: modal + werden al final.

@ 39 | Mir wurde geholfen | Me ayudaron
I Hoy vemos la pasiva con dativo: cuando el complemento que recibe la acción va en dativo, la frase pasiva empieza por el dativo.
E Pasiva con dativo :: En alemán hay verbos con dativo (**helfen**, **danken**, **gratulieren**). En pasiva se mantiene el dativo y la frase empieza por él, con **es** o sin sujeto real: **Mir wurde geholfen** (me ayudaron). Literalmente: «a mí se me ayudó». :: Con «es» delante, se usa para introducir la frase: **Es wurde mir geholfen** (me ayudaron; se me ayudó).
E Verbos con dativo en pasiva :: **Mir wurde gedankt** (me dieron las gracias), **Ihm wurde gratuliert** (le felicitaron). Solo se pueden pasivizar en impersonal, sin sujeto. Ojo con el falso amigo: en alemán **gedankt werden** no es «ser agradecido», sino «recibir las gracias».
B Activa | Pasiva con dativo | Significado
| Man hat mir geholfen. | Mir wurde geholfen. | Me ayudaron.
| Man hat ihm gedankt. | Ihm wurde gedankt. | Le dieron las gracias.
| Man hat uns gratuliert. | Uns wurde gratuliert. | Nos felicitaron.
W geholfen = ayudado (participio de «helfen») existente (024)
W gedankt = agradecido, dado las gracias (participio de «danken») | ge-DANKT
W danken = agradecer, dar las gracias | DAN-ken
W gratuliert = felicitado (participio de «gratulieren») | gra-tu-LIRT
W gratulieren = felicitar | gra-tu-LI-ren
W Glückwunsch = felicitación (der) | GLÜK-vunsch
W Auftrag = encargo (der) | AUF-trak
W Beratung = asesoramiento (die) | be-RA-tung
W Lob = elogio (das) | lop
W loben = elogiar | LO-ben
W Kauf = compra (der) | kauf
W gelobt = elogiado (participio de «loben») | ge-LOBT
V Vocabulario: agradecimientos
D Después de la venta
Anna: Mir wurde beim Kauf sehr geholfen. = Me ayudaron mucho en la compra.
  > Mir wurde = me ayudaron | sehr geholfen = mucho
Tim: Ihm wurde für den Auftrag gedankt. = Le dieron las gracias por el encargo.
  > Ihm wurde = le dieron | gedankt = las gracias
Anna: Uns wurde zum Erfolg gratuliert. = Nos felicitaron por el éxito.
  > Uns wurde = nos felicitaron | gratuliert = felicitados
Tim: Auch die Beratung wurde gelobt. = También elogiaron el asesoramiento.
  > die Beratung = el asesoramiento | wurde gelobt = fue elogiado
Q ¿Cómo se dice «me ayudaron»?
+ Mir wurde geholfen. :: La pasiva con dativo empieza por «mir».
- Ich wurde geholfen. :: «mir» es dativo: no es «ich».
- Mich wurde geholfen. :: Con «helfen» va dativo, no acusativo.
Q ¿Qué forma es correcta para «le dieron las gracias»?
+ Ihm wurde gedankt. :: Dativo + wurde + participio.
- Ihn wurde gedankt. :: «ihn» es acusativo.
- Er wurde gedankt. :: Falta el dativo.
R Uns wurde gratuliert.
+ Nos felicitaron. :: Pasiva con dativo: uns.
- Nos felicitamos. :: Eso sería reflexivo.
- Felicitamos. :: Eso sería activa.
H Mir ___ geholfen. :: wurde
+ wurde :: Pasado pasivo de «werden».
- wird :: Es presente.
- worden :: Es participio.
A Ihm wurde für den Auftrag gedankt.
+ Le dieron las gracias por el encargo. :: Dativo + pasiva.
- Él dio las gracias por el encargo. :: Eso sería activa.
- Él recibió un encargo. :: Eso no es esta frase.
O Mir wurde geholfen :: Me ayudaron :: pasiva con dativo al principio.
Q ¿Qué significa «gratulieren»?
+ felicitar :: gratulieren = felicitar.
- agradecer :: Eso sería «danken».
- elogiar :: Eso sería «loben».
X Escribe en alemán: «nos felicitaron por el éxito» :: Uns wurde zum Erfolg gratuliert | Uns wurde zum Erfolg gratuliert :: dativo + wurde + participio.

@ 39 | Zahlung, Kauf und Quittung | Pago, compra y recibo
I Cerramos el capítulo con un texto de compra y pago en el que se mezclan pasiva, modales y estilo nominal.
E Estilo nominal con pasiva :: En textos de comercio se mezcla todo: **Nach der Zahlung wird die Quittung ausgestellt** (después del pago se emite el recibo). El sustantivo expresa la acción y la pasiva dice quién o cómo se hace. :: Con **werden** se describe el proceso; con **sein** y participio, el resultado: **Die Quittung ist ausgestellt** (el recibo está emitido).
E Repaso rápido :: **muss bezahlt werden** (obligación), **kann umgetauscht werden** (posibilidad), **ist geliefert worden** (resultado del pasado), **wurde gedankt** (pasiva con dativo). No hace falta memorizarlo todo; repítelo en tus diálogos de compra.
B Estructura | Uso | Ejemplo
| werden + participio | proceso | Die Quittung wird ausgestellt.
| sein + participio | resultado | Die Quittung ist ausgestellt.
| modal + werden | obligación o posibilidad | Die Quittung muss ausgestellt werden.
W ausgestellt = emitido (participio de «ausstellen») existente (098)
W gerechnet = calculado (participio de «rechnen») | ge-REKHNET
W rechnen = calcular | REKH-nen
V Vocabulario: pagar
D En la caja
Verkäuferin: Nach der Zahlung wird die Quittung ausgestellt. = Después del pago se emite el recibo.
  > nach der Zahlung = después del pago | wird = se | ausgestellt = emite
Kunde: Kann ich mit Kreditkarte zahlen? = ¿Puedo pagar con tarjeta de crédito?
  > kann ich = ¿puedo? | zahlen = pagar
Verkäuferin: Ja, aber der Betrag muss sofort bezahlt werden. = Sí, pero el importe hay que pagarlo enseguida.
  > muss = hay que | sofort bezahlt werden = pagarse enseguida
Kunde: Gut, dann nehme ich auch den Gutschein. = Bien, entonces también tomo el vale.
  > nehme ich = tomo | den Gutschein = el vale
Q ¿Qué significa «eingerechnet»?
+ incluido en el cálculo :: einrechnen = incluir en el cálculo.
- excluido :: Es lo contrario.
- pagado :: Eso sería «bezahlt».
R Nach der Zahlung wird die Quittung ausgestellt.
+ Después del pago se emite el recibo. :: wird + participio: proceso.
- Después del pago se emitió el recibo. :: Es pasado.
- Después del pago el recibo está emitido. :: Eso sería estado.
H Die Quittung ___ ausgestellt. :: está
+ ist :: sein + participio: resultado.
- wird :: Es proceso.
- wurde :: Es pasado de proceso.
A Der Betrag muss sofort bezahlt werden.
+ El importe hay que pagarlo enseguida. :: muss + bezahlt werden.
- El importe puede pagarse más tarde. :: Eso sería «kann … später».
- El importe ya está pagado. :: Eso sería estado.
O Die Quittung wird ausgestellt :: Se emite el recibo :: pasiva de proceso.
Q ¿Qué sustantivo corresponde a «der Betrag»?
+ el importe :: Betrag = importe, cantidad.
- el recibo :: Eso sería «Quittung».
- la marca :: Eso sería «Marke».
Q ¿Cómo se dice «hay que firmar el contrato»?
+ Der Vertrag muss unterschrieben werden. :: Modal + participio + werden.
- Der Vertrag muss unterschreiben werden. :: El participio es «unterschrieben».
- Der Vertrag muss unterschrieben sein. :: Es estado, no obligación de proceso.
X Escribe en alemán: «el recibo se emite después del pago» :: Die Quittung wird nach der Zahlung ausgestellt | Die Quittung wird nach der Zahlung ausgestellt :: werden + participio al final.
