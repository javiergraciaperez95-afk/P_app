@ 23 | Das Haus wird renoviert | La casa se está renovando
I Hoy cambiamos de punto de vista: nos interesa lo que pasa, no quién lo hace. Eso es la **voz pasiva**, y en alemán se forma con **werden** y el participio.
E Pasiva en presente :: Se forma con **werden** conjugado y el participio al final: **Das Haus wird renoviert** (la casa se está renovando). Es la forma de «se» + verbo o de «ser + participio» del español, pero siempre con «werden». :: El que hace la acción va con **von** + dativo: **Das Haus wird vom Architekten geplant** (la casa la diseña el arquitecto).
E Activa y pasiva :: En activa el sujeto hace la acción: **Der Architekt plant das Haus** (el arquitecto diseña la casa). En pasiva el objeto pasa a ser el sujeto: **Das Haus wird vom Architekten geplant**. :: Ojo con el falso amigo: «se» en español puede ser pasiva o reflexiva. En alemán la pasiva siempre usa **werden**.
B Forma | Ejemplo | Significa
| werden + participio | Das Haus wird gebaut. | La casa se construye.
| werden + von + dativo | Das Haus wird vom Architekten geplant. | La casa la diseña el arquitecto.
| Man baut das Haus. (activa) | Man baut ein Haus. | Se construye una casa.
W bauen = construir | BAU-en
W gebaut = construido (participio de «bauen») | ge-BAUT
W renovieren = renovar | re-no-VI-ren
W renoviert = renovado (participio de «renovieren») | re-no-VIRT
W geplant = planeado, diseñado (participio de «planen») | ge-PLANT
W planen = planear, diseñar | PLA-nen
W Architekt = arquitecto (der) | ar-shi-TEKT
W Umwelt = medio ambiente (die) | UM-velt
W Energie = energía (die) | e-ner-GI
W Strom = electricidad (der) | shtrom
W Heizung = calefacción (die) | HAI-tsung
W Solaranlage = instalación solar (die) | SO-lar-an-la-ge
W Architekten = arquitecto (dativo de «Architekt») | ar-shi-TEK-ten
W sparen = ahorrar | SHPA-ren
W repariert = reparado (participio de «reparieren») | re-pa-RIRT
W Dach = tejado (das) | dach
W gerade = ahora mismo, justo | ge-RA-de
W wirklich = de verdad, realmente | VIRK-lij
V Vocabulario: la casa y la energía
D La reforma
Lena: Das Haus wird gerade renoviert. = La casa se está renovando ahora mismo.
  > Das Haus wird = la casa se | gerade renoviert = ahora mismo renovando
Thomas: Wirklich? Und wird die Solaranlage vom Architekten geplant? = ¿De verdad? ¿Y la instalación solar la diseña el arquitecto?
  > wird = se | geplant = diseñada | vom Architekten = por el arquitecto
Lena: Ja. Und das Dach wird im Sommer gebaut. = Sí. Y el tejado se construirá en verano.
  > das Dach = el tejado | wird = se | gebaut = construido
Thomas: Gut. Dann sparen wir Strom und Energie. = Bien. Así ahorramos electricidad y energía.
  > sparen wir = ahorramos | Strom und Energie = electricidad y energía
Q ¿Qué verbo auxiliar forma la pasiva en alemán?
+ werden :: Pasiva: werden + participio.
- sein :: Con «sein» se forma otro tipo de frase.
- haben :: Es para el Perfekt.
Q ¿Cómo se dice «la casa se construye»?
+ Das Haus wird gebaut. :: werden + participio al final.
- Das Haus baut sich. :: Es reflexivo, no pasiva.
- Das Haus wird bauen. :: Falta el participio.
R Das Haus wird vom Architekten geplant.
+ La casa la diseña el arquitecto. :: von + dativo indica quién hace la acción.
- El arquitecto diseña la casa. :: Eso es activa.
- La casa se diseña. :: Falta quién lo hace.
H Die Heizung ___ repariert. :: se repara
+ wird :: Con «die Heizung» (singular) → wird.
- werden :: Es con «sie» o «wir» (plural).
- wurde :: Es Präteritum, no presente.
H Das Dach wird im Sommer ___ . :: construido
+ gebaut :: Participio de «bauen».
- bauen :: Es el infinitivo.
- baut :: Es activa.
A Das Haus wird gerade renoviert.
+ La casa se está renovando ahora mismo. :: wird + renoviert = se renueva.
- La casa se renovó ayer. :: Es pasado.
- La casa renueva a los vecinos. :: Eso no es esta frase.
O Das Haus wird gebaut :: La casa se construye :: werden + participio al final.
Q ¿Cuál es la forma pasiva correcta para «se diseña la instalación»?
+ Die Solaranlage wird geplant. :: wird + participio: pasiva.
- Die Solaranlage wird planen. :: Falta el participio.
- Die Solaranlage plant sich. :: Es reflexivo.
X Escribe en alemán: «la casa se construye en verano» :: Das Haus wird im Sommer gebaut | Das Haus wird im Sommer gebaut :: werden + participio al final.

@ 23 | Die Heizung wurde repariert | La calefacción fue reparada
I Ahora contamos algo pasado en pasiva. Para eso usamos **wurde** o **wurden**, el Präteritum de «werden».
E Pasiva en Präteritum :: Se forma con **wurde** (singular) o **wurden** (plural) y el participio al final: **Die Heizung wurde gestern repariert** (la calefacción fue reparada ayer). El orden de la frase no cambia: el verbo conjugado va en segunda posición. :: En plural: **Die Fenster wurden ausgetauscht** (las ventanas fueron cambiadas).
E Perfekt pasivo (solo como aviso) :: En conversación también se dice **ist … worden**: **Die Heizung ist repariert worden** (la calefacción ha sido reparada). Lo verás más adelante en los textos. :: Ojo: **worden** es el participio de «werden» y aparece detrás del participio.
B Tiempo | Forma | Ejemplo
| Präsens | wird + participio | Das Haus wird gebaut.
| Präteritum | wurde + participio | Die Heizung wurde repariert.
| Präteritum (plural) | wurden + participio | Die Fenster wurden ausgetauscht.
W reparieren = reparar | re-pa-RI-ren
W wurde = fue, era (pasiva; Präteritum de «werden») | VUR-de
W wurden = fueron, eran (pasiva; plural) | VUR-den
W ausgetauscht = cambiado (participio de «austauschen») | AUS-ge-tauscht
W austauschen = cambiar, sustituir | AUS-tau-shen
W Müll = basura (der) | mül
W Mülltrennung = separación de residuos (die) | MÜL-tren-nung
W Recycling = reciclaje (das) | ri-SAI-kling
W Plastik = plástico (das) | PLAS-tik
W Papier = papel (das) | pa-PIR
W bezahlt = pagado (participio de «bezahlen») | be-TSALT
W bezahlen = pagar | be-TSA-len
W getrennt = separado (participio de «trennen») | ge-TRENT
W trennen = separar | TRE-nen
W gestern = ayer (existente) | GES-tern
W Vermieter = propietario, arrendador (der) | fer-MI-ter
W Schimmel = moho (der) | SHI-mel
V Vocabulario: reparaciones y reciclaje
D Un problema en el piso
Julia: Die Heizung wurde gestern repariert. = La calefacción fue reparada ayer.
  > Die Heizung wurde = la calefacción fue | gestern repariert = reparada ayer
Peter: Gut! Und wer hat das bezahlt? = ¡Bien! ¿Y quién lo pagó?
  > wer hat das bezahlt = ¿quién lo pagó?
Julia: Der Vermieter. Die Fenster wurden auch ausgetauscht. = El propietario. También se cambiaron las ventanas.
  > die Fenster = las ventanas | wurden = fueron | ausgetauscht = cambiadas
Peter: Super. Dann gibt es keinen Schimmel mehr. = Genial. Así ya no hay moho.
  > keinen Schimmel = ningún moho | mehr = ya no
Q ¿Qué forma de pasiva en Präteritum corresponde a un plural?
+ wurden :: Plural de «wurde».
- wurde :: Es singular.
- werden :: Es el infinitivo.
R Die Heizung wurde gestern repariert.
+ La calefacción fue reparada ayer. :: wurde + participio: pasado pasivo.
- La calefacción se repara hoy. :: Es presente pasivo.
- La calefacción reparó ayer. :: Es activa.
H Die Fenster ___ ausgetauscht. :: fueron
+ wurden :: Plural de Präteritum pasivo.
- wurde :: Singular.
- werden :: Infinitivo.
A Die Fenster wurden ausgetauscht.
+ Las ventanas fueron cambiadas. :: wurden + participio.
- Las ventanas cambian. :: Es presente.
- Las ventanas cambiaron. :: Eso sería activa.
O Die Fenster wurden ausgetauscht :: Las ventanas fueron cambiadas :: wurden + participio al final.
Q ¿Qué significa «keinen Schimmel mehr»?
+ ya no hay moho :: mehr = ya no.
- hay más moho :: Eso sería «mehr Schimmel».
- hay mucho moho :: Eso sería «viel Schimmel».
H Der Müll ___ getrennt. :: se separó
+ wurde :: Singular del Präteritum pasivo.
- wird :: Es presente.
- wurden :: Es plural.
X Escribe en alemán: «la basura fue separada ayer» :: Der Müll wurde gestern getrennt | Der Müll wurde gestern getrennt :: wurde + participio al final.

@ 23 | Ich lasse das Dach reparieren | Hago reparar el tejado
I Ahora un verbo muy útil: **lassen**. Significa «dejar» y también «hacer que alguien haga algo» (mandar hacer).
E lassen: mandar hacer algo :: Con **lassen** + infinitivo, el sujeto no hace la acción: **Ich lasse das Dach reparieren** (hago reparar el tejado). El infinitivo va al final. :: Se conjuga: **ich lasse, du lässt, er/sie lässt, wir lassen, ihr lasst, sie lassen**. Mira: **du lässt** tiene diéresis.
E lass!: déjalo :: Con el imperativo, **Lass das!** significa «¡déjalo!» y **Lass mich in Ruhe!** significa «¡déjame en paz!». :: Ojo con el falso amigo: **lassen** no significa siempre «dejar en un lugar». Si hay un infinitivo detrás, es «mandar hacer».
B Persona | lassen | Ejemplo
| ich | lasse | Ich lasse das Dach reparieren.
| du | lässt | Du lässt das Auto waschen.
| er / sie | lässt | Sie lässt die Wohnung putzen.
| wir | lassen | Wir lassen die Heizung prüfen.
W lassen = dejar; mandar, hacer que alguien haga algo | LA-sen
W lasse = dejo, mando (de «lassen») | LA-se
W Lass = deja, déjalo (imperativo de «lassen») | las
W liegen = quedar tirado, estar sin hacer | LI-gen
W lässt = deja, manda (de «lassen») | lest
W Ruhe = tranquilidad (die) | RU-e
W prüfen = revisar, comprobar | PRÜ-fen
W putzen = limpiar | PU-tsen
W Putzfrau = señora de la limpieza (die) | PUTS-frau
W waschen = lavar | VA-shen
W Handwerker = operario, técnico (der) | HAND-ver-ker
W schneiden = cortar | SHNAI-den
W Haare = pelo (die, plural) | HA-re
W Friseur = peluquero (der) | fri-ZÖR
W eigentlich = en realidad | AI-gent-lij
V Vocabulario: encargar servicios
D Haciendo cosas en casa
Max: Warum lässt du die Heizung prüfen? = ¿Por qué mandas revisar la calefacción?
  > Warum lässt du = ¿por qué mandas? | die Heizung = la calefacción
Lena: Ich lasse sie prüfen, weil es im Winter kalt wird. = La mando revisar, porque en invierno hace frío.
  > ich lasse sie prüfen = la mando revisar | weil = porque | kalt = frío | wird = se pone
Max: Und wer macht das Dach? = ¿Y quién arregla el tejado?
Lena: Ein Handwerker. Eigentlich lasse ich es morgen reparieren. = Un técnico. En realidad lo mando reparar mañana.
  > lasse ich = mando | es = lo | reparieren = reparar | morgen = mañana
Max: Lass es nicht zu lange liegen. = No lo dejes pasar demasiado tiempo.
  > Lass es nicht zu lange liegen = no lo dejes pasar mucho tiempo
Q ¿Qué significa «Ich lasse das Dach reparieren»?
+ Hago reparar el tejado. :: lassen + infinitivo = mandar hacer.
- Dejo el tejado reparado. :: Eso no es la idea de «lassen».
- Reparo el tejado yo mismo. :: Eso no usa «lassen».
Q ¿Qué forma de «lassen» va con «du»?
+ lässt :: Con «du» → lässt, con diéresis.
- lasse :: Es con «ich».
- lassen :: Es el infinitivo o «wir/sie».
R Sie lässt die Wohnung putzen.
+ Ella manda limpiar el piso. :: lässt + infinitivo: mandar hacer.
- Ella limpia el piso. :: Eso no usa «lassen».
- Ella deja el piso sucio. :: lassen puede ser «dejar», pero aquí va con infinitivo.
H Wir ___ die Heizung prüfen. :: mandamos
+ lassen :: wir lassen = mandamos.
- lasst :: Es con «ihr».
- lässt :: Es con «er/sie».
A Lass das!
+ ¡Déjalo! :: Lass = imperativo de «lassen».
- ¡Hazlo! :: Es «mach».
- ¡Llévatelo! :: No es «lassen» aquí.
O Ich lasse das Dach reparieren :: Hago reparar el tejado :: lassen + infinitivo al final.
Q ¿Cómo se dice «mandamos revisar la calefacción»?
+ Wir lassen die Heizung prüfen. :: lassen en segunda posición; infinitivo al final.
- Wir lassen die Heizung geprüft. :: El participio no va con «lassen».
- Wir lassen prüfen die Heizung. :: El orden no es correcto.
X Escribe en alemán: «mandamos cortar el pelo» :: Wir lassen uns die Haare schneiden | Wir lassen uns die Haare schneiden :: lassen + infinitivo al final.
