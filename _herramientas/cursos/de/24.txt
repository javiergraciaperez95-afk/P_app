@ 24 | Dativ und Akkusativ | Verbos con dos objetos
I Cuando un verbo lleva dos complementos, el alemán asigna la persona al dativo y la cosa al acusativo, y su orden relativo varía según sean sustantivos o pronombres.
E Reglas de caso y orden con dos complementos :: 1. **Asignación de casos**: La persona receptora o beneficiaria va en Dativo (**wem?**); el objeto transferido va en Acusativo (**was?**): **Die Kollegin erklärt den Mitarbeitern (Dativ) die Aufgabe (Akkusativ)**. :: 2. **Orden con dos sustantivos**: El Dativo precede al Acusativo: **Ich gebe dem Kunden (Dat) den Vertrag (Akk)**. :: 3. **Orden con pronombre y sustantivo**: El pronombre siempre va primero, sin importar el caso: **Ich gebe ihm (Pron Dat) den Vertrag (Sust Akk)**; **Ich gebe ihn (Pron Akk) dem Kunden (Sust Dat)**. :: 4. **Orden con dos pronombres**: El Acusativo precede obligatoriamente al Dativo: **Ich gebe ihn (Akk) ihm (Dat)**; **Er erklärt es (Akk) mir (Dat)**.

@ 24 | darauf und damit | Adverbios pronominales
I Para no repetir sustantivos precedidos de preposición cuando se trata de cosas o conceptos abstractos, el alemán recurre a los adverbios pronominales con da(r)-.
E Formación y uso de los adverbios pronominales :: 1. **Formación**: Si la preposición empieza por consonante, se añade **da-**: **da + mit = damit** (con ello), **da + für = dafür** (para ello), **da + von = davon** (de ello). Q ¿En qué caso NO se puede utilizar un adverbio pronominal como «darauf» o «damit»?
+ Cuando el referente es un ser humano o una persona concreta :: Para personas se emplea obligatoriamente la preposición junto al pronombre personal («auf sie», «mit ihm»).
- Cuando se habla de una máquina, herramienta o presupuesto :: Para objetos inanimados o conceptos abstractos el adverbio pronominal es la forma estándar correcta.
- Cuando la oración principal se formula en tiempo pasado Perfekt :: El tiempo verbal no condiciona la elección entre adverbio pronominal y pronombre personal.
Q ¿Por qué se añade una «-r-» en «darauf» o «darüber»?
+ Porque la preposición base comienza por vocal y la «-r-» evita el choque vocálico :: Delante de preposiciones con vocal inicial (auf, an, über, in) se usa «dar-».
- Porque el sustantivo sustituido es de género masculino :: El género gramatical original no influye en la adición eufónica de la «-r-».
- Porque indica obligatoriamente una dirección de movimiento :: No es un prefijo direccional, sino un enlace fonético regular.
H Warten Sie auf den Bus? Ja, ich warte schon zehn Minuten ___ . :: a él
+ darauf :: «warten auf» referido a un medio de transporte inanimado («der Bus») se sustituye por «darauf».
- daauf :: Forma incorrecta sin la «-r-» eufónica necesaria ante vocal.
- auf ihn :: Se reservaría para una persona masculina («auf den Kollegen»).
H Denkst du oft an deine Heimat? Ja, ich denke jeden Tag ___ . :: en ella
+ daran :: «denken an» referido a un concepto o lugar abstracto («die Heimat») se sustituye por «daran».
- daan :: Forma inexistente que omite la «-r-» de enlace fonético.
- an sie :: «an sie» se utilizaría para una persona femenina («an meine Schwester»).
R Bist du mit dem Vorschlag einverstanden? Ja, ich bin damit absolut zufrieden. :: ¿Qué manifiesta la respuesta?
+ Plena conformidad y satisfacción con la propuesta presentada. :: «damit zufrieden» retoma «mit dem Vorschlag» mediante el adverbio pronominal.
- Rechazo total a la propuesta por motivos presupuestarios. :: Contradice el acuerdo explícito de la respuesta («damit zufrieden»).
- Duda sobre si la propuesta beneficiará a los clientes. :: No expresa duda, sino conformidad categórica.
H Freust du dich auf deine Schwester? Ja, ich freue mich sehr auf ___ . :: ella
+ sie :: «deine Schwester» es un ser humano; no se puede usar «darauf», sino la preposición más pronombre personal («auf sie»).
- darauf :: Los adverbios pronominales con «da-» nunca se refieren a personas concretas.
- ihr :: Tras «auf» (acusativo en este régimen) el pronombre de 3ª persona femenina es «sie», no el dativo «ihr».
O Ich freue mich sehr darauf :: Me alegro mucho de ello :: sujeto + reflexivo + adverbio + darauf al final.

@ 24 | Worauf und woran | Preguntar por cosas
I Para interrogar sobre cosas o conceptos ligados a verbos con preposición, el alemán utiliza interrogativos pronominales con wo(r)-, reservando «Präposition + wen/wem» para personas.
E Interrogativos con cosas frente a preguntas por personas :: 1. **Preguntar por cosas**: Se antepone **wo-** a la preposición si empieza por consonante (**womit, wofür, wovon**), o **wor-** si empieza por vocal (**worauf, woran, worüber**): **Worauf wartest du? — Auf den Zug** (¿a qué esperas? — Al tren); **Woran denkst du? — An meine Arbeit** (¿en qué piensas? — En mi trabajo). :: 2. **Preguntar por personas**: Se coloca la preposición delante del pronombre interrogativo correspondiente (**wen** para acusativo, **wem** para dativo): **Auf wen wartest du? — Auf den Chef** (¿a quién esperas? — Al jefe); **Von wem sprichst du? — Von meiner Kollegin** (¿de quién hablas? — De mi compañera).

| sprechen über (+ Akk) | Worüber? | Über wen? | Über den Plan. / Über Maria.

Q ¿Qué estructura se utiliza para preguntar por una persona tras una preposición que rige acusativo?
+ «Präposition + wen» (por ejemplo: «Auf wen wartest du?») :: Las personas requieren la preposición seguida del pronombre interrogativo «wen» (acusativo) o «wem» (dativo).
- Un interrogativo con «wor-» (por ejemplo: «Worauf wartest du?») :: Las formas con «wo(r)-» se refieren exclusivamente a cosas, hechos o conceptos.
- La partícula interrogativa «was» seguida de la preposición al final :: Es una construcción del inglés («What are you waiting for?») inexistente en alemán correcto.
Q ¿Por qué se utiliza «woran» y no «worauf» para la pregunta «¿En qué piensas?»?
+ Porque el verbo «denken» rige fijamente la preposición «an» («denken an + Akk») :: El interrogativo pronominal debe reproducir con exactitud la preposición regida por el verbo.
- Porque «an» indica obligatoriamente un lugar cerrado en el interior de un edificio :: El régimen preposicional de los verbos abstractos es idiomático y no depende de la localización física.
- Porque «worauf» solo se puede usar con verbos que expresen movimiento rápido :: La distinción responde al régimen léxico de cada verbo, no a la velocidad de la acción.
H ___ wartest du am Eingang? Auf meine Kollegin Sandra. :: ¿A quién?
+ Auf wen :: Se pregunta por una persona («meine Kollegin») y el régimen de «warten auf» exige acusativo («wen»).
- Worauf :: Se utilizaría únicamente si se esperase una cosa inanimada (un taxi, el autobús).
- Womit :: Preguntaría por el medio o instrumento («¿con qué?»), no por una persona.
H ___ sprecht ihr in der Besprechung? Über das neue Budget. :: ¿De qué?
+ Worüber :: Se pregunta por un asunto inanimado («das neue Budget») regido por «sprechen über + Akk».
- Über wen :: Preguntaría por una persona («¿sobre quién?»), no por el presupuesto.
- Wovon :: Aunque indica procedencia o tema con otros verbos, «sprechen über» exige «worüber».
R Wovon hängt unsere geschäftliche Entscheidung ab? :: ¿Qué indaga esta pregunta?
+ De qué factor o circunstancia depende nuestra decisión comercial. :: «abhängen von + Dat» se interroga mediante «wovon» para conocer la causa o condición.
- Quién autorizó la compraventa de las nuevas instalaciones. :: No pregunta por una persona autorizadora, sino por el factor del que depende la decisión.
- Cuándo se presentará el informe final a los accionistas. :: No es una pregunta temporal con «wann», sino condicional de dependencia con «wovon».
H ___ denkst du so intensiv? An meinen kommenden Urlaub. :: ¿En qué?
+ Woran :: «denken an» exige el interrogativo «woran» ante un concepto o acontecimiento inanimado («der Urlaub»).
- Worauf :: Correspondería a verbos que rigen «auf» (como «warten auf» o «sich freuen auf»).
- An wen :: Preguntaría por una persona concreta («¿en quién?»), no por las vacaciones.
O Worauf wartest du denn noch :: ¿A qué esperas todavía? :: interrogativo worauf + verbo + sujeto + partículas al final.

@ 24 | Reflexiv mit Dativ | Reflexivo en dativo
I Cuando una acción reflexiva cuenta además con un complemento directo acusativo explícito, el pronombre reflexivo de primera y segunda persona pasa obligatoriamente al dativo.
E El pronombre reflexivo en Dativo :: 1. **Regla de alternancia**: Si el sujeto realiza la acción sobre sí mismo sin otro objeto, el reflexivo va en Acusativo: **Ich wasche mich** (me lavo). Pero si aparece un objeto directo (habitualmente partes del cuerpo, prendas o ideas), el reflexivo se convierte en Dativo: **Ich wasche mir (Dativ) die Hände (Akkusativ)**. :: 2. **Formas afectadas**: Solo cambian la 1ª y 2ª persona del singular: **ich → mir**, **du → dir**. La 3ª persona del singular y plural sigue siendo invariable: **er/sie/es/sie/Sie → sich**; y la 1ª/2ª del plural: **wir → uns**, **ihr → euch**. :: 3. **Verbos reflexivos mentales con Dativo**: Son muy frecuentes en alemán: **sich etwas überlegen** (pensar/reflexionar sobre algo): **Ich überlege mir einen Plan**; **sich etwas merken** (memorizar algo): **Ich merke mir die Nummer**; **sich etwas vorstellen** (imaginarse algo): **Ich kann mir das vorstellen**.

| du | Du wäschst dich. | Du wäschst dir das Gesicht. | Hast du dir das gemerkt?
| er / sie | Er wäscht sich. | Er wäscht sich die Haare. | Sie zieht sich die Schuhe an.

Q ¿Por qué se utiliza «mir» y no «mich» en «Ich wasche mir die Hände»?
+ Porque la presencia del objeto directo «die Hände» desplaza al pronombre reflexivo al dativo :: Al haber ya un complemento en acusativo («die Hände»), la persona beneficiaria pasa a dativo.
- Porque «die Hände» es un sustantivo plural y los plurales exigen dativo :: El número del objeto no altera la regla de distribución de casos entre paciente y beneficiario.
- Porque «waschen» es un verbo intransitivo que rechaza el acusativo :: «waschen» es transitivo y rige acusativo para el objeto directo lavado.
Q ¿Qué formas del pronombre reflexivo diferencian entre Acusativo y Dativo?
+ Únicamente la primera y segunda persona del singular: mich/mir y dich/dir :: Las formas «sich», «uns» y «euch» son idénticas en acusativo y dativo.
- Todas las personas gramaticales sin excepción tienen formas diferentes :: En 3ª persona («sich») y en plural («uns», «euch») las formas no cambian.
- Solo la tercera persona del plural presenta una forma exclusiva para dativo :: La tercera persona utiliza siempre «sich» independientemente del caso.
H Ich putze ___ jeden Morgen gründlich die Zähne. :: me
+ mir :: El objeto directo es «die Zähne» (acusativo), por lo que el reflexivo de 1ª persona debe ser «mir» (dativo).
- mich :: «mich» se utilizaría si no hubiera objeto («Ich wasche mich»), pero aquí causaría doble acusativo.
- dir :: Es la 2ª persona («te»), incompatible con el sujeto «ich».
H Hast du ___ diese wichtige Telefonnummer gemerkt? :: te
+ dir :: Con el objeto directo «diese Telefonnummer» (acusativo), el reflexivo con «du» debe ser «dir» (dativo).
- dich :: Sería acusativo, incorrecto ante la presencia de un objeto directo expreso.
- mir :: Se referiría a la 1ª persona («a mí»), no a la persona interrogada («du»).
R Ich kann mir den großen Erfolg schon genau vorstellen. :: ¿Qué manifiesta esta declaración?
+ Que ya puedo concebir e imaginarme con claridad el gran éxito futuro. :: «sich etwas vorstellen» con dativo significa representarse mentalmente o imaginarse algo.
- Que rechazo el éxito porque me da miedo trabajar duro. :: Contradice el sentido de la frase.
- Que no he tenido éxito en la entrevista de trabajo de ayer. :: Habla de concebir el éxito futuro, no de un fracaso pasado.
H Er zieht ___ vor dem Vorstellungsgespräch einen warmen Mantel an. :: se
+ sich :: El reflexivo de 3ª persona del singular («er») es «sich», tanto en acusativo como en dativo.
- ihm :: «ihm» es un pronombre personal de objeto indirecto no reflexivo (se lo pondría a otra persona).
- ihn :: Es el pronombre personal masculino en acusativo, no una forma reflexiva.
O Ich ziehe mir die Anzugjacke an :: Me pongo la chaqueta del traje :: sujeto + verbo + dativo mir + objeto + partícula an al final.

@ 24 | Reflexive Verben mit Präposition | Verbos reflexivos y régimen
I Muchos verbos reflexivos alemanes se vinculan necesariamente a una preposición fija que determina el caso gramatical de su complemento complementario.
E Verbos reflexivos habituales con preposición fija :: 1. **sich freuen auf (+ Akkusativ)**: Alegrarse anticipadamente por un acontecimiento futuro esperado: **Wir freuen uns auf den Urlaub** (nos hace ilusión las vacaciones). :: 2. **sich freuen über (+ Akkusativ)**: Alegrarse por un hecho presente o ya ocurrido: **Ich freue mich über das Geschenk** (me alegro por el regalo que ya recibí). :: 3. **sich interessieren für (+ Akkusativ)**: Mostrar interés por un campo o asunto: **Er interessiert sich für Geschichte**. :: 4. **sich kümmern um (+ Akkusativ)**: Ocuparse de un asunto, atender a alguien: **Ich kümmere mich um die Reservierung**. :: 5. **sich erinnern an (+ Akkusativ)**: Acordarse o tener presente un recuerdo: **Erinnerst du dich an unseren Ausflug?**. :: 6. **sich bewerben um (+ Akkusativ)**: Solicitar o postular a un puesto de trabajo: **Sie bewirbt sich um die Stelle**.

Q ¿Cuál es la diferencia de significado entre «sich freuen auf» y «sich freuen über»?
+ «auf» se refiere a un acontecimiento futuro esperado; «über» a algo presente o ya sucedido :: «sich freuen auf» proyecta ilusión hacia adelante; «sich freuen über» expresa satisfacción por algo ya recibido o vivido.
- «auf» se usa exclusivamente para regalos materiales y «über» para viajes o vacaciones :: Ambos pueden combinarse con distintos tipos de objetos según el marco temporal de la acción.
- «auf» rige caso dativo obligatorio, mientras que «über» rige únicamente acusativo :: Ambos verbos con sus respectivas preposiciones rigen estrictamente caso acusativo.
Q ¿Qué preposición y caso rige el verbo «sich kümmern»?
+ «um» con caso Acusativo :: «sich kümmern um + Akkusativ» expresa responsabilizarse de alguien o encargarse de una tarea.
- «für» con caso Acusativo :: «für» se combina con «sich interessieren», no con «sich kümmern».
- «an» con caso Dativo :: «an» en este contexto se combina con «sich erinnern an + Akkusativ».
H Er interessiert sich schon seit vielen Jahren ___ moderne Architektur. :: por
+ für :: «sich interessieren» rige obligatoriamente la preposición «für» seguida de caso acusativo.
- über :: Preposición incorrecta con este verbo; se utiliza con «sprechen» o «diskutieren».
- an :: No corresponde al régimen de «sich interessieren».
H Wir freuen uns alle schon riesig ___ den kommenden Sommerurlaub. :: por (hacia el futuro)
+ auf :: Como las vacaciones son un acontecimiento futuro deseado, se utiliza «sich freuen auf + Akk».
- über :: Se utilizaría si las vacaciones ya hubieran empezado o fueran un hecho consumado.
- an :: No forma parte de los giros preposicionales asociados al verbo «sich freuen».
R Ich kümmere mich gern persönlich um Ihre Reservierung. :: ¿Qué compromiso asume el interlocutor?
+ Se encargará con agrado y personalmente de gestionar la reserva. :: «sich kümmern um» indica ocuparse activamente de la tramitación de una tarea.
- Rechaza la reserva porque no quedan plazas disponibles. :: La frase expresa total disposición positiva («gern persönlich»).
- Solicita al cliente que acuda en persona a recoger su billete. :: No pide nada al cliente, sino que asume la responsabilidad del trámite.
H Erinnerst du dich noch ___ unseren ersten Urlaub in Wien? :: de
+ an :: «sich erinnern» rige obligatoriamente la preposición «an» con caso acusativo.
- in :: No corresponde al régimen léxico del verbo de memoria «sich erinnern».
- auf :: «auf» se vincula a la expectativa futura de «sich freuen auf», no a los recuerdos pasados.
O Ich kümmere mich um alles :: Me ocupo de todo :: sujeto + verbo + reflexivo + preposición um + objeto alles.
