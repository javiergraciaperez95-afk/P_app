@ 35 | Lequel préfères-tu ? | ¿Cuál prefieres?
I Hoy los relativos compuestos: sirven para elegir entre varias cosas y para unir ideas cuando hay una preposición.
E Lequel, laquelle :: Concuerdan con lo que sustituyen: **lequel** (masculino singular), **laquelle** (femenino singular), **lesquels** y **lesquelles** (plural). :: Ejemplo: **La maison dans laquelle tu habites est jolie** (la casa en la que vives es bonita).
E Formas con «à» y «de» :: Solo algunas formas se contraen: **à + lequel = auquel**, **à + lesquels = auxquels**, **à + lesquelles = auxquelles**; **à laquelle** no se contrae. Con **de**: **duquel**, **desquels**, **desquelles**, pero **de laquelle** no se contrae.
E «Dont» o «duquel» :: Si el verbo exige **de**, normalmente se usa **dont**: **le sujet dont je parle** (el tema del que hablo). **Duquel / de laquelle** aparece sobre todo tras una preposición compuesta: **le bâtiment près duquel j'habite** (el edificio cerca del cual vivo).
B Relativo | Género y número | Con «dans» / «à» / «de»
| lequel | masculino singular | dans lequel / auquel / duquel
| laquelle | femenino singular | dans laquelle / à laquelle / de laquelle
| lesquels | masculino plural | auxquels / desquels
| lesquelles | femenino plural | auxquelles / desquelles
| le sujet | dont je parle | del que hablo
| le bâtiment | près duquel j'habite | cerca del cual vivo

W auquel = al cual | o-kel

W auxquelles = a las cuales | o-kel
W préférence = preferencia | pre-fe-ra(n)s
W ancien = antiguo | a(n)-sye(n)
V Vocabulario: relativos compuestos
D Una elección de casas
Léa: Tu préfères lequel ? = ¿Cuál prefieres?
  > tu préfères = tú prefieres | lequel = cuál (pronombre interrogativo masculino singular)
Thomas: La maison dans laquelle tu habites est jolie. = La casa en la que vives es bonita.
  > la maison = la casa | dans laquelle = en la que, en la cual (femenino singular) | tu habites = tú vives | est jolie = es bonita

  > oui = sí | c'est la maison = es la casa | à laquelle = en la que, a la que («penser à») | je pense = yo pienso
Q ¿Cómo se dice «la casa en la que vivo»?
+ la maison dans laquelle j'habite :: «Dans laquelle» concuerda con «maison», femenino singular.
- la maison dans lequel j'habite :: «Lequel» es masculino y no concuerda con «maison».
- la maison que j'habite :: Con preposición no se usa «que».
Q ¿Cuál es correcta para «¿cuál prefieres?»?
+ Tu préfères lequel ? :: «Lequel» funciona como pronombre interrogativo de elección.
- Tu préfères quel ? :: «Quel» es un determinante adjetivo y exige un sustantivo detrás.
- Tu préfères qui ? :: «Qui» se reserva para preguntar por personas.
H La maison ___ tu habites est jolie. :: Con «dans», femenino
+ dans laquelle :: «Dans» + «laquelle» concuerda con el antecedente femenino «maison».
- dans lequel :: Forma masculina que no concuerda con «maison».
- que :: Con preposición locativa se requiere el relativo compuesto.
H Voilà le café ___ je pense. :: Con «à», masculino
+ auquel :: Contracción obligatoria de «à» + «lequel» ante sustantivo masculino.
- à laquelle :: Forma femenina incompatible con «café».
- que :: Con verbos que rigen «à» («penser à») se usa la forma contracta «auquel».
R La maison dans laquelle tu habites est jolie.
+ La casa en la que vives es bonita. :: «Dans laquelle» traduce con exactitud «en la que».
- La casa que vives es bonita. :: Omite la preposición locativa indispensable.
- La casa de la que vives es bonita. :: Confunde «dans» con la procedencia o materia «de».
A Oui, c'est la maison à laquelle je pense.
+ Sí, es la casa en la que pienso. :: «À laquelle» traduce el régimen de «penser à».
- Sí, es la casa que me gusta. :: Sustituye el verbo y la estructura relativa.
- Sí, es la casa de la que hablo. :: Confunde «penser à» con «parler de».
O auquel :: al que :: Contracción de «à» + «lequel».
Q ¿Cómo se dice correctamente «la casa en la que vivo» con relativo compuesto?
+ la maison dans laquelle j'habite :: «Dans laquelle» concuerda en femenino singular con el antecedente «la maison».
- la maison dans lequel j'habite :: «Lequel» es la forma masculina singular y no concuerda con «maison».
- la maison dans qui j'habite :: El relativo simple «qui» con preposición solo se aplica a personas.

@ 35 | Celui qui parle | El que habla
I Ahora los pronombres demostrativos con relativo: «el que», «la que», «los que».
E Celui, celle, ceux, celles + relativo :: Se forma con **celui** (el), **celle** (la), **ceux** (los), **celles** (las) + **qui**, **que**, **dont** o **où**: **Celui qui parle est mon frère** (el que habla es mi hermano). :: **Celle que j'aime est très belle** (la que quiero es muy bonita).
E Cuidado :: No se dice **celui parle**; siempre necesita el relativo detrás.
B Demostrativo + relativo | Significa | Ejemplo
| celui qui | el que (sujeto) | Celui qui parle est mon frère.
| celle que | la que (objeto) | Celle que j'aime est belle.
| ceux dont | los de los que | Ceux dont tu parles sont mes voisins.
| celles où | las (en) que | Celles où il habite sont belles.

W celle = la que, aquella | sel
W ceux = los que, aquellos | sö
W celles = las que, aquellas | sel

W chacune = cada una | sha-kün
W l'un = uno (de dos) | le(n)
W l'autre = el otro | lo-tr
W les autres = los demás | lez-o-tr
W quiconque = cualquiera que | ki-ko(n)k

W belle = hermosa, bella | bel

D Un grupo de amigos
Léa: Celui qui parle est mon frère. = El que habla es mi hermano.
  > celui qui parle = el que habla (sujeto) | est mon frère = es mi hermano
Thomas: Celle que tu aimes est très belle. = La que quieres es muy bonita.
  > celle que tu aimes = la que quieres (objeto directo) | est très belle = es muy hermosa
Léa: Ceux dont tu parles sont mes voisins. = Aquellos de los que hablas son mis vecinos.
  > ceux dont tu parles = aquellos de los que hablas («parler de») | sont mes voisins = son mis vecinos
Thomas: Chacun a son avis. = Cada uno tiene su opinión.
  > chacun = cada uno | a son avis = tiene su opinión
Q ¿Cómo se dice «el que habla»?
+ Celui qui parle. :: «Celui qui» = el que, en función de sujeto.
- Celui que parle. :: «Que» no puede funcionar como sujeto de «parle».
- Celle qui parle. :: «Celle» es la forma demostrativa femenina singular.
Q ¿Cuál significa «celle que j'aime»?
+ la que quiero :: «Celle que» = la que, en función de objeto directo.
- la que me quiere :: Altera la función sintáctica del pronombre.
- la que ya quiero :: Añade adverbios no presentes en la expresión.
H ___ dont tu parles sont mes voisins. :: Plural, «de los que»
+ Ceux :: «Ceux dont» = aquellos de los que (masculino plural).
- Celui :: Forma singular masculina incompatible con «sont».
- Celle :: Forma singular femenina incompatible con el verbo plural.
H Il lit ___ qui est sur la table. :: Singular masculino
+ celui :: «Celui qui» = el que, libro o documento masculino singular.
- celle :: Forma demostrativa femenina singular.
- ceux :: Forma plural masculina incompatible con el verbo singular «est».
R Celui qui parle est mon frère.
+ El que habla es mi hermano. :: Demostrativo «celui» seguido del relativo sujeto «qui».
- Lo que hablo es mi hermano. :: Confunde «celui» con el neutro «ce que».
- Los que hablan son mis hermanos. :: Convierte erróneamente la oración al plural.
A Chacun a son avis.
+ Cada uno tiene su opinión. :: «Chacun» expresa individualidad en singular.
- Todos tienen la misma opinión. :: Sentido contrario («tous ont le même avis»).
- Nadie tiene opinión formada. :: Niega la afirmación («personne n'a d'avis»).
O celui qui :: el que :: Demostrativo masculino singular con relativo sujeto.
Q ¿Cómo se dice «los que hablan» como pronombre demostrativo sujeto en plural masculino?
+ Ceux qui parlent :: «Ceux» es el demostrativo masculino plural y «qui» actúa como sujeto del verbo.
- Ceux que parlent :: «Que» funciona como complemento directo y no puede ser sujeto de «parlent».
- Celui qui parlent :: «Celui» es singular masculino y no concuerda con el verbo en plural.

@ 35 | Certains d'entre eux | Algunos de ellos
I Último paso: elegir entre un grupo, y decir «algunos de ellos» o «ninguno de nosotros».
E D'entre + pronombre :: Para elegir dentro de un grupo se usa **d'entre** + pronombre tónico: **certains d'entre eux** (algunos de ellos), **aucun d'entre nous** (ninguno de nosotros), **chacun d'entre vous** (cada uno de vosotros).
E Lequel de :: Para preguntar «¿cuál de...?» se usa **lequel de** + grupo: **Lequel de ces films est bon ?** (¿cuál de estas películas es buena?).

| aucun d'entre nous | ninguno de nosotros | Aucun d'entre nous ne doute de cela.
| la plupart de | la mayoría de | La plupart de mes amis aiment ce film.

  > lequel de ces films = cuál de estas películas | tu préfères = prefieres tú

  > certains sont drôles = algunas son divertidas | d'entre eux = de entre ellas, de ellas | un seul me plaît = una sola me gusta

  > la plupart de mes amis = la mayoría de mis amigos | aiment ce film = disfrutan esta película

  > aucun d'entre nous = ninguno de nosotros | ne doute de cela = duda de eso
Q ¿Qué significa «d'entre eux»?
+ de entre ellos :: «D'entre» + pronombre tónico especifica selección de grupo.
- con ellos :: Se expresaría mediante «avec eux».
- para ellos :: Se expresaría mediante «pour eux».
Q ¿Cuál es correcta para «algunos de ellos»?
+ Certains d'entre eux. :: «Certains» + locución «d'entre» + pronombre tónico «eux».
- Certains de eux. :: Falta la preposición compuesta «d'entre».
- Certains entre eux. :: Falta la elisión «d'» ante «entre».
H ___ de ces films est très bon ? :: Pregunta de elección
+ Lequel :: Pronombre interrogativo masculino singular concordante con «film».
- Laquelle :: Forma femenina incompatible con «film».
- Lesquels :: Forma plural incompatible con el verbo en singular «est».
H Chacun ___ son avis. :: Tercera persona singular
+ a :: «Chacun» concuerda estrictamente en tercera persona de singular.
- ont :: Forma de tercera persona del plural incompatible con «chacun».
- avez :: Forma de segunda persona del plural («vous avez»).
R Certains d'entre eux sont drôles.
+ Algunos de ellos son graciosos. :: «Certains d'entre eux» traduce con exactitud la selección dentro del grupo.
- Algunos con ellos son graciosos. :: Confunde «d'entre» con la compañía «avec».
- Algunos son ellos graciosos. :: Construcción agramatical en español.
A La plupart de mes amis aiment ce film.
+ La mayoría de mis amigos aprecian esta película. :: «La plupart de» rige verbo en plural y significa la gran mayoría.
- La mayoría de mis amigos odian esta película. :: Invierte por completo el sentido afirmativo del verbo.
- Todos mis amigos sin excepción aman la película. :: Confunde «la plupart de» con la totalidad «tous».
O aucun d'entre nous :: ninguno de nosotros :: Pronombre negativo con «d'entre».
Q ¿Cómo se construye «algunos de ellos» para seleccionar elementos dentro de un grupo?
+ Certains d'entre eux :: Indefinido «certains» + locución preposicional «d'entre» + pronombre tónico «eux».
- Certains de eux :: En francés se exige la locución «d'entre» ante el pronombre tónico de grupo.
- Certains entre eux :: Falta la elisión «d'» delante de «entre eux».
