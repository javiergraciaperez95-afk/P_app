@ 42 | Révision générale | Examen final de B2
I Ce bilan final valide l'ensemble du niveau B2 à travers 24 questions : 18 questions ciblées sur les structures grammaticales et lexicales clés (chapitres 31 à 41) et 6 questions de compréhension sur un texte inédit («Un projet de mobilité»).
E Déroulement de l'épreuve :: Ce bilan récapitulatif comporte exactement 24 questions structurées en deux volets. Réponds d'abord aux 18 questions de langue pour consolider tes acquis (subjonctif passé, conditionnel d'hypothèse, mise en relief, discours indirect, passé simple et passé antérieur, constructions causatives et voix passive), puis lis attentivement le texte d'actualité pour répondre aux 6 questions de compréhension écrite.
Q Cap. 31. Je suis contente que vous ___ reçu ma réponse. :: Subjonctif passé de «avoir»
+ ayez :: «Avoir» au subjonctif présent + participe passé.
- avez :: Indicatif.
- auriez :: Conditionnel.
Q Cap. 32. Quelle forme suit «au cas où» dans la norme soignée ?
+ Le conditionnel. :: Exemple : «au cas où il pleuvrait».
- Le futur simple. :: On évite «au cas où il pleuvra».
- Le subjonctif. :: Ce n'est pas le mode demandé ici.
Q Cap. 33. «Je répète la consigne de sorte que chacun ___ la comprendre.»
+ puisse :: Finalité recherchée + subjonctif.
- peut :: Indicatif d'une capacité constatée.
- pouvait :: Imparfait, sans la valeur visée.
Q Cap. 34. Quel connecteur concède un point avant l'objection ?
+ Certes..., mais... :: On reconnaît un point, puis on nuance.
- Par conséquent... :: Introduit une conséquence.
- En raison de... :: Introduit une cause avec un nom.
Q Cap. 35. «Le sujet ___ je parle est complexe.»
+ dont :: «Parler de» appelle «dont».
- auquel :: «Parler à» aurait un autre sens.
- que :: Il manque la préposition «de».
Q Cap. 36. Dans «C'est Léa ___ a proposé ce projet», complète le relatif.
+ qui :: Le pronom reprend le sujet.
- que :: «Que» reprend un complément direct.
- dont :: «Dont» reprend un complément introduit par «de».
Q Cap. 37. Au discours indirect, «Je partirai» devient après «il a dit» :
+ qu'il partirait :: Le futur devient conditionnel après un verbe au passé.
- qu'il partira :: Le futur reste inchangé dans ce cas.
- qu'il soit parti :: Cela signifie qu'il est déjà parti.
Q Cap. 37. Quelle phrase est également correcte ?
+ Je lui reproche qu'il ne soit pas venu. :: «Reprocher à quelqu'un que» + subjonctif existe.
- Je le reproche qu'il ne soit pas venu. :: Le complément de personne se construit avec «à».
- Je lui reproche de qu'il ne soit pas venu. :: On ne combine pas «de» et «que» ainsi.
Q Cap. 38. Quelle expression annonce une conclusion ?
+ En somme :: Sert à résumer.
- D'une part :: Introduit un premier aspect.
- À moins que :: Introduit une condition d'exception.
Q Cap. 39. Completa la frase con el pronombre adecuado: «Je ___ fais réparer (ma voiture)».
+ la :: El pronombre de complemento directo femenino precede al verbo causativo «faire».
- en :: Se usaría para una cantidad indeterminada introducida por «de».
- lui :: Es un pronombre de objeto indirecto, incompatible con el COD «ma voiture».
Q Cap. 39. «Il se fait tromper» significa que:
+ Lo engañan. :: El sujeto recibe la acción pasiva a través de «se faire» + infinitivo.
- Engaña a alguien. :: Esa sería una forma activa («il trompe quelqu'un»).
- Deja que otros engañen a alguien. :: El sujeto no es el agente del engaño.
Q Cap. 40. ¿Cuál es la pasiva en futuro?
+ Le projet sera annoncé demain. :: «Être» en futuro simple («sera») + participio concordado («annoncé»).
- Le projet a annoncé demain. :: Falta la forma pasiva y el tiempo es pretérito.
- Le projet est annoncé hier. :: El tiempo presente no concuerda con el adverbio «hier».
Q Cap. 41. Elige la forma correcta con concordancia de participio: «Les lettres que j'ai ___ sont arrivées.»
+ reçues :: «Les lettres» es femenino plural y precede al verbo con «avoir».
- reçu :: Forma sin concordancia, incorrecta aquí porque el COD precede al verbo.
- reçus :: Forma de masculino plural; «lettre» es un sustantivo femenino.
Q Cap. 41. En «Quand il eut terminé, il partit», ¿qué expresa «eut terminé»?
+ Una acción anterior a «partit», en passé antérieur. :: El auxiliar está en passé simple.
- Una acción futura. :: Los dos hechos pertenecen al relato pasado.
- Una costumbre. :: No se trata de un imperfecto habitual.
Q Cap. 41. «Je cherche une solution qui ___ durable.»
+ soit :: Subjuntivo presente para expresar una solución deseada aún no identificada.
- est :: Indicativo para una solución concreta ya existente e identificada.
- sera :: Futuro de indicativo, inapropiado para una búsqueda abierta.
Q Cap. 32. En «Si elle avait lu le message, elle aurait compris», ¿qué expresa la frase?
+ Una hipótesis pasada que no ocurrió. :: «Si» + plus-que-parfait; resultado en conditionnel passé.
- Una condición real para mañana. :: La frase habla de algo irreal en el pasado.
- Una orden. :: No contiene formas de imperativo.
Q Cap. 35. «La maison dans laquelle elle habite» usa «laquelle» porque:
+ Concuerda con «maison», femenino singular. :: El relativo compuesto concuerda con su antecedente.
- «Habiter» siempre exige el femenino. :: El régimen del verbo no determina el género.
- «Dans» exige siempre «laquelle». :: La forma del relativo varía según el género y número del antecedente.
Q Cap. 38. ¿Qué función tiene «d'une part... d'autre part»?
+ Presentar dos aspectos correlativos de una argumentación. :: Organiza y contrapone dos puntos de vista o factores.
- Presentar una causa y su consecuencia inmediata. :: Para ello se emplean conectores causales y consecutivos.
- Introducir una condición hipotética. :: No expresa valor condicional.
T Un projet de mobilité
- La mairie a présenté un projet pour réduire la circulation dans le centre. = El ayuntamiento presentó un proyecto para reducir el tráfico en el centro.
  > la mairie a présenté un projet = el ayuntamiento presentó un proyecto (passé composé de présenter con COD masculino) | pour réduire la circulation = para reducir el tráfico (preposición de finalidad pour + infinitivo réduire) | dans le centre = en el centro (preposición dans + sustantivo)
- D'une part, une nouvelle ligne de bus serait créée ; d'autre part, plusieurs rues deviendraient piétonnes. = Por un lado, se crearía una nueva línea de autobús; por otro, varias calles se harían peatonales.
  > d'une part = por un lado (conector de orden correlativo) | une nouvelle ligne de bus serait créée = se crearía una nueva línea de autobús (voz pasiva con conditionnel présent) | d'autre part = por otro lado (segundo término correlativo) | plusieurs rues deviendraient piétonnes = varias calles se convertirían en peatonales (devenir en condicional + adjetivo femenino plural)
- Selon la mairie, ces changements permettraient de diminuer la pollution et de faciliter les déplacements. = Según el ayuntamiento, estos cambios permitirían reducir la contaminación y facilitar los desplazamientos.
  > selon la mairie = según el ayuntamiento (preposición selon que introduce la fuente institucional) | ces changements permettraient = estos cambios permitirían (conditionnel présent de permettre que expresa consecuencia potencial) | de diminuer la pollution = reducir la contaminación (de + infinitivo) | et de faciliter les déplacements = y facilitar los desplazamientos (coordinación con et + de + infinitivo)
- Pourtant, certains commerçants craignent que leurs clients ne puissent plus se garer à proximité. = Sin embargo, algunos comerciantes temen que sus clientes ya no puedan aparcar cerca.
  > pourtant = sin embargo (conector adversativo de objeción) | certains commerçants craignent = algunos comerciantes temen (indefinido certains + craindre en presente) | que leurs clients ne puissent plus se garer = que sus clientes ya no puedan aparcar (que completivo + «ne» expletivo tras craindre + subjonctif de pouvoir + infinitivo reflexivo) | à proximité = cerca, en las inmediaciones (locución adverbial de lugar)
- La décision sera prise après une consultation publique, prévue le mois prochain. = La decisión se tomará después de una consulta pública prevista para el mes próximo.
  > la décision sera prise = la decisión se tomará, será tomada (voz pasiva en futur simple: être en futuro + participio concordado prise) | après une consultation publique = después de una consulta pública (preposición temporal après + sustantivo y adjetivo femenino) | prévue le mois prochain = prevista para el próximo mes (participio adjetival concertado prévue + expresión temporal)
Q Lectura. ¿Cuál es el objetivo principal del proyecto?
+ Reducir el tráfico en el centro. :: Se explica en la primera frase del texto.
- Cerrar todos los comercios del centro histórico. :: El texto no propone cerrar comercios.
- Aumentar el precio de los billetes de autobús. :: No se menciona ninguna tarifa en el texto.
Q Lectura. ¿Qué dos medidas concretas se proponen?
+ Una nueva línea de autobús y la peatonalización de varias calles. :: La segunda frase presenta ambas actuaciones de movilidad.
- Más plazas de aparcamiento y nuevas tiendas comerciales. :: No figuran esas propuestas en el documento.
- La anulación de la consulta y el corte inmediato del tráfico rodado. :: La consulta es el paso previo para decidir, no una medida ejecutada.
Q Lectura. ¿Por qué algunos comerciantes están preocupados?
+ Temen que sus clientes ya no puedan aparcar cerca. :: «Craignent que leurs clients ne puissent plus se garer à proximité».
- Porque la consulta pública ya rechazó formalmente el proyecto. :: La consulta todavía está pendiente de celebrarse el mes próximo.
- Porque consideran que el tráfico de automóviles aumentará. :: El proyecto persigue el objetivo inverso.
Q Lectura. ¿Qué valor lógico tiene el conector «pourtant» en el texto?
+ Introduce una objeción o contraste frente a los beneficios previstos. :: Contrapone el beneficio esperado con la inquietud comercial.
- Introduce la causa que justifica las medidas municipales. :: La justificación se expresa con «permettraient de diminuer...».
- Resume la conclusión definitiva del proyecto. :: La decisión aún no se ha tomado.
Q Lectura. ¿Cuándo se tomará la decisión sobre el proyecto?
+ Tras la celebración de la consulta pública del próximo mes. :: La última frase indica la condición previa y el marco temporal.
- Inmediatamente antes de presentar la propuesta a los medios. :: El proyecto ya fue presentado.
- El mismo día en que comiencen las obras de la línea de autobús. :: El texto no señala esa fecha.
Q Lectura. ¿Se encuentra ya definitivamente aprobado el proyecto?
+ No; la decisión final depende de los resultados de la consulta pública. :: La pasiva «sera prise après...» indica que la resolución está pendiente.
- Sí; todas las calles ya han pasado a ser exclusivamente peatonales. :: Se trata de propuestas en estudio.
- Sí; la consulta pública ya ratificó el proyecto de movilidad. :: La consulta está prevista para el mes próximo.
