@ 15 | Plus cher, moins cher | Más caro, menos caro
I Vamos de compras. Para comparar precios y cosas usamos plus, moins y aussi.
E Comparar con adjetivos :: **plus** + adjetivo + **que** = más... que; **moins** + adjetivo + **que** = menos... que; **aussi** + adjetivo + **que** = tan... como. El adjetivo concuerda con el nombre: **un pull moins cher**, **une veste moins chère**. :: Ejemplo: **Lyon est plus petit que Paris**; **Ce vélo est aussi rapide que la voiture**.
B Comparar | Forma | Significa | Ejemplo
| plus + adjetivo + que | más... que | Lyon est plus petit que Paris.
| moins + adjetivo + que | menos... que | Le bus est moins rapide que le train.
| aussi + adjetivo + que | tan... como | Ce vélo est aussi rapide que la voiture.
W rapide = rápido | ra-PÍD
W prix = precio | pri
W pull = jersey | pül | Prenda de punto para la parte de arriba.
W chaussette = calcetín | sho-SÉT
W ceinture = cinturón | sa(n)-TÜR
W chapeau = sombrero | sha-PÓ
W bon marché = barato | bo(n) mar-SHÉ
W réduction = descuento | re-dük-SIÓN
W facile = fácil | fa-SÍL
W difficile = difícil | di-fi-SÍL
W élégant = elegante | e-le-GA(N)
W confortable = cómodo | ko(n)-for-TÁBL
W chère = más barata, cara | SHÉR | Forma femenina de «cher».
V Vocabulario: comprar y comparar
D En una tienda
Léa: Ce pull est plus cher que cette veste. = Este jersey es más caro que esta chaqueta.
  > plus cher que = más caro que | cette veste = esta chaqueta
Paul: Oui, mais il est aussi joli. = Sí, pero es igual de bonito.
  > aussi joli = igual de bonito | mais = pero
Léa: Et le prix ? = ¿Y el precio?
  > le prix = el precio
Paul: La veste est moins chère. = La chaqueta es más barata.
  > la veste = la chaqueta | moins chère = menos cara (es decir, más barata)
T Etiqueta de precios
- Pull : 30 euros. = Jersey: 30 euros.
- Veste : 45 euros. = Chaqueta: 45 euros.
- Réduction sur la veste : 5 euros. = Descuento en la chaqueta: 5 euros.
Q Según las etiquetas, ¿qué prenda cuesta menos antes del descuento?
+ Le pull. :: El jersey cuesta 30 euros y la chaqueta, 45.
- La veste. :: La chaqueta cuesta más antes del descuento.
- Elles coûtent le même prix. :: Los precios son distintos.
Q ¿Cuánto se descuenta de la chaqueta?
+ Cinq euros. :: La etiqueta indica «5 euros».
- Trente euros. :: Ese es el precio del jersey.
- Quarante-cinq euros. :: Ese es el precio de la chaqueta antes del descuento.
Q ¿Cómo se dice «Lyon es más pequeño que París»?
+ Lyon est plus petit que Paris. :: «Plus» + adjetivo + «que».
- Lyon est moins petit que Paris. :: Eso sería «menos pequeño».
- Lyon est aussi petit que Paris. :: Eso sería «tan pequeño».
Q ¿Cuál es la forma correcta de «tan rápido como»?
+ aussi rapide que :: «Aussi» + adjetivo + «que» = tan... como.
- plus rapide que :: Eso es «más rápido que».
- moins rapide que :: Eso es «menos rápido que».
H Ce vélo est ___ rapide que la voiture. :: Tan... como
+ aussi :: «Aussi» + adjetivo + «que» = tan... como.
- plus :: Eso es «más».
- moins :: Eso es «menos».
H Ce pull est ___ cher que cette veste. :: Más... que
+ plus :: «Plus» + adjetivo + «que» = más... que.
- aussi :: Eso es «tan».
- moins :: Eso es «menos».
R Ce pull est plus cher que cette veste.
+ Este jersey es más caro que esta chaqueta. :: «Plus cher que» = más caro que.
- Este jersey es menos caro que esta chaqueta. :: Eso sería «moins cher».
- Este jersey es tan caro como esta chaqueta. :: Eso sería «aussi cher».
A La veste est moins chère.
+ La chaqueta es más barata. :: «Moins chère» concuerda con «la veste».
- La chaqueta es más cara. :: Eso sería «plus chère».
- La chaqueta cuesta lo mismo. :: Eso sería «aussi chère».
O Il est aussi joli :: Es igual de bonito :: «Aussi» + adjetivo.
X Escribe en francés: «es menos rápido que el tren» :: il est moins rapide que le train :: «Moins» + adjetivo + «que».

@ 15 | Bon, bien, meilleur, mieux | Bueno, bien, mejor
I Hay dos palabras que cambian de forma por completo al comparar. No siguen la regla de «plus».
E Bon → meilleur :: **Bon** (bueno) cambia en **meilleur** (mejor). Como adjetivo, concuerda: **un meilleur café**, **une meilleure idée**, **de meilleurs cafés**. :: No se dice **plus bon**.
E Bien → mieux :: **Bien** (bien) es un adverbio y cambia en **mieux** (mejor): **Tu parles mieux français que moi**. **Meilleur** es un adjetivo que concuerda con el nombre; **mieux** suele modificar un verbo.
B Comparativos irregulares | Forma base | Comparativo | Ejemplo
| bon (bueno) | meilleur (mejor) | Ce café est meilleur.
| bien (bien) | mieux (mejor) | Tu parles mieux que moi.
W bon = bueno | bo(n) | Con femenino: bonne.
W bonne = buena | bon | Va con sustantivo femenino: une bonne idée.
W meilleur = mejor (masculino) | me-YÖR | Adjetivo: concuerda con el nombre.
W mieux = mejor (adverbio), mejor | miö
W mauvais = malo | mo-VÉ
W pire = peor | pir
W intelligent = inteligente | a(n)-te-li-ZHÁN
W agréable = agradable | a-gre-ÁBL
W fort = fuerte | for
W faible = débil | fe-BÍL
W rapidement = rápidamente | ra-pi-de-MÁN
W doucement = suavemente | du-se-MÁN
V Vocabulario: bueno, mejor
D Hablando del café
Léa: Ce café est bon. = Este café es bueno.
  > ce café = este café | est bon = es bueno
Paul: Oui, mais le café ici est meilleur. = Sí, pero el café de aquí es mejor.
  > le café ici = el café de aquí | est meilleur = es mejor
Léa: Tu parles mieux français que moi ! = ¡Hablas mejor francés que yo!
  > Tu parles mieux = hablas mejor | que moi = que yo
Q ¿Cómo se dice «el café es mejor»?
+ Le café est meilleur. :: «Meilleur» es el comparativo de «bon».
- Le café est plus bon. :: No se dice: «bon» tiene comparativo propio.
- Le café est plus bien. :: No se dice: «bien» tiene comparativo propio.
Q ¿Cuál es el comparativo de «bien»?
+ mieux :: «Mieux» = mejor.
- meilleur :: Eso es el comparativo de «bon».
- plus bien :: No se dice.
H Tu parles ___ que moi. :: Comparativo de «bien»
+ mieux :: «Bien» → «mieux».
- meilleur :: Eso es de «bon».
- plus :: Hace falta «mieux».
H Ce café est ___ ici. :: Comparativo de «bon»
+ meilleur :: «Bon» → «meilleur».
- mieux :: Eso es de «bien».
- plus bon :: No se dice.
R Tu parles mieux français que moi.
+ Hablas mejor francés que yo. :: «Mieux» = mejor.
- Hablas más bien francés que yo. :: No es correcto.
- Hablas peor francés que yo. :: Eso es «moins bien».
A Ce café est bon.
+ Este café es bueno. :: «Bon» = bueno.
- Este café es mejor. :: Eso sería «meilleur».
- Este café es bien. :: «Bien» es adverbio.
O Ce café est meilleur :: Este café es mejor :: «Meilleur» es el comparativo de «bon».
X Escribe en francés: «hablas mejor que yo» :: tu parles mieux que moi :: «Mieux» es el comparativo de «bien».

@ 15 | Le plus, le moins | El más, el menos
I Ya sabes comparar dos cosas. Ahora comparas una con todas: el más grande, el más barato.
E El superlativo :: Se hace con **le/la/les** + **plus** o **moins** + adjetivo: **C'est le plus grand** (es el más grande). **C'est le moins cher** (es el más barato). :: El artículo cambia con el género: **la plus jolie**, **la moins chère**.
E El mejor y la mejor forma :: **Le meilleur / la meilleure** concuerda con el nombre: **C'est la meilleure veste du magasin**. Para decir que algo se hace de la mejor manera, usa **le mieux**: **Tu chantes le mieux** (eres quien mejor canta).
B El superlativo | Forma | Significa | Ejemplo
| le plus + adjetivo | el más... | C'est le plus grand.
| le moins + adjetivo | el menos... (el más barato) | C'est le moins cher.
| le/la meilleur(e) | el/la mejor | C'est la meilleure veste.
W marché = mercado | mar-SHÉ
W vestes = chaquetas | vest | Plural de «veste».
W meilleure = mejor (femenino) | me-YÖR | Femenino de «meilleur».
W soldes = rebajas | sold
W ville = ciudad | vil
W bijou = joya | bi-ZHÚ
W collier = collar | ko-LIÉ
W vendeur = vendedor | va(n)-DÖR
W vendeuse = vendedora | va(n)-DÖZ
W long = largo | lo(n)
W court = corto | kur
W moderne = moderno | mo-DÉRN
V Vocabulario: de compras
D En la tienda de ropa
Julie: Vous voulez voir les vestes ? = ¿Quiere ver las chaquetas?
  > voir = ver | les vestes = las chaquetas
Thomas: Oui, cette veste est la plus jolie. = Sí, esta chaqueta es la más bonita.
  > la plus jolie = la más bonita
Julie: Elle est la moins chère. = Es la más barata.
  > la moins chère = la menos cara (la más barata)
Thomas: C'est la meilleure veste du magasin ! = ¡Es la mejor chaqueta de la tienda!
  > meilleure = mejor (femenino) | du magasin = de la tienda
Q ¿Cómo se dice «el más barato»?
+ le moins cher :: «Le moins» + adjetivo: el menos caro, es decir, el más barato.
- le plus cher :: Eso es «el más caro».
- le meilleur :: Eso es «el mejor».
Q ¿Cuál es correcta para «es el mejor»?
+ C'est le meilleur. :: «Meilleur» es el mejor.
- C'est le mieux bon. :: No se dice.
- C'est le plus bon. :: No se dice.
H C'est ___ grand de la ville. :: El más grande
+ le plus :: «Le plus» + adjetivo: el más grande.
- plus :: Falta el artículo.
- moins :: Eso es «el menos».
H Elle est ___ jolie. :: La más bonita
+ la plus :: Con un femenino, «la plus».
- le plus :: Eso es masculino.
- la moins :: Eso es «la menos».
R C'est la meilleure veste.
+ Es la mejor chaqueta. :: «Meilleure» es el femenino de «meilleur».
- Es la más bonita chaqueta. :: Eso sería «la plus jolie».
- Es la más barata chaqueta. :: Eso sería «la moins chère».
A Cette veste est la plus jolie.
+ Esta chaqueta es la más bonita. :: «La plus jolie» = la más bonita.
- Esta chaqueta es la más cara. :: Eso sería «la plus chère».
- Esta chaqueta es la mejor. :: Eso sería «la meilleure».
O le moins cher :: el más barato :: «Le moins» + adjetivo.
X Escribe en francés: «la más barata» :: la moins chère :: «La» porque «chère» es femenino.
