@ 40 | Examen final | Examen final de B2
I Este es el examen final del nivel B2. Hay preguntas de todos los capítulos. Si fallas alguna, mira de qué capítulo es y repásalo.
E Examen final de B2 :: Veinticinco preguntas sobre los diez capítulos del nivel. Si aciertas veintidós o más, tienes un B2 bien asentado. :: Cada pregunta indica su capítulo, para que sepas qué repasar.
Q Cap. 31. ¿Cómo se dice «que hayas aprobado»?
+ que tu aies réussi :: «Avoir» en subjuntivo + participio: subjuntivo pasado.
- que tu as réussi :: Eso es indicativo.
- que tu réussis :: Eso es presente.
H Cap. 31. Je suis content que tu ___ venu. :: Subjuntivo pasado de «être»
+ sois :: Con «tu», «être» en subjuntivo: sois.
- es :: Eso es indicativo.
- étais :: Eso es imperfecto.
Q Cap. 31. ¿Qué significa «après avoir mangé»?
+ Después de haber comido. :: «Après avoir» + participio.
- Después de que comas. :: Eso sería subjuntivo.
- Antes de comer. :: Eso es «avant de».
Q Cap. 32. ¿Qué significa «au cas où»?
+ Por si acaso. :: Expresa precaución.
- A pesar de que. :: Eso es «malgré».
- Para que. :: Eso es «pour que».
H Cap. 32. Prends un parapluie, ___ tu seras trempé. :: De lo contrario
+ sinon :: «Sinon» = si no, de lo contrario.
- pourtant :: Eso es «sin embargo».
- donc :: Eso es «así que».
Q Cap. 32. ¿Cuál es correcta para «a menos que estés cansada»?
+ à moins que tu sois fatiguée :: «À moins que» + subjuntivo.
- à moins de tu es fatiguée :: «À moins de» va con infinitivo.
- à moins que tu es fatiguée :: «À moins que» va con subjuntivo.
Q Cap. 33. ¿Qué significa «puisque»?
+ puesto que :: Causa conocida.
- aunque :: Eso es «bien que».
- para que :: Eso es «pour que».
H Cap. 33. Il y a ___ boue que nous rentrons à pied. :: Tanto
+ tant de :: «Tant de» + sustantivo + «que».
- beaucoup :: No va con «que» de consecuencia.
- tellement de :: No es el uso de esta frase.
H Cap. 34. Tu aimes le sport ; ___ moi, je le déteste. :: Contraste
+ contrairement à :: «Contrairement à» = a diferencia de.
- loin de :: Eso no expresa oposición.
- malgré :: Eso expresa concesión.
Q Cap. 34. ¿Qué significa «loin de là»?
+ ni mucho menos :: Negación enfática.
- lejos de allí :: Eso es la traducción literal, no el sentido.
- allí lejos :: Eso no es la expresión.
H Cap. 35. La maison ___ tu habites est jolie. :: Con «dans», femenino
+ dans laquelle :: «Dans» + «laquelle» con «maison».
- dans lequel :: Eso es masculino.
- que :: Con preposición no se usa «que».
Q Cap. 35. ¿Cómo se dice «el que habla»?
+ Celui qui parle. :: «Celui qui» = el que, como sujeto.
- Celui que parle. :: «Que» no va delante de un verbo con sujeto.
- Celle qui parle. :: «Celle» es femenino.
H Cap. 36. C'est Léa ___ j'aime. :: Objeto
+ que :: «C'est» + objeto + «que».
- qui :: Eso va con sujeto.
- dont :: Eso va con «de».
Q Cap. 36. ¿Cómo se dice «fue Thomas quien llamó»?
+ C'est Thomas qui a téléphoné. :: «C'est» + sujeto + «qui».
- C'est Thomas que a téléphoné. :: Con sujeto se usa «qui».
- C'est Thomas qui téléphone. :: Eso es presente.
H Cap. 37. Je te ___ de venir en retard. :: Reprochar
+ reproche :: «Reprocher à quelqu'un de» + infinitivo.
- reconnais :: Eso es «reconozco».
- admets :: Eso es «admito».
Q Cap. 37. ¿Qué construcción usa «reprocher»?
+ reprocher à quelqu'un de + infinitif :: Persona + de + infinitivo.
- reprocher que + subjonctif :: Eso no es la construcción.
- reprocher quelqu'un + infinitif :: Falta «à».
H Cap. 37. Léa ___ que Paul est fatigué. :: Murmurar
+ murmure :: «Murmurer que» = murmurar que.
- crie :: Eso es «gritar».
- implore :: Eso es «suplicar».
H Cap. 38. Il ___ de finir le projet. :: Se trata de
+ s'agit :: «Il s'agit de» = se trata de.
- convient :: Eso es «conviene».
- importe :: Eso es «importa».
Q Cap. 38. ¿Qué significa «il me semble que»?
+ me parece que :: Opinión suave.
- me sorprende que :: Eso es «je suis surpris que».
- me alegra que :: Eso es «je suis content que».
H Cap. 39. Je ___ réparer ma voiture. :: Mandar
+ fais :: «Faire» + infinitivo = mandar hacer.
- répare :: Eso es «reparo yo».
- laisse :: Eso es «dejo».
Q Cap. 39. ¿Cómo se dice «mando reparar mi coche»?
+ Je fais réparer ma voiture. :: «Faire» + infinitivo.
- Je répare ma voiture. :: Eso es reparar yo mismo.
- Je fais ma voiture. :: Eso no tiene sentido.
H Cap. 39. Je ___ Thomas parler. :: Dejar que
+ laisse :: «Laisser» + infinitivo = dejar que.
- fais :: Eso es «hacer».
- veux :: Eso es «quiero».
H Cap. 40. La forêt est ___ par la pollution. :: Femenino
+ menacée :: «Forêt» es femenino: menacée.
- menacé :: Eso es masculino.
- menacer :: Eso es infinitivo.
Q Cap. 40. ¿Cómo se dice «el ladrón fue detenido ayer»?
+ Le voleur a été arrêté hier. :: Pasado pasivo.
- Le voleur est arrêté hier. :: Eso es presente.
- Le voleur sera arrêté hier. :: Eso es futuro.
Q Cap. 34. ¿Qué expresa «certes... mais»?
+ Concesión: es verdad..., pero. :: Reconoces un punto y luego contrastas.
- Causa: porque... :: Eso es «parce que».
- Finalidad: para que... :: Eso es «pour que».
