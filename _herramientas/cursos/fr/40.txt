@ 40 | La forêt est menacée | El bosque está amenazado
I Último capítulo temático: el medio ambiente y la actualidad. Son temas muy frecuentes en el DELF B2.
E La voz pasiva en la prensa :: Las noticias usan mucho la pasiva: **La forêt est menacée par la pollution** (el bosque está amenazado por la contaminación). :: Con la pasiva, la noticia se centra en lo que pasa, no en quién lo hace.
E Vocabulario del medio ambiente :: **Le réchauffement climatique** (el calentamiento climático), **le recyclage** (el reciclaje), **un transport durable** (un transporte sostenible). :: Son términos muy repetidos en debates y noticias.

D El clima y nosotros
Léa: La forêt est menacée par la pollution. = El bosque está amenazado por la contaminación.
  > la forêt = el bosque (sujeto femenino) | est menacée = está amenazada (voz pasiva: être en presente + participio concordado) | par la pollution = por la contaminación (complemento agente introducido por par)
Thomas: Il faut recycler, c'est écologique. = Hay que reciclar, es ecológico.
  > il faut recycler = hay que reciclar (falloir impersonal + infinitivo) | c'est écologique = es ecológico (presentador c'est + adjetivo invariable)
Léa: Le climat change à cause du réchauffement. = El clima cambia a causa del calentamiento.
  > le climat change = el clima cambia (sujeto masculino + presente de changer) | à cause du réchauffement = a causa del calentamiento (locución causal desfavorable à cause de + le)
Thomas: Un transport durable est possible. = Un transporte sostenible es posible.
  > un transport durable = un transporte sostenible (sustantivo masculino + adjetivo calificativo) | est possible = es posible (verbo être + atributo)
Q ¿Cómo se dice «el bosque está amenazado por la contaminación»?
+ La forêt est menacée par la pollution. :: Pasiva con «être» + participio y «par».
- La forêt menace la pollution. :: Eso es activa y no tiene sentido.
- La forêt est polluée. :: Eso dice que está contaminado, no amenazado.
Q ¿Qué significa «recycler»?
+ reciclar :: «Recycler» = reciclar.
- contaminar :: Eso es «polluer».
- calentar :: Eso es «réchauffer».
H La forêt est ___ par la pollution. :: Femenino singular
+ menacée :: «Forêt» es femenino: menacée.
- menacé :: Eso es masculino.
- menacer :: Eso es infinitivo.
H Il faut ___ les bouteilles. :: Reciclar
+ recycler :: «Il faut» + infinitivo: recycler.
- polluer :: Eso es contaminar.
- écologique :: Eso es un adjetivo.
R La forêt est menacée par la pollution.
+ El bosque está amenazado por la contaminación. :: Pasiva con «par».
- El bosque amenaza la contaminación. :: Eso es activa.
- El bosque está contaminado. :: Eso no es «menacée».
A Un transport durable est possible.
+ Un transporte sostenible es posible. :: «Durable» = sostenible.
- Un transporte durable es imposible. :: Eso cambia el sentido.
- El transporte es caro. :: Eso no es la frase.
O réchauffement climatique :: calentamiento climático :: Término del medio ambiente.
Q ¿Cómo se dice en francés «el reciclaje»?
+ le recyclage :: Sustantivo masculino derivado del verbo «recycler».
- le recycler :: Es la forma de infinitivo («reciclar»), no el sustantivo.
- la recyclage :: Los sustantivos franceses terminados en -age son masculinos.

@ 40 | Le voleur a été arrêté | El ladrón fue detenido
I Último paso: las noticias de sucesos en pasiva, con «a été» y «sera».
E Passé composé pasivo en la prensa :: **Le voleur a été arrêté hier** (el ladrón fue detenido ayer). Es el tiempo habitual para contar un hecho pasado.
E Futuro pasivo :: **Il sera jugé demain** (será juzgado mañana). Con **être accusé de** se dice de qué se acusa: **Il est accusé de fraude** (está acusado de fraude).
B Noticia | Forma | Ejemplo
| detención | a été arrêté | Le voleur a été arrêté hier.
| acusación | est accusé de | Il est accusé de fraude.
| juicio | sera jugé | Il sera jugé demain.
| víctimas | blessés | Deux blessés sont à l'hôpital.
W accusé = acusado | a-kü-ze
W accuser = acusar | a-kü-ze
W arrêté = detenido | a-re-te
W arrêtée = detenida | a-re-te
W juger = juzgar | zhü-zhe
W jugé = juzgado | zhü-zhe
W condamné = condenado | ko(n)-da-ne
W condamnée = condenada | ko(n)-da-ne
W libéré = liberado | li-be-re
W blessé = herido | ble-se
W blessés = heridos | ble-se

V Vocabulario: sucesos
D Un suceso
Thomas: Le voleur a été arrêté hier. = El ladrón fue detenido ayer.
  > le voleur = el ladrón (sujeto) | a été arrêté = fue detenido (passé composé pasivo: avoir + été + participio masculino singular) | hier = ayer (adverbio temporal)
Léa: Il est accusé de fraude. = Está acusado de fraude.
  > il est accusé = está acusado (voz pasiva con être en presente) | de fraude = de fraude (régimen preposicional de accuser de)
Thomas: Il sera jugé demain. = Será juzgado mañana.
  > il sera jugé = será juzgado (voz pasiva en futur simple: être en futuro + participio) | demain = mañana (adverbio temporal)
Léa: Deux blessés sont à l'hôpital. = Dos heridos están en el hospital.
  > deux blessés = dos heridos (numeral cardinal + adjetivo sustantivado plural) | sont = están (verbo être en presente) | à l'hôpital = en el hospital (preposición de lugar à + l')
Q ¿Cómo se dice «el ladrón fue detenido ayer»?
+ Le voleur a été arrêté hier. :: «A été» + participio: pasado pasivo.
- Le voleur est arrêté hier. :: Eso es presente.
- Le voleur sera arrêté hier. :: Eso es futuro.
Q ¿Qué significa «il sera jugé demain»?
+ Será juzgado mañana. :: Futuro pasivo.
- Será acusado mañana. :: Eso es «accusé».
- Será liberado mañana. :: Eso es «libéré».
H Il est ___ de fraude. :: Acusado
+ accusé :: «Être accusé de» = estar acusado de.
- arrêté :: Eso es «detenido».
- libéré :: Eso es «liberado».
H Deux ___ sont à l'hôpital. :: Heridos
+ blessés :: «Blessés» = heridos, plural.
- victime :: Eso es singular.
- blessé :: Eso es singular.
R Le voleur a été arrêté hier.
+ El ladrón fue detenido ayer. :: Pasado pasivo.
- El ladrón detiene ayer. :: Eso es activa.
- El ladrón será detenido ayer. :: Eso es futuro.
A Il sera jugé demain.
+ Será juzgado mañana. :: Futuro pasivo.
- Juzga mañana. :: Eso es activa.
- Lo juzgará mañana. :: Eso es futuro activo.
O une victime :: una víctima :: Persona que sufre un daño.
Q ¿Cómo se expresa en voz pasiva «él está acusado de fraude»?
+ Il est accusé de fraude. :: Voz pasiva con «être» en presente de indicativo y régimen preposicional «de».
- Il a accusé de fraude. :: Es la voz activa («él acusó»), lo que invierte el papel del sujeto.
- Il s'accuse de fraude. :: Significa «él se acusa a sí mismo».
