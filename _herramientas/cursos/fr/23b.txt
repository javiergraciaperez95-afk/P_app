@ 23 | Une émission sur un livre | Un programa sobre un libro
I Escucha una crítica de un libro en la radio: el personaje, la trama y la opinión. Anota qué gusta y qué no.
E Crítica literaria :: Una **critique** (crítica) habla de una **lecture** (lectura). El **personnage** (personaje) es quien vive la historia. Un **héros** es el protagonista masculino, y la **couverture** (portada) es la imagen del libro.
E En la librería :: En una **librairie** (librería) se compran libros. El **éditeur** (editorial) publica el libro. Un **chapitre** (capítulo) es una parte de la novela.
B Libro | Palabra | Ejemplo
| crítica | une critique | La critique est bonne.
| portada | la couverture | La couverture est bonne.
| librería | la librairie | La librairie est près d'ici.
W critique = crítica | kri-TÍK
W lecture = lectura | lek-TÜR
W personnage = personaje | per-so-NA(N)ZH
W éditeur = editor | e-di-TÖR
W couverture = portada | ku-ver-TÜR
W librairie = librería | li-bre-RÍ
W héros = protagonista | e-RÓ
W chapitre = capítulo | sha-PÍTR
W intrigue = trama | a(n)-TRIG
W poème = poema | po-É(M)
W écrivain = escritor | e-kri-VIÁ(N)
W dédicace = dedicatoria | de-di-KÁS
V Vocabulario: libros
D Una emisión de radio
Animateur: Aujourd'hui, c'est un roman. = Hoy es una novela.
  > aujourd'hui = hoy | un roman = una novela
Animateur: Le personnage est fort. = El personaje es fuerte.
  > le personnage = el personaje | fort = fuerte
Critique: Le héros est jeune. = El protagonista es joven.
  > le héros = el protagonista | jeune = joven
Critique: Une intrigue est bonne, et le dernier chapitre est très bien. = Una trama es buena, y el último capítulo está muy bien.
  > une intrigue = una trama | le dernier chapitre = el último capítulo
Animateur: C'est quel éditeur ? = ¿Qué editorial es?
  > quel éditeur = qué editorial
Critique: La couverture est bonne. = La portada es buena.
  > la couverture = la portada
Q ¿Qué personaje es fuerte?
+ Le personnage. :: El personaje.
- Le héros. :: No es lo que dice el texto.
- L'éditeur. :: No es el personaje.
Q ¿Cómo es la trama?
+ Bonne. :: Buena.
- Triste. :: No lo dice la crítica.
- Mauvaise. :: No lo dice la crítica.
R Le personnage est fort.
+ El personaje es fuerte. :: «Fort» = fuerte.
- El personaje es débil. :: Es lo contrario.
- El personaje es joven. :: No es lo que dice la frase.
H Le ___ est jeune.
+ héros :: Protagonista masculino de la historia.
- chapitre :: Es una parte del libro.
- éditeur :: Es la editorial.
H La ___ est bonne.
+ couverture :: La portada: la imagen de fuera del libro.
- critique :: Es la crítica, no la portada.
- lecture :: Es la lectura.
A La librairie est près d'ici.
+ La librería está cerca de aquí. :: «Près d'ici» = cerca de aquí.
- La librería está lejos de aquí. :: Es lo contrario.
- La librería cierra hoy. :: No lo dice la frase.
O un écrivain :: un escritor :: Persona que escribe libros.
X Escribe en francés: «el último capítulo» :: le dernier chapitre :: «Dernier» antes del sustantivo.

@ 23 | Internet et les réseaux | Internet y las redes
I Hoy hablamos de tecnología: el portátil, la conexión, las aplicaciones y los sitios web. Escucha a dos amigos que hablan de internet.
E Internet :: Con un **portable** (portátil) o un **ordinateur** (ordenador) se entra en un **site** (sitio web) con **internet**. Una **connexion** (conexión) puede ser buena o mala.
E Aplicaciones :: Una **application** (aplicación) se **télécharger** (descargar). Un **logiciel** (programa) funciona en el ordenador. El **clavier** (teclado) es la parte que se escribe.
B Tecnología | Palabra | Ejemplo
| red | le réseau | Le réseau est rapide.
| descargar | télécharger | Je peux télécharger une application.
| teclado | le clavier | Le clavier est petit.
W réseau = red | re-ZÓ
W internet = internet | a(n)-tor-NÉT
W application = aplicación | a-pli-ka-SIÓN
W portable = portátil | por-TÁBL
W site = sitio web | SIT
W clavier = teclado | kla-VIÉ
W numérique = digital | nü-me-RÍK
W connexion = conexión | ko(n)-ne-SIÓN
W logiciel = programa informático | lo-zhi-SIÉL
W télécharger = descargar | te-le-shar-ZHÉ
W messagerie = mensajería | me-sa-zhe-RÍ
W courrier = correo | ku-RIÉ
V Vocabulario: tecnología
D Dos amigos y la tecnología
Léa: Tu as un portable ? = ¿Tienes un portátil?
  > tu as = tienes | un portable = un portátil
Thomas: Oui, mais la connexion est bonne. = Sí, pero la conexión es buena.
  > la connexion = la conexión | bonne = buena
Léa: Tu peux télécharger une application ? = ¿Puedes descargar una aplicación?
  > tu peux = puedes | une application = una aplicación
Thomas: Oui, j'ai un bon site. = Sí, tengo un buen sitio web.
  > un bon site = un buen sitio web
Léa: Tu écris un courrier ? = ¿Escribes un correo?
  > tu écris = escribes | un courrier = un correo
Thomas: Non, le clavier est petit. = No, el teclado es pequeño.
  > le clavier = el teclado | petit = pequeño
Q ¿Qué tiene Thomas?
+ Un portable. :: Un portátil.
- Un réseau. :: No es lo que tiene.
- Un logiciel. :: No aparece en el diálogo.
Q ¿Qué puede descargar Léa?
+ Une application. :: Una aplicación.
- Une lettre. :: No aparece en el diálogo.
- Un clavier. :: No es lo que puede descargar.
R La connexion est bonne.
+ La conexión es buena. :: «Bonne» = buena.
- La conexión es mala. :: Es lo contrario.
- La conexión es lenta. :: No lo dice la frase.
H Je peux ___ une application.
+ télécharger :: Descargar: bajar algo a tu aparato.
- logiciel :: Es el programa, no la acción.
- site :: Es el sitio web.
H Le ___ est petit.
+ clavier :: El teclado del portátil.
- réseau :: Es la red.
- numérique :: Es digital.
A Le réseau est rapide.
+ La red es rápida. :: «Réseau» = red.
- La red es lenta. :: Es lo contrario.
- La red es un teclado. :: No es la frase.
O la messagerie :: la mensajería :: Donde llegan los correos.
X Escribe en francés: «un buen sitio web» :: un bon site :: «Bon» antes del sustantivo.
