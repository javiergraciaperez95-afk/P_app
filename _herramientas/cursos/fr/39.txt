@ 39 | Je fais réparer ma voiture | Mando reparar mi coche
I Hoy hacemos que otros hagan cosas por nosotros, o dejamos que las hagan. Son dos construcciones muy útiles.
E Faire + infinitivo :: **Faire** + infinitivo significa «hacer que alguien haga algo» o «mandar hacer»: **Je fais réparer ma voiture** (mando reparar mi coche). :: No se dice **Je répare ma voiture** si la reparación la hace otra persona.
E Lugar de los pronombres :: Los pronombres van delante de **faire**: **Je la fais réparer** (la mando reparar). El infinitivo no cambia.
B Expresión | Significa | Ejemplo
| faire + infinitivo | mandar hacer | Je fais réparer ma voiture.
| faire tailler | mandar cortar | Tu fais tailler tes cheveux ?
| faire peindre | mandar pintar | Je fais peindre le salon.
W réparer = reparar | re-pa-RÉ
W tailler = cortar | ta-IÉ
W coiffeur = peluquero | kua-FÖR
W coiffeuse = peluquera | kua-FÖZ
W construire = construir | ko(n)-STRUÍR
W peindre = pintar | PA(N)DR
W peint = pintado | PA(N)
W installer = instalar | a(n)-sta-LÉ
W nettoyer = limpiar | ne-toa-YÉ
W nettoie = limpia | ne-TUÁ
W vérifier = verificar | ve-ri-FIÉ
W répare = repara | re-PAR
V Vocabulario: mandar hacer
D Preparar la casa
Léa: Je fais réparer ma voiture demain. = Mando reparar mi coche mañana.
  > je fais réparer = mando reparar | ma voiture = mi coche
Thomas: Tu fais tailler tes cheveux ? = ¿Te cortas el pelo?
  > tu fais tailler = te cortas | tes cheveux = tu pelo
Léa: Oui, je vais chez le coiffeur. = Sí, voy a la peluquería.
  > chez le coiffeur = a la peluquería
Thomas: Je fais peindre le salon. = Mando pintar el salón.
  > je fais peindre = mando pintar | le salon = el salón
Q ¿Cómo se dice «mando reparar mi coche»?
+ Je fais réparer ma voiture. :: «Faire» + infinitivo = mandar hacer.
- Je répare ma voiture. :: Eso significa que yo la reparo.
- Je fais ma voiture. :: Eso no tiene sentido.
Q ¿Cuál es correcta para «mando pintar el salón»?
+ Je fais peindre le salon. :: «Faire» + infinitivo.
- Je fais peint le salon. :: El participio no va con «faire» aquí.
- Je fais à peindre le salon. :: Sobra «à».
H Je fais ___ ma voiture. :: Mandar reparar
+ réparer :: «Faire» + infinitivo: réparer.
- réparée :: Eso es participio.
- répare :: Eso es presente.
H Je vais chez le ___. :: Peluquería
+ coiffeur :: Es el peluquero, donde te cortas el pelo.
- pâtisserie :: Eso es la pastelería.
- docteur :: Eso es el médico.
R Je fais réparer ma voiture.
+ Mando reparar mi coche. :: «Faire réparer» = mandar reparar.
- Reparo mi coche. :: Eso es reparar yo mismo.
- Hago mi coche. :: Eso no tiene sentido.
A Tu fais tailler tes cheveux ?
+ ¿Te cortas el pelo? :: «Faire tailler» = mandar cortar.
- ¿Cortas tu pelo? :: Eso es cortar tú mismo.
- ¿Tienes pelo? :: Eso no es la pregunta.
O faire venir :: hacer venir :: Causativo con infinitivo.
X Escribe en francés: «mando pintar el salón» :: je fais peindre le salon :: «Faire» + infinitivo.

@ 39 | Je laisse Thomas parler | Dejo que Thomas hable
I Ahora dejar que otros hagan algo: «laisser» + infinitivo.
E Laisser + infinitivo :: **Laisser** + infinitivo significa «dejar que»: **Je laisse Thomas parler** (dejo que Thomas hable). :: El sujeto del infinitivo va después del verbo **laisser**.
E Laisser tomber :: **Laisser tomber** (dejarlo, olvidarlo) es una expresión muy usada: **Laisse tomber, c'est sans importance** (déjalo, no es importante).
B Expresión | Significa | Ejemplo
| laisser + infinitivo | dejar que | Je laisse Thomas parler.
| laisser tranquille | dejar en paz | Tu me laisses tranquille !
| laisser le choix | dejar elegir | Je te laisse le choix.
W laisser = dejar | le-SÉ
W laisse = deja | les
W laisses = dejas | les
W laissé = dejado | le-SÉ
W tranquille = tranquilo | tra(n)-KIL
W tranquillement = tranquilamente | tra(n)-kil-MA(N)
W souci = preocupación | sü-SI
W soucier = preocupar | sü-sié
W lâcher = soltar | la-SHÉ
W lâche = suelta | LASH
W relâcher = aflojar | re-la-SHÉ
W tomber = caer | to(n)-BÉ
W choix = elección | shuá
W liberté = libertad | li-BER-TÉ

D Un poco de paz

  > je laisse Thomas parler = dejo que Thomas hable

  > tu me laisses tranquille = me dejas en paz

  > je te laisse le choix = te dejo elegir
Thomas: Laisse tomber, c'est sans importance. = Déjalo, no es importante.
  > laisse tomber = déjalo | sans importance = sin importancia
Q ¿Qué significa «laisser parler»?
+ dejar hablar :: «Laisser» + infinitivo = dejar que.
- hacer hablar :: Eso es «faire parler».
- obligar a hablar :: Eso no es esta construcción.
Q ¿Cuál es correcta para «dejo que Léa hable»?
+ Je laisse Léa parler. :: «Laisser» + sujeto + infinitivo.
- Je laisse Léa parle. :: Después de «laisser» va infinitivo.
- Je laisse Léa de parler. :: Sobra «de».
H Je ___ Thomas parler. :: Dejar que
+ laisse :: «Laisser» en presente con «je».
- fais :: Eso es «hacer».
- veux :: Eso es «quiero».
H Tu me ___ tranquille ! :: Dejar en paz
+ laisses :: «Laisser» en presente con «tu».
- fais :: Eso es «hacer».
- veux :: Eso es «quieres».
R Je laisse Thomas parler.
+ Dejo que Thomas hable. :: «Laisser» + infinitivo.
- Hago que Thomas hable. :: Eso es «faire».
- Obligo a Thomas a hablar. :: Eso es «obliger».
A Laisse tomber, c'est sans importance.
+ Déjalo, no es importante. :: «Laisser tomber» = olvidarlo.
- Recógelo, es importante. :: Eso es «ramasser».
- Levántate, es importante. :: Eso es «se lever».
O laisser tomber :: dejarlo, olvidarlo :: Expresión.

@ 39 | Se laisser convaincre | Dejarse convencer
I Último paso: «se laisser» y «se faire», cuando la acción le pasa a la persona.
E Se laisser + infinitivo :: **Se laisser** + infinitivo significa «dejarse»: **Paul se laisse convaincre** (Paul se deja convencer).
E Se faire + infinitivo :: **Se faire** + infinitivo también puede significar «dejarse», sobre todo en lo negativo: **Il se fait tromper facilement** (se deja engañar fácilmente).
B Expresión | Significa | Ejemplo
| se laisser + infinitif | dejarse | Il se laisse convaincre.
| se faire + infinitif | dejarse (lo negativo) | Il se fait tromper facilement.
| ne pas se laisser | no dejarse | Il ne faut pas se laisser influencer.
W convaincre = convencer | ko(n)-VÉNKR
W convaincu = convencido | ko(n)-va(n)-KÜ
W convaincue = convencida | ko(n)-va(n)-KÜ
W tromper = engañar | tro(n)-PÉ
W trompé = engañado | tro(n)-PÉ
W tromperie = engaño | tro(n)-PRÍ
W persuader = persuadir | per-sü-a-DÉ
W persuadé = persuadido | per-sü-a-DÉ
W influencer = influir | i(n)-flü-a(n)-SÉ
W influence = influencia | i(n)-flü-A(N)S
W piéger = engañar, atrapar | pié-ZHÉ
W piège = trampa | pièzh
W facilement = fácilmente | fa-si-l-MA(N)
V Vocabulario: dejarse
D No ser ingenuo

  > se laisse convaincre = se deja convencer
Thomas: Il se fait tromper facilement. = Se deja engañar fácilmente.

Q ¿Qué significa «se laisser convaincre»?
+ dejarse convencer :: «Se laisser» + infinitivo.
- convencer a alguien :: Eso sería «convaincre quelqu'un».
- hacerse convencer :: Eso no es esta construcción.
Q ¿Cuál es correcta para «se deja engañar»?
+ Il se laisse tromper. :: «Se laisser» + infinitivo.
- Il se fait laisser tromper. :: Eso no es la construcción.
- Il laisse se tromper. :: Eso significa «deja que se engañe».
H Il ne faut pas se ___ influencer. :: Dejarse
+ laisser :: «Se laisser» + infinitivo.
- faire :: Eso no es esta forma aquí.
- avoir :: Eso no es esta forma aquí.
H Il se ___ tromper facilement. :: Dejarse
+ fait :: «Se faire» + infinitivo.
- laisse :: Eso es «se laisse» con infinitivo.
- avoir :: Eso no es esta forma aquí.
R Il se laisse convaincre.
+ Se deja convencer. :: «Se laisser» + infinitivo.
- Se hace convencer. :: Eso no es «se laisser».
- Convence a los demás. :: Eso no es reflexivo.
A Il se fait tromper facilement.
+ Se deja engañar fácilmente. :: «Se faire» + infinitivo, lo negativo.
- Engaña fácilmente. :: Eso es activo.
- Se hace engañar, no es fácil. :: Eso no tiene sentido.
O se laisser influencer :: dejarse influir :: «Se laisser» + infinitivo.
