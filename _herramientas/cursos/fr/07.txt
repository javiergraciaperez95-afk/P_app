@ 7 | Les vêtements | La ropa y los demostrativos
E Este, esta, estos :: Por sí solas, las formas **ce/cet/cette/ces** no distinguen «este» de «ese»; el contexto lo aclara. Si hace falta, se puede añadir **-ci** (aquí) o **-là** (allí) después del nombre: **ce pantalon-ci**, **ce pantalon-là**. :: **ce** pantalon (masculino), **cette** robe (femenino), **ces** chaussures (plural). :: Delante de vocal o h muda, **ce** se convierte en **cet**: **cet ordinateur**, **cet hôtel**.
B Los demostrativos | | Forma | Ejemplo
| masculino | ce | ce manteau
| masculino ante vocal | cet | cet appartement
| femenino | cette | cette veste
| plural | ces | ces chaussures
E Llevar puesto :: **Porter** es «llevar puesto»: **Je porte une veste** (llevo una chaqueta). Es un verbo regular en -er. :: Los colores concuerdan con la prenda: **un manteau noir**, **une veste noire**, **des chaussures noires**. Recuerda: **blanc** → **blanche**. Los que acaban en -e no cambian en femenino: **rouge**, **jaune**. :: **J'aime bien** = me gusta (bastante). **Je préfère** = prefiero.

W chemise = camisa | she-MIZ
W tee-shirt = camiseta | ti-SHERT
W pantalon = pantalón | pa(n)-ta-LO(N)
W jean = vaqueros | yin
W robe = vestido | rob
W jupe = falda | zhüp
W veste = chaqueta | vest
W manteau = abrigo | ma(n)-TÓ
W chaussures = zapatos | sho-SÜR
W je porte = llevo puesto | zhe port
W il porte = lleva puesto | il port
W ce = este, ese (masculino) | se
W cet = este, ese (masculino ante vocal o h muda) | sè
W cette = esta, esa | set
W ces = estos, estas; esos, esas | se
W bleue = azul (femenino) | blö
w blanche = blanca | bla(n)sh

V Vocabulario: la ropa
D Por teléfono
Julie: Salut, Hugo. Tu es où ? = Hola, Hugo. ¿Dónde estás?
  > Tu es où = dónde estás
Hugo: Je suis devant le magasin. Je porte une veste rouge. = Estoy delante de la tienda. Llevo una chaqueta roja.
  > devant le magasin = delante de la tienda | Je porte = llevo puesto | une veste rouge = una chaqueta roja
Julie: Moi, je porte un manteau noir et un jean bleu. = Yo llevo un abrigo negro y unos vaqueros azules.
  > un manteau noir = un abrigo negro | un jean bleu = unos vaqueros azules (en francés, singular)
Hugo: Thomas est avec toi ? = ¿Thomas está contigo?
  > avec toi = contigo
Julie: Oui. Il porte un tee-shirt vert. = Sí. Lleva una camiseta verde.
  > Il porte = él lleva | un tee-shirt vert = una camiseta verde
Hugo: D'accord, je vois Thomas ! = ¡Vale, ya veo a Thomas!
  > je vois = veo
D En el escaparate
Emma: J'aime bien cette robe bleue. = Me gusta este vestido azul.
  > J'aime bien = me gusta | cette robe = este vestido (femenino en francés) | bleue = azul, con -e
Lucas: Et ce pantalon ? = ¿Y este pantalón?
  > ce pantalon = este pantalón
Emma: Non, je préfère ces chaussures. = No, prefiero estos zapatos.
  > je préfère = prefiero | ces chaussures = estos zapatos
Q ¿Cómo dices «este vestido»?
+ cette robe :: «Robe» es femenino → cette.
- ce robe :: «Ce» es para masculino.
- ces robe :: «Ces» es para plural.
Q ¿Cómo dices «este hotel»?
+ cet hôtel :: Masculino ante h muda → cet.
- ce hôtel :: Ante vocal o h muda hay que usar «cet».
- cette hôtel :: «Hôtel» es masculino.
Q ¿Cuál es correcta?
+ une veste noire :: «Veste» es femenino: el color lleva -e.
- une veste noir :: Falta la -e del femenino.
- une noire veste :: El color va detrás.
R Je porte un manteau noir.
+ Llevo un abrigo negro. :: Porter = llevar puesto.
- Compro un abrigo negro. :: Sería «j'achète».
- Llevo una chaqueta negra. :: Chaqueta es «veste».
H ___ chaussures sont dans le magasin.
+ Ces :: Plural → ces.
- Ce :: Es singular masculino.
- Cette :: Es singular femenino.
H J'aime bien ___ jupe.
+ cette :: «Jupe» es femenino.
- ce :: Es para masculino.
- cet :: Es para masculino ante vocal.
A Il porte une chemise blanche.
+ Lleva una camisa blanca. :: Chemise = camisa; blanche = blanca.
- Lleva una camiseta blanca. :: Camiseta es «tee-shirt».
- Lleva una camisa negra. :: Negra es «noire».
O Je préfère ces chaussures noires :: Prefiero estos zapatos negros :: Je préfère + demostrativo + prenda + color.

@ 7 | Ça coûte combien ? | Comprar: precios y tallas
E Del 70 al 100 :: En el francés estándar de Francia, **70–79** se forman con **soixante + 10–19**. Para **71** se usa **et**: **soixante et onze**; para **73**: **soixante-treize**. :: **80** se dice **quatre-vingts** con una **s** final cuando va solo. Del **81** al **89** se usa **quatre-vingt + 1–9**, sin esa **s**: **quatre-vingt-un**. :: Del **90** al **99** se usa **quatre-vingt + 10–19**: **91**, **quatre-vingt-onze**; **99**, **quatre-vingt-dix-neuf**. :: **100** es **cent**.
B Del 70 al 100 | Número | Francés | Se pronuncia
| 70 | soixante-dix | sua-sa(n)t-DIS
| 71 | soixante et onze | sua-sa(n)-te-O(N)Z
| 80 | quatre-vingts | katr-VE(N)
| 81 | quatre-vingt-un | katr-ve(n)-E(N)
| 90 | quatre-vingt-dix | katr-ve(n)-DIS
| 99 | quatre-vingt-dix-neuf | katr-ve(n)-dis-NÖF
| 100 | cent | sa(n)
E En la tienda :: El precio se pregunta con **coûter**: **Cette robe coûte combien ?** En plural: **Ces chaussures coûtent combien ?** :: **Trop** delante de un adjetivo es «demasiado»: **trop cher** (demasiado caro), **trop petit**. :: **Je peux essayer ?** = ¿puedo probármelo? :: Para decidirte: **Je le prends** (me lo llevo, masculino) o **Je la prends** (me la llevo, femenino). :: Para pagar: **par carte** (con tarjeta) o **en espèces** (en efectivo).

W coûtent = cuestan | cut
W cher = caro | shèr
W chère = cara | shèr
W trop = demasiado | tro
W pas cher = barato | pa sher
W taille = talla | tai
W je peux = puedo | zhe pö
W essayer = probar, probarse | e-se-YÉ
W jolie = bonita | zho-LÍ
W joli = bonito | zho-LÍ
W je la prends = me la llevo | zhe la pra(n)
W je le prends = me lo llevo | zhe le pra(n)
W payer = pagar | pe-YÉ
W par carte = con tarjeta | par cart
W en espèces = en efectivo | a(n)-nes-PÈS
W cent = cien | sa(n)
W soixante-dix = setenta | sua-sa(n)t-DIS
W quatre-vingts = ochenta | katr-VE(N)
V Vocabulario: de compras
D En la tienda de ropa
Marie: Excusez-moi, cette robe coûte combien ? = Disculpe, ¿cuánto cuesta este vestido?
  > cette robe = este vestido | coûte combien = cuánto cuesta
Chloé: Elle coûte 45 euros. = Cuesta 45 euros.
  > Elle coûte = cuesta («elle» porque «robe» es femenino)
Marie: Et ces chaussures ? = ¿Y estos zapatos?
  > ces chaussures = estos zapatos
Chloé: Elles coûtent 80 euros. = Cuestan 80 euros.
  > Elles coûtent = cuestan (plural)
Marie: C'est trop cher. Vous avez cette robe en taille 38 ? = Es demasiado caro. ¿Tiene este vestido en la talla 38?
  > trop cher = demasiado caro | en taille 38 = en la talla 38
Chloé: Oui, voilà. = Sí, aquí tiene.
  > voilà = aquí tiene
Marie: Je peux essayer ? = ¿Puedo probármelo?
  > Je peux = puedo | essayer = probar
Chloé: Bien sûr. = Por supuesto.
  > Bien sûr = claro
Marie: Elle est jolie. Je la prends. Je peux payer par carte ? = Es bonito. Me lo llevo. ¿Puedo pagar con tarjeta?
  > Je la prends = me la llevo («la» = la robe) | payer par carte = pagar con tarjeta
Q ¿Cómo se dice «70»?
+ soixante-dix :: Sesenta + diez.
- septante :: Es oficial en Bélgica y Suiza, y también se conserva en algunas regiones de Francia. En el francés estándar de Francia se usa «soixante-dix».
- sept-dix :: No.
Q ¿Qué número es «quatre-vingt-dix»?
+ 90 :: Cuatro veintes más diez.
- 80 :: Sería «quatre-vingts».
- 410 :: No se lee cifra a cifra.
Q Te llevas una chaqueta («une veste»). ¿Qué dices?
+ Je la prends. :: Femenino → la.
- Je le prends. :: «Le» es para masculino.
- Je prends elle. :: El pronombre va delante del verbo.
R C'est trop cher.
+ Es demasiado caro. :: Trop + adjetivo = demasiado.
- Es muy barato. :: Barato es «pas cher».
- No es caro. :: No.
H Ces chaussures ___ combien ?
+ coûtent :: Plural → coûtent.
- coûte :: Es singular.
- coûtez :: Va con «vous».
H Je peux payer ___ carte ?
+ par :: Par carte = con tarjeta.
- avec :: Se entiende, pero la expresión es «par carte».
- en :: «En» va con «espèces».
A Je peux essayer cette veste ?
+ ¿Puedo probarme esta chaqueta? :: Essayer = probarse.
- ¿Puedo comprar esta chaqueta? :: Sería «acheter».
- ¿Cuánto cuesta esta chaqueta? :: No.
O Cette jupe coûte combien :: ¿Cuánto cuesta esta falda? :: Demostrativo + prenda + coûte combien.

@ 7 | Plus cher, moins cher | Comparar precios
E Comparar precios :: Para comparar dos precios puedes usar **plus cher que** (más caro que) y **moins cher que** (menos caro que / más barato que). :: La estructura es **plus/moins + cher/chère + que**: **Ce sac est moins cher que cette veste**. El adjetivo concuerda en género y número: **un sac moins cher**, **une chemise moins chère**, **des chaussures moins chères**. :: En este nivel basta con reconocer y usar estas expresiones en una compra.
B Comparar precios | Francés | Español
| plus cher que | más caro que
| plus chère que | más cara que
| moins cher que | menos caro que; más barato que
| moins chère que | menos cara que; más barata que
W plus = más | plü
W moins = menos | mue(n)
W que = que | ke
W plus cher = más caro | plü shèr
W moins cher = menos caro, más barato | mue(n) shèr
W plus chère = más cara | plü shèr
W moins chère = menos cara; más barata | mue(n) shèr
W tu préfères = prefieres | tü pre-FÈR
V Vocabulario: comparar
D ¿Qué móvil te llevas?
Thomas: Tu préfères le téléphone blanc ? = ¿Prefieres el móvil blanco?
  > Tu préfères = prefieres
Léa: Le téléphone blanc est moins cher que le téléphone noir. = El móvil blanco es más barato que el negro.
  > moins cher que = menos caro que; más barato que
Thomas: Et le téléphone noir ? = ¿Y el móvil negro?
  > et = y
Léa: Il est plus cher. Je prends le blanc. = Es más caro. Me llevo el blanco.
  > plus cher = más caro | je prends = me llevo
Q ¿Cómo dices «más caro que»?
+ plus cher que :: Plus + cher + que.
- plus cher de :: En esta comparación se usa «que».
- cher plus que :: «Plus» va delante de «cher».
Q ¿Qué significa «moins cher»?
+ Menos caro; más barato. :: Es una expresión útil al comprar.
- Más caro. :: Eso es «plus cher».
- El más caro. :: «Le plus cher» es el más caro.
Q El móvil blanco cuesta menos. ¿Cuál frase lo expresa?
+ Le téléphone blanc est moins cher. :: «Moins cher» = menos caro.
- Le téléphone blanc est plus cher. :: Significa que cuesta más.
- Le téléphone blanc est cher plus. :: El orden no es correcto.
R Ce sac est plus cher que cette veste.
+ Este bolso es más caro que esta chaqueta. :: Plus cher que = más caro que.
- Este bolso es más barato que esta chaqueta. :: Sería «moins cher».
- Esta chaqueta es más cara que este bolso. :: Al revés.
H Cette chemise est moins chère ___ cette veste.
+ que :: Al comparar, «que»; «chère» concuerda con «chemise».
- de :: No.
- comme :: No.
H Le téléphone blanc est ___ cher que le noir.
+ moins :: El blanco cuesta menos que el negro.
- plus :: «Plus» significa más.
- aussi :: «Aussi» significa tan; aquí falta la comparación correspondiente.
A Le téléphone noir est plus cher que le blanc.
+ El móvil negro es más caro que el blanco. :: Plus cher que = más caro que.
- El móvil negro es más barato que el blanco. :: Sería «moins cher».
- El móvil blanco es más caro que el negro. :: Se invierte el orden.
O Ce téléphone est moins cher que ce sac :: Este teléfono es menos caro que este bolso :: Moins + cher/chère + que.
