@ 26 | Le pain est fait | El pan está hecho
I Hoy la voz pasiva: cuando lo importante es lo que se hace, no quien lo hace.
E Formación :: Se forma con **être** (en el tiempo que quieras) + participio pasado. El participio **concuerda con el sujeto**: **Le gâteau est fait** (el pastel está hecho), **La lettre est écrite** (la carta está escrita). :: Compara con el español: «está hecho» o «fue escrito» es igual en francés.
E Ojo :: Con **être** el participio cambia de forma: masculino o femenino y singular o plural: **écrit**, **écrite**, **écrits**, **écrites**.
B Participio | Masculino singular | Femenino singular | Plural
| escribir | écrit | écrite | écrits / écrites
| construir | construit | construite | construits / construites
| vender | vendu | vendue | vendus / vendues
| leer | lu | lue | lus / lues
W écrit = escrito | e-kri
W écrite = escrita | e-krit
W écrites = escritas | e-krit
W construit = construido | ko(n)-strüi
W construite = construida | ko(n)-strüit
W cuit = cocido | küi
W vendu = vendido | va(n)-dü
W vendue = vendida | va(n)-dü
W vendus = vendidos | va(n)-dü
W lu = leído | lü
W lue = leída | lü
W créé = creado | kre-e
W créée = creada | kre-e
W connu = conocido | ko-nü
W gâteau = pastel | ga-to
W chocolat = chocolate | sho-ko-la
W fermée = cerrada | fèr-me
V Vocabulario: participios
D Un pastel especial
Léa: Ce gâteau est fait avec du chocolat ! = ¡Este pastel está hecho con chocolate!
  > Ce gâteau = este pastel | est fait = está hecho | avec du chocolat = con chocolate
Thomas: Il est vendu à la boulangerie ? = ¿Se vende en la panadería?
  > Il est vendu = se vende / es vendido | à la boulangerie = en la panadería
Léa: Oui, il est cuit ce matin. = Sí, está cocido esta mañana.
  > Oui = sí | il est cuit = está cocido / horneado | ce matin = esta mañana
Thomas: Ce livre est écrit par un auteur très connu. = Este libro está escrito por un autor muy conocido.
  > Ce livre = este libro | est écrit = está escrito | par un auteur = por un autor | très connu = muy conocido
Q ¿Cómo se dice «el pastel es preparado por Léa»?
+ Le gâteau est préparé par Léa. :: «Être» + participio + «par» = pasiva.
- Le gâteau prépare Léa. :: Eso es activa.
- Le gâteau a préparé Léa. :: Eso es activa en passé composé.
Q ¿Cuál es correcta para «las cartas están escritas»?
+ Les lettres sont écrites. :: «Lettres» es femenino plural: «écrites».
- Les lettres sont écrit. :: Falta concordar el participio.
- Les lettres sont écrits. :: Eso es masculino plural.
H La porte est ___. :: Femenino singular
+ fermée :: «Porte» es femenino: «fermée».
- fermé :: Eso es masculino.
- fermés :: Eso es masculino plural.
H Les gâteaux sont ___ ce matin. :: Masculino plural
+ vendus :: «Gâteaux» es masculino plural: «vendus».
- vendue :: Eso es femenino singular.
- vendu :: Eso es masculino singular.
R Le gâteau est fait avec du chocolat.
+ El pastel está hecho con chocolate. :: Pasiva con «être».
- El pastel hace chocolate. :: Eso es activa.
- El pastel hizo chocolate. :: Eso es pasado activo.
A Ce livre est écrit par un auteur.
+ Este libro está escrito por un autor. :: Pasiva con agente «par».
- Este libro escribe un autor. :: Eso es activa.
- Este libro escribió un autor. :: Eso es pasado activo.
O est vendu :: está vendido :: Pasiva en presente: «est» + participio.
Q ¿Cómo se dice correctamente «la carta está escrita»?
+ La lettre est écrite. :: El participio «écrit» concuerda en género femenino con «la lettre» («écrite»).
- La lettre est écrit. :: Falta la concordancia de femenino en el participio («écrite»).
- La lettre a écrit. :: Eso indicaría voz activa («la carta ha escrito»), no pasiva.

@ 26 | Construit par des ouvriers | Construido por obreros
I Ahora decimos quién hace la acción: con «par» o con «de».
E Par (agente) :: **Par** suele introducir al agente que realiza una acción: **Ce pont est construit par des ouvriers** (este puente lo construyen unos obreros). :: No siempre se expresa el agente: **Le pont a été construit en 1990** (el puente se construyó en 1990).
E De (algunos verbos y expresiones) :: **De** aparece con frecuencia con verbos de sentimiento o valoración: **Il est aimé de tout le monde** (todo el mundo lo quiere). :: Es una tendencia de uso, no una regla absoluta; la elección depende del verbo y de la expresión.
B Agente | Preposición | Ejemplo
| acción concreta | par | Le pont est construit par des ouvriers.
| sentimiento o estado | de | Il est aimé de tout le monde.
W pont = puente | po(n)
W ouvrier = obrero | u-vrye
W ouvriers = obreros | u-vrye
W respecté = respetado | rès-pèk-te
W apprécié = apreciado | a-pre-sye
W admiré = admirado | ad-mi-re
W ministre = ministro | mi-nistr
W gouvernement = gobierno | gu-vèr-ne-ma(n)
W loi = ley | lua
W bâtiment = edificio | ba-ti-ma(n)
W architecte = arquitecto | ar-shi-tèkt
W populaire = popular | po-pü-lèr
V Vocabulario: obras y personas
D El edificio nuevo
Léa: Ce pont est construit par des ouvriers. = Este puente está construido por obreros.
  > Ce pont = este puente | est construit = está construido | par des ouvriers = por obreros
Thomas: Le bâtiment est construit par un architecte. = El edificio está construido por un arquitecto.
  > Le bâtiment = el edificio | est construit = está construido | par un architecte = por un arquitecto
Léa: Il est très apprécié de tout le monde. = Es muy apreciado por todo el mundo.
  > Il est très apprécié = es muy apreciado | de tout le monde = por todo el mundo
Thomas: Oui, il est populaire. = Sí, es popular.
  > Oui = sí | il est populaire = es popular
Q ¿Qué preposición introduce el agente en «construit par des ouvriers»?
+ par :: «Par» introduce quién hace la acción.
- de :: «De» se usa con sentimientos o estados.
- à :: «À» no introduce agentes.
Q ¿Cuál es correcta para «es admirado por todos»?
+ Il est admiré de tout le monde. :: Con verbos de admiración se usa «de».
- Il est admirer tout le monde. :: Eso no es una frase correcta.
- Il est admiré tout le monde. :: Falta la preposición.
H Ce pont est ___ par des ouvriers. :: Masculino singular
+ construit :: «Pont» es masculino: «construit».
- construite :: Eso es femenino.
- connu :: Eso no significa construido.
H Il est ___ de tout le monde. :: Sentimiento
+ aimé :: Con «aimé» y «de» se habla de sentimiento.
- aimes :: Eso es «amas».
- vendu :: Eso significa «vendido»; no encaja con sentimientos.
R Le bâtiment est construit par un architecte.
+ El edificio está construido por un arquitecto. :: Pasiva con agente.
- El edificio construye un arquitecto. :: Eso es activa.
- El edificio construyó un arquitecto. :: Eso es pasado activo.
A Il est très apprécié.
+ Está muy apreciado. :: Pasiva en presente.
- Aprecia mucho. :: Eso es activa.
- Apreciará mucho. :: Eso es futuro activo.
O par des ouvriers :: por obreros :: «Par» + agente.
Q ¿Cómo se formula en pasiva «el cuadro es admirado por todos»?
+ Le tableau est admiré de tout le monde. :: Con verbos de sentimiento o estima («admirer», «aimer»), el agente se introduce tradicionalmente con «de».
- Le tableau a admiré tout le monde. :: Eso es voz activa en passé composé («el cuadro ha admirado a todos»).
- Le tableau est admiré par le monde entière. :: Error gramatical y léxico frente al uso idiomático «admiré de tout le monde».

@ 26 | Le musée a été ouvert hier | El museo fue abierto ayer
I Último paso: la pasiva en pasado y en futuro, que es lo que más se oye en las noticias.
E Passé composé pasivo :: Se usa **avoir été** + participio: **Le musée a été ouvert hier** (el museo fue abierto ayer). :: El participio concuerda con el sujeto, como siempre con «être».
E Futuro pasivo :: Se usa **sera** + participio: **Le pont sera fini demain** (el puente estará terminado mañana).
B Tiempo | Forma | Ejemplo
| presente | est + participio | Les travaux sont terminés.
| pasado | a été + participio | Le musée a été ouvert hier.
| futuro | sera + participio | Le pont sera fini demain.
w été = sido (participio de «être») | e-te
W ouverte = abierta | u-vèrt
W annoncé = anunciado | a-no(n)-se
W réparé = reparado | re-pa-re
W réparée = reparada | re-pa-re
W rénové = renovado | re-no-ve
W terminé = terminado | tèr-mi-ne
W terminée = terminada | tèr-mi-ne
W terminés = terminados | tèr-mi-ne
W prévu = previsto | pre-vü
W élu = elegido | e-lü
W travaux = obras | tra-vo
V Vocabulario: noticias
D Las noticias del barrio
Thomas: Le musée a été ouvert hier. = El museo fue abierto ayer.
  > Le musée = el museo | a été ouvert = fue abierto / ha sido abierto | hier = ayer
Léa: Le pont sera fini demain ? = ¿El puente estará terminado mañana?
  > Le pont = el puente | sera fini = estará terminado / será finalizado | demain = mañana
Thomas: Oui, les travaux sont terminés. = Sí, las obras están terminadas.
  > Oui = sí | les travaux = las obras | sont terminés = están terminadas
Léa: La route a été réparée ? = ¿La carretera fue reparada?
  > La route = la carretera | a été réparée = fue reparada
Q ¿Cómo se dice «el museo fue abierto ayer»?
+ Le musée a été ouvert hier. :: «A été» + participio = pasado pasivo.
- Le musée est ouvert hier. :: Eso es presente.
- Le musée sera ouvert hier. :: Eso es futuro.
Q ¿Qué forma es correcta para «el puente estará terminado»?
+ Le pont sera fini demain. :: Futuro pasivo con «sera».
- Le pont a été fini demain. :: Eso es pasado.
- Le pont est fini demain. :: Eso es presente.
H Le musée ___ été ouvert hier. :: Auxiliar de passé composé
+ a :: «A été» es el auxiliar «avoir» + «été».
- est :: Eso es presente.
- sera :: Eso es futuro.
H La route a été ___. :: Femenino singular
+ réparée :: «Route» es femenino: «réparée».
- réparé :: Eso es masculino.
- lue :: Eso significa «leída», no encaja con una carretera.
R Le pont sera fini demain.
+ El puente estará terminado mañana. :: Futuro pasivo.
- El puente termina mañana. :: Eso es presente.
- El puente terminó ayer. :: Eso es pasado.
A Les travaux sont terminés.
+ Las obras están terminadas. :: Pasiva en presente, plural masculino.
- Las obras terminaron. :: Eso es pasado activo.
- Las obras terminarán. :: Eso es futuro activo.
O a été ouvert :: fue abierto :: Pasado de la pasiva.
Q ¿Cuál es la forma correcta para «la carretera fue reparada»?
+ La route a été réparée. :: «Passé composé» pasivo con concordancia de femenino en el participio («réparée»).
- La route a été réparé. :: Falta la «e» final de concordancia con el sujeto femenino «la route».
- La route est réparée hier. :: Con un marcador temporal pasado («hier»), debe emplearse «a été réparée», no presente.
