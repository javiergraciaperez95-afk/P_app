@ 22 | Je pourrais venir | Podría venir
I Hoy el conditionnel: sirve para lo que sería posible, para pedir con cortesía y para aconsejar.
E Formación :: Se forma con el futuro (la raíz) + las terminaciones del imperfecto: **-ais, -ais, -ait, -ions, -iez, -aient**. :: Ejemplo: **je pourrais** (podría), **nous voudrions** (querríamos), **ils seraient** (serían).
E Para qué se usa :: Para pedir con cortesía: **Je voudrais** (ya lo conoces). :: Para algo posible o un deseo: **Je ferais le voyage** (haría el viaje). :: Para aconsejar: **Tu devrais dormir** (deberías dormir).
B Conditionnel présent | Persona | pouvoir (poder) | être (ser, estar)
| je | je pourrais | je serais
| tu | tu pourrais | tu serais
| il / elle | il pourrait | il serait
| nous | nous pourrions | nous serions
| vous | vous pourriez | vous seriez
| ils / elles | ils pourraient | ils seraient
W serait = sería, estaría | se-RÉ
W aurait = tendría, habría | o-RÉ
W ferait = haría | fe-RÉ
W ferais = haría (yo, tú) | fe-RÉ
W irait = iría | i-RÉ
W pourrait = podría | pu-RÉ
W pourrais = podría (yo, tú) | pu-RÉ
W pourrions = podríamos | pu-RIÓN
W voudrait = querría | vu-DRÉ
W voudriez = querríais | vu-DRIÉ
W devrait = debería | de-VRÉ
W serais = sería, estaría (yo, tú) | se-RÉ
W aurais = tendría, habría (yo, tú) | o-RÉ
W aimerait = le gustaría | é-me-RÉ
V Vocabulario: el condicional
D Un plan para el sábado
Léa: Tu pourrais venir demain ? = ¿Podrías venir mañana?
  > tu pourrais venir = podrías venir | demain = mañana
Thomas: Je voudrais bien, mais je serais fatigué. = Me gustaría, pero estaría cansado.
  > je voudrais = me gustaría | je serais fatigué = estaría cansado
Léa: Tu devrais dormir ce soir. = Deberías dormir esta noche.
  > tu devrais dormir = deberías dormir
Thomas: Tu aurais raison. = Tendrías razón.
  > tu aurais raison = tendrías razón
Q ¿Cómo se dice «podría venir»?
+ Je pourrais venir. :: Condicional de «pouvoir»: pourrais.
- Je peux venir. :: Eso es presente: «puedo».
- Je pourrai venir. :: Eso es futuro: «podré».
Q ¿Cuál es el condicional de «être» con «il»?
+ Il serait. :: Condicional de «être»: serait.
- Il sera. :: Eso es futuro.
- Il était. :: Eso es imperfecto.
H Je ___ bien aller au cinéma. :: Me gustaría
+ voudrais :: «Voudrais» = querría, me gustaría.
- veux :: Eso es «quiero».
- vais :: Eso es «voy».
H Nous ___ venir si tu veux. :: Podríamos
+ pourrions :: Condicional de «pouvoir» con «nous».
- allons :: Eso es «vamos».
- sommes :: Eso es «somos» o «estamos».
R Je ferais le voyage.
+ Haría el viaje. :: Condicional de «faire».
- Hago el viaje. :: Eso es presente.
- Haré el viaje. :: Eso es futuro.
A Tu devrais dormir.
+ Deberías dormir. :: «Devrais» da un consejo.
- Debes dormir. :: Eso es obligación, no consejo.
- Dormirás. :: Eso es futuro.
O Je pourrais venir :: Podría venir :: Condicional de «pouvoir».
X Escribe en francés: «yo sería» :: je serais :: Condicional de «être» con «je».

@ 22 | Si j'avais le temps | Si tuviera tiempo
I Ahora la hipótesis: «si» + imparfait, y después el conditionnel.
E Si + imparfait, conditionnel :: Para algo que quizá pase o es poco probable: **Si j'avais le temps, je voyagerais** (si tuviera tiempo, viajaría). :: El orden puede cambiar: **Je voyagerais si j'avais le temps.**
E Ojo :: Después de **si** nunca va condicional. No se dice **si je voudrais**; se dice **si je voulais** (si quisiera) — "voulais" W.
B Condición (si + imparfait) | Consecuencia (conditionnel) | Ejemplo
| si j'avais de l'argent | je partirais | Si j'avais de l'argent, je partirais.
| si tu venais | je serais content | Si tu venais, je serais content.
W voyagerais = viajaría | vua-ya-ZHÉ
W irais = irías, iría (yo, tú) | i-RÉ
W viendrais = vendrías | via(n)-DRÉ
W gagnerais = ganaría | ga-ñe-RÉ
W riche = rico | rish
W temps = tiempo | ta(n)
W partirais = saldrías | par-ti-RÉ
W habiterais = vivirías | a-bi-te-RÉ
W lirais = leerías | li-RÉ
W saurais = sabrías | so-RÉ
W tour = vuelta, viaje | tur
W voulais = querías, quería | vu-LÉ
V Vocabulario: la hipótesis
D Si tuviera dinero
Léa: Si tu avais le temps, tu voyagerais ? = Si tuvieras tiempo, ¿viajarías?
  > si tu avais le temps = si tuvieras tiempo | tu voyagerais = viajarías
Thomas: Oui, je voyagerais en Espagne. = Sí, viajaría a España.
  > je voyagerais = viajaría | en Espagne = a España
Léa: Et si tu avais de l'argent ? = ¿Y si tuvieras dinero?
  > si tu avais de l'argent = si tuvieras dinero
Thomas: Je partirais demain. = Saldría mañana.
  > je partirais = saldría | demain = mañana
Q ¿Qué tiempo va después de «si» en «si j'avais le temps»?
+ Imparfait. :: Después de «si» va imparfait.
- Conditionnel. :: Después de «si» nunca va condicional.
- Futur. :: Después de «si» nunca va futuro.
Q ¿Cuál frase está bien construida?
+ Si j'avais le temps, je voyagerais. :: «Si» + imparfait, después conditionnel.
- Si j'ai le temps, je voyagerais. :: Después de «si» no va presente con condicional aquí.
- Si j'avais le temps, je voyage. :: La segunda parte debe ir en conditionnel.
H Si j'avais le temps, je ___ au cinéma. :: Condicional de «aller»
+ irais :: Condicional de «aller»: irais.
- vais :: Eso es presente.
- suis :: Eso es «soy» o «estoy».
H Si tu venais, je ___ content. :: Condicional de «être»
+ serais :: Condicional de «être» con «je».
- suis :: Eso es presente.
- étais :: Eso es imperfecto.
R Si j'avais le temps, je voyagerais.
+ Si tuviera tiempo, viajaría. :: «Si» + imparfait + conditionnel.
- Si tengo tiempo, viajo. :: Eso es presente.
- Si tuve tiempo, viajé. :: Eso es passé composé.
A Je partirais demain.
+ Saldría mañana. :: Condicional: algo posible o hipotético.
- Salgo mañana. :: Eso es presente.
- Salí ayer. :: Eso es pasado.
O Si j'avais le temps :: Si tuviera tiempo :: «Si» + imparfait.
X Escribe en francés: «si tuviera dinero, viajaría» :: si j'avais de l'argent, je voyagerais :: Después de «si» va imparfait.

@ 22 | J'aurais dû le dire | Debería haberlo dicho
I Último paso: lo que no pasó. Para lamentarlo o criticarlo usamos el conditionnel passé.
E Formación :: Se forma con el conditionnel de **avoir** o **être** + participio pasado: **j'aurais mangé** (habría comido), **je serais parti** (me habría ido). :: Con **être** el participio concuerda con el sujeto: **Elle serait venue** (ella habría venido).
E Para qué se usa :: Para lamentar algo que no pasó: **J'aurais aimé venir** (me habría gustado venir). :: Para criticar: **J'aurais dû le dire** (debería haberlo dicho).
E Con si :: **Si tu avais su, tu serais venu** (si hubieras sabido, habrías venido).
B Conditionnel passé | Uso | Ejemplo
| lamentar | aurais aimé | J'aurais aimé venir.
| criticar | aurais dû | J'aurais dû le dire.
| condición | avais su + serais venu | Si tu avais su, tu serais venu.
W aimé = querido, gustado | e-MÉ
W dû = debido (participio de «devoir») | dü
W su = sabido (participio de «savoir») | sü
W venu = venido | ve-NÜ
W j'aurais = habría (yo) | zho-RÉ
W erreur = error | e-RÖR
W regretter = lamentar | re-gre-TÉ
W conseil = consejo | ko(n)-SÈY
W occasion = ocasión | o-ka-ZIÓN
W réussite = éxito | re-ü-SIT
W échouer = fracasar | e-shua-É
W chance = suerte | sha(n)s
W coupable = culpable | ku-PABL
V Vocabulario: lamentar y criticar
D Un olvido
Léa: Tu as oublié mon anniversaire ! = ¡Has olvidado mi cumpleaños!
  > tu as oublié = has olvidado | mon anniversaire = mi cumpleaños
Thomas: Pardon, j'aurais dû te prévenir. = Perdona, debería haberte avisado.
  > j'aurais dû = debería haber | prévenir = avisar
Léa: Si tu avais su, tu serais venu. = Si lo hubieras sabido, habrías venido.
  > si tu avais su = si lo hubieras sabido | tu serais venu = habrías venido
Thomas: C'est une grande erreur. = Es un gran error.
  > une grande erreur = un gran error
Léa: Tu aurais aimé venir ? = ¿Te habría gustado venir?
  > tu aurais aimé = te habría gustado
Thomas: Oui, j'aurais aimé venir. = Sí, me habría gustado venir.
  > j'aurais aimé = me habría gustado
Q ¿Cuál es el conditionnel passé de «venir» con «il»?
+ Il serait venu. :: «Venir» usa «être» en conditionnel passé.
- Il aurait venu. :: «Venir» no va con «avoir».
- Il serait venue. :: Con «il» el participio es masculino.
Q ¿Qué significa «j'aurais dû le dire»?
+ Debería haberlo dicho. :: Crítica a algo que no pasó.
- Tengo que decirlo. :: Eso es obligación en presente.
- Lo diré. :: Eso es futuro.
H Tu ___ dû me prévenir. :: Condicional de «avoir»
+ aurais :: «Aurais» = habrías, tendrías.
- avais :: Eso es imperfecto.
- serais :: Eso es condicional de «être».
H Si j'avais su, je ___ venu. :: Condicional de «être» con «venir»
+ serais :: «Venir» usa «être»: serais venu.
- suis :: Eso es presente.
- avais :: Eso es imperfecto.
R J'aurais aimé venir.
+ Me habría gustado venir. :: Lamento que no pasó.
- Me gusta venir. :: Eso es presente.
- Quiero venir. :: Eso es presente.
A Tu aurais raison.
+ Tendrías razón. :: Condicional para algo hipotético.
- Tuviste razón. :: Eso es pasado.
- Tendrás razón. :: Eso es futuro.
O J'aurais dû partir :: Debería haber salido :: «Dû» es el participio de «devoir».
X Escribe en francés: «me habría gustado» :: j'aurais aimé :: Conditionnel passé de «aimer» con «avoir».
