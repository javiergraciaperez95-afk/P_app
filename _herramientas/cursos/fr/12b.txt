@ 12 | Un message sur le répondeur | Un mensaje en el contestador
I Escucha un mensaje de contestador: quién llama, qué cambia y qué hay que hacer. La app lee el texto en voz alta.
E El contestador :: En un mensaje de contestador, la persona dice quién llama y para qué. Palabras clave: **le répondeur** (el contestador), **un appel** (una llamada), **déplacé** (cambiado de hora).
E Escuchar sin perder datos :: Fíjate en el día, la hora y el lugar. **Demain** (mañana), **à quinze heures** (a las tres de la tarde), **au bureau** (en la oficina). Si no hay cobertura, el mensaje se oye dos veces.
B Dato | Palabra | Ejemplo
| contestador | le répondeur | Je laisse un message sur le répondeur.
| cambiado de hora | déplacé | Le cours est déplacé.
| llamada | un appel | Je fais un appel.
W répondeur = contestador | re-po(n)-DÖR
W déplacé = cambiado de hora | de-pla-SÉ
W appel = llamada | a-PÉL
W sonner = sonar | so-NÉ
W sonnerie = timbre, señal de llamada | so-ne-RÍ
W déranger = molestar | de-ra(n)-ZHÉ
W absent = ausente | ab-SA(N)
W bip = pitido | BIP
W tonalité = tono (del teléfono) | to-na-li-TÉ
W composer = marcar (un número) | ko(n)-po-ZÉ
W raccrocher = colgar | ra-kro-SHÉ
W joindre = contactar | ZHUIN-dr
V Vocabulario: el contestador
D Mensajes en el contestador
Message : Bonjour Paul, c'est Léa. = Mensaje: Hola Paul, soy Léa.
  > c'est Léa = soy Léa
Message : Le cours de demain est déplacé à quinze heures. = Mensaje: la clase de mañana se cambia a las tres.
  > est déplacé = está cambiado | à quinze heures = a las tres
Message : Tu peux venir au bureau ? = Mensaje: ¿puedes venir a la oficina?
  > tu peux venir = puedes venir | au bureau = a la oficina
Thomas: Le cours est déplacé ? C'est quand ? = ¿La clase se cambia? ¿Cuándo es?
  > c'est quand = ¿cuándo es?
Q ¿A qué hora es la clase cambiada?
+ À quinze heures. :: A las tres de la tarde.
- À neuf heures. :: Esa es la hora de otro aviso.
- À dix heures. :: El mensaje no dice eso.
Q ¿Qué le pide Léa a Paul?
+ Venir au bureau. :: Que vaya a la oficina.
- Parler au téléphone. :: El mensaje no pide eso.
- Acheter du pain. :: No aparece en el mensaje.
R Le cours est déplacé à quinze heures.
+ La clase se cambia a las tres. :: «Déplacé» = cambiado de hora.
- La clase es a las diez. :: No es lo que dice el mensaje.
- La clase está cancelada. :: Se dice «annulé», no «déplacé».
H Le cours est ___ à quinze heures.
+ déplacé :: Cambiado de hora.
- annulé :: Eso significa que no hay clase.
- suivant :: Eso es «siguiente».
H Tu peux ___ au bureau ?
+ venir :: Puedes venir a la oficina.
- manger :: No encaja con «au bureau».
- répondeur :: Es el aparato, no un verbo.
A Tu peux venir demain ?
+ ¿Puedes venir mañana? :: «Demain» = mañana.
- ¿Puedes venir hoy? :: Eso sería «aujourd'hui».
- ¿Quieres venir mañana? :: Eso sería «tu veux».
O le répondeur :: el contestador :: Donde se deja un mensaje.
X Escribe en francés: «puedes venir mañana» :: tu peux venir demain :: «Pouvoir» + infinitivo.

@ 12 | Louer un appartement | Alquilar un piso
I Vocabulario para alquilar un piso: el alquiler, la fianza y el propietario. Te servirá para leer anuncios y hablar con la agencia.
E Alquilar :: **Louer** (alquilar) un piso. **Le loyer** (el alquiler) es lo que pagas al propietario. **La caution** (la fianza) es un dinero que se da al entrar.
E Quién es quién :: El **propriétaire** (propietario) alquila a un **locataire** (inquilino). Un piso **meublé** tiene muebles. Un **studio** es un piso de una sola habitación.
B Palabra | Significa | Ejemplo
| alquilar | louer | Je veux louer un studio.
| alquiler | le loyer | Le loyer est de cent euros.
| fianza | la caution | La caution est chère.
W louer = alquilar | lu-É
W loyer = alquiler | lua-YÉ
W caution = fianza | ko-SIÓN
W propriétaire = propietario | pro-pri-e-TÉR
W locataire = inquilino | lo-ka-TÉR
W meublé = amueblado | meu-BLÉ
W agence = agencia | a-ZHA(N)S
W balcon = balcón | bal-KÓ(N)
W ascenseur = ascensor | a-sa(n)-SÖR
W studio = estudio (piso pequeño) | stü-DIO
W immeuble = edificio | i-MEU-bl
W couloir = pasillo | ku-LUÁR
W déménager = mudarse | de-me-na-ZHÉ
W logement = piso, vivienda | lo-zhe-MA(N)
W signer = firmar | si-ÑÉ
V Vocabulario: alquilar
D Visitando un piso
Léa: Bonjour, je veux louer un studio. = Buenos días, quiero alquilar un estudio.
  > je veux louer = quiero alquilar | un studio = un estudio
Agent: Le loyer est de cent euros. = El alquiler es de cien euros.
  > le loyer = el alquiler | cent euros = cien euros
Léa: Il y a un balcon ? = ¿Hay balcón?
  > il y a = hay
Agent: Oui, il y a un ascenseur dans le couloir. = Sí, hay un ascensor en el pasillo.
  > dans le couloir = en el pasillo
Léa: Le logement est meublé ? = ¿El piso está amueblado?
  > le logement = el piso
Agent: Non, il n'est pas meublé. Vous pouvez déménager demain. = No, no está amueblado. Puede mudarse mañana.
  > il n'est pas meublé = no está amueblado
Léa: Je peux signer demain, avec la caution ? = ¿Puedo firmar mañana, con la fianza?
  > je peux signer = puedo firmar
Q ¿Cuánto es el alquiler del estudio?
+ Cent euros. :: Cien euros al mes.
- Six euros. :: Ese precio no aparece.
- Mille euros. :: El diálogo dice cien.
Q ¿Qué es un «studio»?
+ Un piso de una sola habitación. :: Piso pequeño y sencillo.
- Un edificio grande. :: Eso es «immeuble».
- Una oficina. :: Eso es «bureau».
R Je veux louer un studio.
+ Quiero alquilar un estudio. :: «Louer» = alquilar.
- Quiero comprar un estudio. :: «Acheter» es comprar.
- Quiero vender un estudio. :: Eso es otro verbo.
H Le ___ est de cent euros.
+ loyer :: El alquiler: lo que se paga cada mes.
- studio :: Es el piso, no el precio.
- couloir :: Es el pasillo.
H Je suis le ___ de ce studio.
+ locataire :: El inquilino es quien alquila.
- propriétaire :: El propietario es quien alquila, no quien paga.
- agence :: Es la agencia, no el inquilino.
A Il y a un balcon ?
+ ¿Hay balcón? :: «Il y a» = hay.
- ¿Hay un ascensor? :: Eso es «ascenseur».
- ¿Es un balcón? :: Eso sería «c'est».
O la caution :: la fianza :: Dinero que se da al entrar.
X Escribe en francés: «quiero alquilar un piso» :: je veux louer un appartement :: «Louer» + sustantivo.
