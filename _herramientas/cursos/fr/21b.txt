@ 21 | Un reportage à la radio | Un reportaje en la radio
I Escucha un reportaje de radio sobre un hecho real. Anota qué pasó primero, qué pasó después y quién lo vio.
E El reportaje :: Un **reportage** (reportaje) cuenta un hecho con un **témoin** (testigo) y un **événement** (suceso). Para contar lo que pasó antes se usa el plus-que-parfait: **Le train était déjà parti** (el tren ya se había ido).
E Una noticia real :: Una **découverte** (descubrimiento) puede cambiar la historia de un lugar. El **reporter** cuenta lo que había pasado antes de su llegada.
B Hecho | Palabra | Ejemplo
| reportaje | le reportage | Le reportage dure dix minutes.
| testigo | le témoin | Le témoin a tout vu.
| descubrimiento | la découverte | La découverte est grande.
W reportage = reportaje | re-por-TÁZH
W témoin = testigo | te-MUÍN
W événement = suceso | e-ven-MA(N)
W découverte = descubrimiento | de-ku-VÉRT
W reporter = periodista de campo | re-por-TÉR
W fouille = búsqueda | FUI
W trouvé = encontrado | tru-VÉ
W police = policía | po-LÍS
W mystère = misterio | mis-TÉR
W villageois = aldeano | vi-la-ZHUÁ
W récit = relato | re-SÍ
W pompier = bombero | po(n)-PIÉ
V Vocabulario: reportaje
D En el reportaje
Journaliste: Un événement est arrivé hier. = Periodista: ayer ocurrió un suceso.
  > est arrivé = ocurrió | hier = ayer
Journaliste: Le témoin avait vu une lumière. = Periodista: el testigo había visto una luz.
  > avait vu = había visto | une lumière = una luz
Témoin: Quand je suis arrivé, c'était ouvert. = Cuando llegué, estaba abierto.
  > c'était = estaba | ouvert = abierto
Journaliste: La police avait déjà fini la fouille. = La policía ya había terminado la búsqueda.
  > avait déjà fini = ya había terminado | la fouille = la búsqueda
Témoin: Ils avaient trouvé une clé. = Habían encontrado una llave.
  > avaient trouvé = habían encontrado | une clé = una llave
Q ¿Qué había pasado cuando llegó el testigo?
+ C'était ouvert. :: Estaba abierto.
- La police arrivait. :: No lo dice el reportaje.
- Le témoin partait. :: No lo dice el reportaje.
Q ¿Qué habían encontrado?
+ Une clé. :: Una llave.
- Une lumière. :: Era lo que había visto el testigo.
- Un pompier. :: No lo dice el reportaje.
R Le témoin avait vu une lumière.
+ El testigo había visto una luz. :: Plus-que-parfait: «avait vu» = había visto.
- El testigo ve una luz. :: Es presente.
- El testigo verá una luz. :: Es futuro.
H La police avait déjà ___ la fouille.
+ fini :: Había terminado: pasado anterior.
- finir :: Es el infinitivo.
- trouvé :: Es encontrado, no terminado.
H Le ___ a vu la scène.
+ témoin :: El testigo: quien vio el hecho.
- police :: La policía, no quien vio.
- mystère :: Es el misterio.
A Ils avaient trouvé une clé.
+ Habían encontrado una llave. :: «Avaient trouvé» = habían encontrado.
- Encontraron una llave. :: Es pasado simple, no plus-que-parfait.
- Encuentran una llave. :: Es presente.
O un récit :: un relato :: Historia que se cuenta.
X Escribe en francés: «había visto una luz» :: avait vu une lumière :: Plus-que-parfait con «avoir».

@ 21 | Les nouvelles et la presse | Las noticias y la prensa
I Hoy hablamos de la prensa: el titular, el artículo y la actualidad. Escucha a una persona que habla de las noticias del día.
E La prensa :: Las **actualité** (noticia de actualidad) aparece en una **chaîne** (canal de televisión) o en un periódico. Un **titre** (titular) abre el artículo.
E Lectores :: Un **lecteur** (lector) lee el **magazine** (revista) y la **page** (página). Una **édition** (edición) puede ser diaria (**quotidien**) o semanal (**hebdomadaire**).
B Medio | Palabra | Ejemplo
| noticia | une actualité | Une actualité est importante. →
| titular | le titre | Le titre est très bien.
| revista | le magazine | Le magazine est lu le mardi.
W actualité = noticia de actualidad | ak-tü-a-li-TÉ
W chaîne = canal de televisión | SHEN
W titre = titular | TÍTR
W magazine = revista | ma-ga-ZÍN
W page = página | PAZH
W lecteur = lector | lek-TÖR
W édition = edición | e-di-SIÓN
W rédacteur = redactor | re-dak-TÖR
W abonné = suscrito | a-bo-NÉ
W kiosque = quiosco | kiu-SK
W quotidien = diario | ko-ti-DIÉ(N)
W hebdomadaire = semanal | eb-do-ma-DÉR
W éditorial = editorial | e-di-to-RIÁL
V Vocabulario: prensa
D Las noticias del día
Léa: Tu as vu une actualité ce matin ? = ¿Has visto una noticia de esta mañana?
  > tu as vu = has visto | une actualité = una noticia
Thomas: Oui, le titre est très bien. = Sí, el titular está muy bien.
  > le titre = el titular | très bien = muy bien
Léa: Un article parle de la grande édition. = Un artículo habla de la gran edición.
  > parle de = habla de | la grande édition = la gran edición
Thomas: Le rédacteur a une bonne information. = El redactor tiene una buena información.
  > une bonne information = una buena información
Léa: Tu es abonné au magazine ? = ¿Estás suscrito a la revista?
  > abonné = suscrito | au magazine = a la revista
Thomas: Non, je prends le magazine au kiosque. = No, cojo la revista en el quiosco.
  > prends = cojo | au kiosque = en el quiosco
Q ¿Qué lee Léa?
+ Une actualité. :: Una noticia.
- Un roman. :: No aparece en el diálogo.
- Un film. :: No aparece en el diálogo.
Q ¿Dónde compra Thomas la revista?
+ Au kiosque. :: En el quiosco.
- À la poste. :: No aparece en el diálogo.
- Sur internet. :: No aparece en el diálogo.
R Le titre est très bien.
+ El titular está muy bien. :: «Très bien» = muy bien.
- El titular es muy caro. :: No lo dice el diálogo.
- El titular no es bueno. :: Es lo contrario.
H La ___ est à vingt heures.
+ chaîne :: Canal de televisión: donde se ven las noticias.
- page :: Es la página de un libro.
- titre :: Es el titular de un artículo.
H Tu es ___ au magazine ?
+ abonné :: Suscrito: pagas la revista cada año.
- lecteur :: Quien lee, no quien paga.
- rédacteur :: Quien escribe.
A Le magazine est là le mardi.
+ La revista está ahí los martes. :: «Est là» = está ahí.
- La revista cuesta el martes. :: No es lo que dice la frase.
- La revista sale el martes. :: No es la palabra correcta.
O un éditorial :: un editorial :: Artículo de opinión del periódico.
X Escribe en francés: «el lector» :: le lecteur :: Quien lee el periódico o la revista.
