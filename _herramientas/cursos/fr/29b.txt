@ 29 | Une annonce de service public | Un aviso de servicio público
I Escucha un aviso de la mairie: documentos, plazos y el lugar donde se entrega todo. Anota qué hay que llevar.
E Trámites :: En un **service** (servicio) público se hace una **démarche** (trámite). Hay que llevar una **attestation** (certificado) y un **justificatif** (justificante), y rellenar un **formulaire** (formulario).
E Plazos y entrega :: El **délai** (plazo) indica hasta cuándo se entrega el trámite. Se hace un **dépôt** (entrega) en el **guichet** (ventanilla) y el **agent** (funcionario) pone el **tampon** (sello).
B Trámite | Palabra | Ejemplo
| trámite | une démarche | C'est une démarche simple.
| justificante | un justificatif | J'ai un justificatif.
| formulario | le formulaire | Il faut le formulaire.
W démarche = trámite | de-MARSH
W service = servicio | ser-VÍS
W attestation = certificado | a-tes-ta-SIÓN
W justificatif = justificante | zhü-sti-fi-KA-tif
W formulaire = formulario | for-mü-LÉR
W délai = plazo | de-LÉ
W inscription = inscripción | a(n)-skrip-SIÓN
W dépôt = entrega | de-PÓ
W agent = funcionario | a-ZHA(N)
W tampon = sello | ta(n)-PÓ(N)
W formalité = trámite | for-ma-li-TÉ
W procédure = procedimiento | pro-se-DÜR
W remplir = rellenar | ra(n)-PLÍR
V Vocabulario: trámites
D En la mairie
Agent: Bonjour, vous avez un dossier ? = Buenos días, ¿tiene un expediente?
  > vous avez = tiene | un dossier = un expediente
Usager: Oui, j'ai le formulaire. = Sí, tengo el formulario.
  > le formulaire = el formulario
Agent: Il faut une attestation et une pièce. = Hace falta un certificado y un documento.
  > une pièce = un documento
Usager: J'ai un justificatif. = Tengo un justificante.
  > un justificatif = un justificante
Agent: Le délai est court. = El plazo es corto.
  > le délai = el plazo | court = corto
Usager: Je peux revenir demain. = Puedo volver mañana.
  > revenir = volver | demain = mañana
Agent: Vous pouvez signer ici. = Puede firmar aquí.
  > signer = firmar
Q ¿Qué lleva el usuario?
+ Un formulaire. :: Un formulario.
- Un tampon. :: No lo lleva; lo pone el funcionario.
- Une attestation. :: Hace falta, pero no la lleva.
Q ¿Cuándo puede volver el usuario?
+ Demain. :: Mañana.
- Hier. :: Es pasado.
- Aujourd'hui. :: No lo dice el diálogo.
R Le délai est court.
+ El plazo es corto. :: «Délai» = plazo.
- El plazo es largo. :: Es lo contrario.
- El servicio es corto. :: No es la frase.
H Il faut un ___ de la mairie.
+ formulaire :: Papel que se rellena.
- agent :: Es la persona del servicio.
- tampon :: Es el sello.
H Vous pouvez ___ ici.
+ signer :: Firmar: poner tu nombre.
- remplir :: Es rellenar, no firmar.
- démarche :: Es el trámite.
A Vous pouvez signer ici.
+ Puede firmar aquí. :: «Pouvez» = puede.
- Puede volver aquí. :: Es «revenir».
- Puede rellenar aquí. :: Es «remplir».
O un tampon :: un sello :: Marca oficial en un documento.
X Escribe en francés: «hace falta un certificado» :: il faut une attestation :: «Il faut» + sustantivo.

@ 29 | École et orientation | Escuela y orientación
I Escucha a dos amigos que hablan de sus estudios, de una beca y de unas prácticas. Anota qué estudian y qué hacen el verano.
E Estudios :: Después del **bac** (bachillerato) se elige una **filière** (vía de estudios) y una **licence** (grado de licenciatura), y después un **master**. Una **option** (asignatura optativa) y una **spécialité** (especialidad) cambian el plan.
E Ayuda :: Un **conseiller** (orientador) ayuda a elegir. Una **bourse** (beca) ayuda con el dinero. Para entrar en un curso hay una **inscription** (inscripción) y a veces un **candidat** (candidato).
B Estudios | Palabra | Ejemplo
| beca | une bourse | J'ai une bourse.
| prácticas | un stage | Je fais un stage cet été.
| orientación | l'orientation | (véase el aviso)
W orientation = orientación | o-rien-ta-SIÓN
W filière = vía (de estudios) | fi-LIÉR
W candidat = candidato | ka-di-DÁ
W lycéen = estudiante de liceo | li-se-A(N)
W scolarité = escolaridad | sko-la-ri-TÉ
W bourse = beca | BURS
W licence = licenciatura | li-SA(N)S
W master = máster | mas-TÉR
W bac = bachillerato | BAK
W option = optativa | op-SIÓN
W spécialité = especialidad | spe-sia-li-TÉ
W conseiller = orientador | ko(n)-se-IÉ
V Vocabulario: estudios
D Dos amigos y sus estudios
Léa: Tu fais quelle filière ? = ¿Qué vía de estudios haces?
  > quelle filière = qué vía
Thomas: Je fais une licence, puis un master. = Hago una licenciatura, y luego un máster.
  > une licence = una licenciatura | un master = un máster
Léa: Tu as le bac ? = ¿Tienes el bachillerato?
  > le bac = el bachillerato
Thomas: Oui, et j'ai une bourse. = Sí, y tengo una beca.
  > une bourse = una beca
Léa: Le conseiller est là. = El orientador está ahí.
  > le conseiller = el orientador
Thomas: Je fais un stage en été. = Hago prácticas en verano.
  > un stage = unas prácticas | en été = en verano
Q ¿Qué tiene Thomas para pagar los estudios?
+ Une bourse. :: Una beca.
- Une licence. :: Es el grado, no el dinero.
- Un master. :: Es un grado, no el dinero.
Q ¿Qué hace Thomas este verano?
+ Un stage. :: Unas prácticas.
- Un master. :: Es un grado académico.
- Une inscription. :: No aparece en el diálogo.
R Je fais une licence, puis un master.
+ Hago una licenciatura y luego un máster. :: «Puis» = luego.
- Hago un máster y luego una licenciatura. :: Es el orden contrario.
- Hago una beca y luego un bac. :: No es lo que dice la frase.
H Tu as le ___ ?
+ bac :: El bachillerato.
- stage :: Son las prácticas.
- bourse :: Es la beca.
H Je fais un ___ en été.
+ stage :: Prácticas en una empresa.
- candidat :: Es un candidato.
- conseiller :: Es el orientador.
A Le conseiller est là.
+ El orientador está ahí. :: «Est là» = está ahí.
- El orientador está lejos. :: No lo dice la frase.
- El candidato está ahí. :: Es «candidat».
O une option :: una optativa :: Asignatura que se elige además de la principal.
X Escribe en francés: «hago prácticas en verano» :: je fais un stage en été :: «Faire un stage» = hacer prácticas.
