@ 15 | Une publicité à la radio | Un anuncio en la radio
I Escucha un anuncio de radio de una tienda. Anota qué se rebaja, cuánto y hasta cuándo.
E Anuncios de promoción :: En un anuncio aparecen: **une promotion** (una promoción), **une remise** (un descuento), **une offre** (una oferta) y **gratuit** (gratis). Las **soldes** son las rebajas de temporada.
E Comparar precios :: Con los comparativos del capítulo: **moins cher que** (más barato que), **plus de** (más de), **moins de** (menos de). Por ejemplo: **Ce pull est moins cher que la semaine dernière**.
B Oferta | Palabra | Ejemplo
| descuento | une remise | Il y a une remise de vingt pour cent.
| oferta | une offre | C'est une bonne offre.
| gratis | gratuit | La livraison est gratuite.
W publicité = publicidad | pü-bli-si-TÉ
W promotion = promoción | pro-mo-sió(n)
W remise = descuento | re-MIS
W offre = oferta | O-fr
W réduction = reducción | re-dük-SIÓN
W pour cent = por ciento | pur sa(n)
W livraison = entrega | li-vre-ZÓN
W gratuite = gratis | gra-TÜÍT
W limité = limitado | li-mi-TÉ
W valable = válido | va-LÁBL
W stock = existencias | STOK
W article = artículo | ar-ti-KL
W prix bas = precio bajo | PRI BA — hmm use: "bas" maybe defined? risky; skip.
V Vocabulario: rebajas
D Un anuncio de la tienda
Annonce : Les soldes, c'est demain. Une remise de vingt pour cent sur le magasin. = Anuncio: las rebajas son mañana. Un descuento del veinte por ciento en toda la tienda.
  > une remise = un descuento | pour cent = por ciento
Annonce : La livraison est gratuite ce week-end. = Anuncio: la entrega es gratis este fin de semana.
  > gratuite = gratis | ce week-end = este fin de semana
Léa: C'est une bonne offre ? = ¿Es una buena oferta?
  > une bonne offre = una buena oferta
Thomas: Oui, le stock est limité. = Sí, las existencias son limitadas.
  > le stock = las existencias
Léa: Ce pull est moins cher que la semaine dernière. = Este jersey es más barato que la semana pasada.
  > moins cher que = más barato que
Thomas: Alors c'est une bonne promotion. = Entonces es una buena promoción.
  > une bonne promotion = una buena promoción
Q ¿Qué descuento anuncia la radio?
+ Vingt pour cent. :: El veinte por ciento.
- Dix pour cent. :: No es el dato del anuncio.
- Cinquante pour cent. :: No aparece en el anuncio.
Q ¿Cuándo es gratis la entrega?
+ Ce week-end. :: Este fin de semana.
- Demain. :: El anuncio no dice eso.
- Toujours. :: El anuncio no dice eso.
R Une remise de vingt pour cent sur le magasin.
+ Un descuento del veinte por ciento en toda la tienda. :: «Sur» = en.
- Un descuento del diez por ciento. :: Es un dato falso.
- Un precio fijo en todos los artículos. :: No es lo que dice el anuncio.
H Il y a une ___ de vingt pour cent.
+ remise :: Descuento: rebaja del precio.
- offre :: Es una oferta, no un descuento.
- livraison :: Es la entrega a casa.
H La livraison est ___ ce week-end.
+ gratuite :: Gratis: no cuesta nada.
- valable :: Es válido, no gratis.
- limité :: No es el dato del anuncio.
A Le stock est limité.
+ Las existencias son limitadas. :: «Stock» = existencias.
- El stock es ilimitado. :: Es lo contrario.
- El precio está limitado. :: No es la palabra.
O une promotion :: una promoción :: Oferta especial de una tienda.
X Escribe en francés: «el descuento es válido este fin de semana» :: la remise est valable ce week-end :: «Valable» = válido.

@ 15 | Au marché | En el mercado
I Escucha a un vendedor del mercado. Anota los precios, la cantidad y lo que compra el cliente.
E Mercado :: En el mercado se compra por kilo o por unidad: **un kilo de tomates** (un kilo de tomates), **une barquette de fraises** (una caja de fresas). El vendedor dice **le prix** (el precio) y **c'est combien ?** (¿cuánto es?).
E Contar y pagar :: Para pagar se usa **la monnaie** (el cambio) y se pregunta **Vous avez la monnaie ?** (¿tiene cambio?). Con precios por kilo se dice **le kilo** (el kilo).
B Compra | Palabra | Ejemplo
| caja | une barquette | Une barquette de fraises.
| kilo | le kilo | Le kilo coûte deux euros.
| cambio | la monnaie | Vous avez la monnaie ?
W étal = puesto | e-TAL
W barquette = caja, bandeja | bar-KÉT
W fraises = fresas | FREZ
W carottes = zanahorias | ka-RÓT
W courgette = calabacín | kur-ZHÉT
W salade = ensalada | sa-LAD
W poireau = puerro | pua-RÓ
W panier = cesta | pa-NIÉ
W poids = peso | PUA
W peser = pesar | pe-ZÉ
W frais = fresco | FRE
W épicerie = tienda de comestibles | e-pi-se-RÍ
W marchand = comerciante | mar-SHÁ(N)
V Vocabulario: el mercado
D En el mercado
Vendeuse: Bonjour, vous désirez ? = Buenos días, ¿qué desea?
  > vous désirez = qué desea
Client: Une barquette de fraises, s'il vous plaît. = Una caja de fresas, por favor.
  > une barquette = una caja
Vendeuse: Elles sont très bien. Et des carottes ? = Están muy bien. ¿Y zanahorias?
  > très bien = muy bien | des carottes = zanahorias
Client: Oui, un kilo de carottes et une salade. = Sí, un kilo de zanahorias y una lechuga.
  > un kilo de = un kilo de
Vendeuse: Le kilo de carottes coûte deux euros. = El kilo de zanahorias cuesta dos euros.
  > le kilo = el kilo
Client: Voilà. Vous avez la monnaie ? = Aquí tiene. ¿Tiene cambio?
  > la monnaie = el cambio
Vendeuse: Oui, voilà votre monnaie. = Sí, aquí tiene su cambio.
  > votre monnaie = su cambio
Q ¿Cuánto cuesta el kilo de zanahorias?
+ Deux euros. :: Dos euros.
- Trois euros. :: No es el precio del diálogo.
- Un euro. :: No es el precio del diálogo.
Q ¿Qué compra el cliente?
+ Des fraises, des carottes et une salade. :: Fresas, zanahorias y lechuga.
- Des poireaux. :: No los compra.
- Un panier. :: No lo compra.
R Un kilo de carottes, s'il vous plaît.
+ Un kilo de zanahorias, por favor. :: «Un kilo de» + sustantivo.
- Una caja de zanahorias, por favor. :: Eso sería «une barquette».
- Un kilo de tomates, por favor. :: Las tomates no aparecen.
H Une ___ de fraises, s'il vous plaît.
+ barquette :: Caja o bandeja de fruta.
- kilo :: Se dice con «un kilo de».
- panier :: Es una cesta.
H Vous avez la ___ ?
+ monnaie :: El cambio al pagar.
- salade :: Es una lechuga.
- poids :: Es el peso.
A Le kilo de carottes coûte deux euros.
+ El kilo de zanahorias cuesta dos euros. :: «Coûter» = costar.
- El kilo de zanahorias pesa dos euros. :: «Peser» es pesar.
- El kilo de zanahorias cuesta dos. :: Falta «euros».
O un étal :: un puesto :: Donde se vende en el mercado.
X Escribe en francés: «un kilo de zanahorias» :: un kilo de carottes :: «Un kilo de» + sustantivo.
