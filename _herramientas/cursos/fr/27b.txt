@ 27 | Un métier, une radio | Un oficio, una radio
I Escucha una entrevista de radio a un artesano que habla de su oficio. Anota qué hace, desde cuándo y qué le cuesta.
E Oficios :: Un **boulanger** (panadero), un **cuisinier** (cocinero), un **menuisier** (carpintero), un **maçon** (albañil), un **électricien** (electricista) y un **plombier** (fontanero) son oficios manuales. Un **artisan** (artesano) trabaja por su cuenta.
E Aprender :: Un **apprenti** (aprendiz) aprende el oficio en el trabajo. Antes se hace una **formation** (formación) y un **stage** (prácticas). El **gérant** (gerente) dirige el negocio.
B Oficio | Palabra | Ejemplo
| panadero | le boulanger | Le boulanger travaille tôt.
| aprendiz | un apprenti | Il a un apprenti.
| artesano | un artisan | Un artisan travaille seul.
W cuisinier = cocinero | kui-zi-NIÉ
W agriculteur = agricultor | a-gri-kül-TÖR
W menuisier = carpintero | me-nui-ZIÉ
W boulanger = panadero | bu-la(n)-ZHÉ
W maçon = albañil | ma-SÓN
W électricien = electricista | e-lek-tri-SIÉ(N)
W plombier = fontanero | plo(n)-BIÉ
W artisan = artesano | ar-ti-ZA(N)
W apprenti = aprendiz | a-pra(n)-TI
W formation = formación | for-ma-SIÓN
W stage = prácticas | STAZH
W gérant = gerente | zhe-RA(N)
V Vocabulario: oficios
D Entrevista a un artesano
Animatrice: Vous êtes boulanger depuis quand ? = ¿Desde cuándo es usted panadero?
  > vous êtes = es usted | depuis quand = desde cuándo
Boulanger: Je travaille tôt, en chantant. = Trabajo temprano, cantando.
  > en chantant = cantando | tôt = temprano
Animatrice: Vous avez un apprenti ? = ¿Tiene un aprendiz?
  > vous avez = tiene
Boulanger: Oui, il travaille avec moi, en chantant. = Sí, trabaja conmigo, cantando.
  > avec moi = conmigo | en chantant = cantando
Animatrice: Et le salaire ? = ¿Y el sueldo?
  > le salaire = el sueldo
Boulanger: Le salaire est petit au début. = El sueldo es pequeño al principio.
  > au début = al principio
Animatrice: Merci pour votre témoignage. = Gracias por su testimonio.
  > votre témoignage = su testimonio
Q ¿Cuándo trabaja el panadero?
+ Tôt. :: Temprano.
- Tard. :: No lo dice la entrevista.
- Le dimanche. :: No aparece en la entrevista.
Q ¿Cómo aprende el aprendiz?
+ En travaillant. :: Trabajando.
- En lisant. :: No aparece en la entrevista.
- En voyageant. :: No aparece en la entrevista.
R Je travaille tôt, en chantant.
+ Trabajo temprano, cantando. :: «En chantant» = cantando.
- Trabajo tarde, en silencio. :: Es lo contrario.
- Trabajo tarde, cantando. :: No es lo que dice la frase.
H Il a un ___ .
+ apprenti :: Aprendiz del oficio.
- artisan :: Es el artesano.
- boulanger :: Es el panadero.
H Le ___ est petit au début.
+ salaire :: El sueldo.
- stage :: Son las prácticas.
- gérant :: Es el gerente.
A Il travaille avec moi.
+ Trabaja conmigo. :: «Avec moi» = conmigo.
- Trabaja contra mí. :: Eso sería «contre moi».
- Trabaja sin mí. :: Eso sería «sans moi».
O un plombier :: un fontanero :: Oficio que arregla tuberías.
X Escribe en francés: «trabajo cantando» :: je travaille en chantant :: «En» + gerundio.

@ 27 | Le sport et la compétition | El deporte y la competición
I Escucha a dos amigos que hablan de un entrenamiento, una competición y una victoria. Anota qué día es y qué quieren ganar.
E Deporte :: Un **entraînement** (entrenamiento) prepara la **compétition** (competición). Un **joueur** (jugador) y un **entraîneur** (entrenador) trabajan en el **terrain** (campo) y en el **tournoi** (torneo).
E Resultados :: Una **victoire** (victoria) es ganar y una **défaite** (derrota) es perder. Una **médaille** (medalla) premia a quien gana. Un **record** (récord) es el mejor resultado. El **vestiaire** (vestuario) es donde se cambian los deportistas.
B Deporte | Palabra | Ejemplo
| victoria | une victoire | C'est une victoire.
| derrota | une défaite | C'est une défaite.
| medalla | une médaille | Il a une médaille.
W entraînement = entrenamiento | a(n)-tre-na-MA(N)
W compétition = competición | ko(n)-pe-ti-SIÓN
W victoire = victoria | vik-TUÁR
W défaite = derrota | de-FÉT
W médaille = medalla | me-DÁIY
W marathon = maratón | ma-ra-TÓN
W vestiaire = vestuario | ves-TIÉR
W joueur = jugador | zhu-ÖR
W entraîneur = entrenador | a(n)-tre-NÖR
W terrain = campo (de juego) | te-RA(N)
W tournoi = torneo | tur-NUÁ
W record = récord | re-KÓR
W sportif = deportista | spor-TÍF
V Vocabulario: deporte
D Dos amigos y el deporte
Léa: Tu as un entraînement demain ? = ¿Tienes un entrenamiento mañana?
  > un entraînement = un entrenamiento | demain = mañana
Thomas: Oui, pour la compétition de samedi. = Sí, para la competición del sábado.
  > pour la compétition = para la competición | samedi = sábado
Léa: Tu veux gagner une médaille ? = ¿Quieres ganar una medalla?
  > gagner = ganar | une médaille = una medalla
Thomas: Je veux un record, mais j'ai une défaite. = Quiero un récord, pero tengo una derrota.
  > un record = un récord | une défaite = una derrota
Léa: Le vestiaire est derrière le terrain. = El vestuario está detrás del campo.
  > derrière = detrás | le terrain = el campo
Thomas: Le sportif est très fatigué. = El deportista está muy cansado.
  > le sportif = el deportista | très fatigué = muy cansado
Q ¿Qué día es la competición?
+ Samedi. :: El sábado.
- Demain. :: Es el entrenamiento.
- Dimanche. :: No aparece en el diálogo.
Q ¿Qué quiere ganar Léa?
+ Une médaille. :: Una medalla.
- Un marathon. :: No aparece en el diálogo.
- Un tournoi. :: No aparece en el diálogo.
R Je veux un record, mais j'ai une défaite.
+ Quiero un récord, pero tengo una derrota. :: «Mais» = pero.
- Quiero un récord, y tengo una victoria. :: Es lo contrario.
- Quiero un vestuario, pero tengo una victoria. :: No es la frase.
H Le ___ de Thomas est fatigué.
+ joueur :: Persona que juega en el equipo.
- entraînement :: Es el entrenamiento.
- vestiaire :: Es el vestuario.
H C'est une ___ pour toi.
+ victoire :: Ganar: el equipo se impone.
- défaite :: Es perder.
- médaille :: Es la medalla.
A Le vestiaire est derrière le terrain.
+ El vestuario está detrás del campo. :: «Derrière» = detrás.
- El vestuario está delante del campo. :: Es lo contrario.
- El vestuario está en el campo. :: No lo dice la frase.
O un tournoi :: un torneo :: Serie de partidos para ganar.
X Escribe en francés: «hay un entrenamiento mañana» :: il y a un entraînement demain :: «Il y a» = hay.
