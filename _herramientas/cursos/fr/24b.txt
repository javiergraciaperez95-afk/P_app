@ 24 | Un débat sur les règles | Un debate sobre las normas
I Escucha un debate de radio sobre las normas de la ciudad: la velocidad, los peatones y las multas. Anota qué se prohíbe y qué se permite.
E Normas :: Una **interdiction** (prohibición) es algo que no se puede hacer. Una **autorisation** (permiso) dice lo que sí se puede hacer. La **vitesse** (velocidad) tiene un **limite** (límite) en cada zona.
E Sanciones :: Una **sanction** (sanción) puede ser una **contravention** (multa). El **piéton** (peatón) camina por el **trottoir** (acera) y cruza por el **passage** (paso) de peatones.
B Norma | Palabra | Ejemplo
| prohibición | une interdiction | Il y a une interdiction.
| permiso | une autorisation | J'ai une autorisation.
| multa | une contravention | Il y a une contravention.
W interdiction = prohibición | a(n)-ter-dik-SIÓN
W autorisation = permiso | o-to-ri-za-SIÓN
W vitesse = velocidad | vi-TES
W sanction = sanción | sa(n)-ksi-ÓN
W contravention = multa | ko(n)-tra-va(n)-SIÓN
W piéton = peatón | pie-TÓN
W cycliste = ciclista | si-KLÍST
W trottoir = acera | tro-TUÁR
W passage = paso | pa-SÁZH
W zone = zona | ZON
W limite = límite | li-MIT
W conducteur = conductor | ko(n)-dük-TÖR
V Vocabulario: normas
D En el debate de radio
Animatrice: La police est là. = La policía está allí.
  > la police = la policía | est là = está allí
Auditeur: Je veux une limite de vitesse. = Quiero un límite de velocidad.
  > une limite = un límite | de vitesse = de velocidad
Animatrice: Oui, mais la sanction est grande. = Sí, pero la sanción es grande.
  > la sanction = la sanción | grande = grande
Auditeur: Le piéton a un passage. = El peatón tiene un paso.
  > le piéton = el peatón | un passage = un paso
Animatrice: Et le cycliste a une zone. = Y el ciclista tiene una zona.
  > le cycliste = el ciclista | une zone = una zona
Auditeur: Il y a une contravention pour le conducteur. = Hay una multa para el conductor.
  > une contravention = una multa | le conducteur = el conductor
Q ¿Qué quiere el oyente?
+ Une limite de vitesse. :: Un límite de velocidad.
- Une autorisation. :: No es lo que pide.
- Un trottoir. :: No es lo que pide.
Q ¿Quién tiene una zona?
+ Le cycliste. :: El ciclista.
- Le piéton. :: Tiene un paso, no una zona.
- Le conducteur. :: No aparece con zona.
R La police est là.
+ La policía está allí. :: «Est là» = está allí.
- La policía estuvo allí. :: Es pasado.
- La policía vendrá allí. :: Es futuro.
H Il y a une ___ pour le conducteur.
+ contravention :: Multa por infringir una norma.
- zone :: Es la zona, no la multa.
- passage :: Es el paso de peatones.
H Le piéton a un ___ .
+ passage :: Paso reservado para peatones.
- trottoir :: Es la acera.
- conducteur :: Es quien conduce.
A Il y a une interdiction de fumer.
+ Hay una prohibición de fumar. :: «Interdiction de» + infinitivo.
- Hay un permiso para fumar. :: Es lo contrario.
- Hay una sanción de fumar. :: No es la frase.
O un trottoir :: una acera :: Parte de la calle para los peatones.
X Escribe en francés: «hay que respetar la regla» :: il faut respecter la règle :: «Il faut» + infinitivo.

@ 24 | Le monde du travail | El mundo del trabajo
I Escucha a dos compañeros que hablan de una huelga, de un aumento de sueldo y de un despido. Anota qué pasa y qué piensan.
E Huelga y sindicato :: Una **grève** (huelga) la convoca un **syndicat** (sindicato). Si alguien deja el trabajo hace una **démission** (dimisión). Si la empresa lo despide, hay un **licenciement** (despido).
E Sueldo y carrera :: Una **augmentation** (aumento) del sueldo llega con el **bulletin** (la nómina) del mes. Un **employé** (empleado) trabaja para un **employeur** (empleador) y tiene una **carrière** (carrera) profesional. Cuando no hay trabajo hay **chômage** (paro).
B Trabajo | Palabra | Ejemplo
| huelga | la grève | Il y a une grève demain.
| despido | le licenciement | Le licenciement est injuste.
| aumento | une augmentation | Une augmentation de salaire.
W grève = huelga | GREV
W syndicat = sindicato | sin-di-KÁ
W démission = dimisión | de-mi-SIÓN
W licenciement = despido | li-sa(n)-si-MA(N)
W chômage = paro | sho-MÁZH
W bulletin = nómina | bü-le-TÁN
W carrière = carrera | ka-RIÉR
W augmentation = aumento | o-gma(n)-ta-SIÓN
W employé = empleado | a(n)-plua-YÉ
W salarié = asalariado | sa-la-rie-É
W usine = fábrica | ü-ZÍN
W employeur = empleador | a(n)-plua-YÖR
V Vocabulario: trabajo
D En la oficina
Léa: Il y a une grève demain. = Mañana hay una huelga.
  > une grève = una huelga | demain = mañana
Thomas: Le syndicat demande une augmentation. = El sindicato pide un aumento.
  > le syndicat = el sindicato | une augmentation = un aumento
Léa: Mon bulletin est petit ce mois. = Mi nómina es pequeña este mes.
  > mon bulletin = mi nómina | petit = pequeño
Thomas: Tu veux une démission ? = ¿Quieres una dimisión?
  > une démission = una dimisión
Léa: Non, je veux une bonne carrière. = No, quiero una buena carrera.
  > une bonne carrière = una buena carrera
Thomas: Un employé parle avec le patron. = Un empleado habla con el jefe.
  > un employé = un empleado | le patron = el jefe
Q ¿Qué pide el sindicato?
+ Une augmentation. :: Un aumento.
- Une démission. :: No lo pide el sindicato.
- Un chômage. :: No lo pide el sindicato.
Q ¿Quién habla con el jefe?
+ Un employé. :: Un empleado.
- Un syndicat. :: Es el sindicato, no el trabajador.
- Un bulletin. :: Es la nómina.
R Il y a une grève demain.
+ Mañana hay una huelga. :: «Demain» = mañana.
- Hoy hay una huelga. :: Eso sería «aujourd'hui».
- Mañana hay una reunión. :: No lo dice la frase.
H Le ___ demande une augmentation.
+ syndicat :: Organización que defiende a los trabajadores.
- chômage :: Es el paro.
- usine :: Es la fábrica.
H Mon ___ est petit ce mois.
+ bulletin :: La nómina del mes.
- démission :: Es la dimisión.
- licenciement :: Es el despido.
A Une bonne carrière est un avantage.
+ Una buena carrera es una ventaja. :: «Un avantage» = una ventaja.
- Una buena carrera es una desventaja. :: Es lo contrario.
- Un buen sueldo es una ventaja. :: «Salaire» es el sueldo.
O un licenciement :: un despido :: Cuando la empresa deja a alguien sin trabajo.
X Escribe en francés: «hay una huelga mañana» :: il y a une grève demain :: «Il y a» = hay.
