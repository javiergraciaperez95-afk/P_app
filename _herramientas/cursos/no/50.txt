

@ 50 | Avsluttende prøve | Examen final de A2
E Examen final de A2 :: Veinticinco preguntas sobre los capítulos 11–20. Si aciertas veinte o más, has superado este repaso de los contenidos incluidos en el nivel. El resultado es orientativo y no certifica por sí solo el nivel A2. :: Cada pregunta indica su capítulo para ayudarte a elegir qué repasar.
Q Cap. 26. ¿Qué significa «i går»?
+ Ayer :: Se refiere al día anterior.
- Hoy :: «I dag» significa hoy.
- Mañana :: «I morgen» significa mañana.
H Cap. 26. I går ___ hun en enkel plan. :: pista: preparó
+ laget :: Es el pasado de «lage».
- lager :: Es presente.
- lage :: Es infinitivo.
R Cap. 27. Jeg har nettopp skrevet en kort tekst. :: Traduce la frase.
+ Acabo de escribir un texto corto. :: «Har nettopp skrevet» expresa una acción reciente.
- Escribí un texto corto el año pasado. :: Eso sería «I fjor skrev jeg…».
- Estoy escribiendo un texto corto ahora. :: La frase usa presente perfecto.
Q Cap. 27. Si se dice «i går», ¿qué tiempo se usa normalmente para contar la acción terminada?
+ Pasado simple :: Un momento pasado concreto suele ir con pasado simple.
- Presente perfecto :: Se usa para experiencias sin una fecha terminada concreta.
- Infinitivo :: No expresa por sí solo el hecho pasado.
H Cap. 28. Jeg skal ___ på en ny utdanning. :: pista: empezar
+ begynne :: Después de «skal» va el infinitivo sin «å».
- begynner :: Es presente.
- begynte :: Es pasado.
Q Cap. 28. ¿Cómo invitas a alguien con «¿Te apetece ir a un concierto?»?
+ Har du lyst til å gå på konsert? :: «Har du lyst til å…?» sirve para invitar.
- Jeg er dessverre opptatt på lørdag. :: Significa que lo siento, estoy ocupado/a el sábado.
- Det passer fint. :: Significa me viene bien.
H Cap. 29. Jeg øver ___ jeg vil bestå. :: pista: porque
+ fordi :: «Fordi» introduce una razón.
- men :: Significa pero.
- eller :: Significa o.
Q Cap. 29. ¿Qué significa «Skriv svaret på linjen»?
+ Escribe la respuesta en la línea. :: «Skriv» es un imperativo.
- Lee la instrucción con cuidado. :: Eso sería «Les instruksjonen nøye».
- Entrega la tarea ahora. :: Eso sería «Levere oppgaven nå».
R Cap. 30. Jeg søker en jobb som resepsjonist. :: Traduce la frase.
+ Solicito un trabajo como recepcionista. :: «Som» significa «como» delante de una profesión.
- Recomiendo a una persona como jefa. :: Eso sería «anbefaler» y no aparece en la frase.
- Trabajo en equipo con los recepcionistas. :: Eso sería «samarbeider».
Q Cap. 30. En «en leder som hjelper meg», ¿qué función tiene «som»?
+ Introduce una descripción: «que me ayuda». :: Se refiere al sustantivo «leder».
- Significa «porque». :: «Fordi» significa porque.
- Indica posesión: «su». :: «Hans», «hennes» y «deres» son posesivos.
Q Cap. 31. ¿Qué es «fastlege»?
+ Médico/a de cabecera :: Es el profesional que atiende habitualmente al paciente.
- Farmacéutico/a :: «Farmasøyt» significa farmacéutico/a.
- Persona de atención al cliente :: «Kundeservice» significa atención al cliente.
H Cap. 31. Har du vondt i ___? :: pista: la rodilla
+ kneet :: Es la forma definida de «kne».
- ankelen :: Significa el tobillo.
- isen :: Significa el hielo.
A Cap. 31. Du bør følge rådet fra legen. :: ¿Qué recomienda la frase?
+ Seguir el consejo del médico. :: «Bør» expresa un consejo.
- Cancelar la cita por enfermedad. :: Eso sería «avlyse avtalen på grunn av sykdom».
- Renovar una receta. :: Eso sería «fornye resepten».
Q Cap. 32. ¿Qué significa «holdeplass»?
+ Parada de transporte :: Es el lugar donde para el autobús.
- Estación de tren :: «Stasjon» significa estación.
- Archivo adjunto :: «Vedlegg» significa archivo adjunto.
R Cap. 32. Pakken kommer om to dager. :: Traduce la frase.
+ El paquete llega dentro de dos días. :: «Om to dager» expresa ese plazo.
- El paquete llegó ayer. :: La frase está en presente y dice «om to dager».
- El pedido está roto. :: Eso sería «bestillingen er ødelagt».
H Cap. 33. Toget er raskere ___ bussen. :: pista: que, al comparar
+ enn :: «Enn» introduce el segundo elemento de la comparación.
- fordi :: Significa porque.
- men :: Significa pero.
Q Cap. 33. ¿Qué significa «Jeg er ikke helt enig»?
+ No estoy del todo de acuerdo. :: «Ikke helt» suaviza el desacuerdo.
- Estoy completamente de acuerdo. :: «Ikke» niega la idea.
- Quiero ahorrar dinero. :: Eso sería «Jeg vil spare penger».
R Cap. 33. Jeg velger bussen fordi den er billigst. :: Traduce la frase.
+ Elijo el autobús porque es el más barato. :: «Billigst» es el superlativo de «billig».
- Elijo el tren porque es más rápido. :: La frase habla del autobús y el precio.
- El autobús es más caro, pero cómodo. :: La frase da la razón para elegirlo.
Q Cap. 34. ¿Qué significa «vedlegg» en un correo?
+ Archivo adjunto :: Es un archivo añadido al mensaje.
- Asunto :: «Emne» significa asunto.
- Destinatario :: «Mottaker» significa destinatario.
H Cap. 34. Jeg håper å få en tilbakemelding ___ fredag. :: pista: antes del viernes
+ innen :: «Innen fredag» significa antes del viernes.
- på forhånd :: Significa de antemano.
- snarest :: Significa lo antes posible.
Q Cap. 34. ¿Qué significa «Takk på forhånd»?
+ Gracias de antemano :: «På forhånd» significa de antemano.
- Gracias por la respuesta recibida. :: La frase no dice que ya haya una respuesta.
- Gracias por cambiar el formulario. :: No se menciona un cambio.
Q Cap. 35. ¿Qué significa «påmelding»?
+ Inscripción :: Es el proceso de registrarse para una actividad.
- Intersección :: «Kryss» significa cruce.
- Barrio :: «Nabolag» significa barrio.
A Cap. 35. Gå rett fram til krysset. :: ¿Qué indicación da?
+ Seguir recto hasta el cruce. :: «Gå rett fram» significa seguir recto.
- Girar a la izquierda junto a la biblioteca. :: Eso no es lo que indica la frase.
- Volver al centro cultural. :: La frase indica avanzar hasta el cruce.
H Cap. 35. Målet mitt er å bli ___. :: pista: con más confianza
+ tryggere :: Es el comparativo de «trygg».
- trygg :: Significa seguro/a, sin comparación.
- nødvendig :: Significa necesario/a.
X Cap. 35. Escribe en noruego: «a pie» :: til fots :: «Til fots» significa a pie.
