
@ 16 | På biblioteket | En la biblioteca
E Préstamos :: **Et lånekort** permite pedir libros prestados en una biblioteca. Su forma definida es **lånekortet**. :: **Lånetid** es el período durante el que puedes conservar un préstamo; **lånefrist** es la fecha límite para devolverlo.
W lånekort = carné de biblioteca | LO-ne-kort
W lånekortet = el carné de biblioteca | LO-ne-kor-tet
W låne = pedir prestado | LO-ne
W låner = pide prestado | LO-ner
W lånetid = período de préstamo | LO-ne-tid
W lånetiden = el período de préstamo | LO-ne-ti-den
W uker = semanas | Ü-ker
W lånefrist = fecha límite de devolución | LO-ne-frist
W lånefristen = la fecha límite de devolución | LO-ne-fris-ten
W lånet = el préstamo | LO-net
W forlenge = prorrogar | for-LÉN-ge
W gratis = gratis | GRÁ-tis
W gebyr = tasa; cargo | ge-BÜR
W Har du et lånekort = ¿Tienes carné de biblioteca? | HAR dü et LO-ne-kort
W Her er lånekortet = Aquí tienes el carné de biblioteca | JÉR er LO-ne-kor-tet
W Du kan låne en bok = Puedes pedir un libro prestado | dü kan LO-ne en BUK
W Hvor lang er lånetiden = ¿Cuánto dura el período de préstamo? | VUR LANG er LO-ne-ti-den
W Lånetiden er fire uker = El período de préstamo es de cuatro semanas | LO-ne-ti-den er FÍ-re Ü-ker
W Når er lånefristen = ¿Cuándo vence el préstamo? | NOR er LO-ne-fris-ten
W Lånefristen er om fire uker = La fecha límite es dentro de cuatro semanas | LO-ne-fris-ten er om FÍ-re Ü-ker
W Kan jeg forlenge lånet = ¿Puedo prorrogar el préstamo? | kan YÁI for-LÉN-ge LO-net
W Det er ikke noe gebyr = No hay ningún cargo | de er Í-ke NÚ-e ge-BÜR
V Vocabulario: carné y préstamos
D Pedir un libro
Nora: Har du et lånekort? = ¿Tienes carné de biblioteca?
  > Har du = tienes | et lånekort = un carné de biblioteca
Ali: Ja, her er lånekortet. = Sí, aquí tienes el carné.
  > her er = aquí tienes | lånekortet = el carné
Nora: Du kan låne en bok. = Puedes pedir un libro prestado.
  > Du kan låne = puedes pedir prestado | en bok = un libro
Ali: Hvor lang er lånetiden? = ¿Cuánto dura el período de préstamo?
  > Hvor lang = cuánto dura | lånetiden = el período de préstamo
Nora: Lånetiden er fire uker. = El período de préstamo es de cuatro semanas.
  > Lånetiden = el período de préstamo | er fire uker = es de cuatro semanas
Ali: Når er lånefristen? = ¿Cuándo vence el préstamo?
  > Når er = cuándo es | lånefristen = la fecha límite de devolución
Nora: Lånefristen er om fire uker. = La fecha límite es dentro de cuatro semanas.
  > Lånefristen = la fecha límite | er om fire uker = es dentro de cuatro semanas
Ali: Kan jeg forlenge lånet? = ¿Puedo prorrogar el préstamo?
  > Kan jeg forlenge = ¿puedo prorrogar? | lånet = el préstamo
Nora: Ja, det er ikke noe gebyr. = Sí, no hay ningún cargo.
  > det er ikke noe = no hay ningún | gebyr = cargo
Q ¿Para qué sirve un «lånekort»?
+ Para pedir libros prestados. :: El carné permite usar el servicio de préstamo.
- Para pagar una multa. :: Eso sería un cargo, «gebyr».
- Para saber el horario de apertura. :: Eso es «åpningstider».
Q ¿Qué significa «lånetid»?
+ El período durante el que conservas un préstamo. :: Es la duración del préstamo.
- La fecha de apertura de la biblioteca. :: No se refiere a horarios.
- Un cargo por devolver tarde. :: Eso es «gebyr».
R Du kan låne en bok. :: Traduce la frase.
+ Puedes pedir un libro prestado. :: «Låne» significa pedir prestado.
- Puedes comprar un libro. :: No aparece «kjøpe».
- Tienes que devolver el libro. :: La frase habla de pedirlo prestado.
H Lånetiden er fire ___. :: Completa «semanas».
+ uker :: «Fire uker» significa cuatro semanas.
- dager :: «Dager» significa días.
- timer :: «Timer» significa horas.
H Kan jeg ___ lånet? :: Completa «prorrogar».
+ forlenge :: «Forlenge» significa alargar o prorrogar.
- betale :: Significa pagar.
- hente :: Significa recoger.
A Når er lånefristen? :: ¿Qué quiere saber la persona?
+ Cuándo debe devolver el préstamo. :: «Lånefristen» es la fecha límite.
- Cuánto cuesta el libro. :: No pregunta por un precio.
- Dónde está la biblioteca. :: No pregunta por un lugar.
O Lånefristen er om fire uker. :: La fecha límite es dentro de cuatro semanas. :: «Om» con una duración sitúa algo en el futuro.
X Escribe «Puedes pedir un libro prestado» :: Du kan låne en bok. :: «Kan» va seguido del infinitivo sin «å».

@ 16 | På servicekontoret | En la oficina de atención
E Trámites sencillos :: **Et skjema** significa «un formulario» y su forma definida es **skjemaet**. :: Para pedir ayuda puedes decir **Jeg trenger hjelp**. El imperativo **fyll ut** significa «rellena».
W servicekontor = oficina de atención | SÉR-vi-se-kon-TÚR
W servicekontoret = la oficina de atención | SÉR-vi-se-kon-TÚ-ret
W kølapp = ticket para esperar turno; número de turno | KÖ-lap
W kølappen = el ticket para esperar turno | KÖ-lap-pen
W skranke = mostrador de atención | SKRÁN-ke
W skranken = el mostrador de atención | SKRÁN-ken
W skjema = formulario | SHÉ-ma
W skjemaet = el formulario | SHÉ-ma-et
W fylle ut = rellenar | FÜ-le ÜT
W fyll ut = rellena (imperativo) | FÜL ÜT
W signere = firmar | sig-NÉ-re
W signerer = firma | sig-NÉ-rer
W underskrift = firma; rúbrica | ÜN-der-skrift
W underskriften = la firma; la rúbrica | ÜN-der-skrif-ten
W hjelp = ayuda | YELP
W Jeg trenger hjelp = Necesito ayuda | YÁI TRÉN-ger YELP
W Hvor finner jeg skjemaet = ¿Dónde encuentro el formulario? | VUR FÍN-ner YÁI SHÉ-ma-et
W Ta en kølapp = Toma un número | ta en KÖ-lap
W Kan du fylle ut skjemaet = ¿Puedes rellenar el formulario? | kan dü FÜ-le ÜT SHÉ-ma-et
W Jeg signerer her = Firmo aquí | YÁI sig-NÉ-rer JÉR
W Hvor finner jeg servicekontoret = ¿Dónde encuentro la oficina de atención? | VUR FÍN-ner YÁI SÉR-vi-se-kon-TÚ-ret
V Vocabulario: pedir atención y completar un formulario
D En una oficina municipal
Ali: Hvor finner jeg servicekontoret? = ¿Dónde encuentro la oficina de atención?
  > Hvor finner jeg = dónde encuentro | servicekontoret = la oficina de atención
Nora: Det er ved inngangen. = Está junto a la entrada.
  > Det er = está | ved inngangen = junto a la entrada
Ali: Jeg trenger hjelp. = Necesito ayuda.
  > Jeg trenger = necesito | hjelp = ayuda
Nora: Ta en kølapp. = Toma un turno.
  > Ta en = toma un | kølapp = turno de espera
Ali: Hvor finner jeg skjemaet? = ¿Dónde encuentro el formulario?
  > Hvor finner jeg = dónde encuentro | skjemaet = el formulario
Nora: Fyll ut skjemaet her. = Rellena el formulario aquí.
  > Fyll ut = rellena | skjemaet her = el formulario aquí
Ali: Jeg signerer her. = Firmo aquí.
  > Jeg signerer = firmo | her = aquí
Q ¿Qué debes tomar para esperar tu turno?
+ Una «kølapp». :: La palabra se refiere al turno de espera.
- Un «lånekort». :: Ese carné se usa en la biblioteca.
- Un «skjema». :: El formulario se rellena.
Q ¿Qué significa «underskrift»?
+ Firma. :: Es el nombre escrito al final de un documento.
- Mostrador. :: Eso es «skranke».
- Turno de espera. :: Eso es «kølapp».
R Jeg trenger hjelp. :: Traduce la frase.
+ Necesito ayuda. :: «Trenger» significa necesito.
- Firmo aquí. :: Eso es «Jeg signerer her».
- Relleno el formulario. :: Eso es «Jeg fyller ut skjemaet».
H ___ ut skjemaet her. :: Completa el imperativo «rellena».
+ Fyll :: «Fyll ut» es la orden para completar el formulario.
- Finner :: Significa «encuentra».
- Signerer :: Significa «firma».
H Hvor finner jeg ___? :: Completa «el formulario».
+ skjemaet :: Es la forma definida de «skjema».
- kølappen :: Significa «el turno».
- underskriften :: Significa «la firma».
A Ta en kølapp. :: ¿Qué debe hacer la persona?
+ Tomar un turno de espera. :: «Kølapp» es un número o turno para esperar.
- Firmar el formulario. :: No aparece «signere».
- Pedir un libro prestado. :: Eso se hace con «låne».
O Kan du fylle ut skjemaet? :: ¿Puedes rellenar el formulario? :: El infinitivo tras «kan» no lleva «å».
X Escribe «Necesito ayuda» :: Jeg trenger hjelp. :: «Jeg trenger» significa necesito.

@ 16 | Åpningstider og informasjon | Horarios e información
E Horarios :: **Når åpner …?** pregunta a qué hora abre un lugar. :: **Stenger** significa «cierra»; **åpningstid** es el horario de apertura. **Kort** significa «breve» en **kort ventetid**, pero **et kort** también es «una tarjeta».
W åpner = abre | ÓP-ner
W stenger = cierra | STÉNG-er
W åpningstid = horario de apertura | ÓP-nings-tid
W åpningstiden = el horario de apertura | ÓP-nings-tí-den
W ventetid = tiempo de espera | VÉN-te-tid
W ventetiden = el tiempo de espera | VÉN-te-ti-den
W kort = corto/a | KURT
W informasjonsskranke = mostrador de información | in-for-ma-SHÚNS-skrán-ke
W informasjonsskranken = el mostrador de información | in-for-ma-SHÚNS-skrán-ken
W kontoret = la oficina | kon-TÚ-ret
W Når åpner servicekontoret = ¿A qué hora abre la oficina de atención? | NOR ÓP-ner SÉR-vi-se-kon-TÚ-ret
W Det åpner klokka ni = Abre a las nueve | de ÓP-ner KLO-ka NI
W Kontoret stenger klokka tre = La oficina cierra a las tres | kon-TÚ-ret STÉNG-er KLO-ka TRE
W Er det åpent på lørdag = ¿Está abierto el sábado? | er de Ó-pen po LÖR-dag
W Kontoret er stengt på lørdag = La oficina está cerrada el sábado | kon-TÚ-ret er STENGT po LÖR-dag
W Hvor er informasjonsskranken = ¿Dónde está el mostrador de información? | VUR er in-for-ma-SHÚNS-skrán-ken
W Skranken er ved inngangen = El mostrador está junto a la entrada | SKRÁN-ken er ve ÍN-gang-en
W Ventetiden er kort = La espera es corta | VÉN-te-ti-den er KURT
V Vocabulario: horarios y atención
D Consultar los horarios
Ali: Når åpner servicekontoret? = ¿A qué hora abre la oficina de atención?
  > Når åpner = a qué hora abre | servicekontoret = la oficina de atención
Nora: Det åpner klokka ni. = Abre a las nueve.
  > Det åpner = abre | klokka ni = a las nueve
Ali: Kontoret stenger klokka tre. = La oficina cierra a las tres.
  > Kontoret stenger = la oficina cierra | klokka tre = a las tres
Mina: Er det åpent på lørdag? = ¿Está abierto el sábado?
  > Er det åpent = está abierto | på lørdag = el sábado
Nora: Nei, kontoret er stengt på lørdag. = No, la oficina está cerrada el sábado.
  > kontoret er stengt = la oficina está cerrada | på lørdag = el sábado
Ali: Hvor er informasjonsskranken? = ¿Dónde está el mostrador de información?
  > Hvor er = dónde está | informasjonsskranken = el mostrador de información
Mina: Skranken er ved inngangen. = El mostrador está junto a la entrada.
  > Skranken = el mostrador | ved inngangen = junto a la entrada
Nora: Ventetiden er kort. = La espera es corta.
  > Ventetiden = la espera | er kort = es corta
Q ¿Qué pregunta «Når åpner servicekontoret?»
+ A qué hora abre la oficina de atención. :: «Når» pregunta cuándo.
- Dónde está el mostrador. :: Eso se pregunta con «Hvor».
- Si hay que rellenar un formulario. :: La frase pregunta por la hora de apertura.
Q ¿Qué significa «stenger»?
+ Cierra. :: «Kontoret stenger» significa la oficina cierra.
- Abre. :: Eso es «åpner».
- Firma. :: Eso es «signerer».
R Kontoret stenger klokka tre. :: Traduce la frase.
+ La oficina cierra a las tres. :: «Stenger» es cierra.
- La oficina abre a las tres. :: Eso sería «åpner».
- La espera es corta. :: Eso es «Ventetiden er kort».
H Er det ___ på lørdag? :: Completa «abierto».
+ åpent :: «Åpent» se usa con «det».
- stengt :: Significa cerrado.
- kort :: Significa corto.
H Ventetiden er ___. :: Completa «corta».
+ kort :: «Kort» significa corto/a.
- stengt :: Significa cerrado.
- gratis :: Significa gratis.
A Det åpner klokka ni. :: ¿A qué hora abre?
+ A las nueve. :: «Klokka ni» es a las nueve.
- A las tres. :: Eso sería «klokka tre».
- El sábado. :: La frase da una hora.
O Skranken er ved inngangen. :: El mostrador está junto a la entrada. :: «Ved» indica que está al lado o cerca.
X Escribe «La oficina cierra a las tres» :: Kontoret stenger klokka tre. :: «Stenger» significa cierra.
