@ 34 | Meldinger og skjemaer | Mensajes y formularios
E Enviar un correo :: **Emne** significa «asunto» y **vedlegg**, «archivo adjunto». En noruego se dice **legge ved et dokument** para indicar que se adjunta un documento.
E Mensajes breves :: **Beskjed** es un aviso o recado. **Motta** significa recibir; **mottaker**, destinatario. **Snart** ya se aprendió en un capítulo anterior.
W beskjed = aviso; recado | be-SHÉD
W mottaker = destinatario/a | MÚ-ta-ker
W motta = recibir | MÚ-ta
W mottar = recibo; recibe | MÚ-tar
W emne = asunto (de un correo) | ÉM-ne
w emnet = el asunto | ÉM-net
W vedlegg = archivo adjunto | VÉD-leg
w vedlegget = el archivo adjunto | VÉD-leg-get
W legge ved = adjuntar | LÉ-ge ved
W lenke = enlace | LÉN-ke
w lenken = el enlace | LÉN-ken
W klikke = hacer clic | KLÍ-ke
W klikker = hago clic; hace clic | KLÍ-ker
W klikk = haz clic | KLIK
W innboks = bandeja de entrada | ÍN-boks
W åpne = abrir | ÓP-ne
w klart = listo | KLART
w e-posten = el correo electrónico | É-post-en
w meldingen = el mensaje | MÉL-ding-en
V Vocabulario: correos y mensajes
D Un correo con archivo
Amina: Jeg sender deg en e-post nå. = Te envío un correo ahora.
  > Jeg sender deg = te envío | en e-post nå = un correo ahora
Jon: Hva er emnet? = ¿Cuál es el asunto?
  > Hva er = cuál es | emnet = el asunto
Amina: Det gjelder timen på torsdag. = Trata de la cita del jueves.
  > Det gjelder = trata de | timen på torsdag = la cita del jueves
Jon: Kan du legge ved skjemaet? = ¿Puedes adjuntar el formulario?
  > Kan du legge ved = puedes adjuntar | skjemaet = el formulario
Amina: Ja, vedlegget er klart. = Sí, el archivo adjunto está listo.
  > vedlegget er klart = el archivo adjunto está listo
Jon: Jeg åpner e-posten nå. = Abro el correo ahora.
  > Jeg åpner = abro | e-posten nå = el correo ahora
Amina: Klikk på lenken i meldingen også. = Haz clic también en el enlace del mensaje.
  > Klikk på lenken = haz clic en el enlace | i meldingen også = también en el mensaje
Jon: Takk. Jeg svarer snart. = Gracias. Responderé pronto.
  > Jeg svarer snart = responderé pronto
Q ¿Qué significa «vedlegg»?
+ Archivo adjunto :: Es un archivo que se añade a un correo o mensaje.
- Asunto :: «Emne» significa asunto.
- Destinatario :: «Mottaker» significa destinatario.
Q ¿Qué le pide Jon a Amina?
+ Que adjunte el formulario. :: «Legge ved skjemaet» es adjuntar el formulario.
- Que borre el correo. :: No le pide que borre nada.
- Que cambie la fecha de la cita. :: Solo dice que el correo trata de la cita.
R Kan du legge ved skjemaet? :: Traduce la pregunta.
+ ¿Puedes adjuntar el formulario? :: «Legge ved» significa adjuntar.
- ¿Puedes abrir el formulario? :: «Åpne» significa abrir.
- ¿Puedes responder al mensaje? :: Eso sería «svare på meldingen».
H Hva er ___? :: Completa «el asunto».
+ emnet :: «Emne» es asunto; «emnet» es el asunto.
- vedlegget :: Significa el archivo adjunto.
- mottaker :: Significa destinatario.
H Jeg ___ deg en e-post nå. :: Completa «envío».
+ sender :: Es la forma presente de «sende».
- mottar :: Significa recibo.
- åpner :: Significa abro.
A Klikk på lenken i meldingen også. :: ¿Qué tiene que hacer Jon?
+ Hacer clic en el enlace del mensaje. :: «Klikk på» es una instrucción para hacer clic.
- Enviar un archivo adjunto. :: Eso lo pide en la frase anterior.
- Recibir un correo más tarde. :: La frase da una instrucción ahora.
O Jeg åpner e-posten nå. :: Abro el correo ahora. :: «Åpner» es presente y aquí describe una acción actual.
X Escribe en noruego: «destinatario» :: mottaker :: «En mottaker» es un destinatario.

@ 34 | Fylle ut et skjema | Completar un formulario
E Datos de un formulario :: **Felt** es un campo; **postnummer**, código postal; **fødselsdato**, fecha de nacimiento. **Obligatorisk** quiere decir que un dato es obligatorio.
E Acciones en una página :: **Fylle ut** es completar un formulario; **lagre** es guardar; **sende inn** es enviar o presentar. **Trykke på** significa pulsar.
W felt = campo (de formulario) | FELT
w feltet = el campo | FEL-te
W postnummer = código postal | PÓST-nü-mer
W telefonnummer = número de teléfono | te-le-FÚN-nü-mer
W fødselsdato = fecha de nacimiento | FÖD-sels-da-tu
W obligatorisk = obligatorio/a | o-bli-ga-TÚ-risk
W valgfritt = opcional | VAL-frit
W fyller ut = completo; completa | FÜ-ler ÜT
W lagre = guardar | LÁ-gre
W lagrer = guardo; guarda | LÁ-grer
W lagret = guardado | LÁ-gret
W nett = internet | NET
w nettet = internet | NÉT-et
W trykke = pulsar; presionar | TRÜ-ke
W trykker = pulso; pulsa | TRÜ-ker
W sende inn = enviar; presentar | SÉN-de ÍN
W huske = recordar | JÜS-ke
W husk = recuerda (imperativo) | JUSK
V Vocabulario: formularios
D En la página de inscripción
Kari: Jeg skal fylle ut skjemaet på nettet. = Voy a completar el formulario en internet.
  > Jeg skal fylle ut = voy a completar | skjemaet på nettet = el formulario en internet
Ola: Hvilke felt må du fylle ut? = ¿Qué campos tienes que completar?
  > Hvilke felt = qué campos | må du fylle ut = tienes que completar
Kari: Navn, adresse, postnummer og telefonnummer. = Nombre, dirección, código postal y número de teléfono.
  > navn, adresse, postnummer og telefonnummer = nombre, dirección, código postal y número de teléfono
Ola: Er fødselsdato obligatorisk? = ¿Es obligatoria la fecha de nacimiento?
  > Er fødselsdato = es la fecha de nacimiento | obligatorisk = obligatoria
Kari: Nei, det feltet er valgfritt. = No, ese campo es opcional.
  > det feltet = ese campo | er valgfritt = es opcional
Ola: Husk å trykke på «Lagre». = Recuerda pulsar «Guardar».
  > Husk å trykke på = recuerda pulsar | Lagre = Guardar
Kari: Nå har jeg lagret skjemaet. = Ya he guardado el formulario.
  > Nå har jeg lagret = ya he guardado | skjemaet = el formulario
Ola: Du må sende inn skjemaet til slutt. = Tienes que enviar el formulario al final.
  > Du må sende inn = tienes que enviar | skjemaet til slutt = el formulario al final
Q ¿Qué significa «postnummer»?
+ Código postal :: Es el número que identifica una zona postal.
- Número de teléfono :: «Telefonnummer» significa número de teléfono.
- Fecha de nacimiento :: «Fødselsdato» significa fecha de nacimiento.
Q ¿Qué tiene que hacer Kari al final?
+ Enviar el formulario. :: «Sende inn» es enviar o presentar.
- Borrar los campos. :: No se menciona borrar información.
- Cambiar su número de teléfono. :: El diálogo solo enumera los datos.
R Er fødselsdato obligatorisk? :: Traduce la pregunta.
+ ¿Es obligatoria la fecha de nacimiento? :: «Obligatorisk» significa obligatorio/a.
- ¿Cuál es tu fecha de nacimiento? :: Esa pregunta sería «Hva er fødselsdatoen din?».
- ¿Puedo guardar el formulario? :: Eso sería «Kan jeg lagre skjemaet?».
H Husk å ___ på «Lagre». :: Completa «pulsar».
+ trykke :: Después de «husk å» se usa infinitivo con «å».
- lagret :: Significa guardado.
- fyller ut :: Significa completo.
H Nå har jeg ___ skjemaet. :: Completa «guardado».
+ lagret :: «Har lagret» forma el perfecto: he guardado.
- fyller ut :: Significa completo.
- obligatorisk :: Significa obligatorio.
A Du må sende inn skjemaet til slutt. :: ¿Qué debe hacer la persona?
+ Enviar el formulario al final. :: «Må» expresa que tiene que hacerlo.
- Completar la fecha de nacimiento obligatoria. :: La fecha no es obligatoria en el ejemplo.
- Pulsar el enlace del correo. :: Aquí se habla de un formulario.
O Jeg skal fylle ut skjemaet på nettet. :: Voy a completar el formulario en internet. :: «Skal» puede expresar una acción prevista.
X Escribe en noruego: «campo» :: felt :: «Et felt» es un campo de formulario.

@ 34 | En høflig e-post | Un correo cortés
E Saludo y despedida :: **Kjære** abre un mensaje formal. **Vennlig hilsen** equivale a «saludos cordiales»; **Med vennlig hilsen**, a «atentamente».
E Pedir información :: **Jeg lurer på** significa «quisiera saber» o «me pregunto». **På forhånd** aparece en **Takk på forhånd** («gracias de antemano»).
W Kjære = estimado/a; querido/a | SHÉ-re
W lurer = me pregunto; quisiera saber | LÜ-rer
W tilbakemelding = respuesta; comentarios | til-ba-ke-MÉL-ding
W opplysninger = datos; información | ÓP-lüs-ning-er
W frist = plazo; fecha límite | FRIST
W innen = antes de; dentro de | ÍN-en
W behandlingstid = tiempo de tramitación | be-JÁND-lings-tid
W håper = espero | JÓ-per
W hilsen = saludo | JÍL-sen
W vennlig hilsen = saludos cordiales | VÉN-li JÍL-sen
W med vennlig hilsen = atentamente | me VÉN-li JÍL-sen
W på forhånd = de antemano | po for-JÓN
W snarest = lo antes posible | SNÁ-rest
W gjeldende = vigente; actual | YÉL-den-de
w hjelpen = la ayuda | JÉL-pen
V Vocabulario: correos corteses
T Pedir información
- Kjære kundeservice. = Estimado equipo de atención al cliente.
  > Kjære kundeservice = estimado equipo de atención al cliente
- Jeg lurer på når kurset begynner. = Quisiera saber cuándo empieza el curso.
  > Jeg lurer på = quisiera saber | når kurset begynner = cuándo empieza el curso
- Kan dere sende meg opplysninger om timeplanen? = ¿Pueden enviarme información sobre el horario?
  > Kan dere sende meg = pueden enviarme | opplysninger om timeplanen = información sobre el horario
- Jeg håper å få en tilbakemelding innen fredag. = Espero recibir una respuesta antes del viernes.
  > Jeg håper å få = espero recibir | en tilbakemelding innen fredag = una respuesta antes del viernes
- Takk på forhånd for hjelpen. = Gracias de antemano por la ayuda.
  > Takk på forhånd = gracias de antemano | for hjelpen = por la ayuda
- Med vennlig hilsen. = Atentamente.
  > Med vennlig hilsen = atentamente
Q ¿Qué significa «Jeg lurer på» en este correo?
+ Quisiera saber :: Es una manera cortés de introducir una pregunta.
- Estoy perdido/a :: «Lurer» aquí no significa estar perdido.
- Lo sé con seguridad :: La expresión presenta una pregunta indirecta.
Q ¿Qué significa «Takk på forhånd»?
+ Gracias de antemano :: «På forhånd» significa de antemano.
- Gracias por responder :: No dice que ya haya recibido una respuesta.
- Gracias por el plazo :: «Frist» significa plazo.
R Jeg håper å få en tilbakemelding innen fredag. :: Traduce la frase.
+ Espero recibir una respuesta antes del viernes. :: «Innen fredag» indica que sea antes del viernes.
- Espero enviar la respuesta el viernes. :: La frase espera recibirla, no enviarla.
- La fecha límite es el próximo viernes. :: No se informa una fecha límite concreta.
H Jeg lurer på når kurset ___. :: Completa «empieza».
+ begynner :: «Begynner» significa empieza.
- sender :: Significa envía.
- håper :: Significa espero.
H Jeg håper å få en tilbakemelding ___ fredag. :: Completa «antes del».
+ innen :: «Innen fredag» significa antes del viernes.
- på forhånd :: Significa de antemano.
- snarest :: Significa lo antes posible.
A Kan dere sende meg opplysninger om timeplanen? :: ¿Qué solicita la persona?
+ Información sobre el horario. :: «Opplysninger om timeplanen» significa información sobre el horario.
- Una cita con el médico. :: No se menciona una cita médica.
- Que cambien la fecha límite. :: No se pide cambiar ningún plazo.
O Med vennlig hilsen. :: Atentamente. :: Es una fórmula habitual de despedida en un correo.
X Escribe en noruego: «de antemano» :: på forhånd :: «Takk på forhånd» significa gracias de antemano.
