Q ¿Qué es un «valgløfte»?

- La oposición forma la mayoría antes de votar. :: No es lo que dice.

+ valglokale :: Es el lugar donde se deposita el voto.
- partiprogram :: Es el programa de un partido.
- opposisjon :: Es la oposición.
H Etter valget kan partiene ___ om samarbeid. :: Completa «negociar».
+ forhandle :: «Forhandle om» significa negociar.
- stemme :: Significa votar.
- påvirke :: Significa influir.

+ Que los partidos negocien una coalición. :: «Forhandle om» significa negociar algo.
- Que el tribunal cambie los resultados. :: No se menciona un tribunal.
- Que cada votante represente a un partido. :: La pregunta trata de negociaciones.
O Flere partier kan danne en koalisjon etter valget. :: Varios partidos pueden formar una coalición después de las elecciones. :: «Etter valget» sitúa la acción en el tiempo.

+ Minoría :: Es el grupo que tiene menos representantes que la mayoría.
- Mayoría :: Eso es «flertall».
- Promesa electoral :: Eso es «valgløfte».

  > avveiningen = la valoración | målbar og langsiktig = medible y a largo plazo
Q ¿Qué es una «skattelette»?
+ Una reducción de impuestos :: Disminuye la cantidad que se paga en impuestos.
- Una subvención municipal :: Eso es «tilskudd».
- Una evaluación de consecuencias :: Eso es «konsekvensutredning».
R En satsing kan koste mye på kort sikt, men gi et fellesgode på lang sikt. :: Traduce la frase.
+ Una inversión prioritaria puede costar mucho a corto plazo, pero ofrecer un bien común a largo plazo. :: Contrasta el coste inmediato con el beneficio posterior.
- Una inversión es siempre gratuita y no tiene efectos comunes. :: La frase menciona un coste y un posible beneficio.
- Un bien común solo se puede financiar a corto plazo. :: No es lo que dice.
H En ___ kan vise kostnadene ved tiltaket. :: Completa «evaluación de consecuencias».
+ konsekvensutredning :: Examina los efectos previstos de una propuesta.
- skattelette :: Significa reducción de impuestos.
- utgift :: Significa gasto.
A Hvilken løsning er gjennomførbar innenfor kommunebudsjettet? :: ¿Qué pregunta el asesor?
+ Qué solución puede realizarse dentro del presupuesto municipal. :: «Gjennomførbar» significa viable.
- Qué impuesto se ha pagado el año pasado. :: La pregunta trata de una solución posible.
- Qué persona puede votar en el municipio. :: No pregunta quién vota.
O Tiltaket kan være kostnadskrevende, men gjennomførbart. :: La medida puede ser costosa, pero viable. :: «Men» introduce un contraste.
X Escribe en noruego: «a largo plazo» :: langsiktig :: También se usa «på lang sikt».
Q ¿Qué es una «avveining»?
+ Una valoración que sopesa ventajas y costes :: Ayuda a comparar los efectos de distintas opciones.
- Una cantidad de impuestos :: Eso se expresa con «skatteinntekt».
- Un partido de oposición :: Eso es «opposisjon».

Q ¿Qué significa «omfordeling»?
+ Redistribución :: Se redistribuyen recursos entre grupos.
- Reducción de impuestos :: Eso es «skattelette».
- Bien común :: Eso es «fellesgode».

E Matizar una conclusión :: No hace falta presentar una política como totalmente buena o mala. Puedes señalar sus condiciones, el grupo que beneficia y el coste que implica.

Q ¿Qué introduce «til tross for»?
+ Una concesión :: Presenta una dificultad que no impide lo que se afirma después.
- Una causa confirmada :: Eso puede introducirse con «fordi».
- Una conclusión definitiva :: No es un marcador de conclusión.
R Til tross for kostnaden kan tiltaket gi en positiv fordelingseffekt. :: Traduce la frase.
+ A pesar del coste, la medida puede tener un efecto distributivo positivo. :: La concesión presenta un coste y luego un posible beneficio.
- Debido al coste, la medida no tiene ningún efecto. :: La frase afirma que puede tener un efecto positivo.
- La distribución positiva aumenta el coste automáticamente. :: No dice eso.
H ___ kan manglende tiltak føre til større forskjeller. :: Completa «al contrario».
+ Tvert imot :: Introduce una idea contraria.
- Til tross for :: Significa a pesar de.
- På kort sikt :: Significa a corto plazo.

- underbygge :: Significa respaldar con pruebas.
- prioritere :: Significa priorizar.

O En viktig betingelse er at tilbudet er tilgjengelig for alle. :: Una condición importante es que el servicio esté disponible para todos. :: «At» introduce la explicación de la condición.
