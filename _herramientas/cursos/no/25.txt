

@ 25 | Avsluttende prøve | Examen final de A1
I Este es el examen final del nivel A1. Cada pregunta indica qué capítulo repasar si la respuesta no te sale.
E Examen final de A1 :: Veinticinco preguntas sobre los diez capítulos. Si aciertas veinte o más, tienes una buena base para seguir aprendiendo; este repaso no sustituye una certificación oficial. :: Todas las preguntas señalan su capítulo para que puedas volver a la lección correspondiente.
w Cap = capítulo (marcador del examen) | KAP
H Cap. 1. Jeg ___ Nora. :: Presentarte
+ heter :: «Jeg heter Nora» significa «Me llamo Nora».
- er :: «Er» significa soy o estoy.
- bor :: «Bor» significa vivo o vive.
Q Cap. 1. ¿Qué significa «ha det»?
+ Adiós :: Es una despedida.
- Gracias :: «Takk» significa gracias.
- Buenos días :: «God dag» significa buen día.
Q Cap. 2. ¿Qué significa «Jeg kommer fra Spania»?
+ Vengo de España. :: «Kommer fra» indica procedencia.
- Vivo en España. :: «Bor i» significa vivo en.
- Hablo español. :: «Snakker spansk» significa hablo español.
H Cap. 2. Jeg snakker ___. :: Completa «inglés».
+ engelsk :: «Jeg snakker engelsk» significa hablo inglés.
- spansk :: Significa español.
- fransk :: Significa francés.
H Cap. 3. Jeg er ___ år gammel. :: Completa con el número 30.
+ tretti :: «Tretti» significa treinta.
- tretten :: Significa trece.
- tolv :: Significa doce.
X Cap. 3. Escribe en noruego: «hermana» :: søster :: «Søster» significa hermana.
Q Cap. 4. ¿Qué significa «soverom»?
+ Dormitorio :: «Soverom» es la habitación donde se duerme.
- Cocina :: «Kjøkken» significa cocina.
- Salón :: «Stue» significa salón.
H Cap. 4. Boka ligger ___ bordet. :: Completa para decir «debajo de la mesa».
+ under :: «Under bordet» significa debajo de la mesa.
- over :: «Over» significa encima de o por encima de.
- mellom :: «Mellom» significa entre.
Q Cap. 5. ¿Qué significa «om morgenen»?
+ Por la mañana :: Es una expresión para la mañana.
- Por la tarde-noche :: «Om kvelden» significa por la noche.
- Por la tarde :: «Ettermiddag» significa tarde.
H Cap. 5. Kurset ___ klokka ni. :: Completa «empieza».
+ begynner :: «Kurset begynner» significa el curso empieza.
- slutter :: Significa termina.
- jobber :: Significa trabaja.
R Cap. 6. Kan jeg få et glass vann? :: Traduce la petición.
+ ¿Me puede poner un vaso de agua? :: «Kan jeg få» sirve para pedir algo con cortesía.
- ¿Puedo pagar un vaso de agua? :: «Betale» significa pagar.
- ¿Puedo ver el menú? :: «Se menyen» significa ver el menú.
Q Cap. 6. ¿Qué significa «uten sukker»?
+ Sin azúcar :: «Uten» significa sin.
- Con azúcar :: «Med» significa con.
- Mucha azúcar :: «Mye» significa mucho.
Q Cap. 7. ¿Qué significa «billig»?
+ Barato/a :: «Billig» se usa para algo que cuesta poco.
- Caro/a :: «Dyr» significa caro/a.
- Descuento :: «Rabatt» significa descuento.
H Cap. 7. Den ___ tre hundre kroner. :: Completa «cuesta».
+ koster :: «Koster» significa cuesta.
- trenger :: Significa necesita.
- bruker :: Significa usa o lleva puesto.
R Cap. 8. Gå rett fram til veikrysset. :: Traduce la indicación.
+ Sigue recto hasta el cruce. :: «Rett fram» significa todo recto.
- Gira a la izquierda en la parada. :: La frase no indica girar a la izquierda.
- Bájate del tren en la estación. :: La frase habla de seguir recto hasta un cruce.
Q Cap. 8. ¿Qué significa «neste stopp»?
+ La siguiente parada :: «Neste» significa siguiente y «stopp», parada.
- El billete de autobús :: «Billett» significa billete.
- La ruta del autobús :: «Bussrute» significa ruta u horario.
R Cap. 9. Jeg liker å høre på musikk. :: Traduce la frase.
+ Me gusta escuchar música. :: «Liker å» va seguido del infinitivo.
- Me gusta tocar la guitarra. :: Eso sería «Jeg liker å spille gitar».
- Me gusta bailar y nadar. :: Eso sería «Jeg liker å danse og svømme».
Q Cap. 9. ¿Qué significa «om vinteren»?
+ En invierno, habitualmente :: «Om» se usa con una estación que se repite.
- Este invierno :: Para una estación concreta se usa «i vinter».
- En enero :: Enero es «januar».
Q Cap. 9. ¿Cómo se escribe «el cuatro de mayo»?
+ 4. mai :: El día se escribe antes del mes y el mes va en minúscula.
- 4. juni :: Eso significa el cuatro de junio.
- mai 4. :: El orden habitual es día y después mes.
Q Cap. 10. ¿Qué palabra significa «pasaporte»?
+ pass :: «Pass» significa pasaporte.
- billett :: «Billett» significa billete.
- bagasje :: «Bagasje» significa equipaje.
H Cap. 10. Jeg har vondt i ___. :: Completa «la cabeza».
+ hodet :: «I hodet» significa en la cabeza.
- magen :: «I magen» significa en el estómago.
- halsen :: «I halsen» significa en la garganta.
Q Cap. 10. ¿Qué es una «legevakt»?
+ Un centro médico de urgencias :: Atiende consultas médicas urgentes fuera del horario habitual.
- Una farmacia :: «Apotek» significa farmacia.
- Una recepción de hotel :: «Resepsjon» significa recepción.
R Cap. 10. Hvor skal dere overnatte? :: Traduce la pregunta.
+ ¿Dónde van a pasar la noche? :: «Overnatte» significa pasar la noche.
- ¿Qué van a comprar en la estación? :: La pregunta pide dónde pasarán la noche.
- ¿Cuándo sale el avión? :: Eso sería «Når er avreisen?».
A Cap. 10. Jeg er forkjølet og hoster litt. :: ¿Qué síntomas tiene la persona?
+ Está resfriada y tose un poco. :: «Forkjølet» significa resfriado/a y «hoster», tose.
- Tiene fiebre y dolor de cabeza. :: La frase no menciona fiebre ni dolor.
- Tiene sueño y prepara una maleta. :: La frase no habla de sueño ni de equipaje.
O Cap. 10. Jeg skal reise til Spania i dag. :: Voy a viajar a España hoy :: «Skal» más infinitivo expresa un plan.
