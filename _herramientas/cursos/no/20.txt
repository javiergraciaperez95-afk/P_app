@ 20 | Rutetider | Horarios de transporte
E Leer horarios :: **Rutetabell** es el horario publicado de una ruta; **avgang** es la salida y **ankomst**, la llegada. :: **Reisetid** indica cuánto dura el viaje. En noruego, la hora suele expresarse con **klokka** seguida de la hora: **klokka ni** («a las nueve»).
W rutetabell = horario de una ruta | RÜ-te-ta-bel
W rutetabellen = el horario de una ruta | RÜ-te-ta-bel-en
W holdeplass = parada de transporte | JÓL-de-plas
W holdeplassen = la parada de transporte | JÓL-de-plas-en
W avgang = salida de transporte | ÁV-gang
W avgangen = la salida de transporte | ÁV-gang-en
W avgangstid = hora de salida | ÁV-gang-stid
W ankomststid = hora de llegada | AN-komst-stid
W reisetid = duración del viaje | RÁI-se-tid
W reisetiden = la duración del viaje | RÁI-se-tí-den
W reisen = el viaje | RÁI-sen
W minutter = minutos | mi-NÜ-ter
W framme = llegado/a; en el destino | FRAM-me
W lang = largo/a (duración o distancia) | LANG
V Vocabulario: horarios y duración
D Consultar el horario
Nora: Har du rutetabellen? = ¿Tienes el horario?
  > Har du = tienes | rutetabellen = el horario
Ali: Ja, her er den. = Sí, aquí está.
  > Ja, her er den = sí, aquí está
Nora: Når er neste avgang? = ¿Cuándo es la próxima salida?
  > Når er = cuándo es | neste avgang = la próxima salida
Ali: Avgangen er klokka ni. = La salida es a las nueve.
  > Avgangen = la salida | er klokka ni = es a las nueve
Nora: Hvor lang er reisetiden? = ¿Cuánto dura el viaje?
  > Hvor lang = cuánto dura | er reisetiden = es la duración del viaje
Ali: Reisen tar tjue minutter. = El viaje dura veinte minutos.
  > Reisen tar = el viaje dura | tjue minutter = veinte minutos
Nora: Når er toget framme? = ¿Cuándo llega el tren?
  > Når er = cuándo está | toget framme = el tren llegado
Ali: Toget er framme klokka ti. = El tren llega a las diez.
  > Toget er framme = el tren llega | klokka ti = a las diez
Q ¿Qué es una «rutetabell»?
+ El horario de una ruta. :: Muestra las horas de salida y llegada.
- Un billete mensual. :: Eso es un tipo de «billett».
- Una parada de autobús. :: Eso es «holdeplass».
R Reisen tar tjue minutter. :: Traduce la frase.
+ El viaje dura veinte minutos. :: «Reisen tar» expresa la duración.
- El tren sale dentro de veinte minutos. :: La frase habla de duración, no de salida.
- La llegada es a las diez. :: Eso sería «Ankomst er klokka ti».
H Neste ___ er klokka ni. :: Completa «salida».
+ avgang :: «Avgang» es una salida de transporte.
- ankomst :: Significa llegada.
- holdeplass :: Significa parada.
A Toget er framme klokka ti. :: ¿A qué hora llega el tren?
+ A las diez. :: «Klokka ti» significa a las diez.
- A las nueve. :: Eso es «klokka ni».
- En veinte minutos. :: Eso es «tjue minutter».
O Hvor lang er reisetiden? :: ¿Cuánto dura el viaje? :: «Hvor lang» pregunta aquí por la duración.
Q ¿Qué indica «ankomststid»?
+ La hora de llegada. :: «Ankomst» significa llegada.
- La hora de salida. :: Eso es «avgangstid».
- La duración total del viaje. :: Eso es «reisetid».
H Reisen tar tjue ___. :: Completa «minutos».
+ minutter :: Es el plural de «minutt».
- klokka :: Significa el reloj o la hora.
- holdeplass :: Significa parada.
X Escribe «el viaje dura veinte minutos» :: Reisen tar tjue minutter :: «Reisen» es el viaje y «tar» expresa cuánto dura.

@ 20 | Forsinkelser | Retrasos
E Avisos de retraso :: **Forsinket** significa «con retraso» y **avlyst**, «cancelado/a». **I tide** significa «a tiempo». :: **På grunn av** introduce la causa: **forsinket på grunn av trafikken** («con retraso debido al tráfico»). La forma definida **trafikken** suele traducirse como «el tráfico».
W forsinket = con retraso | for-SHÍN-ket
W forsinkelse = retraso | for-SHÍN-el-se
W forsinkelsen = el retraso | for-SHÍN-el-sen
W i tide = a tiempo | i TÍ-de
W på grunn av = debido a; por causa de | po GRÜN av
W trafikk = tráfico | TRA-fik
W trafikken = el tráfico | TRA-fik-en
W snøen = la nieve | SNÖ-en
W avlyst = cancelado/a | AV-lüst
W senere = más tarde | SÉ-ne-re
W kommer senere = llega más tarde | KÓ-mer SÉ-ne-re
W går som vanlig = funciona como siempre; circula con normalidad | GOR som va-NLÍ
W hvorfor = por qué | VOR-for
V Vocabulario: retrasos y cambios
D Un aviso en la parada
Lina: Er bussen forsinket? = ¿Tiene retraso el autobús?
  > Er bussen = ¿está el autobús? | forsinket = con retraso
Erik: Ja, det er en forsinkelse på grunn av trafikken. = Sí, hay un retraso debido al tráfico.
  > det er en forsinkelse = hay un retraso | på grunn av trafikken = debido al tráfico
Lina: Er toget også forsinket? = ¿También tiene retraso el tren?
  > Er toget = ¿está el tren? | også forsinket = también con retraso
Erik: Nei, toget går som vanlig. = No, el tren circula con normalidad.
  > toget går = el tren circula | som vanlig = con normalidad
Lina: Er bussen i tide nå? = ¿Llega el autobús a tiempo ahora?
  > Er bussen = ¿está el autobús? | i tide nå = a tiempo ahora
Erik: Nei, den kommer senere. = No, llega más tarde.
  > den kommer = llega | senere = más tarde
Lina: Hvorfor er toget avlyst? = ¿Por qué se ha cancelado el tren?
  > Hvorfor = por qué | er toget = está el tren | avlyst = cancelado
Erik: På grunn av snøen. = Debido a la nieve.
  > På grunn av = debido a | snøen = la nieve
Q ¿Qué significa «i tide»?
+ A tiempo. :: Indica que algo ocurre a la hora prevista.
- Con retraso. :: Eso es «forsinket».
- Cancelado. :: Eso es «avlyst».
R Toget går som vanlig. :: Traduce la frase.
+ El tren circula con normalidad. :: «Som vanlig» significa como siempre.
- El tren está cancelado. :: Eso es «Toget er avlyst».
- El tren llega más tarde. :: Eso es «Toget kommer senere».
H Bussen er ___ på grunn av trafikken. :: Completa «con retraso».
+ forsinket :: «Forsinket» significa con retraso.
- avlyst :: Significa cancelado/a.
- senere :: Significa más tarde.
A På grunn av snøen. :: ¿Cuál es la causa?
+ La nieve. :: «Snøen» significa la nieve.
- El tráfico. :: Eso es «trafikken».
- Un retraso. :: Eso es «forsinkelse».
O Bussen kommer senere :: El autobús llega más tarde :: «Senere» significa más tarde.
Q ¿Qué significa «avlyst»?
+ Cancelado/a. :: Se usa cuando un servicio no se realiza.
- A tiempo. :: Eso es «i tide».
- En la parada. :: Eso es «på holdeplassen».
H Toget er ___ på grunn av snøen. :: Completa «cancelado».
+ avlyst :: Es un servicio cancelado.
- forsinket :: Significa con retraso.
- vanlig :: Significa habitual.
X Escribe «El tren circula con normalidad» :: Toget går som vanlig :: «Som vanlig» significa con normalidad o como siempre.

@ 20 | Bytte transport | Cambiar de transporte
E Subir, bajar y cambiar :: **Gå på** es subir a un vehículo y **gå av**, bajarse. **Bytte tog** significa cambiar de tren; **bytte buss**, cambiar de autobús. :: **Plattform** es el andén; **spor** es la vía. En las estaciones, el número de vía indica desde dónde sale el tren.
W plattform = andén | PLAT-form
W plattformen = el andén | PLAT-for-men
W spor = vía de tren | SPUR
W sporet = la vía de tren | SPÚ-ret
W retning = dirección; sentido | RET-ning
W i retning av = en dirección a | i RET-ning av
W bytte tog = cambiar de tren | BÜ-te TUG
W bytte buss = cambiar de autobús | BÜ-te BUS
W gå av = bajarse | GO AV
W går av = se baja; se bajan | GOR AV
W gå på = subir a un transporte | GO PO
W går på = sube a un transporte | GOR PO
W videre = más allá; luego | VÍ-de-re
W spor tre = vía tres | SPUR TRE
V Vocabulario: andenes y transbordos
D Cambiar de tren a autobús
Nora: Går toget til sentrum? = ¿Va el tren al centro?
  > Går toget = va el tren | til sentrum = al centro
Ali: Ja, men du må bytte tog på stasjonen. = Sí, pero tienes que cambiar de tren en la estación.
  > du må = tienes que | bytte tog = cambiar de tren | på stasjonen = en la estación
Nora: Hvilken plattform går toget fra? = ¿De qué andén sale el tren?
  > Hvilken plattform = qué andén | går toget fra = sale el tren
Ali: Plattform tre. = Andén tres.
  > Plattform tre = andén tres
Nora: Hvor går jeg av? = ¿Dónde me bajo?
  > Hvor går jeg av = dónde me bajo
Ali: Gå av på neste stopp, og gå på buss fire der. = Bájate en la próxima parada y sube allí al autobús cuatro.
  > Gå av = bájate | på neste stopp = en la próxima parada | gå på buss fire = sube al autobús cuatro | der = allí
Nora: Går bussen videre til sentrum? = ¿Sigue el autobús hasta el centro?
  > Går bussen videre = sigue el autobús | til sentrum = hasta el centro
Ali: Ja, den går i retning av sentrum. = Sí, va en dirección al centro.
  > den går = va | i retning av sentrum = en dirección al centro
Q ¿Qué significa «gå av»?
+ Bajarse de un transporte. :: Se usa para dejar el autobús o el tren.
- Subir a un transporte. :: Eso es «gå på».
- Cambiar de tren. :: Eso es «bytte tog».
R Hvilken plattform går toget fra? :: Traduce la pregunta.
+ ¿De qué andén sale el tren? :: «Plattform» significa andén.
- ¿En qué vía llega el autobús? :: «Toget» es el tren y «fra» indica origen.
- ¿A qué hora sale el autobús? :: La pregunta trata del andén.
H Gå ___ på neste stopp. :: Completa «bájate».
+ av :: «Gå av» significa bajarse.
- på :: «Gå på» significa subir.
- fra :: «Fra» significa desde.
A Gå på buss fire der. :: ¿Qué debe hacer Nora?
+ Subir allí al autobús cuatro. :: «Gå på» significa subir a un transporte.
- Bajarse allí del tren cuatro. :: No menciona bajarse del tren.
- Cambiar al andén cuatro. :: «Buss fire» significa autobús cuatro.
O Ja, den går i retning av sentrum :: Sí, va en dirección al centro :: «I retning av» significa en dirección a.
Q ¿Qué significa «plattform»?
+ Andén. :: Es el lugar donde se espera el tren.
- Ruta de autobús. :: Eso es «bussrute».
- Retraso. :: Eso es «forsinkelse».
H Du må ___ tog på stasjonen. :: Completa «cambiar de».
+ bytte :: «Bytte tog» significa cambiar de tren.
- gå av :: Significa bajarse.
- går på :: Significa sube a un transporte.
X Escribe «cambiar de autobús» :: bytte buss :: «Bytte buss» significa pasar de un autobús a otro.
