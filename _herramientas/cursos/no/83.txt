@ 83 | Avtaler i arbeidslivet | Acuerdos en la vida laboral

+ Participación de los empleados en las decisiones :: Se escucha a las personas afectadas.
- Pago de horas extra :: Eso es «overtidsbetaling».
- Protección frente a la lluvia :: No es el significado de la palabra.

+ møtet :: Es la forma definida de «møte».

- stillingsprosenten :: Es el porcentaje de jornada.

+ La mediación :: «Mekling» facilita el diálogo.
- La protección frente al despido :: No es lo que se plantea.
- El porcentaje de jornada :: Es una condición laboral.
O Tariffavtalen gir partene en ramme for forhandlingene. :: El convenio colectivo ofrece a las partes un marco para negociar. :: «Gir» significa da u ofrece.
Q ¿Qué significa «avspasering»?
+ Compensación de horas extra con tiempo libre :: Se recibe tiempo libre en lugar de pago.
- Reunión para consultar al empleador :: Eso es «drøftingsmøte».
- Una modificación del contrato :: Eso puede ser «endringsforslag».
R Medbestemmelse betyr at de ansatte blir hørt. :: Traduce la frase.
+ La participación en decisiones significa que se escucha a los empleados. :: «Blir hørt» es una pasiva.
- Los empleados deben escuchar a todos los clientes. :: No es lo que afirma.
- El convenio colectivo significa que no hay consultas. :: La frase dice lo contrario.

Q ¿Qué protege el «oppsigelsesvern»?
+ A la persona trabajadora frente al despido :: Establece protección relacionada con la terminación del empleo.
- El acceso a un servicio digital :: Eso no es una norma laboral.
- La confidencialidad de una noticia :: No es el significado.

- Informal y sin documentación. :: No se dice eso.

Q ¿Qué significa «gjengjeldelsesforbud»?

- Informe de riesgos psicosociales :: No es esa palabra.
R Arbeidsmiljøutvalget ber om en risikovurdering. :: Traduce la frase.
+ El comité de entorno laboral solicita una evaluación de riesgos. :: «Ber om» significa solicita.

- El delegado de seguridad presenta una apelación. :: No es la frase.

Q ¿Qué prohíbe el «gjengjeldelsesforbud»?
+ Tomar represalias contra quien informa :: Protege a quien comunica un problema.
- Registrar una reunión :: Eso se hace con un referat.
- Consultar a los trabajadores :: La consulta no está prohibida.

E Presise formuleringer :: Skill mellom et forslag, en beslutning og en innsigelse. Hvis deltakerne er uenige, kan referatet gjengi uenigheten uten å framstille den som en avgjørelse.

  > møtelederen = el moderador | beslutningsgrunnlaget = la base para decidir

Q ¿Qué diferencia «referat» de «protokoll»?
+ El acta resume; el protocolo documenta decisiones formales :: La protokoll registra vedtak.
- El acta fija siempre una sanción :: No es su función general.
- El protocolo contiene solo opiniones individuales :: También registra decisiones.
R Referatet skiller mellom forslag og vedtak. :: Traduce la frase.
+ El acta distingue entre propuestas y resoluciones. :: «Skille mellom» es distinguir entre.
- La resolución distingue entre reuniones y horarios. :: No es lo que dice.
- El moderador elimina todas las propuestas. :: La frase no dice eso.

A Hva blir journalført sammen med protokollen? :: ¿Qué se registra junto con el acta formal?
+ La propuesta documentada :: Así lo dice el texto.
- La lista de salarios de todos los participantes :: No se menciona.
- Una resolución que aún no se ha escrito :: No es la frase.
O Møtelederen presiserer at beslutningen ikke var enstemmig. :: El moderador precisa que la decisión no fue unánime. :: «Presisere» añade precisión.
Q ¿Qué significa «etterlevelse»?
+ Cumplimiento de una norma u orden :: Describe si algo se ha respetado.
- Derecho a objetar :: Eso es «innsigelse».
- Un plazo para presentar una consulta :: No es el significado.
R Saksframlegget journalføres sammen med protokollen. :: Traduce la frase.
+ La propuesta documentada se registra junto con el acta formal. :: «Journalføre» es registrar en un expediente.
- La propuesta cancela el acta formal. :: No es lo que dice.
- El moderador rechaza una consulta pública. :: No se menciona.

Q ¿Qué significa «etterlevelse»?
+ Cumplimiento de una norma u orden :: Indica si se ha respetado.
- Una objeción a una propuesta :: Eso es «innsigelse».
- Una reunión de consulta :: Eso es «drøftingsmøte».
