@ 77 | Høyere utdanning | Estudios superiores
E Preguntas indirectas formales :: **Hvorvidt** introduce una pregunta indirecta equivalente a «si» o «hasta qué punto»: **Jeg undersøker hvorvidt studiet passer**. Dentro de la subordinada, el sujeto va antes del verbo. :: **Læringsutbytte** es lo que se espera que el alumnado sepa hacer al terminar un curso.

W pensumliste = lista de lecturas y contenidos | PÉN-sum-lis-te

V Vocabulario: universidad y aprendizaje
D Elegir un programa
Student: Jeg vurderer høyere utdanning neste år. = Estoy considerando estudiar en la universidad el año que viene.
  > vurderer høyere utdanning = considera estudiar en la universidad | neste år = el año que viene
Rådgiver: Har du lest pensum og pensumlisten? = ¿Has leído el temario y la lista de lecturas?
  > lest pensum = leído el temario | pensumlisten = la lista de lecturas
Student: Jeg vil vite hvorvidt studieprogrammet er yrkesrettet. = Quiero saber si el programa de estudios está orientado a una profesión.
  > hvorvidt = si (en pregunta indirecta) | studieprogrammet er yrkesrettet = el programa está orientado a una profesión
Rådgiver: Studiet har forskningsbasert teori og praktiske arbeidskrav. = El programa tiene teoría basada en investigación y requisitos prácticos.
  > forskningsbasert teori = teoría basada en investigación | praktiske arbeidskrav = requisitos prácticos
Student: Hvilke undervisningsformer bruker dere? = ¿Qué modalidades de enseñanza utilizan?
  > undervisningsformer = modalidades de enseñanza | bruker dere = utilizan
Rådgiver: Vi har seminar og selvstendig fordypning. = Tenemos seminarios y profundización autónoma.
  > seminar = seminario | selvstendig fordypning = profundización autónoma
Student: Hvordan følger jeg studieprogresjonen? = ¿Cómo sigo mi progreso académico?
  > følger jeg = sigo | studieprogresjonen = el progreso académico
Rådgiver: Du kan drøfte arbeidskravene med en medstudent. = Puedes analizar los requisitos con un compañero de estudios.
  > drøfte arbeidskravene = analizar los requisitos | med en medstudent = con un compañero de estudios
Q ¿Qué es «læringsutbytte»?
+ Un resultado de aprendizaje :: Describe lo que se espera que el alumnado pueda hacer.
- Una lista de lecturas :: Eso es «pensumliste».
- Un compañero de estudios :: Eso es «medstudent».
R Jeg vil vite hvorvidt studieprogrammet er yrkesrettet. :: Traduce la frase.
+ Quiero saber si el programa de estudios está orientado a una profesión. :: «Hvorvidt» introduce una pregunta indirecta.
- Quiero saber quién diseñó la lista de lecturas. :: La frase pregunta si el programa es profesional.
- Quiero estudiar una profesión el año pasado. :: La frase no está en pasado.
H Studiet har forskningsbasert ___. :: Completa «teoría».
+ teori :: «Teori» significa teoría.
- pensum :: Significa temario.
- seminar :: Significa seminario.
H Du kan ___ arbeidskravene med en medstudent. :: Completa «analizar y debatir».
+ drøfte :: «Drøfte» es analizar distintas ideas.
- hvile :: Significa descansar.
- lindre :: Significa aliviar.
A Hvilke undervisningsformer bruker dere? :: ¿Qué pregunta el estudiante?
+ Qué modalidades de enseñanza utilizan. :: «Undervisningsformer» son modalidades de enseñanza.
- Qué temas de salud se investigan. :: No pregunta por la investigación.
- Cuántos requisitos ya ha completado. :: No pregunta por un número.
O Jeg undersøker hvorvidt studiet passer for meg. :: Investigo si el programa me conviene. :: En la pregunta indirecta, «studiet» precede al verbo.
X Escribe en noruego: «compañero/a de estudios» :: medstudent :: «En medstudent» estudia contigo.
Q ¿Qué expresa «yrkesrettet»?
+ Orientado/a a una profesión :: Describe un programa relacionado con una salida profesional.
- Basado/a en una investigación :: Eso es «forskningsbasert».
- De larga duración :: Eso es «langvarig».

@ 77 | Kildebruk og akademisk redelighet | Fuentes e integridad académica
E Citar y reformular :: **Et sitat** reproduce palabras exactas; **en parafrase** expresa la idea con una formulación propia. En ambos casos se indica la fuente. :: **Etterprøvbar** significa que otras personas pueden comprobar la información.
E Evitar el plagio :: Una **kildehenvisning** señala de dónde procede una idea. Presentar palabras o ideas ajenas como propias puede considerarse **plagiat**.

w parafrasen = la paráfrasis | pa-ra-FRÁ-sen
W sitat = cita textual | si-TÁT
w sitatet = la cita textual | si-TÁ-tet
W ordrett = literalmente; palabra por palabra | ÓR-ret
W kildehenvisning = cita de fuente; referencia | KÍL-de-jén-vis-ning
w kildehenvisningen = la cita de fuente | KÍL-de-jén-vis-ning-en
W referanseliste = bibliografía; lista de referencias | re-fe-RÁN-se-lis-te
W plagiat = plagio | pla-gi-ÁT
W etterprøvbar = verificable | É-ter-pröv-bar
W formulering = formulación | for-mu-LÉ-ring
w formuleringer = formulaciones | for-mu-LÉ-ring-er
W omskrive = reformular; reescribir | ÓM-skri-ve
w omskriver = reformula; reescribe | ÓM-skri-ver

w mediesamfunnet = la sociedad de los medios | MÉ-di-e-sam-fun-net

V Vocabulario: fuentes y escritura académica
D Revisar una tarea
Student: Jeg skriver en fagtekst om mediesamfunnet. = Estoy escribiendo un texto académico sobre la sociedad de los medios.
  > fagtekst = texto académico | mediesamfunnet = la sociedad de los medios
Lærer: Husk kildehenvisning og referanseliste. = Recuerda incluir citas de fuentes y bibliografía.
  > kildehenvisning = cita de fuente | referanseliste = bibliografía
Student: Kan jeg gjengi ideen med en egen formulering? = ¿Puedo transmitir la idea con una formulación propia?
  > gjengi ideen = transmitir la idea | en egen formulering = una formulación propia
Lærer: Ja, men parafrasen må være presis og etterprøvbar. = Sí, pero la paráfrasis debe ser precisa y verificable.
  > parafrasen = la paráfrasis | presis og etterprøvbar = precisa y verificable
Student: Hva gjør jeg med et direkte sitat? = ¿Qué hago con una cita textual directa?
  > direkte sitat = cita textual directa
Lærer: Gjengi det ordrett, og vis hvor det kommer fra. = Reprodúcelo literalmente e indica de dónde procede.
  > gjengi det ordrett = reproducirlo literalmente | hvor det kommer fra = de dónde procede
Student: Da skiller jeg mellom egne formuleringer og sitater. = Entonces distinguiré entre mis propias formulaciones y las citas.
  > skiller jeg mellom = distingo entre | egne formuleringer og sitater = formulaciones propias y citas
Lærer: Nettopp. Uten kildebruk kan teksten framstå som plagiat. = Exacto. Sin uso adecuado de fuentes, el texto puede parecer un plagio.
  > Uten kildebruk = sin uso de fuentes | framstå som plagiat = parecer un plagio
Q ¿Qué caracteriza a una paráfrasis?
+ Expresa una idea con una formulación propia :: Aun así, se indica de dónde procede la idea.
- Reproduce necesariamente palabras exactas :: Eso describe una cita textual.
- No necesita fuente ni referencia :: También hay que indicar la fuente.
R Gjengi sitatet ordrett, og vis hvor det kommer fra. :: Traduce la frase.
+ Reproduce la cita literalmente e indica de dónde procede. :: «Ordrett» significa literalmente.
- Resume la cita sin mencionar su origen. :: La frase pide reproducirla y mostrar la fuente.
- Cambia la fuente para que parezca propia. :: Eso sería un uso deshonesto.
H En parafrase må være presis og ___. :: Completa «verificable».
+ etterprøvbar :: Otras personas pueden comprobarla.
- langvarig :: Significa de larga duración.
- helsefremmende :: Significa beneficioso para la salud.
H Uten en ___ kan teksten framstå som plagiat. :: Completa «cita de fuente».
+ kildehenvisning :: Señala de dónde procede la idea.
- pensumliste :: Es una lista de lecturas.
- selvfølelse :: Significa autoestima.
A Husk kildehenvisning og referanseliste. :: ¿Qué debe recordar el estudiante?
+ Añadir citas de fuentes y bibliografía. :: Son los dos elementos mencionados.
- Reproducir todas las fuentes literalmente. :: La frase no indica eso.
- Entregar una paráfrasis sin revisar. :: No se dice eso.
O I en fagtekst må vi skille mellom sitater og egne formuleringer. :: En un texto académico distinguimos entre citas y formulaciones propias. :: «Skille mellom» introduce dos elementos diferenciados.
X Escribe en noruego: «plagio» :: plagiat :: «Plagiat» es presentar trabajo ajeno como propio.
Q ¿Qué indica «etterprøvbar»?
+ Que la información puede comprobarse :: Es una cualidad importante de una afirmación académica.
- Que la idea se ha copiado palabra por palabra :: Eso es «ordrett».
- Que el contenido se ha omitido :: No expresa omisión.

@ 77 | Vurdering og læringsformer | Evaluación y formas de aprendizaje
E Comparar modalidades :: **Mens** puede presentar dos situaciones simultáneas o contrastarlas: **En hjemmeeksamen gir tid, mens en muntlig høring tester spontan forståelse**. :: Los sustantivos compuestos noruegos suelen escribirse juntos: **mappevurdering**, evaluación mediante una carpeta de trabajos.
E Criterios claros :: **Vurderingskriterier** son los criterios con los que se evalúa una tarea. Una modalidad puede favorecer la reflexión y otra medir la respuesta espontánea.

V Vocabulario: evaluación y aprendizaje
D Hva viser vurderingen?
Student: Hvilken vurderingsform passer best til læringsmålet? = ¿Qué modalidad de evaluación se ajusta mejor al objetivo de aprendizaje?
  > vurderingsform = modalidad de evaluación | læringsmålet = el objetivo de aprendizaje
Lærer: En hjemmeeksamen gir tid til fordypning. = Un examen para hacer en casa da tiempo para profundizar.
  > hjemmeeksamen = examen para hacer en casa | gir tid til fordypning = da tiempo para profundizar
Student: Mens en muntlig høring tester spontan forståelse? = ¿Mientras que una prueba oral evalúa la comprensión espontánea?
  > muntlig høring = prueba oral | spontan forståelse = comprensión espontánea
Lærer: Ja, men begge deler bør følge tydelige vurderingskriterier. = Sí, pero ambas modalidades deberían seguir criterios de evaluación claros.
  > begge deler = ambas cosas | tydelige vurderingskriterier = criterios de evaluación claros
Student: Er mappevurdering mer rettferdig? = ¿Es más justa la evaluación mediante trabajos recopilados?
  > mappevurdering = evaluación mediante trabajos recopilados | mer rettferdig = más justa
Lærer: Det avhenger av læringsmålet og innsatsen som blir lagt ned. = Depende del objetivo de aprendizaje y del esfuerzo realizado.
  > læringsmålet = el objetivo de aprendizaje | innsatsen = el esfuerzo | blir lagt ned = se dedica
Student: En god vurdering bør være både forutsigbar og rettferdig. = Una buena evaluación debería ser previsible y justa.
  > forutsigbar og rettferdig = previsible y justa
Q ¿Qué es una «hjemmeeksamen»?
+ Un examen que se hace en casa :: Permite responder desde casa durante el plazo indicado.
- Una prueba oral espontánea :: Eso es «muntlig høring».
- Una lista de lecturas :: Eso es «pensumliste».
R En hjemmeeksamen gir tid til fordypning, mens en muntlig høring tester spontan forståelse. :: Traduce la frase.
+ Un examen para hacer en casa da tiempo para profundizar, mientras que una prueba oral evalúa la comprensión espontánea. :: «Mens» contrasta las modalidades.
- Una prueba oral da tiempo para profundizar, mientras que un examen en casa evalúa la respuesta espontánea. :: La frase asigna cada característica al formato contrario.
- Ambas modalidades evalúan exactamente lo mismo. :: La frase establece un contraste.
H En mappevurdering ___ flere oppgaver. :: Completa «recopila».
+ samler :: «Samle» significa reunir o recopilar.
- skala :: Significa escala.
- høring :: Significa prueba oral de preguntas.
H Et tydelig vurderingskriterium gir en ___. :: Completa «previsible».
+ forutsigbar :: «Forutsigbar» significa previsible.
- læringsmål :: Significa objetivo de aprendizaje.
- innsats :: Significa esfuerzo.
A Er mappevurdering mer rettferdig? :: ¿Qué pregunta el estudiante?
+ Si la evaluación mediante trabajos es más justa. :: «Rettferdig» significa justo/a.
- Si el examen oral ya terminó. :: No pregunta por el momento del examen.
- Si puede cambiar la lista de lecturas. :: No aparece la lista de lecturas.
O Underveisvurdering kan støtte læring før sluttvurderingen. :: La evaluación continua puede apoyar el aprendizaje antes de la evaluación final. :: Se contraponen el seguimiento durante el curso y la evaluación final.
X Escribe en noruego: «evaluación final» :: sluttvurdering :: «Sluttvurdering» es la evaluación al final del proceso.
Q ¿Qué significa «forutsigbar»?
+ Previsible :: Se puede anticipar cómo se evaluará.
- Verificable :: Eso es «etterprøvbar».
- Beneficioso para la salud :: Eso es «helsefremmende».
