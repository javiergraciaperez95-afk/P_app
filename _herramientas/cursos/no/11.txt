@ 11 | Lyd og uttale | Sonidos y pronunciación
I Hoy empezamos con una clave del noruego: no basta con distinguir los sonidos; también importa cuánto duran.
E Vocales largas y cortas :: En una sílaba tónica, la vocal puede ser larga o corta. Como orientación, una vocal ante una consonante suele ser larga; ante consonante doble o grupo consonántico suele ser corta. Hay excepciones. :: La longitud puede cambiar el significado: **vin** («vino») y **vinn** («gana»). La doble consonante escrita suele señalar una vocal corta.

Q ¿Qué suele indicar una consonante doble después de la vocal?
+ Que la vocal suele ser corta. :: Es una orientación ortográfica frecuente.
- Que la vocal siempre es larga. :: La doble consonante suele señalar lo contrario.
- Que la palabra se escribe en plural. :: La consonante doble no marca plural.
R En kort vokal står foran en dobbel konsonant. :: Traduce la frase.
+ Una vocal corta aparece delante de una consonante doble. :: La frase expresa la pauta general.
- Una vocal larga aparece detrás de una consonante simple. :: Cambia la longitud y la posición.
- Una consonante doble está delante de una vocal larga. :: No es lo que dice la frase.
Q ¿Cuál de estas parejas ilustra una diferencia de longitud vocálica?
+ vin / vinn :: La vocal es larga en «vin» y corta en «vinn».
- hus / bil :: Son palabras distintas, no una pareja mínima de longitud.
- stor / liten :: Son contrarios, no cambia solo la longitud.
H Vi hører ___. :: Completa con «una vocal larga».
+ kort :: «Kort» significa corta.
- bak :: «Bak» significa detrás.
- fremre :: «Fremre» significa anterior.
H En kort vokal står ___ en dobbel konsonant. :: Elige la posición.
+ foran :: «Foran» significa delante de.
- bak :: «Bak» significa detrás de.
- over :: «Over» significa encima de.
A En kort vokal står foran en dobbel konsonant. :: ¿Qué describe la frase?
+ Una vocal corta aparece delante de una consonante doble. :: Coincide con la regla de escritura.
- Una vocal larga aparece detrás de una consonante simple. :: Invierte las dos características.
- Una consonante doble alarga la vocal anterior. :: La doble consonante suele señalar vocal corta.
O Vi lytter etter språklyd og lydlengde. :: Escuchamos los sonidos del habla y su duración. :: «Lytter etter» introduce aquello que escuchamos.

La sílaba tónica destaca frente a las átonas. :: El noruego tiene dos tonos léxicos en muchos dialectos. Q ¿Dónde recae el acento en muchas palabras noruegas?
+ En la primera sílaba. :: Es la pauta general para muchas palabras.
- Siempre en la última sílaba. :: Los préstamos pueden variar, pero no existe esa regla general.
- En todas las sílabas por igual. :: El noruego distingue sílabas tónicas y átonas.
R Et låneord kan ha et annet mønster. :: Traduce la frase.
+ Una palabra prestada puede tener otro patrón. :: «Låneord» es préstamo lingüístico.
- Una palabra compuesta siempre tiene dos tonos. :: No es lo que dice.
- La primera sílaba no lleva nunca acento. :: La frase no afirma eso.
Q ¿Qué afirmación sobre los tonos léxicos es adecuada?
+ Su realización puede variar según el dialecto. :: La melodía no es idéntica en todas las regiones.
- Siempre se escriben con una tilde. :: No se señalan así en la ortografía noruega.
- Solo existen en los préstamos. :: No es esa la distribución.

- svar :: «Svar» significa respuesta.

Usa la ortografía como apoyo y practica primero con un ritmo claro, sin suponer que existe una única pronunciación oral estándar.

Q ¿Qué conviene hacer al principio de una práctica de escucha?
+ Escuchar despacio y después a velocidad normal. :: El diálogo propone esa progresión.
- Aprender una única melodía para todos los dialectos. :: Hay variación regional.
- Ignorar las sílabas átonas. :: También forman parte del habla.

+ ¿Puedo escuchar la grabación una vez más? :: «Én gang til» significa una vez más.
- ¿Puedo borrar la grabación? :: No aparece «borrar».
- ¿Puedo hablar más rápido? :: La pregunta pide escuchar otra vez.

- Porque desaparecen todas las vocales tónicas. :: No.
- Porque cada palabra cambia de significado. :: La reducción no implica eso.
