  > Jeg vil søke om bostøtte = quiero solicitar una ayuda para vivienda | Hvor finner jeg informasjon = dónde encuentro información

  > lese om støtteordningen = leer sobre el programa de ayudas | på kommunens nettside = en la página del municipio

Q ¿Qué significa «bostøtte»?
+ Ayuda para gastos de vivienda :: Es una prestación relacionada con la vivienda.
- Ayuda para pagar estudios :: «Studielån» es un préstamo para estudiar.
- Pago por horas extra :: «Overtidsbetaling» es pago de horas extra.
Q ¿Qué significa «behovsprøvd»?
+ Que se evalúa según las necesidades y los ingresos :: No todas las personas reciben la ayuda automáticamente.
- Que se concede a todas las personas :: La palabra indica que hay una evaluación.
- Que solo se puede solicitar en internet :: No describe el canal de solicitud.

+ Depende de la necesidad y los ingresos. :: «Avhenger av» significa depende de.
- La ayuda se concede hoy. :: La frase no indica cuándo se concede.
- Los ingresos no se pueden declarar. :: No expresa eso.
H Jeg vil ___ om bostøtte. :: Completa «solicitar».
+ søke :: La expresión es «søke om».
- avslå :: Significa denegar.
- innvilge :: Significa conceder.
H Du får et ___. :: Completa «resolución».
+ vedtak :: «Et vedtak» es una resolución administrativa.
- avslag :: Significa denegación.
- inntekt :: Significa ingresos.
A Søknaden kan også bli avslått. :: ¿Qué puede pasar con la solicitud?
+ También pueden denegarla. :: «Bli avslått» significa ser denegada.
- Se concede siempre. :: La frase expresa una posibilidad de rechazo.
- Se transforma en un impuesto. :: No se menciona un impuesto.
O Noen ytelser er behovsprøvde. :: Algunas prestaciones dependen de una evaluación de necesidades e ingresos. :: «Behovsprøvd» describe cómo se determina la prestación.

Q ¿Qué forma se usa para una situación hipotética?
+ «Hvis» + pasado y «ville» + infinitivo :: Presenta una situación imaginaria y su posible resultado.
- «Hvis» + presente y «har» + participio :: Esa forma no presenta aquí la hipótesis.
- «Når» + imperativo :: «Når» suele significar cuando.
Q ¿Qué significa «livskvalitet»?
+ Calidad de vida :: Incluye bienestar y condiciones de vida.
- Tiempo de espera :: «Ventetid» significa tiempo de espera.
- Prestación económica :: «Ytelse» es prestación.
R Hvis kommunen hadde flere ansatte, ville ventetiden bli kortere. :: Traduce la frase.
+ Si el municipio tuviera más empleados, el tiempo de espera sería más corto. :: «Hadde» y «ville» expresan una hipótesis.
- Cuando el municipio contrata empleados, la espera ya es más corta. :: La frase no afirma que haya ocurrido.
- El municipio tendrá menos empleados y más espera. :: Es una hipótesis, no una predicción afirmada.
H Hvis kommunen ___ flere ansatte, ville ventetiden bli kortere. :: Completa «tuviera».
+ hadde :: Es el pasado usado en una hipótesis.
- har :: Es presente.
- vil ha :: Significa quiere tener.

+ anbefaler :: Es la forma presente de «anbefale».
- rapporterer :: Significa informo.
- oppsummerer :: Significa resumo.
