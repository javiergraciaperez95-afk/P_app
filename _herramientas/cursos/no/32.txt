@ 32 | Problemer i hverdagen | Problemas cotidianos
E Hablar del transporte :: **Forsinket** significa «con retraso». **Å rekke bussen** es llegar a tiempo para tomar el autobús. **Holdeplass** es una parada; **avgang** es una salida.
E Cambios de forma :: En **billetten** y **bussen**, el sustantivo aparece en forma definida: «el billete» y «el autobús». **Gjelder** indica que un billete sigue siendo válido.
W rekke = llegar a tiempo; alcanzar | RÉ-ke
W rekker = llego a tiempo; alcanza | RÉ-ker
W gjelder = es válido/a; sirve | YÉL-der
W utenfor = fuera de | Ü-ten-for
W rett = justo; directamente | RET
w bussen = el autobús | BÚ-sen
w toget = el tren | TÚ-get
w billetten = el billete | bi-LÉT-ten
w minutter = minutos | mi-NÚ-ter
V Vocabulario: transporte y retrasos
D Un cambio de parada
Lina: Unnskyld, er toget forsinket? = Disculpa, ¿el tren tiene retraso?
  > toget forsinket = el tren retrasado
Erik: Ja, det er ti minutter forsinket. = Sí, tiene diez minutos de retraso.
  > ti minutter = diez minutos | forsinket = con retraso
Lina: Rekker jeg neste buss? = ¿Llego a tiempo para el siguiente autobús?
  > Rekker jeg = llego a tiempo | neste buss = el siguiente autobús
Erik: Nei, bussen går fra en annen holdeplass. = No, el autobús sale de otra parada.
  > bussen går = el autobús sale | fra en annen holdeplass = de otra parada
Lina: Hvor er holdeplassen? = ¿Dónde está la parada?
  > Hvor er = dónde está | holdeplassen = la parada
Erik: Den er rett utenfor stasjonen. = Está justo fuera de la estación.
  > rett utenfor stasjonen = justo fuera de la estación
Lina: Gjelder billetten på neste avgang? = ¿Sirve el billete para la siguiente salida?
  > Gjelder billetten = sirve el billete | på neste avgang = para la siguiente salida
Erik: Ja, du kan reise senere. = Sí, puedes viajar más tarde.
  > reise senere = viajar más tarde
Q ¿Qué significa «forsinket»?
+ Con retraso :: Describe que algo llega o sale más tarde.
- A tiempo :: Eso se expresa con «i tide».
- Cancelado :: La palabra significa que lleva retraso, no que se canceló.
Q ¿Qué significa «holdeplass»?
+ Parada de transporte :: Es el lugar donde para el autobús.
- Estación de tren :: «Stasjon» significa estación.
- Billete de autobús :: «Billett» es billete.
R Rekker jeg neste buss? :: Traduce la pregunta.
+ ¿Llego a tiempo para el siguiente autobús? :: «Rekker» pregunta si da tiempo a tomarlo.
- ¿Dónde está el autobús siguiente? :: Eso sería «Hvor er neste buss?».
- ¿Cuándo sale el tren siguiente? :: La frase pregunta por el autobús y si se llega a tiempo.
H Toget er ti minutter ___. :: Completa «con retraso».
+ forsinket :: «Forsinket» es retrasado.
- senere :: Significa más tarde.
- rett :: Significa justo o directamente.
H Bussen går fra en annen ___. :: Completa «parada».
+ holdeplass :: «Holdeplass» es parada de transporte.
- avgang :: Significa salida.
- billett :: Significa billete.
A Gjelder billetten på neste avgang? :: ¿Qué quiere saber Lina?
+ Si el billete sirve para la siguiente salida. :: «Gjelder» pregunta si sigue siendo válido.
- Si el autobús sale de la estación. :: Eso no es lo que pregunta.
- Si el tren tiene retraso. :: Esa pregunta aparece al principio.
O Den er rett utenfor stasjonen. :: Está justo fuera de la estación. :: «Rett utenfor» significa justo fuera de.
X Escribe en noruego: «retraso» :: forsinkelse :: «En forsinkelse» es un retraso.

@ 32 | En pakke mangler | Falta un artículo del paquete
E Explicar un problema :: **Bestilling** es un pedido; **pakke**, un paquete. **Mangle** significa que falta algo y **ødelagt**, que está roto.
E Pedir una solución :: Para solicitar ayuda, puedes **kontakte kundeservice** («contactar con atención al cliente») y facilitar el **ordrenummer** («número de pedido»). **Sende en ny vare** es enviar un artículo nuevo.
W bestilling = pedido | be-STÍ-ling
W bestillingen = el pedido | be-STÍ-ling-en
W pakke = paquete | PÁ-ke
W pakken = el paquete | PÁ-ken
W levering = entrega | LÉ-ve-ring
W mangle = faltar | MÁNG-le
W mangler = falta | MÁNG-ler
W innhold = contenido | ÍN-jold
W kundeservice = atención al cliente | KÜN-de-seR-VÍ-se
W ordrenummer = número de pedido | ÚR-de-nü-mer
W ordrenummeret = el número de pedido | ÚR-de-nü-me-ret
W sende = enviar | SÉN-de
W sender = envía | SÉN-der
W erstatning = reemplazo; sustitución | ER-stat-ning
W ny = nuevo/a | NÜ
w problem = problema | pro-BLÉM
W dager = días | DÁ-ger
w leveringen = la entrega | LÉ-ve-ring-en
w nummeret = el número | nü-MÉ-ret
V Vocabulario: pedidos y entregas
D Contactar con atención al cliente
Sara: Hei, jeg har et problem med bestillingen min. = Hola, tengo un problema con mi pedido.
  > et problem med bestillingen = un problema con el pedido | min = mío
Kundeservice: Hva mangler i pakken? = ¿Qué falta en el paquete?
  > Hva mangler = qué falta | i pakken = en el paquete
Sara: En vare er ødelagt, og en annen vare mangler. = Un artículo está roto y falta otro artículo.
  > En vare er ødelagt = un artículo está roto | en annen vare mangler = falta otro artículo
Kundeservice: Kan du sende ordrenummeret? = ¿Puedes enviar el número de pedido?
  > Kan du sende = puedes enviar | ordrenummeret = el número de pedido
Sara: Ja, nummeret er 4821. = Sí, el número es 4821.
  > nummeret er = el número es
Kundeservice: Vi sender en ny vare i morgen. = Enviaremos un artículo nuevo mañana.
  > Vi sender = enviaremos | en ny vare = un artículo nuevo | i morgen = mañana
Sara: Takk. Når kommer leveringen? = Gracias. ¿Cuándo llega la entrega?
  > Når kommer = cuándo llega | leveringen = la entrega
Kundeservice: Pakken kommer om to dager. = El paquete llega dentro de dos días.
  > Pakken kommer = el paquete llega | om to dager = dentro de dos días
Q ¿Qué significa «mangler»?
+ Falta :: «En vare mangler» significa que falta un artículo.
- Está roto :: «Ødelagt» significa roto.
- Ha llegado :: «Kommer» significa llega.
Q ¿Qué dato pide atención al cliente?
+ El número de pedido :: «Ordrenummeret» es el número del pedido.
- La hora de la entrega :: Pregunta cuándo llegará, pero no pide una hora.
- La dirección de la estación :: En este diálogo se habla de un paquete.
R En vare er ødelagt, og en annen vare mangler. :: Traduce la frase.
+ Un artículo está roto y falta otro artículo. :: «Ødelagt» es roto y «mangler» es falta.
- El pedido está completo y el paquete está nuevo. :: La frase dice que hay un artículo roto y otro que falta.
- El número de pedido está en el artículo. :: Esa información no aparece.
H Hva ___ i pakken? :: Completa «falta».
+ mangler :: «Mangler» significa falta.
- sender :: Significa envía.
- kommer :: Significa llega.
H Vi ___ en ny vare i morgen. :: Completa «enviamos».
+ sender :: «Sender» es la forma presente de enviar.
- mangler :: Significa falta.
- erstatning :: Significa reemplazo.
A Kan du sende ordrenummeret? :: ¿Qué solicita la persona de atención al cliente?
+ Que envíe el número de pedido. :: «Kan du sende» significa «¿puedes enviar?».
- Que devuelva el paquete hoy. :: No se menciona devolverlo.
- Que espere en la estación. :: El diálogo trata de una entrega.
O Pakken kommer om to dager. :: El paquete llega dentro de dos días. :: «Om to dager» expresa un plazo de dos días.
X Escribe en noruego: «paquete» :: pakke :: «En pakke» es un paquete.

@ 32 | Feil i leiligheten | Averías en casa
E Comunicar una avería :: **Vaktmester** es la persona encargada del mantenimiento del edificio. **Lekkasje** significa fuga; **å dryppe**, gotear.
E Pedir una reparación :: **Reparere** es reparar. Para describir el problema puedes decir **Dusjen virker ikke** («La ducha no funciona») o **Vannet er kaldt** («El agua está fría»).
W vaktmester = encargado/a del mantenimiento del edificio | VAKT-mes-ter
W lekkasje = fuga | le-KÁ-she
W lekkasjen = la fuga | le-KÁ-shen
W vasken = el lavabo | VAS-ken
W dryppe = gotear | DRÜ-pe
W drypper = gotea | DRÜ-per
W reparerer = repara | re-pa-RÉ-rer
W varmtvann = agua caliente | VÁRMT-van
W varmtvannet = el agua caliente | VÁRMT-van-et
W radiator = radiador | ra-di-a-TÚR
W oppvarming = calefacción | ÓP-var-ming
W dusj = ducha | DÜSH
W dusjen = la ducha | DÜ-shen
W formiddag = mañana (antes del mediodía) | FOR-mi-dag
w resten = el resto | RÉS-ten
w røret = la tubería | RÖ-ret
V Vocabulario: reparaciones domésticas
D Una avería en casa
Mina: Hei, jeg ringer fordi dusjen ikke virker. = Hola, llamo porque la ducha no funciona.
  > jeg ringer = llamo | fordi dusjen ikke virker = porque la ducha no funciona
Vaktmester: Er det varmtvann i resten av leiligheten? = ¿Hay agua caliente en el resto del apartamento?
  > varmtvann = agua caliente | i resten av leiligheten = en el resto del apartamento
Mina: Nei, vannet er kaldt. = No, el agua está fría.
  > vannet er kaldt = el agua está fría
Mina: Det drypper også fra røret under vasken. = También gotea de la tubería debajo del lavabo.
  > Det drypper = gotea | fra røret under vasken = de la tubería debajo del lavabo
Vaktmester: Jeg kan reparere lekkasjen. = Puedo reparar la fuga.
  > Jeg kan reparere = puedo reparar | lekkasjen = la fuga
Mina: Når kan du komme? = ¿Cuándo puedes venir?
  > Når kan du komme = cuándo puedes venir
Vaktmester: Jeg kommer i morgen formiddag. = Vendré mañana por la mañana.
  > Jeg kommer = vendré | i morgen formiddag = mañana por la mañana
Mina: Takk. Jeg er hjemme da. = Gracias. Estaré en casa entonces.
  > Jeg er hjemme = estaré en casa | da = entonces
Q ¿Qué significa «vaktmester»?
+ Encargado/a de mantenimiento :: Se ocupa de reparaciones en el edificio.
- Médico/a de cabecera :: «Fastlege» es médico de cabecera.
- Persona de atención al cliente :: «Kundeservice» es atención al cliente.
Q ¿Qué problema tiene la ducha?
+ No funciona :: «Dusjen ikke virker» indica que no funciona.
- Llega mañana por la mañana. :: Esa es la hora de la visita del encargado.
- Está junto al radiador. :: El diálogo no dice dónde está.
R Det drypper fra røret under vasken. :: Traduce la frase.
+ Gotea de la tubería debajo del lavabo. :: «Rør» es tubería y «drypper» significa gotea.
- Sale agua caliente de la ducha. :: La frase dice que gotea bajo el lavabo.
- El radiador no funciona en casa. :: No se menciona el radiador.
H Det ___ fra røret. :: Completa «gotea».
+ drypper :: «Drypper» significa gotea.
- reparerer :: Significa repara.
- ringer :: Significa llama por teléfono.
H Jeg kan ___ lekkasjen. :: Completa «reparar».
+ reparere :: Después de «kan» se usa el infinitivo sin «å».
- dryppe :: Significa gotear.
- ringe :: Significa llamar.
A Jeg kommer i morgen formiddag. :: ¿Cuándo vendrá el encargado?
+ Mañana por la mañana. :: «I morgen formiddag» significa mañana por la mañana.
- Esta tarde. :: No dice «i ettermiddag».
- Dentro de dos días. :: Eso sería «om to dager».
O Vannet er kaldt. :: El agua está fría. :: «Vannet» es la forma definida de «vann».
X Escribe en noruego: «fuga» :: lekkasje :: «En lekkasje» es una fuga.
