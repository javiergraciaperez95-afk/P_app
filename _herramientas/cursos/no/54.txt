@ 54 | Utdanningsbakgrunn | Formación académica y profesional
E Describir estudios :: **Utdanningsbakgrunn** es la formación que una persona ha recibido. **Fagbrev** es un certificado profesional noruego; **vitnemål** es un certificado o expediente de estudios. **Yrkesfaglig** describe la formación profesional.
E Reconocer títulos :: **Godkjenning** es reconocimiento oficial. Para solicitarlo, puede hacer falta documentación que muestre qué estudiaste, durante cuánto tiempo y qué cualificación obtuviste.

D Reconocer una formación
Marta: Jeg tok yrkesfaglig utdanning i hjemlandet mitt. = Estudié formación profesional en mi país.
  > Jeg tok = estudié | yrkesfaglig utdanning = formación profesional | i hjemlandet mitt = en mi país
Veileder: Har du fagbrev eller et annet vitnemål? = ¿Tienes un certificado profesional u otro certificado de estudios?
  > Har du fagbrev = tienes un certificado profesional | eller et annet vitnemål = u otro certificado de estudios
Marta: Ja, her er vitnemålet og en attest fra arbeidsgiveren min. = Sí, aquí está el certificado y una constancia de mi empleador.
  > her er vitnemålet = aquí está el certificado | en attest fra arbeidsgiveren min = una constancia de mi empleador
Veileder: Dokumentasjonen må være fullstendig og oversatt. = La documentación debe estar completa y traducida.
  > Dokumentasjonen må være = la documentación debe estar | fullstendig og oversatt = completa y traducida
Marta: Kan dere godkjenne utdanningen min? = ¿Pueden reconocer mis estudios?
  > Kan dere godkjenne = pueden reconocer | utdanningen min = mis estudios
Veileder: Vi vurderer kvalifikasjonen og yrkeserfaringen din. = Evaluamos tu cualificación y tu experiencia profesional.
  > Vi vurderer = evaluamos | kvalifikasjonen = la cualificación | yrkeserfaringen din = tu experiencia profesional
Q ¿Qué significa «fagbrev»?
+ Certificado profesional :: Acredita una formación en una profesión u oficio.
- Expediente médico :: «Vitnemål» es un certificado de estudios.
- Contrato de alquiler :: «Leiekontrakt» significa contrato de alquiler.
Q ¿Qué debe estar completo y traducido?
+ La documentación :: El diálogo dice que la documentación debe estar completa y traducida.
- La experiencia profesional :: La experiencia se evalúa, pero no se traduce aquí.
- El sistema educativo :: No se menciona un sistema educativo concreto.
R Kan dere godkjenne utdanningen min? :: Traduce la pregunta.
+ ¿Pueden reconocer mis estudios? :: «Godkjenne» significa reconocer oficialmente.
- ¿Pueden enviarme mi certificado? :: «Sende» significa enviar.
- ¿Pueden evaluar mi experiencia laboral? :: La pregunta se refiere a los estudios.
H Dokumentasjonen må være ___. :: Completa «completa».
+ fullstendig :: «Fullstendig» significa completo/a.
- akademisk :: Significa académico/a.
- utenlandsk :: Significa extranjero/a.
H Jeg har et ___ fra hjemlandet. :: Completa «certificado profesional».
+ fagbrev :: «Fagbrev» acredita una cualificación profesional.
- attest :: Es una constancia o certificado, no necesariamente profesional.
- kvalifikasjon :: Significa cualificación.
A Vi vurderer kvalifikasjonen og yrkeserfaringen din. :: ¿Qué evalúa el asesor?
+ La cualificación y la experiencia profesional. :: Es lo que enumera la frase.
- La traducción y el certificado médico. :: No se menciona un certificado médico.
- El alquiler y el sistema educativo. :: No son los elementos nombrados.
O En utenlandsk utdanning kan bli godkjent. :: Una formación extranjera puede ser reconocida. :: «Utenlandsk» concuerda con «utdanning».

@ 54 | Spørre om godkjenning | Preguntar por el reconocimiento de estudios
E Preguntas indirectas :: **Jeg lurer på om ...** («quisiera saber si…») introduce una pregunta indirecta. Dentro de ella, el sujeto precede al verbo: **Jeg lurer på om dere trenger flere dokumenter**. No se usa el orden de pregunta directa.
E Solicitar información :: **Behandlingstid** es el tiempo que tarda una solicitud. **Saksbehandler** es la persona que la tramita. **Bekreftet kopi** es una copia certificada.
W saksbehandler = persona que tramita un expediente | SAKS-be-jand-ler
W bekreftet kopi = copia certificada | be-KREF-tet KÓ-pi
W kopi = copia | KÓ-pi
W original = original | o-ri-gi-NAL
W sende inn = presentar; enviar | SÉN-de ÍN
W sender inn = presento; presenta | SÉN-der ÍN
W mottatt = recibido/a | MÚ-tat
W forventet = previsto/a; esperado/a | for-VÉN-tet
W foreløpig = por ahora; provisionalmente | FÓ-re-lö-pig
W derfor = por eso; por lo tanto | DÉR-for
W eventuell = posible; eventual | e-ven-tu-ÉL
W ettersende = enviar más tarde; completar después | É-ter-sen-de
W inn = dentro; hacia dentro | IN
w kopien = la copia | KÓ-pi-en
w originalen = el original | o-ri-gi-NAL-en
w sendt = enviado/a; presentado/a | SENT
w søknaden = la solicitud | SÖK-na-den
w attesten = la constancia | a-TÉS-ten
V Vocabulario: trámites y consultas formales
D Una consulta sobre la solicitud
Marta: Jeg lurer på om dere trenger en bekreftet kopi. = Quisiera saber si necesitan una copia certificada.
  > Jeg lurer på om = quisiera saber si | dere trenger = necesitan | en bekreftet kopi = una copia certificada
Saksbehandler: Ja, vi trenger kopien, men ikke originalen. = Sí, necesitamos la copia, pero no el original.
  > vi trenger kopien = necesitamos la copia | men ikke originalen = pero no el original
Marta: Jeg har sendt inn søknaden. Er dokumentasjonen mottatt? = He presentado la solicitud. ¿Se recibió la documentación?
  > Jeg har sendt inn søknaden = he presentado la solicitud | Er dokumentasjonen mottatt = se recibió la documentación
Saksbehandler: Ja, men det mangler en attest. = Sí, pero falta una constancia.
  > det mangler = falta | en attest = una constancia
Marta: Kan jeg ettersende den? = ¿Puedo enviarla más tarde?
  > Kan jeg ettersende = puedo enviar más tarde | den = la
Saksbehandler: Ja. Hvis du sender den innen søknadsfristen, går det fint. = Sí. Si la envías antes del plazo de solicitud, está bien.
  > Hvis du sender den = si la envías | innen søknadsfristen = antes del plazo de solicitud | går det fint = no hay problema
Marta: Hva er forventet behandlingstid? = ¿Cuál es el tiempo de tramitación previsto?
  > Hva er = cuál es | forventet behandlingstid = el tiempo de tramitación previsto
Q ¿Qué significa «saksbehandler»?
+ Persona que tramita un expediente :: Es quien se ocupa de procesar la solicitud.
- Persona que traduce documentos :: «Oversetter» significa traductor/a.
- Persona que alquila una vivienda :: «Utleier» significa arrendador/a.
Q ¿Qué falta en la solicitud de Marta?
+ Una constancia :: El asesor dice que falta una «attest».
- El original del certificado :: No necesitan el original.
- Una copia certificada :: Ya han recibido documentación, pero falta una constancia.
R Jeg lurer på om dere trenger en bekreftet kopi. :: Traduce la frase.
+ Quisiera saber si necesitan una copia certificada. :: Es una pregunta indirecta cortés.
- ¿Necesitan saber si la copia está certificada? :: Cambia quién pregunta y qué necesita.
- Quiero certificar el original ahora. :: La frase pregunta si necesitan una copia.
H Hvis du sender den innen søknadsfristen, går det ___. :: Completa «está bien».
+ fint :: «Det går fint» significa que está bien o no hay problema.
- foreløpig :: Significa por ahora.
- mottatt :: Significa recibido.
H Jeg kan ___ attesten senere. :: Completa «enviar más tarde».
+ ettersende :: «Ettersende» significa enviar después lo que falta.
- sende inn :: Significa presentar.
- mangle :: Significa faltar.
A Ja, vi trenger kopien, men ikke originalen. :: ¿Qué documento necesitan?
+ La copia, no el original. :: La frase contrasta «kopien» y «originalen».
- Solo el original. :: La respuesta dice explícitamente que no.
- Una traducción certificada. :: No se menciona una traducción.
O Jeg lurer på om dokumentasjonen er mottatt. :: Quisiera saber si se recibió la documentación. :: La pregunta indirecta mantiene sujeto y verbo en ese orden.
X Escribe en noruego: «plazo de solicitud» :: søknadsfrist :: «Søknadsfrist» es la fecha límite para presentar una solicitud.

@ 54 | Studier og erfaringer | Estudios y experiencias
E Pasado simple y presente perfecto :: Usa el pasado simple con un momento terminado: **Jeg studerte i fjor** («estudié el año pasado»). Usa **har + participio** para una experiencia sin fecha concreta o una situación que sigue: **Jeg har studert her i to år** («llevo dos años estudiando aquí»).
E Hablar de estudios :: Un **semester** es una mitad del año académico. **Studiepoeng** son créditos; **forelesning**, clase magistral; **innlevering**, trabajo que se entrega.
W semester = semestre | se-MÉS-ter
W studiepoeng = créditos académicos | STÜ-di-e-pöng
W forelesning = clase magistral; conferencia | FÓ-re-les-ning
W forelesningene = las clases magistrales | FÓ-re-les-ning-e-ne
W studiegruppe = grupo de estudio | STÜ-di-e-grü-pe
W innlevering = trabajo entregado; entrega académica | ÍN-le-ve-ring
W innleveringen = el trabajo entregado | ÍN-le-ve-ring-en
W vurdering = evaluación | VÜR-de-ring
W vurderer = evalúo; evalúa | VÜR-de-rer
W tilbakemelding = comentarios; respuesta | til-ba-ke-MÉL-ding
W bestå = aprobar (un examen) | be-STÓ
W bestått = aprobado/a | be-STÓT
W stryke = suspender (un examen) | STRÜ-ke
W utveksling = intercambio académico | ÜT-vek-sling

W læringsmiljø = entorno de aprendizaje | LÉ-rings-mi-lö

w studert = estudiado/a | stu-DÉRT

w leverte = entregué; entregó | le-VÉR-te

w fagene = las asignaturas | FÁ-ge-ne

V Vocabulario: la vida de estudiante
T Mi experiencia de estudios
- Jeg har studert norsk i to år, og jeg har fått mange studiepoeng. = Llevo dos años estudiando noruego y he conseguido muchos créditos.
  > Jeg har studert = he estudiado | i to år = durante dos años | har fått mange studiepoeng = he conseguido muchos créditos
- I fjor deltok jeg i en studiegruppe. = El año pasado participé en un grupo de estudio.
  > I fjor = el año pasado | deltok jeg = participé | i en studiegruppe = en un grupo de estudio
- Vi møttes før forelesningene og hjalp hverandre. = Nos reuníamos antes de las clases magistrales y nos ayudábamos.
  > Vi møttes = nos reuníamos | før forelesningene = antes de las clases | hjalp hverandre = nos ayudábamos
- Jeg leverte innleveringen i tide og fikk nyttig tilbakemelding. = Entregué el trabajo a tiempo y recibí comentarios útiles.
  > Jeg leverte innleveringen = entregué el trabajo | i tide = a tiempo | fikk nyttig tilbakemelding = recibí comentarios útiles
- Nå vurderer jeg videreutdanning eller et semester på utveksling. = Ahora estoy considerando formación continua o un semestre de intercambio.
  > Nå vurderer jeg = ahora estoy considerando | videreutdanning = formación continua | et semester på utveksling = un semestre de intercambio
- Målet mitt er å bestå alle fagene og få gode karakterer. = Mi objetivo es aprobar todas las asignaturas y sacar buenas notas.
  > Målet mitt er = mi objetivo es | å bestå alle fagene = aprobar todas las asignaturas | få gode karakterer = sacar buenas notas
Q ¿Cuándo se usa normalmente el pasado simple?
+ Con un momento pasado terminado :: «I fjor» sitúa la acción en un periodo ya terminado.
- Para una experiencia sin fecha concreta :: A menudo se usa «har» más participio.
- Para una acción que sigue hasta hoy :: El presente perfecto puede expresar continuidad.
Q ¿Qué es «studiepoeng»?
+ Créditos académicos :: Indican carga o progreso dentro de los estudios.
- Una calificación :: «Karakter» es una nota.
- Una clase magistral :: «Forelesning» significa clase magistral.
R Jeg har studert norsk i to år. :: Traduce la frase.
+ Llevo dos años estudiando noruego. :: La situación continúa hasta el presente.
- Estudié noruego durante dos años y ya terminé. :: La frase no indica que haya terminado.
- Estudiaré noruego dentro de dos años. :: No expresa futuro.
H I fjor ___ jeg i en studiegruppe. :: Completa «participé».
+ deltok :: El marcador «i fjor» acompaña al pasado simple.
- har deltatt :: Es presente perfecto.
- delta :: Es infinitivo.
H Målet mitt er å ___ alle fagene. :: Completa «aprobar».
+ bestå :: Después de «å» va el infinitivo.
- bestått :: Es el participio.
- stryke :: Significa suspender.
A Jeg leverte innleveringen i tide. :: ¿Qué hizo la persona?
+ Entregó el trabajo a tiempo. :: «Leverte» es pasado y «i tide», a tiempo.
- Recibió una calificación baja. :: No se menciona el resultado.
- Se inscribió en un intercambio. :: Eso es una posibilidad futura en el texto.
O Nå vurderer jeg videreutdanning. :: Ahora estoy considerando formación continua. :: «Vurderer» expresa que lo está pensando.
X Escribe en noruego: «nota; calificación» :: karakter :: «En karakter» es una nota académica.
