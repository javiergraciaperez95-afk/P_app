@ 56 | Vilkår og rettigheter | Condiciones y derechos laborales
E Condiciones de trabajo :: **Arbeidstaker** es una persona empleada. **Arbeidsvilkår** incluye horario, salario, vacaciones y otras condiciones. Una **tariffavtale** es un acuerdo colectivo sobre condiciones laborales.
E Derechos y deberes :: **Rettighet** es un derecho; **plikt**, una obligación. **Tillitsvalgt** es un representante elegido por los trabajadores; **verneombud**, la persona representante de la seguridad laboral.

Q ¿Qué es una «tariffavtale»?
+ Un convenio colectivo :: Establece condiciones laborales acordadas colectivamente.
- Un recibo de salario :: «Lønnsslipp» es la nómina.
- Una obligación individual :: «Plikt» significa deber u obligación.
Q ¿Quién es un «verneombud»?
+ Un representante de seguridad laboral :: Se ocupa de asuntos de seguridad en el trabajo.
- Un representante de una comunidad de vecinos :: «Tillitsvalgt» es un representante de los trabajadores.
- Un responsable de nóminas :: No es el significado de la palabra.
R Partene har rettigheter og plikter. :: Traduce la frase.
+ Las partes tienen derechos y obligaciones. :: «Rettigheter» son derechos y «plikter», obligaciones.
- Los empleados reciben horas extra. :: No es lo que dice la frase.
- El convenio colectivo termina hoy. :: No se menciona cuándo termina.
H En arbeidstaker kan spørre fagforeningen om ___. :: Completa «derechos».
+ rettigheter :: «Rettigheter» significa derechos.
- pauser :: Significa pausas.
- lønnsslipp :: Significa nómina.
H Hvor mye ___ kan avtales? :: Completa «horas extra».
+ overtid :: «Overtid» son las horas extra.
- feriepenge :: Es la paga de vacaciones.
- pause :: Es una pausa.
A Det må stå i kontrakten. :: ¿Dónde debe aparecer la información?
+ En el contrato. :: «I kontrakten» significa en el contrato.
- En la nómina. :: «Lønnsslipp» es la nómina.
- En el sindicato. :: La frase se refiere a un documento.

@ 56 | Arbeidstid og lønn | Jornada y salario
E Pasiva con «-s» :: La pasiva con **-s** es frecuente en normas y textos formales: **Lønn utbetales hver måned** («El salario se paga cada mes»). El agente suele omitirse.
E Pasiva con «bli» :: ****Bli + participio** presenta una acción o un cambio: **Timene blir registrert** («Las horas se registran»). En bokmål, **registrert** no cambia por el plural de **timene**: se mantiene la misma forma del participio.

  > Arbeidstiden registreres = el horario se registra | digitalt = digitalmente

  > Hvis en ansatt jobber overtid = si una persona empleada hace horas extra | blir timene registrert = las horas quedan registradas

  > Overtid må avtales = las horas extra deben acordarse | på forhånd = de antemano

  > Et tillegg for nattevakt = un suplemento por turno nocturno | beregnes etter avtalen = se calcula según el acuerdo
- Fravær registreres også, men sykefravær følger egne regler. = Las ausencias también se registran, pero las ausencias por enfermedad siguen reglas propias.
  > Fravær registreres også = las ausencias también se registran | sykefravær følger egne regler = las ausencias por enfermedad siguen reglas propias
Q ¿Qué forma es frecuente en normas y textos formales?
+ La pasiva con «-s» :: Por ejemplo, «Lønn utbetales».
- El infinitivo con «å» después de «kan» :: Después de «kan» se usa el infinitivo sin «å».
- El pasado de todos los verbos con «-et» :: No describe la pasiva.

+ Se paga; se abona :: Es una forma pasiva con «-s».
- Se registra :: «Registreres» significa se registra.
- Se calcula :: «Beregnes» significa se calcula.

- Las horas se registran en papel. :: La frase dice digitalmente.

+ avtales :: «Avtales» es la pasiva de «avtale».
- beregnes :: Significa se calcula.
- utbetales :: Significa se paga.
H Et tillegg for nattevakt ___. :: Completa «se calcula».
+ beregnes :: Es la pasiva con «-s» de «beregne».
- registreres :: Significa se registra.
- utbetales :: Significa se paga.
