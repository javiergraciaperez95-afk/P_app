
@ 15 | Skilt i bygninger | Señales en edificios
E Leer señales :: Muchos letreros usan una sola palabra o una frase corta. :: **Inngang** es el lugar por donde se entra; **utgang**, por donde se sale. **Nødutgang** es una salida para una emergencia.
W inngang = entrada | ÍN-gang
W inngangen = la entrada | ÍN-gang-en
W utgang = salida | ÜT-gang
W utgangen = la salida | ÜT-gang-en
W nødutgang = salida de emergencia | NÖD-ÜT-gang
W toalett = aseo; baño | tu-a-LET
W toalettet = el aseo; el baño | tu-a-LET-et
W åpent = abierto | Ó-pen
W stengt = cerrado | STENGT
W åpningstider = horario de apertura | ÓP-nings-TÍ-der
W stengt i dag = cerrado hoy | STENGT i DAG
W inngang her = entrada por aquí | ÍN-gang JÉR
W utgang her = salida por aquí | ÜT-gang JÉR
W nødutgang her = salida de emergencia por aquí | NÖD-ÜT-gang JÉR
W Hvor er inngangen = ¿Dónde está la entrada? | VUR er ÍN-gang-en
W Inngangen er her = La entrada está aquí | ÍN-gang-en er JÉR
W Hvor er toalettet = ¿Dónde está el aseo? | VUR er tu-a-LET-et
W Toalettet er ved utgangen = El aseo está junto a la salida | tu-a-LET-et er ve ÜT-gang-en
W Det står åpent på skiltet = El letrero indica que está abierto | de stor Ó-pen po SHIL-tet
V Vocabulario: entradas, salidas y horarios
D Buscar el aseo
Nora: Hvor er inngangen? = ¿Dónde está la entrada?
  > Hvor er = dónde está | inngangen = la entrada
Ali: Inngangen er her. = La entrada está aquí.
  > Inngangen = la entrada | er her = está aquí
Nora: Hvor er toalettet? = ¿Dónde está el aseo?
  > Hvor er = dónde está | toalettet = el aseo
Ali: Toalettet er ved utgangen. = El aseo está junto a la salida.
  > Toalettet = el aseo | ved utgangen = junto a la salida
Mina: Det står «Åpent» på skiltet. = El letrero indica «Abierto».
  > Det står = indica | Åpent = abierto | på skiltet = en el letrero
Q ¿Qué significa «nødutgang»?
+ Salida de emergencia. :: Es la salida que se utiliza en una emergencia.
- Entrada principal. :: Eso es «inngang».
- Aseo público. :: Eso es «toalett».
Q ¿Qué significa «stengt»?
+ Cerrado. :: Indica que no está abierto.
- Abierto. :: Eso es «åpent».
- Junto a la salida. :: Eso es «ved utgangen».
R Hvor er toalettet? :: Traduce la pregunta.
+ ¿Dónde está el aseo? :: «Hvor er» pregunta dónde está algo.
- ¿Dónde está la salida? :: La frase dice «toalettet».
- ¿Cuándo abre el aseo? :: No pregunta por un horario.
H Inngangen er ___. :: Completa «aquí».
+ her :: «Her» significa aquí.
- utgang :: Significa salida.
- stengt :: Significa cerrado.
H Toalettet er ved ___. :: Completa «la salida».
+ utgangen :: Es la forma definida de «utgang».
- inngangen :: Significa «la entrada».
- nødutgang :: Significa «salida de emergencia».
A Det står «Åpent» på skiltet. :: ¿Qué indica el letrero?
+ Que está abierto. :: «Åpent» significa abierto.
- Que está cerrado hoy. :: Eso es «stengt i dag».
- Que hay una salida de emergencia. :: Eso es «nødutgang».
O Toalettet er ved utgangen. :: El aseo está junto a la salida. :: «Ved» expresa cercanía o ubicación junto a algo.
X Escribe «salida de emergencia» :: nødutgang :: «Nødutgang» es la salida prevista para una emergencia.

@ 15 | Forbud og regler | Prohibiciones y normas
E Prohibiciones :: **Ikke** va antes del verbo en una orden negativa: **Ikke gå inn!** («¡No entres!»). :: **Må ikke + infinitivo** expresa prohibición: **Du må ikke parkere her** («No puedes aparcar aquí»). No equivale a «no hace falta».
W adgang = acceso; entrada | ÁD-gang
W forbudt = prohibido | for-BÜDT
W adgang forbudt = prohibido el paso | ÁD-gang for-BÜDT
W røyking = fumar; el acto de fumar | RÖI-king
W røyking forbudt = prohibido fumar | RÖI-king for-BÜDT
W parkering = estacionamiento; aparcamiento | par-KÉ-ring
W parkering forbudt = prohibido aparcar | par-KÉ-ring for-BÜDT
W parkere = aparcar | par-KÉ-re
W gå inn = entrar | GO IN
W må ikke = no se debe; está prohibido | MO Í-ke
W må ikke gå inn = no se debe entrar | MO Í-ke GO IN
W ikke røyk = no fumes | Í-ke RÖIK
W ikke parker her = no aparques aquí | Í-ke par-KÉR JÉR
W regel = norma; regla | RÉ-gel
W regler = normas; reglas | RÉ-gler
W Her er en regel = Aquí hay una norma | JÉR er en RÉ-gel
W Du må ikke parkere her = No puedes aparcar aquí | dü MO Í-ke par-KÉ-re JÉR
W Kan jeg gå inn her = ¿Puedo entrar aquí? | kan YÁI GO IN JÉR
W Kan jeg parkere her = ¿Puedo aparcar aquí? | kan YÁI par-KÉ-re JÉR
V Vocabulario: prohibiciones y normas
D Leer las normas
Ali: Kan jeg gå inn her? = ¿Puedo entrar aquí?
  > Kan jeg = ¿puedo? | gå inn her = entrar aquí
Nora: Nei, adgang forbudt. = No, prohibido el paso.
  > Nei = no | adgang forbudt = prohibido el paso
Mina: Kan jeg parkere her? = ¿Puedo aparcar aquí?
  > Kan jeg parkere = ¿puedo aparcar? | her = aquí
Nora: Nei, parkering forbudt. = No, prohibido aparcar.
  > Nei = no | parkering forbudt = prohibido aparcar
Ali: Her er en regel. = Aquí hay una norma.
  > Her = aquí | er en regel = hay una norma
Q ¿Qué significa «adgang forbudt»?
+ Prohibido el paso. :: La entrada no está permitida.
- Prohibido fumar. :: Eso es «røyking forbudt».
- Salida por aquí. :: Eso es «utgang her».
Q ¿Qué significa «parkering forbudt»?
+ Prohibido aparcar. :: «Parkering» es aparcamiento y «forbudt», prohibido.
- Aparcamiento abierto. :: No aparece «åpent».
- Entrada prohibida. :: Eso se expresa con «adgang forbudt».
R Nei, adgang forbudt. :: Traduce el letrero.
+ No, prohibido el paso. :: «Adgang forbudt» indica que no se permite entrar.
- No, salida de emergencia. :: Eso es «nødutgang».
- No, aparcamiento abierto. :: El letrero prohíbe el paso.
H ___ forbudt. :: Completa «prohibido fumar».
+ røyking :: «Røyking forbudt» significa prohibido fumar.
- parkering :: «Parkering» es aparcamiento.
- adgang :: «Adgang» es acceso o entrada.
H Du ___ parkere her. :: Completa la prohibición «no puedes».
+ må ikke :: «Må ikke» expresa prohibición.
- er her :: Significa «está aquí».
- åpner :: Significa «abre».
A Kan jeg gå inn her? :: ¿Qué quiere saber la persona?
+ Si puede entrar por aquí. :: «Gå inn» significa entrar.
- Si puede aparcar aquí. :: Eso se pregunta con «parkere».
- Si el aseo está abierto. :: No pregunta por el aseo.
O Ikke røyk. :: No fumes. :: En una orden negativa, «ikke» aparece antes del imperativo.
X Escribe «prohibido el paso» :: adgang forbudt :: Es una expresión breve que aparece en señales.

@ 15 | Varsler og forsiktighet | Avisos y precaución
E Advertencias :: **Vær forsiktig** significa «ten cuidado». :: **Glatt** describe una superficie resbaladiza; **vått** concuerda con el sustantivo neutro **gulv**: **et vått gulv**.
W glatt = resbaladizo; resbaladiza | GLAT
W gulv = suelo | GÜLV
W gulvet = el suelo | GÜL-vet
W våt = mojado/a | VOT
W vått = mojado (con sustantivo neutro) | VOT
W forsiktig = con cuidado; prudente | for-SÍK-ti
W fare = peligro | FÁ-re
W farlig = peligroso/a | FÁR-li
W sakte = despacio | SÁK-te
W vær forsiktig = ten cuidado | ver for-SÍK-ti
W Gulvet er vått = El suelo está mojado | GÜL-vet er VOT
W Gulvet er glatt = El suelo está resbaladizo | GÜL-vet er GLAT
W Det er farlig her = Es peligroso aquí | de er FÁR-li JÉR
W Jeg går sakte = Camino despacio | YÁI gor SÁK-te
W pass på = ten cuidado; presta atención | PAS po
V Vocabulario: avisos y seguridad
D Suelo mojado
Nora: Gulvet er vått. = El suelo está mojado.
  > Gulvet = el suelo | er vått = está mojado
Ali: Ja, gulvet er glatt. = Sí, el suelo está resbaladizo.
  > Ja = sí | gulvet er glatt = el suelo está resbaladizo
Mina: Vær forsiktig. = Ten cuidado.
  > Vær forsiktig = ten cuidado
Ali: Jeg går sakte. = Camino despacio.
  > Jeg går = camino | sakte = despacio
Nora: Det er farlig her. = Es peligroso aquí.
  > Det er farlig = es peligroso | her = aquí
Ali: Fare! = ¡Peligro!
  > Fare = peligro
Q ¿Qué significa «glatt»?
+ Resbaladizo. :: Describe un suelo por el que es fácil resbalar.
- Mojado. :: Eso es «vått».
- Cerrado. :: Eso es «stengt».
Q ¿Qué significa «vær forsiktig»?
+ Ten cuidado. :: Es una advertencia.
- Entra por aquí. :: Eso es «inngang her».
- No fumes. :: Eso es «ikke røyk».
R Gulvet er vått. :: Traduce la frase.
+ El suelo está mojado. :: «Vått» concuerda con el neutro «gulv».
- El suelo está resbaladizo. :: Eso es «Gulvet er glatt».
- El suelo está cerrado. :: «Stengt» se usa para cerrado.
H Gulvet er ___. :: Completa «resbaladizo».
+ glatt :: «Glatt» significa resbaladizo.
- vått :: Significa mojado.
- forsiktig :: Significa con cuidado.
H Jeg går ___. :: Completa «despacio».
+ sakte :: «Sakte» significa despacio.
- farlig :: «Farlig» significa peligroso.
- åpent :: «Åpent» significa abierto.
A Jeg går sakte. :: ¿Cómo camina la persona?
+ Despacio. :: «Sakte» significa despacio.
- Con cuidado porque está lloviendo. :: La frase no menciona lluvia.
- Por la salida. :: La frase no menciona una salida.
O Vær forsiktig. :: Ten cuidado. :: «Vær» es el imperativo de «å være».
X Escribe «el suelo está mojado» :: Gulvet er vått. :: «Gulvet» es el sustantivo definido y «vått» concuerda con el neutro.
