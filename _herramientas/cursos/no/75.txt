

@ 75 | Avsluttende prøve | Examen final de B1
E Examen final de B1 :: Veinticinco preguntas sobre los capítulos 21–30. Si aciertas veinte o más, has superado este repaso de los contenidos incluidos en el nivel. El resultado es orientativo y no certifica por sí solo el nivel B1. :: Cada pregunta indica el capítulo que debes repasar.
Q Cap. 51. ¿Qué significa «husleie»?
+ Alquiler mensual :: Es el dinero que se paga por vivir en una vivienda.
- Electricidad :: «Strøm» significa electricidad.
- Fianza :: «Depositum» significa fianza.
R Cap. 51. Strøm er ikke inkludert i husleien. :: Traduce la frase.
+ La electricidad no está incluida en el alquiler. :: «Ikke inkludert» significa no incluido.
- El alquiler incluye la electricidad. :: La frase afirma lo contrario.
- La fianza no está disponible. :: «Depositum» no aparece en la frase.
H Cap. 51. Du må betale ___ fristen. :: Completa «antes del».
+ innen :: «Innen fristen» significa antes del plazo.
- etter :: Significa después de.
- under :: Significa debajo de.
Q Cap. 52. ¿Qué es una «dugnad»?
+ Una actividad comunitaria voluntaria :: Los vecinos colaboran en una tarea común.
- Una ayuda para el alquiler :: «Bostøtte» es una ayuda para vivienda.
- Una reunión de trabajo remunerada :: La «dugnad» es voluntaria.
H Cap. 52. Han rydder boden ___. :: Completa «su propio trastero».
+ sin :: «Sin» se refiere al sujeto y concuerda con «bod».
- sitt :: Se usa con un sustantivo neutro.
- sine :: Se usa con un sustantivo plural.
R Cap. 52. Beboerne må snakke med hverandre. :: Traduce la frase.
+ Los residentes tienen que hablar entre sí. :: «Hverandre» expresa reciprocidad.
- Los residentes tienen que hablar consigo mismos. :: «Hverandre» se refiere a otras personas.
- La junta tiene que hablar con el arrendador. :: La frase dice «beboerne».
Q Cap. 53. ¿Qué significa «verken ... eller»?
+ Ni ... ni :: Presenta dos opciones negadas.
- Tanto ... como :: Eso se expresa con «både ... og».
- Aunque ... aun así :: Eso se expresa con «selv om» y «likevel».
R Cap. 53. Vi prøver å dele husarbeidet rettferdig. :: Traduce la frase.
+ Intentamos repartir las tareas domésticas de forma equitativa. :: «Rettferdig» significa justo o equitativo.
- Decidimos que una persona haga todo el trabajo. :: La frase expresa un reparto equitativo.
- Trabajamos a jornada completa en casa. :: No habla de una jornada laboral.
H Cap. 53. ___ arbeidet blir fordelt mellom generasjonene. :: Completa «todo el trabajo».
+ Alt :: «Arbeidet» es neutro: se usa «alt».
- All :: Se usa con un sustantivo común singular.
- Alle :: Suele acompañar a personas o sustantivos plurales.
Q Cap. 54. ¿Qué es un «fagbrev»?
+ Certificado profesional :: Acredita formación en una profesión u oficio.
- Certificado médico :: «Vitnemål» es un certificado de estudios.
- Permiso de residencia :: «Oppholdstillatelse» significa permiso de residencia.
R Cap. 54. Jeg lurer på om dere trenger en bekreftet kopi. :: Traduce la frase.
+ Quisiera saber si necesitan una copia certificada. :: Es una pregunta indirecta cortés.
- ¿Necesitan que certifique el original? :: La frase pregunta si necesitan una copia.
- Quiero recibir la documentación hoy. :: No se menciona hoy.
H Cap. 54. I fjor ___ jeg i en studiegruppe. :: Completa «participé».
+ deltok :: «I fjor» sitúa la acción en un periodo pasado terminado.
- har deltatt :: Es presente perfecto.
- delta :: Es infinitivo.
Q Cap. 55. ¿Qué es un «søknadsbrev»?
+ Carta de solicitud :: Acompaña una solicitud de empleo.
- Oferta de empleo :: «Stillingsannonse» es una oferta.
- Entrevista de trabajo :: «Arbeidsintervju» significa entrevista.
H Cap. 55. Jeg ønsker ___ søke på stillingen. :: Completa el infinitivo con «å».
+ å :: Después de «ønsker» se usa «å» más infinitivo.
- til :: «Til» no introduce aquí el infinitivo.
- for :: «For» no introduce aquí el infinitivo.
R Cap. 55. Jeg er vant til å samarbeide med ulike mennesker. :: Traduce la frase.
+ Estoy acostumbrada a colaborar con personas diferentes. :: «Vant til å» expresa costumbre.
- Quiero dejar de colaborar con otras personas. :: La frase expresa una costumbre.
- Ya he convocado a varias personas. :: «Innkalt» significa convocado/a.
Q Cap. 56. ¿Qué establece una «tariffavtale»?
+ Condiciones laborales acordadas colectivamente :: Es un convenio colectivo.
- La resolución de una solicitud social :: «Vedtak» significa resolución administrativa.
- La fecha de una entrevista :: No es el significado de la palabra.
R Cap. 56. Arbeidstiden registreres digitalt. :: Traduce la frase.
+ El horario laboral se registra digitalmente. :: «Registreres» es pasiva con «-s».
- El horario laboral se paga en efectivo. :: La frase habla de registrar, no pagar.
- La jornada se acuerda por escrito. :: No aparece «avtales».
Q Cap. 57. ¿Qué significa «kildekritikk»?
+ Valorar si una fuente es fiable :: Se comprueba quién publicó la información y qué pruebas ofrece.
- Compartir todas las noticias :: El análisis crítico evalúa la fuente primero.
- Escribir un titular :: «Overskrift» significa titular.
R Cap. 57. Hun sa at hun hadde sett bildet før. :: Traduce la frase.
+ Dijo que ya había visto la imagen. :: «Hadde sett» sitúa la visión antes de lo que dijo.
- Dice que verá la imagen mañana. :: La frase está en pasado.
- Pregunta si la imagen está manipulada. :: La frase comunica lo que dijo.
Q Cap. 58. ¿Qué significa «bærekraftig»?
+ Sostenible :: Describe algo que puede mantenerse a largo plazo con menor impacto ambiental.
- De un solo uso :: «Engangsplast» significa plástico desechable.
- Desperdicio de comida :: «Matsvinn» significa desperdicio de comida.
H Cap. 58. Jo mer jeg ___, jo mindre drivstoff bruker jeg. :: Completa «voy en bicicleta».
+ sykler :: Es la forma presente de «sykle».
- pendler :: Significa me desplazo al trabajo.
- prioriterer :: Significa priorizo.
Q Cap. 59. ¿Qué es «avlastning»?
+ Un respiro para quien cuida a otra persona :: Permite que la persona cuidadora descanse.
- Una evaluación de ingresos :: «Behovsprøvd» describe esa evaluación.
- Una prestación para pagar estudios :: No es lo que significa.
H Cap. 59. Hvis kommunen ___ flere ansatte, ville ventetiden bli kortere. :: Completa «tuviera».
+ hadde :: Es el pasado usado en una situación hipotética.
- har :: Es presente.
- vil ha :: Significa quiere tener.
Q Cap. 60. ¿Qué significa «oppholdstillatelse»?
+ Permiso de residencia :: Autoriza a una persona a residir en el país.
- Certificado profesional :: «Fagbrev» acredita una cualificación profesional.
- Libertad de expresión :: «Ytringsfrihet» significa libertad de expresión.
R Cap. 60. På den andre siden kan ulike dialekter være vanskelige å forstå. :: Traduce la frase.
+ Por otro lado, puede ser difícil entender dialectos distintos. :: «På den andre siden» introduce otro aspecto.
- En primer lugar, todos los dialectos son iguales. :: La frase expresa lo contrario.
- En mi opinión, no hay otras lenguas. :: «Etter min mening» significa en mi opinión.
