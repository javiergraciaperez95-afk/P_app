@ 76 | Helse og livskvalitet | Salud y calidad de vida
I En B2 aprenderás a hablar de temas generales con precisión y matices. Hoy veremos cómo expresar una posibilidad sin presentarla como un hecho seguro.
E Matizar una afirmación :: **Det kan tyde på at ...** significa «eso puede indicar que...». La expresión presenta una interpretación posible, no una certeza. :: **Å skyldes** señala una causa; **å lindre** es aliviar y **å forverre** es empeorar.

W helsefremmende = beneficioso para la salud | JÉL-se-frem-men-de

w langvarige = prolongados/as; de larga duración | LANG-va-ri-ge

w plagene = las molestias; las dolencias | PLÁ-ge-ne
W belastning = carga; presión | be-LAST-ning

w søvnkvaliteten = la calidad del sueño | SÖVN-kva-li-TÉ-ten
w symptomene = los síntomas | süm-TÓ-me-ne

W behandlingstilbud = servicio de tratamiento | be-HAND-lings-tíl-bud

V Vocabulario: salud y matices
D Una consulta sobre síntomas
Lege: Flere beskriver langvarige plager. = Varias personas describen molestias prolongadas.
  > Flere beskriver = varias personas describen | langvarige plager = molestias prolongadas
Pasient: Kan søvnkvaliteten være en helseutfordring? = ¿Puede la calidad del sueño ser un problema de salud?
  > søvnkvaliteten = la calidad del sueño | en helseutfordring = un problema de salud
Lege: Dårlig søvn kan gi høy belastning. = Dormir mal puede causar mucha presión.
  > Dårlig søvn = dormir mal | kan gi høy belastning = puede causar mucha presión
Pasient: Hva kan symptomene tyde på? = ¿Qué pueden indicar los síntomas?
  > symptomene = los síntomas | tyde på = indicar
Lege: De kan skyldes flere årsaker. = Pueden deberse a varias causas.
  > De kan skyldes = pueden deberse a | flere årsaker = varias causas
Pasient: Er bivirkningen alvorlig? = ¿Es grave el efecto secundario?
  > bivirkningen = el efecto secundario | alvorlig = grave
Lege: Nei, den er mild, men plagene kan forverres. = No, es leve, pero las molestias pueden empeorar.
  > den er mild = es leve | plagene kan forverres = las molestias pueden empeorar
Pasient: Hvilket behandlingstilbud kan lindre plagene? = ¿Qué servicio de tratamiento puede aliviar las molestias?
  > behandlingstilbud = servicio de tratamiento | lindre plagene = aliviar las molestias
Q ¿Qué comunica «det kan tyde på»?
+ Una posibilidad o interpretación :: La expresión evita presentar la conclusión como segura.
- Una causa demostrada :: «Kan tyde på» no confirma una causa.
- Una instrucción médica :: No es una orden.
R Symptomene kan tyde på en langvarig plage. :: Traduce la frase.
+ Los síntomas pueden indicar una dolencia prolongada. :: «Kan tyde på» expresa posibilidad.
- Los síntomas han curado una dolencia. :: La frase no indica que haya curación.
- La dolencia causa los síntomas con certeza. :: La frase formula una posibilidad.
H Dårlig søvn kan ___ høy belastning. :: Completa «causar».
+ gi :: «Kan» va seguido del infinitivo sin «å».
- gir :: Es presente, no infinitivo.
- gitt :: Es participio.
H Hva kan symptomene ___ på? :: Completa «indicar».
+ tyde :: La expresión es «tyde på».
- lindre :: Significa aliviar.
- påvise :: Significa detectar o demostrar.
A Er bivirkningen alvorlig? :: ¿Qué pregunta el paciente?
+ Si el efecto secundario es grave. :: «Alvorlig» significa grave.
- Si el tratamiento está disponible. :: La pregunta trata de un efecto secundario.
- Si las molestias ya han desaparecido. :: No pregunta por su desaparición.
O Plagene kan forverres selv om bivirkningen er mild. :: Las molestias pueden empeorar aunque el efecto secundario sea leve. :: «Selv om» introduce una concesión.
X Escribe en noruego: «aliviar» :: lindre :: El verbo es «å lindre».
Q ¿Qué significa «helsefremmende»?
+ Beneficioso para la salud :: Describe algo que favorece la salud.
- De larga duración :: Eso es «langvarig».
- Grave :: Eso es «alvorlig».

@ 76 | Psykisk helse og grenser | Salud mental y límites

  > stressnivået = el nivel de estrés | påvirke den psykiske helsen = afectar a la salud mental
Nora: Jeg kjenner en langvarig påkjenning. = Siento una carga prolongada.
  > kjenner = siento | langvarig påkjenning = una carga prolongada
Rådgiver: Slik belastning kan svekke selvfølelsen. = Esa carga puede debilitar la autoestima.
  > Slik belastning = esa carga | svekke selvfølelsen = debilitar la autoestima

  > forebygge = prevenir | utbrenthet = agotamiento
Rådgiver: Det hjelper å sette grenser og hvile. = Ayuda poner límites y descansar.
  > sette grenser = poner límites | hvile = descansar
Nora: Hvordan kan jeg håndtere dette bedre? = ¿Cómo puedo manejar esto mejor?
  > håndtere dette = manejar esto | bedre = mejor
Rådgiver: Pauser og hvile kan gjenopprette balansen. = Las pausas y el descanso pueden restablecer el equilibrio.
  > pauser og hvile = pausas y descanso | gjenopprette balansen = restablecer el equilibrio
Q ¿Qué es «selvfølelse»?
+ La autoestima :: Es cómo una persona se valora a sí misma.
- La calidad del sueño :: Eso es «søvnkvalitet».
- Un efecto secundario :: Eso es «bivirkning».
R Slik belastning kan svekke selvfølelsen. :: Traduce la frase.
+ Esa carga puede debilitar la autoestima. :: «Svekke» significa debilitar.
- La autoestima puede curar cualquier carga. :: La frase no dice eso.
- Esa carga demuestra que el descanso es innecesario. :: La frase propone una posibilidad, no una certeza.
H Det hjelper å ___ grenser. :: Completa «poner».
+ sette :: La expresión es «sette grenser».
- hvile :: Significa descansar.
- svekke :: Significa debilitar.
H Pauser og hvile kan ___ balansen. :: Completa «restablecer».
+ gjenopprette :: Es el infinitivo después de «kan».
- gjenoppretter :: Es presente.
- gjenopprettet :: Es participio.
A Kan jeg forebygge utbrenthet? :: ¿Qué quiere saber Nora?
+ Si puede prevenir el agotamiento. :: «Forebygge» significa prevenir.
- Si puede dormir en el trabajo. :: No pregunta eso.
- Si el agotamiento mejora la autoestima. :: No pregunta por una mejora.
O Det psykiske stressnivået kan påvirke selvfølelsen. :: El nivel de estrés mental puede afectar a la autoestima. :: «Kan» presenta una posibilidad.
X Escribe en noruego: «poner límites» :: sette grenser :: La expresión combina «sette» y «grenser».
Q ¿Qué significa «en påkjenning»?
+ Una carga o experiencia exigente :: Requiere esfuerzo o afecta a la persona.
- Una pausa de descanso :: Eso es «hvile».
- Una medida de salud pública :: Eso no es «påkjenning».
