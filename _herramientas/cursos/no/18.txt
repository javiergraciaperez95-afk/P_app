@ 18 | Enkel matlaging | Cocina sencilla
E Ingredientes y cantidades :: **Oppskrift** significa «receta». En noruego, las medidas suelen ir seguidas del nombre del ingrediente sin artículo: **to desiliter vann** («dos decilitros de agua»). :: **En halv** significa «medio/a» y **litt** expresa una pequeña cantidad; no se usa como el español «un poco de» con una preposición.
W oppskrift = receta | ÓP-skrift
W oppskriften = la receta | ÓP-skrif-ten
W ingrediens = ingrediente | in-gre-di-ÉNS
W ingredienser = ingredientes | in-gre-di-ÉN-ser
W ingrediensene = los ingredientes | in-gre-di-ÉN-se-ne
W mengde = cantidad | MÉNG-de
W gram = gramo(s) | GRAM
W desiliter = decilitro(s) | de-si-LÍ-ter
W teskje = cucharadita | TÉS-she
W spiseskje = cucharada | SPÍ-se-she
W salt = sal | SALT
W løk = cebolla | LÖK
W løken = la cebolla | LÖ-ken
W halv = medio/a | HALV
W en teskje salt = una cucharadita de sal | en TÉS-she SALT
V Vocabulario: recetas y medidas
D En la cocina
Ali: Har du en oppskrift? = ¿Tienes una receta?
  > Har du = tienes | en oppskrift = una receta
Nora: Ja, oppskriften er her. = Sí, la receta está aquí.
  > oppskriften = la receta | er her = está aquí
Ali: Hva trenger vi? = ¿Qué necesitamos?
  > Hva trenger = qué necesitamos | vi = nosotros/as
Nora: Vi trenger litt salt og en halv løk. = Necesitamos un poco de sal y media cebolla.
  > Vi trenger = necesitamos | litt salt = un poco de sal | en halv løk = media cebolla
Ali: Hvor mye vann trenger vi? = ¿Cuánta agua necesitamos?
  > Hvor mye vann = cuánta agua | trenger vi = necesitamos
Nora: To desiliter vann og en teskje salt. = Dos decilitros de agua y una cucharadita de sal.
  > To desiliter vann = dos decilitros de agua | en teskje salt = una cucharadita de sal
Q ¿Qué significa «oppskrift»?
+ Receta. :: Es una guía para preparar algo.
- Ingrediente. :: Eso es «ingrediens».
- Cantidad. :: Eso es «mengde».
R Vi trenger litt salt. :: Traduce la frase.
+ Necesitamos un poco de sal. :: «Litt salt» significa un poco de sal.
- Necesitamos mucha cebolla. :: La frase habla de sal.
- Tenemos una receta nueva. :: «Vi trenger» significa necesitamos.
H Vi trenger ___ salt. :: Completa «un poco de».
+ litt :: «Litt» expresa una pequeña cantidad.
- gram :: Es una unidad de masa.
- oppskriften :: Significa «la receta».
A To desiliter vann. :: ¿Qué cantidad se menciona?
+ Dos decilitros de agua. :: «To» es dos y «vann» es agua.
- Una cucharadita de sal. :: Esa medida es «en teskje salt».
- Media cebolla. :: Eso es «en halv løk».
O En halv løk :: Media cebolla :: «Halv» concuerda con la expresión de cantidad; «løk» es cebolla.
Q ¿Qué palabra significa «ingredientes»?
+ ingredienser :: Es el plural indefinido de «ingrediens».
- ingrediensene :: Lleva la forma definida: «los ingredientes».
- oppskriften :: Significa «la receta».
H Hvor ___ vann trenger vi? :: Completa «cuánta cantidad».
+ mye :: «Hvor mye» pregunta por una cantidad no contable.
- mange :: «Hvor mange» se usa con elementos contables.
- halv :: Significa «medio/a».
X Escribe «una cucharadita de sal» :: en teskje salt :: La medida va seguida directamente del ingrediente.

@ 18 | Kutt og rør | Cortar y remover
E El imperativo :: En muchas instrucciones, el imperativo noruego termina en consonante: **vaske → vask**, **skrelle → skrell** y **skjære → skjær**. :: **Vask** también puede ser un sustantivo («fregadero»); aquí es un verbo porque da una instrucción. **Rør** también significa «tubo», pero en la receta es «remueve».
W vask = lava (imperativo); fregadero | VASK
W skrell = pela (imperativo) | SKREL
W skjær = corta (imperativo) | SHÄR
W hakk = pica (imperativo) | HAK
W bland = mezcla (imperativo) | BLAND
W rør = remueve (imperativo); tubo | RÖR
W hell = vierte (imperativo) | HEL
W kok = cuece; hierve (imperativo) | KOK
W bruk = usa (imperativo) | BRÜK
W gryte = olla | GRÜ-te
W gryta = la olla | GRÜ-ta
W kniv = cuchillo | KNIV
W kniven = el cuchillo | KNÍ-ven
W skjærebrett = tabla de cortar | SHÄ-re-bret
W skjærebrettet = la tabla de cortar | SHÄ-re-bret-tet
W poteten = la patata | pu-TÉ-ten
W gulroten = la zanahoria | GÜL-ru-ten
W biter = trozos | BÍ-ter
V Vocabulario: instrucciones de cocina
D Sigue los pasos
Nora: Vask poteten og gulroten. = Lava la patata y la zanahoria.
  > Vask = lava | poteten og gulroten = la patata y la zanahoria
Ali: Skrell poteten og løken. = Pela la patata y la cebolla.
  > Skrell = pela | poteten og løken = la patata y la cebolla
Nora: Skjær gulroten i biter. = Corta la zanahoria en trozos.
  > Skjær = corta | gulroten i biter = la zanahoria en trozos
Ali: Bruk kniven på skjærebrettet. = Usa el cuchillo sobre la tabla de cortar.
  > Bruk = usa | kniven = el cuchillo | på skjærebrettet = sobre la tabla de cortar
Nora: Hell vann i gryta. = Vierte agua en la olla.
  > Hell = vierte | vann i gryta = agua en la olla
Ali: Kok poteten, og rør i gryta. = Cuece la patata y remueve en la olla.
  > Kok poteten = cuece la patata | og rør i gryta = y remueve en la olla
Q ¿Qué significa «skrell» en una receta?
+ Pela. :: Es una instrucción para quitar la piel.
- Remueve. :: Eso es «rør».
- Vierte. :: Eso es «hell».
R Skjær gulroten i biter. :: Traduce la instrucción.
+ Corta la zanahoria en trozos. :: «Skjær» es el imperativo de «skjære».
- Pela la cebolla en la olla. :: La frase habla de cortar zanahoria.
- Lava el cuchillo y la tabla. :: Eso no es lo que dice la frase.
H ___ poteten og løken. :: Completa «pela».
+ Skrell :: Es el imperativo de «skrelle».
- Skjær :: Significa «corta».
- Hell :: Significa «vierte».
A Bruk kniven på skjærebrettet. :: ¿Dónde se usa el cuchillo?
+ Sobre la tabla de cortar. :: «På skjærebrettet» significa sobre la tabla de cortar.
- Dentro de la olla. :: «I gryta» significa en la olla.
- En la receta. :: «Oppskrift» significa receta.
O Rør i gryta :: Remueve en la olla :: «Rør» es una instrucción; el contexto evita confundirlo con «tubo».
Q ¿Qué significa «gryta»?
+ La olla. :: Es la forma definida de «gryte».
- La zanahoria. :: Eso es «gulrot».
- La tabla de cortar. :: Eso es «skjærebrett».
H Hell vann i ___. :: Completa «la olla».
+ gryta :: «I gryta» significa en la olla.
- kniven :: Significa el cuchillo.
- gulroten :: Significa la zanahoria.
X Escribe «Usa el cuchillo» :: Bruk kniven :: El imperativo «bruk» va antes del objeto.

@ 18 | En enkel oppskrift | Una receta sencilla
E Describir los pasos :: Para contar una receta, **først** significa «primero», **så** significa «luego» y **til slutt** significa «por último». :: En noruego, el presente puede describir instrucciones generales: **Vi koker poteten** («cocemos la patata»). La forma verbal no cambia según quién realiza la acción.
W vasker = lava; lavamos | VÁS-ker
W skreller = pela; pelamos | SKREL-ler
W skjærer = corta; cortamos | SHÄ-rer
W hakker = pica; picamos | HÁ-ker
W blander = mezcla; mezclamos | BLAN-der
W heller = vierte; vertemos | HÉ-ler
W koker = cuece; cocemos | KÓ-ker
W rører = remueve; removemos | RÖ-rer
W serverer = sirve; servimos | ser-VÉ-rer
W gulrot = zanahoria | GÜL-rut
W gulrøtter = zanahorias | GÜL-rö-ter
W grønnsak = verdura | GRÖN-sak
W grønnsakene = las verduras | GRÖN-sak-e-ne
W bit = trozo | BIT
W suppe = sopa | SÚ-pe
W suppen = la sopa | SÚ-pen
W til slutt = por último; al final | til SLÜT
W potetene = las patatas | pu-TÉ-te-ne
V Vocabulario: pasos y preparación
T Slik lager vi suppe
- Først vasker vi poteten og gulroten. = Primero lavamos la patata y la zanahoria.
  > Først vasker vi = primero lavamos | poteten og gulroten = la patata y la zanahoria
- Så skreller vi poteten og løken. = Luego pelamos la patata y la cebolla.
  > Så skreller vi = luego pelamos | poteten og løken = la patata y la cebolla
- Vi skjærer gulroten i biter. = Cortamos la zanahoria en trozos.
  > Vi skjærer = cortamos | gulroten i biter = la zanahoria en trozos
- Vi hakker løken og blander grønnsakene. = Picamos la cebolla y mezclamos las verduras.
  > Vi hakker løken = picamos la cebolla | og blander grønnsakene = y mezclamos las verduras
- Vi heller vannet i gryta og koker potetene. = Echamos el agua en la olla y cocemos las patatas.
  > Vi heller vannet = echamos el agua | i gryta = en la olla | og koker potetene = y cocemos las patatas
- Så rører vi i suppen. = Luego removemos la sopa.
  > Så rører vi = luego removemos | i suppen = en la sopa
- Til slutt serverer vi suppen. = Por último servimos la sopa.
  > Til slutt = por último | serverer vi suppen = servimos la sopa
Q ¿Qué significa «til slutt»?
+ Por último. :: Introduce el último paso.
- Primero. :: Eso es «først».
- Luego. :: Eso es «så».
R Vi heller vannet i gryta. :: Traduce la frase.
+ Echamos el agua en la olla. :: «Heller» es presente de «helle».
- Pelamos la cebolla en la olla. :: «Skreller» significa pela/pelamos.
- Servimos la sopa en la mesa. :: «Serverer» significa sirve/servimos.
H Vi ___ gulroten i biter. :: Completa «cortamos».
+ skjærer :: Es presente de «skjære».
- skreller :: Significa pela/pelamos.
- serverer :: Significa sirve/servimos.
A Vi hakker løken. :: ¿Qué hacemos con la cebolla?
+ La picamos. :: «Hakker» significa pica/picamos.
- La servimos. :: «Serverer» significa sirve/servimos.
- La pelamos. :: «Skreller» significa pela/pelamos.
O Først vasker vi poteten :: Primero lavamos la patata :: «Først» va al principio y el verbo sigue antes del sujeto.
Q ¿Qué se hace al final de la receta?
+ Se sirve la sopa. :: «Til slutt serverer vi suppen» expresa el último paso.
- Se pela la cebolla. :: Eso aparece antes.
- Se corta la zanahoria. :: Ese paso también aparece antes.
H Til slutt ___ vi suppen. :: Completa «servimos».
+ serverer :: «Serverer vi» significa servimos.
- koker :: Significa cocemos.
- vasker :: Significa lavamos.
X Escribe «Luego pelamos la patata y la cebolla» :: Så skreller vi poteten og løken :: «Så» significa luego y el verbo aparece antes de «vi».
