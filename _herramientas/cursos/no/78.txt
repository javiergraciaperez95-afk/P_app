  > kan skifte = puede cambiar | handlingen blir sett = la trama se ve | fra en annen side = desde otra perspectiva

  > karakterutviklingen skjer gradvis = la evolución ocurre gradualmente | stående usagt = sin decir

  > underteksten = el subtexto | tydelig = claro

  > symbolikken = el simbolismo | kan tolkes = puede interpretarse | på flere måter = de varias maneras
Q ¿Qué describe la «synsvinkel»?
+ El punto de vista desde el que se cuenta la historia :: Puede cambiar según quién narra o percibe los hechos.
- La lista de personajes :: Eso no es el punto de vista narrativo.
- El final de la historia :: La palabra no significa final.
R Karakterutviklingen skjer gradvis. :: Traduce la frase.
+ La evolución del personaje ocurre gradualmente. :: «Gradvis» significa gradualmente.
- La trama termina de manera repentina. :: No es lo que dice la frase.
- El protagonista cambia de punto de vista. :: La frase habla de la evolución del personaje.
H Noe blir stående ___. :: Completa «sin decir».
+ usagt :: «Usagt» describe algo que no se expresa directamente.
- flertydig :: Significa ambiguo/a.
- gradvis :: Significa gradualmente.
H Symbolikken kan ___ på flere måter. :: Completa «interpretarse».
+ tolkes :: Es la forma pasiva de «tolke».
- skifter :: Significa cambia.
- oppfatter :: Significa percibe.
A Er underteksten tydelig? :: ¿Qué quiere saber el alumno?
+ Si el subtexto está claro. :: «Undertekst» es subtexto.
- Si la novela tiene muchos personajes. :: No pregunta por personajes.
- Si la historia ya terminó. :: No pregunta por el final.
O Fortellerstemmen skifter, men synsvinkelen er den samme. :: La voz narrativa cambia, pero el punto de vista es el mismo. :: «Men» contrasta dos elementos.
X Escribe en noruego: «protagonista» :: hovedperson :: «Hovedperson» es el personaje principal.
Q ¿Qué significa «flertydig»?
+ Que puede interpretarse de varias maneras :: La palabra se refiere a más de un sentido posible.
- Que se ha contado en orden :: Eso no define la palabra.
- Que se ha dejado de publicar :: No es su significado.

  > skildringen av hovedpersonen = el retrato del protagonista | treffende og overbevisende = acertado y convincente

Q ¿Qué aporta un «helhetsinntrykk»?
+ Resume la impresión general de la obra :: No describe solo un detalle aislado.
- Indica quién escribió el guion :: Eso es información de producción.
- Enumera las escenas de una película :: No es una lista de escenas.
R Romanen er engasjerende, selv om midtdelen er ujevn. :: Traduce la frase.
+ La novela engancha, aunque la parte central es irregular. :: «Selv om» introduce una reserva.

- La parte central es la única que mantiene el interés. :: La frase no dice eso.

Q ¿Para qué sirve mencionar un «forbehold»?

- Para identificar a la persona entrevistada :: Eso es «intervjuperson».
