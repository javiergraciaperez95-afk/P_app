@ 79 | I rettssystemet | En el sistema judicial
E Ord fra en rettssak :: **Tiltalte** es la persona acusada ante un tribunal; un **vitne** cuenta lo que sabe y un **bevis** puede respaldar una explicación. :: **Å anke** es pedir que una decisión judicial sea revisada por una instancia superior.
E Dos pasivas frecuentes :: En textos jurídicos puede aparecer la pasiva con **-s**: **saken ankes** («se apela el caso»). **Bli + participio** presenta la acción: **personen blir frifunnet** («la persona es absuelta»).
W rettssystem = sistema judicial | RETS-süs-TÉM
W rettssak = juicio; proceso judicial | RETS-sak
W domstol = tribunal | DÚM-stul
W dommer = juez | DÚM-mer
W vitne = testigo | VÍT-ne
w vitnet = el/la testigo | VÍT-net
W bevis = prueba; evidencia | be-VÍS
W tiltalt = acusado/a | TÍL-talt
w tiltalte = el/la acusado/a | TÍL-tal-te
W anklage = acusación; acusar | ÁN-kla-ge
w anklages = se acusa | ÁN-kla-ges
W lovbrudd = infracción; delito | LÓV-brud
W forklare seg = declarar; dar su versión | for-KLÁ-re sei
W forklarer seg = declara; da su versión | for-KLÁ-rer sei
W frifinne = absolver | FRÍ-fin-ne
w frifunnet = absuelto/a | FRÍ-fun-net
W dømme = juzgar; condenar | DÖM-me

W rettsforhandling = vista judicial; juicio oral | RETS-for-hand-ling

V Vocabulario: juicio y apelación
D En una conversación sobre un juicio
Student: Det skal være en rettssak neste uke. = Habrá un juicio la semana que viene.
  > rettssak = juicio | neste uke = la semana que viene
Lærer: Hvem er tiltalt? = ¿Quién está acusado?
  > Hvem er = quién es | tiltalt = acusado/a
Student: En person er tiltalt for et lovbrudd. = Una persona está acusada de un delito.
  > tiltalt for = acusado/a de | lovbrudd = delito
Lærer: Hvilke bevis blir lagt fram? = ¿Qué pruebas se presentan?
  > bevis = pruebas | blir lagt fram = se presentan
Student: Et vitne skal forklare seg. = Un testigo va a declarar.
  > vitne = testigo | skal forklare seg = va a declarar
Lærer: Domstolen vurderer forklaringene før den avsier dom. = El tribunal valora las declaraciones antes de dictar sentencia.
  > Domstolen vurderer = el tribunal valora | avsier dom = dicta sentencia
Student: Kan dommeren frifinne den tiltalte? = ¿Puede el juez absolver al acusado?
  > dommeren = el juez | frifinne den tiltalte = absolver al acusado
Lærer: Ja. En dom kan også ankes innen ankefristen. = Sí. Una sentencia también se puede apelar dentro del plazo.
  > dom = sentencia | ankes = se apela | innen ankefristen = dentro del plazo para apelar
Q ¿Qué es un «vitne»?
+ Una persona que declara sobre lo que sabe :: El testigo puede aportar información al juicio.
- La persona que dicta sentencia :: Eso es un «dommer».
- La persona acusada :: Eso es «tiltalt».
R Domstolen vurderer bevisene før den avsier dom. :: Traduce la frase.
+ El tribunal valora las pruebas antes de dictar sentencia. :: «Avsi dom» significa dictar sentencia.
- El acusado apela las pruebas antes del juicio. :: La frase no dice que la persona acusada apele.
- El juez declara antes de presentar las pruebas. :: La frase presenta el orden al revés.
H Et vitne skal ___ seg. :: Completa «declarar».
+ forklare :: La expresión es «forklare seg».
- frifinne :: Significa absolver.
- anke :: Significa apelar.
H En dom kan ___ innen ankefristen. :: Completa «apelarse».
+ ankes :: Es la pasiva con «-s» de «anke».
- anklages :: Significa se acusa.
- dømmes :: Significa se juzga o se condena.
A Hvem er tiltalt? :: ¿Qué pregunta el profesor?
+ Quién está acusado. :: «Tiltalt» es la persona acusada.
- Quién presenta las pruebas. :: Eso no es lo que pregunta.
- Quién puede apelar la sentencia. :: La pregunta es quién está acusado.
O Den tiltalte blir frifunnet hvis bevisene ikke holder. :: La persona acusada es absuelta si las pruebas no son suficientes. :: «Blir + participio» presenta el resultado.
X Escribe en noruego: «plazo para apelar» :: ankefrist :: «Ankefrist» indica hasta cuándo puede apelarse.
Q ¿Qué significa «avsi dom»?
+ Dictar sentencia :: Es la decisión formal del tribunal.
- Presentar una acusación :: Eso es «anklage».
- Declarar como testigo :: Eso es «forklare seg».

@ 79 | Rettssikkerhet og vern | Seguridad jurídica y protección
E Garantías generales :: **Rettssikkerhet** es la protección frente a decisiones arbitrarias. **Uskyldspresumsjon** significa que una persona debe considerarse inocente mientras no se pruebe su culpabilidad. :: **Upartisk** significa imparcial; **uavhengig**, independiente.

V Vocabulario: garantías y asistencia jurídica
D Pedir orientación
Innbygger: Jeg trenger juridisk bistand etter et vedtak. = Necesito asesoramiento jurídico después de una resolución.
  > juridisk bistand = asesoramiento jurídico | etter et vedtak = después de una resolución
Rådgiver: Du kan be om rettshjelp og spørre om innsynsrett. = Puedes pedir asistencia jurídica y preguntar por el derecho de acceso a información.
  > rettshjelp = asistencia jurídica | innsynsrett = derecho de acceso a información
Innbygger: Gjelder klageretten også i denne saken? = ¿Se aplica también el derecho a reclamar en este caso?
  > klageretten = el derecho a reclamar | i denne saken = en este caso
Rådgiver: Det må vurderes konkret. Du kan få advokatbistand. = Hay que valorarlo en concreto. Puedes recibir asistencia de un abogado.
  > vurderes konkret = se valora en concreto | advokatbistand = asistencia de un abogado
Innbygger: Hvordan sikres rettssikkerheten? = ¿Cómo se garantiza la seguridad jurídica?
  > sikres = se garantiza | rettssikkerheten = la seguridad jurídica
Rådgiver: Uavhengige og upartiske vurderinger beskytter den enkelte. = Las valoraciones independientes e imparciales protegen a cada persona.
  > uavhengige og upartiske vurderinger = valoraciones independientes e imparciales | beskytter den enkelte = protegen a cada persona
Innbygger: Og uskyldspresumsjonen gjelder mens saken behandles? = ¿Y se aplica la presunción de inocencia mientras se tramita el caso?
  > uskyldspresumsjonen = la presunción de inocencia | mens saken behandles = mientras se tramita el caso
Rådgiver: Ja, den tiltalte regnes som uskyldig inntil skyld er bevist. = Sí, se considera inocente al acusado hasta que se demuestre su culpabilidad.
  > den tiltalte regnes som uskyldig = se considera inocente al acusado | skyld er bevist = se ha probado la culpabilidad
Q ¿Qué expresa la «uskyldspresumsjon»?
+ Que se considera inocente a la persona hasta que se pruebe su culpabilidad :: Es una garantía general del proceso.
- Que toda persona acusada será condenada :: La presunción expresa lo contrario.
- Que un juicio no necesita pruebas :: Las pruebas son relevantes para el proceso.
R Uavhengige og upartiske vurderinger beskytter den enkelte. :: Traduce la frase.
+ Las valoraciones independientes e imparciales protegen a cada persona. :: «Upartisk» significa imparcial.
- Las personas protegidas deben ser independientes del tribunal. :: La frase describe las valoraciones.
- La asistencia jurídica protege solo al juez. :: No dice eso.
H En ___ vurdering skal ikke favorisere noen av partene. :: Completa «imparcial».
+ upartisk :: No favorece a ninguna de las partes.
- skyldig :: Significa culpable.
- vilkårlig :: Significa arbitrario/a.
H Innbyggeren kan be om juridisk ___. :: Completa «asistencia».
+ bistand :: «Juridisk bistand» es asistencia jurídica.
- skyld :: Significa culpabilidad.
- bevis :: Significa prueba.
A Gjelder klageretten også i denne saken? :: ¿Qué pregunta la persona?
+ Si el derecho a reclamar también se aplica a ese caso. :: «Klagerett» es el derecho a reclamar.
- Si el juez ya dictó sentencia. :: No pregunta por el resultado.
- Si las pruebas son inocentes. :: No pregunta eso.
O Den tiltalte regnes som uskyldig inntil skyld er bevist. :: Se considera inocente al acusado hasta que se demuestre su culpabilidad. :: «Inntil» marca el límite temporal.
X Escribe en noruego: «independiente» :: uavhengig :: «Uavhengig» significa que no depende de otra parte.
Q ¿Qué puede incluir «rettshjelp»?
+ Orientación o asistencia jurídica :: Puede ayudar a comprender un asunto legal.
- Una condena automática :: No es una sentencia.
- Un cambio de escena :: Eso es «sceneskifte».

@ 79 | Begrunne en klage | Justificar una reclamación
E Presentar una reclamación :: **Begrunnelse** es la explicación de los motivos. **Innsigelse** es una objeción formal. **Vedlegg** es un documento añadido a una carta o solicitud. :: En un escrito formal, indica a qué decisión te refieres, explica el motivo y adjunta la documentación pertinente.
E Subordinadas de excepción :: **Med mindre** significa «a menos que» y presenta una excepción: **Saken avsluttes ikke med mindre nye opplysninger kommer fram**. :: Después de **dersom** («si») y **med mindre**, la subordinada mantiene el orden sujeto + verbo.

W grunnlag = fundamento; base | GRÜN-lag

W klagefrist = plazo para reclamar | KLÁ-ge-frist
W redegjøre = exponer; explicar detalladamente | re-de-YÖ-re

D Una carta sobre una decisión
Innbygger: Jeg viser til vedtaket datert 4. mai. = Me refiero a la resolución fechada el 4 de mayo.
  > viser til vedtaket = me refiero a la resolución | datert 4. mai = fechada el 4 de mayo
Saksbehandler: Hva er grunnlaget for klagen? = ¿Cuál es el fundamento de la reclamación?
  > grunnlaget = el fundamento | for klagen = de la reclamación
Innbygger: Begrunnelsen mangler opplysninger om saksbehandlingen. = A la justificación le faltan datos sobre la tramitación.
  > begrunnelsen = la justificación | opplysninger om saksbehandlingen = datos sobre la tramitación
Saksbehandler: Kan du redegjøre for innsigelsen? = ¿Puedes explicar detalladamente la objeción?
  > redegjøre for = explicar detalladamente | innsigelsen = la objeción
Innbygger: Ja. Vedlagt følger dokumentasjon som underbygger klagen. = Sí. Adjunto se incluye documentación que respalda la reclamación.
  > Vedlagt følger dokumentasjon = se adjunta documentación | underbygger klagen = respalda la reclamación
Saksbehandler: Dersom du finner en feil, kan du be om at vedtaket korrigeres. = Si encuentras un error, puedes pedir que se corrija la resolución.
  > Dersom du finner en feil = si encuentras un error | be om at vedtaket korrigeres = pedir que se corrija la resolución
Innbygger: Kan saken vurderes på nytt med mindre fristen er oversittet? = ¿Se puede volver a evaluar el caso, a menos que haya vencido el plazo?
  > vurderes på nytt = se evalúa de nuevo | med mindre fristen er oversittet = a menos que haya vencido el plazo
Saksbehandler: Klagefristen står i brevet. = El plazo para reclamar aparece en la carta.
  > Klagefristen = el plazo para reclamar | står i brevet = aparece en la carta
Q ¿Qué es un «vedlegg»?
+ Un documento adjunto :: Se añade a una carta o solicitud.
- Una objeción oral :: Eso es «innsigelse».
- Una persona testigo :: Eso es «vitne».
R Vedlagt følger dokumentasjon som underbygger klagen. :: Traduce la frase.
+ Se adjunta documentación que respalda la reclamación. :: «Underbygge» significa respaldar con pruebas.
- La reclamación documenta que se ha vencido el plazo. :: La frase dice que la documentación respalda la reclamación.
- Se corrige una objeción sin aportar información. :: No es lo que dice.
H ___ du finner en feil, kan du be om en ny vurdering. :: Completa «si».
+ Dersom :: Introduce una condición.
- Likevel :: Significa aun así.
- Med mindre :: Significa a menos que.
H Dokumentasjonen kan ___ klagen. :: Completa «respaldar con pruebas».
+ underbygge :: Es el infinitivo después de «kan».
- redegjøre :: Significa explicar detalladamente.
- korrigere :: Significa corregir.
A Klagefristen står i brevet. :: ¿Dónde aparece el plazo?
+ En la carta. :: «Står i brevet» significa aparece en la carta.
- En el testimonio. :: «Vitne» significa testigo.
- En una grabación. :: Eso es «opptak».
O Med mindre nye opplysninger kommer fram, avsluttes saken. :: A menos que aparezcan datos nuevos, se cierra el caso. :: «Med mindre» introduce una excepción.
X Escribe en noruego: «objeción formal» :: innsigelse :: «En innsigelse» expresa desacuerdo fundamentado.
Q ¿Qué debe contener una reclamación bien explicada?
+ Referencia a la decisión, motivos y documentos pertinentes :: Así se presenta y respalda una solicitud de revisión.
- Solo una opinión sin fundamento :: La explicación necesita motivos.
- Únicamente la fecha de una vista :: No basta para explicar una reclamación.
