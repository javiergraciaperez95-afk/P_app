@ 5 | Dagen en tijd | Decir los días y la hora
I Aprendemos los días de la semana, las horas del día y la inversión temporal obligatoria.
E Días, horas e inversión sintáctica :: Los días de la semana en neerlandés son: maandag (lunes), dinsdag (martes), woensdag (miércoles), donderdag (jueves), vrijdag (viernes), zaterdag (sábado), zondag (domingo). Para preguntar la hora: «Hoe laat is het?» (¿Qué hora es?) y para responder: «Het is acht uur» (Son las ocho en punto). ¡Regla de oro de inversión!: si empiezas la frase con un complemento de tiempo como «Vandaag», el verbo se coloca obligatoriamente en 2ª posición y el sujeto pasa a la 3ª: «Vandaag is het maandag» (y nunca *Vandaag het is...).
W maandag = lunes
W dinsdag = martes
W woensdag = miércoles
W donderdag = jueves
W vrijdag = viernes
W zaterdag = sábado
W zondag = domingo
W week = semana
W tijd = tiempo
W hoe laat = qué hora
W uur = hora en punto
W half = media
W morgen = mañana
W welke = qué
V Vocabulario clave
D En una situación cotidiana
Luca: Welke dag is het vandaag? = ¿Qué día es hoy?
  > Welke dag = qué día | is het = es | vandaag = hoy
Sara: Vandaag is het maandag. = Hoy es lunes.
  > Vandaag = hoy | is het = es | maandag = lunes
Luca: Hoe laat is het? = ¿Qué hora es?
  > Hoe laat = qué hora | is het = es
Sara: Het is acht uur. = Son las ocho.
  > Het is = son las | acht uur = ocho en punto
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «lunes»?
+ maandag :: «Maandag» es el primer día de la semana.
- dinsdag :: Corresponde al «martes».
- woensdag :: Corresponde al «miércoles».
R Vandaag is het maandag. :: ¿Qué significa esta frase y qué orden sigue?
+ Hoy es lunes. :: Comienza con «Vandaag», obligando a invertir: verbo is + sujeto het.
- Mañana será martes por la mañana. :: No habla de mañana ni de futuro.
- El lunes no tenemos clase de neerlandés. :: No es una frase negativa.
H Vandaag is het ___. :: Completa la frase: «Hoy es lunes».
+ maandag :: Es el día lunes en neerlandés.
- dinsdag :: Es el día martes.
- week :: Significa «semana», no es un día concreto.
R Hoe laat is het? :: ¿Qué pregunta Luca?
+ ¿Qué hora es? :: Es la expresión estándar para pedir la hora actual.
- ¿Qué día de la semana es? :: Preguntaría «Welke dag is het?».
- ¿Cuánto tiempo libre tienes? :: Preguntaría por tiempo disponible.
O Welke dag is het vandaag :: ¿Qué día es hoy? :: Pregunta interrogativa con inversión: Welke dag + is + het + vandaag.
Q ¿Qué día de la semana es «donderdag»?
+ jueves :: «Donderdag» es el jueves.
- viernes :: «Viernes» se dice «vrijdag».
- sábado :: «Sábado» se dice «zaterdag».
R Het is acht uur. :: Elige la traducción correcta de la hora.
+ Son las ocho. :: «Acht uur» indica las ocho en punto.
- Son las siete y media. :: Siete y media usaría «half».
- Son las nueve en punto. :: Nueve sería «negen uur».


@ 5 | Mijn dag | Describir una rutina
I Aprendemos a describir la rutina diaria con verbos separables como «opstaan» y complementos de hora con «om».
E Rutina y verbos separables :: En neerlandés muchos verbos cotidianos son separables: el prefijo se separa y se coloca al final de la frase principal. «Opstaan» (levantarse) se conjuga: «Ik sta om zeven uur op» (el prefijo «op» va al final). Para indicar la hora exacta de una acción se usa la preposición «om»: «om zeven uur» (a las siete). Para indicar el lugar de estudio: «thuis» (en casa).
W opstaan = levantarse
W sta op = me levanto
W ontbijten = desayunar
W ontbijt = desayuno
W leren = aprender
W eten = comer
W drink = bebo
W slapen = dormir
W slaap = duermo
W elke dag = cada día
W thuis = en casa
w nee = no
w sta = me levanto; estoy de pie
w om = a; a las
V Vocabulario clave
D En una situación cotidiana
Anna: Hoe laat sta je op? = ¿A qué hora te levantas?
  > Hoe laat = a qué hora | sta je = te levantas tú | op = parte separable de opstaan
Tom: Ik sta om zeven uur op. = Me levanto a las siete.
  > Ik sta = yo me levanto | om zeven uur = a las siete | op = parte separable
Anna: Werk je vandaag? = ¿Trabajas hoy?
  > Werk je = trabajas tú | vandaag = hoy
Tom: Nee, ik leer thuis. = No, estudio en casa.
  > Nee = no | ik leer = yo aprendo | thuis = en casa
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo «levantarse»?
+ opstaan :: Es el verbo separable «opstaan» (op + staan).
- ontbijten :: Significa «desayunar».
- slapen :: Significa «dormir».
R Ik sta om zeven uur op. :: ¿Qué significa esta frase y qué ocurre con «op»?
+ Me levanto a las siete. :: «Opstaan» se separa: «sta» va en segunda posición y «op» al final.
- Me acuesto siempre a las siete. :: No habla de acostarse.
- Empiezo a trabajar a las ocho. :: No habla de empezar a trabajar.
H Ik ___ om zeven uur op. :: Completa con la forma verbal conjugada de «opstaan».
+ sta :: Con «ik» se conjuga «sta», y el prefijo «op» queda al final.
- slaap :: Es el verbo dormir («ik slaap»).
- ontbijt :: Es el verbo desayunar («ik ontbijt»).
R Werk je vandaag? :: ¿Qué pregunta Anna?
+ ¿Trabajas hoy? :: Pregunta si hoy desempeña su jornada laboral.
- ¿Estudias en la escuela hoy? :: Preguntaría con «leer je» o «studeer je».
- ¿A qué hora sales de casa? :: Preguntaría por la hora de salida.
O Hoe laat sta je op :: ¿A qué hora te levantas? :: Inversión interrogativa: Hoe laat + sta (verbo) + je (sujeto) + op (partícula separable al final).
Q ¿Qué significa el sustantivo «ontbijt»?
+ desayuno :: «Het ontbijt» es la primera comida del día.
- cena :: «Cena» es «avondeten».
- almuerzo :: «Almuerzo» es «lunch».
R Nee, ik leer thuis. :: Elige la traducción correcta.
+ No, estudio en casa. :: «Leren» es aprender/estudiar y «thuis» es en casa.
- Sí, voy a la oficina ahora. :: Contrario a lo que expresa.
- No, descanso en el jardín. :: No menciona descanso ni jardín.


@ 5 | Afspraken en planning | Concertar una cita y hablar de horarios
I Aprendemos a concertar citas y proponer planes con «zullen we» y complementos de tiempo.
E Concertar citas y propuestas con «zullen» :: Para hacer una propuesta amable a alguien se usa «Zullen we... + infinitivo al final?»: «Zullen we om tien uur afspreken?» (¿Quedamos a las diez?). Para confirmar disponibilidad decimos «Ik ben vrij» (Estoy libre) o «Ik ben beschikbaar» (Estoy disponible). Para despedirte fijando la cita: «Tot morgen!» (¡Hasta mañana!).
W afspraak = cita
W afspreken = quedar
W om = a las
W van = de
W tot = hasta
W beginnen = empezar
W begin = empiezo
W eindigen = terminar
W eindigt = termina
W vrij = libre
W beschikbaar = disponible
W later = más tarde
W nu = ahora
W samen = juntos
w heb = tengo
w we = nosotros; nosotras
w zullen = vamos a; auxiliar de propuesta
V Vocabulario clave
D En una situación cotidiana
Noor: Heb je morgen tijd? = ¿Tienes tiempo mañana?
  > Heb je = tienes tú | morgen = mañana | tijd = tiempo
Luca: Ja, ik ben vrij. = Sí, estoy libre.
  > Ja = sí | ik ben vrij = estoy libre
Noor: Zullen we om tien uur afspreken? = ¿Quedamos a las diez?
  > Zullen we = quedamos nosotros | om tien uur = a las diez | afspreken = quedar
Luca: Goed. Tot morgen! = Vale. ¡Hasta mañana!
  > Goed = bien, de acuerdo | Tot morgen = hasta mañana
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «cita»?
+ afspraak :: «De afspraak» es la cita o compromiso acordado.
- tijd :: Significa «tiempo».
- week :: Significa «semana».
R Ja, ik ben vrij. :: ¿Qué responde Luca?
+ Sí, estoy libre. :: Confirma que no tiene compromisos y tiene disponibilidad.
- No, tengo que trabajar toda la tarde. :: Diría que está ocupado («ik ben druk»).
- Quizás más tarde pueda avisarte. :: Expresaría duda, no confirmación.
H Zullen we om tien uur ___? :: Completa con el infinitivo al final tras el auxiliar «zullen».
+ afspreken :: El auxiliar «zullen» exige el infinitivo al final de la oración.
- afspraak :: Es el sustantivo («cita»), no el verbo en infinitivo.
- begin :: Es la forma conjugada de primera persona («yo empiezo»).
R Zullen we om tien uur afspreken? :: ¿Qué propone Noor en esta frase?
+ ¿Quedamos a las diez? :: Propone una hora de encuentro con la estructura «Zullen we... afspreken?».
- ¿Termina la clase a las diez? :: Preguntaría con «eindigen».
- ¿Podemos estudiar juntos a las nueve? :: Menciona las diez («tien uur»), no las nueve.
O Heb je morgen tijd :: ¿Tienes tiempo mañana? :: Pregunta de confirmación: verbo Heb + sujeto je + tiempo morgen + objeto tijd.
Q ¿Qué preposición expresa origen temporal «desde» o «de»?
+ van :: Se usa en correlación con «tot»: «van tien tot elf» (de diez a once).
- om :: Significa «a las» con una hora fija.
- met :: Significa «con».
R Goed. Tot morgen! :: Elige la traducción correcta de la despedida.
+ Vale. ¡Hasta mañana! :: «Goed» acepta la propuesta y «Tot morgen» despide hasta el día siguiente.
- Mal. Hasta la próxima semana. :: «Slecht» sería mal; «volgende week», próxima semana.
- De acuerdo. Hasta luego en la noche. :: «Tot vanavond» sería hasta la noche.
