N Sara, Tom, Klant, Verkoper

@ 16 | Dagen en datums | Días y fechas
I Lee e interpreta fechas y días de la semana para organizar actividades cotidianas.
E Días y fechas en neerlandés :: Los días de la semana y los meses del año se escriben en minúscula en neerlandés: «maandag» (lunes), «vrijdag» (viernes), «zaterdag» (sábado), «maart» (marzo). Para indicar la fecha en que sucede un acontecimiento se antepone la preposición «op»: «op maandag 12 maart» (el lunes 12 de marzo).
W datum = fecha
W toets = examen; prueba
w dus = por tanto; entonces
V Días y calendario
D En una situación cotidiana
Sara: Wanneer begint de cursus? = ¿Cuándo empieza el curso?
  > Wanneer begint = cuándo empieza | de cursus = el curso
Tom: Op maandag 12 maart. = El lunes 12 de marzo.
  > Op maandag = el lunes | 12 maart = 12 de marzo
Sara: En wanneer is de eerste toets? = ¿Y cuándo es el primer examen?
  > En = y | wanneer is = cuándo es | de eerste toets = el primer examen
Tom: Op vrijdag 23 maart. = El viernes 23 de marzo.
  > Op vrijdag = el viernes | 23 maart = 23 de marzo
Sara: Dus niet op zaterdag? = Entonces, ¿no es el sábado?
  > Dus niet = entonces no | op zaterdag = en sábado; el sábado
Q ¿Con qué preposición se introduce un día o una fecha concreta en neerlandés?
+ op :: Se utiliza «op» para días y fechas («op maandag», «op 12 maart»).
- in :: «In» se reserva para meses aislados o años («in maart», «in 2026»).
- bij :: «Bij» expresa proximidad física o compañía («junto a / en casa de»).
R Wanneer begint de cursus? :: ¿Qué fecha indica Tom para el inicio del curso?
+ El lunes 12 de marzo. :: «Op maandag 12 maart» es el lunes 12 de marzo.
- El viernes 23 de marzo. :: El 23 de marzo es la fecha del primer examen, no el inicio del curso.
- El sábado 24 de marzo. :: Sara aclara expresamente que el sábado no hay actividad lectiva.
H En wanneer is de eerste ___? :: Completa para preguntar por el primer examen.
+ toets :: «Toets» significa examen o prueba de evaluación.
- datum :: «Datum» significa fecha en general, no la prueba en sí.
- les :: Aunque significa clase, el diálogo pregunta específicamente por «de eerste toets».
R Dus niet op zaterdag? :: ¿Qué deduce Sara tras escuchar la respuesta de Tom?
+ Que el examen no se celebra en sábado. :: «Dus niet op zaterdag» confirma que no cae en sábado sino en viernes.
- Que el curso se ha cancelado definitivamente :: No se cancela nada; solo constata qué día no hay prueba.
- Que el examen durará todo el fin de semana :: Sara comprueba que el sábado queda libre de examen.
H Op ___ 23 maart. :: Completa con el día de la semana correspondiente a la fecha del examen.
+ vrijdag :: El examen se realiza en viernes («vrijdag»).
- maandag :: El lunes 12 de marzo es el inicio del curso.
- zaterdag :: Sara confirma que precisamente no cae en sábado.
O Wanneer begint de cursus :: ¿Cuándo empieza el curso? :: Pregunta temporal con «wanneer» y verbo en segunda posición.

@ 16 | Prijzen vragen | Preguntar por precios
I Pregunta por el precio de artículos individuales y en conjunto y comprende el coste total.
E Preguntar y expresar precios :: Para preguntar el precio de un artículo individual se usa «Hoeveel kost dit / deze appel?» (¿Cuánto cuesta...?). Si se trata de varios artículos en plural se emplea la forma en -en: «Hoeveel kosten drie appels?» (¿Cuánto cuestan...?). La expresión «per stuk» significa «por unidad» o «cada uno».
W per stuk = por unidad; cada uno
w stuk = pieza; unidad
w appels = manzanas
V Precios en el mercado
D En una situación cotidiana
Klant: Goedemiddag, hoeveel kost deze appel? = Buenas tardes, ¿cuánto cuesta esta manzana?
  > Goedemiddag = buenas tardes | hoeveel kost = cuánto cuesta | deze appel = esta manzana
Verkoper: Één euro per stuk. = Un euro por unidad.
  > Één euro = un euro | per stuk = por pieza; por unidad
Klant: En hoeveel kosten drie appels? = ¿Y cuánto cuestan tres manzanas?
  > En = y | hoeveel kosten = cuánto cuestan | drie appels = tres manzanas
Verkoper: Samen twee euro vijftig. = Dos euros con cincuenta en total.
  > Samen = juntos; en total | twee euro vijftig = dos euros con cincuenta
Klant: Dat is niet duur. = No es caro.
  > Dat is = eso es | niet duur = no caro; barato
Q ¿Qué diferencia hay entre «kost» y «kosten» al preguntar precios?
+ «Kost» se usa para un artículo singular y «kosten» para varios en plural :: Concordancia obligatoria con el sujeto gramatical.
- «Kost» es la forma formal con «u» y «kosten» la informal :: Ambas formas dependen del número del sustantivo, no del tratamiento de cortesía.
- «Kost» se usa para alimentos y «kosten» para ropa u objetos :: El tipo de mercancía no altera la conjugación del verbo.
R Één euro per stuk. :: ¿Cuánto cuesta cada manzana por separado?
+ Un euro por unidad. :: «Per stuk» especifica el precio de cada unidad individual.
- Dos euros y medio por unidad. :: Dos con cincuenta es el precio por las tres manzanas juntas.
- Cincuenta céntimos por unidad. :: El texto indica un euro («één euro»).
H En hoeveel ___ drie appels? :: Completa con la forma verbal plural adecuada para tres manzanas.
+ kosten :: Con el sujeto plural «drie appels» el verbo concierta en plural («kosten»).
- kost :: Es la forma de singular, válida solo para una manzana («deze appel kost»).
- stuk :: Es un sustantivo («unidad»), no la forma verbal conjugada.
R Samen twee euro vijftig. :: ¿Cuál es el precio conjunto ofrecido por el vendedor?
+ Dos euros con cincuenta céntimos en total. :: «Samen» indica el coste total combinado.
- Tres euros en total con descuento. :: El importe exacto es 2,50 euros.
- Un euro con cincuenta por las tres. :: Confunde cincuenta céntimos con un euro y medio.
H Goedemiddag, ___ kost deze appel? :: Completa para preguntar cuánto cuesta la manzana.
+ hoeveel :: «Hoeveel» es el interrogativo cuantitativo para preguntar «cuánto».
- wie :: «Wie» pregunta por personas («quién»).
- waar :: «Waar» indaga por lugares («dónde»).
O Goedemiddag, hoeveel kost deze appel :: Buenas tardes, ¿cuánto cuesta esta manzana? :: Saludo inicial, interrogativo de cantidad y verbo conjugado en singular.

@ 16 | Een bon lezen | Leer un recibo
I Interpreta un comprobante o recibo de compra con artículos, importes y forma de pago.
E Lectura de comprobantes de compra :: En un recibo de compra («kassabon» o «bon»), los importes se desglosan por producto, especificando en ocasiones el número de piezas («stuks»). Al final figuran el importe total acumulado («totaal») y la modalidad de pago utilizada («betaald met kaart» o «contant»).
W aantal = cantidad
W totaal = total
W betaald = pagado
w bon = recibo; tíquet
w stuks = unidades; piezas
V Términos de compras
T Texto breve
- Brood: 1,20 euro. = Pan: 1,20 euros.
  > Brood = pan | 1,20 euro = 1,20 euros
- Melk: 1,45 euro. = Leche: 1,45 euros.
  > Melk = leche | 1,45 euro = 1,45 euros
- Appels, 3 stuks: 2,50 euro. = Manzanas, 3 unidades: 2,50 euros.
  > Appels = manzanas | 3 stuks = 3 piezas; 3 unidades | 2,50 euro = 2,50 euros
- Totaal: 5,15 euro. = Total: 5,15 euros.
  > Totaal = total | 5,15 euro = 5,15 euros
- Betaald met kaart. = Pagado con tarjeta.
  > Betaald = pagado | met kaart = con tarjeta
Q En un recibo comercial, ¿qué indica la anotación «3 stuks»?
+ Tres piezas o unidades del producto :: «Stuks» es el plural de «stuk» y expresa unidades contables.
- Un descuento especial del 3% en caja :: No representa ningún porcentaje de descuento.
- El número de lote de expedición :: Expresa la cantidad física adquirida.
R Betaald met kaart. :: ¿De qué manera se ha abonado la compra?
+ Se ha pagado con tarjeta bancaria. :: «Betaald met kaart» indica pago con tarjeta (de débito o crédito).
- Se ha pagado en efectivo con monedas exactas. :: En efectivo sería «contant betaald».
- El cliente tiene pendiente el pago para fin de mes. :: La forma «betaald» certifica que la transacción ya se ha completado.
H Totaal: 5,15 ___. :: Completa con la divisa en que se expresa el importe.
+ euro :: Los precios en los Países Bajos y Bélgica se expresan en «euro» (invariable tras cifra).
- cent :: 5,15 representa euros y céntimos, la palabra principal de la unidad monetaria es euro.
- stuks :: «Stuks» cuantifica artículos, no moneda.
Q ¿Cuál es el importe total del recibo según el desglose?
+ 5,15 euros :: El campo «Totaal» marca exactamente 5,15 euros.
- 2,50 euros :: 2,50 euros corresponde solo a las tres manzanas.
- 1,20 euros :: 1,20 euros es el coste del pan.
R Appels, 3 stuks: 2,50 euro. :: ¿Qué producto y coste refleja este apunte del recibo?
+ Tres manzanas por un importe conjunto de 2,50 euros. :: Especifica 3 unidades de fruta con su precio total.
- Una manzana por 2,50 euros la unidad. :: 2,50 euros es el precio de las tres juntas.
- Tres bolsas de leche fresca por 2,50 euros. :: El artículo detallado son manzanas («appels»), no leche.
H Melk: 1,45 ___. :: Completa la línea del recibo con la unidad monetaria.
+ euro :: La unidad monetaria tras la cifra decimal es «euro».
- stuks :: La leche se mide en envases o litros, y el importe va en «euro».
- totaal :: «Totaal» es la línea sumatoria final del tíquet.
O Betaald met kaart :: Pagado con tarjeta. :: Participio de pago seguido del medio con preposición instrumental «met».
