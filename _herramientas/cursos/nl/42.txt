N Anna, Tom, Noor, Mila, Amir, Utrecht

@ 12 | Zijn in het dagelijks leven | El verbo zijn
I Usa formas frecuentes de zijn para identificar a personas y describir cómo están.
E Formas de zijn e inversión :: En presente de indicativo, el verbo irregular «zijn» (ser/estar) tiene las formas: «ik ben» (yo soy/estoy), «jij bent» (tú eres/estás), «u bent» (usted es/está), «hij/zij/het is» (él/ella/ello es/está) y «wij/jullie/zij zijn» (nosotros/vosotros/ellos son o están). Regla clave: en preguntas o tras inversión con el pronombre de segunda persona «jij/je» en posición posverbal, el verbo pierde obligatoriamente la -t final: «Ben je ziek?» (¿estás enfermo?).
w bent = eres; estás
w klaar = listo; preparado
w alleen = solamente; solo
w zij = ella
V Formas básicas
D En una situación cotidiana
Anna: Ik ben vandaag moe. = Hoy estoy cansada.
  > Ik ben = yo estoy | vandaag = hoy | moe = cansada
Tom: Ben je ziek? = ¿Estás enferma?
  > Ben je = estás tú | ziek = enferma
Anna: Nee, ik ben alleen laat gaan slapen. = No, solo me acosté tarde.
  > Nee = no | ik ben = yo he | alleen = solamente | laat gaan slapen = acostado tarde
Tom: Is Noor al klaar? = ¿Noor ya está lista?
  > Is Noor = está Noor | al klaar = ya lista
Anna: Ja, zij is klaar voor de les. = Sí, está lista para la clase.
  > Ja = sí | zij is klaar = ella está lista | voor de les = para la clase
Q ¿Qué forma adopta el verbo «zijn» cuando se invierte ante «je» en una pregunta?
+ ben :: Al pasar el verbo delante de «jij/je» en una pregunta, la terminación -t desaparece («Ben je...?»).
- bent :: «Bent» es la forma afirmativa ordinaria («jij bent»), pero pierde la -t en inversión («ben je»).
- is :: «Is» corresponde a la tercera persona del singular («hij/zij/het is»).
R Ik ben vandaag moe. :: ¿Cómo se encuentra Anna hoy?
+ Hoy está cansada. :: «Moe» significa cansada y «vandaag» es hoy.
- Hoy está muy enferma. :: No dice estar enferma, solo cansada por dormir tarde.
- Hoy está lista para salir. :: Confunde «moe» con «klaar» (lista).
H Ben ___ ziek? :: Completa la pregunta dirigida a una persona de confianza.
+ je :: «Ben je» es la combinación correcta con inversión; la forma pierde la -t.
- u :: Con «u» se mantendría la -t: «Bent u...?».
- hij :: Con «hij» la forma correcta del verbo sería «Is hij...?».
Q ¿Cómo se dice en neerlandés «ella está lista»?
+ Zij is klaar. :: «Zij» es el pronombre femenino ella, «is» la tercera persona y «klaar» significa lista.
- Ik ben klaar. :: Significa «yo estoy listo/a».
- Jij bent moe. :: Significa «tú estás cansado/a».
R Is Noor al klaar? :: ¿Qué quiere averiguar Tom sobre Noor?
+ Si Noor ya está lista. :: «Al» significa ya y «klaar» lista o preparada.
- Si Noor se encuentra enferma hoy. :: No pregunta por enfermedad, sino por si está lista.
- Si Noor va a llegar tarde a clase. :: No menciona la hora de llegada, solo si está preparada.
H Ja, zij is klaar voor de ___. :: Completa la frase indicando la actividad para la que está lista.
+ les :: «De les» significa la clase o la lección.
- tas :: «Tas» significa bolso y no encaja con la preposición «voor de».
- fiets :: «Fiets» significa bicicleta.
O Ik ben vandaag moe :: Hoy estoy cansada. :: Sujeto («ik»), verbo en segunda posición («ben») y adjetivo final.

@ 12 | Hebben en wat je bezit | El verbo hebben y las pertenencias
I Habla de lo que tienes con hebben y pregunta por pertenencias cotidianas.
E El verbo hebben y la necesidad :: El verbo «hebben» (tener o haber) se conjuga: «ik heb», «jij hebt» (o «heb je?» en inversión sin -t), «hij/zij heeft», «wij/jullie/zij hebben». La estructura «nodig hebben» equivale en español a «necesitar»: «Heb jij een fiets nodig?» (¿necesitas una bicicleta?).
w hebben = tener
w hebt = tienes
w tas = bolso
w sleutel = llave
w nodig = necesario; necesitar
V Vocabulario de posesión
D En una situación cotidiana
Mila: Heb je mijn sleutel gezien? = ¿Has visto mi llave?
  > Heb je = has tú | mijn sleutel = mi llave | gezien = visto
Amir: Nee, maar ik heb jouw tas hier. = No, pero tengo aquí tu bolso.
  > Nee = no | maar = pero | ik heb = yo tengo | jouw tas = tu bolso | hier = aquí
Mila: Heb jij ook een fiets nodig? = ¿También necesitas una bicicleta?
  > Heb jij = tienes tú | ook = también | een fiets = una bicicleta | nodig = necesidad; necesitar
Amir: Nee, ik ik heb al een fiets. = No, ya tengo una bicicleta.
  > Nee = no | ik heb = yo tengo | al = ya | een fiets = una bicicleta
Mila: Fijn, dan hebben we alles. = Bien, entonces tenemos todo.
  > Fijn = bien; estupendo | dan hebben we = entonces tenemos | alles = todo
Q ¿Cómo se expresa en neerlandés «necesitas una bicicleta» con la perífrasis «nodig hebben»?
+ Heb jij een fiets nodig? :: La combinación de «hebben» con el adjetivo «nodig» al final expresa necesidad.
- Heb jij een fiets hier? :: «Hier» indica lugar («aquí»), no necesidad.
- Is jouw fiets al klaar? :: Pregunta si la bicicleta está lista, no si la necesita.
R Heb je mijn sleutel gezien? :: ¿Qué objeto está buscando Mila?
+ Su llave. :: «Sleutel» significa llave.
- Su bolso de viaje. :: El bolso es «tas», mencionado después por Amir.
- Su bicicleta nueva. :: La bicicleta es «fiets», que comentan a continuación.
H Nee, maar ik heb jouw ___ hier. :: Completa con la palabra que indica el bolso que tiene Amir.
+ tas :: «Jouw tas» significa tu bolso.
- sleutel :: Amir aclara que no tiene la llave, sino el bolso.
- les :: «Les» significa lección.
R Fijn, dan hebben we alles. :: ¿Qué concluye Mila al final del diálogo?
+ Estupendo, entonces lo tenemos todo. :: «Fijn» es bien/estupendo, «dan» es entonces y «alles» es todo.
- Qué lástima, nos falta la llave. :: Dice lo contrario: concluye con alivio que ya lo tienen todo.
- Por favor, busca mi bolso enseguida. :: No es una orden ni una petición, sino una confirmación.
H Dan ___ we alles. :: Completa con la forma correcta de primera persona del plural de hebben.
+ hebben :: Con el sujeto plural «we» (nosotros) se utiliza el infinitivo conjugado «hebben».
- heb :: «Heb» es la forma exclusiva de primera persona del singular («ik heb»).
- hebt :: «Hebt» se usa con la segunda persona («jij hebt»).
O Heb je mijn sleutel gezien :: ¿Has visto mi llave? :: Pregunta de sí o no con inversión inicial del verbo auxiliar.

@ 12 | Werkwoorden in de tegenwoordige tijd | Verbos frecuentes en presente
I Construye frases afirmativas en presente con verbos cotidianos y respeta la posición V2.
E Conjugación regular y orden V2 :: En neerlandés, el presente regular se forma con la raíz para «ik» (werk, woon, kook), la raíz + -t para «jij/hij/zij» (werkt, woont, kookt) y la forma en -en para los plurales «wij/jullie/zij» (werken, wonen, koken). Si la frase empieza por un complemento circunstancial de tiempo o lugar («Elke dag...», «Na het werk...»), el verbo conjugado se mantiene obligatoriamente en segunda posición y el sujeto pasa a la tercera (inversión sujeto-verbo).
W leert = aprende
W kookt = cocina
W bezoeken = visitamos; visitar
w wij = nosotros
V Verbos de rutina
T Texto breve
- Ik woon in Utrecht en ik werk in een café. = Vivo en Utrecht y trabajo en una cafetería.
  > Ik woon = yo vivo | in Utrecht = en Utrecht | en = y | ik werk = yo trabajo | in een café = en una cafetería
- Mijn broer leert Nederlands op school. = Mi hermano aprende neerlandés en la escuela.
  > Mijn broer = mi hermano | leert = aprende | Nederlands = neerlandés | op school = en la escuela
- Elke dag oefenen wij samen. = Cada día practicamos juntos.
  > Elke dag = cada día | oefenen wij = practicamos nosotros | samen = juntos
- Na het werk kookt mijn broer thuis. = Después del trabajo mi hermano cocina en casa.
  > Na het werk = después del trabajo | kookt = cocina | mijn broer = mi hermano | thuis = en casa
- In het weekend bezoeken we onze vrienden. = El fin de semana visitamos a nuestros amigos.
  > In het weekend = el fin de semana | bezoeken we = visitamos nosotros | onze vrienden = a nuestros amigos
Q ¿Qué terminación recibe la raíz verbal en presente con el sujeto «hij» (mi hermano)?
+ Se añade -t a la raíz del verbo :: «Koken» tiene raíz «kook» y con «mijn broer» (hij) da «kookt».
- Se añade -en como en el plural :: La terminación -en se reserva para las formas del plural (wij, jullie, zij).
- Se deja la raíz desnuda sin ninguna desinencia :: La raíz sola corresponde a la primera persona «ik».
R Na het werk kookt mijn broer thuis. :: ¿Qué hace el hermano después de la jornada laboral?
+ Cocina en casa. :: «Kookt» es cocina y «thuis» es en casa.
- Va a un café en Utrecht con amigos. :: Confunde el lugar de trabajo del hermano con la actividad posterior.
- Aprende idiomas en la escuela nocturna. :: El estudio escolar se menciona en la frase anterior.
H Elke dag ___ wij samen. :: Completa con la forma verbal correcta para el sujeto «wij».
+ oefenen :: Con el pronombre de plural «wij» el verbo adopta la forma completa con -en.
- oefent :: La terminación -t es de singular («hij oefent»).
- oefen :: La raíz simple «oefen» corresponde a «ik».
Q ¿Por qué va el verbo «kookt» antes de «mijn broer» en «Na het werk kookt mijn broer thuis»?
+ Porque al comenzar la oración con un complemento circunstancial se produce inversión obligatoria :: En neerlandés el verbo finito siempre ocupa la segunda posición sintáctica (regla V2).
- Porque es una frase interrogativa indirecta :: No es una pregunta, sino una afirmación con inversión sintáctica.
- Porque el sujeto «mijn broer» es un pronombre tónico :: La inversión depende de la estructura de la frase, no del tipo de sustantivo.
R In het weekend bezoeken we onze vrienden. :: ¿Qué actividad realizan durante el fin de semana?
+ Visitan a sus amigos. :: «Bezoeken» significa visitar y «onze vrienden» nuestros amigos.
- Trabajan juntos en la cafetería. :: El texto indica que trabajan en días laborables y el fin de semana tienen tiempo social.
- Se quedan descansando en el jardín. :: No menciona descansar en el jardín, sino visitar amistades.
H Ik ___ in Utrecht en ik werk in een café. :: Completa con el verbo de residencia en primera persona.
+ woon :: Con «ik» se utiliza la raíz verbal directa («wonen» -> «woon»).
- woont :: Lleva la -t de segunda y tercera persona singular («hij woont»).
- wonen :: Es el infinitivo o la forma plural («wij wonen»).
O Na het werk kookt mijn broer thuis :: Después del trabajo mi hermano cocina en casa. :: Complemento temporal inicial, verbo en segunda posición e inversión del sujeto.
