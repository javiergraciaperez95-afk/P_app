@ 3 | Mijn familie | Hablar de la familia
I Aprendemos los miembros de la familia y los pronombres demostrativos básicos.
E La familia y los demostrativos :: Para presentar a las personas de la familia usamos «Dit is...» (este/esta es) o «Dat is...» (ese/aquel es). Para preguntar por la identidad de alguien: «Wie is...?» (¿Quién es...?). Observa el género y los artículos de los miembros de la familia: «de vader» (el padre), «de moeder» (la madre), «de broer» (el hermano), «de zus» (la hermana), «de man» (el hombre/esposo), «de vrouw» (la mujer/esposa), «de ouders» (los padres), y en género neutro «het kind» (el niño/hijo).
W familie = familia
W vader = padre
W moeder = madre
W broer = hermano
W zus = hermana
W kind = hijo o niño
W ouders = padres
W man = hombre o marido
W vrouw = mujer o esposa
W jouw = tu
W dit = esto
W dat = eso
W wie = quién
V Vocabulario clave
D En una situación cotidiana
Noor: Dit is mijn familie. = Esta es mi familia.
  > Dit is = esta es | mijn familie = mi familia
Luca: Wie is de man? = ¿Quién es el hombre?
  > Wie is = quién es | de man = el hombre
Noor: Dat is mijn vader. = Ese es mi padre.
  > Dat is = ese es | mijn vader = mi padre
Luca: En wie is de vrouw? = ¿Y quién es la mujer?
  > En = y | wie is = quién es | de vrouw = la mujer
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «familia»?
+ familie :: «De familie» es la familia.
- ouders :: Significa «padres».
- kind :: Significa «hijo / niño».
R Wie is de man? :: ¿Qué significa esta pregunta?
+ ¿Quién es el hombre? :: «Wie» es quién y «de man» es el hombre.
- ¿Dónde está el padre? :: Preguntaría con «Waar» por el padre.
- ¿Cómo se llama tu hermano? :: Preguntaría por el nombre del hermano.
H Dit is ___ vader. :: Completa con «mi» para decir «Este es mi padre».
+ mijn :: «Mijn» es el posesivo de primera persona («mi»).
- jouw :: Significa «tu» («tu padre»), no «mi padre».
- wie :: Es el interrogativo «quién».
R Dat is mijn vader. :: ¿Qué afirma Noor en esta frase?
+ Ese es mi padre. :: «Dat is» señala a distancia («ese es») y «mijn vader» es mi padre.
- Este es mi hermano pequeño. :: «Hermano» se dice «broer».
- Aquel es mi abuelo materno. :: No menciona abuelo.
O Dit is mijn familie :: Esta es mi familia. :: Orden directo: sujeto demostrativo Dit + verbo is + complemento.
Q ¿Qué significa el sustantivo «broer»?
+ hermano :: «De broer» es el hermano.
- hermana :: «Hermana» se dice «zus».
- padre :: «Padre» se dice «vader».
R En wie is de vrouw? :: Elige la traducción correcta de la pregunta.
+ ¿Y quién es la mujer? :: «De vrouw» significa la mujer o la esposa.
- ¿Y de dónde viene el niño? :: No habla de origen ni de niño («kind»).
- ¿Y cómo están los padres? :: Preguntaría por «de ouders».


@ 3 | Leeftijd en verjaardag | Decir la edad y el cumpleaños
I Aprendemos a decir la edad, los meses del año y cuándo es tu cumpleaños.
E La edad con «zijn» y los meses :: A diferencia del español (que usa «tener»), en neerlandés la edad se expresa con el verbo «zijn» (ser/estar): «Ik ben twintig jaar» (Tengo veinte años). Para preguntar: «Hoe oud ben je?» (¿Cuántos años tienes?). Para el cumpleaños se usa el adjetivo «jarig»: «Wanneer ben je jarig?» (¿Cuándo cumples años?), y se responde con la preposición «in»: «In mei» (En mayo).
W leeftijd = edad
W jaar = año
W oud = de edad
W hoe oud = cuántos años
W verjaardag = cumpleaños
W dag = día
W maand = mes
W januari = enero
W februari = febrero
W maart = marzo
W april = abril
W mei = mayo
W juni = junio
W jarig = cumpleañero
W wanneer = cuándo
w twintig = veinte
W juli = julio
W augustus = agosto
W september = septiembre
W oktober = octubre
W november = noviembre
W december = diciembre
V Vocabulario clave
D En una situación cotidiana
Luca: Hoe oud ben je? = ¿Cuántos años tienes?
  > Hoe oud = cuántos años | ben je = tienes tú
Noor: Ik ben twintig jaar. = Tengo veinte años.
  > Ik ben = tengo | twintig jaar = veinte años
Luca: Wanneer ben je jarig? = ¿Cuándo es tu cumpleaños?
  > Wanneer = cuándo | ben je jarig = cumples años tú
Noor: In mei. = En mayo.
  > In mei = en mayo
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «edad»?
+ leeftijd :: «De leeftijd» es la edad cronológica.
- verjaardag :: Es el «cumpleaños».
- maand :: Es el «mes».
R Ik ben twintig jaar. :: ¿Qué significa esta frase?
+ Tengo veinte años. :: En neerlandés la edad se expresa con «zijn» (ik ben) y «jaar».
- Nací el veinte de mayo. :: Expresaría fecha de nacimiento.
- Hace veinte años que vivo aquí. :: Expresaría duración temporal.
H Hoe ___ ben je? :: Completa la pregunta «¿Cuántos años tienes?».
+ oud :: La fórmula fija para la edad es «Hoe oud ben je?».
- jaar :: «Jaar» es el sustantivo año; va con la respuesta.
- leeftijd :: Es el sustantivo «edad», no encaja en «Hoe ___».
R Wanneer ben je jarig? :: ¿Qué pregunta Luca?
+ ¿Cuándo es tu cumpleaños? :: «Jarig zijn» significa cumplir años o estar de cumpleaños.
- ¿A qué hora empieza la fiesta? :: Preguntaría por el inicio de fiesta.
- ¿Cuántos días dura el viaje? :: Preguntaría por días («hoeveel dagen»).
O Hoe oud ben je :: ¿Cuántos años tienes? :: «Hoe oud» funciona como bloque interrogativo inicial.
Q ¿Qué significa la combinación «hoe oud»?
+ cuántos años :: Pregunta por la edad («cuán viejo»).
- qué mes :: Preguntaría «welke maand».
- qué fecha :: Preguntaría «welke datum».
R In mei. :: Elige la traducción correcta de la respuesta.
+ En mayo. :: «Mei» es el quinto mes del año (mayo).
- En marzo. :: «Marzo» en neerlandés es «maart».
- En junio. :: «Junio» en neerlandés es «juni».


@ 3 | Getallen en hoeveelheden | Usar números y cantidades
I Aprendemos los números del once al cien y a preguntar por los precios.
E Números y preguntas de precio :: Para preguntar cuánto cuesta algo se usa «Hoeveel kost dit?» (en singular) o «Hoeveel kosten deze?» (en plural con «kosten»). Los numerales de las decenas son regulares: twintig (20), dertig (30), veertig (40), vijftig (50) y honderd (100). Fíjate en que la moneda «euro» se mantiene en singular tras los numerales: «twaalf euro», «twintig euro».
W elf = once
W twaalf = doce
W dertien = trece
W veertien = catorce
W vijftien = quince
W zestien = dieciséis
W zeventien = diecisiete
W achttien = dieciocho
W negentien = diecinueve
W hoeveel = cuánto
W euro = euro
W kosten = costar
W kost = cuesta
W deze = estos
W dertig = treinta
W veertig = cuarenta
W vijftig = cincuenta
W honderd = cien
V Vocabulario clave
D En una situación cotidiana
Tom: Hoeveel kost dit? = ¿Cuánto cuesta esto?
  > Hoeveel = cuánto | kost = cuesta | dit = esto
Emma: Twaalf euro. = Doce euros.
  > Twaalf = doce | euro = euros
Tom: Hoeveel kosten deze? = ¿Cuánto cuestan estos?
  > Hoeveel = cuánto | kosten = cuestan | deze = estos
Emma: Twintig euro. = Veinte euros.
  > Twintig = veinte | euro = euros
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el número «once»?
+ elf :: 11 en neerlandés es «elf».
- twaalf :: Es el número 12 («doce»).
- dertien :: Es el número 13 («trece»).
R Twaalf euro. :: ¿Qué significa esta frase?
+ Doce euros. :: «Twaalf» es 12 y «euro» no añade -s tras número.
- Quince euros. :: Quince sería «vijftien euro».
- Veinte euros. :: Veinte sería «twintig euro».
H Hoeveel ___ dit? :: Completa con el verbo en singular: «¿Cuánto cuesta esto?».
+ kost :: Con sujeto singular neutro «dit» corresponde «kost».
- kosten :: Es la forma plural para varios objetos («kosten deze»).
- euro :: Es el sustantivo monetario «euro».
R Hoeveel kosten deze? :: ¿Qué pregunta Tom?
+ ¿Cuánto cuestan estos? :: «Kosten» es el plural para preguntar por varios artículos («deze»).
- ¿Cuántos euros te quedan? :: No pregunta por saldo restante.
- ¿A qué hora abren la tienda? :: Preguntaría por el horario de tienda.
O Hoeveel kost dit :: ¿Cuánto cuesta esto? :: Interrogativo Hoeveel + verbo kost + demostrativo dit.
Q ¿Qué número representa la palabra «veertien»?
+ catorce :: «Veertien» es el número 14.
- dieciséis :: «Dieciséis» es «zestien».
- cuarenta :: «Cuarenta» es «veertig».
R Twintig euro. :: Elige la traducción correcta del precio.
+ Veinte euros. :: «Twintig» corresponde exactamente al número 20.
- Treinta euros. :: Treinta se dice «dertig euro».
- Cincuenta euros. :: Cincuenta se dice «vijftig euro».
