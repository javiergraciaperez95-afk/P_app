@ 4 | In huis | Nombrar habitaciones
I Aprendemos a describir las partes de una casa y a expresar existencia con «er is» y «er zijn».
E La casa y la existencia :: En neerlandés la existencia se expresa con «er is» (hay, singular) y «er zijn» (hay, plural): «Er is een kleine tuin» (Hay un jardín pequeño), «Er zijn drie kamers» (Hay tres habitaciones). En preguntas se invierte: «Is er een tuin?» (¿Hay jardín?), «Hoeveel kamers zijn er?». Conoce las estancias principales: «de woonkamer» (el salón), «de keuken» (la cocina), «de slaapkamer» (el dormitorio), «de badkamer» (el baño), «de deur» (la puerta) y «het raam» (la ventana).
W huis = casa
W kamer = habitación
W woonkamer = salón
W keuken = cocina
W slaapkamer = dormitorio
W badkamer = baño
W tuin = jardín
W deur = puerta
W raam = ventana
W er = hay
W is = es o está
W zijn = son o están
W mooi = bonito
W een = un o una
w kamers = habitaciones
w kleine = pequeño (forma con -e)
V Vocabulario clave
D En una situación cotidiana
Anna: Is er een tuin? = ¿Hay un jardín?
  > Is er = hay | een tuin = un jardín
Tom: Ja, er is een kleine tuin. = Sí, hay un jardín pequeño.
  > Ja = sí | er is = hay | een kleine tuin = un jardín pequeño
Anna: Hoeveel kamers zijn er? = ¿Cuántas habitaciones hay?
  > Hoeveel kamers = cuántas habitaciones | zijn er = hay
Tom: Er zijn drie kamers. = Hay tres habitaciones.
  > Er zijn = hay | drie kamers = tres habitaciones
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «casa»?
+ huis :: «Het huis» es la casa o vivienda.
- kamer :: Es una estancia o «habitación».
- woonkamer :: Es específicamente el «salón».
R Ja, er is een kleine tuin. :: ¿Qué significa esta afirmación?
+ Sí, hay un jardín pequeño. :: «Er is» expresa existencia singular y «kleine tuin», jardín pequeño.
- No, no tenemos terraza exterior. :: Es una negación contraria a «ja».
- Sí, la casa tiene tres balcones. :: No menciona balcones ni la cifra tres.
H Er ___ drie kamers. :: Completa con la forma plural de haber («hay»).
+ zijn :: Para plural se usa siempre «er zijn».
- is :: Se usa solo con elementos en singular («er is»).
- een :: Es el artículo indeterminado («un / una»).
R Hoeveel kamers zijn er? :: ¿Qué pregunta Anna?
+ ¿Cuántas habitaciones hay? :: «Hoeveel» pide cantidad y «kamers», habitaciones.
- ¿Qué tamaño tiene el jardín? :: Preguntaría por las dimensiones del jardín.
- ¿Dónde está la cocina moderna? :: Preguntaría por la ubicación de la cocina.
O Is er een tuin :: ¿Hay un jardín? :: En preguntas de sí o no: verbo Is + pronombre er + sujeto un tuin.
Q ¿Qué estancia designa la palabra «keuken»?
+ cocina :: «De keuken» es la cocina.
- dormitorio :: «Dormitorio» se dice «slaapkamer».
- baño :: «Baño» se dice «badkamer».
R Er zijn drie kamers. :: Elige la traducción correcta.
+ Hay tres habitaciones. :: Traduce fielmente «er zijn» (hay) y «drie kamers» (tres habitaciones).
- La casa tiene tres baños. :: «Baño» se dice «badkamer».
- Hay una habitación grande. :: Dice «drie» (tres), no una grande.


@ 4 | Meubels en spullen | Nombrar muebles y objetos
I Aprendemos los muebles habituales y los verbos de posición «staan» y «liggen».
E Muebles y verbos de posición :: En neerlandés se distingue la postura de los objetos: «staan» (estar de pie o apoyado sobre una base vertical, como lámparas, botellas o armarios) y «liggen» (estar tumbado o plano, como libros, llaves o alfombras): «De lamp staat op de tafel» frente a «Het boek ligt op het bed». Recuerda los artículos: «de tafel» (la mesa), «de stoel» (la silla), «het bed» (la cama), «de kast» (el armario), «de lamp» (la lámpara).
W tafel = mesa
W stoel = silla
W bed = cama
W kast = armario
W lamp = lámpara
W boek = libro
W telefoon = teléfono
W sleutel = llave
W spullen = cosas
W staan = estar de pie
W staat = está de pie
W liggen = estar tumbado
W ligt = está tumbado
W op = encima de
W het = el o lo
V Vocabulario clave
D En una situación cotidiana
Noor: Waar staat de lamp? = ¿Dónde está la lámpara?
  > Waar staat = dónde está | de lamp = la lámpara
Emma: De lamp staat op de tafel. = La lámpara está sobre la mesa.
  > De lamp staat = la lámpara está | op de tafel = sobre la mesa
Noor: Waar ligt het boek? = ¿Dónde está el libro?
  > Waar ligt = dónde está | het boek = el libro
Emma: Het boek ligt op het bed. = El libro está sobre la cama.
  > Het boek ligt = el libro está | op het bed = sobre la cama
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «mesa»?
+ tafel :: «De tafel» es la mesa.
- stoel :: Significa «silla».
- bed :: Significa «cama».
R De lamp staat op de tafel. :: ¿Qué significa esta frase?
+ La lámpara está sobre la mesa. :: «Staat» indica posición erguida y «op de tafel», sobre la mesa.
- La lámpara está apagada en el suelo. :: No habla de apagada ni de suelo.
- La silla está al lado de la mesa. :: Confunde lámpara («lamp») con silla («stoel»).
H De lamp ___ op de tafel. :: Completa con el verbo de posición erguida.
+ staat :: Los objetos verticales que se apoyan sobre su base usan «staan / staat».
- ligt :: Se usa para objetos planos o tumbados («het boek ligt»).
- stoel :: Es el sustantivo «silla», no un verbo.
R Waar ligt het boek? :: ¿Qué pregunta Noor?
+ ¿Dónde está el libro? :: «Liggen» se aplica a libros colocados en plano.
- ¿Dónde compraste el libro nuevo? :: Preguntaría por compra («kopen»).
- ¿De qué color es la mesa? :: Preguntaría por color («welke kleur»).
O Waar staat de lamp :: ¿Dónde está la lámpara? :: Interrogativo Waar + verbo staat + sujeto de lamp.
Q ¿Qué mueble designa la palabra «kast»?
+ armario :: «De kast» es el armario o estantería cerrada.
- cama :: «Cama» se dice «bed».
- silla :: «Silla» se dice «stoel».
R Het boek ligt op het bed. :: Elige la traducción correcta.
+ El libro está sobre la cama. :: «Ligt» indica posición plana y «op het bed», sobre la cama.
- El libro está dentro del armario. :: «Dentro» se diría «in de kast».
- La llave está encima de la mesa. :: «Llave» se dice «sleutel».


@ 4 | Kleuren en plaats | Describir objetos y decir dónde están
I Aprendemos los colores principales y las preposiciones de lugar «onder», «naast» e «in».
E Colores y preposiciones de ubicación :: Los colores básicos son: «rood» (rojo), «blauw» (azul), «groen» (verde), «geel» (amarillo), «wit» (blanco), «zwart» (negro). Delante de un sustantivo con «de», el adjetivo suele añadir -e: «de rode bal», «de blauwe tas». Para ubicar objetos usamos preposiciones espaciales: «onder» (debajo de), «naast» (al lado de), «op» (sobre) e «in» (dentro de).
W kleur = color
W rood = rojo
W blauw = azul
W groen = verde
W wit = blanco
W zwart = negro
W geel = amarillo
W onder = debajo de
W naast = al lado de
W in = dentro de
W tas = bolsa
W bal = pelota
W die = ese
w blauwe = azul (forma con -e)
w rode = rojo (forma con -e)
V Vocabulario clave
D En una situación cotidiana
Tom: Waar is de blauwe tas? = ¿Dónde está la bolsa azul?
  > Waar is = dónde está | de blauwe tas = la bolsa azul
Anna: De tas ligt onder de tafel. = La bolsa está debajo de la mesa.
  > De tas ligt = la bolsa está | onder de tafel = debajo de la mesa
Tom: Waar is de rode bal? = ¿Dónde está la pelota roja?
  > Waar is = dónde está | de rode bal = la pelota roja
Anna: Die ligt naast de stoel. = Está al lado de la silla.
  > Die ligt = esa está | naast de stoel = al lado de la silla
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «color»?
+ kleur :: «De kleur» es el color.
- rood :: Es el color específico «rojo».
- blauw :: Es el color específico «azul».
R De tas ligt onder de tafel. :: ¿Qué significa esta frase?
+ La bolsa está debajo de la mesa. :: «Onder» significa debajo y «de tafel», la mesa.
- La bolsa está encima de la silla. :: Encima sería «op de stoel».
- La maleta está dentro del armario. :: Sería «in de kast».
H De tas ligt ___ de tafel. :: Completa con «debajo de».
+ onder :: «Onder de tafel» significa debajo de la mesa.
- naast :: Significa «al lado de».
- in :: Significa «dentro de».
R Waar is de rode bal? :: ¿Qué busca Tom?
+ ¿Dónde está la pelota roja? :: «Rode bal» es la pelota roja.
- ¿Dónde está la bolsa azul? :: «Bolsa azul» sería «de blauwe tas».
- ¿De qué color es la silla? :: Preguntaría por el color de la silla.
O Waar is de blauwe tas :: ¿Dónde está la bolsa azul? :: Fíjate en el adjetivo «blauwe» antes del sustantivo «tas».
Q ¿Qué color significa «groen»?
+ verde :: «Groen» es el color verde.
- amarillo :: «Amarillo» se dice «geel».
- blanco :: «Blanco» se dice «wit».
R Die ligt naast de stoel. :: Elige la traducción correcta.
+ Está al lado de la silla. :: «Naast» indica proximidad lateral («al lado de»).
- Está debajo de la cama. :: Debajo sería «onder het bed».
- Está dentro de la caja. :: Dentro sería «in».
