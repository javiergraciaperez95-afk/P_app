@ 9 | Vrije tijd | Hablar de aficiones
I Aprendemos a hablar de aficiones y gustos en el tiempo libre usando el adverbio «graag».
E Aficiones y el adverbio «graag» :: En neerlandés el adverbio «graag» (con gusto) colocado tras el verbo equivale al español «me gusta + infinitivo»: «Ik luister graag naar muziek» (Me gusta escuchar música), «Ik wandel graag» (Me gusta pasear). Para preguntar qué le gusta hacer a alguien: «Wat doe je graag?». Actividades de ocio: «de hobby» (la afición), «lezen» (leer), «naar muziek luisteren» (escuchar música), «voetbal spelen» (jugar al fútbol), «wandelen» (pasear / caminar) y «zwemmen» (nadar).
W vrije tijd = tiempo libre
W hobby = afición
W lezen = leer
W lees = leo
W muziek = música
W luisteren = escuchar
W luister = escucho
W sport = deporte
W voetbal = fútbol
W spelen = jugar
W speel = juego
W wandelen = pasear
W zwemmen = nadar
w wandel = paseo
V Vocabulario clave
D En una situación cotidiana
Sara: Wat doe je graag? = ¿Qué te gusta hacer?
  > Wat doe je = qué haces tú | graag = con gusto
Luca: Ik luister graag naar muziek. = Me gusta escuchar música.
  > Ik luister graag = me gusta escuchar | naar muziek = música
Sara: Speel je ook voetbal? = ¿También juegas al fútbol?
  > Speel je = juegas tú | ook = también | voetbal = fútbol
Luca: Nee, ik wandel graag. = No, me gusta pasear.
  > Nee = no | ik wandel graag = me gusta pasear
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «tiempo libre»?
+ vrije tijd :: «De vrije tijd» es el tiempo libre o de ocio.
- hobby :: Es la «afición» o pasatiempo.
- sport :: Es la práctica de «deporte».
R Ik luister graag naar muziek. :: ¿Qué afición expresa Luca?
+ Me gusta escuchar música. :: El adverbio «graag» expresa preferencia placentera por la música.
- Toco la guitarra en un grupo musical. :: No habla de tocar un instrumento.
- No tengo tiempo para escuchar la radio. :: Es una frase afirmativa de disfrute.
H Ik luister ___ naar muziek. :: Completa para expresar gusto («me gusta escuchar»).
+ graag :: Colocado tras el verbo indica que la actividad se hace con agrado.
- hobby :: Es un sustantivo («afición»), no un adverbio.
- lezen :: Es el verbo «leer», no encaja aquí.
R Speel je ook voetbal? :: ¿Qué pregunta Sara?
+ ¿También juegas al fútbol? :: Pregunta si además practica el deporte del fútbol.
- ¿Miras los partidos por televisión? :: Preguntaría por mirar la tele («kijken»).
- ¿Prefieres nadar en la piscina? :: Preguntaría por nadar («zwemmen»).
O Wat doe je graag :: ¿Qué te gusta hacer? :: Interrogativo Wat + verbo doe + sujeto je + adverbio graag.
Q ¿Qué forma verbal corresponde a «yo leo»?
+ lees :: Es la primera persona singular de «lezen» («ik lees»).
- lezen :: Es el infinitivo «leer».
- speel :: Es la forma «juego» («ik speel»).
R Nee, ik wandel graag. :: Elige la traducción exacta de la respuesta.
+ No, me gusta pasear. :: Niega jugar al fútbol y afirma su afición por caminar o pasear.
- Sí, entreno fútbol cada tarde. :: Contrario a la respuesta negativa.
- No, prefiero quedarme en casa leyendo. :: No menciona leer («lezen»).


@ 9 | Het weer en seizoenen | Hablar del tiempo
I Aprendemos a describir las condiciones atmosféricas y las cuatro estaciones del año.
E El tiempo y las estaciones :: Para preguntar qué tiempo hace se dice «Wat voor weer is het vandaag?». Respuestas habituales con el verbo impersonal «het is»: «Het is koud» (Hace frío), «Het is warm» (Hace calor). Para fenómenos naturales se usa «er is» o verbos específicos: «Er is wind» (Hay viento), «Er is regen» (Hay lluvia), «De zon schijnt» (Brilla el sol). Las cuatro estaciones son: «de lente» (la primavera), «de zomer» (el verano), «de herfst» (el otoño) y «de winter» (el invierno).
W weer = tiempo atmosférico
W zon = sol
W regen = lluvia
W wind = viento
W warm = hace calor
W koud = hace frío
W slecht = malo
W lente = primavera
W zomer = verano
W herfst = otoño
W winter = invierno
W buiten = fuera
W schijnt = brilla
V Vocabulario clave
D En una situación cotidiana
Noor: Wat voor weer is het vandaag? = ¿Qué tiempo hace hoy?
  > Wat voor weer = qué tiempo | is het = hace | vandaag = hoy
Emma: Het is koud en er is wind. = Hace frío y hay viento.
  > Het is koud = hace frío | en = y | er is wind = hay viento
Noor: Is er ook regen? = ¿También llueve?
  > Is er = hay | ook = también | regen = lluvia
Emma: Nee, de zon schijnt. = No, brilla el sol.
  > Nee = no | de zon schijnt = brilla el sol
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «tiempo atmosférico» o clima?
+ weer :: «Het weer» es el tiempo meteorológico.
- zon :: Es el «sol».
- regen :: Es la «lluvia».
R Het is koud en er is wind. :: ¿Qué describe Emma sobre el clima de hoy?
+ Hace frío y hay viento. :: Describe bajas temperaturas («koud») y rachas de viento («wind»).
- Hace calor y el cielo está despejado. :: Sería «warm».
- Está nevando intensamente en la calle. :: No menciona nieve.
H Het is ___ en er is wind. :: Completa con «frío» para describir el día.
+ koud :: «Koud» significa frío.
- warm :: Significa «cálido / hace calor».
- lente :: Es la estación «primavera».
R Is er ook regen? :: ¿Qué consulta Noor?
+ ¿También llueve? :: Pregunta si además hay precipitaciones de lluvia («regen»).
- ¿Va a hacer sol todo el fin de semana? :: Preguntaría por el sol («zon»).
- ¿Hace mucho frío en el jardín exterior? :: Preguntaría por frío («koud»).
O Wat voor weer is het vandaag :: ¿Qué tiempo hace hoy? :: Expresión fija para preguntar las condiciones meteorológicas.
Q ¿Qué fenómeno meteorológico designa la palabra «wind»?
+ viento :: «De wind» es el viento.
- lluvia :: «Lluvia» se dice «regen».
- nieve :: «Nieve» se dice «sneeuw».
R Nee, de zon schijnt. :: Elige la traducción exacta.
+ No, brilla el sol. :: «De zon schijnt» afirma que el día es soleado y luminoso.
- Sí, el viento sopla muy fuerte. :: No habla del viento soplando.
- No, el pronóstico anuncia tormenta. :: No menciona tormentas.


@ 9 | Uitnodigingen en plannen | Invitar y hacer planes
I Aprendemos a proponer planes sociales, invitar al cine y responder con agrado.
E Invitaciones y propuestas :: Para proponer un plan a amigos se utiliza «Zullen we... gaan?» (¿Vamos a...?): «Zullen we vanavond naar de film gaan?» (¿Vamos al cine esta noche?). Para expresar entusiasmo: «Leuk!» (¡Genial! / ¡Qué bien!). Para invitar a venir: «Kom je mee?» (¿Te vienes? / ¿Vienes conmigo?). Para aceptar con entusiasmo: «Ja, graag!» (¡Sí, encantado!). Para disculparte si no puedes: «Sorry, ik kan niet» (Lo siento, no puedo).
W uitnodigen = invitar
W uitnodiging = invitación
W zullen we = ¿vamos a?
W film = película
W bioscoop = cine
W vanavond = esta noche
W komen = venir
W kunnen = poder
W leuk = genial
W sorry = lo siento
w mee = con; conmigo
V Vocabulario clave
D En una situación cotidiana
Mila: Zullen we vanavond naar de film gaan? = ¿Vamos al cine esta noche?
  > Zullen we = vamos nosotros | vanavond = esta noche | naar de film gaan = ir al cine
Tom: Leuk! Hoe laat? = ¡Qué bien! ¿A qué hora?
  > Leuk = qué bien | Hoe laat = a qué hora
Mila: Om acht uur. Kom je mee? = A las ocho. ¿Vienes conmigo?
  > Om acht uur = a las ocho | Kom je mee = vienes tú conmigo
Tom: Ja, graag. = Sí, encantado.
  > Ja, graag = sí, con mucho gusto
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo «invitar»?
+ uitnodigen :: Es el verbo separable «uitnodigen».
- uitnodiging :: Es el sustantivo «invitación».
- komen :: Significa «venir».
R Leuk! Hoe laat? :: ¿Cómo reacciona Tom ante la propuesta?
+ ¡Qué bien! ¿A qué hora? :: Muestra entusiasmo («Leuk!») y pregunta la hora del plan.
- ¡Qué lástima! No tengo dinero. :: Mostraría rechazo o imposibilidad.
- Imposible, tengo clase temprano mañana. :: Sería una negativa.
H Zullen we vanavond naar de ___ gaan? :: Completa para proponer ir al cine/película.
+ film :: «Naar de film gaan» significa ir a ver una película / ir al cine.
- uitnodiging :: Es el sustantivo «invitación», no un lugar al que ir.
- hobby :: Significa afición o pasatiempo.
R Om acht uur. Kom je mee? :: ¿Qué información y pregunta añade Mila?
+ A las ocho. ¿Vienes conmigo? :: Fija la hora («om acht uur») y pregunta si la acompaña («Kom je mee?»).
- A las siete de la tarde en la estación. :: Menciona las ocho, no las siete.
- Mañana después del almuerzo en mi casa. :: Habla de esta noche («vanavond»).
O Zullen we vanavond naar de film gaan :: ¿Vamos al cine esta noche? :: Estructura de propuesta: Zullen we + tiempo + naar de film + infinitivo gaan al final.
Q ¿Qué significa el sustantivo «film»?
+ película :: «De film» es una película cinematográfica.
- invitación :: «Invitación» se dice «uitnodiging».
- afición :: «Afición» se dice «hobby».
R Ja, graag. :: Elige la traducción que mejor refleja esta aceptación entusiasta.
+ Sí, encantado. :: Acepta con gran agrado la invitación compartida.
- No, muchas gracias de todos modos. :: Sería un rechazo educado.
- Quizá llegue un poco tarde. :: Expresaría retraso.
