@ 2 | Waar woon je? | Decir dónde vives
I Aprendemos a decir el lugar de residencia, la ciudad y la dirección en neerlandés.
E Dónde vives y la dirección :: Para preguntar el lugar de residencia se dice «Waar woon je?». En la respuesta afirmativa el verbo va en 2ª posición: «Ik woon in Utrecht». Para preguntar la dirección: «Wat is je adres?». Fíjate en los sustantivos con artículo: «de straat» (la calle), «de stad» (la ciudad), «het dorp» (el pueblo). En neerlandés el orden de dirección suele poner primero la calle y luego el número: Marktstraat 12.
W wonen = vivir
W woon = vivo
W woont = vives
W stad = ciudad
W dorp = pueblo
W straat = calle
W adres = dirección
W huisnummer = número de casa
W postcode = código postal
W in = en
W Utrecht = Utrecht
W Amsterdam = Ámsterdam
W hier = aquí
W de = el o la
w marktstraat = Marktstraat, calle
B Wonen | Persona | Forma
| yo | woon
| tú | woont
| usted | woont
| él/ella | woont
V Vocabulario clave
D En una situación cotidiana
Emma: Waar woon je? = ¿Dónde vives?
  > Waar = dónde | woon je = vives tú
Noor: Ik woon in Utrecht. = Vivo en Utrecht.
  > Ik woon = yo vivo | in = en | Utrecht = Utrecht
Emma: Wat is je adres? = ¿Cuál es tu dirección?
  > Wat is = cuál es | je adres = tu dirección
Noor: Mijn straat is de Marktstraat. = Mi calle es Marktstraat.
  > Mijn straat = mi calle | is = es | de Marktstraat = la calle Marktstraat
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo «vivir»?
+ wonen :: Es el infinitivo regular terminado en -en.
- woon :: Es la 1ª persona del singular («ik woon»).
- straat :: Es el sustantivo «calle».
R Ik woon in Utrecht. :: ¿Qué significa esta frase?
+ Vivo en Utrecht. :: Indica residencia en la ciudad de Utrecht.
- Trabajo en Utrecht. :: Correspondería al verbo werken («ik werk»).
- Vengo de Utrecht. :: Correspondería a «ik kom uit Utrecht».
H Ik ___ in Utrecht. :: Completa con la forma verbal adecuada para «ik».
+ woon :: La primera persona «ik» lleva la raíz sin desinencia: «woon».
- woont :: Lleva desinencia -t para «jij/hij/zij», no para «ik».
- straat :: Es un sustantivo («calle»), no un verbo.
R Wat is je adres? :: ¿Qué pregunta Emma en esta frase?
+ ¿Cuál es tu dirección? :: Pide los datos de dirección postal.
- ¿Cuál es tu número de teléfono? :: Pediría el número («je nummer»).
- ¿En qué ciudad naciste? :: Preguntaría por el lugar de nacimiento.
O Waar woon je :: ¿Dónde vives? :: En preguntas con pronombre interrogativo: interrogativo + verbo + sujeto.
Q ¿Qué significa el sustantivo «stad»?
+ ciudad :: «De stad» significa la ciudad.
- pueblo :: «Pueblo» en neerlandés se dice «dorp».
- calle :: «Calle» se dice «straat».
R Mijn straat is de Marktstraat. :: Elige la traducción correcta.
+ Mi calle es Marktstraat. :: Identifica el nombre de la calle.
- Mi casa está en el centro. :: Habla de ubicación general, no de la calle.
- Mi ciudad es Ámsterdam. :: Menciona otra ciudad y otro concepto.


@ 2 | Werk en studie | Hablar del trabajo y los estudios
I Aprendemos a hablar de la profesión, los estudios y el lugar de trabajo.
E Profesiones y estudios :: Para preguntar a qué se dedica alguien se dice «Wat voor werk doe je?» (¿Qué clase de trabajo haces?). Para indicar tu profesión usas «Ik ben...»: «Ik ben student» (soy estudiante), «Ik ben leraar» (soy profesor). Para decir dónde trabajas: «Ik werk op een school» (trabajo en una escuela) o «Ik werk in een kantoor» (trabajo en una oficina).
W werk = trabajo
W werken = trabajar
W baan = empleo
W beroep = profesión
W student = estudiante
W leraar = profesor
W arts = médico
W kok = cocinero
W bakker = panadero
W school = escuela
W kantoor = oficina
W studeren = estudiar
W studeer = estudio
W leer = aprendo
W op = en
w doe = haces
w een = un; una
w voor = para; delante de
V Vocabulario clave
D En una situación cotidiana
Tom: Wat voor werk doe je? = ¿En qué trabajas?
  > Wat voor werk = qué clase de trabajo | doe je = haces tú
Sara: Ik ben student. Ik studeer Nederlands. = Soy estudiante. Estudio neerlandés.
  > Ik ben student = soy estudiante | Ik studeer = yo estudio | Nederlands = neerlandés
Tom: Waar werk je? = ¿Dónde trabajas?
  > Waar = dónde | werk je = trabajas tú
Sara: Ik werk op een school. = Trabajo en una escuela.
  > Ik werk = yo trabajo | op een school = en una escuela
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «trabajo» como sustantivo?
+ werk :: «Het werk» significa el trabajo.
- beroep :: Significa «profesión».
- baan :: Significa puesto o «empleo».
R Ik ben student. Ik studeer Nederlands. :: ¿Qué significa esta frase?
+ Soy estudiante. Estudio neerlandés. :: Describe su condición académica y qué estudia.
- Soy profesor. Enseño neerlandés. :: Diría «Ik ben leraar».
- Busco trabajo en una escuela. :: Expresaría búsqueda de empleo.
H Ik ___ Nederlands. :: Completa con el verbo adecuado para «yo estudio».
+ studeer :: Es la primera persona del verbo studeren («ik studeer»).
- school :: Es el sustantivo «escuela».
- leraar :: Es el sustantivo «profesor».
R Waar werk je? :: ¿Qué pregunta Tom en esta frase?
+ ¿Dónde trabajas? :: Pregunta por el lugar donde desempeña su trabajo.
- ¿Qué estudias hoy? :: Preguntaría por los estudios («Wat studeer je?»).
- ¿A qué hora empiezas? :: Preguntaría por la hora de entrada.
O Wat voor werk doe je :: ¿En qué trabajas? :: «Wat voor werk» (qué tipo de trabajo) + verbo doe + sujeto je.
Q ¿Qué significa el sustantivo «beroep»?
+ profesión :: Significa profesión u oficio formal.
- oficina :: «Oficina» se dice «kantoor».
- escuela :: «Escuela» se dice «school».
R Ik werk op een school. :: Elige la traducción correcta.
+ Trabajo en una escuela. :: «Op een school» se traduce por «en una escuela».
- Estudio en una universidad. :: No menciona universidad ni estudiar.
- Tengo una cita en la oficina. :: No habla de citas ni de oficina.


@ 2 | Hoe gaat het? | Describir cómo te sientes
I Aprendemos a preguntar cómo está alguien y a expresar el estado de ánimo y cansancio.
E Estados de ánimo y el verbo zijn :: La pregunta clave para saludar e interesarse por alguien es «Hoe gaat het?» (¿Cómo va? / ¿Qué tal?). Para contestar: «Goed» (bien), «Prima» (muy bien), o explicar cómo te sientes con el verbo «zijn»: «Ik ben moe» (estoy cansado), «Ik ben blij» (estoy contento), «Ik ben druk» (estoy ocupado/con mucho lío).
W zijn = ser o estar
W ben = soy o estoy
W bent = eres o estás
W blij = contento
W moe = cansado
W druk = ocupado
W vriendelijk = amable
W groot = grande
W klein = pequeño
W vandaag = hoy
W ook = también
W goed = bien
W prima = muy bien
W maar = pero
w gaat = va
w het = el; lo
w ja = sí
B Zijn (ser/estar) | Persona | Forma
| yo | ben
| tú | bent
| usted | bent
| él/ella | is
V Vocabulario clave
D En una situación cotidiana
Sara: Hoe gaat het vandaag? = ¿Qué tal hoy?
  > Hoe gaat het = cómo va | vandaag = hoy
Tom: Goed, maar ik ben moe. = Bien, pero estoy cansado.
  > Goed = bien | maar = pero | ik ben moe = estoy cansado
Sara: Ben je druk? = ¿Estás ocupado?
  > Ben je = estás tú | druk = ocupado
Tom: Ja, een beetje. En jij? = Sí, un poco. ¿Y tú?
  > Ja = sí | een beetje = un poco | En jij = ¿y tú?
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo del verbo «ser o estar»?
+ zijn :: Es el verbo copulativo básico e irregular («ser / estar»).
- ben :: Es la primera persona del presente («yo soy / estoy»).
- bent :: Es la segunda persona («tú eres / estás»).
R Goed, maar ik ben moe. :: ¿Qué significa esta respuesta?
+ Bien, pero estoy cansado. :: «Goed» indica bien y «moe» expresa cansancio.
- Mal, porque estoy enfermo. :: No dice mal («slecht») ni enfermo («ziek»).
- Muy ocupado, no tengo tiempo. :: No usa la palabra «druk» en esta respuesta.
H Ik ___ moe. :: Completa con la forma correcta de «ser/estar» para «ik».
+ ben :: Con «ik» corresponde siempre «ben».
- bent :: Es para «jij / u» («jij bent»).
- is :: Es para la tercera persona («hij / zij is»).
R Ben je druk? :: ¿Qué pregunta Sara en esta intervención?
+ ¿Estás ocupado? :: «Druk» significa con mucho trabajo o ajetreado.
- ¿Estás contento hoy? :: Preguntaría con «blij» («Ben je blij?»).
- ¿Vienes con nosotros? :: Preguntaría por venir («Kom je mee?»).
O Hoe gaat het vandaag :: ¿Qué tal hoy? :: «Hoe gaat het» es la expresión fija para preguntar qué tal.
Q ¿Qué significa el adjetivo «blij»?
+ contento :: Significa contento o alegre.
- cansado :: «Cansado» se dice «moe».
- amable :: «Amable» se dice «vriendelijk».
R Ja, een beetje. En jij? :: Elige la traducción correcta.
+ Sí, un poco. ¿Y tú? :: «Een beetje» significa un poco; «En jij?», ¿y tú?
- No, nada en absoluto. :: Es lo contrario de «ja».
- Muy bien, gracias a todos. :: No incluye esa frase de agradecimiento.
