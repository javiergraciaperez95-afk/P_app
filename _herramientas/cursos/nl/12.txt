
@ 25 | Toen ik klein was | Cuando era pequeño
I En esta lección practicarás una situación cotidiana de nivel A2.
E Idea clave :: Usa imperfecto para describir el pasado y perfecto para acciones terminadas.
W vroeger = antes
W opgegroeid = crecido
W boerderij = granja
W platteland = campo
W dieren = animales
W paardrijden = montar a caballo
W vaak = a menudo
W herinneren = recordar
W kippen = gallinas
w deed = hacía
w hadden = teníamos
w kon = podía
W paarden = caballos
w waren = eran
V Vocabulario clave
D En una situación cotidiana
Tom: Waar ben je opgegroeid? = ¿Dónde creciste?
Sara: Ik ben op het platteland opgegroeid. = Crecí en el campo.
Tom: Waren er dieren op de boerderij? = ¿Había animales en la granja?
Sara: Ja, we hadden paarden en kippen. = Sí, teníamos caballos y gallinas.
Tom: Kon je paardrijden? = ¿Sabías montar a caballo?
Sara: Ja, dat deed ik vroeger vaak. = Sí, antes lo hacía a menudo.
Q ¿Cómo se dice en neerlandés «antes»?
+ vroeger :: Es la respuesta correcta.
- opgegroeid :: Es otra opción.
- boerderij :: Es otra opción.

+ Crecí en el campo. :: Es la respuesta correcta.
- Sí, teníamos caballos y gallinas. :: Es otra opción.
- Sí, antes lo hacía a menudo. :: Es otra opción.
H Ja, dat deed ik ___ vaak. :: Completa la frase.
+ vroeger :: Es la respuesta correcta.
- opgegroeid :: Es otra opción.
- boerderij :: Es otra opción.
