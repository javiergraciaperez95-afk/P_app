@ 17 | Kamers en meubels | Habitaciones y muebles
I Nombra las estancias de una casa y la posición de los muebles principales.
E Ubicación espacial y mobiliario :: Para indicar dónde está un mueble se combinan verbos de posición como «staan» (para cosas de pie) o «liggen» (para cosas planas) con preposiciones espaciales: «naast» (al lado de), «bij» (junto a, cerca de), «op» (sobre), «onder» (debajo de). «Boven» significa arriba o en la planta superior, y «beneden» abajo.
W boven = arriba; en la planta de arriba
W toch = ¿verdad?; ciertamente
w slaapkamer = dormitorio
w badkamer = cuarto de baño
w lamp = lámpara
w kast = armario
V Estancias y muebles
D En una situación cotidiana
Anna: Waar staat de lamp? = ¿Dónde está la lámpara?
  > Waar staat = dónde está | de lamp = la lámpara
Noor: De lamp staat naast het bed. = La lámpara está al lado de la cama.
  > De lamp = la lámpara | staat = está | naast het bed = al lado de la cama
Anna: En waar is de kast? = ¿Y dónde está el armario?
  > En = y | waar is = dónde está | de kast = el armario
Noor: In de slaapkamer, bij het raam. = En el dormitorio, junto a la ventana.
  > In de slaapkamer = en el dormitorio | bij het raam = junto a la ventana
Anna: De badkamer is boven, toch? = El baño está arriba, ¿verdad?
  > De badkamer = el baño | is boven = está arriba | toch = ¿verdad?
Q ¿Qué adverbio de lugar significa «arriba» o «en la planta superior» en neerlandés?
+ boven :: «Boven» indica la planta de arriba o posición elevada, en contraste con «beneden» (abajo).
- beneden :: Significa lo contrario: abajo o en la planta baja.
- dichtbij :: Significa cerca en distancia horizontal, no específicamente arriba.
R De lamp staat naast het bed. :: ¿Dónde está colocada la lámpara según Noor?
+ Al lado de la cama. :: «Naast het bed» significa junto a la cama o al lado de ella.
- Encima de la mesa del comedor. :: No está en el comedor sino en el dormitorio junto a la cama.
- Dentro del armario grande. :: La lámpara no está guardada dentro del armario.
H In de ___, bij het raam. :: Completa con la habitación donde se encuentra el armario.
+ slaapkamer :: El armario está en el dormitorio («de slaapkamer»).
- badkamer :: «Badkamer» es el cuarto de baño, situado en la planta de arriba.
- keuken :: «Keuken» es la cocina, no mencionada para el armario.
Q ¿Qué partícula se añade al final de una frase afirmativa para pedir confirmación («¿verdad?» / «¿no?»)?
+ toch :: «Toch» funciona como coletilla interrogativa equivalente a «¿a que sí?» o «¿verdad?».
- niet :: «Niet» es la negación común; para pedir confirmación se usa «toch».
- wel :: «Wel» enfatiza una afirmación contra una duda, no forma la coletilla de pregunta.
R De badkamer is boven, toch? :: ¿Qué intenta comprobar Anna con su pregunta?
+ Si el cuarto de baño se encuentra en la planta superior. :: «Boven» sitúa en el piso de arriba y «toch» solicita confirmación.
- Si el cuarto de baño dispone de ventana exterior :: No pregunta por ventanas en el baño, sino por su ubicación arriba.
- Si la lámpara del baño funciona correctamente :: La lámpara mencionada estaba al lado de la cama en el dormitorio.
H Waar ___ de lamp? :: Completa con el verbo de postura adecuado para una lámpara apoyada de pie.
+ staat :: Los objetos que se apoyan de pie verticales rigen el verbo «staan».
- ligt :: «Liggen» se usa para objetos tendidos planos (libros, llaves).
- zit :: «Zitten» se usa para personas sentadas o cosas encajadas en un hueco.
O Waar staat de lamp :: ¿Dónde está la lámpara? :: Pregunta de ubicación con «waar» y verbo de posición «staat».

@ 17 | Mijn woning beschrijven | Describir una vivienda
I Describe las características de una vivienda, su distribución y el entorno del barrio.
E Describir una vivienda :: Para detallar las estancias se utiliza «er is» (hay, singular) o «er zijn» (hay, plural): «Er is een woonkamer met veel licht» (hay un salón con mucha luz). Para indicar la altura se usa «op de... verdieping» (en la... planta/piso). La expresión «dichtbij» significa cercano y «betaalbaar» describe un precio o alquiler asequible.
w woning = vivienda
w huur = alquiler
w licht = luminoso; luz
w rustig = tranquilo
w verdieping = piso; planta
w betaalbaar = asequible
w woonkamer = salón; cuarto de estar
V Términos de vivienda
T Texto breve
- Ik woon in een klein appartement op de tweede verdieping. = Vivo en un apartamento pequeño en la segunda planta.
  > Ik woon = vivo | in een klein appartement = en un pequeño apartamento | op de tweede verdieping = en la segunda planta
- Er is een woonkamer met veel licht. = Hay un salón con mucha luz.
  > Er is = hay | een woonkamer = un salón | met veel licht = con mucha luz
- De slaapkamer is rustig, maar niet groot. = El dormitorio es tranquilo, pero no grande.
  > De slaapkamer = el dormitorio | is rustig = es tranquilo | maar = pero | niet groot = no grande
- De keuken is naast de woonkamer. = La cocina está junto al salón.
  > De keuken = la cocina | is naast = está al lado de | de woonkamer = el salón
- De supermarkt is dichtbij en de huur is betaalbaar. = El supermercado está cerca y el alquiler es asequible.
  > De supermarkt = el supermercado | is dichtbij = está cerca | en = y | de huur = el alquiler | is betaalbaar = es asequible
Q ¿En qué planta se encuentra el apartamento descrito en el texto?
+ En la segunda planta :: «Op de tweede verdieping» indica el segundo piso.
- En la planta baja :: La planta baja se denomina «op de begane grond».
- En el primer piso :: El primer piso sería «op de eerste verdieping».
R Er is een woonkamer met veel licht. :: ¿Qué cualidad destaca del salón?
+ Que es una estancia luminosa con abundante luz natural. :: «Veel licht» significa mucha luz o muy luminoso.
- Que es muy ruidoso por el tráfico exterior. :: No dice que sea ruidoso, sino que tiene mucha luz.
- Que carece de ventanas hacia la calle. :: Al contrario, disponer de mucha luz presupone buena orientación.
H De supermarkt is dichtbij en de ___ is betaalbaar. :: Completa con la palabra que designa el coste mensual de la vivienda.
+ huur :: «De huur» es el alquiler de la casa.
- woning :: «Woning» es la vivienda en sí, no el precio del arrendamiento.
- verdieping :: «Verdieping» es la planta o piso arquitectónico.
Q ¿Qué significa el adjetivo «betaalbaar» en neerlandés?
+ Asequible / pagable :: Deriva de «betalen» (pagar) y expresa que el precio es razonable.
- Extremadamente caro :: Caro se dice «duur».
- Gratuito sin coste alguno :: Gratuito es «gratis».
R De keuken is naast de woonkamer. :: ¿Dónde está situada la cocina?
+ Al lado del salón. :: «Naast de woonkamer» ubica la cocina contigua al cuarto de estar.
- En el piso de arriba junto al baño. :: Arriba está el baño, no la cocina.
- Al final del jardín exterior. :: Es un apartamento en planta, no una casa con jardín.
H De slaapkamer is ___, maar niet groot. :: Completa con la cualidad de silencio y tranquilidad del dormitorio.
+ rustig :: «Rustig» significa tranquilo, apacible.
- duur :: «Duur» significa caro, no encaja como cualidad de estancia.
- dicht :: «Dicht» significa cerrado.
O Er is een woonkamer met veel licht :: Hay un salón con mucha luz. :: Estructura existencial («Er is»), sustantivo con artículo y complemento preposicional.

@ 17 | Een klein problema thuis | Un problema sencillo en casa
I Comunica averías domésticas al propietario y acuerda la visita de un técnico.
E Notificar averías :: Para describir problemas en el hogar se usan verbos y adjetivos específicos: «De kraan lekt» (el grifo gotea), «De verwarming is kapot» (la calefacción está rota). Para indicar el inicio del problema temporalmente se emplea «sinds»: «sinds vanochtend» (desde esta mañana). «Laten weten» es una perífrasis clave que significa «avisar» o «hacer saber».
W monteur = técnico; instalador
W vanochtend = esta mañana
w kapot = estropeado; roto
w kraan = grifo
w lekt = gotea
w verwarming = calefacción
w repareren = reparar
w stuur = envío
w huurder = inquilino
w verhuurder = arrendador; casero
V Averías domésticas
D En una situación cotidiana
Huurder: De kraan in de keuken lekt. = El grifo de la cocina gotea.
  > De kraan = el grifo | in de keuken = en la cocina | lekt = gotea
Verhuurder: Sinds wanneer is dat? = ¿Desde cuándo ocurre eso?
  > Sinds wanneer = desde cuándo | is dat = es eso; ocurre eso
Huurder: Sinds vanochtend. De verwarming is ook kapot. = Desde esta mañana. La calefacción también está estropeada.
  > Sinds vanochtend = desde esta mañana | De verwarming = la calefacción | is ook kapot = también está rota
Verhuurder: Ik stuur vandaag een monteur. = Hoy enviaré a un técnico.
  > Ik stuur = yo envío | vandaag = hoy | een monteur = a un técnico
Huurder: Dank u. Kunt u mij laten weten hoe laat? = Gracias. ¿Puede decirme a qué hora?
  > Dank u = gracias a usted | Kunt u = puede usted | mij laten weten = hacerme saber | hoe laat = a qué hora
Q ¿Qué averías concretas comunica el inquilino al propietario?
+ El grifo de la cocina gotea y la calefacción está estropeada :: Menciona dos incidencias: «kraan lekt» y «verwarming kapot».
- Se ha roto el cristal de la ventana del salón :: No menciona rotura de cristales en las ventanas.
- La cerradura de la puerta principal no abre :: No tiene problemas de cerrajería, sino de fontanería y calefacción.
R Sinds vanochtend. De verwarming is ook kapot. :: ¿Desde cuándo persisten estos problemas?
+ Desde la mañana de hoy. :: «Sinds vanochtend» precisa que comenzó esta misma mañana.
- Desde hace más de dos semanas. :: No lleva dos semanas, empezó esa misma mañana.
- Desde la noche del viernes pasado. :: No se remonta al fin de semana anterior.
H Ik stuur vandaag een ___. :: Completa con el profesional que enviará el casero.
+ monteur :: «Monteur» es el técnico o especialista que acude a reparar la avería.
- huurder :: «Huurder» es el inquilino que sufre el problema.
- verhuurder :: «Verhuurder» es el propietario que encarga el servicio.
Q ¿Qué significa la expresión neerlandesa «laten weten»?
+ Avisar o comunicar / hacer saber :: Perífrasis común para solicitar confirmación de horario o datos.
- Pagar el recibo pendiente :: Pagar es «betalen».
- Limpiar a fondo una habitación :: Limpiar es «schoonmaken».
R Kunt u mij laten weten hoe laat? :: ¿Qué solicita el inquilino tras conocer que irá un técnico?
+ Que le avisen de la hora exacta de la visita. :: «Hoe laat» pregunta a qué hora vendrá el profesional.
- Que le envíen la factura antes de comenzar la reparación :: No pide el presupuesto, pregunta por la hora de llegada.
- Que le rebajen el importe del alquiler mensual :: No plantea negociar el alquiler en esta conversación.
H De kraan in de keuken ___. :: Completa con el verbo adecuado para indicar que el grifo pierde agua.
+ lekt :: «Lekt» significa gotea o tiene fugas de agua.
- staat :: No expresa el mal funcionamiento del grifo.
- kookt :: «Kookt» significa hierve o cocina.
O De kraan in de keuken lekt :: El grifo de la cocina gotea. :: Sujeto con sintagma preposicional y verbo intransitivo de avería.
