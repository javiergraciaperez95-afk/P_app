@ 19 | Lichaamsdelen en pijn | Partes del cuerpo y dolor
I Nombra las partes principales del cuerpo humano y describe la localización de un dolor.
E Expresar dolor corporal :: En neerlandés se expresa dolor principalmente de dos maneras: con «Ik heb pijn aan...» (tengo dolor en...: «Ik heb pijn aan mijn rug») o con el verbo «pijn doen» (doler: «Mijn hoofd doet pijn», «Doet uw been ook pijn?»). Para ubicar temporalmente el inicio se utiliza «sinds» (desde): «sinds gisteren» (desde ayer).
W arm = brazo
W been = pierna
W rug = espalda
w hoofd = cabeza
V Anatomía básica
D En una situación cotidiana
Patiënt: Ik heb pijn aan mijn rug. = Me duele la espalda.
  > Ik heb pijn aan = tengo dolor en | mijn rug = mi espalda
Assistente: Sinds wanneer? = ¿Desde cuándo?
  > Sinds wanneer = desde cuándo
Patiënt: Sinds gisteren. Mijn hoofd doet ook pijn. = Desde ayer. También me duele la cabeza.
  > Sinds gisteren = desde ayer | Mijn hoofd = mi cabeza | doet ook pijn = también duele
Assistente: Doet uw been ook pijn? = ¿También le duele la pierna?
  > Doet uw been = duele su pierna | ook pijn = también dolor; doler
Patiënt: Nee, alleen mijn rug en mijn hoofd. = No, solo la espalda y la cabeza.
  > Nee = no | alleen mijn rug = solo mi espalda | en mijn hoofd = y mi cabeza
Q ¿Cómo se dice en neerlandés «me duele la cabeza» mediante el verbo «pijn doen»?
+ Mijn hoofd doet pijn. :: La locución verbal es «pijn doen», con el verbo «doet» conjugado en singular.
- Mijn hoofd heeft koorts. :: Significa «mi cabeza tiene fiebre», no es la expresión idiomática.
- Mijn hoofd is kapot. :: «Kapot» se aplica a máquinas u objetos averiados, no a partes del cuerpo humano.
R Ik heb pijn aan mijn rug. :: ¿Qué síntoma describe el paciente a la asistenta médica?
+ Tiene dolor localizado en la espalda. :: «Mijn rug» es la espalda y «pijn aan» expresa dónde duele.
- Se ha lesionado la pierna derecha al correr. :: No menciona la pierna en esta frase inicial.
- Le duele la garganta desde hace una semana. :: «Rug» es espalda, no garganta («keel»).
H Doet uw ___ ook pijn? :: Completa la pregunta médica sobre la pierna del paciente.
+ been :: «Het been» significa pierna en neerlandés.
- arm :: Aunque es una extremidad, la asistenta pregunta expresamente por «uw been».
- rug :: El paciente ya había declarado el dolor de espalda previamente.
R Sinds gisteren. Mijn hoofd doet ook pijn. :: ¿Cuándo comenzó el malestar del paciente?
+ El día de ayer. :: «Sinds gisteren» fija el inicio temporal en el día anterior.
- Hace un mes completo. :: «Gisteren» significa estrictamente ayer.
- Esta misma mañana al levantarse. :: Esta mañana sería «vanochtend».
H Nee, alleen mijn rug en mijn ___. :: Completa con la otra parte del cuerpo que le duele al paciente.
+ hoofd :: Al paciente le duelen la espalda y la cabeza («mijn hoofd»).
- been :: El paciente niega explícitamente que le duela la pierna.
- arm :: No declara dolor en el brazo.
O Ik heb pijn aan mijn rug :: Me duele la espalda. :: Construcción fija de dolor corporal con preposición «aan».

@ 19 | Klachten en duur | Síntomas y duración
I Describe síntomas de enfermedad común (tos, fiebre, resfriado) y detalla su evolución.
E Síntomas y estado de salud :: Para describir un cuadro catarral se emplean expresiones como «ik ben verkouden» (estoy resfriado) e «ik hoest» (toso / tengo tos). «Koorts» es fiebre («Heeft u koorts?»). Para consultar si el estado empeora se usa el adjetivo comparativo «erger» (peor): «Wordt de hoest erger?» (¿empeora la tos?).
W hoest = tos; toser
W erger = peor; más grave
w verkouden = resfriado
w sinds = desde
w gisteren = ayer
w koorts = fiebre
w slecht = mal; malo
V Síntomas clínicos
D En una situación cotidiana
Patiënt: Ik hoest en ik ben verkouden. = Toso y estoy resfriado.
  > Ik hoest = yo toso | en = y | ik ben verkouden = estoy resfriado
Huisarts: Heeft u koorts? = ¿Tiene fiebre?
  > Heeft u = tiene usted | koorts = fiebre
Patiënt: Een beetje, sinds gisteren. = Un poco, desde ayer.
  > Een beetje = un poco | sinds gisteren = desde ayer
Huisarts: Wordt de hoest erger? = ¿La tos está empeorando?
  > Wordt = se vuelve; está | de hoest = la tos | erger = peor; empeorando
Patiënt: Nee, maar ik slaap slecht. = No, pero duermo mal.
  > Nee = no | maar = pero | ik slaap slecht = duermo mal
Q ¿Qué término neerlandés significa «fiebre»?
+ koorts :: «Koorts» es la elevación de temperatura corporal.
- hoest :: «Hoest» es la tos.
- erger :: «Erger» es el comparativo de empeoramiento («peor»).
R Ik hoest en ik ben verkouden. :: ¿Qué cuadro presenta el paciente según sus palabras?
+ Tiene tos y se encuentra acatarrado. :: «Hoest» es toser y «verkouden» describe el resfriado.
- Padece una fractura ósea en el brazo. :: No presenta traumatismo, sino un proceso respiratorio vírico.
- Sufre una alergia grave por frutos secos. :: No habla de alergias alimentarias.
H Heeft u ___? :: Completa la pregunta del médico de cabecera sobre la temperatura corporal.
+ koorts :: «Koorts hebben» es la locución médica habitual para tener fiebre.
- erger :: «Erger» es un adjetivo comparativo, no un sustantivo patológico.
- slecht :: «Slecht» es un adverbio/adjetivo («mal»).
R Wordt de hoest erger? :: ¿Qué evolución indaga el médico de familia?
+ Si la tos está empeorando con el paso de las horas. :: «Erger worden» significa empeorar o agravarse.
- Si la tos ha desaparecido por completo tras el descanso. :: Pregunta precisamente si va a peor, no si ha remitido.
- Si el paciente necesita un certificado médico urgente. :: No aborda trámites administrativos.
H Nee, maar ik slaap ___. :: Completa para indicar que el paciente descansa deficientemente por las noches.
+ slecht :: «Slecht slapen» significa dormir mal.
- goed :: «Goed» expresaría que duerme bien, en contradicción con «maar».
- koorts :: «Koorts» es un sustantivo y no puede funcionar como adverbio modal.
O Ik hoest en ik ben verkouden :: Toso y estoy resfriado. :: Dos oraciones coordinadas en presente para describir sintomatología básica.

@ 19 | Bij de apotheek | En la farmacia
I Solicita medicamentos para dolencias leves y comprende pautas de administración.
E Instrucciones farmacéuticas :: En la farmacia («de apotheek»), para pedir algo contra un dolor se dice «Heeft u iets tegen keelpijn?» (¿tiene algo contra el dolor de garganta?). El verbo separable «innemen» significa tomar o ingerir un medicamento: «Hoe vaak moet ik ze innemen?» (¿con qué frecuencia debo tomarlas?). La partícula separable «in» se coloca al final de la frase afirmativa: «Neem ze met water in».
W tabletten = pastillas; comprimidos
W aanwijzingen = instrucciones; indicaciones
w tablet = comprimido; pastilla
w innemen = tomar; ingerir
w ze = las; ellos; ellas
w etiket = etiqueta
w dagelijks = a diario
w keelpijn = dolor de garganta
w volgen = seguir
V Medicamentos y posología
D En una situación cotidiana
Klant: Heeft u iets tegen keelpijn? = ¿Tiene algo para el dolor de garganta?
  > Heeft u = tiene usted | iets tegen = algo contra | keelpijn = dolor de garganta
Apotheker: Deze tabletten kunnen helpen. = Estas pastillas pueden ayudar.
  > Deze tabletten = estas pastillas | kunnen helpen = pueden ayudar
Klant: Hoe vaak moet ik ze innemen? = ¿Con qué frecuencia debo tomarlas?
  > Hoe vaak = con qué frecuencia | moet ik ze = debo yo las | innemen = tomar
Apotheker: Lees het etiket en neem ze met water in. = Lea la etiqueta y tómelas con agua.
  > Lees het etiket = lea la etiqueta | en neem ze = y tómelas | met water in = con agua (innemen)
Klant: Dank u, ik zal de aanwijzingen volgen. = Gracias, seguiré las indicaciones.
  > Dank u = gracias | ik zal = yo voy a; seguiré | de aanwijzingen = las indicaciones | volgen = seguir
Q ¿Qué verbo separable neerlandés se utiliza específicamente para tomar o ingerir medicamentos?
+ innemen :: Es el verbo técnico común para medicación oral («tabletten innemen»).
- meenemen :: Significa llevarse algo consigo a otro lugar.
- opstaan :: Significa levantarse de la cama o asiento.
R Deze tabletten kunnen helpen. :: ¿Qué producto recomienda el farmacéutico?
+ Unas pastillas o comprimidos para aliviar las molestias. :: «Tabletten» son pastillas y «helpen» ayudar o aliviar.
- Un jarabe líquido sabor a limón. :: No recomienda jarabe, sino comprimidos.
- Una crema hidratante para aplicar sobre la piel. :: No ofrece ningún ungüento tópico.
H Hoe vaak moet ik ze ___? :: Completa con el infinitivo que cierra la perífrasis modal con «moeten».
+ innemen :: Cierra la estructura con el verbo de ingestión de fármacos.
- etiket :: «Etiket» es el sustantivo etiqueta.
- water :: «Water» es agua.
R Lees het etiket en neem ze met water in. :: ¿Qué pautas de administración transmite el farmacéutico?
+ Leer el prospecto o etiqueta y tomarlas acompañadas de agua. :: «Het etiket lezen» y «met water innemen».
- Masticar los comprimidos antes de acostarse sin beber nada. :: Especifica claramente que deben tomarse con agua («met water»).
- Disolver las pastillas en leche caliente tres veces al día. :: No menciona leche ni calor.
H Dank u, ik zal de ___ volgen. :: Completa con el sustantivo que designa las instrucciones médicas.
+ aanwijzingen :: «De aanwijzingen» son las instrucciones o indicaciones a seguir.
- tabletten :: No encaja con el verbo «volgen» (seguir unas pastillas carece de sentido).
- koorts :: «Koorts» es fiebre.
O Heeft u iets tegen keelpijn :: ¿Tiene algo para el dolor de garganta? :: Pregunta cortés con verbo inicial y preposición adversativa «tegen».
