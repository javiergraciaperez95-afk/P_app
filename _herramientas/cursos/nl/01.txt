@ 1 | Hallo, ik heet Anna | Saludar y presentarse
I Empezamos con las fórmulas básicas de saludo y presentación en neerlandés.
E Saludos y presentaciones :: «Hallo» es el saludo habitual en cualquier situación cotidiana, mientras que «hoi» es más informal entre amigos y jóvenes. «Dag» sirve tanto para saludar («buenos días / hola») como para despedirse («adiós»). Para presentarte usas «ik heet...» (me llamo...) o «ik ben...» (yo soy...). Para preguntar el nombre se dice «Hoe heet jij?» (¿Cómo te llamas?). Al despedirte dices «tot ziens» (hasta la vista) o «doei» (chao, informal).
W hallo = hola
W hoi = hola informal
W dag = hola o adiós
W doei = adiós
W tot ziens = hasta luego
W ik = yo
W heet = me llamo
W jij = tú
W hoe = cómo
W ben = soy
W aangenaam = encantado
W dank = gracias
W je = tú; te
V Vocabulario clave
D En una situación cotidiana
Anna: Hallo! Ik heet Anna. = ¡Hola! Me llamo Anna.
  > Hallo = hola | Ik heet = me llamo
Tom: Hoi, Anna. Hoe heet jij? = Hola, Anna. ¿Cómo te llamas?
  > Hoi = hola informal | Hoe heet jij = ¿cómo te llamas?
Anna: Ik ben Anna. Aangenaam! = Soy Anna. ¡Encantada!
  > Ik ben = yo soy | Aangenaam = encantada
Tom: Aangenaam. Tot ziens! = Encantado. ¡Hasta luego!
  > Aangenaam = encantado | Tot ziens = hasta luego
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «hola» de manera estándar y neutral?
+ hallo :: Es el saludo habitual y neutro.
- doei :: Es una despedida informal («adiós»).
- tot ziens :: Significa «hasta luego».
R Hoi, Anna. Hoe heet jij? :: ¿Qué significa esta frase?
+ Hola, Anna. ¿Cómo te llamas? :: «Hoi» es hola informal y «Hoe heet jij?» pregunta el nombre.
- Adiós, Anna. ¿De dónde eres? :: Mezcla una despedida con una pregunta de origen.
- Hola, Anna. ¿Cómo estás hoy? :: Pregunta cómo está, no cómo se llama.
H Hoe ___ jij? :: Completa la pregunta «¿Cómo te llamas?».
+ heet :: Con el pronombre jij se usa la forma «heet».
- ben :: Significa «soy» («ik ben»), no encaja con «Hoe».
- dank :: Significa «gracias», no es un verbo para llamar.
R Ik ben Anna. Aangenaam! :: ¿Qué expresa Anna con estas palabras?
+ Soy Anna. ¡Encantada! :: «Ik ben» expresa identidad y «Aangenaam» es la fórmula de cortesía al conocerse.
- Me voy ahora. ¡Hasta luego! :: No expresa una despedida.
- Hola a todos. ¡Muchas gracias! :: No es un saludo plural de agradecimiento.
O Hallo! Ik heet Anna :: ¡Hola! Me llamo Anna. :: Fíjate en el orden: sujeto (Ik) y verbo (heet).
Q Para despedirte de manera informal de un amigo neerlandés, ¿qué palabra usas?
+ doei :: Es la despedida coloquial cotidiana («chao»).
- hallo :: Es un saludo («hola»), no una despedida.
- aangenaam :: Significa «encantado / mucho gusto».
Q ¿Qué significa «doei» en español?
+ adiós :: Es una despedida coloquial equivalente a «chao» o «adiós».
- hola :: Es un saludo de entrada.
- por favor :: Es una petición de cortesía.
R Aangenaam. Tot ziens! :: Elige la traducción correcta de esta despedida.
+ Encantado. ¡Hasta luego! :: «Aangenaam» es encantado y «tot ziens» es hasta luego.
- Muchas gracias. Por favor. :: Mezcla agradecimiento y petición.
- Hola informal. Bienvenido. :: Contiene fórmulas de saludo de llegada.


@ 1 | Waar kom je vandaan? | Decir de dónde eres y qué idiomas hablas
I Aprendemos a preguntar la procedencia y los idiomas que hablas.
E Procedencia e idiomas :: Para preguntar de dónde eres se dice «Waar kom je vandaan?». Fíjate en que «vandaan» va al final. Para responder: «Ik kom uit...» (Vengo de / Soy de...). Para preguntar por idiomas: «Spreek je Nederlands?» (¿Hablas neerlandés?). Con el pronombre «je» pospuesto al verbo en preguntas, el verbo pierde la -t final: «spreek je» (y no «spreekt je»).
W waar = dónde
W vandaan = de dónde
W kom = vengo
W komt = vienes
W uit = de
W Spanje = España
W Nederland = Países Bajos
W België = Bélgica
W spreek = hablo
W spreekt = hablas
W Nederlands = neerlandés
W Spaans = español
W Engels = inglés
W een beetje = un poco
W je = tú
w en = y
V Vocabulario clave
D En una situación cotidiana
Noor: Waar kom je vandaan? = ¿De dónde eres?
  > Waar = dónde | kom je = vienes tú | vandaan = de dónde
Luca: Ik kom uit Spanje. = Soy de España.
  > Ik kom = yo vengo | uit = de | Spanje = España
Noor: Spreek je Nederlands? = ¿Hablas neerlandés?
  > Spreek je = hablas tú | Nederlands = neerlandés
Luca: Een beetje. Ik spreek Spaans en Engels. = Un poco. Hablo español e inglés.
  > Een beetje = un poco | Ik spreek = yo hablo | Spaans = español | en = y | Engels = inglés
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el interrogativo «dónde»?
+ waar :: Es el pronombre interrogativo de lugar.
- vandaan :: Significa «de dónde» (origen/procedencia).
- uit :: Es la preposición «de» o «desde».
R Ik kom uit Spanje. :: ¿Qué significa esta frase?
+ Soy de España. :: «Ik kom uit» indica procedencia («vengo de España»).
- Voy a España mañana. :: Indica dirección futura, no procedencia.
- Hablo español muy bien. :: Habla del idioma, no del país de origen.
H Ik kom ___ Spanje. :: Completa con la preposición de origen («vengo de»).
+ uit :: Se usa «uit» para indicar el país o ciudad de origen.
- vandaan :: Se combina con «waar» al inicio: «Waar kom je vandaan?».
- en :: Es la conjunción copulativa «y».
R Spreek je Nederlands? :: ¿Qué pregunta Noor en esta frase?
+ ¿Hablas neerlandés? :: Pregunta si hablas el idioma neerlandés.
- ¿Vives en los Países Bajos? :: Preguntaría por residencia («Woon je...»).
- ¿Entiendes a las personas? :: Preguntaría por comprensión auditiva.
O Waar kom je vandaan :: ¿De dónde eres? :: Recuerda poner «vandaan» al final de la pregunta.
Q ¿Qué forma verbal corresponde a la segunda persona «jij komt»?
+ komt :: Es la forma de presente para «jij» en orden afirmativo directo.
- kom :: Es la forma de primera persona («ik kom»).
- spreek :: Es el verbo hablar («ik spreek»).
Q ¿Qué significa «komt»?
+ vienes :: Forma conjugada del verbo komen («jij komt»).
- hablas :: Corresponde a «spreekt».
- vives :: Corresponde a «woont».
R Een beetje. Ik spreek Spaans en Engels. :: Elige la traducción correcta de esta respuesta.
+ Un poco. Hablo español e inglés. :: «Een beetje» significa un poco; «Spaans en Engels», español e inglés.
- Mucho. No hablo inglés ni neerlandés. :: Dice lo opuesto de lo que afirma Luca.
- Por supuesto. Hablo cuatro idiomas europeos. :: Agrega información inexistente.


@ 1 | Spellen en nummers | Deletrear y decir números
I Aprendemos a deletrear nombres propios y a contar los números del cero al diez.
E Deletrear y números de teléfono :: Para pedir que alguien deletree su nombre usamos «Hoe spel je je naam?» (¿Cómo deletreas tu nombre?). Al dar el número de teléfono decimos «Mijn nummer is...» y enumeramos las cifras una a una: nul, één, twee, drie, vier, vijf, zes, zeven, acht, negen, tien.
W spellen = deletrear
W spel = deletreo
W naam = nombre
W nummer = número
W telefoonnummer = número de teléfono
W nul = cero
W één = uno
W twee = dos
W drie = tres
W vier = cuatro
W vijf = cinco
W zes = seis
W zeven = siete
W acht = ocho
W negen = nueve
W tien = diez
W wat = qué
W mijn = mi
W is = es
w n-o-o-r = deletreo de Noor
V Vocabulario clave
D En una situación cotidiana
Sara: Hoe spel je je naam? = ¿Cómo se deletrea tu nombre?
  > Hoe = cómo | spel je = deletreas tú | je naam = tu nombre
Noor: Ik spel mijn naam: Noor. = N-O-O-R. Me llamo Noor.
  > Ik spel = yo deletreo | mijn naam = mi nombre
Sara: Wat is je nummer? = ¿Cuál es tu número?
  > Wat is = cuál es | je nummer = tu número
Noor: Mijn nummer is zes, twee, één. = Mi número es seis, dos, uno.
  > Mijn nummer is = mi número es | zes = seis | twee = dos | één = uno
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo «deletrear»?
+ spellen :: Es el infinitivo con terminación regular «-en».
- spel :: Es la forma de primera persona («ik spel»).
- nummer :: Significa «número».
R N-O-O-R. Mijn naam is Noor. :: ¿Qué significa esta frase?
+ N-O-O-R. Mi nombre es Noor. :: Deletrea las letras y confirma su nombre.
- Uno, dos, tres. Mi teléfono es Noor. :: Confunde el deletreo con números.
- No lo sé. ¿Cómo te llamas tú? :: Es una pregunta de desconocimiento.
H Hoe ___ je je naam? :: Completa la frase: «¿Cómo deletreas tu nombre?».
+ spel :: Tras inversión con «je», el verbo pierde la -t y queda «spel».
- spellen :: Es el infinitivo («deletrear»), no la forma conjugada con je.
- naam :: Es el sustantivo «nombre», no un verbo conjugado.
R Wat is je nummer? :: ¿Qué pregunta Sara en esta intervención?
+ ¿Cuál es tu número? :: «Wat is je nummer?» pide el número de contacto.
- ¿Cuál es tu dirección? :: Pediría la dirección («je adres»).
- ¿Dónde vives ahora? :: Preguntaría por el lugar de residencia.
O Hoe spel je je naam :: ¿Cómo se deletrea tu nombre? :: Fíjate en la inversión: verbo spel antes del sujeto je.
Q ¿Qué significa el sustantivo «nummer» en español?
+ número :: Significa número, como en teléfono o cifra.
- nombre :: «Nombre» en neerlandés se dice «naam».
- dirección :: «Dirección» se dice «adres».
R Mijn nummer is zes, twee, één. :: Elige la traducción correcta de las cifras.
+ Mi número es seis, dos, uno. :: Traduce exactamente «zes (6), twee (2), één (1)».
- Mi número es siete, tres, cero. :: Cifras incorrectas (sería «zeven, drie, nul»).
- Mi teléfono es cinco, cuatro, dos. :: Cifras incorrectas (sería «vijf, vier, twee»).
