@ 6 | Eten en drinken | Nombrar alimentos y bebidas
I Aprendemos los alimentos básicos, las comidas del día y a expresar qué comes y bebes.
E Comidas, alimentos y bebidas :: Para hablar de las comidas del día usamos: «het ontbijt» (el desayuno), «de lunch» (el almuerzo) y «het avondeten» (la cena). La preposición «bij» expresa «en/durante»: «bij het ontbijt» (en el desayuno). Los verbos clave son «eten» (comer, irregular: ik eet) y «drinken» (beber: ik drink). Conoce los alimentos comunes: «het brood» (el pan), «de kaas» (el queso), «de appel» (la manzana), «de banaan» (el plátano), «het water» (el agua), «de koffie» (el café), «de thee» (el té) y «de melk» (la leche).
w eten = comer
W drinken = beber
W brood = pan
W kaas = queso
W appel = manzana
W banaan = plátano
W water = agua
W koffie = café
W thee = té
W melk = leche
W lunch = almuerzo
W avondeten = cena
W eet = como
W bij = en
V Vocabulario clave
D En una situación cotidiana
Emma: Wat eet je bij het ontbijt? = ¿Qué comes en el desayuno?
  > Wat eet je = qué comes tú | bij het ontbijt = en el desayuno
Tom: Ik eet brood en kaas. = Como pan y queso.
  > Ik eet = yo como | brood en kaas = pan y queso
Emma: Drink je koffie? = ¿Bebes café?
  > Drink je = bebes tú | koffie = café
Tom: Nee, ik drink thee. = No, bebo té.
  > Nee = no | ik drink = yo bebo | thee = té
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés el infinitivo «comer»?
+ eten :: Es el infinitivo «comer».
- drinken :: Es el infinitivo «beber».
- brood :: Es el sustantivo «pan».
R Ik eet brood en kaas. :: ¿Qué significa esta frase?
+ Como pan y queso. :: «Eet» es primera persona de comer y nombra pan con queso.
- Bebo leche con café por la mañana. :: No habla de beber ni de café con leche.
- Compro queso y manzanas en el mercado. :: No usa el verbo comprar ni manzanas.
H Ik ___ brood en kaas. :: Completa con la forma correcta de comer para «ik».
+ eet :: Con «ik» la forma conjugada de «eten» es «eet».
- drinken :: Significa beber en infinitivo.
- kaas :: Es el sustantivo «queso», no un verbo.
R Drink je koffie? :: ¿Qué pregunta Emma?
+ ¿Bebes café? :: Inversión interrogativa de «drinken» con «je».
- ¿Quieres comer queso holandés? :: Preguntaría por comer queso («kaas eten»).
- ¿Tienes té caliente en la cocina? :: Preguntaría por té («thee»).
O Wat eet je bij het ontbijt :: ¿Qué comes en el desayuno? :: Interrogativo Wat + verbo eet + sujeto je + complemento temporal bij het ontbijt.
Q ¿Qué alimento es «kaas»?
+ queso :: «De kaas» es el queso.
- pan :: «Pan» se dice «brood».
- manzana :: «Manzana» se dice «appel».
R Nee, ik drink thee. :: Elige la traducción correcta de la respuesta.
+ No, bebo té. :: Niega beber café y afirma que bebe té («thee»).
- Sí, prefiero agua con hielo. :: Agua se dice «water».
- No, no tomo desayuno hoy. :: No menciona el desayuno.


@ 6 | Wat vind je lekker? | Expresar gustos y pedir comida
I Aprendemos a opinar sobre la comida con la estructura «lekker vinden» y a pedir platos con «ik wil graag...».
E Gustos culinarios y cortesía :: Para expresar que algo te gusta en neerlandés no se suele usar un verbo equivalente a «gustar», sino «lekker vinden» (literalmente «parecerte rico»): «Ik vind de soep lekker» (Me gusta la sopa). En preguntas: «Vindt u de soep lekker?» (¿Le gusta la sopa?). Para pedir de manera cortés en un restaurante se usa «Ik wil graag...» (Quisiera... / Me gustaría...): «Ik wil graag soep».
W lekker = rico
W vinden = opinar
W vind = me parece
W houden van = gustar
W graag = con gusto
W wil = quiero
W willen = querer
W soep = sopa
W salade = ensalada
W rijst = arroz
W vis = pescado
W vlees = carne
W vegetarisch = vegetariano
W menu = menú
W u = usted
w vindt = opina
w wilt = quieres; quiere
V Vocabulario clave
D En una situación cotidiana
Ober: Wat wilt u eten? = ¿Qué quiere comer?
  > Wat wilt u = qué quiere usted | eten = comer
Noor: Ik wil graag soep. = Quisiera sopa.
  > Ik wil graag = quisiera | soep = sopa
Ober: Vindt u de soep lekker? = ¿Le gusta la sopa?
  > Vindt u = le parece a usted | de soep = la sopa | lekker = rica
Noor: Ja, de soep is lekker. = Sí, la sopa está rica.
  > Ja = sí | de soep is = la sopa es / está | lekker = rica
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés que una comida está «rica» o deliciosa?
+ lekker :: Es el adjetivo predilecto para comida sabrosa («lekker»).
- menu :: Significa «menú».
- vegetarisch :: Significa «vegetariano».
R Ik wil graag soep. :: ¿Qué pide Noor en esta frase?
+ Quisiera sopa. :: «Ik wil graag» es la forma habitual y educada de pedir comida.
- No me gusta la sopa caliente. :: Sería una queja, no una petición cordial.
- Tráigame carne con arroz blanco. :: Carne con arroz sería «vlees met rijst».
H Ik ___ graag soep. :: Completa con la forma verbal para expresar deseo educado («quisiera»).
+ wil :: «Ik wil graag» formula una petición educada.
- wilt :: Es la forma para «jij/u», no para «ik».
- lekker :: Es un adjetivo («rico»), no un verbo.
R Vindt u de soep lekker? :: ¿Qué indaga el camarero con esta pregunta?
+ ¿Le gusta la sopa? :: La construcción «lekker vinden» pregunta si encuentra rica la comida.
- ¿Desea otra porción de pan? :: Preguntaría por pan («brood»).
- ¿Quiere pedir la cuenta ya? :: Preguntaría por «de rekening».
O Wat wilt u eten :: ¿Qué quiere comer? :: Orden interrogativo formal con pronombre u: Wat + wilt + u + eten.
Q ¿Qué expresión verbal se usa para expresar afición o cariño por algo («gustar / amar»)?
+ houden van :: Significa «gustar mucho» o «querer a alguien».
- bestellen :: Significa pedir o encargar.
- betalen :: Significa pagar.
R Ja, de soep is lekker. :: Elige la traducción correcta.
+ Sí, la sopa está rica. :: Afirma con claridad que la sopa es de su agrado.
- No, la ensalada no tiene sal. :: Ensalada es «salade».
- Sí, el pescado está frío. :: Pescado es «vis».


@ 6 | In het café | Pedir algo y pagar
I Aprendemos a pedir consumiciones en una cafetería y a pagar en efectivo o con tarjeta.
E Pedir y pagar en la cafetería :: Para pedir educadamente se añade «alstublieft» (por favor, formal): «Een kopje thee, alstublieft» (Una taza de té, por favor). Para pedir la cuenta: «De rekening, alstublieft». Para el método de pago se distingue: «contant» (en efectivo) o «pinnen» (pagar con tarjeta de débito, verbo imprescindible en los Países Bajos). «Wilt u nog iets?» significa «¿Desea algo más?».
W café = cafetería
W ober = camarero
W bestellen = pedir
W bestel = pido
W rekening = cuenta
W alstublieft = por favor
W contant = en efectivo
W pinnen = pagar con tarjeta
W betalen = pagar
W betaal = pago
W glas = vaso
W kopje = taza
W nog = más
W dank u = gracias
w goedemiddag = buenas tardes
w iets = algo
V Vocabulario clave
D En una situación cotidiana
Ober: Goedemiddag. Wat wilt u bestellen? = Buenas tardes. ¿Qué desea pedir?
  > Goedemiddag = buenas tardes | Wat wilt u = qué desea usted | bestellen = pedir
Sara: Een kopje thee, alstublieft. = Una taza de té, por favor.
  > Een kopje thee = una taza de té | alstublieft = por favor
Ober: Wilt u nog iets? = ¿Desea algo más?
  > Wilt u = desea usted | nog iets = algo más
Sara: Nee, dank u. De rekening, alstublieft. = No, gracias. La cuenta, por favor.
  > Nee = no | dank u = gracias | De rekening = la cuenta | alstublieft = por favor
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «cafetería»?
+ café :: «Het café» es la cafetería o taberna.
- rekening :: Significa «cuenta».
- ober :: Significa «camarero».
R Een kopje thee, alstublieft. :: ¿Qué pide Sara?
+ Una taza de té, por favor. :: «Een kopje thee» es una taza de té y «alstublieft» es por favor.
- Un vaso de agua fría, por favor. :: Un vaso de agua sería «een glas water».
- Un café con leche caliente. :: Café con leche sería «koffie met melk».
H De ___, alstublieft. :: Completa para pedir «La cuenta, por favor».
+ rekening :: «De rekening» es la cuenta del restaurante o café.
- café :: Es el establecimiento («cafetería»).
- glas :: Es el objeto «vaso».
R Wilt u nog iets? :: ¿Qué ofrece el camarero?
+ ¿Desea algo más? :: «Nog iets» significa algo más / algo adicional.
- ¿Desea pagar con tarjeta? :: Preguntaría con el verbo «pinnen».
- ¿Va a comer aquí o para llevar? :: Preguntaría por comer allí.
O Goedemiddag. Wat wilt u bestellen :: Buenas tardes. ¿Qué desea pedir? :: Saludo formal seguido de interrogativa con infinitivo bestellen al final.
Q ¿Qué forma verbal corresponde a «yo pido / encargo»?
+ bestel :: Es la primera persona singular del presente («ik bestel»).
- bestellen :: Es el infinitivo («pedir»).
- betaal :: Es el verbo pagar («ik betaal»).
R Nee, dank u. De rekening, alstublieft. :: Elige la traducción correcta.
+ No, gracias. La cuenta, por favor. :: Rechaza más pedidos y solicita amablemente la cuenta.
- Sí, por favor. Tráigame otro café. :: Pide más bebida en vez de pedir la cuenta.
- No tengo efectivo para pagar. :: No habla de dinero en efectivo («contant»).
