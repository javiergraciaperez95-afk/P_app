@ 7 | Kleding | Nombrar ropa y colores
I Aprendemos los nombres de las prendas de vestir y los demostrativos «deze» y «dit».
E Ropa y demostrativos :: Los demostrativos de cercanía dependen del artículo del sustantivo: para palabras con «de» se usa «deze» («deze jas» - esta chaqueta, «deze broek» - este pantalón); para palabras con «het» se usa «dit» («dit shirt» - esta camiseta, «dit kind» - este niño). Prendas habituales: «de jas» (la chaqueta / abrigo), «de broek» (el pantalón), «de jurk» (el vestido), «het shirt» (la camiseta), «de schoenen» (los zapatos), «de sokken» (los calcetines). El verbo vestir o llevar puesto es «dragen» (ik draag).
W kleding = ropa
W jas = chaqueta
W broek = pantalón
W jurk = vestido
W shirt = camiseta
W schoenen = zapatos
W sokken = calcetines
W dragen = llevar puesto
W draag = llevo
W deze = este
W roze = rosa
V Vocabulario clave
D En una situación cotidiana
Mila: Vind je deze jas mooi? = ¿Te gusta esta chaqueta?
  > Vind je = te parece a ti | deze jas = esta chaqueta | mooi = bonita
Noor: Ja, de jas is mooi. = Sí, la chaqueta es bonita.
  > Ja = sí | de jas is = la chaqueta es | mooi = bonita
Mila: En dit shirt? = ¿Y esta camiseta?
  > En = y | dit shirt = esta camiseta
Noor: Het shirt is roze. = La camiseta es rosa.
  > Het shirt is = la camiseta es | roze = rosa
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «ropa» en general?
+ kleding :: «De kleding» es la ropa o vestimenta.
- jas :: Es específicamente la «chaqueta».
- broek :: Es el «pantalón».
R Ja, de jas is mooi. :: ¿Qué opina Noor sobre la prenda?
+ Sí, la chaqueta es bonita. :: Confirma que le gusta y la encuentra bonita («mooi»).
- No, el abrigo es muy viejo y caro. :: Contrario a lo afirmado.
- Prefiero comprar una falda negra. :: No habla de faldas ni de comprar.
H Vind je ___ jas mooi? :: Completa con el demostrativo para un sustantivo con «de» (jas).
+ deze :: «Jas» es palabra «de», por lo que requiere el demostrativo «deze».
- dit :: Se usa solo para palabras con «het» («dit shirt»).
- broek :: Es el sustantivo pantalón, no un demostrativo.
R En dit shirt? :: ¿Qué pregunta Mila?
+ ¿Y esta camiseta? :: «Dit shirt» usa «dit» porque shirt es palabra con «het».
- ¿Y aquellos pantalones largos? :: Hablaría de «deze broek».
- ¿Dónde están los calcetines blancos? :: Preguntaría por «sokken».
O Vind je deze jas mooi :: ¿Te gusta esta chaqueta? :: Orden interrogativo: verbo Vind + sujeto je + demostrativo deze jas + adjetivo mooi.
Q ¿Qué prenda de vestir significa «jurk»?
+ vestido :: «De jurk» es el vestido femenino.
- chaqueta :: «Chaqueta» se dice «jas».
- camiseta :: «Camiseta» se dice «shirt».
R Het shirt is roze. :: Elige la traducción exacta de la frase.
+ La camiseta es rosa. :: Describe el color rosa («roze») de la camiseta.
- La camiseta es verde y blanca. :: Verde y blanca sería «groen en wit».
- El vestido es demasiado grande. :: «Vestido» sería «de jurk».


@ 7 | Maten en prijzen | Preguntar por tallas y precios
I Aprendemos a pedir tallas de ropa y a expresar adecuación con el adverbio «te» (demasiado).
E Tallas y el uso de «te» :: Para preguntar por la talla se dice «Welke maat zoek je?» (¿Qué talla buscas?). El verbo probarse ropa es «passen»: «Wil je deze broek passen?» (¿Quieres probarte este pantalón?). Cuando una prenda no queda bien usamos «te» (demasiado): «hij is te klein» (es demasiado pequeño) o «hij is te groot» (es demasiado grande). Recuerda que a los objetos masculinos/femeninos se alude con «hij»: «de broek... hij is te klein».
W maat = talla
W te = demasiado
W passen = probarse
W pas = me pruebo
W duur = caro
W goedkoop = barato
W prijs = precio
W kassa = caja
W korting = descuento
W deze = este
W hij = él
w zoek = busco
V Vocabulario clave
D En una situación cotidiana
Mila: Welke maat zoek je? = ¿Qué talla buscas?
  > Welke maat = qué talla | zoek je = buscas tú
Tom: Maat M, alstublieft. = La talla M, por favor.
  > Maat M = talla M | alstublieft = por favor
Mila: Wil je deze broek passen? = ¿Quieres probarte este pantalón?
  > Wil je = quieres tú | deze broek = este pantalón | passen = probarte
Tom: Ja, maar hij is te klein. = Sí, pero es demasiado pequeño.
  > Ja = sí | maar = pero | hij is te klein = es demasiado pequeño
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «talla» de ropa?
+ maat :: «De maat» es la talla o medida.
- prijs :: Significa «precio».
- kassa :: Significa «caja» de cobro.
R Maat M, alstublieft. :: ¿Qué solicita Tom al dependiente?
+ La talla M, por favor. :: Especifica educadamente la talla mediana que necesita.
- Tres camisetas medianas, gracias. :: No pide tres camisetas.
- La cuenta para pagar en caja. :: No pide pagar.
H Hij is te ___ . :: Completa: «Es demasiado pequeño».
+ klein :: «Te klein» expresa «demasiado pequeño».
- groot :: Significaría lo contrario («demasiado grande»).
- duur :: Significaría «demasiado caro».
R Wil je deze broek passen? :: ¿Qué propone Mila en esta intervención?
+ ¿Quieres probarte este pantalón? :: «Passen» es probarse ropa y «deze broek» es este pantalón.
- ¿Vas a pagar el pantalón en efectivo? :: Preguntaría por pagar («betalen»).
- ¿Prefieres una chaqueta más barata? :: Preguntaría por una «jas».
O Welke maat zoek je :: ¿Qué talla buscas? :: Interrogativo Welke maat + verbo zoek + sujeto je.
Q ¿Qué significa el adverbio «te» colocado delante de un adjetivo?
+ demasiado :: Indica exceso («te klein» = demasiado pequeño, «te duur» = demasiado caro).
- un poco :: «Un poco» se dice «een beetje».
- muy :: «Muy» se dice «heel» o «erg».
R Ja, maar hij is te klein. :: Elige la traducción correcta del motivo.
+ Sí, pero es demasiado pequeño. :: Acepta probárselo pero señala que le queda estrecho/pequeño.
- Sí, pero no tengo dinero suficiente. :: No menciona dinero («geld»).
- No, porque el color no me gusta. :: No menciona el color.


@ 7 | In de winkel | Comprar en una tienda
I Aprendemos el vocabulario de las compras, a pedir ayuda al dependiente y el pago con tarjeta.
E Comprar en comercios :: La frase típica del dependiente es «Goedemiddag. Kan ik u helpen?» (Buenas tardes, ¿puedo ayudarle?). Para decir lo que buscas: «Ik zoek...» (Busco...). El verbo «mogen» expresa permiso: «Mag ik pinnen?» (¿Puedo pagar con tarjeta?). Elementos de la compra: «de winkel» (la tienda), «het geld» (el dinero), «de bon» (el recibo / ticket de compra), «de pinpas» (la tarjeta de débito).
W winkel = tienda
W kopen = comprar
W koop = compro
W zoeken = buscar
W mag = puedo
W mogen = poder
W nodig = necesario
W bon = ticket
W geld = dinero
W pinpas = tarjeta bancaria
W helpen = ayudar
W dat is alles = eso es todo
W kan = puedo
V Vocabulario clave
D En una situación cotidiana
Medewerker: Goedemiddag. Kan ik u helpen? = Buenas tardes. ¿Puedo ayudarle?
  > Goedemiddag = buenas tardes | Kan ik = puedo yo | u helpen = ayudarle a usted
Noor: Ik zoek een tas. = Busco una bolsa.
  > Ik zoek = yo busco | een tas = una bolsa
Medewerker: Deze tas kost tien euro. = Esta bolsa cuesta diez euros.
  > Deze tas kost = esta bolsa cuesta | tien euro = diez euros
Noor: Mag ik pinnen? = ¿Puedo pagar con tarjeta?
  > Mag ik = puedo yo | pinnen = pagar con tarjeta
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «tienda»?
+ winkel :: «De winkel» es la tienda o comercio.
- kassa :: Es la caja cobradora.
- bon :: Es el recibo o «ticket».
R Ik zoek een tas. :: ¿Qué explica Noor al empleado?
+ Busco una bolsa. :: Explica qué artículo está buscando en la tienda.
- Quiero devolver una bolsa rota. :: No habla de devoluciones.
- Ya encontré la bolsa que quería. :: Dice que la está buscando ahora.
H Ik ___ een tas. :: Completa con la forma verbal «busco».
+ zoek :: Con «ik» corresponde la forma «zoek».
- kopen :: Es el infinitivo «comprar».
- koop :: Significa «compro», no «busco».
R Deze tas kost tien euro. :: ¿Qué información da el dependiente?
+ Esta bolsa cuesta diez euros. :: Comunica el precio exacto del artículo.
- Esta bolsa tiene un diez por ciento de descuento. :: No habla de porcentaje ni descuento.
- Esta bolsa solo se vende con tarjeta. :: No restringe el método de pago aún.
O Goedemiddag. Kan ik u helpen :: Buenas tardes. ¿Puedo ayudarle? :: Saludo de cortesía + auxiliar Kan + sujeto ik + objeto u + infinitivo helpen.
Q ¿Qué verbo significa «buscar» en infinitivo?
+ zoeken :: Es el infinitivo «buscar».
- kopen :: Significa «comprar».
- helpen :: Significa «ayudar».
R Mag ik pinnen? :: Elige la traducción exacta de la pregunta.
+ ¿Puedo pagar con tarjeta? :: «Pinnen» es el verbo específico neerlandés para pago electrónico con tarjeta de débito.
- ¿Puedo pagar en monedas sueltas? :: Pago en efectivo sería «contant betalen».
- ¿Me da una bolsa de plástico gratis? :: Preguntaría por una bolsa («tas»).
