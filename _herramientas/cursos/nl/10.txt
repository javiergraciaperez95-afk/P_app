@ 10 | Bij de dokter | Hablar de la salud
I Aprendemos a describir síntomas de enfermedad, partes del cuerpo y a concertar una cita médica.
E Salud y citas médicas :: Para expresar dolor se usa «Ik heb...» o el nombre compuesto con -pijn: «Ik heb hoofdpijn» (Me duele la cabeza), «Ik heb keelpijn» (Me duele la garganta), «Ik heb buikpijn» (Me duele la barriga). Para estados de salud: «Ik ben ziek» (Estoy enfermo) frente a «Ik ben gezond» (Estoy sano). Para síntomas: «de koorts» (la fiebre), «hoesten» (toser). En el centro de salud («de huisarts»), la recepcionista dice: «Ik maak een afspraak voor morgen» (Le doy cita para mañana).
W dokter = médico
W huisarts = médico de cabecera
W ziek = enfermo
W gezond = sano
W pijn = dolor
W hoofd = cabeza
W buik = vientre
W keel = garganta
W koorts = fiebre
W hoesten = toser
W ik heb = tengo
w heeft = tiene
w hoofdpijn = dolor de cabeza
w keelpijn = dolor de garganta
w maak = hago
V Vocabulario clave
D En una situación cotidiana
Patiënt: Ik ben ziek. Ik heb hoofdpijn. = Estoy enfermo. Me duele la cabeza.
  > Ik ben ziek = estoy enfermo | Ik heb = tengo | hoofdpijn = dolor de cabeza
Assistente: Heeft u ook koorts? = ¿También tiene fiebre?
  > Heeft u = tiene usted | ook = también | koorts = fiebre
Patiënt: Nee, maar ik heb keelpijn. = No, pero me duele la garganta.
  > Nee = no | maar = pero | ik heb = tengo | keelpijn = dolor de garganta
Assistente: Ik maak een afspraak voor morgen. = Le doy una cita para mañana.
  > Ik maak = yo hago | een afspraak = una cita | voor morgen = para mañana
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «médico» o doctor en general?
+ dokter :: «De dokter» es el médico.
- huisarts :: Es específicamente el médico de cabecera o de familia.
- ziek :: Es el adjetivo «enfermo».
R Heeft u ook koorts? :: ¿Qué pregunta la asistente médica?
+ ¿También tiene fiebre? :: Pregunta formalmente con «u» si el paciente presenta temperatura alta.
- ¿Le duele la cabeza por las noches? :: Preguntaría por dolor de cabeza («hoofdpijn»).
- ¿Puede venir a la consulta hoy? :: Preguntaría por acudir a la consulta.
H Ik heb ___ . :: Completa con el síntoma de temperatura corporal («fiebre»).
+ koorts :: «Koorts» significa fiebre.
- gezond :: Significa «sano», incompatible con «Ik heb...».
- dokter :: Significa «médico».
R Nee, maar ik heb keelpijn. :: ¿Qué aclara el paciente?
+ No, pero me duele la garganta. :: Niega tener fiebre pero indica dolor de garganta («keelpijn»).
- Sí, y además tengo dolor de muelas. :: No menciona muelas y empieza con «Nee».
- No, solo necesito un justificante médico. :: No pide justificantes.
O Ik ben ziek. Ik heb hoofdpijn :: Estoy enfermo. Me duele la cabeza. :: Dos oraciones breves y claras de estado y síntoma.
Q ¿Qué adjetivo describe a una persona «sana»?
+ gezond :: «Gezond» significa sano o saludable.
- ziek :: Significa «enfermo».
- pijn :: Significa «dolor».
R Ik maak een afspraak voor morgen. :: Elige la traducción exacta.
+ Le doy una cita para mañana. :: «Een afspraak maken» significa concertar o programar una cita.
- Venga a urgencias de inmediato. :: No lo deriva a urgencias.
- El doctor regresa la semana que viene. :: No habla de la próxima semana.


@ 10 | Op reis | Hablar de viajes y alojamiento

En recepción te pedirán los datos: «Wat is uw naam?» y presentarás tus documentos: «Hier is mijn paspoort» (Aquí está mi pasaporte). Para orientarte en el edificio: «Het ontbijt is beneden» (El desayuno se sirve abajo). Vocabulario de viaje: «de reis» (el viaje), «het hotel» (el hotel), «de bagage» (el equipaje).

W hotel = hotel
W reserveren = reservar
W gereserveerd = reservado
W paspoort = pasaporte
W bagage = equipaje
W beneden = abajo

Q ¿Cómo se dice en neerlandés «viaje»?
+ reis :: «De reis» es el viaje.
- hotel :: Es el establecimiento hotelero («het hotel»).
- bagage :: Es el «equipaje».
R Wat is uw naam? :: ¿Qué solicita el recepcionista?
+ ¿Cuál es su nombre? :: Pregunta formalmente el nombre del huésped con el posesivo «uw».
- ¿Tiene reserva confirmada para dos noches? :: Preguntaría por noches reservadas.
- ¿Dónde dejó su equipaje de mano? :: Preguntaría por «bagage».
H Ik heb een ___ gereserveerd. :: Completa con la palabra para «habitación».
+ kamer :: «Een kamer reserveren» es reservar una habitación de hotel.
- hotel :: Significa el edificio del hotel en sí.
- reis :: Significa «viaje».
R Mijn naam is Noor. Hier is mijn paspoort. :: ¿Qué hace la huésped?
+ Me llamo Noor. Aquí está mi pasaporte. :: Da su nombre y entrega la documentación requerida.
- Soy Noor. Olvidé mi pasaporte en el tren. :: No dice haberlo olvidado.
- Vengo con mi familia y dos maletas grandes. :: No menciona maletas.
O Goedemiddag. Ik heb een kamer gereserveerd :: Buenas tardes. He reservado una habitación. :: Saludo cortés seguido de frase con participio gereserveerd al final.
Q ¿Qué verbo significa «reservar» en infinitivo?
+ reserveren :: Es el infinitivo «reservar».
- reizen :: Significa «viajar».
- helpen :: Significa «ayudar».
R Dank u. Het ontbijt is beneden. :: Elige la traducción exacta.
+ Gracias. El desayuno está abajo. :: Agradece e indica la ubicación del servicio de desayuno («beneden»).
- Gracias. Su habitación está en el segundo piso. :: No habla del piso de la habitación.
- De nada. El restaurante abre a las ocho. :: No menciona restaurante ni hora.


@ 10 | Praktische situaties | Pedir ayuda y aclaraciones
I Aprendemos a resolver dificultades comunicativas pidiendo que hablen más despacio o repitan.
E Aclaraciones y pedir ayuda :: Cuando no comprendes a tu interlocutor dices: «Sorry, ik begrijp het niet» (Perdón, no lo entiendo). Fíjate en la negación con «niet» para acciones. Para pedir repetición cortés: «Kunt u dat herhalen?» (¿Puede usted repetir eso?). Para pedir que hablen con más calma: «Kunt u langzaam praten?» (¿Puede hablar despacio?). Respuestas amables: «Natuurlijk. Geen probleem!» (¡Por supuesto, ningún problema!).
W begrijpen = entender
W begrijp = entiendo
W herhalen = repetir
W langzaam = despacio
W duidelijk = claro
W praten = hablar
W praat = hablo
W vragen = preguntar
W vraag = pregunto
W probleem = problema
W nood = emergencia
W natuurlijk = naturalmente
W geen = ningún
w niet = no
w zal = voy a; auxiliar
V Vocabulario clave
D En una situación cotidiana
Noor: Sorry, ik begrijp het niet. = Perdón, no lo entiendo.
  > Sorry = perdón | ik begrijp het niet = no lo entiendo
Medewerker: Zal ik langzaam praten? = ¿Hablo despacio?
  > Zal ik = hablo yo | langzaam praten = hablar despacio
Noor: Ja, alstublieft. Kunt u dat herhalen? = Sí, por favor. ¿Puede repetirlo?
  > Ja, alstublieft = sí, por favor | Kunt u = puede usted | dat herhalen = repetir eso
Medewerker: Natuurlijk. Geen probleem. = Claro. Ningún problema.
  > Natuurlijk = claro, por supuesto | Geen probleem = ningún problema
Anna: Dank je! = ¡Gracias!
  > Dank je = gracias
Tom: Tot ziens! = ¡Hasta luego!
  > Tot ziens = hasta luego
Q ¿Cómo se dice en neerlandés «entender / comprender»?
+ begrijpen :: Es el infinitivo «begrijpen».
- herhalen :: Significa «repetir».
- praten :: Significa «hablar».
R Zal ik langzaam praten? :: ¿Qué ofrece el empleado amablemente?
+ ¿Hablo despacio? :: Propone modular su ritmo al hablar para que se entienda mejor.
- ¿Quiere que lo escriba en un papel? :: No ofrece escribir.
- ¿Prefiere hablar en inglés o español? :: No pregunta por otros idiomas.
H Kunt u dat ___? :: Completa con «repetir».
+ herhalen :: «Herhalen» es el infinitivo que complementa a «Kunt u».
- begrijpen :: Significaría «¿puede usted entender eso?».
- praten :: Significaría hablar sin especificar repetición.
R Ja, alstublieft. Kunt u dat herhalen? :: ¿Qué pide Noor?
+ Sí, por favor. ¿Puede repetirlo? :: Acepta la ayuda y solicita una repetición pausada.
- No, gracias. Ya lo entiendo perfectamente. :: Contrario a lo que pide.
- Sí, llame a otro compañero de la oficina. :: No pide otro empleado.
O Sorry, ik begrijp het niet :: Perdón, no lo entiendo. :: Negación estándar de frase verbal con niet al final.
Q ¿Qué adverbio significa «despacio / lentamente»?
+ langzaam :: «Langzaam» significa lento o despacio.
- duidelijk :: Significa «claro / claramente».
- natuurlijk :: Significa «por supuesto / naturalmente».
R Natuurlijk. Geen probleem. :: Elige la traducción correcta.
+ Claro. Ningún problema. :: «Natuurlijk» expresa conformidad y «geen probleem», sin inconveniente.
- Lo siento. No puedo atenderle ahora. :: Sería una negativa.
- Es una emergencia muy grave. :: No habla de emergencias («nood»).
