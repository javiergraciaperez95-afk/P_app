
@ 27 | Een gewone werkdag | Un día normal de trabajo
I En esta lección practicarás una situación cotidiana de nivel A2.
E Idea clave :: Los verbos separables se dividen en la frase principal: Ik sta vroeg op.
W wekker = despertador
W wakker worden = despertarse
W douchen = ducharse
W aankleden = vestirse
W ontbijt klaarmaken = preparar el desayuno
W aanzetten = encender
W pauzeren = hacer una pausa
W thuiskomen = volver a casa
W uitrusten = descansar
W boterham = rebanada de pan
W douche = ducha
W klaar = listo
w me = me
w na = después
w rust = descanso
w wakker = despierto
w word = me vuelvo
V Vocabulario clave
D En una situación cotidiana
Anna: Hoe laat word je wakker? = ¿A qué hora te despiertas?
Tom: Om half zeven. Daarna douche ik me. = A las seis y media. Después me ducho.
Anna: Maak je thuis ontbijt klaar? = ¿Preparas el desayuno en casa?
Tom: Ja, ik neem een boterham mee. = Sí, me llevo un sándwich.
Anna: Wat doe je na je werk? = ¿Qué haces después del trabajo?
Tom: Ik kom om zes uur thuis en rust dan uit. = Vuelvo a casa a las seis y descanso.
Q ¿Cómo se dice en neerlandés «despertador»?
+ wekker :: Es la respuesta correcta.
- wakker worden :: Es otra opción.
- douchen :: Es otra opción.
R Om half zeven. Daarna douche ik me. :: ¿Qué significa?
+ A las seis y media. Después me ducho. :: Es la respuesta correcta.
- Sí, me llevo un sándwich. :: Es otra opción.
- Vuelvo a casa a las seis y descanso. :: Es otra opción.
H ___ word je wakker? :: Completa la frase.
+ hoe laat :: Es la palabra que aparece en la frase.
- wakker worden :: Es otra opción.
- douchen :: Es otra opción.
A Ja, ik neem een boterham mee. :: Escucha. ¿Qué significa?
+ Sí, me llevo un sándwich. :: Es la respuesta correcta.
- ¿A qué hora te despiertas? :: Es otra opción.
- ¿Qué haces después del trabajo? :: Es otra opción.
O Hoe laat word je wakker :: ¿A qué hora te despiertas? :: Observa el orden de las palabras.

R Ik kom om zes uur thuis en rust dan uit. :: Elige la traducción correcta.

@ 27 | Een afspraak verzetten | Cambiar una cita
I En esta lección practicarás una situación cotidiana de nivel A2.
E Idea clave :: En una subordinada con omdat, el verbo conjugado va al final.
W verzetten = cambiar de fecha
W afspraakbevestiging = confirmación de cita
W vrijdagmiddag = el viernes por la tarde
W maandagochtend = el lunes por la mañana
W helaas = por desgracia
W mogelijk = posible
W bevestigen = confirmar
W annuleren = cancelar
W agenda = agenda
W berichtje = mensaje
w bevestig = confirmo
w nieuwe = nuevo
w omdat = porque
w per = por
w zet = pongo
V Vocabulario clave
D En una situación cotidiana
Assistente: U heeft morgen een afspraak. = Tiene una cita mañana.
Patiënt: Kan ik die verzetten? = ¿Puedo cambiarla de fecha?
Assistente: Wanneer bent u beschikbaar? = ¿Cuándo está disponible?
Patiënt: Maandagochtend, omdat ik vrijdagmiddag werk. = El lunes por la mañana, porque trabajo el viernes por la tarde.
Assistente: Ik bevestig de nieuwe afspraak per berichtje. = Confirmo la cita nueva por mensaje.
Patiënt: Dank u. Ik zet het in mijn agenda. = Gracias. Lo apunto en mi agenda.

+ verzetten :: Es la respuesta correcta.
- afspraakbevestiging :: Es otra opción.
- vrijdagmiddag :: Es otra opción.
R Kan ik die verzetten? :: ¿Qué significa?
+ ¿Puedo cambiarla de fecha? :: Es la respuesta correcta.
- El lunes por la mañana, porque trabajo el viernes por la tarde. :: Es otra opción.
- Gracias. Lo apunto en mi agenda. :: Es otra opción.
H Kan ik die ___? :: Completa la frase.
+ verzetten :: Es la respuesta correcta.
- afspraakbevestiging :: Es otra opción.
- vrijdagmiddag :: Es otra opción.
A Maandagochtend, omdat ik vrijdagmiddag werk. :: Escucha. ¿Qué significa?
+ El lunes por la mañana, porque trabajo el viernes por la tarde. :: Es la respuesta correcta.
- Tiene una cita mañana. :: Es otra opción.
- Confirmo la cita nueva por mensaje. :: Es otra opción.

V Vocabulario clave
D En una situación cotidiana
