@ 5 | 学习中文 | En la escuela
I Para hablar de estudiar, leer o escribir, el mandarín mantiene el verbo igual con todas las personas: **我读** («yo leo»), **你读** («tú lees»). El contexto y los pronombres indican quién hace la acción.
E Leer y escribir :: **读** es leer en voz alta o estudiar un texto; **看** es mirar o leer; **写**, escribir; **听**, escuchar. **汉字** son los caracteres chinos y **字**, un carácter o letra. :: **作业** es deberes y **考试**, examen. Una **题** es una pregunta o ejercicio de examen; **问题** suele ser una pregunta o un problema.
E Hacer y responder :: **做** significa hacer. **练习** puede ser practicar o un ejercicio. **回答** es responder y **懂**, entender. En chino el verbo no cambia por «yo», «tú» o «él».
W 字 = carácter; letra | ZÌ
W 汉字 = carácter chino | HÀNZÌ
W 读 = leer (en voz alta) | DÚ
W 写 = escribir | XIĚ
W 看 = mirar; leer | KÀN
W 听 = escuchar | TĪNG
W 练习 = practicar; ejercicio | LIÀNXÍ
W 作业 = deberes; tarea | ZUÒYÈ
W 问题 = pregunta; problema | WÈNTÍ
W 考试 = examen | KǍOSHÌ
W 题 = pregunta o ejercicio de examen | TÍ
W 回答 = responder; respuesta | HUÍDÁ
W 懂 = entender | DǑNG
W 做 = hacer; realizar | ZUÒ
V Estudiar y practicar
D Antes del examen
学生: 老师，我 的 汉字 作业 有 问题。 = Profesor, tengo un problema con los deberes de caracteres.
  > 老师 = profesor | 我 的 = mis | 汉字 作业 = deberes de caracteres | 有 问题 = tener un problema
老师: 你 读 这 个 题 吗？ = ¿Lees esta pregunta?
  > 你 = tú | 读 = leer | 这 个 题 = este ejercicio | 吗 = pregunta sí/no
学生: 我 读 题，也 写 汉字。 = Leo las preguntas y también escribo caracteres chinos.
  > 我 = yo | 读 题 = leo preguntas | 也 = también | 写 汉字 = escribo caracteres chinos
老师: 你 做 练习 吗？ = ¿Haces ejercicios?
  > 你 = tú | 做 = hacer | 练习 = ejercicios | 吗 = pregunta sí/no
学生: 我 做 练习，也 看 书。 = Hago ejercicios y también leo libros.
  > 我 = yo | 做 练习 = hago ejercicios | 也 = también | 看 书 = leo libros
老师: 好，明天 考试。 = Bien, mañana hay examen.
  > 好 = bien | 明天 = mañana | 考试 = examen
T En clase
- 我 每天 读 汉字。 = Leo caracteres chinos cada día.
  > 我 = yo | 每天 = cada día | 读 汉字 = leo caracteres chinos
- 老师 写 题。 = El profesor escribe preguntas.
  > 老师 = profesor | 写 = escribe | 题 = preguntas
- 学生 做 作业。 = El estudiante hace los deberes.
  > 学生 = estudiante | 做 作业 = hace los deberes
- 我 听 老师 说 中文。 = Escucho al profesor hablar chino.
  > 我 = yo | 听 = escucho | 老师 = profesor | 说 中文 = hablar chino
- 他 看 题。 = Él lee las preguntas.
  > 他 = él | 看 = lee | 题 = preguntas
- 我 不 懂 这 个 问题。 = No entiendo esta pregunta.
  > 我 = yo | 不 懂 = no entiendo | 这 个 问题 = esta pregunta
Q ¿Qué verbo significa «escribir»?
+ 写 :: Se pronuncia xiě.
- 读 :: Significa leer.
- 听 :: Significa escuchar.
Q ¿Qué significa 作业?
+ deberes; tarea :: Es el trabajo que se hace para clase.
- examen :: Examen es 考试.
- carácter :: Carácter es 字.
Q ¿Qué significa 懂?
+ entender :: Se usa en 我不懂, «no entiendo».
- hacer :: Hacer es 做.
- responder :: Responder es 回答.
R 我 读 题，也 写 汉字。 :: Traduce la frase.
+ Leo las preguntas y también escribo caracteres chinos. :: 也 significa también.
- Escucho al profesor y hago los deberes. :: Esas acciones no aparecen.
- Leo libros y escribo mi nombre. :: La frase habla de preguntas y caracteres.
R 我 不 懂 这 个 问题。 :: Traduce la frase.
+ No entiendo esta pregunta. :: 不 niega 懂.
- No hago esta tarea. :: Hacer es 做.
- El profesor responde la pregunta. :: Profesor es 老师.
H 我 每天 ___ 汉字。 :: Completa «leo caracteres chinos cada día».
+ 读 :: Significa leer.
- 写 :: Significa escribir.
- 听 :: Significa escuchar.
A 老师 写 题。 :: ¿Qué dice la frase?
+ El profesor escribe preguntas. :: 写 es escribir y 题 es pregunta de ejercicio.
- El profesor lee los deberes. :: Leer es 读 y deberes es 作业.
- El estudiante escucha al profesor. :: Estudiante es 学生.
O 我 不 懂 这 个 问题 :: No entiendo esta pregunta :: 不 niega el verbo 懂.

@ 5 | 工作和职业 | El trabajo y las profesiones
I **工作** puede significar «trabajar» o «trabajo». En presente no se conjuga: **我工作** («trabajo») y **他工作** («él trabaja»). El lugar o la profesión aclaran el sentido.
E Lugares de trabajo :: **公司** es empresa; **办公室**, oficina; **商店**, tienda. **上班** es ir o estar en el trabajo; **下班**, salir del trabajo. :: En estas palabras no hay artículo: **在公司工作** es «trabajar en una empresa».
E Profesiones :: **工人** es obrero/a, **医生**, médico/a, **司机**, conductor/a, **服务员**, camarero/a o dependiente/a. **老板** es jefe/a y **经理**, gerente. Estas palabras sirven para cualquier género.

W 办公室 = oficina | BÀNGŌNGSHÌ
W 商店 = tienda | SHĀNGDIÀN
W 老板 = jefe; jefa; dueño/a | LǍOBǍN
W 经理 = gerente; encargado/a | JĪNGLǏ
W 工人 = obrero; obrera | GŌNGRÉN
W 医生 = médico; médica | YĪSHĒNG
W 服务员 = camarero; camarera; dependiente | FÚWÙYUÁN
W 司机 = conductor; conductora | SĪJĪ
W 上班 = ir al trabajo; trabajar | SHÀNGBĀN
W 下班 = salir del trabajo | XIÀBĀN
W 职员 = empleado; empleada | ZHÍYUÁN

  > 我 = yo | 在 公司 = en una empresa | 工作 = trabajo

  > 你 = tú | 是 = eres | 经理 = gerente | 吗 = pregunta sí/no

  > 不 = no | 我 = yo | 是 = soy | 工人 = obrero
王明: 你 的 妻子 也 在 公司 吗？ = ¿Tu esposa también trabaja en la empresa?
  > 你 的 妻子 = tu esposa | 也 = también | 在 公司 = en la empresa | 吗 = pregunta sí/no
卡洛斯: 不，她 是 医生。 = No, ella es médica.
  > 不 = no | 她 = ella | 是 = es | 医生 = médica

  > 爸爸 = papá | 是 = es | 司机 = conductor
- 妈妈 是 医生。 = Mamá es médica.
  > 妈妈 = mamá | 是 = es | 医生 = médica
- 老板 在 办公室。 = El jefe está en la oficina.
  > 老板 = jefe | 在 办公室 = en la oficina
- 经理 在 公司 工作。 = El gerente trabaja en la empresa.
  > 经理 = gerente | 在 公司 = en la empresa | 工作 = trabaja
- 服务员 在 商店。 = El dependiente está en la tienda.
  > 服务员 = dependiente | 在 商店 = en la tienda
- 工人 和 职员 都 在 公司。 = Los obreros y empleados están en la empresa.
  > 工人 和 职员 = obreros y empleados | 都 = todos | 在 公司 = en la empresa
Q ¿Qué significa 公司?
+ empresa :: Se pronuncia gōngsī.
- oficina :: Oficina es 办公室.
- tienda :: Tienda es 商店.
Q ¿Qué profesión es 医生?
+ médico o médica :: Se usa para cualquier género.

+ salir del trabajo :: Es terminar la jornada.

@ 5 | 我会说中文 | Capacidades, deseos y permiso
I Para expresar habilidades, deseos y permiso, el mandarín coloca un verbo modal antes del verbo principal. El verbo principal no cambia: **我会读** («sé leer»), **我想读** («quiero leer»).
E Tres formas de «poder» :: **会** expresa una habilidad aprendida o algo que ocurrirá; **能** indica capacidad o posibilidad; **可以** expresa permiso o posibilidad. En español a menudo usamos «poder» para las tres, así que fíjate en la intención.
E Deseo y ayuda :: **想** es querer o tener ganas; **要** expresa querer o necesitar con más decisión. **需要** es necesitar. **帮** y **帮助** significan ayudar; **一下** suaviza una petición. **再** es otra vez y **先**, primero. :: **一点儿** significa un poco. **还** significa todavía; **可能**, quizá o posible.
W 会 = saber; poder (habilidad aprendida) | HUÌ
W 能 = poder; ser capaz de | NÉNG
W 想 = querer; pensar | XIǍNG
W 要 = querer; necesitar | YÀO
W 可以 = poder; estar permitido | KĚYǏ
W 需要 = necesitar | XŪYÀO
W 帮 = ayudar | BĀNG
W 帮助 = ayuda; ayudar | BĀNGZHÙ
W 学 = aprender; estudiar | XUÉ
W 一下 = un poco; un momento | YÍXIÀ
W 可能 = quizá; posible | KĚNÉNG
W 还 = todavía; aún | HÁI
W 再 = otra vez; de nuevo | ZÀI
W 先 = primero; antes | XIĀN
W 一点儿 = un poco | YÌDIǍNR

Q ¿Qué modal destaca una habilidad aprendida?
+ 会 :: Por ejemplo, 会说中文: saber hablar chino.
- 能 :: 能 destaca capacidad o posibilidad.
- 可以 :: 可以 suele expresar permiso o posibilidad.
Q ¿Qué palabra significa «necesitar»?
+ 需要 :: Se pronuncia xūyào.
- 想 :: Significa querer o pensar.
- 帮 :: Significa ayudar.
Q ¿Qué significa 先?
+ primero :: Se usa antes de una acción que ocurre después.
- otra vez :: Otra vez es 再.
- todavía :: Todavía es 还.

- ¿Necesitas estudiar inglés? :: Inglés es 英语.
