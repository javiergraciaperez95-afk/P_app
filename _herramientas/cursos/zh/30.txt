Q Cap. 21. ¿Qué estructura compara dos cosas?
+ A 比 B :: 比 introduce aquello con lo que se compara.
- 因为 A，所以 B :: 因为…所以… expresa causa y resultado.
- 虽然 A，但是 B :: 虽然…但是… expresa contraste.
R Cap. 21. 这 条 裤子 比 那 条 贵. :: ¿Qué significa?
+ Estos pantalones cuestan más que aquellos. :: 比 introduce la comparación y 贵 significa «caro».
- Estos pantalones cuestan lo mismo que aquellos. :: La frase afirma que estos son más caros.
- Aquellos pantalones cuestan más que estos. :: El orden de la comparación sería al revés.
H Cap. 21. 他 ___ 我 一样 高. :: Completa «Él es tan alto como yo».
+ 跟 :: 跟……一样 expresa que dos cualidades son iguales.
- 比 :: 比 indicaría que él es más alto o más bajo.
- 因为 :: 因为 introduce una causa.
Q Cap. 22. ¿Qué estructura indica el punto de partida de un lugar?
+ 从……起 :: 从 señala el origen o el punto de partida.

- 被…… :: 被 marca una oración pasiva.
