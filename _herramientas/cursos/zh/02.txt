@ 2 | 早上好 | Saludos y cortesía
I En chino puedes saludar según la hora del día. La expresión cortés 您好 usa 您 para dirigirte a alguien con respeto. La cortesía no cambia el orden básico de la frase.
E Saludar según la hora :: **早上好** y **早安** son «buenos días»; **下午好**, «buenas tardes»; **晚上好**, «buenas noches» como saludo; **晚安** se dice al despedirse para ir a dormir. **中午好** es un saludo posible al mediodía. :: **喂** se usa para contestar el teléfono. **对不起** es «lo siento» y **没关系**, «no pasa nada». Puedes responder **不客气** a «gracias».
E Buenos días no es «buen día» :: En español solemos usar «buenos días» en plural, pero el saludo chino no tiene plural. **大家好** significa «hola a todos»: 大家 («todo el mundo») va antes de 好 («bien»).
W 早上 = mañana (parte del día) | ZǍOSHANG
W 上午 = mañana; antes del mediodía | SHÀNGWǓ
W 中午 = mediodía | ZHŌNGWǓ
W 下午 = tarde; después del mediodía | XIÀWǓ
W 晚上 = noche; tarde-noche | WǍNSHANG
W 早安 = buenos días | ZǍO'ĀN
W 晚安 = buenas noches (al despedirse) | WǍN'ĀN
W 大家 = todo el mundo; todos | DÀJIĀ
W 您好 = hola (cortés) | NÍN HǍO
W 喂 = hola (al teléfono) | WÈI
W 对不起 = lo siento; disculpe | DUÌBUQǏ
W 没关系 = no pasa nada | MÉI GUĀNXI
W 不客气 = de nada | BÚ KÈQI
V Saludos del día
D Antes de clase
王明: 早上 好，安娜！ = ¡Buenos días, Ana!
  > 早上 = por la mañana | 好 = saludo, literalmente «bien» | 安娜 = nombre propio
安娜: 早上 好！你 好 吗？ = ¡Buenos días! ¿Cómo estás?
  > 早上 好 = buenos días | 你 好 吗 = ¿estás bien?
王明: 我 很 好，谢谢。 = Estoy muy bien, gracias.
  > 我 = yo | 很 好 = muy bien | 谢谢 = gracias
安娜: 大家 好！ = ¡Hola a todos!
  > 大家 = todo el mundo | 好 = saludo
王明: 您好，老师！ = ¡Hola, profesor!
  > 您好 = saludo cortés | 老师 = profesor
安娜: 再见，王明！ = ¡Adiós, Wang Ming!
  > 再见 = adiós | 王明 = nombre propio
T Saludos en distintos momentos
- 上午 好！ = ¡Buenos días!
  > 上午 = antes del mediodía | 好 = saludo
- 中午 好！ = ¡Hola al mediodía!
  > 中午 = mediodía | 好 = saludo
- 下午 好！ = ¡Buenas tardes!
  > 下午 = después del mediodía | 好 = saludo
- 晚上 好！ = ¡Buenas noches!
  > 晚上 = por la noche | 好 = saludo
- 喂，你 好！ = ¡Hola! (por teléfono)
  > 喂 = hola al teléfono | 你 好 = hola
- 晚安！ = ¡Buenas noches! (al despedirse)
  > 晚安 = buenas noches al despedirse
Q ¿Qué expresión se usa al contestar el teléfono?
+ 喂 :: Es un saludo telefónico.
- 晚安 :: Se dice al despedirse para dormir.
- 早安 :: Se usa por la mañana.
Q ¿Qué significa 没关系?
+ No pasa nada. :: Es una respuesta a una disculpa.
- De nada. :: De nada es 不客气.
- Buenas tardes. :: Buenas tardes es 下午好.
Q ¿Cuál es un saludo cortés?
+ 您好 :: Usa 您 para tratar a alguien con respeto.
- 喂 :: Se usa sobre todo al teléfono.
- 晚安 :: Es una despedida nocturna.
R 大家 好！ :: Traduce el saludo.
+ ¡Hola a todos! :: 大家 significa «todo el mundo».
- ¡Adiós a todos! :: Adiós es 再见.
- ¡Buenos días! :: Buenos días es 早上好.
R 对不起，没关系。 :: Traduce el intercambio.
+ Lo siento. No pasa nada. :: La segunda parte responde a la disculpa.
- Gracias. De nada. :: Gracias es 谢谢.
- Hola. ¿Cómo te llamas? :: No pregunta el nombre.
H 你 好 ___？ :: Completa la pregunta «¿estás bien?».
+ 吗 :: Convierte la frase en pregunta de sí o no.
- 呢 :: Devuelve una pregunta.
- 不 :: Niega un verbo.
A 晚安 :: ¿Qué expresión oyes?
+ buenas noches al despedirse :: Se usa antes de ir a dormir.
- buenos días :: Buenos días es 早安.
- no pasa nada :: No pasa nada es 没关系.
O 下午 好 :: ¡Buenas tardes! :: La hora del día precede al saludo 好.

@ 2 | 你是哪国人 | Países e idiomas
I Para preguntar de dónde es alguien, en chino se dice literalmente «¿de qué país eres persona?». Los nombres de países van antes de 人 («persona»). Para hablar de idiomas, usa el verbo 说 («hablar»).
E País y nacionalidad :: **你是哪个国家的人？** pregunta «¿de qué país eres?». En chino no hay una terminación distinta para «español» y «española»: **西班牙人** sirve para ambos. **美国人** significa «estadounidense» y **英国人**, «británico/a».
E Hablar idiomas :: **说** significa «hablar». **中文** y **汉语** son dos formas corrientes de decir «chino» como idioma; **英语** es «inglés» y **西班牙语**, «español». En español añadimos a menudo «el» delante del idioma; en chino no se pone artículo.
W 哪个 = cuál; qué (entre opciones) | NǍGE
W 国家 = país | GUÓJIĀ
W 的 = partícula de relación o posesión | DE
W 美国 = Estados Unidos | MĚIGUÓ
W 英国 = Reino Unido | YĪNGGUÓ
W 日本 = Japón | RÌBĚN
W 中文 = chino (idioma; uso general) | ZHŌNGWÉN
W 汉语 = chino (idioma) | HÀNYǓ
W 英语 = inglés | YĪNGYǓ
W 西班牙语 = español (idioma) | XĪBĀNYÁYǓ
W 说 = hablar | SHUŌ
W 哪儿 = dónde (coloquial) | NǍR
W 哪里 = dónde (forma general) | NǍLǏ
W 住 = vivir; residir | ZHÙ
W 学习 = estudiar; aprender | XUÉXÍ
W 和 = y; con | HÉ
V Países e idiomas
E Una pregunta corta :: **哪儿** y **哪里** significan «dónde». **住** es «vivir» y **学习**, «estudiar» o «aprender». Para contestar, repite la información: **你住哪儿？—我住在西班牙。**
D En clase de idiomas
安娜: 你 是 哪个 国家 的 人？ = ¿De qué país eres?
  > 你 = tú | 是 = eres | 哪个 国家 = qué país | 的 人 = persona de
卡洛斯: 我 是 西班牙 人。 = Soy español.
  > 我 = yo | 是 = soy | 西班牙 人 = persona de España
安娜: 你 说 西班牙语 吗？ = ¿Hablas español?
  > 你 = tú | 说 = hablar | 西班牙语 = español (idioma) | 吗 = pregunta sí/no
卡洛斯: 我 说 中文 和 英语。 = Hablo chino e inglés.
  > 我 = yo | 说 = hablo | 中文 = chino | 和 = y | 英语 = inglés
安娜: 你 住 哪儿？ = ¿Dónde vives?
  > 你 = tú | 住 = vivir | 哪儿 = dónde
卡洛斯: 我 住 在 西班牙。 = Vivo en España.
  > 我 = yo | 住 = vivo | 在 = en | 西班牙 = España
T En la escuela
- 他 是 美国 人。 = Él es estadounidense.
  > 他 = él | 是 = es | 美国 人 = persona de Estados Unidos
- 她 是 日本 人。 = Ella es japonesa.
  > 她 = ella | 是 = es | 日本 人 = persona de Japón
- 你 说 汉语 吗？ = ¿Hablas chino?
  > 你 = tú | 说 = hablar | 汉语 = chino | 吗 = pregunta sí/no
- 我 学习 英语。 = Estudio inglés.
  > 我 = yo | 学习 = estudio | 英语 = inglés
- 你 住 哪里？ = ¿Dónde vives?
  > 你 = tú | 住 = vivir | 哪里 = dónde
- 我 说 中文。 = Hablo chino.
  > 我 = yo | 说 = hablo | 中文 = chino
Q ¿Qué significa 哪儿?
+ dónde (coloquial) :: Se pronuncia nǎr.
- qué país :: Qué país se dice 哪个国家.
- quién :: Quién se dice 谁.
Q ¿Qué idioma es 英语?
+ inglés :: 英语 significa inglés.
- español :: Español es 西班牙语.
- japonés :: Japón se dice 日本.
Q ¿Qué significa 住?
+ vivir :: Se usa en preguntas sobre el lugar donde vive alguien.
- hablar :: Hablar es 说.
- estudiar :: Estudiar es 学习.
R 我 说 中文 和 英语。 :: Traduce la frase.
+ Hablo chino e inglés. :: 和 une dos elementos.
- Hablo español y japonés. :: Esos idiomas no aparecen.
- Estudio inglés en China. :: La frase dice «hablo» y no menciona China.
R 你 是 哪个 国家 的 人？ :: Traduce la pregunta.
+ ¿De qué país eres? :: Literalmente pregunta «¿eres persona de qué país?».
- ¿Qué idioma hablas? :: Hablar es 说.
- ¿Dónde vives? :: Dónde vives es 你住哪儿.
H 你 住 ___？ :: Completa «¿dónde vives?».
+ 哪儿 :: Significa dónde.
- 英语 :: Significa inglés.
- 国家 :: Significa país.
A 她 是 日本 人。 :: ¿Qué oyes?
+ Ella es japonesa. :: 她 es ella y 日本 es Japón.
- Él es japonés. :: Él se escribe 他.
- Ella es estadounidense. :: Estados Unidos es 美国.
O 我 学习 英语 :: Estudio inglés :: 学习 es estudiar y 英语 es inglés.

@ 2 | 这是谁 | Personas y relaciones
I Ya sabes preguntar de dónde es alguien. Ahora puedes preguntar quién es una persona y presentarla. Para contar a una persona con cortesía, se usa 位 en lugar del clasificador general 个, que aparecerá en el capítulo siguiente.
E Quién :: **谁** significa «quién». **哪位** pregunta «qué persona» de forma cortés. **这位** es «esta persona» y **那位**, «aquella persona». El clasificador 位 va entre el demostrativo y la persona.
E Relación y género :: **先生** equivale a «señor» y **女士**, a «señora» o «señorita». **同学** es compañero/a de clase; **同事**, compañero/a de trabajo. Estas palabras no llevan marca de género. :: **也** significa «también» y **都**, «todos». En mandarín, las dos suelen colocarse antes del verbo.
W 谁 = quién | SHÉI
W 哪位 = qué persona (cortés) | NǍ WÈI
W 位 = clasificador cortés para personas | WÈI
W 先生 = señor | XIĀNSHENG
W 女士 = señora; señorita | NǚSHÌ
W 同学 = compañero; compañera de clase | TÓNGXUÉ
W 同事 = compañero; compañera de trabajo | TÓNGSHÌ
W 也 = también | YĚ
W 都 = todos; ambas/os | DŌU
W 这里 = aquí; este lugar | ZHÈLǏ
W 那里 = allí; ese lugar | NÀLǏ
W 新 = nuevo; nueva | XĪN
W 老 = viejo; antiguo | LǍO
W 一起 = juntos; juntas | YÌQǏ
V Personas y relaciones
D Presentar a los compañeros
安娜: 这 位 先生 是 谁？ = ¿Quién es este señor?
  > 这 = este | 位 = clasificador cortés | 先生 = señor | 是 谁 = es quién
李华: 他 是 我 的 老师。 = Él es mi profesor.
  > 他 = él | 是 = es | 我 的 = mi | 老师 = profesor
安娜: 那 位 女士 呢？ = ¿Y aquella señora?
  > 那 = aquella | 位 = clasificador cortés | 女士 = señora | 呢 = ¿y…?
李华: 她 是 我 的 同事。 = Ella es mi compañera de trabajo.
  > 她 = ella | 是 = es | 我 的 = mi | 同事 = compañera de trabajo
安娜: 哪位 老师 在 这里？ = ¿Qué profesor está aquí?
  > 哪位 = qué persona | 老师 = profesor | 在 这里 = está aquí
李华: 老师 和 学生 都 在 那里。 = El profesor y los estudiantes están allí.
  > 老师 和 学生 = profesor y estudiantes | 都 = todos | 在 那里 = están allí
T Personas que conocemos
- 我 的 新 朋友 是 安娜。 = Mi nueva amiga es Ana.
  > 我 的 = mi | 新 = nueva | 朋友 = amiga | 是 = es | 安娜 = nombre propio
- 王明 是 我 的 老 同学。 = Wang Ming es mi antiguo compañero de clase.
  > 王明 = nombre propio | 是 = es | 我 的 = mi | 老 同学 = antiguo compañero de clase
- 我们 一起 在 这里。 = Estamos juntos aquí.
  > 我们 = nosotros | 一起 = juntos | 在 这里 = aquí
- 老师 在 那里。 = El profesor está allí.
  > 老师 = profesor | 在 那里 = allí
- 他 也 是 学生。 = Él también es estudiante.
  > 他 = él | 也 = también | 是 = es | 学生 = estudiante
- 我 和 朋友 在 学校。 = Estoy con un amigo en la escuela.
  > 我 和 朋友 = yo con un amigo | 在 学校 = en la escuela
Q ¿Qué pregunta significa «¿quién?»?
+ 谁 :: 谁 se pronuncia shéi.
- 哪儿 :: Significa dónde.
- 哪个 :: Significa cuál o qué entre opciones.
Q ¿Qué significa 同事?
+ compañero de trabajo :: 同学 es compañero de clase.
- profesor :: Profesor es 老师.
- amigo :: Amigo es 朋友.
Q ¿Qué suele indicar 位?
+ Un clasificador cortés para personas. :: Se coloca antes del sustantivo.
- El plural de los verbos. :: 位 no es un sufijo verbal.
- El tiempo pasado. :: El chino no cambia el verbo así.
R 这 位 先生 是 谁？ :: Traduce la pregunta.
+ ¿Quién es este señor? :: 这位 presenta a una persona cercana.
- ¿Dónde está aquel señor? :: Dónde es 哪儿.
- ¿Quién es la profesora? :: Profesora sería 老师 y aquí aparece 先生.
R 我 的 新 朋友 是 安娜。 :: Traduce la frase.
+ Mi nueva amiga es Ana. :: 的 enlaza posesión y nombre.
- Ana es mi antigua compañera. :: Nueva es 新, no 老.
- Estoy con una amiga nueva. :: La frase dice que Ana es esa amiga.
H 他 ___ 是 学生。 :: Completa «él también es estudiante».
+ 也 :: 也 significa también y va antes del verbo.
- 都 :: 都 significa todos.
- 哪位 :: 哪位 pregunta qué persona.
A 老师 和 学生 都 在 那里。 :: ¿Qué significa la frase?
+ El profesor y los estudiantes están todos allí. :: 都 incluye al grupo entero.
- El profesor está aquí con un estudiante. :: 那里 significa allí.
- ¿Quién es el profesor y el estudiante? :: La frase es una afirmación.
O 我 和 朋友 在 学校 :: Estoy con un amigo en la escuela :: 和 puede significar «con» entre personas.
