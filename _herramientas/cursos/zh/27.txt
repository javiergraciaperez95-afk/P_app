@ 27 | 价格和质量 | Precio y calidad
I En una tienda, preguntaremos por ofertas y compararemos el precio con la calidad.
E Ofertas y precios :: **打折** significa que el precio baja durante una oferta. **原价** es el precio anterior y **半价** equivale a la mitad del precio original. :: **划算** expresa que una compra merece la pena por lo que cuesta y por su calidad.
B En una oferta | Palabra | Significado
| 原价 | precio original
| 半价 | mitad de precio
| 打折 | estar rebajado; aplicar un descuento
| 划算 | salir a cuenta; ser una buena compra
W 价格 = precio | JIÀGÉ | Coste de un producto o servicio.
W 质量 = calidad | ZHÌLIÀNG | Describe cómo está hecho un producto.
W 打折 = estar rebajado; aplicar un descuento | DǍZHÉ | Se usa cuando el precio se reduce.
W 原价 = precio original | YUÁNJIÀ | Precio antes de una rebaja.
W 半价 = mitad de precio | BÀNJIÀ | La mitad del precio original.
W 新款 = modelo nuevo; nuevo diseño | XĪNKUǍN | Diseño o modelo recién presentado.
W 商品 = producto; mercancía | SHĀNGPǏN | Objeto que se vende en una tienda.
W 顾客 = cliente | GÙKÈ | Persona que compra en una tienda.
W 店员 = dependiente/a; empleado/a de tienda | DIÀNYUÁN | Persona que trabaja atendiendo en una tienda.
W 推荐 = recomendar | TUĪJIÀN | Decir que algo es adecuado o merece la pena.
W 省钱 = ahorrar dinero | SHĚNGQIÁN | Gastar menos dinero.
W 划算 = rentable; que sale a cuenta | HUÁSUÀN | Se usa para una compra conveniente por su precio.
W 优点 = ventaja; punto fuerte | YŌUDIǍN | Cualidad positiva de una cosa o persona.
W 缺点 = desventaja; punto débil | QUĒDIǍN | Cualidad negativa o problema de algo.
W 原来 = antes; originalmente | YUÁNLÁI | Puede señalar el estado anterior o expresar sorpresa.

V Vocabulario: precios
D Una rebaja
顾客: 这个 新款 的 衬衫 打折 吗? = ¿Está rebajada esta camisa de nuevo modelo?
  > 这个 新款 的 衬衫 = esta camisa de nuevo modelo | 打折 吗 = ¿está rebajada?
店员: 打折, 原价 不 低, 现在 是 半价. = Sí, está rebajada; el precio original no era bajo y ahora cuesta la mitad.
  > 原价 不 低 = el precio original no era bajo | 现在 是 半价 = ahora cuesta la mitad
顾客: 质量 怎么样? = ¿Qué tal es la calidad?
  > 质量 怎么样 = qué tal es la calidad
店员: 质量 很 好, 很 多 顾客 推荐 这 个 商品. = La calidad es muy buena; muchos clientes recomiendan este producto.
  > 质量 很 好 = la calidad es muy buena | 顾客 推荐 这 个 商品 = clientes recomiendan este producto
顾客: 那 我 买, 这样 比较 划算. = Entonces lo compro; así sale más a cuenta.
  > 我 买 = lo compro | 比较 划算 = sale más a cuenta
T Elegir una oferta
- 这 件 衣服 原来 不 便宜, 现在 打折 了. = Esta prenda antes no era barata; ahora está rebajada.
  > 原来 不 便宜 = antes no era barata | 现在 打折 了 = ahora está rebajada
- 这个 商品 有 一 个 优点, 质量 很 好. = Este producto tiene una ventaja: la calidad es muy buena.
  > 有 一 个 优点 = tiene una ventaja | 质量 很 好 = la calidad es muy buena
- 价格 低, 买 两 个 更 省钱. = El precio es bajo; comprar dos ahorra más dinero.
  > 价格 低 = el precio es bajo | 更 省钱 = ahorra más dinero
- 这 个 新款 的 缺点 是 价格 高. = La desventaja de este modelo nuevo es que el precio es alto.
  > 新款 的 缺点 = la desventaja del nuevo modelo | 价格 高 = el precio es alto
- 店员 推荐 的 商品 很 划算. = El producto que recomienda el dependiente sale muy a cuenta.
  > 店员 推荐 的 商品 = el producto recomendado por el dependiente | 很 划算 = sale muy a cuenta
Q ¿Qué significa «半价»?
+ La mitad del precio original. :: 半 significa «mitad» y 价 se refiere al precio.
- El precio más alto. :: Alto es 高.
- Una camisa nueva. :: Camisa es 衬衫.
Q ¿Qué expresa «省钱»?
+ Ahorrar dinero. :: La compra cuesta menos.
- Recomendar un producto. :: Recomendar es 推荐.
- Tener una desventaja. :: Desventaja es 缺点.
R 这个 商品 有 一 个 优点, 质量 很 好. :: ¿Qué significa?
+ Este producto tiene una ventaja: la calidad es muy buena. :: 优点 es una cualidad positiva.
- Este producto tiene un defecto y cuesta mucho. :: La frase dice 优点, «ventaja».
- Este producto está rebajado a la mitad. :: Mitad de precio es 半价.
H 这个 新款 的 ___ 是 价格 高. :: «La desventaja de este modelo nuevo es que el precio es alto».
+ 缺点 :: 缺点 significa «desventaja» o «punto débil».
- 优点 :: 优点 significa «ventaja».
- 质量 :: 质量 significa «calidad».
A 现在 是 半价. :: Escucha. ¿Cuánto cuesta ahora?
+ La mitad del precio original. :: 半价 es la mitad del precio.
- El doble del precio original. :: El doble no es 半价.
- El precio no ha cambiado. :: La frase indica que está a mitad de precio.
O 这个 商品 质量 很 好 :: Este producto tiene muy buena calidad :: 质量 describe cómo está hecho el producto.
R 店员 推荐 的 商品 很 划算. :: ¿Qué significa?
+ El producto que recomienda el dependiente sale muy a cuenta. :: 划算 describe una buena relación entre precio y valor.
- El cliente dice que el producto tiene una desventaja. :: Cliente es 顾客 y desventaja es 缺点.
- El modelo nuevo cuesta la mitad. :: Mitad de precio es 半价.
Q ¿Qué significa «原来» en este capítulo?
+ Antes; originalmente. :: Señala el estado anterior.
- En total. :: En total es 一共.
- Probarse una prenda. :: Probarse es 试穿.

@ 27 | 尺寸和试穿 | Tallas y probarse ropa
E Tallas y ajuste :: **试穿** es probarse una prenda antes de comprarla. **尺码** indica la talla. :: **合身** significa que la ropa queda bien al cuerpo; **合适** significa que algo resulta adecuado en general. Si una prenda queda estrecha, puedes decir **太紧了**.
B Ropa | Chino | Español
| 小号 | talla pequeña
| 中号 | talla mediana
| 大号 | talla grande
| 试穿 | probarse una prenda
W 尺码 = talla; número de talla | CHǏMǍ | Número o letra que indica el tamaño de una prenda.
W 试穿 = probarse (ropa) | SHÌCHUĀN | Ponerse una prenda para ver cómo queda.
W 合身 = quedar bien al cuerpo | HÉSHĒN | Describe ropa que tiene el ajuste adecuado.
W 款式 = estilo; diseño | KUǍNSHÌ | Forma o apariencia de un modelo.
W 小号 = talla pequeña | XIǍOHÀO | Talla para una prenda pequeña.
W 中号 = talla mediana | ZHŌNGHÀO | Talla intermedia.
W 大号 = talla grande | DÀHÀO | Talla para una prenda grande.
W 紧 = estrecho/a; apretado/a | JǏN | Describe ropa que queda demasiado ajustada.
W 宽松 = holgado/a; amplio/a | KUĀNSŌNG | Describe ropa con espacio y sin apretar.
W 换 = cambiar; cambiar por otro | HUÀN | Puede ser cambiar una prenda por otra talla o modelo.
W 退货 = devolver una compra | TUÌHUÒ | Entregar un producto de vuelta a la tienda.
W 适合 = ser adecuado para; convenir | SHÌHÉ | Indica que algo resulta apropiado para alguien o algo.
W 试衣间 = probador | SHÌYĪJIĀN | Espacio de una tienda para probarse ropa.
W 那边 = allí; por allí | NÀBIAN | Señala un lugar situado a cierta distancia.
W 而且 = además; y además | ÉRQIĚ | Añade otra información al mismo argumento.
W 有点儿 = un poco; algo | YǑUDIǍNR | Suaviza una descripción, a menudo negativa.
W 如果 = si; en caso de que | RÚGUǑ | Introduce una condición.
W 合适 = adecuado/a; apropiado/a | HÉSHÌ | Indica que algo encaja con una necesidad o situación.
W 或 = o; u | HUÒ | Presenta una alternativa.
W 短 = corto/a | DUǍN | Describe poca longitud.
V Vocabulario: tallas
D En el probador

  > 可以 试穿 = poder probarse | 这 件 衬衫 = esta camisa

  > 试衣间 = probador | 在 那边 = está allí

  > 这 个 尺码 = esta talla | 太 紧 = aprieta demasiado | 有 大号 吗 = ¿hay una grande?
店员: 有, 大号 的 款式 也 很 好. = Sí, el diseño de la talla grande también es muy bonito.
  > 大号 的 款式 = el diseño de talla grande | 也 很 好 = también es muy bueno

  > 颜色 适合 我 = el color me queda bien | 很 合身 = queda bien al cuerpo

  > 裤子 太 短 = los pantalones son demasiado cortos | 换 一 条 = cambiar por otro par

  > 去 试衣间 = ir al probador | 试穿 = probarse

  > 尺码 不 合适 = la talla no va bien | 退货 或 换 = devolver o cambiar

Q ¿Qué significa «试穿»?
+ Probarse una prenda. :: Se hace antes de decidir si se compra.
- Devolver una compra. :: Devolver es 退货.
- Cambiar de color. :: Color es 颜色.
Q ¿Qué diferencia hay entre «合身» y «合适»?
+ 合身 habla del ajuste de la ropa; 合适 significa adecuado en general. :: Una prenda puede quedar bien al cuerpo o ser adecuada por otros motivos.
- 合身 significa talla grande; 合适 significa talla pequeña. :: Las tallas son 大号 y 小号.
- Ambas significan «devolver». :: Devolver es 退货.
R 这 个 尺码 太 紧, 有 大号 吗? :: ¿Qué significa?
+ Esta talla aprieta demasiado; ¿hay una grande? :: 紧 indica que queda apretada.
- Esta talla es holgada; ¿hay una pequeña? :: Holgada es 宽松 y pequeña es 小号.
- ¿Puedo devolver este color? :: La frase pregunta por una talla grande.
H 如果 尺码 不 合适, 可以 ___ 或 换. :: «Si la talla no va bien, puedes devolver la compra o cambiarla».
+ 退货 :: 退货 significa «devolver una compra».
- 试穿 :: 试穿 significa «probarse una prenda».
- 合身 :: 合身 describe el ajuste de la ropa.
A 这个 颜色 适合 我, 而且 很 合身. :: Escucha. ¿Qué dice la persona?
+ El color le va bien y la prenda le queda bien al cuerpo. :: 适合 indica que le conviene y 合身 describe el ajuste.
- Quiere devolver una prenda demasiado corta. :: Devolver es 退货.
- Busca una talla pequeña. :: Talla pequeña es 小号.
O 这 件 衣服 有点儿 紧 :: Esta prenda aprieta un poco :: 有点儿 suaviza la descripción.
R 这个 款式 很 适合 她, 颜色 也 好看. :: ¿Qué significa?
+ Este diseño le va muy bien; el color también es bonito. :: 适合 expresa que algo le conviene.
- Este diseño es demasiado estrecho y hay que devolverlo. :: Estrecho es 紧.
- Ella está buscando el probador. :: El probador es 试衣间.
Q ¿Qué talla significa «中号»?
+ Talla mediana. :: 中号 es el tamaño intermedio.
- Talla pequeña. :: Pequeña es 小号.
- Talla grande. :: Grande es 大号.

@ 27 | 付款和重量 | Pagar y pesar
