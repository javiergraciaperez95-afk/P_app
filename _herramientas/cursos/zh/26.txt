@ 26 | 请求和帮忙 | Peticiones y ayuda
I Practicaremos cómo pedir ayuda con cortesía y cómo encargar tareas pequeñas.
E Pedir algo con educación :: **请** suaviza una petición. **麻烦你……** equivale a «¿te importa…?» o «hazme el favor de…». :: Puedes añadir **好吗？** para pedir confirmación: 麻烦你帮我打印一份资料，好吗？
B Peticiones | Expresión | Uso
| 请你…… | por favor, haz…
| 麻烦你…… | ¿te importa…?; hazme el favor de…
| 帮我…… | ayúdame a…
W 麻烦 = molestar; hacer el favor de | MÁFAN | En 麻烦你, introduce una petición cortés.
W 打印 = imprimir | DǍYÌN | Se usa para imprimir documentos.
W 资料 = material; documentos; información | ZĪLIÀO | Puede referirse a materiales de estudio o documentos.
W 文件 = archivo; documento | WÉNJIÀN | Documento escrito o archivo digital.
W 份 = ejemplar; copia (clasificador) | FÈN | Clasifica documentos, periódicos y otros conjuntos.
W 递 = pasar; alcanzar (a alguien) | DÌ | Indica entregar algo a otra persona con la mano.
W 关上 = cerrar | GUĀNSHÀNG | Expresa que algo queda cerrado.
W 记得 = acordarse de; recordar | JÌDE | Puede introducir algo que hay que recordar hacer.
W 会议 = reunión; conferencia | HUÌYÌ | Encuentro organizado para conversar o trabajar.
W 复印 = fotocopiar | FÙYÌN | Hacer una copia en papel de un documento.
W 不用 = no hace falta; no es necesario | BÚYÒNG | Expresa que algo no es necesario.
W 需要 = necesitar; hacer falta | XŪYÀO | Expresa que algo es necesario.
V Vocabulario: peticiones
D Una petición en la oficina
李华: 麻烦 你 帮 我 打印 一 份 资料, 好 吗? = ¿Te importa ayudarme a imprimir una copia del material?
  > 麻烦 你 = ¿te importa? | 帮 我 打印 = ayudarme a imprimir | 一 份 资料 = una copia del material
安娜: 好, 你 还 需要 复印 这 个 文件 吗? = Sí. ¿También quieres fotocopiar este documento?
  > 还 需要 复印 = también necesitas fotocopiar | 这 个 文件 = este documento
李华: 不用, 请 递 一 张 纸 给 我. = No hace falta; por favor, pásame el papel.
  > 不用 = no hace falta | 请 递 一 张 纸 给 我 = por favor, pásame una hoja
安娜: 好. 会议 马上 开始, 你 记得 关上 门. = Vale. La reunión empieza enseguida; acuérdate de cerrar la puerta.
  > 会议 马上 开始 = la reunión empieza enseguida | 记得 关上 门 = acuérdate de cerrar la puerta
T En la sala
- 麻烦 你 打印 两 份 文件. = ¿Te importa imprimir dos copias del documento?
  > 麻烦 你 = ¿te importa? | 打印 两 份 文件 = imprimir dos copias del documento
- 请 你 递 这 张 纸 给 老师. = Por favor, pásale este papel al profesor.
  > 这 张 纸 = este papel | 递 这 张 纸 给 老师 = pasarle este papel al profesor
- 他 记得 会议 的 时间. = Él recuerda la hora de la reunión.
  > 记得 = recordar | 会议 的 时间 = la hora de la reunión
- 请 关上 门, 别 让 风 进来. = Cierra la puerta, por favor, no dejes que entre el viento.
  > 关上 门 = cerrar la puerta | 让 风 进来 = dejar entrar el viento
- 你 可以 帮 我 复印 这 份 资料 吗? = ¿Puedes ayudarme a fotocopiar este material?
  > 帮 我 复印 = ayudarme a fotocopiar | 这 份 资料 = este material
Q ¿Qué expresa «麻烦你» al empezar una petición?
+ Una petición cortés, como «¿te importa…?». :: Suaviza lo que se pide.
- Una orden para salir. :: Salir es 出去.
- Una pregunta por el precio. :: Precio es 价格.
Q ¿Qué diferencia hay entre «打印» y «复印»?
+ 打印 es imprimir y 复印 es fotocopiar. :: Una crea una impresión y la otra una copia.
- Ambas significan «cerrar». :: Cerrar es 关上.
- 打印 es pasar un papel y 复印 es recordar. :: Pasar es 递; recordar es 记得.
R 请 递 一 张 纸 给 我. :: ¿Qué significa?
+ Por favor, pásame el papel. :: 递 expresa pasar algo a alguien.
- Por favor, imprime dos documentos. :: Imprimir es 打印.
- Acuérdate de cerrar la puerta. :: Cerrar es 关上.
H 麻烦 你 ___ 一 份 资料. :: «¿Te importa imprimir una copia del material?»
+ 打印 :: 打印 significa «imprimir».
- 关上 :: 关上 significa «cerrar».
- 递 :: 递 significa «pasar algo a alguien».
A 你 记得 关上 门. :: Escucha. ¿Qué tiene que recordar?
+ Cerrar la puerta. :: 记得关上门 significa «acordarse de cerrar la puerta».
- Fotocopiar el documento. :: Fotocopiar es 复印.
- Pasar el papel al profesor. :: Pasar es 递.
O 麻烦 你 帮 我 打印 一 份 资料 :: ¿Te importa ayudarme a imprimir una copia del material? :: 麻烦你 presenta la petición con cortesía.
R 请 你 递 这 张 纸 给 老师. :: ¿Qué significa?
+ Por favor, pásale este papel al profesor. :: 张 clasifica objetos planos como una hoja de papel.
- Por favor, fotocopia dos documentos. :: Fotocopiar es 复印.
- Acuérdate de cerrar la puerta. :: La frase pide pasar un papel.

@ 26 | 把东西处理好 | Dejar las cosas hechas con 把
E El objeto delante del verbo :: En **把 + objeto + verbo**, el objeto aparece antes del verbo porque se destaca qué se hace con él. Suele indicarse un resultado, un cambio o un lugar: 把房间整理好 = dejar la habitación ordenada. :: En español el objeto suele ir después del verbo: «ordena la habitación». En chino, 把 anuncia que se va a actuar sobre ese objeto.
B Estructura | Chino | Español
| Sujeto + 把 + objeto + verbo + resultado | 我把书放好 | Dejo el libro en su sitio.
| Sujeto + 把 + objeto + verbo + lugar | 她把衣服放进抽屉 | Mete la ropa en el cajón.
W 把 = marcador que adelanta el objeto | BǍ | Presenta el objeto sobre el que recae una acción.
W 整理 = ordenar; organizar | ZHĚNGLǏ | Poner cosas en orden o preparar información.
W 抽屉 = cajón | CHŌUTI | Compartimento que se desliza dentro de un mueble.
W 收拾 = ordenar; recoger | SHŌUSHI | Dejar un espacio recogido o preparar pertenencias.
W 垃圾 = basura | LĀJĪ | Residuos que se tiran.
W 扔掉 = tirar; desechar | RĒNGDIÀO | Lanzar algo para deshacerse de ello.
W 书架 = estantería para libros | SHŪJIÀ | Mueble donde se colocan libros.
W 整齐 = ordenado; bien colocado | ZHĚNGQÍ | Describe cosas colocadas con orden.
W 叠 = doblar; apilar | DIÉ | Doblar ropa o colocar cosas una sobre otra.
W 挂 = colgar | GUÀ | Poner algo suspendido de un gancho o la pared.
W 墙上 = en la pared | QIÁNGSHÀNG | Indica una posición sobre una pared.
W 摆 = colocar; disponer | BǍI | Poner objetos en un lugar o de una manera determinada.
W 放好 = dejar bien colocado; guardar | FÀNGHǍO | Poner algo en su sitio y dejarlo ordenado.
W 放 = poner; colocar | FÀNG | Verbo general para colocar algo en un lugar.
W 照片 = foto; fotografía | ZHÀOPIÀN | Imagen tomada con una cámara.
V Vocabulario: organizar objetos
D Ordenar la habitación
安娜: 请 把 桌子 整理 好. = Por favor, deja ordenada la mesa.
  > 把 桌子 整理 好 = dejar la mesa ordenada
李华: 书 应该 放 在 哪儿? = ¿Dónde deberían ponerse los libros?
  > 书 应该 放 在 哪儿 = dónde deberían ponerse los libros
安娜: 把 书 放 在 书架 上, 把 资料 放 进 抽屉. = Pon los libros en la estantería y los documentos en el cajón.
  > 把 书 放 在 书架 上 = poner los libros en la estantería | 把 资料 放 进 抽屉 = poner los documentos en el cajón
李华: 好, 我 把 房间 收拾 好. = Vale, dejo la habitación recogida.
  > 把 房间 收拾 好 = dejar la habitación recogida
T Todo en su sitio
- 请 把 垃圾 扔掉. = Por favor, tira la basura.
  > 把 垃圾 扔掉 = tirar la basura
- 她 把 衣服 叠 好, 放 进 抽屉. = Ella dobla la ropa y la guarda en el cajón.
  > 把 衣服 叠 好 = doblar la ropa | 放 进 抽屉 = guardar en el cajón
- 墙上 挂 着 一 张 照片. = Hay una foto colgada en la pared.
  > 墙上 挂 着 = estar colgado en la pared | 一 张 照片 = una foto
- 他 把 杯子 摆 在 桌子 上. = Él coloca la taza sobre la mesa.
  > 把 杯子 摆 在 桌子 上 = colocar la taza sobre la mesa
- 我 把 书 放好 了. = Dejé el libro en su sitio.
  > 把 书 放好 了 = dejar el libro en su sitio
Q ¿Qué aporta 把 en «我把书放好»?
+ Adelanta el objeto para destacar qué se hace con él. :: La frase se centra en dejar el libro en su sitio.
- Indica quién recibe la acción. :: El receptor suele aparecer con 给.
- Significa «porque». :: Porque se expresa con 因为.
Q ¿Qué significa «放好»?
+ Dejar algo bien colocado. :: 放好 indica que queda en su sitio.
- Tirar algo a la basura. :: Tirar es 扔掉.
- Colgar algo en la pared. :: Colgar es 挂.
Q ¿Qué significa «递»?
+ pasar o alcanzar algo a alguien :: 递 describe entregar algo con la mano.
- fotocopiar :: Fotocopiar es 复印.
- recordar :: Recordar es 记得.
R 请 把 垃圾 扔掉. :: ¿Qué significa?
+ Por favor, tira la basura. :: 扔掉 significa «tirar» o «desechar».
- Por favor, dobla la ropa. :: Doblar es 叠.
- Por favor, coloca los libros en la estantería. :: Estantería es 书架.
H 请 把 书 放 在 ___. :: «Por favor, pon los libros en la estantería».
+ 书架 上 :: 书架上 indica que se ponen encima de la estantería.
- 垃圾 :: 垃圾 significa «basura».
- 墙上 :: 墙上 significa «en la pared».
A 她 把 衣服 叠 好, 放 进 抽屉. :: Escucha. ¿Qué hace?
+ Dobla la ropa y la guarda en el cajón. :: 叠好 y 放进抽屉 describen las acciones.
- Tira los libros a la basura. :: Tirar es 扔掉.
- Cuelga una foto en la pared. :: Colgar es 挂.
O 我 把 书 放好 了 :: Dejé el libro en su sitio :: 把 presenta el objeto y 放好 indica el resultado.
Q ¿Qué describe «整齐»?
+ que las cosas están ordenadas :: 整齐 describe algo bien colocado.
- que la puerta se cerró :: Cerrar es 关上.
- que alguien salió de una habitación :: Salir es 出去.
R 他 把 杯子 摆 在 桌子 上. :: ¿Qué significa?
+ Él coloca la taza sobre la mesa. :: 摆 significa colocar o disponer.
- Él cuelga la taza en la pared. :: En la pared es 墙上.
- Él tira la mesa a la basura. :: Basura es 垃圾.

@ 26 | 被动句 | Oraciones pasivas con 被
E Recibir una acción :: **被** presenta a quien o lo que recibe una acción: objeto + 被 + agente + verbo. Por ejemplo, 我的自行车被工人修好了 = «el trabajador me arregló la bicicleta». :: Si no importa quién hizo la acción, se puede omitir el agente: 门被关上了 = «la puerta fue cerrada». El chino usa 被 para marcar la pasiva; en español solemos cambiar el orden o usar «ser» más participio.
B Estructura | Ejemplo | Traducción
| objeto + 被 + agente + verbo | 车被工人修好了 | El trabajador arregló el coche.
| objeto + 被 + verbo | 门被关上了 | La puerta fue cerrada.
W 被 = marcador de voz pasiva | BÈI | Presenta a quien o lo que recibe una acción.
W 修理 = reparar | XIŪLǏ | Arreglar algo que está roto o no funciona.
W 工人 = trabajador; obrero | GŌNGRÉN | Persona que realiza un trabajo manual o técnico.
W 修好 = reparar y dejar arreglado | XIŪHǍO | Expresa el resultado de una reparación terminada.
W 问题 = problema; cuestión | WÈNTÍ | Puede ser una dificultad o algo que se pregunta.
W 解决 = resolver; solucionar | JIĚJUÉ | Encontrar una respuesta o solución a un problema.
W 原因 = causa; motivo | YUÁNYĪN | Explica por qué ocurre algo.
W 进不去 = no poder entrar | JÌN BU QÙ | Expresa que no se logra entrar en un lugar.
W 玻璃 = vidrio; cristal | BŌLI | Material transparente usado en ventanas y vasos.
W 吹 = soplar; ser llevado por el viento | CHUĪ | El viento puede hacer esta acción sobre algo.
W 破 = roto; romperse | PÒ | Describe algo que se ha roto o dañado.
W 受伤 = resultar herido; lesionarse | SHÒUSHĀNG | Sufrir una lesión física.
V Vocabulario: recibir una acción
D La bicicleta
安娜: 你 的 自行车 修好 了 吗? = ¿Ya está arreglada tu bicicleta?
  > 你 的 自行车 = tu bicicleta | 修好 了 吗 = ¿ya está arreglada?
李华: 修好 了, 是 工人 修理 的. = Sí, un trabajador la arregló.
  > 修好 了 = ya está arreglada | 工人 修理 的 = la reparó un trabajador
安娜: 那 个 问题 解决 了 吗? = ¿Se resolvió ese problema?
  > 那 个 问题 = ese problema | 解决 了 吗 = ¿se resolvió?
李华: 终于 解决 了, 我 也 发现 了 原因. = Por fin se resolvió; también descubrí la causa.
  > 终于 解决 了 = por fin se resolvió | 发现 了 原因 = descubrir la causa
T Cosas que pasan
- 我 的 自行车 被 工人 修好 了. = El trabajador me arregló la bicicleta.
  > 我 的 自行车 = mi bicicleta | 被 工人 修好 了 = fue arreglada por el trabajador
- 窗户 被 风 吹 破 了. = El viento rompió la ventana.
  > 窗户 被 风 吹 破 了 = la ventana fue rota por el viento
- 这个 问题 被 老师 解决 了. = El profesor resolvió este problema.
  > 这个 问题 = este problema | 被 老师 解决 了 = fue resuelto por el profesor
- 他 的 腿 受伤 了, 朋友 照顾 他. = Se lesionó la pierna y un amigo lo cuidó.
  > 腿 受伤 了 = se lesionó la pierna | 照顾 他 = cuidarlo
- 门 被 关上 了, 我们 进不去. = La puerta se cerró y no podemos entrar.
  > 门 被 关上 了 = la puerta fue cerrada | 进不去 = no poder entrar
Q ¿Qué marca 被?
+ Que alguien o algo recibe una acción. :: 被 introduce una oración pasiva.
- Que el hablante pregunta por una razón. :: Razón es 原因.
- Que la acción ocurrirá mañana. :: Mañana es 明天.
Q ¿Qué significa «终于»?
+ Por fin; finalmente. :: Indica que algo ocurre tras esperar o intentarlo.
- De repente. :: De repente es 突然.
- Con cuidado. :: Con cuidado es 小心.
R 窗户 被 风 吹 破 了. :: ¿Qué significa?
+ El viento rompió la ventana. :: La ventana recibe la acción de romperse.
- La ventana abrió el viento. :: La oración dice que el viento la rompió.
- El trabajador arregló la bicicleta. :: Bicicleta es 自行车.
H 这个 问题 ___ 老师 解决 了. :: «El profesor resolvió este problema».
+ 被 :: 被 marca que el problema recibe la acción de resolver.
- 乘 :: 乘 significa «viajar en» un transporte.
- 比 :: 比 se usa para comparar.
A 我 的 自行车 被 工人 修好 了. :: Escucha. ¿Qué ocurrió?
+ El trabajador arregló la bicicleta. :: 自行车 es bicicleta y 被 marca la pasiva.
- El viento rompió la ventana. :: Ventana es 窗户.
- El profesor resolvió el problema. :: Problema es 问题.
O 这个 问题 被 老师 解决 了 :: El profesor resolvió este problema :: 被 señala que el problema recibe la acción.
Q En una oración pasiva con 被, ¿qué aparece después del agente?
+ el verbo :: El verbo expresa la acción recibida.
- el lugar donde empieza el viaje :: La pasiva no indica el inicio de un viaje.
- la persona que hace la pregunta :: 被 presenta a quien recibe la acción.
R 门 被 关上 了, 我们 进不去. :: ¿Qué significa?
+ La puerta se cerró y no podemos entrar. :: 进不去 expresa que no se puede entrar.
- La puerta está abierta y podemos salir. :: La frase indica que se cerró.
- El trabajador arregló la bicicleta. :: Bicicleta es 自行车.
