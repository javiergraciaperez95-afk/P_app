@ 1 | 汉字和笔画 | Los caracteres: formas y trazos
I El chino se escribe con caracteres. Aquí verás espacios entre palabras para que puedas identificarlas; en la escritura normal del chino no se separan así. El pinyin ayuda a pronunciar y las marcas muestran tonos, no tildes españolas.
E Un carácter, una sílaba :: Cada carácter representa una sílaba y aporta significado. Una palabra puede tener uno o varios caracteres: **人** es «persona» y **大** significa «grande». :: En pinyin, **ā, á, ǎ, à** muestran los cuatro tonos. La misma sílaba con otro tono puede significar otra cosa; pronúncialos con cuidado.
E Forma y orden :: Los trazos se escriben normalmente de arriba abajo y de izquierda a derecha. Aprende a reconocer la forma completa; no intentes deducir la pronunciación solo por el dibujo.

@ 1 | 拼音和声调 | Pinyin y tonos
I El pinyin usa letras latinas para representar sonidos del mandarín. Las cuatro marcas tonales cambian el tono de la voz; no son el acento escrito del español. Al principio, escucha la diferencia y memoriza cada palabra con su tono.
E Los cuatro tonos :: **mā** mantiene un tono alto; **má** sube; **mǎ** baja y vuelve a subir; **mà** cae. La sílaba sin marca, como **ma**, tiene tono neutro y se dice breve. :: Las letras **q, x, zh, ch, sh** no suenan como en español: **q** se acerca a «ch», **x** a una «sh» suave y **zh** a una «ch» sonora.
E Sílabas y espacios :: Una palabra de varios caracteres puede formar una sola unidad, como **你好** (hola). En estas lecciones ponemos un espacio entre palabras, no entre sílabas de una misma palabra. :: **他** y **她** se pronuncian igual: tā. La escritura distingue «él» y «ella», aunque al hablar no se oye esa diferencia.

V Pronombres y tonos
T Una conversación breve
- 你 好 吗？ = ¿Estás bien?
  > 你 = tú | 好 = bien | 吗 = marca pregunta sí/no
- 我 很 好。 = Estoy muy bien.
  > 我 = yo | 很 好 = estoy bien; literalmente, muy bien
- 你 呢？ = ¿Y tú?
  > 你 = tú | 呢 = devuelve la pregunta
- 他 很 好。 = Él está bien.
  > 他 = él | 很 好 = está bien
- 这 是 月。 = Esto es la luna.
  > 这 = esto | 是 = es | 月 = luna
- 那 是 山。 = Aquello es una montaña.
  > 那 = aquello | 是 = es | 山 = montaña
Q ¿Cuántos tonos léxicos tiene el mandarín estándar?
+ Cuatro :: A ellos se añade el tono neutro, que no lleva marca.
- Dos :: Las marcas distinguen cuatro tonos principales.
- Seis :: Para este nivel se estudian cuatro tonos y el neutro.
Q ¿Qué significa 她?
+ ella :: Se pronuncia tā, igual que 他.
- él :: Él se escribe 他.
- nosotros :: Nosotros se dice 我们.
Q ¿Qué añade 吗 al final de una frase?
+ Una pregunta de sí o no. :: No hace falta cambiar el orden de la frase.
- Una negación. :: La negación básica es 不.
- El plural. :: 们 marca plural con pronombres de persona.
Q ¿Cómo se pronuncian 他 y 她?
+ Los dos se pronuncian tā. :: El contexto o el carácter indica «él» o «ella».
- Los dos se pronuncian wǒ. :: 我 se pronuncia wǒ.
- Uno se pronuncia nǐ y el otro wǒ. :: Esos sonidos corresponden a 你 y 我.
R 我 很 好。 :: Traduce la frase.
+ Estoy muy bien. :: 很 acompaña al adjetivo; no siempre significa «muy» enfático.
- No estoy bien. :: 不 no aparece en la frase.
- Él está bien. :: 我 significa «yo».
H 你 好 ___？ :: Completa la pregunta «¿estás bien?».
+ 吗 :: Convierte la frase en pregunta de sí o no.
- 不 :: Significa «no» y no va aquí.
- 呢 :: Devuelve una pregunta ya hecha.
A 他 :: ¿Qué pronombre oyes?
+ él :: 他 se pronuncia tā.
- ella :: 她 también se pronuncia tā, pero aquí se oye el mismo sonido.
- yo :: 我 se pronuncia wǒ.
O 我 们 很 好 :: Estamos bien :: 们 marca el plural de personas y 很 好 expresa estado.

@ 1 | 词语和书写 | Palabras y lectura
I Ya puedes reconocer palabras de dos o más caracteres. Lee primero cada bloque, mira el pinyin y fíjate en el orden de los trazos. El chino no usa mayúsculas ni separa normalmente las palabras con espacios.
E Cómo se forma una palabra :: **中国** significa China y **中国人**, persona china. Los caracteres aportan pistas de significado, pero no siempre se traducen por separado. :: **什么** significa «qué» y ocupa el lugar de la respuesta que se busca: **你 叫 什么？** significa «¿cómo te llamas?». No se añade 吗 a una pregunta con palabra interrogativa.
E Nombres y cortesía :: **老师** significa profesor o profesora; no tiene terminación masculina o femenina. **学生** significa estudiante. :: **你好** es un saludo y **谢谢** significa «gracias». **再见** se usa para despedirse. Escribe los nombres propios con caracteres chinos cuando los conozcas; aquí también hay nombres extranjeros transcritos.
