@ 7 | 多少钱 | Preguntar precios
I Para preguntar el precio, di **多少钱？**, literalmente «¿cuánto dinero?». El chino no cambia las cifras por género ni número. Puedes decir el precio con 元, forma más formal, o 块, forma corriente al hablar.
E Precios :: **钱** significa dinero; **元** es la unidad monetaria escrita y **块**, la forma oral habitual. **十块钱** son diez yuanes. :: **贵** significa caro y **便宜**, barato. **买** es comprar y **卖**, vender. No confundas 买 y 卖: cambian el trazo superior.
E Números y precio :: **多少** pregunta «cuánto/cuántos». Para preguntar por un objeto, di **这个苹果多少钱？** («¿cuánto cuesta esta manzana?»). En chino el precio suele ir sin el verbo «costar».
W 买 = comprar | MǍI
W 卖 = vender | MÀI
W 钱 = dinero | QIÁN
W 条 = clasificador para peces y cosas alargadas | TIÁO
W 多少 = cuánto; cuántos | DUŌSHAO
W 元 = yuan (unidad monetaria) | YUÁN
W 块 = yuan (forma oral) | KUÀI
W 贵 = caro; costoso | GUÌ
W 便宜 = barato; económico | PIÁNYI
W 价钱 = precio | JIÀQIÁN
W 现金 = dinero en efectivo | XIÀNJĪN
W 找 = devolver cambio; buscar | ZHǍO
W 找钱 = dar el cambio | ZHǍOQIÁN
V Precios y compras
D En el mercado
安娜: 这 个 苹果 多少 钱？ = ¿Cuánto cuesta esta manzana?
  > 这 个 苹果 = esta manzana | 多少 钱 = cuánto dinero
卡洛斯: 十 块 钱。 = Diez yuanes.
  > 十 = diez | 块 钱 = yuanes (forma oral)
安娜: 这 个 苹果 贵 吗？ = ¿Esta manzana es cara?
  > 这 个 苹果 = esta manzana | 贵 = caro | 吗 = pregunta sí/no
卡洛斯: 不 贵，很 便宜。 = No es cara; es muy barata.
  > 不 贵 = no es cara | 很 便宜 = muy barata
安娜: 我 买 一 个 苹果。 = Compro una manzana.
  > 我 = yo | 买 = comprar | 一 个 苹果 = una manzana
卡洛斯: 好，十 元。 = De acuerdo, diez yuanes.
  > 好 = de acuerdo | 十 元 = diez yuanes
T Mira los precios
- 这 个 苹果 十 元。 = Esta manzana cuesta diez yuanes.
  > 这 个 苹果 = esta manzana | 十 元 = diez yuanes
- 这 个 菜 很 便宜。 = Este plato es muy barato.
  > 这 个 菜 = este plato | 很 便宜 = muy barato
- 那 条 鱼 很 贵。 = Ese pescado es muy caro.
  > 那 条 鱼 = ese pescado | 很 贵 = muy caro
- 我 有 十 块 钱。 = Tengo diez yuanes.
  > 我 = yo | 有 = tengo | 十 块 钱 = diez yuanes
- 你 买 什么？ = ¿Qué compras?
  > 你 = tú | 买 = comprar | 什么 = qué
- 他 卖 水果。 = Él vende fruta.
  > 他 = él | 卖 = vender | 水果 = fruta
Q ¿Qué significa 便宜?
+ barato :: Lo contrario de 贵.
- caro :: Caro es 贵.
- dinero :: Dinero es 钱.
Q ¿Qué significa 元 en un precio?
+ yuan, unidad monetaria :: Aparece en precios escritos.
- dinero en efectivo :: Efectivo es 现金.
- cambio :: Dar el cambio es 找钱.
Q ¿Qué verbo significa «comprar»?
+ 买 :: Fíjate en el trazo superior.
- 卖 :: Significa vender.
- 找 :: Significa devolver cambio o buscar.
R 这 个 苹果 多少 钱？ :: Traduce la pregunta.
+ ¿Cuánto cuesta esta manzana? :: 多少 pregunta cuánto y 钱 es dinero.
- ¿Cuántas manzanas hay? :: La frase pregunta el precio.
- ¿Esta manzana es barata? :: Barata es 便宜.
R 不 贵，很 便宜。 :: Traduce la respuesta.
+ No es cara; es muy barata. :: 便宜 significa barato.
- Es muy cara. :: 贵 significa caro, pero aquí está negado.
- Cuesta diez yuanes. :: Ese precio se dice 十元.
H 这 个 苹果 十 ___。 :: Completa «esta manzana cuesta diez yuanes».
+ 元 :: Es la unidad monetaria.
- 块 :: Es la forma oral, pero aquí el modelo usa 元.
- 钱 :: Significa dinero y no expresa la unidad por sí sola.
A 他 卖 水果。 :: ¿Qué hace él?
+ Vende fruta. :: 卖 es vender.
- Compra fruta. :: Comprar es 买.
- Busca una manzana. :: Buscar es 找.
O 我 买 一 个 苹果 :: Compro una manzana :: 买 significa comprar.

@ 7 | 买衣服 | Ropa y colores
I Para contar prendas, usa 件 delante del nombre; para los zapatos, usa 双 («par»). Los colores pueden ir antes de la prenda: **红衣服** («ropa roja»). El adjetivo no cambia por género ni plural.
E Ropa y tallas :: **衣服** es ropa, **裤子**, pantalones y **鞋**, zapatos. **裙子** es falda y **外套**, abrigo o chaqueta. **件** cuenta prendas; **双**, pares. :: **号码** es número o talla. **试穿** significa probarse una prenda.
E Colores :: **红**, **白** y **黑** son rojo, blanco y negro. **颜色** significa color. Para preguntar puedes decir **你喜欢什么颜色？** («¿qué color te gusta?»). En chino el color no concuerda con la prenda.

@ 7 | 怎么付款 | Pagar una compra
I Para pagar, puedes dar dinero en efectivo o usar una tarjeta. **给** significa dar y **收** significa recibir. **一共** resume el importe total; **找钱** es devolver el cambio.
E Formas de pago :: **现金** es efectivo; **卡** es tarjeta y **银行卡**, tarjeta bancaria. **付钱** significa pagar. **人民币** es la moneda china, el renminbi; en los precios diarios se oye a menudo 块. :: **带** significa llevar o traer. Si preguntas si puedes pagar con tarjeta, di **可以用银行卡吗？**.
E El cambio :: **找钱** se forma con 找 («devolver cambio») y 钱 («dinero»). Puedes preguntar **一共多少钱？** («¿cuánto es en total?»). En español a menudo decimos «¿cuánto es?» sin mencionar el dinero.
