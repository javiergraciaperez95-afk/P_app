@ 34 | Följa en föreläsning | Seguir una exposición
I Identifica la idea central de una explicación y distingue los ejemplos secundarios.
E Tomar notas :: Anota el tema, la idea principal y los ejemplos. **Det innebär att…** reformula una consecuencia con tus propias palabras.
W en föreläsning = una exposición, una conferencia
W en resurs = un recurso
W begränsad = limitado, limitada
W förnybar = renovable
W en förbrukning = un consumo
W begränsade = limitados
W energikällor = fuentes de energía
W förbrukning = consumo
W förnybara = renovables
W måste = debe
W naturligt = naturalmente
W planeras = se planifica
W resurser = recursos
W vind = viento
W vissa = algunos
W återskapas = se renueva
V Energi i vardagen
D I klassrummet
Lärare: Energi är en resurs, men vissa resurser är begränsade. = La energía es un recurso, pero algunos recursos son limitados.
Lärare: Sol och vind är exempel på förnybara energikällor. = El sol y el viento son ejemplos de fuentes de energía renovables.
Student: Det innebär att de kan återskapas naturligt, men vår förbrukning måste ändå planeras. = Eso significa que pueden regenerarse de forma natural, pero aun así nuestro consumo debe planificarse.
Q ¿Cuál es la idea principal?
+ Algunas fuentes de energía son limitadas y otras renovables. :: La explicación contrasta los tipos de recursos.
- La electricidad siempre es gratis. :: No lo afirma.
- El viento no produce energía. :: Es lo contrario.
Q ¿Qué ejemplos de fuentes renovables aparecen?
+ Sol y viento. :: El profesor los menciona.
- Gas y carbón. :: No aparecen.
- Agua y madera. :: No se mencionan.
R Vår förbrukning måste ändå planeras.
+ Aun así, nuestro consumo debe planificarse. :: «Ändå» introduce una concesión.
- No tenemos que pensar en el consumo. :: Dice lo contrario.
- Los recursos son ilimitados. :: No lo afirma.
H Sol och vind är exempel på ___ energikällor.
+ förnybara :: «Förnybar» significa renovable.
- begränsade :: «Begränsad» significa limitada.
- använda :: «Använda» significa usadas.
O Sol och vind är exempel på förnybara energikällor :: El sol y el viento son ejemplos de fuentes de energía renovables :: Los ejemplos desarrollan la idea principal.

@ 34 | Hänvisa till en källa | Citar una fuente
I Presenta información de otra persona con claridad y diferencia cita directa de paráfrasis.
E Atribuir información :: **Enligt forskaren…** atribuye una idea. En una paráfrasis, conserva el sentido y expresa la idea con palabras propias; no cambies la fuente.
W hänvisa till = citar, referirse a
W en forskare = un investigador, una investigadora
W ett citat = una cita
W med egna ord = con palabras propias
W en rapport = un informe
W en studie = un estudio
W ett samband = una relación, una conexión
W citat = cita
W exakta = exactas
W formuleringen = la formulación
W forskaren = el investigador
W rapporten = el informe
W resonemang = razonamiento
W slutsatsen = la conclusión
W text = texto
V Skriva en uppgift
D Prata om en källa
Nora: Hur kan jag använda rapporten i min text? = ¿Cómo puedo usar el informe en mi texto?
Leo: Hänvisa till forskaren och sammanfatta slutsatsen med egna ord. = Cita al investigador y resume la conclusión con tus propias palabras.
Nora: Behöver jag ta med ett direkt citat? = ¿Tengo que incluir una cita directa?
Leo: Bara om den exakta formuleringen är viktig för ditt resonemang. = Solo si la formulación exacta es importante para tu argumento.
Q ¿Qué recomienda Leo?
+ Atribuir la fuente y resumir la conclusión con palabras propias. :: Describe ambas acciones.
- Copiar todo el informe. :: No lo recomienda.
- Cambiar la conclusión para que apoye su opinión. :: No lo dice.
Q ¿Cuándo sería útil una cita directa?
+ Cuando la formulación exacta sea importante. :: Esa es la condición que explica Leo.
- Siempre, en cada frase. :: No lo recomienda.
- Cuando no se conoce la fuente. :: No es lo que dice.
R Med egna ord.
+ Con palabras propias. :: Es una paráfrasis.
- En el informe original. :: No es la expresión.
- Sin indicar la fuente. :: Leo recomienda atribuirla.
H Hänvisa till forskaren och sammanfatta ___ .
+ slutsatsen :: «Slutsats» significa conclusión.
- biljetten :: «Biljett» significa billete.
- vädret :: «Väder» significa tiempo atmosférico.
O Den exakta formuleringen är viktig för ditt resonemang :: La formulación exacta es importante para tu argumento :: «Resonemang» es el razonamiento desarrollado.

@ 34 | Förklara en process | Explicar un proceso
I Describe los pasos de un procedimiento y explica por qué se sigue ese orden.
E Procedimientos :: Usa conectores temporales y formas pasivas cuando importa el proceso: **först samlas uppgifterna in**, **därefter jämförs de**.
W en process = un proceso
W samla in = recopilar
W uppgifter = datos, tareas
W därefter = después
W ett mönster = un patrón
W dra en slutsats = sacar una conclusión
W i flera steg = en varios pasos
W deltagarna = participantes
W jämförs = se comparan
W materialet = el material
W samlas = se recopilan
W sist = al final
W svaren = las respuestas
W synligt = visiblemente
V En enkel undersökning
D På kursen
Lärare: Först samlas svaren in från alla deltagare. = Primero se recogen las respuestas de todos los participantes.
Lärare: Därefter jämförs svaren och ett mönster kan bli synligt. = Después se comparan las respuestas y puede hacerse visible un patrón.
Student: Och till sist drar vi en slutsats? = ¿Y al final sacamos una conclusión?
Lärare: Ja, men vi måste också beskriva vad materialet inte visar. = Sí, pero también debemos describir qué no muestran los datos.
Q ¿Qué ocurre primero?
+ Se recogen las respuestas. :: Es el primer paso descrito.
- Se publica una conclusión. :: La conclusión se formula al final.
- Se decide qué muestran los datos. :: Primero se recopilan.
Q ¿Por qué hay que explicar qué no muestran los datos?
+ Para describir los límites de la información. :: El profesor añade esta precaución.
- Para esconder resultados. :: No es su objetivo.
- Para evitar comparar respuestas. :: La comparación sí forma parte del proceso.
R Därefter jämförs svaren.
+ Después se comparan las respuestas. :: «Därefter» señala el siguiente paso y «jämförs» es pasiva.
- Primero se escriben las preguntas. :: No es la frase.
- Las respuestas no se revisan. :: Dice que se comparan.
H Först samlas svaren ___ från deltagarna.
+ in :: «Samla in» significa recopilar.
- om :: «Om» significa si o acerca de.
- bort :: «Bort» significa lejos.
O Vi måste beskriva vad materialet inte visar :: Debemos describir qué no muestran los datos :: También es importante indicar los límites de un análisis.
X Escribe en sueco: «Después se comparan las respuestas» :: Därefter jämförs svaren
