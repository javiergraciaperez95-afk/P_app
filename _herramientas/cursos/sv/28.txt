@ 28 | En bokcirkel | Un club de lectura
I Recomienda un libro y explica qué te pareció su personaje principal.
E Hablar de un libro :: **Den handlar om…** presenta el tema. **Jag fastnade för…** significa que algo te interesó mucho.
W en bokcirkel = un club de lectura
W handla om = tratar de
W en huvudperson = un personaje principal
W fastna för = interesarse mucho por
W en förändring = un cambio
W en berättelse = un relato
W trovärdig = creíble
W rekommendera = recomendar
W berättelsen = la historia
W fastnade = se interesó, se quedó con
W flyttar = se muda
W handlar = trata
W hon = ella
W huvudpersonen = el personaje principal
W misstag = errores
V Månadens bok
D Efter läsningen
Maja: Vad tyckte du om boken? = ¿Qué te pareció el libro?
Omar: Den handlar om en familj som flyttar till en ny stad. = Trata de una familia que se muda a una ciudad nueva.
Maja: Vem fastnade du för? = ¿Qué personaje te interesó más?
Omar: Huvudpersonen. Hon gör misstag, men förändras under berättelsen. = La protagonista. Comete errores, pero cambia a lo largo de la historia.
Q ¿De qué trata el libro?
+ De una familia que se muda a otra ciudad. :: Esa es la trama que resume Omar.
- De un viaje a Noruega. :: No es el tema del libro.
- De una entrevista de trabajo. :: No se menciona.
Q ¿Por qué le interesa la protagonista a Omar?
+ Porque comete errores y cambia. :: Menciona esas características.
- Porque nunca tiene problemas. :: Dice que comete errores.
- Porque cuenta toda la historia. :: No lo dice.
R Den handlar om en familj.
+ Trata de una familia. :: «Handlar om» introduce el tema.
- La familia está en la estación. :: No es la traducción.
- La protagonista recomienda un libro. :: No es la frase.
H Huvudpersonen ___ under berättelsen.
+ förändras :: «Förändras» significa cambia.
- rekommenderar :: «Rekommenderar» significa recomienda.
- försenas :: «Försenas» significa se retrasa.
O Hon gör misstag, men förändras :: Comete errores, pero cambia :: «Men» conecta la dificultad y la evolución.

@ 28 | Film och bok | Película y libro
I Compara una adaptación con el libro y explica cuál prefieres.
E Comparar versiones :: **Jämfört med…** significa «comparado con…». Usa **medan** para presentar una diferencia entre dos cosas.
W en filmatisering = una adaptación cinematográfica
W jämfört med = comparado con
W en scen = una escena
W en skådespelare = un actor, una actriz
W en detalj = un detalle
W en tempo = un ritmo
W däremot = en cambio
W föredra = preferir
W beskrev = describía
W detaljer = detalles
W filmatiseringen = la adaptación cinematográfica
W föredrar = prefiere
W högre = más alto
W medan = mientras
W personerna = las personas
W tempo = ritmo
W version = versión
V Samma historia på film
D Ett samtal efter filmen
Nora: Hur var filmatiseringen jämfört med boken? = ¿Qué tal fue la adaptación comparada con el libro?
Leo: Filmen hade ett högre tempo, medan boken beskrev personerna mer. = La película tenía un ritmo más rápido, mientras que el libro describía más a las personas.
Nora: Vilken version föredrar du? = ¿Qué versión prefieres?
Leo: Jag föredrar boken, eftersom jag tycker om alla detaljer. = Prefiero el libro porque me gustan todos los detalles.
Q ¿Qué diferencia menciona Leo?
+ La película tiene más ritmo y el libro describe más a los personajes. :: Contrasta ambos aspectos.
- La película es más larga que el libro. :: No compara la duración.
- El libro tiene más actores. :: No lo dice.
Q ¿Qué versión prefiere Leo?
+ El libro. :: Lo dice claramente.
- La película. :: Dice que prefiere el libro.
- Le gustan por igual. :: Expresa una preferencia.
R Medan boken beskrev personerna mer.
+ Mientras que el libro describía más a las personas. :: «Medan» contrapone dos versiones.
- Después, el libro se convirtió en película. :: No es la frase.
- La película tenía más detalles. :: Dice que el libro describía más.
H Jag ___ boken, eftersom jag tycker om alla detaljer.
+ föredrar :: «Föredrar» significa prefiero.
- jämför :: «Jämför» significa compara.
- saknar :: «Saknar» significa echa de menos.
O Filmen hade ett högre tempo, medan boken beskrev personerna mer :: La película tenía un ritmo más rápido, mientras que el libro describía más a los personajes :: «Medan» expresa contraste.

@ 28 | En kulturkväll | Una velada cultural
I Invita a alguien a un evento y comenta la experiencia después.

W en kulturkväll = una velada cultural
W en föreställning = una función, un espectáculo
W en scen = un escenario
W en publik = un público
W en biljettpris = un precio de entrada
W visa sig = resultar
W även om = aunque
W både = tanto, ambos
W föreställningen = el espectáculo
W ganska = bastante
W scener = escenas
W sig = se
W snabba = rápidas
W trodde = pensaba
W visade = mostró, resultó
V På teatern
D Efter föreställningen
Sara: Vad tyckte du om föreställningen? = ¿Qué te pareció el espectáculo?
Ali: Den var bättre än jag trodde. Det visade sig att berättelsen var både rolig och viktig. = Fue mejor de lo que pensaba. Resultó que la historia era divertida e importante.
Sara: Var det lätt att följa med? = ¿Era fácil seguirla?
Ali: Ja, även om några scener var ganska snabba. = Sí, aunque algunas escenas eran bastante rápidas.
Q ¿Qué resultó ser la historia?
+ Divertida e importante. :: Ali la describe así.
- Demasiado larga y triste. :: No lo dice.
- Difícil de entender. :: Dice que fue fácil seguirla.
Q ¿Qué dificultad menciona Ali?
+ Algunas escenas eran bastante rápidas. :: Dice que eran rápidas.
- El espectáculo empezó tarde. :: No lo menciona.
- No había entradas. :: Ya vio la función.
R Även om några scener var ganska snabba.
+ Aunque algunas escenas eran bastante rápidas. :: «Även om» introduce una concesión.
- Como las escenas eran demasiado largas. :: No es la frase.

H Det visade sig ___ berättelsen var viktig.
+ att :: «Det visade sig att» introduce lo que resultó ser cierto.
- om :: «Om» significa si.
- därför :: «Därför» significa por eso.
O Den var bättre än jag trodde :: Fue mejor de lo que pensaba :: «Än» compara la experiencia con una expectativa.
