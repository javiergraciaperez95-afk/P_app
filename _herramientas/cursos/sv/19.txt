@ 19 | I går | Ayer
I Cuenta una actividad reciente con verbos frecuentes en pasado.
E Pasado :: Muchos verbos suecos forman el pasado con **-de** o **-te**: **arbetar–arbetade**, **köper–köpte**. Aprende las formas más comunes en contexto.
W arbetade = trabajó, trabajé
W köpte = compró, compré
W träffade = quedó con, se encontró con
W åt = comió
W efteråt = después
W dagen = el día
W gjorde = hizo, hice
V En lördag
D Vad gjorde du?
Mira: Vad gjorde du i går? = ¿Qué hiciste ayer?
Jonas: Jag arbetade på dagen och träffade en vän efteråt. = Trabajé durante el día y después quedé con un amigo.
Mira: Vad åt ni? = ¿Qué comieron?
Jonas: Vi åt middag på en restaurang. = Cenamos en un restaurante.
Q ¿Qué hizo Jonas durante el día?
+ Trabajó. :: «Arbetade» significa trabajó.
- Estudió en casa. :: No lo menciona.
- Compró un billete. :: No lo menciona.
Q ¿Dónde cenaron?
+ En un restaurante. :: Jonas dice «på en restaurang».
- En casa de un amigo. :: No se menciona una casa.
- En la estación. :: No se menciona una estación.
R Jag träffade en vän efteråt.
+ Después quedé con un amigo. :: «Efteråt» significa después.
- Ayer llamé a un amigo. :: «Ringde» sería llamé.
- Trabajé con un amigo todo el día. :: No es la frase.
H Vi ___ middag på en restaurang.
+ åt :: «Åt» es el pasado de «äter».
- äter :: «Äter» está en presente.
- äta :: «Äta» es infinitivo.
O Jag arbetade på dagen och träffade en vän :: Trabajé durante el día y quedé con un amigo :: Dos acciones en pasado.
X Escribe en sueco: «¿Qué hiciste ayer?» :: Vad gjorde du i går

@ 19 | En minnesvärd dag | Un día memorable
I Relata una experiencia especial y di cómo te sentiste.
E Relatar :: **Förra året** significa el año pasado. **Det var roligt** significa que fue divertido.
W förra året = el año pasado
W besökte = visitó
W en familj = una familia
W ett slott = un castillo
W en stad = una ciudad
W roligt = divertido
W tog = tomó, cogió
W reste = reste
V Ett reseminne
D Ett foto från resan
Nora: Var var du förra året? = ¿Dónde estuviste el año pasado?
Leo: Jag reste till Uppsala och besökte min familj. = Viajé a Upsala y visité a mi familia.
Nora: Vad gjorde ni där? = ¿Qué hicieron allí?
Leo: Vi såg ett slott tillsammans. Det var roligt. = Vimos un castillo juntos. Fue divertido.
Q ¿A dónde viajó Leo?
+ A Upsala. :: Dice «reste till Uppsala».
- A Malmö. :: No se menciona Malmö.
- A Estocolmo. :: No se menciona Estocolmo.
Q ¿Qué hicieron juntos?
+ Vieron un castillo. :: «Vi såg ett slott».
- Fueron de compras. :: No se menciona comprar.
- Visitaron un museo. :: No se menciona un museo.
R Det var roligt.
+ Fue divertido. :: «Var» es pasado y «roligt» es divertido.
- Es muy caro. :: «Dyrt» significa caro.
- Estaba muy lejos. :: No aparece la distancia.
H Vi ___ ett slott tillsammans.
+ såg :: «Såg» es el pasado de «ser» (ver).
- ser :: «Ser» está en presente.
- besökte :: «Besökte» significa visitó.
O Jag reste till Uppsala och besökte min familj :: Viajé a Upsala y visité a mi familia :: «Reste» y «besökte» están en pasado.
X Escribe en sueco: «El año pasado visité a mi familia» :: Förra året besökte jag min familj

@ 19 | Varför? | ¿Por qué?
I Explica una opinión y cuenta una experiencia usando conectores simples.
E Conectar ideas :: **Men** introduce contraste («pero»). **Därför** introduce un resultado («por eso»). **För att** introduce un motivo.
W därför = por eso
W för att = porque, para
W rolig = divertido
W en vänskap = una amistad
W lära sig = aprender
W ny = nuevo, nueva
W Filmen = la película
W filmer = películas
W får = consigo, tiene
W lär = aprendo, aprende
W ord = palabras
W prata = hablar
W slutet = el final
W sorgligt = triste
W sådana = ese tipo de
W Tyckte = gustó, pensó
V Åsikter
D Efter filmen
Nora: Tyckte du om filmen? = ¿Te gustó la película?
Leo: Ja, den var rolig, men slutet var lite sorgligt. = Sí, fue divertida, pero el final fue un poco triste.
Nora: Varför gillar du sådana filmer? = ¿Por qué te gustan ese tipo de películas?
Leo: För att jag lär mig nya ord och får något att prata om. = Porque aprendo palabras nuevas y tengo algo de qué hablar.
Q ¿Qué piensa Leo del final?
+ Fue un poco triste. :: Dice «slutet var lite sorgligt».
- Fue muy divertido. :: Dice que la película fue divertida, pero el final triste.
- Fue demasiado largo. :: No habla de la duración.
Q ¿Por qué le gustan esas películas?
+ Aprende palabras nuevas y tiene algo de qué hablar. :: Da esas dos razones.
- Porque son cortas. :: No lo dice.
- Porque las ve con su familia. :: No lo dice.
R Den var rolig, men slutet var lite sorgligt.
+ Fue divertida, pero el final fue un poco triste. :: «Men» contrasta dos ideas.
- Fue triste porque la película era larga. :: No dice eso.
- El final fue divertido y nuevo. :: No es el sentido de la frase.
H ___ jag lär mig nya ord.
+ För att :: Introduce el motivo: porque aprendo palabras nuevas.
- Därför :: Significa por eso y presenta un resultado.
- Men :: Significa pero.
O Filmen var rolig, men slutet var sorgligt :: La película fue divertida, pero el final fue triste :: «Men» conecta una idea con su contraste.
X Escribe en sueco: «Porque aprendo palabras nuevas» :: För att jag lär mig nya ord
