@ 11 | Min vanliga dag | Mi día habitual
I Describe una rutina con más detalle y cuenta a qué hora haces las cosas.
E Rutinas :: Para hablar de frecuencia, usa **ofta** («a menudo»), **ibland** («a veces») y **varje dag** («cada día»). :: El verbo suele ir en segunda posición: **På morgonen dricker jag kaffe**.
W varje dag = cada día
W lagar mat = cocina
W först = primero
W brukar = suele
W bussen = el autobús
W upp = levantarse
V En vardag
D På väg till jobbet
Maja: Jag brukar gå upp klockan sju. = Suelo levantarme a las siete.
Omar: Vad gör du sedan? = ¿Qué haces después?
Maja: Först äter jag frukost, sedan tar jag bussen. = Primero desayuno y después cojo el autobús.
Omar: När börjar du arbeta? = ¿Cuándo empiezas a trabajar?
Maja: Jag börjar klockan nio och slutar klockan fem. = Empiezo a las nueve y termino a las cinco.
Q ¿Qué significa «ibland»?
+ A veces. :: «Ibland» indica que algo ocurre algunas veces.
- Siempre. :: «Alltid» significa siempre.
- Nunca. :: «Aldrig» significa nunca.
Q ¿Qué hace Maja primero?
+ Desayuna. :: Primero come el desayuno.
- Coge el autobús. :: Eso lo hace después.
- Empieza a trabajar. :: Empieza a las nueve.
R Jag börjar klockan nio och slutar klockan fem.
+ Empiezo a las nueve y termino a las cinco. :: «Börjar» es empieza y «slutar» es termina.
- Trabajo de nueve a siete. :: No es lo que dice la frase.
- Desayuno a las nueve. :: «Frukost» significa desayuno.
H Först äter jag ___, sedan tar jag bussen.
+ frukost :: «Frukost» es desayuno.
- middag :: «Middag» es cena o comida principal.
- kaffe :: «Kaffe» es café.
O Jag brukar gå upp klockan sju :: Suelo levantarme a las siete :: «Brukar» expresa una costumbre.
X Escribe en sueco: «Después cojo el autobús» :: Sedan tar jag bussen

@ 11 | En ledig dag | Un día libre
I Habla de lo que haces en tu tiempo libre y de actividades habituales.
E Frecuencia :: **På helgen** significa «el fin de semana». Para decir que haces algo con otra persona, puedes añadir **med en vän**.
W på helgen = el fin de semana
W träffar = queda con, se encuentra con
W en vän = un amigo, una amiga
W brukar läsa = suele leer
W gärna = con gusto, le gusta
W dina = tus
W göra = hacer
W promenera = pasear
W vänner = amigos, amigas
V Fritid
D Planer för lördagen
Maja: Vad brukar du göra på helgen? = ¿Qué sueles hacer el fin de semana?
Omar: Jag brukar promenera eller läsa hemma. = Suelo pasear o leer en casa.
Maja: Träffar du dina vänner ibland? = ¿Quedas con tus amigos a veces?
Omar: Ja, jag träffar gärna en vän och äter lunch ute. = Sí, me gusta quedar con un amigo y comer fuera.
Maja: Vad trevligt! = ¡Qué bien!
Q ¿Qué significa «på helgen»?
+ El fin de semana. :: «Helg» significa fin de semana.
- Por la mañana. :: «Morgon» significa mañana.
- Después del trabajo. :: Esa expresión es «efter jobbet».
Q ¿Qué le gusta hacer a Omar?
+ Quedar con un amigo y comer fuera. :: Dice que queda con un amigo y come fuera.
- Trabajar hasta tarde. :: No se menciona trabajar.
- Ir de compras. :: No aparece en el diálogo.
R Jag brukar promenera eller läsa hemma.
+ Suelo pasear o leer en casa. :: «Eller» significa o.
- Suelo cocinar y comer fuera. :: «Laga mat» significa cocinar.
- Quiero leer con mi amigo. :: «Vill» significa quiero.
H Jag träffar gärna en ___ och äter lunch ute.
+ vän :: «Vän» significa amigo o amiga.
- buss :: «Buss» significa autobús.
- bok :: «Bok» significa libro.
O Jag brukar promenera eller läsa hemma :: Suelo pasear o leer en casa :: «Eller» une alternativas.
X Escribe en sueco: «¿Qué sueles hacer el fin de semana?» :: Vad brukar du göra på helgen

@ 11 | Veckans planer | Los planes de la semana
I Organiza una semana y responde a una invitación con una hora concreta.
E Días y planes :: **På tisdag** es «el martes». **Kan du…?** sirve para preguntar si alguien puede hacer algo.
W på tisdag = el martes
W på torsdag = el jueves
W kan = puede, poder
W träna = hacer ejercicio
W efter skolan = después de clase
W passar = viene bien
W tyvärr = por desgracia
W tränar = hace ejercicio, hacemos ejercicio
V Kalendern
D En inbjudan
Sara: Kan du träna på tisdag? = ¿Puedes hacer ejercicio el martes?
Leo: Tyvärr kan jag inte på tisdag. = Por desgracia, el martes no puedo.
Sara: Passar torsdag efter skolan? = ¿Te viene bien el jueves después de clase?
Leo: Ja, det passar bra. Vi tränar tillsammans. = Sí, me viene bien. Hacemos ejercicio juntos.
Q ¿Cuándo propone Sara hacer ejercicio por segunda vez?
+ El jueves después de clase. :: Propone «torsdag efter skolan».
- El lunes por la mañana. :: No se menciona el lunes.
- El sábado por la noche. :: No se menciona el sábado.
Q ¿Qué significa «tyvärr»?
+ Por desgracia. :: «Tyvärr» expresa una respuesta negativa con cortesía.
- Quizá. :: «Kanske» significa quizá.
- Juntos. :: «Tillsammans» significa juntos.
R Det passar bra.
+ Me viene bien. :: Se usa para aceptar una hora o un plan.
- No tengo tiempo. :: «Tid» es tiempo.
- Estoy cansado. :: «Trött» significa cansado.
H Kan du träna på ___?
+ tisdag :: «Tisdag» es martes.
- vinter :: «Vinter» es invierno.
- morgon :: «Morgon» es mañana.
O Vi tränar tillsammans efter skolan :: Hacemos ejercicio juntos después de clase :: La frase expresa un plan compartido.
X Escribe en sueco: «¿Te viene bien el jueves?» :: Passar torsdag
