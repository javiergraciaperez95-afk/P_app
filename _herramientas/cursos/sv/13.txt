@ 13 | Vilken är billigast? | ¿Cuál es la más barata?
I Compara precios y pregunta por una opción más económica.
E Comparar :: Para comparar, añade **-are** a muchos adjetivos: **billig–billigare** (barato–más barato). **Än** significa «que» en una comparación.
W billigare = más barato, más barata
W dyrare = más caro, más cara
W än = que (comparación)
W vilken = cuál
W en jacka = una chaqueta
W båda = ambos, ambas
W femhundra = quinientos
W fina = bonitos
W svarta = negra
V Priser
D I klädbutiken
Alma: Vilken jacka är billigare? = ¿Qué chaqueta es más barata?
Butiksbiträde: Den blå kostar femhundra kronor. = La azul cuesta quinientas coronas.
Alma: Och den svarta? = ¿Y la negra?
Butiksbiträde: Den svarta är dyrare. Båda är fina. = La negra es más cara. Ambas son bonitas.
Q ¿Qué chaqueta es más barata?
+ La azul. :: La azul cuesta quinientas coronas; la negra es más cara.
- La negra. :: El dependiente dice que la negra es más cara.
- Las dos cuestan lo mismo. :: Indica que una es más cara.
Q ¿Qué significa «båda»?
+ Ambas. :: «Båda» se refiere a las dos chaquetas.
- Ninguna. :: «Ingen» significa ninguna.
- La más cara. :: «Dyrare» es más cara.
R Den svarta är dyrare.
+ La negra es más cara. :: «Dyrare» es el comparativo de «dyr».
- La negra es más barata. :: «Billigare» significa más barata.
- La negra es muy pequeña. :: «Liten» significa pequeña.
H Den blå kostar ___ kronor.
+ femhundra :: «Femhundra» significa quinientos.
- femtio :: «Femtio» significa cincuenta.
- femton :: «Femton» significa quince.
O Den svarta är dyrare :: La negra es más cara :: «Dyrare» compara dos precios.

@ 13 | Hitta rätt storlek | Encontrar la talla adecuada
I Pregunta por otra talla y describe cómo queda una prenda.
E Tallas :: **Har ni den i storlek…?** pregunta si tienen algo en una talla. **Den sitter bra** significa que queda bien.
W en storlek = una talla
W större = más grande
W mindre = más pequeño, más pequeña
W sitter bra = queda bien
W en provhytt = un probador
W borta = lejos, allí
W provhytten = el probador
V Kläder och storlekar
D Vid provhytten
Alma: Kan jag prova den här tröjan? = ¿Puedo probarme este jersey?
Butiksbiträde: Ja, provhytten är där borta. = Sí, el probador está allí.
Alma: Den är lite liten. Har ni en större storlek? = Es un poco pequeño. ¿Tienen una talla más grande?
Butiksbiträde: Ja, här är en större. = Sí, aquí tiene uno más grande.
Q ¿Qué quiere hacer Alma?
+ Probarse el jersey. :: Pregunta «Kan jag prova…?».
- Comprar zapatos. :: No se mencionan zapatos.
- Devolver una chaqueta. :: No menciona devolverla.

+ El jersey es un poco pequeño. :: Dice «Den är lite liten».

R Har ni en större storlek?
+ ¿Tienen una talla más grande? :: «Större» significa más grande.
- ¿Tienen una talla más pequeña? :: «Mindre» es más pequeña.

@ 13 | Byta en vara | Cambiar un producto
I Explica que una prenda no te sirve y pide cambiarla o recibir el dinero.
E Devoluciones :: **Jag skulle vilja byta den** significa «Quisiera cambiarla». Guarda el recibo: **kvittot** es el recibo.
W byta = cambiar
W en vara = un producto
W ett kvitto = un recibo
W lämna tillbaka = devolver
W pengarna tillbaka = el dinero de vuelta
W en färg = un color
W fortfarande = todavía
W Färgen = el color
W kvittot = el recibo
W mig = me
W skulle = querría
W vilja = querer
V I kassan
D Ett byte
Alma: Jag skulle vilja byta den här tröjan. = Quisiera cambiar este jersey.
Butiksbiträde: Har du kvittot? = ¿Tienes el recibo?
Alma: Ja. Färgen passar inte mig. = Sí. El color no me queda bien.
Butiksbiträde: Vill du byta färg eller få pengarna tillbaka? = ¿Quieres cambiar el color o recibir el dinero de vuelta?
Q ¿Qué quiere hacer Alma?
+ Cambiar el jersey. :: Dice que quisiera cambiarlo.
- Comprar otro recibo. :: El recibo se presenta como prueba de compra.
- Reservar unos zapatos. :: No se mencionan zapatos.
Q ¿Qué pregunta el dependiente?
+ Si quiere cambiar el color o recibir el dinero. :: Ofrece esas dos opciones.
- Si quiere una talla más pequeña. :: No lo pregunta aquí.
- Si quiere pagar en efectivo. :: No se habla del pago.
R Har du kvittot?
+ ¿Tienes el recibo? :: «Kvitto» significa recibo.
- ¿Tienes otra talla? :: «Storlek» significa talla.
- ¿Tienes el dinero? :: «Pengar» significa dinero.
H Vill du få pengarna ___?
+ tillbaka :: «Tillbaka» significa de vuelta.
- tillsammans :: «Tillsammans» significa juntos.
- billigare :: «Billigare» significa más barato.
O Jag skulle vilja byta den här tröjan :: Quisiera cambiar este jersey :: Fórmula cortés para expresar lo que quieres.
X Escribe en sueco: «¿Tienes el recibo?» :: Har du kvittot
