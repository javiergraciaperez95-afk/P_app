@ 17 | På stationen | En la estación
I Pregunta por una salida, un andén y la duración del viaje.
E Horarios :: **När går tåget?** pregunta a qué hora sale el tren. **Hur lång tid tar det?** pregunta cuánto tarda.
W ett tåg = un tren
W en avgång = una salida
W ett spår = una vía, un andén
W går = sale, va
W direkt = directo
W en resa = un viaje
W en timme = una hora
W tar = tarda, toma
W en försening = un retraso
W Resan = el viaje
W spår = andén, vía
V Tågresan
D Vid informationen
Resenär: När går tåget till Malmö? = ¿A qué hora sale el tren a Malmö?
Personal: Det går klockan tio från spår tre. = Sale a las diez del andén tres.
Resenär: Går det direkt? = ¿Va directo?
Personal: Ja, resan tar en timme. = Sí, el viaje dura una hora.
Q ¿A qué hora sale el tren?
+ A las diez. :: El empleado dice «klockan tio».
- A las tres. :: Tres es el andén.
- A las once. :: No se menciona las once.
Q ¿Cuánto dura el viaje?
+ Una hora. :: «En timme» significa una hora.
- Tres horas. :: No es la duración indicada.
- Diez minutos. :: No es la duración indicada.
R Det går från spår tre.
+ Sale del andén tres. :: «Spår» puede referirse al andén o la vía.
- El tren llega a las tres. :: «Klockan tre» sería a las tres.
- El viaje dura tres horas. :: No dice la duración.
H Tåget går klockan ___ .
+ tio :: «Tio» significa diez.
- tre :: «Tre» significa tres.
- ett :: «Ett» significa uno.
O Resan tar en timme :: El viaje dura una hora :: «Tar» expresa duración en esta pregunta.
X Escribe en sueco: «¿Va directo?» :: Går det direkt

@ 17 | Boka ett rum | Reservar una habitación
I Reserva una habitación para unas fechas y confirma el precio.
E Reservar :: **Jag skulle vilja boka…** es una forma cortés de reservar. **Per natt** significa por noche.
W boka ett rum = reservar una habitación
W ett enkelrum = una habitación individual
W ett dubbelrum = una habitación doble
W per natt = por noche
W ingår = está incluido
W från den tredje = desde el día tres
W till den femte = hasta el día cinco
W datum = fechas
W juni = junio
W vilka = cuáles
W åttahundra = ochocientos
V Ett hotellrum
D Ett telefonsamtal
Kund: Jag skulle vilja boka ett dubbelrum. = Quisiera reservar una habitación doble.
Receptionist: För vilka datum? = ¿Para qué fechas?
Kund: Från den tredje till den femte juni. = Del tres al cinco de junio.
Receptionist: Rummet kostar åttahundra kronor per natt. Frukost ingår. = La habitación cuesta ochocientas coronas por noche. El desayuno está incluido.
Q ¿Qué tipo de habitación reserva?
+ Una habitación doble. :: Dice «ett dubbelrum».
- Una habitación individual. :: «Enkelrum» significa individual.
- Dos habitaciones individuales. :: No pide dos.
Q ¿Está incluido el desayuno?
+ Sí. :: «Frukost ingår» significa que está incluido.
- No, cuesta aparte. :: No se indica un coste adicional.
- No lo sabe la recepcionista. :: La recepcionista lo confirma.
R Rummet kostar åttahundra kronor per natt.
+ La habitación cuesta ochocientas coronas por noche. :: «Per natt» significa por noche.
- La habitación cuesta trescientas coronas por día. :: No dice ese precio.
- El desayuno cuesta ochocientas coronas. :: Ese precio es de la habitación.
H Frukost ___ .
+ ingår :: «Ingår» significa está incluido.
- börjar :: «Börjar» significa empieza.
- stänger :: «Stänger» significa cierra.
O Jag skulle vilja boka ett dubbelrum :: Quisiera reservar una habitación doble :: Petición cortés para hacer una reserva.
X Escribe en sueco: «¿Para qué fechas?» :: För vilka datum

@ 17 | Ett problem på resan | Un problema durante el viaje
I Explica que has perdido algo y pide ayuda en un lugar público.
E Pedir ayuda :: **Jag har tappat bort…** significa «He perdido…». **Kan du hjälpa mig att…?** pide ayuda para hacer algo.
W tappa bort = perder
W ett bagage = un equipaje
W en väska = un bolso, una bolsa
W ett pass = un pasaporte
W en biljett = un billete
W en polis = un policía
W hittegods = objetos perdidos
W bort = perdido, fuera
W kontaktar = contacta, contactar
W senast = por última vez
W såg = vio, vi
W tappat = perdido
W väska = bolso, bolsa
V På flygplatsen
D Vid servicedisken
Resenär: Jag har tappat bort min väska. = He perdido mi bolso.
Personal: När såg du den senast? = ¿Cuándo lo viste por última vez?
Resenär: På tåget. Här är min biljett. = En el tren. Aquí está mi billete.
Personal: Vi kontaktar hittegods. = Nos pondremos en contacto con objetos perdidos.
Q ¿Qué ha perdido la persona?
+ Su bolso. :: Dice «min väska».
- Su pasaporte. :: No dice que haya perdido el pasaporte.
- Su billete. :: Muestra el billete.
Q ¿Dónde vio el bolso por última vez?
+ En el tren. :: Responde «På tåget».
- En el hotel. :: No lo menciona.
- En la estación. :: No es lo que responde.
R Här är min biljett.
+ Aquí está mi billete. :: «Här är» significa aquí está.
- He perdido mi billete. :: «Tappat bort» significa perdido.
- ¿Dónde está mi pasaporte? :: No es la frase.
H Vi kontaktar ___ .
+ hittegods :: «Hittegods» significa objetos perdidos.
- hotellet :: «Hotellet» significa el hotel.
- läkaren :: «Läkaren» significa el médico.
O Jag har tappat bort min väska :: He perdido mi bolso :: «Har tappat bort» comunica que falta algo.
X Escribe en sueco: «¿Cuándo lo viste por última vez?» :: När såg du den senast
