@ 12 | På restaurang | En el restaurante
I Pide una mesa y pregunta por el menú de forma amable.
E En una mesa :: **Skulle jag kunna få…?** es una petición cortés. **Vad rekommenderar du?** pregunta qué recomienda la otra persona.
W en meny = un menú
W ett bord = una mesa
W skulle jag kunna få = ¿podría pedir?
W rekommenderar = recomienda
W en servitör = un camarero
W en servitris = una camarera
W en rätt = un plato
W gärna = con gusto
W till = para, de acompañamiento
W Dagens = del día
W följ = sigue, acompaña
W för = para
W god = rico, buena
W menyn = el menú
V På restaurangen
D Vid bordet
Kund: Hej, har ni ett bord för två? = Hola, ¿tienen una mesa para dos?
Servitör: Ja, följ med här. Vill ni se menyn? = Sí, vengan conmigo. ¿Quieren ver el menú?
Kund: Ja tack. Vad rekommenderar du? = Sí, gracias. ¿Qué recomienda?
Servitör: Dagens fisk är mycket god. = El pescado del día está muy rico.
Q ¿Qué pide el cliente al principio?
+ Una mesa para dos. :: Pregunta por «ett bord för två».
- La cuenta. :: La cuenta es «notan».
- Una mesa para cuatro. :: Dice «för två», para dos.
Q ¿Qué recomienda el camarero?
+ El pescado del día. :: Recomienda «dagens fisk».
- La sopa de verduras. :: No aparece en el diálogo.
- El postre de chocolate. :: No aparece en el diálogo.
R Vad rekommenderar du?
+ ¿Qué recomienda? :: Es una manera de pedir una recomendación.
- ¿Dónde está la mesa? :: «Var» pregunta dónde.
- ¿Cuánto cuesta el pescado? :: «Hur mycket» pregunta cuánto.
H Skulle jag kunna få en ___ för två?
+ meny :: «Meny» significa menú.
- nyckel :: «Nyckel» significa llave.
- biljett :: «Biljett» significa billete o entrada.
O Har ni ett bord för två :: ¿Tienen una mesa para dos? :: «Har ni» pregunta si tienen algo.
X Escribe en sueco: «¿Qué recomienda?» :: Vad rekommenderar du

@ 12 | Beställa mat | Pedir comida
I Elige un plato, pregunta por una opción vegetariana y comenta una preferencia.
E Pedir y elegir :: **Jag tar…** significa «Tomaré…». Para preguntar si un plato contiene algo, di **Innehåller den…?**.
W jag tar = tomaré
W vegetarisk = vegetariano, vegetariana
W innehåller = contiene
W grönsaker = verduras
W stark = picante
W utan = sin
W en soppa = una sopa
W soppan = la sopa
V Välja en rätt
D En vegetarisk rätt
Nina: Jag tar gärna en soppa. = Tomaré una sopa, por favor.
Servitör: Vill du ha bröd till? = ¿Quieres pan de acompañamiento?
Nina: Tack, men innehåller soppan kött? = Gracias, pero ¿la sopa contiene carne?
Servitör: Nej, den är vegetarisk och har grönsaker. = No, es vegetariana y lleva verduras.
Q ¿Qué quiere Nina?
+ Una sopa. :: Dice «Jag tar gärna en soppa».
- Pollo con arroz. :: No lo pide.
- Una ensalada picante. :: No aparece en el diálogo.
Q ¿La sopa contiene carne?
+ No, es vegetariana. :: El camarero dice que no y que lleva verduras.
- Sí, lleva pollo. :: Dice que no contiene carne.
- No lo sabe. :: El camarero responde claramente.
R Innehåller soppan kött?
+ ¿La sopa contiene carne? :: «Innehåller» significa contiene.
- ¿La sopa está caliente? :: «Varm» significa caliente.
- ¿La sopa está lista? :: «Klar» significa lista.
H Den är vegetarisk och har ___ .
+ grönsaker :: «Grönsaker» significa verduras.
- kyckling :: «Kyckling» significa pollo.
- kött :: «Kött» significa carne.
O Jag tar gärna en soppa :: Tomaré una sopa, por favor :: «Jag tar» sirve para pedir.
X Escribe en sueco: «¿Contiene carne?» :: Innehåller den kött

@ 12 | Betala notan | Pagar la cuenta
I Pide la cuenta, pregunta por el pago con tarjeta y revisa una cuenta sencilla.
E Pagar :: **Notan, tack** significa «La cuenta, por favor». **Kan jag betala med kort?** pregunta si puedes pagar con tarjeta.
W en nota = una cuenta
W med kort = con tarjeta
W en dricks = una propina
W var = cada uno
W stämmer = es correcto
W blir = llegaré, se vuelve
W Notan = la cuenta
W tvåhundra = doscientos
V Betalning
D När lunchen är slut
Nina: Notan, tack. Kan jag betala med kort? = La cuenta, por favor. ¿Puedo pagar con tarjeta?
Servitör: Ja, självklart. = Sí, por supuesto.
Nina: Vi betalar tillsammans. = Pagamos juntos.
Servitör: Det blir tvåhundra kronor. = Son doscientas coronas.
Q ¿Cómo quiere pagar Nina?
+ Con tarjeta. :: Pregunta si puede pagar con tarjeta.
- En efectivo. :: «Kontant» significa en efectivo.
- Cada uno por separado. :: Dice que pagan juntos.
Q ¿Cuánto cuesta la comida?
+ Doscientas coronas. :: El camarero dice «tvåhundra kronor».
- Cien coronas. :: No es la cantidad indicada.
- Veinte coronas. :: No es la cantidad indicada.
R Vi betalar tillsammans.
+ Pagamos juntos. :: «Tillsammans» significa juntos.
- Pagamos cada uno por separado. :: «Var» puede significar cada uno.
- Pagamos en efectivo. :: «Kontant» significa en efectivo.
H Kan jag betala med ___?
+ kort :: «Kort» es tarjeta en esta expresión.
- bröd :: «Bröd» significa pan.
- bord :: «Bord» significa mesa.
O Notan, tack :: La cuenta, por favor :: Petición breve y cortés.
X Escribe en sueco: «Pagamos juntos» :: Vi betalar tillsammans
