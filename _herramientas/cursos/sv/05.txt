@ 5 | Vad tycker du om? | Hablar de comida y gustos
I Aprende nombres de comidas y a decir qué te gusta. **Tycker om** significa gustar.
E Gustos :: **Jag tycker om kaffe** significa «Me gusta el café». :: Para decir que no te gusta algo: **Jag tycker inte om…**. El verbo no cambia con la persona.
W mat = comida | mat
W bröd = pan | bröd
W ost = queso | ust
W smör = mantequilla | smör
W mjölk = leche | myölk
W vatten = agua | VAT-en
W kaffe = café | KA-fe
W te = té | te
W ägg = huevo | eg
W frukt = fruta | frukt
W äpple = manzana | É-ple
W banan = plátano | ba-NAN
W gillar = gusta, le gusta | YIL-ar
W hungrig = hambriento, con hambre | HUN-grig
W med = con | med
W dricker = bebe, bebo | DRIK-er
W äpplen = manzanas | É-plen
V Comida y gustos
D Frukost
Sofia: Vad tycker du om till frukost? = ¿Qué te gusta desayunar?
Johan: Jag tycker om bröd med ost. = Me gusta el pan con queso.
Sofia: Dricker du kaffe? = ¿Bebes café?
Johan: Nej, jag dricker te. Jag gillar också äpplen. = No, bebo té. También me gustan las manzanas.
Q ¿Qué significa «bröd»?
+ Pan. :: «Bröd» es pan.
- Queso. :: Queso es «ost».
- Leche. :: Leche es «mjölk».
Q ¿Qué significa «hungrig»?
+ Tener hambre. :: «Hungrig» expresa tener hambre.
- Tener sed. :: «Törstig» es tener sed.
- Cansado. :: «Trött» significa cansado.
Q ¿Cómo se dice «me gusta el café»?
+ Jag tycker om kaffe. :: «Tycker om» expresa gustar.
- Jag kommer från kaffe. :: «Kommer från» expresa procedencia.
- Jag heter kaffe. :: «Heter» expresa el nombre.
R Jag gillar också äpplen.
+ También me gustan las manzanas. :: «Också» significa también.
- No me gustan las manzanas. :: «Inte» niega la frase.
- Bebo un té con manzana. :: Beber es «dricker».
H Jag tycker ___ om te.
+ inte :: «Inte» convierte la frase en negativa.
- mycket :: «Mycket» significa mucho.
- varifrån :: «Varifrån» significa de dónde.
A Jag tycker om bröd med ost.
+ Me gusta el pan con queso. :: «Med» significa con.
- Quiero pan y leche. :: «Vill ha» significa quiero.
- No como queso. :: «Äter inte ost» significa no como queso.
O bröd med ost :: pan con queso :: «Med» une los alimentos.
X Escribe en sueco: «Me gusta el té» :: Jag tycker om te

@ 5 | På kaféet | Pedir en una cafetería
I En una cafetería puedes saludar, pedir algo con **jag vill ha** y dar las gracias.
E Pedir con cortesía :: **Jag vill ha en kaffe, tack** significa «Quiero un café, por favor». :: **Kan jag få…?** es una forma amable de pedir: «¿Me puede dar…?».
W vill = quiere; quiero | vil
W ha = tener | ha
W vill ha = quiere; quiero | vil ha
W kan = puede; puedo | kan
W få = recibir, obtener | fo
W kopp = taza | kop
W juice = zumo | yus
W smörgås = bocadillo, sándwich abierto | SMÖR-gos
W meny = menú | me-NÜ
W socker = azúcar | SOK-er
W nota = cuenta | NU-ta
W betala = pagar | be-TÁ-la
W kan jag få = me puede dar | kan ya fo
W en kopp kaffe = una taza de café | en kop KA-fe
W självklart = claro, por supuesto | shelv-KLART
W teet = el té | te-et
W varsågod = aquí tiene; de nada | var-so-GUD
W betalar = paga, pago | be-TÁ-lar
W här = aquí | her
W kafé = cafetería | ka-FÉ
W kaféet = la cafetería | ka-FÉ-et
V En fika
D På kaféet
Ali: Hej! Kan jag få en kopp te och en smörgås? = ¡Hola! ¿Me puede dar una taza de té y un bocadillo?
Kim: Självklart. Vill du ha mjölk i teet? = Claro. ¿Quieres leche en el té?
Ali: Nej tack, men lite socker. = No, gracias, pero un poco de azúcar.
Kim: Varsågod. Betalar du här? = Aquí tienes. ¿Pagas aquí?
Ali: Ja, tack. = Sí, gracias.
Q ¿Qué significa «meny»?
+ Menú. :: «Meny» es menú.
- Cuenta. :: La cuenta es «nota».
- Taza. :: Taza es «kopp».
Q ¿Cómo pides algo con cortesía?
+ Kan jag få…? :: Significa «¿Me puede dar…?».
- Var bor du? :: Pregunta dónde vives.
- Vad heter du? :: Pregunta el nombre.
Q ¿Qué significa «betala»?
+ Pagar. :: «Betala» significa pagar.
- Beber. :: Beber es «dricka».
- Comer. :: Comer es «äta».
R Kan jag få en kopp te?
+ ¿Me puede dar una taza de té? :: Fórmula amable para pedir.
- ¿Puedo pagar con tarjeta? :: Tarjeta es «kort».
- ¿Quieres una taza de té? :: «Vill du ha…?» pregunta qué quieres.
H Jag vill ___ en smörgås.
+ ha :: «Vill ha» significa querer algo.
- är :: «Är» significa ser o estar.
- bor :: «Bor» significa vivir.
A Vill du ha mjölk i teet?
+ ¿Quieres leche en el té? :: «Vill du ha» significa quieres.
- ¿Te gusta el café? :: «Tycker du om kaffe?».
- ¿Dónde está la leche? :: «Var är mjölken?».
O en kopp kaffe :: una taza de café :: «En kopp» significa una taza.
X Escribe en sueco: «Quiero una taza de té» :: Jag vill ha en kopp te

@ 5 | I mataffären | Comprar alimentos
I En una tienda puedes preguntar el precio, pedir una cantidad y decir qué necesitas.
E Precio y cantidad :: **Hur mycket kostar det?** significa «¿Cuánto cuesta?». :: **Jag behöver…** significa «Necesito…». Para pedir algo: **Jag skulle vilja ha…** (Quisiera…).
W mataffär = supermercado, tienda de alimentos | MAT-a-fer
W kostar = cuesta | KOS-tar
W hur mycket = cuánto | hur MÜ-ket
W behöver = necesita, necesito | be-HÖ-ver
W potatis = patata | po-TÁ-tis
W tomat = tomate | to-MAT
W gurka = pepino | GUR-ka
W fisk = pescado | fisk
W kyckling = pollo | SHÜK-ling
W kött = carne | shöt
W kilo = kilo | KÍ-lo
W liter = litro | LÍ-ter
W billig = barato, barata | BIL-ig
W dyr = caro, cara | dür
W handla = hacer la compra | HAN-dla
W hur mycket kostar det = cuánto cuesta | hur MÜ-ket KOS-tar de
W ursäkta = perdone, disculpa | ur-SHEK-ta
W potatisen = las patatas | po-TÁ-tis-en
W kronor = coronas (moneda sueca) | KRÚ-nor
W kilot = el kilo (forma definida) | KÍ-lot
W tomater = tomates | to-MÁ-ter
W något = algo | NO-got
W mer = más | mer
V En inköpslista
D I mataffären
Emma: Ursäkta, hur mycket kostar potatisen? = Perdone, ¿cuánto cuestan las patatas?
Nils: Tio kronor kilot. = Diez coronas el kilo.
Emma: Jag behöver ett kilo och två tomater. = Necesito un kilo y dos tomates.
Nils: Varsågod. Något mer? = Aquí tiene. ¿Algo más?
Emma: Nej tack, det är bra. = No, gracias, está bien.
Q ¿Qué significa «billig»?
+ Barato, barata. :: «Billig» significa barato.
- Caro, cara. :: Caro es «dyr».
- Fresco, fresca. :: Fresco es «färsk».
Q ¿Cómo se pregunta «¿Cuánto cuesta?»?
+ Hur mycket kostar det? :: Es la pregunta por el precio.
- Vad heter det? :: Pregunta cómo se llama.
- Var finns det? :: Pregunta dónde está.
Q ¿Qué significa «potatis»?
+ Patata. :: «Potatis» es patata.
- Tomate. :: Tomate es «tomat».
- Pepino. :: Pepino es «gurka».
R Jag behöver ett kilo.
+ Necesito un kilo. :: «Behöver» significa necesitar.
- Quiero un litro. :: Litro es «liter».
- Tengo un kilo. :: «Har» significa tener.
H Jag ___ ett kilo potatis.
+ behöver :: «Behöver» significa necesito.
- kostar :: «Kostar» significa cuesta.
- handla :: «Handla» significa hacer la compra.
A Tio kronor kilot.
+ Diez coronas el kilo. :: «Kronor» es coronas y «kilo» kilo.
- Diez litros de leche. :: Litro es «liter» y leche es «mjölk».
- Diez patatas. :: «Potatis» es patata.
O Jag behöver två tomater :: Necesito dos tomates :: «Behöver» expresa necesidad.
X Escribe en sueco: «Necesito un kilo de patatas» :: Jag behöver ett kilo potatis
