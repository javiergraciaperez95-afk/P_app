@ 18 | Årstider och väder | Estaciones y tiempo
I Describe el tiempo y relaciona una estación con una actividad.
E El clima :: Para el clima se usa **det är**: **Det är soligt** (Hace sol), **Det är kallt** (Hace frío). **På vintern** significa en invierno.
W en årstid = una estación del año
W vår = primavera
W höst = otoño
W våren = la primavera
V Väderrapport
D Väder i april
Mira: Hur är vädret i dag? = ¿Qué tiempo hace hoy?
Jonas: Det är molnigt, men det regnar inte. = Está nublado, pero no llueve.
Mira: Vad tycker du om våren? = ¿Qué te parece la primavera?
Jonas: Jag tycker om våren. Då promenerar jag gärna. = Me gusta la primavera. Entonces me gusta pasear.
Q ¿Qué tiempo hace hoy?
+ Está nublado y no llueve. :: Jonas dice «molnigt» y «regnar inte».
- Hace sol y mucho viento. :: No lo dice.
- Nieva y hace frío. :: No lo menciona.
Q ¿Qué le gusta hacer a Jonas en primavera?
+ Pasear. :: Dice «promenerar».
- Nadar. :: No se menciona nadar.
- Quedarse en casa. :: No aparece esa actividad.
R Jag tycker om våren.
+ Me gusta la primavera. :: «Tycker om» significa gustar.
- Me gusta el otoño. :: «Höst» significa otoño.
- Hace buen tiempo en verano. :: No es la frase.
H Det är ___, men det regnar inte.
+ molnigt :: «Molnigt» significa nublado.
- soligt :: «Soligt» significa soleado.
- varmt :: «Varmt» significa cálido.
O Det är molnigt i dag :: Hoy está nublado :: «Det är» se usa para describir el tiempo.

@ 18 | Vad ska vi göra? | ¿Qué vamos a hacer?
I Propón un plan para el fin de semana y responde si puedes participar.
E Planes futuros :: **Ska** expresa un plan: **Vi ska bada** (Vamos a bañarnos). **Om det regnar** significa si llueve.
W ska = va a, vamos a
W bada = bañarse, nadar
W en strand = una playa
W en picknick = un pícnic
W om = si
W en filt = una manta
W packa = preparar, empacar
W ta med = llevar consigo
W picknick = pícnic
W stranden = la playa
V En helgplan
D På fredag
Mira: Vad ska vi göra på lördag? = ¿Qué vamos a hacer el sábado?
Jonas: Vi ska ha picknick vid stranden. = Vamos a hacer un pícnic en la playa.
Mira: Bra! Jag tar med en filt. = ¡Bien! Llevaré una manta.
Jonas: Och om det regnar kan vi gå på museum. = Y si llueve, podemos ir a un museo.
Q ¿Qué plan tienen para el sábado?
+ Hacer un pícnic en la playa. :: Jonas propone «picknick vid stranden».
- Ir de compras al centro. :: No lo propone.
- Visitar a un médico. :: No lo menciona.
Q ¿Qué hará Mira?
+ Llevará una manta. :: Dice «Jag tar med en filt».
- Llevará comida al museo. :: No lo dice.
- Preparará las entradas. :: No se menciona.
R Om det regnar kan vi gå på museum.
+ Si llueve, podemos ir a un museo. :: «Om» significa si.
- Si hace sol, iremos a la playa. :: No es lo que dice.
- Vamos a nadar cuando llueva. :: No aparece esa idea.
H Vi ska ha ___ vid stranden.
+ picknick :: «Picknick» se usa igual que pícnic.
- lektion :: «Lektion» significa lección.
- möte :: «Möte» significa reunión.
O Jag tar med en filt :: Llevaré una manta :: El presente puede expresar un plan futuro cercano.
X Escribe en sueco: «¿Qué vamos a hacer el sábado?» :: Vad ska vi göra på lördag

@ 18 | Mina intressen | Mis intereses
I Explica qué actividad prefieres y por qué.
E Preferencias :: **Jag tycker bättre om…** significa «Me gusta más…». **Eftersom** significa «porque» y enlaza una razón.
W ett intresse = un interés
W bättre = mejor, más
W eftersom = porque
W en film = una película
W hellre = más bien, preferiblemente
W spännande = emocionante
W glad = contento, feliz
W lyssna = escuchar
W lyssnar = escucha, escucho
W Varför = por qué
V Fritidsintressen
D En kväll hemma
Nora: Vill du se en film eller lyssna på musik? = ¿Quieres ver una película o escuchar música?
Leo: Jag lyssnar hellre på musik. = Prefiero escuchar música.
Nora: Varför? = ¿Por qué?
Leo: Eftersom musik gör mig glad. = Porque la música me pone contento.
Q ¿Qué prefiere Leo?
+ Escuchar música. :: Dice «Jag lyssnar hellre på musik».
- Ver una película. :: Nora lo propone, pero Leo prefiere música.
- Leer una novela. :: No se menciona leer.
Q ¿Por qué le gusta la música a Leo?
+ Porque le pone contento. :: Dice que la música lo hace feliz.
- Porque es emocionante. :: No usa «spännande».
- Porque es nueva. :: No lo dice.
R Jag lyssnar hellre på musik.
+ Prefiero escuchar música. :: «Hellre» marca una preferencia.
- Me gusta más ver películas. :: No es su respuesta.
- Escucho música todos los días. :: No habla de frecuencia.
H ___ musik gör mig glad.
+ Eftersom :: Introduce la razón: porque la música me alegra.
- Men :: «Men» significa pero.
- Därför :: «Därför» significa por eso.
O Musik gör mig glad :: La música me pone contento :: «Gör mig glad» significa me hace feliz.
X Escribe en sueco: «Prefiero escuchar música» :: Jag lyssnar hellre på musik
