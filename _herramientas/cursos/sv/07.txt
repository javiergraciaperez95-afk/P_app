@ 7 | Var finns biblioteket? | Preguntar por lugares
I En una ciudad, puedes preguntar **Var finns…?** (¿Dónde está…?) o **Var ligger…?** (¿Dónde se encuentra…?).
E Lugares :: **Finns** pregunta si algo existe o está disponible; **ligger** se usa para la ubicación de lugares. :: **Ursäkta** sirve para llamar la atención con educación: «Perdone».
W torg = plaza | torg
W station = estación | sta-SHUN
W bibliotek = biblioteca | bi-bli-o-TEK
W apotek = farmacia | a-po-TEK
W skola = escuela | SKU-la
W park = parque | park
W restaurang = restaurante | res-tau-RANG
W toalett = baño, aseo | tu-a-LET
W ligger = está situado | LIG-er
W långt = lejos | longt
W var finns = dónde hay | var fins
W var ligger = dónde está situado | var LIG-er
W nära = cerca | NÉ-ra
W biblioteket = la biblioteca | bi-bli-o-TEK-et
W torget = la plaza | TOR-get
W skolan = la escuela | SKU-lan
W apoteket = la farmacia | a-po-TEK-et
W härifrån = de aquí | HER-i-fron
W stationen = la estación | sta-SHUN-en
V Lugares de la ciudad
D I centrum
Omar: Ursäkta, var ligger biblioteket? = Perdone, ¿dónde está la biblioteca?
Eva: Det ligger nära torget, bredvid skolan. = Está cerca de la plaza, al lado de la escuela.
Omar: Är apoteket långt härifrån? = ¿Está lejos la farmacia de aquí?
Eva: Nej, det ligger nära stationen. = No, está cerca de la estación.
Q ¿Qué significa «bibliotek»?
+ Biblioteca. :: «Bibliotek» significa biblioteca.
- Librería. :: Librería es «bokhandel».
- Escuela. :: Escuela es «skola».
Q ¿Qué significa «nära»?
+ Cerca. :: «Nära» significa cerca.
- Lejos. :: «Långt» significa lejos.
- Al lado. :: «Bredvid» significa al lado.
Q ¿Cómo se dice «Perdone»?
+ Ursäkta. :: «Ursäkta» es una forma cortés para llamar la atención.
- Varsågod. :: «Varsågod» se dice al dar algo.
- Hej då. :: «Hej då» es adiós.
R Det ligger nära torget.
+ Está cerca de la plaza. :: «Ligger» indica dónde está un lugar.
- Está lejos de la plaza. :: «Långt» significa lejos.
- Hay una plaza cerca. :: «Finns» expresa que hay algo.
H Var ligger ___?
+ biblioteket :: «Biblioteket» es la biblioteca.
- tack :: «Tack» significa gracias.
- måndag :: «Måndag» es lunes.
A Är apoteket långt härifrån?
+ ¿Está lejos la farmacia de aquí? :: «Härifrån» significa de aquí.
- ¿Está abierta la farmacia hoy? :: Abierta es «öppet».
- ¿Dónde está la biblioteca? :: «Var ligger biblioteket?».
O biblioteket ligger nära stationen :: la biblioteca está cerca de la estación :: «Nära» significa cerca.
X Escribe en sueco: «¿Dónde está la estación?» :: Var ligger stationen?

@ 7 | Buss och tåg | Viajar en transporte público
I Aprende a nombrar algunos transportes, preguntar por un billete y comprender una hora de salida.
E Transporte :: **Jag åker buss** significa «Voy en autobús». Para preguntar por un billete: **En biljett till… tack**. :: **Nästa** significa próximo; **avgår** significa sale.
W buss = autobús | bus
W tåg = tren | tog
W spårvagn = tranvía | spor-vagn
W bil = coche | bil
W biljett = billete | bi-YET
W hållplats = parada | HOL-plats
W åker = va en; viaja | Ó-ker
W nästa = siguiente, próximo | NEK-sta
W avgår = sale (un transporte) | AV-gor
W plattform = andén | PLAT-form
W enkel = sencillo, solo ida | EN-kel
W tur och retur = ida y vuelta | tur o re-TUR
W en biljett till = un billete a | en bi-YET til
W minuter = minutos | mi-NU-ter
W försenad = retrasado, retrasada | för-SÉ-nad
W tåget = el tren | TO-get
V Transporte y billetes
D På stationen
Nils: En biljett till Göteborg, tack. = Un billete a Gotemburgo, por favor.
Maja: Enkel eller tur och retur? = ¿Solo ida o ida y vuelta?
Nils: Tur och retur. När avgår tåget? = Ida y vuelta. ¿Cuándo sale el tren?
Maja: Tåget avgår från plattform två om tio minuter. = El tren sale del andén dos dentro de diez minutos.
Q ¿Qué significa «hållplats»?
+ Parada. :: «Hållplats» es la parada del autobús o tranvía.
- Andén. :: Andén es «plattform».
- Billete. :: Billete es «biljett».
Q ¿Qué es «ett tåg»?
+ Un tren. :: «Tåg» significa tren.
- Un autobús. :: Autobús es «buss».
- Un coche. :: Coche es «bil».
Q ¿Qué significa «nästa»?
+ Siguiente, próximo. :: «Nästa» significa siguiente.
- Retrasado. :: «Försenad» significa retrasado.
- Sencillo. :: «Enkel» significa sencillo o solo ida.
R När avgår tåget?
+ ¿Cuándo sale el tren? :: «Avgår» pregunta por la salida.
- ¿Dónde está el tren? :: «Var är tåget?».
- ¿Cuánto cuesta el billete? :: «Vad kostar biljetten?».
H En biljett ___ Stockholm, tack.
+ till :: «Till» indica destino.
- från :: «Från» indica procedencia.
- bredvid :: «Bredvid» significa al lado de.
A Tåget avgår från plattform två.
+ El tren sale del andén dos. :: «Plattform» es andén.
- El tren llega en dos horas. :: Llegar es «kommer fram».
- El autobús sale de la parada dos. :: Autobús es «buss».
O en biljett tur och retur :: un billete de ida y vuelta :: «Tur och retur» significa ida y vuelta.
X Escribe en sueco: «Un billete a Göteborg, por favor» :: En biljett till Göteborg, tack

@ 7 | Hur kommer jag dit? | Entender indicaciones
I Si no conoces el camino, pide ayuda. Lee expresiones cortas y sigue las indicaciones paso a paso.
E Direcciones :: **Gå rakt fram** significa «Siga recto». :: **Till höger** es a la derecha y **till vänster** a la izquierda. **Sväng** significa girar.
W höger = derecha | HÖ-ger
W vänster = izquierda | VEN-ster
W rakt fram = todo recto | rakt fram
W sväng = gira, gire | sveng
W första = primero, primera | FÖR-sta
W andra = segundo, segunda | AN-dra
W korsning = cruce | KOR-shning
W gå = ir a pie; andar | go
W gå rakt fram = siga recto | go rakt fram
W till höger = a la derecha | til HÖ-ger
W till vänster = a la izquierda | til VEN-ster
W där = allí | der
W vid = en, junto a | vid
W efter = después de | EF-ter
W korsningen = el cruce | KOR-shning-en
V Seguir indicaciones
D På gatan
Ali: Ursäkta, hur kommer jag till stationen? = Perdone, ¿cómo llego a la estación?
Sofia: Gå rakt fram och sväng till vänster vid torget. = Siga recto y gire a la izquierda en la plaza.
Ali: Är stationen nära? = ¿Está cerca la estación?
Sofia: Ja. Gå till höger efter den första korsningen. = Sí. Vaya a la derecha después del primer cruce.
Q ¿Qué significa «höger»?
+ Derecha. :: «Till höger» es a la derecha.
- Izquierda. :: «Till vänster» es a la izquierda.
- Recto. :: «Rakt fram» es recto.
Q ¿Qué significa «gå»?
+ Ir a pie, andar. :: «Gå» significa andar o ir caminando.
- Girar. :: «Sväng» significa girar.
- Llegar. :: «Komma fram» significa llegar.
Q ¿Qué significa «första»?
+ Primero, primera. :: «Första» significa primero.
- Segundo, segunda. :: «Andra» significa segundo.
- Siguiente. :: «Nästa» significa siguiente.
R Gå rakt fram och sväng till vänster.
+ Siga recto y gire a la izquierda. :: Son dos instrucciones para llegar a un lugar.
- Vaya a la derecha y pare. :: «Höger» es derecha.
- Gire a la izquierda en la estación. :: «Vid stationen» es en la estación.
H Sväng till ___ vid torget.
+ vänster :: «Till vänster» significa a la izquierda.
- morgon :: «Morgon» es mañana.
- långt :: «Långt» significa lejos.
A Gå till höger efter den första korsningen.
+ Vaya a la derecha después del primer cruce. :: «Efter» es después.
- Gire a la izquierda antes de la plaza. :: «Vänster» es izquierda.
- Siga recto hasta la estación. :: «Rakt fram» es recto.
O gå rakt fram och sväng :: siga recto y gire :: «Och» enlaza dos instrucciones.
X Escribe en sueco: «A la derecha» :: till höger
