@ 1 | Hej! | Saludar y despedirse
I En sueco, **hej** sirve para saludar a cualquier hora. Lee el saludo, practica la respuesta y despídete con cortesía.
E Saludos :: **Hej!** significa «¡hola!». Para despedirte puedes decir **hej då**. :: **Tack** significa «gracias». **Tack så mycket** es «muchas gracias».
W hej = hola | yey
W då = entonces; en «hej då», adiós | do
W tack = gracias; por favor al pedir | tak
W så = tan, así | so
W mycket = mucho | MÜ-ket
W god morgon = buenos días (por la mañana) | gud MÓR-gon
W god kväll = buenas tardes, buenas noches (al llegar) | gud kvel
W ja = sí | ya
W nej = no | ney
W och = y | o
W bra = bien | bra
W jag = yo | ya | La g final casi no se oye.
W hur = cómo | hur
W mår = te encuentras | mor
W du = tú, usted | du
W tack så mycket = muchas gracias | tak so MÜ-ket
W på = en, sobre | po
W kursen = el curso | KUR-sen
V Saludos y cortesía
D På kursen
Anna: Hej, Erik! = ¡Hola, Erik!
Erik: Hej, Anna! Hur mår du? = ¡Hola, Anna! ¿Qué tal estás?
Anna: Jag mår bra, tack. Och du? = Estoy bien, gracias. ¿Y tú?
Erik: Bra, tack så mycket. Hej då! = Bien, muchas gracias. ¡Adiós!
Anna: Hej då! = ¡Adiós!
Q ¿Qué significa «Hej»?
+ Hola. :: Es el saludo sueco más común.
- Gracias. :: Gracias es «tack».
- Adiós. :: Para despedirse: «hej då».
Q ¿Qué dices al despedirte?
+ Hej då. :: «Då» completa la despedida «hej då».
- God morgon. :: Es un saludo de la mañana.
- Hur mår du? :: Pregunta qué tal está alguien.
Q ¿Cómo se dice «gracias»?
+ Tack. :: «Tack» significa gracias.
- Nej. :: «Nej» significa no.
- Mycket. :: «Mycket» significa mucho.
R Hur mår du?
+ ¿Qué tal estás? :: «Hur» es cómo y «mår» expresa encontrarse.
- ¿Dónde estás? :: «Var» es dónde.
- ¿Cómo te llamas? :: «Vad heter du?» pregunta el nombre.
H Jag mår ___, tack.
+ bra :: «Bra» significa bien.
- nej :: «Nej» significa no.
- då :: «Då» aparece en «hej då».
A God morgon.
+ Buenos días. :: Se usa por la mañana.
- Buenas noches (al ir a dormir). :: Para decirlo al acostarse se usa «god natt».
- Hasta luego. :: «Hej då» es adiós.
O Hej då :: Adiós :: Despedida habitual.
X Escribe en sueco: «muchas gracias» :: tack så mycket | tack

@ 1 | Jag heter Anna | Decir cómo te llamas
I Ahora vas a decir tu nombre y preguntar el de otra persona. En sueco, **jag heter** significa «me llamo».
E Preguntar el nombre :: **Vad heter du?** significa «¿cómo te llamas?». :: Para contestar: **Jag heter…** (me llamo…). También puedes decir **Jag är…** (soy…).
W heter = se llama; me llamo | JÉ-ter
W vad = qué; cuál | vad
W är = soy, eres, es, estamos, están | er
W namn = nombre | nam
W mitt = mi (neutro) | mit
W trevligt = agradable; encantado | TRÉV-lit
W att = a; que; marca de infinitivo | at
W träffas = encontrarse | TRÉ-fas
W igen = otra vez | i-YEN
W vem = quién | vem
W jag heter = me llamo | ya JÉ-ter
W vad heter du = cómo te llamas | vad JÉ-ter du
W nya = nuevos, nuevas | NÜ-a
W kursdeltagare = participante del curso | kurs-del-TA-ga-re
W detsamma = igualmente | DE-sa-ma
V Nombres y presentaciones
D Två nya kursdeltagare
Sara: Hej! Jag heter Sara. Vad heter du? = ¡Hola! Me llamo Sara. ¿Cómo te llamas?
Amir: Jag heter Amir. = Me llamo Amir.
Sara: Trevligt att träffas! = ¡Encantada de conocerte!
Amir: Detsamma. = Igualmente.
Q ¿Cómo se pregunta «¿Cómo te llamas?»?
+ Vad heter du? :: Es la pregunta habitual por el nombre.
- Vem är du? :: Pregunta quién eres.
- Vad mår du? :: No es la expresión para preguntar el nombre.
Q Completa: «___ heter Sara».
+ Jag :: «Jag» significa yo.
- Du :: «Du» significa tú.
- Vem :: «Vem» significa quién.
Q ¿Qué significa «namn»?
+ Nombre. :: «Namn» es nombre.
- Número. :: «Nummer» es número.
- País. :: «Land» es país.
R Jag heter Amir.
+ Me llamo Amir. :: «Jag heter» se usa para decir el nombre.
- Tú eres Amir. :: «Du är» sería tú eres.
- ¿Quién es Amir? :: «Vem är Amir?» sería quién es Amir.
H Vad ___ du?
+ heter :: La expresión es «Vad heter du?».
- mår :: «Hur mår du?» pregunta qué tal estás.
- tack :: «Tack» significa gracias.
A Trevligt att träffas!
+ ¡Encantado de conocerte! :: Fórmula amable al conocer a alguien.
- ¡Hasta mañana! :: «Vi ses i morgon» es hasta mañana.
- ¡Muchas gracias! :: Se dice «Tack så mycket».
O Jag heter Anna :: Me llamo Anna :: Presentación del nombre.
X Escribe en sueco: «Me llamo Sara» :: Jag heter Sara

@ 1 | Varifrån kommer du? | Decir de dónde eres
I Aprende a decir de dónde vienes y qué idioma hablas. Para A1 bastan frases breves y datos personales.
E Origen e idioma :: **Varifrån kommer du?** pregunta de dónde vienes. :: **Jag kommer från Spanien** significa «Vengo de España». Para hablar de idiomas: **Jag talar svenska** (hablo sueco).

W kommer = viene; vengo | KO-mer
W från = de, desde | fron
W talar = habla, hablo | TÁ-lar
W svenska = sueco, lengua sueca | SVEN-ska
W spanska = español, lengua española | SPAN-ska
W engelska = inglés, lengua inglesa | ENG-els-ka
W lite = un poco | LÍ-te
W också = también | ÓK-so
W inte = no, no… | IN-te
W land = país | land
W var = dónde | var
W varifrån kommer du = de dónde vienes | va-ri-FRON KO-mer du
W men = pero | men
W bor = vive, vivo | bur
W i = en | i
W Sverige = Suecia | SVE-rie

V Países e idiomas
D I klassrummet
Maria: Hej, jag heter Maria. Varifrån kommer du? = Hola, me llamo Maria. ¿De dónde vienes?
Leo: Jag kommer från Spanien, men jag bor i Sverige nu. = Vengo de España, pero ahora vivo en Suecia.
Maria: Talar du svenska? = ¿Hablas sueco?
Leo: Lite. Jag talar också engelska. = Un poco. También hablo inglés.
Q ¿Qué significa «Varifrån kommer du?»?
+ ¿De dónde vienes? :: «Varifrån» significa de dónde y «kommer» viene.
- ¿Cómo te llamas? :: «Vad heter du?» pregunta el nombre.
- ¿Qué idioma hablas? :: «Vilket språk talar du?» pregunta el idioma.
Q «Jag kommer ___ Spanien».
+ från :: Se dice «komma från» para decir de dónde vienes.
- till :: «Till» significa hacia, a.
- tack :: «Tack» significa gracias.
Q ¿Cómo se dice «un poco»?
+ Lite. :: «Lite» significa un poco.
- Mycket. :: «Mycket» significa mucho.
- Också. :: «Också» significa también.
R Jag talar svenska.
+ Hablo sueco. :: «Talar» es la forma de hablar.
- Vivo en Suecia. :: «Jag bor i Sverige».
- Vengo de Suecia. :: «Jag kommer från Sverige».
H Jag talar ___ engelska.
+ också :: «Också» significa también.
- varifrån :: «Varifrån» significa de dónde.
- land :: «Land» significa país.
A Jag kommer från Spanien.
+ Vengo de España. :: «Från» indica procedencia.
- Vivo en España. :: «Jag bor i Spanien».
- Hablo español. :: «Jag talar spanska».
O Jag talar lite svenska :: Hablo un poco de sueco :: «Lite» expresa una cantidad pequeña.
