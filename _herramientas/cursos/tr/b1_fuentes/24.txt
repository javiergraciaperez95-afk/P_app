Kiracı: Kontratın süresini konuşabilir miyiz? = ¿Podemos hablar de la duración del contrato?

@ 24 | Şehir içi ulaşım | Transporte urbano
I Explica tu rutina de transporte y resuelve un cambio o una devolución de billete.
E Transporte :: **aktarma** = transbordo; **iade** = devolución; **sefer** = servicio/salida. :: **tercih etmek** expresa una elección. :: Las instrucciones de seguridad suelen usar formas impersonales como **kapılar kapanmalıdır** («las puertas deben permanecer cerradas»).
W aktarma = transbordo | ak-tar-MA
W iade = devolución | i-a-DE
W sefer = servicio; salida | se-FER
W yoğunluk = congestión | yo-un-LUK
W kalabalık = abarrotado/a | ka-la-ba-LUH
W gecikme = retraso | ge-jik-ME
w toplu taşıma = transporte público | top-lu ta-shı-MA
w değiştirmek = cambiar | de-ğiş-tir-MEK
w iade etmek = devolver | i-a-de et-MEK
w ücretinde = en la tarifa
w olacak = será
w değişebilir = puede cambiar
w değiştirebiliriz = podemos cambiar

w değiştirebilir = puede cambiar

V Cambiar un billete
D En la taquilla
Yolcu: Otobüsüm gecikti. Biletimi başka bir seferle değiştirebilir miyim? = Mi autobús se retrasó. ¿Puedo cambiar mi billete por otro servicio?
Görevli: Evet. Aktarmalı sefer daha erken kalkıyor. = Sí. El servicio con transbordo sale antes.
Yolcu: Bilet ücretinde değişiklik olacak mı? = ¿Habrá algún cambio en el precio del billete?
Görevli: Hayır, ama koltuk numaranız değişebilir. = No, pero su número de asiento puede cambiar.
N Yolcu, Görevli
W otobüsüm = mi autobús | o-to-bü-SÜM
W başka bir seferle = con otro servicio | bash-ka bir se-fer-LE
W aktarmalı = con transbordo | ak-tar-ma-LUH

Q ¿Qué significa «aktarma»?
+ transbordo :: Aktarma es cambiar de línea o vehículo.
- devolución :: Devolución es iade.
- retraso :: Retraso es gecikme.
Q ¿Qué problema tiene el viajero?
+ Su autobús se retrasó :: Otobüsüm gecikti.
- Perdió su asiento :: El asiento puede cambiar, pero no está perdido.
- Compró el billete equivocado :: No se dice.
Q ¿Qué ofrece el empleado?
+ Otro servicio con transbordo :: Aktarmalı sefer.
- Devolver el dinero inmediatamente :: No lo propone.
- Viajar en tren :: No aparece tren.
Q ¿Qué puede cambiar?
+ El número de asiento :: Koltuk numaranız değişebilir.
- El precio del billete :: El empleado dice que no.
- El destino :: No se menciona un cambio de destino.
R Aktarmalı sefer daha erken kalkıyor. :: Traduce.
+ El servicio con transbordo sale antes. :: Aktarmalı = con transbordo.
- El autobús llega tarde. :: Esa es la frase del viajero.
- El asiento cuesta menos. :: No se habla del precio del asiento.
H Otobüsüm ___ . :: Completa: «Mi autobús se retrasó».
+ gecikti :: Gecikti = se retrasó.
- kalkıyor :: Sale.
- değişebilir :: Puede cambiar.
