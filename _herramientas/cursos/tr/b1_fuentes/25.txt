@ 25 | Radyo ve televizyon haberleri | Noticias en radio y televisión
I Comprende el tema principal de un informativo y transmite los datos importantes.
E Resumir un boletín :: **duyuru** = anuncio; **yayın** = emisión; **uyarı** = advertencia. :: Para resumir una noticia, menciona el hecho principal, el lugar y la hora. :: **-dığı bildirildi** significa «se informó que...»: **yolun kapandığı bildirildi** = se informó que la carretera estaba cerrada.
W duyuru = anuncio | du-yu-RU
W yayın = emisión | ya-YUN
W uyarı = advertencia | u-ya-RUH
W ana yol = carretera principal | a-na YOL
W kapanmak = cerrarse | ka-pan-MAK
W kaza = accidente | ka-ZA
W bildirmek = informar | bil-dir-MEK
w kapandığı bildirildi = se informó que estaba cerrada | ka-pan-dı-ğı bil-di-ril-DI
w nedeniyle = debido a | ne-de-niy-LE
w trafik = tráfico | tra-FIK
w Ana = principal
w yolda = en la carretera
w bildirildi = se informó
w Sürücülerin = de los conductores
w yolu = ruta
V Un boletín de tráfico
D Aviso en la radio
Spiker: Ana yolda bir kaza olduğu bildirildi. = Se informó de que hubo un accidente en la carretera principal.
Spiker: Bu nedenle yolun kapandığı bildirildi. = Por este motivo, se informó de que la carretera estaba cerrada.
Spiker: Sürücülerin alternatif yolu kullanmaları öneriliyor. = Se recomienda a los conductores usar una ruta alternativa.
Spiker: Yeni bilgi saat onda verilecek. = Se darán nuevas noticias a las diez.
N Spiker
W olduğu = que hubo | ol-du-ĞU
W yolun = la carretera | yo-LUN
W sürücü = conductor/a | sü-rü-JÜ
W alternatif = alternativo/a | al-ter-na-TIF
W kullanmaları = que usen | kul-lan-ma-la-RUH
W öneriliyor = se recomienda | ö-ne-ri-li-YOR
W yeni bilgi = nueva información | ye-ni bil-GI
w verilecek = se dará | ve-ri-le-JEK
w saat onda = a las diez | sa-at on-DA
Q ¿Qué significa «duyuru»?
+ anuncio :: Duyuru transmite información al público.
- conductor/a :: Conductor es sürücü.
- carretera :: Carretera es yol.
Q ¿Qué ocurrió en la carretera principal?
+ Hubo un accidente :: Ana yolda bir kaza olduğu bildirildi.
- La carretera se abrió :: No, se informó que se cerró.
- Se canceló un autobús :: No se menciona un autobús.
Q ¿Qué recomienda la radio?
+ Usar una ruta alternativa :: Alternatif yolu kullanmaları öneriliyor.
- No salir de casa :: No da esa recomendación.
- Esperar hasta la noche :: La nueva información será a las diez.
Q ¿Cuándo darán nueva información?
+ A las diez :: Saat onda.
- A las ocho :: No se indica esa hora.
- Mañana :: La hora será hoy a las diez.
R Yolun kapandığı bildirildi. :: Traduce.
+ Se informó de que la carretera estaba cerrada. :: -dığı bildirildi transmite información referida.
- La carretera se cerrará mañana. :: Futuro sería kapanacak.
- Se recomienda otra carretera. :: Esa es otra oración.
H Sürücülerin alternatif yolu ___ öneriliyor. :: Completa: «Se recomienda que los conductores usen una ruta alternativa».
+ kullanmaları :: La forma -maları convierte la acción en «que ellos usen».
- kullanıyor :: Están usando.
- kullandılar :: Usaron.
A Ana yolda bir kaza olduğu bildirildi. :: Escucha el hecho principal.
+ Se informó de un accidente en la carretera principal. :: Es el dato central.
- La carretera está abierta. :: No es la noticia.
- Los conductores deben detenerse. :: Se recomienda otra ruta.
O Sürücülerin alternatif yolu kullanmaları öneriliyor :: Se recomienda que los conductores usen una ruta alternativa :: Öneriliyor = se recomienda.
X Escribe «Por este motivo, se informó...» :: bu nedenle bildirildi :: Bu nedenle introduce la consecuencia.
@ 25 | Yazılı basın ve internet | Prensa e internet
I Compara dos fuentes, localiza los datos de una noticia y comenta si confías en ella.
E Leer noticias :: **kaynak** = fuente; **başlık** = titular; **kanıt** = prueba. :: **güvenilir** significa fiable. :: Para evaluar información, pregunta quién la publica, cuándo y qué pruebas aporta.
W kaynak = fuente | kay-NAK
W başlık = titular | bash-LUH
W kanıt = prueba | ka-NUHT
W güvenilir = fiable | gü-ve-ni-LIR
W paylaşım = publicación; compartir | pay-la-SHUM
W doğrulamak = verificar | doğ-ru-la-MAK
W iddia = afirmación | id-di-A
w sosyal ağ = red social | so-syal A
w gerçek = verdadero/a | ge-REK
w tarih = fecha | ta-RIH
w paylaşımda = en la publicación
w haberin = de la noticia
w kaynağı = fuente
w bilgiyi = la información
w yerden = de un sitio
V Analizar una publicación
D ¿Es fiable?
Elif: Bu paylaşımda haberin kaynağı yazıyor mu? = ¿En esta publicación aparece la fuente de la noticia?
Ali: Hayır, yalnızca dikkat çekici bir başlık var. = No, solo hay un titular llamativo.
Elif: O zaman bilgiyi başka bir yerden doğrulayalım. = Entonces verifiquemos la información en otro lugar.
Ali: Evet, güvenilir bir kaynak bulmadan paylaşmamalıyız. = Sí, no deberíamos compartirla sin encontrar una fuente fiable.
W yazıyor = está escrito | ya-zı-YOR
W yalnızca = solamente | yal-nız-JA
W dikkat çekici = llamativo/a | dik-kat çek-i-JI
W doğrulayalım = verifiquemos | doğ-ru-la-ya-LUHM
W bulmadan = sin encontrar | bul-ma-DAN
w paylaşmamalıyız = no deberíamos compartir | pay-laş-ma-ma-lı-YUZ
Q ¿Qué significa «kaynak» en una noticia?
+ fuente :: La fuente indica quién publica la información.
- titular :: Titular es başlık.
- prueba :: Prueba es kanıt.
Q ¿Qué falta en la publicación?
+ La fuente de la noticia :: Elif pregunta si aparece, y la respuesta es no.
- Un titular :: Sí hay un titular.
- Una fecha de cumpleaños :: No viene al caso.
Q ¿Qué deciden hacer?
+ Verificar la información en otro lugar :: Doğrulayalım = verifiquemos.
- Compartirla enseguida :: Dicen que no deben compartir sin una fuente fiable.
- Borrar todas las noticias :: No dicen eso.
Q «Güvenilir» significa…
+ fiable :: Güvenilir es digno de confianza.
- llamativo/a :: Llamativo/a es dikkat çekici.
- falso/a :: Falso/a es yanlış.
R Güvenilir bir kaynak bulmadan paylaşmamalıyız. :: Traduce.
+ No deberíamos compartirla sin encontrar una fuente fiable. :: -madan = sin hacer; -malıyız = deberíamos.
- Debemos compartir todas las fuentes. :: Es lo contrario.
- Encontramos una noticia llamativa. :: No es esa frase.
H Bu bilgiyi başka bir yerden ___ . :: Completa: «Verifiquemos esta información en otro lugar».
+ doğrulayalım :: -alım/-elim propone hacer algo juntos.
- doğruladık :: Verificamos (pasado).
- doğruluyor :: Está verificando.
A Bu paylaşımda haberin kaynağı yazıyor mu? :: Escucha qué pregunta Elif.
+ ¿Aparece la fuente de la noticia en esta publicación? :: Kaynak = fuente.
- ¿Quién escribió el titular? :: Kim yazdı?
- ¿La noticia es de hoy? :: Bugünün haberi mi?
O Güvenilir bir kaynak bulmadan paylaşmamalıyız :: No deberíamos compartirla sin encontrar una fuente fiable :: -madan expresa «sin».
X Escribe «La noticia es fiable» :: haber güvenilir :: Güvenilir = fiable.
@ 25 | Reklamlar ve medya dili | Anuncios y lenguaje de los medios
I Comprende un anuncio, distingue una opinión de un dato y pide más información.
E Anuncios :: **kampanya** = campaña; **indirim** = descuento; **koşul** = condición. :: Los anuncios suelen destacar beneficios, pero hay que revisar las condiciones y la fecha de validez. :: **-dığı sürece** significa «mientras/siempre que».
W kampanya = campaña | kam-pan-YA
W indirimli = con descuento | in-di-rim-LI
W koşul = condición | ko-SHUL
W geçerli = válido/a | ge-cher-LI
W son tarih = fecha límite | son ta-RIH
W avantaj = ventaja | a-van-TAJ
W ayrıntı = detalle | ay-rın-TUH
w faydalanmak = beneficiarse | fay-da-lan-MAK
w satın almak = comprar | sa-tın al-MAK
w süresince = durante | sü-re-SIN-je
w İndirimli = rebajado/a
w Ayrıntıları = los detalles
w İnternet = internet
w sayfamızdan = desde nuestra página
w okuyabilirsiniz = pueden leer
w internet = internet

V Leer un anuncio
D Una oferta en línea
Müşteri: Bu kampanya hangi tarihe kadar geçerli? = ¿Hasta qué fecha es válida esta campaña?
Görevli: Ayın sonuna kadar. İndirimli ürünlerde iade koşulu farklı. = Hasta fin de mes. La condición de devolución es diferente para los productos con descuento.
Müşteri: Ayrıntıları nereden okuyabilirim? = ¿Dónde puedo leer los detalles?
Görevli: İnternet sayfamızdan faydalanabilirsiniz. = Puede consultarlos en nuestra página de internet.
N Müşteri, Görevli
W hangi tarihe kadar = hasta qué fecha | han-gi ta-ri-he ka-DAR
W ayın sonuna kadar = hasta fin de mes | a-yın so-nu-na ka-DAR
W iade koşulu = condición de devolución | i-a-de ko-shu-LU
W farklı = diferente | far-KLUH
W internet sayfası = página de internet | in-ter-net say-fa-SUH
W faydalanabilirsiniz = puede beneficiarse/consultar | fay-da-la-na-bi-lir-si-NIZ
w ürünlerde = en los productos | ü-rün-ler-DE
w okuyabilirim = puedo leer | o-ku-ya-bi-li-RIM
Q ¿Qué significa «kampanya»?
+ campaña :: Una oferta promocional por un periodo.
- condición :: Condición es koşul.
- fecha límite :: Fecha límite es son tarih.
Q ¿Hasta cuándo es válida la oferta?
+ Hasta fin de mes :: Ayın sonuna kadar.
- Todo el año :: No dice todo el año.
- Hasta mañana :: No especifica mañana.
Q ¿Qué condición cambia para los productos rebajados?
+ La de devolución :: İade koşulu farklı.
- La garantía :: Garantía es garanti.
- El precio original :: No habla del precio original.
Q ¿Dónde se pueden leer los detalles?
+ En la página de internet :: İnternet sayfamızdan.
- En el recibo :: Fiş no aparece.
- En la tienda de al lado :: No se indica.
R İndirimli ürünlerde iade koşulu farklı. :: Traduce.
+ La condición de devolución es diferente para los productos con descuento. :: İndirimli = con descuento.
- Los productos con descuento no se pueden comprar. :: No dice eso.
- La campaña termina hoy. :: No se especifica hoy.
H Bu kampanya hangi tarihe kadar ___? :: Completa: «¿Hasta qué fecha es válida esta campaña?».
+ geçerli :: Geçerli = válido/a.
- farklı :: Diferente.
- avantajlı :: Ventajoso/a.
A Ayrıntıları internet sayfamızdan okuyabilirsiniz. :: Escucha dónde consultar los detalles.
+ Puede leerlos en nuestra página de internet. :: Internet sayfamızdan = desde nuestra página.
- Puede devolver el producto en la tienda. :: No lo dice.
- La campaña dura hasta mañana. :: No indica mañana.
O İndirimli ürünlerde iade koşulu farklı :: La condición de devolución es diferente para productos con descuento :: Koşul = condición.
X Escribe «La campaña es válida hasta fin de mes» :: kampanya ayın sonuna kadar geçerli :: Geçerli = válido/a.
