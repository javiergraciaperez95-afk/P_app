- La energía es cara :: No menciona precios.

+ Poner contenedores de reciclaje :: Geri dönüşüm kutuları koyalım.
- Cerrar el arroyo :: No propone cerrarlo.
- Dejar de ahorrar agua :: Propone ahorrar agua.

- La contaminación está en casa. :: No es la frase.

- por un lado :: Bir yandan.
- comparado con :: -e göre.

+ Debemos controlar qué información compartimos. :: -malı expresa necesidad.
- La información está segura. :: Esa es otra frase.
- Compartimos una aplicación. :: No es la frase.

@ 30 | Güncel konular ve tartışma | Actualidad y debate

E Debatir :: **görüş** = punto de vista; **gerekçe** = razón; **sonuç** = conclusión. :: En un debate, escucha, resume la idea anterior y después responde. :: **Bir yandan ... öte yandan ...** permite reconocer dos perspectivas antes de llegar a una conclusión.

Can: Görüşünü anlıyorum. Ancak belediyenin bu hizmeti nasıl finanse edeceğini de düşünmeliyiz. = Entiendo tu punto de vista. Sin embargo, también debemos pensar cómo financiará el municipio este servicio.
Deniz: Haklısın. Bir yandan herkes ulaşabilir, öte yandan bütçe gerekir. = Tienes razón. Por un lado, todos podrían acceder; por otro, hace falta presupuesto.
Can: O hâlde önce maliyeti araştırıp sonra karar verelim. = Entonces investiguemos primero el coste y decidamos después.
W böylece = así; de este modo | böy-le-JE

Q ¿Qué significa «gerekçe»?
+ razón; justificación :: Explica por qué se apoya una idea.
- conclusión :: Conclusión es sonuç.
- municipio :: Municipio es belediye.
Q ¿Por qué apoya Deniz el transporte gratuito?
+ Porque podría reducir el tráfico y facilitar el acceso :: Presenta esas ventajas.
- Porque no cuesta nada al municipio :: Can dice que hay un coste.
- Porque nadie usa el transporte público :: No lo dice.
Q ¿Qué preocupación plantea Can?
+ Cómo financiar el servicio :: Pregunta por la financiación.
- Si el autobús es cómodo :: No habla de comodidad.
- Si la ciudad tiene tráfico :: Ambos aceptan que hay tráfico.

+ Investigar el coste :: Önce maliyeti araştırıp...
- Cancelar el servicio :: No lo deciden.
- Hacer una encuesta nacional :: No lo menciona.
R Görüşünü anlıyorum, ancak maliyeti de düşünmeliyiz. :: Traduce.
+ Entiendo tu punto de vista, pero también debemos pensar en el coste. :: Ancak = pero/sin embargo.
- No entiendo tu conclusión. :: No es la frase.
- Estoy de acuerdo con el transporte gratuito. :: Es otra idea.
H Önce maliyeti ___ sonra karar verelim. :: Completa: «Primero investiguemos el coste y después decidamos».
+ araştırıp :: -ıp conecta dos acciones consecutivas.
- araştırmadan :: Sin investigar.
- araştıracak :: Investigará.
A Bir yandan herkes ulaşabilir, öte yandan bütçe gerekir. :: Escucha los dos lados.
+ Por un lado todos podrían acceder; por otro, hace falta presupuesto. :: Presenta dos perspectivas.
- Todos están de acuerdo en que es gratis. :: Hay una preocupación financiera.
