@ 23 | Öğrenme biçimleri | Formas de aprender
I Explica qué método te funciona y comenta el progreso en un proyecto escolar.
E Aprender :: **öğrenme biçimi** = forma de aprendizaje; **ilerleme** = progreso; **zorlanmak** = tener dificultades. :: **-erek/-arak** puede expresar cómo haces algo: **not alarak öğreniyorum** = aprendo tomando notas. :: **şu ana kadar** significa «hasta ahora».
W öğrenme biçimi = forma de aprendizaje | ö-ren-me bi-çi-MI
W ilerleme = progreso | i-ler-le-ME
W zorlanmak = tener dificultades | zor-lan-MAK
W not almak = tomar notas | not al-MAK
W görsel = visual | gör-SEL
W yöntem = método | yön-TEM
W şu ana kadar = hasta ahora | şu a-na ka-DAR
w ders çalışmak = estudiar | ders ça-lış-MAK
w grup çalışması = trabajo en grupo | grup ça-lış-ma-SUH
w açıklamak = explicar | a-chık-la-MAK
w derste = en clase
w yöntemle = con qué método
w öğreniyorsun = aprendes
w not = apuntes
w alarak = tomando
w Projede = en el proyecto
w zorlanıyorum = me cuesta
V Aprender mejor
D En el descanso
Anna: Bu derste en iyi hangi yöntemle öğreniyorsun? = ¿Con qué método aprendes mejor en esta clase?
Can: Görselleri kullanarak ve not alarak daha iyi öğreniyorum. = Aprendo mejor usando imágenes y tomando notas.
Anna: Projede ne kadar ilerledin? = ¿Cuánto has avanzado en el proyecto?
Can: Şu ana kadar ilk bölümü bitirdim ama sonuçları açıklamakta zorlanıyorum. = Hasta ahora terminé la primera parte, pero tengo dificultades para explicar los resultados.
W görselleri = las imágenes | gör-sel-le-RI
W kullanarak = usando | kul-la-na-RAK
W ilerledin = avanzaste | i-ler-le-DIN
W bölümü = la parte | bö-lü-MÜ
W bitirdim = terminé | bi-tir-DIM
W sonuçları = los resultados | so-nuç-la-RUH
w açıklamakta = al explicar | a-chık-la-mak-TA
Q ¿Qué significa «ilerleme»?
+ progreso :: İlerleme expresa el avance en una tarea.
- método :: Método es yöntem.
- imagen :: Imagen es görsel.
Q ¿Cómo aprende mejor Can?
+ Usando imágenes y tomando notas :: Enumera esos dos métodos.
- Escuchando música :: No lo menciona.
- Estudiando siempre solo :: No habla de estudiar solo.
Q ¿Qué significa «şu ana kadar»?
+ hasta ahora :: Sitúa el progreso hasta el momento actual.
- desde mañana :: Mañana es yarından itibaren.
- hace un momento :: Hace un momento es az önce.
Q ¿Qué dificultad tiene Can?
+ Explicar los resultados :: Sonuçları açıklamakta zorlanıyor.
- Terminar la primera parte :: Ya la terminó.
- Usar las imágenes :: Ese método le funciona.
R Not alarak daha iyi öğreniyorum. :: Traduce.
+ Aprendo mejor tomando notas. :: -arak enlaza el modo de aprender.
- Escribo las notas después de clase. :: No dice cuándo las escribe.
- Aprendo mejor en grupo. :: Grupo es grup.
H Görselleri kullan___ daha iyi öğreniyorum. :: Completa: «Aprendo mejor usando imágenes».
+ arak :: -arak/-erek expresa cómo se realiza una acción.
- dığım için :: Porque hice algo.
- mak için :: Para hacer algo.
A İlk bölümü bitirdim. :: Escucha qué completó Can.
+ Terminé la primera parte. :: İlk bölümü bitirdim.
- Terminé el proyecto entero. :: Aún trabaja en los resultados.
- Empecé la primera parte. :: Empezar es başladım.
O Sonuçları açıklamakta zorlanıyorum :: Tengo dificultades para explicar los resultados :: Zorlanmak expresa dificultad.
X Escribe «¿Cuánto has avanzado?» :: ne kadar ilerledin :: Ne kadar pregunta cuánto.
@ 23 | Meslek seçimi | Elegir una profesión
I Describe una profesión, tus aptitudes y las razones de tu elección.
E Hablar de profesiones :: **beceri** = habilidad; **arzu** = deseo; **deneyim** = experiencia. :: **-mek istiyorum** expresa deseo; **-ebilirim** indica capacidad. :: Puedes justificar una elección con **bu nedenle** («por este motivo») o **bana göre** («en mi opinión»).
W beceri = habilidad | be-je-RI
W arzu = deseo | ar-ZU
W yaratıcı = creativo/a | ya-ra-tı-JUH
W sabırlı = paciente | sa-bır-LUH
W tasarımcı = diseñador/a | ta-sa-rım-JUH
W bana göre = en mi opinión | ba-na gö-RE
w insanlarla çalışmak = trabajar con personas | in-san-lar-la ça-lış-MAK
w çizim = dibujo | chi-ZIM
w yardım etmek = ayudar | yar-dım et-MEK
w Yaratıcıyım = soy creativo/a
w beceriler = habilidades
w insanlarla = con personas
V Una decisión profesional
D Hablar del futuro
Deniz: Neden tasarımcı olmak istiyorsun? = ¿Por qué quieres ser diseñador?
Elif: Yaratıcıyım ve çizim yapmayı seviyorum. = Soy creativa y me gusta dibujar.
Deniz: Bu iş için hangi beceriler gerekli? = ¿Qué habilidades hacen falta para este trabajo?
Elif: Sabırlı olmak ve insanlarla iyi iletişim kurabilmek. = Ser paciente y poder comunicarse bien con la gente.
W olmak = ser | ol-MAK
W gerekli = necesario/a | ge-rek-LI
W iletişim = comunicación | i-le-ti-SHIM
W kurabilmek = poder establecer | ku-ra-bil-MEK
w yapmayı = hacer (como actividad) | yap-ma-YUH
w neden = por qué | ne-DEN
Q ¿Qué significa «beceri»?
+ habilidad :: Es una capacidad para realizar una tarea.
- deseo :: Deseo es arzu.
- experiencia :: Experiencia es deneyim.
Q ¿Por qué quiere Elif ser diseñadora?
+ Porque es creativa y le gusta dibujar :: Da ambas razones.
- Porque quiere trabajar en un hospital :: No lo dice.
- Porque ya tiene mucha experiencia :: No menciona su experiencia.
Q «Gerekli» significa…
+ necesario/a :: Gerekli describe algo que hace falta.
- creativo/a :: Creativo/a es yaratıcı.
- paciente :: Paciente es sabırlı.
Q ¿Qué habilidades menciona Elif?
+ Ser paciente y comunicarse bien :: Ambas aparecen en su respuesta.
- Hablar varios idiomas :: No se menciona.
- Diseñar edificios :: No se menciona.
R Sabırlı olmak ve insanlarla iyi iletişim kurabilmek. :: Traduce.
+ Ser paciente y poder comunicarse bien con la gente. :: Kurabilmek = poder establecer/comunicarse.
- Quiero ser diseñadora y dibujar. :: Es otra idea.
- Tengo experiencia trabajando con personas. :: No aparece experiencia.
H Yaratıcıyım ve çizim yapmayı ___ . :: Completa: «Soy creativa y me gusta dibujar».
+ seviyorum :: Sevmek = gustar.
- biliyorum :: Saber.
- arıyorum :: Buscar.
A Bu iş için hangi beceriler gerekli? :: Escucha la pregunta.
+ ¿Qué habilidades hacen falta para este trabajo? :: Gerekli = necesario.
- ¿Cuánto gana un diseñador? :: Maaş ne kadar?
- ¿Dónde trabaja Elif? :: Nerede çalışıyor?
O Sabırlı olmak gerekli :: Ser paciente es necesario :: -mek convierte el verbo en infinitivo.
X Escribe «Quiero ayudar a las personas» :: insanlara yardım etmek istiyorum :: İstiyorum expresa deseo.
@ 23 | İş ilanı ve mülakat | Ofertas y entrevistas
I Comprende una oferta, resume tu experiencia y pide aclaraciones durante una entrevista.
E Solicitar trabajo :: **iş ilanı** = oferta de empleo; **özgeçmiş** = currículum; **mülakat** = entrevista. :: **başvuru nedeni** = motivo de solicitud. :: Si no entiendes una pregunta, pide que la repitan: **Soruyu tekrar edebilir misiniz?**
W iş ilanı = oferta de empleo | ish i-la-NUH
W özgeçmiş = currículum | öz-gech-MISH
W mülakat = entrevista | mü-la-KAT
W deneyimli = con experiencia | de-ye-nim-LI
W başvuru nedeni = motivo de solicitud | bash-vu-ru ne-de-NI
W tekrar etmek = repetir | tek-rar et-MEK
W tekrar edebilir misiniz = ¿puede repetir? | tek-rar e-de-bi-LIR mi-si-niz
w iletişim becerisi = habilidad de comunicación | i-le-ti-shim be-je-re-SI
w bilgisayar kullanmak = usar un ordenador | bil-gi-sa-yar kul-lan-MAK
w randevu almak = pedir una cita | ran-de-vu al-MAK
w pozisyona = para el puesto
w hizmetlerinde = en servicios
w İletişim = comunicación
w programlarını = programas
w Soruyu = la pregunta
V La entrevista
D Una oferta de empleo
İşveren: Bu pozisyona neden başvurdunuz? = ¿Por qué solicitó este puesto?
Başvuran: Beş yıl müşteri hizmetlerinde çalıştım. İletişim becerim güçlü. = Trabajé cinco años en atención al cliente. Tengo buenas habilidades de comunicación.
İşveren: Bilgisayar programlarını kullanabiliyor musunuz? = ¿Sabe usar programas de ordenador?
Başvuran: Soruyu tekrar edebilir misiniz? = ¿Puede repetir la pregunta?
N İşveren, Başvuran
W pozisyon = puesto | po-zis-YON
W başvurdunuz = solicitó/usted | bash-vur-du-NUZ
W güçlü = fuerte | güch-LÜ
W program = programa | prog-RAM
W kullanabiliyor musunuz = ¿sabe usar? | kul-la-na-bi-li-YOR mu-su-nuz
w beş yıl = cinco años | beş yuhl
w becerim = mi habilidad | be-je-RIM
Q ¿Qué significa «iş ilanı»?
+ oferta de empleo :: Es un anuncio de un puesto de trabajo.
- currículum :: Currículum es özgeçmiş.
- entrevista :: Entrevista es mülakat.
Q ¿Cuánta experiencia tiene la persona candidata?
+ Cinco años :: Beş yıl çalıştım.
- Tres años :: No dice tres.
- Diez años :: No dice diez.
Q ¿Cuál es su motivo para solicitar el puesto?
+ Tiene experiencia en atención al cliente y buena comunicación :: Explica su experiencia y habilidad.
- Quiere estudiar informática :: No se menciona estudiar.
- Conoce al empleador :: No aparece.
Q ¿Qué hace cuando no entiende la pregunta?
+ Pide que la repitan :: Soruyu tekrar edebilir misiniz?
- Termina la entrevista :: Continúa respondiendo.
- Cambia de tema :: No cambia de tema.
R İletişim becerim güçlü. :: Traduce.
+ Tengo buenas habilidades de comunicación. :: Güçlü = fuerte; en este contexto, buenas.
- La comunicación es difícil. :: Difícil es zor.
- Busco un puesto en atención al cliente. :: Esa no es la frase.
H Bu pozisyona neden ___? :: Completa: «¿Por qué solicitó este puesto?».
+ başvurdunuz :: Başvurmak = solicitar/presentarse.
- çalıştınız :: Trabajó.
- ayrıldınız :: Se marchó.
A Bilgisayar programlarını kullanabiliyor musunuz? :: Escucha la pregunta.
+ ¿Sabe usar programas de ordenador? :: Kullanabiliyor musunuz pregunta por capacidad.
- ¿Tiene experiencia de cinco años? :: No es la pregunta.
- ¿Puede repetir la pregunta? :: Esa es la respuesta del candidato.
O Bu pozisyona neden başvurdunuz :: ¿Por qué solicitó este puesto? :: Başvurmak = solicitar.
X Escribe «¿Puede repetir la pregunta?» :: soruyu tekrar edebilir misiniz :: Fórmula para pedir aclaración.
