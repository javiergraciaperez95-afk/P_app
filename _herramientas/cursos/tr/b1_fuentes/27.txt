@ 27 | Tatil hazırlıkları ve gezi | Preparativos y excursiones
I Elige un destino, compara opciones y recomienda una visita según el tiempo y el presupuesto.
E Preparar el viaje :: **broşür** = folleto; **giriş ücreti** = precio de entrada; **bütçe** = presupuesto. :: **ziyaret etmeye değer** significa «merece la pena visitar». :: **-e rağmen** significa «a pesar del»: **yağmura rağmen** = a pesar de la lluvia.
W broşür = folleto | bro-SHÜR
W giriş ücreti = precio de entrada | gi-rish üc-re-TI
W bütçe = presupuesto | büch-CHE
W ziyaret etmeye değer = merece la pena visitar | zi-ya-ret et-me-ye de-ER
W manzara = paisaje; vista | man-za-RA
W yürüyüş yolu = ruta de senderismo | yü-rü-yüş yo-LU
W yağmura rağmen = a pesar de la lluvia | yaa-mu-ra ra-MEN
w seçmek = elegir | seç-MEK
w önermek = recomendar | ö-ner-MEK
w yaparız = hacemos
w yoluna = a la ruta
V Elegir una excursión
D Plan para el domingo
Ali: Broşürdeki göl ziyaret etmeye değer mi? = ¿Merece la pena visitar el lago del folleto?
Ece: Evet, manzarası çok güzel. Giriş ücreti de bütçemize uygun. = Sí, el paisaje es muy bonito. El precio de entrada también se ajusta a nuestro presupuesto.
Ali: Yağmur yağarsa ne yaparız? = ¿Qué hacemos si llueve?
Ece: Yağmura rağmen yürüyüş yoluna gidebiliriz; uygun kıyafet seçelim. = A pesar de la lluvia, podemos ir a la ruta; elijamos ropa adecuada.
W göl = lago | göl
W broşürdeki = que está en el folleto | bro-shür-de-KI
W manzarası = su paisaje | man-za-ra-SUH
W bütçemize = a nuestro presupuesto | büt-che-mi-ZE
W gidebiliriz = podemos ir | gi-de-bi-li-RIZ
w uygun kıyafet = ropa adecuada | uy-gun kı-ya-FET
w seçelim = elijamos | se-che-LIM
Q ¿Qué significa «bütçe»?
+ presupuesto :: El presupuesto limita cuánto se puede gastar.
- paisaje :: Paisaje es manzara.
- folleto :: Folleto es broşür.
Q ¿Por qué el grupo considera adecuado el lago?
+ Por el paisaje y el precio :: Ece da ambas razones.
- Porque no hay que caminar :: Hay una ruta de senderismo.
- Porque está dentro de la ciudad :: No lo menciona.
Q «Ziyaret etmeye değer» significa…
+ merece la pena visitar :: Değer = vale/la pena.
- es demasiado caro :: Caro/a es pahalı.
- queda lejos :: Lejos es uzak.
Q ¿Qué harán si llueve?
+ Aun así, pueden ir con ropa adecuada :: La lluvia no cancela automáticamente el plan.
- Se quedarán en casa :: No es su decisión.
- Cambiarán de ciudad :: No se dice.
R Giriş ücreti bütçemize uygun. :: Traduce.
+ El precio de entrada se ajusta a nuestro presupuesto. :: Uygun = adecuado.
- La entrada es gratuita. :: Gratis es ücretsiz.
- El paisaje está dentro del presupuesto. :: No es la frase.
H Broşürdeki göl ziyaret etmeye ___ mi? :: Completa: «¿Merece la pena visitar el lago del folleto?».
+ değer :: Değer = merece/vale.
- gerekir :: Hace falta.
- başladı :: Empezó.
A Yağmura rağmen yürüyüş yoluna gidebiliriz. :: Escucha el plan.
+ Podemos ir a la ruta a pesar de la lluvia. :: -e rağmen = a pesar de.
- No podemos salir por la lluvia. :: No es lo que dice.
- La lluvia empieza en la ruta. :: No es la frase.
O Uygun kıyafet seçelim :: Elijamos ropa adecuada :: -elim propone una acción compartida.
X Escribe «Merece la pena visitar el lago» :: gölü ziyaret etmeye değer :: Değer = vale la pena.
@ 27 | Seyahat sorunları ve güvenlik | Problemas y seguridad en viaje
I Explica un problema durante el viaje, informa a la autoridad adecuada y sigue instrucciones.
E Incidencias :: **kayıp** = pérdida; **çalınmak** = ser robado; **karakol** = comisaría. :: Para explicar qué pasó, incluye cuándo, dónde y qué objeto falta. :: **-miş** puede presentar información que acabas de descubrir: **çantam kaybolmuş** = resulta que mi bolso se ha perdido.
W kayıp = pérdida; perdido/a | ka-YUP
W çalınmak = ser robado | cha-lın-MAK
W karakol = comisaría | ka-ra-KOL
W ifade vermek = declarar | i-fa-de ver-MEK
W çanta = bolso | chan-TA
W cüzdan = cartera | cüz-DAN
w kaybolmuş = resulta que se perdió | kay-bol-MUSH
w çalınmış = resulta que fue robado | cha-lın-MUSH
w en yakın = el más cercano | en ya-KUHN
w İçinde = dentro
w vardı = había
w İfade = declaración
w vermem = tengo que dar
w formu = el formulario
V En la comisaría
D Informar de una pérdida
Yolcu: Çantam otobüste kaybolmuş. İçinde pasaportum ve cüzdanım vardı. = Resulta que mi bolso se perdió en el autobús. Dentro estaban mi pasaporte y mi cartera.
Polis: En son ne zaman gördünüz? = ¿Cuándo lo vio por última vez?
Yolcu: Bugün saat üçte. İfade vermem gerekiyor mu? = Hoy a las tres. ¿Tengo que declarar?
Polis: Evet, lütfen bu formu doldurun. = Sí, por favor, rellene este formulario.
N Yolcu, Polis
W otobüste = en el autobús | o-to-büs-TE
W içinde = dentro | i-chin-DE
W pasaportum = mi pasaporte | pa-sa-por-TUM
W cüzdanım = mi cartera | cüz-da-NUHM
W en son = la última vez | en SON
W gördünüz = vio/usted | gör-dü-NÜZ
W form = formulario | form
w doldurun = rellene | dol-du-RUN
w saat üçte = a las tres | sa-at üç-TE
Q ¿Qué significa «çalınmak»?
+ ser robado :: El verbo describe una cosa sustraída por alguien.
- declarar :: Declarar es ifade vermek.
- rellenar :: Rellenar es doldurmak.
Q ¿Qué perdió el viajero?
+ Un bolso con el pasaporte y la cartera :: Enumera los objetos que llevaba.
- Una maleta con ropa :: No menciona ropa.
- Su billete de autobús :: No se perdió el billete.
Q ¿Cuándo vio el bolso por última vez?
+ Hoy a las tres :: Bugün saat üçte.
- Ayer por la noche :: No aparece.
- En la estación :: No dice la estación.
Q ¿Qué tiene que hacer el viajero?
+ Rellenar un formulario :: La policía se lo pide.
- Comprar un pasaporte nuevo inmediatamente :: No aparece.
- Volver al autobús :: No es la instrucción.
R Çantam otobüste kaybolmuş. :: Traduce.
+ Resulta que mi bolso se perdió en el autobús. :: -miş expresa una noticia descubierta o referida.
- Mi bolso se perderá en el autobús. :: Futuro sería kaybolacak.
- Perdí el autobús y mi bolso. :: No es la frase.
H İçinde pasaportum ve cüzdanım ___ . :: Completa: «Dentro estaban mi pasaporte y mi cartera».
+ vardı :: Vardı = había/estaban.
- var :: Hay.
- olacak :: Habrá.
A En son ne zaman gördünüz? :: Escucha la pregunta de la policía.
+ ¿Cuándo lo vio por última vez? :: En son = la última vez.
- ¿Dónde compró el pasaporte? :: Nereden aldınız?
- ¿Cuándo llegará el autobús? :: Otobüs ne zaman gelecek?
O Lütfen bu formu doldurun :: Por favor, rellene este formulario :: Doldurun es un imperativo formal.
X Escribe «Tengo que declarar» :: ifade vermem gerekiyor :: Gerekiyor expresa necesidad.
@ 27 | Konaklama ve şikâyet | Alojamiento y reclamaciones
I Comunica un problema de alojamiento y solicita una solución o una compensación.
E Resolver un problema :: **arıza** = avería; **şikâyet** = queja; **fatura** = factura. :: Explica el problema con calma y di qué solución esperas. :: **-mesine rağmen** = a pesar de que: **rezervasyon yapmama rağmen** = a pesar de que hice una reserva.
W arıza = avería | a-RUH-za
W şikâyet = queja | shi-ka-YET
W fatura = factura | fa-tu-RA
W klima = aire acondicionado | kli-MA
W çalışmamak = no funcionar | cha-lış-ma-MAK
W çözüm = solución | çö-ZÜM
W ücret iadesi = reembolso | üc-ret i-a-de-SI
w rezervasyon yapmama rağmen = a pesar de haber reservado | re-zer-vas-yon yap-ma-ma ra-men
w oda değiştirmek = cambiar de habitación | o-da de-ğiş-tir-MEK
w ilgilenmek = ocuparse | il-gi-len-MEK
w Arızayı = la avería
w Odanızı = su habitación
w veya = o
V En recepción
D Una avería en la habitación
Misafir: Klimanın çalışmamasına rağmen oda çok sıcak. = Aunque el aire acondicionado no funciona, la habitación está muy caliente.
Görevli: Arızayı hemen kontrol edelim. = Revisemos la avería ahora mismo.
Misafir: Rezervasyon yapmama rağmen oda hazır değildi. = A pesar de que hice una reserva, la habitación no estaba lista.
Görevli: Özür dileriz. Odanızı değiştirebilir veya ücret iadesi isteyebilirsiniz. = Lo sentimos. Puede cambiar de habitación o solicitar un reembolso.
N Misafir, Görevli
W klimanın = del aire acondicionado | kli-ma-NIN
W çalışmamasına rağmen = a pesar de que no funciona | cha-lış-ma-ma-sı-na ra-men
W hemen = enseguida | he-MEN
W kontrol edelim = revisemos | kon-trol e-de-LIM
W hazır değildi = no estaba lista | ha-zır de-YIL-di
W isteyebilirsiniz = puede solicitar | is-te-ye-bi-lir-si-NIZ
w özür dileriz = lo sentimos | ö-zür di-le-RIZ
Q ¿Qué significa «arıza»?
+ avería :: Una avería es un problema técnico.
- factura :: Factura es fatura.
- reembolso :: Reembolso es ücret iadesi.
Q ¿Cuál es el problema de la habitación?
+ El aire acondicionado no funciona y hace calor :: El huésped describe ambas cosas.
- No hay agua caliente :: No lo menciona.
- La habitación es demasiado pequeña :: No lo dice.
Q ¿Qué otra queja expresa el huésped?
+ La habitación no estaba lista pese a la reserva :: Rezervasyon yapmama rağmen...
- El hotel está lejos :: No aparece la ubicación.
- La factura es incorrecta :: No habla de la factura.
Q ¿Qué soluciones ofrece el empleado?
+ Cambiar de habitación o pedir un reembolso :: Presenta dos opciones.
- Cancelar todas las reservas :: No lo dice.
- Esperar hasta mañana :: No lo propone.
R Odanızı değiştirebilir veya ücret iadesi isteyebilirsiniz. :: Traduce.
+ Puede cambiar de habitación o solicitar un reembolso. :: Veya = o; iade = devolución.
- Debe pagar otra factura. :: No dice eso.
- La habitación estará lista mañana. :: No es la frase.
H Rezervasyon yapmama ___ oda hazır değildi. :: Completa: «A pesar de que hice una reserva, la habitación no estaba lista».
+ rağmen :: -mama rağmen expresa «a pesar de».
- önce :: Antes de.
- sonra :: Después de.
A Klimanın çalışmamasına rağmen oda çok sıcak. :: Escucha la queja.
+ Aunque el aire acondicionado no funciona, hace mucho calor en la habitación. :: -mesine rağmen = a pesar de que.
- La habitación tiene aire acondicionado nuevo. :: No aparece.
- La factura está demasiado alta. :: No se menciona una factura.
O Özür dileriz. Odanızı değiştirebiliriz :: Lo sentimos. Podemos cambiarle de habitación :: Cambiar la habitación es una solución ofrecida.
X Escribe «La avería no está resuelta» :: arıza çözülmedi :: Çözülmedi = no se resolvió.
