N Anna, Ali, Ece, Mert, Elif, Baran, Deniz
@ 3 | Kime? Yönelme hâli | ¿Adónde? El caso direccional
I Indica adónde va una persona con **-(y)a/e** y presta atención a la vocal de enlace.
E Destino :: **Okula gidiyorum** = voy a la escuela; **kafeye gidiyoruz** = vamos a la cafetería. :: Si el nombre termina en vocal, añade **y**: **arabaya**, **kafeye**.
W okul = escuela
V Destinos
D Yol tarifi
Ali: Nereye gidiyorsun? = ¿Adónde vas?
Anna: Okula gidiyorum. = Voy a la escuela.
Ali: Kafeye de gidiyor musun? = ¿También vas a la cafetería?
Anna: Evet, kafeye gidiyorum. = Sí, voy a la cafetería.
w Nereye gidiyorsun = ¿adónde vas?
w Okula gidiyorum = voy a la escuela
w Kafeye de gidiyor musun = ¿también vas a la cafetería?
w Evet kafeye gidiyorum = sí voy a la cafetería
w Kafeye gidiyorum = voy a la cafetería
w Kafeye gidiyoruz = vamos a la cafetería
Q ¿Qué pregunta «Nereye gidiyorsun?»?
+ ¿Adónde vas? :: Nereye pregunta por el destino.
- ¿Dónde estás? :: Nerede pregunta por la ubicación.
- ¿De dónde vienes? :: Nereden pregunta por la procedencia.
Q ¿Qué sufijo aparece en «kafeye»?
+ -(y)e :: Kafe termina en vocal y toma y de enlace.
- -de :: Expresaría ubicación.
- -den :: Expresaría procedencia.
R Okula gidiyorum. :: Traduce.
+ Voy a la escuela. :: Okul-a marca el destino.
- Estoy en la escuela. :: Esa frase sería okulda.
- Vengo de la escuela. :: Esa frase sería okuldan geliyorum.
H Kafe___ gidiyoruz. :: Completa «vamos a la cafetería».
+ ye :: La palabra termina en vocal, así que lleva y.
- de :: Significa «en la cafetería».
- den :: Significa «desde la cafetería».
A Kafeye de gidiyor musun? :: ¿Qué pregunta?
+ Si también va a la cafetería. :: De significa también en este contexto.
- Si trabaja en la escuela. :: No aparece çalışmak.
- Si viene de la cafetería. :: El sufijo es direccional.
O Okula gidiyorum :: Voy a la escuela. :: El caso direccional indica destino.
X Escribe «Voy a la cafetería.» :: Kafeye gidiyorum. :: Añade y de enlace.

@ 3 | Nerede? Bulunma hâli | ¿Dónde? El caso locativo
I Distingue el lugar donde algo está y aplica **-da/-de/-ta/-te**.
E Ubicación :: El locativo expresa «en»: **evde** = en casa; **okulda** = en la escuela. :: Tras consonantes sordas frecuentes, d cambia a t: **parkta**. La vocal depende de la última vocal de la palabra.
W çanta = bolso
V Lugares
D Evde
Ece: Çanta nerede? = ¿Dónde está el bolso?
Mert: Masada. = Sobre la mesa.
Ece: Anahtar parkta mı? = ¿Está la llave en el parque?
Mert: Hayır, evde. = No, en casa.
w Çanta nerede = ¿dónde está el bolso?
w Masada = sobre la mesa
w Anahtar parkta mı = ¿está la llave en el parque?
w Hayır evde = no en casa
w Evden geliyorum = vengo de casa
Q ¿Qué significa «evde»?
+ En casa :: -de expresa ubicación.
- A casa :: Para dirección se usa eve.
- Desde casa :: Para procedencia se usa evden.
Q ¿Por qué aparece **t** en «parkta»?
+ Park termina en una consonante sorda. :: El locativo cambia d por t después de p, ç, t, k y otras consonantes sordas.
- Porque park es plural. :: No es plural.
- Porque indica destino. :: El destino lleva -a/-e.
R Çanta masada. :: Traduce.
+ El bolso está sobre la mesa. :: Masada expresa la ubicación.
- El bolso va a la mesa. :: No hay sufijo direccional.
- El bolso viene de la mesa. :: No hay sufijo de procedencia.
H Okul___. :: Completa «en la escuela».
+ da :: La última vocal es u y la consonante final es sonora.
- ta :: T no corresponde a la forma de okul.
- dan :: Esa forma significa desde la escuela.
A Hayır, evde. :: ¿Dónde está?
+ En casa. :: Evde significa en casa.
- En el parque. :: Parkta significa en el parque.
- En la escuela. :: Okulda significa en la escuela.
O Parkta mı :: ¿Está en el parque? :: La partícula de pregunta se escribe aparte.
X Escribe «en casa». :: evde :: El sufijo de lugar se une al sustantivo.

@ 3 | Nereden? Ayrılma hâli | ¿De dónde? El caso ablativo
I Expresa de dónde viene alguien y compáralo con **nerede** y **nereye**.
E Procedencia :: **-dan/-den/-tan/-ten** expresa origen: **evden geliyorum** = vengo de casa. :: Compara **evde** (en casa), **eve** (a casa) y **evden** (desde casa).
W gelmek = venir
V Origen y destino
D Yolda
Baran: Nereden geliyorsun? = ¿De dónde vienes?
Deniz: İstasyondan geliyorum. = Vengo de la estación.
Baran: Şimdi nereye gidiyorsun? = ¿Adónde vas ahora?
Deniz: Otobüs durağına gidiyorum. = Voy a la parada del autobús.
w Nereden geliyorsun = ¿de dónde vienes?
w İstasyondan geliyorum = vengo de la estación
w Şimdi nereye gidiyorsun = ¿adónde vas ahora?
w Otobüs durağına gidiyorum = voy a la parada del autobús
Q ¿Qué pregunta «Nereden geliyorsun?»?
+ De dónde vienes. :: Nereden pregunta por el origen.
- Adónde vas. :: Nereye pregunta por el destino.
- Dónde estás. :: Nerede pregunta por la ubicación.
Q ¿Qué significa «istasyondan»?
+ Desde la estación. :: -dan marca procedencia.
- En la estación. :: Esa forma es istasyonda.
- A la estación. :: Esa forma es istasyona.
R İstasyondan geliyorum. :: Traduce.
+ Vengo de la estación. :: Geliyorum significa vengo.
- Voy a la estación. :: Cambia el sentido del sufijo.
- Estoy en la estación. :: El locativo sería istasyonda.
H Ev___ geliyorum. :: Completa «vengo de casa».
+ den :: Evden indica el origen.
- de :: Significa en casa.
- e :: Significa a casa.
A Otobüs durağına gidiyorum. :: ¿Adónde va?
+ A la parada del autobús. :: Durağına marca el destino.
- Desde la estación. :: Esa idea aparece en otra frase.
- A casa. :: Ev no aparece.
O Nereden geliyorsun :: ¿De dónde vienes? :: Nereden solicita el origen.
X Escribe «Estoy en la estación.» :: İstasyondayım. :: Usa el locativo y la terminación de yo.

@ 3 | Sahiplik zinciri | Posesión con dos nombres
I Expresa quién posee algo: **Ece'nin kitabı** significa «el libro de Ece».
E Poseedor y objeto :: El poseedor lleva **-(n)ın/in/un/ün** y el objeto un sufijo posesivo: **okulun kapısı** = la puerta de la escuela. :: Después de nombre propio se escribe apóstrofo: **Ece'nin kitabı**.
W kapı = puerta
W defter = cuaderno
W anahtar = llave
V Objetos y poseedores
D Sınıfta
Ece: Bu kimin kitabı? = ¿De quién es este libro?
Mert: Ece'nin kitabı. = Es el libro de Ece.
Ece: Okulun kapısı açık mı? = ¿Está abierta la puerta de la escuela?
Mert: Evet, kapı açık. = Sí, la puerta está abierta.
w Bu kimin kitabı = ¿de quién es este libro?
w Ece'nin kitabı = el libro de Ece
w Okulun kapısı açık mı = ¿está abierta la puerta de la escuela?
w Okulun kapısı açık = la puerta de la escuela está abierta
w Evet kapı açık = sí la puerta está abierta
w kapı açık = la puerta está abierta
Q ¿Qué significa «okulun kapısı»?
+ La puerta de la escuela. :: El poseedor es okulun y el objeto kapısı.
- La escuela en la puerta. :: Cambia la relación entre los nombres.
- La llave de la casa. :: No aparecen anahtar ni ev.
Q ¿Qué pregunta «Kimin kitabı?»?
+ De quién es el libro. :: Kimin pregunta quién es el poseedor.
- Dónde está el libro. :: Nerede pregunta dónde.
- Cuántos libros hay. :: Kaç kitap pregunta cantidad.
R Ece'nin kitabı. :: Traduce.
+ El libro de Ece. :: El apóstrofo separa el sufijo del nombre propio.
- El cuaderno de la escuela. :: No aparece defter ni okul.
- La puerta de Ece. :: No aparece kapı.
H Okulun ___ açık. :: Completa «la puerta de la escuela está abierta».
+ kapısı :: La puerta recibe el sufijo de tercera persona.
- kapı :: Falta la marca de posesión.
- kapıda :: Significa «en la puerta».
A Bu kimin kitabı? :: ¿Qué información busca?
+ Quién es el dueño del libro. :: Kimin pregunta por el poseedor.
- Qué libro es nuevo. :: Yeni significa nuevo.
- Dónde está la escuela. :: Okul aparece en otra frase.
O Ece'nin kitabı :: El libro de Ece. :: El sufijo del nombre propio va tras apóstrofo.
X Escribe «la puerta de la escuela». :: okulun kapısı :: Marca al poseedor y al objeto.
