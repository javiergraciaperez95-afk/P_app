@ 13 | Günlük alışkanlıklar | Hábitos diarios
I Habla de lo que haces normalmente y de la frecuencia con que lo haces.
E Frecuencia :: **her gün** = todos los días; **genellikle** = generalmente; **bazen** = a veces; **nadiren** = rara vez. :: **-den önce** significa antes de y **-den sonra**, después de. :: El presente habitual suele terminar en **-r/-ar/-er**: **kahvaltı ederim** = desayuno.
W genellikle = generalmente | ge-nel-LIK-le
W nadiren = rara vez | na-di-REN
W kahvaltı ederim = desayuno | kah-val-tuh e-de-RIM
W işe = al trabajo | i-SHE
w kalkarım = me levanto | kal-ka-RUHM
w kalkar = se levanta habitualmente
w kahvaltıdan = después del desayuno
V Frecuencia y rutina
D Rutinas distintas
Ali: Her gün erken kalkarım. = Todos los días me levanto temprano.
Deniz: Ben genellikle saat yedide kalkarım. = Yo generalmente me levanto a las siete.
Ali: Kahvaltıdan sonra işe giderim. = Después de desayunar voy al trabajo.
Deniz: Ben bazen evde kahvaltı ederim. = A veces desayuno en casa.
w giderim = voy | gi-de-RIM
Q ¿Qué significa «bazen»?
+ a veces :: Bazen indica que algo ocurre algunas veces.
- todos los días :: Her gün significa todos los días.
- rara vez :: Nadiren significa rara vez.
Q ¿Qué hace Ali después de desayunar?
+ Va al trabajo :: İşe giderim = voy al trabajo.
- Se acuesta temprano :: No aparece dormir.
- Desayuna en casa :: Ali no dice eso.
Q «Genellikle» significa…
+ generalmente :: Genellikle expresa frecuencia habitual.
- después :: Después es sonra.
- temprano :: Temprano es erken.
Q ¿Qué significa «her gün»?
+ todos los días :: Her gün significa cada día.
- a veces :: Bazen.
- por la noche :: Gece.
R Ben bazen evde kahvaltı ederim. :: Traduce.
+ A veces desayuno en casa. :: Bazen = a veces; evde = en casa.
- Todos los días voy al trabajo. :: Her gün işe giderim.
- Desayuno después de las siete. :: No aparece yedi.
H Ali her gün erken ___ . :: Completa: «Ali se levanta temprano todos los días».
+ kalkar :: Kalkar es «se levanta» en hábito.
- gider :: Gider significa «va».
- yatar :: Yatar significa «se acuesta».
A Kahvaltıdan sonra işe giderim. :: Escucha el orden de la rutina.
+ Después de desayunar voy al trabajo. :: -dan sonra = después de.
- Antes del desayuno voy a casa. :: No se menciona antes.
- Generalmente desayuno a las siete. :: No aparece la hora.
O Her gün erken kalkarım :: Todos los días me levanto temprano :: Her gün indica frecuencia diaria.
X Escribe «Generalmente voy al trabajo» :: genellikle işe giderim :: Genellikle = generalmente.

@ 13 | Günümü planlamak | Organizar el día
I Explica tu horario y ordena actividades con expresiones de tiempo.
E Horarios :: **öğle yemeği** = almuerzo; **akşam yemeği** = cena; **boş zaman** = tiempo libre. :: **-dan önce/sonra** se une a un nombre: **işten sonra** = después del trabajo. :: **Saat kaçta?** pregunta «¿a qué hora?».
W öğle yemeği = almuerzo | ö-le ye-me-YI
W akşam yemeği = cena | ak-sham ye-me-YI
W işten sonra = después del trabajo | ish-ten son-RA
W toplantı = reunión | top-lan-TUH
W bitiyor = termina | bi-ti-YOR
w evime = a mi casa | e-vi-ME
w saat altıda = a las seis | sa-at al-tuh-DA
w dinlenirim = descanso | din-le-ni-RIM
w işten = del trabajo
w İşten = del trabajo
V El horario
D Al salir del trabajo
Can: Toplantı saat kaçta bitiyor? = ¿A qué hora termina la reunión?
Ece: Saat altıda bitiyor. = Termina a las seis.
Can: İşten sonra ne yaparsın? = ¿Qué haces después del trabajo?
Ece: Evime gider ve dinlenirim. = Voy a casa y descanso.
W ne yaparsın = qué haces | ne ya-par-SUHN
W gider = va | gi-DER
Q ¿Qué significa «kaçta»?
+ a qué hora :: Kaçta pregunta la hora de una actividad.
- qué día :: Hangi gün pregunta qué día.
- cuánto tiempo :: Ne kadar süre significa cuánto tiempo.
Q ¿A qué hora termina la reunión?
+ A las seis :: Saat altıda.
- A las siete :: Saat yedide.
- Después del trabajo :: İşten sonra.
Q «İşten sonra» significa…
+ después del trabajo :: -den sonra = después de.
- antes del trabajo :: Antes es önce.
- durante la reunión :: Reunión es toplantı.
Q ¿Qué hace Ece después del trabajo?
+ Va a casa y descansa :: Evime gider ve dinlenirim.
- Tiene una reunión :: La reunión termina a las seis.
- Almuerza en casa :: No se menciona el almuerzo.
R Toplantı saat altıda bitiyor. :: Traduce.
+ La reunión termina a las seis. :: Bitiyor = termina.
- La reunión empieza a las seis. :: Empieza es başlıyor.
- Voy a casa después del trabajo. :: Esa es otra frase.
H İşten sonra evime ___ . :: Completa: «Después del trabajo voy a casa».
+ giderim :: Giderim significa «voy» como hábito.
- bitiyor :: Termina.
- toplantı :: Reunión.
A Saat kaçta bitiyor? :: Escucha la pregunta.
+ ¿A qué hora termina? :: Kaçta = a qué hora.
- ¿Dónde termina? :: Nerede = dónde.
- ¿Cuándo empieza? :: Ne zaman = cuándo.
O İşten sonra dinlenirim :: Descanso después del trabajo :: İşten sonra = después del trabajo.
X Escribe «La cena termina a las ocho» :: akşam yemeği saat sekizde bitiyor :: Saat sekizde = a las ocho.

@ 13 | Alışkanlıklar ve değişiklikler | Hábitos y cambios
I Describe qué haces a menudo y qué está cambiando en tu vida.
E Frecuencia y progreso :: **her zaman** = siempre; **çoğu zaman** = la mayoría de las veces; **hiçbir zaman** = nunca. :: Para hablar de una acción en curso, conserva el presente progresivo que ya conoces: **bu hafta çok çalışıyorum** = esta semana estoy trabajando mucho. :: **ama** conecta dos ideas opuestas: «pero».
W her zaman = siempre | her za-MAN
W çoğu zaman = la mayoría de las veces | cho-u za-MAN
W hiçbir zaman = nunca | hiç-bir za-MAN
W bu hafta = esta semana | bu haf-TA
W değişiklik = cambio | de-yi-shik-LIK
W daha az = menos | da-HA az
w kitap okurum = leo libros habitualmente | ki-tap o-ku-RUM
w yürüyüş = paseo | yü-rü-YÜSH
w yürüyüş yaparım = paseo, salgo a caminar | yü-rü-yüsh ya-pa-RUHM
w okuyorum = estoy leyendo | o-ku-YO-rum
w yapar = hace
V Hábitos y cambios
D Un nuevo hábito
Deniz: Çoğu zaman kitap okurum. = La mayoría de las veces leo libros.
Anna: Ben de kitap okurum ama bu hafta daha az okuyorum. = Yo también leo, pero esta semana leo menos.
Deniz: Her zaman yürüyüş yapar mısın? = ¿Siempre sales a caminar?
Anna: Hayır, hiçbir zaman yağmurda yürüyüş yapmam. = No, nunca paseo bajo la lluvia.
W yağmurda = bajo la lluvia | yaa-mur-DA
w yapmam = no hago | yap-MAM
Q ¿Qué significa «çoğu zaman»?
+ la mayoría de las veces :: Es una expresión de frecuencia.
- nunca :: Nunca es hiçbir zaman.
- esta semana :: Bu hafta.
Q ¿Qué cambio menciona Anna?
+ Esta semana lee menos :: Daha az okuyorum significa leo menos.
- Esta semana camina más :: No menciona caminar esta semana.
- Nunca lee libros :: Deniz sí dice que suele leer.
Q «Her zaman» significa…
+ siempre :: Her zaman expresa frecuencia total.
- a veces :: Bazen.
- generalmente :: Genellikle.
Q ¿Cuándo no pasea Anna?
+ Cuando llueve :: Yağmurda = bajo la lluvia; yapmam = no hago.
- Después del trabajo :: No aparece en el diálogo.
- Esta semana :: Bu hafta no es la respuesta.
R Bu hafta daha az okuyorum. :: Traduce.
+ Esta semana leo menos. :: Bu hafta = esta semana; daha az = menos.
- Siempre leo libros. :: Her zaman kitap okurum.
- Nunca paseo bajo la lluvia. :: Esa es la frase de Anna.
H Hiçbir zaman yağmurda yürüyüş ___ . :: Completa: «Nunca paseo bajo la lluvia».
+ yapmam :: Yapmam = no hago.
- yaparım :: Yap hago afirmativo.
- okuyorum :: Estoy leyendo.
A Ben de kitap okurum. :: Escucha el hábito.
+ Yo también leo libros. :: Ben de = yo también.
- Esta semana leo menos. :: No aparece esta semana.
- Nunca paseo. :: No aparece nunca.
O Çoğu zaman kitap okurum :: La mayoría de las veces leo libros :: Çoğu zaman indica frecuencia.
X Escribe «Siempre salgo a caminar» :: her zaman yürüyüş yaparım :: Her zaman = siempre.
