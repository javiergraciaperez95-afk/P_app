@ 19 | Teknoloji günlük hayatta | Tecnología en la vida diaria
I Explica para qué sirve un aparato y describe pasos sencillos para usarlo.
E Tecnología :: **cihaz** = aparato; **düğme** = botón; **ekran** = pantalla. :: **ne işe yarar?** pregunta «¿para qué sirve?». :: Para ordenar instrucciones: **önce** (primero), **sonra** (después), **en sonunda** (al final).
W cihaz = aparato | ji-HAZ
W düğme = botón | dü-ME
W ekran = pantalla | ek-RAN
W ne işe yarar = para qué sirve | ne i-she ya-RAR
W açmak = encender; abrir | ach-MAK
W kapatmak = apagar; cerrar | ka-pat-MAK
W şifre = contraseña | şif-RE
W önce = primero | ÖN-je
w çalıştırmak = poner en marcha | cha-lısh-tır-MAK
w yarıyor = sirve
w İnternete = a internet | in-ter-ne-TE
w bağlanıyor = se conecta
w düğmeye = al botón
w Ekranı = la pantalla | ek-ra-NI
V Instrucciones de uso
D Ayuda con una tableta
Ali: Bu cihaz ne işe yarıyor? = ¿Para qué sirve este aparato?
Ece: İnternete bağlanıyor. Önce düğmeye bas, sonra şifreni gir. = Se conecta a internet. Primero pulsa el botón y después escribe tu contraseña.
Ali: En sonunda ne yapmalıyım? = ¿Qué debo hacer al final?
Ece: Ekranı kontrol et. = Comprueba la pantalla.
W internete = a internet | in-ter-ne-TE
W bağlanmak = conectarse | ba-ğlan-MAK
W bas = pulsa | bas
W şifreni = tu contraseña | şif-re-NI
W gir = escribe; introduce | gir
W kontrol et = comprueba | kon-trol et
Q ¿Qué significa «cihaz»?
+ aparato :: Cihaz es un dispositivo.
- pantalla :: Pantalla es ekran.
- contraseña :: Contraseña es şifre.
Q ¿Para qué sirve el aparato?
+ Para conectarse a internet :: İnternete bağlanıyor.
- Para lavar la ropa :: No aparece lavadora.
- Para hacer llamadas :: No se menciona teléfono.
Q ¿Qué debe hacerse primero?
+ Pulsar el botón :: Önce düğmeye bas.
- Escribir la contraseña :: Eso viene después.
- Comprobar la pantalla :: Eso es al final.
Q «Şifreni gir» significa…
+ introduce tu contraseña :: Şifreni = tu contraseña; gir = introduce.
- apaga la pantalla :: Kapat = apaga.
- pulsa el botón :: Bas = pulsa.
R Ekranı kontrol et. :: Traduce.
+ Comprueba la pantalla. :: Kontrol et = comprueba.
- Enciende el aparato. :: Enciende es cihazı aç.
- Escribe tu contraseña. :: Esa es otra instrucción.
H Önce düğmeye ___ . :: Completa: «Primero pulsa el botón».
+ bas :: Bas es el imperativo «pulsa».
- gir :: Introduce.
- kontrol et :: Comprueba.
A Şifreni gir. :: Escucha la instrucción.
+ Introduce tu contraseña. :: Gir = introduce.
- Comprueba la pantalla. :: Ekranı kontrol et.
- Apaga el aparato. :: Cihazı kapat.
O Önce düğmeye bas :: Primero pulsa el botón :: Önce ordena el primer paso.
X Escribe «¿Para qué sirve este aparato?» :: bu cihaz ne işe yarar :: Ne işe yarar pregunta por la función.

@ 19 | Güncel haberler ve fikirler | Actualidad y opiniones
I Comenta una noticia sencilla, expresa tu opinión y conecta ideas con una razón.
E Noticias y opiniones :: **haber** = noticia; **çevre** = medioambiente/entorno; **fikir** = opinión/idea. :: **bence** = en mi opinión; **katılıyorum** = estoy de acuerdo; **katılmıyorum** = no estoy de acuerdo. :: **çünkü** introduce el motivo.
W haber = noticia | ha-BER
W çevre = medioambiente | çev-RE
W fikir = idea; opinión | fi-KIR
W katılmak = estar de acuerdo; participar | ka-tıl-MAK
W katılıyorum = estoy de acuerdo | ka-tı-lı-YO-rum
W katılmıyorum = no estoy de acuerdo | ka-tıl-mı-YO-rum
W önemli = importante | ö-nem-LI
W korumak = proteger | ko-ru-MAK
w haberler = noticias | ha-ber-LER
V Opinar
D Una noticia local
Deniz: Şehirde yeni bir park açılacak. = Se abrirá un parque nuevo en la ciudad.
Can: Bence bu çok önemli çünkü çevreyi korumalıyız. = En mi opinión, esto es muy importante porque debemos proteger el medioambiente.
Deniz: Sana katılıyorum. Parklar herkese lazım. = Estoy de acuerdo contigo. Los parques son necesarios para todos.
Can: Bu fikir güzel. = Esta idea es buena.
W açılacak = se abrirá | a-chuh-la-JAK
W çevreyi = el medioambiente (objeto) | çev-re-YI
W korumalıyız = debemos proteger | ko-ru-ma-luh-YUZ
W sana = a ti | sa-NA
W parklar = parques | park-LAR
W herkese = para todos | her-ke-SE
Q ¿Qué significa «haber»?
+ noticia :: Haber es información sobre un hecho.
- opinión :: Opinión es fikir.
- parque :: Parque es park.
Q ¿Qué ocurrirá en la ciudad?
+ Se abrirá un parque nuevo :: Yeni bir park açılacak.
- Cerrarán una escuela :: Escuela es okul.
- Construirán un hospital :: Hospital es hastane.
Q ¿Qué significa «bence»?
+ en mi opinión :: Bence introduce una opinión.
- estoy de acuerdo :: Katılıyorum.
- porque :: Çünkü.
Q ¿Por qué considera importante el parque?
+ Porque debemos proteger el medioambiente :: Çevreyi korumalıyız.
- Porque está cerca de casa :: No se menciona la ubicación.
- Porque habrá una fiesta :: No se menciona una fiesta.
R Sana katılıyorum. :: Traduce.
+ Estoy de acuerdo contigo. :: Sana = contigo/a ti; katılıyorum = estoy de acuerdo.
- No estoy de acuerdo contigo. :: Katılmıyorum sería negativo.
- Estoy de acuerdo con el parque. :: No dice con el parque.
H Çevreyi ___ . :: Completa: «Debemos proteger el medioambiente».
+ korumalıyız :: -malı expresa obligación.
- açılacak :: Se abrirá.
- katılıyorum :: Estoy de acuerdo.
A Bence bu çok önemli. :: Escucha la opinión.
+ En mi opinión, esto es muy importante. :: Bence = en mi opinión.
- No estoy de acuerdo. :: Katılmıyorum.
- El parque se abrirá. :: Park açılacak.
O Çevreyi korumalıyız :: Debemos proteger el medioambiente :: -malı/-meli expresa necesidad.
X Escribe «Estoy de acuerdo» :: katılıyorum :: Katılıyorum = estoy de acuerdo.

@ 19 | Öneri ve şart | Consejos y condiciones
I Da un consejo y explica el resultado de una condición sencilla.
E Consejos y condición :: **gerekmek** = ser necesario; **zorunda olmak** = tener que. :: **daha çok** = más; **daha az** = menos. :: La condición con **-sa/-se** enlaza una situación y su resultado: **erken yatarsan dinlenirsin** = si te acuestas temprano, descansas.
W gerek = necesario | ge-REK
W zorunda = obligado/a; tener que | zor-un-DA
W yatmak = acostarse | yat-MAK
W yatarsan = si te acuestas | ya-tar-SAN
W dinlenirsin = descansas | din-le-nir-SIN
W sağlıklı = saludable | saah-luhk-LUH
w sebze = verdura | seb-ZE
w spor yapmak = hacer deporte | spor yap-MAK
w eğer = si | e-ĞER
w yorgunum = estoy cansado/a
w spor = deporte
w yaparsan = si haces
w olursun = serás/estarás
V Consejos saludables
D Un consejo
Ece: Son zamanlarda çok yorgunum. = Últimamente estoy muy cansada.
Anna: Daha çok uyuman gerek. Her gün spor yaparsan daha sağlıklı olursun. = Necesitas dormir más. Si haces deporte todos los días, estarás más saludable.
Ece: Haklısın. Daha az kahve içmeliyim. = Tienes razón. Debo tomar menos café.
Anna: Evet, erken yatarsan daha iyi dinlenirsin. = Sí, si te acuestas temprano, descansas mejor.
W son zamanlarda = últimamente | son za-man-lar-DA
W uyumak = dormir | u-yu-MAK
W uyuman = que duermas | u-yu-MAN
W olur = serás/estarás | o-LUR
W içmeliyim = debo beber/tomar | ich-me-li-YIM
W erken yatarsan = si te acuestas temprano | er-ken ya-tar-SAN
Q ¿Qué significa «zorunda»?
+ tener que; estar obligado/a :: Zorunda expresa obligación.
- poder :: Poder es -ebilmek.
- quizá :: Quizá es belki.
Q ¿Qué consejo da Anna primero?
+ Dormir más :: Daha çok uyuman gerek.
- Tomar más café :: Debe tomar menos café.
- Dejar el deporte :: Le recomienda hacer deporte.
Q «Daha az» significa…
+ menos :: Daha az es menos.
- más :: Más es daha çok.
- saludable :: Saludable es sağlıklı.
Q ¿Qué ocurrirá si Ece hace deporte cada día?
+ Estará más saludable :: Her gün spor yaparsan daha sağlıklı olursun.
- Estará más cansada :: No es el resultado que se indica.
- Dormirá menos :: No se dice.
R Daha az kahve içmeliyim. :: Traduce.
+ Debo tomar menos café. :: -meliyim = debo; daha az = menos.
- Quiero tomar más café. :: Quiero = istiyorum.
- Si tomo café, duermo. :: No aparece una condición.
H Erken yatarsan daha iyi ___ . :: Completa: «Si te acuestas temprano, descansas mejor».
+ dinlenirsin :: Dinlenirsin = descansas.
- yatarsan :: Si te acuestas.
- uyuman :: Que duermas.
A Her gün spor yaparsan daha sağlıklı olursun. :: Escucha el consejo.
+ Si haces deporte cada día, estarás más saludable. :: -san expresa condición.
- Debes dormir más. :: Esa es la primera recomendación.
- Últimamente estoy cansada. :: Esa frase abre el diálogo.
O Her gün spor yaparsan sağlıklı olursun :: Si haces deporte cada día, estarás saludable :: -san/-sen introduce la condición.
X Escribe «Necesitas dormir más» :: daha çok uyuman gerek :: Gerek expresa necesidad.
