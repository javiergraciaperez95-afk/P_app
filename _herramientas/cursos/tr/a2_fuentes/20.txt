@ 20 | Seyahat planı | Planear un viaje
I Pregunta por un destino, elige transporte y habla de la duración del viaje.
E Viajes :: **seyahat** = viaje; **tren** = tren; **uçak** = avión; **otobüs** = autobús. :: **-le/-la** puede significar «con/en»: **trenle** = en tren. :: **kaç günlüğüne?** pregunta «¿por cuántos días?».
W trenle = en tren | tren-LE
W uçak = avión | u-CHAK
W kaç günlüğüne = por cuántos días | kach gün-lü-ĞÜ-ne
W seyahat = viaje | se-ya-HAT
w dönüş = regreso | dö-NÜSH
w gidiş dönüş = ida y vuelta | gi-dish dö-NÜSH
w gideceksin = irás
w için = para | i-CHIN
V Preparar el viaje
D En la estación
Ali: İstanbul'a nasıl gideceksin? = ¿Cómo irás a Estambul?
Deniz: Trenle gideceğim. Biletimi aldım. = Iré en tren. Ya compré mi billete.
Ali: Kaç günlüğüne kalacaksın? = ¿Por cuántos días te quedarás?
Deniz: Hafta sonu için. Pazar günü döneceğim. = Para el fin de semana. Volveré el domingo.
W İstanbul'a = a Estambul | is-tan-bu-LA
W biletimi = mi billete | bi-le-ti-MI
W aldım = compré | al-DUHM
W pazar günü = el domingo | pa-zar gü-NÜ
W döneceğim = volveré | dö-ne-JE-im
Q ¿Qué significa «tren»?
+ tren :: Tren es el medio de transporte.
- autobús :: Otobüs.
- billete :: Bilet.
Q ¿Cómo viajará Deniz a Estambul?
+ En tren :: Trenle gideceğim.
- En avión :: Uçakla.
- En autobús :: Otobüsle.
Q «Kaç günlüğüne?» pregunta…
+ por cuántos días :: Gün = día; günlüğüne = por un número de días.
- a qué hora :: Kaçta.
- con quién :: Kimle.
Q ¿Cuándo volverá Deniz?
+ El domingo :: Pazar günü döneceğim.
- El sábado :: Cumartesi günü.
- El lunes :: Pazartesi günü.
R Biletimi aldım. :: Traduce.
+ Compré mi billete. :: Aldım = compré; biletimi = mi billete.
- Comprarás tu billete. :: Futuro sería alacağım.
- ¿Dónde está mi billete? :: Nerede = dónde.
H Trenle ___ . :: Completa: «Iré en tren».
+ gideceğim :: Gideceğim = iré.
- gittim :: Fui.
- gidiyorum :: Estoy yendo.
A İstanbul'a nasıl gideceksin? :: Escucha la pregunta.
+ ¿Cómo irás a Estambul? :: Nasıl = cómo; gideceksin = irás.
- ¿Cuándo irás a Estambul? :: Ne zaman = cuándo.
- ¿Por cuántos días irás? :: Kaç günlüğüne.
O Pazar günü döneceğim :: Volveré el domingo :: Döneceğim = volveré.
X Escribe «Iré en avión» :: uçakla gideceğim :: Uçakla = en avión.

@ 20 | Otel ve rezervasyon | Hotel y reservas
I Reserva una habitación, pregunta por el precio y entiende información básica de alojamiento.
E Alojamientos :: **otel** = hotel; **oda ayırtmak** = reservar una habitación; **gecelik** = por noche. :: **kahvaltı dahil** = desayuno incluido; **boş oda** = habitación disponible. :: **bir gece** = una noche; **iki kişilik oda** = habitación doble.
W oda ayırtmak = reservar una habitación | o-da a-yırt-MAK
W gecelik = por noche | ge-je-LIK
W boş oda = habitación libre | bosh o-DA
W iki kişilik oda = habitación doble | i-ki ki-shi-LIK o-DA
w müsait = disponible | mü-SA-it
w gecelik fiyat = precio por noche | ge-je-lik fi-YAT
V Reservar
D Llamar al hotel
Misafir: Merhaba, cuma gecesi için oda ayırtmak istiyorum. = Hola, quiero reservar una habitación para el viernes por la noche.
Görevli: Tek kişilik mi, iki kişilik mi? = ¿Individual o doble?
Misafir: İki kişilik oda. Kahvaltı dahil mi? = Una habitación doble. ¿Está incluido el desayuno?
Görevli: Evet, gecelik fiyat 900 lira. = Sí, el precio por noche es de 900 liras.
N Misafir, Görevli
W cuma gecesi = el viernes por la noche | ju-ma ge-je-SI
W 900 = novecientos | dokuz yüz
Q ¿Qué significa «otel»?
+ hotel :: Otel es un lugar de alojamiento.
- reserva :: Reserva es rezervasyon.
- habitación :: Habitación es oda.
Q ¿Qué tipo de habitación reserva la persona?
+ Una doble :: İki kişilik oda.
- Una individual :: Tek kişilik.
- Una habitación familiar :: No se menciona.
Q «Kahvaltı dahil mi?» significa…
+ ¿Está incluido el desayuno? :: Kahvaltı = desayuno; dahil = incluido.
- ¿A qué hora es el desayuno? :: Saat kaçta = a qué hora.
- ¿Hay una habitación libre? :: Boş oda var mı?
Q ¿Cuál es el precio por noche?
+ 900 liras :: Gecelik fiyat 900 lira.
- 90 liras :: No es noventa.
- 900 euros :: La moneda es lira.
R Oda ayırtmak istiyorum. :: Traduce.
+ Quiero reservar una habitación. :: Ayırtmak = reservar; istiyorum = quiero.
- Quiero cancelar mi habitación. :: Cancelar es iptal etmek.
- ¿Hay una habitación libre? :: Esa es una pregunta.
H İki ___ oda. :: Completa: «Una habitación doble».
+ kişilik :: İki kişilik = para dos personas.
- gecelik :: Por noche.
- dahil :: Incluido.
A Gecelik fiyat 900 lira. :: Escucha el precio.
+ El precio por noche es de 900 liras. :: Gecelik = por noche.
- La habitación doble cuesta 90 liras. :: El precio es 900.
- El desayuno cuesta 900 liras. :: Es el precio de la habitación.
O Cuma gecesi için oda ayırtmak istiyorum :: Quiero reservar una habitación para el viernes por la noche :: - için = para.
X Escribe «¿Hay una habitación libre?» :: boş oda var mı :: Boş oda = habitación disponible.

@ 20 | Yolculuk ve A2 tekrarı | Viaje y repaso A2
I Usa lo aprendido para resolver situaciones de viaje y demostrar que puedes comunicar planes, experiencias y necesidades.
E Viajar con autonomía :: En un viaje puedes pedir información con **Nereden bilet alabilirim?** («¿Dónde puedo comprar un billete?») y explicar un problema con **Yardımınıza ihtiyacım var** («Necesito su ayuda»). :: Para narrar, sitúa la acción en el pasado; para organizar un plan, usa futuro y expresiones de tiempo. :: Repasa presentaciones, comparaciones, rutina, compras, trabajo, consejos y condiciones.
W nereden = desde dónde; dónde | ne-re-DEN
W yardımınıza = su ayuda | yar-dı-mı-NUH-za
W kayıp = perdido/a | ka-YUP
W bagaj = equipaje | ba-GAJ
W danışma = información; mostrador | da-nısh-MA
w bulmak = encontrar | bul-MAK
w yardımınıza ihtiyacım var = necesito su ayuda | yar-dı-mı-nı-za ih-ti-ya-JUHM var
w durağı = parada | du-ra-UH
w gişesinin = de la taquilla
w Yardımcı = ayudar | yar-dım-JUH
w olabilir = puede
w miyim = ¿puedo?
w eşya = objeto/pertenencia
w bürosuna = a la oficina
V Viaje y repaso
D En la estación
Yolcu: Affedersiniz, danışma nerede? = Disculpe, ¿dónde está información?
Görevli: Bilet gişesinin yanında. Yardımcı olabilir miyim? = Al lado de la taquilla. ¿Puedo ayudarle?
Yolcu: Bagajımı kaybettim. Yardımınıza ihtiyacım var. = Perdí mi equipaje. Necesito su ayuda.
Görevli: Önce kayıp eşya bürosuna gidin. = Primero vaya a la oficina de objetos perdidos.
N Yolcu
W affedersiniz = disculpe | af-fe-der-si-NIZ
W bilet gişesi = taquilla | bi-let gi-she-SI
W bagajımı = mi equipaje | ba-ga-jı-MUH
W kaybettim = perdí | kay-bet-TIM
W kayıp eşya bürosu = oficina de objetos perdidos | ka-yıp eş-ya bü-ro-SU
w gidin = vaya | gi-DIN
Q ¿Qué significa «danışma»?
+ información; mostrador de información :: Danışma es un lugar donde se pide información.
- taquilla :: Bilet gişesi.
- hotel :: Otel.
Q ¿Dónde está el mostrador de información?
+ Al lado de la taquilla :: Bilet gişesinin yanında.
- Enfrente del hotel :: No aparece hotel.
- En la parada :: Durağı = parada.
Q ¿Qué problema tiene el viajero?
+ Perdió su equipaje :: Bagajımı kaybettim.
- Perdió el billete :: Bilet es billete.
- El tren llega tarde :: No se menciona retraso.
Q ¿Adónde debe ir primero?
+ A la oficina de objetos perdidos :: Kayıp eşya bürosuna gidin.
- A la taquilla :: La taquilla solo es referencia de ubicación.
- Al hotel :: No se menciona hotel.
R Yardımınıza ihtiyacım var. :: Traduce.
+ Necesito su ayuda. :: Yardımınıza = su ayuda; ihtiyacım var = necesito.
- Puedo ayudarle. :: Yardımcı olabilir miyim?
- Mi equipaje está perdido. :: No es la frase exacta.
H Bagajımı ___ . :: Completa: «Perdí mi equipaje».
+ kaybettim :: Kaybettim = perdí.
- buldum :: Encontré.
- alacağım :: Compraré/recibiré.
A Önce kayıp eşya bürosuna gidin. :: Escucha la indicación.
+ Primero vaya a la oficina de objetos perdidos. :: Önce = primero.
- Primero compre un billete. :: Bilet al = compre un billete.
- La oficina está al lado de la taquilla. :: Esa es otra frase.
O Bagajımı kaybettim :: Perdí mi equipaje :: -dim/-dım marca el pasado.
X Escribe «¿Dónde está información?» :: danışma nerede :: Nerede = dónde está.

@ 20 | A2 genel değerlendirme | Evaluación general A2
I Comprueba lo que sabes hacer en situaciones cotidianas: presentarte, contar una experiencia, organizar un plan y pedir ayuda.
E Repaso integrado :: **Daha önce ne yaptın?** = ¿Qué hiciste antes?; **gelecek hafta ne yapacaksın?** = ¿qué harás la semana que viene? :: Recuerda elegir el tiempo verbal según la referencia temporal y mantener el orden de palabras turco. :: Un mensaje claro suele incluir saludo, motivo, datos importantes y despedida.
W daha önce = antes; anteriormente | da-ha ön-JE
W mesaj = mensaje | me-SAJ
W iyi yolculuklar = buen viaje | i-yi yol-ju-LUK-lar
w iyi = bueno/a; bien | i-YI
w Şehir = ciudad | she-HIR
w Otelde = en el hotel | o-tel-DE
w gerekirse = si hace falta
w danışmaya = a información
V Repaso final
T Un viaje planificado
- Geçen ay İstanbul'a gittim. = El mes pasado fui a Estambul.
- Şehir çok güzeldi çünkü eski binaları gezdim. = La ciudad era muy bonita porque visité edificios antiguos.
- Gelecek hafta ailemle Ankara'ya gideceğim. = La semana que viene iré a Ankara con mi familia.
- Otelde iki kişilik oda ayırttım. = Reservé una habitación doble en el hotel.
- Yolculuk sırasında yardım gerekirse danışmaya soracağım. = Si necesito ayuda durante el viaje, preguntaré en información.
W geçen ay = el mes pasado | ge-chen AY
W binaları = los edificios | bi-na-la-RUH
W ailemle = con mi familia | a-i-lem-LE
W ayırttım = reservé | a-yırt-TUHM
W sırasında = durante | sı-ra-SUH-n-da
W soracağım = preguntaré | so-ra-ja-UHM
Q ¿Cuándo fue la primera visita a Estambul?
+ El mes pasado :: Geçen ay = el mes pasado.
- La semana que viene :: Esa es la visita a Ankara.
- Hace dos años :: No aparece esa fecha.
Q ¿Por qué le gustó la ciudad?
+ Porque visitó edificios antiguos :: Es la razón que da el texto.
- Porque el hotel era barato :: No se menciona el precio.
- Porque fue con su familia :: La familia irá a Ankara.
Q ¿Qué hará la semana que viene?
+ Irá a Ankara con su familia :: Gelecek hafta ailemle Ankara'ya gideceğim.
- Volverá a Estambul :: No se dice.
- Buscará un hotel :: Ya reservó una habitación.
Q «İki kişilik oda ayırttım» significa…
+ Reservé una habitación doble :: İki kişilik = para dos personas.
- Reservé dos habitaciones individuales :: No dice dos habitaciones.
- Quiero reservar una habitación :: Ayırttım es pasado.
R Yolculuk sırasında yardım gerekirse danışmaya soracağım. :: Traduce.
+ Si necesito ayuda durante el viaje, preguntaré en información. :: Gerekirse = si hace falta.
- Pregunté en información durante el viaje. :: Soracağım es futuro.
- Necesito reservar una habitación doble. :: No habla de reserva.
H Gelecek hafta Ankara'ya ___ . :: Completa: «La semana que viene iré a Ankara».
+ gideceğim :: Futuro de gitmek (ir).
- gittim :: Fui.
- gidiyorum :: Estoy yendo.
A Geçen ay İstanbul'a gittim. :: Escucha cuándo viajó.
+ El mes pasado fui a Estambul. :: Geçen ay = el mes pasado.
- La semana que viene iré a Ankara. :: Futuro y otro destino.
- Este mes visitaré Estambul. :: No dice este mes.
O Otelde iki kişilik oda ayırttım :: Reservé una habitación doble en el hotel :: Ayırttım está en pasado.
X Escribe «Buen viaje» :: iyi yolculuklar :: Fórmula para desear un buen viaje.

@ 20 | Kendini değerlendir | Autoevaluación A2
I Repasa tus objetivos: entender mensajes breves, hablar de experiencias y planes, y comunicarte en tareas cotidianas.
E Puedo hacerlo :: Puedo presentarme con más detalle y describir a otras personas. :: Puedo explicar mi entorno, mis rutinas, mis gustos y mis planes. :: Puedo comprar, pedir información, contar algo que ocurrió y escribir un mensaje breve.
w yağarsa = si llueve | yaa-rar-SA
w rezervasyonunuz = su reserva | re-zer-vas-yo-nu-NUZ
w hazır = listo/a | ha-ZUHR
Q ¿Qué tiempo verbal usarías para «el fin de semana pasado»?
+ Pasado :: Geçen hafta sonu sitúa una acción terminada.
- Futuro :: El futuro expresa planes posteriores.
- Presente habitual :: Describe rutinas.
Q ¿Qué expresión significa «la semana que viene»?
+ gelecek hafta :: Gelecek = futuro/próximo.
- geçen hafta :: La semana pasada.
- her hafta :: Cada semana.
Q ¿Cómo expresas «en mi opinión»?
+ bence :: Bence introduce una opinión.
- belki :: Belki = quizás.
- çünkü :: Çünkü = porque.
Q ¿Qué frase formula una petición cortés?
+ Yardımcı olabilir misiniz? :: Es una pregunta formal «¿puede ayudarme?».
- Çok yorgunum. :: Estoy muy cansado/a.
- Dün müzeye gittim. :: Ayer fui al museo.
R Gelecek hafta ailemi ziyaret edeceğim. :: Traduce.
+ La semana que viene visitaré a mi familia. :: Gelecek hafta = la semana que viene.
- La semana pasada visité a mi familia. :: Pasado sería ziyaret ettim.
- Visito a mi familia todos los días. :: Rutina: her gün ziyaret ederim.
H Yağmur yağarsa ___ . :: Completa una condición: «Si llueve, me quedaré en casa».
+ evde kalacağım :: Evde = en casa; kalacağım = me quedaré.
- evde kaldım :: Me quedé en casa.
- evde kalıyorum :: Me estoy quedando en casa.
A Otel rezervasyonunuz hazır. :: Escucha el mensaje.
+ Su reserva de hotel está lista. :: Rezervasyonunuz = su reserva.
- Su billete de tren está listo. :: Tren es tren.
- El hotel está cerrado. :: Cerrado es kapalı.
O Bence Türkçe öğrenmek çok güzel :: En mi opinión, aprender turco es muy bonito :: Bence = en mi opinión.
X Escribe «Necesito su ayuda» :: yardımınıza ihtiyacım var :: İhtiyacım var expresa necesidad.
