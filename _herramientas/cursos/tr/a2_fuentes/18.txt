@ 18 | Gelecek planlarım | Mis planes de futuro
I Cuenta qué vas a hacer y pregunta a alguien por sus planes.
E Futuro :: El futuro usa **-(y)acak/-(y)ecek**: **gideceğim** = iré, **yapacağım** = haré. :: **gelecek hafta** = la semana que viene; **bir saat içinde** = dentro de una hora. :: Añade **mi** para preguntar: **gidecek misin?** = ¿irás?
W gideceğim = iré | gi-de-JE-im
W yapacağım = haré | ya-pa-JA-UM
W gelecek hafta = la semana que viene | ge-le-JEK haf-TA
W bir saat içinde = dentro de una hora | bir sa-at i-chin-DE
W tatil = vacaciones | ta-TIL
W plan = plan | plan
W ziyaret etmek = visitar | zi-ya-ret et-MEK
w gidecek misin = ¿irás? | gi-de-JEK mi-sin
w ailemi = a mi familia | a-i-le-MI
w ziyaret = visitar
w edeceğim = haré; realizaré
w kalacağım = me quedaré
V Planes
D Hablar del verano
Ali: Yazın ne yapacaksın? = ¿Qué harás en verano?
Ece: Ailemi ziyaret edeceğim. = Visitaré a mi familia.
Ali: Kaç gün kalacaksın? = ¿Cuántos días te quedarás?
Ece: İki hafta kalacağım. Sonra tatile gideceğim. = Me quedaré dos semanas. Después me iré de vacaciones.
W yapacaksın = harás | ya-pa-ja-KSUHN
W kalacaksın = te quedarás | ka-la-ja-KSUHN
W iki hafta = dos semanas | i-ki haf-TA
w tatile = de vacaciones | ta-ti-LE
Q ¿Qué significa «gideceğim»?
+ iré :: Es el futuro de gitmek (ir).
- fui :: Fui es gittim.
- voy :: Voy es gidiyorum.
Q ¿Qué hará Ece en verano?
+ Visitará a su familia :: Ailemi ziyaret edeceğim.
- Trabajará en una oficina :: No dice trabajar.
- Irá a Ankara primero :: Ankara no aparece.
Q «Gelecek hafta» significa…
+ la semana que viene :: Gelecek = próximo/futuro.
- la semana pasada :: Geçen hafta.
- dentro de una hora :: Bir saat içinde.
Q ¿Cuánto tiempo se quedará Ece?
+ Dos semanas :: İki hafta.
- Dos días :: İki gün.
- Una hora :: Bir saat.
R Sonra tatile gideceğim. :: Traduce.
+ Después me iré de vacaciones. :: Sonra = después; tatile gideceğim = iré de vacaciones.
- Antes de las vacaciones visitaré a mi familia. :: No dice antes.
- La semana que viene me quedaré dos días. :: Esa no es la frase.
H Ailemi ziyaret ___ . :: Completa: «Visitaré a mi familia».
+ edeceğim :: Ziyaret edeceğim = visitaré.
- ettim :: Visité.
- ediyorum :: Estoy visitando.
A Yazın ne yapacaksın? :: Escucha la pregunta.
+ ¿Qué harás en verano? :: Yazın = en verano; ne yapacaksın = qué harás.
- ¿Qué hiciste el verano pasado? :: Geçen yaz ne yaptın?
- ¿Cuándo visitarás a tu familia? :: Ne zaman?
O Ailemi ziyaret edeceğim :: Visitaré a mi familia :: -(y)acağım expresa una acción futura.
X Escribe «¿Cuántos días te quedarás?» :: kaç gün kalacaksın :: Kaç gün = cuántos días.

@ 18 | Kutlamalar ve özel günler | Celebraciones y días especiales
I Habla de una celebración y ofrece una felicitación o un regalo.
E Celebrar :: **doğum günü** = cumpleaños; **bayram** = festividad; **hediye** = regalo. :: **kutlamak** = celebrar; **tebrik etmek** = felicitar. :: Para enumerar: **ilk olarak** = primero; **son olarak** = por último.
W bayram = festividad | bay-RAM
W hediye = regalo | he-di-YE
W kutlamak = celebrar | kut-la-MAK
W tebrik etmek = felicitar | teb-rik et-MEK
W ilk olarak = primero | ilk o-la-RAK
W son olarak = por último | son o-la-RAK
w davetli = invitado/a | da-vet-LI
w afiyet olsun = buen provecho | a-fi-yet ol-SUN
w gününü = su día
w kutlayacaksınız = celebraréis
w İlk = primero (orden de acciones) | ilk
w arkadaşlarımızı = a nuestros amigos/as
V Una fiesta
D Preparativos de cumpleaños
Anna: Doğum gününü nasıl kutlayacaksınız? = ¿Cómo vais a celebrar el cumpleaños?
Deniz: İlk olarak pasta alacağız. Son olarak arkadaşlarımızı davet edeceğiz. = Primero compraremos una tarta. Por último invitaremos a nuestros amigos.
Anna: Hediye de alacak mısınız? = ¿También compraréis un regalo?
Deniz: Evet, küçük bir hediye alacağız. = Sí, compraremos un regalo pequeño.
W pasta = tarta | pas-TA
W alacağız = compraremos/tomaremos | a-la-JA-UZ
W davet etmek = invitar | da-vet et-MEK
W davet edeceğiz = invitaremos | da-vet e-de-JE-iz
W alacak mısınız = ¿compraréis? | a-la-JAK muh-suh-nuhz
Q ¿Qué significa «doğum günü»?
+ cumpleaños :: Literalmente, día de nacimiento.
- festividad :: Festividad es bayram.
- invitación :: Invitación es davetiye.
Q ¿Qué harán primero?
+ Comprar una tarta :: İlk olarak pasta alacağız.
- Invitar a sus amigos :: Eso será al final.
- Comprar flores :: Flores es çiçekler.
Q «Son olarak» significa…
+ por último :: Presenta la última acción.
- primero :: Primero es ilk olarak.
- después de la fiesta :: Después es kutlamadan sonra.
Q ¿Qué regalo comprarán?
+ Uno pequeño :: Küçük bir hediye.
- Una tarta grande :: La tarta se compra antes.
- Flores :: No se mencionan flores.
R Arkadaşlarımızı davet edeceğiz. :: Traduce.
+ Invitaremos a nuestros amigos. :: Davet edeceğiz = invitaremos.
- Nuestros amigos nos invitaron. :: Eso sería bizi davet ettiler.
- Compraremos un regalo. :: Hediye alacağız.
H İlk olarak pasta ___ . :: Completa: «Primero compraremos una tarta».
+ alacağız :: Alacağız = compraremos/tomaremos.
- alıyoruz :: Estamos comprando.
- aldık :: Compramos.
A Hediye de alacak mısınız? :: Escucha la pregunta.
+ ¿También compraréis un regalo? :: De significa también.
- ¿Qué regalo comprasteis? :: Eso sería hangi hediyeyi aldınız?
- ¿Vais a celebrar el cumpleaños? :: Esa pregunta aparece al inicio.
O Son olarak arkadaşlarımızı davet edeceğiz :: Por último invitaremos a nuestros amigos :: Son olarak ordena la última acción.
X Escribe «Feliz cumpleaños» :: doğum günün kutlu olsun :: Fórmula habitual de felicitación.

@ 18 | Davet ve olasılık | Invitaciones y posibilidad
I Acepta o rechaza una invitación y haz una predicción sencilla.
E Invitaciones y posibilidad :: **davet etmek** = invitar; **katılmak** = asistir/participar. :: **Belki** = quizás; **muhtemelen** = probablemente. :: **yağmur yağabilir** = puede que llueva; **gelebilirim** = quizá pueda venir.
W davet = invitación | da-VET
W katılmak = asistir; participar | ka-tıl-MAK
W belki = quizás | bel-KI
W muhtemelen = probablemente | muh-te-me-LEN
W yağmur yağabilir = puede que llueva | yaa-mur ya-a-bi-LIR
W gelebilirim = quizá pueda venir | ge-le-bi-li-RIM
W kusura bakmayın = disculpe | ku-su-ra bak-ma-YUHN
w çok isterim = me encantaría | chok is-te-RIM
w hava = tiempo (clima) | ha-VA
w akşamı = la noche
w katılır = asiste
w yağmurlu = lluvioso/a
w olabilir = puede ser
w zaman = entonces; tiempo
V Una invitación
D Una fiesta el sábado
Ece: Cumartesi akşamı partimize katılır mısın? = ¿Vendrás a nuestra fiesta el sábado por la noche?
Ali: Çok isterim. Belki biraz geç gelebilirim. = Me encantaría. Quizá llegue un poco tarde.
Ece: Sorun değil. Hava yağmurlu olabilir. = No pasa nada. Puede que llueva.
Ali: O zaman taksiyle gelirim. = Entonces iré en taxi.
W partimize = a nuestra fiesta | par-ti-mi-ZE
W geç = tarde | gech
W sorun değil = no pasa nada | so-run de-YIL
W taksiyle = en taxi | tak-si-YLE
w gelirim = vendré/iré | ge-li-RIM
Q ¿Qué significa «katılmak»?
+ asistir/participar :: Katılmak es tomar parte en una actividad.
- invitar :: Invitar es davet etmek.
- llegar tarde :: Llegar es gelmek.
Q ¿Qué responde Ali a la invitación?
+ Acepta con entusiasmo :: Çok isterim significa «me encantaría».
- La rechaza por completo :: No la rechaza.
- Pide cambiar el día :: No pide cambiarlo.
Q «Belki» significa…
+ quizás :: Expresa posibilidad.
- probablemente :: Probablemente es muhtemelen.
- por eso :: Por eso es bu yüzden.
Q ¿Cómo irá Ali si llueve?
+ En taxi :: O zaman taksiyle gelirim.
- En autobús :: Autobús es otobüs.
- No irá :: Acepta la invitación.
R Hava yağmurlu olabilir. :: Traduce.
+ Puede que llueva. :: Olabilir expresa posibilidad.
- Está lloviendo ahora. :: Ahora sería yağmur yağıyor.
- Probablemente hará sol. :: Sol es güneş.
H Belki biraz geç ___ . :: Completa: «Quizá llegue un poco tarde».
+ gelebilirim :: Gelebilirim expresa posibilidad personal.
- geldim :: Llegué.
- geliyorum :: Estoy llegando.
A Çok isterim. :: Escucha la aceptación.
+ Me encantaría. :: Expresa una respuesta positiva.
- Lo siento, no puedo. :: Esa sería una negativa.
- Quizá llueva. :: Esa es otra frase.
O O zaman taksiyle gelirim :: Entonces iré en taxi :: O zaman = entonces.
X Escribe «Quizá pueda venir» :: belki gelebilirim :: Belki = quizá.
