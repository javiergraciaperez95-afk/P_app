@ 12 | Evim ve mahallem | Mi casa y mi barrio
I Describe tu casa, di dónde está cada cosa y habla de tu barrio.
E La vivienda :: **ev** = casa; **oda** = habitación; **mutfak** = cocina; **banyo** = baño. :: Para ubicar algo usa **-de/-da**: **evde** = en casa, **odada** = en la habitación. :: **yakın** significa cerca y **uzak**, lejos.
W mutfak = cocina | mut-FAK
W banyo = baño | ban-YO
W balkon = balcón | bal-KON
W mahalle = barrio | ma-hal-LE
w odam = mi habitación | o-DAM
w geniş = espacioso/a | ge-NISH
w evim = mi casa
w mahallemize = a nuestro barrio
w evimde = en mi casa
V Casa y barrio
D Una visita
Anna: Evim küçük ama çok güzel. = Mi casa es pequeña pero muy bonita.
Ece: Kaç oda var? = ¿Cuántas habitaciones hay?
Anna: İki oda var ve bir balkon var. = Hay dos habitaciones y un balcón.
Ece: Park mahallemize yakın mı? = ¿El parque está cerca de nuestro barrio?
Anna: Evet, çok yakın. = Sí, muy cerca.
w var = hay; tener | var
w parkımız = nuestro parque | par-ku-MUZ
Q ¿Qué significa «mutfak»?
+ cocina :: Mutfak es la cocina.
- baño :: Baño es banyo.
- balcón :: Balcón es balkon.
Q ¿Dónde está el parque según Anna?
+ Cerca :: Yakın significa cerca.
- Lejos :: Lejos es uzak.
- Dentro de casa :: Evde significa en casa.
Q ¿Qué significa «evde»?
+ en casa :: Ev = casa; -de = en.
- mi casa :: Mi casa es evim.
- casa pequeña :: Pequeño/a es küçük.
Q «İki oda var» significa…
+ hay dos habitaciones :: İki = dos; oda = habitación.
- hay dos balcones :: Balcón es balkon.
- mi habitación es pequeña :: No aparece odam.
R Evim küçük ama güzel. :: Traduce.
+ Mi casa es pequeña pero bonita. :: Küçük = pequeña; güzel = bonita.
- Mi barrio está lejos. :: Barrio es mahalle.
- Hay dos baños. :: Baño es banyo.
H Park mahallemize ___ mı? :: Completa: «¿El parque está cerca de nuestro barrio?».
+ yakın :: Yakın significa cerca.
- uzak :: Uzak significa lejos.
- küçük :: Küçük significa pequeño/a.
A Evimde bir balkon var. :: Escucha lo que hay en la casa.
+ Hay un balcón en mi casa. :: Evimde = en mi casa.
- Mi casa está cerca del parque. :: No se menciona el parque.
- La habitación es espaciosa. :: Espaciosa es geniş.
O Evim küçük ama güzel :: Mi casa es pequeña pero bonita :: Ama significa «pero».
X Escribe «Mi habitación está en casa» :: odam evde :: Evde significa «en casa».

@ 12 | Şehrimdeki yerler | Lugares de mi ciudad
I Cuenta qué servicios hay cerca de ti y cómo llegar a ellos.
E Servicios del entorno :: **market** es supermercado; **fırın**, panadería; **sağlık merkezi**, centro de salud. :: **karşısında** = enfrente; **yanında** = al lado. :: Para decir «hay» o «no hay» usa **var/yok**: **mahallede eczane yok** = no hay farmacia en el barrio.
W market = supermercado | mar-KET
W fırın = panadería; horno | fuh-RUHN
W sağlık merkezi = centro de salud | saah-luhk mer-ke-ZI
W karşısında = enfrente | kar-shuh-SUHN-da
W yanında = al lado | ya-nuhn-DA
W yok = no hay | yok
W eczane yok = no hay farmacia | ec-za-ne yok
w postane = oficina de correos | pos-ta-NE
w mahallede = en el barrio
V Servicios
D Buscando una panadería
Ali: Mahallede fırın var mı? = ¿Hay una panadería en el barrio?
Deniz: Evet, marketin yanında. = Sí, al lado del supermercado.
Ali: Sağlık merkezi nerede? = ¿Dónde está el centro de salud?
Deniz: Parkın karşısında. = Enfrente del parque.
W marketin = del supermercado | mar-ke-TIN
w parkın = del parque | par-KUHN
w nerede = dónde está | ne-re-DE
Q ¿Qué significa «fırın»?
+ panadería :: Fırın es horno o panadería.
- banco :: Banco es banka.
- oficina de correos :: Postane es oficina de correos.
Q ¿Dónde está la panadería?
+ Al lado del supermercado :: Marketin yanında expresa esa ubicación.
- Enfrente del parque :: Esa es la ubicación del centro de salud.
- Lejos del barrio :: No se dice uzak.
Q ¿Qué significa «yok»?
+ no hay :: Yok niega la existencia.
- enfrente :: Enfrente es karşısında.
- al lado :: Al lado es yanında.
Q «Parkın karşısında» significa…
+ enfrente del parque :: Karşısında es enfrente.
- al lado del parque :: Junto a es yanında.
- dentro del parque :: Dentro es içinde.
R Mahallede eczane yok. :: Traduce.
+ No hay farmacia en el barrio. :: Yok significa «no hay».
- La farmacia está enfrente del barrio. :: No se dice enfrente.
- Hay un centro de salud. :: Salud merkezi es centro de salud.
H Marketin ___ bir fırın var. :: Completa: «Hay una panadería al lado del supermercado».
+ yanında :: Yanında significa al lado.
- karşısında :: Significa enfrente.
- uzakta :: Significa lejos.
A Sağlık merkezi parkın karşısında. :: Escucha la indicación.
+ El centro de salud está enfrente del parque. :: Karşısında = enfrente.
- El parque está al lado de la panadería. :: No se menciona la panadería.
- No hay un centro de salud. :: Var indica que sí hay.
O Fırın marketin yanında :: La panadería está al lado del supermercado :: Yanında expresa cercanía lateral.
X Escribe «No hay una oficina de correos» :: postane yok :: Yok significa «no hay».

@ 12 | Ev işleri ve düzen | Tareas y orden en casa
I Di qué tareas haces y expresa de manera sencilla qué hay que hacer.
E Tareas domésticas :: **temizlik** = limpieza; **çamaşır** = ropa para lavar; **bulaşık** = platos. :: **-malı/-meli** expresa deber: **temizlik yapmalıyım** = debo limpiar. :: **önce** significa antes/primero y **sonra**, después.
W temizlik = limpieza | tem-iz-LIK
W çamaşır = ropa para lavar | cha-ma-SHUHR
W bulaşık = platos sucios | bu-la-SHUHK
W yapmalıyım = debo hacer | yap-ma-luh-YUHM
W önce = antes; primero | ÖN-je
W düzenli = ordenado/a | dü-zen-LI
w temiz = limpio/a | te-MIZ
w odamı = mi habitación (objeto) | o-da-MUH
w yapıyorum = hago | ya-puh-YO-rum
w bulaşıkları = los platos
V Tareas de casa
D Plan para la tarde
Anna: Önce odamı temizliyorum. = Primero limpio mi habitación.
Can: Sonra ne yapıyorsun? = ¿Qué haces después?
Anna: Bulaşıkları yıkamalıyım. = Debo lavar los platos.
Can: Ben de çamaşır yıkıyorum. = Yo también lavo la ropa.
W temizliyorum = estoy limpiando | tem-iz-li-YO-rum
W yıkamalıyım = debo lavar | yuh-ka-ma-luh-YUHM
w yıkıyorum = lavo | yuh-kuh-YO-rum
Q ¿Qué significa «önce»?
+ primero; antes :: Önce marca la primera acción.
- después :: Después es sonra.
- limpio :: Limpio es temiz.
Q ¿Qué debe hacer Anna?
+ Lavar los platos :: Bulaşıkları yıkamalıyım = debo lavar los platos.
- Lavar la ropa :: Eso lo hace Can.
- Ir al parque :: No aparece en el diálogo.
Q «Düzenli» significa…
+ ordenado/a :: Düzenli se refiere al orden.
- sucio/a :: Sucio/a es kirli.
- cansado/a :: Cansado/a es yorgun.
Q ¿Qué palabra significa «ropa para lavar»?
+ çamaşır :: Çamaşır se usa para la ropa y la colada.
- bulaşık :: Son los platos.
- temizlik :: Es limpieza.
R Önce odamı temizliyorum. :: Traduce.
+ Primero limpio mi habitación. :: Önce = primero; odamı = mi habitación.
- Después lavo los platos. :: Después = sonra.
- Debo ordenar la cocina. :: Cocina es mutfak.
H Bulaşıkları ___ . :: Completa: «Debo lavar los platos».
+ yıkamalıyım :: Yıkamalıyım = debo lavar.
- temiz :: Limpio/a.
- sonra :: Después.
A Ben de çamaşır yıkıyorum. :: Escucha la tarea.
+ Yo también lavo la ropa. :: Çamaşır = ropa; yıkıyorum = lavo.
- Debo limpiar mi habitación. :: Esa es la tarea de Anna.
- Primero lavo los platos. :: No se menciona önce.
O Önce odamı temizliyorum :: Primero limpio mi habitación :: Önce señala el orden.
X Escribe «Después lavo los platos» :: sonra bulaşıkları yıkıyorum :: Sonra = después.
