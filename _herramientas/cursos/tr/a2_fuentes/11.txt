@ 11 | Kendini anlatmak | Presentarse mejor
I Presenta a alguien con más detalle y compara su aspecto o personalidad con la tuya.
E Rasgos personales :: **kişilik** significa «personalidad». Puedes describir a alguien con adjetivos: **sakin** (tranquilo/a), **neşeli** (alegre) o **dürüst** (honesto/a). :: Para comparar usa **daha** («más») y para destacar, **en** («el/la más»): **Ece benden daha uzun** = Ece es más alta que yo.
W kişilik = personalidad | ki-shi-LIK
W sakin = tranquilo/a | sa-KIN
W neşeli = alegre | ne-SHE-li
W dürüst = honesto/a | dü-RÜST
W çalışkan = trabajador/a, aplicado/a | cha-luhsh-KAN
W uzun = alto/a; largo/a | u-ZUN
W kısa = bajo/a; corto/a | kuh-SA
W daha = más | da-HA
W en = el/la más | en
W benden = que yo | BEN-den
w çok = muy | chok
w neşeliyim = soy alegre
w sakinim = estoy tranquilo/a
w senden = que tú
w arkadaşımız = nuestro/a amigo/a
V Personalidad y aspecto
D Dos amigos
Anna: Arkadaşım çok neşeli. = Mi amiga es muy alegre.
Ali: Ben de neşeliyim ama daha sakinim. = Yo también soy alegre, pero soy más tranquilo.
Anna: Ece senden daha uzun mu? = ¿Ece es más alta que tú?
Ali: Evet, Ece en uzun arkadaşımız. = Sí, Ece es nuestra amiga más alta.
Q ¿Qué significa «dürüst»?
+ honesto/a :: Dürüst describe a una persona sincera.
- bajo/a :: Bajo/a es kısa.
- alegre :: Alegre es neşeli.
Q ¿Qué palabra significa «más» al comparar?
+ daha :: Daha se coloca antes del adjetivo.
- en :: En significa «el/la más».
- benden :: Benden significa «que yo».
Q «Ece benden daha uzun» quiere decir…
+ Ece es más alta que yo :: Benden = que yo; daha uzun = más alta.
- Yo soy la más alta :: Esa idea sería diferente.
- Ece es mi amiga tranquila :: No aparece sakin.
Q ¿Qué significa «en çalışkan»?
+ el/la más aplicado/a :: En da el grado superlativo.
- menos trabajador/a :: Menos no es en.
- que el trabajador :: No es una comparación con benden.
R Neşeliyim ama bugün sakinim. :: Traduce la frase.
+ Soy alegre, pero hoy estoy tranquilo/a. :: Neşeliyim = soy alegre; bugün = hoy.
- Soy más alto que mi amigo. :: No se habla de altura.
- Hoy estoy en casa. :: Casa es ev.
H Ece benden daha ___ . :: Completa: «Ece es más alta que yo».
+ uzun :: Uzun significa alto/a o largo/a.
- sakin :: Sakin significa tranquilo/a.
- dürüst :: Dürüst significa honesto/a.
A En neşeli arkadaşım Ece. :: Escucha la descripción.
+ Ece es mi amiga más alegre. :: En neşeli = la más alegre.
- Ece es más alta que yo. :: Eso sería Ece benden daha uzun.
- Mi amiga es honesta. :: Honesta es dürüst.
O Ali benden daha sakin :: Ali es más tranquilo que yo :: Daha expresa «más».
X Escribe «Ece es la más alta» :: Ece en uzun :: En uzun = la/el más alto/a.

@ 11 | Duygular ve fikirler | Emociones y opiniones
I Explica cómo te sientes y pregunta con tacto por el estado de otra persona.
E Expresar emociones :: **mutlu** = feliz; **üzgün** = triste; **şaşkın** = sorprendido/a. :: Para preguntar con cuidado puedes decir **Neyin var?** («¿Qué te pasa?»). **Bence** significa «en mi opinión» y **çünkü**, «porque».
W mutlu = feliz | mut-LU
W üzgün = triste | üz-GÜN
W şaşkın = sorprendido/a | shash-KUHN
W yorgun = cansado/a | yor-GUN
W bence = en mi opinión | BEN-je
W çünkü = porque | chün-KÜ
W neyin = qué (de ti) | ne-YIN
W var = hay; tener | var
w kendimi = me (a mí mismo/a) | ken-di-MI
w hissediyorum = siento | his-se-di-YO-rum
w çalıştım = trabajé
V Emociones
D Una conversación
Ece: Bugün üzgün görünüyorsun. Neyin var? = Hoy pareces triste. ¿Qué te pasa?
Anna: Kendimi yorgun hissediyorum çünkü çok çalıştım. = Me siento cansada porque trabajé mucho.
Ece: Bence biraz dinlenmelisin. = En mi opinión, deberías descansar un poco.
Anna: Haklısın, teşekkür ederim. = Tienes razón, gracias.
W görünüyorsun = pareces | gö-rü-nü-YOR-sun
W haklısın = tienes razón | hak-luh-SUHN
Q ¿Qué significa «üzgün»?
+ triste :: Üzgün describe una emoción triste.
- feliz :: Feliz es mutlu.
- cansado/a :: Cansado/a es yorgun.
Q ¿Cómo se dice «en mi opinión»?
+ bence :: Bence introduce una opinión.
- çünkü :: Çünkü significa «porque».
- neyin :: Neyin aparece en «¿qué te pasa?».
Q ¿Por qué Anna se siente cansada?
+ Porque trabajó mucho :: Çünkü expresa la causa.
- Porque está feliz :: No está feliz.
- Porque tiene razón :: Haklısın significa «tienes razón».
Q «Neyin var?» se usa para preguntar…
+ qué le pasa a alguien :: Es una pregunta por el estado de una persona.
- dónde vive :: ¿Dónde vives? es Nerede yaşıyorsun?
- cuánto cuesta :: ¿Cuánto cuesta? es Ne kadar?
R Kendimi mutlu hissediyorum. :: Traduce la frase.
+ Me siento feliz. :: Kendimi hissediyorum = me siento.
- Estoy triste hoy. :: Triste es üzgün.
- Estoy cansado porque trabajé. :: No aparece cansado.
H Bence biraz ___ . :: Completa: «En mi opinión, deberías descansar un poco».
+ dinlenmelisin :: Es el consejo «deberías descansar».
- şaşkın :: Significa sorprendido/a.
- üzgün :: Significa triste.
A Bugün kendimi yorgun hissediyorum. :: Escucha cómo se siente la persona.
+ Hoy me siento cansado/a. :: Yorgun = cansado/a.
- Hoy estoy sorprendido/a. :: Sorprendido/a es şaşkın.
- Hoy estoy alegre. :: Alegre es mutlu.
O Çünkü çok çalıştım :: Porque trabajé mucho :: Çünkü introduce una causa.
X Escribe «En mi opinión, estoy triste» :: Bence üzgünüm :: Bence = en mi opinión.

@ 11 | İnsanları karşılaştırmak | Comparar personas
I Compara a dos personas y describe a tu mejor amigo o amiga.
E Comparaciones :: **-den/-dan** puede marcar el punto de comparación: **Ali Ayşe'den daha kısa** = Ali es más bajo que Ayşe. :: **en** expresa el grado máximo: **en çalışkan öğrenci** = el/la estudiante más aplicado/a. La armonía vocálica elige la variante del sufijo.
W öğrenci daha = más estudiante (en comparación) | ö-ren-JI da-HA
W Ayşe'den = que Ayşe | ay-SHE-den
W benim = mi; mío/a | be-NIM
w Ali = Ali | a-LI
w kadar = tan; tanto como | ka-DAR
w İkiniz = vosotros dos | i-ki-NIZ
V Comparar
D En clase
Can: Ali Ayşe'den daha kısa. = Ali es más bajo que Ayşe.
Deniz: Evet, ama Ali en çalışkan öğrenci. = Sí, pero Ali es el estudiante más aplicado.
Can: Benim arkadaşım da çok çalışkan. = Mi amigo también es muy aplicado.
Deniz: İkiniz de çok iyisiniz. = Los dos sois muy buenos.
W ikiniz = vosotros dos | i-ki-NIZ
w iyisiniz = sois buenos/as | i-yi-si-NIZ
Q ¿Qué función tiene «-den» en Ayşe'den?
+ Marca «que Ayşe» en la comparación :: Separa a la persona usada como referencia.
- Significa «con Ayşe» :: «Con» sería Ayşe'yle.
- Significa «para Ayşe» :: «Para» sería Ayşe için.
Q «En çalışkan öğrenci» significa…
+ el/la estudiante más aplicado/a :: En marca el grado máximo.
- un estudiante tranquilo :: Tranquilo/a es sakin.
- un estudiante más bajo :: Bajo/a es kısa.
Q ¿Qué significa «benim arkadaşım»?
+ mi amigo/a :: Benim = mi; arkadaşım = mi amigo/a.
- el amigo de Ayşe :: No aparece Ayşe.
- nuestro estudiante :: Öğrenci = estudiante.
Q ¿Cuántas personas quiere decir «ikiniz»?
+ dos :: İkiniz significa vosotros dos.
- una :: Bir significa uno/a.
- tres :: Üç significa tres.
R Ali en çalışkan öğrenci. :: Traduce.
+ Ali es el estudiante más aplicado. :: En çalışkan = el más aplicado.
- Ali es el estudiante más bajo. :: Bajo es kısa.
- Ayşe es más aplicada que Ali. :: El orden de comparación sería otro.
H Ali Ayşe'den daha ___ . :: Completa: «Ali es más bajo que Ayşe».
+ kısa :: Kısa significa bajo/a o corto/a.
- uzun :: Uzun significa alto/a o largo/a.
- neşeli :: Neşeli significa alegre.
A Benim arkadaşım çok çalışkan. :: Escucha la descripción.
+ Mi amigo/a es muy aplicado/a. :: Çalışkan = aplicado/a.
- Soy el estudiante más aplicado. :: Benim arkadaşım habla de un amigo.
- Ayşe es más baja que Ali. :: No se compara a Ayşe.
O Ali Ayşe'den daha kısa :: Ali es más bajo que Ayşe :: -den señala el referente.
X Escribe «el estudiante más aplicado» :: en çalışkan öğrenci :: En marca el superlativo.
