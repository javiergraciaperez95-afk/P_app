@ 16 | Eğitim hayatım | Mi vida académica
I Habla de tus estudios, de lo que estás aprendiendo y de tus planes de formación.
E Estudios :: **eğitim** = educación; **ders** = clase; **sınav** = examen. :: **kurs** = curso; **öğrenmek** = aprender. :: **... öğreniyorum** = estoy aprendiendo algo. Puedes expresar una intención con **istiyorum** («quiero»).
W eğitim = educación | e-yi-TIM
W ders = clase | ders
W sınav = examen | suh-NAV
W kurs = curso | kurs
W öğrenmek = aprender | ö-ren-MEK
W öğreniyorum = estoy aprendiendo | ö-re-ni-YO-rum
W bölüm = departamento; especialidad | bö-LÜM
W üniversite = universidad | ü-ni-ver-si-TE
w bilgisayar = ordenador | bil-gi-sa-YAR
w Türkçe öğreniyorum = estoy aprendiendo turco | türk-che ö-re-ni-YO-rum
w Üniversitede = en la universidad
w bölümde = en la especialidad
w okuyorsun = estudias
w sınava = para el examen
w Türkçemi = mi turco
V Estudios
D En la universidad
Ece: Üniversitede hangi bölümde okuyorsun? = ¿Qué especialidad estudias en la universidad?
Ali: Mühendislik okuyorum. Türkçe kursuna da gidiyorum. = Estudio ingeniería y también voy al curso de turco.
Ece: Bu akşam sınava çalışacak mısın? = ¿Vas a estudiar para el examen esta tarde?
Ali: Evet, çünkü Türkçemi geliştirmek istiyorum. = Sí, porque quiero mejorar mi turco.
W hangi = cuál; qué | han-GI
W mühendislik = ingeniería | mü-hen-dis-LIK
W okuyorum = estudio; leo | o-ku-YO-rum
W kursuna = a su curso | kur-su-NA
w çalışacak mısın = ¿vas a estudiar? | cha-luh-sha-JAK muh-suhn
w geliştirmek = mejorar | ge-lish-tir-MEK
Q ¿Qué significa «sınav»?
+ examen :: Sınav es una evaluación.
- clase :: Clase es ders.
- curso :: Curso es kurs.
Q ¿Qué estudia Ali?
+ Ingeniería :: Mühendislik okuyorum.
- Informática :: No se especifica esa especialidad.
- Turco en la universidad :: Va a un curso de turco.
Q «Türkçe kursuna gidiyorum» significa…
+ Voy al curso de turco :: Kursuna = a su curso; gidiyorum = voy.
- Enseño turco en un curso :: Enseñar sería öğretmek.
- Quiero estudiar ingeniería :: No dice querer.
Q ¿Qué quiere hacer Ali?
+ Mejorar su turco :: Türkçemi geliştirmek istiyorum.
- Cambiar de universidad :: No se menciona.
- Cancelar el examen :: Va a estudiar.
R Bu akşam sınava çalışacak mısın? :: Traduce.
+ ¿Vas a estudiar para el examen esta tarde? :: Es una pregunta de plan futuro.
- ¿Estudias ingeniería? :: Esa es otra pregunta.
- ¿Quieres aprender turco? :: No es la frase.
H Türkçemi ___ istiyorum. :: Completa: «Quiero mejorar mi turco».
+ geliştirmek :: Geliştirmek = mejorar.
- öğreniyorum :: Estoy aprendiendo.
- sınav :: Examen.
A Türkçe kursuna da gidiyorum. :: Escucha lo que hace Ali.
+ También va al curso de turco. :: Da = también.
- Está aprendiendo ingeniería. :: Ingeniería es mühendislik.
- Quiere mejorar su turco. :: Esa idea aparece después.
O Türkçemi geliştirmek istiyorum :: Quiero mejorar mi turco :: -mek istiyorum expresa querer hacer algo.
X Escribe «Estoy aprendiendo turco» :: Türkçe öğreniyorum :: Öğreniyorum = estoy aprendiendo.

@ 16 | İş ve meslekler | Trabajo y profesiones
I Describe tareas laborales, habla de lo que haces y comenta qué trabajo te gustaría tener.
E Profesiones y tareas :: **iş** = trabajo; **meslek** = profesión; **ofis** = oficina. :: **çalışmak** puede significar trabajar o estudiar, según el contexto. :: El presente habitual describe tareas: **doktor hastaları muayene eder** = el médico examina a los pacientes.
W ofis = oficina | o-FIS
W muayene etmek = examinar (a un paciente) | mu-a-ye-ne et-MEK
W hasta = paciente; enfermo/a | has-TA
W maaş = salario | ma-ASH
W izin = permiso; vacaciones | i-ZIN
w iş başvurusu = solicitud de empleo | ish bash-vu-ru-SU
w tecrübe = experiencia | te-j-rü-BE
w ofiste = en una oficina
w tecrübem = mi experiencia
w tür = tipo
w Maaşı = su salario | ma-a-SHUH
w arıyorum = busco
V El trabajo
D Una entrevista breve
İşveren: Daha önce nerede çalıştınız? = ¿Dónde trabajó antes?
Başvuran: Bir ofiste çalıştım. İki yıllık tecrübem var. = Trabajé en una oficina. Tengo dos años de experiencia.
İşveren: Ne tür bir iş arıyorsunuz? = ¿Qué tipo de trabajo busca?
Başvuran: Maaşı iyi ve çalışma saatleri uygun bir iş. = Un trabajo con buen salario y horario conveniente.
N İşveren, Başvuran
W işveren = empleador/a | ish-ve-REN
W başvuran = solicitante | bash-vu-RAN
W çalıştınız = trabajó/usted | cha-luhsh-tuh-NUZ
W yıllık = de años | yuhl-LUHK
W arıyorsunuz = busca/usted | a-ruh-YOR-su-nuz
W çalışma saatleri = horario laboral | cha-luhsh-ma sa-at-le-RI
W uygun = adecuado/a | uy-GUN
Q ¿Qué significa «maaş»?
+ salario :: Maaş es el dinero que se recibe por el trabajo.
- experiencia :: Experiencia es tecrübe.
- permiso :: Permiso es izin.
Q ¿Dónde trabajó antes la persona solicitante?
+ En una oficina :: Bir ofiste çalıştım.
- En un hospital :: No se menciona hospital.
- En una universidad :: No se menciona universidad.
Q ¿Cuántos años de experiencia tiene?
+ Dos años :: İki yıllık tecrübem var.
- Un año :: No dice bir yıllık.
- Cinco años :: No dice beş yıllık.
Q «Uygun çalışma saatleri» significa…
+ horario laboral conveniente :: Uygun = conveniente; çalışma saatleri = horario.
- salario alto :: Alto es yüksek.
- empleo temporal :: Temporal es geçici.
R Bir ofiste çalıştım. :: Traduce.
+ Trabajé en una oficina. :: Çalıştım está en pasado.
- Trabajo en una oficina. :: El presente sería çalışıyorum.
- Busco una oficina. :: Aramak = buscar.
H İki yıllık ___ var. :: Completa: «Tengo dos años de experiencia».
+ tecrübem :: Tecrübe = experiencia; tecrübem = mi experiencia.
- maaşım :: Mi salario.
- iznim :: Mi permiso.
A Ne tür bir iş arıyorsunuz? :: Escucha la pregunta.
+ ¿Qué tipo de trabajo busca? :: Ne tür = qué tipo; iş = trabajo.
- ¿Dónde está su oficina? :: Nerede = dónde.
- ¿Cuánto es el salario? :: Ne kadar = cuánto.
O Maaşı iyi bir iş arıyorum :: Busco un trabajo con buen salario :: Maaşı iyi = con buen salario.
X Escribe «Busco trabajo» :: iş arıyorum :: İş = trabajo; arıyorum = busco.

@ 16 | Telefon ve rica | Llamadas y peticiones
I Contesta una llamada, pide que alguien deje un mensaje y formula solicitudes amables.
E Llamadas :: **alo** = diga; **kiminle görüşüyorum?** = ¿con quién hablo?; **mesaj bırakmak** = dejar un mensaje. :: **-ebilir misiniz?** permite pedir algo con cortesía: **bekleyebilir misiniz?** = ¿puede esperar? :: **lütfen** suaviza una petición.
W alo = diga (al teléfono) | a-LO
W görüşmek = hablar; reunirse | gö-rüş-MEK
W kiminle = con quién | ki-min-LE
W mesaj bırakmak = dejar un mensaje | me-saj bu-rak-MAK
W beklemek = esperar | bek-le-MEK
W bekleyebilir misiniz = ¿puede esperar? | bek-le-ye-bi-LIR mi-si-niz
W aramak = llamar | a-ra-MAK
w hatta = en la línea | hat-TA
w şu anda = ahora mismo | shu an-DA
w müsait değil = no está disponible | mü-sa-it de-YIL
w görüşüyorum = estoy hablando
w Hanım'la = con la señora | ha-nım-LA
w ister = quiere
w misiniz = pregunta formal a usted
V Al teléfono
D Una llamada a la oficina
Sekreter: Alo, Güneş Ofisi. Kiminle görüşüyorum? = Diga, oficina Güneş. ¿Con quién hablo?
Deniz: Ben Deniz. Ayşe Hanım'la görüşebilir miyim? = Soy Deniz. ¿Puedo hablar con la señora Ayşe?
Sekreter: Şu anda müsait değil. Mesaj bırakmak ister misiniz? = Ahora mismo no está disponible. ¿Quiere dejar un mensaje?
Deniz: Evet, lütfen beni arasın. = Sí, por favor, que me llame.
N Sekreter, Güneş, Ayşe
W ofisi = oficina | o-fi-SI
W hanım = señora | ha-NUHM
W arasın = que me llame | a-ra-SUHN
w görüşebilir miyim = ¿puedo hablar? | gö-rü-she-bi-LIR mi-YIM
w beni = a mí | be-NI
Q ¿Qué significa «alo»?
+ diga (al teléfono) :: Alo es una fórmula para contestar el teléfono.
- hola, adiós :: No se usa para despedirse.
- esperar :: Esperar es beklemek.
Q ¿Con quién quiere hablar Deniz?
+ Con la señora Ayşe :: Ayşe Hanım'la görüşebilir miyim?
- Con el señor Güneş :: Güneş es el nombre de la oficina.
- Con su secretaria :: Habla con la secretaria.
Q «Şu anda müsait değil» significa…
+ ahora mismo no está disponible :: Müsait değil = no está disponible.
- está en la línea :: Hatta = en la línea.
- espere un momento :: Esa sería una petición distinta.
Q ¿Qué pide Deniz?
+ Que le llamen :: Beni arasın = que me llame.
- Que le dejen un mensaje :: Deniz es quien dejaría el mensaje.
- Que espere :: No lo pide en el diálogo.
R Mesaj bırakmak ister misiniz? :: Traduce.
+ ¿Quiere dejar un mensaje? :: Mesaj bırakmak = dejar un mensaje.
- ¿Puede esperar? :: Bekleyebilir misiniz?
- ¿Con quién hablo? :: Kiminle görüşüyorum?
H Lütfen beni ___ . :: Completa: «Por favor, que me llame».
+ arasın :: Arasın es una petición «que llame».
- beklesin :: Que espere.
- görüşsün :: Que hable.
A Bekleyebilir misiniz? :: Escucha la petición cortés.
+ ¿Puede esperar? :: Bekleyebilir misiniz es una petición formal.
- ¿Quiere dejar un mensaje? :: Mesaj bırakmak ister misiniz?
- ¿Puedo hablar con Ayşe? :: Ayşe'yle görüşebilir miyim?
O Şu anda müsait değil :: Ahora mismo no está disponible :: Şu anda = ahora mismo.
X Escribe «¿Puedo hablar con Ayşe?» :: Ayşe'yle görüşebilir miyim :: -ebilir miyim formula una petición.
