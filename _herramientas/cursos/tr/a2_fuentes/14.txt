@ 14 | Hobilerim | Mis aficiones
I Habla de tus pasatiempos y pregunta a otras personas qué les gusta hacer.
E Aficiones :: **hobi** = afición; **fotoğraf çekmek** = hacer fotos; **müzik dinlemek** = escuchar música. :: Para decir «me gusta», usa **-mayı/-meyi seviyorum**: **yüzmeyi seviyorum** = me gusta nadar. :: **boş vaktimde** significa «en mi tiempo libre».
W fotoğraf = fotografía | fo-to-RAF
W fotoğraf çekmek = hacer fotos | fo-to-raf çek-MEK
W yüzmeyi = nadar (como actividad) | yüz-me-YI
W seviyorum = me gusta | se-vi-YO-rum
W boş vaktimde = en mi tiempo libre | bosh vak-tim-DE
w vaktinde = en tu tiempo
w severim = me gusta
w sever = le gusta
w etmeyi = hacer (actividad)
V Aficiones
D Plan de fin de semana
Ece: Boş vaktinde ne yapmayı seversin? = ¿Qué te gusta hacer en tu tiempo libre?
Anna: Fotoğraf çekmeyi ve müzik dinlemeyi severim. = Me gusta hacer fotos y escuchar música.
Ece: Yüzmeyi sever misin? = ¿Te gusta nadar?
Anna: Evet, ama dans etmeyi daha çok seviyorum. = Sí, pero me gusta más bailar.
W seversin = te gusta | se-ver-SIN
W çekmeyi = hacer (fotos) como actividad | çek-me-YI
w daha çok = más | da-HA chok
Q ¿Qué significa «hobi»?
+ afición :: Hobi es un pasatiempo.
- fotografía :: Fotografía es fotoğraf.
- música :: Música es müzik.
Q ¿Qué le gusta hacer a Anna?
+ Hacer fotos y escuchar música :: Son las dos actividades que menciona.
- Leer libros y nadar :: No menciona leer libros.
- Bailar y cocinar :: Le gusta bailar, no cocinar.
Q «Yüzmeyi sever misin?» pregunta…
+ si te gusta nadar :: Yüzmek = nadar; sevmek = gustar.
- si sabes nadar :: Saber nadar se expresa con -ebil.
- dónde nadas :: Dónde es nerede.
Q ¿Qué le gusta más a Anna?
+ Bailar :: Dans etmeyi daha çok seviyorum.
- Nadar :: Le gusta, pero prefiere bailar.
- Hacer fotos :: No dice que sea su preferencia mayor.
R Müzik dinlemeyi seviyorum. :: Traduce.
+ Me gusta escuchar música. :: Dinlemeyi seviyorum = me gusta escuchar.
- Me gusta bailar. :: Bailar es dans etmek.
- Escucho música ahora. :: Ahora sería una acción en curso.
H Boş vaktimde kitap ___ . :: Completa: «En mi tiempo libre me gusta leer libros».
+ okumayı seviyorum :: Okumayı seviyorum = me gusta leer.
- çekmeyi seviyorum :: Me gusta hacer fotos.
- yüzmeyi biliyorum :: Sé nadar.
A Fotoğraf çekmeyi severim. :: Escucha la afición.
+ Me gusta hacer fotos. :: Fotoğraf çekmek = hacer fotos.
- Me gusta escuchar música. :: Esa es otra afición.
- Sé hacer fotos. :: No expresa saber.
O Dans etmeyi daha çok seviyorum :: Me gusta más bailar :: Daha çok expresa preferencia mayor.
X Escribe «Me gusta nadar» :: yüzmeyi seviyorum :: -meyi seviyorum = me gusta hacer algo.

@ 14 | Teklif ve plan | Propuestas y planes
I Invita a alguien a hacer una actividad y responde con cortesía.
E Invitar :: **İster misin?** = ¿quieres?; **birlikte** = juntos; **tabii** = claro. :: El patrón **-maya/-meye ne dersin?** sugiere una actividad: **sinemaya gitmeye ne dersin?** = ¿qué te parece ir al cine? :: Una respuesta amable puede empezar con **Memnuniyetle** («con mucho gusto») o **Üzgünüm** («lo siento»).
W tabii = claro; por supuesto | ta-BI-i
W memnuniyetle = con mucho gusto | mem-nu-ni-yet-LE
W gitmeye ne dersin = qué te parece ir | git-me-ye ne der-SIN
w müsait = libre, disponible | mü-SA-it
w gelebilir misin = ¿puedes venir? | ge-le-bi-LIR mi-sin
V Proponer una actividad
D Invitación
Ali: Yarın birlikte sinemaya gitmeye ne dersin? = ¿Qué te parece si mañana vamos juntos al cine?
Ece: Memnuniyetle! Saat kaçta? = ¡Con mucho gusto! ¿A qué hora?
Ali: Saat yedide. Gelebilir misin? = A las siete. ¿Puedes venir?
Ece: Tabii, görüşürüz. = Claro, nos vemos.
w saat yedide = a las siete | sa-at ye-di-DE
Q ¿Qué significa «birlikte»?
+ juntos/as :: Birlikte indica que hacen algo juntos.
- mañana :: Mañana es yarın.
- con mucho gusto :: Memnuniyetle.
Q ¿Qué propone Ali?
+ Ir juntos al cine :: Sinemaya gitmeye ne dersin?
- Ir al parque por la mañana :: No menciona el parque.
- Escuchar música en casa :: No aparece esa actividad.
Q «Memnuniyetle» es una respuesta…
+ positiva y cortés :: Significa «con mucho gusto».
- negativa :: Una negativa sería Üzgünüm.
- de duda :: No expresa duda.
Q ¿A qué hora quedan?
+ A las siete :: Saat yedide.
- A las seis :: Saat altıda.
- A las ocho :: Saat sekizde.
R Yarın birlikte sinemaya gitmeye ne dersin? :: Traduce.
+ ¿Qué te parece si mañana vamos juntos al cine? :: Es una propuesta.
- ¿Puedes venir al cine hoy? :: Gelebilir misin pregunta si puedes venir.
- Lo siento, no puedo. :: No aparece una negativa.
H Saat yedide gelebilir ___? :: Completa: «¿Puedes venir a las siete?».
+ misin :: La partícula interrogativa forma la pregunta.
- mısın :: Se usa en otra armonía vocálica.
- musun :: Se usa en otra armonía vocálica.
A Memnuniyetle! Saat kaçta? :: Escucha la respuesta.
+ ¡Con mucho gusto! ¿A qué hora? :: Memnuniyetle = con mucho gusto.
- Lo siento, mañana no puedo. :: No hay negativa.
- Nos vemos a las seis. :: La hora es siete.
O Yarın sinemaya gitmeye ne dersin :: ¿Qué te parece ir al cine mañana? :: -maya ne dersin sugiere una actividad.
X Escribe «Claro, nos vemos» :: tabii, görüşürüz :: Tabii = claro; görüşürüz = nos vemos.

@ 14 | Tercihler ve etkinlikler | Preferencias y actividades
I Explica qué actividad prefieres y qué te gusta hacer con tus amistades.
E Preferencias :: **tercih etmek** = preferir; **dışarı çıkmak** = salir. :: Para contrastar dos opciones usa **... yerine ...** («en vez de...»): **evde oturmak yerine dışarı çıkarım** = en vez de quedarme en casa, salgo. :: **çünkü** introduce el motivo.
W tercih etmek = preferir | ter-cih et-MEK
W dışarı = fuera | duh-sha-RUH
W dışarı çıkmak = salir | duh-sha-rı chuhk-MAK
W yerine = en vez de | ye-ri-NE
W konser = concierto | kon-SER
W sergi = exposición | ser-GI
w arkadaşlarımla = con mis amigos/as | ar-ka-dash-la-RUH-m-la
w Konseri = el concierto (objeto) | kon-se-RI
w tercih = preferir
w ederim = hago; prefiero
w oturmak = quedarse; sentarse
w çıkmayı = salir (como actividad)
w çıkarım = salgo
V Preferencias
D Elegir un plan
Deniz: Konser mi, sergi mi? = ¿Concierto o exposición?
Anna: Konseri tercih ederim çünkü canlı müzik seviyorum. = Prefiero el concierto porque me gusta la música en directo.
Deniz: Evde oturmak yerine dışarı çıkalım mı? = ¿Salimos en vez de quedarnos en casa?
Anna: Evet, arkadaşlarımla dışarı çıkmayı severim. = Sí, me gusta salir con mis amigos.
W canlı = en directo; vivo/a | jan-LUH
w çıkalım = salgamos | chuh-ka-LUHM
Q ¿Qué significa «tercih etmek»?
+ preferir :: Es elegir una opción sobre otra.
- quedarse :: Quedarse es kalmak.
- invitar :: Invitar es davet etmek.
Q ¿Qué prefiere Anna?
+ El concierto :: Konseri tercih ederim.
- La exposición :: Sergi es exposición.
- Quedarse en casa :: Propone salir.
Q «Yerine» significa…
+ en vez de :: Conecta dos opciones alternativas.
- porque :: Porque es çünkü.
- fuera :: Fuera es dışarı.
Q ¿Por qué prefiere el concierto?
+ Porque le gusta la música en directo :: Canlı müzik seviyorum.
- Porque la exposición está lejos :: No se menciona la distancia.
- Porque quiere quedarse en casa :: Prefiere salir.
R Arkadaşlarımla dışarı çıkmayı severim. :: Traduce.
+ Me gusta salir con mis amigos/as. :: Arkadaşlarımla = con mis amigos/as.
- Prefiero el concierto. :: Konseri tercih ederim.
- Me gusta la exposición. :: Sergi = exposición.
H Evde oturmak ___ dışarı çıkarım. :: Completa: «En vez de quedarme en casa, salgo».
+ yerine :: Yerine significa «en vez de».
- çünkü :: Porque.
- birlikte :: Juntos.
A Konseri tercih ederim. :: Escucha la preferencia.
+ Prefiero el concierto. :: Tercih ederim = prefiero.
- Prefiero la exposición. :: Exposición es sergi.
- Salgo con mis amigos. :: Esa es otra frase.
O Evde oturmak yerine dışarı çıkarım :: En vez de quedarme en casa, salgo :: Yerine contrasta opciones.
X Escribe «Prefiero la exposición» :: sergiyi tercih ederim :: Sergi = exposición.
