@ 15 | Ürün seçmek | Elegir un producto
I Compara productos por precio, tamaño y calidad antes de decidir.
E Comparar en una tienda :: **ucuz** = barato; **pahalı** = caro; **kaliteli** = de buena calidad. :: **daha ucuz** = más barato; **en ucuz** = el más barato. :: **bunun** significa «de esto/este», y **şu** señala algo cercano a la persona que escucha.
W kaliteli = de buena calidad | ka-li-te-LI
W bunun = de esto; de este/a | bu-NUN
W şu = ese/a (cercano al oyente) | shu
W beden = talla | be-DEN
W denemek = probarse | de-ne-MEK
w daha pahalı = más caro/a | da-ha pa-ha-LUH
w en ucuz = el/la más barato/a | en u-JUZ
w Bin = mil | bin
w bedeni = su talla
V En la tienda
D Comprando una chaqueta
Müşteri: Bu ceket ne kadar? = ¿Cuánto cuesta esta chaqueta?
Satıcı: Bin lira. Şu ceket daha ucuz. = Mil liras. Esa chaqueta es más barata.
Müşteri: Bunun rengi güzel. Başka bedeni var mı? = El color de esta es bonito. ¿Hay otra talla?
Satıcı: Evet, deneyebilirsiniz. = Sí, puede probársela.
N Müşteri, Satıcı
W başka = otro/a | bash-KA
W deneyebilirsiniz = puede probarse | de-ne-ye-bi-LIR-si-niz
Q ¿Qué significa «ucuz»?
+ barato/a :: Ucuz describe un precio bajo.
- caro/a :: Caro/a es pahalı.
- de buena calidad :: Kaliteli.
Q ¿Qué producto cuesta mil liras?
+ Esta chaqueta :: Bu ceket cuesta bin lira.
- La chaqueta más barata :: No se especifica su precio.
- Una talla diferente :: Beden significa talla.
Q ¿Qué significa «başka bedeni var mı?»
+ ¿Hay otra talla? :: Başka = otra; beden = talla.
- ¿De qué color es? :: Color es renk.
- ¿Puedo pagar con tarjeta? :: No aparece tarjeta.
Q «Daha ucuz» quiere decir…
+ más barato/a :: Daha = más; ucuz = barato/a.
- el más caro :: En pahalı.
- de mejor calidad :: Kaliteli significa de calidad.
R Şu ceket daha ucuz. :: Traduce.
+ Esa chaqueta es más barata. :: Şu señala esa prenda; daha ucuz = más barata.
- Esta chaqueta es muy cara. :: Muy caro = çok pahalı.
- ¿Hay otra talla? :: Esa es una pregunta diferente.
H Bunun ___ güzel. :: Completa: «El color de esta es bonito».
+ rengi :: Renk = color; rengi = su color.
- bedeni :: Su talla.
- fiyatı :: Su precio.
A Bin lira. Şu ceket daha ucuz. :: Escucha la comparación.
+ Mil liras. Esa chaqueta es más barata. :: Bin lira = mil liras.
- Cuesta cien liras y es más cara. :: Bin es mil.
- Esta es la chaqueta más cara. :: Daha ucuz significa más barata.
O Şu ceket daha ucuz :: Esa chaqueta es más barata :: Daha expresa comparación.
X Escribe «El color de esta es bonito» :: bunun rengi güzel :: Rengi = su color.

@ 15 | Alışveriş ve ödeme | Compras y pago
I Pregunta por un producto, pide una cantidad y elige cómo pagar.
E Pagar y pedir :: **fiş** = recibo; **nakit** = efectivo; **kredi kartı** = tarjeta de crédito. :: **Kaç tane?** pregunta «¿cuántos/cuántas?». :: **alabilir miyim?** es una petición cortés: «¿puedo comprar/tomar?».
W fiş = recibo | fish
W nakit = efectivo | na-KIT
W kredi kartı = tarjeta de crédito | kre-di kar-TUH
W kaç tane = cuántos/as | kach ta-NE
W alabilir miyim = ¿puedo comprar/tomar? | a-la-bi-LIR mi-YIM
W indirim = descuento | in-di-RIM
W fiyat = precio | fi-YAT
w tane = unidad/contador | ta-NE
w ödeme = pago | ö-de-ME
V Comprar y pagar
D En la tienda de fruta
Müşteri: İki kilo elma alabilir miyim? = ¿Me da dos kilos de manzanas?
Satıcı: Tabii. Başka bir şey? = Claro. ¿Algo más?
Müşteri: Fiş alabilir miyim? Nakit ödeyeceğim. = ¿Me da el recibo? Pagaré en efectivo.
Satıcı: Buyurun. = Aquí tiene.
N Müşteri, Satıcı
W ödeyeceğim = pagaré | ö-de-ye-JE-im
W buyurun = aquí tiene; adelante | bu-yu-RUN
Q ¿Qué significa «nakit»?
+ efectivo :: Nakit es dinero en efectivo.
- descuento :: Descuento es indirim.
- recibo :: Recibo es fiş.
Q ¿Qué pide el cliente?
+ Dos kilos de manzanas :: İki kilo elma.
- Dos manzanas y una tarjeta :: No menciona una tarjeta.
- Un kilo de fruta :: Pide dos kilos.
Q «Fiş alabilir miyim?» significa…
+ ¿Me da el recibo? :: Fiş = recibo; alabilir miyim = ¿puedo recibir?
- ¿Hay descuento? :: Descuento es indirim.
- ¿Cuánto cuesta? :: Esa pregunta es Ne kadar?
Q ¿Cómo pagará el cliente?
+ En efectivo :: Nakit ödeyeceğim.
- Con tarjeta de crédito :: Kredi kartı no aparece.
- Con descuento :: Indirim significa descuento.
R İki kilo elma alabilir miyim? :: Traduce.
+ ¿Me da dos kilos de manzanas? :: Es una petición amable.
- ¿Cuántas manzanas hay? :: Kaç tane pregunta cantidad.
- Pagaré en efectivo. :: Nakit ödeyeceğim.
H Nakit ___ . :: Completa: «Pagaré en efectivo».
+ ödeyeceğim :: Es la forma «pagaré».
- alabilir miyim :: ¿Puedo comprar?
- indirim :: Descuento.
A Buyurun. :: Escucha lo que dice el vendedor.
+ Aquí tiene. :: Buyurun se usa al entregar algo.
- ¿Cuánto cuesta? :: Ne kadar?
- Pagaré con tarjeta. :: No aparece el pago.
O Fiş alabilir miyim :: ¿Me da el recibo? :: Alabilir miyim formula una petición cortés.
X Escribe «¿Hay descuento?» :: indirim var mı :: Var mı pregunta si hay algo.

@ 15 | Sipariş ve müşteri hizmetleri | Pedidos y atención al cliente
I Pregunta por teléfono por el estado de un pedido y explica un problema sencillo.
E Consultas de pedidos :: **sipariş** = pedido; **kargo** = envío; **gecikmek** = retrasarse. :: **Siparişim nerede?** = ¿Dónde está mi pedido? :: **yardımcı olabilir misiniz?** significa «¿puede ayudarme?».
W sipariş = pedido | si-pa-RISH
W kargo = envío; mensajería | kar-GO
W gecikmek = retrasarse | ge-jik-MEK
W siparişim = mi pedido | si-pa-ri-SHIM
W yardımcı olabilir misiniz = ¿puede ayudarme? | yar-dım-jı o-la-bi-LIR mi-si-niz
W müşteri hizmetleri = atención al cliente | müş-te-ri hiz-met-le-RI
W teslimat = entrega | tes-li-MAT
w kontrol etmek = comprobar | kon-trol et-MEK
w Kargonuz = su envío
V Una llamada
D Consultar una entrega
Müşteri: Merhaba, siparişim gecikti. = Hola, mi pedido se ha retrasado.
Görevli: Sipariş numaranızı alabilir miyim? = ¿Me puede dar su número de pedido?
Müşteri: Evet, numaram 245. = Sí, mi número es 245.
Görevli: Kontrol ediyorum. Kargonuz yarın gelecek. = Lo estoy comprobando. Su envío llegará mañana.
N Müşteri, Görevli
W gecikti = se retrasó | ge-jik-TI
W görevli = empleado/a | gö-rev-LI
W gelecek = llegará | ge-le-JEK
w kontrol ediyorum = estoy comprobando | kon-trol e-di-YO-rum
w numaranızı = su número | nu-ma-ra-nı-ZUH
Q ¿Qué significa «sipariş»?
+ pedido :: Sipariş es algo que el cliente compró.
- envío :: Kargo es el envío.
- entrega :: Teslimat es la entrega.
Q ¿Qué problema tiene el cliente?
+ Su pedido se retrasó :: Siparişim gecikti.
- No conoce el precio :: No pregunta el precio.
- No puede pagar :: No se habla del pago.
Q ¿Qué pide el empleado?
+ El número del pedido :: Sipariş numaranızı alabilir miyim?
- La dirección del cliente :: No la solicita.
- El recibo :: Fiş significa recibo.
Q ¿Cuándo llegará el paquete?
+ Mañana :: Yarın gelecek = llegará mañana.
- Hoy :: Hoy es bugün.
- La semana que viene :: Gelecek hafta.
R Kargonuz yarın gelecek. :: Traduce.
+ Su envío llegará mañana. :: Kargonuz = su envío; gelecek = llegará.
- Mi pedido se retrasó. :: Esa frase aparece al principio.
- ¿Puede ayudarme? :: Es una petición distinta.
H Siparişim ___ . :: Completa: «Mi pedido se ha retrasado».
+ gecikti :: Gecikti = se retrasó.
- teslimat :: Entrega.
- kontrol :: Comprobación.
A Yardımcı olabilir misiniz? :: Escucha la petición.
+ ¿Puede ayudarme? :: Es una pregunta cortés.
- ¿Dónde está mi pedido? :: Siparişim nerede?
- ¿Cuándo llegará? :: Ne zaman gelecek?
O Siparişim gecikti :: Mi pedido se retrasó :: Gecikti describe un retraso pasado.
X Escribe «¿Dónde está mi pedido?» :: siparişim nerede :: Siparişim = mi pedido.
