N Anna, Ali, Ece, Can, Madrid, İspanya, Türkiye, Ankara, İstanbul, İspanyol, Türk

@ 2 | Nerelisin? | Países y origen
I En turco, los nombres de países y los sufijos de origen se escriben unidos. Aprende a preguntar y contestar de dónde eres.
E Países y nacionalidad :: **Nerelisin?** significa «¿de dónde eres?». Se forma con **nereli** (de qué lugar) y la terminación de «tú». :: **İspanya'danım** = soy de España (literalmente, «soy desde España»). El sufijo **-dan/-den** indica procedencia y cambia según la armonía vocálica. Tras un país escrito con mayúscula se pone apóstrofo: **İspanya'dan**. :: **İspanyolum** expresa «soy español/a»; el sufijo personal se une a la palabra.
W ülke = país | ül-ke
W nereli = de dónde, originario de dónde | ne-re-LI
W nereden = desde dónde | ne-re-DEN
W sen = tú | sen
W İspanya'danım = soy de España | is-pan-ya-da-NUHM
W Türkiye'denim = soy de Turquía | tür-ki-ye-de-NIM
W Madrid'den = de Madrid | mad-rid-DEN
W Ankara'dan = de Ankara | an-ka-ra-DAN
W Madrid'denim = soy de Madrid | mad-rid-de-NIM
W İspanya'dan = de España | is-pan-ya-DAN
W mısın = ¿eres tú? | muh-SUHN
W Türküm = soy turco/a | tür-KÜM
W orada = allí | o-ra-DA
W ya = o, bien | ya
V Países y procedencia
D En el curso
Anna: Ali, nerelisin? = Ali, ¿de dónde eres?
  > nerelisin = de dónde eres
Ali: Madrid'denim. = Soy de Madrid.
  > Madrid'denim = soy de Madrid
Anna: İspanya'dan mısın? = ¿Eres de España?
  > İspanya'dan = de España | mısın = eres tú (pregunta)
Ali: Evet, İspanyolum. = Sí, soy español.
  > Evet = sí | İspanyolum = soy español
Ali: Sen nerelisin? = ¿Y tú, de dónde eres?
  > Sen = tú | nerelisin = de dónde eres
Anna: Türkiye'denim. = Soy de Turquía.
  > Türkiye'denim = soy de Turquía
Q ¿Qué pregunta «Nerelisin?»?
+ ¿De dónde eres? :: Nereli pregunta por el origen.
- ¿Dónde estás? :: Eso es nerede.
- ¿Cuál es tu país? :: Se puede preguntar ülken ne?
Q «İspanya'danım» significa…
+ Soy de España :: -dan indica procedencia.
- Estoy en España :: «En» es -da/-de, no -dan.
- Soy español :: Eso es İspanyolum.
Q ¿Qué sufijo marca procedencia en «Ankara'dan»?
+ -dan :: Significa «desde/de».
- -de :: Marca ubicación: en.
- -lar :: Marca plural.
Q Completa: «Ben ___» = Soy de Turquía.
+ Türkiye'denim :: El origen se expresa con -den.
- Türkiye'de :: Significa «en Turquía».
- Türküm :: Significa «soy turco/a».
R Madrid'denim.
+ Soy de Madrid. :: El sufijo -den marca procedencia.
- Estoy en Madrid. :: «En» se forma con -de.
- Soy Madrid. :: Madrid es el lugar de origen.
A Nerelisin? :: Elige qué dato solicita.
+ El lugar de origen :: Nerelisin pregunta de dónde es alguien.
- El nombre :: Adın ne pregunta el nombre.
- La profesión :: Mesleğin ne pregunta el trabajo.
O Türkiye'denim :: Soy de Turquía :: Türkiye + -den + terminación personal.
X Escribe «soy español/a» :: İspanyolum :: La misma forma sirve para cualquier género.

@ 2 | Mesleğin ne? | Profesiones e idiomas
I Ahora pregunta por el trabajo y por los idiomas que alguien habla. Observa que los verbos cambian según la persona.
E Profesión :: **Mesleğin ne?** = ¿cuál es tu profesión? La respuesta **Öğretmenim** significa «soy profesor/a». :: **Ben doktorum** = soy médico/a. El turco normalmente no usa un verbo separado para «ser» en presente: la terminación se une al nombre. :: **O** significa «él, ella» o «eso»; el contexto aclara el sentido.
E Idiomas y hablar :: El sufijo **-ca/-ce** puede formar el nombre de una lengua: **Türkçe** (turco), **İngilizce** (inglés), **İspanyolca** (español). :: **Konuşuyorum** = hablo; **konuşuyor musun?** = ¿hablas? La partícula interrogativa se escribe separada. :: **Biraz** significa «un poco».
W meslek = profesión | mes-LEK
W mesleğin = tu profesión | mes-le-ĞIN
W öğretmen = profesor/a | ö-ret-MEN
W öğretmenim = soy profesor/a | ö-ret-me-NIM
W doktor = médico/a | dok-TOR
W doktorum = soy médico/a | dok-to-RUM
W öğrenci = estudiante | ö-ren-JI
W öğrenciyim = soy estudiante | ö-ren-ji-YIM
W misin = ¿eres tú? | mi-SIN
W dil = idioma, lengua | dil
W Türkçe = turco (idioma) | türk-CHE
W İngilizce = inglés | in-gi-liz-JE
W İspanyolca = español (idioma) | is-pan-yol-ja
W konuşuyorum = hablo | ko-nu-shu-YO-rum
W konuşuyor = habla | ko-nu-shu-YOR
W musun = ¿(tú) hablas? | mu-SUN
W biraz = un poco | bi-RAZ
W ve = y | ve
W ama = pero | a-MA
V Trabajo e idiomas
D En una cafetería
Ece: Mesleğin ne, Anna? = ¿Cuál es tu profesión, Anna?
  > Mesleğin = tu profesión | ne = qué
Anna: Öğrenciyim. Sen öğretmen misin? = Soy estudiante. ¿Eres profesor?
  > Öğrenciyim = soy estudiante | öğretmen = profesor | misin = eres (pregunta)
Ece: Hayır, doktorum. = No, soy médica.
  > Hayır = no | doktorum = soy médico/a
Anna: Türkçe konuşuyor musun? = ¿Hablas turco?
  > Türkçe = turco | konuşuyor musun = ¿hablas?
Ece: Biraz konuşuyorum. İngilizce de konuşuyorum. = Hablo un poco. También hablo inglés.
  > Biraz = un poco | konuşuyorum = hablo | İngilizce = inglés | de = también
Anna: Ben de Türkçe konuşuyorum. = Yo también hablo turco.
  > Ben = yo | de = también | Türkçe konuşuyorum = hablo turco
Q ¿Qué significa «mesleğin ne»?
+ ¿Cuál es tu profesión? :: Meslek es profesión.
- ¿De dónde eres? :: Eso es nerelisin.
- ¿Qué idioma hablas? :: Dil significa idioma.
Q Completa: «Ben öğretmen___» = Soy profesor/a.
+ im :: La terminación -im expresa «yo soy».
- sin :: -sin significa «tú eres».
- iz :: -iz expresa «nosotros somos».
Q ¿Qué significa «İngilizce»?
+ inglés :: Es el nombre del idioma.
- turco :: Türkçe significa turco.
- español :: İspanyolca significa español.
Q En «Ben de konuşuyorum», «de» significa…
+ también :: Se añade para decir «yo también».
- pero :: «Pero» es ama.
- desde :: Procedencia se expresa con -dan/-den.
R Öğrenciyim.
+ Soy estudiante. :: Öğrenci = estudiante; -yim = soy.
- Eres profesor. :: Eso sería öğretmensin.
- Soy médico. :: Eso sería doktorum.
A Türkçe konuşuyor musun? :: Escucha qué pregunta.
+ ¿Hablas turco? :: Türkçe es turco y konuşuyor musun es «¿hablas?».
- ¿Eres profesor? :: Eso sería öğretmen misin?
- ¿Cuál es tu profesión? :: Eso sería mesleğin ne?
O Biraz İngilizce konuşuyorum :: Hablo un poco de inglés :: Biraz = un poco; konuşuyorum = hablo.
X Escribe «soy estudiante» :: öğrenciyim :: Öğrenci + la terminación de «yo soy».

@ 2 | Kişisel bilgiler | Números y datos personales
I Aprende números cotidianos y cómo dar datos básicos. En turco las decenas se combinan con las unidades sin «y».
E Números :: **Bir, iki, üç, dört, beş, altı, yedi, sekiz, dokuz, on** son del uno al diez. :: Las decenas se forman por separado: **yirmi** (20), **otuz** (30), **kırk** (40), **elli** (50), **altmış** (60), **yetmiş** (70), **seksen** (80), **doksan** (90). :: **Yirmi üç** = 23; **otuz beş** = 35.
E Edad y contacto :: **Kaç yaşındasın?** = ¿cuántos años tienes? Se responde **Yirmi yaşındayım** (tengo veinte años). :: **Telefon numaran ne?** = ¿cuál es tu número de teléfono? **Kaç?** significa «¿cuántos?». Para dar un correo se usa **e-posta adresi**.
W sıfır = cero | suh-FUHR
W bir = uno, un/a | bir
W iki = dos | i-KI
W dört = cuatro | dört
W beş = cinco | besh
W altı = seis | al-TUH
W yedi = siete | ye-DI
W sekiz = ocho | se-KIZ
W dokuz = nueve | do-KUZ
W on = diez | on
W yirmi = veinte | YIR-mi
W otuz = treinta | o-TUZ
W yaş = edad, año de edad | yash
W yaşındayım = tengo (tantos) años | ya-shuhn-da-YUHM
W yaşındasın = tienes (tantos) años | ya-shuhn-da-SUHN
W kaç = cuánto, cuántos | kach
W telefon = teléfono | te-le-FON
W numara = número | nu-ma-RA
W numaran = tu número | nu-ma-RAN
W numaram = mi número | nu-ma-RAM
W tamam = vale, de acuerdo | ta-MAM
V Números y edad
D En la inscripción
Can: Kaç yaşındasın, Anna? = ¿Cuántos años tienes, Anna?
  > Kaç = cuántos | yaşındasın = tienes (edad)
Anna: Yirmi yaşındayım. = Tengo veinte años.
  > Yirmi = veinte | yaşındayım = tengo años
Can: Telefon numaran ne? = ¿Cuál es tu número de teléfono?
  > Telefon numaran = tu número de teléfono | ne = cuál
Anna: Numaram sıfır, beş, üç… = Mi número es cero, cinco, tres…
  > Numaram = mi número | sıfır = cero | beş = cinco | üç = tres
Can: Teşekkürler. Benim numaram burada. = Gracias. Mi número está aquí.
  > Teşekkürler = gracias | benim = mi | numaram = mi número | burada = aquí
Anna: Tamam, Can. = Vale, Can.
  > Tamam = vale, de acuerdo
Q ¿Cuánto vale «yirmi»?
+ Veinte :: Yirmi es 20.
- Doce :: Doce es on iki.
- Treinta :: Treinta es otuz.
Q ¿Qué significa «kaç yaşındasın»?
+ ¿Cuántos años tienes? :: Edad se dice yaş.
- ¿Cuál es tu número? :: Eso es numaran ne.
- ¿De dónde eres? :: Eso es nerelisin.
Q «Telefon numaran ne?» pregunta…
+ Tu número de teléfono :: Telefon numarası es el número de teléfono.
- Tu dirección :: Dirección es adres.
- Tu edad :: Edad es yaş.
Q ¿Qué significa «beş»?
+ Cinco :: Beş = 5.
- Seis :: Altı = 6.
- Ocho :: Sekiz = 8.
R Yirmi yaşındayım.
+ Tengo veinte años. :: Yirmi = veinte.
- Tengo treinta años. :: Treinta es otuz.
- Tengo dos teléfonos. :: Dos es iki.
A Telefon numaran ne? :: Elige el dato solicitado.
+ El número de teléfono :: Telefon numaran ne pregunta el número.
- La edad :: Kaç yaşındasın pregunta la edad.
- La profesión :: Mesleğin ne pregunta la profesión.
O sıfır, beş, üç :: cero, cinco, tres :: Los números se dicen uno a uno en un teléfono.
X Escribe «veinte» en turco :: yirmi :: Yirmi = 20.
