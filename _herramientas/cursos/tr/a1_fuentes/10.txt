@ 10 | Sağlık | El cuerpo y la salud
I Di cómo te encuentras, nombra partes del cuerpo y pide ayuda en una consulta.
E El cuerpo y el dolor :: **Baş** = cabeza; **karın** = barriga; **boğaz** = garganta; **diş** = diente. :: **Başım ağrıyor** = me duele la cabeza (literalmente, mi cabeza duele). El sufijo **-ım** significa «mi». :: **Hastayım** = estoy enfermo/a; **iyiyim** = estoy bien. **Doktor** es médico y **eczane**, farmacia.
W baş = cabeza | bash
W başım = mi cabeza | ba-SHUHM
W karın = barriga | ka-RUHN
W boğaz = garganta | bo-AZ
W diş = diente | dish
W kulak = oreja | ku-LAK
W el = mano | el
W ayak = pie | a-YAK
W ağrıyor = duele | aa-ruh-YOR
W başım ağrıyor = me duele la cabeza | ba-shuhm aa-ruh-YOR
W hastayım = estoy enfermo/a | has-ta-YUHM
W eczane = farmacia | ec-za-NE
W yardım = ayuda | yar-DUHM
W yardım edin = ayúdeme | yar-duhm e-DIN
w neren = qué parte de ti | ne-REN
w boğazın = tu garganta | bo-a-ZUHN
w boğazım = mi garganta | bo-a-ZUHM

V Salud y cuerpo
D En la consulta
Doktor: Merhaba. Neren ağrıyor? = Hola. ¿Qué te duele?
  > Merhaba = hola | neren = qué parte de ti | ağrıyor = duele
Anna: Başım ağrıyor. = Me duele la cabeza.
  > Başım = mi cabeza | ağrıyor = duele
Doktor: Boğazın da ağrıyor mu? = ¿También te duele la garganta?
  > Boğazın = tu garganta | da = también | ağrıyor mu = duele
Anna: Hayır, boğazım iyi. = No, mi garganta está bien.
  > Hayır = no | boğazım = mi garganta | iyi = bien
Doktor: Dinlen ve su iç. = Descansa y bebe agua.
  > Dinlen = descansa | ve = y | su = agua | iç = bebe
Anna: Teşekkür ederim. = Gracias.
  > Teşekkür ederim = gracias
Q ¿Qué significa «başım»?
+ mi cabeza :: Baş = cabeza; -ım = mi.
- tu cabeza :: Tu cabeza es başın.
- mi mano :: Mano es el.
Q ¿Qué parte del cuerpo es «boğaz»?
+ garganta :: Boğaz = garganta.
- oído :: Kulak = oreja.
- diente :: Diş = diente.
Q «Başım ağrıyor» significa…
+ me duele la cabeza :: Literalmente, mi cabeza duele.
- tengo dolor de garganta :: Eso sería boğazım ağrıyor.
- estoy bien :: Eso es iyiyim.
Q ¿Dónde compras medicina?
+ eczane :: Eczane = farmacia.
- hastane :: Hastane = hospital.
- okul :: Okul = escuela.
R Hastayım.
+ Estoy enfermo/a. :: Hastayım = estoy enfermo/a.
- Estoy bien. :: Eso es iyiyim.
- Me duele la cabeza. :: Eso es başım ağrıyor.
A Yardım edin! :: Escucha la petición de ayuda.
+ ¡Ayúdeme! :: Yardım edin es una petición formal.
- ¡Gracias! :: Teşekkürler = gracias.
- ¡Descanse! :: Dinlen = descansa (informal).
O Başım ve boğazım ağrıyor :: Me duelen la cabeza y la garganta :: -ım expresa «mi».
X Escribe «me duele la cabeza» :: başım ağrıyor :: Başım = mi cabeza.

@ 10 | Eczanede | Necesidades y recomendaciones

D Una recomendación
Anna: Merhaba, boğazım ağrıyor. = Hola, me duele la garganta.
  > Merhaba = hola | boğazım = mi garganta | ağrıyor = duele

  > İlaç = medicina | lazım = necesaria | mı = pregunta

  > Evet = sí | ilaca = a medicina | ihtiyacım var = la necesito
Eczacı: Bu ilacı günde iki kez almalısın. = Debes tomar esta medicina dos veces al día.
  > Bu ilacı = esta medicina | günde = al día | iki kez = dos veces | almalısın = debes tomar

  > Nasıl = cómo | kullanılır = se usa

  > Dinlenmelisin = deberías descansar | ve = y | su içmelisin = deberías beber agua
Q ¿Qué significa «ilaç»?
+ medicina :: İlaç = medicina.
- receta :: Receta es reçete.
- crema :: Crema es krem.
Q «İhtiyacım var» significa…
+ lo necesito :: Literalmente, tengo necesidad.
- no lo necesito :: No necesitar sería ihtiyacım yok.
- me duele :: Duele es ağrıyor.
Q ¿Qué expresa «dinlenmelisin»?
+ deberías descansar :: -malı/-meli da consejo u obligación.
- estoy descansando :: Eso es dinleniyorum.
- descansa (orden) :: Eso es dinlen.
Q «Günde iki kez» significa…
+ dos veces al día :: Günde = al día; iki kez = dos veces.
- dos días :: Dos días es iki gün.
- dos veces por semana :: Semana es hafta.
R Su içmelisin.
+ Deberías beber agua. :: İçmelisin = deberías beber.
- Estoy bebiendo agua. :: Eso es su içiyorum.
- Necesito agua. :: Eso es suya ihtiyacım var.
A İlaç lazım mı? :: Escucha qué se pregunta.
+ ¿Hace falta medicina? :: İlaç = medicina; lazım = necesario.
- ¿Cómo se usa la medicina? :: Nasıl kullanılır = cómo se usa.
- ¿Cuántas veces al día? :: Günde kaç kez.
O Dinlenmelisin ve su içmelisin :: Deberías descansar y beber agua :: Consejo con -meli.
X Escribe «necesito agua» :: suya ihtiyacım var :: Literalmente, tengo necesidad de agua.

@ 10 | Günlük işler | Situaciones cotidianas y repaso
I Integra lo aprendido: pedir algo, encontrar un lugar, hablar de planes y contar una acción pasada.
E Peticiones corteses :: **… alabilir miyim?** = ¿podría tomar/recibir…? **Bakar mısınız?** = ¿me atiende?/¿podría mirar? :: **Anlamadım** = no entendí; **tekrar eder misiniz?** = ¿podría repetir? :: **Yardım eder misiniz?** = ¿podría ayudarme? Son fórmulas útiles en una tienda, estación o consulta.
W bakar mısınız = ¿me atiende?, ¿podría mirar? | ba-KAR muh-suh-NUHZ
W anlamadım = no entendí | an-la-ma-DUHM
W tekrar = otra vez | tek-RAR
W tekrar eder misiniz = ¿podría repetir? | tek-rar e-der mi-si-NIZ
W yardım eder misiniz = ¿podría ayudarme? | yar-duhm e-der mi-si-NIZ
W gidebilir miyim = ¿puedo ir? | gi-de-bi-LIR mi-YIM
w gidin = vaya, vayan (formal) | gi-DIN
w dönün = gire, giren (formal) | dö-NÜN
V Frases útiles
D En la estación
Anna: Bakar mısınız? = Disculpe, ¿me atiende?
  > Bakar mısınız = ¿me atiende? (cortés)
Görevli: Evet, buyurun. = Sí, dígame.
  > Evet = sí | buyurun = adelante, dígame
Anna: İstasyona nasıl giderim? = ¿Cómo llego a la estación?
  > İstasyona = a la estación | nasıl = cómo | giderim = llego
Görevli: Düz gidin, sonra sağa dönün. = Siga recto y luego gire a la derecha.
  > Düz = recto | gidin = vaya (formal) | sonra = después | sağa = a la derecha | dönün = gire (formal)
Anna: Anlamadım. Tekrar eder misiniz? = No entendí. ¿Podría repetir?
  > Anlamadım = no entendí | tekrar eder misiniz = ¿podría repetir?
Görevli: Tabii. = Claro.
  > Tabii = claro
Q ¿Qué significa «anlamadım»?
+ no entendí :: Es la forma pasada de «entender» en primera persona.
- no entiendo :: Eso es anlamıyorum.
- no hablo :: Hablo es konuşuyorum.
Q «Tekrar eder misiniz?» es…
+ ¿Podría repetir? :: Fórmula formal para pedir repetición.
- ¿Adónde va? :: Nereye gidiyorsunuz?
- ¿Cuánto cuesta? :: Ne kadar?
Q ¿Qué significa «bakar mısınız»?
+ ¿Me atiende?/¿podría mirar? :: Forma cortés para llamar la atención.
- ¿Dónde está? :: Nerede?
- ¿Puede ir? :: Gidebilir misin?
Q ¿Cómo dices «siga recto» formalmente?
+ Düz gidin :: Gidin es imperativo formal/plural.
- Düz git :: Es informal singular.
- Düz gidiyorum :: Significa «voy recto».
R Dün istasyona gittim.
+ Ayer fui a la estación. :: Dün = ayer; istasyona = a la estación.
- Mañana voy a la estación. :: Mañana es yarın.
- Ayer estuve en la estación. :: En la estación es istasyonda.
A Tekrar eder misiniz? :: Escucha la petición.
+ ¿Podría repetir? :: Tekrar = otra vez.
- ¿Podría ayudarme? :: Yardım eder misiniz?
- ¿Me atiende? :: Bakar mısınız?
O Düz gidin, sonra sağa dönün :: Siga recto y luego gire a la derecha :: Indicaciones en forma cortés.
X Escribe «no entendí» :: anlamadım :: Anlamak + pasado -dı y terminación «yo».
