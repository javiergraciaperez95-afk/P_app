@ 8 | Tarihler | Meses, fechas y cumpleaños
I Di la fecha y pregunta cuándo es el cumpleaños de alguien.
E Meses y fecha :: Los meses son: **ocak, şubat, mart, nisan, mayıs, haziran, temmuz, ağustos, eylül, ekim, kasım, aralık**. Se escriben con minúscula. :: **Bugün 14 Mayıs** = hoy es 14 de mayo. Para decir «el 14 de mayo», se usa **14 Mayıs'ta**; con números, el sufijo va separado por apóstrofo. :: **Doğum günün ne zaman?** = ¿cuándo es tu cumpleaños?
E Fechas y ordinales :: Para leer fechas se dice primero el día y luego el mes: **23 Nisan** = 23 de abril. **Kaçıncı?** pregunta «¿cuál número/qué fecha?». :: **Doğum günü** significa cumpleaños (literalmente, día de nacimiento).
W ocak = enero | o-JAK
W şubat = febrero | shu-BAT
W mart = marzo | mart
W nisan = abril | ni-SAN
W mayıs = mayo | ma-YUHS
W haziran = junio | ha-zi-RAN
W temmuz = julio | tem-MUZ
W ağustos = agosto | aa-us-TOS
W eylül = septiembre | ey-LÜL
W ekim = octubre | e-KIM
W kasım = noviembre | ka-SUHM
W aralık = diciembre | a-ra-LUHK
W tarih = fecha, historia | ta-RIH
W doğum = nacimiento | do-UM
W doğum günü = cumpleaños | do-um gü-NÜ
W Mayıs'ta = en mayo | ma-yuhs-TA
w günün = tu cumpleaños/día | gü-NÜN
w günüm = mi cumpleaños/día | gü-NÜM
w martta = en marzo | mart-TA
W kutlama = celebración | kut-la-MA
V Fechas y cumpleaños
D Una invitación
Anna: Doğum günün ne zaman? = ¿Cuándo es tu cumpleaños?
  > Doğum günün = tu cumpleaños | ne zaman = cuándo
Ali: 14 Mayıs'ta. = El 14 de mayo.
  > 14 Mayıs'ta = el 14 de mayo
Anna: Benim doğum günüm martta. = Mi cumpleaños es en marzo.
  > Benim = mi | doğum günüm = mi cumpleaños | martta = en marzo
Ali: Kutlama ne zaman? = ¿Cuándo es la celebración?
  > Kutlama = celebración | ne zaman = cuándo
Anna: 23 Mayıs'ta. = El 23 de mayo.
  > 23 Mayıs'ta = el 23 de mayo
Ali: Tamam, görüşürüz. = Vale, nos vemos.
  > Tamam = vale | görüşürüz = nos vemos
Q ¿Qué mes es «ekim»?
+ octubre :: Ekim = octubre.
- enero :: Ocak = enero.
- mayo :: Mayıs = mayo.
Q ¿Qué significa «doğum günü»?
+ cumpleaños :: Literalmente, «día de nacimiento».
- día festivo :: Bayram = fiesta.
- fecha de viaje :: Viaje es seyahat.
Q «Ne zaman?» pregunta…
+ cuándo :: Se usa para preguntar el tiempo.
- dónde :: Nerede = dónde.
- cuántos :: Kaç = cuántos.
Q ¿Cómo se dice «en mayo»?
+ Mayıs'ta :: El sufijo del mes se separa con apóstrofo.
- Mayısda :: Después de s, el sufijo empieza con t.
- Mayıstan :: Significa «desde mayo».
R 14 Mayıs'ta.
+ El 14 de mayo. :: Se dice día + mes + sufijo.
- El 14 de marzo. :: Marzo es mart.
- En octubre. :: Ekim = octubre.
A Doğum günün ne zaman? :: Escucha qué pregunta.
+ ¿Cuándo es tu cumpleaños? :: Ne zaman = cuándo.
- ¿Cuál es tu nombre? :: Adın ne = cuál es tu nombre.
- ¿Cuántos años tienes? :: Kaç yaşındasın = cuántos años tienes.
O Bugün 23 Mayıs :: Hoy es 23 de mayo :: Bugün = hoy.
X Escribe «abril» en turco :: nisan :: Nisan se escribe con minúscula.

@ 8 | Hava nasıl? | Estaciones y tiempo
I Pregunta qué tiempo hace y describe las estaciones con frases breves.
E Hablar del tiempo :: **Hava nasıl?** = ¿qué tiempo hace? **Hava güzel** = hace buen tiempo. :: **Yağmur yağıyor** = llueve (literalmente, cae lluvia); **kar yağıyor** = nieva. **Güneşli** significa soleado y **bulutlu**, nublado. :: Para decir la temperatura: **Hava sıcak** (hace calor) o **hava soğuk** (hace frío).
E Estaciones :: **İlkbahar** = primavera; **yaz** = verano; **sonbahar** = otoño; **kış** = invierno. :: **-de/-da** también puede indicar la estación: **yazın** (en verano), **kışın** (en invierno).
W hava = tiempo, aire | ha-VA
W yağmur = lluvia | yaa-MUR
W yağıyor = cae, está cayendo | yaa-uh-YOR
W kar = nieve | kar
W güneş = sol | gü-NESH
W güneşli = soleado/a | gü-nesh-LI
W bulut = nube | bu-LUT
W bulutlu = nublado/a | bu-lut-LU
W rüzgâr = viento | rüz-GYAR
W ilkbahar = primavera | ilk-ba-HAR
W yaz = verano | yaz
W sonbahar = otoño | son-ba-HAR
W kış = invierno | kuhsh
W hava nasıl = qué tiempo hace | ha-va na-SUHL
W yağmur yağıyor = está lloviendo | yaa-mur yaa-uh-YOR
w mu = partícula de pregunta | mu
w kışın = en invierno | kuh-shuhn
w yazın = en verano | ya-zuhn
V El tiempo
D Un día de primavera
Ece: Hava nasıl bugün? = ¿Qué tiempo hace hoy?
  > Hava = tiempo | nasıl = cómo | bugün = hoy
Anna: Güneşli ve sıcak. = Soleado y cálido.
  > Güneşli = soleado | ve = y | sıcak = cálido
Ece: Yağmur yağıyor mu? = ¿Está lloviendo?
  > Yağmur yağıyor = está lloviendo | mu = pregunta
Anna: Hayır, yağmur yok. = No, no hay lluvia.
  > Hayır = no | yağmur = lluvia | yok = no hay
Ece: Kışın hava soğuk. = En invierno hace frío.
  > Kışın = en invierno | hava = tiempo | soğuk = frío
Anna: Evet, yazın hava güzel. = Sí, en verano hace buen tiempo.
  > Evet = sí | yazın = en verano | hava güzel = hace buen tiempo
Q ¿Qué significa «güneşli»?
+ soleado/a :: Güneş = sol; güneşli = soleado.
- nublado/a :: Bulutlu = nublado.
- lluvioso/a :: Yağmurlu = lluvioso.
Q ¿Qué estación es «sonbahar»?
+ otoño :: Sonbahar = otoño.
- primavera :: İlkbahar = primavera.
- invierno :: Kış = invierno.
Q «Yağmur yağıyor» significa…
+ está lloviendo :: Literalmente, cae lluvia.
- está nevando :: Kar yağıyor = está nevando.
- hace sol :: Hace sol se puede decir güneşli.
Q ¿Qué significa «hava soğuk»?
+ hace frío :: Soğuk = frío.
- hace calor :: Sıcak = calor.
- hace viento :: Rüzgâr var = hay viento.
R Yazın hava güzel.
+ En verano hace buen tiempo. :: Yazın = en verano.
- En invierno llueve. :: Kışın = en invierno.
- En primavera nieva. :: İlkbahar = primavera.
A Hava nasıl? :: Escucha qué pregunta.
+ ¿Qué tiempo hace? :: Hava = tiempo; nasıl = cómo.
- ¿Qué día es hoy? :: Bugün hangi gün?
- ¿Qué estación es? :: Mevsim ne?
O Kışın kar yağıyor :: En invierno nieva :: Kışın = en invierno.
X Escribe «nublado» :: bulutlu :: Bulut = nube; -lu expresa «con».

@ 8 | Hobilerim | Aficiones, gustos y capacidad
I Habla de lo que te gusta hacer y pregunta por las aficiones de otra persona.
E Gustar :: **Kitap okumayı seviyorum** = me gusta leer libros. El verbo **sevmek** (querer/gustar) recibe el objeto en **-(y)I**: **müzik dinlemeyi seviyorum**. :: Para preguntar: **Ne yapmayı seviyorsun?** = ¿qué te gusta hacer? **Ben de** = a mí también. :: **-abilir/-ebilir** expresa capacidad: **yüzebilirim** = sé/puedo nadar; **yüzemem** = no puedo nadar.
W hobi = afición | ho-BI
W kitap okumak = leer libros | ki-tap o-u-MAK
W müzik dinlemek = escuchar música | mü-zik din-le-MEK
W yüzmek = nadar | yüz-MEK
W yürümek = caminar | yü-rü-MEK
W koşmak = correr | kosh-MAK
W yemek yapmak = cocinar | ye-mek yap-MAK
W dans etmek = bailar | dans et-MEK
W seviyorum = me gusta, quiero | se-vi-YO-rum
W seviyorsun = te gusta, quieres | se-vi-YOR-sun
W okumayı = leer (como objeto) | o-ku-ma-YUH
W dinlemeyi = escuchar (como objeto) | din-le-me-YI
W yüzebilirim = puedo nadar | yü-ze-bi-li-RIM
W yüzemem = no puedo nadar | yü-ze-MEM
W boş zaman = tiempo libre | bosh za-MAN
W birlikte = juntos/as | bir-lik-TE
W dans = baile, bailar | dans
w boş = libre, vacío | bosh
w zamanda = en el tiempo | za-man-DA
w yapmayı = hacer (como objeto) | yap-ma-YUH
w seviyor = le gusta, quiere | se-vi-YOR
w edebiliriz = podemos hacer | e-de-bi-li-RIZ
w yüzebilir = puede nadar | yü-ze-bi-LIR
w yürüyelim = caminemos | yü-rü-ye-LIM
V Tiempo libre
D Planes para el sábado
Ali: Boş zamanda ne yapmayı seviyorsun? = ¿Qué te gusta hacer en tu tiempo libre?
  > Boş zamanda = en el tiempo libre | ne yapmayı seviyorsun = qué te gusta hacer
Anna: Kitap okumayı seviyorum. = Me gusta leer libros.
  > Kitap okumayı = leer libros | seviyorum = me gusta
Ali: Müzik dinlemeyi seviyor musun? = ¿Te gusta escuchar música?
  > Müzik dinlemeyi = escuchar música | seviyor musun = te gusta
Anna: Evet, birlikte dans edebiliriz. = Sí, podemos bailar juntos.
  > Evet = sí | birlikte = juntos | dans edebiliriz = podemos bailar
Ali: Yüzebilir misin? = ¿Sabes nadar?
  > Yüzebilir misin = puedes nadar
Anna: Evet, yüzebilirim. = Sí, puedo nadar.
  > Evet = sí | yüzebilirim = puedo nadar
Q ¿Cómo se dice «me gusta leer libros»?
+ Kitap okumayı seviyorum :: La acción que gusta lleva -mayı.
- Kitap okuyorum seviyorum :: La estructura une leer como objeto y sevmek.
- Kitap okumak seviyor :: Falta la terminación de «yo».
Q ¿Qué expresa «yüzebilirim»?
+ puedo nadar :: -ebilir expresa capacidad.
- no puedo nadar :: Eso es yüzemem.
- me gusta nadar :: Eso es yüzmeyi seviyorum.
Q «Boş zaman» significa…
+ tiempo libre :: Boş = libre/vacío; zaman = tiempo.
- fin de semana :: Eso es hafta sonu.
- después de clase :: Clase es ders.
Q ¿Qué pregunta «Yüzebilir misin?»?
+ ¿Sabes nadar? :: Pregunta por la capacidad.
- ¿Te gusta nadar? :: Sería yüzmeyi seviyor musun.
- ¿Cuándo nadas? :: Ne zaman = cuándo.
R Müzik dinlemeyi seviyorum.
+ Me gusta escuchar música. :: Dinlemeyi seviyorum = me gusta escuchar.
- Estoy escuchando música. :: Eso es müzik dinliyorum.
- Puedo escuchar música. :: Eso es müzik dinleyebilirim.
A Yüzemem. :: Escucha la capacidad negativa.
+ No puedo nadar :: -emem expresa que no puedo.
- Puedo nadar :: Yüzebilirim.
- Me gusta nadar :: Yüzmeyi seviyorum.
O Hafta sonu birlikte yürüyelim :: Caminemos juntos el fin de semana :: Propuesta sencilla con -elim.
X Escribe «puedo nadar» :: yüzebilirim :: Yüzmek + sufijo de capacidad y «yo».
