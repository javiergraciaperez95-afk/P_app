N Anna, Ali, Ece, Can, Madrid, İspanya, Türkiye, Ankara, İstanbul, Ayşe, Mehmet, Elif, Deniz

@ 7 | Renkler ve eşyalar | Colores y objetos
I Describe objetos con colores y tamaños. En turco los adjetivos preceden al nombre y no cambian.
E Colores y adjetivos :: Los colores van antes del nombre: **kırmızı araba** (coche rojo), **mavi çanta** (bolso azul). :: El adjetivo no cambia por género o plural: **güzel ev**, **güzel evler** (casa bonita, casas bonitas). :: Para decir «esto es…», usa **Bu…**; **şu** señala algo más apartado y **o** algo lejano.
W kırmızı = rojo/a | kuh-ruh-MUH-zuh
W mavi = azul | ma-VI
W beyaz = blanco/a | be-YAZ
W siyah = negro/a | si-YAH
W yeşil = verde | ye-SHIL
W sarı = amarillo/a | sa-RUH
W renk = color | renk
W çanta = bolso, mochila | chan-TA
W masa = mesa | ma-SA
W sandalye = silla | san-dal-YE
W araba = coche | a-ra-BA
W büyük = grande | bü-YÜK
W yeni = nuevo/a | ye-NI
W eski = viejo/a | es-KI
W şu = ese/a, eso (cerca de ti) | shu
W o = aquel/a, aquello, él/ella | o
w kimin = de quién | ki-MIN
w çantam = mi bolso | chan-TAM
w rengi = su color | ren-GI
V Colores y objetos
D En el aula
Ece: Bu çanta kimin? = ¿De quién es este bolso?
  > Bu = este | çanta = bolso | kimin = de quién
Anna: Benim çantam. = Mi bolso.
  > Benim = mío | çantam = mi bolso
Ece: Rengi ne? = ¿De qué color es?
  > Rengi = su color | ne = qué
Anna: Mavi. = Azul.
  > Mavi = azul
Ece: Şu masa yeni mi? = ¿Esa mesa es nueva?
  > Şu = esa | masa = mesa | yeni = nueva | mi = pregunta
Anna: Hayır, eski. = No, es vieja.
  > Hayır = no | eski = vieja
Q ¿Dónde se coloca normalmente el color?
+ Antes del nombre :: Mavi çanta = bolso azul.
- Después del nombre :: El adjetivo va antes del sustantivo.
- Al principio siempre :: Puede ir al principio de la frase, pero modifica al nombre.
Q ¿Qué significa «yeşil»?
+ verde :: Yeşil es el color verde.
- amarillo :: Sarı = amarillo.
- negro :: Siyah = negro.
Q ¿Qué señala «şu»?
+ algo cerca de quien escucha :: Şu suele señalar algo apartado del hablante.
- algo aquí en la mano :: Bu suele señalar algo cercano al hablante.
- una persona solamente :: O también señala objetos.
Q «Eski» significa…
+ viejo/a :: Yeni significa nuevo.
- grande :: Büyük significa grande.
- pequeño/a :: Küçük significa pequeño.
R Bu kırmızı araba.
+ Este coche es rojo. :: Kırmızı = rojo; araba = coche.
- Este coche es azul. :: Azul es mavi.
- Esa casa es roja. :: Casa es ev.
A Sarı masa. :: Escucha el color y el objeto.
+ mesa amarilla :: Sarı = amarillo; masa = mesa.
- silla blanca :: Sandalye = silla; blanco = beyaz.
- bolso verde :: Bolso = çanta; verde = yeşil.
O Büyük, yeni bir araba :: Un coche grande y nuevo :: Adjetivos antes del nombre.
X Escribe «bolso azul» :: mavi çanta :: El color precede al nombre.

@ 7 | Kıyafetler | Ropa y objeto directo
I Di qué ropa llevas o compras. El objeto definido puede llevar el sufijo -(y)I.
E Ropa :: **Gömlek** = camisa; **pantolon** = pantalones; **elbise** = vestido. Los nombres de ropa se usan normalmente en singular para una prenda. :: **Bu gömleği alıyorum** = compro esta camisa. El objeto definido recibe **-(y)ı/-i/-u/-ü**: **gömlek → gömleği**. Si termina en vocal, aparece **y**: **çantayı** (el bolso). :: El sufijo no es necesario al hablar de algo indefinido: **Bir gömlek alıyorum** = compro una camisa.
W gömlek = camisa | göm-LEK
W pantolon = pantalones | pan-to-LON
W elbise = vestido | el-bi-SE
W etek = falda | e-TEK
W ayakkabı = zapato | a-yak-ka-BUH
W ceket = chaqueta | ce-KET
W şapka = sombrero, gorra | shap-KA
W çorap = calcetín | cho-RAP
W giyiyorum = llevo puesto, me visto | gi-yi-YO-rum
W giyiyorsun = llevas puesto | gi-yi-YOR-sun
W alıyorum = compro | a-lu-YO-rum
W gömleği = la camisa (objeto definido) | göm-le-YI
W çantayı = el bolso (objeto definido) | chan-ta-YUH
W elbiseyi = el vestido (objeto definido) | el-bi-se-YI
W hangi = cuál, qué | han-GI
w giyiyor = lleva puesto | gi-yi-YOR
w almıyorum = no compro | al-mu-YO-rum
w ceketi = la chaqueta (objeto definido) | ce-ke-TI
V Ropa
D De compras
Anna: Hangi gömleği alıyorsun? = ¿Qué camisa compras?
  > Hangi = cuál | gömleği = la camisa | alıyorsun = compras
Ali: Mavi gömleği alıyorum. = Compro la camisa azul.
  > Mavi = azul | gömleği = la camisa | alıyorum = compro
Anna: Bu elbiseyi giyiyor musun? = ¿Llevas este vestido?
  > Bu = este | elbiseyi = el vestido | giyiyor musun = llevas
Ali: Hayır, elbiseyi almıyorum. = No, no compro el vestido.
  > Hayır = no | elbiseyi = el vestido | almıyorum = no compro
Anna: Şu ceket güzel. = Esa chaqueta es bonita.
  > Şu = esa | ceket = chaqueta | güzel = bonita
Ali: Evet, ceketi alıyorum. = Sí, compro la chaqueta.
  > Evet = sí | ceketi = la chaqueta | alıyorum = compro
Q ¿Qué significa «gömlek»?
+ camisa :: Gömlek = camisa.
- vestido :: Elbise = vestido.
- chaqueta :: Ceket = chaqueta.
Q «Bu gömleği alıyorum» significa…
+ Compro esta camisa :: Gömleği lleva el sufijo de objeto definido.
- Llevo una camisa :: Giyiyorum significa llevo puesto.
- La camisa está aquí :: Aquí es burada.
Q ¿Qué sufijo aparece en «çantayı»?
+ -(y)ı :: El objeto definido recibe este sufijo.
- -lar :: Ese es plural.
- -de :: Ese indica ubicación.
Q ¿Qué significa «hangi»?
+ cuál, qué :: Se usa para preguntar qué objeto.
- quién :: Kim = quién.
- dónde :: Nerede = dónde.
R Mavi gömleği alıyorum.
+ Compro la camisa azul. :: Mavi = azul; gömleği = la camisa.
- Llevo una camisa azul. :: Llevar es giyiyorum.
- Compro un vestido azul. :: Vestido es elbise.
A Şu ceket güzel. :: Escucha qué prenda es bonita.
+ Esa chaqueta es bonita :: Ceket = chaqueta.
- Ese sombrero es bonito :: Şapka = sombrero.
- Ese vestido es bonito :: Elbise = vestido.
O Bir şapka alıyorum :: Compro un sombrero :: Un objeto indefinido no necesita el sufijo definido.
X Escribe «la camisa» como objeto definido :: gömleği :: Gömlek cambia k por ğ y recibe -i.

@ 7 | İnsanlar | Describir personas y profesiones
I Habla del aspecto físico y reconoce profesiones. **Var** y **yok** sirven para decir qué tiene una persona.
E Describir a alguien :: **Uzun** significa alto/largo; **kısa**, bajo/corto. **Saç** es pelo y **göz** es ojo. :: **Uzun saçlı** = de pelo largo; **mavi gözlü** = de ojos azules. Los sufijos **-lı/-li/-lu/-lü** pueden significar «con/tener»: **gözlü** (con ojos). :: **Saçı var** = tiene pelo; **gözlük** = gafas.
W saç = pelo | sach
W saçlı = de pelo, con pelo | sach-LUH
W gözlü = de ojos | göz-LÜ
W gözlük = gafas | göz-LÜK
W sakal = barba | sa-KAL
W sakallı = con barba | sa-kal-LUH
W aşçı = cocinero/a | ash-CHUH
W mühendis = ingeniero/a | mü-hen-DIS
W polis = policía | po-LIS
w biri = persona, alguien | bi-RI
w boylu = de cierta estatura | boy-LU
w gözlüklü = con gafas | göz-lük-LÜ
w olarak = como, en calidad de | o-la-RAK
w eşi = su pareja, su cónyuge | e-SHI
w mu = partícula interrogativa | mu
V Personas y trabajos
D Dos amigos
Anna: Mehmet nasıl biri? = ¿Cómo es Mehmet?
  > Mehmet = nombre propio | nasıl biri = cómo es una persona
Ali: Uzun boylu, genç ve gözlüklü. = Alto, joven y con gafas.
  > Uzun boylu = alto | genç = joven | gözlüklü = con gafas
Anna: Ne iş yapıyor? = ¿En qué trabaja?
  > Ne iş yapıyor = qué trabajo hace
Ali: Doktor olarak çalışıyor. = Trabaja como médico.
  > Doktor = médico | olarak = como | çalışıyor = trabaja
Anna: Eşi de doktor mu? = ¿Su pareja también es médico/a?
  > Eşi = su pareja | de = también | doktor = médico | mu = pregunta
Ali: Hayır, aşçı. = No, es cocinera.
  > Hayır = no | aşçı = cocinero/a
Q ¿Qué significa «uzun» al describir a una persona?
+ alto/a :: También puede significar largo/a.
- bajo/a :: Kısa significa bajo/a.
- joven :: Genç significa joven.
Q ¿Cómo dices «con barba»?
+ sakallı :: Sakal + sufijo -lı.
- sakal :: Significa barba, sin «con».
- gözlüklü :: Significa con gafas.
Q ¿Qué significa «aşçı»?
+ cocinero/a :: Aşçı = cocinero/a.
- médico/a :: Doktor = médico/a.
- policía :: Polis = policía.
Q ¿Qué significa «gözlük»?
+ gafas :: Gözlük = gafas.
- ojos :: Göz = ojo.
- pelo :: Saç = pelo.
R Uzun boylu ve genç.
+ Alto/a y joven. :: Uzun boylu = alto/a.
- Bajo/a y mayor. :: Bajo/a es kısa; mayor es yaşlı.
- De pelo largo. :: Eso es uzun saçlı.
A Doktor olarak çalışıyor. :: Escucha la profesión.
+ Trabaja como médico/a :: Doktor = médico/a.
- Trabaja como cocinero/a :: Aşçı = cocinero/a.
- Trabaja como profesor/a :: Öğretmen = profesor/a.
O Genç ve uzun boylu :: Joven y alto/a :: Los adjetivos no cambian por género.
X Escribe «con gafas» :: gözlüklü :: Gözlük + sufijo que expresa «con».
