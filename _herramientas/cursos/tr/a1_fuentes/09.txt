@ 9 | Davet | Invitar y aceptar
I Invita a alguien, acepta o rechaza una propuesta con educación.
E Invitar :: **Sinemaya gidelim mi?** = ¿vamos al cine? La terminación **-elim/-alım** propone hacer algo juntos: **yiyelim** (comamos), **içelim** (bebamos). :: **İster misin?** = ¿quieres? **Olur** significa «vale» y **üzgünüm** (lo siento) sirve para rechazar con amabilidad. :: **Saat kaçta buluşalım?** = ¿a qué hora quedamos?
W sinema = cine | si-ne-MA
W sinemaya = al cine | si-ne-ma-YA
W film = película | film
W gidelim = vayamos | gi-de-LIM
W gidelim mi = ¿vamos? | gi-de-LIM mi
W yiyelim = comamos | yi-ye-LIM
W içelim = bebamos | i-che-LIM
W ister misin = ¿quieres? | is-ter mi-SIN
W olur = vale, de acuerdo | o-LUR
W üzgünüm = lo siento | üz-gü-NÜM
W yarın = mañana | ya-RUHN
W buluşalım = quedemos | bu-lu-sha-LUHM
W buluşalım mı = ¿quedamos? | bu-lu-sha-LUHM mi
W saat kaçta = a qué hora | sa-at kach-TA
W beraber = juntos/as | be-ra-BER
w komedi = comedia | ko-me-DI
w izleyelim = veamos | iz-le-ye-LIM
w olmaz = no es posible, no vale | ol-MAZ
w yemek = comida, comer | ye-MEK
V Invitaciones
D Un plan para la tarde
Anna: Bugün sinemaya gidelim mi? = ¿Vamos hoy al cine?
  > Bugün = hoy | sinemaya = al cine | gidelim mi = ¿vamos?
Ali: Olur. Hangi film? = Vale. ¿Qué película?
  > Olur = vale | hangi = qué | film = película
Anna: Komedi izleyelim. = Veamos una comedia.
  > Komedi = comedia | izleyelim = veamos
Ali: Saat kaçta buluşalım? = ¿A qué hora quedamos?
  > Saat kaçta = a qué hora | buluşalım = quedamos
Anna: Saat yedide, beraber. = A las siete, juntos.
  > Saat yedide = a las siete | beraber = juntos
Ali: Tamam, görüşürüz. = Vale, nos vemos.
  > Tamam = vale | görüşürüz = nos vemos
Q ¿Qué expresa «gidelim»?
+ vayamos :: -elim forma una propuesta de «nosotros».
- vamos (ahora) :: Voy es gidiyorum.
- fuiste :: El pasado es gittim.
Q ¿Qué significa «olur»?
+ vale, de acuerdo :: Se usa para aceptar una propuesta.
- lo siento :: Eso es üzgünüm.
- mañana :: Eso es yarın.
Q «İster misin?» pregunta…
+ ¿Quieres? :: Es una oferta o pregunta amable.
- ¿Dónde quieres ir? :: Dónde es nereye.
- ¿A qué hora quedamos? :: Eso es saat kaçta buluşalım.
Q ¿Qué significa «sinemaya»?
+ al cine :: Sinema + sufijo direccional.
- en el cine :: En el cine sería sinemada.
- desde el cine :: Desde sería sinemadan.
R Bugün sinemaya gidelim mi?
+ ¿Vamos hoy al cine? :: Es una invitación.
- ¿Estás hoy en el cine? :: En el cine sería sinemada.
- ¿Qué película vemos mañana? :: Mañana es yarın.
A Üzgünüm, bugün olmaz. :: Escucha una forma amable de rechazar.
+ Lo siento, hoy no puedo :: Üzgünüm = lo siento.
- Vale, de acuerdo :: Olur = vale.
- ¿Quieres? :: İster misin = ¿quieres?
O Yarın beraber yemek yiyelim :: Comamos juntos mañana :: -elim expresa una propuesta.
X Escribe «¿vamos?» con el verbo gitmek :: gidelim mi :: Gitmek + terminación de propuesta + pregunta.

@ 9 | Seyahat | Viajes y alojamiento
I Pregunta por un hotel, una habitación y un billete. Las formas vistas para lugar y dirección también sirven al viajar.
E Viajar :: **Otel** = hotel; **oda** = habitación; **rezervasyon** = reserva. **Bir oda istiyorum** = quiero una habitación. :: **Tek kişilik oda** = habitación individual; **iki kişilik oda** = habitación doble. **Kahvaltı dahil mi?** = ¿está incluido el desayuno? :: **Giriş** es entrada/check-in y **çıkış** es salida/check-out.
W otel = hotel | o-TEL
W oda = habitación | o-DA
W rezervasyon = reserva | re-zer-vas-YON
W tek = uno, único | tek
W kişilik = para (tantas) personas | ki-shi-LIK
W tek kişilik = individual | tek ki-shi-LIK
W iki kişilik = doble | i-ki ki-shi-LIK
W giriş = entrada, check-in | gi-RISH
W çıkış = salida, check-out | chu-KUSH
W dahil = incluido/a | da-HIL
W kahvaltı dahil = desayuno incluido | kah-val-tuh da-HIL
W kaç gece = cuántas noches | kach ge-JE
W gece = noche | ge-JE
W kalıyorum = me alojo, me quedo | ka-lu-YO-rum
W kalıyorsun = te alojas | ka-lu-YOR-sun
W pasaport = pasaporte | pa-sa-PORT
w rezervasyonum = mi reserva | re-zer-vas-yo-NUM
w kalıyorsunuz = se queda usted | ka-lu-yor-SU-nuz
V En el hotel
D En recepción
Anna: Merhaba, rezervasyonum var. = Hola, tengo una reserva.
  > Merhaba = hola | rezervasyonum = mi reserva | var = tengo
Görevli: Kaç kişilik oda? = ¿Habitación para cuántas personas?
  > Kaç = cuántas | kişilik oda = habitación para personas
Anna: Tek kişilik oda. = Una habitación individual.
  > Tek kişilik = individual | oda = habitación
Görevli: Kaç gece kalıyorsunuz? = ¿Cuántas noches se queda?
  > Kaç gece = cuántas noches | kalıyorsunuz = se queda usted
Anna: İki gece. Kahvaltı dahil mi? = Dos noches. ¿Está incluido el desayuno?
  > İki gece = dos noches | kahvaltı dahil = desayuno incluido | mi = pregunta
Görevli: Evet. Pasaport, lütfen. = Sí. El pasaporte, por favor.
  > Evet = sí | pasaport = pasaporte | lütfen = por favor
Q ¿Qué significa «oda»?
+ habitación :: Oda = habitación.
- reserva :: Reserva es rezervasyon.
- hotel :: Hotel también se dice otel.
Q «Tek kişilik oda» es…
+ una habitación individual :: Tek = una; kişilik = para personas.
- una habitación doble :: Doble es iki kişilik.
- dos habitaciones :: Dos habitaciones es iki oda.
Q ¿Qué pregunta «kaç gece»?
+ cuántas noches :: Gece = noche.
- a qué hora :: Eso es saat kaçta.
- qué hotel :: Hangi otel.
Q «Dahil» significa…
+ incluido :: Kahvaltı dahil = desayuno incluido.
- entrada :: Entrada es giriş.
- salida :: Salida es çıkış.
R İki gece kalıyorum.
+ Me quedo dos noches. :: Gece = noche; kalıyorum = me quedo.
- Me quedo dos días. :: Día es gün.
- Tengo dos habitaciones. :: Habitación es oda.
A Kahvaltı dahil mi? :: Escucha qué pregunta el huésped.
+ ¿Está incluido el desayuno? :: Kahvaltı = desayuno; dahil = incluido.
- ¿A qué hora es el desayuno? :: Hora es saat.
- ¿Dónde está el hotel? :: Dónde es nerede.
O Pasaport, lütfen :: El pasaporte, por favor :: Petición breve en recepción.
X Escribe «habitación doble» :: iki kişilik oda :: İki kişilik = para dos personas.

@ 9 | Dün ne yaptın? | Ayer y experiencias pasadas
I Aprende a contar una acción terminada en pasado y a preguntar qué hizo otra persona.
E Pasado definido :: Para contar una acción terminada, añade **-dı/-di/-du/-dü** o, después de consonante sorda, **-tı/-ti/-tu/-tü**. Después se añade la persona: **geldim** (vine), **gittim** (fui), **izledim** (vi). :: **Dün** significa ayer; **geçen hafta** significa la semana pasada. :: Pregunta informal: **Ne yaptın?** = ¿qué hiciste? El verbo **yapmak** (hacer) tiene una forma irregular frecuente: **yaptım** (hice).
W dün = ayer | dün
W geçen = pasado/a (anterior) | ge-CHEN
W geçen hafta = la semana pasada | ge-chen haf-TA
W yaptım = hice | yap-TUHM
W yaptın = hiciste | yap-TUHN
W gittim = fui | git-TIM
W gittin = fuiste | git-TIN
W geldim = vine | gel-DIM
W izledim = vi, miré | iz-le-DIM
W okudum = leí | o-ku-DUM
W yedim = comí | ye-DIM
W içtim = bebí | ich-TIM
W gezdim = paseé, recorrí | gez-DIM
W ne yaptın = qué hiciste | ne yap-TUHN
W güzel = bonito, bien | gü-ZEL
W müze = museo | mü-ZE
W dün müzeye gittim = ayer fui al museo | dün mü-ze-ye git-TIM
w Müzeye = al museo | mü-ze-YE
w izledin = viste, miraste | iz-le-DIN
w yemek = comida | ye-MEK
V Ayer
D Una conversación
Anna: Dün ne yaptın? = ¿Qué hiciste ayer?
  > Dün = ayer | ne yaptın = qué hiciste
Ali: Müzeye gittim. = Fui al museo.
  > Müzeye = al museo | gittim = fui
Anna: Orada ne izledin? = ¿Qué viste allí?
  > Orada = allí | ne = qué | izledin = viste
Ali: Güzel bir film izledim. = Vi una película bonita.
  > Güzel = bonita | bir film = una película | izledim = vi
Anna: Sonra ne yaptın? = ¿Qué hiciste después?
  > Sonra = después | ne yaptın = qué hiciste
Ali: Eve geldim, yemek yedim. = Vine a casa y comí.
  > Eve = a casa | geldim = vine | yemek yedim = comí
Q ¿Qué significa «dün»?
+ ayer :: Dün = ayer.
- mañana :: Yarın = mañana.
- la semana pasada :: Geçen hafta = la semana pasada.
Q ¿Qué terminación ves en «gittim»?
+ -ti + -m :: La t aparece tras la consonante sorda t; -m marca «yo».
- -di + -n :: Esa forma sería gittin, «fuiste».
- -yor + -um :: Eso forma el presente continuo.
Q «Ne yaptın?» pregunta…
+ ¿Qué hiciste? :: Yaptın es pasado de «tú».
- ¿Qué haces? :: Ne yapıyorsun es presente.
- ¿Qué quieres hacer? :: Ne yapmak istiyorsun.
Q ¿Qué significa «okudum»?
+ leí :: Okumak = leer; -dum = yo hice la acción.
- leo :: Okuyorum = leo.
- leeré :: Gelecek = futuro.
R Dün müzeye gittim.
+ Ayer fui al museo. :: Dün = ayer; gittim = fui.
- Mañana voy al museo. :: Mañana es yarın; voy es gidiyorum.
- Ayer vine del museo. :: Desde el museo sería müzeden.
A Yemek yedim. :: Escucha qué hizo.
+ Comí :: Yedim = comí.
- Bebí :: İçtim = bebí.
- Leí :: Okudum = leí.
O Dün film izledim :: Ayer vi una película :: El pasado -di marca una acción terminada.
X Escribe «fui» :: gittim :: Gitmek + pasado -ti + «yo».
