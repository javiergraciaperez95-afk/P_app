@ 4 | Şimdiki zamanda ünlü daralması | Cambios vocálicos en el presente
I Observa cómo algunas raíces acabadas en **a/e** cambian al añadir **-iyor**.
E Cambios frecuentes :: En **başlamak**, la a se estrecha: **başlıyor**. En **beklemek**, la e se estrecha: **bekliyor**. :: No todas las raíces siguen el mismo cambio; aprende estas formas frecuentes dentro de frases.
V Verbos en contexto
D Durakta
Anna: Otobüs bekliyor musun? = ¿Estás esperando el autobús?
Ali: Evet, otobüsü bekliyorum. = Sí, estoy esperando el autobús.
Anna: Ders ne zaman başlıyor? = ¿Cuándo empieza la clase?
Ali: Ders saat dokuzda başlıyor. = La clase empieza a las nueve.
w Otobüs bekliyor musun = ¿estás esperando el autobús?
w Evet otobüsü bekliyorum = sí estoy esperando el autobús
w Otobüsü bekliyorum = estoy esperando el autobús
w Ders ne zaman başlıyor = ¿cuándo empieza la clase?
w Ders saat dokuzda başlıyor = la clase empieza a las nueve
Q ¿Cuál es la forma correcta de **başlamak** con **-iyor**?
+ başlıyor :: La a se estrecha a ı.
- başlaıyor :: No se conservan las dos vocales.
- başliyor :: No se escribe con i.
Q ¿Qué hace Ali?
+ Está esperando el autobús. :: Otobüsü bekliyorum significa eso.
- Está empezando la clase. :: La clase empieza a las nueve.
- Está llegando a casa. :: No aparece ev.
R Ders saat dokuzda başlıyor. :: Traduce.
+ La clase empieza a las nueve. :: Saat dokuzda indica la hora.
- El autobús llega a las nueve. :: Otobüs es autobús y gelmek no aparece.
- La clase termina a las nueve. :: Başlamak significa empezar.
H Ders ne zaman ___? :: Completa «¿cuándo empieza la clase?».
+ başlıyor :: Es la forma de başlamak en presente.
- bekliyor :: Significa espera.
- başlaıyor :: Tiene una vocal de más.
A Evet, otobüsü bekliyorum. :: ¿Qué está haciendo?
+ Espera el autobús. :: Bekliyorum es «estoy esperando».
- Da clase. :: Ders es clase.
- Va a casa. :: No aparece ev.
O Otobüsü bekliyorum :: Estoy esperando el autobús. :: El objeto definido lleva el sufijo -(y)I.
X Escribe «La clase empieza.» :: Ders başlıyor. :: La a cambia a ı.

@ 4 | Şimdiki zamanda olumsuzluk | Negar en presente
I Di qué acción no está ocurriendo y pregunta por una rutina actual.
E Negación verbal :: En el presente, coloca **-m-** antes de **-iyor**: **çalışıyorum → çalışmıyorum**. :: Para preguntar, usa la partícula separada: **Çalışmıyor musun?** = ¿No estás trabajando?
W çalışmak = trabajar
W dinlenmek = descansar
W ders = clase
V Afirmar y negar
D Evde
Mert: Şimdi ders çalışıyor musun? = ¿Estás estudiando ahora?
Ece: Hayır, çalışmıyorum. = No, no estoy estudiando.
Mert: Dinleniyor musun? = ¿Estás descansando?
Ece: Evet, biraz dinleniyorum. = Sí, estoy descansando un poco.
w Şimdi ders çalışıyor musun = ¿estás estudiando ahora?
w Hayır çalışmıyorum = no no estoy estudiando
w Çalışmıyor musun = ¿no estás trabajando o estudiando?
w Dinleniyor musun = ¿estás descansando?
w Evet biraz dinleniyorum = sí estoy descansando un poco
Q ¿Qué expresa **çalışmıyorum**?
+ No estoy trabajando/estudiando. :: -m- marca negación en esta forma.
- Estoy trabajando. :: La forma afirmativa es çalışıyorum.
- No estoy en clase. :: Esa frase sería derste değilim.
Q ¿Dónde se escribe **mi** en «Çalışmıyor musun?»?
+ Separada del verbo. :: La partícula interrogativa se escribe aparte.
- Unida al verbo con guion. :: No se usa guion.
- Antes de la negación. :: La forma del modelo pone mi tras el verbo.
R Evet, biraz dinleniyorum. :: Traduce.
+ Sí, estoy descansando un poco. :: Biraz significa un poco.
- No, no estoy estudiando. :: Es otra respuesta.
- Sí, estoy trabajando mucho. :: Mucho es çok.
H Şimdi ders ___. :: Completa «ahora no estoy estudiando».
+ çalışmıyorum :: La negación va antes de -iyor.
- çalışıyorum :: Es afirmativo.
- çalışmıyor musun :: Es una pregunta a otra persona.
A Çalışmıyor musun? :: ¿Qué pregunta?
+ Si la persona no está trabajando/estudiando. :: La forma está negada y es interrogativa.
- Si la persona ya descansó. :: No se usa el pasado.
- Si la clase empieza ahora. :: No aparece ders başlıyor.
O Şimdi çalışmıyorum :: Ahora no estoy estudiando/trabajando. :: El adverbio se coloca antes del verbo.
X Escribe «No estoy estudiando.» :: Çalışmıyorum. :: Inserta -m- antes de -iyor.

@ 4 | Günlük program ve sıklık | Horario y frecuencia
I Lee un horario breve y cuenta cuándo realizas una actividad.
E Hora y frecuencia :: **Her gün** significa «todos los días»; **bazen**, «a veces». :: La hora concreta suele llevar el sufijo locativo: **saat sekizde** = a las ocho.
V Rutina diaria
T Bir günüm
- Sabah saat yedide kalkıyorum. = Por la mañana me levanto a las siete.
- Her gün kahvaltı yapıyorum. = Desayuno todos los días.
- Öğle yemeğini saat birde yiyorum. = Almuerzo a la una.
- Akşam bazen kitap okuyorum. = Por la noche a veces leo un libro.
w Sabah saat yedide kalkıyorum = por la mañana me levanto a las siete
w Her gün kahvaltı yapıyorum = desayuno todos los días
w Öğle yemeğini saat birde yiyorum = almuerzo a la una
w Akşam bazen kitap okuyorum = por la noche a veces leo un libro
D İki arkadaş
Anna: Her gün erken kalkıyor musun? = ¿Te levantas temprano todos los días?
Ali: Evet, saat yedide kalkıyorum. = Sí, me levanto a las siete.
Anna: Akşam kitap okuyor musun? = ¿Lees por la noche?
Ali: Bazen kitap okuyorum. = A veces leo un libro.
w Her gün erken kalkıyor musun = ¿te levantas temprano todos los días?
w Evet saat yedide kalkıyorum = sí me levanto a las siete
w Akşam kitap okuyor musun = ¿lees por la noche?
w Bazen kitap okuyorum = a veces leo un libro
Q ¿A qué hora se levanta la persona del texto?
+ A las siete. :: Saat yedide indica esa hora.
- A la una. :: A la una almuerza.
- A las ocho. :: No aparece sekizde.
Q ¿Qué significa **bazen**?
+ A veces :: La palabra señala una frecuencia ocasional.
- Todos los días :: Her gün significa todos los días.
- Temprano :: Erken significa temprano.
R Öğle yemeğini saat birde yiyorum. :: Traduce.
+ Almuerzo a la una. :: Öğle yemeği es almuerzo.
- Desayuno a las siete. :: Kahvaltı es desayuno.
- Ceno a las ocho. :: Akşam yemeği es cena.
H Her gün kahvaltı ___. :: Completa «desayuno todos los días».
+ yapıyorum :: Kahvaltı yapmak significa desayunar.
- okuyorum :: Significa leo.
- kalkıyorum :: Significa me levanto.
A Akşam bazen kitap okuyorum. :: ¿Qué hace por la noche?
+ A veces lee un libro. :: Bazen y kitap okuyorum expresan eso.
- Desayuna todos los días. :: Esa acción ocurre por la mañana.
- Se levanta a la una. :: No se habla de levantarse.
O Saat yedide kalkıyorum :: Me levanto a las siete. :: El sufijo de hora se escribe unido.
X Escribe «Todos los días desayuno.» :: Her gün kahvaltı yapıyorum. :: Her gün va antes de la acción.

@ 4 | Saat ve randevu | La hora y una cita
I Pregunta a qué hora empieza una actividad y acuerda un momento para quedar.
E Concertar una hora :: **Saat kaçta?** pregunta «¿a qué hora?». **Saat üçte** significa «a las tres». :: Para proponer una hora, usa **Saat üçte buluşalım mı?** = ¿quedamos a las tres?
W buluşmak = quedar
W randevu = cita
V Horas y planes
D İki arkadaş
Deniz: Yarın saat kaçta buluşalım? = ¿A qué hora quedamos mañana?
Elif: Saat üçte buluşalım. = Quedemos a las tres.
Deniz: Kafede olur mu? = ¿Te va bien en la cafetería?
Elif: Olur, görüşürüz. = Vale, nos vemos.
w Yarın saat kaçta buluşalım = ¿a qué hora quedamos mañana?
w Saat üçte buluşalım = quedemos a las tres
w Kafede olur mu = ¿te va bien en la cafetería?
w Olur görüşürüz = vale nos vemos
Q ¿Qué significa «Saat üçte»?
+ A las tres :: El sufijo indica la hora en que ocurre algo.
- Son las tres en punto. :: Para decir la hora se dice Saat üç.
- Desde las tres. :: No aparece el ablativo.
Q ¿Qué propone Deniz?
+ Quedar mañana. :: Buluşalım propone quedar.
- Ir a clase ahora. :: No aparece ders.
- Hacer una reserva de hotel. :: No aparece otel.
R Saat üçte buluşalım. :: Traduce.
+ Quedemos a las tres. :: La terminación propone hacer algo juntos.
- Nos vemos a las tres ayer. :: No se expresa pasado.
- ¿A qué hora es la cita? :: Es una pregunta diferente.
H Yarın saat kaçta ___? :: Completa «¿a qué hora quedamos mañana?».
+ buluşalım :: Buluşalım es una propuesta conjunta.
- buluşuyor :: Describe una acción actual.
- buluştum :: Significa quedé.
A Kafede olur mu? :: ¿Qué pregunta?
+ Si está bien quedar en la cafetería. :: Kafede indica el lugar.
- Si la cafetería está abierta ayer. :: No se habla del pasado.
- Cuánto cuesta el café. :: Ne kadar pregunta por el precio.
O Yarın saat üçte buluşalım :: Quedemos mañana a las tres. :: El día y la hora aparecen antes del verbo.
X Escribe «Quedemos a las tres.» :: Saat üçte buluşalım. :: Usa la forma de propuesta conjunta.

@ 4 | Önce, sonra ve kısa yönergeler | Antes, después e instrucciones
I Ordena actividades con **önce/sonra** y entiende órdenes de una sola acción.
E Secuencia y órdenes :: **Önce** significa «primero/antes» y **sonra**, «después». :: Las instrucciones breves usan el imperativo: **Bekle!** = ¡Espera!; **Buraya gel!** = ¡Ven aquí!
W önce = antes; primero
V Secuencias y acciones
T Evde sabah
- Önce yüzümü yıkıyorum. = Primero me lavo la cara.
- Sonra kahvaltı yapıyorum. = Después desayuno.
- Saat sekizde evden çıkıyorum. = Salgo de casa a las ocho.
- Otobüsü durakta bekliyorum. = Espero el autobús en la parada.
w Önce yüzümü yıkıyorum = primero me lavo la cara
w Sonra kahvaltı yapıyorum = después desayuno
w Saat sekizde evden çıkıyorum = salgo de casa a las ocho
w Otobüsü durakta bekliyorum = espero el autobús en la parada
D Durakta
Ali: Otobüs ne zaman geliyor? = ¿Cuándo llega el autobús?
Anna: Birazdan geliyor. = Llega dentro de un momento.
Ali: Burada bekle. = Espera aquí.
Anna: Tamam, burada bekliyorum. = Vale, estoy esperando aquí.
w Otobüs ne zaman geliyor = ¿cuándo llega el autobús?
w Birazdan geliyor = llega dentro de un momento
w Burada bekle = espera aquí
w Tamam burada bekliyorum = vale espero aquí
Q ¿Qué hace primero la persona del texto?
+ Se lava la cara. :: Önce presenta la primera acción.
- Sale de casa. :: Sale a las ocho, después.
- Espera el autobús. :: Esa acción ocurre en la parada.
Q ¿Qué significa **bekle** en el diálogo?
+ Espera :: Es un imperativo de beklemek.
- Ven aquí :: Esa orden sería buraya gel.
- Sal de casa :: Evden çık.
R Sonra kahvaltı yapıyorum. :: Traduce.
+ Después desayuno. :: Sonra expresa la secuencia.
- Antes me lavo la cara. :: Esa es la frase anterior.
- Espero en la parada. :: No aparece durak.
H Burada ___. :: Completa «espera aquí».
+ bekle :: Es la orden singular.
- bekliyorum :: Significa estoy esperando.
- beklemek :: Es el infinitivo.
A Otobüsü durakta bekliyorum. :: ¿Dónde espera?
+ En la parada. :: Durakta significa en la parada.
- En casa. :: Evde significa en casa.
- En el autobús. :: Otobüste sería en el autobús.
O Önce kahvaltı yapıyorum :: Primero desayuno. :: Önce marca la primera acción.
X Escribe «Después desayuno.» :: Sonra kahvaltı yapıyorum. :: Sonra va antes de la acción.
