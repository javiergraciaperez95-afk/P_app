N Anna, Ali, Ece, Mert, Elif, Baran, Deniz
@ 1 | Ünlü sesleri ayırt etmek | Distinguir vocales
I Escucha pares como **gül/göl** y **kır/kir**: una vocal distinta puede cambiar el significado.
E Vocales turcas :: **ı** y **i**, **o** y **ö**, **u** y **ü** son sonidos distintos. Practica primero despacio y luego dentro de una palabra. :: **gül** significa «flor» o «sonríe»; **göl**, «lago». **Kır** y **kir** también tienen significados distintos.
W gül = flor; sonríe
W kır = campo
W kir = suciedad
V Pares para escuchar
D En clase
Anna: Bu bir gül. = Esto es una flor.
Ali: Göl değil, gül. = No es un lago, es una flor.
Anna: Kırmızı bir gül. = Una flor roja.
Ali: Evet, çok güzel. = Sí, muy bonita.
w Bu bir gül = esto es una flor
w Göl değil gül = no es un lago es una flor
w Kırmızı bir gül = una flor roja
w Evet çok güzel = sí muy bonita
Q ¿Qué significa «göl»?
+ lago :: La vocal ö distingue esta palabra de gül.
- flor :: Flor es gül.
- suciedad :: Suciedad es kir.
Q En «Kırmızı bir gül», ¿qué es rojo?
+ Una flor :: Gül significa flor.
- Un lago :: La frase no dice göl.
- El campo :: Kır significa campo.
R Göl değil, gül. :: Traduce la frase.
+ No es un lago, es una flor. :: Conserva la diferencia entre las dos palabras.
- No es una flor, es un campo. :: Cambia las palabras clave.
- La suciedad es roja. :: No aparece esa idea.
H Bu bir ___. :: Completa con «flor».
+ gül :: Gül significa flor.
- göl :: Göl significa lago.
- kir :: Kir significa suciedad.
A Kırmızı bir gül. :: ¿Qué objeto se describe?
+ Una flor roja. :: Gül es flor y kırmızı es rojo.
- Un lago azul. :: No aparece göl ni mavi.
- Una casa roja. :: Casa es ev.
O Evet çok güzel :: Sí muy bonita. :: Las vocales se mantienen en cada palabra.
X Escribe «No es un lago, es una flor.» :: Göl değil, gül. :: Contrasta ö e ü.

@ 1 | Hece ve vurgu | Sílabas y acento
I Divide palabras largas en sílabas y escucha dónde cae el acento más habitual.
E Sílabas y ritmo :: Pronuncia cada sílaba con claridad: **ki-tap**, **ar-ka-daş**, **İs-pan-ya**. :: En muchas palabras turcas el acento cae cerca del final, aunque hay excepciones y algunos sufijos cambian el patrón. Imita la palabra completa, no una regla rígida.
W hece = sílaba
W vurgu = acento
V Palabras para marcar el ritmo
w ki-tap = palabra separada en sílabas
D En clase
Ece: Ki-tap, üç hece mi? = Ki-tap, ¿tiene tres sílabas?
Mert: Hayır, iki hece: ki-tap. = No, dos sílabas: ki-tap.
Ece: Ar-ka-daş kaç hece? = Ar-ka-daş, ¿cuántas sílabas?
Mert: Üç hece. = Tres sílabas.
w Ki-tap üç hece mi = Ki-tap ¿tiene tres sílabas?
w Hayır iki hece ki-tap = No dos sílabas ki-tap
w Ar-ka-daş kaç hece = Ar-ka-daş ¿cuántas sílabas?
w Üç hece = Tres sílabas.
Q ¿Cuántas sílabas tiene «kitap»?
+ Dos :: Se divide ki-tap.
- Tres :: Tres sílabas serían ar-ka-daş.
- Cuatro :: No corresponde a la palabra.
Q ¿Qué palabra significa «acento»?
+ vurgu :: Es el término para el acento prosódico.
- hece :: Hece significa sílaba.
- kitap :: Kitap significa libro.
R Ar-ka-daş kaç hece? :: Traduce la pregunta.
+ ¿Cuántas sílabas tiene ar-ka-daş? :: Kaç hece pregunta por el número de sílabas.
- ¿Dónde está mi amigo? :: No es el significado de kaç hece.
- ¿Qué libro lees? :: No se menciona leer.
H Ki-tap, iki ___. :: Completa «dos sílabas».
+ hece :: Hece significa sílaba.
- vurgu :: Vurgu significa acento.
- kitap :: Kitap significa libro.
A Üç hece. :: ¿Cuántas sílabas?
+ Tres :: Üç significa tres.
- Dos :: Dos es iki.
- Cuatro :: Cuatro es dört.
O Kitap iki hece :: Libro tiene dos sílabas. :: La separación es ki-tap.
X Escribe «dos sílabas» en turco. :: iki hece :: Recuerda el orden turco.

@ 1 | Türkçe klavye | El teclado turco
I Practica las letras que no están en el teclado español y distingue **ı/I** de **i/İ**.
E Letras y mayúsculas :: El turco usa **ç, ğ, ı, İ, ö, ş, ü**. La mayúscula de **i** es **İ**; la de **ı** es **I**. :: Usa el mapa de letras de la app para escribirlas y vuelve a leer cada palabra en voz alta.
W tuş = tecla
W İstanbul = Estambul
V Letras especiales
D En clase
Deniz: İstanbul'da hangi harf var? = ¿Qué letra aparece en İstanbul?
Baran: İ harfi. = La letra İ.
Deniz: Şu kelimede ç var: çay. = En esta palabra hay ç: çay.
Baran: Türkçe klavyede yazıyorum. = Lo escribo con el teclado turco.
w İstanbul'da hangi harf var = qué letra hay en Estambul
w İ harfi = la letra İ
w Şu kelimede ç var = en esta palabra hay ç
w Türkçe klavyede yazıyorum = lo escribo con el teclado turco
Q ¿Cuál es la mayúscula de **i** con punto?
+ İ :: La forma mayúscula conserva el punto.
- I :: I es la mayúscula de ı.
- Ş :: Ş corresponde a ş.
Q ¿Qué letra aparece en «çay»?
+ ç :: Çay empieza con ç.
- ş :: Ş no aparece en esa palabra.
- ı :: La palabra no lleva ı.
R Türkçe klavyede yazıyorum. :: Traduce.
+ Lo escribo con el teclado turco. :: Klavyede significa en el teclado.
- Escribo una carta en Estambul. :: No aparece mektup.
- ¿Qué letra tiene el teclado? :: Cambia la frase.
H ___ harfi. :: Completa «la letra İ».
+ İ :: Es la mayúscula de i con punto.
- I :: Es la mayúscula de ı.
- ç :: Es otra letra especial.
A İstanbul'da hangi harf var? :: ¿Qué pregunta la persona?
+ Qué letra hay en Estambul. :: Hangi harf significa qué letra.
- A qué hora sale el tren. :: No se habla de tren.
- Cuántas teclas tiene el teclado. :: No se pregunta un número.
O Şu kelimede ç var :: En esta palabra hay ç. :: La letra especial se escribe ç.
X Escribe «la letra İ» en turco. :: İ harfi :: Distingue İ de I.

@ 1 | Ekleri doğru yazmak | Escribir los sufijos correctamente
I Añade sufijos a nombres propios y observa cuándo se escribe apóstrofo.
E Nombres propios y sufijos :: Después de nombres propios, el sufijo de caso se separa con apóstrofo: **Ankara'da**, **İstanbul'a**. :: En nombres comunes, se escribe unido: **evde**, **okula**. Las mayúsculas turcas **İ** e **I** no son intercambiables.
W Ankara = Ankara
W apóstrofo = apóstrofo
V Escritura de sufijos
D Dos amigos
Anna: Ankara'da mısın? = ¿Estás en Ankara?
Ali: Hayır, İstanbul'dayım. = No, estoy en Estambul.
Anna: Yarın Ankara'ya gidiyor musun? = ¿Mañana vas a Ankara?
Ali: Evet, Ankara'ya gidiyorum. = Sí, voy a Ankara.
w Ankara'da mısın = ¿estás en Ankara?
w İstanbul'dayım = estoy en Estambul
w Yarın Ankara'ya gidiyor musun = ¿mañana vas a Ankara?
w Ankara'ya gidiyorum = voy a Ankara
Q ¿Cómo se escribe el sufijo después de «Ankara»?
+ Separado con apóstrofo :: Los nombres propios llevan apóstrofo antes del sufijo.
- Unido sin separación :: Esa regla se aplica a nombres comunes.
- Con guion :: No se usa guion.
Q ¿Cuál es la forma correcta para decir «en casa»?
+ evde :: El sufijo se une al nombre común.
- ev'de :: No se separa con apóstrofo.
- ev-de :: No se usa guion.
R İstanbul'dayım. :: Traduce la frase.
+ Estoy en Estambul. :: El sufijo expresa ubicación y persona.
- Voy a Estambul mañana. :: Esa idea aparece en otra frase.
- Estambul es una casa. :: Cambia el sentido.
H Ankara'___ gidiyorum. :: Completa «voy a Ankara».
+ ya :: La terminación direccional sigue al nombre propio con apóstrofo.
- da :: Significaría «en Ankara» y falta la forma completa.
- dan :: Significaría «desde Ankara».
A Ankara'da mısın? :: ¿Qué pregunta?
+ Si la persona está en Ankara. :: -da expresa ubicación.
- Si la persona viene de Ankara. :: Para procedencia se usa -dan.
- Si la persona vive en casa. :: No aparece ev.
O Ankara'ya gidiyorum :: Voy a Ankara. :: El destino lleva el sufijo direccional.
X Escribe «Estoy en Estambul.» :: İstanbul'dayım. :: El sufijo se escribe con apóstrofo.
