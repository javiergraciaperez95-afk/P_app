@ 5 | Menü okumak ve yemek seçmek | Leer el menú y elegir
I Encuentra comidas sencillas en un menú y elige una opción.
E Menú :: **Çorba** es sopa; **salata**, ensalada; **pilav**, arroz. :: Para pedir, coloca el alimento antes de **istiyorum**: **çorba istiyorum** = quiero sopa.
W çorba = sopa
W salata = ensalada
W pilav = arroz
V En el restaurante
T Bugünün menüsü
- Mercimek çorbası ve salata var. = Hay sopa de lentejas y ensalada.
- Tavuk ve pilav da var. = También hay pollo y arroz.
- Su bir lira. = El agua cuesta una lira.
w Mercimek çorbası ve salata var = hay sopa de lentejas y ensalada
w Tavuk ve pilav da var = también hay pollo y arroz
w Su bir lira = el agua cuesta una lira
D Lokantada
Mert: Ne istiyorsun? = ¿Qué quieres?
Ece: Çorba ve salata istiyorum. = Quiero sopa y ensalada.
Mert: Pilav da ister misin? = ¿También quieres arroz?
Ece: Hayır, teşekkürler. = No, gracias.
w Ne istiyorsun = ¿qué quieres?
w Çorba ve salata istiyorum = quiero sopa y ensalada
w Pilav da ister misin = ¿también quieres arroz?
w Hayır teşekkürler = no gracias
Q ¿Qué dos opciones hay en el menú?
+ Sopa y ensalada. :: Ambas aparecen en el menú.
- Pescado y patatas. :: No aparecen balık ni patates.
- Café y pastel. :: No aparecen kahve ni pasta.
Q ¿Qué pide Ece?
+ Sopa y ensalada. :: Dice çorba ve salata.
- Arroz y pollo. :: No elige esos platos.
- Una botella de agua. :: Su aparece en el menú, pero no lo pide.
R Çorba ve salata istiyorum. :: Traduce.
+ Quiero sopa y ensalada. :: Los alimentos van antes de istiyorum.
- ¿Quieres sopa o ensalada? :: Es una pregunta diferente.
- Hay sopa y ensalada. :: Var significa hay.
H Çorba ve salata ___. :: Completa «quiero sopa y ensalada».
+ istiyorum :: Significa quiero.
- var :: Significa hay.
- ister misin :: Significa ¿quieres?
A Tavuk ve pilav da var. :: ¿Qué hay además?
+ Pollo y arroz. :: Tavuk es pollo y pilav arroz.
- Sopa y ensalada. :: Es otra opción del menú.
- Agua y café. :: No aparece kahve.
O Çorba istiyorum :: Quiero sopa. :: La comida precede al verbo.
X Escribe «Quiero ensalada.» :: Salata istiyorum. :: Usa el nombre antes de istiyorum.

@ 5 | Sipariş vermek ve nazikçe istemek | Pedir con cortesía
I Haz un pedido completo y pide una cosa adicional de manera educada.
E Peticiones :: **Alabilir miyim?** significa «¿podría tomar/recibir?». :: **Bir çay alabilir miyim?** es una petición cortés; la partícula **mi** sigue separada.
V Pedir en una cafetería
D Kafede
Anna: Bir çay alabilir miyim? = ¿Me puede traer un té?
Ali: Elbette. Başka bir şey? = Claro. ¿Algo más?
Anna: Bir su, lütfen. = Un agua, por favor.
Ali: Hemen getiriyorum. = Lo traigo enseguida.
w Bir çay alabilir miyim = ¿me puede traer un té?
w Elbette başka bir şey = claro ¿algo más?
w Bir su lütfen = un agua por favor
w Hemen getiriyorum = lo traigo enseguida
Q ¿Qué pide Anna primero?
+ Un té. :: Çay significa té.
- Un café. :: Café es kahve.
- Una sopa. :: Sopa es çorba.
Q ¿Qué expresa **alabilir miyim?**?
+ Una petición cortés. :: La forma pregunta con educación si puede recibir algo.
- Una orden directa. :: No es un imperativo.
- Una despedida. :: Güle güle sirve para despedirse.
R Bir su, lütfen. :: Traduce.
+ Un agua, por favor. :: Su significa agua y lütfen por favor.
- Quiero té sin azúcar. :: No aparece şeker.
- ¿Cuánto cuesta el café? :: Ne kadar pregunta el precio.
H Bir çay alabilir ___? :: Completa la pregunta cortés.
+ miyim :: Mi se escribe separada y lleva la terminación de yo.
- misin :: Preguntaría a otra persona.
- miyiz :: Preguntaría por un grupo.
A Hemen getiriyorum. :: ¿Cuándo lo trae?
+ Enseguida. :: Hemen significa enseguida.
- Mañana. :: Yarın significa mañana.
- A las tres. :: Saat üçte significa a las tres.
O Bir su alabilir miyim :: ¿Me puede traer un agua? :: Es una petición cortés.
X Escribe «¿Me puede traer un té?» :: Bir çay alabilir miyim? :: Mantén mi separado.

@ 5 | Hesap ve ödeme | La cuenta y el pago
I Comprueba el total y pregunta cómo pagar antes de despedirte.
E Pagar :: **Hesap** significa cuenta; **fiş**, recibo. :: **Kartla ödeyebilir miyim?** pregunta si puedes pagar con tarjeta. **Nakit** significa efectivo.
V La cuenta
D Kasada
Elif: Hesabı alabilir miyim? = ¿Me trae la cuenta?
Baran: Tabii, hesap burada. = Claro, aquí está la cuenta.
Elif: Kartla ödeyebilir miyim? = ¿Puedo pagar con tarjeta?
Baran: Evet, kart geçiyor. = Sí, aceptamos tarjeta.
w Hesabı alabilir miyim = ¿me trae la cuenta?
w Tabii hesap burada = claro aquí está la cuenta
w Kartla ödeyebilir miyim = ¿puedo pagar con tarjeta?
w Evet kart geçiyor = sí aceptamos tarjeta
w Kart geçiyor = se puede pagar con tarjeta
Q ¿Qué solicita Elif?
+ La cuenta. :: Hesabı significa la cuenta.
- El menú. :: Menü es menú.
- Un recibo de hotel. :: No se habla de hotel.
Q ¿Qué significa «Kart geçiyor» en este diálogo?
+ Aceptan tarjeta. :: La tarjeta sirve para pagar.
- Solo aceptan efectivo. :: Nakit significa efectivo.
- No hay cuenta. :: Hesap aparece dos veces.
R Hesabı alabilir miyim? :: Traduce.
+ ¿Me trae la cuenta? :: Es una petición cortés.
- ¿Puedo pagar en efectivo? :: Esa pregunta sería Nakit ödeyebilir miyim?
- ¿Dónde está el recibo? :: No se pregunta por el recibo.
H Fiş alabilir ___? :: Completa «¿Me puede dar un recibo?».
+ miyim :: Es la terminación de yo en la petición.
- misin :: Pregunta si tú puedes hacerlo.
- mı :: Falta la terminación personal del modelo.
A Kartla ödeyebilir miyim? :: ¿Qué pregunta Elif?
+ Si puede pagar con tarjeta. :: Kartla indica el medio de pago.
- Si puede pedir un café. :: No aparece kahve.
- Si puede ir mañana. :: No aparece yarın.
O Kartla ödeyebilir miyim :: ¿Puedo pagar con tarjeta? :: Kartla significa con tarjeta.
X Escribe «la cuenta» en turco. :: hesap :: No confundas hesap con fiş.

@ 5 | Miktar ve kilo | Cantidad y peso
I Pide una cantidad en el mercado y confirma el precio antes de comprar.
E Cantidades :: **Bir kilo elma** = un kilo de manzanas; el sustantivo permanece singular después de la cantidad. :: **Yarım kilo** significa medio kilo y **kaç lira?** pregunta cuántas liras cuesta.
V En el mercado
T Pazarda
- Elmanın kilosu otuz lira. = El kilo de manzanas cuesta treinta liras.
- Domatesin kilosu yirmi lira. = El kilo de tomates cuesta veinte liras.
- Yarım kilo domates alıyorum. = Compro medio kilo de tomates.
w Elmanın kilosu otuz lira = el kilo de manzanas cuesta treinta liras
w Domatesin kilosu yirmi lira = el kilo de tomates cuesta veinte liras
w Yarım kilo domates alıyorum = compro medio kilo de tomates
D Pazarda
Satıcı: Ne kadar elma istiyorsunuz? = ¿Cuántas manzanas quiere?
Anna: Bir kilo, lütfen. = Un kilo, por favor.
Satıcı: Başka bir şey? = ¿Algo más?
Anna: Yarım kilo domates. = Medio kilo de tomates.
w Ne kadar elma istiyorsunuz = ¿cuántas manzanas quiere?
w Bir kilo lütfen = un kilo por favor
w Başka bir şey = ¿algo más?
w Yarım kilo domates = medio kilo de tomates
Q ¿Cuánto cuesta un kilo de tomates?
+ Veinte liras. :: El texto dice yirmi lira.
- Treinta liras. :: Ese es el precio de las manzanas.
- Diez liras. :: On significa diez.
Q Después de «bir kilo», ¿cómo aparece el producto?
+ En singular. :: Tras una cantidad no se añade plural.
- Siempre en plural. :: No se dice elma-lar tras kilo.
- Con sufijo de destino. :: No hay movimiento hacia el producto.
R Yarım kilo domates alıyorum. :: Traduce.
+ Compro medio kilo de tomates. :: Yarım kilo es medio kilo.
- Quiero un kilo de manzanas. :: Cambia el producto y la cantidad.
- Los tomates cuestan veinte liras. :: Es otro dato del texto.
H Bir kilo ___ istiyorum. :: Completa «quiero un kilo de manzanas».
+ elma :: El nombre va en singular tras kilo.
- elmalar :: No se añade plural tras la cantidad.
- yarım :: Significa medio.
A Domatesin kilosu yirmi lira. :: ¿Cuánto cuesta el kilo?
+ Veinte liras. :: Yirmi significa veinte.
- Treinta liras. :: Otuz es treinta.
- Medio kilo. :: Yarım kilo es medio kilo.
O Yarım kilo domates :: Medio kilo de tomates. :: El orden turco pone la cantidad antes del producto.
X Escribe «un kilo de manzanas». :: bir kilo elma :: El sustantivo se mantiene singular.

@ 5 | Ürün seçmek ve fiyat karşılaştırmak | Elegir y comparar productos
I Pregunta por el precio, compara dos productos y elige uno.
E Comparar precios :: **Daha ucuz** significa «más barato»; **daha pahalı**, «más caro». :: **Bu kaç lira?** pregunta cuánto cuesta el objeto que se señala.
V En una tienda
D Dükkânda
Mert: Bu çanta kaç lira? = ¿Cuántas liras cuesta este bolso?
Ece: Beş yüz lira. = Quinientas liras.
Mert: Şu çanta daha ucuz mu? = ¿Ese bolso es más barato?
Ece: Evet, ama bu daha güzel. = Sí, pero este es más bonito.
w Bu çanta kaç lira = ¿cuántas liras cuesta este bolso?
w Beş yüz lira = quinientas liras
w Şu çanta daha ucuz mu = ¿ese bolso es más barato?
w Evet ama bu daha güzel = sí pero este es más bonito
Q ¿Qué significa **daha ucuz**?
+ Más barato :: Daha expresa «más» y ucuz significa barato.
- Muy caro :: Pahalı significa caro.
- El precio más bajo :: No se usa un superlativo.
Q ¿Cuánto cuesta el primer bolso?
+ Quinientas liras. :: Mert recibe esa respuesta.
- Cien liras. :: Yüz significa cien.
- Cincuenta liras. :: Elli significa cincuenta.
R Şu çanta daha ucuz mu? :: Traduce.
+ ¿Ese bolso es más barato? :: Şu señala ese objeto y daha compara.
- ¿Este bolso es muy caro? :: No aparece pahalı.
- ¿Cuánto cuesta el bolso? :: Es una pregunta diferente.
H Bu çanta daha ___. :: Completa «este bolso es más bonito».
+ güzel :: Güzel significa bonito/a.
- pahalı :: Significa caro/a.
- ucuz :: Significa barato/a.
A Evet, ama bu daha güzel. :: ¿Qué prefiere Ece?
+ El bolso que señala con bu. :: Dice que este es más bonito.
- El bolso más barato. :: No afirma esa preferencia.
- Ningún bolso. :: Acepta una de las opciones.
O Bu daha güzel :: Este es más bonito. :: El adjetivo no cambia por género.
X Escribe «más barato». :: daha ucuz :: Daha precede al adjetivo.
