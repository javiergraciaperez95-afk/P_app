N Anna, Ali, Ece, Mert, Elif, Baran, Deniz
@ 2 | İsim cümlelerinde kişi | La persona en frases nominales
I Aprende cómo los nombres y adjetivos expresan quién eres o cómo estás.
E Terminaciones personales :: **Ben öğretmenim** = soy profesor/a; **sen öğrencisin** = eres estudiante; **biz yorgunuz** = estamos cansados. :: En turco, el pronombre puede omitirse si la terminación ya muestra la persona.
V Personas y estados
w Biz yorgunuz = estamos cansados
D İki arkadaş
Anna: Ben öğrenciyim. = Soy estudiante.
Ali: Ben de öğrenciyim. = Yo también soy estudiante.
Anna: Ece öğretmen mi? = ¿Ece es profesora?
Ali: Hayır, Ece doktor. = No, Ece es médica.
w Ben öğrenciyim = soy estudiante
w Ben de öğrenciyim = yo también soy estudiante
w Ece öğretmen mi = ¿Ece es profesora?
w Hayır Ece doktor = no Ece es médica
Q ¿Qué indica la terminación en «öğrenciyim»?
+ Primera persona singular :: La forma significa «soy estudiante».
- Segunda persona plural :: Esa persona sería siz.
- Tercera persona :: No es una forma de o.
Q ¿Qué pregunta Anna?
+ Si Ece es profesora. :: Öğretmen mi formula una pregunta nominal.
- Si Ece está cansada. :: No aparece yorgun.
- Si Ece es estudiante. :: No aparece öğrenci.
R Ben de öğrenciyim. :: Traduce.
+ Yo también soy estudiante. :: De expresa «también» en esta frase.
- No soy profesor. :: Cambia el significado.
- ¿Eres estudiante? :: No es una pregunta.
H Ben ___. :: Completa «soy estudiante».
+ öğrenciyim :: La terminación -yim expresa «yo soy».
- öğrencisin :: Es la forma de «tú».
- öğrenciler :: Es plural.
A Ben öğrenciyim. :: ¿Quién habla de sí mismo?
+ Un estudiante. :: La terminación muestra «yo».
- Varios profesores. :: No aparece öğretmenler.
- Una médica. :: Doktor aparece en otra respuesta.
O Biz yorgunuz :: Estamos cansados. :: La terminación marca la primera persona plural.
X Escribe «Soy profesor/a.» :: Öğretmenim :: La terminación se une al nombre.

@ 2 | Olumsuz isim cümleleri | Frases nominales negativas
I Niega una profesión, una identidad o una descripción con **değil**.
E Negar con değil :: Coloca **değil** después del nombre o adjetivo: **öğrenci değilim** = no soy estudiante. :: La terminación personal se añade a **değil**: **hasta değilsin** = no estás enfermo/a.
W hasta = enfermo/a
V Descripciones afirmativas y negativas
w değilim = no soy, no estoy
D İki arkadaş
Mert: Bugün yorgun musun? = ¿Estás cansado hoy?
Ece: Hayır, yorgun değilim. = No, no estoy cansada.
Mert: Hasta mısın? = ¿Estás enferma?
Ece: Hayır, mutluyum. = No, estoy feliz.
w Bugün yorgun musun = ¿estás cansado hoy?
w Hayır yorgun değilim = no no estoy cansado
w Hasta mısın = ¿estás enfermo?
w Hayır mutluyum = no estoy feliz
Q ¿Qué significa «öğrenci değilim»?
+ No soy estudiante. :: Değil niega la frase nominal y -im marca «yo».
- Soy estudiante. :: La frase contiene una negación.
- No estás enfermo. :: Esa frase sería hasta değilsin.
Q ¿Qué palabra introduce la negación?
+ değil :: Se coloca después del nombre o adjetivo.
- bugün :: Bugün significa hoy.
- hayır :: Hayır significa no como respuesta.
R Hayır, yorgun değilim. :: Traduce.
+ No, no estoy cansado/a. :: La frase niega el estado.
- Sí, estoy cansado/a. :: Expresa lo contrario.
- No estoy en casa. :: No se menciona ev.
H Öğrenci ___. :: Completa «no soy estudiante».
+ değilim :: La terminación -im concuerda con «yo».
- değilsin :: Corresponde a «tú».
- değil :: Falta la terminación personal del modelo.
A Hasta mısın? :: ¿Qué quiere saber?
+ Si la otra persona está enferma. :: Hasta significa enfermo/a.
- Si está en el hospital. :: Hastane es hospital.
- Si está feliz. :: Mutlu significa feliz.
O Mutlu değilim :: No estoy feliz. :: Değil niega el adjetivo.
X Escribe «No soy estudiante.» :: Öğrenci değilim :: Añade la terminación de primera persona.

@ 2 | Mi/mı/mu/mü ile soru | Preguntar con mi/mı/mu/mü
I Forma preguntas de sí o no y separa correctamente la partícula interrogativa.
E Partícula interrogativa :: La partícula **mi/mı/mu/mü** se escribe separada y sigue la armonía vocálica: **öğrenci misin?**, **hasta mısın?** :: La terminación personal se une a la partícula: **miyim, misin, mu?**
W soru = pregunta
V Preguntas breves
w hazırım = listo/a
D İki arkadaş
Ali: Hazır mısın? = ¿Estás listo?
Anna: Evet, hazırım. = Sí, estoy lista.
Ali: Öğrenci misin? = ¿Eres estudiante?
Anna: Evet, öğrenciyim. = Sí, soy estudiante.
w Hazır mısın = ¿estás listo?
w Evet hazırım = sí estoy listo
w Öğrenci misin = ¿eres estudiante?
w Evet öğrenciyim = sí soy estudiante
Q ¿Cuál es la escritura correcta?
+ Öğrenci misin? :: La partícula va separada.
- Öğrencimisin? :: No se escribe unida.
- Öğrenci-mi-sin? :: No lleva guiones.
Q ¿Qué significa «Hazır mısın?»?
+ ¿Estás listo/a? :: Hazır significa listo/a.
- ¿Eres estudiante? :: Esa pregunta es Öğrenci misin?
- ¿Tienes una pregunta? :: Soru significa pregunta.
R Evet, öğrenciyim. :: Traduce.
+ Sí, soy estudiante. :: Evet afirma y -yim marca primera persona.
- No, no estoy listo. :: Cambia la respuesta.
- ¿Eres estudiante? :: Es una pregunta, no una respuesta.
H Öğrenci ___? :: Completa «¿eres estudiante?».
+ misin :: Mi se escribe separado y recibe -sin.
- değilim :: Es una forma negativa de «yo».
- muyum :: No concuerda con öğrenci.
A Hazır mısın? :: ¿Qué pregunta la persona?
+ Si la otra persona está lista. :: Hazır significa listo/a.
- Si ya salió. :: Çıktı es salió.
- Si quiere estudiar. :: No aparece estudiar.
O Öğrenci misin :: ¿Eres estudiante? :: La partícula interrogativa queda separada.
X Escribe «¿Estás listo/a?» :: Hazır mısın? :: La partícula se escribe aparte.

@ 2 | Çoğul ve miktar | Plural y cantidad
I Usa **-lar/-ler** para hablar de varios objetos y mantén el nombre en singular después de un número.
E El plural :: Añade **-lar/-ler** según la última vocal: **kitaplar**, **evler**. :: Después de un número, el nombre permanece singular: **iki kitap**, **üç ev**.
V Objetos y cantidades
D Evde
Deniz: Evde kaç sandalye var? = ¿Cuántas sillas hay en casa?
Baran: Üç sandalye var. = Hay tres sillas.
Deniz: Kitaplar nerede? = ¿Dónde están los libros?
Baran: Evde, masada. = En casa, sobre la mesa.
w Evde kaç sandalye var = ¿cuántas sillas hay en casa?
w Üç sandalye var = hay tres sillas
w Kitaplar nerede = ¿dónde están los libros?
w Evde masada = en casa sobre la mesa
Q ¿Qué forma significa «libros»?
+ kitaplar :: -lar marca el plural tras la vocal a.
- kitap :: Es singular.
- kitapler :: No sigue la armonía vocálica.
Q ¿Cómo se dice «tres casas»?
+ üç ev :: Tras un número, ev no lleva plural.
- üç evler :: El nombre suele quedarse en singular tras el número.
- üç evin :: Esa forma significa «de tres casas» en otro contexto.
R Üç sandalye var. :: Traduce.
+ Hay tres sillas. :: Var indica que existen.
- No hay sillas. :: Yok sería «no hay».
- ¿Dónde están las sillas? :: Es una pregunta diferente.
H İki ___ var. :: Completa «hay dos libros».
+ kitap :: Tras iki, el nombre está en singular.
- kitaplar :: No se añade plural tras el número.
- evler :: Cambia el objeto.
A Kitaplar nerede? :: ¿Qué pregunta?
+ Dónde están los libros. :: Nerede significa dónde.
- Cuántos libros hay. :: Kaç kitap pregunta cuántos.
- Si hay una mesa. :: No se pregunta por masa.
O İki kitap var :: Hay dos libros. :: El sustantivo queda en singular después del número.
X Escribe «tres casas». :: üç ev :: No añadas el sufijo plural.
