@ 38 | I had already left | Pasado perfecto: lo que ya había pasado
I En el pasado hay algo que pasó antes de otra cosa del pasado. Para marcar ese orden, se usa **had** + participio.
E Had + participio :: **When we arrived, the film had already started** (cuando llegamos, la película ya había empezado). El **had** muestra la acción más antigua; el pasado simple, la más reciente. :: Con **by the time** (para cuando) se usa el mismo truco: **By the time we got in, the film had finished**.
E Had y pasado simple juntos :: **After she left, he called her** (después de que se fuera, él la llamó): aquí el orden lo marcan **after** y **before**. Con **after**, puedes usar pasado simple para las dos cosas. Con **before**, el pasado perfecto es lo más claro: **He had left before we came**.
W by the time = para cuando | bai the taim
W ahead = delante; por delante | a-JÉD
W reach = llegar a; alcanzar | rich
W reached = llegó a; alcanzó | richt
W rehearse = ensayar | ri-JÉRS
W rehearsal = ensayo | ri-JÉR-sal
W spotted = vio; detectó | SPÓ-tid
W dropped = dejó caer; bajó | DRÓPT
W performance = actuación; representación | per-FÓR-mans
W audience = público; audiencia | Ó-dien-s
W applause = aplausos | a-PLÓ-s
W encore = bis | ÁN-kor
V Vocabulario: teatro
D Una noche de teatro
Anna: When we arrived, the performance had already started. = Cuando llegamos, la actuación ya había empezado.
  > had already started = ya había empezado
Tom: We had reached the cinema late, because of the queue. = Habíamos llegado tarde al cine por la cola.
  > had reached = habíamos llegado
Anna: By the time we got in, the film had finished. = Para cuando entramos, la película ya había terminado.
  > By the time = para cuando
Tom: Did you rehearse before? = ¿Ensayaste antes?
  > rehearse = ensayar
Anna: Yes, the rehearsal had gone well. = Sí, el ensayo había salido bien.
  > had gone well = había salido bien
Tom: The audience had left early. = El público se había ido pronto.
  > had left = se había ido
Anna: The teacher spotted me. = La profesora me vio.
  > spotted = vio; detectó
Tom: The applause was big, and there was an encore! = ¡El aplauso fue grande, y hubo bis!
  > encore = bis
Q ¿Qué significa «I had already left when you called»?
+ Ya me había ido cuando llamaste. :: Past perfect: algo anterior a otra cosa del pasado.
- Ya me voy cuando llamas. :: Eso sería presente.
- Me fui cuando llamaste. :: Eso sería pasado simple, no anterior.
Q ¿Cuál es correcta para «para cuando llegamos, ya había empezado»?
+ By the time we arrived, it had started. :: By the time + pasado simple + had + participio.
- By the time we arrived, it started. :: Sin had no se marca lo anterior.
- By the time we arrive, it had started. :: Arrived va en pasado.
R The teacher had already gone.
+ La profesora ya se había ido. :: Had gone = se había ido (antes).
- La profesora ya se va. :: Eso sería presente.
- La profesora se fue. :: Eso sería pasado simple.
H The film ___ already started when we arrived. :: Ya había
+ had :: Had + participio: lo que pasó antes.
- has :: Presente perfecto, no pasado.
- have :: Presente perfecto, no pasado.
H By the ___ we got there, the film had finished. :: Para cuando
+ time :: By the time = para cuando.
- later :: No forma by the time.
- end :: No forma by the time.
A I had reached the cinema late.
+ Había llegado tarde al cine. :: Had reached = había llegado.
- Llegué tarde al cine. :: Eso sería pasado simple.
- Llego tarde al cine. :: Eso sería presente.
O The applause had already started :: El aplauso ya había empezado :: Had + participio: anterior.
X ¿Cómo se dice «bis» (repetición al final de un espectáculo) en inglés? :: encore :: Ojo: encore también es una palabra francesa usada en inglés.

@ 38 | I've been waiting since six | Presente y pasado perfecto continuo: llevar haciendo
I Para decir cuánto tiempo llevas haciendo algo, usas **have been** + -ing. Si el punto de referencia es el pasado, usas **had been** + -ing.
E Presente perfecto continuo :: **I've been waiting since six** (llevo esperando desde las seis). Lo que empezó antes y sigue hasta hoy. :: Con **for**: **I've been waiting for an hour** (llevo una hora esperando).
E Pasado perfecto continuo :: **The plumber had been waiting for an hour** (el fontanero llevaba una hora esperando). Es la duración hasta un momento del pasado. :: Diferencia: **has been** = hasta ahora; **had been** = hasta antes de otra cosa del pasado.

@ 38 | The novel is ready | Texto de teatro y falsos amigos

E Teatro :: **Cast** = reparto. **Scene** = escena. **Costume** = vestuario. **Script** = guion. **Premiere** = estreno. **Review** = crítica. **Box office** = taquilla. **Award** = premio.
