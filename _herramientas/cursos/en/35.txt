@ 35 | It is said that the bridge is old | Pasiva con verbos de opinión
I En B2 se habla de creencias, rumores y estimaciones sin decir quién lo afirma. Para eso sirve la pasiva con verbos como **say**, **believe** y **think**.
E It is said that… :: **It is said / believed / thought / rumoured that…** (se dice / se cree / se piensa / se rumorea que…): **It is believed that a teacher built it** (se cree que lo construyó un profesor). Es impersonal: no dices quién lo cree.
E Subject + is said to be :: **The bridge is said to be old** (se dice que el puente es antiguo). Aquí el sujeto de la frase es el que habla: el puente. Se usa con infinitivo: **to be** o **to have**. :: Con **thought** también: **It is thought to be safe** (se cree que es seguro).
W believed = creído; se cree | bi-LÍVD
W thought = pensado; creído | zot
W century = siglo | SÉN-chu-ri
W legend = leyenda | LÉ-yend
W estimate = calcular; estimación | ES-ti-meit
W claim = afirmar; afirmación | kleim
W rumoured = rumoreado; se rumorea | RÚ-mord
W discover = descubrir | dis-KÁ-ver
W experts = expertos | EKS-perts
W archaeologists = arqueólogos | ar-kio-LÓ-yists
W site = yacimiento; emplazamiento | sait
W date = fecha; datar | deit
V Vocabulario: opiniones impersonales
D Un puente con historia
Anna: This bridge is said to be old. = Se dice que este puente es antiguo.
  > is said to be = se dice que es
Tom: It is believed that a teacher built it. = Se cree que un profesor lo construyó.
  > It is believed that = se cree que
Anna: It is rumoured that the bridge is closed. = Se rumorea que el puente está cerrado.
  > It is rumoured that = se rumorea que
Tom: The experts claim that it is a century older. = Los expertos afirman que es un siglo más antiguo.
  > claim that = afirman que | century = siglo
Anna: The archaeologists will discover the date soon. = Los arqueólogos descubrirán la fecha pronto.
  > discover = descubrir
Tom: The site is closed, so we can't visit it. = El yacimiento está cerrado, así que no podemos visitarlo.
  > site = yacimiento (no solo «sitio»)
Anna: Their estimate is big. = Su estimación es alta.
  > estimate = estimación
Tom: It is thought to be safe. = Se cree que es seguro.
  > is thought to be = se cree que es
Q ¿Qué significa «It is said that the bridge is old»?
+ Se dice que el puente es antiguo. :: Forma impersonal de opinión.
- El puente dice que es antiguo. :: Eso es activa, no pasiva.
- Dicen que el puente es nuevo. :: Eso cambia el sentido.
Q ¿Qué forma va en «The bridge ___ thought to be old»?
+ is :: Pasiva en presente: is thought to be.
- think :: Falta la forma pasiva.
- thinking :: No va en esta forma.
R It is believed that a teacher built it.
+ Se cree que un profesor lo construyó. :: It is believed that = se cree que.
- Un profesor cree que lo construyó. :: Eso sería activa.
- Un profesor lo construirá. :: Eso sería futuro.
H The site is ___, so we can't visit it. :: Cerrado
+ closed :: Cerrado.
- visit :: Es visitar.
- closes :: Eso es presente activo.
H The experts ___ that it is old. :: Afirman
+ claim :: Plural: claim.
- claims :: Con experts va la forma sin -s.
- claiming :: No va aquí.
A It is rumoured that the bridge is closed.
+ Se rumorea que el puente está cerrado. :: Rumoured that = se rumorea que.
- Se rumorea que el puente está abierto. :: Eso es lo contrario.
- El puente rumorea que está cerrado. :: No es pasiva.
O It is thought to be safe :: Se cree que es seguro :: Thought to be = se cree que es.
X ¿Cómo se dice «se cree que» (impersonal) en inglés? :: It is believed that :: También vale It is thought that.

@ 35 | It is being built | Pasiva en continuo, perfecto y con modales
I Ahora la pasiva con más tiempos: está siendo, ha sido, debería haber sido.
E Presente continuo pasivo :: **am / is / are being** + participio: **The house is being renovated** (la casa se está reformando). Se usa para algo que está pasando ahora mismo. :: Con **is being**, el tiempo está en curso; con **is**, es un hecho general.
E Perfecto pasivo :: **has / have been** + participio: **The house has been renovated since 2010** (la casa ha sido reformada desde 2010). Es lo que se ha hecho hasta hoy.
E Modal perfecto pasivo :: **should have been** + participio: **It should have been done yesterday** (debería haberse hecho ayer). Se usa para lo que no pasó como debía.
W being = siendo; estando | BÍ-ing
W renovated = reformado; renovado | RE-no-veitid
W scaffolding = andamio | SKÁ-fol-ding
W fence = valla; cerca | fens
W permit = permiso; permitir | PÉR-mit
W paint = pintura; pintar | peint
W construction = construcción; obra | kon-STRÁK-shon
W council = ayuntamiento; consejo municipal | KÁU-nsil | Falso amigo: no es «consejo» (advice).
W inspected = inspeccionado; inspeccionada | in-SPÉK-ted
W brick = ladrillo | brik
W gravel = grava | GRÁ-vel
W cement = cemento | se-MÉNT
V Vocabulario: obras
D Obras en la casa
Lucy: The house is being renovated. = La casa se está reformando.
  > is being renovated = se está reformando
Pedro: There is scaffolding and a fence outside. = Hay andamios y una valla fuera.
  > scaffolding = andamio
Lucy: The council approved the permit. = El ayuntamiento aprobó el permiso.
  > council = ayuntamiento (no «consejo»)
Pedro: The paint has been bought. = La pintura ha sido comprada.
  > has been bought = ha sido comprada
Lucy: The gravel should have been delivered on Monday. = La grava debería haberse entregado el lunes.
  > should have been delivered = debería haberse entregado
Pedro: The construction was inspected yesterday. = La obra fue inspeccionada ayer.
  > was inspected = fue inspeccionada
Lucy: Is the house being cleaned? = ¿Se está limpiando la casa?
  > being cleaned = se está limpiando
Pedro: Not yet, but it will be finished soon. = Todavía no, pero pronto estará terminada.
  > will be finished = estará terminada
Q ¿Qué significa «The house is being renovated»?
+ La casa se está reformando. :: Presente continuo pasivo: ahora mismo.
- La casa se reformó. :: Eso sería pasado.
- La casa se reformará. :: Eso sería futuro.
Q ¿Cuál es la forma correcta de «ha sido construida»?
+ has been built :: Perfecto pasivo: has been + participio.
- has built :: Eso es activa.
- is built :: Eso es presente pasivo.
R It should have been done yesterday.
+ Debería haberse hecho ayer. :: Should have been + participio.
- Debe hacerse ayer. :: Eso sería must.
- Lo hicieron ayer. :: Eso sería activa.
H The construction ___ inspected yesterday. :: Fue
+ was :: Pasado: fue inspeccionada.
- is :: Eso es presente, no pasado.
- be :: Eso no va aquí.
H The council ___ the permit yesterday. :: Aprobó
+ approved :: Pasado de approve.
- approve :: Es la forma base.
- approves :: Es presente.
A The fence is still there.
+ La valla sigue ahí. :: Still = todavía, sigue.
- La valla se ha ido. :: Eso no es still.
- La valla está nueva. :: Eso no es still.
O The gravel should have been delivered :: La grava debería haberse entregado :: Should have been = debería haber sido.
X ¿Cómo se dice «ayuntamiento» en inglés? :: council :: Ojo: council no es «consejo» (advice).
