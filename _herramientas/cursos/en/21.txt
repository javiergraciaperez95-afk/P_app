@ 21 | The house was built in 1900 | La voz pasiva: se hace, se construyó
I Hasta ahora casi siempre hablabas de quien hace la acción. Hoy hablamos de lo que se hace o se hizo, sin decir quién.
E La pasiva en presente :: **am / is / are** + participio: **The windows are cleaned every week** (las ventanas se limpian cada semana). **The door is closed at night** (la puerta se cierra de noche). :: En español solemos decir «se» + verbo. En inglés es **be** + participio.
E La pasiva en pasado :: **was / were** + participio: **This house was built in 1900** (esta casa se construyó en 1900). **The bridge was rebuilt in 1950** (el puente se reconstruyó en 1950). :: **Was** para singular, **were** para plural.
E El participio :: Los regulares terminan en **-ed**: **cleaned**, **closed**, **painted**. Los irregulares hay que aprenderlos: **made**, **built**, **written**, **spoken**. :: Quién hace la acción se dice con **by**: **built by my father** (construida por mi padre).
W by = por (agente) | bai
W built = construido; construida | bilt | Participio de «build» (construir).
W cleaned = limpiado; limpiada | klind
W painted = pintado; pintada | PEIN-ted
W opened = abierto; abierta | O-pend
W delivered = entregado; entregada | di-LÍ-verd
W invented = inventado; inventada | in-VÉN-ted
W discovered = descubierto; descubierta | dis-KÁ-verd
W translated = traducido; traducida | trans-LÉI-ted
W fixed = arreglado; reparado | fikst
W spoken = hablado | SPÓU-ken | Participio de «speak».
V Vocabulario: pasiva
D Una casa con historia
Tom: This house was built in 1900. = Esta casa se construyó en 1900.
  > was built = se construyó
Anna: Really? Was it painted recently? = ¿De verdad? ¿Se pintó hace poco?
  > Was it painted = ¿se pintó?
Tom: Yes, it was painted last year. = Sí, se pintó el año pasado.
  > was painted = se pintó
Anna: The windows are cleaned every week. = Las ventanas se limpian cada semana.
  > are cleaned = se limpian
Tom: The garden is opened in summer. = El jardín se abre en verano.
  > is opened = se abre
Anna: The door is closed at night. = La puerta se cierra de noche.
  > is closed = se cierra
Tom: Who was the house built by? = ¿Quién construyó la casa?
  > built by = construida por
Anna: It was built by my father. = La construyó mi padre.
  > was built by = fue construida por
Q ¿Qué forma va en «The house ___ built in 1900»?
+ was :: Pasado pasivo con singular: was.
- were :: Con plural.
- is :: Es presente.
Q ¿Cuál es la forma pasiva correcta de «They built the bridge»?
+ The bridge was built. :: Was + participio.
- The bridge built. :: Falta el auxiliar was.
- The bridge was build. :: El participio es built.
R The windows are cleaned every week.
+ Las ventanas se limpian cada semana. :: Are cleaned = se limpian.
- Las ventanas limpian cada semana. :: Eso sería voz activa.
- Las ventanas se limpiaron ayer. :: Eso sería pasado con fecha.
H English is ___ here. :: Se habla
+ spoken :: Participio de «speak».
- speak :: Es la forma base.
- speaks :: Eso sería activa.
H The house was ___ by my father. :: Construida
+ built :: Participio de «build».
- build :: Es la forma base.
- builds :: Eso sería presente activo.
A The windows are cleaned every week.
+ Las ventanas se limpian cada semana. :: Are cleaned = se limpian.
- Las ventanas limpian cada semana. :: Eso sería activa.
- Las ventanas se limpiaron la semana pasada. :: Eso sería pasado con fecha.
O This house was built in 1900 :: Esta casa se construyó en 1900 :: Was built = pasiva en pasado.
X ¿Cómo se dice «se pintó» (en pasado) en inglés? :: was painted :: Was / were + participio.

@ 21 | You needn't come | Need, needn't y have got to
I Tres formas para hablar de obligación y de necesidad: tener que, no hace falta y necesitar.
E Have got to: tener que :: **Have got to** = tener que, obligación fuerte: **You have got to sign this** (tienes que firmar esto). Es casi igual que **have to**. :: Con **he**, **she** o **it** es **has got to**.
E Need y needn't :: **Need** = necesitar: **Do I need a visa?** (¿necesito un visado?). **Needn't** = no hace falta: **You needn't come** (no hace falta que vengas). :: **Needn't** no es lo mismo que **mustn't** (está prohibido). Aquí solo se dice que no hay necesidad.
E Falsos amigos: fee y tax :: **Fee** = tasa, cuota (lo que pagas por un servicio). **Tax** = impuesto. No son la misma cosa.
W needn't = no hace falta | NÍ-dent
W necessary = necesario; necesaria | NÉ-se-se-ri
W unnecessary = innecesario; innecesaria | an-NÉ-se-se-ri
W queue = cola; fila | kiú
W form = formulario; impreso | form
W visa = visado | VÍ-sa
W fee = tasa; cuota | fi | Falso amigo de «tax»: no es impuesto.
W tax = impuesto | taks
W deadline = plazo límite; fecha límite | DÉD-lain
W sign = firmar; señal | sain
W signature = firma | SÍG-na-chur
V Vocabulario: trámites
D En la oficina de visados
Anna: You have got to sign this form. = Tienes que firmar este formulario.
  > have got to sign = tienes que firmar
Pedro: Do I need a visa? = ¿Necesito un visado?
  > need = necesitar
Anna: No, you needn't have one for this trip. = No, no hace falta que tengas uno para este viaje.
  > needn't have = no hace falta tener
Pedro: And the fee? = ¿Y la tasa?
  > fee = tasa
Anna: It's not necessary to pay the fee. = No es necesario pagar la tasa.
  > not necessary = no es necesario
Pedro: There is a queue. = Hay una cola.
  > queue = cola
Anna: We have got to wait. = Tenemos que esperar.
  > have got to wait = tenemos que esperar
Pedro: The deadline is today! = ¡El plazo acaba hoy!
  > deadline = plazo límite
Q ¿Qué significa «You needn't come»?
+ No hace falta que vengas. :: Needn't = no hace falta.
- No debes venir. :: Eso sería «mustn't», prohibido.
- No puedes venir. :: Eso sería «can't».
Q ¿Qué significa «have got to»?
+ tener que :: Obligación fuerte.
- poder :: Eso sería «can».
- deber (consejo) :: Eso sería «should».
R You have got to sign it.
+ Tienes que firmarlo. :: Have got to = tener que.
- Puedes firmarlo. :: Eso sería «can».
- Firmarás. :: Eso sería futuro.
H We ___ a visa. :: No hace falta tener
+ needn't have :: No hace falta.
- mustn't have :: Eso es prohibición.
- can't have :: Eso es imposibilidad.
H The form is ___. :: Necesario
+ necessary :: Necesario.
- unnecessary :: Eso es innecesario.
- necessity :: Es el sustantivo: necesidad.
A The queue is long.
+ La cola es larga. :: Queue = cola.
- La cuerda es larga. :: Eso es «rope».
- La cuenta es larga. :: Eso es «bill».
O You don't have to wait :: No tienes que esperar :: Don't have to = no hace falta.
X ¿Cómo se dice «tasa, cuota» en inglés? :: fee :: Ojo: tax es impuesto.

@ 21 | The old town | Textos sobre lugares antiguos y falsos amigos
I Un texto sobre una ciudad antigua. Hay tres falsos amigos muy traicioneros: léelos con calma.
E Falsos amigos :: **Ancient** = antiguo, de hace siglos (no «anciano», que es **elderly**). **Support** = apoyar, ayudar (no «soportar», que es **bear** o **stand**). **Location** = ubicación, lugar (no «locución», que es **phrase**).
E Pasiva en textos :: En textos de historia se usa mucho la pasiva: **was built**, **was restored**, **was rebuilt**. Cuando sabes quién hizo algo, usa **by**.
W ancient = antiguo; muy antiguo | ÉN-shent
W support = apoyar; ayudar | sa-PÓRT
W location = ubicación; lugar | lou-KÉI-shon
W town = pueblo; ciudad | taun
W stone = piedra | stoun
W statue = estatua | STÁ-chu
W temple = templo | TÉM-pel
W restored = restaurado; restaurada | ris-TÓRD
W rebuilt = reconstruido; reconstruida | ri-BÍLT
W preserved = conservado; conservada | pri-ZÉRVD
W visitor = visitante | VÍ-si-ter
W gate = puerta (de una muralla) | geit
V Vocabulario: lugares antiguos
T La ciudad vieja
- This old town was built a long time ago. = Esta ciudad vieja se construyó hace mucho tiempo.
  > was built = se construyó | a long time ago = hace mucho tiempo
- The wall is made of stone. = La muralla está hecha de piedra.
  > is made of stone = está hecha de piedra
- The ancient temple was restored in 2010. = El antiguo templo se restauró en 2010.
  > ancient = antiguo (no «anciano») | was restored = se restauró
- It is not allowed here. = Aquí no está permitido.
  > is not allowed = no está permitido
- The statue was visited by my friends. = La estatua fue visitada por mis amigos.
  > was visited = fue visitada
- Our guide is very nice. = Nuestro guía es muy simpático.
  > guide = guía
- The bridge was rebuilt in 1950. = El puente se reconstruyó en 1950.
  > was rebuilt = se reconstruyó
- The location of the castle is near the sea. = La ubicación del castillo está cerca del mar.
  > location = ubicación (no «locución»)
Q ¿Qué significa «ancient»?
+ antiguo :: Falso amigo: no es «anciano», que es «elderly».
- anciano :: Eso es «elderly».
- moderno :: Lo contrario es «modern».
Q ¿Qué significa «support» en un proyecto?
+ apoyar :: Falso amigo: «soportar» es «bear».
- soportar (aguantar) :: Eso es «bear».
- quitar :: Eso es «remove».
R The wall is made of stone.
+ La pared está hecha de piedra. :: Is made of = está hecha de.
- La pared es de madera. :: Eso sería «wood».
- La pared está pintada. :: Eso sería «painted».
H The statue was ___ by my friends. :: Visitada
+ visited :: Pasiva: was + participio.
- visit :: Es la forma base.
- visiting :: Es la forma -ing.
H The bridge was ___ in 1950. :: Reconstruido
+ rebuilt :: Participio de «rebuild».
- build :: Es la forma base.
- builds :: Eso sería presente activo.
A The location is near the sea.
+ La ubicación está cerca del mar. :: Location = ubicación.
- La locución está cerca del mar. :: Eso sería «phrase».
- La ubicación está lejos del mar. :: Eso es lo contrario.
O The old town was built a long time ago :: La ciudad vieja se construyó hace mucho tiempo :: Was built = pasiva en pasado.
X ¿Cómo se dice «antiguo» (de hace siglos) en inglés? :: ancient :: Ojo: anciano es elderly.
