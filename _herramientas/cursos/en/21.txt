@ 21 | The house was built in 1900 | La voz pasiva: se hace, se construyó
I La pasiva centra la frase en la persona o cosa que recibe la acción. A veces no decimos quién la hace; si importa, podemos añadirlo con **by**.
E La pasiva en presente :: **am / is / are + participio**: **The windows are cleaned every week** (las ventanas se limpian cada semana). La forma de **be** concuerda con el sujeto: **is** con singular, **are** con plural.
E La pasiva en pasado :: **was / were + participio**: **This house was built in 1900** (esta casa se construyó en 1900); **The bridge was opened in 1950** (el puente se abrió en 1950). Usa **was** con singular y **were** con plural.
E El participio y by :: Los participios regulares suelen terminar en **-ed**: **cleaned**, **closed**, **painted**. Algunos son irregulares: **build → built**, **speak → spoken**. Para nombrar quién realiza la acción, añade **by**: **built by my family** (construida por mi familia).
W by = por (agente) | bai
W built = construido; construida | bilt | Participio de **build** (construir).
W cleaned = limpiado; limpiada | klind
W closed = cerrado; cerrada | klóuzd
W painted = pintado; pintada | péin-tid
W opened = abierto; abierta | óu-pend
W locked = cerrado con llave | lokt
W spoken = hablado | spóu-ken | Participio de **speak**.
V Vocabulario: pasiva
D Una casa con historia
Tom: This house was built in 1900. = Esta casa se construyó en 1900.
  > was built = se construyó
Anna: Really? Was it painted recently? = ¿De verdad? ¿Se pintó hace poco?
  > Was it painted = ¿se pintó?
Tom: Yes, it was painted last year. = Sí, se pintó el año pasado.
  > was painted = se pintó
Anna: The windows are cleaned every week. = Las ventanas se limpian cada semana.
  > are cleaned = se limpian
Tom: The garden is opened to visitors every summer. = El jardín se abre al público cada verano.
  > is opened to visitors = se abre al público
Anna: Is the door locked at night? = ¿Se cierra la puerta con llave por la noche?
  > is locked = se cierra con llave
Tom: Yes, it is locked by my family. = Sí, mi familia la cierra con llave.
  > locked by my family = cerrada con llave por mi familia
Anna: Who was it built by? = ¿Quién la construyó?
  > built by = construida por
Tom: It was built by my family. = La construyó mi familia.
  > was built by my family = construida por mi familia
Q ¿Qué forma va en **The house ___ built in 1900**?
+ was :: Pasado pasivo con sujeto singular.
- were :: Se usa con sujeto plural.
- is :: Es presente, pero la acción ocurrió en 1900.
Q ¿Cuál es la forma pasiva correcta de **They built the bridge**?
+ The bridge was built. :: **Was + participio**; el agente puede omitirse.
- The bridge built. :: Falta **was**.
- The bridge was build. :: El participio es **built**.
R The windows are cleaned every week.
+ Las ventanas se limpian cada semana. :: **Are cleaned** = se limpian; presente pasivo plural.
- Las ventanas limpian cada semana. :: Eso sería activa y falta el objeto.
- Las ventanas se limpiaron ayer. :: Eso sería pasado.
H English is ___ here. :: Se habla
+ spoken :: Participio irregular de **speak**.
- speak :: Es la forma base.
- speaks :: Esa es una forma activa.
H The house was ___ by my family. :: Construida
+ built :: **Built** es el participio de **build**.
- build :: Es la forma base.
- builds :: Es presente activo.
H The windows ___ cleaned last week. :: Fueron
+ were :: Pasado pasivo con sujeto plural.
- was :: Se usa con sujeto singular.
- are :: Es presente.
O The garden is opened to visitors every summer :: El jardín se abre al público cada verano :: **Is + participio** forma el presente pasivo singular.
X ¿Cómo dices «Las puertas se pintaron el año pasado»? :: The doors were painted last year. :: Sujeto plural en pasado: **were + participio**.

@ 21 | You needn't come | Need, needn't y have got to
I Tres formas para expresar obligaciones y necesidades: **have (got) to**, **need to** y **needn't**.
E Have got to :: **Have to** y **have got to** significan «tener que»; **have got to** es más informal. Con **he**, **she** o **it**, usa **has got to**: **She has got to sign this form**.
E Need y needn't :: Como verbo principal, **need** suele ir con **to**: **Do I need to sign?** **Needn't + verbo base** (sin **to**) significa «no hace falta» y equivale a **don't have to**: **You needn't come**. **Mustn't** significa «no debes; está prohibido», no falta de necesidad.
E Fee y tax :: **Fee** = tasa o cuota que se paga por un servicio. **Tax** = impuesto. No significan lo mismo.

W fee = tasa; cuota | fi | No es lo mismo que **tax**.

@ 21 | By, needn't and have to | indicar agente y necesidad
I Aprende cuándo nombrar a quien realiza una acción y cómo distinguir obligación de ausencia de obligación.
E Agente en la pasiva :: **By + agente** indica quién realiza la acción: **The picture was painted by Lee.** Si no interesa o no se sabe quién la hizo, se puede omitir el agente.
E Necesidad y obligación :: **Needn't + verbo base** significa que no hace falta hacer algo; equivale a **don't have to**. **Have to + verbo base** expresa obligación (**has to** con **he/she/it**). **Mustn't** significa que algo está prohibido, no que sea opcional.
W agent = agente (quien realiza la acción) | ÉI-yent
W painted = pintado; participio de paint | PÉIN-tid
W repair = reparar | ri-PÉR
V Palabras clave
T Ejemplos
- The picture was painted by Lee. = El cuadro fue pintado por Lee.
  > by Lee = por Lee (agente de la acción)
- You needn't bring anything to the meeting. = No hace falta que traigas nada a la reunión.
  > needn't + verbo base = no hace falta
- Mia has to repair the front door before the shop opens. = Mia tiene que reparar la puerta principal antes de que abra la tienda.
  > has to + verbo base = obligación; con **he/she/it** usamos **has**
Q The picture was painted ___ Lee.
+ by :: **By + agente** indica quién pintó el cuadro.
- with :: **With** suele indicar el instrumento, por ejemplo **with a brush**.
- for :: **For** expresa para quién se hizo algo, no quién lo hizo.
H You needn't ___ the bike today; we can repair it tomorrow.
+ repair :: Después de **needn't** usamos el verbo base, sin **to**.
- repairs :: No añadimos **-s** después de **needn't**.
- to repair :: **Needn't** no lleva **to** delante del verbo base.
Q ¿Qué significa «agent» en una frase pasiva?
+ quien realiza la acción :: El agente es la persona o cosa que realiza la acción.
- la persona que recibe la acción :: Esa persona o cosa suele ser el sujeto de la pasiva.
- una herramienta :: El instrumento suele introducirse con **with**.
R Mia has to repair the front door before the shop opens. :: ¿Qué significa?

- Está prohibido que Mia repare la puerta principal. :: Eso expresaría prohibición.

+ needn't :: No hay obligación de traer nada; la frase dice que es opcional.
- have to :: Expresa obligación, pero aquí no hay ninguna.
- mustn't :: Expresa prohibición, pero la frase dice que es opcional.
