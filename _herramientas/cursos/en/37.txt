@ 37 | She must have forgotten | Deducciones sobre el pasado: must, might, can't have
I Hablamos de algo pasado que no sabemos seguro: lo suponemos. Para eso se usa un modal + **have** + participio.
E Must have: seguro que :: **She must have forgotten** (debe de haberlo olvidado: estoy casi seguro). Es una deducción fuerte basada en pruebas. :: Lo contrario, con más duda, es **might have** o **may have**: **He might have missed the bus** (quizá haya perdido el autobús).
E Can't have: imposible :: **They can't have arrived yet** (no pueden haber llegado todavía). Es una deducción negativa: lo consideras imposible. :: **Can't have** no es lo mismo que **mustn't**: esa es una prohibición.
W missed = perdió; echó de menos | mist
W wrong = equivocado; mal | rong
W explanation = explicación | ek-splan-EI-shon
W guess = suposición; adivinar | ges
W conclusion = conclusión | kon-KLÚ-yon
W deduce = deducir | di-DIÚS
W certainly = seguramente; ciertamente | SÉR-tan-li
W clue = pista | klu
W investigation = investigación | in-ves-ti-GÉI-shon
W accident = accidente | ÁK-si-dent
W mystery = misterio | MÍS-te-ri
W fault = culpa; fallo | folt
V Vocabulario: suposiciones
D ¿Dónde está Tom?
Anna: Tom isn't here. He must have missed the bus. = Tom no está aquí. Debe de haber perdido el autobús.
  > must have missed = debe de haber perdido
Tom: Or maybe I'm wrong. = ¿O quizá me equivoque?
  > I'm wrong = me equivoque
Anna: The explanation can't be the traffic. = La explicación no puede ser el tráfico.
  > can't be = no puede ser
Tom: He might have had an accident. = Quizá haya tenido un accidente.
  > might have had = quizá haya tenido
Anna: It's a guess. = Es una suposición.
  > guess = suposición
Tom: I'm certain he has left. = Estoy seguro de que se ha ido.
  > certain = seguro
Anna: Then he should have called. = Entonces debería haber llamado.
  > should have called = debería haber llamado
Tom: He can't have forgotten, he is very careful. = No puede haberlo olvidado, es muy cuidadoso.
  > can't have forgotten = no puede haberlo olvidado
Q ¿Qué significa «He must have missed the bus»?
+ Debe de haber perdido el autobús. :: Must have = deducción segura.
- Tiene que perder el autobús. :: Eso sería presente.
- Perdió el autobús. :: Eso sería pasado simple.
Q ¿Qué significa «He can't have arrived yet»?
+ No puede haber llegado todavía. :: Can't have = deducción negativa.
- No puede llegar todavía. :: Eso sería presente.
- No debería haber llegado. :: Eso sería shouldn't have.
R She might have forgotten.
+ Quizá lo haya olvidado. :: Might have = quizá haya.
- Ella olvidará. :: Eso sería futuro.
- Ella olvidó. :: Eso sería pasado simple.
H He ___ have missed the bus. :: Debe de
+ must :: Deducción segura.
- should :: Eso sería un consejo.
- mustn't :: Eso sería una prohibición.
H It ___ have been the traffic. :: No puede
+ can't :: Deducción negativa: imposible.
- must :: Eso significaría que sí fue.
- should :: Eso sería un consejo.
A It's a guess.
+ Es una suposición. :: Guess = suposición.
- Es una certeza. :: Eso sería certainty.
- Es un accidente. :: Eso sería accident.
O She must have forgotten :: Debe de haberlo olvidado :: Must have + participio.
X ¿Cómo se dice «debe de haber» (deducción segura) en inglés? :: must have :: Ojo: must be es «debe de estar» (presente).

@ 37 | I should have listened | Críticas y lamentos: should have, could have, needn't have
I Hablar del pasado con crítica o con lamento: lo que deberías haber hecho, lo que podías haber hecho, y lo que no hacía falta hacer.
E Should have :: **You should have listened** (deberías haber escuchado). Es una crítica sobre algo que no se hizo. Se escribe **should have** + participio.
E Could have :: **We could have gone by train** (podríamos haber ido en tren). Algo posible que no pasó. No es una crítica, sino una posibilidad perdida.
E Needn't have :: **You needn't have bought the ticket** (no hacía falta que compraras el billete). Se hizo algo innecesario. Ojo: **shouldn't have** es «no debiste hacerlo».
W listened = escuchó | LÍ-send
W warned = avisó; advirtió | uornd
W ignored = ignoró | ig-NÓRD
W wasted = malgastado; desperdiciado | UÉI-sted
W rushed = apresurado; con prisa | rasht
W opportunity = oportunidad | op-or-TIÚ-ni-ti
W stupid = estúpido; tonto | STIÚ-pid
W gamble = arriesgar; jugar | GÁM-bol
W risky = arriesgado; peligroso | RÍS-ki
W embarrassing = embarazoso; vergonzoso | im-BÁ-ra-sin
W silly = tonto; absurdo | SÍ-li
W wise = sensato; sabio | uais
V Vocabulario: críticas

  > should have listened = debería haber escuchado

  > ignored = ignoraste

  > wasted = malgasté

  > could have gone = podríamos haber ido
Lucy: We rushed, and we missed the opportunity. = Nos apresuramos, y perdimos la oportunidad.
  > rushed = nos apresuramos
Pedro: You needn't have bought the ticket. = No hacía falta que compraras el billete.
  > needn't have bought = no hacía falta haber comprado
Lucy: I know, it was risky. = Lo sé, fue arriesgado.
  > risky = arriesgado
Pedro: Let's be wise next time! = ¡Seamos sensatos la próxima vez!
  > wise = sensato
Q ¿Qué significa «You should have listened»?
+ Deberías haber escuchado. :: Crítica sobre el pasado.
- Debes escuchar. :: Eso sería presente.
- Escuchaste. :: Eso sería pasado simple.
Q ¿Qué significa «You needn't have bought the ticket»?
+ No hacía falta que compraras el billete. :: Needn't have = no era necesario.
- No debiste comprar el billete. :: Eso sería shouldn't have.
- No puedes comprar el billete. :: Eso sería can't.
R We could have gone by train.
+ Podríamos haber ido en tren. :: Could have = podríamos haber.
- Debemos ir en tren. :: Eso sería must.
- Fuimos en tren. :: Eso sería pasado.
H You ___ listened to me. :: Deberías haber
+ should have :: Crítica sobre el pasado.
- should :: Eso sería presente.
- shouldn't :: Eso sería no deberías.
H We ___ the opportunity. :: Perdimos
+ missed :: Pasado de miss.
- miss :: Forma base.
- misses :: Presente.
A It was a risky decision.
+ Fue una decisión arriesgada. :: Risky = arriesgado.
- Fue una decisión segura. :: Eso no es risky.
- Fue una decisión tonta. :: Eso sería silly.
