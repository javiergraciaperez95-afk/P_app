@ 6 | I like coffee | La comida y lo que te gusta
E Gustar :: En inglés «gustar» funciona como un verbo normal: **I like coffee** (literalmente «yo gusto café»). El que siente es el sujeto. :: **I love** = me encanta. **I don't like** = no me gusta. **I hate** = odio. :: Para no repetir se usa **it** (singular) o **them** (plural): **I love it**, **I don't like them**.
E A, an y some :: Lo que se puede contar lleva **a** o **an** en singular: **an apple**, **an egg**, **a banana**. :: Lo que no se cuenta (líquidos, masas) no lleva «a»: se dice **some**: **some bread**, **some milk**, **some cheese**. :: Con plurales también vale **some**: **some apples**.
B ¿Se cuenta o no? | Se cuenta | No se cuenta
| an apple | some bread
| an egg | some cheese
| a banana | some milk
| a sandwich | some rice

V Vocabulario: la comida
D ¿Te gusta el pescado?
Sara: Do you like fish, Tom? = ¿Te gusta el pescado, Tom?
  > Do you like = ¿te gusta…? (do + sujeto + verbo)
Tom: No, I don't. I hate fish! But I love chicken. = No. ¡Odio el pescado! Pero me encanta el pollo.
  > I hate = odio | I love = me encanta
Sara: What do you have for breakfast? = ¿Qué desayunas?
  > What do you have = qué tomas | for breakfast = para desayunar
Tom: I usually have some bread and cheese, and an apple. = Normalmente tomo pan con queso y una manzana.
  > some bread = pan (no se cuenta) | an apple = una manzana (se cuenta)
Sara: Do you like coffee? = ¿Te gusta el café?
  > coffee = sin artículo cuando se habla en general
Tom: Yes, I love it. I have coffee with milk every morning. = Sí, me encanta. Tomo café con leche todas las mañanas.
  > I love it = me encanta (it = el café) | every morning = todas las mañanas
Sara: I don't like coffee. I like tea. = A mí no me gusta el café. Me gusta el té.
  > I don't like = no me gusta
Q ¿Cómo dices «me gusta el té»?
+ I like tea. :: Sujeto + like + cosa, sin artículo.
- Tea likes me. :: Eso sería «yo le gusto al té».
- I like the tea. :: Con «the» sería un té concreto, no el té en general.
Q ¿Cuál es correcta?
+ some bread :: El pan no se cuenta: «some».
- a bread :: «Bread» no lleva «a».
- an bread :: No.
Q Te encantan las manzanas. ¿Cómo lo dices sin repetir «apples»?
+ I love them. :: Plural → them.
- I love it. :: «It» es para singular.
- I love they. :: Después del verbo va «them».
R I don't like meat.
+ No me gusta la carne. :: Don't like = no gustar.
- Me gusta la carne. :: Falta la negación.
- No me gusta el pescado. :: «Meat» es carne.
H She ___ fruit.
+ loves :: Con «she» el verbo lleva -s.
- love :: Falta la -s.
- loving :: No.
H I have ___ egg for breakfast.
+ an :: «Egg» empieza por vocal.
- a :: Delante de vocal va «an».
- some :: Un huevo se puede contar.
A I have coffee with milk every morning.
+ Tomo café con leche todas las mañanas. :: Every morning = todas las mañanas.
- Tomo té con leche todas las mañanas. :: Té es «tea».
- Tomo café con leche todos los días. :: «Morning» es mañana.
O Do you like chicken and rice :: ¿Te gusta el pollo con arroz? :: Do + sujeto + like + comida.

@ 6 | I'd like a coffee, please | Pedir en una cafetería
E Pedir con educación :: Para pedir no se dice «I want» (suena brusco). Se dice **I'd like…** (querría…) o **Can I have…?** (¿me pone…?). :: **I'd** es la forma corta de **I would**. :: El camarero pregunta **Would you like…?** (¿quiere…?) o **Anything else?** (¿algo más?). Al darte las cosas dice **Here you are** (aquí tiene).
E Cantidades y precio :: Las bebidas se piden con su recipiente: **a cup of tea** (una taza de té), **a glass of water** (un vaso de agua), **a bottle of water** (una botella de agua). :: Para el precio: **How much is it?** (¿cuánto es?). La moneda británica es la libra: **£6.50** se lee «six pounds fifty». :: Al final de la comida: **Can I have the bill, please?** (¿me trae la cuenta?).

  > Here you are = lo que se dice al dar algo

Q ¿Cuál es la forma educada de pedir un café?
+ I'd like a coffee, please. :: «I'd like» es lo normal al pedir.
- I want a coffee. :: Se entiende, pero suena brusco.
- Give me a coffee. :: Es una orden.
Q El camarero te da el café. ¿Qué dice?
+ Here you are. :: «Aquí tiene».
- How are you? :: Eso es «¿cómo estás?».
- Anything else? :: Eso es «¿algo más?».
Q ¿Qué significa «Anything else?»?
+ ¿Algo más? :: Lo pregunta quien atiende.
- ¿Algo de comer? :: No.
- ¿Nada más? :: Se parece, pero la traducción exacta es «¿algo más?».
R Can I have the bill, please?
+ ¿Me trae la cuenta, por favor? :: The bill = la cuenta.
- ¿Me trae la carta, por favor? :: La carta es «the menu».
- ¿Cuánto es, por favor? :: Sería «How much is it?».
H I'd ___ a glass of juice.
+ like :: I'd like = querría.
- want :: Con «I'd» va «like».
- have :: No se dice así.
H ___ you like sugar?
+ Would :: Would you like…? = ¿quiere…?
- Do :: «Do you like sugar?» preguntaría si te gusta en general.
- Are :: No.
H A ___ of coffee, please.
+ cup :: El café va en taza: «a cup of».
- glass :: «Glass» es vaso.
- bottle :: «Bottle» es botella.
A How much is it?
+ ¿Cuánto es? :: Pregunta por el precio.
- ¿Cuántos hay? :: Sería «How many are there?».
- ¿Cómo es? :: No.
O Can I have a bottle of water please :: ¿Me pone una botella de agua, por favor? :: Can I have + cantidad + please.

@ 6 | How much do we need? | Cantidades: much, many, a lot of
E Much y many :: Para preguntar la cantidad hay dos formas. **How many** va con lo que se cuenta, en plural: **How many eggs?** :: **How much** va con lo que no se cuenta: **How much milk?**, **How much rice?** :: Por eso el precio se pregunta con «how much»: el dinero no se cuenta por unidades.
E Mucho y poco :: **A lot of** (mucho, muchos) vale para todo: **a lot of eggs**, **a lot of milk**. :: En negativo: **not many** (no muchos, para lo que se cuenta) y **not much** (no mucho, para lo que no se cuenta). :: **Need** es «necesitar» y **buy** es «comprar». **Let's** + verbo sirve para proponer: **Let's go!** (¡vamos!).
