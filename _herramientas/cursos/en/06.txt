Q ¿Cómo dices «odio el pescado»?
+ I hate fish. :: «Hate» significa odiar.
- Fish hates me. :: Eso cambiaría el sujeto y el sentido.
- I don't fish. :: Significa que no pescas o que no comes pescado según el contexto.
Q ¿Cómo preguntas «¿te gusta el pollo?»?
+ Do you like chicken? :: Do + sujeto + verbo en forma base.
- Like you chicken? :: Falta el auxiliar «do».
- Are you like chicken? :: No usamos «are» con «like» así.
Q ¿Cómo dices «tengo sed»?
+ I'm thirsty. :: «Thirsty» significa tener sed.
- I'm hungry. :: «Hungry» significa tener hambre.
- I'm tired. :: «Tired» significa estar cansado.
Q Sara no toma café. ¿Qué dice?
+ I don't like coffee. :: Don't + verbo expresa una preferencia negativa.
- I doesn't like coffee. :: Con I usamos «don't».
- I not like coffee. :: Hace falta el auxiliar.
R I love tea.
+ Me encanta el té. :: El sujeto «I» es quien siente el gusto.
- Amo a una persona llamada Tea. :: «Tea» aquí es la bebida.
- No me gusta el té. :: «Love» expresa una preferencia positiva.
H She ___ fish.
+ loves :: Con «she» el verbo lleva -s.
- love :: Falta la -s de tercera persona.
- loving :: No es la forma del presente simple.
H I have ___ for breakfast.
+ bread :: «Bread» significa pan.
- cheese :: Queso también es comida, pero no es la respuesta dada.
- chicken :: Pollo no aparece en esta frase.
A I like rice, but I don't like fish.
+ Me gusta el arroz, pero no me gusta el pescado. :: «But» une dos ideas opuestas.
- No me gusta el arroz, pero me gusta el pescado. :: Invierte las dos ideas.
- Me gusta el arroz porque me gusta el pescado. :: «But» significa «pero».
O Do you like coffee :: ¿Te gusta el café? :: Do + sujeto + like + comida.

@ 6 | A banana, an egg and some rice | Artículos, cantidades y pronombres de objeto
E A, an y the :: Usa **a/an** con un sustantivo contable singular cuando lo mencionas por primera vez: **a banana**, **an egg**. Elige por el sonido inicial: **an apple**, pero **a university**. :: Usa **the** cuando hablamos de algo concreto o ya conocido: **I have an apple. The apple is red**.
E Comida en general y cantidades :: Para hablar en general, no usamos artículo con plurales ni incontables: **I like apples / tea**. Con **some** hablamos de una cantidad no especificada: **some apples / some milk**. :: **Any** es frecuente en preguntas neutras y negativas: **Do you have any apples? / We don't have any milk**. En ofrecimientos y peticiones es normal **some**: **Would you like some tea?**
E Pronombres de objeto :: El pronombre de objeto recibe la acción y va después del verbo o de una preposición: **I like him**, **She helps us**, **This is for me**. Aprende la pareja completa: **I/me, you/you, he/him, she/her, it/it, we/us, they/them**.

  > for us = para nosotros | apples = manzanas | them = pronombre de objeto plural

Q Mencionas una manzana por primera vez. ¿Qué artículo eliges?
+ I have an apple. :: «Apple» empieza por sonido vocálico, por eso usamos «an».
- I have a apple. :: Se elige por el sonido inicial, no por la letra.
- I have the apple. :: «The» sería una manzana concreta que ya conocemos.
Q Hablas de la leche en general. ¿Cuál es normal?
+ I like milk. :: «Milk» es incontable y se habla en general.
- I like a milk. :: Para pedir una porción se necesita un contexto concreto.
- I like the milk. :: «The milk» sería una leche concreta.
Q ¿Qué pronombre completa «I like ___» si hablas de Tom?
+ him :: Después del verbo usamos el pronombre de objeto.
- he :: «He» es pronombre de sujeto.
- his :: «His» indica posesión.
Q ¿Cuál es el pronombre de objeto de «she»?
+ her :: «She» es sujeto; «her» es objeto.
- she :: «She» funciona como sujeto.
- hers :: «Hers» expresa posesión.
R I like apples. I like them.

- Me gustan las manzanas. Me gusta él. :: «Them» es plural.
- Me gustan las manzanas. Me gusto. :: «Me» no sustituye «apples».
H I don't have ___ milk.
+ any :: «Any» es habitual en negativas con incontables.
- some :: Aquí la frase es negativa.
- a :: «Milk» es incontable.

- we :: «We» es pronombre de sujeto.
- our :: «Our» necesita un sustantivo.

- Soy una naranja y algo de sopa. :: «Have» significa tener o tomar, según contexto.

@ 6 | I'd like a coffee, please | Pedir en una cafetería
E Pedir con educación :: Para pedir con cortesía son muy útiles **I'd like…** (quisiera…) y **Can I have…?** (¿me da…?, ¿me pone…?). **I want…** es gramatical, pero suele sonar más directo; el tono y la situación también importan. :: **I'd** es la forma corta de **I would**. El camarero pregunta **Would you like…?** (¿quiere…?) o **Anything else?** (¿algo más?). Al darte las cosas dice **Here you are** (aquí tiene).
E Cantidades y precio :: Las bebidas se piden con su recipiente: **a cup of tea** (una taza de té), **a glass of water** (un vaso de agua), **a bottle of water** (una botella de agua). :: Para el precio: **How much is it?** (¿cuánto es?). La moneda británica es la libra: **£6.50** se lee «six pounds fifty». :: Al final de la comida: **Can I have the bill, please?** (¿me trae la cuenta?).

@ 6 | How much do we need? | Cantidades: much, many, a lot of
E Much y many :: Para preguntar por el número de unidades, usa **how many** con sustantivos contables en plural: **How many eggs?** Para preguntar por una cantidad no contable, usa **how much**: **How much milk?**, **How much rice?** :: **How much is it?** es una pregunta fija por el precio; también se dice **How much money?** porque **money** es incontable. **How many pounds?** pregunta por el número de libras.
E Mucho y poco :: **A lot of** (mucho, muchos) vale para sustantivos contables e incontables: **a lot of eggs**, **a lot of milk**. En afirmativas normalmente preferimos **a lot of** a **much/many**. :: En negativas usamos **not many** (no muchos, con contables) y **not much** (no mucho, con incontables). :: **Need** es «necesitar» y **buy** es «comprar». **Let's** + verbo sirve para proponer: **Let's go!** (¡vamos!).
