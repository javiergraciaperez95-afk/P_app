@ 39 | I wish I had more time | Ojalá: deseos sobre el presente
I Cuando quieres que algo fuera distinto de como es, usas **wish** o **if only** (ojalá). El tiempo cambia según lo que lamentas.
E Wish + pasado simple (presente) :: **I wish I had more time** (ojalá tuviera más tiempo). **I wish I were taller** (ojalá fuera más alto). Para todas las personas, con **be** se usa **were**. :: **If only** = ojalá, con más emoción: **If only I were rich!** (¡ojalá fuera rico!).
E Wish + would :: **I wish you would stop** (ojalá dejaras de hacerlo). Se usa para quejarte de algo que hace otra persona y que no cambia. Lo normal es que te moleste.
E Falso amigo: hopefully :: **Hopefully** = esperemos que, ojalá (que pase algo posible). No se usa para un deseo imposible. Para eso, usa **wish** o **if only**.
W if only = ojalá (con más emoción) | if ÓN-li
W envy = envidia; envidiar | EN-vi
W jealous = celoso; envidioso | JÉ-lus
W annoying = molesto; irritante | a-NÓ-yin
W annoyed = molesto; irritado | a-NÓID
W hopefully = esperemos que; ojalá | JÓP-ful-li
W miserable = desdichado; muy triste | MÍ-se-ra-bol
W talented = talentoso; con talento | TÁ-len-tid
W poor = pobre | púr
W lonely = solo; solitario | LÓN-li
W sad = triste | sad
W unhappy = infeliz; descontento | an-JÁ-pi
W cheerful = alegre | CHÍR-ful
V Vocabulario: deseos
D Ojalá…
Anna: I wish I had more time. = Ojalá tuviera más tiempo.
  > I wish I had = ojalá tuviera
Tom: If only I were talented like you! = ¡Ojalá fuera tan talentoso como tú!
  > If only I were = ojalá fuera
Anna: You are not poor, and you are not lonely. = No eres pobre, y no estás solo.
  > poor = pobre
Tom: I wish you would stop. = Ojalá dejaras de hacerlo.
  > I wish you would stop = ojalá dejaras
Anna: That noise is annoying! = ¡Ese ruido es molesto!
  > annoying = molesto (cosa)
Tom: I'm annoyed, and I envy your trip. = Estoy molesto, y envidio tu viaje.
  > envy = envidiar
Anna: Hopefully, the weather will be sunny. = Ojalá haga sol.
  > Hopefully = esperemos que
Tom: I'm sad, but I'm not jealous. = Estoy triste, pero no tengo celos.
  > jealous = celoso
Q ¿Qué significa «I wish I had more time»?
+ Ojalá tuviera más tiempo. :: Wish + pasado simple: deseo sobre el presente.
- Espero tener más tiempo. :: Eso sería hope.
- Tenía más tiempo. :: Eso sería pasado.
Q ¿Qué forma va en «If only I ___ rich»?
+ were :: Con be, were para todas las personas en wish y if only.
- am :: Es presente real.
- will be :: No va will tras if only.
R I wish I had a bigger house.
+ Ojalá tuviera una casa más grande. :: Wish + pasado simple.
- Espero tener una casa más grande. :: Eso sería hope.
- Tuve una casa más grande. :: Eso sería pasado.
H I wish you ___ stop. :: Dejaras
+ would :: Wish + would: queja sobre lo que hace otro.
- will :: Eso no va con wish.
- can :: Eso expresa capacidad.
H I wish I ___ tall. :: Fuera
+ were :: Con be, en wish, were.
- am :: Es presente real.
- will be :: No va con wish.
A That noise is annoying.
+ Ese ruido es molesto. :: Annoying = molesto (cosa).
- Ese ruido está bien. :: Eso no es annoying.
- Ese ruido es silencioso. :: Eso no es annoying.
O If only I were talented :: Ojalá fuera talentoso :: If only = ojalá.
X ¿Cómo se dice «ojalá» (deseo imposible) con if en inglés? :: if only :: Ojo: hopefully es «esperemos que», para algo posible.

@ 39 | I wish I had studied harder | Ojalá: lamentos del pasado
I Cuando lamentas algo que ya pasó, el tiempo cambia: pasado perfecto.
E Wish + pasado perfecto :: **I wish I had studied harder** (ojalá hubiera estudiado más). **If only I had listened!** (¡ojalá hubiera escuchado!). Se forma con **had** + participio. :: Compara: **I wish I were** (presente) y **I wish I had been** (pasado).
E Relaciones de confianza :: **Rely on** = confiar en (depender de algo o alguien). **Trust** = confiar en una persona. **Forgive** = perdonar. **Betray** = traicionar.
W harder = más duro; con más empeño | HÁR-der
W trust = confiar en (una persona) | trast
W betray = traicionar | bi-TREI
W forgive = perdonar | fo-GÍV
W rely = confiar en; depender de | ri-LÁI
W neglect = descuidar; desatender | ni-GLÉKT
W scared = asustado; con miedo | SKÉRD
W dictionary = diccionario | DÍK-sho-ne-ri
W essay = redacción; ensayo (escolar) | É-sei
W grade = nota; calificación | greid
W clearly = claramente | KLÍR-li
W upset = disgustado; afectado | ap-SÉT
V Vocabulario: lamentos
D Después del examen
Lucy: I wish I had studied harder for the exam. = Ojalá hubiera estudiado más para el examen.
  > I wish I had studied = ojalá hubiera estudiado
Pedro: If only I had listened to my teacher! = ¡Ojalá hubiera escuchado a mi profesor!
  > If only I had listened = ojalá hubiera escuchado
Lucy: The grade was bad, and I'm upset. = La nota fue mala, y estoy disgustada.
  > upset = disgustada
Pedro: Don't be sad, you can still pass! = ¡No estés triste, todavía puedes aprobar!
  > still = todavía
Lucy: I rely on your help. = Confío en tu ayuda.
  > rely on = confiar en
Pedro: I trust you, and I forgive you. = Confío en ti, y te perdono.
  > forgive = perdonar
Lucy: I'd never betray you. = Nunca te traicionaría.
  > betray = traicionar
Pedro: I'm scared of the next exam, but I'll study hard. = Tengo miedo del próximo examen, pero estudiaré mucho.
  > scared of = tengo miedo de
Q ¿Qué significa «I wish I had studied harder»?
+ Ojalá hubiera estudiado más. :: Wish + pasado perfecto: lamento del pasado.
- Ojalá estudie más. :: Eso sería presente.
- Espero haber estudiado más. :: Eso sería hope.
Q ¿Qué diferencia hay entre «I wish I had» y «I wish I was»?
+ had = lamento del pasado; was/were = deseo del presente. :: Es una diferencia de tiempo.
- No hay diferencia. :: Sí la hay: cambia el tiempo.
- had = futuro. :: No es futuro.
R I wish I had listened to the advice.
+ Ojalá hubiera escuchado el consejo. :: Wish + pasado perfecto.
- Ojalá escuche el consejo. :: Eso sería presente.
- Espero escuchar el consejo. :: Eso sería hope.
H If only I ___ the exam! :: Hubiera aprobado
+ had passed :: Lamento del pasado.
- pass :: Es presente.
- will pass :: No va con if only.
H I wish I ___ harder. :: Hubiera estudiado
+ had studied :: Pasado perfecto.
- will study :: No va con wish.
- am studying :: Es presente continuo.
A I'm scared of the exam.
+ Tengo miedo del examen. :: Scared of = tener miedo de.
- Estoy contenta con el examen. :: Eso no es scared.
- Estoy harto del examen. :: Eso sería fed up.
O She was upset about the grade :: Estaba disgustada por la nota :: Upset = disgustada.
X ¿Cómo se dice «confiar en» (una persona) en inglés? :: trust :: Ojo: rely on es confiar en algo o alguien para depender de él.

@ 39 | My plan is mixed | Texto de universidad y falsos amigos
I Un texto sobre estudiar fuera y becas. Hay dos falsos amigos traicioneros: léelos con calma.
E Falsos amigos :: **College** = universidad (no es «colegio», que es **school**). **Application** = solicitud (no es «aplicación» en el sentido de app, que es **app**).
E Condicional mixto :: Si hablas de algo imaginario del pasado con consecuencias en el presente: **If I had got the scholarship, I would be happy now** (si hubiera conseguido la beca, ahora estaría contenta).
W college = universidad | KÓ-lidch
W application = solicitud | ap-li-KÉI-shon
W essay = redacción (de estudios) | É-sei
W mixed = mixto; confuso | mikst
W scholarship = beca | SKÓ-lar-ship
W tuition = matrícula; tasas | tiu-ÍSH-on
W subject = asignatura; tema | SÚB-yekt
W professor = profesor (universitario) | pro-FÉ-sor
W campus = campus | KÁM-pus
W semester = semestre | se-MÉS-ter
W dormitory = residencia de estudiantes | DÓR-mi-to-ri
W graduate = graduarse; licenciado | GRÁ-diu-eit
V Vocabulario: universidad
T Estudiar fuera
- I wish I had gone to college. = Ojalá hubiera ido a la universidad.
  > college = universidad (no «colegio»)
- If I had got the scholarship, I would be happy now. = Si hubiera conseguido la beca, ahora estaría contenta.
  > If I had got = si hubiera conseguido
- The application form was in the box. = El formulario de solicitud estaba en la caja.
  > application = solicitud (no «aplicación»)
- My essay is good, but the tuition is expensive. = Mi redacción es buena, pero la matrícula es cara.
  > essay = redacción | tuition = matrícula
- The professor is strict. = El profesor es estricto.
  > professor = profesor universitario
- Our campus has a big library. = Nuestro campus tiene una biblioteca grande.
  > campus = campus
- My semester starts in January. = Mi semestre empieza en enero.
  > semester = semestre
- I'll graduate next year, and my plan is mixed. = Me graduaré el año que viene, y mi plan es confuso.
  > graduate = graduarse | mixed = confuso
Q ¿Qué significa «college» en «I wish I had gone to college»?
+ universidad :: Falso amigo: «colegio» es school.
- colegio :: Eso es school.
- instituto :: Eso es high school.
Q ¿Qué significa «application» en «The application form»?
+ solicitud :: Falso amigo: no es «aplicación» en el sentido de app.
- aplicación informática :: Eso es app.
- uso :: Eso es use.
R My essay is good.
+ Mi redacción es buena. :: Essay = redacción.
- Mi ensayo de teatro es bueno. :: Ensayo de teatro es rehearsal.
- Mi examen es bueno. :: Eso sería exam.
H If I ___ the scholarship, I would be happy now. :: Hubiera conseguido
+ had got :: Pasado perfecto en el if: lo que no pasó.
- got :: Pasado simple: no marca lo imaginario.
- will get :: No va will en la parte if.
H The ___ is expensive. :: Matrícula
+ tuition :: Matrícula.
- tutor :: Es el profesor particular.
- scholarship :: Es la beca.
A The semester starts in January.
+ El semestre empieza en enero. :: Semester = semestre.
- El examen empieza en enero. :: Eso sería exam.
- El curso de inglés empieza en enero. :: Eso sería course.
O I graduate next year :: Me gradúo el año que viene :: Graduate = graduarse.
X ¿Cómo se dice «beca» en inglés? :: scholarship :: Ojo: grant también puede significar subvención.
