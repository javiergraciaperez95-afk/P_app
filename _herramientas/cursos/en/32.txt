E Present perfect continuous :: Afirmativa: **have/has been + verbo en -ing**: **I've been waiting for an hour**. Negativa: **haven't/hasn't been + -ing**; pregunta: **Have/Has + sujeto + been + -ing?**: **Have you been waiting long?**. El contraste no es absoluto: **I've lived here for years** y **I've been living here for years** pueden expresar una situación que continúa. Los verbos de estado, como **know**, normalmente usan el presente perfecto simple.

- too :: Too significa demasiado.
- as :: As… as es igualdad.
R Although the ground was wet, we went there. :: Cap. 28. ¿Qué significa?
+ Aunque el suelo estaba mojado, fuimos allí. :: Although = aunque.
- Porque el suelo estaba mojado, fuimos allí. :: Eso expresaría causa, no contraste.
- Para que el suelo estuviera mojado, fuimos allí. :: Eso expresaría propósito.
H Cap. 28. ___ you go, pick up the ticket. :: Antes de ir
+ Before :: Antes de.
- After :: Después de.
- During :: Durante.
Q Cap. 29. ¿Qué significa «You ought to rest»?
+ Deberías descansar. :: Ought to expresa consejo o lo que sería adecuado; no equivale a una obligación absoluta.
- Debes descansar, es obligatorio. :: Eso expresaría una obligación más fuerte, como must.
- Puedes descansar. :: Eso sería can.
H Cap. 29. I ___ to work yesterday. :: Tuve que
+ had :: Pasado de have to.
- have :: Es presente.
- has :: Es presente con he, she, it.
R It might rain tomorrow. :: Cap. 29. ¿Qué significa?
+ Quizá llueva mañana. :: Might = quizá.
- Lloverá mañana. :: Eso sería will, sin duda.
- Llovió mañana. :: Eso es pasado.
Q Cap. 30. ¿Qué significa «look after» en «Can you look after the dog?»?
+ cuidar :: Phrasal verb: no es «mirar después».
- mirar después :: Eso es la traducción literal.
- buscar :: Eso sería look for.
H Cap. 30. I dream ___ Japan. :: Con
+ of :: Dream of = soñar con.
- to :: No va con dream.
- in :: No va con dream.
Q Cap. 31. ¿Cuándo se usa el presente continuo para el futuro?
+ Para planes ya acordados, con hora o fecha. :: Es un acuerdo fijo.
- Para hablar de algo que pasó. :: Eso es pasado.
- Para una opinión sin pruebas. :: Eso sería will.
H Cap. 31. The timetable says the train is ___ to arrive at ten. :: Previsto
+ due :: **Be due to** indica que algo está previsto o programado.
- about :: About to = a punto de.
- sold :: Eso es vendido.
Q Cap. 32. ¿Qué significa «I'm keen on painting»?
+ Me entusiasma pintar. :: Keen on = entusiasmado con.
- Pinto poco. :: Eso no es keen on.
- Estoy harta de pintar. :: Eso sería fed up with.
H Cap. 32. I've had the ___ for two weeks. :: Gripe
+ flu :: **The flu** es una forma habitual; también se dice **have flu** sin artículo.
- nurse :: Es la enfermera.
- pharmacist :: Es el farmacéutico.
X Cap. 28. Escribe una conjunción que exprese contraste, como «mientras que». :: whereas | while :: **Whereas** y **while** sirven para contrastar; **while** también puede indicar simultaneidad temporal.
