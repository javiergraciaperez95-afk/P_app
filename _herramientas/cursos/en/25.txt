@ 25 | The rules must be followed | Voz pasiva con modales
I En A2 ya viste la pasiva. Ahora la combinas con modales: **can**, **must**, **should**. La regla es la misma.
E Modal + be + participio :: **can be carried** (se puede llevar), **must be checked** (debe revisarse), **should be locked** (debería cerrarse con llave). La estructura siempre es: modal + **be** + participio. :: Negativa: **can't be stored** (no se puede guardar), **mustn't be used** (no debe usarse).
E La pasiva con by :: Si quieres decir quién hace la acción, usa **by**: **The product is made by a machine** (el producto lo hace una máquina). :: Sin **by** no decimos quién, y es lo normal: **The door must be locked** (la puerta debe cerrarse).
W followed = seguido; cumplido | FÓ-lod | Participio de «follow».
W follow = seguir; cumplir | FÓ-lou
W done = hecho; terminado | dan
W locked = cerrado con llave | lokt
W lock = cerrar con llave | lok
W carried = llevado; transportado | KÁ-rid
W recycled = reciclado; reciclada | ri-SÁI-kld
W stored = guardado; almacenado | stórd
W approved = aprobado; aprobada | a-PRÚVD
W delayed = retrasado; retrasada | di-LÉID
W forbidden = prohibido; prohibida | for-BÍ-den
W safety = seguridad | SÉIF-ti
V Vocabulario: normas
D Normas de la fábrica
Tom: The rule must be followed here. = Aquí la norma debe cumplirse.
  > must be followed = debe cumplirse
Anna: Why? = ¿Por qué?
  > Why = ¿por qué?
Tom: Because the car must be checked. = Porque el coche debe revisarse.
  > must be checked = debe revisarse
Anna: The bag can be carried here. = La bolsa se puede llevar aquí.
  > can be carried = se puede llevar
Tom: No, it can't be stored here. = No, aquí no se puede guardar.
  > can't be stored = no se puede guardar
Anna: The door must be locked at night. = La puerta debe cerrarse con llave por la noche.
  > must be locked = debe cerrarse con llave
Tom: The garden is forbidden. = El jardín está prohibido.
  > is forbidden = está prohibido
Anna: The trip was delayed. = El viaje se retrasó.
  > was delayed = se retrasó
Q ¿Qué significa «The bag can be carried»?
+ La bolsa se puede llevar. :: Modal + be + participio.
- La bolsa puede llevar a alguien. :: No es pasiva.
- La bolsa llevaba a alguien. :: Eso es pasado activo.
Q ¿Cuál es la forma correcta? «The door ___ locked at night.» (debe)
+ must be :: Modal + be + participio.
- must is :: Con modal no va is.
- must be lock :: Falta el participio: locked.
R The garden is forbidden.
+ El jardín está prohibido. :: Forbidden = prohibido.
- El jardín es bonito. :: Eso no es forbidden.
- El jardín está cerrado con llave. :: Eso sería locked.
H The trip was ___ because of the storm. :: Retrasado
+ delayed :: Participio de «delay».
- delay :: Es la forma base.
- delays :: Es presente.
H The door must be ___ at night. :: Cerrada con llave
+ locked :: Participio de «lock».
- lock :: Es la forma base.
- locks :: Es presente.
A The bag can be carried here.
+ La bolsa se puede llevar aquí. :: Can be carried = se puede llevar.
- La bolsa no se puede llevar aquí. :: Eso sería can't be carried.
- La bolsa lleva aquí. :: Eso no es pasiva.
O It must be done today :: Debe hacerse hoy :: Must be + participio.
X ¿Cómo se dice «debe cumplirse» en inglés? :: must be followed :: Ojo: follow = seguir o cumplir una norma.

@ 25 | Is it kept by hand? | Preguntas en pasiva y el robo de la cartera
I En preguntas pasivas, el auxiliar va delante del sujeto, como en las preguntas normales.
E Preguntas en pasiva :: **Was the window cleaned?** (¿se limpió la ventana?). **Where are the keys kept?** (¿dónde se guardan las llaves?). **Who was the book written by?** (¿quién escribió el libro?). :: Las respuestas cortas siguen el auxiliar: **Yes, it was.** / **No, it wasn't.**
E Keep, kept :: **Keep** = guardar, mantener. Su pasado es **kept**: **The document was kept in the bag** (el documento estaba guardado en el bolso).
W keep = guardar; mantener | kip
W kept = guardado; mantenido | kept | Pasado de «keep».
W steal = robar | stil
W stolen = robado; robada | STÓ-len | Participio de «steal».
W insured = asegurado; asegurada | in-SHÚRD
W insurance = seguro (de protección) | in-SHÚ-rans
W document = documento | DÓ-kiu-ment
W hand = mano | jand | «By hand» = a mano.
W owner = dueño; dueña | Ó-ner
W credit = crédito | KRÉ-dit
W clerk = empleado de oficina | klérk
W police = policía | pe-LÍS
V Vocabulario: robos y papeles
D Un robo
Lucy: My wallet was stolen! = ¡Me han robado la cartera!
  > was stolen = me han robado
Pedro: When was it stolen? = ¿Cuándo te la robaron?
  > was it stolen = ¿te la robaron?
Lucy: It was stolen on the bus. = Me la robaron en el autobús.
  > was stolen = me la robaron
Pedro: Was the document kept in the bag? = ¿El documento estaba guardado en el bolso?
  > kept = guardado
Lucy: Yes, it was. = Sí, lo estaba.
  > it was = sí, lo estaba
Pedro: Who is the owner of the bag? = ¿Quién es el dueño del bolso?
  > the owner = el dueño
Lucy: My insurance will pay for it. = Mi seguro lo pagará.
  > insurance = seguro
Pedro: Is it insured by the bank? = ¿Está asegurado por el banco?
  > insured by = asegurado por
Q ¿Cuál es la pregunta correcta en pasiva?
+ Was the window cleaned? :: Auxiliar delante del sujeto.
- Did the window clean? :: Eso es activa.
- Is the window cleaned yesterday? :: Con «yesterday» va pasado.
Q ¿Qué respuesta corta es correcta a «Was the bag kept here?»?
+ Yes, it was. :: La respuesta sigue el auxiliar: was.
- Yes, it did. :: Did no corresponde a was.
- Yes, it is. :: Is es presente.
R The wallet was stolen.
+ La cartera fue robada. :: Was stolen = fue robada.
- La cartera fue encontrada. :: Eso sería «found».
- La cartera fue comprada. :: Eso sería «bought».
H Where are the keys ___? :: Guardadas
+ kept :: Participio de «keep».
- keep :: Es la forma base.
- keeps :: Es presente activo.
H My phone was ___ yesterday. :: Robado
+ stolen :: Participio de «steal».
- steal :: Es la forma base.
- steals :: Es presente.
A Was the document kept here?
+ ¿Se guardaba el documento aquí? :: Was kept = se guardaba.
- ¿Guardó el documento aquí? :: Eso sería activa.
- ¿Dónde guardó el documento? :: Eso sería activa con «where».
O Who was the book written by? :: ¿Por quién fue escrito el libro? :: By + quien hace la acción.
X ¿Cómo se dice «guardar» (en el sentido de conservar) en inglés? :: keep :: Ojo: kept es el pasado de keep.

@ 25 | The factory tour | Visita a una fábrica y falsos amigos
I Un texto sobre una visita a una fábrica. Tres falsos amigos aparecen aquí: léelos con calma.
E Falsos amigos :: **Quarter** = barrio (en una ciudad), o un cuarto (de hora). No es «cuarto» de la casa, que es **room**. **Estate agent** = agente inmobiliario (no es «agente de estado»). **Factory** = fábrica (no es «factoría» en el sentido de la empresa de la finca).
E Pasiva en los procesos :: Las visitas guiadas usan mucho la pasiva: **The product is made by a machine**, **Every machine must be checked**.
W factory = fábrica | FÁK-to-ri
W product = producto | PRÓ-dakt
W machine = máquina | ma-SHÍN
W worker = trabajador; trabajadora | UÉR-ker
W quarter = barrio; cuarto de hora | KWÓR-ter | Falso amigo: no es «cuarto» de casa (eso es «room»).
W estate agent = agente inmobiliario | is-TÉIT ÉI-yent | Falso amigo: no es «agente de estado».
W warehouse = almacén | UÉR-jaus
W process = proceso | PRÓ-ses
W produce = producir | pro-DIÚS
W delivery = entrega | di-LÍ-veri
W ingredient = ingrediente | in-GRÍ-dient
W container = contenedor | kon-TÉI-ner
V Vocabulario: fábrica
T Visita a una fábrica
- Our tour started at the factory. = Nuestra visita empezó en la fábrica.
  > factory = fábrica
- The product is made by a machine. = El producto lo hace una máquina.
  > is made by = lo hace
- Every machine must be checked every day. = Cada máquina debe revisarse todos los días.
  > must be checked = debe revisarse
- The worker must wear a helmet. = El trabajador debe llevar casco.
  > must wear = debe llevar
- The house is in an old quarter of the city. = La casa está en un barrio antiguo de la ciudad.
  > quarter = barrio (no «cuarto»)
- The estate agent said the flat was sold. = El agente inmobiliario dijo que el piso se había vendido.
  > estate agent = agente inmobiliario | was sold = se había vendido
- The product is stored in a warehouse. = El producto se almacena en un almacén.
  > is stored = se almacena
- The process is safe for the worker. = El proceso es seguro para el trabajador.
  > process = proceso
Q ¿Qué significa «quarter» en «an old quarter of the city»?
+ barrio :: Falso amigo: «cuarto» de casa es «room».
- cuarto (de casa) :: Eso es «room».
- moneda de 25 centavos :: Eso también es quarter, pero no aquí.
Q ¿Qué significa «estate agent»?
+ agente inmobiliario :: Falso amigo: no es «agente de estado».
- agente del gobierno :: Eso sería «government agent».
- espía :: Eso sería «spy».
R The product is made by a machine.
+ El producto lo hace una máquina. :: Is made by = lo hace.
- El producto hace una máquina. :: Eso sería voz activa.
- El producto se vende en una máquina. :: Eso sería «sold».
H Every machine ___ checked every day. :: Debe revisarse
+ must be :: Modal + be + participio.
- must check :: Falta el be.
- is checking :: Eso es presente continuo.
H The worker ___ wear a helmet. :: Debe llevar
+ must :: Obligación.
- mustn't :: Eso es prohibición.
- can't :: Eso es imposibilidad.
A The process is safe.
+ El proceso es seguro. :: Safe = seguro.
- El proceso es peligroso. :: Eso sería «dangerous».
- El proceso es lento. :: Eso sería «slow».
O The product is stored in a warehouse :: El producto se almacena en un almacén :: Is stored = pasiva presente.
X ¿Cómo se dice «producir» en inglés? :: produce :: Ojo: product es producto.
