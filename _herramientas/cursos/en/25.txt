Q ¿Cuál es la pregunta pasiva de sí o no bien formada?
+ Was the report published online? :: «Was» va antes del sujeto.
- Did the publisher publish the report online? :: Es activa; la pregunta pide la forma pasiva.
- Was published the report online? :: El sujeto debe ir después del auxiliar y antes del participio.
H When ___ the results published? :: Cuándo
+ were :: «Results» es plural, por eso se usa «were».
- was :: «Was» no concuerda con el sujeto plural.
- did :: La frase ya tiene el participio pasivo «published».
H Where ___ printed copies delivered? :: Dónde
+ were :: «Copies» es plural.
- was :: «Was» no concuerda con «copies».
- did :: No se combina «did» con esta forma pasiva.
Q ¿Qué respuesta breve corresponde a «Were the printed copies delivered?»?
+ Yes, they were. :: «Copies» es plural; la respuesta usa «they were».
- Yes, it was. :: Eso correspondería a un sujeto singular.
- Yes, they did. :: La pregunta empieza con «were», no con «did».
Q ¿Qué pregunta pregunta quién escribió el informe?
+ Who was the report written by? :: «By» introduce al agente.
- When was the report published? :: Pregunta cuándo.
- Where were the copies delivered? :: Pregunta dónde.
R The report was written by two local engineers.
+ El informe fue escrito por dos ingenieros de la zona. :: «By two local engineers» nombra a quienes lo escribieron.
- El informe fue enviado a dos ingenieros locales. :: Eso no es lo que expresa «written by».
- Dos ingenieros recibieron el informe local. :: Cambia la relación entre las palabras.
O By whom was the report written? :: ¿Quién escribió el informe? :: Es la forma más formal de preguntar por el agente.
X ¿Cómo se dice «El informe se publicó en línea el 12 de junio»? :: The report was published online on 12 June :: «Was published» es pasiva en pasado.
