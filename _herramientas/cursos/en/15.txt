@ 15 | It's more interesting | Comparar con adjetivos largos
I En el A1 comparaste con -er (cheaper, bigger). Ahora, los adjetivos largos y algunas trampas.
E Adjetivos cortos: -er :: Un adjetivo corto añade **-er** y **than** para decir «que»: **cheap** → **cheaper than** (más barato que). Se duplica la última consonante en **big** → **bigger** (más grande). Si acaba en **y**, la **y** pasa a **i**: **easy** → **easier** (más fácil).
E Adjetivos de dos o más sílabas :: Muchos adjetivos de dos sílabas y la mayoría de los más largos usan **more**: **more careful**, **more interesting**. Pero los que terminan en consonante + **y** suelen cambiar **y** por **i** y añadir **-er**: **busy → busier**, **easy → easier**. Algunos adjetivos de dos sílabas admiten las dos formas: **cleverer / more clever**. :: No combines las dos marcas: **cheaper**, no «more cheaper».
E Falso amigo: interesting :: **Interesting** = interesante (la cosa). **Interested** = interesado (la persona). Por eso se dice **I'm interested in…** (me interesa…).
W interesting = interesante | IN-trest-in | Para cosas. Para personas, «interested».
W interested = interesado; interesada | IN-trest-id
W easy = fácil | Í-si
W easier = más fácil | Í-si-er
W busier = más ocupado; más ocupada | BÍ-zi-er
W clever = listo; inteligente | KLÉ-ver
W more = más | mor
W hotter = más caliente | JÓ-ter
W younger = más joven | YÁN-guer
W popular = popular | PÓ-piu-lar
W famous = famoso; famosa | FÉI-mos
W careful = cuidadoso; con cuidado | KÉR-ful
W exciting = emocionante | ik-SÁI-tin
W quicker = más rápido; más rápida | KUÍ-ker
V Vocabulario: comparar
D ¿Qué película vemos?
Lucy: Which film is more interesting? = ¿Qué película es más interesante?
  > more interesting = más interesante
Tom: This one is more exciting! = ¡Esta es más emocionante!
  > more exciting = más emocionante
Lucy: Really? This one is easier. = ¿De verdad? Esta es más fácil.
  > easier = más fácil
Tom: I'm more interested in it. = A mí me interesa más.
  > I'm more interested = me interesa más | in it = en ella
Lucy: Ok! Let's go to the cinema. = ¡Vale! Vamos al cine.
  > Let's go = vamos
Tom: The cinema is cheaper than the restaurant. = El cine es más barato que el restaurante.
  > cheaper than = más barato que
Lucy: My cousin is younger than me, but she is quicker! = ¡Mi prima es más joven que yo, pero es más rápida!
  > younger than = más joven que | quicker = más rápida
Tom: You are famous now. = Ahora eres famosa.
  > famous = famosa
Q ¿Cuál es el comparativo de «cheap»?
+ cheaper :: Adjetivo corto: se añade -er.
- more cheap :: Con adjetivos cortos no se usa more.
- cheapest :: Eso es el superlativo.
Q ¿Cuál es correcta?
+ This film is more exciting. :: Adjetivo largo: more + adjetivo.
- This film is excitinger. :: Ese adjetivo no existe así.
- This film is more exciting than. :: Falta el objeto de la comparación.
Q ¿Cuál es el comparativo habitual de «busy»?
+ busier :: Termina en consonante + y: y cambia a i y se añade -er.
- more busy :: Es posible en algunos usos, pero busier es la forma habitual que se enseña aquí.
- busyer :: La y cambia a i.
R This one is easier.
+ Esta es más fácil. :: Easier = más fácil (easy → easier).
- Esta es muy fácil. :: Eso sería «very easy».
- Esta es la más fácil. :: Eso sería superlativo: «the easiest».
H I'm more ___ in it. :: Interesada
+ interested :: Persona interesada.
- interesting :: Cosa interesante.
- interest :: Es el sustantivo: «interés».
H The cinema is ___ than the restaurant. :: Más barato
+ cheaper :: Adjetivo corto: cheap → cheaper.
- more cheap :: Con adjetivos cortos no va more.
- cheapest :: Eso es el superlativo.
A My cousin is younger than me.
+ Mi primo es más joven que yo. :: Younger = más joven.
- Mi prima es mayor que yo. :: Eso sería «older».
- Mi primo es el más joven. :: Eso sería superlativo.
O This one is more popular :: Esta es más popular :: More + adjetivo largo.
X ¿Cómo se dice «interesante» (no «interesado») en inglés? :: interesting :: Interested es «interesado».

@ 15 | As cheap as the bus | Igual de… que, no tan… como
I Para decir que dos cosas son iguales o que una no supera a la otra, usamos **as… as**.
E Igual de… que :: **As + adjetivo + as** = igual de…: **as cheap as the bus** (tan barato como el autobús). Se usa un adjetivo sin cambiarlo: **as fast as**, **as comfortable as**. :: No se usa **than** con **as… as**.
E No tan… como :: **Not as + adjetivo + as** = no tan…: **not as expensive as the train** (no tan caro como el tren). :: Si quieres decir «más… que» con una cosa mejor, usa **-er** o **more** con **than**, no **as**.
E Igual que :: **The same as** = igual que: **It's the same as the bus** (es igual que el autobús). **Almost the same** = casi igual.
W as = igual de (en comparaciones) | as
W same = igual; mismo | seim
W almost = casi | ÓL-most
W realize = darse cuenta | RÍ-a-láis | Falso amigo: no es «realizar» (eso es «carry out»).
W journey = trayecto; viaje | YÉR-ni | Falso amigo: no es «jornada» (eso es «working day»).
W plane = avión | plein
W fast = rápido; rápida | fast
W slow = lento; lenta | slou
W speed = velocidad | spid
W comfortable = cómodo; cómoda | KÁM-for-ta-bol
W tasty = sabroso; rico | TÉI-sti
W distance = distancia | DÍS-tans
V Vocabulario: viajar

  > How long is the journey = ¿cuánto dura el viaje?

  > as comfortable as = igual de cómodo que

  > The plane is very fast = el avión es muy rápido

  > not as expensive = no tan caro | slow = lento

  > realize = darse cuenta

  > tasty = sabrosa
Q ¿Qué significa «as cheap as the bus»?
+ tan barato como el autobús :: As… as = igual de… que.
- más barato que el autobús :: Eso sería «cheaper than».
- el más barato del autobús :: Eso sería superlativo.
Q ¿Cuál es la negación correcta para «No es tan caro como el tren»?
+ It's not as expensive as the train. :: Not as + adjetivo + as.
- It's not more expensive than the train. :: Eso sería «más caro que».
- It's not so expensive than the train. :: Con as… as no va than.
R Almost the same.
+ Casi igual. :: Almost = casi.
- Exactamente diferente. :: Eso sería «different».
- Casi nunca. :: Eso sería «almost never».
H This plane is as ___ as the train. :: Rápido
+ fast :: Igual de rápido: fast no cambia.
- more fast :: Con adjetivos cortos no va more.
- fastest :: Eso es superlativo, no sirve aquí.
H I didn't ___ that! :: Darme cuenta
+ realize :: Darse cuenta.
- realistic :: Eso es «realista».
- reality :: Eso es «realidad».
A The journey is not as slow as the bus.
+ El viaje no es tan lento como el autobús. :: Not as slow as = no tan lento como.
- El viaje es más lento que el autobús. :: Eso sería «slower than».
- El viaje es el más lento. :: Eso sería superlativo.
O It is the same as the bus :: Es igual que el autobús :: The same as = igual que.
X ¿Cómo se dice «darse cuenta» en inglés? :: realize :: No confundir con «realizar», que es «carry out».
