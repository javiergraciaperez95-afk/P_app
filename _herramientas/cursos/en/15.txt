@ 15 | It's more interesting | Comparar con adjetivos largos
I En el A1 comparaste con -er (cheaper, bigger). Ahora, los adjetivos largos y algunas trampas.
E Adjetivos cortos: -er :: Un adjetivo corto forma el comparativo añadiendo **-er**: **cheap** → **cheaper** (más barato). **Than** introduce el segundo elemento: **cheaper than the restaurant** (más barato que el restaurante). En adjetivos monosílabos con una vocal breve entre dos consonantes, se duplica la consonante final: **big** → **bigger**, **hot** → **hotter**. Si terminan en consonante + **y**, la **y** cambia a **i**: **easy** → **easier** (más fácil).
E Adjetivos de dos o más sílabas :: Muchos adjetivos de dos sílabas y la mayoría de los más largos usan **more**: **more careful**, **more interesting**. Pero los que terminan en consonante + **y** suelen cambiar **y** por **i** y añadir **-er**: **busy → busier**, **easy → easier**. Algunos adjetivos de dos sílabas admiten las dos formas: **cleverer / more clever**. :: No combines las dos marcas: **cheaper**, no «more cheaper».
E Falso amigo: interesting :: **Interesting** = interesante (la cosa). **Interested** = interesado (la persona). Por eso se dice **I'm interested in…** (me interesa…).
W interesting = interesante | IN-trest-in | Para cosas. Para personas, «interested».
W interested = interesado; interesada | IN-trest-id
W easy = fácil | Í-si
W easier = más fácil | Í-si-er
W busier = más ocupado; más ocupada | BÍ-zi-er
W clever = listo; inteligente | KLÉ-ver

W hotter = más caliente | JÓ-ter

@ 15 | As cheap as the bus | Igual de… que, no tan… como
I Para decir que dos cosas son iguales o que una no supera a la otra, usamos **as… as**.
E Igual de… que :: **As + adjetivo + as** = igual de…: **as cheap as the bus** (tan barato como el autobús). Se usa un adjetivo sin cambiarlo: **as fast as**, **as comfortable as**. :: No se usa **than** con **as… as**.

W convenient = conveniente | ken-VÍ-ni-ent

V Palabras clave
Q Completa la frase: The train is ___ than the bus.
+ faster :: «Fast» es monosílabo y forma el comparativo con «-er».
- fastest :: «Fastest» es el superlativo; se usa para comparar con un grupo completo.
- more fast :: «Fast» es monosílabo: se dice «faster», no «more fast».
H This route is ___ than the old one. :: Más conveniente
+ more convenient :: Con este adjetivo largo se usa «more + adjetivo».
- more conveniently :: Es un adverbio; aquí hace falta un adjetivo.
- most convenient :: Es el superlativo y requeriría comparar con un grupo.
Q ¿Qué significa «route»?
+ ruta :: Traducción de «route».
- conveniente :: Esa es «convenient».
- más rápido :: Esa es «faster».
R The plane is faster than the train. :: ¿Qué significa?
+ El avión es más rápido que el tren. :: «Faster than» compara el avión con el tren.
- El tren es más rápido que el avión. :: Invierte el sujeto y el elemento con que se compara.
- El avión es el más rápido. :: Eso sería el superlativo.
