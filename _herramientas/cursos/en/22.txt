@ 22 | Phrasal verbs and object position | usar verbos frasales cotidianos
I Practica usar verbos frasales cotidianos con una regla breve y ejemplos claros.
E usar verbos frasales cotidianos :: Muchos verbos frasales separables con objeto permiten poner un sustantivo entre verbo y partícula (**turn the TV off**) o después (**turn off the TV**). Si el objeto es un pronombre, va antes de la partícula: **turn it off**, no **turn off it**. En **look for**, **for** es preposición y no se separa: **look for it**, no **look it for**. :: **Please turn it off before you leave.** = Apágalo antes de irte, por favor.
W turn off = apagar | térn of
w pick up = recoger | pik ap
W look for = buscar | luk for
w off = apagado; apagar
w turn = girar; apagar (en un verbo frasal)
V Palabras clave
Q Completa la frase: Please turn ___ off before you leave.
+ it :: Es la forma que pide esta estructura.
- off it :: Revisa la forma verbal o el orden.
- it off it :: Esta opción no encaja en la frase.
H I can't find my keys. I'm looking ___. :: Completa con «look for» y el pronombre adecuado.
+ for them :: «Look for» no se separa: el pronombre va después de «for».
- them for :: El pronombre no se intercala entre «look» y «for».
- for it :: «Keys» es plural; corresponde «them».
Q En «turn the TV off», ¿qué significa «turn off»?
+ apagar :: Traducción de «turn off».
- recoger :: Esa es «pick up».
- buscar :: Esa es «look for».
R I'm looking for my keys. :: ¿Qué significa?
+ Estoy buscando mis llaves. :: «Look for» significa «buscar»; «my keys» = «mis llaves».
- Estoy mirando mis llaves. :: Eso describe que las miras, no que intentas encontrarlas.
- Estoy buscando mi llave. :: El original dice «keys» en plural.
O Please turn it off before you leave. :: Apágalo antes de irte, por favor. :: Observa el orden de la estructura.
