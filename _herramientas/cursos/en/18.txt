@ 18 | You must wear a helmet | Obligaciones, prohibiciones y reglas
I Hoy hablamos de reglas: qué es obligatorio, qué está prohibido y qué no hace falta. Las tres ideas son distintas.
E Must: obligación :: **Must** + verbo base: obligación fuerte, sobre todo cuando es una regla: **You must wear a helmet** (debes llevar casco). Igual para todas las personas: **I must**, **she must**. :: Muchas veces suena como una orden.
E Mustn't: prohibido :: **Mustn't** = no debes, no se puede: **You mustn't smoke here** (no puedes fumar aquí). Es una prohibición. :: Ojo: **mustn't** no es «no tienes que». Eso es **don't have to**, y lo vemos en la lección siguiente.
E Falso amigo: warn y advise :: **Warn** = advertir, avisar de un peligro. **Advise** = aconsejar (no «advertir»). Por eso: **I must warn you** = debo advertirte.
W must = deber (obligación) | mast
W mustn't = no debes; no se puede | MÁ-sent | Prohibición.
W helmet = casco | JÉL-met
W seatbelt = cinturón de seguridad | SÍT-belt
W rule = regla | rul
W allowed = permitido; permitida | a-LÁUD
W smoke = fumar; humo | smóuk
W warn = advertir; avisar | uorn | Falso amigo: no es «aconsejar» (eso es «advise»).
W drink = beber; bebida | drink
W health = salud | jelz
W exercise = ejercicio; hacer ejercicio | EK-ser-saiz
W sleep = dormir | slip
V Vocabulario: reglas
D En la bici

  > must wear = debemos llevar

  > Why = ¿por qué?

  > the rule = la regla
Pedro: Ok, but you mustn't drink and drive. = Vale, pero no debes beber y conducir.
  > mustn't drink = no debes beber
Liz: I don't drink! = ¡Yo no bebo!
  > don't drink = no bebo
Pedro: You mustn't smoke in the car. = No debes fumar en el coche.
  > mustn't smoke = no debes fumar
Liz: Ok! I must wear my seatbelt too. = ¡Vale! Yo también debo llevar el cinturón.
  > must wear = debo llevar

  > must sleep = debes dormir
Q ¿Qué significa «You mustn't smoke here»?
+ No debes fumar aquí. :: Mustn't = prohibición.
- No tienes que fumar aquí. :: Eso sería «don't have to».
- Puedes fumar aquí. :: Eso sería «can».
Q ¿Qué forma va en «You ___ wear a helmet»?
+ must :: Obligación fuerte: must + verbo base.
- must to :: Con must no va «to».
- musts :: Must no cambia.
R You must sleep.
+ Debes dormir. :: Must = deber, obligación.
- Duermes mucho. :: Eso sería presente.
- Dormirás mucho. :: Eso sería futuro.

- don't :: Esto no es una forma de must.

+ helmet :: Casco de protección.

- rule :: Es la regla.

+ No está permitido. :: Not allowed = no permitido.
- Está permitido. :: Eso sería «allowed».
- Es obligatorio. :: Eso sería «compulsory».
O We must warn them :: Debemos advertirles :: Warn = advertir o avisar.

@ 18 | You don't have to come | Have to, don't have to y should
I Ahora tres formas más: tener que (obligación de fuera), no hace falta, y deberías (consejo).
E Have to: tener que :: **Have to** = tener que, obligación que viene de fuera: **I have to work tomorrow** (tengo que trabajar mañana). :: Con **he**, **she** o **it** es **has to**: **She has to go** (tiene que irse).
E Don't have to: no hace falta :: **Don't have to** = no hace falta, no es necesario: **You don't have to come** (no tienes que venir). :: Ojo: **mustn't** = está prohibido; **don't have to** = puedes, pero no hace falta. Son opuestos.
E Should: consejo :: **Should** + verbo base = deberías: **You should sleep more** (deberías dormir más). Negativa: **shouldn't** = no deberías: **You shouldn't eat so much sugar** (no deberías comer tanto azúcar).
E Falso amigo: advice y advise :: **Advice** = consejo (sustantivo, no tiene plural). **Advise** = aconsejar (verbo). **I need some advice** (necesito un consejo).
W have to = tener que; deber | JAF-tu
W should = deberías; debería | shud
W shouldn't = no deberías | SHÚ-dent
W advise = aconsejar | ad-VÁIS | Falso amigo: no es «advertir» (eso es «warn»).
W advice = consejo | ad-VÁIS | Sustantivo: no tiene plural.
W rest = descansar; resto | rest
W meeting = reunión | MÍ-tin
W junk = basura; comida basura | yank
W tooth = diente | tuz
W afford = permitirse (económicamente) | a-FÓRD | Falso amigo: no es «afortunado».
W quit = dejar (un hábito) | kuit
W check = revisar; mirar | chek
V Vocabulario: obligación y consejo

  > should rest = deberías descansar

  > don't have to come = no tienes que venir
Tom: I'll help you. = Te ayudo.
  > I'll help = te ayudo
Anna: Thanks! What's your advice? = ¡Gracias! ¿Cuál es tu consejo?
  > advice = consejo

  > shouldn't check = no deberías mirar
Anna: Maybe... but I can't quit it! = Quizá... ¡pero no puedo dejarlo!
  > can't quit = no puedo dejarlo
Tom: Then you should sleep more. = Entonces deberías dormir más.
  > should sleep = deberías dormir
Q ¿Qué significa «You don't have to come»?
+ No tienes que venir. :: Don't have to = no hace falta.
- No puedes venir. :: Eso sería «can't».
- No debes venir. :: Eso sería «mustn't», prohibido.
Q ¿Qué significa «You shouldn't eat so much sugar»?
+ No deberías comer tanto azúcar. :: Shouldn't = no deberías, consejo.
- No puedes comer azúcar. :: Eso sería prohibición: «mustn't».
- Debes comer azúcar. :: Eso sería «must».
R I have to work today.
+ Tengo que trabajar hoy. :: Have to = tener que.
- Puedo trabajar hoy. :: Eso sería «can».
- Trabajaré hoy. :: Eso sería futuro.
H You ___ rest a little. :: Deberías
+ should :: Consejo: should + verbo base.
- shouldn't :: Eso es no deber.
- don't :: No es la forma de un consejo.
H You ___ have to come. :: No hace falta
+ don't :: Don't have to = no hace falta.
- mustn't :: Eso es prohibición.
- shouldn't :: Eso es consejo negativo.

+ Tengo que irme ahora. :: Have to go = tener que irse.
- Puedo irme ahora. :: Eso sería «can».
- No tengo que irme. :: Eso sería «don't have to».
O I need some advice :: Necesito un consejo :: Advice no tiene plural.
