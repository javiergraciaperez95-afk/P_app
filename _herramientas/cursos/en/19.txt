@ 19 | If it rains, we'll stay home | Primer condicional: si pasa esto, pasará aquello
I Para decir qué pasará si ocurre algo posible. Es una de las estructuras más útiles del A2.
E La fórmula :: **If** + presente, **will** + verbo base: **If it rains, we'll stay home** (si llueve, nos quedaremos en casa). La parte con **if** va en presente, aunque la idea sea del futuro. :: Puedes cambiar el orden: **We'll stay home if it rains**. Si la parte con **if** va primero, se pone coma; si va después, no.
E Cuándo se usa :: Para algo posible o probable en el futuro: **If you study, you'll pass** (si estudias, aprobarás). No se usa para cosas imposibles o muy hipotéticas; eso es otro tema.
E Falso amigo: hope :: **Hope** = esperar, desear que algo pase. **I hope you pass** = espero que apruebes. No es «esperar» en el sentido de aguardar (eso es **wait**).
W if = si (condición) | if | No confundir con «sí», que es «yes».
W unless = a menos que | an-LES
W home = casa; hogar | joum
W pass = aprobar; pasar | pas
W hope = esperar (desear) | joup | Falso amigo: no es «esperar» en el sentido de aguardar (eso es «wait»).
W wish = desear | uish
W lose = perder | luz
W win = ganar | uin
W invite = invitar | in-VÁIT
W result = resultado | ri-SÓLT
W rich = rico; rica | rich
W game = partido; juego | geim
V Vocabulario: si y el futuro
D Si llueve…
Julia: If it rains, we'll stay home. = Si llueve, nos quedaremos en casa.
  > If it rains = si llueve | we'll stay = nos quedaremos
Tom: And if it's sunny? = ¿Y si hace sol?
  > if it's sunny = si hace sol
Julia: We'll go to the park. = Iremos al parque.
  > We'll go = iremos
Tom: I'll invite my friends, unless you hate them! = Invitaré a mis amigos, a menos que los odies.
  > unless = a menos que | I'll invite = invitaré
Julia: I won't hate them. = No los odiaré.
  > won't hate = no odiaré
Tom: If you pass the exam, we'll celebrate. = Si apruebas el examen, celebraremos.
  > If you pass = si apruebas
Julia: I hope I pass! = ¡Espero aprobar!
  > I hope = espero (desear)
Tom: You will! = ¡Aprobarás!
  > You will = aprobarás
Q ¿Qué tiempo va en la parte con «if» en «If it rains, we'll stay home»?
+ presente :: Con if, el presente habla del futuro.
- futuro :: Con if no va will.
- pasado :: Eso sería «if it had rained».
Q ¿Qué significa «If you study, you'll pass»?
+ Si estudias, aprobarás. :: If + presente, will + verbo.
- Si estudiaste, aprobaste. :: Eso sería pasado.
- Si estudiarás, aprobarás. :: Con if no va will.
R I hope you pass the exam.
+ Espero que apruebes el examen. :: Hope = esperar (desear).
- Espero el examen. :: Eso sería «wait for».
- Apruebas el examen. :: Eso sería presente.
H If it rains, we ___ stay home. :: Nos quedaremos
+ will :: Will + verbo base en la parte principal.
- would :: Eso no es el futuro normal.
- are :: Eso es presente.
H We'll stay home ___ it rains. :: Si
+ if :: Si: condición.
- so :: Así que: resultado.
- but :: Pero: contraste.
A If it rains, I'll stay.
+ Si llueve, me quedaré. :: If + presente, will.
- Si llovió, me quedé. :: Eso sería pasado.
- Si llueve, me iré. :: Eso sería «I'll go».
O We'll win the game if we play :: Ganaremos el partido si jugamos :: If + presente: la parte con if va en presente.
X ¿Cómo se dice «a menos que» en inglés? :: unless :: Unless = if not: «a menos que».

@ 19 | Because it's late | Conectores: because, so, but, also
I Para unir ideas: por qué pasa algo (**because**), qué pasa como consecuencia (**so**) y un contraste (**but**).
E Because: porque (causa) :: **Because** + frase explica la causa: **I'm tired because I work a lot** (estoy cansada porque trabajo mucho). También puede ir al principio: **Because I work a lot, I'm tired**.
E So: así que (consecuencia) :: **So** introduce el resultado: **It rained, so we stayed home** (llovió, así que nos quedamos en casa). :: No uses **because** y **so** a la vez para la misma idea.
E But: pero (contraste) :: **But** une dos ideas que se oponen: **I'm tired, but I'm happy** (estoy cansada, pero contenta).
E Falso amigo: also :: **Also** = también, además. Aquí «además» es parecido a **also**, pero «aparte de» es **besides**.
W also = también; además | ÓL-so
W traffic = tráfico | TRÁ-fik
W jam = atasco | yam
W delay = retraso | di-LÉI
W cancelled = cancelado; cancelada | CÁN-sild
W lucky = afortunado; afortunada | LÁ-ki | Falso amigo: no es «lúcido» (eso es «lucid»).
W rush = prisa | rash
W mood = humor; estado de ánimo | mud
W huge = enorme | jiúy
W crowd = multitud; gente | craud
W dream = sueño; soñar | drim
V Vocabulario: razones y conectores
D En la estación
Anna: Why are you late? = ¿Por qué llegas tarde?
  > Why are you late = ¿por qué llegas tarde?
Tom: Because the train was cancelled! = ¡Porque cancelaron el tren!
  > because = porque | was cancelled = cancelaron
Anna: Bad! So we'll walk. = ¡Qué mal! Así que iremos andando.
  > So we'll walk = así que iremos andando
Tom: There is a lot of traffic, but the bus is fast. = Hay mucho tráfico, pero el autobús es rápido.
  > traffic = tráfico | but = pero
Anna: I'm lucky, I'm not tired! = ¡Tengo suerte, no estoy cansada!
  > lucky = afortunada
Tom: Also, there is a huge crowd. = Además, hay una multitud enorme.
  > Also = además | huge = enorme
Anna: The delay is not long. = El retraso no es largo.
  > delay = retraso
Tom: Let's go! I'm in a rush. = ¡Vamos! Tengo prisa.
  > in a rush = con prisa
Q ¿Qué significa «Because it's late, I'm tired»?
+ Estoy cansada porque es tarde. :: Because = porque: causa.
- Estoy cansada, pero es tarde. :: Eso sería «but».
- Estoy cansada, así que es tarde. :: Eso sería «so», mal usado.
Q ¿Qué conector va en «It rained, ___ we stayed home»?
+ so :: So = así que: consecuencia.
- but :: But = pero: contraste.
- because :: Because explica la causa, no la consecuencia.
R I'm lucky, because I have a good job.
+ Tengo suerte, porque tengo un buen trabajo. :: Because = porque.
- Soy lúcida, porque tengo un buen trabajo. :: Eso sería «lucid».
- Tengo suerte, pero no tengo trabajo. :: Eso sería «but».
H The bus is late ___ there is a lot of traffic. :: Porque
+ because :: Causa: por qué llega tarde.
- but :: Contraste.
- so :: Consecuencia.
H I'm tired, ___ I'm happy. :: Pero
+ but :: Contraste: cansada, pero contenta.
- because :: Causa.
- so :: Consecuencia.
A It's a huge crowd.
+ Es una multitud enorme. :: Huge = enorme; crowd = multitud.
- Es un grupo pequeño. :: Eso sería «small group».
- Es una fiesta enorme. :: Eso sería «party».
O I'm in a rush :: Tengo prisa :: In a rush = con prisa.
X ¿Cómo se dice «así que» (consecuencia) en inglés? :: so :: Ojo: so no es «sólo», que es «only».

@ 19 | If I don't sleep, I feel tired | Hechos generales: el condicional cero
I El condicional cero describe hechos, reglas o resultados que suelen ser siempre ciertos. La forma más común usa presente en las dos partes.
E La estructura :: **If + presente simple, presente simple**: **If I don't sleep well, I feel tired** (si no duermo bien, me siento cansado). También puedes usar **when**: **When it rains, I take an umbrella** (cuando llueve, cojo un paraguas).
E Cero o primer condicional :: Usa el cero para un hábito o resultado general: **If it's cold, I wear a coat**. Usa el primero para una posibilidad futura concreta: **If it rains tomorrow, we'll stay home**.
W tired = cansado; cansada | táierd
W happens = pasa; ocurre | JÁ-penz
W ground = suelo; terreno | graund
W gets = se pone; se vuelve | gets
V Vocabulario: hechos y resultados
D Hábitos cotidianos
Teacher: What happens if you don't sleep well? = ¿Qué pasa si no duermes bien?
  > don't sleep well = no duermes bien
Maya: If I don't sleep well, I feel tired. = Si no duermo bien, me siento cansada.
  > I feel tired = me siento cansada
Teacher: What do you do when it rains? = ¿Qué haces cuando llueve?
  > when it rains = cuando llueve
Maya: I take an umbrella. = Cojo un paraguas.
  > take an umbrella = coger un paraguas
Teacher: And what do you wear if it's cold? = ¿Y qué te pones si hace frío?
  > if it's cold = si hace frío
Maya: I wear a coat. = Me pongo un abrigo.
  > wear a coat = ponerse un abrigo
Q ¿Qué estructura se usa para una regla general?
+ If + presente, presente. :: El condicional cero expresa hechos generales.
- If + pasado, would. :: Esa forma expresa una situación hipotética.
- If + presente, will siempre. :: Es más habitual para una posibilidad futura concreta.
Q ¿Cuál expresa una regla o hábito?
+ If I don't sleep well, I feel tired. :: Describe un resultado habitual.
- If it rains tomorrow, we'll stay home. :: Es un plan futuro concreto: primer condicional.
- If I won, I'd travel. :: Es una situación hipotética.
R I take an umbrella when it rains.
+ Cojo un paraguas cuando llueve. :: Presente para hábito general.
- Cogí un paraguas ayer. :: Eso sería pasado.
- Cogeré un paraguas mañana. :: Eso sería futuro.
H If it's cold, I ___ a coat. :: Me pongo
+ wear :: Presente simple en las dos partes.
- wore :: Es pasado.
- will wear :: Aquí describe un hábito, no una decisión futura puntual.
H When I don't sleep well, I ___ tired. :: Me siento
+ feel :: Presente simple para el resultado habitual.
- will feel :: No es una consecuencia futura puntual.
- felt :: Eso es pasado.
A If it rains, I take an umbrella.
+ Si llueve, cojo un paraguas. :: Describe un resultado habitual.
- Si llovió, cogí un paraguas. :: Eso sería pasado.
- Si llueve mañana, me quedaré en casa. :: Ese ejemplo usa el primer condicional.
O If I don't sleep well, I feel tired :: Si no duermo bien, me siento cansada :: Condicional cero: presente en ambas partes.
X ¿Cómo se dice «me pongo un abrigo» en inglés? :: I wear a coat :: Wear = llevar puesto; ponerse.
