- Return a towel. :: Esa condición se refiere a pedir prestada la toalla.
- Pack a swimsuit. :: La piscina determina si la llevará.
Q Which phrase is the more formal way to introduce a necessary condition?
+ provided that :: Es la opción más formal de las dos formas condicionales aquí.
- as long as :: También introduce una condición, pero suele sonar más cotidiano.
- in case :: Introduce una precaución ante una posibilidad.
R You may borrow a towel as long as you return it. :: ¿Qué significa?
+ Puedes pedir prestada una toalla siempre que la devuelvas. :: **As long as** expresa aquí la condición para pedirla.
- Puedes pedir prestada una toalla por si la devuelves. :: **In case** expresa una precaución, no este requisito.
- Puedes pedir prestada una toalla aunque la devuelvas. :: **Although** expresaría contraste.
Q Which sentence says that someone prepares now for a possible future need?
+ I'll take cash in case we need it. :: **In case** presenta la preparación ante una posibilidad.
- I'll take cash if we need it. :: Aquí tomaré el dinero solo si se da esa condición.
- I'll take cash provided that we need it. :: Aquí la necesidad se presenta como requisito, no como precaución anticipada.
