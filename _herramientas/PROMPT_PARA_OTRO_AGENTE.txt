EL MODELO v2 (leer esto dos veces)
----------------------------------
Cada lección son TRECE archivos:

  1 esqueleto:   Idiomas/cursos/es/lessons/NNN.json
  12 catálogos:  Idiomas/cursos/es/traducciones/<idioma>/NNN.json

Los 12 idiomas, siempre los mismos, sin excepción:
  en es vi zh pt fr ja it ko ru de id

REGLA DE ORO: el esqueleto NO lleva ni una frase de texto. Ni título, ni intro,
ni explicaciones, ni frases de diálogo. Solo estructura. Todo el texto está en
los 12 catálogos, y los 12 llevan EXACTAMENTE las mismas claves.

Ojo: en el curso de español, la carpeta traducciones/es/ NO es una copia del
esqueleto. Es el catálogo del español, con el mismo papel que los demás.

PASO 1 — ESCRIBE EL ESQUELETO
-----------------------------
Archivo: Idiomas/cursos/es/lessons/NNN.json

{
  "esquema": 2,
  "id": "NNN",
  "capitulo": 2,                 ← el del v1 que sustituyes
  "nivel": "A1",                 ← debe coincidir con el de capitulos.json
  "palabras": {
    "el libro":  { "pron": "el LI-bro", "cat": "sust", "genero": "m" },
    "grande":    { "pron": "GRAN-de", "cat": "adj" },
    "hola":      { "pron": "O-la", "cat": "interj" },
    "Ana":       { "propio": true }
  },
  "bloques": [
    { "id": "b1", "tipo": "explicacion" },
    { "id": "b2", "tipo": "dialogo", "frases": [
        { "quien": "Lucía", "sintaxis": { … } },
        { "quien": "Pablo", "sintaxis": { … } } ] },
    { "id": "b3", "tipo": "vocabulario", "palabras": ["el libro", "grande"] },
    { "id": "b4", "tipo": "gramatica", "ejemplos": [ { "sintaxis": { … } } ] },
    { "id": "b5", "tipo": "texto", "registro": "literario", "parrafos": [0, 1] },
    { "id": "b6", "tipo": "test",    "opciones": [ {"correcta": true}, {"correcta": false}, {"correcta": false} ] },
    { "id": "b7", "tipo": "huecos",  "opciones": [ … igual … ] },
    { "id": "b8", "tipo": "ordenar" },
    { "id": "b9", "tipo": "escribir", "respuestas": ["El problema es grande"] }
  ]
}

Detalles que se comprueban:
- "palabras": toda palabra no propia lleva "pron" (sílaba tónica en MAYÚSCULAS)
  y "cat". Si cat es "sust", hace falta "genero" (m, f, m/f o f/m).
  Los nombres propios llevan SOLO { "propio": true }.
- "cat" es un código, no texto: sust adj verb adv pron prep conj art num interj
  expr frase propio.
- Los 5 primeros bloques son obligatorios y en ese orden exacto:
  b1 explicacion, b2 dialogo, b3 vocabulario, b4 gramatica, b5 texto.
  Después, de b6 en adelante, solo ejercicios (test, huecos, ordenar, escribir).
- b5 lleva "registro": "literario" y "parrafos": [0, 1] (son índices, el texto
  está en las traducciones).
- Los ejercicios test y huecos NO llevan "texto" en las opciones: solo
  { "correcta": true/false }.
- "respuestas" del ejercicio escribir SÍ va en el esqueleto, y en español.

EL ANÁLISIS SINTÁCTICO (lo más delicado)
----------------------------------------
Cada frase de diálogo y cada ejemplo de gramática lleva "sintaxis":

  "sintaxis": {
    "oracion": "bimembre",          o "unimembre"
    "sujeto": "omitido",            "expreso" u "omitido" (solo si bimembre)
    "unidades": [                   nivel 1
      { "funcion": "PRED", "texto": "Soy de España", "nucleo": "Soy",
        "partes": [                 nivel 2
          { "funcion": "V", "texto": "Soy", "nucleo": "Soy" },
          { "funcion": "ATRIB", "texto": "de España", "nucleo": "España",
            "partes": [             nivel 3
              { "funcion": "PREP", "texto": "de" },
              { "funcion": "TERM", "texto": "España", "nucleo": "España" } ] } ] } ]
  }

Se comprueba automáticamente, y falla si no se cumple:
- las unidades de CADA nivel, en orden, reconstruyen el texto del nivel
  superior, ignorando puntuación y mayúsculas;
- "funcion" pertenece al catálogo (ver lista abajo);
- "nucleo" aparece dentro de su "texto";
- bimembre + expreso → exactamente una unidad SUJ;
- bimembre + omitido → ninguna unidad SUJ;
- exactamente una unidad PRED;
- unimembre → no puede haber SUJ ni PRED;
- una unidad V no se descompone (su núcleo es el verbo, sin "partes").

Catálogo de funciones:
  SUJ PRED VOC INTERJ NEG CONJ
  V CD CI ATRIB CPVO CRV CAG
  CCL CCT CCM CCF CCC CCA CCINSTR CCCOMP
  N DET ADY CN APOS PREP TERM ADV PRON CUANT INF GER PART AUX

Trucos que me ahorraron horas:
- La negación («No»), el adverbio de afirmación («Sí») y las conjunciones
  («y», «pero») van DENTRO del PRED, como "partes", no como unidad de nivel 1.
- Una frase unimembre con nexo y vocativo («¿Y la mesa?») se modela como una
  sola unidad VOC cuyo "texto" es la frase entera, con CONJ y N en "partes".
- Si separas una frase en dos (por ejemplo el final de un diálogo), cada trozo
  tiene que reconstruirse con SUS unidades. Comprueba que la unión coincide.
- Escríbelo y valida: el validador te dice exactamente qué nivel no cuadra.


PASO 2 — EL CATÁLOGO ESPAÑOL (la fuente)
----------------------------------------
Archivo: Idiomas/cursos/es/traducciones/es/NNN.json

Primero pide las claves exactas:

  node _herramientas/validar_v2.mjs es NNN --claves

Devuelve un JSON con dos listas: "de_estudio" y "de_ayuda". Los 12 catálogos
llevan TODAS las claves de las dos listas. Ni una más, ni una menos.

Hay dos clases de clave:

DE ESTUDIO (la frase en ese idioma):
  b2.f<n>.texto   cada frase del diálogo (n empieza en 0)
  b4.e<n>.texto   cada ejemplo de gramática
  b5.p<n>         cada párrafo del texto literario
  b6.o<n>         el texto de cada opción de un ejercicio
  b7.frase        la frase del hueco o del ejercicio de ordenar

DE AYUDA (la explicación para el alumno):
  titulo, intro
  b<n>.titulo            título del bloque
  b<n>.texto             explicación (b1) y gramática (b4)
  b<n>.pregunta          enunciado del ejercicio
  b<n>.traduccion        traducción de la frase de «ordenar»
  b<n>.o<n>.refuerzo     por qué cada opción está bien o mal
  p.<palabra>.glosa      significado de la palabra, muy breve
  p.<palabra>.consejo    la explicación de la tutora al pulsar «?», máx. 160 caracteres

Formato del archivo:

{
  "idioma": "es",
  "leccion": "NNN",
  "titulo": "…",
  "intro": "…",
  "b1.titulo": "…",
  "b1.texto": "…",
  "b2.f0.texto": "…",
  …
}

Plano, clave → texto. Sin objetos anidados, sin listas.

En el catálogo del idioma del curso (es/, en el curso de español) las claves de
estudio llevan el texto español TAL CUAL, y las de ayuda también van en español.


PASO 3 — LOS OTROS 11 CATÁLOGOS
-------------------------------
Para cada idioma de en vi zh pt fr ja it ko ru de id, crea
Idiomas/cursos/es/traducciones/<idioma>/NNN.json con las mismas claves.

Guía de traducción:
- Registro claro y cercano, nivel A1. Traduce con naturalidad, no palabra por
  palabra.
- Las claves de_estudio se traducen al idioma de destino.
- Las claves de_ayuda también se traducen al idioma de destino.
- DENTRO de una explicación, las palabras españolas que se enseñan SE QUEDAN EN
  ESPAÑOL: «el mapa es masculino aunque acabe en -a». Se traduce el comentario,
  no el ejemplo.
- p.<palabra>.glosa: el significado, 2-6 palabras.
- p.<palabra>.consejo: máximo 160 caracteres.
- Conserva el Markdown: **negrita**, guiones de lista, saltos de línea \n.
- No cambies las comillas tipográficas «» ni las comillas rectas del JSON.

CONTENIDO (no negociable):
- Apolítico y neutro. Nada de partidos, gobiernos, elecciones, conflictos,
  religión, ni juicios sobre grupos de personas.
- Nada sexista, racista ni homófobo.
- Ejercicios pensados para TDAH: una sola decisión por bloque, enunciado de 15
  palabras como máximo, 3 o 4 opciones, y un «refuerzo» por opción.
- El texto literario son dos párrafos de verdad, de 120 caracteres útiles cada
  uno como mínimo (un carácter chino o japonés cuenta doble).

PASO 5 — COMPROBAR QUE LAS TRADUCCIONES SON DE VERDAD
-----------------------------------------------------
El validador comprueba que las claves existen y no están vacías, pero NO
detecta que una traducción sea una copia del español. Eso pasó de verdad: un
agente tradujo las explicaciones al indonesio y dejó el diálogo entero en
español, y el validador dijo «Todo correcto».

Antes de dar por buena la lección, ejecuta esto y corrige lo que salga:

--- guardar como tmp_no_copiado.mjs y ejecutar: node tmp_no_copiado.mjs NNN
import { readFileSync } from 'node:fs';
const IDIOMAS = ['en','vi','zh','pt','fr','ja','it','ko','ru','de','id'];
const id = process.argv[2];
const es = JSON.parse(readFileSync(`Idiomas/cursos/es/traducciones/es/${id}.json`,'utf8'));
// Claves que PUEDEN coincidir con el español y es correcto que coincidan:
// el texto de una opción, la frase que se estudia, y la glosa de un artículo
// o de una palabra española (en italiano «Completa», en portugués «grande»).
const puedeCoincidir = k => /^b\d+\.o\d+$/.test(k) || /^p\..*\.glosa$/.test(k);
for (const idioma of IDIOMAS) {
  const t = JSON.parse(readFileSync(`Idiomas/cursos/es/traducciones/${idioma}/${id}.json`,'utf8'));
  const iguales = Object.keys(t).filter(k =>
    !['idioma','leccion'].includes(k) && t[k] === es[k] && !puedeCoincidir(k));
  if (iguales.length) console.log(idioma, '→', iguales.join(', '));
}
---

Ojo con los falsos positivos: «grande» en portugués e italiano, o «Completa» en
italiano, se escriben igual que en español y es correcto. Míralos uno a uno
antes de cambiarlos.

Y revisa a mano estas cuatro cosas, que es donde fallaron los agentes:
1. b2.f*.texto  → el diálogo COMPLETO traducido. Es el fallo más frecuente.
2. b<n>.titulo  → los títulos de bloque. A veces se quedan en español.
3. p.*.glosa    → el significado de cada palabra. A veces se queda en español.
4. Palabras inventadas: mezclas de español y el idioma de destino.
   Pasó con «los livros» en portugués (correcto: «os livros»).

globalThis.addEventListener = () => {};

Requisitos: «avisos: 0», «texto literario: 2 párrafos» y que la traducción
salga en el idioma pedido.

DOS COSAS QUE PARECEN FALLOS Y NO LO SON:
1. Con la interfaz en «es» y el curso de español, las traducciones salen en
   INGLÉS. Es a propósito: el inglés es el idioma pivote cuando interfaz y
   curso coinciden (así lo hace tr() en i18n.js desde siempre). No lo «arregles».
2. El bloque de texto literario aparece como «dialogo» con la marca esTexto:
   es así como lo deja el adaptador. Busca por b.esTexto, no por tipo === 'texto'.

Hazlo al menos con «es» y con dos idiomas más (por ejemplo «en» y «ja»). Para
«es» comprueba que salen 2 párrafos y 0 avisos; para los demás, que la
traducción está en ese idioma.


CÓMO CORREGIR ERRORES DEL ESQUELETO SIN ROMPER NADA
---------------------------------------------------
- Un error de sintaxis se arregla SIEMPRE en el esqueleto (NNN.json), no en los
  catálogos. Los catálogos solo llevan texto.
- Si cambias un "id" de bloque, cambian TODAS las claves de ese bloque en los 12
  catálogos. Casi nunca merece la pena: deja los ids como están.
- Si añades o quitas un bloque, hay que recalcular las claves con --claves y
  tocar los 12 catálogos.
- Comprueba la sintaxis del código solo si tocas algún .js:
    Copy-Item Idiomas\js\lessons.js _c.mjs ; node --check _c.mjs ; Remove-Item _c.mjs
  (node --check no acepta .js sueltos con import/export; cópialo a .mjs).
