E Test 47 :: Repaso del capítulo 47: la oficina; **reuniones** (đề nghị, kiến nghị, biểu quyết, thông qua, phân công), **presentaciones y gráficos** (như quý vị thấy, tăng đều, đạt đỉnh, chạm đáy), **correos formales** (xin vui lòng, rất mong, trân trọng) y **solicitudes** (căn cứ, kính đề nghị, kính mong).
Q «biên bản» es…
+ el acta :: Nhờ Minh ghi biên bản giúp.
- el gráfico :: Es «biểu đồ».
- el borrador :: Es «bản thảo».
- la cláusula :: Es «điều khoản».
Q «tiến độ» es…
+ el ritmo de avance :: Dự án đang chậm tiến độ.
- el plazo :: Es «thời hạn».
- el presupuesto :: Es «báo giá».
- el cargo :: Es «chức vụ».
Q «chạm đáy» es lo contrario de…
+ đạt đỉnh :: chạm đáy = tocar fondo; đạt đỉnh = alcanzar el máximo.
- dao động :: Es «oscilar».
- giữ ổn định :: Es «mantenerse estable».
- tăng đều :: Es «subir de forma constante».
Q «phản hồi» es…
+ respuesta :: Rất mong nhận được phản hồi của chị.
- firma :: Es «chữ ký».
- cita :: Es «lịch hẹn».
- molestia :: Es «sự bất tiện».
Q En una reunión, ¿con qué verbo eleva un empleado una petición a su jefa?
+ kiến nghị :: Tôi xin kiến nghị…
- phân công :: Eso lo hace la jefa.
- thông qua :: Es aprobar.
- chủ trì :: Es presidir.
Q ¿Qué frase abre una presentación?
+ Hôm nay tôi xin trình bày về kết quả kinh doanh. :: Hôm nay tôi xin trình bày về…
- Tôi xin kết thúc ở đây. :: Cierra.
- Quý vị có câu hỏi nào không? :: Va al final.
- Chúng ta thống nhất như vậy nhé. :: Es de reunión.
Q ¿Cómo se cierra un correo formal?
+ Trân trọng, :: Atentamente.
- Thân, :: Es entre amigos.
- Hẹn gặp lại nhé! :: Es informal.
- Chào cậu, :: Es informal.
H Sau khi thảo luận, đề xuất đã được ___ với đa số phiếu. :: «aprobada»
+ thông qua :: được thông qua.
- phân công :: No.
- trình bày :: No.
- dao động :: No.
H Như quý vị thấy trên ___, doanh số tăng đều trong ba năm. :: «en el gráfico»
+ biểu đồ :: trên biểu đồ.
- biên bản :: Es el acta.
- bản thảo :: Es el borrador.
- đơn :: Es la solicitud.
H Doanh số ___ từ mười lăm tỷ xuống mười tỷ. :: «baja de… a…»
+ giảm :: giảm từ… xuống…
- tăng :: Con «xuống» no puede subir.
- đạt đỉnh :: No.
- giữ ổn định :: No.
H Xin ___ gửi lại hợp đồng trước thứ sáu. :: La fórmula de ruego
+ vui lòng :: xin vui lòng + verbo.
- thông cảm :: Es «disculpe».
- cam kết :: Es «comprometerse».
- phát biểu :: No.
H ___ vào luật lao động, người lao động được nghỉ mười hai ngày phép mỗi năm. :: «Con arreglo a»
+ Căn cứ :: căn cứ vào + norma.
- Kính mong :: No.
- Trân trọng :: No.
- Tiếp theo :: No.
R Tôi phân công chị Hoa phụ trách việc liên hệ với khách hàng.
+ Encargo a Hoa que se ocupe del contacto con los clientes. :: phân công + persona + phụ trách + tarea.
- Hoa me encarga los clientes. :: Al revés.
- Hoa no quiere a los clientes. :: No.
- Los clientes eligen a Hoa. :: No.
R Chúng tôi xin phép dời lịch hẹn sang tuần sau.
+ Le pedimos permiso para pasar la cita a la semana que viene. :: dời lịch hẹn = cambiar la fecha.
- Cancelamos la cita. :: «dời» es aplazar, no cancelar.
- La cita es hoy. :: No.
- Queremos adelantar la cita. :: La pasan a más adelante.
R Kính đề nghị quý khách không hút thuốc trong tòa nhà.
+ Se ruega a los señores clientes que no fumen en el edificio. :: kính đề nghị = se ruega (formal, de cartel).
- Se invita a fumar en el edificio. :: Al contrario.
- Los clientes proponen no fumar. :: No.
- No hay clientes en el edificio. :: No.
Q ¿Qué partes tiene un informe (báo cáo), según la lección?
+ Objeto, situación, resultados, dificultades y propuestas. :: mục đích, tình hình, kết quả, khó khăn, đề xuất.
- Saludo, chiste y despedida. :: No.
- Solo cifras. :: No.
- Título y firma. :: Falta todo lo demás.
Q ¿Cuál de estas frases NO pertenece a un correo formal?
+ Anh gửi giúp em nhé! :: «nhé» es de conversación.
- Xin vui lòng xem tệp đính kèm. :: Es formal.
- Rất mong nhận được phản hồi của anh. :: Es formal.
- Xin chân thành cảm ơn. :: Es formal.
