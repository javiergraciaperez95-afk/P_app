@ 30 | Bài 30 · Kiểm tra 30 | Lección 30: test de repaso
E Test 30 :: Repaso del capítulo 30: viajar y contarlo; **ra, vào, lên, xuống, về, sang** según el mapa, adjetivo + **ra / lên / đi / lại**, **đã từng / chưa từng**, **hồi / lúc / khi** y **đang… thì…, vừa… thì…, trong khi, sau khi**.
Q Desde Saigón, vas a Hanói. ¿Qué dices?
+ Tôi ra Hà Nội. :: Hacia el norte: ra.
- Tôi vào Hà Nội. :: «vào» es hacia el sur.
- Tôi xuống Hà Nội. :: «xuống» es bajar.
- Tôi sang Hà Nội. :: «sang» es a otro país.
Q Desde Hanói, vas a la montaña, a Sa Pa. ¿Qué dices?
+ Tôi lên Sa Pa. :: A la montaña: lên.
- Tôi xuống Sa Pa. :: Es bajar.
- Tôi vào Sa Pa. :: Es hacia el sur.
- Tôi về Sa Pa. :: Solo si es tu casa.
Q «thung lũng» es…
+ valle :: một bản làng trong thung lũng.
- cumbre :: Es «đỉnh núi».
- cascada :: Es «thác».
- cueva :: Es «hang».
Q «hạ cánh» es lo contrario de…
+ cất cánh :: cất cánh = despegar; hạ cánh = aterrizar.
- khởi hành :: Es «salir de viaje».
- thất lạc :: Es «extraviarse».
- xếp hàng :: Es «hacer cola».
H Nghỉ hè xong, em bé cao ___ nhiều. :: Un cambio a más
+ lên :: cao lên = crecer, hacerse más alto.
- đi :: «đi» es para cambios a menos.
- lại :: «lại» es encogerse.
- về :: No.
H Sau khi bị ốm, bà ấy gầy ___ trông thấy. :: Un cambio a menos
+ đi :: gầy đi = adelgazar.
- ra :: «ra» es a más: béo ra.
- lên :: Es a más.
- sang :: No.
H Tôi ___ từng ăn món này bao giờ. Hôm nay là lần đầu tiên. :: «Nunca hasta hoy»
+ chưa :: chưa từng… bao giờ = nunca.
- đã :: «đã từng» sería «alguna vez sí».
- sẽ :: Es futuro.
- đang :: No.
H Tôi đang nấu cơm ___ có người gõ cửa. :: Una cosa corta a la otra
+ thì :: đang A thì B.
- nên :: Es «por eso».
- nhưng :: Es «pero».
- hoặc :: Es «o».
R Hồi tôi còn là sinh viên, tôi thường đi phượt.
+ Cuando era estudiante, solía viajar por libre. :: hồi = una época del pasado.
- Cuando sea estudiante, viajaré por libre. :: «hồi» solo mira al pasado.
- Ayer, a la hora de clase, me fui de viaje. :: No es un momento concreto.
- Nunca viajé de estudiante. :: Al contrario.
R Trong khi tôi xếp hàng, vợ tôi đi đổi tiền.
+ Mientras yo hacía cola, mi mujer fue a cambiar dinero. :: trong khi = mientras.
- Después de hacer cola, cambié dinero. :: No: las dos cosas pasan a la vez.
- Mi mujer hizo cola por mí. :: No.
- Antes de hacer cola, cambiamos dinero. :: No.
R Tôi vừa đến nơi thì trời tối.
+ Nada más llegar, se hizo de noche. :: vừa A thì B.
- Llegué cuando ya era de noche desde hacía horas. :: No: fue justo al llegar.
- Llegaré antes de que anochezca. :: No es futuro.
- No llegué porque era de noche. :: No.
Q ¿Cómo preguntas «¿Has estado alguna vez en Huế?»?
+ Anh đã bao giờ đi Huế chưa? :: đã bao giờ… chưa?
- Anh bao giờ đi Huế? :: Eso es «¿cuándo vas a Huế?».
- Anh đi Huế không? :: Eso es «¿vas a Huế?».
- Anh từng Huế chưa? :: Falta el verbo.
Q ¿Qué frase dice que los precios han subido?
+ Giá cả tăng lên nhiều. :: tăng lên = subir.
- Giá cả giảm đi nhiều. :: Es «han bajado».
- Giá cả vẫn thế. :: «Siguen igual».
- Giá cả chậm lại. :: No se dice de los precios.
A Chủ nhà rất nhiệt tình, họ mời chúng tôi ở lại ăn cơm.
+ Los anfitriones se volcaron: nos invitaron a quedarnos a comer. :: nhiệt tình = entusiasta; ở lại = quedarse.
- Los dueños nos echaron de la casa. :: Al contrario.
- Invitamos a los dueños a comer. :: Está al revés.
- Los dueños no estaban en casa. :: No.
A Đường trơn nên tôi bị trượt chân mấy lần.
+ El camino resbalaba y me caí varias veces. :: trơn = resbaladizo; trượt chân = resbalar.
- El camino era largo y me cansé mucho. :: No.
- Me perdí varias veces. :: Sería «lạc đường».
- El camino estaba cerrado. :: No.
O Anh đã bao giờ đi Sa Pa chưa? :: ¿Has estado alguna vez en Sa Pa? :: đã bao giờ… chưa?
O Trông chị trẻ ra nhiều. :: Se te ve mucho más joven. :: trẻ ra = rejuvenecer.
