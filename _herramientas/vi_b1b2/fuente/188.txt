@ 34 | Bài 34 · Kiểm tra 34 | Lección 34: test de repaso
E Test 34 :: Repaso del capítulo 34: cine, libros y música; contar lo que dijo otro con **rằng / là, bảo, hỏi… có… không**, el **mà** que une un nombre con su explicación, **nghe nói** y **theo**, **đã… lại còn…** y **chẳng**.
Q «đạo diễn» es…
+ director de cine :: Người mà tôi gặp hôm qua là đạo diễn.
- actor :: Es «diễn viên».
- autor :: Es «tác giả».
- espectador :: Es «khán giả».
Q «cốt truyện» es…
+ el argumento :: Cốt truyện dựa trên câu chuyện có thật.
- la portada :: Es «bìa».
- el capítulo :: Es «chương».
- la banda sonora :: Es «nhạc phim».
Q «bán chạy» quiere decir que un libro…
+ se vende mucho. :: Cuốn nào của ông ấy cũng bán chạy.
- está agotado. :: Sería «hết».
- es muy barato. :: No.
- está prohibido. :: No.
Q «vỗ tay» es…
+ aplaudir :: Khán giả vỗ tay rất lâu.
- cantar a coro :: Es «hát theo».
- emocionarse :: Es «xúc động».
- tocar el tambor :: Es «đánh trống».
Q Nam dice: «Tôi sẽ đến muộn.» ¿Cómo lo cuentas?
+ Nam nói là anh ấy sẽ đến muộn. :: Solo cambia la persona.
- Nam nói là tôi sẽ đến muộn. :: Diría que el que llega tarde eres tú.
- Nam hỏi anh ấy đến muộn. :: «hỏi» es preguntar.
- Nam nói đến muộn là anh ấy. :: El orden no es ese.
Q Hoa pregunta: «Cậu có thích nhạc trẻ không?» ¿Cómo lo cuentas?
+ Hoa hỏi tôi có thích nhạc trẻ không. :: hỏi… có… không.
- Hoa nói là tôi thích nhạc trẻ. :: Eso es afirmar, no preguntar.
- Hoa hỏi tôi rằng thích nhạc trẻ. :: Falta «có… không».
- Hoa bảo tôi thích nhạc trẻ. :: «bảo» sería una orden.
H Bài hát ___ cô ấy vừa hát tên là gì? :: «La canción que acaba de cantar…»
+ mà :: nombre + mà + explicación.
- rằng :: Es para contar lo que se dice.
- nên :: No.
- chẳng :: Es una negación.
H ___ báo chí, bộ phim đã nhận được năm giải thưởng. :: «Según…»
+ Theo :: theo + fuente.
- Nghe :: «nghe báo chí» no se dice así; sería «nghe nói».
- Bảo :: No.
- Kể :: No.
H Quán này đã xa ___ đắt. :: «además de lejos, caro»
+ lại :: đã… lại…
- nên :: No.
- chứ :: No.
- mà là :: No.
H Tôi tìm khắp nơi mà ___ thấy đâu cả. :: Un «no» rotundo
+ chẳng :: chẳng… đâu cả = en ningún sitio.
- đã :: No niega.
- cũng :: No niega.
- lại :: No niega.
R Mẹ bảo tôi phải về trước mười giờ.
+ Mi madre me ha dicho que tengo que volver antes de las diez. :: bảo + persona + lo que debe hacer.
- Le he dicho a mi madre que vuelva a las diez. :: Al revés.
- Mi madre vuelve antes de las diez. :: La que tiene que volver soy yo.
- Mi madre me pregunta a qué hora vuelvo. :: No.
R Nghe nói ca sĩ đó sắp sang Việt Nam biểu diễn.
+ Dicen que ese cantante va a venir a actuar a Vietnam. :: nghe nói = dicen que.
- Vi a ese cantante actuar en Vietnam. :: No lo ha visto.
- Ese cantante ya no actúa. :: No.
- Ese cantante es vietnamita. :: No lo dice.
R Đây là cuốn sách mà tôi đã kể với bạn.
+ Este es el libro del que te hablé. :: cuốn sách + mà + explicación.
- Este libro te lo regalo. :: No.
- Te cuento este libro, pero es malo. :: «mà» no es «pero» aquí.
- Este libro lo escribí yo. :: No.
A Chị ấy khen phim hay nhưng chê kết thúc hơi buồn.
+ Dice que la película es buena, pero le pone la pega de que el final es un poco triste. :: khen = elogiar; chê = criticar.
- Dice que la película es mala y el final, bueno. :: Al revés.
- No ha visto el final. :: No.
- Le encantó el final. :: Lo critica.
A Vé đã đắt gấp đôi lại còn ngồi tận khán đài cuối.
+ La entrada, además de costar el doble, era para la última grada. :: đã… lại còn…
- La entrada era barata y con buen asiento. :: Al contrario.
- Compré dos entradas. :: «gấp đôi» es el doble de precio.
- No quedaban entradas. :: Sí consiguió una.
O Anh ấy hỏi tôi có muốn đi xem phim không. :: Me preguntó si quería ir al cine. :: hỏi… có… không.
O Tôi chẳng biết gì về nhạc cổ điển cả. :: No sé nada de nada de música clásica. :: chẳng… gì… cả.
