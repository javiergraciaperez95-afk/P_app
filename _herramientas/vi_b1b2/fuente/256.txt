@ 48 | Bài 48 · Tiếng của giới trẻ | Lección 48: el habla coloquial y la jerga joven; «cứ… là…»
E «cứ… là…»: en cuanto…, siempre que… :: Ya la viste de pasada. **Cứ + A + là + B** = basta que pase A para que pase B; cada vez que A, B. Es la forma más hablada de decir una costumbre: «**Cứ** nghe nhạc này **là** tớ buồn ngủ» = Es oír esta música y me entra sueño. «**Cứ** đến thứ hai **là** chán». :: **Cứ** + verbo (sin «là») = seguir haciéndolo, hacerlo sin más: «**Cứ** nói đi» = Tú habla. «Nó **cứ** cười» = No para de reírse.
E Cómo hablan y escriben los jóvenes :: Esto **no es para usarlo en un examen**, pero lo verás en cada chat. Palabras bastante asentadas: :: **xịn** = de calidad, de los buenos. **đỉnh** = lo más, top. **chất** = con estilo. **chán** = un rollo. **bó tay** = me rindo, no hay quien pueda. :: **chém gió** = fanfarronear, hablar por hablar. **thả thính** = tirar la caña, coquetear. **sống ảo** = vivir para las redes. **trẻ trâu** = niñato. **gấu** = novio o novia. **ế** = sin pareja. :: En los mensajes se acorta todo: **ko / k** = không · **dc / đc** = được · **j** = gì · **r** = rồi · **bt** = bình thường / biết · **ng** = người · **mk** = mình · **ntn** = như thế nào. :: Y se mezcla inglés: **ok**, **check**, **deadline**, **sale**. :: Regla: entiéndelo todo, úsalo solo con gente de tu edad y de confianza, y nunca por escrito formal.

Q ¿Qué significa «ko» en un chat?
+ không :: Es la abreviatura más frecuente.
- có :: No.
- khi nào :: No.
- không ai :: No.
Q ¿Qué significa «gấu» aquí?
+ Novio o novia. :: Es jerga joven.
- Oso. :: Es el sentido literal, no el de la conversación.
- Amigo de clase. :: No.
- Profesor. :: No.
Q ¿Qué le reprocha Hoa a Nam con «đừng chém gió»?
+ Que no cuente cuentos: creen que sí tiene novia. :: chém gió = fanfarronear, hablar por hablar.
- Que no hable tan alto. :: No.
- Que no corte el viento. :: Es el sentido literal.
- Que no llegue tarde. :: No.
Q ¿Qué le recuerda Carlos al grupo?
+ Que su profesor le ha dicho que no escriba así en el examen. :: «không được viết thế trong bài thi».
- Que no entiende nada. :: Entiende la mitad.
- Que no puede ir. :: No dice eso.
- Que no tiene móvil. :: No.
Q ¿Con quién puedes usar esta jerga?
+ Con gente de tu edad y de confianza, nunca por escrito formal. :: Es la regla de la lección.
- Con tu jefa. :: No.
- En una solicitud. :: No.
- Con cualquier desconocido. :: No.

R Cứ nghe bài hát này là tôi nhớ nhà.
+ Es oír esta canción y echar de menos mi casa. :: cứ… là… = cada vez que.
- Aunque oigo esta canción, no echo de menos mi casa. :: Al contrario.
- Oiré esta canción en casa. :: No.
- No me gusta esta canción. :: No.
A Chat thì chat, thi thì thi.
+ Una cosa es el chat y otra el examen. :: A thì A, B thì B = cada cosa en su sitio.
- En el examen se chatea. :: Al contrario.
- No chatees nunca. :: No.
- El examen es por chat. :: No.
