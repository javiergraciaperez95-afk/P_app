Q «quá tải» es…
+ saturado, desbordado :: Bệnh viện lúc nào cũng quá tải.
- gratuito :: Es «miễn phí».
- privado :: Es «tư».
- vacío :: Es «trống».
Q «trầm cảm» es…

- ansiedad :: Es «lo âu».
- estigma :: Es «kỳ thị».
- terapia :: Es «trị liệu».
Q «lây» es…

- vacunar :: Es «tiêm».
- aislar :: Es «cách ly».
- desinfectar :: Es «khử trùng».

Q Un amigo te cuenta que está pasando una mala época. ¿Qué respuesta sigue el consejo del texto?
+ Tớ không biết giúp cậu thế nào, nhưng tớ ở đây và tớ nghe cậu. :: Escuchar antes que juzgar o aconsejar.
- Cố lên, nghĩ nhiều làm gì! :: Es justo lo que no ayuda.
- Cậu yếu đuối quá. :: Es juzgar.
- Kệ cậu. :: «Allá tú».
