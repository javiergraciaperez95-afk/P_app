E Test 33 :: Repaso del capítulo 33: la casa, los vecinos y el lugar donde vives; **bằng, như, không… bằng, gấp đôi**, **hình như… thì phải, có vẻ, chắc, chắc chắn**, **so với, khác với, giống như, còn… thì…** y **mới… đã…, chưa… đã…, xong… mới…**.
Q «đặt cọc» es…
+ dejar una fianza :: Đặt cọc hai tháng tiền nhà.
- firmar el contrato :: Es «ký hợp đồng».
- mudarse :: Es «dọn đến» o «chuyển đến».
- pagar la luz :: Es «trả tiền điện».
Q «nội thất» es…
+ el mobiliario :: Nội thất có đầy đủ không?
- la superficie :: Es «diện tích».
- el balcón :: Es «ban công».
- el callejón :: Es «ngõ».
Q «ô nhiễm» es…
+ contaminación :: không khí ô nhiễm.
- atasco :: Es «tắc đường».
- ruido :: Es «tiếng ồn».
- prisa :: Es «vội vàng».
Q «bừa bộn» es lo contrario de…
+ ngăn nắp :: bừa bộn = desordenado; ngăn nắp = ordenado.
- dễ vỡ :: Es «frágil».
- đầy đủ :: Es «completo».
- xa lạ :: Es «desconocido».
H Con trai tôi cao ___ bố nó rồi. :: Misma altura
+ bằng :: cao bằng = igual de alto.
- nhất :: «cao nhất» no lleva comparación detrás.
- gấp :: Falta «đôi».
- thì phải :: Va al final.
H Phòng này không sáng ___ phòng kia. :: «no tan luminosa como»
+ bằng :: không + adjetivo + bằng.
- hơn :: «không sáng hơn» sería «no más luminosa»; lo habitual para «no tan… como» es «bằng».
- nhất :: No lleva comparación detrás.
- gấp đôi :: No encaja con «không».
H ___ anh ấy đang ngủ thì phải. Tôi gọi mãi không ai trả lời. :: Suposición dudosa
+ Hình như :: hình như… thì phải.
- Chắc chắn :: Choca con «thì phải».
- So với :: Es «comparado con».
- Thảo nào :: Es «con razón».
H Ở miền Bắc thì có bốn mùa, ___ ở miền Nam thì chỉ có hai mùa. :: «…mientras que…»
+ còn :: A thì…, còn B thì…
- nên :: No.
- bằng :: No.
- đã :: No.
R Mới gặp một lần mà anh ấy đã nhớ tên tôi.
+ Me ha visto una sola vez y ya se acuerda de mi nombre. :: mới… mà đã…
- Me ha visto muchas veces y no recuerda mi nombre. :: Al contrario.
- No nos hemos visto nunca. :: No.
- Me preguntó mi nombre una vez. :: No dice eso.
R Chưa đến nơi đã hết xăng.
+ Aún no habíamos llegado y ya nos quedamos sin gasolina. :: chưa… đã…
- Llegamos y luego echamos gasolina. :: No.
- No llegamos porque no quisimos. :: No.
- Teníamos gasolina de sobra. :: Al contrario.
R Ăn xong mới được ăn kem.
+ Hasta que no termines de comer, no hay helado. :: xong… mới… = solo después.
- Come el helado primero. :: Al revés.
- No hay helado. :: Sí, pero después.
- Puedes comer helado ahora. :: No.
Q ¿Qué frase expresa más seguridad?
+ Chắc chắn mai trời sẽ mưa. :: chắc chắn = sin duda.
- Hình như mai trời mưa thì phải. :: Es la más dudosa.
- Có lẽ mai trời mưa. :: «quizá».
- Nghe nói mai trời mưa. :: Es lo que dicen otros.
Q ¿Qué frase dice que dos hermanos se parecen mucho?
+ Hai anh em giống nhau như hai giọt nước. :: «como dos gotas de agua».
- Hai anh em khác hẳn nhau. :: «totalmente distintos».
- Anh cao gấp đôi em. :: Compara la altura.
- So với anh, em thấp hơn. :: Compara la altura.
A Nó rộng gấp đôi căn này nhưng giá chỉ cao hơn một chút.
+ Es el doble de grande que este, pero solo un poco más caro. :: gấp đôi = el doble; hơn một chút = un poco más.
- Es la mitad de grande y el doble de caro. :: No.
- Es igual de grande y más barato. :: No.
- Es un poco más grande y mucho más caro. :: Está al revés.
A Ở quê thì khác hẳn.
+ En el pueblo es completamente distinto. :: khác hẳn = totalmente distinto.
- En el pueblo es igual. :: Al contrario.
- En el pueblo no hay nada. :: No.
- Quiero volver al pueblo. :: No lo dice.
