E Test 35 :: Repaso del capítulo 35: fiestas, bodas, cocina y creencias; la pasiva con **được** y **do**, **hãy / đừng / chớ**, las palabras del final **đi, nào, thôi, đã, nhé**, y **kẻo, để khỏi, phải… mới…**.
Q «đèn lồng» es…
+ farolillo :: Đường phố được trang trí bằng đèn lồng.
- pastel de luna :: Es «bánh trung thu».
- tambor :: Es «trống».
- sobre rojo :: Es «lì xì».
Q «chú rể» es…
+ el novio :: cô dâu chú rể = los novios.
- la novia :: Es «cô dâu».
- el invitado :: Es «khách mời».
- el padrino :: No.
Q «nguyên liệu» es…
+ los ingredientes :: Nguyên liệu gồm những gì?
- la receta :: Es «công thức».
- las especias :: Es «gia vị».
- la sartén :: Es «chảo».
Q «tổ tiên» es…
+ los antepasados :: thắp hương mời tổ tiên.
- los nietos :: Es «các cháu».
- los vecinos :: Es «hàng xóm».
- los invitados :: Es «khách mời».
H Ngôi nhà này ___ ông tôi xây năm 1960. :: Quién lo hizo
+ do :: A + do + quien lo hace + verbo.
- bị :: Lo presentaría como algo malo.
- nên :: No.
- kẻo :: No.
H Hội nghị sẽ ___ tổ chức ở Đà Nẵng. :: Pasiva neutra
+ được :: được + verbo.
- bị :: Para algo malo.
- do :: Falta quien lo hace.
- hãy :: No.
H ___ nói to trong thư viện! :: «No…»
+ Đừng :: đừng + verbo.
- Hãy :: Sería animar a hablar alto.
- Được :: No.
- Mới :: No.
H Nghỉ một chút ___, rồi làm tiếp. :: «primero»
+ đã :: «đã» al final = primero.
- nào :: No ordena en el tiempo.
- chứ :: No.
- kẻo :: No va al final.
H Mang ô đi, ___ trời mưa. :: Un aviso
+ kẻo :: consejo + kẻo + lo malo.
- để :: «para que llueva» no tiene sentido.
- mới :: No.
- do :: No.
R Phải có vé mới vào được.
+ Solo se puede entrar con entrada. :: phải… mới… = solo así.
- No hace falta entrada para entrar. :: Al contrario.
- Hay que entrar para comprar la entrada. :: Al revés.
- Las entradas son nuevas. :: Aquí «mới» no es «nuevo».
R Tôi đi xe buýt để khỏi phải tìm chỗ để xe.
+ Voy en autobús para no tener que buscar aparcamiento. :: để khỏi = para no tener que.
- Voy en autobús porque no encuentro el coche. :: No.
- No voy en autobús porque no hay aparcamiento. :: No.
- Busco aparcamiento para el autobús. :: No.
R Ăn đi nào, kẻo nguội!
+ ¡Venga, a comer, que se enfría! :: đi nào = venga; kẻo nguội = no vaya a enfriarse.
- No comas, que está frío. :: Al contrario.
- Come cuando se enfríe. :: No.
- ¿Ya has comido? :: No.
Q ¿Qué se dice a los novios en una boda?
+ Chúc hai bạn trăm năm hạnh phúc! :: «Que seáis felices cien años».
- Chúc mừng năm mới! :: Es «feliz año nuevo».
- Chúc ngon miệng! :: Es «que aproveche».
- Chúc mừng sinh nhật! :: Es «feliz cumpleaños».
Q ¿Cuál de estas frases suena a cartel o a discurso?
+ Hãy giữ gìn vệ sinh chung. :: «hãy» es solemne: mantengan limpio el espacio común.
- Ăn đi! :: Es de andar por casa.
- Về thôi! :: Es coloquial.
- Chờ tớ đã! :: Es coloquial.
A Bánh trung thu được làm từ bột mì.

- Los pasteles de luna se compran con harina. :: No.
- No hay harina para los pasteles. :: No.
- Mi abuela hace pasteles de luna. :: No dice quién.
