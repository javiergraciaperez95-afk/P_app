@ 45 | Bài 45 · Một bài báo kinh tế | Lección 45: leer una noticia económica; «khẳng định», «nhấn mạnh», «nhờ vào», «so với cùng kỳ»
E Los verbos con que la prensa cita :: En una conversación basta con «nói». Un periódico elige el verbo según **cómo** se dijo: :: **cho biết** = informar (neutro, el más frecuente). **nói thêm** = añadir. :: **khẳng định** = afirmar con rotundidad. **nhấn mạnh** = recalcar, subrayar. :: **cảnh báo** = advertir. **dự báo** = prever, pronosticar. **nhận định** = valorar, opinar (un experto). :: **thừa nhận** = admitir, reconocer. **phủ nhận** = desmentir. :: La fuente va **antes** («Theo ông A,…») o **después** («…, ông A cho biết»).
E Las preposiciones del periódico :: **nhờ (vào)** + causa buena = gracias a: «**nhờ vào** giá tăng». **do** + causa (neutra o mala) = debido a. :: **nhằm** + objetivo = con el fin de. **nhờ đó** / **qua đó** = gracias a ello, con ello. :: **so với cùng kỳ năm ngoái** = respecto al mismo periodo del año pasado: la frase más repetida de las páginas de economía. :: **đạt** + cifra = alcanzar: «**đạt** 5 tỷ đô la». **ước tính** = se calcula. **chiếm** + porcentaje = suponer.

Q ¿Cuánto han subido las exportaciones de café?
+ Casi un treinta por ciento respecto al mismo periodo del año pasado. :: «tăng gần ba mươi phần trăm so với cùng kỳ năm ngoái».
- Un tres por ciento. :: No.
- Se han duplicado. :: No.
- Han bajado. :: Lo que bajó fue la producción.
Q ¿A qué se debe la subida?
+ Al fuerte aumento del precio mundial, no a que se produzca más. :: «nhờ vào giá cà phê thế giới tăng mạnh, chứ không phải do sản lượng tăng».
- A que la cosecha ha sido enorme. :: La producción incluso bajó un poco.
- A una nueva ley. :: No.
- A que Brasil no exporta. :: No lo dice.
Q ¿Qué advierten los expertos?
+ Que no hay que apresurarse a plantar más, porque el precio puede bajar. :: «không nên vội mở rộng diện tích trồng… không có nghĩa là năm sau vẫn cao».
- Que hay que dejar de exportar. :: No.
- Que el café vietnamita es malo. :: No.
- Que hay que plantar el doble. :: Al contrario.
Q ¿Por qué el valor añadido es bajo?
+ Porque casi todo se exporta en grano sin elaborar. :: «dưới dạng hạt thô».
- Porque se vende muy barato en Vietnam. :: No lo dice.
- Porque es de mala calidad. :: No.
- Porque hay demasiadas fábricas. :: Al contrario.
Q ¿Qué verbo usa el periódico para una afirmación rotunda del Ministerio?
+ khẳng định :: = afirmar con rotundidad.
- thừa nhận :: Es «admitir».
- phủ nhận :: Es «desmentir».
- dự báo :: Es «prever».
H Doanh thu quý ba tăng mười phần trăm so với ___ năm ngoái. :: «el mismo periodo»
+ cùng kỳ :: so với cùng kỳ năm ngoái.
- cuối cùng :: Es «por último».
- cùng nhau :: Es «juntos».
- kỳ thi :: Es «examen».
H Công ty ___ rằng đã mắc sai lầm trong việc quảng cáo. :: «admitió»
+ thừa nhận :: thừa nhận = reconocer algo que te perjudica.
- khẳng định :: Es afirmar con seguridad.
- dự báo :: Es prever.
- kêu gọi :: Es hacer un llamamiento.
