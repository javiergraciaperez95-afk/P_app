@ 31 | Bài 31 · Kiểm tra 31 | Lección 31: test de repaso
E Test 31 :: Repaso del capítulo 31: el médico, el estrés, los hábitos y las urgencias; **đành phải**, **đến mức / đến nỗi**, **nên / cần / phải / không được**, **hạn chế, tránh, ít nhất** y **bị / được** con quien lo hace.
Q «triệu chứng» es…
+ síntoma :: Anh có triệu chứng gì?
- análisis :: Es «xét nghiệm».
- receta :: Es «đơn thuốc».
- herida :: Es «vết thương».
Q «mất ngủ» es…
+ tener insomnio :: Đêm qua tôi bị mất ngủ.
- dormir lo suficiente :: Es «ngủ đủ giấc».
- tener náuseas :: Es «buồn nôn».
- estar agotado :: Es «kiệt sức».
Q «tác dụng phụ» es…
+ efecto secundario :: Thuốc này không có tác dụng phụ.
- analgésico :: Es «thuốc giảm đau».
- seguro médico :: Es «bảo hiểm y tế».
- primeros auxilios :: Es «sơ cứu».
Q «bất tỉnh» es lo contrario de…
+ tỉnh :: tỉnh = consciente; bất tỉnh = inconsciente.
- khỏi :: Es «curarse».
- nhẹ :: Es «leve».
- may :: Es «por suerte».
H Xe hỏng giữa đường, tôi ___ phải gọi taxi. :: No queda más remedio
+ đành :: đành phải = no tener más remedio.
- được :: «được phải» no existe.
- nên :: «nên phải» no encaja.
- tránh :: Es «evitar».
H Anh ấy mệt ___ ngủ quên trên xe buýt. :: «tan cansado que…»
+ đến nỗi :: adjetivo + đến nỗi + consecuencia.
- thay vì :: Es «en vez de».
- mặc dù :: Es «aunque».
- ít nhất :: Es «como mínimo».
H Trong bệnh viện ___ hút thuốc. :: Prohibido
+ không được :: không được + verbo = prohibido.
- không cần :: Es «no hace falta».
- không phải :: Es «no es obligatorio».
- nên :: Sería un consejo de fumar.
H Mai là chủ nhật, em ___ dậy sớm. :: «no hace falta»
+ không phải :: không phải + verbo = no tienes por qué.
- không được :: Sería una prohibición de madrugar.
- phải :: Es lo contrario.
- đành phải :: No.
R Tôi bị xe máy đâm vào chân.
+ Una moto me ha dado en la pierna. :: bị + quien lo hace + verbo.
- Le he dado a una moto con la pierna. :: Está al revés.
- Tengo una moto nueva. :: No.
- Me duele la pierna de ir en moto. :: No.
R Bộ phim hay đến mức tôi xem ba lần.
+ La película es tan buena que la he visto tres veces. :: đến mức = hasta el punto de.
- La película no es tan buena. :: Sería «không đến nỗi hay».
- He visto tres películas buenas. :: No.
- La película dura tres horas. :: No.
R Bạn nên tránh thức khuya.
+ Deberías evitar trasnochar. :: tránh = evitar; thức khuya = acostarse tarde.
- Deberías acostarte más tarde. :: Al contrario.
- Tienes prohibido dormir. :: No.
- Nunca trasnochas. :: No.
Q Estás llamando al 115. ¿Qué dices primero?
+ Ở số 15 phố Huế có người bị tai nạn. :: Lo primero es decir dónde.
- Tôi tên là Carlos, tôi là người Tây Ban Nha. :: Eso puede esperar.
- Hôm nay trời đẹp quá. :: No viene a cuento.
- Tôi muốn đặt lịch khám. :: Eso es pedir cita, no una urgencia.
Q ¿Qué frase es un consejo, no una orden ni una prohibición?
+ Anh nên nghỉ ngơi vài ngày. :: nên = deberías.
- Anh phải nghỉ ngơi vài ngày. :: «phải» es obligación.
- Anh không được đi làm. :: Es prohibición.
- Nghỉ ngơi đi! :: Es una orden.
A Uống ngày hai lần, mỗi lần một viên, sau khi ăn.
+ Dos veces al día, una pastilla cada vez, después de comer. :: ngày hai lần = dos veces al día; viên = pastilla.
- Una vez al día, dos pastillas, antes de comer. :: Los números están cambiados y «sau» es después.
- Dos pastillas antes de dormir. :: No.
- Solo si tiene fiebre. :: No.
A Anh ấy được sơ cứu kịp thời nên mất ít máu.
+ Recibió los primeros auxilios a tiempo y perdió poca sangre. :: kịp thời = a tiempo; ít = poco.
- Nadie lo ayudó y perdió mucha sangre. :: Al contrario.
- Lo operaron de urgencia. :: No dice eso.
- Llegó tarde al hospital. :: «kịp thời» es a tiempo.
O Bạn phải uống thuốc đúng giờ. :: Tienes que tomar la medicina a su hora. :: phải + verbo = obligación.
O Tôi đành phải nghỉ làm một ngày. :: No me quedó otra que faltar un día al trabajo. :: đành phải + verbo.
