@ 29 | Bài 29 · Kiểm tra 29 | Lección 29: test de repaso
E Test 29 :: Repaso del capítulo 29: carácter, familia y relaciones; **nếu… thì…** y **nếu không thì**, **hễ… là…**, **mỗi khi**, **cứ… là…**, **giá mà… thì (đã)…**, **ước gì**, **thà… chứ không…** y los consejos con **nên**.
Q «nóng tính» es…
+ de mal genio :: Bố con ngày xưa nóng tính lắm.
- gracioso :: Es «vui tính».
- tímido :: Es «nhút nhát».
- atento :: Es «chu đáo».
Q «khiêm tốn» es lo contrario de…
+ kiêu ngạo :: khiêm tốn = modesto; kiêu ngạo = arrogante.
- hào phóng :: Es «generoso».
- hiền :: Es «bueno».
- thẳng thắn :: Es «franco».
Q «làm lành» es…
+ hacer las paces :: Cãi nhau rồi lại làm lành.
- discutir :: Es «cãi nhau».
- regañar :: Es «mắng».
- mimar :: Es «cưng».
Q «tiết kiệm» es…
+ ahorrar :: tiết kiệm tiền thuê nhà.
- pedir prestado :: Es «vay».
- gastar :: Es «chi tiêu».
- deber dinero :: Es «nợ».
H Con phải mặc áo ấm vào, ___ thì bị cảm đấy. :: «si no…»
+ nếu không :: nếu không thì = de lo contrario.
- giá mà :: Es «ojalá».
- mỗi khi :: Es «cada vez que».
- thay vì :: Es «en vez de».
H ___ thấy tôi là con chó chạy ra chào. :: Una costumbre que no falla
+ Hễ :: hễ… là… = siempre que.
- Giá :: «giá mà» es para algo irreal.
- Thà :: Es «prefiero».
- Tuy :: Es «aunque».
H Giá mà hôm qua tôi mang ô thì đã ___ bị ướt. :: «…no me habría mojado»
+ không :: giá mà… thì đã không… = si hubiera…, no habría…
- sẽ :: «đã sẽ» no existe.
- đang :: No.
- rất :: Diría que sí se mojó mucho.
H Tôi thà ở một mình ___ ở với người ích kỷ. :: «…antes que…»
+ chứ không :: thà A chứ không B.
- nếu không :: Es «si no».
- mà còn :: Es «sino también».
- hễ :: Es «siempre que».
R Mỗi lần gặp nhau, họ đều cãi nhau.
+ Cada vez que se ven, discuten. :: mỗi lần… đều…
- Si se ven, discutirán. :: Es una costumbre, no una posibilidad.
- Nunca discuten cuando se ven. :: Al contrario.
- Se vieron una vez y discutieron. :: «mỗi lần» = cada vez.
R Ước gì tôi biết bơi!
+ ¡Ojalá supiera nadar! :: ước gì = ojalá (no sé).
- Sé nadar muy bien. :: No sabe.
- Quiero aprender a nadar mañana. :: Es un deseo, no un plan.
- ¿Sabes nadar? :: No es pregunta.
R Lẽ ra tôi phải gọi điện trước.
+ Tendría que haber llamado antes. :: lẽ ra… phải… = debería haber…
- Llamé antes de venir. :: No llamó: lo lamenta.
- Te llamaré antes. :: No es futuro.
- No hace falta llamar antes. :: No.
Q Tu amigo está triste porque ha discutido con su novia. ¿Qué consejo es amable?
+ Theo tớ, cậu nên xin lỗi cô ấy. :: Theo tớ… nên… = en mi opinión, deberías…
- Cậu phải chia tay ngay! :: Es una orden muy dura.
- Tớ không quan tâm. :: «No me importa».
- Cậu sai rồi, tớ không nói nữa. :: «Te has equivocado, no digo más».
Q ¿Qué frase habla de algo que ya no tiene arreglo?
+ Giá mà tôi học chăm hơn thì đã thi đỗ. :: giá mà… thì đã… = pasado irreal.
- Nếu tôi học chăm thì sẽ thi đỗ. :: Eso todavía es posible.
- Hễ học chăm là thi đỗ. :: Es una regla general.
- Tôi nên học chăm hơn. :: Es un consejo para ahora.
A Anh ấy vui tính lắm, lúc nào cũng làm con cười.
+ Es muy gracioso, siempre me hace reír. :: vui tính = gracioso; làm… cười = hacer reír.
- Tiene mal genio y siempre me hace llorar. :: No.
- Es muy serio y nunca se ríe. :: No.
- Se ríe siempre de mí. :: No dice eso.
A Em nên cân nhắc kỹ rồi hãy quyết định.
+ Deberías pensarlo bien y luego decidir. :: cân nhắc kỹ = sopesar bien; quyết định = decidir.
- Decide ahora mismo. :: Dice que lo piense antes.
- Ya has decidido bien. :: No.
- No hace falta que decidas. :: No.
