E Test 44 :: Repaso del capítulo 44: historia, patrimonio, creencias y tacto; las palabras **sino-vietnamitas**, la **reduplicación** (nho nhỏ, nhè nhẹ, lung linh…), **vốn / vốn dĩ / từng là / xưa kia** y las formas de **suavizar** (hơi, không… lắm, cũng được, e là).
Q «triều đại» es…
+ dinastía :: các triều đại Lý, Trần, Lê, Nguyễn.
- colonia :: Es «thuộc địa».
- leyenda :: Es «truyền thuyết».
- guerra :: Es «chiến tranh».
Q «di sản» es…
+ patrimonio :: Di sản Văn hóa Thế giới.
- arquitectura :: Es «kiến trúc».
- creencia :: Es «tín ngưỡng».
- turista :: Es «du khách».
Q «mê tín» es…
+ superstición :: Có người gọi đó là mê tín.
- religión :: Es «tôn giáo».
- gratitud :: Es «lòng biết ơn».
- tradición :: Es «truyền thống».
Q «mất mặt» es…
+ perder la cara, quedar mal :: Nói thế thì người nghe mất mặt.
- perder la memoria :: No.
- enfadarse :: No.
- tener tacto :: Es «tế nhị».
Q Si «quốc» es «país» y «tế» es «entre, relación», ¿qué es «quốc tế»?
+ internacional :: sân bay quốc tế = aeropuerto internacional.
- nacional :: Es «quốc gia».
- provincial :: No.
- extranjero :: Es «nước ngoài».
Q Si «bệnh» es «enfermedad» y «nhân» es «persona», ¿qué es «bệnh nhân»?
+ paciente :: bệnh + nhân.
- médico :: Es «bác sĩ».
- hospital :: Es «bệnh viện».
- enfermero :: Es «y tá».
Q ¿Cuál de estas palabras tiene el adjetivo delante, al modo culto?
+ đại học :: đại (grande) + học (estudio).
- trường lớn :: Es el orden de casa: nombre + adjetivo.
- nhà nhỏ :: Nombre + adjetivo.
- sông dài :: Nombre + adjetivo.
H Ngôi nhà ___ bên bờ sông trông rất dễ thương. :: «pequeñita»
+ nho nhỏ :: nhỏ → nho nhỏ.
- nhộn nhịp :: Es «bulliciosa».
- lặng lẽ :: Es «en silencio».
- thẳng thừng :: Es «sin rodeos».
H Ông cụ ___ bước qua đường. :: «despacito»
+ chầm chậm :: chậm → chầm chậm.
- lung linh :: Es «centelleante».
- xanh xanh :: Es «verdoso».
- khéo léo :: Es «hábil».
H Cô ấy ___ là người Huế nhưng lớn lên ở Sài Gòn. :: «de origen»
+ vốn :: vốn là = en origen.
- sắp :: No.
- toàn :: No.
- hơi :: No.
H Đà Lạt ___ là nơi nghỉ mát của người Pháp. :: «fue en otro tiempo»
+ từng :: từng là = fue (y ya no).
- sẽ :: Es futuro.
- e :: No.
- cũng :: No dice el tiempo.
R Bài viết của em hơi dài và phần đầu không rõ lắm.
+ Tu texto es un poco largo y el principio no queda muy claro. (Crítica suave: hay que cambiarlo.) :: hơi… / không… lắm.
- Tu texto es perfecto. :: No.
- Tu texto es cortísimo. :: «dài» es largo.
- No he leído tu texto. :: No.
R Thứ bảy này à? Tôi e là không tiện lắm.
+ ¿Este sábado? Me temo que no me viene muy bien. (Es un no.) :: e là… không tiện lắm.
- ¿Este sábado? Perfecto. :: Al contrario.
- No sé qué día es. :: No.
- El sábado me viene mejor que el domingo. :: No compara.
R Phố cổ về đêm lung linh ánh đèn.
+ De noche, el casco antiguo centellea de luces. :: lung linh = centellear.
- De noche, el casco antiguo está a oscuras. :: Al contrario.
- De noche cierran el casco antiguo. :: No.
- Las luces molestan en el casco antiguo. :: No.
Q Un compañero te enseña un informe flojo. ¿Cómo se lo dices con tacto, al modo vietnamita?
+ Phần đầu rất hay. Phần cuối có lẽ anh nên xem lại một chút. :: Elogio primero; luego «có lẽ… nên…».
- Bài này dở quá! :: Demasiado directo.
- Tôi không muốn đọc. :: Ofensivo.
- Anh làm sai hết rồi. :: Hace perder la cara.
Q ¿Qué frase suele ser un «no» educado?
+ Để tôi xem đã. :: «Déjeme verlo»: casi siempre es que no.
- Được chứ! :: Es un sí rotundo.
- Nhất định rồi. :: Es un sí.
- Tôi đồng ý. :: Es un sí.
A Hội An từng là một thương cảng nhộn nhịp.
+ Hội An fue en otro tiempo un puerto comercial muy animado. :: từng là = fue; nhộn nhịp = bullicioso.
- Hội An será un gran puerto. :: No es futuro.
- Hội An nunca tuvo puerto. :: No.
- Hội An es hoy un puerto industrial. :: No.
A Người Việt vốn coi trọng việc thờ cúng tổ tiên.
+ Los vietnamitas, de siempre, dan mucha importancia al culto a los antepasados. :: vốn = de por sí, desde siempre.
- Los vietnamitas han dejado de venerar a los antepasados. :: No.
- Solo los mayores veneran a los antepasados. :: No lo dice.
- Es una costumbre reciente. :: Al contrario.
O Gió thổi nhè nhẹ qua phố cổ. :: Una brisa suavecita recorre el casco antiguo. :: nhè nhẹ = suavecito.
O Tôi e là hôm nay không kịp. :: Me temo que hoy no da tiempo. :: e là + lo que temes.
