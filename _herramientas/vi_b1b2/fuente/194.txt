E El tiempo de la acción, todo junto :: El verbo vietnamita no cambia. Lo que marca el momento son unas palabritas delante. Ya las conoces sueltas; aquí van ordenadas, del futuro al pasado: :: **sẽ** = futuro sin más: «Ngày mai trời **sẽ** mưa». **sắp** = a punto de, muy pronto: «Bão **sắp** vào đất liền» = El tifón está a punto de tocar tierra. Con «sắp» se suele acabar en **rồi**: «sắp mưa **rồi**». :: **đang** = ahora mismo: «Bão **đang** di chuyển về phía tây». :: **vừa / mới / vừa mới** = hace nada, acaba de: «Trời **vừa** tạnh mưa» = Acaba de dejar de llover. :: **đã** = ya, pasado cumplido: «Bão **đã** suy yếu» = El tifón ya se ha debilitado. :: Importante: si hay una palabra de tiempo (hôm qua, ngày mai), «đã» y «sẽ» **no son obligatorios**. En las noticias sí se ponen, porque dan precisión.

Q ¿Dónde y cuándo tocará tierra el tifón?
+ En las provincias del centro, probablemente mañana de madrugada. :: «sắp vào đất liền các tỉnh miền Trung… sáng sớm ngày mai».
- En Hanói, esta noche. :: No.
- En el sur, dentro de tres días. :: No.
- Ya ha tocado tierra. :: Está a punto.
Q ¿Qué han hecho ya las autoridades?
+ Evacuar a más de dos mil personas. :: «đã sơ tán hơn hai nghìn người dân».
- Cerrar todos los colegios del país. :: No lo dice.
- Prohibir salir de casa. :: Solo lo recomiendan.
- Nada todavía. :: Sí.
Q ¿Qué pasará después de que el tifón toque tierra?
+ Se debilitará, pero seguirá lloviendo dos o tres días, con riadas. :: «suy yếu dần… mưa lớn sẽ còn kéo dài hai, ba ngày nữa, gây lũ».
- Hará sol al día siguiente. :: No.
- Se hará más fuerte. :: Al contrario.
- Nevará en la montaña. :: No.
Q ¿Cuál indica que algo está a punto de pasar?
+ sắp :: Trời sắp mưa rồi = está a punto de llover.
- đã :: Es «ya» (pasado).
- vừa :: Es «acaba de».
- đang :: Es «ahora mismo».
H Trời ___ tạnh mưa, đường vẫn còn ướt. :: «acaba de»
+ vừa :: vừa + verbo = acabar de.
- sắp :: Si estuviera a punto de escampar, todavía estaría lloviendo.
- sẽ :: Es futuro.
- chưa :: Seguiría lloviendo.
H Nhanh lên, tàu ___ chạy rồi! :: «está a punto de salir»
+ sắp :: sắp… rồi = a punto de.
- đã :: «đã chạy rồi» sería «ya ha salido»: no tendría sentido correr.
- vừa :: Igual: ya se habría ido.
- từng :: No.
