E Test 26 :: Repaso del capítulo 26: buscar trabajo, la oficina y las causas: **vì / do / nhờ / tại… nên…**, **làm cho, khiến, gây**, **bởi vì, vì vậy, sở dĩ… là vì…** y pedir favores con **nhờ… giúp**.
Q «kinh nghiệm» es…
+ experiencia :: Em đã có kinh nghiệm làm việc chưa?
- sueldo :: Es «lương».
- oportunidad :: Es «cơ hội».
- resultado :: Es «kết quả».
Q «tốt nghiệp» es…
+ graduarse :: Em tốt nghiệp ngành kế toán.
- estar en paro :: Es «thất nghiệp».
- ascender :: Es «thăng chức».
- dejar el trabajo :: Es «nghỉ việc».
Q «hợp đồng» es…
+ contrato :: ký hợp đồng = firmar un contrato.
- informe :: Es «báo cáo».
- documento :: Es «tài liệu».
- proyecto :: Es «dự án».
Q «hạn chót» es…
+ la fecha límite :: Hạn chót là thứ sáu.
- el turno de noche :: Es «ca đêm».
- la reunión :: Es «cuộc họp».
- el primer día :: Es «ngày đầu tiên».
H ___ kẹt xe nên tôi đến muộn. :: La causa es mala: «por culpa de…»
+ Tại :: tại = por culpa de.
- Nhờ :: «nhờ» es para causas buenas.
- Nếu :: «nếu» es «si».
- Sở dĩ :: Pediría «là vì».
H Nhờ chị ấy hướng dẫn ___ em hiểu ngay. :: «Gracias a que ella me lo explicó, lo entendí enseguida»
+ nên :: nhờ… nên…
- nhưng :: «pero» no encaja.
- là vì :: Va con «sở dĩ».
- bởi vì :: Sería otra causa, no la consecuencia.
H Sở dĩ anh ấy được thăng chức ___ anh ấy làm việc rất tốt. :: Destaca la causa
+ là vì :: sở dĩ… là vì…
- nên :: «nên» va con vì, do, nhờ, tại.
- vì vậy :: Es «por eso».
- cho nên :: Es «por eso».
R Tiếng ồn làm tôi đau đầu.
+ El ruido me da dolor de cabeza. :: cosa + làm + persona + cómo se queda.
- Hago ruido cuando me duele la cabeza. :: Quien provoca el dolor es el ruido.
- Me duele la cabeza, por eso hago ruido. :: Está al revés.
- No oigo nada por el dolor de cabeza. :: No.
R Do thời tiết xấu nên chuyến bay bị muộn.
+ Debido al mal tiempo, el vuelo se ha retrasado. :: do… nên… (formal).
- Aunque hace mal tiempo, el vuelo sale puntual. :: No hay «aunque».
- Gracias al buen tiempo, el vuelo llegó pronto. :: «xấu» es malo y «muộn» es tarde.
- Si hace mal tiempo, no habrá vuelo. :: No es una condición.
Q ¿Qué frase es correcta?
+ Mưa to gây ra tai nạn. :: gây (ra) + cosa mala.
- Mưa to gây tôi buồn. :: Con personas se usa «làm (cho)» o «khiến».
- Tôi gây vui cho mẹ. :: «gây» no va con cosas buenas.
- Tin vui gây tôi. :: Le falta todo.
Q Tu compañero te pregunta «Tại sao em nghỉ việc?». ¿Qué respuesta encaja?
+ Bởi vì lương thấp quá. :: «bởi vì» contesta a «tại sao?».
- Vì vậy lương thấp quá. :: «vì vậy» es «por eso».
- Cho nên em nghỉ việc. :: Repite la pregunta, no da la causa.
- Nhờ anh giúp. :: No contesta.
Q ¿Cómo le pides a una compañera mayor que te revise un informe?
+ Chị kiểm tra giúp em báo cáo này với. :: verbo + giúp em… với: petición amable.
- Chị kiểm tra báo cáo đi! :: Es una orden.
- Em kiểm tra giúp chị nhé. :: Eso es ofrecerte tú.
- Báo cáo này có lỗi. :: No pide nada.
A Thứ sáu này em muốn xin phép nghỉ một ngày.
+ Este viernes quería pedir un día libre. :: xin phép nghỉ = pedir permiso para faltar.
- Este viernes trabajo todo el día. :: Al contrario.
- El viernes pasado no vine. :: «này» es «este», no «pasado».
- Quiero un mes de vacaciones. :: «một ngày» es un día.
A Sếp không thích nhân viên đến muộn.
+ Al jefe no le gusta que los empleados lleguen tarde. :: đến muộn = llegar tarde.
- El jefe siempre llega tarde. :: Quienes llegan tarde son los empleados.
- A los empleados no les gusta el jefe. :: Está al revés.
- El jefe quiere más empleados. :: No.
O Nhờ anh giúp nên tôi làm xong. :: Gracias a tu ayuda he terminado. :: nhờ… nên…: causa buena y consecuencia.
O Công việc này khiến tôi căng thẳng. :: Este trabajo me estresa. :: khiến + persona + cómo se queda.
