E Decir que no sin decir «no» :: En Vietnam, decir «không» a la cara puede hacer que el otro **pierda la cara** (mất mặt). Por eso muchas negativas vienen **envueltas**. Un B2 tiene que saber leerlas: :: «**Để tôi xem đã**» (déjeme verlo) / «**Để tôi suy nghĩ thêm**» (lo pensaré) → casi siempre es un **no**. :: «**Hơi khó đấy**» (es algo difícil) / «**Chắc không tiện lắm**» (no vendrá muy bien) → es un **no**. :: «**Vâng**» / «**Dạ**» → a menudo solo significa «le estoy escuchando», no «estoy de acuerdo». :: Y al revés, para **criticar con suavidad**, se rebaja todo: :: **hơi** + adjetivo = un poco: «**hơi** dài». :: **không… lắm** = no muy: «**không** hợp **lắm**». :: **cũng… (thôi)** = pasable, sin más: «**cũng** được» = no está mal (= no me entusiasma). :: **e là / e rằng / sợ là** + frase = me temo que: «**E là** không kịp». :: **có lẽ… nên…** = quizá convendría: «**Có lẽ** anh **nên** xem lại». :: Regla práctica: cuanto más suave la frase, más seria suele ser la objeción.
