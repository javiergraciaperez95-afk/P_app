E Test 36 :: Repaso del capítulo 36: el tiempo, el tráfico y las noticias; **sắp, sẽ, đang, vừa, mới, đã**, **lại, luôn, còn, đều, vẫn**, las cifras aproximadas (**khoảng, gần, hơn, hàng trăm**), **theo… / …cho biết** y **thế mà, không ngờ**.
Q «bão» es…
+ tifón :: Bão sắp vào đất liền.
- inundación :: Es «lụt».
- niebla :: Es «sương mù».
- sequía :: No.
Q «sơ tán» es…
+ evacuar :: sơ tán hơn hai nghìn người dân.
- detener :: Es «bắt».
- investigar :: Es «điều tra».
- desmentir :: Es «phủ nhận».
Q «giờ cao điểm» es…
+ la hora punta :: Giờ cao điểm đường luôn đông.
- la medianoche :: Es «nửa đêm».
- el semáforo :: Es «đèn giao thông».
- el atajo :: Es «đường tắt».
Q «nhân chứng» es…
+ testigo :: Một nhân chứng cho biết…
- sospechoso :: Es «nghi phạm».
- víctima :: Es «nạn nhân».
- bombero :: Es «lính cứu hỏa».
H Trời tối rồi, chắc ___ mưa. Mang áo mưa đi. :: «está a punto de»
+ sắp :: sắp + verbo = a punto de.
- vừa :: «acaba de llover» no pediría chubasquero.
- đã :: Es pasado.
- từng :: No.
H Tôi ___ ăn cơm xong, chưa đói đâu. :: «acabo de»
+ vừa :: vừa… xong = acabar de terminar.
- sắp :: «a punto de» no explica que no tenga hambre.
- sẽ :: Es futuro.
- còn :: No.
H Ba chị em tôi ___ làm giáo viên. :: Las tres, sin excepción
+ đều :: sujeto plural + đều.
- lại :: Es «otra vez».
- sắp :: No.
- hơn :: No.
H Mười một giờ đêm rồi mà con ___ chưa ngủ à? :: «¿todavía…?»
+ vẫn :: vẫn chưa = todavía no.
- lại :: No.
- đều :: No.
- vừa :: No.
H ___ ba trăm người đã đến xem buổi biểu diễn. (unas) :: Cifra aproximada
+ Khoảng :: khoảng = unos, alrededor de.
- Đều :: No va delante de un número.
- Vẫn :: No.
- Thế mà :: No.
R Hôm qua mất điện, hôm nay lại mất điện.
+ Ayer se fue la luz y hoy se ha ido otra vez. :: lại + verbo = otra vez.
- Ayer se fue la luz, hoy no. :: Hoy también.
- Hoy vuelve la luz. :: No.
- Siempre hay luz. :: Al contrario.
R Theo bác sĩ, ông ấy sẽ ra viện vào tuần sau.
+ Según el médico, le darán el alta la semana que viene. :: theo + fuente.
- El médico se va la semana que viene. :: El que sale es el paciente.
- Sigue al médico por el hospital. :: Aquí «theo» es «según».
- Le dieron el alta la semana pasada. :: «tuần sau» es la que viene.
R Tôi đã nhắc ba lần. Thế mà anh ấy vẫn quên!
+ Se lo recordé tres veces. ¡Y aun así se le olvidó! :: thế mà… vẫn…
- Se lo recordé y por eso se acordó. :: Al contrario.
- No se lo recordé. :: Sí, tres veces.
- Se me olvidó a mí. :: No.
Q ¿Qué dices si un amigo te cuenta que a su abuela la han operado?
+ Tội nghiệp bà quá! Bây giờ bà thế nào rồi? :: «Pobre… ¿Cómo está ahora?»
- May quá! :: Sería alegrarse.
- Không thể tin được, tuyệt vời! :: No.
- Thế mà tôi không biết! Kệ. :: «Me da igual»: muy feo.
Q ¿Qué frase pondrías al final de una noticia cuando aún no se sabe por qué pasó?
+ Nguyên nhân đang được điều tra. :: «La causa se está investigando».
- Nguyên nhân là tin giả. :: No.
- Không ai quan tâm. :: «A nadie le importa».
- Hậu quả rất tốt. :: No.
A Gió mạnh cấp mười, gió giật cấp mười hai.
+ Viento de fuerza diez, con rachas de fuerza doce. :: cấp = grado de fuerza; gió giật = rachas.
- Diez grados de temperatura y doce de mínima. :: Habla del viento.
- Doce horas de viento. :: No.
- Viento flojo. :: Al contrario.
