@ 38 | Bài 38 · Kiểm tra 38 | Lección 38: test de repaso
E Test 38 :: Repaso del capítulo 38: la educación; hacer nombres con **sự, việc, nỗi, niềm, cái**; situar una opinión con **đối với, về mặt, xét về, về phần**; y hablar de cantidades de gente con **hầu hết, đa số, phần lớn, một số… số khác, không ít**.
Q «bắt buộc» es…
+ obligatorio :: Việc học tiểu học là bắt buộc.
- gratuito :: Es «miễn phí».
- limitado :: Es «có hạn».
- flexible :: Es «linh hoạt».
Q «phụ huynh» es…
+ los padres de un alumno :: Đa số phụ huynh phản đối.
- los profesores :: Es «giáo viên».
- los compañeros :: Es «bạn học».
- el director :: Es «hiệu trưởng».
Q «học vẹt» es…
+ aprender de memoria sin entender :: Điểm số khuyến khích học vẹt.
- estudiar por tu cuenta :: Es «tự học».
- ir a refuerzo :: Es «học thêm».
- estudiar en línea :: Es «học trực tuyến».
Q «động lực» es…
+ motivación :: Nhiều người nhanh chóng mất động lực.
- disciplina :: Es «kỷ luật».
- capacidad :: Es «năng lực».
- habilidad :: Es «kỹ năng».
H ___ phát triển của công nghệ làm thay đổi cách chúng ta học. :: Una idea abstracta: «el desarrollo»
+ Sự :: sự phát triển = el desarrollo.
- Nỗi :: Es para sentimientos tristes.
- Niềm :: Es para sentimientos alegres.
- Cuốn :: Es para libros.
H ___ dạy trẻ em cần rất nhiều kiên nhẫn. :: Una actividad: «el enseñar»
+ Việc :: việc + verbo.
- Niềm :: No.
- Nỗi :: No.
- Tấm :: No.
H Bà kể chuyện với ___ vui hiện rõ trên mặt. :: Un sentimiento alegre
+ niềm :: niềm vui.
- nỗi :: Es para lo triste.
- việc :: No.
- cái :: «cái vui» no es lo habitual para el sentimiento.
H Sau tai nạn, ___ sợ lớn nhất của anh ấy là lái xe. :: Un sentimiento que pesa
+ nỗi :: nỗi sợ.
- niềm :: Es para lo alegre.
- sự :: «sự sợ» no es lo habitual; con el miedo se dice «nỗi sợ».
- việc :: No.
H ___ người nước ngoài, thanh điệu là phần khó nhất. :: «Para los extranjeros…»
+ Đối với :: đối với + persona.
- Về mặt :: Va con un aspecto.
- Hầu hết :: Cambiaría la frase.
- Xét về :: Va con un aspecto.
H ___ chất lượng, hai trường này không khác nhau nhiều. :: «En cuanto a la calidad…»
+ Về mặt :: về mặt + aspecto.
- Đối với :: «Para la calidad» no tiene sentido.
- Về phần :: Va con personas.
- Một số :: No.
R Cái mới không phải lúc nào cũng tốt hơn cái cũ.
+ Lo nuevo no siempre es mejor que lo viejo. :: cái + adjetivo = «lo…».
- Lo nuevo siempre es mejor. :: «không phải lúc nào cũng» = no siempre.
- No hay nada nuevo. :: No.
- Lo viejo ya no sirve. :: No.
R Phần lớn thời gian trong ngày, trẻ em ở trường.
+ La mayor parte del día, los niños están en el colegio. :: phần lớn + cantidad o tiempo.
- Los niños están poco en el colegio. :: Al contrario.
- Casi todos los niños van al colegio. :: Habla del tiempo, no de cuántos niños.
- Los niños van al colegio todo el año. :: No.
R Một số em học vì điểm, số khác học vì thích.
+ Unos niños estudian por la nota; otros, porque les gusta. :: một số…, số khác…
- Todos estudian por la nota. :: No.
- A nadie le gusta estudiar. :: No.
- Los que sacan buena nota disfrutan. :: No dice eso.
Q En un debate, ¿cómo pides añadir algo?
+ Em xin bổ sung một ý. :: bổ sung = añadir.
- Em không nghĩ như vậy. :: Eso es discrepar.
- Tóm lại,… :: Eso es resumir.
- Đùa thôi! :: Eso es «es broma».
Q ¿Cuál de estas frases suena más a texto escrito?
+ Việc sử dụng công nghệ trong lớp học ngày càng phổ biến. :: «việc sử dụng…» convierte la acción en tema: estilo escrito.
- Bây giờ lớp nào cũng dùng máy tính ấy mà. :: Es de conversación.
- Dùng máy tính đi! :: Es una orden.
- Ôi, công nghệ! :: Es una exclamación.
A Sự cạnh tranh ở các thành phố lớn rất gay gắt.
+ La competencia en las grandes ciudades es feroz. :: sự cạnh tranh = la competencia; gay gắt = feroz.
- En las grandes ciudades no hay competencia. :: Al contrario.
- Las ciudades compiten entre sí. :: No dice eso.
- La competencia es mayor en el campo. :: No.
A Học một mình đòi hỏi tính tự giác và kỷ luật rất cao.
+ Estudiar solo exige mucha iniciativa y disciplina. :: đòi hỏi = exigir; kỷ luật = disciplina.
- Estudiar solo es muy fácil. :: Al contrario.
- No se puede estudiar solo. :: No dice eso.
- La disciplina no importa. :: No.
O Hầu hết học sinh đều sợ thi. :: Casi todos los alumnos temen los exámenes. :: hầu hết… đều…
O Về phần tôi, tôi không đồng ý. :: Por mi parte, no estoy de acuerdo. :: về phần tôi.
