E Test 32 :: Repaso del capítulo 32: banco, averías, reclamaciones y compras por internet; **chứ**, **ngay cả… cũng…**, **làm sao mà… được**, **hóa ra**, **thảo nào**, **tuy nhiên**, **ngược lại** y **trong khi đó**.
Q «chuyển khoản» es…
+ hacer una transferencia :: Chuyển khoản qua ứng dụng không mất phí.
- sacar dinero :: Es «rút tiền».
- ingresar dinero :: Es «gửi tiền».
- abrir una cuenta :: Es «mở tài khoản».
Q «bảo hành» es…
+ garantía :: Điều hòa này còn bảo hành không?
- seguro médico :: Es «bảo hiểm y tế».
- presupuesto :: Es «báo giá».
- mano de obra :: Es «tiền công».
Q «hoàn tiền» es…
+ devolver el dinero :: được hoàn tiền trong vòng ba ngày.
- pagar :: Es «thanh toán».
- ahorrar :: Es «tiết kiệm».
- pedir prestado :: Es «vay».
Q «hàng nhái» es…
+ una imitación :: Có người gửi hàng nhái.
- un artículo defectuoso :: Es «hàng lỗi».
- un pedido :: Es «đơn hàng» o «đặt hàng».
- una oferta :: Es «khuyến mãi».
H — Chị có biết lái xe không? — Biết ___! :: «¡Pues claro!»
+ chứ :: «chứ» al final de la respuesta = claro que sí.
- hoặc :: Es «o».
- nên :: Es «por eso».
- thôi :: «biết thôi» sería «solo sé eso».
H Tôi gọi cà phê đen ___ không phải cà phê sữa. :: «…y no…»
+ chứ :: A chứ không phải B.
- nên :: No.
- mà còn :: Sumaría, no corregiría.
- hoặc :: Es «o».
H Ngay cả ngày Tết bác sĩ ___ phải đi làm. :: La pareja de «ngay cả»
+ cũng :: ngay cả… cũng…
- nên :: No.
- thì :: No es la pareja.
- chứ :: No.
H Nhà không có điện, ___ mà tôi nấu cơm được? :: «¿cómo voy a…?»
+ làm sao :: làm sao mà… được?
- tại sao :: «tại sao» pregunta de verdad el motivo.
- bao giờ :: Es «cuándo».
- ở đâu :: Es «dónde».
R Anh ấy sống ở Pháp mười năm à? Thảo nào nói tiếng Pháp giỏi thế!
+ ¿Vivió diez años en Francia? ¡Con razón habla tan bien francés! :: thảo nào = ahora lo entiendo.
- Vivió en Francia, pero no habla francés. :: No.
- No sé si habla francés. :: No.
- Aprendió francés en diez días. :: Son diez años.
R Tôi tưởng cô ấy là người Nhật. Hóa ra cô ấy là người Hàn Quốc.
+ Creía que era japonesa. Resulta que es coreana. :: tưởng… hóa ra… = creía… resulta que…
- Es japonesa, como yo creía. :: Estaba equivocado.
- Es mitad japonesa, mitad coreana. :: No.
- No sé de dónde es. :: Ya lo sabe.
R Đến tên mình nó cũng không viết được.
+ No sabe escribir ni su propio nombre. :: đến… cũng không… = ni siquiera.
- Solo sabe escribir su nombre. :: Ni eso.
- Escribe su nombre muy bien. :: Al contrario.
- No quiere decir su nombre. :: No.
Q ¿Qué conector usarías? «El piso es grande y luminoso. ___, está muy lejos del centro.»
+ Tuy nhiên :: Hay contraste: sin embargo.
- Thêm vào đó :: Sumaría otra ventaja.
- Vì vậy :: Sería una consecuencia.
- Thảo nào :: No encaja.
Q ¿Qué frase compara dos cosas a la vez?
+ Ở Hà Nội đang lạnh. Trong khi đó, ở Sài Gòn vẫn nóng. :: trong khi đó = mientras tanto, en cambio.
- Ở Hà Nội đang lạnh. Vì vậy tôi mặc áo ấm. :: Es una consecuencia.
- Ở Hà Nội đang lạnh. Thảo nào tôi bị cảm. :: Es atar cabos.
- Ở Hà Nội đang lạnh chứ! :: Es una afirmación rotunda.
A Vòi nước trong bếp bị rò.
+ El grifo de la cocina gotea. :: vòi nước = grifo; bị rò = tener una fuga.
- Se ha cortado el agua en la cocina. :: Sería «mất nước».
- El fregadero está atascado. :: Sería «bị tắc».
- No hay agua caliente. :: No.
A Tôi muốn trả hàng và được hoàn tiền.
+ Quiero devolverlo y que me devuelvan el dinero. :: trả hàng = devolver; hoàn tiền = reembolso.
- Quiero cambiarlo por otro. :: Sería «đổi hàng».
- Quiero pagar con tarjeta. :: No.
- Quiero un descuento. :: No.
