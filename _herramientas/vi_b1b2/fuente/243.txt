@ 45 | Bài 45 · Kiểm tra 45 | Lección 45: test de repaso
E Test 45 :: Repaso del capítulo 45: la prensa; **titulares y siglas**, los **verbos de cita** (cho biết, khẳng định, nhấn mạnh, thừa nhận, dự báo), **nhờ vào, nhằm, so với cùng kỳ**, las **preguntas de entrevista** (xin ông cho biết, liệu… có… không) y la **voz de opinión** (rõ ràng, phải chăng, đáng lo ngại, đã đến lúc).
Q «khánh thành» es…
+ inaugurar :: Khánh thành tuyến metro thứ hai.
- empezar las obras :: Es «khởi công».
- cerrar :: Es «đóng cửa».
- rechazar :: Es «bác bỏ».
Q «xuất khẩu» es lo contrario de…
+ nhập khẩu :: xuất khẩu = exportar; nhập khẩu = importar.
- sản xuất :: Es «producir».
- chế biến :: Es «elaborar».
- tiêu dùng :: Es «consumir».
Q «nghệ nhân» es…
+ maestro artesano :: Phỏng vấn nghệ nhân Bát Tràng.
- periodista :: Es «phóng viên».
- experto :: Es «chuyên gia».
- representante :: Es «đại diện».
Q «đáng lo ngại» es…
+ preocupante :: Điều đáng lo ngại là…
- alentador :: Es «đáng mừng».
- lamentable :: Es «đáng tiếc».
- evidente :: Es «hiển nhiên».
Q ¿Qué significa «CSGT»?
+ cảnh sát giao thông :: La policía de tráfico.
- an toàn giao thông :: Es «ATGT».
- bảo hiểm y tế :: Es «BHYT».
- Ủy ban nhân dân :: Es «UBND».
Q ¿Qué significa «ĐH» en un titular?
+ đại học :: Universidad.
- điện thoại :: No.
- đồng hồ :: No.
- đô la :: No.
Q En el titular «Bộ Y tế: Dịch cúm đang tăng», los dos puntos equivalen a…
+ «dice que». :: La fuente, dos puntos, lo que afirma.
- «porque». :: No.
- «pero». :: No.
- «por ejemplo». :: No.
H Giám đốc ___ rằng công ty sẽ không sa thải ai. :: Una afirmación rotunda
+ khẳng định :: khẳng định = afirmar con seguridad.
- thừa nhận :: Es «admitir».
- dự báo :: Es «prever».
- phỏng vấn :: Es «entrevistar».
H Doanh thu tăng mạnh ___ thị trường xuất khẩu mở rộng. :: «gracias a»
+ nhờ vào :: nhờ vào + causa buena.
- nhằm :: Es «con el fin de».
- liệu :: No.
- phải chăng :: No.
H Chính phủ giảm thuế ___ hỗ trợ doanh nghiệp nhỏ. :: «con el fin de»
+ nhằm :: nhằm + objetivo.
- nhờ vào :: Es «gracias a».
- so với :: Es «respecto a».
- thực ra :: No.
H ___ bà cho biết kế hoạch của công ty trong năm tới. :: Abrir una pregunta con respeto
+ Xin :: Xin bà cho biết…
- Liệu :: «Liệu bà cho biết» no es la fórmula.
- Rõ ràng :: No.
- Đã đến lúc :: No.
H ___ giá nhà có giảm trong năm tới không? :: Pregunta sobre algo incierto
+ Liệu :: liệu… có… không?
- Xin :: No.
- Nhằm :: No.
- Nhờ :: No.
R Các chuyên gia dự báo giá vàng sẽ tiếp tục tăng.
+ Los expertos prevén que el oro seguirá subiendo. :: dự báo = prever.
- Los expertos admiten que el oro ha bajado. :: No.
- Los expertos desmienten la subida. :: No.
- El oro ya no subirá. :: Al contrario.
R Không thể phủ nhận rằng du lịch mang lại nhiều việc làm.
+ No se puede negar que el turismo trae mucho empleo. :: không thể phủ nhận rằng…
- Hay que negar que el turismo traiga empleo. :: Al contrario.
- El turismo no trae empleo. :: No.
- Se desmiente que haya turismo. :: No.
R Phải chăng chúng ta đang sống quá vội?
+ ¿No será que vivimos demasiado deprisa? :: phải chăng… ? = pregunta retórica.
- Vivimos demasiado despacio. :: No.
- ¿Tenemos prisa hoy? :: No pregunta eso.
- Hay que vivir más deprisa. :: Al contrario.
Q ¿Qué estructura tiene un buen artículo de opinión, según la lección?
+ Un caso concreto, dos o tres razones, reconocer la otra postura y cerrar con un llamamiento. :: «Đúng là… nhưng…» y «đã đến lúc…».
- Solo cifras, sin opinión. :: Eso es una noticia.
- Una lista de preguntas. :: Eso es una entrevista.
- Un titular y nada más. :: No.
Q ¿Qué expresión es la más repetida en las páginas de economía?
+ so với cùng kỳ năm ngoái :: «Respecto al mismo periodo del año pasado».
- thế nào cũng :: No.
- nói gì đến :: No.
- chẳng lẽ :: No.
A Kim ngạch xuất khẩu tăng gần ba mươi phần trăm so với cùng kỳ năm ngoái.
+ El valor de las exportaciones ha subido casi un treinta por ciento respecto al mismo periodo del año pasado. :: so với cùng kỳ năm ngoái.
- Las exportaciones han bajado un treinta por ciento. :: «tăng» es subir.
- Las importaciones han subido. :: Son las exportaciones.
- El año pasado no se exportó. :: No.
A Liệu nghề gốm thủ công có tồn tại được không?
+ ¿Podrá sobrevivir la alfarería artesanal? :: liệu… có… không?
- La alfarería artesanal ya ha desaparecido. :: No.
- ¿Dónde se hace cerámica? :: No.
- La alfarería sobrevivirá seguro. :: Es una pregunta abierta.
