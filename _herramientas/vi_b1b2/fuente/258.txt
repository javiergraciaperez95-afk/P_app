@ 48 | Bài 48 · Kiểm tra 48 | Lección 48: test de repaso
E Test 48 :: Repaso del capítulo 48: **refranes** y frases hechas, las **partículas del final** (cơ, mà, đấy, nhỉ, đâu, thôi, vậy), el habla **coloquial** y la jerga joven con **cứ… là…**, y los recursos de un **texto literario** (comparación, personificación, palabras repetidas).
Q «tục ngữ» es…
+ refrán :: Ông bà ta có câu…
- jerga :: Es «tiếng lóng».
- partícula :: Es «tiểu từ».
- comparación :: Es «so sánh».
Q «chém gió» es…
+ fanfarronear, hablar por hablar :: Thôi đừng chém gió.
- coquetear :: Es «thả thính».
- rendirse :: Es «bó tay».
- quedar en grupo :: Es «tụ tập».
Q «thì thầm» es…
+ susurrar :: Gió thì thầm.
- chisporrotear :: Es «lách tách».
- parpadear :: Es «chập chờn».
- relucir :: Es «sáng bóng».
Q «ký ức» es…
+ recuerdo, memoria :: Ký ức về cái bếp của bà.
- ceniza :: Es «tro».
- leña :: Es «củi».
- alero :: Es «mái hiên».
Q ¿Qué refrán habla de las malas compañías?
+ Gần mực thì đen, gần đèn thì sáng. :: Cerca de la tinta, negro.
- Uống nước nhớ nguồn. :: Habla de la gratitud.
- Có công mài sắt, có ngày nên kim. :: Habla de la constancia.
- Nước đến chân mới nhảy. :: Habla de dejarlo todo para el final.
Q ¿Qué refrán anima a quien empieza algo difícil?
+ Vạn sự khởi đầu nan. :: Todo comienzo es difícil.
- Tốt gỗ hơn tốt nước sơn. :: Habla de la apariencia.
- Lá lành đùm lá rách. :: Habla de la solidaridad.
- Chậm mà chắc. :: Habla de ir despacio y seguro.
Q «Hai mươi cái cơ?» expresa…
+ sorpresa porque es mucho: «¿veinte, nada menos?». :: «cơ» recalca.
- que son pocos. :: Eso sería «thôi».
- una orden. :: No.
- respeto. :: Eso sería «ạ».
Q «Không khó đâu» significa…
+ No es difícil para nada. :: «đâu» refuerza la negación.
- ¿Dónde está lo difícil? :: Aquí «đâu» no es «dónde».
- Es dificilísimo. :: Al contrario.
- No sé si es difícil. :: No.
H Tớ đã nói rồi ___! Sao cậu không nghe? :: Protesta: «¡si ya te lo dije!»
+ mà :: «mà» insiste o protesta.
- nhỉ :: Buscaría acuerdo.
- ạ :: Es respeto.
- thôi :: Limitaría.
H Hết xe buýt rồi. Thôi, đi bộ ___. :: «pues andando, qué remedio»
+ vậy :: «vậy» al final = qué remedio.
- cơ :: No.
- đấy :: Avisaría.
- à :: Preguntaría.
H Phim này hay ___? Tớ muốn xem lại lần nữa. :: Buscas que te den la razón
+ nhỉ :: «nhỉ» = ¿verdad?
- đâu :: Negaría.
- mà :: Protestaría.
- vậy :: No.
H Cứ uống cà phê buổi tối ___ tôi mất ngủ. :: La pareja de «cứ»
+ là :: cứ… là…
- nên :: No.
- chứ :: No.
- cơ :: No.
R Trong tin nhắn: «Mai đi đc ko?»
+ ¿Mañana puedes ir? :: đc = được; ko = không.
- Mañana no voy. :: Es una pregunta.
- ¿Adónde vas mañana? :: No.
- Mañana voy contigo. :: No.
R Con phố ngủ yên dưới ánh trăng.
+ La calle duerme tranquila a la luz de la luna. (La calle hace lo que una persona: personificación.) :: nhân hóa.
- En la calle duerme gente. :: La que «duerme» es la calle.
- No hay luna en la calle. :: Al contrario.
- La calle está muy animada. :: Al contrario.
R Tiếng cười của em trong như tiếng chuông.
+ Tu risa es clara como una campana. (Comparación con «như».) :: so sánh.
- Te ríes de la campana. :: No.
- La campana suena en tu casa. :: No.
- No te oigo reír. :: No.
Q ¿Cuál de estas frases NO deberías escribir en un examen?
+ Bài này khó quá, tớ bó tay luôn r. :: Es jerga y lleva abreviaturas de chat.
- Bài này tương đối khó đối với tôi. :: Es correcta.
- Theo tôi, bài này khá khó. :: Es correcta.
- Tôi cho rằng bài này không dễ. :: Es correcta.
Q En un texto literario, ¿qué hacen palabras como «rì rào» o «lách tách»?
+ Pintan un sonido o una imagen. :: No suavizan: describen.
- Suavizan un adjetivo. :: Eso lo hacen «nho nhỏ», «đèm đẹp».
- Indican respeto. :: No.
- Marcan el pasado. :: No.
A Nước đến chân mới nhảy.
+ No salta hasta que el agua le llega a los pies: lo deja todo para el final. :: Refrán.
- Salta al agua con alegría. :: No.
- El agua está fría. :: No.
- Hay que saltar pronto. :: Es lo que no hace.
A Tớ đùa thôi mà. Tớ có giận thật đâu.
+ Si era broma. No estaba enfadada de verdad. :: đùa thôi mà; có… đâu.
- Estoy muy enfadada, no es broma. :: Al contrario.
- ¿Dónde está la broma? :: No.
- No me gustan las bromas. :: No.
O Ông bà ta có câu: uống nước nhớ nguồn. :: Nuestros mayores decían: al beber agua, acuérdate de la fuente. :: Ông bà ta có câu:…
O Mưa rơi lách tách trên mái hiên. :: La lluvia repiquetea en el alero. :: lách tách pinta el sonido.
