E Seguro que sí: thế nào cũng, kiểu gì cũng, chắc hẳn :: **Thế nào (rồi) cũng** + verbo = seguro que, tarde o temprano, de un modo u otro: «Không tiêm thì **thế nào cũng** bị cúm» = Si no te vacunas, seguro que acabas con gripe. Predice algo que el que habla da por **inevitable**. :: **Kiểu gì cũng** es lo mismo, más coloquial: «Mai **kiểu gì** tôi **cũng** đến» = Mañana voy sí o sí. :: **Chắc hẳn** = seguramente, debe de (es una **deducción**, no una predicción): «Bà **chắc hẳn** mệt lắm» = Debe de estar usted muy cansada. Más formal: **ắt hẳn**. :: Compara con B1: **chắc** (seguramente) < **chắc chắn** (seguro, lo sé) ≈ **thế nào cũng** (seguro, no hay escapatoria). «Chắc hẳn» es la que usas cuando **deduces** por lo que ves.

Q ¿Qué argumento de Hoa pesa más?
+ Que tiene la tensión alta y, con una enfermedad previa, la gripe es más peligrosa. :: «Người có bệnh nền mà bị cúm thì nguy cơ nặng cao hơn nhiều».
- Que la vacuna es obligatoria. :: No lo es.
- Que le pagan por vacunarse. :: No.
- Que la gripe no existe. :: No.
Q ¿Qué deduce la señora Tư sobre su vecino?
+ Que seguramente no se había vacunado. :: «Chắc hẳn ông ấy cũng không tiêm».
- Que se vacunó dos veces. :: No.
- Que nunca estuvo enfermo. :: Estuvo ingresado.
- Que se mudó. :: No.
Q ¿En qué queda la conversación?

- Irá el año que viene. :: No.
- Hoa se vacunará por ella. :: No.
R Cứ đi theo đường này, thế nào cũng đến.
+ Sigue por esta calle y seguro que llegas. :: thế nào cũng = seguro que, de un modo u otro.
- Por esta calle nunca se llega. :: Al contrario.
- ¿Cómo se llega por esta calle? :: No pregunta.
- Quizá llegues por esta calle. :: Es más que quizá: seguro.
R Đi đường xa thế, anh chắc hẳn mệt lắm.
+ Con un viaje tan largo, debes de estar muy cansado. :: chắc hẳn = deducción.
- Seguro que no estás cansado. :: Al contrario.
- ¿Estás cansado del viaje? :: No es pregunta: lo deduce.
- Has descansado mucho. :: No.
