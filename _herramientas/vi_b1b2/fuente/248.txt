@ 46 | Bài 46 · Kiểm tra 46 | Lección 46: test de repaso
E Test 46 :: Repaso del capítulo 46: debatir; **opinar** (tôi cho rằng, theo quan điểm của tôi, cá nhân tôi, dường như), **acuerdo y desacuerdo** (đồng ý một phần, có điều, tôi e rằng), **pros y contras** (một mặt… mặt khác…, bên cạnh đó, xét cho cùng) y **convencer** (chi bằng, hãy thử tưởng tượng, vì những lý do trên).
Q «bằng chứng» es…
+ prueba, evidencia :: Anh có bằng chứng gì không?
- opinión :: Es «ý kiến».
- postura :: Es «lập trường».
- propuesta :: Es «đề xuất».
Q «khả thi» es…
+ viable :: Phương án nào khả thi hơn?
- justo :: Es «công bằng».
- razonable :: Es «hợp lý».
- negativo :: Es «tiêu cực».
Q «tác hại» es lo contrario de…
+ lợi ích :: tác hại = perjuicio; lợi ích = beneficio.
- bất đồng :: Es «desacuerdo».
- thử nghiệm :: Es «ensayo».
- lo ngại :: Es «reparo».
Q «tán thành» es…
+ estar a favor :: Ai tán thành xin giơ tay.
- oponerse :: Es «phản đối».
- interrumpir :: Es «ngắt lời».
- rebatir :: Es «phản bác».
Q ¿Cuál expresa una opinión formal y segura?
+ Tôi cho rằng… :: Considero que…
- Có lẽ… :: Quizá.
- Tôi không chắc lắm… :: No estoy muy seguro.
- Dường như… :: Parece que.
Q ¿Cuál es la forma más educada de discrepar?
+ Tôi hiểu ý chị, nhưng tôi nghĩ hơi khác một chút. :: Reconocer primero, matizar después.
- Chị sai rồi. :: Demasiado directa.
- Không đúng! :: Brusca.
- Tôi không muốn nghe. :: Maleducada.
H Tôi đồng ý ___ với anh: ý tưởng tốt, nhưng thời điểm chưa phù hợp. :: «en parte»
+ một phần :: đồng ý một phần.
- hoàn toàn :: Sería «del todo», y luego pone una pega.
- duy nhất :: No.
- bằng không :: No.
H Kế hoạch rất hay, ___ chi phí hơi cao. :: «lo que pasa es que»
+ có điều :: có điều = solo que.
- chi bằng :: Es «más vale».
- xét cho cùng :: Es «a fin de cuentas».
- một mặt :: Necesitaría «mặt khác».
H Một mặt, công nghệ giúp ta tiết kiệm thời gian. ___, nó làm ta ít nói chuyện với nhau hơn. :: «Por otro lado…»
+ Mặt khác :: một mặt… mặt khác…
- Bên cạnh đó :: Sumaría otra ventaja.
- Vì những lý do trên :: Cerraría.
- Chi bằng :: No.
H Du lịch đem lại việc làm. ___, nó còn giúp giới thiệu văn hóa Việt Nam. :: Otro punto del mismo lado
+ Bên cạnh đó :: bên cạnh đó = además.
- Trái lại :: Sería lo contrario.
- Tuy vậy :: Sería una pega.
- Mặt khác :: Introduciría la otra cara.
H Cãi nhau cũng không giải quyết được gì, ___ ngồi xuống nói chuyện. :: «más vale»
+ chi bằng :: chi bằng + propuesta.
- có điều :: No.
- dường như :: No.
- tôi e rằng :: No.
R Xét cho cùng, ai cũng muốn con mình hạnh phúc.
+ A fin de cuentas, todos quieren que sus hijos sean felices. :: xét cho cùng = bien mirado.
- Al final, nadie quiere hijos. :: No.
- Primero, hay que ser feliz. :: No ordena.
- No todos quieren que sus hijos sean felices. :: Al contrario.
R Tôi e rằng tôi không thể đồng ý với đề xuất này.
+ Me temo que no puedo estar de acuerdo con esta propuesta. :: tôi e rằng… = desacuerdo educado.
- Estoy totalmente de acuerdo. :: Al contrario.
- No he leído la propuesta. :: No.
- Temo que aprueben la propuesta. :: No.
R Dường như mọi người chưa hiểu rõ vấn đề.
+ Parece que la gente aún no ha entendido bien el problema. :: dường như = parece que.
- Seguro que todos lo han entendido. :: Al contrario.
- Nadie quiere entenderlo. :: No.
- El problema es fácil. :: No.
Q En un discurso, ¿para qué sirve «Có người sẽ nói rằng… Nhưng…»?
+ Para adelantarse a una objeción y contestarla. :: Es una técnica de quien convence.
- Para dar las gracias. :: No.
- Para cambiar de tema. :: No.
- Para terminar. :: No.
Q ¿Con qué frase cerrarías una intervención?
+ Vì những lý do trên, tôi đề nghị chúng ta bắt đầu ngay. :: Recoge lo dicho y pide algo.
- Trước hết, tôi xin giới thiệu. :: Es para empezar.
- Xin lỗi, cho tôi ngắt lời. :: Es para interrumpir.
- Một mặt,… :: Abre una comparación.
A Cấm mà không có phương án thay thế thì không công bằng.
+ Prohibir sin dar una alternativa no es justo. :: phương án thay thế = alternativa.
- Prohibir es siempre justo. :: No.
- No hay que prohibir nada nunca. :: No dice eso.
- La alternativa es prohibir. :: No.
A Phàn nàn mãi cũng không thay đổi được gì.
+ Quejarse sin parar no cambia nada. :: mãi = sin parar.
- Quejarse lo cambia todo. :: Al contrario.
- Nadie se queja. :: No.
- No hay nada que cambiar. :: No.
O Về cơ bản tôi đồng ý với chị. :: En lo básico estoy de acuerdo con usted. :: về cơ bản = básicamente.
O Hãy cùng nhau thử trong ba tháng. :: Probémoslo juntos durante tres meses. :: hãy cùng nhau + verbo.
