@ 35 | Bài 35 · Đi ăn cưới | Lección 35: invitado a una boda; «hãy», «đừng», «chớ» y los buenos modales
E Decir qué hacer y qué no :: **Hãy** + verbo = haz… (un consejo o una petición con cierta solemnidad): «**Hãy** đến đúng giờ». Hablando entre amigos casi no se usa: suena a cartel, a discurso o a libro. :: **Đừng** + verbo = no hagas…: «**Đừng** mặc đồ trắng». Es el «no» normal para pedir u ordenar. :: **Chớ** + verbo = no se te ocurra…: es un «đừng» más fuerte y algo anticuado; se oye en refranes y en consejos de mayores: «**Chớ** nói chuyện buồn trong đám cưới». :: Más suave que todos: **không nên** (no deberías) y **nên tránh** (conviene evitar).
E Lo que se dice en una boda :: A los novios: **Chúc mừng hạnh phúc!** (¡felicidades!), **Chúc hai bạn trăm năm hạnh phúc!** (que seáis felices cien años). :: No se lleva regalo: se da dinero en un sobre, **phong bì mừng cưới**. «**Đi ăn cưới**» es, literalmente, «ir a comer la boda».

  > Trước hết = antes de nada | anh hãy xem kỹ thiệp mời = mira bien la invitación | tiệc bắt đầu lúc mấy giờ = a qué hora empieza el banquete

Q ¿Qué se regala en una boda vietnamita?
+ Dinero en un sobre con tu nombre. :: «người ta mừng cưới bằng tiền… cho tiền vào phong bì».
- Flores blancas. :: El blanco se evita.
- Un electrodoméstico. :: No.
- Nada. :: Sí se da dinero.
Q ¿Por qué no hay que usar un sobre blanco?
+ Porque el blanco es el color del luto. :: «màu trắng là màu tang».
- Porque es de pobres. :: No.
- Porque se ensucia. :: No.
- Porque es el color de la novia. :: No es esa la razón que da.
Q ¿Qué debe decir Carlos cuando los novios lleguen a su mesa?
+ «Chúc hai bạn trăm năm hạnh phúc!» :: Es la fórmula del brindis.
- «Chúc mừng năm mới!» :: Eso es «feliz año nuevo».
- «Chúc ngủ ngon!» :: Es «buenas noches».
- «Xin chia buồn.» :: Eso se dice en un entierro.
Q ¿Cuál de estas tres es la más fuerte para prohibir?
+ chớ :: «chớ» = no se te ocurra.
- không nên :: Es la más suave.
- đừng :: Es la normal.
- hãy :: No prohíbe: anima a hacer.
H ___ quên mang thiệp mời nhé! :: «No te olvides…»
+ Đừng :: đừng + verbo = no hagas.
- Hãy :: Sería «olvídate», lo contrario.
- Nên :: Sería aconsejar olvidarla.
- Được :: No.
H Các bạn ___ cố gắng học mỗi ngày một chút. :: Un consejo solemne, en positivo
+ hãy :: hãy + verbo.
- chớ :: Es negativo.
- đừng :: Es negativo.

R Đừng về sớm quá, kẻo chủ nhà buồn.
+ No te vayas demasiado pronto, no sea que los anfitriones se disgusten. :: kẻo = no vaya a ser que.
- Vete pronto, que los anfitriones están tristes. :: Al revés.
- Los anfitriones quieren que te vayas. :: No.
- No vuelvas nunca a esa casa. :: No.
