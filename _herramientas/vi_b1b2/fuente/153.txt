E Test 27 :: Repaso del capítulo 27: la universidad, los exámenes y aprender idiomas; **tuy / mặc dù / dù… nhưng… vẫn…**, **càng… càng…**, **dù… cũng…**, **không phải… mà là…** y **được** delante y detrás del verbo.
Q «học bổng» es…
+ beca :: Em ấy được học bổng.
- matrícula :: Es «học phí».
- semestre :: Es «học kỳ».
- manual :: Es «giáo trình».
Q «thi trượt» es…
+ suspender :: Lo contrario de «thi đỗ».
- aprobar :: Es «thi đỗ».
- repasar :: Es «ôn thi».
- entregar :: Es «nộp bài».
Q «tiến bộ» es…
+ progresar :: Tiếng Việt của bạn tiến bộ nhiều.
- rendirse :: Es «bỏ cuộc».
- equivocarse :: Es «nhầm» o «mắc lỗi».
- memorizar :: Es «ghi nhớ».
Q «thuyết trình» es…
+ hacer una presentación :: Nhóm em thuyết trình về giao thông.
- pasar lista :: Es «điểm danh».
- debatir :: Es «thảo luận».
- levantar la mano :: Es «giơ tay».
H Tuy đề thi khó ___ cả lớp đều thi đỗ. :: La pareja de «tuy»
+ nhưng :: tuy… nhưng…
- nên :: Es la pareja de «vì».
- càng :: Es la pareja de otro «càng».
- mà là :: Es la pareja de «không phải».
H Mặc dù đã ôn thi rất kỹ, em ấy ___ lo. :: «…sigue preocupada»
+ vẫn :: mặc dù… vẫn…
- càng :: Necesitaría otro «càng».
- nên :: Sería consecuencia, no contraste.
- được :: No encaja.
H Càng luyện nghe nhiều, em ___ hiểu nhanh. :: «Cuanto más…, más…»
+ càng :: càng… càng…
- vẫn :: «vẫn» es «todavía».
- cũng :: «cũng» es «también».
- nhưng :: Es «pero».
H Người gọi điện không phải là thầy Quang ___ cô Lan. :: «…sino la profesora Lan»
+ mà là :: không phải là… mà là…
- nhưng :: Con «không phải» se usa «mà là».
- và :: «y» cambiaría el sentido.
- nên :: No.
R Dù ai nói gì, tôi vẫn tiếp tục học.
+ Diga quien diga lo que diga, sigo estudiando. :: dù + palabra de pregunta… vẫn…
- Como nadie dice nada, sigo estudiando. :: No es causa.
- Nadie me dice que estudie. :: No.
- Si alguien me lo dice, dejaré de estudiar. :: Al contrario.
R Ở đây không được chụp ảnh.
+ Aquí no está permitido hacer fotos. :: không được + verbo = prohibido.
- Aquí no consigo hacer fotos. :: Capacidad sería «không chụp được».
- Aquí no hay fotos. :: No.
- Aquí nunca he hecho fotos. :: No.
R Tôi không đọc được chữ trên bảng.
+ No consigo leer lo que pone en la pizarra. :: verbo + được = poder, ser capaz.
- No me dejan leer la pizarra. :: Permiso sería «không được đọc».
- No quiero leer la pizarra. :: No.
- En la pizarra no hay nada escrito. :: No.
Q ¿Cómo le pides a una profesora que hable más despacio?
+ Thưa cô, cô có thể nói chậm hơn được không ạ? :: Thưa cô… có thể… được không ạ?
- Cô nói chậm đi! :: Es una orden: de mala educación.
- Cô nói nhanh quá, em không thích. :: Es una queja, no una petición.
- Em nói chậm nhé. :: Eso es decir que tú hablarás despacio.
Q ¿Qué frase dice que cada vez hay más gente que estudia vietnamita?
+ Càng ngày càng nhiều người học tiếng Việt. :: càng ngày càng + nhiều.
- Tuy nhiều người học tiếng Việt nhưng khó. :: Dice otra cosa.
- Không phải ai cũng học tiếng Việt. :: «No todo el mundo…».
- Nhiều người đã bỏ cuộc. :: «Mucha gente se ha rendido».
A Thầy nói hơi nhanh nên em không ghi kịp.
+ Ha hablado usted un poco rápido y no me ha dado tiempo a apuntar. :: ghi kịp = dar tiempo a apuntar.
- Ha hablado usted muy despacio. :: «nhanh» es rápido.
- No he traído el cuaderno. :: No.
- Ya lo he apuntado todo. :: «không ghi kịp» = no ha dado tiempo.
A Cho dù khó, tôi cũng không bỏ cuộc.
+ Por difícil que sea, no me rindo. :: cho dù… cũng…; bỏ cuộc = rendirse.
- Como es difícil, me rindo. :: Al contrario.
- No es difícil, por eso sigo. :: No.
- Si es difícil, lo dejaré. :: No.
O Tuy bận nhưng anh ấy vẫn đi học. :: Aunque está ocupado, sigue yendo a clase. :: tuy… nhưng… vẫn…
O Càng học càng thấy tiếng Việt hay. :: Cuanto más estudio, más bonito me parece el vietnamita. :: càng… càng…
