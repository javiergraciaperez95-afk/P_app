E Examen final de B1 :: Veinticuatro preguntas sobre todo lo visto en los capítulos 26 a 37. Si aciertas veinte o más, estás listo para B2. Si fallas un bloque entero (causas, condiciones, comparar…), repasa ese capítulo antes de seguir: en B2 se da todo por sabido.
Q Capítulo 26. «Nhờ anh giúp nên tôi làm xong sớm» quiere decir…
+ Gracias a tu ayuda he terminado pronto. :: nhờ… nên… = causa buena.
- Por tu culpa he terminado tarde. :: Sería «tại».
- Aunque me ayudaste, no he terminado. :: No.
- Si me ayudas, terminaré pronto. :: No es una condición.
H Tiếng ồn ___ tôi không ngủ được. :: «hace que yo…»
+ làm cho :: cosa + làm cho + persona + cómo se queda.
- gây :: Detrás de «gây» va una cosa, no una persona.
- nhờ :: No.
- nên :: Le falta la causa con «vì».
H Mặc dù trời lạnh, bọn trẻ ___ ra sân chơi. :: Capítulo 27
+ vẫn :: mặc dù… vẫn…
- nên :: Sería consecuencia.
- càng :: Pediría otro «càng».
- mới :: No.
R Càng lớn tuổi, ông ấy càng vui tính.
+ Cuanto mayor se hace, más gracioso es. :: càng… càng…
- Aunque es mayor, es gracioso. :: No.
- De joven era más gracioso. :: Al contrario.
- Es mayor y por eso no es gracioso. :: No.
H Chị ấy không những nấu ăn ngon ___ hát rất hay. :: Capítulo 28
+ mà còn :: không những… mà còn…
- mà là :: Va con «không phải».
- chứ không :: Diría lo contrario.
- nên :: No.
Q ¿Cuál es correcta para preguntar «¿Vamos andando o en taxi?»?
+ Mình đi bộ hay đi taxi? :: En preguntas para elegir: hay.
- Mình đi bộ hoặc đi taxi? :: «hoặc» es para frases que no preguntan.
- Mình đi bộ mà đi taxi? :: No.
- Mình đi bộ nên đi taxi? :: No.
H ___ thấy mẹ về là em bé chạy ra cửa. :: Capítulo 29: una costumbre que no falla
+ Hễ :: hễ… là…
- Giá :: Es para lo irreal.
- Thà :: Es «prefiero».
- Tuy :: Es «aunque».
R Giá mà tôi biết sớm hơn thì đã không mua.
+ Si lo hubiera sabido antes, no lo habría comprado. :: giá mà… thì đã…
- Como lo supe antes, no lo compré. :: No lo supo.
- Si lo sé, no lo compraré. :: Eso es futuro, con «nếu».
- Lo compré porque lo sabía. :: No.
Q Capítulo 30. Estás en Hanói y vas a Huế, al sur. Dices…
+ Tôi vào Huế. :: Hacia el sur: vào.
- Tôi ra Huế. :: «ra» es hacia el norte.
- Tôi lên Huế. :: «lên» es a la montaña.
- Tôi sang Huế. :: «sang» es a otro país.
H Sau kỳ nghỉ, trông anh khỏe ___ nhiều. :: Un cambio a mejor
+ ra :: khỏe ra.
- đi :: «đi» es a peor: yếu đi.
- lại :: No.
- xuống :: No.
H Tôi mệt ___ không muốn ăn gì. :: Capítulo 31
+ đến nỗi :: adjetivo + đến nỗi + consecuencia.
- đành phải :: No.
- thay vì :: No.
- ít nhất :: No.
Q «Bệnh nhân không được ăn đồ cay» quiere decir que el paciente…
+ tiene prohibido el picante. :: không được = prohibido.
- no es capaz de comer picante. :: Sería «không ăn được».
- no necesita comer picante. :: Sería «không cần».
- no ha comido picante. :: No.
H Ngay cả giám đốc ___ không biết chuyện này. :: Capítulo 32
+ cũng :: ngay cả… cũng…
- nên :: No.
- thì :: No es la pareja.
- chứ :: No.
R Anh ấy là người Huế à? Thảo nào nói giọng khác thế!
+ ¿Es de Huế? ¡Con razón tiene ese acento tan distinto! :: thảo nào = ahora lo entiendo.
- Es de Huế, pero habla como en Hanói. :: No.
- No sé de dónde es. :: Ya lo sabe.
- Habla raro porque está enfermo. :: No.
H Con gái tôi cao ___ mẹ nó rồi. :: Capítulo 33: la misma altura
+ bằng :: cao bằng = igual de alto.
- nhất :: «cao nhất» no lleva comparación detrás.
- gấp :: Falta «đôi».
- thì phải :: Va al final.
Q ¿Cuál expresa más duda?
+ Hình như anh ấy ốm thì phải. :: hình như… thì phải = me parece, creo.
- Chắc chắn anh ấy ốm. :: Es la más segura.
- Anh ấy ốm. :: Lo afirma.
- Anh ấy ốm chứ! :: Lo afirma con fuerza.
Q Capítulo 34. Mai dice: «Tôi không thích phim này.» ¿Cómo lo cuentas?
+ Mai nói là chị ấy không thích phim này. :: Solo cambia la persona.
- Mai nói là tôi không thích phim này. :: Diría que eres tú.
- Mai hỏi không thích phim này. :: «hỏi» es preguntar.
- Mai bảo tôi không thích phim này. :: «bảo» sería una orden.
H Quán ___ chúng ta ăn hôm qua đóng cửa rồi. :: «El bar en el que comimos ayer…»
+ mà :: nombre + mà + explicación.
- rằng :: No.
- nên :: No.
- kẻo :: No.
H Ngôi đền này ___ xây từ thế kỷ mười một. :: Capítulo 35: pasiva
+ được :: được + verbo.
- bị :: Para algo malo.
- hãy :: No.
- kẻo :: No.
R Uống thuốc đi, kẻo ốm nặng hơn.
+ Tómate la medicina, no vayas a ponerte peor. :: kẻo = no vaya a ser que.
- No tomes la medicina, que te pone peor. :: Al contrario.
- Tómala cuando estés peor. :: No.
- Ya estás mejor. :: No.
H Nhanh lên, phim ___ bắt đầu rồi! :: Capítulo 36: a punto de
+ sắp :: sắp… rồi.
- vừa :: Ya habría empezado.
- từng :: No.
- còn :: No.
R Tôi đã gọi ba lần. Thế mà không ai nghe máy!
+ He llamado tres veces. ¡Y nadie lo coge! :: thế mà = y sin embargo.
- He llamado y me han contestado. :: Al contrario.
- No he llamado. :: Sí, tres veces.
- Llamaré tres veces. :: No es futuro.
Q Capítulo 37. ¿Cuál usarías para desearle algo a un amigo que se examina mañana?
+ Chúc cậu thi tốt! :: chúc + persona + lo bueno.
- Ước cậu thi tốt! :: «ước» es para sueños propios.
- Định cậu thi tốt! :: No tiene sentido.
- Nhằm cậu thi tốt! :: No tiene sentido.
Q ¿Cómo se cierra una carta a un profesor?
+ Kính thư, :: Cierre respetuoso.
- Thân, :: Es entre amigos.
- Hẹn gặp lại nhé! :: Demasiado informal.
- Tạm biệt cậu, :: Es para un amigo.
A Sở dĩ tôi học tiếng Việt là vì tôi muốn hiểu văn hóa Việt Nam.
+ Si estudio vietnamita es porque quiero entender la cultura de Vietnam. :: sở dĩ… là vì…
- Estudio vietnamita aunque no me interesa la cultura. :: No.
- Como entiendo la cultura, no estudio vietnamita. :: No.
- Quiero enseñar vietnamita. :: No.
A Phải kiên trì mới học giỏi ngoại ngữ được.
+ Solo siendo constante se llega a dominar un idioma. :: phải… mới…
- No hace falta constancia para aprender idiomas. :: Al contrario.
- Ya domino el idioma. :: No.
- Los idiomas nuevos son difíciles. :: «mới» aquí no es «nuevo».
O Tuy khó nhưng tôi không bỏ cuộc. :: Aunque es difícil, no me rindo. :: tuy… nhưng…
