E Test 28 :: Repaso del capítulo 28: aficiones, deporte y planes; **không những… mà còn…**, **ai / gì / đâu / lúc nào cũng**, **bất cứ… nào cũng**, **hay / hoặc**, **thay vì**, **ngoài… ra** y **trừ**.
Q «sưu tầm» es…
+ coleccionar :: Vợ anh ấy sưu tầm tem.
- dibujar :: Es «vẽ».
- actuar :: Es «biểu diễn».
- relajarse :: Es «thư giãn».
Q «huấn luyện viên» es…
+ entrenador :: Nhờ huấn luyện viên mới…
- jugador :: Es «cầu thủ».
- aficionado :: Es «người hâm mộ».
- campeón :: Es «vô địch».
Q «cắm trại» es…
+ ir de acampada :: Chúng tôi đi cắm trại bên bờ sông.
- ordenar la casa :: Es «dọn dẹp».
- quedarse en la cama :: Es «ngủ nướng».
- reservar entradas :: Es «đặt vé».
Q «Hai đội hòa một – một» quiere decir que…
+ empataron a uno. :: hòa = empatar.
- ganó el primero. :: Sería «thắng».
- perdió el primero. :: Sería «thua».
- no se jugó el partido. :: No.
H Em ấy không những học giỏi ___ chơi thể thao rất hay. :: «…sino que además…»
+ mà còn :: không những… mà còn…
- mà là :: Va con «không phải».
- nhưng :: Va con «tuy».
- nên :: Va con «vì».
H Ở thành phố này ___ cũng có quán cà phê. :: «en todas partes»
+ đâu :: ở đâu cũng = en todas partes.
- ai :: Es para personas.
- gì :: Es para cosas.
- bao giờ :: Es para el tiempo.
H ___ đi ăn ở ngoài, tối nay chúng ta nấu cơm ở nhà đi. :: «En vez de…»
+ Thay vì :: thay vì A, B.
- Ngoài :: Sería «además de».
- Trừ :: Es «excepto».
- Bất cứ :: Es «cualquier».
H Tất cả mọi người đều thích bộ phim, ___ tôi. :: «…menos yo»
+ trừ :: trừ = excepto.
- thay vì :: No encaja.
- hoặc :: Es «o».
- mà còn :: No encaja.
Q ¿Cuál es la correcta para preguntar «¿Quedamos el sábado o el domingo?»?
+ Mình hẹn nhau thứ bảy hay chủ nhật? :: En preguntas para elegir: hay.
- Mình hẹn nhau thứ bảy hoặc chủ nhật? :: «hoặc» no es para elegir en una pregunta.
- Mình hẹn nhau thứ bảy trừ chủ nhật? :: No tiene sentido.
- Mình hẹn nhau thứ bảy mà còn chủ nhật? :: No tiene sentido.
R Anh ấy chơi môn gì cũng giỏi.
+ Se le da bien cualquier deporte. :: môn gì cũng = cualquier (asignatura o deporte).
- ¿Qué deporte se le da bien? :: Con «cũng» no es pregunta.
- No se le da bien ningún deporte. :: Sería con «không».
- Solo se le da bien un deporte. :: Al contrario.
R Bất cứ ai cũng có thể tham gia.
+ Cualquiera puede participar. :: bất cứ ai = cualquiera.
- Nadie puede participar. :: Sería «không ai».
- ¿Quién puede participar? :: No es pregunta.
- Solo algunos pueden participar. :: No.
R Ngoài chạy bộ ra, tôi còn tập bơi.
+ Además de correr, practico natación. :: ngoài… ra… còn…
- En vez de correr, nado. :: Sería «thay vì».
- Corro, pero no nado. :: No.
- Solo corro. :: No.
Q ¿Qué frase dice «Aparte de ti, no conozco a nadie aquí»?
+ Ngoài cậu ra, tớ không quen ai ở đây. :: ngoài… ra + negación = excluye.
- Ngoài cậu ra, tớ còn quen nhiều người ở đây. :: Esa suma: «además de ti, conozco a muchos».
- Thay vì cậu, tớ quen người khác. :: «En vez de ti…»: otra cosa.
- Ai tớ cũng quen, trừ cậu. :: «Conozco a todos menos a ti»: lo contrario.
A Cuối tuần nào em cũng mang máy ảnh ra phố.
+ Todos los fines de semana salgo a la calle con la cámara. :: cuối tuần nào… cũng = todos los fines de semana.
- Este fin de semana compraré una cámara. :: No.
- Nunca salgo con la cámara. :: Al contrario.
- ¿Qué fin de semana salimos a hacer fotos? :: No es pregunta.
A Phim gì tớ cũng xem được, miễn là không phải phim kinh dị.
+ Veo cualquier película, con tal de que no sea de terror. :: miễn là = con tal de que.
- Solo veo películas de terror. :: Al contrario.
- No me gusta ninguna película. :: No.
- Prefiero las comedias a las de terror. :: No compara.
O Tối nay tôi sẽ đọc sách hoặc nghe nhạc. :: Esta noche leeré o escucharé música. :: En frases normales: hoặc.
