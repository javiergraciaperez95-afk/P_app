E ¿Para qué?: để y nhằm :: **Để** + verbo = para: «Tôi học tiếng Anh **để** đi du học». Es el «para» de todos los días. :: **Nhằm** + verbo = con el fin de. Es formal: aparece en solicitudes, noticias y documentos: «Chương trình này **nhằm** giúp sinh viên nghèo» = Este programa tiene como fin ayudar a los estudiantes sin recursos. :: **Để + persona + verbo** = para que alguien haga algo: «Tôi gửi hồ sơ sớm **để** họ **có** thời gian xem» = Mando la documentación pronto para que tengan tiempo de verla.
E Tener un plan: định, dự định, tính :: **Định** + verbo = pensar hacer algo, tener intención: «Tôi **định** nộp đơn tháng sau». :: **Dự định** es lo mismo, más serio; también es un nombre: «**Dự định** của em là gì?» = ¿Cuáles son tus planes? :: **Tính** (coloquial, sobre todo en el sur) = tener pensado. :: **Sẽ** promete; **định** solo anuncia la intención. Compara: «Tôi **sẽ** đi» (voy seguro) / «Tôi **định** đi» (tengo pensado ir).

Q ¿Cuál es la más formal?
+ Dự án này nhằm bảo vệ môi trường. :: «nhằm» es propio de documentos y noticias.
- Dự án này để bảo vệ môi trường. :: Es la normal.
- Dự án này cho bảo vệ môi trường. :: No se dice así.
- Dự án này vì bảo vệ môi trường. :: «vì» da la causa.
H Tôi tiết kiệm tiền ___ mua xe máy. :: «para»
+ để :: để + verbo = para.
- nên :: Es «por eso».
- kẻo :: Es «no vaya a ser que».
- do :: Es «por causa de».
H Cuối tuần này anh ___ làm gì? :: «¿Qué piensas hacer?»
+ định :: định + verbo = tener intención de.
- nhằm :: Demasiado formal y no va con «làm gì» así.
- đành :: Es «no tener más remedio».
- từng :: Es «alguna vez».
R Tôi nói chậm để mọi người hiểu.
+ Hablo despacio para que todos entiendan. :: để + persona + verbo = para que…
- Hablo despacio porque todos entienden. :: No es causa.
- Todos hablan despacio para que yo entienda. :: Al revés.
- Entiendo cuando hablan despacio. :: No.
A Em dự định thi lại vào tháng hai.
+ Tengo previsto volver a examinarme en febrero. :: dự định = tener previsto; thi lại = examinarse otra vez.
- Me examiné en febrero. :: Es un plan, no algo hecho.
- No pienso examinarme más. :: Al contrario.
- El examen dura dos meses. :: No.
