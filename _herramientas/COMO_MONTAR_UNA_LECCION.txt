CÓMO FUNCIONA EL SISTEMA DE TRADUCCIONES — PAGLOT
==================================================
Para el agente que construye lecciones. Escrito el 17-10-2026.
Esto describe cómo funciona HOY el código que ya está en producción.
Si te saltas algo, `_herramientas/validar_v2.mjs` te lo dirá y la lección no entra.


0. EN UNA FRASE
---------------
Cada lección son 13 archivos: 1 con la estructura (sin texto) y 12 con el texto,
uno por cada idioma de la app. Los 12 son iguales en forma; ninguno es especial.
El código los junta al cargar y cada alumno lee en su idioma.


1. QUÉ HAY EN DISCO
-------------------
Idiomas/cursos/es/lessons/001.json                    SOLO estructura. Ni una frase.
Idiomas/cursos/es/lessons/capitulos.json              Los 26 capítulos, con «nivel» y «nombre».
Idiomas/cursos/es/traducciones/<idioma>/001.json      Todo el texto de la lección 001,
                                                      en ese idioma.
Idiomas/cursos/es/traducciones/<idioma>/_etiquetas.json   Nombres de las categorías y
                                                      funciones gramaticales.
_herramientas/ESQUEMA_V2.txt                          La norma completa.
_herramientas/validar_v2.mjs                          La puerta.

<idioma> es siempre uno de los 12: en es vi zh pt fr ja it ko ru de id.
En el curso de español, traducciones/es/ contiene el mismo juego de claves que en/:
NO es una copia del archivo base, es el texto español que se estudia.

--------------------------------------------------
{

  "nivel": "A1",
  "palabras": {
    "hola": { "pron": "O-la", "cat": "interj" },
    "la mesa": { "pron": "la ME-sa", "cat": "sust", "genero": "f" },
    "Lucía": { "propio": true }
  },
  "bloques": [
    { "id": "b1", "tipo": "explicacion" },
    { "id": "b2", "tipo": "dialogo", "frases": [
        { "quien": "Lucía", "sintaxis": { … } },
        { "quien": "Pablo", "sintaxis": { … } } ] },
    { "id": "b3", "tipo": "vocabulario", "palabras": ["hola", "adiós"] },
    { "id": "b4", "tipo": "gramatica", "ejemplos": [ { "sintaxis": { … } } ] },
    { "id": "b5", "tipo": "texto", "registro": "literario", "frases": [
        { "parrafo": 0, "sintaxis": { … } }, …  (3 a 5 frases por párrafo) ] },
    { "id": "b6", "tipo": "test",    "opciones": [ { "correcta": true }, { "correcta": false }, { "correcta": false } ] },
    { "id": "b7", "tipo": "huecos",  "opciones": [ … ] },
    { "id": "b8", "tipo": "ordenar" },

OJO: aquí NO hay titulo, intro, ni ninguna frase. Tampoco el consejo ni la glosa de
las palabras. Todo el texto está en los 12 catálogos.


3. EL CATÁLOGO DE CADA IDIOMA — texto plano
-------------------------------------------
Un objeto plano clave → texto. Ni arrays, ni objetos anidados. Las MISMAS claves en
los 12 archivos. Ejemplo real, en/001.json:

{
  "idioma": "en",
  "leccion": "001",

  "titulo": "Hello!",
  "intro": "First lesson. Today you learn to say hello…",

  "b1.titulo": "Greeting people in Spanish",
  "b1.texto": "In Spanish there is one greeting that works at any time of day: **hola**…",

  "b2.titulo": "At the bakery",
  "b2.f0.texto": "Hi!",
  "b2.f1.texto": "Hi, Lucía!",

  "b4.titulo": "Buenos días, buenas tardes",
  "b4.texto": "Greetings with «buenos» or «buenas» agree with…",
  "b4.e0.texto": "Good morning.",
  "b4.e1.texto": "Good night.",

  "b5.titulo": "The first light",
  "b5.f0.texto": "The bakery on the corner opens before the sun comes up.",
  "b5.f1.texto": "When Lucía pushes the door, it smells of warm flour.",


  "b6.titulo": "Which greeting?",
  "b6.pregunta": "It's ten in the morning. How do you greet your teacher?",
  "b6.o0.refuerzo": "Correct: in the morning you say «buenos días».",
  "b6.o1.refuerzo": "That's for the night, not for the morning.",
  "b6.o2.refuerzo": "«Hasta luego» is a goodbye, not a greeting.",

  "b7.titulo": "Complete",
  "b7.pregunta": "Complete the greeting.",
  "b7.frase": "___ días, señora Ruiz.",
  "b7.o0.refuerzo": "«Días» is masculine plural: buenos días.",

  "b8.titulo": "Put in order",
  "b8.frase": "Hasta luego, Pablo.",
  "b8.traduccion": "See you later, Pablo.",

  "b9.titulo": "Write it",
  "b9.pregunta": "Write in Spanish: «thank you».",

  "p.hola.glosa": "hello, hi",
  "p.hola.consejo": "The h is silent in Spanish: «hola» sounds like «ola»."
}

En el curso de español, es/001.json lleva EXACTAMENTE las mismas claves, pero los
valores de las claves «de estudio» son el texto español original.


4. LAS DOS CLASES DE CLAVE   <-- esto es lo que hay que entender
----------------------------------------------------------------
4.1 DE ESTUDIO — la frase o palabra en ese idioma
    b2.f<n>.texto    cada frase del diálogo
    b4.e<n>.texto    cada ejemplo de gramática
    b5.f<n>.texto    cada frase de la lectura (lleva «parrafo» y «sintaxis» en el esqueleto)
    b6.o<n>          el texto de cada opción
    b7.frase         la frase del hueco o del ejercicio de ordenar
    n empieza en 0.

    En el idioma del curso lleva el texto tal cual; en los otros 11, su traducción.
    Son las palabras que el alumno tiene que reconocer (para la sintaxis, para los
    juegos, para el cuaderno), por eso existen en todos los idiomas.

4.2 DE AYUDA — la explicación para el alumno
    titulo, intro
    b<n>.titulo             título del bloque
    b<n>.texto              explicación (b1) y gramática (b4)
    b<n>.pregunta           enunciado del ejercicio
    b<n>.traduccion         traducción de la frase de «ordenar»
    b<n>.o<m>.refuerzo      por qué cada opción está bien o mal
    p.<palabra>.glosa       significado de la palabra
    p.<palabra>.consejo     la explicación que da la tutora al pulsar «?»

    Cada una va en su idioma: esto es lo que lee el alumno para entender.
    Dentro de un consejo o una explicación, las palabras estudiadas se quedan en el
    idioma del curso: se traduce el comentario, no el ejemplo.

4.3 NUNCA escribas las claves a mano.
    Pídelas al validador, que las deriva del esqueleto:
        node _herramientas/validar_v2.mjs es 007 --claves
    Devuelve dos listas: de_estudio y de_ayuda. Los 12 catálogos llevan las dos.


5. CÓMO LO LEE LA APP (lo que hace lessons.js)
----------------------------------------------
El archivo de la lección solo dice QUÉ hay; los catálogos dicen CÓMO se dice.

1. Se piden dos catálogos:
     - el del idioma del alumno  (el que tenga puesto en la app)
     - el de «en», como respaldo, si el primero no es inglés
2. Para cada texto:
     - las claves de AYUDA salen del catálogo del alumno (y si falta, del inglés);
     - las claves de ESTUDIO salen del catálogo del IDIOMA DEL CURSO,
       y se guardan además bajo el código de cada idioma.
3. El resultado de cada texto es un objeto  { "<idioma>": "…", "idioma": "…" }.
   Y tr() resuelve:  valor[idioma]  →  valor.en  →  valor.es.
4. El análisis sintáctico se aplana de los niveles 1-2-3 a una lista plana, y cada
   unidad se pinta con su etiqueta traducida, sacada del _etiquetas.json del idioma.

Por eso un idioma que falta nunca rompe la lección: se cae al inglés.

Caso especial: si la app está en español Y se estudia español, las explicaciones
salen en inglés, que es el idioma pivote (el mismo criterio que ya usaba tr()).


6. EL ANÁLISIS SINTÁCTICO
-------------------------
Cada frase de diálogo y cada ejemplo de gramática lleva "sintaxis" en el ESQUELETO:

  "sintaxis": {
    "oracion": "bimembre",          o "unimembre"
    "sujeto": "omitido",            "expreso" u "omitido" (solo si es bimembre)
    "unidades": [                   nivel 1
      { "funcion": "PRED", "texto": "Soy de España", "nucleo": "Soy",
        "partes": [                 nivel 2
          { "funcion": "V", "texto": "Soy", "nucleo": "Soy" },
          { "funcion": "ATRIB", "texto": "de España", "nucleo": "España",
            "partes": [             nivel 3
              { "funcion": "PREP", "texto": "de" },
              { "funcion": "TERM", "texto": "España", "nucleo": "España" } ] } ] } ]
  }

Se comprueba automáticamente:
  - las unidades de cada nivel, EN ORDEN, reconstruyen el texto del nivel superior
    (ignorando puntuación y mayúsculas);
  - la función existe en el catálogo;
  - el «nucleo» aparece dentro de su «texto»;
  - bimembre + expreso → exactamente una unidad SUJ; omitido → ninguna;
  - exactamente una unidad PRED;
  - un unimembre no lleva SUJ ni PRED;
  - una unidad V no se descompone: su núcleo es el verbo.


7. CATÁLOGOS CERRADOS (no se traducen 12 veces)
-----------------------------------------------
  cat:      sust adj verb adv pron prep conj art num interj expr frase propio
  funcion:  SUJ PRED VOC INTERJ NEG CONJ
            V CD CI ATRIB CPVO CRV CAG
            CCL CCT CCM CCF CCC CCA CCINSTR CCCOMP
            N DET ADY CN APOS PREP TERM ADV PRON CUANT INF GER PART AUX

Los nombres visibles están UNA vez por idioma en traducciones/<idioma>/_etiquetas.json.


8. RECETA: AÑADIR UNA LECCIÓN
-----------------------------
1) Escribe Idiomas/cursos/es/lessons/NNN.json (esqueleto, sin texto).
2) Pide las claves:   node _herramientas/validar_v2.mjs es NNN --claves
3) Escribe los 12 catálogos Idiomas/cursos/es/traducciones/<idioma>/NNN.json
   con EXACTAMENTE esas claves (de_estudio + de_ayuda).
4) Valida:            node _herramientas/validar_v2.mjs es NNN -v
5) Repite hasta que diga «Todo correcto». No hay avisos que ignorar.

Contenido (se comprueba, y si no, se rehace):
- apolítico y neutro: nada de partidos, gobiernos, elecciones, conflictos, religión,
  ni juicios sobre grupos de personas. Si algo puede leerse en clave política, se cambia;
- ejercicios para TDAH: UNA decisión por bloque, enunciado ≤15 palabras, 3-4 opciones,
  un «refuerzo» que explique por qué cada opción está bien o mal;
- el texto literario son dos párrafos de verdad. Se mide en caracteres útiles y cada
  carácter chino o japonés cuenta doble (lleva más información que una letra latina).


9. ERRORES QUE YA HEMOS COMETIDO (no los repitas)
-------------------------------------------------
- Poner «partes» dentro de una unidad V: el núcleo del verbo no se descompone.
- Dejar texto en el archivo de la lección: no puede llevar ni una frase.
- Creer que es/ es una copia del esqueleto: es el catálogo del español, con sus 12
  claves de ayuda y sus claves de estudio.
- Copiar el texto del curso a la clave de traducción de otro idioma: el validador no
  lo detecta solo, y el alumno lee español traducido como alemán. Comprueba que
  las traducciones NO son iguales al original.
- Meter una clave nueva en de.js / id.js / ru.js ANTES de «...en»: el spread la pisa
  y vuelve a salir en inglés. Va después.
- Añadir un campo a un bloque sin meterlo en CAMPOS de lessons.js: la app lo avisa
  y lo ignora.
